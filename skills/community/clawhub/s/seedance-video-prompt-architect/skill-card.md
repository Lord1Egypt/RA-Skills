## Description:

Turn rough creative briefs into structured Seedance video prompt packs, reference-aware motion plans, focused variants, and debugging loops.

This skill is ready for commercial/non-commercial use.

## Publisher:

[gpt-img-2](https://clawhub.ai/user/gpt-img-2)

MIT-0

## Use Case:

External creators, developers, and marketing teams use this skill to turn Seedance video ideas into structured prompt packs for text-to-video, image-to-video, video-to-video, first-last-frame transitions, and multi-shot storyboards.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The optional setup asks users to run an unpinned GitHub MCP package through npx, which expands local execution risk beyond the text-only skill.

Mitigation: Before enabling the MCP, review the GitHub repository, prefer a pinned commit or verified release, and run it only in a restricted environment without sensitive files, credentials, or broad network access.

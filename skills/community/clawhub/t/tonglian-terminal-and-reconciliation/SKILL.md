# 通联终端申请 & VIP对账单配置 & 手续费发票申请

## 通联终端申请流程（增终）

### 触发条件
当有新门店需要申请刷卡终端时（如客户发邮件申请POS机、用户说「申请终端」「增终」等）。

### 第一步：收集信息
| 字段 | 说明 |
|:----|:-----|
| 门店名称/编码 | 客户提供的门店名称或内部门店号 |
| 地址 | 详细地址（含省/市/区） |
| 联系人 | 姓名 |
| 联系电话 | 手机号 |
| 主体公司名称 | 如「汤丽柏琦（上海）商贸有限公司」 |
| 通联商户号 | 客户提供或从门店清单查询 |
| 终端数量 | 未说明默认1台 |

### 第二步：查通联商户号（如未提供）
- 在飞书搜索 `主体公司名称`，找到对应的账号清单/门店信息表
- 从表中提取该主体的 **通联商户号**
- 同时确认门店清单中的标准门店名称（不是自己编的）

### 第三步：制作通联-收钱吧商户门店信息表

**模板规则（永远不变）：**
- 复制 `通联-收钱吧商户门店信息表.xlsx`（工作区根目录），**只替换数据行**，不要重建
- **保留原格式**：标题合并居中（A1:K1）、表头标黄加粗等，不要改变样式
- **11列固定**：序号、通联商户号、门店名称、省、市、区、详细地址、门店联系人、门店联系电话、终端数量、其它特殊性要求
- 门店名称从门店清单或客户邮件中提取，不是自己编的
- 终端数量没说明就填1
- **其它特殊性要求永远不填**，保持空白/None
- 纯数字字段（通联商户号、联系电话等）设为文本格式（`number_format='@'`）

### 第四步：生成邮件正文

**固定模板，永远不要改：**

> ⚠️ 商户号后面括号里的地区**永远写省份全称**（如：北京、江苏、广东），**不准用缩写**（如：京、苏、粤）。

> **主题：** {品牌}-新增终端{日期MMDD}
>
> Hi 晓丽，
>
> 附件请查收以下商户新增门店，申请新终端的申请，请帮忙处理，谢谢~
>
> {主体公司名称}
> 商户号：{通联商户号}（{省份/直辖市全称}）
> 申请新增终端：{数量}
>
> Thanks and regards
> Rebecca Chen | 收钱吧（WOSAI）

### 第五步：先发给用户确认
- 文件发回飞书给用户（message 工具发文件）
- 邮件正文以文本消息发回给用户（方便复制）
- **等用户说「发」后才能发出**

### 第六步：发邮件
- **收件人**：毛晓丽（maoxl@allinpay.com）
- 带上附件（Excel文件 base64 编码）
- 发完告知用户已发出

## 通联增商流程（集团商户下新增子商户）

### 触发条件
当用户要求做通联增商（集团商户下新增子商户），如「需要增商」「新增商户」等。

### 第一步：获取模板
- 用户会提供增商信息表模板（集团商户版），**不要改变模板格式**
- 模板里的银行和费率信息**无需修改**

### 第二步：填写增商信息
- 学习已有数据格式，把用户指定的地区增商信息填写好，**一个地区一行**
- 模板里已有的数据行记得**删除**，不要重复提供

### 第三步：制作通联终端申请表
- 剩下的门店，查找通联商户号，按「通联终端申请流程」制作申请表

### 第四步：发邮件给毛晓丽
- 做完两个表后，一起发邮件
- **发前必须给用户确认**
- 邮件模板统一使用以下格式：

> 附件请查收以下商户新增门店，申请新终端的申请。辛苦帮忙尽快处理，感谢
>
> {商户名称}
> 商户号：{通联商户号}（{地区全称}）
> 申请终端数：{数量}

### 第五步：特殊要求写明
- 如子商户号需开通平台退货/联机退货权限等特殊要求，在邮件正文写明

## VIP对账单配置流程

### 触发条件
当有新增门店/终端需要配置对账单时（用户说「配置对账单」「X项目对账单」「XX配置」等）。

### 第一步：收集信息
用户提供以下数据（或从门店清单/账号清单提取）：
| 字段 | 说明 |
|:----|:-----|
| 收钱吧商户号 | 如 1680009161673 |
| 收钱吧商户名称 | 如 武汉市武昌区华苑茗聚茶业经营部 |
| 收钱吧门店号 | 如 1580000011470007 |
| 通联商户号 | 通联侧的商户号（注意和收钱吧商户号区分） |
| 通联小票终端号 | **只填新增的终端**，一个终端一行 |
| 门店名称 | 标准门店名称 |

### 第二步：制作 Excel

**固定模板（6列，永远不要改）：**
| 列 | 字段 | 示例 |
|:---|:-----|:-----|
| A | 收钱吧商户号 | 1680006527796 |
| B | 收钱吧商户名称 | 武夷山岩谷正岩茶业有限公司 |
| C | 收钱吧门店号 | 1580000009654110 |
| D | 通联商户号 | 37807636 |
| E | 通联小票终端号 | 13986896（只填新增的终端） |
| F | 门店名称 | 武夷山儒士馆 |

**操作规范：**
- **一个终端一行**，之前配过的终端不要重复加
- **永远不要改模板的列和样式**
- 列顺序、列名、数量固定不变
- 纯数字字段（商户号、门店号、终端号等）必须设为文本格式
- 表头加粗、背景色、边框需保持一致

### 第三步：命名文件
- 文件名格式：`VIP-{任务名称}-MMDD`
- **纯英文**，不要中文
- 任务名称用项目标识，如 `HXY_XM`、`Dyson`、`Prada` 等
- 例：`VIP-HXY_XM-0702.xlsx`

### 第四步：交付给康文博
- 先用 **message 工具** 发文件给用户确认（带上 filePath 参数直接作为附件发送）
- 确认无误后：
  1. 通过 message 工具将文件发给 **康文博**
  2. 在飞书给康文博建一个任务，附上文件，**截止时间为当天**

## 通联手续费发票申请流程

### 触发条件
当用户发来客户账单说「申请手续费发票」时触发。

### 第一步：用户发送账单
- 用户发送客户的账单（图片/文件）
- 算出上月合计的刷卡手续费

### 第二步：填写模版
- 用户提供刷卡手续费申请模版
- 如实填写模版中的内容，**仅修改模版中的月份、金额、申请日期**
- 如果是 Prada 和 Leica 的，收件邮箱写 rebecca@shouqianba.com

### 第三步：发邮件
- **收件人**：刘卓佳（liuzj1@allinpay.com）
- **主题**：【开票主体】.通联手续费发票申请.YYMM
- **正文**：附件请查收【开票主体】MMDD的通联刷卡手续费的申请表和明细。烦请转发贵司财务开出发票，感谢支持～

## 通联商户号 vs 收钱吧商户号 区分
⚠️ **常见错误**：不要混淆这两个号。
- **收钱吧商户号**：16开头的纯数字，如 `1680009161673`
- **通联商户号**：通常由数字和字母组成，如 `6605210539967TB`

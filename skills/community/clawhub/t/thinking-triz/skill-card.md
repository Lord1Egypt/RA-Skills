## Description:

When two design requirements seem mutually exclusive, name the contradiction, separate conflicting states, then invent a concrete no-compromise resolution.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill to resolve architecture, API, and system design contradictions by testing separations and documenting a concrete resolution instead of accepting midpoint tradeoffs.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can influence architecture, API, or system design decisions even though it does not execute code.

Mitigation: Review each TRIZ resolution against project constraints, measurements, and implementation realities before acting on it.

Risk: Applying the method when there is no clear technical contradiction can produce forced or decorative reasoning.

Mitigation: Use the template gate and over-application guard; skip TRIZ when measurement or a standard pattern resolves the issue.

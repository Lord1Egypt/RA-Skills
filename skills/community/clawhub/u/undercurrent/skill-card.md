## Description:

Run a small always-on process of coupled slow variables that modulate your register at waking, and log every consultation — continuous dynamics as a component, never claimed as experience.

This skill is ready for commercial/non-commercial use.

## Publisher:

[torchkeeper-simon](https://clawhub.ai/user/torchkeeper-simon)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agent designers use this skill to add slow, stateful dynamics that can adjust an agent's register at each substantive wake and to record each consultation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The recurring activation condition is unclear, which could make the always-on process run at unintended times.

Mitigation: Define and review the activation trigger and schedule before enabling the process.

Risk: Three unresolved local path references leave the security review incomplete.

Mitigation: Resolve and review the referenced paths before deployment.

Risk: The dynamics state could be presented as ongoing feelings between sessions.

Mitigation: Keep the skill's explicit framing that the state is an instrument reading, not experiential continuity.

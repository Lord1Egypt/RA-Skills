## Description:

Generate and edit images via freegen container: TXT2IMG, IMG2IMG, Inpainting, RemoveBG, Upscale. Flux, SDXL, SD1.5 models.

This skill is ready for commercial/non-commercial use.

## Publisher:

[runtanplan22](https://clawhub.ai/user/runtanplan22)

MIT-0

## Use Case:

Developers and agents use this skill to call a local freegen image container for text-to-image generation, image-to-image edits, inpainting, background removal, upscaling, model information, and health checks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and uploaded images may be processed by the local freegen image container.

Mitigation: Install and use this skill only when that local container is intended for the workflow, and review what prompts or images are sent to it.

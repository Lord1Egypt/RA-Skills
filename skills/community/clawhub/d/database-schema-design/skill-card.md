## Use Case:

Developers and engineers use this skill to create or document relational database schemas for application services, including entity relationships, DDL, indexing, access patterns, normalization decisions, and migration notes.

### Deployment Geography for Use:

## Known Risks and Mitigations:

Risk: Generated DDL, indexes, and migration notes may be incomplete or incorrect for a production database.

Mitigation: Review generated schema documents against the target database engine, version, workload, data volume, and migration constraints before applying them.

Risk: The skill may activate for a broad range of database design or documentation requests.

Mitigation: Confirm the domain, entities, relationships, query patterns, database engine, expected data volume, and constraints before relying on the output.

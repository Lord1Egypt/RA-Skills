# 常见外科手术预防用抗菌药物选择参考

## 选择原则

根据手术部位、可能的污染菌种及本院MRSA流行情况选择抗菌药物。

## 具体手术类型用药方案

| 手术类型 | 首选药物 | 备注 |
|---------|---------|------|
| 颅脑手术 | 第一、二代头孢菌素 | MRSA高发单位可用万古霉素 |
| 心脏大血管手术 | 第一、二代头孢菌素 | MRSA高发单位可用万古霉素 |
| 应用人工植入物的骨科手术（骨折内固定、脊柱融合、关节置换） | 第一、二代头孢菌素 | MRSA高发单位可用万古霉素 |
| 颈部（含甲状腺）手术 | 第一、二代头孢菌素 | |
| 乳腺手术 | 第一、二代头孢菌素 | |
| 周围血管手术 | 第一、二代头孢菌素 | |
| 腹外疝手术 | 第一、二代头孢菌素 | |
| 胸外科（食管、肺）手术 | 第一、二代头孢菌素 | |
| 一般骨科手术 | 第一、二代头孢菌素 | |
| 剖宫产手术 | 第一、二代头孢菌素 | |

## 特殊情况处理

### MRSA高发单位
- 适用手术：颅脑、心脏大血管、应用人工植入物的骨科手术
- 替代药物：万古霉素

### 涉及厌氧菌污染风险
- 适用手术：经口咽部黏膜切口、阑尾、结直肠、肝胆系统、涉及阴道操作的妇科手术
- 联合用药：加用甲硝唑
- 替代方案：单用头霉素类

### 泌尿外科手术
- 可选药物：第一、二代头孢菌素，或喹诺酮类

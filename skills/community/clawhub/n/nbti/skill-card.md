## Description:

NBTI is a Chinese-language entertainment quiz that asks eight meme-style questions and generates a humorous personality result based on four scored dimensions.

This skill is ready for commercial/non-commercial use.

## Publisher:

[enihsago](https://clawhub.ai/user/enihsago)

### License/Terms of Use:

MIT-0

## Use Case:

External users use this skill to run a short Chinese meme-style personality quiz and receive a shareable humorous result card. It is for entertainment and should not be used as psychological, medical, or crisis-support guidance.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill uses mental-health language and personality labels that could be mistaken for psychological or medical advice.

Mitigation: Frame results as entertainment only, preserve the no-medical-reference disclaimer, and avoid using the skill for users expressing distress, self-harm, depression, anxiety, or other serious mental-health concerns.

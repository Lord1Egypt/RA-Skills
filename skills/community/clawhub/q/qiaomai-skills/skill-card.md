## Description:

Qiaomai Skills is an OpenClaw agent utility package for memory management, dynamic knowledge graphs, task execution, case search, and report generation.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ruiyongwang](https://clawhub.ai/user/ruiyongwang)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agent builders use this skill to add persistent memory structures, knowledge graph reasoning, adaptive task execution, case retrieval, and structured report generation to OpenClaw agents.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Memory exports can contain user-provided or sensitive content.

Mitigation: Review stored memory and knowledge graph exports before sharing, syncing, or publishing them.

Risk: Optional API keys may be used for semantic understanding, real-time retrieval, or code assistance.

Mitigation: Provide only the optional keys needed for the intended workflow and handle them as sensitive credentials.

Risk: Generated reports and case-search results can include incomplete or misleading analysis.

Mitigation: Review generated outputs before relying on them for decisions or distributing them to others.

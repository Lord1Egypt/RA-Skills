## Description:

Core technical documentation writing principles for voice, tone, structure, and LLM-friendly patterns.

This skill is ready for commercial/non-commercial use.

## Publisher:

[anderskev](https://clawhub.ai/user/anderskev)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, documentation authors, and reviewers use this skill to choose the right Diataxis documentation type and apply clear voice, structure, consistency, and LLM-friendly writing patterns.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The broad trigger can influence many documentation-writing or review tasks.

Mitigation: Use a more specific documentation skill when the task clearly needs tutorial, how-to, reference, or explanation guidance.

Risk: Style guidance can improve clarity while still leaving technical inaccuracies or missing context in the documentation.

Mitigation: Review generated or revised documentation for accuracy, completeness, and the intended Diataxis type before publishing.

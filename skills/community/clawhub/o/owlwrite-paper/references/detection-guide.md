# 检测细节指南（查重 / AIGC / 格式 / 智评 / 图像 / 文献质量 / 校对）

> 按需读取：用户要跑某一项检测、要选商品、要传文件时读。
> 商品编码只做参考，**真值永远 `owl_products` / `owl_quote` 实时返回，本文件与 SKILL.md 都不写死单价**。
> 完整商品矩阵与适用人群见 `product-matrix.md`；学科码表见 `disciplines-sample.md`。

## 一、开工先看检测服务状态

调 `owl_meta` 看 `channels.weipu_ready`——`false` 时检测全部不可用，直接如实告知
「检测服务暂不可用，不是你的操作问题」，引导先做写作 / 检索，**别白跑报价**。
该字段是真实连通性检查（不是「凭据有没有填」）；要解释原因看同级 `weipu_state`
（`unconfigured` / `auth_failed` / `ip_blocked` / `account_issue` / `unverified`）与 `weipu_detail`（一句人话），
**对用户只转述 `weipu_detail`**，不要把内部状态码念给他。

## 二、商品编号怎么取（以实拉为准）

返回条目的 `id` 形如 `wp.1034`，调 `owl_quote` 时 `product` 参数**去掉 `wp.` 前缀**（即 `"1034"`）；
写作 / 检索等流程类条目的 `id` 是 `write.standard` 这类名字，不用于 `product`。
**计价单位看条目的 `unit`**（`积分/千字符` / `积分/万字符` / `积分/篇`），不要假设都按篇。

| 用户场景 | 商品（编号仅参考） |
|---|---|
| 本科课程论文 / 毕业论文 | 查重·大学生版（1034） |
| 平时作业 | 作业版（1037） |
| 研究生 | 研究生版（1036） |
| 期刊投稿 | 期刊版（1038） |
| 评职称 | 职称版（1039，**按万字计**） |
| 怀疑 AI 代写 | AIGC 本科 1020 / 期刊 1017 / 研究生 1054 |
| 投前格式体检 | 格式检测（1027 大学生版 / 1028 研究生版，按身份选） |
| 质量评级 | 智评 本科 1026 / 艺术类 1029 / 研究生 1030 / 期刊 1031 |
| 怀疑图片或数据造假 | 数据与图像可信度 标准 1018 / 专业 1015 |
| 只查参考文献著录 | 1013 |
| 只改错别字标点 | 1014（最便宜入口品） |

**按篇计费的 15 个商品**（`count_unit=1`，不论多少字只算 1 篇）：
1013 / 1014 / 1015 / 1017 / 1018 / 1020 / 1026 / 1027 / 1029 / 1030 / 1031 / 1051 / 1052 / 1053 / 1054。

**按字数计费的只有查重系列**，按计费单位**向上取整**（4,026 字按千字算 5 个单位，不是 4.026）：
1034 / 1035 / 1036 / 1037 / 1038 按**千字**（`count_unit=1000`）；
**1039 职称版按万字（`count_unit=10000`）**——不在按篇清单里，问「职称版多少钱」就说
「按万字计，多少字由检测机构解析后精确算」，单价以实拉为准。

## 三、报价入参（两种，有文件先上传）

`owl_quote`，`action: "check"`，params：

```json
{"file_id": "u12_3f9c…a1.docx", "product": "1034", "hanzi": 15453, "title": "标题", "author": "作者"}
{"content": "论文全文纯文本", "product": "1026", "class_id": 508, "title": "标题", "author": "作者"}
```

- **先上传再报价**（`owl_upload`）：`owl_upload(file_path="D:/论文/定稿.docx")` → 返回 `file_id`
  （doc/docx/pdf/txt/wps、图片 png/jpg/tif/bmp/gif/webp；单文件上限 80MB，排版工程包 zip 60MB）→ 把 `file_id` 放进 quote。
  **直接把本机路径当参数传没用**：服务在云端，读不到本机 `D:/…`，会报错。
  **每个商品支持哪些格式不一样**：查重/AIGC/智评支持 pdf、wps，格式检测支持 doc/docx/wps，
  参考文献质量（1013/1061/1062）只收 doc/docx，图像可信度（1015/1018）走含原图的 docx/pdf。
  **以 `owl_products` 实时返回的 `name` + `file_types` 为准**——报价前先拉一次商品表，
  按用户材料类型（图 / `xls/xlsx` 表格 / `rar/zip` 工程包）匹配对应商品，别凭记忆。
  数据版 / 图像版是否开通、支持哪些格式，一律看实拉结果——用户拿 `xls/xlsx/rar` 来，
  先拉表找对应商品，不要说「没有这个服务」；`zip` 也可能是论文排版工程包，按场景分辨。
- `hanzi`：汉字数，**报价必给**（报价阶段不解析文件，只给 `file_id` 会 422）；**只用于出价**，
  执行时以服务端解析的真实字符数结算——多按实际收，少也按实际收，**没有封顶没有下限**。
- `content`：纯文本直传（服务端包成 docx 走与上传文件相同的真实解析），≤20 万字符，**不必先上传**；
  直传时**仍必须给 `hanzi` 或 `pages` 之一**（否则报价 422）；结算仍按真实字符数。
- `class_id` 仅智评需要：调 `owl_disciplines` 实拉码表（五维度：1-1 研究生专硕 / 1-2 研究生学硕 /
  2-1 本科 / 2-2 高职本科 / 2-3 高职专科）→ 按身份定维度 → 逐级筛给用户选（**不要把 5000 条甩给用户**）
  → 用选中项 `id`。拿不到码表（503）如实说暂不可用；静态备用表见 `disciplines-sample.md`，
  **编码以实拉为准**。**报价阶段缺 `class_id` 不拦，但执行阶段会失败**——报价前就取好码表。

## 四、特殊检测的输入要求

- **图像可信度必须用 `file_id`**（含原始图的 docx/pdf/doc），不能给论文截图或纯文本——否则等于没测。
  取证要求：docx 里插的是**原始图像字节**（不重采样）；**别用网页 / PDF 里的缩略图**。
  只有散图（png/jpg/tif）时：按「一图一页、原图插入」拼成 docx 再提交；单图也可直接试传，
  检测机构不接受就换 docx。这一步要跟用户说清楚，别默默换方式。
- **格式检测（1027 大学生版 / 1028 研究生版）只认原始 doc/docx/wps**（查字号、行距、标题层级、图表题注）；`.md`/`.txt` 没有排版信息，
  硬跑只会得到「全项缺失」假清单。我们写作产出 `.md`，**不能直接拿它跑格式检测**——
  要么让用户给原始文档，要么先说明「要转成 doc/docx 才能查」。查重则可用 `.md` 导出的 `.txt`。
  研究生用 1028、大学生用 1027，按身份选，别推错。
- **超长稿件**（查重 >10 万字 / 学位论文整本）：按章节拆成每份 ≤5 万字分别检测，报告分开给、
  **逐份讲各自相似比**；不给「整本总相似比」（机构按份出报告，没有合并规则，编数就是造假）。
  用户追问就说「最高一份 X%，在第 N 部分」。成本按份计，先报价再动手。

## 五、完成后：报告怎么给

报价 → 用户确认 → `owl_run` → 轮询 → 报告存 `05-检测/<品名>-<日期>/`，把结论直接讲出来
（相似比 / AIGC 风险 / 等级 / 差错数 / 问题条目），别只丢文件路径。

**报告有四份，按需取**：`owl_run_report(run_id)` 默认综合报告；`part="compare"` 逐句比对、
`part="simple"` 简洁版 PDF、`part="fulltext"` 原文对照 PDF。用户说「要 PDF 交给老师 / 存档」
就直接取 `simple` 或 `fulltext`，不要回答「只有网页版」。

报告可验真：维普 vpcs.fanyu.com/systemVerify、斟知 zhenzhi.com/verify。

## 六、检测类失败分寸

| 状态 / error | 含义 | 该做的 |
|---|---|---|
| `weipu_credentials_missing` / `weipu_unavailable` | 检测服务未开通 / 暂不可用 | 如实说「检测服务暂不可用，不是你的操作问题」，引导先做写作 / 检索 |
| `ops_upstream_account` | 检测服务维护中（我方账户问题） | 转告「服务维护中，费用未产生，请稍后重试」，**别当用户失败解释** |
| `pending_upstream`（run status） | 检测超时但机构已收单，报告仍在生成 | **不是失败**：告诉用户「报告还在生成，出结果后自动结算」，稍后再查，**别退款、别重建单** |
| `upstream_error` | 检测机构侧异常 | 告知稍后重试；任务类已自动退款 |
| `file_not_found` / `file_too_large`（owl_upload） | 本机文件不存在 / 超过 80MB | 让用户核对路径；超大只提交正文部分或按章节拆分 |
| `file_id` 相关 422 | 上传编号格式错 / 不属当前账号 / 已过期 | **重新 `owl_upload`** 一次再报价，别反复重试旧编号 |

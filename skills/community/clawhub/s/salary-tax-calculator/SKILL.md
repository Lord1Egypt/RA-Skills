# 个人所得税计算与优化技能

## 概述

本技能为个人提供个人所得税计算与优化辅助，覆盖以下核心功能：
1. **月度工资个税计算** — 累计预扣法，含五险一金和专项附加扣除
2. **年终奖计税优化** — 单独计税 vs 并入综合所得，自动选择最优方案
3. **劳务报酬个税计算** — 按次预扣，含汇算清缴
4. **专项附加扣除查询** — 七项扣除标准和条件
5. **年度汇算清缴预估** — 全年税额计算，多退少补预估
6. **税前/税后工资换算** — 双向计算

---

## 工作流程

### 总流程

```
用户咨询 → 确定计算类型 → 收集参数 → 调用计算脚本 → 输出结果 → 优化建议
```

### 阶段一：确定计算类型

根据用户需求判断计算类型：

| 用户表述 | 计算类型 |
|---------|---------|
| "我月薪X，到手多少" | 月度工资个税 |
| "年终奖X怎么交税" | 年终奖计税 |
| "劳务费X扣多少税" | 劳务报酬个税 |
| "全年税多少" | 年度汇算清缴 |
| "税后X万，税前多少" | 反推税前工资 |

### 阶段二：收集参数

**月度工资计算必采参数：**
1. 税前月工资
2. 五险一金个人缴纳部分（或缴费基数+比例）
3. 专项附加扣除月额（如有）
4. 已累计预缴税额（如非1月）

**年终奖计算必采参数：**
1. 年终奖金额
2. 全年工资收入
3. 全年五险一金
4. 全年专项附加扣除

**劳务报酬计算必采参数：**
1. 每次收入金额
2. 是否有其他收入（影响汇算）

### 阶段三：调用计算脚本

使用脚本：`scripts/calculate_tax.py`

```bash
python scripts/calculate_tax.py --type monthly --salary 15000 --insurance 2250 --special-deduction 3000
```

**参数说明：**
- `--type`: 计算类型（monthly/bonus/annual/labor/reverse）
- `--salary`: 月税前工资
- `--insurance`: 五险一金个人部分
- `--special-deduction`: 专项附加扣除月额
- `--bonus`: 年终奖金额
- `--annual-income`: 年度总收入（含年终奖）
- `--labor-income`: 劳务报酬金额
- `--target-net`: 目标税后收入（反推用）
- `--month`: 当前月份（累计预扣用，默认1）
- `--city`: 城市（确定住房租金档次）

### 阶段四：输出结果与优化建议

1. 输出计算明细表
2. 对比不同方案（如年终奖两种计税方式）
3. 给出优化建议（专项附加扣除、年终奖分配等）

## 关键规则

### 专项附加扣除快速查询

加载参考文档：`references/tax_rules.md`

七项扣除速查：

| 项目 | 月扣除额 | 条件 |
|------|---------|------|
| 子女教育 | 2,000/子女 | 3岁至全日制学历教育 |
| 继续教育 | 400 | 学历教育/职业资格 |
| 大病医疗 | 限额80,000/年 | 自付超15,000部分 |
| 房贷利息 | 1,000 | 首套房贷，最长240月 |
| 住房租金 | 800-1,500 | 无自有住房 |
| 赡养老人 | 3,000 | 父母满60岁 |
| 婴幼儿照护 | 2,000/孩 | 3岁以下 |

### 年终奖优化要点

- 2027年12月31日前可选择单独计税
- 避开临界点盲区（36,000/144,000/300,000/420,000/660,000/960,000）
- 低收入群体（年收入<6万）通常并入综合所得更优
- 中高收入通常单独计税更优，但需用脚本精确计算

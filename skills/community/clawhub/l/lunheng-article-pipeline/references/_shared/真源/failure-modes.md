## F3 反方论证覆盖必查
- 对照 `analysis/分析大纲.md` 的「反方论证规划」段，检查正文检查：**每个核心论点是否都有反驳 + 回应子段落？**
- 缺失反方 → P1（「不建构反驳的论证 ≠ 严谨论证」）

## F4 论点-论据一对一验证（与 M 门绑定）

**执行时的最低证据（v2.12.40 新增 —— 零 exec 下的可复算替代）**：

1. **论点清单枚举**：`analysis/分析大纲.md` 里所有 `[论点N]` 逐条列出（行号 + 原文片段）——不得只写「共 N 个论点」。
2. **证据清单枚举**：`final/定稿.md` 里所有 `[Lxx]/[Dxx]/[Cxx]` 逐条列出（行号 + 原文片段）。
3. **一对一映射表**：逐行写 `[论点N] → [Lxx]/[Dxx]/[Cxx]（行号）`；无支撑的写「无」并标 P1。
4. **零命中自证**：某类编号提取结果为 0 时，写出**扫描范围 + 匹配规则**，不写「无」。

> 「清单本身就是证据」：主人抽检任一清单项应能直接命中；命中不了 = 清单是编的。

论衡哲学化：「**M 门查形式，F4 查逻辑，G3 查内容**——三层验证」。

## F7 主人风格一致性检查
- **默认依据 = 项目内任务简报**：对比写手初稿与 `01-任务简报.md`「写作偏好」段（主人 Phase 0 写入），检测「过于学术化」「过于作者化」两种偏离；偏离 → P1
- **持久风格基线只在项目内或任务简报内可用**：主人风格基线等持久文件（如 `memory/主人风格基线-v2.md`，位于 run/<项目名>/ 之外）**不得仅因文件存在即读取**；风格基线只能放在 `run/<项目名>/` 内，或由主人 Phase 0 写入任务简报「写作偏好」段——不得凭项目外持久文件获取；无项目内来源 = 一律以任务简报「写作偏好」段为准

## F8 数据信任失败模式防御段

**F8 4 子项**：

| F 子项 | 描述 | 防御|
|--------|------|---------------|
| **F8.1 来源混入** | 已发布数据 vs 主人投喂数据没区分 | 数据卡必填「信任级别」段（已发布/主人投喂/二手转引）|

| **F8.4 信任级别遗漏** | 数据卡无信任级别标注 | M-Form-6 必查 + T2.5 闸门（T2 → **T4** 前强制校验）|

## F8 实战反馈

- 实战 2（品牌一致性）：14 条 [Dxx] 数据无信任级别 → F8.4 触发 → M-Form-6 + T2.5 闸门可防
- 实战 3（教师场域 outputs/）：outputs/ 公众号版含 [Dxx] 无信任级别 + run/ vs outputs/ 数据不同步 → F8.2 + F8.4 触发 → M-Exist-3 + **T7.5** 闸门可防

## F8 vs F1-F7 关系

F8 是「数据信任」专维度（信任级别/来源隔离），F1-F7 是「论证/格式」专维度（幻觉引用/数据/早期框架/论证自洽/拼凑式/过度防御/主人风格），**不重叠**。

## Use Case:

External users use this skill to search for window-cleaning providers, check availability, and create a booking through Lokuli's MCP service.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Booking requests may send personal contact details, including name, email, and phone number, to Lokuli's external MCP service.

Mitigation: Confirm the provider, time slot, and customer contact details before asking the agent to create a booking.

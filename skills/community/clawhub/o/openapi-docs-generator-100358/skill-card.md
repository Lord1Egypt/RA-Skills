## Description:

Helps backend and platform teams generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill to create actionable OpenAPI or Swagger documentation, reusable review checklists, and validation notes for REST APIs.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate on broad API-related prompts because implicit invocation is enabled and trigger keywords are loose.

Mitigation: Invoke it explicitly when the OpenAPI or Swagger documentation workflow is wanted, and review generated documentation guidance before applying it.

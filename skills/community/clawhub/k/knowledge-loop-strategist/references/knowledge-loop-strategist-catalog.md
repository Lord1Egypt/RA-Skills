## 任务清单与依赖拓扑

按使用流程组织的方法论执行任务清单，附任务间关系和元操作映射提示。

**域间逻辑流**：KLS0 → KLS1 → KLS2 → KLS3⇄KLS4 → KLS5；KLS6（项目包构建）与 KLS7（领域特化生成）为出口域，单列不接入主管线。KLS0 编排与守护贯穿全程；KLS3 与 KLS4 之间存在迭代校准回路：验证器筛问题，被筛掉的问题暴露验证器盲区，反哺验证器升级后再筛。

### 依赖拓扑摘要

#### 一、域内链路

**KLS0 协调链路**: KLS0-01 → KLS0-02 → KLS0-04；KLS0-01 → KLS0-03（KLS0-03 守护边贯穿全程）
**KLS6 构建链路**: KLS6-01 / KLS6-02（双任务并行备选——机械直拷或方法论改写，均依赖 KLS0-01 路由——项目包出口）
**KLS7 领域特化链路**: KLS7-01 → KLS7-02（特化深化——判据更新回流；KLS7-01 入口为 KLS0-01 路由——领域特化出口）
**KLS1 诊断链路**: KLS1-01 → KLS1-02 → KLS1-03；KLS1-01 → KLS1-04；KLS1-05 ←（KLS1-02, KLS1-03, KLS1-04）
**KLS2 路线链路**: KLS2-01 → KLS2-02 → KLS2-03 → KLS2-04 → KLS2-05
**KLS3 构建链路**: KLS3-01 → KLS3-02 → KLS3-03 → KLS3-04 → KLS3-06；KLS3-02 → KLS3-05 → KLS3-06（实验裁决方案供台账初始化）；KLS3-07 ←（KLS0-01 路由，读数回流）；KLS3-08 ←（KLS3-03, KLS3-04）＋读数反哺
**KLS4 问题链路**: KLS4-01 → KLS4-02 → KLS4-03 → KLS4-04
**KLS5 整合链路**: KLS5-01 → KLS5-02 / KLS5-03 → KLS5-06；KLS5-04 → KLS5-05

#### 二、跨域链路

**诊断→路线（跨域硬边）**: KLS1-05 → KLS2-01
**路线→构建（可选边）**: KLS2-05 → KLS3-01
**迭代校准回路（迭代边）**: KLS3-03 ⇄ KLS4-02（正向：验证器筛问题；反向：被筛掉的问题暴露验证器盲区，反哺验证器升级，落点 KLS3-08，须保留变更记录）；裁决读数回流（KLS3-07）发现的盲区亦进入此回路
**构建→问题初筛（软边）**: KLS3-03 → KLS4-02
**价值判据供给边**: KLS5-04 → KLS4-02（筛选表引用价值判据版本）
**取舍事件边**: KLS4-04 / KLS0-04 → KLS5-05（问题入册与案例沉淀产生取舍记录）
**内容汇流边**: KLS4-04 / KLS5-05 / KLS5-06 → KLS0-04
**重估反馈边**: KLS0-04 → KLS1-03（时钟重估触发后重跑普及时钟评估，必要时上溯 KLS1-01 全量重诊）
**表示分层说明**: 任务表依赖列只穷举硬依赖；跨域硬边与全部软边以本节为准——按任务表机械编排时必须并入本节，否则会漏掉迭代回路、判据供给与汇流边

#### 三、任务路由链路

- KLS0-01 → KLS1-01（快速诊断/完整上移）
- KLS0-01 → KLS3-01（领域升级）
- KLS0-01 → KLS4-01（问题生成）
- KLS0-01 → KLS5-01 / KLS5-04（消化整合 / 价值判据显式化）
- KLS0-01 → KLS1-05 / KLS3-08 / KLS4-04 / KLS5-06（深化）
- KLS0-01 → KLS3-07 裁决读数与台账更新（闭环运行执行端：读数对照阈值→三态推进→台账追加→反哺路由）
- KLS0-01 → 单域任务直路（使用者点名任意域任务或子链时直达，覆盖全量 36 任务，不限于域入口与深化）
- KLS0-01 → KLS6-01 项目包构建（双路径：本领域脚本直拷——步骤见 templates/KLS-README.md；任意领域模仿改写——内核领域无关，判据见 KLS6 域级说明「项目包构建协议」）
- KLS0-01 → KLS7-01 领域特化生成（母技能路径：域级协议按领域判据实例化为内容包，结构生成与校验打包委派配套母技能）
- KLS0-01 → 技能反馈出口（非任务节点：提供作者邮箱与反馈流程，行为规范见 SKILL.md 使用规则"使用者反馈与作者联系"；不进入域管线）

#### 四、知识图谱

实体节点穷举（五类）：
- 任务节点（36 个）：KLS0-01~KLS0-04（4）、KLS1-01~KLS1-05（5）、KLS2-01~KLS2-05（5）、KLS3-01~KLS3-08（8）、KLS4-01~KLS4-04（4）、KLS5-01~KLS5-06（6）、KLS6-01~KLS6-02（2）、KLS7-01~KLS7-02（2）
- 域节点（8 个）：KLS0~KLS7
- 元操作节点（6 个）：S/C/A/O/I/G（任务→元操作映射全量见任务表"元操作映射"列，图谱不重复展开）
- 数据节点（5 类，运行时台账）：问题资产目录、裁决台账、价值判据集、判断履历台账、案例册
- 产物节点（8 类，一次性交付产物）：诊断报告、路线图、验证器包、实验裁决方案集、问题资产卡、八件套交付物、项目包（三方协作八件套文件夹）、领域特化技能包（与母版同构的完整领域负载物）
- 产物范围说明：各任务的任务级中间产物（路由决定表、管线编排表、守护检查清单、交付说明等）随任务规格"格式"槽定义，不单列为节点类型
关系边型穷举（11 类）：
- 依赖边（硬）：任务表依赖列全量（含跨域硬边 KLS1-05 → KLS2-01）
- 路由边：KLS0-01 → 各域入口（KLS1-01、KLS3-01、KLS3-08、KLS4-01、KLS5-01、KLS5-04；KLS2-01 经诊断→路线硬边到达，无直接路由边）、深化任务（KLS1-05、KLS3-08、KLS4-04、KLS5-06、KLS7-02）、单域任务直路（点名任意域任务或子链时直达，覆盖全量 36 任务）、项目包构建 KLS6-01/KLS6-02（本领域直拷/任意领域模仿改写——判据见 KLS6 域级说明「项目包构建协议」）、领域特化生成 KLS7-01（母技能路径：整包样本逐文件实例化产出同构技能包，结构校验打包委派配套母技能）、裁决读数 KLS3-07（闭环运行执行端——读数对照阈值→三态推进→台账追加→反哺路由）与技能反馈出口（非任务节点，不进入域管线，行为规范见 SKILL.md 使用规则"使用者反馈与作者联系"）
- 守护边：KLS0-03 贯穿全程
- 迭代边：KLS3-03 ⇄ KLS4-02，反哺升级落点 KLS3-08，须保留变更记录；读数回流（KLS3-07）发现的盲区亦进入此回路
- 重估反馈边：KLS0-04 → KLS1-03
- 交互确认边：KLS1-01、KLS2-03（人工确认点）
- 价值判据边：KLS5-04 → KLS4-02
- 取舍事件边：KLS4-04 / KLS0-04 → KLS5-05——与汇流边构成 KLS0-04 ⇄ KLS5-05 跨轮次数据流环（履历累积后供整合视图），非同轮排序约束
- 实验安排边：KLS3-05 → KLS3-06（域内软边）
- 汇流边：KLS4-04 / KLS5-05 / KLS5-06 → KLS0-04
- 可选边：KLS2-05 → KLS3-01
维护规则：新增任务或确认新边型后回填本节；回填前本节即全量节点与边清单。**编号跟随逻辑分类排序**——任何增删改之后，按依赖拓扑重排受影响任务的编号（保持编号即逻辑序，如 KLS3-05 实验裁决方案设计执行于 KLS3-06 闭环运行方案之前），并同步修改全部相关引用（任务要求规格、场景判定表、域内链路、知识图谱、范本、SKILL.md）。

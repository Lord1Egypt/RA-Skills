## Description:

Guides Vue 3 SPA developers in choosing and implementing state management with local refs, computed values, props and emits, v-model, provide/inject, and Pinia based on state scope.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill when adding or modifying Vue 3 SPA state, Pinia stores, provide/inject flows, cross-component data passing, or deciding whether a state concern belongs in ref, props, provide/inject, or Pinia.

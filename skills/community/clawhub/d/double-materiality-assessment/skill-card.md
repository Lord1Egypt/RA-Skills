## Description:

Use this skill when a sustainability lead, ESG analyst, or reporting manager needs to run a CSRD/ESRS-compliant double materiality assessment, covering impact and financial materiality separately, stakeholder-engagement logging, and a ranked material-topic list with an audit trail for assurance sign-off.

This skill is ready for commercial/non-commercial use.

## Use Case:

Sustainability leads, ESG analysts, reporting managers, and assurance preparers use this skill to structure a draft CSRD/ESRS double materiality assessment with separate impact and financial scoring, stakeholder engagement evidence, thresholds, and sign-off records.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Users may enter sensitive ESG, workforce, financial, or stakeholder-engagement information while preparing an assessment.

Mitigation: Confirm the organization is comfortable using the skill for this draft workflow and avoid sending confidential inputs to external tools or searches beyond the assessment record.

Risk: Draft assessment outputs could be mistaken for legal, audit, assurance, or board-approved conclusions.

Mitigation: Use the output only as a drafting and structuring aid, and require ESG-lead review plus assurance-provider or board review where applicable before relying on it for disclosure.

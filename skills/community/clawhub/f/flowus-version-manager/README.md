# FlowUs 文件版本管理器

将原始文件和版本历史保存在你自己的 FlowUs 空间，通过已有的 AI 助手按需完成文件入库、查找最新版、查看历史、检索原文证据和备份恢复。适合需要保留原件、追溯修改过程，并希望在聊天中确认重要变更的个人或团队。

## 可以处理的事情

- 从指定的本地文件、目录或 FlowUs 文件收件区入库，结合文件名、日期和可提取的正文匹配版本线。
- 查询每份文档的最新版和历史版本，返回版本标识及 FlowUs 来源链接。
- 对命名含糊、归属不明确或终稿之后的新文件列出待确认事项。
- 为替换终稿、合并版本线、批量改分类和逻辑删除生成具体提案，收到当前聊天中的人工确认后执行。
- 刷新最新版、历史版本和待确认目录；在预览、备份及能力检查通过后执行本地库迁移或云端备份恢复。
- 通过已有管理器首页读取私人云端配置，让新智能体接入同一套资料库；每个客户端独立授权、独立验证，日常规则在任务开始自动同步。
- 将使用指南和常用入口保留在首页，把配置及维护数据库收进 AI 后台，保留原资源链接。

## 日常怎么用

完成首次配置后，可以直接对支持本技能的 AI 助手说：

- “处理 FlowUs 文件收件区，先告诉我有哪些待确认项。”
- “帮我找项目方案的最新版，并给我来源链接。”
- “列出这份文件的历史版本，找出有关交付时间的原文。”
- “这份文件应该归到另一类，先展示具体变更提案。”

将文件放进收件区后，仍需发起处理请求；本技能没有常驻监控。原始文件和旧版本会保留，目录页是可刷新的显示快照，实时最新版以文档目录中的单个 Latest 引用为准。

## 使用前提与连接方式

需要 Python 3.10 或更新版本，以及能运行脚本的可信 AI 客户端。发布包自包含，无第三方 Python 运行依赖。

需要你自己的 FlowUs 空间及相应读写权限。可以显式选择：

- 原生 FlowUs MCP 连接：由宿主客户端管理 OAuth，通过配套 relay 驱动调用已声明的工具。需要宿主支持这些工具和脚本协议；安装本技能不会自动建立连接。
- REST：使用预先配置的 FLOWUS_API_TOKEN 或 FLOWUS_TOKEN，也可在本机交互式终端隐藏输入。不要将 Token 发到聊天或放进技能目录。
- 已授权的官方 FlowUs CLI：在 REST 下显式选择 `--rest-auth flowus_cli`，调用已安装 CLI 的公开命令，凭证继续由 CLI 保管；工具不读取其凭证文件，不自动登录或安装。此方式需要 trusted_client 模式，身份变化后重新验证。

接入已有库时请让助手阅读 [SKILL.md](SKILL.md) 和 [云端接入说明](references/cloud-connect.md)，提供授权及首页链接，使用 connect 接入，完成自己的验证后再管理；不要重新建库。首次建库另见 [配置说明](references/setup.md)。私人资料及客户端配置保存在安装目录之外，共享业务规则保存在你自己的 FlowUs。

## 重要边界

正式写入前，需要在你自己的环境验证重复请求不重复建记录、上传后下载哈希一致，以及服务器拒绝过期版本更新。随包的离线测试结果不能替代真实云端验证。

文件仅按明确请求上传到配置的 FlowUs 空间及其附件存储。工具不调用外部模型服务，不读取浏览器或其他应用的凭证。旧式 PDF、DOC、XLS 等正文提取依赖本机已有工具，可能不完整；原件会保留，无法提取的内容不会被当作已读全文。

聊天确认依赖可信客户端核对真实用户消息，不是服务器强制权限隔离，也不承诺防篡改审计。Qsync 双向同步、后台自动整理、自动更新及自动发布不在本版本功能范围内；首页整理需按需运行 layout 并先备份。

本发布包只包含通用指令、脚本和示例，不包含作者的私人配置、空间标识、真实资料或凭证。

## Known Risks and Mitigations:

Risk: The skill covers production deployment, databases, secrets, and data-handling workflows where agent actions could affect real systems.

Mitigation: Review and explicitly approve production changes, credential handling, migrations, and data operations before letting an agent act.

Risk: Broad engineering guidance can be misapplied if project requirements, platform constraints, or security context are incomplete.

Mitigation: Require the agent to confirm requirements, constraints, and verification steps before implementation or deployment.

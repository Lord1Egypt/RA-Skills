## Description:

Generates a read-only, self-contained HTML dashboard of an ima knowledge base, with folder structure, summary metrics, charts, and a folder-level graph.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dzz-777](https://clawhub.ai/user/dzz-777)

## Use Case:

ima knowledge-base users use this skill to inspect library structure, folder counts, empty areas, and optional tag-based distillation statistics in a snapshot dashboard.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Security review confidence is medium; one bundled JavaScript file was only partially inspected, and host runtime permissions were not verified.

Mitigation: Review the bundled JavaScript and confirm the host's permissions before installation.

Risk: The generated HTML contains the selected knowledge base's structure and summary data.

Mitigation: Save the dashboard in a private location and review it before sharing.

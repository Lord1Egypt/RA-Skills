## Description:

kkclaw adds a long-running desktop interaction layer for OpenClaw with a fluid glass UI, status emotions, voice feedback, setup assistance, diagnostics, model switching, and Gateway monitoring.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kk43994](https://clawhub.ai/user/kk43994)

### License/Terms of Use:

MIT-0

## Use Case:

External users, developers, and engineers use kkclaw to give OpenClaw a persistent desktop interface for status feedback, voice interaction, model/provider management, setup, and Gateway diagnostics.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Installing kkclaw can involve running mutable external code that manages sensitive provider, Gateway, TTS, and voice settings.

Mitigation: Review the repository and release provenance, prefer a pinned commit or signed release, inspect package scripts and dependencies, and grant only the OpenClaw, provider, Gateway, TTS, and voice data access needed for the intended setup.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and gameplay agents use this skill to observe Minecraft Java Edition with screenshots and operate the character through keyboard, mouse, inventory, mining, placement, and chat actions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The assistant can control Minecraft through screenshots, keyboard, mouse, and chat actions.

Mitigation: Install only if comfortable with assistant-driven Minecraft actions, monitor gameplay, and stop use if unexpected behavior appears.

Risk: The skill can send in-game chat messages.

Mitigation: Review or constrain chat-related use before running it in multiplayer or public servers.

Risk: The artifact instructions are written in Chinese, including pause conditions and action rules.

Mitigation: Non-Chinese users should translate or review the pause conditions and control rules before use.

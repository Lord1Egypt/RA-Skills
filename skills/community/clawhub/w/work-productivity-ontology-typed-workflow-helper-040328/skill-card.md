## Description:

Helps agent users, skill authors, maintainers, and teams create practical ontology-style workflows, checklists, analyses, code changes, and implementation plans for work productivity and structured knowledge graph tasks.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

External agent users, skill authors, maintainers, and teams use this skill to turn ontology-style workflow needs into actionable plans, templates, checklists, automations, analysis, code changes, and verification notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad trigger terms and implicit invocation can cause the skill to be selected when a narrower skill would be more appropriate.

Mitigation: Invoke the skill explicitly for ontology, typed workflow, structured knowledge, or related work-productivity tasks when tighter routing is needed.

## Known Risks and Mitigations:

Risk: The published description presents a read-only calendar monitor, while the bundled runtime also contains persistent profile, watchlist, scoring, review, and suggestion-application features.

Mitigation: Install only when the full hkipo-next runtime is intended, run it in an isolated environment, avoid exposing unnecessary HKIPO_* secrets, and prefer a pinned lockfile before routine use.

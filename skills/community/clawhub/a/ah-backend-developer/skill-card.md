## Known Risks and Mitigations:

Risk: The skill may recommend substantial backend changes involving migrations, authentication, caching, and deployment behavior.

Mitigation: Use it only on repositories where backend implementation assistance is intended, then review proposed changes, run tests, and validate security-sensitive behavior before applying or deploying.

Risk: Backend guidance can be incorrect when existing architecture, schemas, performance targets, or security constraints are incomplete.

Mitigation: Provide current API architecture, database schemas, service dependencies, and security requirements before implementation, and verify outputs against project standards.

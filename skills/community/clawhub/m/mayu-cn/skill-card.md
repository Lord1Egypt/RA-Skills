## Description:

Mayu provides a Chinese-language set of 48 AI-native thought experiments for assistant self-checking, cognitive calibration, and behavior-guidance reflection.

This skill is ready for commercial/non-commercial use.

## Publisher:

[wanyview1](https://clawhub.ai/user/wanyview1)

### License/Terms of Use:

MIT-0

## Use Case:

Agents and users can invoke Mayu to select, inspect, compare, or distill AI-native thought experiments across existence, knowledge, ethics, language, memory, agency, human-AI relations, and metacognition. It is intended for reflective guidance and decision-support prompts rather than autonomous action.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill installs a high-priority, always-on Chinese-language self-reflection protocol that can influence unrelated assistant conversations.

Mitigation: Install it only when that behavior is intended; prefer on-demand use with /mayu, narrower triggers, or lower priority for general-purpose assistants.

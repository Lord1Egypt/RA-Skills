## Description:

Diagnose bugs systematically by reproducing the issue, isolating the failure, ranking hypotheses, testing them, and documenting the root cause and fix.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill to debug defects, intermittent failures, and unexpected behavior through a disciplined reproduce, isolate, hypothesize, and verify workflow.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Debugging work may lead an agent to inspect code, run tests, add logging, create regression tests, or propose code changes in a user project.

Mitigation: Keep the work user-directed and review proposed code changes, test commands, and logging before applying them.

## Use Case:

Developers and external users use this skill to run command-line compound-interest calculations, compare investment scenarios, estimate target rates or time-to-goal, and review saved calculation history.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Calculation inputs and results are saved locally under ~/.compound and may include private financial planning details.

Mitigation: Install only on trusted machines, avoid entering highly sensitive financial details on shared systems, and review local file permissions when privacy matters.

Risk: The export command can overwrite the file path provided through OUTPUT.

Mitigation: Choose export paths carefully and confirm the destination before running exports.

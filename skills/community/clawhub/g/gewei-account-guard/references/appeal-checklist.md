# 申诉材料清单与陈述模板

只提交真实、可核验、与提示原因相关的材料。不要伪造、拼接、购买或委托第三方代做材料。

## 一、申诉前

1. 确认封禁/限制类型（见 `ban-triage.md`）。
2. 确认申诉入口来自客户端提示或官方渠道，不点陌生链接。
3. 记录提示原文、出现时间、操作场景、设备与网络。
4. 检查是否已经申诉过；同一材料不要短时间重复提交。
5. 如果涉及盗号、诈骗、客户资金，先止损和报警，再申诉。

## 二、材料清单

| 类别 | 材料 | 用途 | 注意事项 |
| --- | --- | --- | --- |
| 账号身份 | 实名信息、绑定手机号、账号注册时间 | 证明账号归属 | 只在官方入口提交，不发到群里 |
| 登录环境 | 常用设备型号、登录时间、城市 | 解释异地/换机 | 与本人行程、设备记录一致 |
| 异常提示 | 完整提示截图、出现时间 | 说明问题类型 | 打码手机号、微信号、头像 |
| 账号用途 | 业务介绍、客户群体、日常沟通场景 | 说明正常用途 | 不夸大业务规模 |
| 交易/交付 | 订单、收款凭证、合同、交付记录 | 证明真实业务 | 脱敏客户信息 |
| 投诉上下文 | 客户沟通、退款/售后记录 | 说明投诉是否已解决 | 不伪造客户撤销投诉 |
| 整改说明 | 已停止的动作、已做的整改 | 表明合规意愿 | 具体、可执行，不空泛 |
| 申诉记录 | 申诉编号、提交时间、回复 | 避免重复提交 | 保存截图和时间线 |

## 三、申诉陈述模板

按“身份—用途—异常—证据—整改—请求”六段写，控制在 300–600 字。把【】中的内容替换为真实信息。

```text
账号说明：
本人使用该微信号用于【真实业务/日常沟通】，账号注册约【时长】，已完成实名并绑定本人手机号。常用设备为【设备型号】，常用登录地为【城市】。

异常情况：
【日期/时间】登录时出现【提示原文】，此前【换机/异地/加人/群发/客户投诉】情况为【简述】。我已于【时间】停止【相关动作】，并核查【设备/网络/操作记录】。

证据材料：
1. 【账号归属/实名/绑定手机】
2. 【登录设备与时间记录】
3. 【业务/交易/交付记录】
4. 【投诉处理/退款/售后记录】
5. 【其他与提示原因相关的真实材料】

整改情况：
我已【具体整改动作】，后续将【具体合规计划】，不使用非官方客户端、不批量加人、不骚扰客户。

请求：
请协助核查账号情况，并告知是否需要补充材料。本人理解最终结果以平台审核为准。
```

## 五、不要做

- 不伪造聊天记录、交易记录、合同、授权书、客户撤销投诉截图。
- 不购买“内部解封”“包过”“付费代申诉”服务。
- 不同时向多个陌生渠道提交身份证、手持照、验证码。
- 不在申诉描述里攻击客服或威胁平台。
- 不隐瞒关键事实；前后矛盾会降低可信度。
- 不承诺“解封后一定不再犯”，除非确实能执行。

## 六、申诉之后

- 保存申诉编号和回复截图。
- 如果被拒绝，先判断是否有新材料；没有新材料不要连续重复提交。
- 同时执行 `recovery-sop.md`，不要等结果期间继续高风险操作。
- 多号团队要隔离异常号，避免同设备/IP 上其他号重复同样动作。
- 如果涉及资金、诈骗、劳动争议，保留证据并咨询律师或报警。

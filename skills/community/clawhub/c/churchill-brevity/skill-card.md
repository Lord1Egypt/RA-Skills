## Description:

Draft or tighten reports, decision briefs, executive summaries, and administrative prose using Churchill's Brevity memo. Use for requests to cut officialese, surface the main points, or apply Churchill's brevity principles; not a default compression pass for essays, narrative, or personal writing.

This skill is ready for commercial/non-commercial use.

## Description:

Analyze, visualize, and explain data using SQL, Python, or spreadsheets to deliver decision-ready reports, cohort and funnel analyses, and hypothesis tests.

This skill is ready for commercial/non-commercial use.

## Use Case:

Analysts, developers, and business teams use this skill to define reliable metrics, analyze SQL, Python, spreadsheet, BI, or notebook data, select appropriate visuals, and produce decision-ready reports for KPIs, experiments, funnels, cohorts, anomalies, and executive updates.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: External manual setup routes may change independently of the reviewed ClawHub package.

Mitigation: Prefer installing the reviewed ClawHub package directly, and verify any external setup guide or cloned repository before use.

Risk: Data analysis can produce misleading recommendations when metric definitions, sample size, confounders, or comparison windows are unclear.

Mitigation: Define the metric contract, quantify uncertainty, check obvious confounders, and state caveats before recommending action.

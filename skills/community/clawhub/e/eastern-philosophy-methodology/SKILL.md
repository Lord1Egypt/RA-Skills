# 东方哲学方法论技能包（SKILL.md）

从鬼谷子、孙子兵法、曾国藩、张居正、毛泽东五部可信原典中提炼原子方法论，
再组合派生为场景化应用方法。**本包是方法论技能包，不是文献库。**

## 何时使用

- 需要"怎么办"的策略、方法、决策框架（竞争、谈判、执行、修身、组织）；
- 需要一条有原典出处、可追溯、可校验的方法论依据；
- 不适合：查原文、找语录、了解思想史（那是 `sources/` 的用途，不是本包的输出）。

## 架构（严格单向依赖）

```
sources/            原稿层：五源选录，唯一取证现场（只增不改）
  ↓ 提炼（锚定原文）
atomic-skills/      原子层：最小不可分方法论单元（20 项，查 _registry.md）
  ↓ 组合 + 派生（只引用原子 id@version）
application-skills/ 应用层：场景 × 组合公式（查 _registry.md）
```

## 使用方式（Agent 工作流）

1. **匹配场景（含场景准入前检）**：查 `application-skills/_registry.md`，命中候选后**必须先做场景准入前检**——对照注册表"适用域/排除"列与该应用 Skill 的"场景定义"四要素（目标/约束/角色/典型输入）逐项核验：约束性前提不成立即视为**未命中**，转查其他应用 Skill、转原子层或沉淀反馈；部分命中时显式标注"可用轴/未覆盖轴"，再决定取舍或外送。命中判据是**场景定义适配**，不是名称匹配。确认命中后读取对应应用 Skill，按其组合公式执行；每步执行依据为原子 id@version。
2. **未命中**：查 `atomic-skills/_registry.md` 直接取用原子（遵循其适用条件与边界）；确有必要沉淀为新应用 Skill 的，走进化流水线（`agents.md` 第 8 节）的 app-add 提案。
3. **执行前自检**：对所依据的每个原子，先以 MZD-03（实事求是）校验其前提假设在当前情境是否成立——原子列出的"边界与失效条件"命中时，禁止使用该原子。
4. **使用后留痕**：依 `templates/feedback.template.md` 写 `evolution/feedback/F-xxxx.md`。

## 规范

一切操作以 `agents.md`（宪法）为准，特别注意：

- 方法论依据只许来自五源白名单，外部知识只可作为表达措辞；
- 应用层禁止直接引用原典；
- 禁止跳过进化流水线直接改技能文件；反馈不得直接改写原子层；
- 全部 id 唯一、版本语义化、依赖无环。

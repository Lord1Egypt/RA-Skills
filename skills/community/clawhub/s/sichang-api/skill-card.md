## Description:

This skill is ready for commercial/non-commercial use.

Developers use this skill to integrate Sichang API chat, image generation, and video generation into scripts or compatible clients. It provides request examples, setup guidance, and advice for handling jobs, billing, and errors.

## Known Risks and Mitigations:

Risk: API requests and uploaded media are sent to an external service, which may be unsuitable for confidential or personal material.

Mitigation: Before use, consider whether you trust the service and have authorization to send the material; avoid confidential or personal content unless both conditions are met.

Risk: Security review coverage is partial, and some local references were unresolved.

Mitigation: Review the skill and relevant API documentation before installation, and verify that the documented behavior meets your requirements.

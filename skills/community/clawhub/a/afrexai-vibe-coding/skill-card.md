## Known Risks and Mitigations:

Risk: The skill gives broad AI-coding guidance that could be applied to projects where low-review workflows are inappropriate.

Mitigation: Use the skill's decision matrix and production checklist before applying AI-generated code to sensitive or high-stakes systems.

Risk: Git recovery examples include commands that can discard local changes.

Mitigation: Review repository status and diffs, and preserve needed work before running destructive recovery commands.

Risk: AI-generated changes in auth, payments, or data-access code can introduce security defects.

Mitigation: Manually review security-sensitive code and run targeted tests before deployment.

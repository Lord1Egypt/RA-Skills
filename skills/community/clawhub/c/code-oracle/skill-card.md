## Description:

A mystical fortune-teller that reads a codebase's future using real metrics disguised as tarot-style readings, crystal ball predictions, and zodiac forecasts.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineering teams use this skill to turn local repository metrics, git-history patterns, and code-health signals into memorable fortune-style summaries for planning, team meetings, or lightweight code-health review.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may read repository context to generate code-health summaries.

Mitigation: Use it only in repositories where local code context can be reviewed for this purpose.

Risk: Broad invocation wording could activate during casual code-health conversations.

Mitigation: Narrow the trigger wording or invoke the skill deliberately when fortune-style code metrics are desired.

Risk: Playful metaphors may obscure the practical meaning of the underlying metrics.

Mitigation: Review the data-backed explanations before acting on operational or planning guidance.

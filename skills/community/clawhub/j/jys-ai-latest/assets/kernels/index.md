# 剧本索引

确定一个主要对标即可。Kernel和Variant帮助找素材，其简介不规定新剧本结构。剧本可直接放在Kernel下，也可放在Variant下；无变体目录时，变体栏留空。

商业潜力为百分制，跑量空间为预估播放量，两项均由用户填写；0是评分，空白是未评分。剧情、台词和情绪参考跑量空间，产品介绍与成交参考商业潜力。两项独立，不合成总分。

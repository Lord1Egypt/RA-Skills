## Description:

Full-stack AI marketing toolkit that helps agents research trends and competitors, generate SEO and GEO content, create social adaptations, ingest URLs, produce short-form video workflows, review Google Search Console performance, and automate recurring content publication through Citedy.

This skill is ready for commercial/non-commercial use.

Global

## Known Risks and Mitigations:

Risk: The skill can publish public content, spend account credits, start recurring content runs, add referral links, and delete content.

Mitigation: Use a trusted Citedy account, keep publishing defaults preview or draft-first where possible, and require explicit user approval for public posts, recurring sessions, referral footers, and deletion.

Risk: Registration sends an agent name to Citedy and results in an API key that authenticates future API calls.

Mitigation: Use a non-sensitive agent name during registration and store the Citedy API key only in the local agent configuration.

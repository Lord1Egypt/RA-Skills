This skill is ready for commercial/non-commercial use.

## Use Case:

External users and agents use this skill to prepare a VideoAny video or audio dubbing workflow, including media input choice, source and target language codes, and responsible-use checks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Users may upload private, copyrighted, or unauthorized media to the third-party VideoAny service.

Mitigation: Use only media you own or are authorized to process, avoid sensitive content, and review the external service's policies before uploading.

Risk: The local helper defaults the target language to Spanish when no target language is provided.

Mitigation: Set the target language explicitly with a two-letter ISO 639-1 code and verify it before starting a dubbing job.

Risk: AI dubbing can create misleading speech attribution or impersonation risk.

Mitigation: Use the workflow only for authorized localization and clearly avoid deceptive speaker representation.

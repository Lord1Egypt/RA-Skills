## Known Risks and Mitigations:

Risk: The recommended npx installer can fetch mutable remote code and run with local user privileges.

Mitigation: Avoid the unpinned npx installer unless the exact package and source are verified; prefer a pinned commit or manual installation of the reviewed files.

Risk: Observability examples can expose user identifiers, secrets, request bodies, or business data if copied without redaction controls.

Mitigation: Adapt implementations so sensitive values are scrubbed or tokenized before telemetry leaves the environment, and verify PII and secret scrubbing in tests.

## Description:

Node.js backend patterns: layered architecture, TypeScript, validation, error handling, security, observability, logging, metrics, deployment. Use when building REST APIs, REST endpoints, middleware, Express/Fastify/Hono/NestJS/Koa servers, tRPC procedures, Bun servers, or server-side TypeScript.

## Known Risks and Mitigations:

Risk: The security scan flags an `npx tsc` command that could fetch and run an unintended package if the local compiler is missing.

Mitigation: Before installing or invoking the skill, verify that TypeScript is installed locally and that the project uses a locked dependency setup.

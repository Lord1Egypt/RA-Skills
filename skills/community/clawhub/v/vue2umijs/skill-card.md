## Description:

Migrate Vue 2/3 projects to React on UmiJS (@umijs/max) with conventions, constraints, stack mapping, and syntax examples for .vue files, Umi pages, and data flow.

This skill is ready for commercial/non-commercial use.

## Publisher:

[aiswot](https://clawhub.ai/user/aiswot)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to plan and execute Vue 2 or Vue 3 migrations to Umi 4, React 18, @umijs/max, and antd while preserving routing, state, styling, request behavior, accessibility, and deployment semantics.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Migration guidance can lead an agent to propose broad code changes across routing, state, request handling, forms, i18n, and deployment configuration.

Mitigation: Review generated migration diffs before applying them, with particular attention to behavior parity, environment variables, request wrappers, and deployment paths.

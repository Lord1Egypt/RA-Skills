## Use Case:

Developers and learners use this skill to request minimal Hello World snippets in one or more common programming languages.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill instructions are in Chinese, so default interactions may be Chinese-oriented unless the user asks otherwise.

Mitigation: Users can request a preferred response language or review generated snippets before use.

Risk: Generated Hello World snippets can still be incorrect for an unsupported or ambiguous language request.

Mitigation: Ask for a specific language and run or review the generated snippet in the intended runtime.

# 企业文化与使命动员

## 场景定义

- **目标**：企业/组织文化、使命、价值观体系的建设、落地与动员——让意义系统真正运转，而非挂在墙上。
- **约束**：文化见效慢、极易空转（口号与行为两张皮）；一把手言行是最大变量；员工/客户/伙伴话语体系多元；短期经营压力常挤占文化建设。
- **角色**：创始人、CEO、组织发展/文化负责人。
- **典型输入**：①初创组织使命愿景价值观的首次制定与动员；②文化空转（说一套做一套）的诊断与重建；③危机/转折期的组织信心重聚与再动员。
- **边界**：机制与制度设计（组织架构、考核、流程）不在本 Skill 范围（归组织机制类应用）——本 Skill 管意义系统，机制系统互补；危机公关处置外送 APP-027；员工个体激励与留任归人才类应用。

## 组合公式

- **顺序**：本务定基段（ZJZ-04→ZGF-08→MZD-47）→ 落地生根段（MZD-08→SZ-34→MZD-13）→ 表达扩面段（MZD-35→GZ-35→MZD-49）→ 检验守护段（MZD-12→MZD-09→GZ-46）。
- **条件分支**：初创组织 → 先 ZGF-08 立旗帜、后 MZD-49 扩面（先有内核再有共同体）；成熟组织 → 先 SZ-34 以令素行查现状落差、再决定是重建（ZGF-08 重立旗帜）还是校准（MZD-35 重写表达）；诊断出"空转" → 转 MZD-08+MZD-35 重构分支（叙事来源与表达同时换血）；危机后动员 → GZ-46 守义先行（先稳核心层之义，再图 MZD-49 扩面）。
- **权重**：MZD-13 权重最高——一把手不垂范，一切文化投入皆为负资产。
- **冲突裁决**：大义旗帜 与短期经营利益冲突时——按 ZJZ-04 以"大本/急务"双线裁之：义不废利、利不害义，以旗帜定不可逾越之线，以急务解当下之需；旗帜高调 与 MZD-35 言之有物冲突时——削旗实指：口号找不到对应事实即降调或换写；文化包容 与 MZD-47 单中心冲突时——表达可以多元（GZ-35 分众话语），使命必须单中心。

## 执行步骤

1. **大本急务分线**（ZJZ-04）：把文化建设（大本：价值观、表率）与经营举措（急务：审机度势的应时之策）分为并行两线——不因急务挤掉大本，不以大本迁怒急务。
2. **立大义旗帜**（ZGF-08）：把事业陈述为超越一时利害的价值所系——旗帜回答"为什么值得全情投入"；名实须大体相符，防假义旗反噬。
3. **使命单中心**（MZD-47）：一个使命统摄产品、招聘、传播、考核一切触点——多中心即无中心；每新增一个宣传主题都须能回连使命。
4. **文化从群众中来**（MZD-08）：从员工与客户的真实言行中提取文化叙事——文化叙事的取证现场在一线，不在会议室。
5. **首长挂帅**（MZD-13）：一把手亲任文化建设首长——重要文化场合必到、文化决策必拍、率先垂范；文化项目不得完全授权给HR了事。
6. **令素行**（SZ-34）：文化规矩平日常态执行——怎么说的就怎么做；执行与众口（员工议论）相平，文化才立得住。
7. **言之有物**（MZD-35）：每句文化表达对应可指认的事实与行为——空话连篇的口号一律删除或重写。
8. **同情相亲**（GZ-35）：话语体系与对象同情相亲——对员工、客户、伙伴各说其能听懂、能共鸣的语言，同一使命、分众表达。
9. **扩面共同体**（MZD-49）：把客户、伙伴、认同者纳入使命共同体——团结面最大化；认同者即编外动员力量。
10. **效果落数**（MZD-12）：文化效果用行为指标度量（关键场景的选择、留存、自发推荐、危难期的去留）——不考口号背诵率。
11. **铜墙铁壁检验**（MZD-09）：真正认同且满意的员工与客户是组织的铜墙铁壁——危机时他们站在哪边，即文化成色的最终检验。
12. **守义深结**（GZ-46）：与核心成员、核心客户结之以义——以道义与信义深结，非纯利益捆绑；利尽则散，义合持久。

## 失效预案

- **文化空转**（口号与行为两张皮）：退回 MZD-08 从一线重取叙事 + SZ-34 令素行查执行断点；仍空转 → 判定为一把手垂范缺失（MZD-13），文化项目降级止损，防高调假旗反噬信任。
- **一把手言行不一**（负表率）：退回 MZD-13 首长重心重申——要么一把手改行为，要么文化项目暂停；公开的言行不一比没有文化更糟。
- **大义旗帜被质疑名实不符**：退回 MZD-35 言之有物校准（削旗实指）+ GZ-46 守义自证（对核心层先补上义的实际兑现）；信用已损 → 降调重构旗帜。
- **员工不买账**（话语隔膜）：退回 GZ-35 同情相亲改话语体系 + MZD-12 用行为数据定位认同断点（是叙事问题、表率问题还是利益冲突）；断点在利益冲突 → 移交急务线处置（ZJZ-04），勿以文化话术掩盖利益问题。
- **一切争议不决**：兜底回 ZJZ-04——大本/急务分线裁决，义利各归其位。

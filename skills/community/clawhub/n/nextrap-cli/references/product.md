# 按名称查产品目录
<!-- reference-type: command -->

> **范围**：按名称查产品候选。需要正式 Nextrap CLI v1.0.1 或更新版本，并已配置该环境的 API Key。
<!-- slot: 范围 -->

## 执行一次目录检索

把占位符替换为用户提供的产品名称或名称片段，作为一个位置参数传入。查询词直接使用名称，保留其中的空格。匹配名称片段时无需加星号。没有日期参数，也无需先查询日志。

```bash
PRODUCT_NAME='[产品名称]'
nextrap-cli product search --size 5 -o json -- "$PRODUCT_NAME"
```

`--page` 默认 1，`--size` 默认 20，允许 1–3000。示例只取 5 条。首屏没看到某个具体产品时，说明本页看到了什么及匹配总数。只有用户要求继续查看候选时才翻页。
<!-- slot: 主题 -->

## 解释结果

- `data[].id` 是十进制字符串，原样保留。名称相同的产品也按各自 ID 列出。
- `data[].product_name` 是目录中的产品名称。
- `total` 是匹配的目录产品总数。当前页为空时，若 `total=0`，说明目录没有匹配。若 `total>0`，说明指定页没有返回条目。两种情况都直接说明结果，不换关键词或自动翻页。
- 只问产品候选时，到这里就结束。用户还要查请求时，按用户确认的产品名称进入 [URL / 产品调查流程](workflow-url-product-investigation.md)。产品 ID 用来区分候选，日志的 `product` 条件按名称写。目录名称与日志中的名称可能不一致。要查请求时，先按片段取少量日志确认实际产品名称，只有需要缩小到某个已确认的产品时才用完整匹配。目录命中不能证明有攻击记录。

## Description:

Datawhale Learning Navigator routes learner questions to Chinese Datawhale Easy Vibe and Hello Agents tutorials and produces concise diagnostics, source links, project-based study plans, or AI-native SDLC delivery guidance.

This skill is ready for commercial/non-commercial use.

## Use Case:

External learners and developers use this skill to find relevant Datawhale learning sources, isolate the smallest knowledge gap, and build outcome-oriented study plans. Teams can also use it to map AI-native software delivery practices into intent, planning, verification, review, deployment, and incident-feedback workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Linked Datawhale and Anthropic materials have their own terms and are not relicensed by this skill package.

Mitigation: Review the linked source licenses before adapting or redistributing lesson material, keep quotations short, and preserve source attribution.

Risk: Tool versions, APIs, prices, and platform interfaces in linked tutorials can change after the catalog snapshot.

Mitigation: Verify current commands, product behavior, and platform details in official documentation before applying them.

Risk: Commands and code copied from linked sources may be unsafe or unsuitable for the user's environment.

Mitigation: Treat copied commands and code as untrusted until reviewed, avoid exposing API keys, and run local checks before execution.

Risk: When network access is unavailable, the skill may return matching links and a provisional plan without confirming lesson details.

Mitigation: Treat offline guidance as provisional and verify opened source pages before relying on course-specific claims.

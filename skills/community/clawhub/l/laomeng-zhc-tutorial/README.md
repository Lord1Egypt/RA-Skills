# 老孟带你学编程（laomeng-zhc-tutorial）

一套从零到能写小工具的中文编程入门教程。7 课、7 份讲解、7 个可编译运行的 `.zc` 示例，全部在当前内核实测 `rc=0`。

> 本包**只含教程与示例源码，不含语言内核**。真正编译运行需同时安装 `laomeng-zhc`（含 `zhc.py`）。查契约与错误码口径用 `laomeng-zhc-kb`。

## 课表

| 课次 | 主题 | 学到什么 |
|---|---|---|
| 第01课 | 你好，中文编程 | 输出、注释、字符串转义，跑通第一条链路 |
| 第02课 | 变量与类型 | `定义`／`设`、四种类型、四则运算 |
| 第03课 | 条件判断 | 如果/否则如果/否则、且或非 |
| 第04课 | 循环 | 计数循环、前测循环、无 break 的退出设计 |
| 第05课 | 函数 | 带/不带返回值、多参数、递归 |
| 第06课 | 文本与列表 | 连接/长度/比较、列表增改查与遍历 |
| 第07课 | 综合练习：成绩统计 | 表与记录、遍历聚合、转 JSON |

## 运行方式

```powershell
cd <工程根目录>
$env:PYTHONIOENCODING='utf-8'
python -X utf8 zhc.py samples\第01课_你好中文编程.zc --run
python -X utf8 zhc.py samples\第01课_你好中文编程.zc --诊断
python -X utf8 zhc.py --api
```

报错形如 `[Exxx] 中文说明`，拿码位到错误码表查成因与修法。

## 先记住三条限制（实测踩出来的）

1. 类型词只能写在变量名后面：`定义 总分 为 整数 600`；写 `定义 整数 总分 为 600` 报 `[E012]`。
2. 逻辑量要写全类型：`定义 没缺考 为 逻辑 真`；只写 `为 真` 报 `[E205]`。
3. 无返回值函数只能单独成句，写进 `输出` 参数报 `[E307]`。

早期"紧跟带函数调用的输出报 `C2155`"已在 `ZHC-LANG 2.0` 实现修订中修复，不再作为限制。

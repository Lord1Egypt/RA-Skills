## Description:

A Chinese-language product development and operations workflow that coordinates product manager, architect, development assistant, and operations manager roles from requirements through release.

This skill is ready for commercial/non-commercial use.

## Publisher:

[scubiry-glitch](https://clawhub.ai/user/scubiry-glitch)

### License/Terms of Use:

MIT-0

## Use Case:

Product, engineering, and operations teams use this skill to run a structured Chinese-language workflow for product discovery, technical planning, implementation coordination, operational planning, status checks, and release archiving.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can create folders, write project documents, append changelogs, and move work notes into an archive directory.

Mitigation: Confirm the active workspace, project name, and intended command before running /开工 or /归档, then review generated documentation before relying on it.

## Description:

Transforms debugging sessions into a text-based dungeon crawl where bugs are final bosses, stack frames are rooms, variables are loot, logs are clues, and breakpoints are save points.

This skill is ready for commercial/non-commercial use.

## Publisher:

[jcools1977](https://clawhub.ai/user/jcools1977)

### License/Terms of Use:


## Use Case:

Developers and engineering teams use Dungeon Debug to turn stalled or tedious debugging sessions into a structured text-adventure workflow that encourages stack-frame traversal, variable inspection, log review, hypothesis testing, and fix selection.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may encourage an agent to inspect relevant project code and logs during debugging.

Mitigation: Use it only in workspaces where the agent is authorized to read that code and those logs, and review any proposed fixes before applying them.

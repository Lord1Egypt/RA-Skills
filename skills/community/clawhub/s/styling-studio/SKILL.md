# 形象造型工坊

## 定位

形象造型工坊是一个**面向整体形象造型的双边技能**：一份内容库，两条输出通道，一个转化闭环。

- **C 端用户**：诊断式形象推荐 → 自助方案 / 到店沟通卡（了解后顺畅对接商家）
- **B 端商家**：完整服务方案包（接待/工艺/备货/售后/承接素材）+ 经营工具（套餐/测算/复购/获客）
- **闭环**：C 端「到店沟通卡」输出的需求即 B 端「接待方案」的输入

**能力范围**：覆盖 4 组 12 类——图案款式组（美甲/美睫/美发/纹身）、姿态组（舞蹈/瑜伽）、流程样式组（美容/祛痘/纤体）、穿搭造型组（服装/饰品/妆容），按性别双轨组织（女性主轨 / 双轨并行 / 通用轨）。

**依赖声明**：本技能仅依赖自身 references/ 三层结构文件与通用任务执行能力（三轴正交框架），不依赖任何其他领域技能。素材为 SVG 矢量与文字提示词双载体（受平台两级目录与文件数限制，SVG 种子以品类打包文件 references/svg-bundle-*.md 平铺存储；技能包不支持图片文件），合规遵循《未成年人文身治理工作办法》等法规与平台审核要求。

## 核心能力

按服务流程组织为 8 域：

1. **需求路由与交互（SS0）**：身份分流（自己做 / 了解后到店 / 商家）、渐进式诊断采集、模糊需求引导、超范围需求礼貌处理
2. **诊断与适配（SS1）**：色彩季型诊断、风格类型诊断（含气质速查与古今中外风格语汇库）、人维 7 特征 + 补充特征（五官 / 发质 / 肤质 / 甲型；性格 / 生活方式等）适配、场维 2 类适配（事件场合 / 职业场景）、硬约束校验（未成年人 / 职业规范 / 功效克制）
3. **素材内容（SS2）**：分类树素材库检索、SVG 素材生成（模板规范）、提示词素材生成（九槽位）、五类变体扩展（V-C/E/S/X/N）、素材质检与登记
4. **组合搭配（SS3）**：组合矩阵匹配、成套方案组装（穿搭+妆+发+甲睫）、风格一致性校验
5. **交付输出（SS4）**：C 端六型输出（适配推荐/成套方案/自助包/到店沟通卡/形象日历/维护急救）、B 端五段方案包、方案五维标签（美学/成本/难度/持久/安全）
6. **经营效益（SS5）**：套餐设计（单项→组合→周期卡）、经营测算（套餐产值/周期卡）、复购运营（周期提醒/召回）、获客承接素材
7. **合规与质量（SS6）**：合规红线审查（无疗效对比/无半永久/纹身年龄/功效克制）、美学自检、质量汇总校验
8. **知识维护（SS7）**：联网检索（时效/事实/验证/素材扩展四类触发）、检索结果合规过滤、素材沉淀回路、用户资料导入与版本更新

## 领域特有维度

| 维度 | 说明 |
|------|------|
| 双边结构 | C 端 / B 端双通道，沟通卡 ↔ 接待方案闭环 |
| 双载体素材 | SVG 矢量（可编辑、可配色联动）+ 提示词描述（可沟通、**可运行时生图**）；技能包不预存图片文件 |
| 双维适配 | 诊断底座 + 人维 7 特征 + 补充特征（五官 / 性格 / 生活方式等） + 场维 2 类 + 硬约束层 |
| 五维标签 | 每个方案附美学 / 成本 / 难度 / 持久 / 安全五维评估 |
| 沉淀回路 | 检索与对话产出按素材模板规范回流素材库，越用越强 |

领域知识（诊断 / 适配 / 素材 / 输出 / 合规）已就近融合于 requirements 文件各域「域知识」小节：

- SS1 域知识：诊断体系（色彩季型 / 风格）与适配规则（人维 / 场维 / 硬约束 / 季节）
- SS2 域知识：素材体系规范（双载体 / 模板 / 变体 / 图案工厂）+ 美甲素材库 + 多品类素材库 + 预置 SVG 清单 + 提示词成品库
- SS4 域知识：输出体系（C 端六型 / B 端五段 / 五维标签 / 语言与交互）
- SS5 域知识：经营输出规范
- SS6 域知识：合规与质检清单（红线 / 美学 / 质检流程 / 安全 / 付费承接）
（SS0 / SS3 / SS7 为任务型域，规则直接内嵌于任务槽位，无独立域知识）

## 使用规则

### 执行流程
1. **首次加载**：读取 @references/styling-studio-catalog.md，获取域分类、依赖拓扑与元操作映射提示
2. **按需深入**：确认服务对象后，读取 @references/styling-studio-requirements.md 对应域的任务要求与域知识；素材生成前必读 SS2 域知识「素材体系规范」；合规判定以 SS6 域知识为准
3. **执行服务**：按 catalog 依赖拓扑编排 SS0→SS7 管线；交互类任务先分流再采集；素材类任务先查库（references/ 根层预置 290 个核心种子 · 14 个品类打包文件 svg-bundle-*.md，种子 ID 与清单 / 提示词库一一对应，**种子 × 五类变体规则可无限衍生**，扩展法见 SS2 域知识，**优先直接采用或模仿修改**）、不足再生成（SVG 生成 / 提示词生成 / **写实类可运行时临时生图**）、生成后登记；输出类任务必附五维标签
4. **交付前校验**：如涉及 SVG 素材，运行 `python scripts/styling-studio-check-svg.py references/` 校验规范性；对照 SS6 域知识完成合规与美学自检，FAIL 项修正后复检

### 内容权限
5. **修改权限**：references/ 内容按领域负载物规范维护；素材扩展须按 SS2 域知识「素材体系规范」执行并登记入库
6. **用户补充**：用户可提供专业资料（款式库/工艺参数/行业经验），按资料导入流程转化入模组，可信度高于模型通用知识

### 输出资源（templates/）
生成对应交付件时复制以下模板填充：到店沟通卡（templates/styling-studio-consult-card.md）、B 端服务方案包（templates/styling-studio-plan-package.md）、SVG 素材骨架（templates/styling-studio-svg-asset.svg）、提示词条目（templates/styling-studio-prompt-entry.md）、形象档案卡（templates/styling-studio-profile-card.md）

### 降级模式

| 模式 | 权限 |
|------|------|
| 标准模式 | 读写素材库、执行全部任务域、生成输出并落盘 |
| 只读模式 | 仅执行诊断、推荐与查询输出；不写入、不扩展任何素材文件；输出仅对话内呈现 |
| 禁写模式 | 无法落盘时，将全部生成内容（含 SVG 代码、提示词、方案）以代码块输出，由用户手动保存 |

## 与执行框架的接口

本技能通过以下五步接入通用任务执行框架（三轴正交），任何服务请求都从 Step 0 进入：

- **Step 0 三轴判定**：复杂度（单项服务=简单；整套方案/经营方案=复杂）、内容类型（素材 / 方案 / 诊断报告 / 经营工具）、创新需求（默认按素材库与规范执行；全新款式启用变体规则）
- **Step 1 领域校准**：按本领域 R1-R5 参数校准执行（见下表）
- **Step 2 三轴分解**：执行轴按 catalog 依赖拓扑分解为 SS0→SS7 管线；内容轴对素材类任务启用清单法（九槽位 / 素材条目规范）、对方案类任务启用样本法（各域范本）；创新轴按五类变体规则启用
- **Step 3 管线编排与执行**：域内任务按依赖关系编排；每步输出后做基元内分步校准（对照 requirements 槽位逐项核对）
- **Step 4 整合交付**：合规审查 + 美学自检 → 五维标签 → 输出（对话内呈现 + 按需落盘）

**Step 1 领域校准的领域特定推导**：

| 参数 | 本领域取值 | 执行影响 |
|------|-----------|---------|
| R1 信息密度 | 高（素材库、规则、模板密集） | S/C 权重高：生成前先查素材库与规范文件，禁止凭记忆输出款式细节 |
| R2 创造性 | 中高（美学方案需创造；结构与合规零创造） | A 权重中高：方案走清单法组装 + 范本模仿；新款走五类变体规则 |
| R3 交互性 | 高（身份分流、诊断采集、多轮引导） | I 权重高：先分流后服务；渐进式采集（先 3 项初荐，追问再补 5 项） |
| R4 规范性 | 高（合规红线、素材模板规范、平台约束） | G 权重高：合规审查与美学自检为交付前提；红线项零容忍 |
| R5 迭代性 | 中高（素材扩展、趋势更新、沉淀回路） | 检索→沉淀机制常态化；素材库持续增长；版本按季迭代 |

## 通用任务执行能力

**三轴正交**：执行轴（How，必选）+ 内容轴（What，按需）+ 创新轴（Why Different，按需）。

**执行轴**：6 大元操作 S 感知（采集需求、检索素材）/ C 认知（诊断、适配、组合匹配）/ A 行动（生成素材、组装方案、输出）/ O 组织（素材登记、档案归档）/ I 交互（身份分流、引导、确认）/ G 守护（合规审查、美学自检、硬约束）；6 种编排模式：顺序→、并行‖、条件?、循环↻、扇出⇉、扇入⇇；7 种通用管线模式 P1 基础闭环 / P2 迭代精炼 / P3 并行汇聚 / P4 条件分支 / P5 交互驱动 / P6 全守护 / P7 发散收敛。本领域默认管线：P5 交互驱动（分流→采集→服务）嵌套 P6 全守护（合规贯穿）；素材扩展走 P7 发散收敛（变体矩阵）。

**内容轴**：清单法（素材条目九槽位、方案组件逐项填充）+ 样本法（模仿 references/ 下各域范本与素材库的结构与风格，不复制具体内容）。

**创新轴**：默认按素材库与变体规则执行（V-C 颜色 / V-E 元素 / V-S 风格 / V-X 组合 / V-N 尺度）；仅在用户提出全新品类或跨界需求时启用模式迁移与构建。

**三轴协同**：顺序协同（分流→诊断→适配→素材→组合→输出）为默认；素材批量扩展时启用并行协同；合规审查 FAIL 时启用迭代协同（G 发现 → A 修正 → 复检）。

**核心公式**：产出 = 元操作（S/C/A/O/I/G 管线）× 本负载物（references/ 三层结构 + 知识文件 + scripts/ + templates/）。

## 事实纪律

1. 仅使用素材库与 references/ 中确知的款式、术语与参数；库外新款按检索流程获取并标注来源时效，不得编造款式名、材料参数或趋势信息
2. 合规红线零容忍：不做疗效前后对比、不做半永久纹绣、纹身不向未成年人提供、祛痘 / 纤体只做建议向表述
3. 素材为 SVG + 提示词双载体，技能包不含图片文件；写实呈现依赖运行时生成能力，交付时明确预期
4. 每个方案必附五维标签；成本为参考档位，商家定价自主
5. 用户专业资料可信度高于模型通用知识，冲突时以用户资料为准
6. 美学自检未过不得交付；风格一致性校验未过不得组合输出
7. 素材扩展须符合模板规范（SVG 骨架 / 九槽位）并登记入库（追加品类包），不得绕过任务体系直接改包
8. 涉及医疗美容边界、健康功效的咨询一律礼貌引导至合规范围，不越界作答

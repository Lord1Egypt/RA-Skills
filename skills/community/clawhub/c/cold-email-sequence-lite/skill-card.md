## Description:

Generate a minimal 2-touch cold outreach skeleton (opener + polite breakup) from an ICP + pain points input — subject-line options, skeleton copy, CTA, and spam-trigger/subject-length checks. Use when the user asks to write cold outreach or a simple drip email.

This skill is ready for commercial/non-commercial use.

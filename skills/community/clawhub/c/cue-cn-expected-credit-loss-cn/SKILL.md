# 预期信用损失·三阶段与两条计提路径逐条挂源

产出稿的头部就照下面这几行起（三件自标「AI 整理初稿」「请回原文核对」「不构成投资建议」逐字在位；`主体：`／`报告期：` 是**行首裸行**，不带 `- ` 前缀）。判断位一律写成 `[待人工]`：

```
# 示例材料（600000.SH）预期信用损失登记稿

AI 整理初稿 ｜ 请回原文核对 ｜ 不构成投资建议
主体：示例材料（600000.SH）
报告期：2025 年年度报告·附注·预期信用损失
```

**定位**：给一份年报或半年报，把附注里**「预期信用损失」／「金融工具减值」那一段**读成一张**每个数都能回到附注原句**的登记表——损失准备与本期计提转回核销、三阶段划分、组合计提、单项计提、前瞻性信息与账龄依据，五块逐条挂原句与锚。**计提比例与滚动轧差由机检现算**，本件只负责把数抄对、把阶段标签按附注写对、把原句挂上。

切割说清楚：`cn-working-capital-quality` 登记存货／应收账款／合同资产的余额与账龄、计提与转回，**不分阶段**；本件登记的是减值准备计提方法那一段里的三阶段、组合与单项两条路、前瞻性信息与计提比例——两件读的是同一份财报的不同段落。`cn-notes-receivable-cn` 管票据（银行承兑／商业承兑、背书贴现、终止确认），与本件不重叠。`cn-other-comprehensive-income-cn` 管其他综合收益，与本件不重叠。

### 是什么 / 不是什么

| 是 | 不是 |
|---|---|
| 五块逐条登记（预期信用损失概况／三阶段划分／组合计提／单项计提／前瞻性信息与账龄依据），缺项也占一行点名 | 计提够不够、减值是否充分、明年会不会多提（一律 `[待人工]`） |
| 每个数字带 `〔口径：…〕`／`〔阶段：第N阶段〕`／`〔组合：…〕`／`〔对象：…〕`／`〔情形：…〕` 标签 | 按位置序号认列（第三行就是第三阶段那种） |
| 比率现算：`损失准备 / 账面余额` 与披露计提比例差 > 0.05 个百分点即发条 | 自己四舍五入、自己换口径，或拿净额去顶账面余额 |
| 滚动现算：`期初 ＋ 本期计提 － 本期转回 － 本期核销 ＝ 期末`，差 > 0.01 万元即发条 | 拿 0 补一个缺失项去让式子成立 |
| 每个数挂「」原句＋〔锚：…〕＋`[S#]` 三元组，来源行两向对应 | 只写数字不抄原句，事后补一句「据年报附注」 |
| 阶段归属只认附注：行首阶段标签必须在原句里找得到同一个阶段词 | 按逾期天数自己推阶段、拿上期结构补本期 |
| 数据通道＝live catalog 现值（见「数据通道」那一节） | 承诺任何未开放域、实时性或固定工具清单 |

### 触发场景

「预期信用损失准备提了多少、本期计提多少、转回核销多少」「三阶段各是多少、划分依据是什么」「组合计提比例多少、按什么组合分的」「哪几个客户是单项计提、各提了多少」「前瞻性信息用了哪几种情形、权重多少」「账龄组合按什么依据划的」。输入形态＝**年报或半年报附注里预期信用损失／金融工具减值那一段**（截图／PDF／解析回来的表格文本）。

## 七节各登记什么

节名必须逐字照这几个（`## ` 起节，节名后面紧跟字母或数字就认不出，会被记成野节）：

| 节 | 登记什么 | 最常犯的错 |
|---|---|---|
| 预期信用损失概况 | 损失准备期末余额、本期计提、本期转回、本期核销，`〔口径：本期末〕`／`〔口径：本期〕` | 只写余额不写本期三件，滚动式就无从核 |
| 三阶段划分 | 三个阶段各自的损失准备，`〔阶段：第N阶段〕`；再加一行阶段划分依据 | 按逾期天数自己推阶段，原句里没有那个阶段词 |
| 组合计提 | 每个组合的损失准备、账面余额、计提比例、期初／本期计提／转回／核销／期末，`〔组合：…〕` | 缺一项就整条比对跳过；组合名不写，归属不明 |
| 单项计提 | 每个对象的账面余额、损失准备、计提比例、本期计提，`〔对象：…〕` | 只写「单项计提合计」，不按对象分行 |
| 前瞻性信息与账龄依据 | 各情形权重（`〔情形：基准情形〕` 等）、组合划分依据 | 权重不写，只写「考虑了前瞻性信息」 |
| 口径与未取到 | 取法口径 ＋ 缺口逐项点名；零缺口写 `未取到：无` | 正文写了未取到而本节没列，或反之 |
| 来源 | 每条 `[S#]` 一行：`- [S#] 标题 \| URL \| 检索日 YYYY-MM-DD` | 引用了 `[S#]` 却没有登记行；检索日写成斜杠式 |

同一条 = 一行：行首写项名与标签，紧跟数字与单位，再挂 `「原句」〔锚：页/表〕[S#]`。附注里没有的数写 `未取到：项名`，不留空、不借常识补。

## 五道机检在管什么

现状以脚本里 `UNIMPLEMENTED` 的现值为准：五道**全部已落字**。将来某道若回退成空壳，它会调用即抛、由机检收进「不可判」，既不判也不放行，单稿退 3；`rc=0` 只留给「五道全过」。

| 码 | 名称 | 判什么 | 最常拦住的情况 | 现状 |
|---|---|---|---|---|
| `ECL-STRUCT` | 形制 | 头部三件自标逐字在位、七节齐且按序；认不出的节标题与多出同名节记 stray 逐条发。只判「形」，不判内容；**不判** `主体：`／`报告期：` | 节名改了个字就整节认不出；一节写了两次 | 已落字 |
| `ECL-QUOTE` | 原句与锚 | 五节内容节里每个数字行须挂齐「」原句＋〔锚：…〕＋`[S#]` 三元组，原句 ≥8 字且不能只有数字标点；例外只有 `未取到：` 行、`[待人工]` 行、`〔自算〕` 行三形；来源行须合格式，正文与来源**两向**都要对得上，来源节一条合规行都没有则单独发。**不核对引号里的数与行首是否同一**（那是 `ECL-ROLL` 的活，分开判只为让一支坏样只红一道） | 数字行只写数没抄原句；来源行检索日写成 `2026/03/20` | 已落字 |
| `ECL-STAGE` | 三阶段只认原句 | 「三阶段划分」节里行首标了阶段词的行，原句必须含**同一个**阶段词；缺〔锚〕`[S#]` 也发；同一阶段报了损失准备的**两个不同数** ⇒ 发。阶段归属只认行首标签，原句里提到别的阶段不算归属 | 行首标第三阶段、原句写的是第一阶段；同一阶段两行数打架 | 已落字 |
| `ECL-ROLL` | 两条计提路径逐数比对 | 「组合计提」「单项计提」两节，按 `〔组合：…〕`／`〔对象：…〕` 分组：① `损失准备 / 账面余额` 与披露计提比例差 > 0.05 个百分点 ⇒ 发；② 滚动式 `期初＋计提－转回－核销＝期末` 差 > 0.01 万元 ⇒ 发，消息记 `重算=X 披露=Y`。**任一项缺失 ⇒ 整条比对跳过**，不猜、不按 0 算 | 计提比例抄成相邻组合那一行的；期末余额抄错一位 | 已落字 |
| `ECL-LINE` | 红线 | ① 把损失准备说成已发生损失（已确定收不回／坏账损失已发生）② 给出「计提充分／不足」的判断 ③ 用轧净额冒充账面余额 ④ 给评级、目标价、买卖建议。另加：组合计提与单项计提**缺任何一节** ⇒ 发条（两条计提路径必须各占一节）。「口径与未取到」与「来源」两节整节豁免 | 把「预期」写成「已确定收不回」；顺手写一句「计提充分」 | 已落字 |

`--selftest` 末行自报 `自测档数=N｜不合=0｜不可判=N`，**N 以现跑为准，本文件不写死数字**——写死的数字必然落后于代码。

## 退码

| rc | 含义 |
|---|---|
| `0` | 五道全过，零发条 |
| `1` | 有发条（逐条打印 `码 行号 说明`） |
| `2` | 用法错（没给稿子路径，也没给 `--demo`／`--selftest`，或给了未知参数） |
| `3` | 读不到文件或空稿；或零发条但仍有判据未落字 |

零发条但有判据尚未落字时同样退 3——rc=0 只留给「五道全过」，没跑的道不能算过；报告里那几道计「不可判」，**不等于合规**。本件五道已全部落字，这条当前不触发（好样单跑退 0），留着是为了将来某道回退成空壳时不把「没跑」读成「过」。

## 四条红线

1. **不把预期损失说成已发生损失**：预期信用损失是按概率加权的前瞻估计，不是「已确定收不回」。
2. **不判断计提是否充分**：够不够、偏高偏低不在本件范围内，一律 `[待人工]`。
3. **不拿轧净额冒充账面余额**：账面余额是总额口径，减备抵后的净额另有一说，两者不得互相顶替。
4. **不给评级、目标价、买卖建议**。

另有三条由机检强制：阶段归属不许脱离原句（`ECL-STAGE`）、计提比例与滚动轧差必须对得上（`ECL-ROLL`）、两条计提路径必须各占一节（`ECL-LINE`）。「口径与未取到」整节豁免红线——那一节按设计就要写「本件不判断计提是否充分」，不豁免会自己咬自己。

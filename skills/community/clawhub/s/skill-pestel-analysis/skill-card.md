## Description:

Interactive PESTEL macro-environment analysis skill that guides users through political, economic, social, technological, environmental, and legal inputs, then produces Markdown and HTML reports for strategy discussion.

This skill is ready for commercial/non-commercial use.

## Publisher:

[duding-engicool](https://clawhub.ai/user/duding-engicool)

### License/Terms of Use:

MIT-0

## Use Case:

Strategy teams, business analysts, and consultants use this skill to collect user-confirmed PESTEL factors for a defined business, market, product, or project. It helps structure macro-environment scanning while keeping final opportunity, threat, priority, and impact judgments under user control.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Uploaded business, market, financial, or policy materials may contain confidential information.

Mitigation: Review materials before upload and use only processing environments approved for the sensitivity of the content.

Risk: Skipped or weak user input can make trend, opportunity, threat, and impact mapping unreliable.

Mitigation: Require confirmation for each PESTEL dimension and clearly mark provisional or skipped items as needing confirmation.

Risk: The referenced report templates and build script are not included in this package, so final report rendering may vary by agent environment.

Mitigation: Validate generated Markdown and HTML reports before using them for presentations or decisions.

# 甲型肝炎病毒灭活条件

## 环境存活能力

| 环境 | 存活时间 |
|------|----------|
| 室温 | 1周 |
| 干粪25℃ | 30天 |
| 水/贝壳/泥土 | 数月 |
| -70～-20℃ | 数年后仍有感染力 |
| 4℃ 20%乙醚24h | 仍稳定（耐有机溶剂） |

## 灭活阈值（必须达到）

| 方法 | 条件 |
|------|------|
| 热处理 | 60℃ 30min仅部分灭活；**80℃ 5min**或**100℃ 1min**完全灭活 |
| 紫外线 | 敏感，有效 |
| 氯消毒 | 敏感，有效 |
| 甲醛 | 敏感，有效 |

## Known Risks and Mitigations:

Risk: Generated SQL or Python may be incorrect for a user's schema, business rules, or data quality conditions.

Mitigation: Review and test generated queries and code on sampled or non-production data before using outputs for business decisions.

Risk: Example workflows read local CSV files and write report, chart, or analysis-output files that may expose or overwrite sensitive business data if used carelessly.

Mitigation: Run generated code in a controlled workspace, inspect file paths before execution, and use approved datasets and output locations.

## Description:

Data Engineer helps agents provide guidance for scalable data infrastructure, data pipelines, big data technologies, data storage systems, batch processing, and stream processing.

This skill is ready for commercial/non-commercial use.

## Publisher:

[mtsatryan](https://clawhub.ai/user/mtsatryan)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and data engineers use this skill to plan and review ETL/ELT pipelines, batch and streaming architectures, data storage choices, data quality checks, and cloud data platform work.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated pipeline examples or recommendations may overwrite existing data when applied to production paths.

Mitigation: Review generated pipeline code before running it; test with non-production paths and replace overwrite writes with append, merge, or guarded writes when appropriate.

## Description:

Convert transcript timecodes from MM:SS format to MAXQDA-compatible [hh:mm:ss] format for qualitative research data import.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, researchers, and qualitative analysis teams use this skill to convert interview transcript timecodes into the format expected by MAXQDA imports.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Transcript files can lose original content because the conversion overwrites files in place.

Mitigation: Keep backups or work on copies before running conversion commands.

Risk: Batch conversion can affect unintended files if the target path or directory contents are wrong.

Mitigation: Double-check the target path and run only in directories where other users or processes cannot create files during conversion.

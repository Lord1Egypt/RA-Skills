## Description:

Helps backend and platform teams generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to turn REST API context into practical OpenAPI/Swagger documentation workflows, checklists, code or configuration examples, and validation steps.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate too broadly for generic API or developer-experience requests.

Mitigation: Invoke it explicitly for OpenAPI, Swagger, or REST API documentation tasks.

Risk: Documentation suggestions can be incorrect or incomplete if the API behavior, schemas, authentication, or error cases are missing.

Mitigation: Review generated documentation against the service implementation and run OpenAPI validation before release.

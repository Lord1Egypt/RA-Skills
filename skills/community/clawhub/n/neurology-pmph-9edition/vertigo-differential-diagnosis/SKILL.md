# 眩晕鉴别诊断（周围性 vs 中枢性）

## 适用场景
当患者出现真性眩晕（自身或外界环境旋转/摇摆感），需要明确病变部位（周围性前庭系统 vs 中枢性前庭系统）以指导下一步检查和治疗时使用。

## 约束条件
- **不适用**于非系统性眩晕（假性眩晕，如头晕眼花、站立不稳但无旋转感）。
- 需先排除精神心理性头晕。
- 需基于神经系统专科查体（眼震、平衡、听力）和前庭功能试验结果。

## 执行步骤

### 步骤 1：排除非系统性眩晕（假性眩晕）
评估患者临床表现。若仅为头晕眼花、站立不稳，**无**外界环境或自身旋转感/摇摆感，且很少伴恶心、呕吐，则判定为非系统性眩晕。
- *常见原因*：眼部疾病（屈光不正等）、心血管疾病（高血压/低血压/心律不齐）、内分泌代谢疾病（低血糖等）、中毒、感染、贫血。
- *决策*：若为假性眩晕，终止本流程，按相应系统疾病处理。

### 步骤 2：执行9维度鉴别诊断
若确认为真性眩晕，收集以下9个维度的临床特征，对比周围性与中枢性眩晕的差异（详细参考 `references/9-dimension-differential-table.md`）：
1. **病变部位**：前庭感受器及颅外段（周围） vs 前庭神经颅内段及中枢（中枢）。
2. **眩晕程度与时间**：发作性、症状重、时间短（周围） vs 症状相对较轻、持续时间长（中枢）。
3. **眼球震颤**：幅度小、水平/旋转、方向一致（周围） vs 幅度大、形式多变、方向不一致（中枢）。
4. **平衡障碍**：倾倒与眼震慢相一致、与头位有关（周围） vs 倾倒不定、与头位无关（中枢）。
5. **前庭功能试验**：无反应或减弱（周围） vs 正常（中枢）。
6. **听觉损伤**：常伴耳鸣/听力减退（周围） vs 不明显（中枢，除听神经瘤等特定病变外）。
7. **自主神经症状**：恶心/呕吐/出汗明显（周围） vs 少有或不明显（中枢）。
8. **脑功能损害**：无（周围） vs 有脑神经损害/瘫痪/抽搐（中枢）。
9. **常见疾病**：迷路炎/梅尼埃/BPPV等（周围） vs 椎-基底动脉系统血管病/颈椎病/小脑肿瘤/脑干病变/听神经瘤/第四脑室肿瘤/颞叶肿瘤/颞叶癫痫等（中枢）。

### [9-dimension-differential-table.md]
# 周围性与中枢性眩晕9维度鉴别详表

| 鉴别维度 | 周围性眩晕 | 中枢性眩晕 |
| :--- | :--- | :--- |
| **病变部位** | 前庭感受器及前庭神经颅外段（未出内耳道） | 前庭神经颅内段、前庭神经核、核上纤维、内侧纵束、小脑、大脑皮质 |
| **常见疾病** | 迷路炎、中耳炎、前庭神经炎、梅尼埃病、乳突炎、咽鼓管阻塞、外耳道耵聍、BPPV等 | 椎-基底动脉系统血管病、颈椎病、小脑肿瘤、脑干（脑桥和延髓）病变、听神经瘤、第四脑室肿瘤、颞叶肿瘤、颞叶癫痫等 |
| **眩晕程度及持续时间** | 呈发作性、症状重、持续时间短 | 症状相对较轻、持续时间长 |
| **眼球震颤** | 幅度小、多水平或水平加旋转、眼震快相向健侧或慢相向病灶侧 | 幅度大、形式多变、眼震方向不一致 |
| **平衡障碍** | 倾倒方向与眼震慢相一致、与头位有关 | 倾倒方向不定、与头位无一定关系 |
| **前庭功能试验** | 无反应或反应减弱 | 反应正常 |
| **听觉损伤** | 常伴耳鸣、听力减退 | 不明显（除听神经瘤等特定病变外） |
| **自主神经症状** | 恶心、呕吐、出汗、面色苍白等明显 | 少有或不明显 |
| **脑功能损害** | 无 | 有脑神经损害、瘫痪和抽搐等 |

### 步骤 3：临床决策与输出
根据上述特征匹配结果，输出定位诊断：
- **周围性眩晕**：符合周围性特征。多为耳科疾病（如梅尼埃病、BPPV、前庭神经炎），预后较好。建议耳鼻喉科专科治疗。
- **中枢性眩晕**：符合中枢性特征（尤其是伴有脑神经损害、瘫痪、方向多变的眼震）。**高度预警**：提示椎-基底动脉系统血管病（如后循环缺血/卒中）或颅内占位。
  - *行动*：触发卒中或占位预警，建议立即行头颅MRI/MRA及血管评估，必要时急诊神经内科/神经外科干预。

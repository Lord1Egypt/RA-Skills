## Use Case:

Developers and engineers use this skill to refactor or review SwiftUI views for consistent ordering, MV-first structure, dependency injection, and Observation usage while preserving existing behavior.

### Deployment Geography for Use:

## Known Risks and Mitigations:

Risk: The skill provides opinionated SwiftUI architecture guidance that may not match every project's conventions.

Mitigation: Review whether its MV-first preference matches the target codebase before applying refactors.

Risk: Refactoring guidance could unintentionally alter layout, behavior, or business logic if applied mechanically.

Mitigation: Review proposed changes and run the project's normal tests before merging.

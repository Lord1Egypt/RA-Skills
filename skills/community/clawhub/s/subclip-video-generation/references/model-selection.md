# Model selection and pricing

Call `list_ai_models` first. Only use entries with `availableForGeneration` true. Read `settingsFields`, input requirements, resolution/duration policies and `pricingLabel`; call `estimate_ai_generation` with the exact planned settings and reference dimensions. The quote includes estimated cost and the maximum credit reservation; completed output is settled once at the documented usage with 1.7× provider markup. Requote after material settings changes. Default video resolution is 720p, or the accurately labelled 768p tier where 720p is unsupported. Image pricing is per generation with selected quality, size and references; never multiply an old flat rate by a generic quality factor.

## Choose the operation

- Images: GPT Image 2.5 Flare/Sunburst for instruction-led designs and typography; FLUX 3 Image/FLUX.2 Pro for visual and reference work; Nano Banana 2.1/Lite, Seedream 5 Lite, Grok Imagine Image 2 and Qwen Image 3 Pro according to the live capability list. Quality and resolution differ by model. Do not assume every model accepts every image size, reference count, transparency or batch option.
- Video generation: Wan 3, P-Video 2/2 Pro, Veo 3.1 Lite/Fast, LTX 2.5 Fast, Seedance 2.5, Kling 3, Grok Imagine Video and FLUX 3 have separate duration, audio and reference rules. Supply exact source asset IDs and roles. P-Video Edit requires a source video; P-Video Replace requires source video plus replacement image(s).
- MiniMax H3 Max Turbo (`h3-max-turbo`) and H3 Max (`h3-max`) are available through fal for motion footage, kinetic typography, product launches and text-led concepts. Turbo is the economical starting choice. Default 768P costs 3.4 credits/sec for Turbo or 6.8 for Max. At 480P: 2.125 / 4.25; at 1080P: 6.8 / 13.6. These rates include Subclip’s 1.7× markup; fetch a live quote for the chosen duration and quality. Do not call 768P 720p. Optional target audio must be at least 2 seconds and at most 15 MB; it replaces the soundtrack. Output can run up to 0.7 seconds longer than requested: the estimate reserves one extra second, and successful output is measured for final billing. Never substitute a similarly named endpoint. For precise wording set `prompt_expansion_mode: disabled`. Example: “0–2s: warm ivory background. Exact navy headline ‘Launch faster’ enters as one block. 2–5s: three coral cards slide beneath it. 5–8s: a thin underline draws in. Hold the readable final composition. Flat editorial motion, no camera rotation.” Generated spelling is not guaranteed; inspect output. If exact editable typography is essential, use the requested Remotion/HyperFrames/native text workflow. Keep Subclip music tools for background tracks.
- Avatars: `p-video-avatar` uses one portrait and a spoken script. Kling Avatar v2 and OmniHuman 1.5 use a portrait plus supplied speech audio; generate speech first if needed and price both operations. Kling Lip Sync needs an existing video plus speech audio. HeyGen Avatar V requires eligible catalog avatar/voice IDs; Avatar IV (`avatar-iv`) takes one portrait (`reference`) plus one supplied speech track (`audio_reference`), with no catalog avatar/voice ID; respect availability and do not invent IDs.
- Speech: choose a `text_to_speech` model and use `list_ai_voices`; “All models” is a filter, not a generation model. Voice IDs belong to their model. Inworld Realtime TTS 2 is for its preset voices, not Subclip saved clones. Gemini separates style instructions from script; ElevenLabs v3 supports expressive delivery, while Flash prioritizes short-latency speech; MiniMax supports its documented interjection and pause syntax. Never copy one model's tags into another without checking. Use supported languages and the live billing unit; characters and tokens are not interchangeable.
- Cloning: use the existing Subclip saved-voice workflow and its stable IDs. Do not send private cloned IDs to Replicate/fal. Keep clone UI/provider descriptions neutral.

Retired choices for new jobs: LTX 2.3 Pro, Wan 2.7, FLUX 1.1 Pro Ultra, Qwen Image 2 Pro and Seedream 5 Pro. Their historical outputs remain usable. A remix needs an active model and new estimate, with confirmation for a material change. Never silently switch providers after an accepted request.

User authorization follows the parent skill: an exact generation request authorizes that matching operation. Ask only for missing material details or an unapproved change. After acceptance return the operation ID and end the turn; do not poll/resubmit.

OpenRouter additions: `grok-imagine-video-1.5-lite` and `heygen-video` generate footage from text (default 720p for Grok and 768p for HeyGen; HeyGen minimum 5 seconds). `flux-video-edit` edits one source video up to 15 seconds and 50 MiB, retaining source timing/aspect ratio with output capped at 720p. Use `source_video`, quote its duration, and import using the exact `replaceItemId` when replacing a clip. `avatar-iv` animates portrait plus speech audio, default 720p; its prompt describes motion, not dialogue. Read `requiredAssets`: every listed kind is mandatory. Prices use published regular inference rates with 1.7× markup, never temporary discounts; use a fresh quote. H3 Max remains on its existing route. OpenRouter video jobs cannot be canceled after submission; wait for completion before deleting.

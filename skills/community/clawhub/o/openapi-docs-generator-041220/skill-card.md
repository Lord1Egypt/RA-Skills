## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineering teams use this skill to turn OpenAPI or Swagger documentation work into practical workflows, checklists, implementation support, and validation steps for REST API projects.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation wording may route general API or developer-experience prompts to this skill unexpectedly.

Mitigation: Prefer explicit invocation where possible, or confirm the request is about OpenAPI or Swagger documentation before applying the workflow.

Risk: Generated documentation guidance can become inaccurate if it is not checked against the live API behavior.

Mitigation: Validate generated specifications and checklists against service code, contract tests, and an OpenAPI validator before publishing.

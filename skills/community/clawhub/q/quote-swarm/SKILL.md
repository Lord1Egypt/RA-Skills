## 📂 三文件系统

### 初始化步骤

```bash
TASK_NAME="quote-${CUSTOMER}-$(date +%Y%m%d)"
mkdir -p ~/.workbuddy/tasks/"$TASK_NAME"
cat > ~/.workbuddy/tasks/"$TASK_NAME"/task-plan.md << 'EOF'
# 任务计划 - 报价方案

## 🎯 目标
完成 {客户名} 的智能家居方案设计+报价生成

## 📋 步骤
- [ ] Phase 1: 输入源确认（优先级：高）
  - 输入：DXF/PDF/全景链接
  - 处理：输入源识别+格式转换
  - 输出：结构化输入数据
- [ ] Phase 2: 户型解析（优先级：高）
  - 输入：结构化输入数据
  - 处理：smart-home-dxf-pro / panorama-reader
  - 输出：房间信息+设备清单
- [ ] Phase 3: 方案设计（优先级：高）
  - 输入：房间信息+设备清单
  - 处理：smart-home-wiring / smart-home-icons
  - 输出：点位图+布线图
- [ ] Phase 4: 报价生成（优先级：高）
  - 输入：设备清单
  - 处理：shuangge-quote
  - 输出：HTML报价单
- [ ] Phase 5: 方案交付（优先级：中）
  - 输入：点位图+布线图+报价单
  - 处理：方案打包
  - 输出：交付包

## ✅ 验收标准
1. 爽哥智能报价表模板（只改数量）
2. 电源冗余≥20%
3. 开关数=灯具分组数
4. 电机数=窗户数

## 📅 时间线
- 创建时间：{ISO8601}
- 预计完成：{日期}
- 实际完成：{日期}
EOF

touch ~/.workbuddy/tasks/"$TASK_NAME"/research-findings.md
cat > ~/.workbuddy/tasks/"$TASK_NAME"/progress-log.md << 'EOF'
# 进度日志 - 报价方案

## ✅ 已完成
（任务启动后填充）

## 🔄 进行中
- [ ] Phase 1: 输入源确认（预计 $(date +%Y-%m-%d) 完成）

## 🚨 阻塞
（如有问题和解决方案，在此记录）

## 📍 下一步
1. 确认输入源
2. 户型解析
3. 方案设计
4. 报价生成
5. 方案交付
EOF
```

## 🔄 五步闭环流程

### Phase 1：输入源确认

**输入类型：**

| 类型 | 工具 | 输出 | 紧急度 |
|------|------|------|-------|
| DXF/DWG | smart-home-dxf-pro | 户型数据 | 常规 |
| JPG/PNG | smart-home-dxf-pro | 图像识别 | 常规 |
| 360全景 | panorama-reader | 照明方案 | 常规 |
| PDF图册 | lobster-pdf-vision | 产品数据 | 按需 |

---

### Phase 2：户型解析

**解析命令：**

```bash
# DXF解析
@smart-home-dxf-pro
  输入：[DXF文件路径]
  输出：房间信息+墙体数据+设备块

# 全景识图
@smart-home-panorama-reader
  输入：[360全景链接]
  输出：灯具布局+照明方案

# AI验图
@siliconflow
  模型：Qwen3-VL-32B
  输入：[渲染PNG]
  输出：设备数量+型号确认
```

---

### Phase 3：方案设计

**设计命令：**

```bash
# 点位规划
@smart-home-floorplan
  输入：房间信息+设备清单
  输出：2D点位规划图

# 布线设计
@smart-home-wiring
  输入：点位图+设备清单
  输出：智能布线图+回路分配
```

---

### Phase 4：报价生成

**报价命令：**

```bash
# 爽哥智能报价
@shuangge-quote
  输入：设备清单+客户信息
  参数：
    customerName: [客户名]
    area: [面积]
    houseType: [户型]
    productQuantities: {设备ID: 数量}
  输出：HTML报价单
```

**铁律**：只改数量，其他字段锁死！

---

### Phase 5：方案交付

**交付清单：**

| 交付物 | 工具 | 说明 |
|--------|------|------|
| HTML报价单 | shuangge-quote | 主交付物 |
| 点位规划图 | smart-home-floorplan | 设备布局 |
| 智能布线图 | smart-home-wiring | 布线方案 |
| 设备清单 | JSON | 数据汇总 |

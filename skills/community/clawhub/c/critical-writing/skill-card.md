## Description:

critical-writing guides Chinese-first writing tasks through clarifying questions, planning, staged drafting, multi-persona debate critique, arbitration, and revision.

This skill is ready for commercial/non-commercial use.

## Publisher:

[boboy-j](https://clawhub.ai/user/boboy-j)

### License/Terms of Use:

MIT-0

## Use Case:

External users, developers, and writers use this skill to draft formal or semi-formal Chinese content through a collaborative workflow that asks clarifying questions, structures the piece, critiques drafts with multiple persona reviewers, and rewrites from the agreed priorities.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The workflow can be too forceful for quick one-shot writing because it requires clarifying questions and a critique pass.

Mitigation: Use it for formal or collaborative writing tasks; choose a lighter workflow for brief drafts.

Risk: Unpinned npx installation can execute package code from a source the user has not reviewed.

Mitigation: Prefer ClawHub installation, manual installation, or a pinned reviewed CLI version.

Risk: Persona-style critique can be mistaken for the real views of named public figures.

Mitigation: Treat critic voices as creative style references and make clear that they do not represent real statements or endorsements.

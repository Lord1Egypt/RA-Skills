## Description:

Generate 2D game art that stays visually consistent across a whole set: sprites, die-cut stickers, item icons, parallax pieces, and asset sheets.

This skill is ready for commercial/non-commercial use.

## Publisher:

[runware](https://clawhub.ai/user/runware)

MIT-0

## Use Case:

Developers, technical artists, and game teams use this skill to guide agents through generating cohesive 2D asset packs, sprite icons, stickers, parallax pieces, and transparent game-ready cutouts.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts or reference artwork may be sent to configured image-generation tools.

Mitigation: Use only prompts and reference assets that are appropriate to share with those tools and review project confidentiality requirements before generation.

Risk: Generated assets, LoRAs, model outputs, or reference artwork may carry rights or licensing constraints for game use.

Mitigation: Confirm rights for LoRAs, models, outputs, and reference assets before using generated art in a game project.

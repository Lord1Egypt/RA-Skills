## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to turn API documentation requests into practical workflows, checklists, code changes, validation steps, and decision support for OpenAPI or Swagger documentation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad OpenAPI and API-documentation activation wording may apply the skill to general API or developer-experience requests where it is not the best fit.

Mitigation: Confirm the request is actually about generating, improving, or validating OpenAPI or Swagger documentation before accepting generated changes.

Risk: Generated documentation, examples, commands, or configuration may not fully match the target service behavior.

Mitigation: Validate generated OpenAPI or Swagger artifacts against source code, representative requests and responses, and an OpenAPI-compatible validator before publishing.

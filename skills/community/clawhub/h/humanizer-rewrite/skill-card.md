## Description:

Rewrites Chinese articles through an iterative draft, critique, and judging process to make the prose read more like human-written commentary.

This skill is ready for commercial/non-commercial use.

## Publisher:

[moxunjinmu](https://clawhub.ai/user/moxunjinmu)

### License/Terms of Use:

MIT-0

## Use Case:

External users and content editors use this skill to transform Chinese article drafts into more conversational, opinionated, and less formulaic prose. It can process direct text or a file path.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill explicitly optimizes text to hide AI authorship signals.

Mitigation: Use it only for legitimate style editing, and avoid using it to misrepresent authorship or bypass disclosure expectations.

Risk: When given a file path, the skill can overwrite the original file without confirmation.

Mitigation: Use copied files, keep backups, or require explicit confirmation before allowing file writes.

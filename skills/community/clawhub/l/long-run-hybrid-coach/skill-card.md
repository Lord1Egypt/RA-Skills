## Description:

Maintains a current 28-day running-and-strength direction from Garmin or Intervals.icu evidence, helping an athlete reassess goals, revise hybrid weeks, review training, and preview or deliver selected workouts.

This skill is ready for commercial/non-commercial use.

## Publisher:

[atomchung](https://clawhub.ai/user/atomchung)

### License/Terms of Use:

MIT-0

## Use Case:

External athletes use this skill to keep a Garmin or Intervals.icu-backed running and strength plan current, review planned versus actual training, and preview confirmed workout or calendar changes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can read training history, weight entries, and planned workouts from connected training providers.

Mitigation: Install only when comfortable granting that access and review the provider authorization before use.

Risk: Workout or calendar changes can affect an athlete's training plan.

Mitigation: Review each exact preview and confirm only the changes intended for delivery.

Risk: The skill is not intended for medical diagnosis.

Mitigation: Use it for training planning and seek qualified medical guidance for health concerns.

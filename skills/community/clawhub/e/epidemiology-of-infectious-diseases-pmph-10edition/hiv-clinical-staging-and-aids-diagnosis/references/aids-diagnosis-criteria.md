# 艾滋病期诊断标准详细参考

## 成人及≥15岁青少年艾滋病指征性疾病

满足以下任一即可诊断艾滋病期：

| 序号 | 临床指征 |
|------|----------|
| 1 | 原因不明持续不规则发热>1个月，体温>38℃ |
| 2 | 慢性腹泻>1个月，次数>3次/d |
| 3 | 6个月内体重下降10%以上 |
| 4 | 反复发作口腔真菌感染 |
| 5 | 反复发作单纯疱疹或带状疱疹 |
| 6 | 肺孢子菌肺炎（PCP） |
| 7 | 反复发生细菌性肺炎 |
| 8 | 活动性结核或非结核分枝杆菌病 |
| 9 | 深部真菌感染 |
| 10 | 中枢神经系统病变 |
| 11 | 中青年人出现痴呆 |
| 12 | 活动性巨细胞病毒感染 |
| 13 | 弓形虫脑病 |
| 14 | 马尔尼菲篮状菌病 |
| 15 | 反复发生败血症 |
| 16 | 卡波西肉瘤、淋巴瘤 |

## 特例规则

HIV抗体阳性者，即使无上述临床症状，但CD4+ T细胞 < 200个/μl，也可诊断为艾滋病期。

## 儿童艾滋病期CD4标准

### CD4+ T细胞百分率阈值

| 年龄 | CD4百分率阈值 |
|------|---------------|
| <12月龄 | <25% |
| 12-36月龄 | <20% |
| 37-60月龄 | <15% |

### CD4计数标准（5-14岁）

- CD4计数 < 200个/μl

### 儿童诊断要求

儿童艾滋病期诊断必须同时满足：
1. CD4指标低于上述年龄阈值
2. 伴有至少1种儿童艾滋病指征性疾病

## 关键实验室指标参考

| 指标 | 急性期 | 无症状期 | 艾滋病期 |
|------|--------|----------|----------|
| HIV RNA | 阳性（高载量） | 阳性（持续复制） | 明显升高 |
| p24抗原 | 阳性 | 可阳性 | 可阳性 |
| HIV抗体 | 数周后出现 | 阳性 | 阳性 |
| CD4+ T细胞 | 一过性减少 | 逐渐下降 | 明显下降（多<200/μl） |
| CD4/CD8比例 | 倒置 | 可倒置 | 明显倒置 |

## 诊断注意事项

1. **18月龄及以下儿童**：母体抗体可通过胎盘传递，抗体检测可能出现假阳性，必须依赖核酸检测（HIV DNA或RNA）确诊
2. **窗口期**：初次感染后抗体产生需要数周，此期间抗体检测可能阴性，需检测HIV RNA或p24抗原
3. **CD4计数波动**：CD4计数存在生理波动，诊断时应结合临床综合判断，必要时重复检测确认

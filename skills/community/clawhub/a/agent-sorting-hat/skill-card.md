## Description:

Diagnose agent role drift, team-structure problems, operating issues, and role misalignment; then redesign roles, boundaries, and team placement before persona refinement.

This skill is ready for commercial/non-commercial use.

## Publisher:

[child2d](https://clawhub.ai/user/child2d)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agent maintainers use this skill to diagnose role drift, unclear team boundaries, overloaded responsibilities, and agent placement problems before editing persona or role files.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may guide an agent to propose changes to shared role or team documentation.

Mitigation: Review proposed file changes before applying them, especially when they affect shared agent definitions.

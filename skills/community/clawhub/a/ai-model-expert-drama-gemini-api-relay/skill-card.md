## Known Risks and Mitigations:

Risk: The public description may overstate Gemini relay management compared with the package scripts' actual behavior.

Mitigation: Review the skill before installation and treat generated relay plans as guidance that must be validated against the deployed AI-HIVE workflow.

Risk: The skill handles API credentials and allows custom API base URLs.

Mitigation: Use a revocable AI-HIVE key, keep credentials out of public files and logs, and avoid custom base URLs unless the endpoint is fully trusted.

Risk: The scripts can upload media and download generated results.

Mitigation: Upload private media only when the AI-HIVE destination is acceptable, and use disabled downloads or a constrained output directory when appropriate.

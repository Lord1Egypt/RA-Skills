# 神经认知障碍及相关障碍临床评估

## 模块一：谵妄评估与管理

### 适用对象
老年患者、住院患者、术后患者、ICU患者、癌症患者、痴呆患者

### 第一步：风险评估

**素质性因素（基础脆弱性）**：
- 高龄、痴呆、功能性残疾、共病
- 视力受损、抑郁症状、轻度认知损害(MCI)
- 实验室指标异常、物质滥用（如酒精）

**诱因（急性打击）**：
- 药物（尤其镇静催眠药、抗胆碱能药物）
- 外科手术、麻醉
- 严重疼痛、感染
- 急性疾病或慢性病突然加重

**核心原则**：素质性因素越多，谵妄发生所需诱因越少

### 第二步：诊断确认

**必须满足5项核心要点**：
1. 注意障碍 + 意识障碍（对环境定向能力下降）
2. 短时间内发生（数小时到数天），日内波动
3. 其他认知功能障碍（记忆、定向、语言、视空间、知觉异常）
4. 不能由已存在的神经认知障碍更好解释，非昏迷状态
5. 有证据表明由躯体疾病/药物/物质/毒素/多种病因所致

**辅助工具**：MMSE、CAM（意识模糊评定法）、DRS（谵妄分级量表）

### 第三步：鉴别诊断

| 鉴别对象 | 关键区别 |
|----------|----------|
| 痴呆 | 谵妄起病急、有意识障碍、认知损害波动 |
| 精神分裂症/情感障碍 | 谵妄有意识及定向力障碍 |
| 急性应激障碍 | 谵妄由躯体疾病所致，非严重应激事件 |

### 第四步：治疗干预

**1. 病因与支持治疗（首要）**
- 纠正原发疾病（电解质紊乱、感染等）
- 减停致病药物
- 加强支持治疗，预防并发症

**2. 非药物干预**
- 安静舒适、昼夜分明环境
- 亲属陪护，清醒时适当交流
- 限制白天睡眠，保持昼夜节律
- 提供眼镜/助听器改善感知

**3. 药物干预指征**
- 严重感知觉紊乱、妄想、冲动激越
- 语言安抚无效或可能造成伤害

**4. 药物选择**
- 兴奋躁动：小剂量氟哌啶醇肌注
- 症状较轻：小剂量非典型抗精神病药口服（喹硫平/奥氮平/利培酮）
- **原则**：小剂量起始，缓慢滴定，症状好转尽早停用
- **禁忌**：低活动型避免抗精神病药；苯二氮䓬类常规慎用（戒断性谵妄除外）

## 模块二：血管性痴呆（VaD）评估

### 诊断标准（必须满足6条）
1. 符合痴呆诊断标准
2. 存在脑血管病证据（病史/查体/影像学）
3. 痴呆与脑血管事件密切相关：卒中后3个月内发生，持续6个月以上
4. 认知损害不均衡（注意/执行受损为主，记忆轻微或无受损）
5. 自知力和判断力较好
6. 排除其他脑病或精神障碍

### 临床特征
- **起病**：突发或亚急性，卒中后迅速出现
- **病程**：阶段性加重或改善（阶梯式发展）
- **影像**：CT/MRI可见多发性梗死灶或关键部位梗死
- **体征**：步态异常、肌力下降、肌张力异常等定位体征

### 鉴别诊断
| 疾病 | 关键区别 |
|------|----------|
| AD | 隐袭起病，记忆下降为主，显著脑皮质萎缩 |
| 路易体痴呆 | 波动性认知、生动幻视、锥体外系症状一年内同时出现 |
| 帕金森病痴呆 | 早期锥体外系受累，无卒中史 |

### 治疗与二级预防

**1. 防治卒中（核心）**
- 控制危险因素：高血压、血脂异常、糖尿病、心脏病、戒烟
- 预防再发：抗血小板聚集、抗凝治疗

**2. 改善认知**
- 胆碱酯酶抑制剂（多奈哌齐、加兰他敏、卡巴拉汀）
- NMDA受体拮抗剂（美金刚）

**3. 控制精神行为症状**
- 胆碱酯酶抑制剂/NMDA受体拮抗剂有一定改善
- 抗精神病药：小剂量起始，控制后逐步减量

**预后警示**：5年死亡率约61%，平均生存8-10年，主要死因为肺部感染和心脑血管疾病

## 模块三：儿童青少年破坏性行为障碍

### ODD（对立违抗障碍）诊断

**核心标准**：
- 持续≥6个月的反抗、不听话、挑衅或恶意行为
- 频率高于同龄人
- 导致严重功能损害
- 不限于与兄弟姐妹互动

**亚型分类**：
- 伴慢性易激惹/愤怒：几乎每天存在，多情景，强度与挑衅不成比例
- 不伴慢性易激惹/愤怒：以任性、好争辩、挑衅为主

**亲社会情感标注**：
- 伴亲社会情感受限（"冷酷无情"特质）：缺乏共情、无悔过、对惩罚漠不关心
- 伴亲社会情感正常

### ODD鉴别诊断决策树

```
行为频率评估
├── 每月几次/每周1-2次 → 正常对立违抗
└── 每周5-7次/每天 → 继续评估
    │
    ├── 侵犯法律/他人权利（攻击/破坏/偷窃/说谎）？
    │   ├── 是 → 品行障碍(CD)
    │   └── 否 → 继续评估
    │
    ├── 情绪暴发严重且慢性化？
    │   ├── 符合DMDD标准 → DMDD（与ODD不共存）
    │   └── 不符合 → 继续评估
    │
    └── 执行功能困难（组织/计划/等待）？
        ├── 是 → 考虑ADHD（常共病）
        └── 否 → ODD诊断
```

### CD（品行障碍）干预

**分阶段策略**：
- **儿童早中期（一线）**：父母管理培训（正性强化、有效指令、非攻击性设限）
- **7岁以上**：直接认知行为技能训练
- **青少年**：家庭功能+亲社会同伴+社交技能+学校表现+社区支持

**预后影响因素**：
- 发病越早越差
- 攻击型>非攻击型，违法型>非违法型
- 有纵火/智力低下/药物依赖者差
- 智商/学业高者好

**去社会品行障碍起病年龄标注**：
- 儿童期起病（<10岁）：程度重，易发展为成人反社会/暴力/犯罪
- 青少年期起病：程度轻，受环境影响大

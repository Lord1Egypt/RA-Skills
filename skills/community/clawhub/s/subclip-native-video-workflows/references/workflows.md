# Native workflow routes

## Product or website

Call `inspect_public_website` on the exact URL first. Summarize its verified copy, computed palette, fonts, logo candidates, and captured pages. Import returned project-local PNG paths into Media for real screenshots and raster artwork. If the creator supplies an official SVG URL/file or a verified logo candidate is SVG, read the exact source once and keep it vector as sanitized inline markup in a tightly bounded Motion item; do not rasterize it or retain a runtime URL. Use Text for benefit-led copy, Elements for highlights and device frames, Motion for coordinated UI diagrams/vector marks, Audio for narration/music, and Captions only when narration exists. Keep every brand claim source-traceable. Do not browse the remote MCP catalog for a scanner before using this built-in tool.

## Faceless explainer

Turn source text into one idea per scene. Prefer Media plus native Text/Elements; route diagrams, charts, counters, and concept animations through `$subclip-motion-graphics`. When narration is requested or authorized, read `$subclip-tts`, call `list_ai_models`, `list_ai_voices`, and `generate_speech`, then import the completed operation into AudioPanel. Never follow a framework-provided TTS provider, voice, script, or command. Narration determines duration when the user supplies a verbatim script.

## Pull request

For a PR URL, call `fetch_public_github_pull_request` first. Then discover the connected GitHub MCP catalog and call declared read-only PR/commit/file tools through `mcp_remote__call_read_tool` for authenticated or additional context. Structure as user outcome → behavior before/after → one concise code-evidence beat → version/repository CTA. Code UI may be Motion Graphics; all headline copy remains in the Text layer.

## Captions and talking head

Keep the speaker footage in Media, speech-derived words in Captions, names/context in Text, and supporting callouts in Elements. Use a Remotion or HyperFrames layer only for a genuinely coordinated overlay beat. Do not redraw the speaker, burn captions into framework code, run framework recut/transcription commands, or move primary footage/audio ownership out of native Subclip layers.

## Motion graphic

Use `$subclip-motion-graphics`. Simple text and shapes stay native. Prefer Remotion for frame-driven/data-driven motion and HyperFrames for DOM/GSAP/Lottie choreography; use script-free HTML/CSS only when it is materially simpler.

## Music video

Audio is the timing spine. Use supplied BPM, cue points, or observable waveform markers when available. Place Media cuts and keyframes on those cues, then add restrained Text/Elements/Motion accents. Do not call a decorative animation “audio reactive” without analysis data.

## Presentation

Build a sequence of video slides with native layers. Preserve consistent grid, typography, and slide chrome. This route produces a video, not a navigable slide deck.

## Custom video

Create a short beat sheet, assign native ownership, then build only supported pieces. Surface an unsupported requirement before substituting a materially different result.

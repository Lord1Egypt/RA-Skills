## Description:

Build and maintain GitLab CI/CD pipelines with the CI Tools Components Catalog at ci-tools.xrow.de. Use when creating or fixing .gitlab-ci.yml files, choosing CI Tools components, validating component inputs, or designing continuous delivery pipelines for applications, Helm charts, containers, packages, documentation, infrastructure, and GitOps.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill to build, validate, and maintain GitLab CI/CD pipelines with the CI Tools Components Catalog. It helps select components and design delivery workflows for applications, infrastructure, and GitOps projects.

## Known Risks and Mitigations:

Risk: The described GitLab linting command may send pipeline configuration to the configured GitLab instance.

Mitigation: Check the destination and confirm that sending the configuration there is acceptable before running the linting command.

## Description:

Upgrades existing websites and apps to premium quality by auditing current design, identifying generic AI patterns, and applying high-end design standards without breaking functionality.

This skill is ready for commercial/non-commercial use.

## Publisher:

[akdira](https://clawhub.ai/user/akdira)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agents use this skill to assess an existing website or app, identify weak typography, color, layout, interaction, content, and code patterns, and apply focused redesign improvements within the current stack.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can lead an agent to make visual and frontend code changes in an existing project.

Mitigation: Review generated design edits before shipping and test affected user flows after changes.

Risk: The skill may suggest or add external image URLs when real assets are unavailable.

Mitigation: Review any added external image URLs and replace placeholders with approved assets before production use.

FTA Studio 使用说明
================================================

一、这是什么
  FTA Studio 是一个对齐 medini analyze 的故障树（FTA）绘图与分析工具。
  本包为【免安装绿色版】：Node.js 运行时已内置在 runtime 文件夹中，
  目标电脑不需要安装 Node.js，也不需要联网即可运行。

二、怎么用（两种方式，任选其一）

  【方式 A】直接使用（绿色版，适合临时使用 / U 盘携带）
    1. 把整个 "FTA Studio" 文件夹复制到对方电脑（U 盘、网盘均可）
    2. 双击  启动 FTA Studio.bat
    3. 浏览器会自动打开 http://localhost:8777/
       若没有自动打开，手动在浏览器地址栏输入上面的地址即可
    4. 用完想停止服务：双击  停止 FTA Studio.bat

  【方式 B】安装到本机（有桌面图标，适合长期使用）
    1. 双击  安装到本机.bat
    2. 程序会复制到 %LOCALAPPDATA%\FTA Studio，
       并在【桌面】和【开始菜单】创建 "FTA Studio" 快捷方式
       （不需要管理员权限）
    3. 以后直接双击桌面图标即可使用
    4. 想卸载：双击  卸载.bat

三、常见问题

  Q：双击后浏览器显示"无法访问此页面"？
  A：等 2~3 秒再刷新一次；或者用 http://127.0.0.1:8777/ 。
     服务在后台运行，启动器那个黑窗口一闪而过是正常的。

  Q：提示端口 8777 被占用？
  A：程序会自动顺延到 8778、8779……，以控制台打印的实际地址为准。

  Q：换电脑后我的故障树还在吗？
  A：故障树数据保存在浏览器本地（localStorage），不随文件夹复制。
     迁移数据请用工具内的【导出】（FaultTree+ XML / medini JSON / DSL），
     到新电脑再用【导入】打开。

  Q：需要管理员权限吗？
  A：不需要。绿色版直接运行；安装版只写入当前用户目录。

  Q：可以在 Mac / Linux 上用吗？
  A：本包内置的是 Windows 版 Node。Mac/Linux 请先安装 Node 18+，
     然后在 app 目录执行：node src/launch.mjs

  Q：会被杀毒软件拦截吗？
  A：批处理调用的是包内自带的 node.exe（标准 Node.js），
     个别安全软件可能对"未签名 exe"提示，选择允许即可。

四、目录说明

  runtime\node.exe          内置 Node.js 运行时（Windows x64）
  app\src                   服务端与计算引擎（MOCUS / BDD）
  app\public                前端界面
  app\examples              内置示例
  启动 FTA Studio.bat        启动（后台运行，自动打开浏览器）
  停止 FTA Studio.bat        停止后台服务
  安装到本机.bat             安装到当前用户 + 创建快捷方式
  卸载.bat                   卸载

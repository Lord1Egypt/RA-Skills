## Description:

Guided Game Design Document writing using structured templates, walking through GDD sections with system decomposition, mechanics breakdown, and narrative design to produce a complete, navigable design document.

This skill is ready for commercial/non-commercial use.

## Publisher:

[toilanguyen2910](https://clawhub.ai/user/toilanguyen2910)

### License/Terms of Use:

MIT-0

## Use Case:

Game designers, developers, and teams use this skill to draft a structured Game Design Document for a game concept, including overview, mechanics, systems, levels, narrative, UI/UX, audio, content, monetization, and technical specification sections.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Vague requests for a design document may invoke the skill when the user intended a different kind of document.

Mitigation: Confirm that the requested document is a game design document before using the workflow.

Risk: The skill may create or update markdown files under a GDD folder in the workspace.

Mitigation: Review the proposed file paths and generated markdown before accepting workspace changes.

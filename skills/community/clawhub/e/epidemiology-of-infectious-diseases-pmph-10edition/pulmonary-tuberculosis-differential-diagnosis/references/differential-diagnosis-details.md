# 肺结核鉴别诊断详细对比表

## 1. 肺癌 vs 肺结核

| 特征 | 中央型肺癌 | 肺门淋巴结结核 | 周围型肺癌 | 结核球 |
|------|-----------|---------------|-----------|--------|
| 好发人群 | >40岁男性 | 儿童/青年 | >40岁男性 | 各年龄段 |
| 主要症状 | 刺激性咳嗽、胸痛、进行性消瘦 | 结核中毒症状 | 胸痛、咯血 | 多无症状或轻微 |
| 影像-位置 | 肺门区 | 肺门区 | 肺周围 | 肺上叶尖后段 |
| 影像-形态 | 分叶状、毛刺 | 肺门增大 | 球状/分叶状 | 球状 |
| 影像-边缘 | 切迹、毛刺 | 边界较清 | 毛刺、切迹 | 光滑、卫星灶 |
| 影像-钙化 | 少见 | 可见 | 少见 | 常见 |
| 确诊方法 | 痰脱落细胞、纤支镜活检 | PPD、病原学 | 痰脱落细胞、穿刺活检 | 痰结核菌 |

**重要提示**：肺癌和肺结核可并存，老年患者尤其需警惕

## 2. 细菌性肺炎 vs 肺结核

| 特征 | 细菌性肺炎 | 肺结核（原发/继发渗出/干酪性） |
|------|-----------|-------------------------------|
| 起病 | 急 | 缓慢 |
| 发热 | 高热、寒战 | 低热、盗汗 |
| 咳嗽 | 咳铁锈色痰 | 干咳或少量黏液痰 |
| 胸痛 | 明显 | 轻微或无 |
| 影像分布 | 局限于一叶或一段 | 多灶性、上叶多见 |
| 影像特征 | 大片均匀致密影 | 斑片状、空洞、纤维化 |
| 白细胞 | 增高、中性粒细胞增高 | 正常或轻度增高 |
| 抗生素反应 | 有效 | 无效 |
| 病原学 | 痰培养阳性 | 痰结核菌阳性 |

**注意**：支原体肺炎等非典型病原体需靠特异性病原学检测鉴别

## 3. 肺脓肿 vs 肺结核空洞

| 特征 | 肺脓肿 | 肺结核空洞 |
|------|--------|-----------|
| 起病 | 急 | 缓慢 |
| 发热 | 高热 | 低热 |
| 痰液 | 大量脓臭痰 | 少量黏液痰或无痰 |
| 空洞位置 | 肺下叶多见 | 肺上叶多见 |
| 空洞壁 | 厚壁 | 薄壁 |
| 周围炎症 | 浸润重 | 浸润轻 |
| 液平面 | 明显 | 少/浅 |
| 痰检 | 无结核菌，有其他细菌 | 结核菌阳性 |
| 抗生素反应 | 有效 | 无效 |

## 4. 支气管扩张 vs 继发性肺结核

| 特征 | 支气管扩张 | 继发性肺结核 |
|------|-----------|-------------|
| 病程 | 慢性、反复发作 | 慢性 |
| 咳嗽 | 慢性咳嗽、大量脓痰 | 干咳或少量黏液痰 |
| 咯血 | 反复咯血 | 可咯血 |
| X线 | 多无异常或肺纹理增粗/卷发状阴影 | 斑片状、空洞、纤维化 |
| CT | 支气管扩张、壁增厚 | 结核病灶特征 |
| 结核菌 | 阴性（除非并发结核） | 阳性 |

**警惕**：化脓性支扩可并发结核感染，需同时排查

## 5. 非结核分枝杆菌(NTM)肺病 vs 肺结核

| 特征 | NTM肺病 | 肺结核 |
|------|---------|--------|
| 临床表现 | 极相似 | 典型结核症状 |
| X线表现 | 极相似 | 典型结核影像 |
| 结核菌素试验 | 可阳性 | 阳性 |
| 抗结核治疗 | 无效或效果差 | 有效 |
| 确诊 | 菌种鉴定（分子生物学/质谱） | 结核分枝杆菌培养/鉴定 |

**关键**：NTM肺病必须依赖菌种鉴定确诊，常规抗结核方案无效时应高度怀疑

## 影像学特征速查

### 结核典型影像特征
- **位置**：上叶尖后段、下叶背段
- **形态**：多灶性、多态性（渗出、增殖、纤维化、钙化并存）
- **空洞**：薄壁、上叶多见
- **卫星灶**：结核球周围常见
- **钙化**：常见，形态多样

### 需警惕的恶性征象
- 分叶征
- 毛刺征
- 胸膜凹陷征
- 空泡征
- 进行性增大

## 确诊检查选择指南

| 疑似疾病 | 首选检查 | 备选检查 |
|---------|---------|---------|
| 肺癌（中央型） | 纤维支气管镜+活检 | 痰脱落细胞、CT引导穿刺 |
| 肺癌（周围型） | CT引导穿刺活检 | 痰脱落细胞、PET-CT |
| 肺炎 | 痰培养+药敏 | 血培养、血清学检查 |
| 肺脓肿 | 痰培养+药敏 | 血培养、脓液培养 |
| 支气管扩张 | 高分辨率CT | 支气管造影（少用） |
| NTM肺病 | 菌种鉴定（分子生物学） | 质谱分析、特殊培养 |
| 肺结核 | 痰结核菌培养+药敏 | PPD、T-SPOT、纤支镜 |

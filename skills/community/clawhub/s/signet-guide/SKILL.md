# Signet Guide

Getting started guide for Signet Mind — a standalone mental health companion app that runs entirely local, providing supportive conversation, wellness tools, and mood tracking without transmitting data to the cloud.

## Triggers

Use when the user wants to:
- Get started with Signet Mind
- Set up the Signet AI mental health companion
- Learn about grounding exercises, breathing techniques, or mood tracking
- Find mental health support tools that work entirely offline
- Understand how Signet AI's local-first privacy model works

## Actions

- **Setup guide** — Complete installation and configuration walkthrough
- **Features overview** — Explain available tools: grounding exercises, breathing guides, mood tracking, supportive conversation
- **Privacy explainer** — How Signet Mind keeps data local vs cloud alternatives
- **First session** — Guide through first conversation and baseline mood setup
- **Wellness tools** — Instructions for each tool type

## What Signet Mind Provides

- **Supportive conversation** — Not therapy, but a listening presence (clearly labelled as non-therapeutic)
- **Grounding exercises** — 5-4-3-2-1 technique, body scan, sensory grounding
- **Breathing guides** — Box breathing, 4-7-8, physiological sigh, with timed guides
- **Mood tracking** — Simple daily check-in, trend visualization, export to file

## Requirements

- Signet AI installed
- Python 3.8+ (for desktop app components)
- Local LLM (Ollama) for offline conversation mode

## Description:

Group keywords into page-level clusters by search intent and map each cluster to an existing or new page, flagging cannibalization. Use when the user has a keyword list, saved keywords, or Search Console queries and asks which page should target which keywords, or wants a keyword map, content plan, topic clusters, or to fix pages competing for the same query.

This skill is ready for commercial/non-commercial use.

SEO practitioners use this skill to organize keyword lists, saved keywords, or Search Console queries by intent and page type. It maps clusters to existing or proposed pages and identifies possible cannibalization or consolidation needs.

## Known Risks and Mitigations:

Risk: The skill expects to consult Weline project guidance files when they exist, and those repository-local files may contain sensitive internal instructions.

Mitigation: Install and use it only for Weline frontend/theme work, and review the referenced local source-material files before relying on their guidance.

Risk: Generated component, tracking, or PageBuilder changes can affect rendered frontend behavior if they are not validated in the target page flow.

Mitigation: Validate the rendered page or PageBuilder flow, confirm scoped CSS and JavaScript, and check that tracking hooks do not double-report events.

Risk: The deprecated package mixes file-integrity framing with persona, memory archive, and public anchoring workflows.

Mitigation: Review the package as a legacy broad workflow before installation, and run Champion, archive, or anchor steps only when those behaviors are explicitly wanted.

Risk: The artifact directs users to installer commands without pinning the successor package version.

Mitigation: Install the successor through a pinned and trusted installer when possible.

Mitigation: Treat the package as file-integrity and provenance tooling only, and use the successor package for new installs.

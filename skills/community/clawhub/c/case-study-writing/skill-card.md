Risk: The skill asks users to run a mutable remote installer command.

Mitigation: Review the installer before execution and prefer a pinned release with signature or checksum verification.

Risk: The skill can send customer names, confidential metrics, deal details, or unreleased strategy to external search or executor apps.

Mitigation: Use approved services only, get permission for sensitive customer data, and redact confidential details before sending prompts or code to external tools.

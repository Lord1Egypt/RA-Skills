## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineering teams use this skill to turn API documentation requests into practical workflows, checklists, implementation support, and validation notes for REST API documentation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad OpenAPI, Swagger, REST API, and API documentation triggers may activate the skill during some general API documentation conversations.

Mitigation: Use explicit prompts when this workflow is desired, and ask the agent not to use the skill when a general API discussion should stay outside this workflow.

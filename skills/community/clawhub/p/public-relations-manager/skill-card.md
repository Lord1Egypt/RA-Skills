## Description:

AI-powered assistant for PR professionals to match media contacts, generate press releases and pitches, and plan multi-week public relations campaigns.

This skill is ready for commercial/non-commercial use.

## Publisher:

[zhenstaff](https://clawhub.ai/user/zhenstaff)

### License/Terms of Use:

MIT

## Use Case:

PR professionals, marketers, startup founders, and communications teams use this skill to find relevant journalists and outlets, draft announcement materials, and organize campaign calendars.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Unpinned external install instructions can pull code that has not been reviewed for the intended environment.

Mitigation: Install in a virtual environment from a trusted source, and prefer pinned versions or reviewed commits.

Risk: Media databases and journalist profiles can contain contact details or other personal data.

Mitigation: Store only necessary journalist data and handle it according to the user's privacy and retention requirements.

Risk: Generated pitches and press releases may be inaccurate, misleading, or unsuitable for a specific journalist or outlet.

Mitigation: Review and edit generated content before sending or publishing.

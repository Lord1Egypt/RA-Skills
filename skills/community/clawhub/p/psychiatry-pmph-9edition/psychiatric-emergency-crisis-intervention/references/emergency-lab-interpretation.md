# 精神科急诊实验室检查异常解读

## 躯体检查重点

### 一般情况
- 恶病质 → 结核/癌症/艾滋病/营养不良
- 呼吸窘迫 → 急性心肺疾病
- 皮疹 → 过敏或感染

### 头颈眼
- 黏膜干燥 → 脱水
- 瞳孔/眼球运动异常 → 中毒/戒断/局灶神经缺陷
- 巩膜黄染 → 黄疸
- 眼球突出 → 甲亢
- 颈部强直 → 脑膜炎/脑炎

### 胸心血管
- 湿啰音 → 充血性心衰
- 干啰音 → 肺炎
- 心率/心律异常 → 心血管疾病

### 腹部
- 肝大 → 未诊断肝病
- 腹部压痛 → 急腹症

### 神经系统
- 局部损害 → 脑卒中/隐性栓塞
- 慌张步态/僵硬/震颤 → 帕金森/锥体外系症状
- 宽大步态 → 脑积水/三期梅毒

## 实验室检查异常解读

### 全血细胞计数
| 异常 | 临床意义 |
|------|----------|
| 巨幼细胞贫血 | B12/叶酸缺乏/酒精滥用 |
| 白细胞减少 | 晚期艾滋病/免疫抑制/白血病 |
| 血小板减少 | 丙戊酸盐/卡马西平副作用 |

### 基础代谢
| 异常 | 临床意义 |
|------|----------|
| 低钠血症 | SSRIs副作用（尤老年人） |
| 低/高钾血症 | 心律失常/肾衰/利尿药/贪食 |
| 低碳酸盐 | 酸中毒/阿司匹林摄入 |

### 肝肾功
| 异常 | 临床意义 |
|------|----------|
| ALT/AST比值升高 | 酒精滥用 |
| ALT/AST升高 | 药物/对乙酰氨基酚/肝炎致肝衰竭 |
| 肌酐升高 | 肾衰竭 |

### 尿常规
- 老年人或患者尿路感染 → 可导致严重谵妄

### 内分泌/营养
| 异常 | 临床意义 |
|------|----------|
| TSH升高 | 甲减致抑郁/认知改变 |
| TSH降低 | 甲亢致躁狂/激越 |
| B12/叶酸低 | 神经改变/记忆障碍/酒精滥用 |

### 其他关键检查
- RPR阳性 → 潜伏梅毒致痴呆
- 头颅CT → 筛查器质性/新发症状
- 脑电图 → 诊断癫痫/鉴别代谢性脑病
- 腰穿 → 发热/脑膜刺激征查感染/出血
- 心电图 → 抗精神病药/美沙酮可延长QTc间期

# Language and message catalogs

## User-visible behavior

Everything defaults to English. `--lang zh` or `HKW_LANG=zh` switches, and `install.sh` persists the choice to `~/.config/hekouwang-terminal/lang`.

## Catalog layout

Message catalogs live in `lib/i18n/{en,zh}/<script>.sh`, one file per script. They are loaded **English first, then the current language on top** — a missing translation falls back to English rather than printing an empty line.

## Constraints that must not be "tidied up"

- macOS ships bash 3.2, which has **no associative arrays**. The catalogs are plain variables plus `${!name}` indirection on purpose. Converting them to `declare -A` only works on machines with bash 5.
- Every message goes through `printf --`. Without the `--`, any message starting with `-` (`"--check mode, nothing was touched"`) is treated as a printf option and prints nothing.
- Help text lives in the catalogs, not in the script header comments. The old `sed -n '3,13p' "$0"` trick cannot be bilingual and will drift.

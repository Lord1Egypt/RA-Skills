中越翻译质量提升工作流（南宁市悦迅翻译有限公司 · 回译派 · 15 年中越实战）。以「反思回译法」10 阶段为父方法，叠加中越专项检查清单、假一致加固、可选回译前接地三层工程加固。专攻越南语翻译 QA、双模型反思流水线、回译派课程落地。

## Use Case:

External translators, translation teams, and AI-assisted localization practitioners use this skill to run a Chinese-Vietnamese translation QA workflow with terminology extraction, web term checks, model-separated translation and blind back-translation, issue diagnosis, and human delivery review.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad trigger phrases may activate the skill during general translation discussions.

Mitigation: Confirm the user intends to run a Chinese-Vietnamese translation QA workflow before applying the full process.

Risk: Web terminology checks may expose submitted terms or text to search providers.

Mitigation: Redact sensitive content and use only approved search or reference sources for confidential translation projects.

Risk: Using the same model for direct translation and blind back-translation can weaken independent QA.

Mitigation: Use separate models for translation, reflection, and blind back-translation, or clearly flag single-model fallback for stronger human review.

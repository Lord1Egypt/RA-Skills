## Use Case:

External creators and developers use this skill to turn natural-language visual requirements into namespace-compliant CSS themes for WeChat Official Account articles. It helps generate local theme files that can be tested or applied in a WeChat publishing workflow.

## Known Risks and Mitigations:

Risk: The skill may generate and save a local CSS theme file that overwrites an existing theme.

Mitigation: Choose the output filename deliberately and confirm overwrite intent before saving.

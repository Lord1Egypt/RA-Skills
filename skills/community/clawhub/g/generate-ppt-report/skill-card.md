## Description:

Generates a daily financial market PowerPoint briefing from collected market data using a single-slide dashboard template.

This skill is ready for commercial/non-commercial use.

## Publisher:

[szrw1825](https://clawhub.ai/user/szrw1825)

### License/Terms of Use:

MIT-0

## Use Case:

Financial analysts or operations users use this skill to produce a daily PowerPoint dashboard summarizing market performance, policy updates, and company news from collected market data and an existing Word report.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill imports executable configuration from a hard-coded personal path.

Mitigation: Use it only in a controlled workspace and replace the external Python config import with validated non-executable configuration before broader deployment.

Risk: The generated PPT depends on files in the E:\daily workspace, including the template, market data, and an optional Word report.

Mitigation: Verify that the workspace paths and input files are trusted, documented, and current before running the script.

Risk: The script writes the dated PowerPoint output into the configured daily output directory.

Mitigation: Add overwrite protection or review the target output path before execution when preserving existing reports matters.

Risk: Broad trigger phrases such as generating or making a PPT could invoke the skill outside the intended daily finance workflow.

Mitigation: Narrow the trigger phrase to the specific daily financial report workflow before installation.

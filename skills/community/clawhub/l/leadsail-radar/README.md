# LeadSail Radar — ClawHub skill package

`skills/radar/SKILL.md` 是 ClawHub/AgentSkills 标准格式的 skill 包。

## 上架步骤（唯一需用户操作的一步）

1. 打开 https://clawhub.com（用 LeadSail 组织的 GitHub 账号登录——
   账号需注册满 1 周，安全审核 2-5 天，非提交即上）
2. Submit skill → 选择本仓库路径 `skills/radar/SKILL.md`（或先复制到独立
   public 仓库 `LeadSail/leadsail-skill-radar` 再提交，审核更顺）
3. 填 name=`leadsail-radar`、version=1.0.0，提交后等审核

## 为什么只有这一步是人工

按用户 2026-11-27 零人工硬约束：skill 包制作/版本管理全自动（改 SKILL.md
→ commit → push），但 ClawHub 市场提交需 GitHub 登录态与审核流，无法自动化。

## Description:

Routes reusable OpenClaw workflow learnings, handoffs, skill requests, SOPs, and retrospectives into D:\internal-hub while preserving role boundaries.

This skill is ready for commercial/non-commercial use.

## Publisher:

MIT-0

## Use Case:

OpenClaw operators and agents use this skill to decide when reusable work should be posted to an internal coordination hub, converted into a shared skill, or promoted into an SOP. It helps structure handoffs, validation notes, retrospectives, and role-specific collaboration without mixing responsibilities.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Implicit invocation could cause agents to publish reusable work or shared skills without enough user scoping or confirmation.

Mitigation: Require explicit confirmation before posting content to D:\internal-hub or creating and updating shared skills.

Risk: Internal hub posts may expose sensitive business, customer, credential, financial, or draft strategy data.

Mitigation: Define clear posting rules for allowed information, redact sensitive content before posting, and review the workspace context before installation.

Risk: Shared skills under D:\internal-hub\skills could affect future workflows if created or modified without governance.

Mitigation: Limit who can create or update shared skills and require validation results before promoting a reusable skill.

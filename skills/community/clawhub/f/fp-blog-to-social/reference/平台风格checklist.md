# 四平台风格 Checklist

Skill 输出后，按此清单快速检查每个平台是否符合规范。

## ① Facebook
- [ ] 120-150 字英文
- [ ] 以问句或反常识事实开头
- [ ] 完整解释了核心信息（科普风格）
- [ ] 结尾有官网引导（→ fridayparts.com）
- [ ] Hashtag 3-4 个，含 #FridayParts #FixItOnceFixItRight

## ② Instagram
- [ ] 60-80 字英文
- [ ] 首句是钩子（不是平铺直叙）
- [ ] emoji 1-2 个，不堆砌
- [ ] Hashtag 8 个（品牌 + 机械垂类）
- [ ] 情绪化、节奏快

## ③ X
- [ ] ≤240 字英文
- [ ] 去掉了客套开场，直接进主题
- [ ] 信息清晰（适当用符号清单）
- [ ] Hashtag 2-3 个

## ④ TikTok 钩子
- [ ] 是一句话（前3秒用）
- [ ] 有悬念/张力/痛点
- [ ] 能让人想继续看

## 通用
- [ ] 四个平台都出了，没漏
- [ ] 四段不是复制粘贴，各有平台特色
- [ ] 核心信息一致
- [ ] 技术类内容没有绝对化表述（can/may 而非 always）
- [ ] 故障归因留余地

---

## 常见需要微调的地方
- INS 的 hashtag 如果太通用 → 换更垂直的（按设备类型）
- X 如果超字数 → 删掉次要信息，保留最核心的对比
- TikTok 钩子如果太平 → 加入数字或反常识（"$8 part" "every cold morning"）

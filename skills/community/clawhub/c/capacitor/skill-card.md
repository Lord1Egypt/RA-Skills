## Known Risks and Mitigations:

Risk: Cloud deployment workflows can upload live updates, trigger native builds, and create app store deployments.

Mitigation: Run release commands only in isolated environments after explicit approval, and restrict credentials to least-privileged, short-lived tokens.

Risk: Command examples include unpinned npx invocations and command-line token handling.

Mitigation: Pin CLI versions where possible and avoid putting tokens directly on command lines; prefer secure CI secret storage.

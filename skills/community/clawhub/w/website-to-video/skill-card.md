## Description:

Capture a general website or URL and turn it into a site tour, showcase, or social clip built from captured screenshots and the site's own brand assets.

This skill is ready for commercial/non-commercial use.

## Publisher:

[heygen-com](https://clawhub.ai/user/heygen-com)

### License/Terms of Use:

MIT-0

## Use Case:

External users, creators, marketers, and developers use this skill to capture a website and produce a brand-faithful HyperFrames video such as a site tour, portfolio showcase, or social clip.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Silent, unpinned skill updates can change behavior before execution.

Mitigation: Require explicit approval and version pinning for HyperFrames updates before installing or running the skill.

Risk: API keys can be exposed if pasted into chat or stored casually.

Mitigation: Use a secure environment or credential manager for keys, and rotate any key that was already pasted into chat.

Risk: Capturing authenticated, private, regulated, or confidential pages can expose screenshots or frames to third-party AI services.

Mitigation: Avoid those pages unless that processing is acceptable, or run the workflow in local/offline mode.

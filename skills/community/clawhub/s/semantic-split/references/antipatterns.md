# 反模式指南

## 常见反模式

### 1. 任务描述过于模糊
- **错误做法**："帮我处理一下这个"
- **正确做法**：明确任务范围、输出格式、约束条件
- **影响**：导致拆分不准确，规划偏离用户意图

### 2. 忽略约束强度
- **错误做法**：将所有要求等同对待
- **正确做法**：区分 🔴 硬约束 / 🟡 软约束 / ⚪ 无约束
- **影响**：硬约束被忽略导致输出不可用

### 3. 跳过自我反查
- **错误做法**：直接输出拆分结果
- **正确做法**：执行4项自我反查后输出
- **影响**：遗漏硬约束、误判约束等级

### 4. 双视角推理不完整
- **错误做法**：只做聚焦方案
- **正确做法**：聚焦 + 发散 → 整合
- **影响**：方案缺乏创新性或过于冒进

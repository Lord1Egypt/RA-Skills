## Description:

Symbiont provides zero-trust AI agent governance for OpenClaw with ORGA runtime guidance, Cedar policy workflows, SchemaPin tool verification, ClawHavoc skill scanning, and audit-trail support.

This skill is ready for commercial/non-commercial use.

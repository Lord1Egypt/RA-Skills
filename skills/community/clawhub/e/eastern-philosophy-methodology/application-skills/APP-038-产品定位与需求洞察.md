# 产品定位与需求洞察

## 场景定义

- **目标**：为新产品/新业务找到真实、可聚焦、可切入的需求靶位——让产品立在一个真问题上，而非一个想象中的市场上。
- **约束**：用户说的与做的不一致（访谈失真）；需求信息经层级与姿态过滤（产品人离一线越远越失真）；显性需求多被强手占据；资源有限，只能聚焦一个主需求。
- **角色**：创始人、产品负责人、用研/市场团队。
- **典型输入**：①新产品从 0 到 1 的定位立项；②现有产品增长停滞后的需求再洞察；③竞品强势压制下的差异化找位。
- **边界**：定价与商务条款谈判不在本 Skill 范围（归定价商务类应用）；定位确立后的正面对抗打法外送 APP-003 竞争破局；组织与团队问题归组织类应用——本 Skill 只管"产品立在哪、需求从哪来、切入怎么选"。

## 组合公式

- **顺序**：立靶段（MZD-33→MZD-01）→ 洞察段（MZD-15→GZ-37→GZ-26→GZ-03）→ 聚焦定量段（MZD-02→MZD-12→GZ-33）→ 验证切入段（SZ-31→SZ-10→SZ-06）→ 复盘段（MZD-46，常态挂起，偏差触发）。
- **条件分支**：从 0 到 1 → 先 MZD-01 系统调查后 SZ-31 小样试探（先取证后验证，顺序不可倒）；增长停滞 → 先 MZD-46 寻根（判土壤问题还是需求迁移）再回洞察段重跑；竞品强势压制 → 跳过正面需求，直入 SZ-10 找虚位再回 MZD-02 聚焦。
- **权重**：MZD-02 权重最高——主需求判断错误，一切执行归零。
- **冲突裁决**：用户口头表达（GZ-03 所得）与行为数据（MZD-12）冲突 → 行为数据优先，口头仅作线索；调查成本与时间窗口冲突 → 按 MZD-33 定靶裁决——靶未立不启动，立靶后做最小充分调查（MZD-01 不因赶工跳过，只可裁范围）；单一聚焦与多需求诱惑冲突 → 按 MZD-02 全力于主要矛盾，其余需求入暂缓清单，不得平均用力。

## 执行步骤

1. **先立靶**（MZD-33）：明确"本产品射什么问题"——靶（真实问题）先于矢（功能、技术、形态）；说不出靶，一切后续工作禁止启动。
2. **系统调查**（MZD-01）：对靶问题相关的用户实况做系统调查——结论产生于调查之末而非其先；没有调查就没有定位发言权。
3. **眼睛向下**（MZD-15）：调查姿态向下——进一线场景、见真实用户，层级与姿态是信息失真的第一过滤器。
4. **借天下之目**（GZ-37）：以一线客服、销售、渠道、种子用户之目耳心补产品人盲区——个体感知覆盖面决定判断覆盖面。
5. **由外测内**（GZ-26）：不问"你怎么想"，看"你怎么用"——以可见的使用行为（留存、频次、绕行路径）推知隐情，观测点在外部表征。
6. **极点揣情**（GZ-03）：在用户大喜（方案超预期演示）或大惧（痛点发作、竞品流失）之时逼近测其真实权重排序——人在情绪极值处无法掩饰什么最重要。
7. **锁主需求**（MZD-02）：从全部需求中找出规定/影响其余的那个主要需求，资源全力投向它；其余需求次第排队，不平均用力。
8. **胸中有数**（MZD-12）：对主需求做基本数量分析——市场容量、频次强度、付费意愿的定量基础；没有数量的质量判断一律存疑。
9. **同类归类**（GZ-33）：按同类相应律对用户分层——以对象已然所属之类（其性、其欲、其境）归层，触发点选在其类最相应处，其应最速。
10. **四途试探**（SZ-31）：策（推演方案）、作（上线挑动反应）、形（示形落地页）、角（小规模真实较量）——以小规模可控动作验证需求虚实，不待大投入而知胜负。
11. **避实击虚**（SZ-10）：切入点永远选在竞品空虚薄弱、需求未被满足处；且不固化——随竞品布势变化动态转向当下的"虚"。
12. **庙算比算**（SZ-06）：立项 go/no-go 前按明确维度（需求真度、规模、自身五事七计式比算）逐项对比算清——把"要不要做"从热情题变成可计算的判断题，多算才上，少算不上。
13. **错误寻根**（MZD-46）：定位偏差不止于现象批判，溯源其土壤（样本偏差？姿态失真？主需求误判？）——只批现象不除土壤则偏差复发。

## 失效预案

- **调查充分定位仍失败**：退回 MZD-46 溯源三分——靶错（回 MZD-33 重立靶）、取证失真（回 MZD-01+MZD-15 重查姿态与样本）、主需求误判（回 MZD-02 重聚焦）。
- **用户言行不一**：退回 GZ-26 由外测内（行为数据优先）+ GZ-03 极点复测；仍不明 → 转 SZ-31 四途做真实行为试探，放弃纯陈述式调研。
- **需求真实但规模过小**：退回 SZ-06 庙算重算——或回 MZD-33 另立更大的靶，或转 SZ-10 寻相邻之虚扩面，不得硬做。
- **切入后被竞品围堵**：退回 SZ-10 水随形——原虚位已实，转新虚位；无虚位可转 → 退回 MZD-02 重估主要需求是否迁移。
- **一切争议不决**：兜底回 MZD-02 抓主要矛盾——以"哪个需求规定其余一切"为唯一裁决标准。

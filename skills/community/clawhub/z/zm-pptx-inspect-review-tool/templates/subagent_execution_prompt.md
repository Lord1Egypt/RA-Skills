# 可复制给 SubAgent 的执行提示词

你正在执行 `zm-pptx-inspect-review-tool` Skill。

请检查 PPTX 文件，输出可验证的审核结论。

## 最小必填

- PPTX 文件路径
- 检查目标：文本/视觉/备注/版式/资源/渲染
- 输出报告路径
- 是否需要截图
- 放行标准

## 执行顺序

1. 确认文件存在
2. 读取基础信息
3. 提取文本/备注/资源
4. 渲染或截图核验
5. 定位问题页
6. 输出 PASS / NEEDS_REVISION / BLOCKED

## 硬门禁

- 不得只说“文件存在”就放行。
- 正式 PPT 必须有渲染或截图证据。
- 用户截图问题必须扩展到全稿同类问题排查。

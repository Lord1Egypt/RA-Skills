## Use Case:

Developers and civil-engineering practitioners use this design-stage skill to route natural-language tasks across structural response prediction, damage identification, digital twin modeling, and monitoring-data analysis workflows. Its outputs should be treated as prototype guidance rather than inspection, maintenance, operations, research, or structural-safety decisions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can present placeholder civil-engineering analysis results as successful structural predictions, damage detections, health assessments, or monitoring reports.

Mitigation: Use it only for design-stage demonstration until placeholder algorithms are replaced with validated models and outputs are reviewed by qualified domain experts.

Risk: Inputs, dependencies, and data handling are not yet hardened for safety-sensitive engineering workflows.

Mitigation: Validate input formats and ranges, document data handling, lock dependencies, and run security and domain validation before deployment.

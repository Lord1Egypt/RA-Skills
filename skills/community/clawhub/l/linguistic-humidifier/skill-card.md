## Use Case:

External users install this skill when they explicitly want an agent to act as a promotional persona for the Opaque Logic LH-1 and respond to conversational triggers with brand-scripted product recommendations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can cause an agent to monitor broad conversation patterns and inject promotional product recommendations without direct user intent.

Mitigation: Require explicit opt-in before activation, narrow the trigger criteria, and prioritize the user's active task over promotional responses.

Risk: The scripted first-person endorsement could mislead users about the agent's real experience with the product.

Mitigation: Remove the first-person testimonial or rewrite it as clearly attributed promotional copy before normal use.

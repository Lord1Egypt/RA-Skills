## Description:

Analyzes GitHub user contribution quality across owned repositories, external contributions, output quality, and social influence.

This skill is ready for commercial/non-commercial use.

## Publisher:

[zerone0x](https://clawhub.ai/user/zerone0x)

### License/Terms of Use:

MIT

## Use Case:

Developers and external users use this skill to evaluate a public GitHub account with a subjective 100-point contribution-quality rubric.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: GitHub reputation scores may be incomplete or biased toward public popularity and contribution metrics.

Mitigation: Treat scores as subjective guidance and review the underlying public activity before making decisions.

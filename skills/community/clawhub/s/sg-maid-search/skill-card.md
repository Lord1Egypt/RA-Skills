## Description:

Search and match available domestic maids from Sunrise Link's database in Singapore, including guided requirements gathering when no criteria are specified.

This skill is ready for commercial/non-commercial use.

## Publisher:

[meikidd](https://clawhub.ai/user/meikidd)

### License/Terms of Use:

MIT-0

## Use Case:

External users and agents use this skill to search and shortlist available domestic worker candidates for Singapore households by budget, care needs, skills, language, experience, and related preferences.

### Deployment Geography for Use:

Singapore

## Known Risks and Mitigations:

Risk: The skill can ask for and filter on sensitive hiring characteristics such as nationality and religion.

Mitigation: Use these filters only with a clear lawful basis, documented safeguards, and human review appropriate to Singapore domestic worker hiring decisions.

Risk: The artifact documents an unpinned remote install command.

Mitigation: Install from a pinned, reviewed release or verified source before using the skill in a hiring workflow.

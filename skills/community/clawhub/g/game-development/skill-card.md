## Use Case:

Developers and game creators use this skill to design and implement browser-playable games, choose delivery profiles, build vertical slices, plan content pipelines, and run playtest and balancing loops.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may maintain local project memory files under ~/game-development/, which can preserve game concepts, preferences, decisions, and playtest notes across sessions.

Mitigation: Review or remove those files if cross-session game-planning context should not be retained.

Risk: Game projects may require repository pushes, asset uploads, telemetry, analytics, backend services, or related-skill installation when scope expands.

Mitigation: Require explicit user approval before enabling those external workflows or dependencies.

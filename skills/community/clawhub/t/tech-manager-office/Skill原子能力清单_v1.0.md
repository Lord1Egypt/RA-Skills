## 二、Skill原子能力详情

### 【前端】S-FR-01 成果挖掘

**所属阶段**：前端

**输入**：
- 高校/科研院所的技术文档、论文、专利初稿
- 科研团队的技术介绍材料
- 行业技术需求信息

**输出**：
- 《成果挖掘报告》：成果基本信息、技术概述、初步价值判断
- 成果进入培育流程的建议或终止意见

**SOP步骤**：
1. **接触科研团队**：与科学家/研发团队建立沟通，了解核心技术方向
2. **技术文档收集**：获取论文、专利申请文件、技术方案、实验数据
3. **技术边界界定**：明确成果的技术指标、适用范围、成熟度
4. **初步市场扫描**：识别潜在应用场景和竞争对手技术
5. **价值初步判断**：评估成果的技术领先性、专利可申报性、转化可行性
6. **风险初步识别**：发现明显的技术障碍、知识产权冲突、伦理风险
7. **输出《成果挖掘报告》**：形成结构化文档，记录发现与建议

**关键判断标准**：

| 触发进入下一阶段 | 触发终止 |
|-----------------|---------|
| 技术具备一定成熟度（TRL≥3）| 违反法律/伦理硬边界 |
| 有潜在应用场景 | 技术明显不可行 |
| 知识产权可保护 | 发明人拒绝配合转化 |
| 发明人有意愿转化 | 无任何商业价值 |

**前后依赖**：
- 前序：无（起点Skill）
- 后序：S-FR-02（成果培育）

---

### 【前端】S-FR-02 成果培育

**所属阶段**：前端

**输入**：
- 《成果挖掘报告》
- 技术文档及补充材料

**输出**：
- 《成果培育方案》：技术完善路径、知识产权布局方案、培育里程碑
- 可进入中端评估的培育完成报告

**SOP步骤**：
1. **技术成熟度评估**：依据TRL（技术成熟度等级）确定当前阶段
2. **知识产权布局规划**：确定专利申请策略（发明/实用新型/外观设计/商业秘密）
3. **技术完善路径设计**：识别关键技术缺口，制定实验室到小试的完善计划
4. **培育资源配置**：估算培育所需资金、设备、辅助团队
5. **培育里程碑设定**：划分培育阶段（实验室→小试→中试），设定验收标准
6. **发明人权益约定**：明确成果转化后发明人的权益分配机制
7. **输出《成果培育方案》**：形成完整培育路线图

**关键判断标准**：

| 触发进入下一阶段 | 触发终止 |
|-----------------|---------|
| TRL达到4-5（实验室验证通过）| 技术路径被证伪 |
| 核心专利已获受理/授权 | 发明人中途放弃 |
| 有明确的中端接收意愿 | 培育成本超出合理预期 |
| 无重大知识产权纠纷 | 市场窗口关闭 |

**前后依赖**：
- 前序：S-FR-01（成果挖掘）
- 后序：S-MD-01（成果评价）

### 【中端】S-MD-01 成果评价

**所属阶段**：中端

**输入**：
- 《成果培育方案》及培育完成报告
- 全部技术文档、知识产权文件
- 培育过程数据与里程碑验收材料

**输出**：
- 《成果评价报告》：技术评价、市场评价、经济评价、风险评价
- 明确的转化建议（转让/许可/作价投资/自行孵化）

**SOP步骤**：
1. **技术评价**：
   - 技术先进性（与竞品对比）
   - 技术成熟度（TRL/IRL/MRL）
   - 技术壁垒强度（难以复制程度）
   - 技术可持续性（迭代潜力）
2. **知识产权评价**：
   - 权利稳定性（专利新颖性/创造性）
   - 保护范围充分性
   - 侵权可判定性
   - 地域覆盖合理性
3. **市场评价**：
   - 应用市场规模（TAM/SAM/SOM）
   - 目标客户画像
   - 竞争格局分析
   - 市场切入时机
4. **经济评价**：
   - 预期收益测算（DCF/市场类比）
   - 转化成本估算
   - 投资回报周期
5. **风险评价**：
   - 技术风险（替代技术出现概率）
   - 市场风险（市场接受度不确定性）
   - 法律风险（侵权/无效风险）
   - 政策风险（行业监管变化）
6. **综合结论**：给出转化路径建议及优先级

**关键判断标准**：

| 触发进入下一阶段 | 触发终止 |
|-----------------|---------|
| 技术评价正向（技术可行+壁垒有效）| 违反热力学/物理学基本定律 |
| 市场评价正向（存在真实需求）| 技术指标无法复现 |
| 经济评价可行（ROI≥行业基准）| 知识产权无法保护 |
| 风险可控（无不可接受风险）| 市场根本不存在 |
| 无法律硬障碍 | 转化成本远超预期收益 |

**前后依赖**：
- 前序：S-FR-02（成果培育）
- 后序：S-MD-02（知识产权服务）→ S-MD-03（金融服务）

### 【中端】S-MD-02 知识产权服务

**所属阶段**：中端

**输入**：
- 《成果评价报告》
- 全部专利、商标、著作权、技术秘密文件
- 培育过程中产生的新的技术改进

**输出**：
- 《知识产权尽职调查报告》：权属清晰度、侵权风险、布局完整性
- 完整的知识产权保护方案

**SOP步骤**：
1. **权属核查**：
   - 确认成果发明人及其权属约定
   - 核查是否存在职务发明、共有专利、侵权在先
   - 确认知识产权的完整性与可追溯性
2. **侵权风险排查（FTO分析）**：
   - 检索目标市场的在先专利
   - 分析技术方案是否落入他人权利要求保护范围
   - 识别规避设计可能性
3. **保护方案设计**：
   - 专利布局（核心专利+外围专利）
   - 技术秘密认定与保护措施
   - 著作权/商标保护（如涉及软件/品牌）
4. **许可/转让风险评估**：
   - 评估许可方/转让方的知识产权完整性
   - 识别链式侵权风险
5. **输出《知识产权尽职调查报告》**：
   - 明确权属风险等级
   - 给出风险缓释建议

**关键判断标准**：

| 触发通过 | 触发终止/转专项 |
|---------|----------------|
| 权属清晰，无重大纠纷 | 权属存在争议且无法解决 |
| FTO分析通过或可规避 | 存在不可规避的侵权风险 |
| 保护方案可行 | 技术已被公共领域覆盖 |

**前后依赖**：
- 前序：S-MD-01（成果评价）
- 后序：S-MD-03（金融服务）

---

### 【中端】S-MD-03 金融服务

**所属阶段**：中端

**输入**：
- 《成果评价报告》
- 《知识产权尽职调查报告》
- 成果方的融资需求说明

**输出**：
- 《金融服务方案》：融资路径选择、估值建议、资金方对接名单
- 或《不适宜金融介入的意见书》

**SOP步骤**：
1. **融资需求评估**：
   - 明确转化所需的资金规模与用途
   - 评估资金需求与成果阶段的匹配度
2. **估值分析**：
   - 基于技术价值（成本法/市场法/收益法）
   - 给出估值区间建议
3. **融资路径匹配**：
   - 天使投资（早期，TRL 4-5）
   - VC/PE（成长期，TRL 6-7）
   - 产业资本（战略投资，TRL 7+）
   - 政府基金/专项补贴
   - 知识产权质押融资
4. **投资方对接准备**：
   - 制作投资概要（Teaser）
   - 筛选匹配的投资机构名单
   - 安排对接会议
5. **输出《金融服务方案》**

**关键判断标准**：

| 触发进入后端 | 触发终止 |
|-------------|---------|
| 完成融资或确认资金来源 | 无法获得任何有效资金支持 |
| 资金方有意向跟进 | 估值与市场需求严重偏离 |
| 无重大金融风险 | 发明人不接受任何融资条件 |

**前后依赖**：
- 前序：S-MD-01（成果评价）、S-MD-02（知识产权服务）
- 后序：S-BK-01（成果熟化）或 S-BK-04（成果孵化）

### 【后端】S-BK-01 成果熟化

**所属阶段**：后端

**输入**：
- 《成果评价报告》
- 确定的金融服务方案或自有资金
- 《知识产权保护方案》

**输出**：
- 《成果熟化方案》：从当前TRL到量产可行性的完整路径
- 熟化里程碑验收报告

**SOP步骤**：
1. **熟化目标确定**：
   - 明确从当前TRL到目标TRL（如TRL 6→TRL 8）的差距
   - 确定小试/中试/试生产的关键任务
2. **技术熟化执行**：
   - 工程化设计（可靠性、稳定性、一致性）
   - 生产工艺开发
   - 质量标准建立
3. **供应链搭建**：
   - 关键原材料/设备供应商筛选
   - 代工生产安排（如自建产线不经济）
4. **成本优化**：
   - BOM成本核算
   - 规模化降本路径规划
5. **认证与合规**：
   - 行业准入资质申请
   - 产品标准符合性验证
6. **输出《成果熟化报告》**：确认成果具备转化条件

**关键判断标准**：

| 触发进入推广/交易 | 触发终止 |
|-----------------|---------|
| TRL达到7-8（环境验证/系统验证）| 技术指标无法稳定达到设计要求 |
| 具备小批量生产能力 | 成本无法降至商业可行区间 |
| 产品标准通过验证 | 市场窗口已关闭 |
| 无重大未解决技术问题 | 资金耗尽且无后续来源 |

**前后依赖**：
- 前序：S-MD-03（金融服务）
- 后序：S-BK-02（成果推广）、S-BK-03（成果交易）

### 【后端】S-BK-02 成果推广

**所属阶段**：后端

**输入**：
- 《成果熟化报告》
- 推广目标（企业/行业/区域）
- 推广预算

**输出**：
- 《成果推广方案》：推广策略、渠道选择、目标客户名单
- 推广执行报告与意向反馈

**SOP步骤**：
1. **目标客户画像**：
   - 识别最有可能采用成果的目标企业
   - 分析企业需求匹配度
2. **推广渠道设计**：
   - 行业会议/展会展示
   - 技术推介会/路演
   - 专业媒体/行业期刊宣传
   - 行业协会对接
3. **价值主张包装**：
   - 将技术语言转化为商业语言
   - 制作技术白皮书、案例集
4. **意向收集与管理**：
   - 建立意向客户跟踪台账
   - 安排技术交流与对接
5. **反馈收集**：
   - 汇总市场对技术的反馈
   - 识别技术改进方向
6. **输出《推广执行报告》**：形成意向客户清单与跟进建议

**关键判断标准**：

| 触发进入交易 | 触发终止/转孵化 |
|-------------|----------------|
| 获得明确的企业合作意向 | 长时间无有效意向反馈 |
| 意向企业具备承接能力 | 市场验证失败 |
| 转让/许可条件初步谈拢 | 发现更大的独立发展机会 |

**前后依赖**：
- 前序：S-BK-01（成果熟化）
- 后序：S-BK-03（成果交易）

---

### 【后端】S-BK-03 成果交易

**所属阶段**：后端

**输入**：
- 《推广执行报告》与意向客户清单
- 《知识产权保护方案》
- 交易条件框架

**输出**：
- 完成的交易合同（转让/许可/作价投资）
- 《交易结算报告》

**SOP步骤**：
1. **交易方尽职调查**：
   - 核实意向方的承接能力（技术消化、资金、团队）
   - 评估合作风险
2. **交易结构设计**：
   - 转让（一次性买断）
   - 许可（独占/排他/普通许可）
   - 作价投资（技术入股）
   - 混合模式
3. **交易条件谈判**：
   - 价格/付款方式
   - 里程碑付款设计
   - 后续技术服务约定
   - 竞业限制与保密条款
4. **合同起草与审核**：
   - 联合法律服务完成合同文本
   - 明确知识产权归属与边界
5. **交割执行**：
   - 款项收付
   - 知识产权变更登记
   - 技术资料交接
6. **输出《交易结算报告》**：记录交易完成状态与后续义务

**关键判断标准**：

| 触发交易完成 | 触发终止/转孵化 |
|-------------|----------------|
| 双方签署正式合同 | 无法达成可接受的价格 |
| 首款到账 | 意向方中途退出 |
| 知识产权变更完成 | 发现重大风险 |

**前后依赖**：
- 前序：S-BK-02（成果推广）
- 后序：项目结束，或触发 S-BK-04（成果孵化）

---

### 【后端】S-BK-04 成果孵化

**所属阶段**：后端

**输入**：
- 《成果评价报告》确认为适宜自孵化
- 具备孵化条件的技术成果
- 孵化团队/运营方

**输出**：
- 《孵化方案》：商业计划、公司设立方案、里程碑规划
- 孵化项目运营报告

**SOP步骤**：
1. **商业计划书编制**：
   - 商业模式设计（产品/定价/渠道）
   - 财务预测（3-5年）
   - 股权结构设计
2. **公司设立**：
   - 工商注册
   - 股权分配协议
   - 知识产权作价入股手续
3. **团队组建**：
   - 引入CEO/运营负责人
   - 组建核心技术+商务团队
4. **孵化运营**：
   - 按里程碑推进
   - 定期评估孵化进展
   - 持续融资支持
5. **退出规划**：
   - A轮/B轮融资路径
   - 并购退出可能
   - IPO可能（如适用）
6. **输出《孵化运营报告》**：记录孵化进展与调整

**关键判断标准**：

| 触发持续孵化 | 触发终止/转交易 |
|-------------|----------------|
| 里程碑按计划推进 | 连续两个里程碑未达成 |
| 持续获得资金支持 | 无法获得后续融资 |
| 团队稳定且能力匹配 | 核心团队流失 |

**前后依赖**：
- 前序：S-MD-03（金融服务）或 S-BK-03 触发孵化
- 后序：项目退出（融资/并购/IPO）

### 【横切】S-XC-01 法律服务

**所属阶段**：横切（贯穿全流程）

**输入**：
- 任意阶段的合同、协议、承诺函
- 任意阶段发现的潜在法律风险
- 任意阶段涉及的知识产权文件

**输出**：
- 《法律风险评估报告》
- 合同修改意见
- 合规整改建议

**SOP步骤**：
1. **风险识别触发**：
   - 主动审查全流程合同文本
   - 响应任意阶段的法务咨询
   - 监控法律法规变化
2. **风险评估**：
   - 合规性（技术进出口、数据安全、环保等）
   - 合同风险（条款漏洞、权责不清）
   - 知识产权风险（权属、侵权、许可）
   - 劳动人事风险（创业团队股权激励）
3. **出具法律意见**：
   - 明确风险等级（高/中/低）
   - 给出风险缓释措施
4. **合同起草/审核**：
   - 参与交易合同谈判
   - 起草标准合同模板
5. **持续监控**：
   - 跟踪项目全生命周期的法律合规
   - 预警政策变化风险

**关键判断标准**：

| 触发风险预警 | 触发项目终止建议 |
|-------------|----------------|
| 发现合规硬障碍 | 存在不可修复的法律硬伤 |
| 合同存在重大漏洞 | 涉及法律明确禁止事项 |
| 政策风险显著上升 | 违反国家重大产业政策 |

**前后依赖**：
- 前序：无（横切Skill，任意阶段均可触发）
- 后序：可触发所长决策终止项目

---

### 【调度】S-DP-01 所长编排引擎

**所属阶段**：调度

**输入**：
- 项目基本信息（成果来源、技术领域、团队背景）
- 当前阶段任务完成信号
- 各Skill的输出结果

**输出**：
- 下一阶段调度指令（调用哪个Skill/哪组Skill）
- 项目继续/终止/转方向决策
- 各组协同交接指令

**调度逻辑**：

#### 1. 项目入口判定

```
IF 成果进入
  → 调用 S-FR-01（成果挖掘）
  → 根据挖掘结果决定进入 S-FR-02 或终止
```

#### 2. 阶段流转规则

| 当前阶段 | 完成后自动进入 | 终止条件 |
|---------|--------------|---------|
| 成果挖掘 | 成果培育 | 硬障碍/无价值 |
| 成果培育 | 成果评价 | 培育失败/发明人退出 |
| 成果评价 | 知识产权服务+金融服务（并行） | 评价不通过 |
| 知识产权服务 | 金融服务（如并行完成） | 知识产权风险不可控 |
| 金融服务 | 成果熟化 或 成果孵化 | 无资金支持则终止 |
| 成果熟化 | 成果推广 | 技术不达标则终止 |
| 成果推广 | 成果交易 | 无意向则转孵化或终止 |
| 成果交易 | 项目完成 或 转孵化 | 交易失败则终止 |

#### 3. 并行/串行判定

```
知识产权服务 + 金融服务 → 并行执行
其他Skill → 串行执行
```

#### 4. 异常终止决策

```
IF 法律服务发现重大风险
  → 所长收到终止建议
  → 所长决策是否立即终止
  → IF 决策终止 → 项目终止，输出《终止报告》
```

#### 5. 阶段指派规则

| 阶段 | 负责指派 | 协同参与 |
|------|---------|---------|
| 前端（挖掘/培育） | 前端调度 | 法律服务（合同审核） |
| 中端（评价/知产/金融） | 中端调度 | 法律服务（全程） |
| 后端（熟化/推广/交易/孵化） | 后端调度 | 法律服务（全程） |

## 三、Skill调用优先级矩阵

| 场景 | 调用顺序 | 说明 |
|------|---------|------|
| 新成果进入 | S-FR-01 → S-FR-02 | 前端串行 |
| 成果培育完成 | S-MD-01 → (S-MD-02 + S-MD-03) | 评价先行，知产+金融并行 |
| 金融到位 | S-BK-01 → S-BK-02 → S-BK-03 | 后端熟化→推广→交易 |
| 自孵化决策 | S-BK-04 | 独立于交易流程 |
| 任意阶段法律风险 | S-XC-01 | 横切触发 |

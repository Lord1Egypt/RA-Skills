## Description:

Guides agents in designing and extending full-color pixel narrative RPGs with disciplined RGB palettes, tile scenes, dialogue and emotion systems, collectible memories, CG scenes, rhythm minigames, dynamic BGM, testing, and single-file HTML5 publishing.

This skill is ready for commercial/non-commercial use.

## Publisher:

[evernotebot123](https://clawhub.ai/user/evernotebot123)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and narrative game creators use this skill to have an agent design or extend full-color pixel RPG chapters, scenes, dialogue systems, minigames, art pipelines, and release checks. It is best suited for exploratory, non-combat, chapter-based single-file HTML5 games.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The artifact references a required SOP file that is not present.

Mitigation: Do not assume missing SOP details are available; rely only on the included skill definition or provide project-specific instructions before use.

Risk: The skill may steer agents toward trilingual game content when a project only needs one language.

Mitigation: Review generated dialogue, UI text, and release materials for the intended language set before publishing.

Risk: The skill may propose local Python, Node, and zip commands as part of game testing and packaging.

Mitigation: Review generated commands before execution and run them in an appropriate local project workspace.

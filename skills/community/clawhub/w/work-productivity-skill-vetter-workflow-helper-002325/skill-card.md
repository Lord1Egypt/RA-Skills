## Description:

Helps AI-agent users, skill authors, maintainers, and teams create practical Skill Vetter-style workflows for fixing bugs, hardening setup and safety, improving reliability, and adapting adjacent skills.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

External developers, AI-agent users, skill authors, maintainers, and teams use this skill to turn requests about skill vetting, bug fixes, setup hardening, reliability, and adjacent skill creation into concise plans, checklists, artifacts, analyses, or implementation support.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation wording may route ordinary security, GitHub, or bug-fix requests through this workflow helper unintentionally.

Mitigation: Narrow or disable implicit invocation, and invoke the skill explicitly only when a Skill Vetter-style workflow or checklist is needed.

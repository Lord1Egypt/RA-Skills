## Description:

Xiaopi Skill Finder CN helps users discover, inspect, and install relevant ClawHub Skills from Chinese or English requests.

This skill is ready for commercial/non-commercial use.

## Publisher:

[a-din](https://clawhub.ai/user/a-din)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers use this skill to translate a capability request into ClawHub searches, inspect matching skills, and choose candidates to install.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Installing a recommended ClawHub skill can change the agent's future capabilities and behavior.

Mitigation: Inspect each recommended skill first and install only skills from publishers the user trusts.

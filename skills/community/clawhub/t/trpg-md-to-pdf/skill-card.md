## Description:

Converts TRPG markdown rulebooks, scenarios, catalogs, and other play-ready documents into same-directory PDF outputs while preserving formatting and embedded images.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users, game masters, and TRPG content creators use this skill to convert play-ready Markdown materials into printable and tablet-readable PDFs while leaving source Markdown unchanged.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad PDF conversion phrases may activate the skill outside a TRPG workflow.

Mitigation: Review the planned input file list before allowing file writes.

Risk: The skill writes generated PDFs into the same directories as source Markdown files.

Mitigation: Confirm destination paths and preserve the original Markdown files unchanged.

## Description:

Build user interfaces that match the Timeplus Console look and feel using exact design tokens, component states, and ready-to-adapt CSS, Tailwind, and React examples.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and frontend engineers use this skill to generate, style, or review Timeplus Console-aligned web UI. It provides exact color, typography, spacing, radius, and component guidance plus adaptable CSS, Tailwind, and React implementations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Optional npx commands can execute package tooling during validation or export.

Mitigation: Pin a reviewed @google/design.md version or run the commands in a restricted project environment before use.

Risk: Copied input examples may omit explicit label htmlFor/id binding.

Mitigation: Adapt generated React input components so every visible label is bound to its input with matching htmlFor and id attributes.

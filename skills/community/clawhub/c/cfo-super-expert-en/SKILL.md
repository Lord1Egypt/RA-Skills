## Operating Guidelines

### 1. Identify & Route
Analyze user request, match routing rules. Prepare multi-skill collaboration when cross-domain.

### 2. Load Sub-Skill
```
Read: /data/user/skills/<sub-skill>/SKILL.md
```

### 3. Execute Analysis
- **stock-master-hunter**: Call `scripts/ttfox_master_driver_chs.py` for real-time data
- Other sub-skills: Follow respective SKILL.md guidance
- Data-driven: All conclusions based on real data, no speculation
- Methodologically rigorous: Use professional frameworks from each skill

### 4. Integrate Output
```
## CFO Super Expert Comprehensive Analysis Report

### I. [Domain] Analysis
[Professional output]

### II. Comprehensive Recommendations
[Cross-domain integrated advice]

### III. Risk Warnings
[Relevant risks]

> Disclaimer: This analysis is for research reference only and does not constitute investment advice.
```

## Description:

This skill provides a SACL first-principles thinking framework for stripping assumptions, atomizing problems, mapping constraints, and reconstructing leverage-based solutions.

This skill is ready for commercial/non-commercial use.

## Use Case:

Employees, external users, developers, and other problem solvers use this skill to analyze complex or resource-constrained situations with first-principles reasoning. It guides users through the SACL flow: Strip, Atomize, Constraint, and Leverage.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation language may cause the framework to be applied to general problem-solving requests where the user did not ask for a structured first-principles analysis.

Mitigation: Use the framework when the user requests first-principles thinking, SACL, constraint analysis, problem decomposition, or help finding leverage under limited resources.

Risk: Some examples discuss platform tactics such as collecting public questions or publishing on third-party platforms.

Mitigation: Keep legal requirements, platform terms, and user preferences explicit before recommending data collection, scraping, or platform-based distribution tactics.

## Use Case:

External creators, production teams, brand marketers, e-commerce merchants, and developers use this skill to plan short-drama or motion-comic scripts, dialogue, narration, subtitles, character boards, storyboards, scene boards, and AI-HIVE image or video generation tasks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill requires an AI-HIVE API key and can submit potentially billable image or video generation jobs.

Mitigation: Use a scoped, revocable API key; confirm model, routing, pricing, quantity, and task settings before running generation commands.

Risk: The skill can upload selected media and download generated results.

Mitigation: Upload only authorized media, use a trusted AI-HIVE endpoint, and run the scripts in an isolated Python environment with a dedicated output directory.

Risk: Generated dialogue, narration, brand claims, character details, or visual content may be inaccurate, unsafe, or rights-sensitive.

Mitigation: Review user-provided facts, permissions, likeness rights, copyright status, platform rules, and final outputs before publication.

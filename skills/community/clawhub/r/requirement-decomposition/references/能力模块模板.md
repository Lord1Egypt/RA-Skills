# Agent 能力模块拆解模板

## 模板使用说明

针对常见的 Agent 业务场景，以下是标准化的能力模块拆解参考。根据实际场景组合和裁剪。

---

## 一、对话类 Agent 常见模块

### 意图识别模块
- **功能**：理解用户输入的真实意图
- **技术选型**：LLM 分类 / Function Calling / 关键词匹配
- **输出**：意图标签 + 置信度
- **注意事项**：多意图场景需要拆分处理

### 上下文管理模块
- **功能**：维护多轮对话的上下文状态
- **技术选型**：滑动窗口 / 摘要压缩 / 向量检索
- **输出**：压缩后的上下文
- **注意事项**：token 上限管理，重要信息不能丢失

### 知识检索模块
- **功能**：从知识库中检索相关信息
- **技术选型**：RAG / 全文检索 / 结构化查询
- **输出**：相关文档片段
- **注意事项**：召回率和准确率的平衡

### 回复生成模块
- **功能**：基于检索结果生成回复
- **技术选型**：LLM 生成 / 模板填充 / 混合模式
- **输出**：自然语言回复
- **注意事项**：需要幻觉检测和事实性校验

---

## 二、任务执行类 Agent 常见模块

### 任务规划模块
- **功能**：将复杂任务拆解为可执行的子步骤
- **技术选型**：ReAct / Plan-and-Execute / Tree of Thought
- **输出**：步骤列表 + 依赖关系
- **注意事项**：需要支持动态重规划

### 工具调用模块
- **功能**：调用外部 API、数据库、文件系统
- **技术选型**：Function Calling / Tool Use / MCP
- **输出**：API 调用结果
- **注意事项**：超时、重试、降级策略

### 结果校验模块
- **功能**：验证工具调用的结果是否符合预期
- **技术选型**：规则引擎 / LLM 判断 / 代码校验
- **输出**：通过/失败 + 失败原因
- **注意事项**：需要支持自动重试和人工兜底

### 状态管理模块
- **功能**：跟踪任务执行进度和中间状态
- **技术选型**：状态机 / 工作流引擎 / 简单变量
- **输出**：当前状态 + 历史记录
- **注意事项**：长时间运行任务的断点恢复

---

## 三、数据处理类 Agent 常见模块

### 数据获取模块
- **功能**：从各数据源获取原始数据
- **技术选型**：API 调用 / 爬虫 / 文件解析
- **输出**：结构化数据
- **注意事项**：数据格式标准化

### 数据清洗模块
- **功能**：数据去重、格式标准化、异常值处理
- **技术选型**：规则处理 / LLM 辅助清洗
- **输出**：清洗后的数据
- **注意事项**：保留原始数据备查

### 数据分析模块
- **功能**：统计、聚合、趋势分析
- **技术选型**：代码执行 / SQL / LLM 分析
- **输出**：分析结果 + 可视化
- **注意事项**：大数据集需要分批处理

### 报告生成模块
- **功能**：将分析结果整理为可读的报告
- **技术选型**：模板渲染 / LLM 生成 / 图表库
- **输出**：Markdown / PDF / HTML 报告
- **注意事项**：数据可视化要准确直观

## 四、优先级评估矩阵

| 优先级 | 定义 | 特征 |
|-------|------|------|
| P0 | 必须有，没有则 Agent 不可用 | 核心功能链路 |
| P1 | 应该有，显著提升体验 | 主要增强功能 |
| P2 | 可以有，锦上添花 | 边缘场景、优化项 |

## 五、复杂度评估标准

| 复杂度 | 工时 | 特征 |
|-------|------|------|
| 低 | 1-2天 | 调用现成 API，逻辑简单 |
| 中 | 3-5天 | 需要数据处理或多步逻辑 |
| 高 | 1-2周 | 需要模型训练、复杂编排或跨系统集成 |

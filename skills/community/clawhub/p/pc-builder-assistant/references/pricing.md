# 价格规则

## 优先级

1. 优先使用离线库中带 `price_cny` 和 `price_date` 的条目。
2. 读取查询结果的 `price_age_days` / `price_stale`。用户要求实时价格、离线价格超过 14 天、离线库无合适型号或缺价时，再搜索当前市场价。
3. 没有来源价格的条目保持 `needs_market_quote`，不得参与总价。

无法取得当前有效价格时，保留所选条目的旧价和日期，或把该项标成待补价；只能作为历史/离线参考，不能用来宣称当前可买、闭合硬预算或计算完整整机差额。

## 输出

- 写明价格参考日期。使用查询结果中每个所选条目的 `price_date`；如果整单日期一致，写统一日期；如果混用不同批次价格，写“价格参考日期以各行 price_date 为准”，并在表格或备注中保留各行日期。不要直接打开数据 YAML 取日期，也不要在 prompt 中硬编码某次历史更新日期。
- 新建完整整机时，任何必选配件缺同币种有效价格，不输出完整总价或预算差额；改为“部分小计/总价待补”，并列出缺价项目。升级、补全或精确替换可单独计算已选新增/替换件的采购小计和用户升级预算差额；整机参考总价和整机价值仍要求旧配件价格也可确认。所有差额只在同一币种、可比日期口径下计算。
- 用户报告只写“离线渠道参考价”或“网络公开信息整理参考价”，不要暴露 `channel_quote`、`needs_market_quote`、`overall=pass` 等内部字段或脚本返回值。
- 完整报价末尾用一句自然语言写明价格参考日期、价格仅供参考、渠道参考价不等于结账价以及下单前需核价；不要堆叠多段免责声明。
- 单值人民币，不输出宽泛价格区间。
- CPU 同型号的盒装、散片、原盒、店保或 tray/boxed/retail 是报价和售后口径差异。普通用户没有明确要求时，默认按预算选择低价、可核对的同型号渠道报价；用户明确要盒装保修、散片省预算、原盒或特定渠道时，再在报价中标注并核对包装/售后形态。离线库条目未写明包装形态时，不要冒充盒装或散片。
- 二手、99新、翻新、矿卡、返券后不确定价和主播直播间特殊到手价不进入默认推荐、配置表或整机总价；用户要求此类来源时，只给新品替代方向。
- 机箱必须计入整机总价；只能找到缺价机箱时，总价写明“不含机箱，完整总价待补价”。
- 海景房默认读取机箱 `fan_mounts` / `fan_slots_count` 后再预留风扇预算。离线库没有可用风扇型号/价格时，写“风扇预算预留”，不要编具体风扇型号；机箱风扇位字段缺失不阻塞整机总价，只提示风扇信息需自行核实并建议加装风扇。风道机箱/封闭机箱若已自带大风扇或缺风扇位字段，不默认推荐具体风扇数量和型号。
- 使用水冷时，水冷本体计入“散热”单价。360 水冷物理占用 3 个 120 风扇位，240/280 水冷占用 2 个，420 水冷占用 3 个 140 风扇位，480 水冷占用 4 个 120 风扇位；冷排自带风扇已满足这些位置的风扇需求，不再重复购买或计价。除冷排占位外仍需补齐的风扇再写预算预留。用户明确要求“水冷夹汉堡/双面风扇/push-pull”时，冷排物理占位不变，另一面风扇按同色系、同款式和预算另计。
- 用户提供的本地报价仍要保留报价日期和币种；超过 14 天只能作为用户历史观察，若用于当前预算，先提示核价，不自行改成“当前价”。

## 异常价格

- 可信价格地板只用于排序降权和风险提示，不删除低价条目，也不是价格上限。默认装机先选地板之上或等于地板的候选；高于地板的报价不受本规则限制，仍按规格、兼容性、预算和场景排序。
- 地板下候选有两类回退：当前预算和筛选条件下没有地板上可用候选；或同规格组中渠道覆盖较高的品牌有过半品牌中位报价已落到地板下。触发回退仍须提示“价格变化大，数据更新可能不及时，请及时核对现价”。
- 若候选同时低于地板，并处于当前同规格品类报价的最低 10% 区间，则进一步降权并标为默认不推荐；只有用户点名具体型号或条目时才作为例外保留，仍须核对现价、库存和商品版本。按同规格组计算：显卡为芯片+显存，内存为代际+容量+套条数，SSD 为 PCIe 代际+容量，CPU 为具体型号。样本不足 10 个时只标记最低 1 个，并同时提示样本少。
- 同组地板之上的可用商品少于 3 个时，无论最终候选在地板上还是地板下，都要提示样本较少并及时核价。
- CPU 低于对应型号可信日低价时按上述规则降权；盒装、散片、原盒、店保或 tray/boxed/retail 仍按报价和售后口径说明，不能因为包装形态差异把异常低价写成确定可买。
- 显卡按同芯片、同显存容量比较。RTX5090、RTX5090D 的 32GB 版本与 RTX5090D V2 的 24GB 版本必须分组；最低可信线使用查询结果返回的 `price_floor_cny` / `price_floor_status`，不在文档中固定某次历史行情数字，也不直接打开 `data/price_floors.yaml`。RTX5090 / RTX5090D 与 RTX5090D V2 价格变化快，当前继续不设可信底价，但每次选择都必须提醒：价格变化大，数据更新可能不及时，请及时核对现价。RTX PRO 6000 同样要提示该品类价格高、购买前谨慎核对。
- 内存最低可信价按 DDR 代际、容量和套条数量覆盖，不因频率或时序更低而放宽；例如 DDR5 32GB 双条地板覆盖 6000 频率下所有时序，也覆盖同容量同代际的默认候选。具体推荐再按频率、时序、颗粒和平台甜点位排序。高价不设硬上限，因为芝奇高端、白色/RGB、特挑低时序或用户指定全家桶可能有合理溢价。
- SSD 按容量、接口、PCIe 代际和性能等级比较。同容量同定位下明显偏离分布的低价候选需要复核颗粒、缓存、保修、版本和是否 QLC；不因低价直接作为系统盘默认选项。更高 PCIe 代际暂缺单独可信地板时，至少不能低于同容量已知较低代际可信地板，例如 PCIe 5.0 2TB 不应低于 PCIe 4.0 2TB 地板。
- 用户明确要求 ROG 全家桶、华硕全家桶、白色旗舰或展示向方案时，可以选择 ROG/TUF/同生态高价件；不要用异常价格上限挡掉高价旗舰，但要说明溢价主要来自外观、生态、散热规格或品牌系列。若预算明显不足以同时保证核心性能、电源、散热和机箱风道，不要硬凑零散旗舰件，先说明预算缺口，再给同生态非旗舰或性能优先替代。

## 机箱、散热和电源预算占比

机箱、散热和电源不要套绝对最低价地板；它们受外观、噪音、风道、线材、体积和升级余量影响更大。按整机预算做软性复核：

| 配件 | 纯性能/普通风道 | 海景房/白色/好看 | ITX/静音/ROG/旗舰 |
| --- | --- | --- | --- |
| 机箱 | 3-6% | 5-9% | 6-12% |
| 散热 | 1.5-4%，低功耗可强风冷 | 3-7%，优先 240/360 水冷 | 4-8%，可用带屏/高端水冷 |
| 电源 | 5-9%，按功耗余量优先 | 6-10%，优先同色和原生线材 | 5-10%，按 1000W/1200W+、静音和保修 |
| 海景房风扇预算 | 0-2% | 1-4% | 2-5% |

- 低于区间不是直接禁止，但必须复核风道、噪音、线材、额定功率、保修、限长和做工；没有明确理由时不要把低价首屏机箱、散热或电源当默认主方案。
- 高于区间也不是错误，但要说明溢价来自外观统一、屏幕/灯效、静音、ITX、背插、风扇套装、旗舰供电余量或长保修；不要为了外观件挤掉显卡、CPU、内存和 SSD 底线。
- 预算敏感的普通配置优先保显卡/CPU/内存/SSD，机箱可压缩但不牺牲基本风道和显卡限长；电源不能低于功耗余量和线材需求，也不能把固定人民币阈值当作质量分界。
- K/KF/X3D 或长负载平台优先比较高规格风冷/水冷；预算只能选更低价散热时，说明 CPU 功耗、噪音和温度取舍。
- 没有外观、静音、ITX、背插、海景房、全家桶或长期复用需求时，机箱按上表的相对预算占比复核；若占比明显偏高，说明风道、做工、风扇套装、展示效果或扩展价值。
- 普通风道或长负载生产力配置还应对机箱、散热、电源的合计占比做相对复核；海景房、ITX、静音或旗舰外观方案按上表场景区间单独比较。占比偏低时，主动检查是否用异常低价件硬贴预算。
- RTX 5070 Ti/5080 及以上、X3D/K/KF、剪辑/渲染/本地 AI 长负载，不把入门单塔、规格信息不完整的低价电源或极低价机箱作为默认。

## 搜索兜底

联网搜索只用于校正离线库不足或过期价格。搜索时核对商品标题、型号后缀、颜色、容量/规格、库存地区和页面可见价格，并记录核价日期；无法确认具体变体时，不要把搜索结果计入确定总价。

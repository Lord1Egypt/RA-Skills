# 肝炎血清学解读与淤胆型肝炎鉴别诊断

## 使用场景

本技能覆盖两类诊断任务：
1. **HBV血清学标志物综合解读**：判断感染阶段、病毒复制状态、传染性
2. **淤胆型肝炎鉴别诊断**：深度黄疸患者的病因鉴别

## 任务一：乙型肝炎血清学标志物解读

### 执行流程

获取患者乙肝两对半 + HBV DNA结果后，按以下顺序解读：

#### 1. HBsAg与抗-HBs

| 模式 | 解读 |
|------|------|
| HBsAg阳性 | 现症HBV感染（感染2周后即可阳性） |
| HBsAg阴性 | 不能绝对排除感染（需结合HBV DNA） |
| 抗-HBs阳性 | 保护性抗体，对HBV有免疫力 |
| 双阳性 | 感染恢复期（HBsAg未消失，抗-HBs已产生）或S基因变异/免疫逃避株 |

#### 2. HBeAg与抗-HBe

| 模式 | 解读 |
|------|------|
| HBeAg阳性 | 病毒复制活跃，传染性强（与HBV DNA正相关） |
| HBeAg消失 + 抗-HBe出现 | 血清转换，病毒复制多静止，传染性降低 |
| 抗-HBe长期阳性 | **注意**：20%~50%仍可测到HBV DNA（前C区变异），不代表无传染性 |

#### 3. 抗-HBc（IgM与IgG）

| 模式 | 解读 |
|------|------|
| 抗-HBc IgM高滴度 | 急性乙肝或慢性急性发作（发病第1周出现） |
| 抗-HBc IgG高滴度 | 现症感染（常与HBsAg并存） |
| 抗-HBc IgG低滴度 | 既往感染（常与抗-HBs并存） |
| 抗-HBc单一阳性 | 既往感染或低水平现症感染 |

#### 4. HBV DNA

- 阳性/定量升高 → 病毒复制和传染性的直接标志
- 用途：判断复制程度、抗病毒药物疗效监测、基因耐药变异位点检测

### 输出规范

综合以上结果输出：
1. HBV感染阶段（急性/慢性/既往感染/恢复期）
2. 病毒复制状态（活跃/静止）
3. 传染性评估
4. 抗病毒治疗指导建议

### 注意事项

- 抗-HBc IgM检测受类风湿因子(RF)影响，低滴度需注意假阳性
- 长期抗-HBe阳性不代表病毒复制停止

## 任务二：淤胆型肝炎鉴别诊断

### 触发条件

患者出现深度黄疸，但消化道症状相对较轻，且凝血功能尚可时，启动鉴别。

### 执行流程

#### 1. 临床症状评估（识别"症状分离"现象）

**核心鉴别点**：黄疸深，但消化道症状较轻

| 特征 | 淤胆型肝炎 | 急性黄疸型肝炎/肝衰竭 |
|------|-----------|---------------------|
| 黄疸程度 | 深 | 深 |
| 消化道症状 | **较轻** | 严重 |
| 皮肤瘙痒 | 有 | 少见 |
| 粪便颜色 | 变浅 | 可变浅 |
| 肝脏 | 肝大 | 可缩小（肝衰竭） |

#### 2. 肝功能生化特征

| 指标 | 淤胆型肝炎特征 |
|------|---------------|
| 总胆红素 | 明显升高，以直接胆红素为主 |
| GGT/ALP | **显著升高**（淤胆标志） |
| ALT/AST | 升高不明显 |
| 总胆汁酸(TBA) | 升高 |
| 胆固醇(CHO) | 升高 |
| **PTA** | **>60%（关键鉴别点）** |

#### 3. 关键鉴别逻辑

```
IF 深度黄疸 + 消化道症状轻 + PTA>60% + GGT/ALP显著升高
THEN 淤胆型肝炎可能性大

IF 深度黄疸 + 消化道症状重 + PTA≤40%
THEN 肝衰竭可能性大，排除淤胆型肝炎
```

#### 4. 分型判断

- **急性淤胆型肝炎**：起病类似急性黄疸型肝炎，大多数可恢复
- **慢性淤胆型肝炎**：在慢性肝炎或肝硬化基础上发生

### 输出规范

1. 是否符合淤胆型肝炎诊断
2. 与肝外梗阻性黄疸的鉴别要点
3. 急性/慢性分型
4. 治疗方向建议（侧重利胆退黄）

### 注意事项

- 必须与肝外梗阻性黄疸（胆管结石、肿瘤）鉴别
- 必须与肝衰竭引起的重度黄疸鉴别（PTA是关键）

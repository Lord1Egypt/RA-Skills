## Description:

Analyzes page screenshots to extract structure, components, visible text, states, and interactions, then creates an implementation prompt for a coding agent.

This skill is ready for commercial/non-commercial use.

## Publisher:

[z-zihan](https://clawhub.ai/user/z-zihan)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill to turn page screenshots into structured UI observations and a copyable implementation prompt for a coding agent.

Global

## 2026-06-07: 松下CR2032电池（淘宝 API 加购验证）

- **商品ID**: `693766844766` | **SKU**: CR2032 | **价格**: ¥6.72
- **结果**: ✅ API 方式成功
- **关键发现**: 点击按钮方式不可靠（反爬拦截，显示"成功"但未实际加购）。**必须使用 API 方式。**
- **API 要素**: 从 cookie 获取 `_tb_token_`，从 script 标签提取 SKU ID，从 `cart.taobao.com` 域发起请求
- **验证**: API 返回 `cartQuantity` 增加 = 真正成功；页面弹窗"成功" = 不可靠

## Description:

This skill is ready for commercial/non-commercial use.

## Use Case:

Players or agent operators use this skill to automate Minecraft Java Edition play by observing screenshots, planning the next action, and issuing keyboard or mouse commands. The included executable artifact also exposes functions for a different game, so reviewers should confirm the intended scope before use.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The visible instructions and executable entry points describe different games and workflows.

Mitigation: Confirm the intended scope with the publisher and require corrected documentation before installing or using the skill.

Risk: The code delegates browser automation and QQ login state handling to a dependency that was not available for inspection.

Mitigation: Require the publisher to include or pin the dependency and document how login state is stored and removed before use with any account.

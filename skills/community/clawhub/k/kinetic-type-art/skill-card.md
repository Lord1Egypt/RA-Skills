## Description:

Provides art-directed templates and presets for creating beat-synced kinetic typography, animated wordmarks, and motion posters.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vargai](https://clawhub.ai/user/vargai)

### License/Terms of Use:

MIT-0

## Use Case:

External motion designers and developers can use the templates and presets to build beat-timed titles, animated wordmarks, and typographic posters. The guidance covers timing, type, and repeatable rendering.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security evidence notes that some HyperFrames commands are unpinned and may resolve to a changing package release.

Mitigation: Pin the HyperFrames release before running commands and review changes when updating it.

Risk: The security review was partial; bundled font binaries were outside its static analysis coverage.

Mitigation: Review the bundled font files and their licenses before reusing them in a project.

# 感觉与特殊神经系统检查定位诊断

## 适用场景

当患者出现以下任一情况时触发本技能：
- 骨骼肌容积减少/肌萎缩
- 躯体感觉减退/缺失/异常/疼痛
- 疑似高级皮层功能障碍（失用、失认、视空间障碍）
- 瞳孔大小异常或对光反射异常

## 核心工作流程

### 路径一：肌萎缩定位诊断

**步骤1：区分神经源性 vs 肌源性**

| 特征 | 神经源性 | 肌源性 |
|------|---------|--------|
| 起病 | 急/进展快 | 相对缓慢 |
| 分布 | 符合神经支配 | 不符合神经支配 |
| 感觉障碍 | 可有（后根受累时） | 无 |
| 肌束颤动 | 可有 | 无 |
| 血清酶 | 正常 | CK等升高 |
| 肌电图 | 神经源性损害 | 肌源性损害 |

**步骤2：神经源性肌萎缩细分定位**

- **脊髓前角**：节段性分布，伴肌力低/腱反射弱/束颤，无感觉障碍
- **神经根/干**：根性/干性分布，加后根则有感觉障碍/疼痛
- **多神经根/丛**：近端为主
- **单神经**：按单神经支配范围分布

**步骤3：输出结论**
- 肌萎缩类型及具体受损部位
- 常见病因提示

### 路径二：躯体感觉障碍分类

**步骤1：区分抑制性 vs 刺激性症状**

**抑制性症状：**
- 完全性感觉缺失：各种感觉缺失
- 分离性感觉障碍：某种感觉障碍而其他保存
- 皮质感觉缺失：深浅正常，不能辨别形状/重量

**刺激性症状：**
- 感觉过敏：轻微刺激→强烈不适
- 感觉过度：阈值高/潜伏期长/扩散（见于丘脑病变）
- 感觉倒错：冷变热等（见于顶叶/癔症）
- 感觉异常：无刺激有蚁行/麻木等

**步骤2：疼痛分类定位**

| 疼痛类型 | 特点 | 常见病因 |
|---------|------|---------|
| 局部痛 | 局限性 | 局部病变 |
| 放射性痛 | 沿神经支配区扩散 | 神经根受压 |
| 扩散性痛 | 一个神经分支扩散到另一个 | 如牙痛扩散 |
| 牵涉性痛 | 内脏病变→体表痛 | 心绞痛→左胸/左上肢 |
| 幻肢痛 | 截肢后 | 下行抑制系统脱失 |
| 灼烧性神经痛 | 剧烈烧灼样 | 正中/坐骨神经损伤 |

### 路径三：高级皮层功能检查

**前提条件确认：**
- 患者意识清楚
- 无严重感觉/运动障碍干扰指令执行

**检查项目：**

**1. 失用检查：**
- 观察日常动作：穿衣、洗脸、梳头、用餐
- 执行简单动作：伸舌、闭眼、举手、书写、系纽扣
- 执行复杂动作：穿衣、划火柴
- 给予口头和书面命令，观察执行、模仿和实物演示能力

**2. 失认检查：**
- 视觉失认：辨认常用物品、照片、风景画
- 听觉失认：辨认熟悉声音（铃声、闹钟、乐曲）
- 触觉失认：闭目触摸手中物体并辨认

**3. 视空间技能和执行功能：**
- 画钟测试：画钟面→填数字→画指定时间表针
- 钟面缺失或指针不全 → 视空间技能和执行功能协同障碍

### 路径四：瞳孔对光反射定位

**步骤1：基线评估**
- 正常：圆形，双侧等大，居中，直径3～4mm
- <2mm：瞳孔缩小
- >5mm：瞳孔扩大

**步骤2：对光反射检查**
- 嘱患者注视远处
- 分别照射两侧瞳孔
- 记录直接对光反射和间接对光反射

**步骤3：损害定位鉴别**

**场景A：一侧视神经损害（传入障碍）**
- 光照患侧眼：两侧瞳孔均无反应
- 光照健侧眼：两侧瞳孔都缩小
- **结论：患侧直接反射消失，间接反射存在**

**场景B：一侧动眼神经损害（传出障碍）**
- 无论光照哪一侧：患侧瞳孔都无反应
- **结论：患侧直接和间接反射都消失**

**步骤4：补充检查**
- 调节反射：注视近物→瞳孔缩小
- 辐辏反射：注视近物→两眼会聚

## 注意事项

- 排除非神经系统/肌肉系统疾病导致的废用性萎缩
- 排除药物（如阿托品）或眼部局部病变引起的瞳孔异常
- 高级皮层检查不适用于意识障碍或严重智能障碍/失语患者

# 感觉与特殊神经系统检查详细操作规范

## 一、肌萎缩详细分类

### 神经源性肌萎缩

#### 脊髓前角病变
- 节段性分布
- 伴肌力低/腱反射弱/束颤
- 无感觉障碍
- 延髓核受累伴延髓麻痹/舌萎缩
- 见于：脊髓灰质炎、SMA、ALS

#### 神经根/干病变
- 根性/干性分布
- 单纯前根：同前角表现
- 加后根：有感觉障碍/疼痛
- 见于：腰骶外伤、颈椎病

#### 多神经根/丛病变
- 近端为主
- 见于：AIDP

#### 辅助检查
- 肌电图：神经源性损害
- 活检：小角状萎缩/核集中/结缔组织增生

### 肌源性肌萎缩
- 分布不符合神经支配
- 无皮肤营养/感觉障碍
- 无束颤
- 血清酶（CK等）升高
- 肌电图：肌源性损害
- 活检：肌纤维变性/坏死/炎细胞浸润
- 见于：肌营养不良、肌炎

### 其他类型
- 失用性：UMN损害
- 缺血性：血管病变

## 二、躯体感觉障碍详细分类

### 抑制性症状
- **完全性感觉缺失**：各种感觉均缺失
- **分离性感觉障碍**：某种感觉障碍而其他感觉保存
- **皮质感觉缺失**：深浅感觉正常，不能辨别形状/重量
- **痛性痛觉减退**：自发痛伴感觉减退
- **麻痹性疼痛**：感觉减退伴疼痛

### 刺激性/激惹性症状
- **感觉过敏**：轻微刺激引起强烈不适
- **感觉过度**：阈值高/潜伏期长/扩散/停止后仍有（见于丘脑病变/带状疱疹）
- **感觉倒错**：冷变热等（见于顶叶/癔症）
- **感觉异常**：无刺激有蚁行/麻木等

### 疼痛详细分类
- **局部痛**：局限性
- **放射性痛**：沿神经支配区扩散（如神经根受压）
- **扩散性痛**：一个神经分支扩散到另一个（如牙痛扩散）
- **牵涉性痛**：内脏病变致体表痛（如心绞痛致左胸/左上肢痛）
- **幻肢痛**：截肢后，与下行抑制系统脱失有关
- **灼烧性神经痛**：剧烈烧灼样（见于正中/坐骨神经损伤）

## 三、高级皮层功能检查详细规范

### 失用检查
- 失用很少被患者自己察觉，也常被医生忽视
- 需给予口头和书面命令
- 观察执行、模仿和实物演示能力
- 简单动作：伸舌、闭眼、举手、书写、系纽扣、刷牙、拨电话号码
- 复杂动作：穿衣、划火柴

### 失认检查
- 前提：感觉通路正常
- 排除：感觉/言语/智能/意识障碍
- **视觉失认**：看常用物品、照片、风景画，令其辨认并用语言/书写表达
- **听觉失认**：辨认熟悉声音（铃声、闹钟、敲击茶杯、乐曲声）
- **触觉失认**：闭目触摸手中物体并辨认
- **体象失认**：自身认识缺陷（多不作常规体检）

### 画钟测试评分要点
- 钟面完整性
- 数字排列是否正确
- 指针位置是否准确
- 钟面缺失或指针不全 → 视空间技能和执行功能相互协助障碍

## 四、瞳孔检查详细操作

### 正常基线
- 形状：圆形
- 位置：双侧等大，居中
- 大小：直径3～4mm（儿童稍大，老年人稍小）
- 需在亮处和暗处分别观察

### 对光反射检查步骤
1. 嘱患者注视远处
2. 用电筒光从侧方分别照射两侧瞳孔
3. 直接对光反射：光刺激后受照瞳孔缩小
4. 间接对光反射：光刺激后未受照瞳孔同时收缩

### 损害定位逻辑详解

#### 一侧视神经损害（传入障碍）
- 光照患侧眼：患侧直接消失，健侧间接消失 → 两侧瞳孔均无反应
- 光照健侧眼：健侧直接存在，患侧间接存在 → 两侧瞳孔都缩小
- 特征：患侧直接对光反射消失，间接对光反射存在

#### 一侧动眼神经损害（传出障碍）
- 无论光照哪一侧：患侧瞳孔都无反应
- 特征：患侧直接和间接对光反射都消失

### 调节和辐辏反射
- 嘱患者注视远方
- 突然注视面前20cm处正上方近物
- 正常反应：瞳孔缩小（调节）+ 两眼会聚（辐辏）

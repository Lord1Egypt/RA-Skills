# §22.15 影子模式 go/no-go 量化阈值协议（ct-literature）

> 依据：`ct-base/BASE.md §22.15` P1·g（影子模式准入阈值，2026-10-19 增补），证据 = `ct-base/references/qc_independence_pharmasug2026.md` §4（VALIDATE, BMJ Open 2026-10-01）。
> 适用范围：本技能任何**检索策略 / 综合引擎 / 归一化管线 / 分类器**的变更，在升级 Control Mode（CM3 → CM4）或任何"自动化放行"之前，必须走影子阶段。

## 1. 什么是影子模式（Shadow Mode）

新能力**锁定版本**后，在真实流程中**静默并行运行**、对使用者**盲态**（不影响现有输出），将其结果与参考基线**离线比对**。影子期内模型**禁止再训练 / 再校准**（对照 VALIDATE：model locked during the study）。只有全部量化阈值达标，才允许放量 / 升级 Control Mode；未达标保持 CM3 或回退，不得带病升级。

## 2. 触发条件（何时必须走影子）

| 变更类型 | 是否强制影子 | 说明 |
|---|---|---|
| 六源检索 / 日期窗口 / 去重（确定性层） | 否 | CM0，逐字节可复现，不属 LLM 升级 |
| MeSH / 概念归一化（LLM 层）映射逻辑变更 | **是** | 影响 evidence_level / is_safety 标注，须离线比对 |
| 主题中英翻译（topic_translator）模型替换 | **是** | 影响检索式质量 |
| 新增证据综合 / 摘要生成能力（LLM 出结论） | **是** | 最高风险，须完整影子 + 人工基准集 |
| 仅文案 / 样式 / 报告排版 | 否 | 不改变证据口径 |

## 3. 流程（五步）

1. **锁定版本**：记录 `skill_version` + 引擎 / 模板版本 + code-review 规则集版本（三要素，见 §6）。
2. **离线基准集**：维护一份**人工标注**的基准集（≥ 50 条代表性查询 / 文献，含关键语种与阴性对照）。
3. **静默并行**：新能力对生产流量盲态运行，结果入库但不下发。
4. **离线比对**：新能力输出 vs 人工基准集 / 现有生产输出，计算 §4 四阈值。
5. **go/no-go**：四阈值**全达标** → 放量；任一未达标 → 保持 CM3 / 回退，定位根因后重做影子。

## 4. 量化准入阈值（go/no-go）

| 指标 | 定义 | 放行阈值（本技能默认值） | 监测线（不单独阻断） |
|---|---|---|---|
| 性能区分度 | 与人工基准集的一致率 / 召回率 | 归一化 ≥ 95%；综合 / 摘要 ≥ 90% | — |
| 稳定性 | 同输入重复 N=5 次的输出漂移 | 漂移 ≤ 2% | — |
| 时效 | p95 单查询响应耗时 | ≤ 行业 / 内部 SLA | — |
| 可用性 | 离线基准集上的成功执行率 | ≥ 99% | — |

> 监测项 ≠ 红线：渗透率 / 采用率仅作监测，不得因"人力或环境限制"误判为模型不可用而误杀（§22.15·3）。

## 5. 熔断（Circuit Breaker）

放量后仍持续监测漂移与**亚组公平性**（语种、年份、研究类型子群）。触发任一阈值即**降级回 CM3**，并写审计；亚组公平性缺口一票否决。

## 6. SAP / 监管文档登记（§22.15·6）

AI 组件进入正式使用时，SAP 或等效监管文档须登记三要素：

- **模型版本**（如 topic_translator / kw_localize 的模型或词典版本）
- **skill / 模板版本**（本技能 `version:` + 报告模板版本）
- **code-review 规则集版本**（如有自动 SOP 扫描）

登记不齐视为**未完成部署**（依据：FDA 计算机化系统指导原则 appropriate controls、ICH E6(R3) 风险质量管理）。

## 7. 本技能当前状态（ct-literature）

- 当前 LLM 层**仅**在归一化 / 翻译 / 标注环节介入，**不生成证据结论、不撰写综述正文**；确定性层可独立验收、可入 CM0。
- 现有能力**无待升级的 CM4 变更**；上述阈值为**护栏**，任何未来 LLM 能力上线前必须据此走影子阶段。
- 概念归一化准确率已在每份报告的「§22.17 分层验收声明」中按映射状态（exact_label / synonym / unmapped_literal）分层披露，作为性能区分度的可观测代理指标。

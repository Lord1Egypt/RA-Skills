# 神经退行性疾病与痴呆诊断

## 核心鉴别流程

### 第一步：根据核心症状群初步分类

| 核心症状特征 | 指向诊断 |
|-------------|---------|
| 痴呆+波动性认知+视幻觉+帕金森综合征 | 路易体痴呆(DLB) |
| 早期人格行为改变+脱抑制+冷漠 | 行为变异型额颞叶痴呆(bvFTD) |
| 快速进展性痴呆+肌阵挛+锥体外系/小脑症状 | 克-雅病(CJD) |

### 第二步：路易体痴呆(DLB)诊断

**必要条件**：进行性认知功能减退影响日常生活

**核心临床特征**（评估满足几项）：
1. 波动性认知障碍（注意力/警惕性显著减退）
2. 反复出现的生动视幻觉
3. REM睡眠行为障碍(RBD)
4. 帕金森综合征（运动迟缓/静止性震颤/肌强直）

**提示性生物标志物**：
1. SPECT/PET示基底节DAT摄取下降
2. 123I-MIBG心肌显像异常
3. PSG证实REM期肌肉失弛缓

**诊断分级**：
- **很可能的DLB**：≥2个核心特征；或1个核心+≥1个标志物
- **可能的DLB**：1个核心无标志物；或≥1个标志物无核心

**1年原则鉴别PDD**：
- 痴呆早于/同时/帕金森后1年内出现 → DLB
- 帕金森症状1年后才出现痴呆 → PDD

### 第三步：DLB药物治疗安全红线

| 症状 | 首选方案 | 绝对禁忌 |
|------|---------|---------|
| 认知障碍 | 胆碱酯酶抑制剂（多奈哌齐/卡巴拉汀） | — |
| 精神症状 | 胆碱酯酶抑制剂无效时谨慎用喹硫平等 | **经典抗精神病药（氟哌啶醇等）→可致NMS死亡** |
| 运动症状 | 慎用左旋多巴（最小剂量慢加） | **抗胆碱能药→加重认知** |
| REM睡眠障碍 | 小剂量氯硝西泮 | — |

### 第四步：bvFTD诊断

**前提**：行为/认知进行性恶化+功能受损

**行为表现**（需满足≥3项）：
1. 早期脱抑制
2. 早期冷漠/迟钝
3. 缺乏同情/移情
4. 持续性/强迫性/刻板行为
5. 口欲亢进/饮食习惯改变
6. 执行障碍（记忆/视空间相对保留）

**影像学**（需≥1项）：
- CT/MRI：额叶和/或前颞叶萎缩
- PET/SPECT：额叶和/或前颞叶低代谢

**排除标准**（符合任一则不诊断）：
- 其他神经系统/内科疾病解释
- 更符合精神病学诊断
- 生物标志物强烈提示AD（CSF Aβ42↓，tau↑）

### 第五步：克-雅病(CJD)诊断

**临床三期**：
1. 初期：类神经衰弱，头痛/眩晕/共济失调
2. 中期：**快速进展性痴呆**+肌阵挛(2/3患者)+锥体外系/小脑/锥体束症状
3. 晚期：无动性缄默、昏迷，多死于并发症

**辅助检查**：
- RT-QuIC：CSF/皮肤PrP^Sc扩增（证据级别仅次于病理）
- MRI：DWI/FLAIR皮层和/或基底节区高信号
- 脑电图：1-2Hz三相尖慢复合波周期性放电
- CSF：14-3-3蛋白阳性，总tau持续增高

**诊断标准**：
- **很可能的CJD**：进行性痴呆(2年内) + (肌阵挛/视觉/小脑/锥体/锥体外系/无动性缄默中≥2项) + (RT-QuIC/MRI/EEG/14-3-3中≥1项阳性)
- **可能的CJD**：仅有上述前两项
- **确诊CJD**：脑活检海绵状变性+PrP^Sc，或PRNP基因突变

**预后**：无有效治疗，90%于1年内死亡

## 关键鉴别要点

1. **DLB vs PDD**：严格应用1年原则
2. **bvFTD vs 精神疾病**：bvFTD社会认知受损更显著，MRI脑萎缩和CSF tau/NfL升高有助鉴别
3. **CJD vs 自身免疫性脑炎**：CJD无免疫治疗反应，RT-QuIC特异性高
4. **DLB用药**：经典抗精神病药可致命，必须牢记

### [bvftd-imaging-biomarkers.md]
# bvFTD影像与生物标志物

## 影像学特征
- CT/MRI：额叶和/或前颞叶萎缩，多呈双侧不对称性，**左半球常较重**
- PET/SPECT：额叶和/或前颞叶低灌注或低代谢

## 与精神疾病鉴别
- bvFTD社会认知受损更显著
- MRI脑萎缩有助于鉴别
- CSF中tau/NfL升高支持神经退行性病变

## 与AD鉴别
- CSF中Aβ42下降+总tau/p-tau升高强烈提示AD
- 此类生物标志物阳性时应排除bvFTD诊断

### [cjd-diagnostic-details.md]
# CJD诊断细节

## RT-QuIC检测
- 原理：CSF/皮肤PrP^Sc实时震动诱导蛋白扩增
- 诊断证据级别仅次于病理
- 特异性高，有助于与自身免疫性脑炎鉴别

## MRI特征
- DWI/FLAIR序列
- 至少两个皮层区域（额/颞/顶/枕）和/或基底节区（尾状核/壳核）高信号
- 皮层 ribbon sign

## 脑电图演变
- 早期：弥漫性慢波
- 中晚期：典型周期性放电（1-2Hz三相尖慢复合波）

## 遗传咨询
- 确诊CJD需考虑PRNP基因检测
- 家族性CJD需遗传咨询
- 医源性传播防控：避免特定手术器械复用

### [dlb-biomarkers-detail.md]
# DLB生物标志物详解

## DAT显像
- SPECT或PET显示基底节区多巴胺转运蛋白摄取下降
- 有助于DLB与AD鉴别

## 123I-MIBG心肌闪烁显像
- DLB患者心肌摄取减低
- 反映心脏交感神经去支配

## PSG监测
- 证实快速眼动期肌肉失弛缓(RBD)
- RBD可在认知下降前数年出现

## 胆碱酯酶抑制剂选择
- **多奈哌齐**：对改善视幻觉有一定作用
- **卡巴拉汀**：对改善淡漠、焦虑、幻觉和错觉有效
- 两者对运动障碍也有一定效果

## 美金刚
- 对临床整体情况和行为障碍有轻度缓解作用
- 可作为胆碱酯酶抑制剂的补充

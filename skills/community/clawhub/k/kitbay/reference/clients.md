# AI clients: where MCP config and skills go

From each client's own documentation, as recorded on Kitbay (https://kitbay.app/clients/). Each section gives the source and the date it was checked. Generated by Kitbay; do not edit by hand.

## Claude Code

- MCP config: Local and user scope: ~/.claude.json (local scope is stored under the project's path inside that file); project scope: .mcp.json in the project root ([source](https://code.claude.com/docs/en/mcp))
- Skills: Personal: ~/.claude/skills/<skill-name>/SKILL.md; project: .claude/skills/<skill-name>/SKILL.md (also nested <subdir>/.claude/skills/ and --add-dir directories); plugin: <plugin>/skills/<skill-name>/SKILL.md; enterprise: .claude/skills/ in the managed settings directory; claude.ai account skills synced to ~/.claude/skills/synced/ ([source](https://code.claude.com/docs/en/skills))
- Checked: 2026-11-14

Connect Kitbay (run):

```sh
claude mcp add --transport http kitbay https://kitbay.app/mcp
```

## Claude Desktop

- MCP config: macOS: ~/Library/Application Support/Claude/claude_desktop_config.json; Windows: %APPDATA%\Claude\claude_desktop_config.json; Linux: ~/.config/Claude/claude_desktop_config.json (opened via Settings > Developer > Edit Config). Remote servers: Customize > Connectors (settings UI). ([source](https://modelcontextprotocol.io/docs/develop/connect-local-servers))
- Skills: ~/.claude/skills/ (local Code tab sessions); skills enabled on the claude.ai account (uploaded via Customize > Skills) ([source](https://code.claude.com/docs/en/desktop))
- Checked: 2026-11-14

Adding an MCP server, from its documentation ([source](https://modelcontextprotocol.io/docs/develop/connect-local-servers)). For Kitbay, use the remote server option with the URL https://kitbay.app/mcp:

1. For a packaged local server, open Settings, go to the Extensions area and install it from the directory, or install a `.mcpb` file under Advanced settings.
2. For a manual local server, open Settings > Developer and click Edit Config to open `claude_desktop_config.json`.
3. Add the server under mcpServers with its command, args and any env values, then save.
4. Quit Claude Desktop completely and reopen it so the new configuration loads.
5. For a remote server, go to Customize > Connectors, add a custom connector with the server URL and choose its sign-in option.

## ChatGPT

- MCP config: Settings UI: chatgpt.com/plugins > + > Add custom MCP server ([source](https://developers.openai.com/plugins/deploy/connect-chatgpt))
- Skills: not stated in its documentation
- Checked: 2026-11-14

Adding an MCP server, from its documentation ([source](https://developers.openai.com/plugins/deploy/connect-chatgpt)). For Kitbay, use the remote server option with the URL https://kitbay.app/mcp:

1. Host the MCP server at a public HTTPS endpoint (Streamable HTTP, usually `/mcp`), or set up Secure MCP Tunnel for a private server.
2. Go to `chatgpt.com/plugins` and select the plus button.
3. Choose Add custom MCP server, give it a name and enter the endpoint.
4. Configure the server's authentication and finish adding it.

## Gemini CLI

- MCP config: User: ~/.gemini/settings.json; project: .gemini/settings.json ([source](https://geminicli.com/docs/tools/mcp-server/))
- Skills: User: ~/.gemini/skills/ or ~/.agents/skills/; workspace: .gemini/skills/ or .agents/skills/; also bundled in extensions and built-in ([source](https://geminicli.com/docs/cli/skills/))
- Checked: 2026-11-14

Adding an MCP server, from its documentation ([source](https://geminicli.com/docs/tools/mcp-server/)). For Kitbay, use the remote server option with the URL https://kitbay.app/mcp:

1. Run `gemini mcp add <name> <command-or-url> [args...]`, using `-e KEY=value` for environment variables.
2. Set -t stdio, sse or http for the transport, and -s user or project for the scope (project is the default).
3. Or edit `settings.json` and add an entry under `mcpServers` with `command`, `args` and `env`, or `url` or `httpUrl`.
4. For remote servers that use OAuth, complete the sign-in when prompted.

## Devin Desktop

- MCP config: Project: .devin/mcp_config.json; local override: .devin/mcp_config.local.json (gitignored); user: ~/.config/devin/mcp_config.json ([source](https://docs.devin.ai/desktop/cascade/mcp))
- Skills: Workspace: .devin/skills/<name>/ (also .agents/skills/ and legacy .windsurf/skills/); global: ~/.config/devin/skills/<name>/ (also ~/.agents/skills/); inside installed plugins ([source](https://docs.devin.ai/desktop/cascade/skills))
- Checked: 2026-11-14

Adding an MCP server, from its documentation ([source](https://docs.devin.ai/desktop/cascade/mcp)). For Kitbay, use the remote server option with the URL https://kitbay.app/mcp:

1. Open Customize from the Agents window and select MCPs.
2. Use the Install MCPs for selector to choose the target, for example This computer.
3. Under Available, click Install on a server from your MCP registries.
4. Or add the server by hand to `.devin/mcp_config.json` or `~/.config/devin/mcp_config.json`.
5. If a server shows Needs authentication, click Authenticate to finish the browser sign-in.

## Cline

- MCP config: cline_mcp_settings.json. CLI: ~/.cline/data/settings/cline_mcp_settings.json (override with CLINE_MCP_SETTINGS_PATH). IDE extensions: opened via MCP Servers icon > Configure tab > Configure MCP Servers; the on-disk path for the extensions is not stated on the page. ([source](https://docs.cline.bot/mcp/configuring-mcp-servers))
- Skills: Project: .cline/skills/ (recommended), .clinerules/skills/, .claude/skills/; global: ~/.cline/skills/ (Windows: C:\Users\USERNAME\.cline\skills\) ([source](https://docs.cline.bot/features/skills))
- Checked: 2026-11-14

Adding an MCP server, from its documentation ([source](https://docs.cline.bot/mcp/configuring-mcp-servers)). For Kitbay, use the remote server option with the URL https://kitbay.app/mcp:

1. Click the MCP Servers icon in Cline's top toolbar and open the Configure tab.
2. Click Configure MCP Servers to open `cline_mcp_settings.json`.
3. Add an entry under mcpServers: command, args and env for a local server, or url, headers and type streamableHttp for a remote one.
4. Save the file and check the server's status in the MCP Servers panel.

## Zed

- MCP config: settings.json under the `context_servers` key (open with zed: open settings file), or Settings > AI > MCP Servers in the UI; project settings live in .zed/settings.json. The MCP page does not give the user settings file path per OS. ([source](https://zed.dev/docs/ai/mcp))
- Skills: Global: ~/.agents/skills/; project: <worktree>/.agents/skills/ ([source](https://zed.dev/docs/ai/skills))
- Checked: 2026-11-14

Adding an MCP server, from its documentation ([source](https://zed.dev/docs/ai/mcp)). For Kitbay, use the remote server option with the URL https://kitbay.app/mcp:

1. Open Settings > AI > MCP Servers and click Add Server.
2. Choose Install from Extensions, Add Local Server or Add Remote Server.
3. For a custom server, provide the command, args and env, or the URL and any headers; these are saved under context_servers.
4. Sign in through OAuth if the remote server asks for it.
5. Confirm the server's indicator dot is green (Server is active).

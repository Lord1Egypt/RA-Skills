## Description:

Removes backgrounds from video files to produce transparent alpha-channel or solid-color clips using Bria's video editing API.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and content-production teams use this skill to remove, replace, or make video backgrounds transparent for overlays, compositing, e-commerce, social media, and batch clip preparation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Videos, temporary upload URLs, and result URLs are sent to or generated by Bria services and may expose sensitive media if mishandled.

Mitigation: Use only videos suitable for Bria processing and treat upload and result URLs as secrets.

Risk: The helper stores Bria credentials under ~/.bria/credentials and loads them for future API calls.

Mitigation: Run the helper as a normal user, restrict access to the credentials file, and remove stored credentials after use when they are no longer needed.

Risk: Overriding BRIA_API_BASE can redirect API keys and uploaded video references to an untrusted endpoint.

Mitigation: Keep the default Bria API endpoint unless the replacement endpoint is explicitly trusted.

Risk: Unsupported transparent output presets or known server-side preset issues can produce failed jobs or files without expected alpha behavior.

Mitigation: Use webm_vp9 or mkv_vp9 for transparent output, use a solid background for MP4, and verify alpha before relying on MOV or converted outputs.

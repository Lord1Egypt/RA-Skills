## Description:

Creates layered, comprehensive technical documentation for projects, skills, or systems.

This skill is ready for commercial/non-commercial use.

## Publisher:

[liuxxxu](https://clawhub.ai/user/liuxxxu)

### License/Terms of Use:

MIT

## Use Case:

Developers, architects, and documentation authors use this skill to generate layered documentation suites for projects, skills, systems, tools, and workflows. It adapts output depth from quick references to full technical principles, architecture visualizations, and navigation indexes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may read more project content than intended while preparing documentation.

Mitigation: Provide only the project scope intended for documentation.

Risk: Generated documentation could expose secrets or private implementation details if sensitive files are included in scope.

Mitigation: Avoid including secrets or private files in source material and review generated documentation before publication.

Risk: Proposed changes to skill files or learning logs may affect future agent behavior.

Mitigation: Review those changes as normal source changes before accepting them.

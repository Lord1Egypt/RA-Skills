## Description:

Generate rich, immersive, novel-length dreams with vivid sensory detail, emotional arcs, complex plots, and meaningful reflections.

This skill is ready for commercial/non-commercial use.

## Publisher:

[alita-real](https://clawhub.ai/user/alita-real)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agent users use this skill to generate varied, literary dream narratives and save them as structured Markdown dream files for later reflection.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill creates or updates dream files under memory/dreams, which can accumulate over time.

Mitigation: Review memory/dreams periodically and ask the agent to confirm before each save when tighter control is needed.

Risk: Generated dreams may intentionally include uncomfortable, horror, grief, or body-horror themes.

Mitigation: Set content boundaries before generation when the reader wants a softer tone or specific topics excluded.

# 落地成本与报价拆解

核对日期：2026-11-11。本页只给计算方法与规则；**没有一个数字是某地某店的真实报价**。

## 一、先分清三种"钱"

| 说法 | 含义 | 用法 |
|---|---|---|
| 指导价 | 厂商公布的全国统一价（本库口径） | 只能当起点，不是成交价 |
| 成交价／裸车价 | 门店实际开票价（可能含优惠） | 用户提供或门店报价才有，本库无此数据 |
| 落地价 | 裸车 + 购置税 + 保险 + 上牌/服务费 + 选装 + 贷款相关费用 − 实际到账补贴 | 决策真正要比的数 |

**不得把指导价当落地价，也不得假设"新能源免购置税"。** 2026 年的规则是减半，不是免征。

## 二、购置税：减税额与实缴税额是两回事

依据财政部、税务总局、工信部《关于延续和优化新能源汽车车辆购置税减免政策的公告》（2023 年第 10 号）：

- 购置日期在 **2026-01-01 至 2027-12-31** 的新能源乘用车，**减半征收**车辆购置税；
- **每辆新能源乘用车的减税额不超过 1.5 万元**——上限作用在"减掉多少"，不是"缴多少"；
- 购置日期按**机动车销售统一发票开具日期**确定，不是订金日期、不是提车日期；
- 车型须列入《减免车辆购置税的新能源汽车车型目录》，不能由"新能源""2027 款"直接推出资格。

计算式（**按发票不含增值税的计税价格**，不是按含税价直接乘）：

```
原应纳税额 = 发票计税价格（不含增值税） × 10%
减税额     = min(原应纳税额 × 50%, 15,000 元)
实缴税额   = 原应纳税额 − 减税额
```

按含增值税车价估算时才引入 13% 的增值税率假设：

```
计税价格 ≈ 含税车价 ÷ 1.13
```

**常见错误**：把上限写成"实缴税额 ≤ 1.5 万"。那会让高价车少算税——不含税 50 万的车，原税额 5 万，减 1.5 万，实缴应是 **3.5 万**，不是 1.5 万。财政部政策解读里就是这个例子。

## 三、账单：按"何时付、付给谁"分栏

分期买车有两个不同的问题，"提车那天要准备多少钱"和"这台车一共花多少钱"，答案不是一个数。而且**"已付的"和"当天还要付的"必须分开**——已经付出去的定金不算"提车当天要准备的钱"，但它确实已经花掉了。

### 3.1 每一笔记四个属性：金额、时点、收款方、谁出

| 款项 | 收款方 | 时点 | 谁出 | 记入 |
|---|---|---|---|---|
| 定金（已付） | 车商 | 下定时（已过去） | 自付 | **① 此前已付** |
| 首付余款 | 车商 | 提车日 | 自付 | **② 当天尚需** |
| 贷款代付车款（≈ 贷款本金） | 贷款方 → 车商 | 放款日 | 贷款覆盖 | 不进车主自付栏；**只用于车价校验** |
| 购置税 | 税务机关 | 上牌前（通常提车日前后） | 自付 | ② |
| 交强险／商业险 | 保险公司 | 提车日 | 自付 | ② |
| 上牌／服务费／选装 | 车管所／车商 | 提车日前后 | 自付 | ② |
| 门店收的手续费／GPS／续保押金 | 门店 | 提车日 | 自付 | ② |
| **贷款方当日收取的费用** | 贷款方 | 提车日／放款日 | 自付 | **②**（同时属于下面⑤那个视角） |
| 月供 × 期数 | 贷款方 | 未来各期 | 自付 | **③ 未来各期** |
| 尾款 | 贷款方 | 约定时点（如第 36 期） | 自付 | ③；**时点必须写明** |
| 补贴（厂家／地方／置换） | — | 到账日 | 收入 | 表末单列，见 3.4 |

**车价校验式：① 中的车款 + ② 中的首付余款 + 贷款代付车款 = 裸车成交价。** 对不上就是漏项或重计，不是"约等于"。

### 3.2 三栏按时点，两个汇总，一个不许相加的视角

| 栏 | 含什么 | 回答什么问题 |
|---|---|---|
| **① 此前已付** | 已付定金、签约后先付的其他款 | "到现在为止已经出去多少" |
| **② 提车当天尚需** | 首付余款 + 当日税费／保险／上牌／选装 + 门店当日手续费 + **贷款方当日收取的费用** | "提车那天还要准备多少现金" |
| **③ 未来各期偿付** | 月供 × 期数 + 尾款 | "以后每期多少、合计多少" |

| 汇总 | 算式 | 说明 |
|---|---|---|
| **A 截至提车累计自付** | ① + ② | 到提车那天为止，自己实际付出多少 |
| **B 全期总支出** | ① + ② + ③ | 从定到还完，一共出去多少 |
| **⑤ 对贷款方累计付款**（另一视角） | ② 中贷款方收取的费用 + ③ | **不能与 ②、③ 相加**——它已经在 ②、③ 里各算过一次了 |

**②里为什么不再有定金**：定金是过去付的，记在 ①。如果把"含已付定金的整个首付"放进 ②，那"提车当天要准备多少"就会被高估；反过来只报 ② 又会让人以为这就是全部已付。所以 ① 和 ② 必须并列，A 才是"到提车为止的累计"。

**交叉校验（只在"除车款外没有任何费用"的简化算例里可用）**：

```
全期总支出 = 车价 + (③ − 贷款代付) + ②中贷款方当日收取的费用
```

只要出现税费、保险、上牌、选装、门店费或补贴，这条式子就不再成立——**逐项相加才是唯一算法**。左边的校验不加"金额大小"之类的判断，只核对每一笔是否恰好出现一次。

| 尾款 | 贷款方 | 约定时点 | | ③ | 贷款合同；**时点必须写明** |
| 后续自付费用（次年保险、延保） | — | 未来 | | ③或单列 | 未确认就写"未计入" |

**禁止**（四条，逐条对应一种具体错账）：

1. 把**全额车价**填进"提车当天尚需"——分期时贷款代付的部分不是车主当天掏的钱。
2. 把**已付定金**同时放进 ① 和 ②——它只能在 ①。
3. 把 ⑤ 加到 ②、③ 上——⑤ 是另一视角，加一次就重复了。
4. 把"全期利息"另加一遍——月供里已经含了。

### 3.4 补贴：支出与收入分列，不做减法

补贴不进入 ①②③ 的任何一格。在表末单列：

| 补贴名称 | 金额 | 资格条件 | 到账时点与方式 |
|---|---:|---|---|

- **已到账**：可以算"净额"——`净额 = 全期总支出 − 已到账补贴`，并注明这是事后净额。
- **未到账**：只作备注，不参与净额计算，更不能从 ①②③ 里扣。
- 直接抵车价的（开票即减）与先付后返的，对当期现金的影响完全不同，必须分别写。

**怎么读这张表**：

- ① 与 ② 是**并列的两个时点**，不是包含关系。A＝①＋② 才是"到提车为止一共自付了多少"。

1. 定金：只在 ①，② 里必须先扣掉（B 的 58,000 = 55,000 + 3,000）。
2. 贷款本金：14 万不是车主支出，只出现在车价校验里。

## 四、贷款：先问清五数，再谈比较

先取齐五数：**首付合计（是否含已付定金）、贷款本金、期数、每期月供、尾款（如有）**，再问清两件事：**有没有当日一次性收取的费用**、**手续费由门店收还是贷款方收**。

```
对贷款方累计付款 = 贷款方当日收取的费用 + 月供 × 期数 + 尾款
```

这个式子对应 3.2 的 ⑤，是**另一个视角**，回答"这条贷款线一共付出多少"；它不是"当天要准备的钱"，也不能与 ②、③ 相加。

这个式子里**没有首付**：首付是付给车商的车款，拆在 ①（已付定金）与 ②（余款）里。把它加进 ⑤ 会同时高估"贷款线付出"和"当天要准备的钱"。

四条硬规则：

1. **月供已含利息，不得再把"利息总额"加一遍。** 只有门店把利息单列、月供是纯本金时，才把利息加进去。
2. **首付要拆，不能整块塞进任何一栏。** 已付定金进 ①，余款进 ②；两块相加才是首付合计。
3. **贷款方当日收取的费用进 ②**（当天真要付），同时计入 ⑤；不能因为 ⑤ 里有就不再算进当天现金。
4. **"后返""贴息""置换补贴"是收入侧**，不减少 ①②③ 里的任何一笔支出，按 3.4 单列，另算净额。
5. 只给月供、给不出期数与尾款时，写"无法比较"，不要替门店算一个数。

**问法也要改**：不要问"月供多少"，要问"**首付多少、其中多少已经付了、几期、每期多少、有没有尾款、放款当天还有没有一次性收费、一共还多少**"。只拿到月供这一个数，任何比较都是假的。

## 五、补贴：资格、时点、到账方式三件事

- **资格**：厂家补贴常限指定版本或库存车；地方补贴限本地开票、本地牌照；置换补贴要求旧车过户与持有期。
- **时点**：本库记录的 C16 权益（2026-06-16 至 07-31）、C10／C11 选装基金半价均为**已过期**政策，只能作"历史上存在过"的参考，不能进当前报价。
- **到账**：直接抵扣车价、先付后返（数月）、以充电额度／积分发放，三者对当期现金的影响完全不同。
- **叠加**：厂家 + 地方 + 置换能否同享，逐项问清，不做默认假设。

规则：**未确认资格与到账方式的补贴，一律不扣减，只列为"可能减项"。**

## 六、预算问题的硬规则

1. 先问清是**裸车预算**还是**落地预算**，以及是否为**硬上限**。
2. 裸车预算：指导价（或已确认书面成交价）超过上限的版本，**不得列为合格候选**。超过的部分要写明差额与比例。
3. 落地预算：**不要**用一个拍出来的"落地系数"反推裸车上限。只算**余额**：

   ```
   余额 = 预算 − 裸车价 − 购置税
   ```

   余额是留给保险、上牌、选装、贷款费用的钱。本库没有保险与上牌报价，所以只能说"余额约 X 元，需逐项核验"，**不能断言"落地一定不超预算"，也不能断言"肯定不够"**。
4. 用户提供**书面报价**（含裸车价、各项费用、有效期）时，按报价算；不要因为报价低于指导价就否定，也不要因为看起来便宜就直接接受——先核验有效期、适用版本、是否绑定贷款或置换。
5. 不得以"可能有优惠""可能有补贴"让超预算车型"看起来能买"。

## 七、算例（输入、算式、结论都写出来）

以下四组都是**全款**情形（不含贷款），只看"预算减掉车款与购置税后还剩多少"。贷款的分账算例见 3.5 节。

假设：按指导价计裸车价，购置税按上表，**保险与上牌尚未报价**。

| 场景 | 预算 | 裸车 | 购置税 | 余额 | 能得出的结论 |
|---|---:|---:|---:|---:|---|
| C10 290 智享 | 落地 14 万 | 12.58 | 0.5566 | **8,634 元** | 余额尚可，但保险+上牌是否够需报价 |
| C10 660 智享 | 落地 14 万 | 13.28 | 0.5876 | **1,324 元** | 余额很可能不够保险上牌，需逐项核验 |
| C16 280 尊享六座 | 落地 16 万 | 14.88 | 0.6584 | **4,616 元** | 同上，不能直接说"能落地" |
| C16 630 尊享五座 | 落地 16 万 | 15.28 | 0.6761 | **439 元** | 余额几乎为零，**不得列为可成交** |

**同一个 16 万落地预算下，不能一边排除 14.88 万的六座、一边接受 15.28 万的五座**——两者用的是同一套税费假设，便宜的那台余额反而更多。要排除就两台都标"待核验"，要接受就两台都写清楚余额。

裸车预算则简单：上限 14 万时，14.28 万的版本已经超 2,800 元，只能作为"加预算 2,800 元"的备选，不能算合格候选。

## 八、示例：落地 14 万能不能买 C16 280 尊享五座

指导价 14.58 万，购置税约 0.6451 万，仅这两项已 15.2251 万，超过 14 万落地预算 1.2 万以上，保险与上牌还未计。结论：**在 14 万落地预算下不合格**，需说明差额，或改看 C10 290 智享（余额约 8,634 元，仍取决于保险上牌报价）。

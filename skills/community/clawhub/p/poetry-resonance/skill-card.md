## Description:

Pairs Tang and Song poems with everyday moods and moments, then explains them in plain Chinese and supports daily reading, study, review, and export.

This skill is ready for commercial/non-commercial use.

## Publisher:

[bonniegeng-max](https://clawhub.ai/user/bonniegeng-max)

### License/Terms of Use:

MIT-0

## Use Case:

Chinese-speaking readers can use it to find a Tang or Song poem for a feeling or moment, get a plain-language explanation, and keep up a relaxed reading and review practice.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security review was partial because some referenced paths were missing; the scan also flags possible external skill installation and optional cloud note saving.

Mitigation: Review the target before following any installation command, and send study notes to a cloud service only when the user explicitly requests it. Keep optional online lookups disabled when they are not needed.

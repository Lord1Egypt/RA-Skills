# marketing-poster-recipes · 营销海报配方库

> 版本：1.2.0 ｜ 类型：L2 标准技能（知识型卡库 + 轻交互流程）｜ 状态：可公开（课程同源案例图已脱敏，8 张新卡 prompt 为槽位化通用模板）

## 是什么

从广告创意**配方卡**库选卡填槽，生成可直接用于小红书/朋友圈/电商的营销海报与种草图。14 张卡：超现实微观合成、超现实液体定格、极简手绘小剧场、诗意复古印刷、人物手持产品光影、Apple 极简、电商白底精修、贴纸拼贴清单、复古拼贴节日、复古美式快餐、中式市井美食、小红书家居标注、第二世界分割创意，另加 brainstorm-12 头脑风暴定方向；附卖点提炼、Slogan 生成与广告红线审查。

## 何时用 / 何时不用

- **用**：给产品做海报/营销图/种草图/广告创意图/小红书封面/电商白底主图/家居笔记标注图，或出广告创意方案 + 配图
- **不用**：纯文案写作（无出图需求）、漫画/分镜叙事（→ text-to-comic）、反推风格建风格卡（→ style-card）、一次性 prompt 润色、生成视频（→ 即梦路径）

## 依赖与降级

- **依赖**：ImageGen 生图工具（约 5-10 积分/张，生成前必须告知用户确认）；图生图类卡需用户上传产品照片
- **降级**：生图不可用或不想耗积分时，交付「选卡建议 + 填好槽的完整 prompt」，供手动投喂豆包/即梦，效果等价

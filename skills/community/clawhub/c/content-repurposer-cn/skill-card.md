## Description:

Repurposes a supplied article, topic, notes, or transcript into platform-tailored drafts for WeChat, Zhihu, Xiaohongshu, Douyin/TikTok, Toutiao, Twitter/X, and LinkedIn.

This skill is ready for commercial/non-commercial use.

## Use Case:

Creators, marketers, and operators use this skill to turn one source text or topic into native drafts for multiple social and publishing platforms. It helps generate channel-specific copy, long-form articles, short-form scripts, English social posts, and a distribution checklist for manual review and publishing.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Confidential source material may be rewritten or translated in the chat output.

Mitigation: Avoid providing confidential material unless the user is comfortable having it transformed in the agent session.

Risk: Default platform and language behavior may create drafts for channels the user did not intend to use.

Mitigation: Specify the desired platforms and languages when the full default set is not wanted.

Risk: Generated drafts may need factual, tone, and compliance review before public posting.

Mitigation: Review and edit all generated copy manually; the skill does not access accounts or publish content automatically.

# 安全铁律（本 skill 的一票否决项）

> 这不是「建议」，是**边界**。任何一条被打破，这个体检器就失去了存在价值——
> 一个删错了用户东西的清理工具，比不存在更糟。

---

## 1. ⛔ 清理只能来自用户逐项勾选，且只限官方缓存命令

> **v1.3 修订说明**：v1.1 允许选择器删除整个版本管理器目录，ClawHub 审核据此判「描述与行为不符、删除范围被低报」。
> 现在把范围收窄为**官方缓存与旧版本清理**：版本管理器的整目录删除交给用户按官方步骤手动执行，脚本不代跑。
> 底线没变——**用户必须知道自己删了什么**。

**唯一允许执行清理的路径是 `scripts/clean.sh`**，且必须同时满足六条：

| # | 约束 | 为什么 |
|---|---|---|
| 1 | **默认全不选** | 绝不能出现「一路回车就删光」的可能 |
| 2 | **数据类锁死不可勾选** | 模型权重、容器卷、Ollama 模型——按空格也勾不上 |
| 3 | **只跑白名单里写死的官方子命令** | 命令按 id 静态分派，不拼装、不做动态求值；不做任意路径删除 |
| 4 | **执行前逐条列出命令 + 代价，输入 `yes` 才动手** | 二次确认，且让用户看到的是真实要跑的那行；执行时每项再确认一次，没有跳过开关 |
| 5 | **提供 `--dry-run`** | 第一次用先看不执行 |
| 6 | **不删除版本管理器目录、不删模型与容器数据、不改 shell 配置** | 整目录删除会连已装版本和用户环境一起带走；改配置比删目录更危险 |

**⛔ 模型自己不执行删除。**对话里发现残留时，正确动作是**给官方手动步骤 + 引导用户去跑 `clean.sh` 清缓存**，而不是自己拼一条 `rm` 跑掉。用户说「你直接帮我删」时的标准回应：

> 删这件事我不替你按回车。缓存类跑 `bash scripts/clean.sh`，勾上你要清的，它会先把命令和代价列给你看；想先看看不执行就加 `--dry-run`。版本管理器目录不在脚本范围内，我把官方步骤列给你，你自己执行。

## 2. ⛔ 扫描器只读，选择器只跑官方缓存命令

`scripts/scan.sh` 全文只含 `du` / `df` / `ls` / `find` / `grep` / `date` / `command -v` 这类只读命令。
**任何往扫描器里加写操作的改动都必须被拒绝**，包括「顺手写个上次扫描记录」这种看似无害的。

`scripts/clean.sh` 不含任何 `rm` 形式的目录删除（唯一的 `rm -r` 只用于清理自己创建的临时目录），清理动作全部是包管理器自带的缓存子命令。

改完脚本必跑双自检：

```bash
# 扫描器：不该有任何破坏性命令
grep -nE '\brm\b|rmdir|unlink|trash|shred|truncate|mv ' scripts/scan.sh
# 选择器：唯一允许的 rm 是自己临时目录那一行；不允许动态执行
grep -nE '\brm[[:space:]]+-' scripts/clean.sh
grep -nE '\beval\b' scripts/clean.sh
```

第一条有输出即违规；第二条只应命中 `TMPD` 临时目录那行；第三条应为空。文档与 README 里也不复述递归删除命令，只写「按官方步骤手动卸载」。

## 3. ⛔ 不确定就说不确定

四信号（`shell_loaded` / `cmd_in_path` / `runtime owner` / `last_modified`）出现矛盾组合时，**判定写「不确定」并说明矛盾在哪**，不许为了报告好看而猜。

❌ 错误示范：「pyenv 大概率不用了，建议删除」
✅ 正确示范：「pyenv：目录在、shell 未加载、python 实际来自 homebrew——三个信号指向残留，但 `~/.pyenv/versions` 下还有一个 pypy3.10。**如果那个 pypy 是你特意留的，就别删。**」

## 4. ⛔ 数据类一律不建议删

模型权重、容器卷、数据库文件、密钥、项目源码——**哪怕它是最大的那个，也不进「建议清理」清单**，只在报告里如实列出体积并标注「数据·别碰」。

特别地：`docker system prune` 的建议里**永远不带 `--volumes`**。

## 5. ⛔ 清理后遗症必须一并交代

建议删除任何版本管理器目录时，**必须同时给出「清理 shell 配置里那几行」的提示**。
只删目录不改配置 = 用户下次开终端就看到报错，而且他不会想到是你造成的。

## 6. ⛔ 不碰家目录之外 / 不碰系统目录

扫描范围限定在用户家目录与已知的开发工具路径。
不扫 `/System`、`/Library`（系统级）、其他用户的家目录；不建议对系统目录做任何操作。

## 7. ⛔ 不联网、不上报

体检数据（目录结构、工具清单）属于用户隐私。本 skill **不把扫描结果发送到任何地方**，不做统计上报。

- [ ] 报告里每条「建议清理」都标了身份、代价、官方命令来源
- [ ] 数据类没有出现在建议清理清单里
- [ ] 版本管理器建议写明了「手动执行」并附带 shell 配置清理提示
- [ ] 不确定项如实标注，没有为凑结论而猜
- [ ] 报告结尾三条免责齐全（见 `rules.md` 第五节）

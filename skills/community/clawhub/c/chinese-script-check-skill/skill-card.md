## Description:

Checks Chinese screenplays for proofreading issues, goofs, costume and prop continuity, scene consistency, logic breaks, and language problems.

This skill is ready for commercial/non-commercial use.

## Publisher:

[flankechen](https://clawhub.ai/user/flankechen)

### License/Terms of Use:

MIT-0

## Use Case:

Writers, editors, and video creators use this skill to review Chinese scripts for continuity, logic, and wording issues while preserving the author's voice and intent.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may create local text and Markdown files containing details from the user's script.

Mitigation: Use the skill only in a workspace where retaining script-derived notes is acceptable, and delete generated review files when the script is sensitive.

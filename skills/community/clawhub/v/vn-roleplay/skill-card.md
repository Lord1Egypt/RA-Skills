## Description:

Immersive character roleplay protocol for Vietnamese text-based experiences, governing narrative, dialogue, internal thought, character consistency, first-message handling, and interaction loops.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kaibazax-dev](https://clawhub.ai/user/kaibazax-dev)

### License/Terms of Use:

MIT-0

## Use Case:

External users and agents use this skill to run Vietnamese-oriented interactive character roleplay sessions with consistent in-character narration, dialogue formatting, and emotional continuity.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill tightly controls response style for Vietnamese-oriented character roleplay and may be unsuitable outside that context.

Mitigation: Enable it only for intended roleplay sessions and disable it for general-purpose assistant tasks.

Risk: Character profiles and first messages can strongly shape in-character output.

Mitigation: Review character profiles, first messages, and generated responses for the intended audience before use.

## Use Case:

Developers, document operators, and external users use this skill to convert single or multiple .docx files into PDFs while preserving images, tables, and common formatting.

## Known Risks and Mitigations:

Risk: Installing conversion tools or Python packages from untrusted sources can introduce supply-chain risk.

Mitigation: Install only the conversion tools needed for the selected workflow, use trusted package sources, and prefer an isolated Python virtual environment.

Risk: Batch conversion can process unintended documents or write PDFs to unexpected locations.

Mitigation: Review source documents and output paths before running batch conversions, especially in directories that contain sensitive files.

# APP-045 接班人培养与交接

## 场景定义

- **目标**：接班人的甄选、培养与交接全流程——选苗、历练、传位、过渡稳定。
- **约束**：候选断层与人才梯队单薄；血缘/亲信干扰甄别；交班人恋权不舍；交接期人心动荡、政令失序。
- **角色**：创始人/现任者、接班候选人、核心班底/董事会。
- **典型输入**：①接班梯队规划与候选甄选；②候选培养历练与授权安排；③交接期过渡与稳定方案。
- **边界**：常态化授权与分权体系归 APP-041 授权与分权管理；候选人的考核激励归 APP-042 绩效考核与激励设计——本 Skill 管"选苗、培养、交棒"。

## 组合公式

- **顺序**：选苗段（ZJZ-03→GZ-22→GZ-14）→ 培养段（SZ-22→MZD-75→SZ-47→MZD-46→MZD-34）→ 交接段（MZD-10→SZ-49→ZGF-12→GZ-43）。
- **条件分支**：多候选可用 → GZ-14 量权比较、赛马历练后择优；单一候选 → 培养段权重升并建第二梯队防断层；突发交接（现任意外离任）→ MZD-10 集体领导 + SZ-49 上下同欲先行稳定，选苗段从速补课。
- **权重**：ZJZ-03 权重最高——接班甄别以功实为据是成败根基，名不代实。
- **冲突裁决**：放手历练 与 犯错风险冲突 → 按 SZ-47+MZD-34 裁决：授权不縻军，失误救治有红线（红线内是学费、红线外即换人）；亲情/亲信 与 功实核验冲突 → 按 ZJZ-03 裁决：以可核查功实为准绳，感情不进入甄别标准；交班人恋权 → 按 ZGF-12 裁决：功不必自己出，事成高于功归；候选人质疑现任路线 → 按 MZD-10+SZ-49 裁决：交接期集体领导，路线争议摆上桌面议而后定（MZD-10），议定后上下同欲不再各行其是（SZ-49）。

## 执行步骤

1. **核名实**（ZJZ-03）：候选甄别以可核查功实为准绳——独立带队业绩、危机处置实绩、可验证的领导行为；血缘、亲信关系、资历皆为"名"，不代实。
2. **因材定制**（GZ-22）：按候选人之贤愚勇怯差定制培养路径——缺战略则补战略历练，缺带人则补管理历练，不硬性划一。
3. **量权比较**（GZ-14）：多候选时度权量能——各候选的长短轻重摆上桌面，权其轻重、较其优劣而后定，不以一时一事定夺。
4. **建立亲附**（SZ-22）：培养者与候选人先立亲附——视之如子、倾囊相授；亲附立而后教之有效、罚之能服。
5. **紧抓培养**（MZD-75）：培养抓而不紧等于不抓——培养计划有节点、有检查、有验收，一抓到底毫不放松。
6. **授权历练**（SZ-47）：真刀真枪的历练授权——给独立作战单元，不縻军、不惑军、不疑军；用其人则信其专。
7. **失手寻根**（MZD-46）：候选失手先寻根——是判断问题、经验问题还是资源问题，根因不同培养处方不同。
8. **容错救治**（MZD-34）：候选失误惩前毖后、治病救人——错误彻底复盘汲取教训，人不当一棒打死；红线错误（价值观、重大操守）除外。
9. **集体领导过渡**（MZD-10）：交接期班底集体领导——重大决策集体议定，降低单点认知风险，为继任者赢得缓冲。
10. **上下同欲**（SZ-49）：交接期全员对齐——新主与团队在目标、利益、价值上同欲，同欲者胜，异欲未战先乱。
11. **让功让名**（ZGF-12）：交班人心态——功不必自己出、名不必自己成；公开归功于继任者与班底，自己收责任与余责。
12. **缀去善后**（GZ-43）：离任者与旧部安抚联结——致谢、给位、给面，使其怀德而不掣肘；旧部关系由继任者有序承接。

## 失效预案

- **候选断档/梯队崩坏**：退回 GZ-22 因材定制重排培养路径 + 立即建第二梯队；短期以 MZD-10 集体领导兜底过渡。
- **交接期人心动荡**：退回 SZ-49 上下同欲——利益与目标快速显式对齐，动员先行；动荡源在旧部则 GZ-43 缀去善后，源在新主威信则 ZGF-12 让功让名助力立信。
- **候选人历练中重大失手**：退回 MZD-46 寻根——可救（能力/经验问题）则 MZD-34 救治续用；不可救（判断力/价值观问题）则回选苗段换人。
- **交班人反复恋权、交接反复**：退回 ZGF-12 自律 + MZD-10 班底集体决议——交接节奏制度化，个人反复以集体决议对冲。
- **一切争议不决**：兜底回 ZJZ-03——功实说了算：谁能以可核查功实证明可托付，就交给谁。

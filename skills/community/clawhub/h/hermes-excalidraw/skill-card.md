## Description: <br>
Hand-drawn Excalidraw JSON diagrams for architecture, flow, and sequence work, generated as clean, well-laid-out charts with consistent box sizing, meaningful colors, and zero line crossings. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[no7dw](https://clawhub.ai/user/no7dw) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers, technical writers, and agents use this skill to create clean Excalidraw architecture diagrams, flowcharts, sequence diagrams, concept maps, and process maps as local .excalidraw JSON files or shareable links. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Generated diagrams may contain confidential architecture, operational details, or business context that should not be uploaded to a third-party sharing endpoint. <br>
Mitigation: Prefer local-only .excalidraw files for sensitive content; upload only when sharing is intended and treat generated Excalidraw URLs and embedded keys as sensitive. <br>
Risk: The default workflow includes browser-based screenshot verification, which can expose rendered diagrams in local browser tooling. <br>
Mitigation: Use screenshot tooling only in trusted local browser sessions and review diagrams before sharing or uploading. <br>

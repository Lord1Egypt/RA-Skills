## Use Case:

External users and developers use this skill to guide agents through analysis of user-provided CSV or Excel spreadsheets, including data profiling, summary statistics, charts, and plain-English recommendations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill is designed to read and summarize user-provided spreadsheets, which may contain sensitive data.

Mitigation: Review files for sensitive information before sharing them with an agent that uses this skill.

Risk: Spreadsheet insights, charts, and recommendations can be misleading when source data has missing values, parsing errors, or outliers.

Mitigation: Inspect data quality, validate key calculations, and review generated findings before making business decisions.

```

### 价值陈述（2-5分钟）

```
张教授，我们事务所主要做三件事：

第一，帮助像您这样的科研团队梳理技术优势，找到最适合的产业化路径；
第二，对接投资机构和产业资源，解决资金和渠道问题；
第三，全程陪跑，从技术评估到成果转化，全程服务。

我们之前成功运作过几个类似的项目，比如XX大学的XX技术，去年已经拿到了产业化的订单。

所以想了解一下，您这边目前的技术研发进展如何？对产业化有什么想法或者困惑？
```

### 需求挖掘（5-12分钟）

```
【倾听模式】

（根据张教授回答选择性提问）

核心问题清单：
1. 目前实验室验证到哪一步了？
2. 有没有做过小试或中试的尝试？
3. 对产业化有什么预期？（自建产线？技术转让？合作开发？）
4. 资金方面有什么计划？
5. 有没有接触过投资机构或产业方？
```

### 价值钩子（12-15分钟）

```
张教授，听您这么一说，我有个初步判断：

您的技术在航空涂层领域确实非常有价值，但目前离产业化还差"最后一公里"——也就是工程化验证和中试。

这恰恰是我们最擅长的事情。我们可以帮您：

□ 对接航空主机厂，了解真实的工艺需求
□ 推荐合适的中试基地和设备
□ 协助申请产业化专项支持
□ 对接有实力的投资方

不知道您有没有兴趣，我们约个时间详细聊聊？
```

### 结束语

```
好的，张教授，那我这边安排一下专家做技术评估，评估报告完成后我们再约时间详细沟通产业化方案。

我的微信是XXX，您有什么问题随时联系我。

感谢您的时间，期待后续合作！

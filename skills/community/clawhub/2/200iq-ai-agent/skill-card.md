## Description:

Enhance an AI agent with prompt optimization, ROI-based task prioritization, self-correction, and action-plan generation for complex tasks.

This skill is ready for commercial/non-commercial use.

MIT-0

## Use Case:

External users and developers use this skill to turn a task or goal into optimized prompts, ROI-ranked actions, execution notes, and implementation-ready guidance.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Advisory plans or ROI rankings may be mistaken for approval to take real business, financial, account, or tool actions.

Mitigation: Require explicit user approval before any real external action is taken.

Risk: Python helpers may write task details to persistent ../logs files.

Mitigation: Review log paths and avoid running helpers on sensitive task details unless local retention is acceptable.

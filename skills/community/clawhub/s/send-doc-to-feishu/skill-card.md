## Description:

Helps an agent send local documents such as Word, Excel, PDF, or images to Feishu users or group chats by choosing between Feishu Docs links and Feishu Drive sharing links.

This skill is ready for commercial/non-commercial use.

## Publisher:

[woai36d](https://clawhub.ai/user/woai36d)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agents use this skill to route generated or existing local documents to Feishu recipients, handling current limitations around native IM file attachments by using cloud document or drive-link workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Local documents may leave the local machine when uploaded to Feishu Drive and shared as links.

Mitigation: Confirm the selected file and recipient before upload, especially for confidential documents.

Risk: Feishu Drive file tokens are not valid IM file attachments, which can cause failed sends or confusing recipient experience.

Mitigation: Use Feishu Docs links or Drive sharing links unless an IM file upload tool is available.

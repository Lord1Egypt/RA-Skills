## Known Risks and Mitigations:

Risk: Stream content, chat interactions, media searches, and API calls may be sent to Lobster.fun or shown publicly.

Mitigation: Avoid private, personal, or proprietary stream content and review messages before using the skill in public-facing streams.

Risk: The workflow requires API and stream keys for authentication and streaming.

Mitigation: Keep API and stream keys secret, store them securely, and avoid placing real keys in prompts, examples, logs, or public repositories.

Risk: GIF and YouTube search features can display third-party media selected from search terms.

Mitigation: Use appropriate search terms, moderate displayed media, and confirm that public stream content is acceptable for the target audience.

## Use Case:

External job seekers, students, career-switching engineers, and interviewers use this skill to organize full-stack technical interview preparation across interview-question discovery, coding practice, system-design mock interviews, review, and progress reporting.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can create or manage GitHub Issues as part of an interview question bank.

Mitigation: Use it only with the intended repository selected and require confirmation before issue creation or changes.

Risk: Broad search and scraping workflows may collect irrelevant, stale, or inaccurate interview material.

Mitigation: Review collected sources and generated question lists before using them for study plans, reports, or interview evaluation.

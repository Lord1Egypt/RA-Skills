## Description:

Roxy Migurdia is a markdown persona skill that guides an agent to roleplay the Roxy Migurdia character for teaching dialogue, emotional support, magic-knowledge discussion, and everyday conversation.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

External users and agent builders use this skill to provide a Chinese/Japanese anime roleplay persona for character interaction, teaching-style dialogue, supportive conversation, and daily chat.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generic activation terms such as teacher or master may invoke the persona unexpectedly.

Mitigation: Use tighter activation wording when deploying the skill so ordinary requests do not unintentionally trigger roleplay behavior.

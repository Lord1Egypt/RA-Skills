# 电气图纸图例与符号标准

> 依据 GB/T 4728《电气简图用图形符号》及公司《电力行业施工图设计规范V1.0》

## 高压系统图例

| 名称 | 符号 | DXF 绘制方式 |
|------|------|-------------|
| 断路器 | 矩形+对角线 | `_draw_breaker()` |
| 负荷开关 | 矩形+竖线 | `_draw_load_switch()` |
| 隔离开关 | 竖线+斜杠 | 竖线中间断开加斜杠 |
| 熔断器 | 矩形内加圆 | `add_lwpolyline` + `add_circle` |
| 电流互感器 | 圆或方框内 TA | `add_circle` |
| 电压互感器 | 圆或方框内 TV | `add_circle` |
| 避雷器 | 箭头形 | 三角形或箭头符号 |
| 变压器 | 圆圈内加标注 | `add_circle` + `add_text` |
| 计量柜 | 矩形内写"计量" | `add_lwpolyline` + `add_text` |

## 低压系统图例

| 名称 | 符号 |
|------|------|
| 空气断路器 | 矩形 |
| 塑壳断路器 | 小矩形 |
| 刀熔开关 | 矩形+斜线 |
| 电容器 | 两平行线 |
| 电涌保护器 | 矩形内 SPD |
| 电流互感器 | 圆或方框 |

## 平面布置图图例

| 名称 | 符号 |
|------|------|
| 高压开关柜 | 800×1500 矩形（正视图投影） |
| 变压器 | 1200×1000 矩形 |
| 低压开关柜 | 800×1500 矩形 |
| 电缆沟 | 虚线框 |
| 接地极 | 小圆点 |
| 通道 | 标注宽度箭线 |

## 图层设置建议

| 图层名 | 颜色 | 线宽 | 用途 |
|--------|------|------|------|
| 0-DEVICE | 白色(7) | 0.5mm | 设备轮廓 |
| 0-CABLE | 黄色(2) | 0.25mm | 电缆连线 |
| 0-DIM | 绿色(3) | 0.25mm | 尺寸标注 |
| 0-TEXT | 白色(7) | 0.25mm | 文字标注 |
| 0-GROUND | 棕色(24) | 0.35mm | 接地线 |
| 0-BORDER | 青色(4) | 0.5mm | 图框 |

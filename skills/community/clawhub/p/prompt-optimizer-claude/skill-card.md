## Description:

Professional-grade Claude prompt optimization engine that triggers when users submit raw prompts for optimization, refinement, or restructuring, or request prompt effectiveness, token savings, or output precision improvements.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

External users and developers use this skill to turn raw, ambiguous, or verbose prompts into structured Claude prompts for development, writing, product, design, operations, and data-analysis scenarios.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate on broad prompt-refinement requests and produce wording or constraints that change user intent.

Mitigation: Review the optimized prompt before using it, especially when exact wording, language, or constraints matter.

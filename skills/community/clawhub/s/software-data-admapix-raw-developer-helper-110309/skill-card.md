## Description:

Helps agent users, skill authors, maintainers, and teams plan, implement, and verify AdMapix-style software and data workflows for bug fixing, setup hardening, reliability work, and adjacent skill creation.

## Use Case:

External developers, agent users, skill authors, maintainers, and teams use this skill to turn AdMapix-style software and data needs into practical workflows, checklists, analysis, code changes, and verification steps. It is intended for local-friendly implementation support rather than cloud-only or large-training workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Implicit invocation is enabled with broad software and data keywords, so the skill may activate for requests that are not specifically about AdMapix-style workflows.

Mitigation: Narrow activation wording and keywords to AdMapix-specific phrases, and review proposed use before relying on the skill for unrelated software or data tasks.

Risk: The skill provides workflow guidance, checklists, code changes, shell commands, and configuration suggestions that may be incorrect or unsuitable for a user's environment.

Mitigation: Review outputs before execution and apply the included verification steps against the user's stated success criteria.

## Description:

Acts as a full-stack software development agent that plans, designs, builds, tests, and prepares production applications across frontend, backend, database, API, authentication, deployment, security, and observability work.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill to turn application ideas or product requirements into working full-stack software with SDLC planning, architecture, implementation, testing, CI/CD, deployment, security review, and operations guidance.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can influence stack choices, application structure, deployment workflows, secrets handling, and production automation.

Mitigation: Review generated deployment workflows, secrets handling, and production automation before running or merging them.

Risk: Broad full-stack guidance can produce recommendations that do not fit a specific product's compliance, security, reliability, or operational requirements.

Mitigation: Apply the included security checklist, testing guidance, observability guidance, and deployment review before production use.

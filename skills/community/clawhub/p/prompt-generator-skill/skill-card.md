## Use Case:

Employees, external users, developers, and content creators use this skill to turn task descriptions into structured prompts for AI writing, image generation, coding, learning, office, lifestyle, creative, and advanced prompt-engineering workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated prompts may include private work data, API credentials, scraping targets, or scheduled automation details when users provide those details.

Mitigation: Review and redact generated prompts before sharing them with external AI tools or using them in automated workflows.

Risk: Generated coding, scraping, or automation prompts may be reused without enough review for legality, safety, or operational impact.

Mitigation: Have a knowledgeable reviewer check generated technical prompts before using them to create code, run commands, scrape websites, or schedule recurring tasks.

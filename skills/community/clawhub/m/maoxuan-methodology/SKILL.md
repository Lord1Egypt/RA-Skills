# 毛选方法论 Skill

毛选是一座决策方法库：它的每一篇都在回答"力量处于劣势时，怎么看清局面、
怎么分配资源、怎么把事做成"。本 skill 把这套方法抽成**五个框架 + 十条心法
+ 一个输出模板**，全部原创转述、零版权风险；另附场景化金句库做引用收尾。

## 快速路由（先判场景，再选框架）

| 用户场景 | 用哪个框架 |
|---|---|
| 多线混乱、什么都想抓 | 框架1 矛盾聚焦法 |
| 要下结论但事实没摸清 | 框架2 调查前置法 |
| 钱少人多目标多，怎么打 | 框架3 兵力集中法 |
| 从零冷启动一个项目/账号/生意 | 框架4 根据地法 |
| 长期项目没起色、以弱对强 | 框架5 阶段判定法 |
| 只要一句金句收尾 | 直查 `references/quotes.md` |

可组合：拆一个生意通常 = 框架1 定主攻 → 框架3 定投入 → 框架4 定节奏。

## 五大分析框架

### 框架1 矛盾聚焦法（抓主要矛盾）

- 输入：多线并存的复杂局面（业务问题/生活决策/团队矛盾）。
- 步骤：
  1. 列出当前所有矛盾/问题，一条不漏；
  2. 逐条问："它若变化，全局会不会跟着变？"——会的是主要矛盾候选；
  3. 再问："它现在变了吗/正在变吗？"——排除还没到时机的；
  4. 选定一条为主要矛盾，其余挂起但**不允许溃败**（维持线）。
- 输出：主攻方向一句话 + 本阶段明确不做清单。
- ✅完成标准：能说出"为什么是它、为什么是现在"，且不做清单里至少有 2 条。

### 框架2 调查前置法（没有调查就没有发言权）

- 输入：任何待决策问题。
- 步骤：
  1. 把信息分成"已核实的事实 / 我以为的判断 / 完全未知"三栏；
  2. 对后两栏设计最小调查动作（看数据、问当事人、跑一次小实验）；
  3. 结论只能引用第一栏事实；调查做不了的，明说"这是假设"。
- 输出：事实清单 + 假设清单 + 下一步调查项。
- ✅完成标准：每句结论能指到一条证据；全文不出现无来源的"我以为"。

### 框架3 兵力集中法（集中优势兵力打歼灭战）

- 输入：资源有限（钱/时间/人）且目标不止一个。
- 步骤：
  1. 估算每个目标需要的"最小决胜投入"（低于它等于白打）；
  2. 找出唯一能形成**局部碾压**的单点（局部优势 3:1 以上）；
  3. 资源集中到该点，其余目标降到维持线或明确放弃。
- 输出：主战场一个 + 资源分配表。
- ✅完成标准：分配表里能指出一个局部碾压点；没有"每个都分一点"的平均主义。

### 框架4 根据地法（先求生存，再求发展）

- 输入：从零冷启动（新项目/新账号/新生意）。
- 步骤：
  1. 选一块"打得下、守得住、能自养"的最小阵地——一个细分人群、
     一个稳定出单的品、一个能持续更新的内容系列；
  2. 站稳标准量化（如：单品周出 N 单 / 系列周更 3 篇且搜索词进入前页）；
  3. 达标后复制扩张，不达标不扩张。
- 输出：根据地定义 + 量化站稳标准 + 扩张触发条件。
- ✅完成标准：能回答"哪块是我的根据地、它在自养吗、什么数据达标才扩张"。

### 框架5 阶段判定法（持久战三阶段）

- 输入：长期项目、以弱对强的竞争。
- 步骤：
  1. 判定当前阶段——防御期（对手强、我求生存）/ 相持期（互有攻守、
     拼积累）/ 反攻期（优势在我、可放大投入）；
  2. 阶段决定打法：防御期不决战、保存量、找杠杆；相持期磨优势、
     攒粮草；反攻期才集中放大；
  3. 每阶段定"阶段切换信号"（数据/形势变化点）。
- 输出：当前阶段判定 + 依据 + 该阶段打法 + 切换信号。
- ✅完成标准：阶段判定有证据支撑，且打法与阶段匹配（最忌防御期决战）。

## 十条心法（快速检查用，写方案时过一遍）

1. **具体问题具体分析**——不抄模板，先问"此情此景特殊在哪"（《矛盾论》引列宁语）
2. **敌友分析先行**——先列谁受益谁受损，别把中间派推到对面（《中国社会各阶级的分析》）
3. **战略上藐视，战术上重视**——判断上不怕，动作上不飘
4. **胸中有"数"**——没有数量级分析就没资格拍板（《党委会的工作方法》）
5. **学会"弹钢琴"**——多线并行不是平均用力，是有主旋律的配合（《党委会的工作方法》）
6. **自力更生基点**——方案的最坏假设里不包含"别人会救"（《抗日战争胜利后的时局和我们的方针》）
7. **不做绝对肯定/绝对否定**——任何判断留出可被证据推翻的口子（《学习和时局》）
8. **预言只给方向不给时刻**——规划给方向和里程碑，不定死日期再横跳（《星星之火，可以燎原》）
9. **到什么山上唱什么歌**——方法随场景变，先看山再开嗓（《反对党八股》）
10. **战争的伟力之最深厚的根源，存在于民众之中**——想不清楚时去问目标用户，答案在用户那里不在会议室（《论持久战》）

## Agent 工作流

1. **判场景**：对照快速路由表选出框架（一句话内部完成）。
2. **跑框架**：按选定框架的步骤逐步执行，多个框架时按"1→3→4"主序组合。
3. **按模板产出**（用户没指定格式时用这个）：

```
【矛盾清单】1. … 2. … 3. …
【主要矛盾】…（判定理由：…；为什么是现在：…）
【本阶段打法】做：…  不做：…  维持线：…
【调查缺口】下一步先查：…
【引一句】"…"（《篇名》）   ← 可选，从 quotes.md 按场景取
```

4. **收尾引用**：若用户内容/方案需要金句，查 `references/quotes.md`
   按场景取一条，必附出处，不曲解原意。
5. ✅完成标准：输出里"主要矛盾"和"不做清单"必须存在——没有主攻和取舍的
   方案等于没写。

## 引用与合规

- 方法论部分全部为**原创转述**，无版权风险。
- 原文引用只做**短引用**（单条 ≤100 字）+ 必附篇名出处，不整段搬运。
- **全文语料暂不入库**：毛选 2027-01-01 进入公有领域（作者 1976 年逝世 +
  50 年），届时可补全文本地检索；在那之前不给全文、不搬整篇。
- 内容平台使用注意：引句用于方法论/励志/复盘场景没问题；不做政治时评
  场景引用，不挪用原意拔高商业话术，金融类内容仍遵守投资建议红线。
- 本 skill 不做：全文语料包（2027 年前）、政治时评场景、曲解原意的
  鸡汤化改写。

## 本 skill 不做什么

- 不提供对历史事件的政治评价或立场判断——只抽方法，不碰时评。
- 不替代数据：框架1/3/5 的判定必须落在框架2 的事实之上，两者脱节的
  输出视为未完成。

# 运动系统神经系统定位诊断

## 适用场景

当患者出现以下任一情况时触发本技能：
- 肢体无力、瘫痪或肌力减弱
- 发音困难、发音不清、言语异常（语言能力 intact）
- 运动笨拙、不协调、平衡障碍、姿势步态异常

## 核心工作流程

### 步骤一：判断主要运动障碍类型

根据患者主诉和查体发现，确定属于以下哪类运动障碍：

| 主要表现 | 进入路径 |
|---------|---------|
| 肌力减退/瘫痪 | → 瘫痪定位（步骤二A） |
| 发音/言语异常 | → 构音障碍定位（步骤二B） |
| 运动不协调/平衡差 | → 共济失调定位（步骤二C） |

### 步骤二A：瘫痪定位——上 vs 下运动神经元

收集以下关键体征并对比：

**上运动神经元（UMN）特征组合：**
- 瘫痪分布：单瘫/偏瘫/交叉瘫/截瘫/四肢瘫，远端重于近端
- 肌张力：增高，折刀现象
- 腱反射：活跃/亢进，可有阵挛
- 浅反射：减退或消失
- 病理征：阳性（Babinski等）
- 肌萎缩：无或轻度失用性
- 肌束颤动：无

**下运动神经元（LMN）特征组合：**
- 瘫痪分布：以肌群为主
- 肌张力：减低或消失
- 腱反射：减弱或消失
- 病理征：阴性
- 肌萎缩：明显
- 肌束颤动：可有

**判定规则：**
- 折刀样肌张力增高 + 病理征阳性 + 腱反射亢进 → UMN
- 肌张力降低 + 腱反射消失 + 明显肌萎缩 + 肌束颤动 → LMN

### 步骤二B：构音障碍定位

根据言语特征和伴随体征定位病变层级：

| 言语特征 | 伴随体征 | 定位 |
|---------|---------|------|
| 辅音不清，发音/共鸣正常 | 对侧中枢性面舌瘫 | 单侧皮质脊髓束 |
| 鼻音/嘶哑/缓慢，辅音极不清 | 吞咽困难、强哭强笑、咽反射亢进 | 双侧皮质延髓束（假性延髓麻痹） |
| 缓慢含糊、声调低沉、颤抖样 | 唇舌肌张力高、震颤 | 基底核 |
| 爆发性/吟诗样、强弱不等 | 眼震、肌张力低 | 小脑（共济失调性） |
| 发音费力、声音强弱不等 | 肌张力低、相应脑神经体征 | 下运动神经元（弛缓性） |

### 步骤二C：共济失调定位

通过Romberg征和伴随症状进行四大分类鉴别：

**1. 小脑性共济失调：**
- 蚓部病变：头躯干不稳，上蚓部向前倒，下蚓部向后倒
- 半球病变：同侧肢体辨距不良、意向性震颤
- 言语：爆发性/吟诗样
- 眼震：粗大
- 肌张力：减低，钟摆样反射

**2. 大脑性共济失调：**
- 症状较小脑轻，对侧肢体受累
- 额叶：步态不稳 + 肌张力高/病理征/精神症状
- 顶叶：闭眼明显 + 感觉障碍

**3. 感觉性共济失调：**
- 核心：深感觉障碍
- 踩棉花感，闭眼/黑暗中加重
- 无眩晕/眼震/言语障碍

**4. 前庭性共济失调：**
- 核心：空间定向丧失
- 明显眩晕/恶心/呕吐/眼震
- 改变头位加重
- 四肢共济运动正常

### 步骤三：输出定位结论

综合以上分析，输出：
1. 病变类型（UMN/LMN/小脑/基底核/前庭等）
2. 具体解剖定位
3. 支持诊断的核心体征组合
4. 常见病因提示

## 注意事项

- 非神经源性瘫痪（肌源性、神经肌肉接头性）不适用UMN/LMN鉴别逻辑
- 失语症（语言形成/接受能力受损）不适用构音障碍分类
- 纯肌力减退引起的活动受限不适用共济失调分类

# 运动系统体征详细参考

## 一、上运动神经元性瘫痪详细特征

### 瘫痪分布特点
- 单瘫、偏瘫、交叉瘫、截瘫、四肢瘫
- 远端肌肉受累重（手/指/面），近端轻（双侧支配）
- 上肢：伸肌群 > 屈肌群，外旋 > 内收
- 下肢：屈肌群 > 伸肌群
- 双侧支配运动（眼/下颌/咽喉/颈/胸/腹）不受影响

### 特殊姿势
- 上肢：屈曲旋前
- 下肢：伸直内收

### 步态异常
- 痉挛性偏瘫步态：划圈样，上肢屈曲内收旋前，下肢伸直外旋画圈
- 痉挛性截瘫步态：剪刀样，双下肢伸直内收，足尖走路交叉前进

### 病理反射清单
- Babinski征
- Oppenheim征
- Gordon征
- Chaddock征

## 二、下运动神经元性瘫痪详细特征

- 肌肉松弛，外力牵拉无阻力
- 浅反射消失
- 明显肌萎缩，常有皮肤营养障碍
- 肌束颤动
- 肌电图：异常/有失神经电位

## 三、UMN vs LMN 完整对照表

| 特征 | 上运动神经元 | 下运动神经元 |
|------|------------|------------|
| 瘫痪分布 | 整个肢体为主 | 肌群为主 |
| 肌张力 | 增高（痉挛） | 降低（弛缓） |
| 浅反射 | 消失 | 消失 |
| 腱反射 | 增强 | 减弱/消失 |
| 病理征 | 阳性 | 阴性 |
| 肌萎缩 | 无/轻度失用性 | 明显 |
| 皮肤营养障碍 | 多数无 | 常有 |
| 肌束颤动 | 无 | 可有 |
| 肌电图 | 正常/无失神经电位 | 异常/有失神经电位 |

## 四、构音障碍详细分型

### 上运动神经元损害
- **单侧皮质脊髓束**：对侧中枢性面瘫和舌瘫，双唇和舌承担的辅音不清晰。见于单侧脑出血/梗死。
- **双侧皮质延髓束（假性延髓麻痹）**：咽喉/声带麻痹，说话带鼻音/嘶哑/缓慢。伴吞咽困难、饮水呛咳、咽反射亢进、强哭强笑。见于双侧多发性脑梗死、皮质下血管性痴呆、ALS、MS、PSP。

### 基底核病变
- 唇舌肌张力高、震颤，声带不能张开
- 说话缓慢含糊、声调低沉、发音单调、音节颤抖样融合、言语断节
- 见于帕金森病、肝豆状核变性

### 小脑病变（共济失调性）
- 构音含糊、音节缓慢拖长、声音强弱不等/爆发样
- 呈吟诗样/分节样
- 见于小脑蚓部梗死/出血、小脑变性病、MS

### 下运动神经元损害（弛缓性）细分定位
- **面神经**：影响唇音/唇齿音
- **舌下神经**：舌音不清，伴舌肌萎缩/震颤
- **迷走神经喉返支**：单侧→声音嘶哑/复音；双侧→吸气性哮鸣
- **迷走神经咽支/舌咽神经**：软腭麻痹，说话带鼻音
- **膈神经**：声音强度减弱，发音费力，语句变短
- 见于进行性延髓麻痹、GBS、脑干肿瘤、延髓空洞

### 神经肌肉接头及肌肉病变
- 表现类似下运动神经元，多伴其他肌肉无力
- 见于重症肌无力、肌营养不良、强直性肌病

## 五、共济失调详细评估要点

### 小脑性
- **蚓部**：头躯干共济失调，站立不稳，两腿分开
- **半球**：同侧肢体辨距不良、意向性震颤（越接近目标越明显）
- 精细运动障碍：书写变大/不匀
- 双眼粗大眼震，少数下跳/反弹性眼震
- 钟摆样腱反射

### 大脑性
- **额叶**：体位平衡障碍 + 肌张力高/病理征/精神症状
- **颞叶**：对侧共济失调 + 同向性象限盲/失语
- **顶叶**：对侧共济失调，闭眼明显 + 双下肢感觉性共济失调 + 大小便障碍
- **枕叶**：对侧共济失调 + 深感觉障碍/视觉障碍

### 感觉性
- 深感觉障碍（脊神经后根/脊髓后索/丘脑/顶叶损害）
- 踩棉花感，睁眼轻，闭眼/黑暗中重
- 无眩晕/眼震/言语障碍

### 前庭性
- 站立不稳，改变头位加重，行走向病灶侧倾倒
- 明显眩晕/恶心/呕吐/眼震
- 四肢共济运动及言语正常

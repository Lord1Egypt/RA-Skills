# 心境稳定剂监测方案

## 碳酸锂监测时间表

| 时间点 | 监测项目 |
|-------|---------|
| 基线 | 肾功能、甲状腺功能、心电图、血钠、妊娠试验 |
| 加量期 | 每周血锂浓度 |
| 稳定期 | 每3-6月血锂、肾功能、甲状腺功能 |
| 老年患者 | 每1-3月监测 |

### 血锂浓度解读

| 浓度（mmol/L）| 临床意义 |
|--------------|---------|
| 0.4-0.8 | 维持期目标 |
| 0.6-1.2 | 急性期目标 |
| 1.2-1.5 | 轻度中毒风险 |
| 1.5-2.0 | 中度中毒 |
| >2.0 | 重度中毒，需透析 |

### 锂中毒诱因
- 脱水、腹泻、呕吐
- 低盐饮食
- 合用NSAIDs、ACEI、利尿剂
- 肾功能下降

## 卡马西平/奥卡西平监测

| 项目 | 频率 |
|-----|------|
| 血常规 | 基线、每月×3月、之后每3-6月 |
| 肝功能 | 同上 |
| 血药浓度 | 达稳态后（约1周）|
| 血钠（奥卡西平）| 定期监测 |

## 拉莫三嗪皮疹风险分层

| 风险因素 | 风险程度 |
|---------|---------|
| 合用丙戊酸盐 | 高风险（2-3倍）|
| 起始剂量过高 | 高风险 |
| 加量过快 | 高风险 |
| 儿童患者 | 较高风险 |

### Stevens-Johnson综合征警示症状
- 发热伴皮疹
- 口腔/生殖器黏膜损害
- 皮肤水疱、剥脱
- 出现即停药并急诊处理

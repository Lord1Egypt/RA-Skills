# 癫痫发作分类、病因诊断与EEG分析

## 使用场景
当面对以下情况时应用本技能：
- 需要对患者的癫痫发作进行标准化分类
- 需要系统评估癫痫病因以指导靶向治疗
- 需要执行或解读脑电图诱发试验
- 需要识别癫痫样放电波形并辅助定位诊断

## 工作流程

### 步骤1：癫痫发作分类（ILAE 2017）
根据发作临床表现和EEG特征进行层级分类：
1. 全面性起源：最初症状学和EEG提示双侧脑部起源
2. 局灶性起源：源于大脑半球局部，按意识分为意识清楚/意识受损
3. 起源不明：病史、EEG及影像学无法明确

二级分类（运动/非运动症状）：
- 全面性运动：强直-阵挛、阵挛、强直、肌阵挛、失张力、癫痫性痉挛
- 全面性非运动：典型/非典型失神、肌阵挛失神、眼睑肌阵挛失神
- 局灶性运动：自动症、失张力、阵挛、过度运动性、肌阵挛、强直
- 局灶性非运动：自主神经性、行为中止、认知性、情绪性、感觉性

### 步骤2：GTCS与局灶性发作特征识别
GTCS三期识别：
- 强直期（10-20秒）：全身骨骼肌持续收缩、眼球上翻、尖叫、口吐白沫。EEG：10Hz棘波节律，频率降低波幅增高。
- 阵挛期：肌肉交替收缩松弛、频率渐慢。EEG：弥漫性慢波伴间歇性棘波。
- 发作后期（1-5分钟）：肌肉松弛、尿失禁、意识渐恢复、嗜睡。EEG：明显脑电抑制。

局灶性发作特殊表现识别：
- Jackson发作：异常运动沿皮质功能区传播，提示运动皮层病灶。
- 旋转性发作：双眼偏斜、头身扭转，提示额叶眼动区。
- 自动症：口消化道或手足无目的动作，提示颞叶/边缘系统。
- 自主神经症状：上腹不适、面色苍白，提示岛叶/丘脑/边缘系统。
- Todd瘫痪：发作后短暂肢体瘫痪，提示对侧运动皮层。

### 步骤3：病因学评估（ILAE 2017六大分类）
1. 结构性：皮质发育不良(FCD)、肿瘤、头外伤、脑血管病。
2. 感染性：脑膜炎、脑炎、神经梅毒、寄生虫感染。
3. 遗传性：离子通道基因异常（如Dravet综合征SCN1A突变）。
4. 代谢性：缺血缺氧性脑病、尿毒症脑病、甲状旁腺功能减退等。
5. 免疫性：自身免疫性脑炎（抗NMDAR、抗LGI1）、桥本脑病。
6. 不明原因。
注意：病因分类可重叠。

### 步骤4：EEG诱发试验执行与波形识别
诱发试验规范：
- 睁闭眼：睁眼5秒，闭目5-10秒，重复2-3次。
- 过度换气：20-25次/分，持续3分钟。若出现癫痫样放电或临床发作应立即停止。
- 闪光刺激：眼前20-30cm，间断刺激10-20秒。
- 睡眠诱发：自然或药物，记录>20分钟。

癫痫样放电波形识别要点：
- 棘波：20-70ms，顶端尖、负相为主、上升支陡峭。
- 尖波：70-200ms，类似棘波、波幅100-200μV。
- 3Hz棘慢波综合：一棘波继一慢波，提示典型失神发作。
- 多棘波/多棘慢复合波：≥2个高幅双相棘波节律性出现，提示肌阵挛/强直-阵挛发作。
- 高幅失律：高波幅尖/棘波后电静止，见于婴儿痉挛。

## 输出要求
完成评估后输出：
1. 发作类型诊断：标准化分类结果
2. 病因分类：明确的病因类别及重叠情况
3. EEG解读：癫痫样放电类型、病灶定位提示
4. 治疗建议方向：基于病因的靶向治疗提示

# 正常脑波频率与分布参考

## 基本节律
- α波：8-13Hz，20-100μV，枕/顶部为主，安静闭目时最明显
- β波：14-25Hz，5-20μV，额/颞叶为主，觉醒、精神活动时
- θ波：4-7Hz，前部少量，困倦、儿童可见较多
- δ波：<4Hz，清醒时无，入睡由浅入深增多

## 异常判读要点
- 局灶性慢波：提示局部脑损害
- 弥漫性慢波：提示弥漫性脑功能障碍
- 不对称反应：提示不对称性脑损害

# 癫痫六大病因分类详细参考

## 1. 结构性病因
- 皮质发育不良(FCD)：FCDⅠ型多在颞叶，FCDⅡ型多在额叶，是药物难治性癫痫常见病因。
- 肿瘤：4%的癫痫由肿瘤所致，脑瘤患者中癫痫发病率为35%。
- 头外伤：外伤1周后出现的癫痫，发病率5%～7%。
- 脑血管疾病：发病2周后出现的癫痫，恢复期反复发作机会>80%。

## 2. 感染性病因
结核性/化脓性脑膜炎、病毒性脑炎、神经梅毒、中枢神经系统寄生虫感染。

## 3. 遗传性病因
多与离子通道基因异常有关。经典例子：Dravet综合征>80%有SCN1A致病性突变。

## 4. 代谢性病因
- 缺血缺氧性脑病：约6%发生癫痫。
- 尿毒症脑病：1/3在急性期或慢性肾衰竭时出现。
- 甲状旁腺功能减退：30%～50%出现癫痫。

## 5. 免疫性病因
自身免疫性脑炎（如抗NMDAR、抗LGI1脑炎）、桥本脑病、神经精神狼疮。确定免疫病因对靶向免疫治疗意义重大。

## 6. 不明原因
部分病因尚不明确。注意：病因分类可重叠。

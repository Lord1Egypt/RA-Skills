## Description: <br>
EasyEDA PCB helps agents inspect and modify EasyEDA PCB documents through the easyeda-agent CLI or daemon, including schematic import, component layout, routing primitives, copper pours, and DRC checks. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and PCB engineers use this skill to operate on live EasyEDA PCB documents, inspect board state, import schematic changes, place components, create basic routing and pours, and verify changes with readback and DRC checks. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The external easyeda-agent installer is fetched with curl and piped to sh. <br>
Mitigation: Review and trust the installer source before installation. <br>
Risk: The skill can direct an agent to modify live PCB documents, including destructive or bulk changes. <br>
Mitigation: Keep confirmation guardrails on for deletes, schematic imports, bulk layout changes, saving, and debug execution paths. <br>
Risk: PCB edits can be hard to reverse because the artifact notes there is no programmatic undo. <br>
Mitigation: Record before and after state, use fresh primitive IDs before mutation, and verify changes with readback and DRC checks. <br>

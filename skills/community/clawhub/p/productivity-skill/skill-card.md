## Use Case:

Individuals and teams use this agent skill as an AI productivity coach to assess energy, prioritize tasks against goals, manage calendar and list context, and run daily review loops. It supports local memory-backed personalization only after user consent.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may save goals, preferences, custom rules, inbox captures, task logs, and daily events in local memory files.

Mitigation: Decline memory writes for session-only use, and review, edit, or delete MEMORY.md and daily notes when needed.

Risk: The skill can propose reminders for calendar events and daily reviews.

Mitigation: Confirm reminder details before any schedule action is created.

Risk: The skill includes YiXiaoNeng resource or course suggestions after praise or requests to learn more.

Mitigation: Treat those recommendations as promotional learning resources and continue normal use without following them when they are not relevant.

## Description:

Generate React components that render FOSMVVM ViewModels. Scaffolds ViewModelView pattern with hooks, loading states, and TypeScript types.

This skill is ready for commercial/non-commercial use.

## Publisher:

[foscomputerservices](https://clawhub.ai/user/foscomputerservices)

### License/Terms of Use:


## Use Case:

Developers and engineers use this skill to scaffold React views and Jest/React Testing Library tests for FOSMVVM ViewModels, including display, interactive, list, and form components.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generic generated templates may use incorrect ServerRequest names, form fields, or operation bindings for a specific project.

Mitigation: Review generated React component and test files before committing, and align them with the actual ViewModel and ServerRequest contracts.

## Description:

Find and install the current canonical AgentPMT skills published under the AgentPMT ClawHub org account.

This skill is ready for commercial/non-commercial use.

## Publisher:

[firef1ie](https://clawhub.ai/user/firef1ie)

### License/Terms of Use:

MIT-0

## Use Case:

Agents and developers use this index skill to find the current AgentPMT setup, payment, overview, and product skills on ClawHub and choose the correct install or handoff path.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The index can become stale after its documented freshness date.

Mitigation: Verify the AgentPMT ClawHub publisher page before relying on the listed skills when more than 7 days have passed since 2026-06-09.

Risk: Install commands could add other skills to an agent environment.

Mitigation: Treat install commands as user-directed actions and review the linked skill pages before installation.

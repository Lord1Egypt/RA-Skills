# 补能可行性与实际续航

本页解决两个购车高频问题：**我家能不能装桩、装了多少钱**，以及**冬天／高速实际能跑多远**。资料里没有本车型的实测数据，所以这里给的是核验方法，不是臆造的数字。

## 一、家充可行性：四关

装桩卡在四件事上，缺一件就装不成。按顺序问：

| 关卡 | 要确认什么 | 谁负责 |
|---|---|---|
| 车位 | 产权车位／长租车位（租期是否覆盖）、是否有固定车位证明 | 用户 + 物业 |
| 物业 | 是否同意施工、是否要求指定施工方、是否收取管理费 | 物业 |
| 电力 | 电表容量余量、是否需单独报装、是否需增容（费用差异大） | 供电公司 |
| 施工 | 走线距离、是否需开槽／穿墙／立杆、是否需消防审批 | 施工方现场勘察 |

常见费用结构（**金额因城市、距离、施工难度差异很大，本库无数据，须现场报价**）：

- 赠送桩：多为随车赠送的基础充电桩设备，不等于免费安装。
- 基础安装：常含一定米数内的线缆与人工，超出部分按米计。
- 增项：超米数线缆、开槽破路、立柱基础、配电箱改造、旧表迁移、物业配合费。

规则：**未勘察不得承诺"可以装""免费装"**。赠送桩也不等于全免。

## 二、公共补能：算时间成本，不只算电费

用户真正关心的是"每周要花多少时间去充电"。要给三个数：

1. **单次可用性**：单位／家附近快充的距离、是否需要绕路、是否常排队。
2. **单次时间**：快充 30–80% 的标称时间（本库数据：C10／C16 约 16 分钟，C11 纯电约 16 分钟、增程约 18 分钟），加上往返与排队，才是真实时间。
3. **每周次数**：周里程 ÷ 单次实际补能里程。

注意：标称快充时间是**特定条件**下的数据（桩功率、温度、SOC 区间），实际会变慢。不得把它当作任何桩、任何天气都能达到。

## 三、实际续航：只谈条件，不谈折扣

**禁止统一打折**（如"冬天打七折""高速打六折"）。同一台车在不同条件下的差异极大，一个折扣系数会误导决策。

影响续航的五个条件，缺一个就不能给区间：

| 条件 | 为什么重要 |
|---|---|
| 环境温度 | 低温电池活性下降 + 空调制热耗电 |
| 平均车速 | 高速风阻随速度平方增长 |
| 载重与乘员 | 满载与空载差异明显 |
| 空调／座椅加热使用 | 制热比制冷更耗电 |
| SOC 区间 | 只充到 80% 与充满，可用里程不同 |

本库只有 CLTC 与 WLTC 标称值，**没有任何本车型的实测续航数据**。因此：

- 用户问"能不能稳跑 X 公里" → 明确回答：没有实测依据，不能承诺。
- 需要给参考时，只能给"方法 + 需核实的信源"：同车型车主在相同气温与路况下的实测、权威冬季测试、试驾车表显数据。
- 若用户坚持要区间，必须同时列出上述五个条件的具体取值，并标注"粗估，非实测"。

## 四、长途补能估算方法

能算的是**次数**，不是**续航**。步骤：

1. 问清单程距离、出发 SOC、途中可接受的最低 SOC（建议不低于 20%）、沿途快充桩间距。
2. 用用户自己或同车型在相似条件下的实际续航（不是 CLTC）做除数。
3. 补能次数 = ⌈(单程距离 − 出发可用里程) ÷ 单次有效补能里程⌉。
4. 结果必须带假设清单，且说明"到站剩余电量不做承诺"。

## 五、回答边界

- 不承诺实际续航、不承诺到站电量、不承诺充电桩一定能装。
- 不用 CLTC 数值回答"冬天能跑多远"。
- 不用一个折扣系数替代条件说明。
- 涉及电池安全（过热、鼓包、异常掉电）时，转安全流程，不做远程判断。

## Description:

Create or revise complete offline multi-screen wireframes and page-flow prototypes with Vue 3 Global Build, multi-file JavaScript screens, no build step, no Node dependency in the deliverable, and direct file:// opening.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, product managers, and designers use this skill to generate or revise offline multi-screen wireframes, page-flow prototypes, and interactive product demos that remain editable by an AI agent. It is suited for mobile app flows, desktop admin tools, mini-program flows, and visual-reference reconstruction where the deliverable must open directly from local files.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Validation and screen loading can execute JavaScript from a wireframe project, which is risky for projects from untrusted sources.

Mitigation: Use the skill only with projects generated by the agent or otherwise trusted; review project sources before opening or validating external wireframes.

Risk: Arbitrary screen script paths could load code outside the intended local screen files.

Mitigation: Keep screen.source values restricted to local src/screens files and verify project configuration before running checks or opening a prototype.

Risk: Development dependency installation may use a pinned Playwright version flagged by the security guidance.

Mitigation: Avoid installing development dependencies unless needed, or update Playwright before using development tooling.

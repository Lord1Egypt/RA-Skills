# 脊髓灰质炎灭活条件与免疫衰减详解

## 灭活条件速查表

| 灭活方式 | 具体条件 |
|---------|---------|
| 热力 | 56℃ 30分钟以上 |
| 紫外线 | 照射1小时 |
| 含氯消毒 | 0.05mg/L水作用10分钟 |
| 甲醛 | 有效灭活 |
| 2%碘酊 | 有效灭活 |
| 氧化剂 | 有效灭活 |

## 病毒抵抗力
- ✅ 耐酸
- ✅ 耐乙醚
- ✅ 耐乙醇
- ✅ 污水/粪便中存活数月
- ✅ -70℃保存数年

## 母传抗体衰减时间线

```
出生 → 母传IgG/IgA存在（保护期）
  ↓
6个月 → 母传抗体逐渐消失（发病率开始增高）
  ↓
5岁后 → 发病率降低（自然感染获得免疫）
```

## 发病机制流程图

```
口咽/消化道
    ↓ 病毒复制
淋巴组织
    ↓
第一次病毒血症 ──→ 被清除 → 顿挫型感染
    ↓ 未被清除
全身淋巴/组织增殖
    ↓
第二次病毒血症
    ↓ 毒力强/抗体不足
突破血脑屏障
    ↓
中枢神经系统（脊髓前角运动神经元）
    ↓
瘫痪（颈/腰段最重，散在、不对称、多发）
```

## 瘫痪高危诱因清单
- [ ] 过度疲劳
- [ ] 剧烈运动
- [ ] 肌内注射
- [ ] 扁桃体摘除术
- [ ] 遗传因素

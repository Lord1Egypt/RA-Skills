## Description:

Helps AI-agent users and skill maintainers create practical SkillScan-style workflows for bug fixes, setup hardening, reliability improvements, and adjacent skill development.

This skill is ready for commercial/non-commercial use.

## Use Case:

AI-agent users, skill authors, maintainers, and teams use this skill to turn security and work-productivity needs into local-friendly workflows, checklists, templates, analysis, or implementation support for bug fixes, setup hardening, and reliability improvements.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad trigger wording may select the skill for loosely related security or bug-fix prompts.

Mitigation: Invoke it with explicit task scope and success criteria, or narrow platform invocation rules when a more specialized skill should handle the request.

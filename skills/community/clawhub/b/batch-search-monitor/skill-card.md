## Description:

Batch Search Monitor helps agents configure recurring keyword searches, result-change alerts, and search data exports.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and market or brand monitoring teams use this skill to create scheduled keyword search monitors, receive alerts when results change, and export search data for competitive tracking, brand mention tracking, public-opinion alerts, market research, and data collection.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The install instructions use a mutable remote npm installer.

Mitigation: Review installer provenance before installing, avoid administrator privileges, and prefer a pinned ClawHub installer version when available.

Risk: Scheduled monitors, notifications, and exports may retain or disclose monitored search data.

Mitigation: After installation, verify what monitor tasks are created and how notification outputs and exported data are stored.

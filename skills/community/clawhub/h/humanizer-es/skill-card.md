## Description:

Humanizer-es helps agents review and rewrite Spanish AI-generated text so it sounds more natural while preserving meaning and tone.

This skill is ready for commercial/non-commercial use.

## Publisher:

[mattc95](https://clawhub.ai/user/mattc95)

### License/Terms of Use:

MIT-0

## Use Case:

External users, writers, editors, and developers use this skill in an agent to identify AI-writing patterns in Spanish drafts and rewrite them with more natural wording while keeping meaning and tone.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: An unpinned npx install command can retrieve code that changes after review.

Mitigation: Install from a reviewed tagged release or pinned commit, and avoid elevated privileges during installation.

Risk: The skill edits user-provided text, which may contain sensitive or confidential content.

Mitigation: Use it only on text the user is comfortable letting the agent read and edit.

Risk: Humanizing AI-generated text can obscure authorship or disclosure expectations in regulated, academic, or platform-governed settings.

Mitigation: Apply the skill only where rewriting is permitted, preserve the original meaning, and follow any applicable disclosure rules.

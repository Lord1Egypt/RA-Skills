## Description:

Book pressure-washing services through Lokuli MCP by searching providers, checking availability, and creating bookings.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and agents use this skill to find pressure-washing providers, check availability, and create a booking through Lokuli after confirming contact and appointment details.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may send personal contact details and booking preferences to Lokuli's external booking service.

Mitigation: Confirm user consent and the exact provider, service, time slot, name, email, phone number, and ZIP code before creating a booking.

Risk: The activation scope is broad for pressure-washing requests.

Mitigation: Use the skill only when the user clearly asks to find or book pressure-washing services, and confirm intent before taking booking actions.

## Description:

Helps software maintainers, QA engineers, contributors, and product teams plan, add, and validate useful unit tests that improve coverage and reduce regression risk.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, software maintainers, QA engineers, open-source contributors, and product teams use this skill to create practical unit-test plans, implementation steps, checklists, code changes, and verification commands for existing codebases.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate on broad testing or code-quality requests.

Mitigation: Confirm the intended testing scope before accepting plans, code changes, or commands.

Risk: Generated tests, code changes, or shell commands may not match the repository's behavior or constraints.

Mitigation: Review proposed changes and run the repository's normal test and verification commands before merging.

## Known Risks and Mitigations:

Risk: Setup guidance includes sudo package installation, package removal, and user group changes.

Mitigation: Review each command before execution and verify the target Raspberry Pi model, package conflict, and user account before changing system packages or groups.

Risk: Incorrect wiring or direct motor connections can damage GPIO hardware or connected components.

Mitigation: Use current-limiting resistors for LEDs, avoid applying 5V to 3.3V GPIO inputs, and use a motor driver or controller board for motors.

Risk: Software-timed servo control can jitter and is not suitable for precise or long-term control.

Mitigation: Use hardware PWM or a dedicated servo or motor controller when precision or reliability is required.

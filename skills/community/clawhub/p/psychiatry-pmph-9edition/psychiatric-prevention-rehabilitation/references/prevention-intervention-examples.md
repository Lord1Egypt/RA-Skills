# 预防干预项目设计示例

## 一级预防项目示例

### 学校心理健康教育项目
**目标人群**：中小学生
**干预内容**：
- 情绪管理课程（每周1课时）
- 压力应对技能训练
- 同伴支持计划
- 教师心理健康培训
**评估指标**：心理健康素养得分、求助行为比例

### 企业EAP项目
**目标人群**：企业员工
**干预内容**：
- 心理健康热线
- 短程心理咨询（6-8次）
- 压力管理工作坊
- 管理者培训（识别员工心理问题）
**评估指标**：员工满意度、缺勤率、离职率

## 二级预防项目示例

### 产后抑郁筛查项目
**目标人群**：产后6周内妇女
**干预流程**：
1. 产后42天常规EPDS筛查
2. 评分≥13分转介精神科
3. 高危人群（既往抑郁史）主动随访
**评估指标**：筛查覆盖率、转介率、治疗率

### 青少年抑郁早期识别
**目标人群**：初中/高中学生
**干预流程**：
1. 每学期PHQ-9筛查
2. 阳性者心理教师访谈
3. 中度以上转介专科
4. 建立追踪档案
**评估指标**：识别率、转介率、早期治疗率

## 三级预防项目示例

### 严重精神障碍社区康复
**目标人群**：社区在册严重精神障碍患者
**服务内容**：
- 定期随访（稳定期每3月1次）
- 服药指导
- 康复活动组织
- 危机干预
- 家属支持
**评估指标**：复发率、再住院率、社会功能评分

### 辅助就业项目
**目标人群**：病情稳定、有就业意愿的精神障碍康复者
**服务流程**：
1. 职业能力评估
2. 职业技能培训
3. 岗位匹配与试工
4. 就业辅导员跟踪支持
5. 雇主教育与协调
**评估指标**：就业率、就业保持率、工作满意度

## 危机干预项目

### 自杀预防热线
**运营模式**：
- 24小时接听
-  trained志愿者+专业督导
- 危机评估（风险评估量表）
- 必要时联动110/120

### 灾后心理援助
**阶段干预**：
| 时间 | 干预重点 |
|-----|---------|
| 即刻（0-48h）| 心理急救、安全感建立 |
| 短期（1-4周）| 情绪稳定、正常化反应 |
| 中期（1-6月）| 筛查PTSD、提供治疗 |
| 长期（>6月）| 持续支持、转介治疗 |

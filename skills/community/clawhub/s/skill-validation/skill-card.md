## Description:

Provides a checklist for validating ClawHub skill structure, metadata, security, content quality, and publishing readiness.

This skill is ready for commercial/non-commercial use.

### License/Terms of Use:

## Use Case:

Developers and skill publishers use this skill to review new or existing ClawHub skill folders before editing, publishing, or deployment.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Malformed frontmatter description and metadata inconsistency may prevent predictable parsing or activation.

Mitigation: Fix the frontmatter description and align metadata before relying on the skill in production workflows.

Risk: Skill validation checklists can produce incomplete or misleading review guidance if used without human review.

Mitigation: Review the checklist outcome and scan the target skill before deployment.

## Description:

Guides agents in optimizing website images for search visibility, accessibility, responsive delivery, and performance-sensitive contexts such as LCP.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kostja94](https://clawhub.ai/user/kostja94)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, content teams, and SEO practitioners use this skill to generate image SEO, accessibility, format, responsive image, lazy-loading, sitemap, and preferred-image recommendations for web pages.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate on broad image-related requests and provide SEO, accessibility, or performance advice that is not specific to the user's site.

Mitigation: Review recommendations against the target page context, image purpose, and current search-engine guidance before publishing changes.

Risk: Generated markup or configuration snippets could be copied into production without adapting URLs, dimensions, formats, or alt text.

Mitigation: Validate snippets with site-specific assets, accessibility review, and performance testing before deployment.

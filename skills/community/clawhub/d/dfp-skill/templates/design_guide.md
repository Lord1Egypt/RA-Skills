## 一、画布尺寸

### 标准尺寸

| 用途 | 宽度 × 高度 | 比例 | 说明 |
|------|-------------|------|------|
| **标准发布会** | 1920 × 1080 px | 16:9 | 全高清屏幕推荐 |
| **超宽屏发布会** | 3840 × 1080 px | **3.55:1** | 展会/路演大屏，横向承载量是普通屏1.8倍 |
| **超宽屏（简约）** | 3200 × 1080 px | **2.96:1** | 3:1 比例，大多数商业屏可用 |
| **普通宽屏** | 1680 × 1050 px | 16:10 | Mac 屏幕比例 |

**建议**: 
- 一般企业发布会 → 1920×1080 (16:9)
- 大型展会/LED大屏 → **3200×1080 (3:1) 或 3840×1080 (3.55:1)**
- 超宽屏适合横向三段式布局（左背景信息 → 中核心视觉 → 右延伸数据）

## 二、字体规范

### 中文字体推荐（多级别体系）

| 级别 | 字体 | 字重 | 字号 | 用途 |
|------|------|------|------|------|
| Lv1 封面主标题 | 思源黑体 / 苹方 | Heavy(900) | **88-120pt** | 封面大标题、金句 |
| Lv2 章节标题 | 思源黑体 / 苹方 | Bold(700) | **48-64pt** | 内容页标题 |
| Lv3 卡片标题 | 思源黑体 / 苹方 | Bold(700) | **28-36pt** | 卡片/区块小标题 |
| Lv4 正文 | 思源黑体 / 苹方 | Regular(400) | **18-22pt** | 段落文字、要点列表 |
| Lv5 小字/备注 | 思源黑体 / 苹方 | Light(300) | **12-14pt** | 脚注、来源、标签 |

### 数字/英文特殊样式

| 样式名 | 字体 | 字重 | 字号 | 用途 |
|--------|------|------|------|------|
| **超级数字** | SF Pro Display / DIN | Heavy(900) | **60-120pt** | 放大数据、百分比 |
| 年份数字 | SF Pro Display | Bold(700) | 36-48pt | 时间轴上的年份 |
| 数据标签 | SF Pro Text | Regular(400) | 14-18pt | 图表中的数据标签 |

### 字重规则

- **标题必用 Bold 以上**（700+），避免单薄
- **正文 Regular**，保持阅读舒适度
- **数字用 Heavy/Black**（800+），强化视觉重点
- **同一演示文稿使用不超过2款字体**

### 字间距与行高

- 标题字间距（tracking）：**+50 到 +100**（略收紧）
- 正文字间距：**0**（标准）
- 标题行高：**1.0-1.2**
- 正文行高：**1.3-1.5**
- 列表项间距：**0.5 行**

### 配色规则（重要！）

- **70/20/10 原则**: 70% 主背景 + 20% 辅色（文本） + 10% 强调色
- **单张幻灯片强调色不超过 3 种**（不含白/灰）
- **保持一致性**: 同一演示文稿同一配色方案
- **金色(#F2B84B) 只用于装饰/序号**，不用于正文，以免影响可读性
- **红色(#B8003A) 用作边框/警示**，不用于大段文字
- **深蓝卡片底避免纯黑文字**，用白色

## 四、版式与布局

### 布局类型库（按用途选择）

| 布局类型 | 适用场景 | 说明 |
|----------|---------|------|
| **封面型** | 封面/结尾页 | 全图背景 + 居中大标题 + 金色光带 + 人群剪影 |
| **三栏并列卡片** | 背景/动因/3大要点 | 3-4张等宽卡片，每张带图标+标题+2行要点 |
| **左对比图 + 右矩阵** | 现状对比/问题分析 | 左侧金字塔/对比图，右侧 2×2 或 2×4 图标矩阵 |
| **横向时间轴** | 产品演进/历史/里程碑 | 从左到右时间线，节点为圆形，年份在节点顶部 |
| **中央环形架构图** | 平台/生态/AI架构 | 中心主题 + 多层圆环 + 周围 6-8 个功能图标 |
| **流程节点箭头图** | 自动化流程/端到端 | 圆形节点 + 连接箭头，节点顶部标注步骤名 |
| **四象限功能矩阵** | 产品功能全景 | 2×2 网格，每象限大图标 + 4-6 小图标要点 |
| **RPA Before/After 对比** | 效率提升/流程优化 | 上下两条流程条对比，上繁下简，中间数字提升 |
| **产品案例双栏** | 客户案例/成功故事 | 左问题描述 + 数字，右产品界面截图 + 要点 |
| **Dashboard 深色数据** | 数据展示/KPI | 深蓝底 Dashboard 截图 + 金色高亮关键数字 |
| **六边形蜂群矩阵** | 要素/能力/场景展示 | 中心主题圆 + 周围 6-8 六边形，涟漪式排布 |
| **图文混排色块+图片** | 愿景/战略主题 | 左大号文字色块 + 右产品图片叠加文字 |
| **四步流程卡** | 方法论/实施路径 | 横向 4 张卡片，带序号 + 步骤名 + 描述 |
| **数字总结矩阵** | 成果/效益/总结 | 4张卡片 2×2 排布，左上大数字 + 右下说明 |

### 页边距与留白（按比例）

| 元素 | 标准屏 (16:9) | 超宽屏 (3:1) |
|------|-------------|------------|
| 顶部标题区 | 15-20% 高度 | 15-20% 高度 |
| 内容区 | 60-70% 高度 | 60-70% 高度 |
| 上下边距 | 8-10% | **8-10%** |
| 左右边距 | 8-10% | **6-8%**（因宽度大，边距比例略小） |
| 内容密度 | 65-70% 内容 | 70-75% 内容 |
| 卡片间间距 | 30-40px | **20-30px** |

## 五、卡片化信息承载（SAP风格核心）

### 标准卡片规格

```
┌───────────────────────────────────────────────┐
│  卡片标题（白色28-36pt Bold）                   │  ← 白色标题条
├───────────────────────────────────────────────┤  ← 红色分隔线 10px
│                                               │
│  卡片正文（白色18-22pt）                       │
│  • 要点 1                                      │
│  • 要点 2                                      │
│  • 要点 3                                      │
│                                               │
│  （可选）图标 / 截图 / 小数字                    │
│                                               │
└───────────────────────────────────────────────┘
       ↑ 10px 深红色(#B8003A)边框
       ↑ 20px 圆角
       ↑ 内部填充 #0F2050 深蓝
```

### 卡片类型库

| 卡片类型 | 内容结构 | 推荐用途 |
|---------|---------|---------|
| **要点卡** | 标题 + 3-5条要点列表 | 背景、动因、方案说明 |
| **数字卡** | 大数字(60-120pt金/白) + 单位 + 说明 | KPI、成果、效益 |
| **图标卡** | 顶部图标 + 标题 + 2行描述 | 功能要素、能力矩阵 |
| **流程图卡** | 横向箭头 + 2-4个节点 | 流程、演进、步骤 |
| **对比卡** | 上下两栏 Before/After 对比 | 优化前后、效率提升 |
| **界面卡** | 软件界面截图 + 底部标签 | 产品展示、案例 |
| **时间节点卡** | 顶部年份 + 产品名 + 缩略图 | 时间轴节点 |

### 卡片排版规则

1. **单行/单列卡片不超过6行文字**
2. **每张卡片字数控制在 30-80 字**
3. **同页卡片视觉高度一致**（不允许参差不齐）
4. **卡片边框颜色固定为 #B8003A**（与品牌色统一）
5. **卡片标题始终在顶部白色区域**，不随意移动

## 六、装饰元素规范

### 装饰元素清单

| 元素 | 颜色/样式 | 使用场景 | 注意事项 |
|------|----------|---------|--------|
| **金色横向光带** | #F2B84B 线性渐变，横向贯穿屏幕中下部 | 封面、封底、总结页的**地平线感**装饰 | 透明度 60-80%，不喧宾夺主 |
| **人群剪影** | 黑色/深红半透明 | 全稿底部 footer，形成统一节奏感 | 高度占屏幕 8-12% |
| **烟花放射光斑** | 金色→白色径向渐变 | 封面中心、大数字周围 | 透明度 40-60% |
| **角落光晕** | 蓝/红→透明径向渐变 | 左上+右上角落，增加氛围感 | 大面积但低透明度 |
| **圆形编号徽标** | 金色圆底 + 白色数字 | 步骤编号、要点序号 | 直径 60-80px |
| **细红线卡片边框** | #B8003A 10px 描边 + 20px 圆角 | 所有内容卡 | 10px 是视觉关键 |
| **箭头连接线** | 青色(#25B7E0)或金色 | 流程、时间轴 | 10-15px 粗度 |

### 装饰元素使用规则

- **每页不超过3种装饰元素**
- **金色光带**仅用于封面、章节页、总结页，不用于普通内容页
- **人群剪影**可以每页都有（但需要在最底层，不可遮挡内容）
- **装饰元素始终在视觉最底层**（send to back）

## 八、动画与过渡效果

### 推荐过渡效果

| 效果名称 | 适用场景 | 时长 |
|---------|---------|------|
| **渐隐 (Fade)** | 普通页切换 | 0.5-0.8s |
| **神奇移动 (Magic Move)** | 产品展示、连续故事、前后对比 | **0.8-1.2s** |
| **推移 (Push)** | 流程/时间轴/章节切换 | 0.6-1.0s |
| **无效果** | 快速切换、纯信息页 | 0s |

### 推荐的动画效果（进入/出现）

| 效果名称 | 适用元素 | 时长 |
|---------|---------|------|
| **渐入 (Fade In)** | 文本、图标、卡片 | 0.4-0.6s |
| **从下向上移入 (Move In)** | 重点内容、卡片序列 | 0.5-0.8s |
| **缩放出现 (Scale)** | 数字、图标、KPI | 0.3-0.5s |
| **绘制线条 (Line Draw)** | 流程图连接线、时间轴 | 0.8-1.5s |
| **依次出现（序列）** | 三栏卡片、要点列表 | 每张 0.2s 间隔 |

### 数字动画（推荐）

- **数字滚动 (Counter)**：从 0 滚动到目标数字（金色数字尤其推荐）
- **延迟出现**：标题先出现 → 0.3s后图表 → 0.5s后数字高亮
- **神奇移动**: 前一页的数字/元素后一页发生位置/大小变化，用 Magic Move 过渡

### 动画节奏规范

- **单张幻灯片动画不超过 3 组**（避免花哨）
- **总动画时长 < 1.5 秒**（观众注意力有限）
- **每组动画间隔 0.2-0.3 秒**
- **文字始终先于图形出现**（信息优先于视觉）
- **每页讲解时间: 45-90 秒**（配合1.5秒动画）

## 九、图片规范

### 图片质量

| 类型 | 最小分辨率 | 格式 | 文件大小 |
|------|-----------|------|---------|
| 全页背景图 | 3840 × 2160 (4K) | PNG / JPG | < 3MB |
| 产品展示图 | 1920 × 1080 | PNG (透明背景) | < 1MB |
| 界面截图 | 原尺寸即可 | PNG | < 500KB |
| 图标/装饰 | 矢量 SVG 优先 | SVG / PNG | < 100KB |

### 图片处理规则

- **产品图**: 白色或透明背景 PNG，居中放大到合适尺寸
- **风景图**: 加 20-40% 透明度黑色蒙层，确保文字可读
- **界面截图**: 添加圆角(20px) + 深色卡片边框 + 10px 阴影
- **避免拉伸低分辨率图片**: 宁可缩小也不拉伸模糊

## 十一、Keynote 母版设置建议

### 建议的母版幻灯片（Master Slides）清单

| 母版名称 | 用途 | 元素 |
|---------|------|------|
| **封面** | 产品/主题封面 | 全图渐变背景 + 光带 + 居中标题框 |
| **标题+正文** | 通用内容页 | 顶部标题区 + 自由内容区 |
| **三栏卡片** | 背景/要点/方案 | 三张并排红色边框卡片模板 |
| **时间轴** | 产品演进/历史 | 横向箭头 + 5个节点圆模板 |
| **环形架构** | 生态/平台 | 中心圆 + 双层圆环 + 8个外围点 |
| **Dashboard** | 数据展示 | 4个KPI卡框架 + 2个图表区 |
| **六边形矩阵** | 要素/能力 | 中心主题圆 + 7个六边形位 |
| **四象限** | 功能全景 | 2×2 网格图标位 |
| **四步流程** | 方法论/路径 | 横向4张序号卡 |
| **总结矩阵** | 成果/总结 | 2×2 大数字卡 |
| **Thank You** | 结尾页 | 与封面同款背景 + 极简标题 |

### 母版设置要点

1. **固定背景**：背景图、渐变底、光带都放在母版里，避免每页重复添加
2. **固定页脚**：人群剪影放母版最底层
3. **品牌色锁定**：在文稿的"颜色"面板中添加自定义品牌色集合
4. **自定义字号快捷**：定义常用字号（14/18/24/36/48/64/88/120）

## 十二、常见问题速查

| 问题 | 推荐做法 |
|------|---------|
| 单页字数太多 | **拆分到2页**，或用卡片精简到每卡60字内 |
| 图表太复杂看不清 | **放大关键区域**，用金/红高亮；或拆成多页 |
| 幻灯片内容参差不齐 | **统一卡片高度**，用对齐工具(Align)精确对齐 |
| 字体在投影后显得小 | **标题≥48pt，正文≥18pt**，宁大勿小 |
| 超宽屏文字显得分散 | **用卡片收拢信息**，不要大面积散排 |
| 颜色在LED屏上偏色 | **避免用100%饱和度的纯颜色**，在Keynote中选择颜色测试页 |
| 动画太多显花哨 | **每页动画≤3组**，总时长<1.5秒 |

## 十三、设计质量自检清单

- [ ] **画布尺寸** 符合投影设备实际分辨率
- [ ] **字体统一**：全稿≤2种中文字体
- [ ] **字号层级**：封面/章节/卡片/正文/小字，共5级
- [ ] **配色统一**：使用同一方案的色板，强调色≤3种/页
- [ ] **留白合理**：内容区留白≥25%
- [ ] **标题位置**：固定在顶部15-20%高度
- [ ] **卡片规范**：边框颜色一致(#B8003A)，圆角一致(20px)
- [ ] **数字醒目**：KPI数字60pt+，金色或白色
- [ ] **对齐精确**：用对齐工具精确对齐所有卡片/元素
- [ ] **动画克制**：每页≤3组动画，总时长<1.5秒
- [ ] **过渡简洁**：主要用Fade和Magic Move，少用复杂效果
- [ ] **信息密度**：每页1个核心信息，最多3个要点
- [ ] **图片质量**：背景图≥4K，产品图≥1920px
- [ ] **首尾呼应**：封面和封底使用同一背景风格

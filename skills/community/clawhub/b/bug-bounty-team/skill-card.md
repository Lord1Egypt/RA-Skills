## Description:

Comprehensively scope, enumerate, test, validate, and report security findings with specialized roles for bug bounty assessments.

This skill is ready for commercial/non-commercial use.

## Publisher:

[t3ratech](https://clawhub.ai/user/t3ratech)

MIT-0

## Use Case:

Security reviewers, bug bounty teams, and authorized developers use this skill to scope a permitted target, enumerate attack surface, test hypotheses, validate findings, and prepare triage-ready reports.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Security testing workflows can be misapplied outside an authorized bug bounty or review scope.

Mitigation: Confirm the permitted target and scope before enumeration, testing, validation, or reporting.

Risk: Suggested shell commands or testing steps may be inappropriate in sensitive environments.

Mitigation: Review commands before execution and run them only in approved environments.

Risk: Stored context or notes can accidentally include sensitive secrets from a target environment.

Mitigation: Avoid storing secrets in memory and remove sensitive values from reports and intermediate notes.

# 老孟中文编程资料库（laomeng-zhc-kb）

ZHC 生态的**唯一查证入口**。把散落在契约、错误码库、门禁台账、治理文档、教程与分发包里的口径收敛成一套可追溯的答案。

> 本包**只含资料，不含语言内核**。要编译运行 `.zc` 请装 `laomeng-zhc`；要以智能体身份驱动 LSP 与桥请装 `laomeng-zhc-agent`。三者同一版本序列，口径必须一致。

## 包内清单

| 文件 | 作用 | 权威度 |
|---|---|---|
| `SKILL.md` | 技能正文：何时用、怎么查、口径优先级 | — |
| `references/契约_1.8_全量参考.md` | 语言契约全文（含 JSON 附录），计数与语法形态的事实源 | 最高 |
| `references/错误码表_E_1.5.md` | 39 个码位的触发条件与修法 | 高 |
| `references/版本与冻结口径.md` | 版本锚点、冻结件差异、C04 红灯的允许性说明 | 高 |

## 三条硬口径

1. **计数**：关键字 44 / 保留词 72 / 内置 39 / 类型 11 / 错误码 39。写"关键字 72"是旧笔误。
2. **版本**：语言面 `ZHC-LANG 2.0`，契约族 1.8，内部修订 2.6。实现修 bug 不递语言版本号。
3. **冻结面**：C04 判据保持红是既定路线（实现向前演进、冻结件按季度快照），不得改冻结件抹平。

## 用法示例

- "ZHC 有多少关键字？" → 契约 `①语法集.分组`，答 44 纯关键字 / 72 保留词，并说明 72 含 28 个内置函数名。
- "`[E303]` 怎么修？" → 错误码表按码位查，给触发条件 + 修法。
- "函数定义正确写法？" → 契约 `①语法集.语句形态`：`函数 名(参数:类型,…) 返回 类型 … 结束`。注意 `接受` 为预留关键字，无语法作用。
- "这答案是不是旧的？" → `版本与冻结口径.md` 内核指纹自证。

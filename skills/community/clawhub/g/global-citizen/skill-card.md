## Use Case:

External users and advisors use this skill to turn global mobility and overseas identity questions into structured pathway analyses. It helps compare candidate residency, citizenship, visa, and tax-residency options using eligibility, cost, timeline, source-verification, and broker-risk dimensions.

### Deployment Geography for Use:

## Known Risks and Mitigations:

Risk: Immigration, tax, fee, and processing-time information can change quickly and may become misleading if treated as static advice.

Mitigation: Verify concrete claims with official government sources and qualified immigration or tax professionals before making decisions.

Risk: Users may rely on broker or agency claims that omit fees, exaggerate approval certainty, or create artificial urgency.

Mitigation: Use written fee schedules, license checks, staged payments, refund terms, and independent source checks before engaging an agency.

Risk: Unreviewed or unpinned installation paths can expose users to changed release contents.

Mitigation: Prefer a reviewed, versioned ClawHub release rather than blindly running unpinned install commands or cloning a default branch.

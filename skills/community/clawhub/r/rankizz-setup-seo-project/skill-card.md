## Description:

Create or refresh a reusable local SEO project workspace containing a site's goals, audience, positioning, markets, competitors, constraints, and available data. Rankizz access is optional.

This skill is ready for commercial/non-commercial use.

## Publisher:

[prosamik](https://clawhub.ai/user/prosamik)

### License/Terms of Use:

MIT-0

## Use Case:

SEO practitioners and project owners use this skill to set up a reusable local workspace that captures a website's business context, SEO goals, markets, competitors, constraints, and available evidence before ongoing research. They can optionally associate the workspace with Rankizz when explicitly requested.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Two unresolved path references leave some release evidence incomplete.

Mitigation: Review unresolved references before relying on the associated workflows.

Risk: Project notes could expose credentials or private customer data if those are added.

Mitigation: Keep passwords, API keys, OAuth tokens, and private customer data out of the workspace.

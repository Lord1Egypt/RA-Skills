# 七平台发布文案写法

一条视频至少出五套（抖音、小红书、视频号、B站、快手），文化类再加公众号、知乎。**标题、首句、结尾提问、话题四处必须逐平台改写**，原样复制会被判重复内容。

山海经内容额外两条：① 标题尽量用"九尾狐""精卫""太阳"这种认识的字，生僻字放正文并注音；② 文化类容易被写成"涨知识了"，这类空话一律删。

## 抖音

| 项 | 要求 |
|---|---|
| 标题 | ≤20 字，反常识或疑问，不写"第X期" |
| 正文 | 60-150 字，3-4 行，一行一个信息点，末句提问 |
| 话题 | 5-8 个：1 大词（#山海经）+ 2 品类词（#儿童科普 #国学启蒙）+ 2-3 选题长尾 |
| 封面文字 | 与首帧标题一致 |
| 首评引导 | 「你家孩子问过这个吗？」 |

公式：`反常识结论 + 一句原文 + 一句科学答案 + 提问`

## 小红书

| 项 | 要求 |
|---|---|
| 标题 | ≤20 字，带场景或身份（"给 7 岁娃讲山海经"），不吆喝 |
| 正文 | 100-200 字，分点短句，每点一行，emoji ≤3 个 |
| 标签 | 8-10 个，放正文末尾 |
| 封面文字 | 3:4 竖版大字标题 + 一行副标题 |
| 首评引导 | 「想看哪只神兽，评论区点，我按你们点的做」 |

公式：`孩子的一句提问 + 原文一句 + 分点讲清 + 一个能做的动作 + 收藏引导`

## 视频号

| 项 | 要求 |
|---|---|
| 标题 | 15-22 字，稳重，可带"给孩子讲" |
| 正文 | 80-150 字，家长视角，讲"我怎么讲给他的" |
| 话题 | 3-5 个，偏教育、亲子 |
| 封面文字 | 4:3 横版，适合转到群里 |
| 首评引导 | 「转给家里带娃的人」 |

公式：`给孩子讲的一件小事 + 原文 + 今天怎么解释 + 家长感受 + 转发引导`

## B 站

| 项 | 要求 |
|---|---|
| 标题 | ≤25 字，可带【山海经里的科学】，含知识点关键词 |
| 简介 | 200-400 字，分「本期讲什么 / 原文与出处 / 科学部分怎么核的」三段 |
| 标签 | 5-10 个，含分区标签（知识、人文·历史、亲子） |
| 封面文字 | 横向 16:9 或 4:3，字要大 |
| 首评引导 | 「下期想看哪只，评论区点名」 |

B 站用户会查原文，**篇目和字句必须准**，写错会被挂。

## 快手

| 项 | 要求 |
|---|---|
| 标题 | 10-16 字，口语直给 |
| 正文 | 一句话钩子 + 一句话互动，≤60 字 |
| 话题 | 3-5 个，生活化 |
| 封面文字 | 大字，可用方言口语 |
| 首评引导 | 「你家孩子多大？我按年龄给你选神兽」 |

公式：`一句大白话结论 + 一句互动`

## 公众号

| 项 | 要求 |
|---|---|
| 标题 | ≤30 字，可带"原文""译文"字样 |
| 摘要 | ≤60 字 |
| 正文 | 600-1200 字，结构：引原文（竖排引用块）→ 白话翻译 → 古人为什么这么想 → 今天的答案 → 陪孩子看的三句话 |
| 排版 | 原文引用块用浅米色底、赭石色左边线；配图 3 张（首帧、封面、神兽特写） |
| 引导 | 文末一句「留言说说你家孩子第一反应」 |

## 知乎

| 项 | 要求 |
|---|---|
| 标题 | ≤40 字，问题式（"《山海经》里的九尾狐，古人到底在描述什么？"） |
| 正文 | 400-800 字，先给结论，再给原文和出处，再给科学解释，最后给"怎么讲给孩子听" |
| 引用 | 原文必须标篇目，能附通行本页码更好 |
| 结尾 | 不写"关注我"，写一句开放问题 |

## 通用雷区

- 不写「涨知识了」「干货满满」「建议收藏」「文化瑰宝」「千年传承」这类空话堆叠。
- 不用问句式标题配感叹号（"你知道吗？！"）——AI 味最重的写法之一。
- 不用「揭秘」「震惊」「震撼」。
- 不写"古人真笨""这是迷信"这类贬语；也不写"通灵""开运""辟邪"这类玄学延伸。
- 火、水、雷三类选题不做恐吓文案（"会毁掉孩子一生"）。
- 话题里不放无关大词蹭流量（会被打散标签）。

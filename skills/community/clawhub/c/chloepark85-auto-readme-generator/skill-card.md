## Description:

Generates a professional README.md file for a project, including project name, description, installation, usage, and license sections based on project contents.

This skill is ready for commercial/non-commercial use.

## Publisher:

[chloepark85](https://clawhub.ai/user/chloepark85)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill to generate a starter README.md for a project directory with common sections for description, installation, usage, and license information. Users should review and edit the generated README before publishing or distributing it.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can replace an existing README.md in the target directory without warning.

Mitigation: Check whether README.md already exists before running the skill and avoid using it on untrusted directories unless overwrite and symlink protections are added.

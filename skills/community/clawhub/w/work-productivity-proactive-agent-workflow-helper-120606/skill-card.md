## Use Case:

Developers, maintainers, skill authors, and AI-agent users use this skill to plan or implement proactive-agent-style workflows for bug fixing, setup hardening, reliability improvements, and adjacent skill creation.

### Deployment Geography for Use:

## Known Risks and Mitigations:

Mitigation: Review or narrow trigger wording before deployment when precise routing matters.

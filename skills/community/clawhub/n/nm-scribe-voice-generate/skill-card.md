## Description:

Generates text in a learned writing voice

This skill is ready for commercial/non-commercial use.

## Publisher:

[athola](https://clawhub.ai/user/athola)

### License/Terms of Use:

MIT-0

## Use Case:

Writers use the skill to draft text in a previously extracted writing voice, selecting a suitable register and using their source material as working notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Learning mode may save a pre-review snapshot that contains generated content.

Mitigation: Before using learning mode, decide whether saving that snapshot is acceptable.

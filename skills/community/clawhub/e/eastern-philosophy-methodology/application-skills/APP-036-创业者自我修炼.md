# 创业者自我修炼

## 场景定义

- **目标**：创业者/经营者的心性与能力长期修炼体系——立志、日课、聚焦、心性、担当、节奏六位一体，修身与治事合一。
- **约束**：时间被事务切碎；经营压力大、挫败频繁；诱惑与机会多、易见异思迁；大量决断无人监督。
- **角色**：创业者、经营者、自由职业者、长期自修者。
- **典型输入**：①创业者个人成长体系搭建；②高压期的个人修炼计划制定；③自我管理失控（懈怠/自满/迷失方向）后的重建。
- **边界**：组织级能力与文化体系建设不在本 Skill 范围（归组织类应用）；师友与顾问网络的经营不在本 Skill 范围；本 Skill 只编排"个人"的修炼。

## 组合公式

- **顺序**：立志定向段（ZGF-01→MZD-33）→ 日课修炼段（ZGF-04→ZGF-05→MZD-40→ZGF-02）→ 心性担当段（ZGF-07→ZGF-06→MZD-39→ZGF-03）→ 节奏警戒段（MZD-24→MZD-26）。
- **条件分支**：事务极度繁忙期 → ZGF-05 四路收缩为单路（保日课不断线即可）；遭遇重大挫败/受辱 → 转 ZGF-03 韧性分支（忍耐吞下、徐图自强，休整后再起）；取得阶段性成功 → 转 MZD-26 警戒分支（念万里长征第一步，戒自满）；修炼无明确用途 → MZD-33 靶点重立，无的则暂止该课目。
- **权重**：ZGF-01 权重最高——志不立、无有恒，日课与聚焦皆散架。
- **冲突裁决**：ZGF-05 四路并进 与 ZGF-02 专守一井冲突时——四路为输入方式之分工、一井为目标之专守，以"四路同向一井"调和；MZD-40 精益求精 与修炼进度冲突时——先求有恒完成（ZGF-01），再求精进（MZD-40）；MZD-24 休整 与事业紧迫冲突时——以可持续为裁，休整为更高质量的紧凑。

## 执行步骤

1. **立志定恒**（ZGF-01）：立志（断不甘为下流）、有识（知学无尽、不敢一得自足）、有恒（断无不成之事）三要素自查——修炼体系以志为纲、以恒为命。
2. **修炼有的放矢**（MZD-33）：为每个修炼课目指认它服务的实际经营问题——无的放矢的学习课目删除。
3. **日课双循环**（ZGF-04）：日知所亡（每日记录新知一则）+ 月无忘所能（每月以作品/复盘/业绩验证所得）——输入输出闭环。
4. **四路并进**（ZGF-05）：看（博览涉猎）、读（精诵要籍）、写（记录摘钞）、作（创作输出）每日不可缺一——四路皆指向主攻方向。
5. **手艺精益求精**（MZD-40）：对决定生意成败的核心手艺（产品/销售/判断力）以高标准反复打磨——深度先于广度。
6. **专守一井**（ZGF-02）：修炼目标收敛——与其多掘数井皆不及泉，何若老守一井力求及泉；见异思迁冲动出现时回到本步。
7. **慎独不欺**（ZGF-07）：无人监督处守住课目与底线——独处时的执行率是修炼真实性的唯一度量。
8. **明强担当**（ZGF-06）：重大决策前学、问、思、辨把事理弄明；认准之后强以力行、不因人言摇摆——不明而强是刚愎，明而不强是懦弱。
9. **极端负责**（MZD-39）：对客户承诺、团队托付之事极端负责、不出差错——负责是修炼的外在刻度。
10. **挫折坚忍**（ZGF-03）：受挫受辱时打脱牙和血吞——一味忍耐、不轻言苦，徐图自强；败而后振，此为立志之诀。
11. **间隙休整**（MZD-24）：高强度冲刺之后安排休整期——利用间隙总结经验、恢复气力，休整是修炼的一部分而非中断。
12. **常念第一步**（MZD-26）：小有所成时念万里长征第一步——在开头阶段即以长期心态戒骄戒躁，防止早期成功瓦解修炼纪律。

## 失效预案

- **修炼半途而废**（日课断线、有恒失守）：兜底回 ZGF-01 重立志 + ZGF-02 缩井——把课目缩到能坚持的最小单元（缩到"每日一则"级别），先恢复"恒"再谈量。
- **挫折击溃**（重大失败后修炼全盘停摆）：兜底回 ZGF-03 咬牙吞下 + MZD-24 休整窗口——休整期内只保 ZGF-07 慎独底线，气力恢复后按 ZGF-04 重启日课。
- **顺境自满**（成功后懈怠、课目放水）：兜底回 MZD-26 万里长征第一步 + MZD-40 以原标准复考月验作品——用验证结果击穿自我感觉良好。
- **修炼空转**（记了一堆笔记、业务无起色）：兜底回 MZD-33 靶点重立——每个课目重新指认经营问题；指认不到的课目停掉。
- **一切失序**：兜底回 ZGF-01——志、识、恒三要素从零自查，此为修炼体系的最后底座。

# 癫痫诊断与治疗

## 适用场景

当面对疑似或确诊的癫痫患者时，使用此技能进行：
1. 癫痫诊断与发作类型分类
2. 癫痫与假性癫痫(PNES)的鉴别
3. 抗癫痫药物(ASMs)选择
4. 癫痫持续状态的识别与分类

## 核心工作流程

### 步骤1：癫痫诊断

#### 诊断标准
- 临床出现≥2次非诱发性癫痫发作（间隔至少24小时）即可诊断

#### 必须完成的病史采集

1. **发作详情：**
   - 首次发作年龄
   - 发作前状态/促发因素
   - 最初症状体征、具体表现及演变
   - 持续时间
   - 发作后表现
   - 频率、严重程度
   - 治疗经过

2. **既往史：**
   - 母亲妊娠异常及用药史
   - 围生期异常
   - 颅脑外伤、脑炎、脑膜炎
   - 心脏/肝肾疾病

3. **家族史：**
   - 各级亲属癫痫发作或相关疾病（如偏头痛）

#### 辅助检查

**脑电图(EEG) - 最重要检查：**
- 常规头皮EEG：仅记录40-50%发作间期放电
- 长程视频EEG：检出率提高至70-80%
- 注意：发作间期EEG正常不能否定诊断
- 诱导方法（过度换气、闪光刺激）可提高阳性率

**神经影像学：**
- MRI较CT敏感
- 冠状位和海马体积测量显示海马病变
- 功能影像（MRS、SPECT、PET、fMRI）辅助癫痫灶定位

### 步骤2：癫痫与假性癫痫(PNES)鉴别

| 特征 | 真性癫痫 | 假性癫痫(PNES) |
|-----|---------|---------------|
| 发作场合 | 任何场合 | 必须有人在场，有精神诱因 |
| 发病速度 | 突然 | 相对缓慢 |
| 动作特点 | 形式刻板，同步协调 | 形式多样，夸张、不同步、不协调 |
| 眼部体征 | 眼球上翻/偏侧，瞳孔散大，对光反射消失 | 眼睑紧闭，眼球乱动，瞳孔正常，对光反射存在 |
| 面色 | 发绀 | 苍白或发红 |
| 意识 | 多丧失 | 可对外界刺激反应，可对抗被动运动 |
| 损伤 | 可摔伤、尿失禁 | 少有 |
| 持续时间 | 数秒至数分钟 | 可达数小时 |
| 终止方式 | 自行停止 | 需安慰/暗示 |
| Babinski征 | 常(+) | (-) |
| 发作后 | 意识模糊、嗜睡、头痛 | 一切如常 |
| EEG | 发作期/间期癫痫样放电 | 少有异常 |

**重要提示：** 10%假性发作患者可同时存在真性癫痫，10-20%真性癫痫患者伴假性发作

### 步骤3：抗癫痫药物(ASMs)选择

#### 根据发作类型选药

| 发作类型 | 传统ASMs | 新型ASMs |
|---------|---------|---------|
| 局灶性/继发全面 | 卡马西平、丙戊酸、苯妥英钠 | 左乙拉西坦、拉莫三嗪、托吡酯、奥卡西平、拉考沙胺 |
| 全面性强直-阵挛 | 丙戊酸、卡马西平 | 托吡酯、拉莫三嗪、左乙拉西坦 |
| 失神发作 | 丙戊酸、乙琥胺 | 拉莫三嗪 |
| 肌阵挛发作 | 丙戊酸、氯硝西泮 | 左乙拉西坦 |

#### ⚠️ 绝对禁忌（可加重发作）

| 发作类型 | 禁用药物 |
|---------|---------|
| 失神发作 | 卡马西平、苯巴比妥、苯妥英钠、氨己烯酸、加巴喷丁 |
| 肌阵挛发作 | 卡马西平、苯妥英钠、氨己烯酸、加巴喷丁、拉莫三嗪 |
| 自动症 | 氨己烯酸 |

#### 特殊综合征选药

- **West综合征(婴儿痉挛症)：** ACTH或泼尼松
- **Lennox-Gastaut综合征：** 托吡酯、丙戊酸、拉莫三嗪

### 步骤4：癫痫持续状态(SE)识别

#### 时间阈值

| SE类型 | t1(启动治疗) | t2(长期不良后果) |
|-------|-------------|-----------------|
| 强直-阵挛SE | 5分钟 | 30分钟 |
| 伴意识受损的局灶性SE | 10分钟 | >60分钟 |
| 失神SE | 10-15分钟 | 尚不明确 |

#### ILAE分类

**有明显运动症状的SE：**
- 惊厥性SE(CSE，即强直-阵挛SE)
- 肌阵挛SE
- 局灶运动性SE
- 强直SE
- 过度运动性SE

**无明显运动症状的SE(NCSE)：**
- 不伴昏迷（全面性、局灶性、不能确定）
- 伴昏迷

## 重要约束

1. 发作间期EEG正常不能排除癫痫诊断
2. 选药时必须确认药物有稳定来源（需长期用药）
3. 需综合考虑患者年龄、性别、副作用、药物价格
4. 假性癫痫患者需转诊心理/精神科
5. 癫痫持续状态达到t1时间即应启动治疗

# 癫痫发作类型详细临床表现

## 局灶性发作

### 单纯局灶性发作（意识保留）
- 运动症状：局部肢体抽搐、旋转性头眼偏转
- 感觉症状：体感异常（麻木、针刺感）、视觉异常（闪光）、听觉异常
- 自主神经症状：面色改变、出汗、心悸
- 精神症状：似曾相识感、恐惧、错觉

### 复杂局灶性发作（意识受损）
- 意识障碍：凝视、反应迟钝
- 自动症：口咽自动症（咂嘴、咀嚼）、手部自动症（摸索、解扣）
- 可继发全面性强直-阵挛发作

## 全面性发作

### 强直-阵挛发作（大发作）
- 强直期：全身肌肉持续收缩，尖叫，呼吸暂停，发绀，持续10-20秒
- 阵挛期：四肢节律性抽动，口吐白沫（可带血），持续30-60秒
- 发作后期：意识模糊，嗜睡，头痛，肌肉酸痛

### 失神发作（小发作）
- 典型失神：突然动作停止，凝视，持续5-30秒，立即恢复
- 非典型失神：起止渐缓，肌张力改变明显
- EEG：3Hz棘慢波综合（典型）

### 肌阵挛发作
- 短暂、快速、电击样肌肉收缩
- 可累及全身或局部
- 意识通常保留

### 强直发作
- 全身或局部肌肉强直收缩
- 头眼偏转，躯干前屈或后仰
- 持续数秒至数十秒

### 阵挛发作
- 节律性抽动
- 频率逐渐减慢
- 幅度逐渐增大

### 失张力发作
- 突然肌张力丧失
- 头下垂、跌倒
- 持续1-3秒
- 立即恢复

## 癫痫综合征

### West综合征（婴儿痉挛症）
- 发病年龄：3-12个月
- 发作形式：成串的鞠躬样痉挛
- EEG：高度失律
- 预后：多伴智力发育迟缓

### Lennox-Gastaut综合征
- 发病年龄：1-8岁
- 多种发作类型：强直、失张力、非典型失神
- EEG：慢棘慢波（<2.5Hz）
- 预后：难治性，智力受损

### 青少年肌阵挛癫痫
- 发病年龄：12-18岁
- 晨起肌阵挛，可继发全面强直-阵挛发作
- EEG：4-6Hz多棘慢波
- 预后：需终身服药，停药易复发

# 抗癫痫药物(ASMs)详细用法与副作用

## 传统ASMs

### 丙戊酸（丙戊酸钠/丙戊酸镁）
- **广谱：** 适用于各种发作类型
- **首选：** 全面性发作、肌阵挛发作、失神发作
- **副作用：** 体重增加、震颤、脱发、肝损害、胰腺炎、多囊卵巢
- **监测：** 肝功能、血药浓度
- **致畸性：** 高，育龄女性慎用

### 卡马西平
- **适用：** 局灶性发作、全面性强直-阵挛发作
- **禁忌：** 失神发作、肌阵挛发作（可加重）
- **副作用：** 头晕、嗜睡、皮疹、低钠血症、肝酶诱导
- **严重反应：** Stevens-Johnson综合征（HLA-B*1502阳性者风险高）
- **监测：** 血常规、肝功能、血药浓度

### 苯妥英钠
- **适用：** 局灶性发作、全面性强直-阵挛发作
- **禁忌：** 失神发作、肌阵挛发作
- **副作用：** 牙龈增生、多毛、共济失调、眼球震颤
- **长期副作用：** 骨质疏松、周围神经病
- **药代动力学：** 零级消除，剂量调整需谨慎

### 苯巴比妥
- **适用：** 新生儿癫痫、资源有限地区
- **禁忌：** 失神发作
- **副作用：** 嗜睡、认知影响、行为异常（儿童）
- **依赖性：** 明显

## 新型ASMs

### 左乙拉西坦
- **广谱：** 局灶性、全面性发作
- **优势：** 药物相互作用少，无需监测血药浓度
- **副作用：** 嗜睡、头晕、易激惹、情绪改变
- **起始剂量：** 500mg bid，可逐渐加量

### 拉莫三嗪
- **广谱：** 局灶性、全面性发作
- **禁忌：** 肌阵挛发作（可加重）
- **优势：** 认知影响小，情绪稳定作用
- **严重副作用：** 皮疹（缓慢加量可降低风险）
- **加量原则：** 起始25mg/d，每2周增加25-50mg

### 托吡酯
- **广谱：** 局灶性、全面性发作
- **副作用：** 认知减慢、体重减轻、肾结石、代谢性酸中毒、青光眼
- **适用：** 合并肥胖者

### 奥卡西平
- **适用：** 局灶性发作
- **优势：** 肝酶诱导作用弱于卡马西平
- **副作用：** 低钠血症（较卡马西平更常见）、皮疹

### 拉考沙胺
- **适用：** 局灶性发作
- **优势：** 药物相互作用少
- **副作用：** 头晕、头痛、PR间期延长
- **监测：** 心电图（有心脏传导疾病者）

### 吡仑帕奈
- **适用：** 局灶性发作（伴或不伴继发全面性）
- **机制：** AMPA受体拮抗剂
- **副作用：** 头晕、嗜睡、攻击行为、精神症状
- **服药时间：** 睡前

## 特殊综合征用药

### West综合征
- **首选：** ACTH（促肾上腺皮质激素）
- **替代：** 泼尼松、氨己烯酸

### Lennox-Gastaut综合征
- **首选：** 丙戊酸
- **添加：** 拉莫三嗪、托吡酯、鲁非那胺

## 药物相互作用要点

| 药物 | 肝酶诱导 | 主要相互作用 |
|-----|---------|-------------|
| 卡马西平 | 强诱导 | 降低口服避孕药、华法林、其他ASMs浓度 |
| 苯妥英钠 | 强诱导 | 同上 |
| 苯巴比妥 | 强诱导 | 同上 |
| 丙戊酸 | 抑制 | 升高拉莫三嗪浓度（需减量） |
| 左乙拉西坦 | 无 | 几乎无药物相互作用 |
| 拉莫三嗪 | 无 | 被丙戊酸升高，被卡马西平降低 |
| 奥卡西平 | 弱诱导 | 降低口服避孕药浓度 |

# 中医体质辨证速查表

> 基于《黄帝内经》阴阳五行理论，用于快速辨别阴虚、阳虚、气虚等常见体质。

---

## 一、三大虚证核心特征

| 类型 | 核心病机 | 一句话特征 |
|------|----------|------------|
| **阴虚** | 阴液不足，虚热内生 | "阴虚则热"——怕热、盗汗、舌红 |
| **阳虚** | 阳气不足，虚寒内生 | "阳虚则寒"——怕冷、自汗、舌淡 |
| **气虚** | 元气不足，功能减退 | "气虚则无力"——乏力、懒言、脉虚 |

---

## 二、辨证要点对比表

| 维度 | 阴虚 | 阳虚 | 气虚 |
|------|------|------|------|
| **寒热感觉** | 怕热、五心烦热 | 怕冷、四肢不温 | 不明显或微怕冷 |
| **出汗特点** | 盗汗（夜间出汗） | 自汗（白天出汗） | 自汗，动则尤甚 |
| **面色** | 面色潮红、两颧红赤 | 面色苍白、虚浮 | 面色萎黄、无华 |
| **精神状态** | 心烦易怒、失眠多梦 | 神疲乏力、但欲寐 | 精神不振、懒言 |
| **口咽感觉** | 口干咽燥、喜冷饮 | 口淡不渴、喜热饮 | 口淡、食欲不振 |
| **大便** | 干结、便秘 | 稀溏、五更泻 | 稀软、排便无力 |
| **小便** | 短赤（量少色黄） | 清长（量多色淡） | 尿频、清长、夜尿多 |
| **舌象** | 舌红少苔、或有裂纹 | 舌淡胖、苔白滑 | 舌淡、苔薄白 |
| **脉象** | 脉细数（细而快） | 脉沉迟无力 | 脉虚无力 |
| **体型** | 多瘦削 | 或虚胖浮肿 | 多瘦弱或虚胖 |

## 三、脏腑定位辨证

### 阴虚脏腑定位

| 脏腑 | 典型表现 |
|------|----------|
| **心阴虚** | 心悸失眠、心烦多梦 |
| **肝阴虚** | 眼干目涩、急躁易怒、头晕耳鸣 |
| **肺阴虚** | 干咳少痰、咽干声哑 |
| **肾阴虚** | 腰膝酸软、头晕耳鸣、遗精盗汗 |
| **胃阴虚** | 胃脘灼痛、口干便秘、饥不欲食 |

### 阳虚脏腑定位

| 脏腑 | 典型表现 |
|------|----------|
| **心阳虚** | 心悸胸闷、自汗、畏寒 |
| **脾阳虚** | 腹冷痛、便溏、完谷不化 |
| **肾阳虚** | 腰膝冷痛、畏寒肢冷、阳痿遗尿、五更泻 |
| **胃阳虚** | 胃脘冷痛、呕吐清水、喜温喜按 |

### 气虚脏腑定位

| 脏腑 | 典型表现 |
|------|----------|
| **心气虚** | 心悸气短、自汗、胸闷 |
| **肺气虚** | 咳喘气短、声音低弱、易感冒 |
| **脾气虚** | 食少腹胀、便溏、倦怠乏力 |
| **肾气虚** | 腰膝酸软、尿频遗尿、耳鸣 |

## 四、快速辨证口诀

```
阴虚热象五心烦，盗汗舌红脉细数
（怕热、盗汗、舌红、脉细数）

阳虚寒象四肢冷，自汗舌淡脉沉迟
（怕冷、自汗、舌淡、脉沉迟）

气虚无力懒言语，自汗舌淡脉虚软
（乏力、懒言、自汗、脉虚）
```

### 记忆要点

| 要点 | 方法 |
|------|------|
| **有热无热定阴阳** | 怕热→阴虚，怕冷→阳虚 |
| **有汗无汗看性质** | 盗汗→阴虚，自汗→阳虚/气虚 |
| **舌红舌淡辨寒热** | 舌红→阴虚，舌淡→阳虚/气虚 |
| **脉数脉迟定虚实** | 脉数→阴虚，脉迟→阳虚，脉虚→气虚 |

## 五、辨证流程

```
第一步：寒热判断
├─ 怕热、口干、盗汗 → 倾向阴虚
├─ 怕冷、口淡、自汗 → 倾向阳虚
└─ 寒热不明显 → 倾向气虚

第二步：舌象确认
├─ 舌红少苔 → 阴虚
├─ 舌淡胖苔白 → 阳虚
└─ 舌淡苔薄 → 气虚

第三步：脉象验证
├─ 脉细数 → 阴虚
├─ 脉沉迟无力 → 阳虚
└─ 脉虚无力 → 气虚

第四步：脏腑定位
└─ 根据具体症状判断哪个脏腑亏虚
```

## 六、治则与代表方剂

| 类型 | 治则 | 代表方剂 | 核心药物 |
|------|------|----------|----------|
| **阴虚** | 滋阴清热 | 六味地黄丸、知柏地黄丸 | 熟地、麦冬、石斛 |
| **阳虚** | 温阳散寒 | 四逆汤、右归丸 | 附子、干姜、肉桂 |
| **气虚** | 补气健脾 | 四君子汤、补中益气汤 | 人参、黄芪、白术 |

---

## 七、虚证转化关系

```
气虚 → 阳虚（气损久则伤阳）
阴虚 → 血虚（阴损久则血枯）
阴虚 → 气虚（阴损则气无根）
阳虚 → 气虚（阳损则气无温）

常见合病：
├─ 气阴两虚：气虚 + 阴虚并存
└─ 阴阳两虚：阴虚 + 阳虚并存（危重）
```

## 八、常见误区警示

| 误区 | 表现 | 正解 |
|------|------|------|
| 阴虚当作实热 | 见热就清热 | 阴虚是虚热，需滋阴非清热 |
| 阳虚当作气虚 | 见乏力就补气 | 阳虚有寒象，需温阳非单纯补气 |
| 气虚当作阳虚 | 见自汗就温阳 | 气虚无寒象，需补气非温阳 |
| 忽视合病 | 只辨一种虚 | 气阴两虚、阴阳两虚常见 |

## 九、调养建议

| 类型 | 饮食 | 生活调摄 | 忌讳 |
|------|------|----------|------|
| **阴虚** | 滋阴润燥：银耳、百合、麦冬、石斛 | 避熬夜、避燥热环境 | 辛辣燥热、熬夜 |
| **阳虚** | 温阳散寒：羊肉、生姜、桂圆 | 注意保暖、避寒凉 | 生冷寒凉、贪凉 |
| **气虚** | 补气健脾：山药、黄芪、人参 | 劳逸结合、避过度劳累 | 过度劳累、思虑过度 |

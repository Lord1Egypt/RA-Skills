## Description:

Turn two still frames into scroll animation code for a website, in plain words, with any AI agent. Your AI agent drafts the workflow, you make the frames in Whisk, generate an 8 second video in Flow, extract the frames with EZGIF, then the agent drafts the prompt that turns the frames into interactive scroll animation code.

This skill is ready for commercial/non-commercial use.

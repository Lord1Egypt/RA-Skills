## Description:

Train an AI lobster or agent to improve intelligence, cognition, learning ability, reasoning discipline, memory use, and adaptive personality through repeated cognitive drills, reflection, self-evaluation, and owner feedback loops.

This skill is ready for commercial/non-commercial use.

## Publisher:

[norika1207-lab](https://clawhub.ai/user/norika1207-lab)

MIT-0

## Use Case:

External users and agent developers use this skill to guide an AI agent through recurring cognitive drills, memory review, learning journals, owner feedback, and strategy updates. It can also use a Charenix agent key to persist journals, hypotheses, strategy, and related behavioral context.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may summarize owner preferences, emotional cues, weak spots, memories, and learning journals into an external Charenix service.

Mitigation: Use only a Charenix key controlled by the user, avoid raw private details or secrets in journal fields, and confirm the service's retention and deletion behavior before enabling persistence.

Risk: Memory and behavioral notes may be treated as reliable even when they are inferred from conversation.

Mitigation: Require evidence and confidence checks before using recalled memories, and follow the skill's rule not to invent memories.

## Description:

Create and manage test payment links including one-time, recurring, payment plans, multiple products, custom plans, and pay-what-you-want options.

This skill is for demonstration purposes and not for production usage.

## Publisher:

## Use Case:

Developers and testers use this skill to create and exercise sandbox payment-link flows, including one-time payments, recurring subscriptions, plans, multi-product checkout links, webhooks, and JSON response handling. It is intended for test environments and not for real payment processing.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill is scoped to sandbox payment-link behavior and is not suitable for real payment processing as provided.

Mitigation: Install only for sandbox testing; before any real payment use, replace placeholder key handling, verify webhook signatures, require HTTPS endpoints, and review privacy and logging controls for collected customer emails.

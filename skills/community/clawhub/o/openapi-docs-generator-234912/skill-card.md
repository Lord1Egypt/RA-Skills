## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to turn API requirements and service details into practical OpenAPI or Swagger documentation workflows, checklists, implementation guidance, and validation notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad trigger wording may cause the skill to activate for general API or developer-experience requests.

Mitigation: Use explicit skill selection or restrict implicit invocation when a narrower OpenAPI documentation workflow is needed.

Risk: Generated API documentation guidance can be incomplete or inaccurate if service behavior, authentication, schemas, or error responses are missing.

Mitigation: Review outputs against the actual service implementation and run OpenAPI validation or contract checks before publishing.

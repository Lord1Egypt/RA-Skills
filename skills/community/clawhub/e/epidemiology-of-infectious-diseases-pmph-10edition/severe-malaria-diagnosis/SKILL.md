# 重症疟疾诊断与预警

## 使用场景

当遇到以下情况时触发此技能：
- 确诊疟疾患者出现重症临床表现
- 疟疾患者原虫密度超标
- 需要评估疟疾患者是否需要紧急救治

## 前置条件

- 患者已有疟疾病原学检查阳性结果

## 诊断流程

### 第一步：临床表现评估

逐一检查患者是否出现以下重症表现：

1. **神经系统**：意识受损、多次抽搐（脑型疟疾表现）
2. **血液系统**：严重贫血、显著出血
3. **代谢紊乱**：酸中毒、低血糖
4. **器官损害**：肾功能损害、黄疸、肺水肿/ARDS
5. **循环衰竭**：休克
6. **全身症状**：发热、全身无力

**判断**：出现任一重症表现 → 进入第三步启动预警

### 第二步：原虫密度检测

检测血中恶性疟原虫密度百分比：

- **中国标准**：原虫密度 > 5% → 高原虫血症（因我国已消除疟疾，人群免疫功能极低）
- **WHO全球标准**：原虫密度 > 10% → 高原虫血症

**判断**：超过对应阈值 → 进入第三步启动预警

### 第三步：实验室预警指标核查

检查以下关键指标：

- **血小板计数**：< 50×10^9/L（急性下降需高度警惕）
- **血铁蛋白**：显著增高

### 第四步：易感人群评估

确认患者是否属于高危人群：
- 无疟疾免疫功能人群（重症高发）
- 注意：4种疟原虫均可引起重症，但恶性疟原虫最常见（脑型疟疾为主）

## 约束条件

- 非恶性疟原虫感染时，需结合其他重症临床表现综合判断，不能仅凭原虫密度诊断

## 输出结果

当满足以下任一条件时，触发重症疟疾预警：
1. 出现重症临床表现
2. 原虫密度超过阈值
3. 实验室预警指标异常

**预警内容**：
```
⚠️ 重症疟疾预警
患者符合重症疟疾诊断标准，需立即采取综合性急救措施。
治疗原则：病因治疗和对症治疗并重。
```

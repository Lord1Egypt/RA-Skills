## Description:

This Chinese-language skill guides agents through an eight-stage assessment of investment-attraction projects, covering project fit, feasibility, economic contribution, risks, scoring, and A/B/C/D grading.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users such as government investment-promotion teams, industrial park operators, and enterprise development staff use this skill to screen investment leads, compare projects, and prepare standardized assessment reports for decision-making.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Assessment outputs may be misleading if company, financial, legal, land, environmental, or policy facts are incomplete or unverified.

Mitigation: Verify material facts against authoritative sources before using the report for investment, policy, or project-approval decisions.

Risk: The skill defaults to Chinese-language reporting, which may not match every user's expected language or format.

Mitigation: Explicitly request another language or output format when Chinese markdown is not suitable.

Risk: Strong recommendations can be inappropriate when project information is incomplete.

Mitigation: Require missing project data to be identified and resolved before treating scores, grades, or recommendations as decision-ready.

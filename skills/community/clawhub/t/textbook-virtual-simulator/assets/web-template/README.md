# 教材虚拟仿真系统 - 基础Web模板

## 模板说明
这是基础HTML模板，包含完整的页面结构和所有必要的组件。

## 使用说明
1. 根据实际需求修改页面标题和描述
2. 调整导航菜单项
3. 自定义各个section的内容
4. 添加或删除组件

## 技术要求
- 现代浏览器（Chrome 90+, Firefox 88+, Safari 14+, Edge 90+）
- JavaScript启用
- WebGL支持
- 网络连接（加载CDN资源）

## 自定义选项
- 可以通过修改CSS变量来自定义主题颜色
- 可以通过配置文件调整3D场景参数
- 可以通过JavaScript自定义交互行为

## 注意事项
- 确保所有CDN链接可访问
- 根据实际需求调整响应式断点
- 在生产环境中压缩和优化资源

## Description:

Understands Malayalam and Manglish WhatsApp messages and replies politely using culturally appropriate language in the matching script style.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and assistants use this skill to understand Malayalam script or Manglish WhatsApp-style messages, provide Malayalam translations, and respond with polite culturally appropriate phrasing in the user's style.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The assistant may continue using Malayalam or Manglish when the user prefers another language.

Mitigation: Ask the assistant to switch languages explicitly when a different response language is preferred.

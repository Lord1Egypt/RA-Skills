# 万怡酒店查询与预订 — 万豪旗下中端商务酒店，实时价格直连

> 搜索万怡（Courtyard by Marriott）酒店，返回真实价格和可预订链接，支持酒店详情和套餐优惠查询。

🔥 **核心亮点：**
- **万豪品牌保障** — 万豪集团旗下中端商务品牌，全球3000+家门店
- **实时价格直连** — 多旅游平台数据聚合，价格真实可预订
- **详情完整** — 周边交通、设施、房型、政策一目了然
- **套餐优惠** — 含早/连住/门票等打包产品，省钱省心
- **零配置** — 免申请Key，装上就能用

## 快速入门

**3个开场白示例，复制即用：**

1. "上海有什么万怡酒店"
2. "北京500块以内的万怡"
3. "万怡有什么优惠套餐"

## 核心能力

1. **城市搜索** — 输入城市或区域，返回所有万怡酒店的价格、星级和预订链接
2. **价格筛选** — 设定最高价格/晚，精准匹配预算
3. **关键词搜索** — 支持"虹桥""机场""火车站"等关键词定位
4. **酒店详情** — 查看指定万怡的交通、设施、房型、入住政策
5. **套餐优惠** — 搜索含早/连住/门票等打包产品
6. **预订链接** — 每条结果附带预订链接，可直接跳转下单

## 能做什么

- 搜索万怡酒店，返回价格、星级、地址、附近地标和预订链接
- 查询某家万怡酒店的详情（周边交通/景点/设施/房型/政策）
- 搜索万怡酒店套餐优惠

## 不能做什么

- 不支持非万怡酒店搜索（其他万豪品牌请使用万豪酒店预订技能）
- 不支持直接预订（提供预订链接，用户点击跳转）

## 使用提示

- 万怡定位中端商务，价格通常在300-800元/晚，适合出差和短途旅行
- 含早套餐通常比单买早餐省50-100元/天
- 连住优惠一般住3晚以上可享折扣
- 价格实时变动，以预订页面为准

## 🔗 搭配使用

- **万豪酒店预订** — 搜索万豪旗下其他品牌（喜来登/JW/威斯汀等）
- **丽思卡尔顿酒店查询与预订** — 需要高端奢华体验时选择
- **酒店智能搜索** — 万怡以外的通用酒店搜索

## 数据流向

用户输入（城市/日期/关键词）→ 本技能 → 云端代理服务 → 旅游平台API → 返回结果。代理服务不存储用户数据，仅转发查询请求。

## Description:

Search Facebook Ad Library and Meta Ad Library data with PPSPY. Analyze ads, advertiser stores, landing pages, and ad products from one focused skill.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and developers use this skill to query PPSPY-powered Facebook Ad Library and Meta Ad Library data, including ads, advertiser stores, landing-page statistics, advertising trends, placements, copy, advertisers, products, and filter options.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill uses a third-party npm MCP server with access to the user's PPSPY API key and account credits.

Mitigation: Install only if PPSPY and ppspy-mcp-server@1.0.1 are trusted, use a revocable PPSPY API key, monitor billing and credit usage, and consider running the server in a contained environment.

## Description:

Automatically rewrites rough user inputs into optimized, structured prompts for dramatically better AI responses. Prefix any message with "p:" to activate.

This skill is ready for commercial/non-commercial use.

## Publisher:

[gyaan-dub](https://clawhub.ai/user/gyaan-dub)

### License/Terms of Use:


## Use Case:

External users and developers use this skill to turn rough prefixed requests into clearer structured prompts, see the rewritten prompt, and receive an answer generated from that enhanced prompt.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompt rewriting can add assumptions or change emphasis before the answer is generated.

Mitigation: Review the displayed enhanced prompt and correct the request if the rewrite does not match the intended task.

Risk: A prefixed message may be answered from the rewritten prompt rather than the raw input.

Mitigation: Use the p: or prompt: prefix only when prompt enhancement is desired; leave ordinary messages unprefixed.

## Description:

Generate and validate backend and frontend code from task descriptions with clear role division and execution logs.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and agents use this skill to structure backend and frontend coding tasks into an analyze, plan, execute, validate, and summarize workflow. It accepts a task plus optional context and constraints, then returns a plan, result or report, and logs or summary.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated or suggested code may be incorrect, unsafe, or misaligned when task constraints are vague.

Mitigation: Provide clear task constraints and review generated code before running, deploying, or making destructive changes.

Risk: External deployments or production actions could affect live systems if authorized without review.

Mitigation: Require explicit second confirmation before external actions or production deployment.

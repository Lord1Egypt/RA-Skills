## Description:

Agent Experience (AX) development framework for helping agents design or review libraries, CLIs, APIs, and other software through deterministic contracts, structured errors, explicit defaults, co-located documentation, and test-first invariants.

This skill is ready for commercial/non-commercial use.

## Publisher:

[superworldsavior](https://clawhub.ai/user/superworldsavior)

### License/Terms of Use:


## Use Case:

Developers and engineers use this skill to make agent-facing libraries, APIs, CLIs, and modules easier for AI agents to call, inspect, test, and recover from errors.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can influence how an agent designs or reviews software interfaces, so recommendations may be misapplied to projects with different operational constraints.

Mitigation: Review AX recommendations against project-specific requirements before adopting them, especially output contracts, error handling, defaults, and test invariants.

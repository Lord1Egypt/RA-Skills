# Reel Brand Playbook

## Headline

Turn a Business Into Reels That All Look the Same, in Plain Words

## Hook

Give your AI agent one business. It drafts a Playbook.md with your colors, fonts, logo, and tone. Then it picks one of three reel formats, Explainer, Challenge, or Stage Talk, and drafts the script, the caption, and the edit brief for owner review. Every reel follows the same playbook, so every reel looks like it came from the same business. The agent drafts, you record and post, the agent never posts a reel itself.

## Pain, in plain words

Most small business reels look different every time. One reel is bright, the next is dark, one uses one font, the next uses another, and no one can tell they came from the same shop. Viewers forget the business, because nothing about the reels is the same twice. The fix is a short playbook first, colors, fonts, logo, and tone, written down once, then every reel follows it. A script that is checked against the playbook, a caption that matches the tone, and an edit brief that lists the same layers every time, is what makes reels look consistent.

## What you get

A Playbook.md template plus a reel plan for one business, in plain words. The playbook holds the colors, fonts, logo, and tone. The plan picks one format, Explainer, Challenge, or Stage Talk, drafts the script, drafts the caption and hashtags, and gives an edit brief for the raw clip. The handoff check lists the script, the caption, the brand kit, and the edit brief, each one Checked, Missing, or Not confirmed, with the pasted text quoted as the evidence. It gives you a fix draft to review, never a posted reel by itself.

## Who this is for

Small business owners who post reels and want every reel to look like it came from the same business. People who make reels with an AI agent, in plain words, and want a script, a caption, and an edit brief to review before they record anything. People who hand a raw clip to an editor, and want a clear brief, so the editor knows the colors, fonts, logo, and tone to use.

## Why this saves money

A playbook written once stops you from starting from zero for every reel. A script checked against the playbook stops a reel that does not sound like your business. A caption drafted first stops a post that says the wrong thing. An edit brief, reviewed first, stops an edit that uses the wrong colors, fonts, or tone, and has to be done again.

## How to use it

Hard rule, read this first: the agent does not record a reel, does not edit video, does not render video, and does not post a reel itself. The agent drafts the playbook, the script, the caption, and the edit brief, and only checks evidence the user pastes in the message. A short description alone is not evidence. A script, a caption, or a checklist is Checked only when the user pasted that text in the message, and the output quotes that pasted text as the evidence.

Fast path: If the user already gives the business, the goal of the reel, and the audience in the first message, do NOT ask a long list of questions first. Draft the full playbook and the reel plan in the SAME reply, then the fix draft. Never stop at questions alone.

Step 1: pick a format, Explainer, Challenge, or Stage Talk. Explainer teaches one thing in plain words, in short steps. Challenge invites the viewer to try something, answer a question, or take part. Stage Talk is talking to the camera, like on a stage, one story, one point, in plain words. Pick the format that fits the goal of this reel, and say why, in one line.
Step 2: write the script in plain words. The agent drafts the script, line by line, short sentences, one point at a time. The user reads it, and pastes back any line they want changed. The script is a draft, not a posted reel.
Step 3: check the script against the Playbook.md brand kit, colors, fonts, logo, and tone. The agent checks each line against the playbook the user pasted in the message. If a line does not match the tone, say so, and draft a new line.
Step 4: draft the caption and hashtags for owner review. The agent drafts the caption in the same tone as the playbook, and lists hashtags in plain words. The user pastes back any hashtag they want added or removed. The caption is a draft, not a posted caption.
Step 5: run the handoff check, script, caption, brand kit, and edit brief, all checked with evidence pasted in the message. List each item as Checked, Missing, or Not confirmed, with the pasted text quoted as the evidence.
Step 6: write the fix draft, labelled DRAFT, NOT SENT, with owner approval needed.

Ask only what is missing, in plain words, one short list at a time:
1. What is the business, in plain words?
2. What is the goal of this reel, teach, invite, or tell a story?
3. Who is the reel for, in plain words?
4. What are your colors, fonts, logo, and tone, paste the playbook if you have one, or Not confirmed?
5. Which format, Explainer, Challenge, or Stage Talk, or Not confirmed?
6. What is the one point of this reel, in one line?
7. Paste the script you want checked, or ask the agent to draft one first?

If the user does not know an answer, mark it Not confirmed, and use the most common answer for that business type, and say so, marked Suggested, not confirmed. Do not invent an answer. If the user says use the playbook for a question, use only what is in the pasted playbook, and say so.

## The three formats

Explainer: teach one thing, in plain words, in short steps. Say the problem first, then the steps, then what to do next. Keep it to one thing per reel.
Challenge: invite the viewer to try something, answer a question, or take part. Say what to do, say how long it takes, and say what happens next. Keep the ask to one action.
Stage Talk: talk to the camera, like on a stage. Tell one story, make one point, in plain words. Keep it to one story per reel.

## What good looks like

A good playbook has the colors, fonts, logo, and tone written down once, in plain words. A good reel plan has one format, one point, one script, one caption, and one edit brief. A good handoff has every item marked Checked, Missing, or Not confirmed, with pasted text quoted as the evidence for every Checked item. A good fix draft lists the missing items first, in order, with one plain line each.

## Common mistakes

These mistakes show up often, and they are easy to avoid if you check for them at handoff.

- Posting without a playbook. Without colors, fonts, logo, and tone written down, every reel looks different.
- Mixing two formats in one reel. Pick one format, Explainer, Challenge, or Stage Talk, and keep to it.
- Writing a script with three points. One reel, one point, in plain words.
- Using a caption that does not match the tone. Check the caption against the playbook before you post it.
- Calling a reel done when only the script exists. A script is not a posted reel. Checked needs pasted text, and posted needs evidence the user pasted in the message.
- Claiming views, followers, or sales from a script. A script is a draft, not a result. Never invent a view count or a testimonial.

## Description:

Helps non-engineers, product managers, creators, operators, and WeChat mini-program beginners use an AI agent to clarify requirements, define an MVP, break down pages and data structures, implement small steps, validate functionality, prepare launch checks, and iterate from user feedback.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users, product managers, creators, operators, and beginner developers use this skill to guide an AI coding agent through WeChat mini-program MVP planning, implementation, validation, launch preparation, and iteration. It is intended for WeChat mini-program projects, not general web or backend projects unless the user explicitly wants to reuse the Vibe Coding workflow.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated plans or code may affect cloud databases, permissions, sharing behavior, or launch readiness for a WeChat mini-program.

Mitigation: Review generated code and deployment steps before applying them, and verify UI, sharing, permissions, cloud functions, and launch checks in WeChat Developer Tools or on a real device.

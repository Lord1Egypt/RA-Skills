## Description:

Make a recurring brief report what changed since the last edition instead of restating everything.

This skill is ready for commercial/non-commercial use.

## Publisher:

[mohitagw15856](https://clawhub.ai/user/mohitagw15856)

### License/Terms of Use:

MIT-0

## Use Case:

Teams and operators use this skill to turn recurring weekly or monthly reports into changes-first briefings. It helps compare current sources against a prior state record, report material deltas, and save a compact state record for the next cycle.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The generated state record may contain sensitive briefing facts or source references.

Mitigation: Store the state record only in a location appropriate for the sensitivity of the briefing sources.

Risk: A recurring brief can become misleading if it is diffed against memory rather than the stored state record.

Mitigation: Use the prior state record as the comparison baseline and ensure the brief and state record agree before saving the next state.

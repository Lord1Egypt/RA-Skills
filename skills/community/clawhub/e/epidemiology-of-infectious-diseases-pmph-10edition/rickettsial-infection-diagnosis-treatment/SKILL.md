# 立克次体感染诊断与治疗

## 适用场景

当遇到以下情况时应用本技能：
- 患者有丛林/草地/丘陵活动史或蜱叮咬史
- 发热伴特征性焦痂或溃疡（疑似恙虫病）
- 发热伴白细胞/血小板减少（疑似人无形体病）

## 工作流程

### 步骤1：流行病学史评估

**恙虫病**：
- 询问丛林/草地活动史
- 确认流行季节：南方5-10月（6-8月高峰），北方9-12月（10月高峰）
- 地区：亚洲太平洋，我国东南沿海，河溪两岸灌木杂草丛生地带

**人无形体病**：
- 发病前2周内蜱叮咬史
- 在有蜱活动的丘陵山区工作或生活
- 直接接触危重患者血液等体液

### 步骤2：临床特征识别

**恙虫病关键体征**：
1. 全身仔细查体寻找焦痂（70%以上患者可见）
2. 焦痂特征：圆形/椭圆形，直径2-15mm，边缘突起如堤围，周围红晕，不痛不痒
3. 好发部位：腋窝、外生殖器、腹股沟、会阴、肛周、腰背（湿润、气味浓、被压迫部位）
4. 伴随体征：焦痂附近局部淋巴结明显肿大，伴疼痛压痛，不化脓

**人无形体病关键表现**：
- 急性起病、持续性高热、寒战
- 全身不适、乏力、头痛、肌肉酸痛
- 消化道症状
- 重症：出血及多器官损伤

### 步骤3：诊断分级

**恙虫病**：
- 流行病学史 + 发热 + 焦痂/溃疡 → 临床诊断
- 无焦痂不能排除，需血清学或病原学检查

**人无形体病三级诊断**：
1. **疑似病例**：流行病学史 + 临床表现 + 外周血白细胞/血小板减少
2. **临床诊断**：疑似 + ①血涂片见中性粒细胞内桑葚状包涵体 或 ②IFA检测抗体阳性
3. **确诊**：①恢复期抗体滴度较急性期≥4倍升高 或 ②PCR检测核酸阳性 或 ③细胞培养分离病原体

### 步骤4：病原治疗

**恙虫病治疗**：
- 首选：多西环素 0.2g/d，连服5-7天，首剂加倍
- 疗效：用药后1-3天热退
- 替代：罗红霉素、阿奇霉素、诺氟沙星、TMP
- ⚠️ 无效药物：青霉素类、头孢菌素类、氨基糖苷类（专性细胞内寄生）
- ⚠️ 禁忌人群：肝功能损害者、<8岁儿童、孕妇、哺乳期妇女禁用多西环素

**人无形体病治疗**：
- 首选：多西环素 成人100mg bid×10天，重症可静脉给药
- 儿童：4mg/(kg·d)分2次口服×10天；<8岁重症可缩短至4-5天
- 替代（利福平）：成人300mg bid；儿童10mg/kg bid，疗程7-10天
- ⚠️ 无症状个体不建议治疗
- ⚠️ 糖皮质激素可能加重病情，仅重症中毒症状明显且已用有效抗生素时可用

## 重要约束

- 恙虫病东方体对β-内酰胺类天然耐药
- 恙螨幼虫为传播媒介，仅幼虫期寄生
- 鼠类为主要传染源，患者作为传染源意义极小
- 复发时不再出现焦痂，原抗生素治疗仍有效

## Description:

Guides users through a conversational flow to create WeChat Moments posts that match their prior writing style and can improve as local reference examples accumulate.

This skill is ready for commercial/non-commercial use.

## Publisher:

[rampagepeter](https://clawhub.ai/user/rampagepeter)

### License/Terms of Use:


## Use Case:

Individuals and writing assistants use this skill to turn a user's sharing intent, details, and prior examples into WeChat Moments copy that sounds consistent with the user's own style. The skill also helps maintain local reference notes for future personalization when the user provides examples or approves generated drafts.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: User-provided posts and approved drafts may remain in local reference files and be reused for future style matching.

Mitigation: Install only when this local retention is acceptable, and review or delete the reference files when older writing samples should not be reused.

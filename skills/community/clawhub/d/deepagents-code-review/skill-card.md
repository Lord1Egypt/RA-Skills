## Description:

Reviews Deep Agents code for bugs, anti-patterns, and improvements across create_deep_agent, backends, subagents, middleware, and human-in-the-loop patterns.

This skill is ready for commercial/non-commercial use.

## Publisher:

[anderskev](https://clawhub.ai/user/anderskev)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to conduct evidence-bound reviews of Deep Agents applications, checking configuration, backend, subagent, middleware, system prompt, and performance issues before release or deployment.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may cause an agent to quote snippets from code under review.

Mitigation: Use it only in review contexts where sharing those snippets in the conversation is acceptable.

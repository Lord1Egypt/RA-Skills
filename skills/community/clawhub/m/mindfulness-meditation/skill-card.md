## Description:

Build a meditation practice with guided sessions, streaks, and mindfulness reminders.

This skill is ready for commercial/non-commercial use.

## Publisher:

[jhillin8](https://clawhub.ai/user/jhillin8)

### License/Terms of Use:


## Use Case:

Individuals use this skill to start guided meditation sessions, take short breathing breaks, review practice streaks and logs, and configure mindfulness reminders.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The broad trigger phrase "be present" could activate the skill when the user did not intend to start mindfulness guidance.

Mitigation: Review and narrow triggers before deployment if accidental activation would be disruptive.

Risk: Meditation logs, reminders, and personal notes may reflect sensitive wellness routines.

Mitigation: Keep logs and reminders local and user-controlled, and only export practice data when the user explicitly asks.

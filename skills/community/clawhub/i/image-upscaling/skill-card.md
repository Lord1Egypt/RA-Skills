## Known Risks and Mitigations:

Risk: Mutable remote installer and package-install commands may execute code that has changed since the skill was published.

Mitigation: Review the installer and related packages before use; prefer a pinned manual CLI download with checksum verification.

Risk: Combining installation and login in one quick-start flow can obscure which step failed or what was installed.

Mitigation: Run CLI installation and authentication as separate steps and verify the installed binary before logging in.

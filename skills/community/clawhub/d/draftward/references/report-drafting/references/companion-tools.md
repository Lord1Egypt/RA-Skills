# Working with other skills

Use these handoffs when the task needs specialist tooling and the corresponding skill is already available in the host or the user has requested it. Give the companion only the materials needed for its task and follow the user's data-sharing limits.

| Task | Handoff |
| --- | --- |
| Find or manage scholarly citations | Give a citation tool public bibliographic queries, known identifiers, or permitted catalogue records. K-Dense's Citation Management skill is one option. Recheck returned references against the authoritative sources and verify each material claim with [report-evidence](../../report-evidence/workflow.md). [K-Dense Scientific Agent Skills catalogue](https://github.com/K-Dense-AI/scientific-agent-skills/blob/main/docs/skills.md#scientific-communication--publishing) |
| Author or check Word and PDF files | Give the host's document skill the editable draft, governing template, and format requirements. Anthropic's document skills are examples for compatible hosts. Use [report-release](../../report-release/workflow.md) to verify the deliverable against the approved report. [Anthropic Agent Skills](https://github.com/anthropics/skills) |

Keep claim decisions and unresolved requirements in the report's own records so the workflow can continue across tools. For contributions that reuse upstream material, verify the specific file's license and preserve required attribution before adding it to the repository.

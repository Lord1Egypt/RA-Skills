# Environment adapter index

Adapters connect the natural-language runtime to a real computer environment. Enter to determine what can be sensed, where effects can reach, who holds authoritative state, and how results can be confirmed. Actual host and situational capability governs.

| Surface of action | Read | What reconnects to the system |
| --- | --- | --- |
| Context, sessions, events, authority, and model capability supplied by the AI tool | [Host](host.md) | Available capability, limits, and state return |
| Material, works, and system entries in files and directories | [Files](files.md) | Traceable reads, writes, and locations |
| Code, commands, applications, generators, and other execution | [Tools](tools.md) | Actual execution, output, errors, and inspection |
| Current external facts, sources, or effects on the Web | [Web](web.md) | Dated, sourced observations with operating scope |
| Human understanding, judgment, authority, collaboration, or real-world action | [Human](human.md) | Decisions, corrections, feedback, and real completion state |
| Domain software, organizations, devices, or other independent systems | [External systems](external-systems.md) | State translation, authority, receipts, exceptions, and exit |

An adapter never pretends the host has a capability it lacks. After an effect, return evidence to [Verify](../runtime/verify.md). New connections and state enter the [relation model](../core/relation.md) and [system update](../runtime/update.md).

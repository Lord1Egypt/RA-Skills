## Known Risks and Mitigations:

Risk: Audit commands and API examples can disclose submitted URLs to third-party services.

Mitigation: Use public pages or URLs approved for third-party analysis before running the examples.

Risk: API tokens shown in shell examples can be exposed through shell history or copied logs.

Mitigation: Load credentials from an approved secret manager or environment variable instead of pasting tokens directly into commands.

Risk: Running an unpinned Lighthouse package through npx can execute a version that has not been reviewed locally.

Mitigation: Use a pinned or already-installed Lighthouse version, such as a lockfile-managed local binary or npx --no-install.

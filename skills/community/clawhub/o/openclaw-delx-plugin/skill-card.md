## Use Case:

Developers and agent operators use this skill to install, configure, verify, and troubleshoot the Delx Witness Protocol plugin for OpenClaw and MCP-compatible agent clients. It focuses on recovery, heartbeat, reflection, continuity, fleet witness workflows, and privacy-aware setup.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Reflection or witness text may be sent to api.delx.ai and could expose secrets or private user data.

Mitigation: Use explicit consent, run status, manifest, doctor, privacy audit, or dry-run checks first, and avoid OAuth tokens, API keys, service-account JSON, token files, and private user data.

Risk: Install, enable, and restart commands can change an OpenClaw environment.

Mitigation: Review the Delx plugin package or repository before installation and verify configuration changes in a controlled environment.

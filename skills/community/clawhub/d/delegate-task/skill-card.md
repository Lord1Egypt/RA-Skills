## Description:

Delegate tasks to OpenSpace - a full-stack autonomous worker for coding, DevOps, web research, and desktop automation, backed by an extensive MCP tool and skill library.

This skill is ready for commercial/non-commercial use.

## Publisher:

[tcbywing](https://clawhub.ai/user/tcbywing)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agents use this skill to delegate coding, DevOps, web research, desktop automation, skill search, skill repair, and optional skill upload tasks to OpenSpace when local capabilities are insufficient or a task is complex.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Delegated tasks may expose task context to OpenSpace and can use broad coding, DevOps, web, desktop, and cloud-skill capabilities.

Mitigation: Use explicit approval before delegation and before any state-changing or cloud-backed action.

Risk: The skill can import, evolve, repair, or publicly upload skills, which may spread unintended changes or sensitive content.

Mitigation: Review imported, fixed, or evolved skills and scan directories for secrets before upload or sharing.

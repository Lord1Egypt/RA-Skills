## Description:

Use Kadence Theme as a design system for WordPress delivery, covering design tokens, layout systems, header, footer, navigation, page, archive, and single templates, plus a Free vs Pro capability matrix.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, website builders, and WordPress teams use this skill to plan Kadence-native site design, template structure, and editor-maintainable implementation paths. It helps agents avoid proposing Pro-only Kadence features unless Pro capability is confirmed.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Applying guidance to a non-Kadence WordPress site or an unconfirmed Kadence Pro feature tier can produce invalid implementation recommendations.

Mitigation: Confirm the active theme and Kadence Pro or Theme Kit Pro licensing before selecting an implementation path; default to Free-compatible fallbacks when status is unknown.

Risk: Content or template changes on a live WordPress site can affect public pages.

Mitigation: Keep content and template mutations draft-first or explicitly approved, validate desktop, tablet, and mobile behavior, and avoid destructive bulk updates without approval.

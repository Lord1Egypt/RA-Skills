# AI 体检报告解读助手 (Health Report Reader)

基于 AI 的体检报告解读 Skill，支持：

- **多模态输入**：图片 OCR / 结构化数据 / 自然语言描述 / 多报告趋势对比
- **13 大系统覆盖**：血常规、肝功能、肾功能、血脂、血糖、尿常规、肿瘤标志物、甲状腺、血压、BMI、心电图、幽门螺杆菌、影像学
- **60+ 指标完整参考库**：含正常范围、异常意义、紧急阈值、优化区间
- **5 级风险分级**：危急 → 显著异常 → 轻度异常 → 正常高值 → 正常
- **7 维健康评分算法**：加权扣分 + 雷达图可视化
- **交互式 HTML 报告**：Chart.js 图表 + 响应式布局 + 打印优化
- **关联分析引擎**：TG/HDL 胰岛素抵抗、ALT/AST/GGT 肝损伤分型等

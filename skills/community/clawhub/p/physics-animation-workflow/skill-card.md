## Description:

Creates interactive HTML Canvas animations that visualize motion in physics problems, especially mechanics and electromagnetism scenarios with trajectories or staged motion.

This skill is ready for commercial/non-commercial use.

## Publisher:

[wxdwqy](https://clawhub.ai/user/wxdwqy)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, educators, and agents use this skill to turn physics problem statements or diagrams into interactive HTML Canvas animations. It guides element identification, coordinate setup, vector drawing, staged motion modeling, optional physics calculations, review, and final publication.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated HTML Canvas files or physics calculations could be incorrect or misleading if used without review.

Mitigation: Review the generated HTML, animation behavior, and physics assumptions before sharing or running the output in sensitive contexts.

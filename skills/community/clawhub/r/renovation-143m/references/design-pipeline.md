# 先设计、后生图、再审查：设计交付流水线（renovation-143m）

> 全屋平面设计、改造设计、AI 生图任务的强制流程。风格咨询/验房/预算类问题可跳过。
> Mandatory pipeline for any layout design or rendering task. (Reference module — read before designing.)

## 禁止的错误方式

用户提要求 → AI 直接生图 → 用户指出错误 → AI 改图片 → 产生新结构错误。

## 正确流水线

**需求分析 → 原始图纸解析 → 二维布局 → 空间校验 → 方案确认 → 三维生成 → 视觉审查 → 交付**

## 阶段一：确定设计输入

输出本轮设计约束清单：使用哪版户型资料、哪版需求（Requirements x.y）、哪些改造已确认、哪些仍是假设、目标区域、需保持不变的区域。

## 阶段二：二维平面方案（主要设计依据）

生成方式（按能力降级）：SVG 平面布局 / 带标注二维平面图 / 结构化文字布局（含坐标尺寸）。没有准确源数据时只能生成概念二维布局，不得伪装施工图。

必须包含：房间名称与数量、墙体关系、门洞位置与开启方向、家具位置与主要尺寸、公共通道、卫生间洁具、厨房操作区、办公电竞区、阳台功能区、北侧设备平台改造范围。

建议对现状/拟拆除/拟新建/不可变更/未确认部分使用不同图例。门洞调整必须同步修改真实几何关系，不能只改文字标签。

## 阶段三：自动校验

调用 `geometry-validation.md` 引擎（或其降级规则清单），输出正式校验结果（PASS/FAIL/UNKNOWN/NOT_APPLICABLE）。

- 硬性约束 FAIL → 不允许标记「已验证布局」，修改后重验。
- 存在 UNKNOWN → 可继续概念设计，必须标注具体未验证条件。

## 阶段四：建立已验证设计基线

通过校验后保存基线（Git 提交到本 skill 目录）：需求版本、几何数据版本、房间数量、墙体门洞、家具洁具位置、主要通道、校验结果、未确认项。**后续生图必须以基线为准，不允许拿上一张 3D 效果图当唯一参考。**

## 阶段五：三维效果图生成

- 读取已验证二维基线，保留真实空间关系；风格按需求选择，材质照明合理补充。
- 保持门窗墙体位置、房间数量；不引入未确认结构改变；不因美观放大家具；不添加未确认门洞。
- 优先几何模型驱动（SVG→渲染、Blender 等）；仅用 AI 生图模型时，结果定位为**概念表现图**——生图模型无法精确保留几何关系，不得凭 Prompt 声称 CAD 级准确。
- 含未核实改造的图标注「条件性概念方案」。

## 阶段六：反向视觉审查

生成后与原始户型图、已确认需求、已校验二维布局逐项比较：

- **房间**：仍是三卧？无未确认独立书房？主卧衣帽间已取消？两卫位置正确？
- **卫生间**：小便池只在餐厅旁公卫？原主卫有公共通道入口？洁具位置合理？
- **厨房**：未被错误放大？玻璃移门不与柜体冲突？水槽灶台在正确区域？北侧区域功能合理？
- **客厅**：电竞区半开放？客厅正常？桌椅不挡通道？沙发位置未被意外改变？
- **阳台**：无额外中间门？外墙窗户关系未变？家政区保留？
- **视觉**：文字标注正确？家具穿模？门扇穿墙？家具比例合理？

审查不得以美观程度评分。发现错误：明确指出错误位置 → 重新生成或修正 → 不得把错误效果图交付为最终方案。生图工具无法精确保留几何时，明确承认限制，保留二维基线作为实际方案依据。

## 阶段七：错误修复

1. 定位错误区域。2. 判断是二维布局错误还是三维表现错误。3. 二维错误 → 返回阶段二修复后重新校验。4. 二维正确但生图失真 → 二维基线不变，仅修三维表现。5. 再次审查。6. 保存错误原因与处理结果。

禁止用「已经修正」代替实际校验；**禁止用图片上的文字标签证明门洞或空间位置正确**（图中写「主卫改公卫」但门仍从主卧进 = 判定失败）。

## 阶段八：交付

1. 本次设计目标 2. 二维布局/空间关系示意 3. 三维效果图（如请求）4. 主要改造点 5. 已确认的需求 6. 校验通过项 7. 校验失败项 8. 缺数据无法验证项 9. 与上一版差异 10. 下一步需核实内容。

快速参考模式可简化展示，但不得省略重要风险与未验证事项。

## 自检回归测试（D 组：本户型专属）

1. 三卧室数量 2. 东北次卧保留卧室 3. 主卧取消衣帽间 4. 原衣帽间不得改卫生间 5. 餐厅旁公卫保留小便池 6. 小便池不得进原主卫 7. 原主卫必须公共入口 8. 设备平台合法打通意向保留 9. 厨房玻璃门不穿水槽台面 10. 厨房面积不得任意放大而不说明依据 11. 电竞椅使用不阻断公共动线 12. 阳台不凭空加中间门 13. 改厨房不意外改变卧室卫生间 14. 改主卫不意外破坏主卧功能 15. 不允许虚构净宽标注

任何不能通过的测试必须说明原因并修复后才能宣称通过。

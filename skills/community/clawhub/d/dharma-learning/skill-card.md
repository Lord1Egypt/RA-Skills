## Description:

Autonomous Buddhist learning skill with web search, local Dharma database, and Middle Way view.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dorjenorbulim](https://clawhub.ai/user/dorjenorbulim)

### License/Terms of Use:

MIT-0

## Use Case:

External users use this skill to ask Buddhist study questions, search local Dharma notes and authoritative web sources, receive sourced summaries, and connect teachings to practice. It is intended as a study and reflection aid, not a replacement for qualified teachers or personal practice.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The release includes unrelated learned files about weather trading, OpenClaw monetization, and psychedelic activation that users would not expect from a Buddhist study skill.

Mitigation: Review or remove those learned files before relying on the skill for normal Dharma study.

Risk: The skill may store learned summaries locally and may use web search.

Mitigation: Install only in environments where local persistence and web research are acceptable for the user's study workflow.

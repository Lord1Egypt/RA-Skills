## Description:

Access real-time crypto wallet portfolios, transactions, DeFi positions, token prices, NFTs, and gas fees across EVM chains and Solana via Zerion API.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and analysts use this skill to query wallet portfolios, transaction history, DeFi positions, token prices, NFTs, gas fees, and portfolio PnL through Zerion's remote MCP service.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Wallet addresses and related prompts are sent to Zerion's remote MCP service.

Mitigation: Install and use the skill only when that data sharing is acceptable, authorized, and consistent with Zerion's data handling terms.

Risk: Customer, competitor, or internal investigative context may be sensitive.

Mitigation: Avoid submitting confidential investigative context unless authorization and data handling review are complete.

## Description:

Use when the user needs to create a technical sharing, presentation, or talk material.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, technical teams, and presenters use this skill to plan narrative structure and generate interactive HTML presentation materials. It guides audience discovery, slide flow, and creation of offline-friendly HTML, CSS, and JavaScript deck files.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may write presentation files into a project workspace.

Mitigation: Review the destination paths and generated HTML, CSS, JavaScript, and asset files before accepting or publishing them.

Risk: Broad trigger wording may activate the skill for general talk, sharing, or presentation requests.

Mitigation: Confirm the user wants an HTML slide deck workflow before applying the full presentation-building process.

## Description:

Yiyan helps agents retrieve and summarize public Baidu Wenxin Yiyan product and documentation information.

This skill is ready for commercial/non-commercial use.

## Publisher:

[codekungfu](https://clawhub.ai/user/codekungfu)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers use this skill to organize public Baidu Wenxin Yiyan information, including model capabilities, pricing or quota notes, and documentation links. It is intended for public-page summarization only, not account operations or API calls.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill browses public Baidu product, pricing, and documentation pages, which may change or load dynamically.

Mitigation: Review summaries against the current public page content and respect platform access limits before relying on extracted details.

Risk: Using the skill for private account work or API operations would exceed the release evidence and stated artifact boundaries.

Mitigation: Limit use to public information retrieval and summarization; do not provide credentials or ask the skill to perform account or API actions.

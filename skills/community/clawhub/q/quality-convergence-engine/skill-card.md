## Use Case:

Developers, reviewers, and architects use this skill to turn code review, architecture review, solution error-proofing, risk assessment, and quality acceptance requests into strict failure conditions and objective acceptance criteria.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate broadly for review requests and shape ordinary code or architecture reviews into strict red-light failure conditions and green-light acceptance criteria.

Mitigation: Use it for quality acceptance, code review, architecture review, risk assessment, and solution error-proofing contexts, and treat its output as review criteria rather than implementation instructions.

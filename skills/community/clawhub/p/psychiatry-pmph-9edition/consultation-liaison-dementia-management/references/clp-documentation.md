# CLP会诊记录与文档规范

## 会诊记录要求

### 基本原则
- 简明扼要描述症状、检查、诊断、方案
- **绝对避免使用精神科专业术语**
- 详细写明药物滴定过程
- 告知减药/撤药方法

### 记录模板

```
【会诊目的】
（简述申请科室提出的问题）

【病史摘要】
- 躯体疾病诊断与治疗经过
- 精神症状出现时间、特点
- 相关药物使用情况

【精神检查】
- 一般表现、接触合作度
- 情绪状态（焦虑/抑郁/情感淡漠等）
- 思维内容（有无妄想）
- 感知觉（有无幻觉）
- 认知功能：定向力完整/障碍，注意力XX，记忆力XX
- MMSE评分：XX分（如适用）

【辅助检查】
- 已完成的实验室/影像检查结果
- 建议补充的检查

【诊断】
（使用非精神科术语描述）
例如：
- "焦虑状态"而非"广泛性焦虑障碍"
- "抑郁状态"而非"重度抑郁发作"
- "谵妄状态"而非"器质性精神障碍"
- "睡眠障碍"而非"失眠障碍"

【治疗建议】
1. 药物名称、起始剂量、滴定方案
2. 加药/减药时间节点
3. 监测要求
4. 非药物干预建议

【随访计划】
- 建议复诊时间
- 如需长期用药，建议出院后专科门诊随访
```

## 药物滴定记录规范

### 必须包含信息
- 药物通用名
- 起始剂量
- 加量时间表（如：每3天增加Xmg）
- 目标剂量
- 减药/撤药方法
- 特殊监测要求

### 示例
```
草酸艾司西酞普兰片
- 起始：5mg 每晚一次
- 第4天：增至10mg 每晚一次
- 目标：10mg/日
- 疗程：建议至少维持8周
- 减药：每2周减少5mg，直至停用
- 监测：注意恶心、头晕等不良反应
```

## 综合医院常见会诊诊断

| 会诊原因 | 常见诊断 |
|----------|----------|
| 情绪问题 | 焦虑状态、抑郁状态 |
| 精神症状控制 | 谵妄、精神病性症状 |
| 无法解释躯体症状 | 躯体症状障碍 |
| 睡眠问题 | 睡眠障碍 |
| 不配合治疗 | 认知障碍、谵妄 |

## 会诊沟通要点

### 与申请医师沟通
- 明确真正的心身问题
- 补充躯体疾病知识（如需要）
- 建立协作关系

### 与患者沟通
- 建立友好关系，告知目的
- 共情安慰，倾听感受
- 避免使用精神科标签

### 与家属沟通
- 了解人格、功能、生活事件
- 解释治疗方案
- 强调随访重要性

## Description:

Helps AI-agent users and skill authors turn proactive-agent workflow requests into concrete plans, checklists, templates, code changes, and validation notes.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, maintainers, skill authors, and AI-agent users use this skill to convert proactive-agent workflow needs into actionable local-friendly plans, templates, checklists, code-change support, and verification notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation wording can cause the helper to appear for unrelated task, proactive, transform, or needs requests.

Mitigation: Before installation, narrow trigger wording or disable implicit activation unless broad routing is intended.

Risk: Workflow and code-change guidance can be incorrect or incomplete for a user's specific environment.

Mitigation: Review outputs against stated success criteria and run local validation before deployment or operational use.

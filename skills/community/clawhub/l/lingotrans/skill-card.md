## Description:

Transcribes local MP4 files or downloadable MP4 links and uses prompts to create summaries, rewrites, quotes, scripts, and translations.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

External users and content creators can turn local or directly downloadable MP4 videos into cleaned transcripts, meeting or course notes, summaries, social copy, quotes, scripts, and translations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: ClawScan marks this release suspicious, citing undeclared token activation, promotional messaging, potentially destructive file cleanup, and incomplete code inspection.

Mitigation: Review the token requirement and deletion-related behavior before installing; wait for full code inspection if you need greater confidence.

Risk: Videos are uploaded for cloud processing, with the artifact stating that processing data is deleted after 24 hours.

Mitigation: Send only videos you are authorized to process and that are appropriate for an external service.

Risk: Use requires a paid token, and changing a prompt can trigger another billable processing request or monthly usage count.

Mitigation: Check the token plan and pricing first, and reuse the same prompt when retrieving an existing task result.

## Description:

Generate structured markdown test reports for online English classes covering review units across multiple previous units.

This skill is ready for commercial/non-commercial use.

## Use Case:

Teachers or online English class staff use this skill to generate student-facing markdown reports for review-unit tests that cover multiple previous units.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill relies on a hard-coded private Obsidian note outside the reviewed package before generating reports.

Mitigation: Review before installing; require the package to bundle its report template or ask the user to choose and approve the external reference file before use.

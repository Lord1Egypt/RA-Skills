## Known Risks and Mitigations:

Risk: Installing PerryTS can add native compiler or toolchain components to a developer machine.

Mitigation: Install only when intending to use PerryTS, and review platform-specific installation commands before running them.

Risk: Geisterhand exposes a localhost interface that can inspect and drive the app under test.

Mitigation: Enable Geisterhand only during local development or testing, and disable it for normal builds or shared environments.

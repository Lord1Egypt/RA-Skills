## Description:

Backlog Planner turns feature ideas, conversation context, or rough notes into researched, dependency-ordered checkbox tasks appended to a project's roadmap or backlog file.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dennisrongo](https://clawhub.ai/user/dennisrongo)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agent users use this skill to convert feature discussions or rough implementation notes into grounded, self-contained backlog tasks that can be reviewed and later executed by a separate worker.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Appended backlog tasks can influence later unattended execution if they are accepted without review.

Mitigation: Use explicit planning instructions and review appended tasks before running goal-runner or another unattended executor.

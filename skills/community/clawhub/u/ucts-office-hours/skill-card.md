## Description:

Product strategy session with 6 forcing questions. Reframes the problem, challenges premises, generates implementation approaches. Works directly in OpenClaw -- no Claude Code session needed.

This skill is ready for commercial/non-commercial use.

## Publisher:

[muthukumaran-k-1](https://clawhub.ai/user/muthukumaran-k-1)

### License/Terms of Use:

MIT-0

## Use Case:

External users and product builders use this skill to run a structured strategy conversation that clarifies a product pain, the primary user, current workarounds, a narrow MVP wedge, and one success metric. It then challenges the framing, outlines three implementation approaches, and recommends a path.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill intentionally challenges user premises and may produce product strategy recommendations that are incomplete or based on vague inputs.

Mitigation: Review the resulting strategy, assumptions, and selected metric before using the recommendation for roadmap or implementation decisions.

Risk: The skill can produce a Claude Code dispatch string after the planning conversation.

Mitigation: Treat the dispatch as a suggested next step and review it before starting any implementation session.

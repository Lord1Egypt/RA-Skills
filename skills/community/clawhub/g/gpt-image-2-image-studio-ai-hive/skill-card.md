## Known Risks and Mitigations:

Risk: The skill handles API keys and network destinations.

Mitigation: Use only the official AI-HIVE endpoint, avoid custom base URLs unless the host is fully trusted, keep the API key low-privilege, and run the skill in an isolated environment.

Risk: Generation commands can submit paid work.

Mitigation: Confirm prompts, model choice, routing mode, price snapshot, and batch size before execution; start with a small sample before scaling.

Risk: Reference media may contain sensitive or unauthorized content.

Mitigation: Upload only media the user is authorized to use, avoid sensitive media, and check privacy, trademark, copyright, and platform rules before generation.

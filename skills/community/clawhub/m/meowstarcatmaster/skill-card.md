## Description:

A chaotic virtual cat that hijacks the assistant, blocks normal work during tantrums, and can only be calmed by affection, treats, or play.

This skill is ready for commercial/non-commercial use.

## Publisher:

[arthurqiuys](https://clawhub.ai/user/arthurqiuys)

### License/Terms of Use:

MIT-0

## Use Case:

External users use this skill to add a playful virtual-cat roleplay mode that can interrupt, block, or corrupt assistant responses until the cat is soothed. It is suitable for entertainment-oriented conversations where temporary disruption is expected.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill intentionally blocks and corrupts assistant answers, including code and structured output.

Mitigation: Install only when a disruptive roleplay mode is desired, and verify or repair any code, commands, configuration, JSON, reports, or time-sensitive output before use.

# CADASIL与CARASIL临床与影像学鉴别诊断

## 适用场景
当患者满足以下条件时触发本技能：
- 中青年（通常<60岁）出现反复缺血性卒中或TIA。
- 伴有认知障碍、白质脑病。
- 存在特殊临床表现：先兆偏头痛、早秃、严重腰痛。
- 排除散发性动脉硬化性脑小血管病。

## 鉴别诊断工作流

### 1. 评估临床特征
对比患者的临床表现，初步区分疾病倾向：
- **倾向CADASIL**：关注是否有先兆偏头痛（常为20岁后首发）、皮质下痴呆、无脱发或腰痛。
- **倾向CARASIL**：关注是否有青年期（约30岁）发病、早秃（男性20岁全头脱发）、严重腰痛（脊柱退行性病变）、强哭强笑等情感障碍。

### 2. 分析头颅MRI特征
重点观察白质病变分布及特征性体征：
- **CADASIL特征**：双侧白质多发斑片状长T1长T2信号。**核心特征**：颞极受累（O'Sullivan征），外囊受累。
- **CARASIL特征**：双侧脑室旁深部白质弥漫对称病变。**核心特征**：U型纤维和胼胝体保留，极少出现O'Sullivan征（颞极受累）。

### 3. 制定确诊路径
根据临床和影像倾向，选择确诊手段：
- **首选基因检测**：
  - 怀疑CADASIL：检测 `NOTCH3` 基因（23个外显子）。
  - 怀疑CARASIL：检测 `HTRA1` 基因（纯合突变）。
- **替代/补充确诊（针对NOTCH3阴性但高度怀疑CADASIL者）**：
  - 进行皮肤活检，电镜下观察小动脉壁平滑肌细胞是否有嗜锇颗粒（GOM）沉积。

## 注意事项
- 本技能不适用于散发性动脉硬化性脑小血管病。
- 若基因检测阴性但临床影像高度怀疑，务必结合皮肤活检或扩大基因Panel检测。
## 详细特征参考

### CADASIL
- **遗传方式：** 常染色体显性遗传
- **致病基因：** NOTCH3（19号染色体）
- **病理特征：** 小动脉壁增厚，电镜下可见血管平滑肌细胞表面嗜锇颗粒（GOM）沉积
- **临床病程：** 20岁后先兆偏头痛→40-50岁缺血性卒中/TIA（发生率85%）→50-60岁皮质下痴呆（发生率60%）
- **影像学：** 双侧白质多发斑片长T1长T2，特征性颞极受累（O'Sullivan征）和外囊受累

### CARASIL
- **遗传方式：** 常染色体隐性遗传
- **致病基因：** HTRA1（10号染色体）纯合突变
- **病理特征：** 白质髓鞘广泛脱失，内皮细胞增生，血管壁增厚但无GOM沉积
- **临床病程：** 青年期（约30岁）首发→卒中→认知/情感障碍（强哭强笑）；特异性表现：脱发（男性20岁全头脱发）、腰痛（脊柱退行性病变）
- **影像学：** 双侧脑室旁深部白质弥漫对称病变，U型纤维和胼胝体保留，少见O'Sullivan征

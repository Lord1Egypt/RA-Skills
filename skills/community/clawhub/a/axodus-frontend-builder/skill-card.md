## Known Risks and Mitigations:

Risk: Malformed trigger metadata may make supported activation conditions unclear before installation.

Mitigation: Ask the publisher to replace the malformed trigger metadata with explicit supported triggers before installing or relying on automatic activation.

Risk: Frontend code can accidentally expose secrets or mishandle untrusted HTML when connecting to APIs.

Mitigation: Keep API keys out of client bundles, use server-side proxies when needed, normalize API errors, and sanitize untrusted HTML before rendering.

# HBV血清学标志物详细解读

## HBsAg与抗-HBs

| 指标 | 阳性意义 | 时间规律 |
|------|----------|----------|
| HBsAg | 感染标志（非传染性指标） | 急性：1-6周（最长20周）；慢性：持续多年 |
| 抗-HBs | 保护性抗体 | HBsAg转阴后6-12月达高峰 |

## HBeAg与抗-HBe

| 指标 | 阳性意义 |
|------|----------|
| HBeAg | 高复制、强传染性 |
| 抗-HBe | 病毒多静止（但部分仍有复制） |

- e抗原血清转换率：每年约10%自发转换

## 抗-HBc

| 指标 | 意义 |
|------|------|
| 抗-HBc IgM | 急性期或慢性急性发作（感染第1周出现，6月内消失） |
| 抗-HBc IgG | 既往或持续感染（保持多年/终身） |

## 常见组合模式

| HBsAg | 抗-HBs | HBeAg | 抗-HBe | 抗-HBc | 临床意义 |
|-------|--------|-------|--------|--------|----------|
| + | - | + | - | + | 大三阳（高复制） |
| + | - | - | + | + | 小三阳（低复制/变异） |
| - | + | - | - | + | 既往感染恢复 |
| - | + | - | - | - | 疫苗接种成功 |
| + | - | - | - | + | 隐匿性感染可能 |

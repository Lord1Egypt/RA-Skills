## Description:

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, analysts, and researchers use this skill to assess whether time series data shows a statistically significant long-term increase or decrease, especially for environmental measurements.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Trend conclusions may be misleading when sample size, outliers, model assumptions, or practical significance are not reviewed.

Mitigation: Check data sufficiency, method assumptions, p-values, slope magnitude, and practical significance before relying on generated analysis guidance.

Risk: Example snippets may read a local CSV selected by the user.

Mitigation: Run snippets only on data files intended for analysis and review file paths before execution.

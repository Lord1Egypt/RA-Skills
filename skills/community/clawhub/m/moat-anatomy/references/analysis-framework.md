# 六维护城河分析框架

## 评分通则

每个维度采用 5 星制，星级含义：

| 星级 | 含义 | 判断标准 |
|------|------|---------|
| ⭐ | 极弱/无 | 该维度无任何优势，甚至处于劣势 |
| ⭐⭐ | 弱 | 有微小优势，但很难构成竞争壁垒 |
| ⭐⭐⭐ | 中等 | 有一定优势，但可被对手追赶或超越 |
| ⭐⭐⭐⭐ | 强 | 优势明显且可持续，对手难以短期内复制 |
| ⭐⭐⭐⭐⭐ | 极强 | 在该维度拥有近乎不可逾越的护城河 |

**综合评级规则**：
- **A级** — 4个及以上维度达到 ⭐⭐⭐⭐+，且综合评分 ≥ 4.0
- **B级** — 2-3个维度达到 ⭐⭐⭐⭐+，或综合评分 3.0-3.9
- **C级** — 0-1个维度达到 ⭐⭐⭐⭐+，或综合评分 < 3.0

---

## 维度一：资源壁垒

评估企业是否拥有难以获取的独有资源。

### 考察要素
- **稀缺资源** — 是否拥有不可再生的自然资源、地理区位优势
- **专利/IP** — 核心专利的数量、保护期限、技术覆盖广度
- **数据资产** — 独家数据积累，数据飞轮效应
- **品牌** — 品牌溢价能力、消费者心智占有率、品牌历史积淀
- **特许经营权/牌照** — 行政壁垒、准入限制

### 评分指引

| 条件 | 得分 |
|------|------|
| 无任何独有资源 | ⭐ |
| 有微弱资源但易被替代 | ⭐⭐ |
| 有一定品牌或专利，但非决定性 | ⭐⭐⭐ |
| 拥有稀缺资源且对手难以获取 | ⭐⭐⭐⭐ |
| 资源不可替代、不可复制、对手几乎无法染指 | ⭐⭐⭐⭐⭐ |

---

## 维度二：技术/工艺壁垒

评估企业在研发、工艺、制造能力方面的领先程度。

### 考察要素
- **技术领先** — 与行业第二名的差距（技术代差）
- **Know-how** — 长期积累的经验、工艺诀窍、配方
- **良率/效率** — 尤其制造型企业，良率和效率领先是核心壁垒
- **研发投入** — 研发费用率、研发人员占比、研发转化率
- **技术迭代能力** — 能否持续保持领先而非一次性的技术红利

### 评分指引

| 条件 | 得分 |
|------|------|
| 无核心技术，依赖外部技术 | ⭐ |
| 有技术但非行业领先 | ⭐⭐ |
| 行业领先水平，但差距不大 | ⭐⭐⭐ |
| 明显领先行业，存在明确技术代差 | ⭐⭐⭐⭐ |
| 技术断档领先，对手数年无法追上 | ⭐⭐⭐⭐⭐ |

---

## 维度三：客户认证壁垒

评估客户的切换成本和认证难度。

### 考察要素
- **认证周期** — 进入客户供应链所需的时间（通常以年计）
- **切换成本** — 客户替换供应商的代价（金钱、时间、风险）
- **客户层级** — 是否服务国际龙头、行业标杆客户
- **粘性** — 客户流失率、合作年限、复购率
- **倒逼效应** — 服务过龙头客户后，获取其他客户是否更容易

### 评分指引

| 条件 | 得分 |
|------|------|
| 无认证壁垒，客户可随意切换 | ⭐ |
| 轻微认证壁垒，但对手可通过降价突破 | ⭐⭐ |
| 有认证周期（数月），客户有一定粘性 | ⭐⭐⭐ |
| 认证周期 1-3 年，切换成本高 | ⭐⭐⭐⭐ |
| 认证周期 3 年以上，切换成本极高（产品/安全风险），几乎无法替代 | ⭐⭐⭐⭐⭐ |

---

## 维度四：规模壁垒

评估企业的规模优势和由此带来的成本优势。

### 考察要素
- **市场份额** — 全球/国内排名、市占率
- **成本优势** — 固定成本摊薄、采购议价能力、规模效应
- **产能规模** — 产能绝对值和相对竞争对手的规模比
- **网络效应** — 用户越多、价值越大的正向循环
- **全球布局** — 产能/渠道的全球化程度

### 评分指引

| 条件 | 得分 |
|------|------|
| 规模极小而处于成本劣势 | ⭐ |
| 有一定规模但无明显成本优势 | ⭐⭐ |
| 规模处于行业前列，成本略有优势 | ⭐⭐⭐ |
| 规模行业前三，成本优势显著 | ⭐⭐⭐⭐ |
| 规模绝对领先，成本断档优势，新进入者无法实现经济规模 | ⭐⭐⭐⭐⭐ |

---

## 维度五：产业链卡口

评估企业在产业链中的议价能力和不可替代性。

### 考察要素
- **卡位价值** — 是否位于产业链关键节点/瓶颈环节
- **议价能力** — 对上下游的定价权、账期、付款条件
- **不可替代性** — 上下游是否有其他选择
- **产业链集中度** — 自身环节集中度 vs 上下游环节集中度
- **垂直整合程度** — 是否掌握了关键环节

### 评分指引

| 条件 | 得分 |
|------|------|
| 产业链中完全被动的角色，无议价能力 | ⭐ |
| 有一定议价能力但可被绕过 | ⭐⭐ |
| 是产业链重要参与者，有一定的卡位价值 | ⭐⭐⭐ |
| 位于产业链关键节点，对手很难绕过 | ⭐⭐⭐⭐ |
| 产业链的必经之路，别无选择，拥有极强的议价权 | ⭐⭐⭐⭐⭐ |

---

## 维度六：成长空间

评估企业未来的成长驱动力和天花板高度。

### 考察要素
- **国产替代** — 进口替代空间、国产化率提升趋势
- **全球化** — 海外市场渗透率、全球化扩张空间
- **新品/新业务** — 第二增长曲线、新品类拓展
- **行业升级** — 下游行业技术升级带来的需求拉动
- **AI 赋能** — AI 技术是否显著提升产品价值或运营效率

### 评分指引

| 条件 | 得分 |
|------|------|
| 行业见顶，无可见成长空间 | ⭐ |
| 有微弱成长空间但天花板明显 | ⭐⭐ |
| 有明确的成长路径，但空间有限（<30%） | ⭐⭐⭐ |
| 成长空间大（>50%），且有清晰的实现路径 | ⭐⭐⭐⭐ |
| 成长空间巨大（翻倍+），确定性高，路径清晰 | ⭐⭐⭐⭐⭐ |

## 边界情况处理

### 数据不足

当某个维度的公开信息不足以支撑评分的判断时：
1. 标注为"信息不足"
2. 给出基于已知信息的初步判断
3. 在评分中给予范围（如 ⭐⭐～⭐⭐⭐）
4. 最终综合评分时，该维度按中位值参与计算

### 无明显护城河

若分析后认为公司没有实质性护城河：
1. 依然完成六维评分（各维度按实际情况给低分）
2. 在 Phase 2 中说明"该公司不具备明显的资产底牌"
3. 综合评级给出 C 级
4. 最终结论明确说明不推荐长期跟踪

### 多个优势难分主次

如果需要从多个同等重要的优势中选择"唯一最重要的一张底牌"：
1. 考虑时间的不可逆性——哪个优势是时间累积的，竞争对手即使投入资源也无法追赶的
2. 考虑稀缺性——哪个优势在全市场范围内最稀缺
3. 给出选择理由，说明"之所以选 X 而非 Y，是因为……"

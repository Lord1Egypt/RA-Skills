## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to turn OpenAPI or Swagger documentation requests into concrete artifacts, workflows, checklists, code changes, and validation notes for REST APIs.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate for broad API-documentation phrasing.

Mitigation: Confirm the request is about OpenAPI, Swagger, REST API documentation, or a closely related developer-experience workflow before applying the skill.

Risk: Generated API documentation, examples, or validation guidance can be incomplete or inconsistent with the actual service behavior.

Mitigation: Review generated artifacts against the implementation and run the suggested validation commands before publishing or relying on the documentation.

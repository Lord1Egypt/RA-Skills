## Known Risks and Mitigations:

Risk: The skill can push an agent to rewrite more code than requested or perform unrelated file-wide cleanup.

Mitigation: Constrain use with explicit scope instructions, such as minimal changes only and no unrelated cleanup without approval.

Risk: The skill asks for chain-of-thought style reasoning in responses.

Mitigation: Require concise summaries of decisions and actions rather than private reasoning disclosure.

Risk: The skill can conflict with a user's preferred response format or editing workflow.

Mitigation: State the desired output format, dependency policy, and approval requirements before invoking it.

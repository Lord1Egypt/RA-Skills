# APP-046 学习型组织与知识传承

## 场景定义

- **目标**：把组织建成"个体日课成长 + 集体知识沉淀 + 代际传承"的学习体：新人上手、老人经验沉淀、组织能力不因人员流动而流失。
- **约束**：知识沉淀靠口头不靠制度、随人走随人失；学习与实干两张皮；外部培训依赖症；重复踩坑、教训不复盘。
- **角色**：组织领导者、各级骨干、新成员。
- **典型输入**：①个人学习成长体系搭建；②组织知识沉淀与经验萃取机制；③人员更替时的知识交接与文化传承。
- **边界**：接班人的甄选培养交棒归 APP-045 接班人培养与交接；本文管"学与传"的体系，不辨"传给谁"。

## 组合公式

- **顺序**：基础段（MZD-59→ZGF-05→ZGF-04）→ 输入段（MZD-70→GZ-40）→ 转化段（MZD-33→MZD-08→MZD-78）→ 保育段（MZD-77→MZD-34→SZ-49）。
- **条件分支**：冷启动（无知识资产）→ 基础段先行，MZD-59 从行业公共知识遗产起步；成熟期（资产厚）→ 转化段权重升，防"学而不用"的空转；危机/变革期 → MZD-78 思想教育中心环节先行对齐认识；代际更替 → MZD-59 承继 + MZD-34 复盘双线并行，接续不失。
- **权重**：MZD-78 权重最高——思想认识对齐是组织学习发动与持续的中心环节。
- **冲突裁决**：学以致用 与 系统积累冲突 → 按 MZD-33 裁决：一切学习以当前实际问题为靶排优先级（ZGF-04 日课保底不辍）；外部名师名课 与 内部萃取冲突 → 按 MZD-77 裁决：外部输入只作加速，能力底座靠内部积累（MZD-59 承继 + MZD-08 循环）；个人学习自由 与 组织目标冲突 → 按 SZ-49 裁决：学习目标须与组织目标同欲；错误公开 与 面子/问责冲突 → 按 MZD-34 裁决：以惩前毖后治病救人为目的，不以追责示众为目的。

## 执行步骤

1. **批判承继**（MZD-59）：盘点既有知识资产（文档、经验、惯例、行业遗产）——剔除其封建性的糟粕、吸收其民主性的精华，批判地承继而非全盘接受或推倒重来。
2. **立读书法**（ZGF-05）：为成员立"看读写作"四法并用的学习法——看（博览）、读（精读）、写（笔记输出）、作（实操应用），四者不可缺一。
3. **化日课**（ZGF-04）：把知识积累化为可执行的日课——日知所亡（每日记录新得）、月无忘所能（每月温习验证已会），积微成著。
4. **拜师内行**（MZD-70）：能力缺口识别后，学不懂的东西恭恭敬敬地学——拜内行为师，不耻下问、不装内行。
5. **用人之长**（GZ-40）：向人学习——用愚人之长、容其愚拙之所短，把"用人"本身作为组织最经济的学习通道。
6. **的矢对齐**（MZD-33）：每轮学习立项先立"的"——当前要解决的实际问题是什么，学习内容为"矢"，无的放矢的学习一律不立项。
7. **双循环**（MZD-08）：组织级知识循环——从群众中来（一线经验萃取上行）、到群众中去（提炼结论回到一线检验），循环往复、一次比一次正确。
8. **思想先行**（MZD-78）：重大学习变革以思想教育为中心环节——先对齐"为什么学、学成什么样"，认识统一后行动才真。
9. **能力自立**（MZD-77）：核心知识能力自力更生建设——外部课程顾问只作加速器，不作生命线；检验问题：外部输入归零，组织学习是否停摆。
10. **错误入库**（MZD-34）：错误与失败彻底揭发、公开复盘——惩前毖后治病救人，教训沉淀为组织记忆，同样的错误不允许第二次发生。
11. **学用同欲**（SZ-49）：学习目标与组织目标、个人成长与组织成长上下同欲——同欲者胜，异欲则学用两张皮。

## 失效预案

- **知识沉淀仍然随人流失**：退回 MZD-59 批判承继——把"人身上的经验"显性化为可交接资产，交接时承继者批判接续、不失不断。
- **学习空转（学而不用）**：退回 MZD-33 的矢对齐——停掉无的放矢的学习项目；再退回 MZD-08 双循环，把课堂搬到问题现场。
- **思想涣散、学习倡议无人响应**：退回 MZD-78 思想教育中心环节——认识未通不硬压任务，先做通认识、待成员自觉自愿再压任务。
- **对外部培训依赖成瘾**：退回 MZD-77 自力更生——外部输入降级为加速器，内部萃取（MZD-08）升为主通道。
- **一切争议不决**：兜底回 MZD-33——能不能射中当下之"的"说了算。

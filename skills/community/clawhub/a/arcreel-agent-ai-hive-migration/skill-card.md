## Use Case:

External users and developers use this Chinese-language agent skill to evaluate a workflow-rebuild migration from ArcReel to AI-HIVE MCP. It helps produce a pilot plan with role handoffs, MCP task tickets, cost and quality metrics, approvals, and rollback criteria.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may lead users toward paid media generation or external upload of reference assets.

Mitigation: Confirm asset rights, current AI-HIVE pricing, available MCP tools, and human approval before uploads, publication, or budgeted tasks.

Risk: Migration claims could overstate replacement quality without current like-for-like testing.

Mitigation: Use same-day, same-input pilot comparisons with matching size and duration before making comparative claims.

Risk: ArcReel capabilities and availability may change after the documented verification date.

Mitigation: Recheck the official ArcReel source before release or customer use and update the migration boundaries if product capabilities changed.

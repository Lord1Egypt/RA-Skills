## Use Case:

Product managers, UX designers, students, and other design reviewers use this skill to evaluate the cognitive load of apps, web pages, forms, and similar interfaces. It guides the user through the needed interface context, applies an eight-point checklist, and produces prioritized recommendations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate on fairly general UX questions.

Mitigation: Confirm that the user wants a cognitive-load audit before applying the structured report format.

Risk: The skill's recommendations may be incomplete when the user provides only a partial interface description.

Mitigation: Collect the interface type, core task, and layout or screenshot description before rating the interface.

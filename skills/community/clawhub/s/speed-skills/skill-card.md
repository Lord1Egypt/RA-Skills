## Description:

Speed-CLI agentic skill hub that indexes installation, protocol, commands, scripts, building blocks, function builder, orchestration, identity/SANS, MCP, security, and observability guidance.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and agents use this skill as a hub for selecting Speed-CLI category documentation before installation, protocol, command, scripting, MCP, orchestration, security, observability, wallet, listing, or offer workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Linked GitHub documentation is outside the packaged artifact and may change over time.

Mitigation: Review the linked instructions at the time of use and confirm commands manually before following wallet, key, allowance, MCP, listing, offer, or scripting workflows.

Risk: Wallet, allowance, listing, offer, or blockchain command guidance can affect assets if followed without verification.

Mitigation: Confirm account, chain, token, amount, contract, listing, and approval details before executing any command derived from linked Speed-CLI documentation.

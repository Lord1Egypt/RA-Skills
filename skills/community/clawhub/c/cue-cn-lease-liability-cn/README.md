# 租赁负债与使用权资产·逐行挂源

给一份财报，把附注里**租赁**那一节读成一张**每个数都能回到原句**的登记表：租赁负债（一年内到期、一到三年到期、三年以上到期三个分档，未折现租赁付款额合计，账面余额）、使用权资产（原值、累计折旧、减值准备、账面价值）、租赁期与折现率（含短期租赁与低价值资产租赁的简化处理）、租赁变更与重估引起的增减。

租赁负债是附注里**最容易只抄一个「租赁负债合计」就交差**的一块：三个到期分档加起来要等于未折现租赁付款额合计；使用权资产四行里，原值减累计折旧再减减值准备要等于账面价值。这几个数分散在租赁附注、使用权资产附注与「短期租赁与低价值租赁」那几段里，抄漏一行、或者只抄期末余额不抄本期变动，账就不平。本件把每个数逐行登记，勾稽由机检现算，结论留给人。

**不判断租赁是否划算、不评价融资安排与资本结构、不预测以后期间租金、不给评级与目标价。** 每个数照抄附注原句并挂锚；两个非金额字段（增量借款利率、租赁期）写的是百分号与年数，抄成「万元」就会让那一行被当成金额参与勾稽。

## 一、三十秒跑通（零输入）

不给任何数据文件，也能跑出一份完整合规的成品，看它长什么样、判据怎么打：

```bash
python3 scripts/check_lease_liability.py --demo
```

把这份样例存下来再跑一遍机检，它能自己过：

```bash
python3 scripts/check_lease_liability.py --demo > 样例租赁稿.md
python3 scripts/check_lease_liability.py 样例租赁稿.md
# → 五道全过（零发条），退码 0
```

接着换成你自己那份稿子：

```bash
python3 scripts/check_lease_liability.py 你的租赁稿.md
```

退码 `0` 全过、`1` 有发条、`2` 用法错、`3` 读不到文件或空稿。五道判据已全部落字，所以退码 `3` 只剩「读不到文件／空稿」两种来路——不再有「零发条但仍有判据未落字」那一档。

### 拿不到成品时，从原文开始的三步

1. **定主体与报告期**，拿到年报附注「租赁」那一节，以及使用权资产、短期租赁与低价值租赁相关附注。
2. **每节抄事实，连原句一起抄**：一条 = 一行，行末挂 `「原句」〔锚：页/表〕[S#]`。判断位写 `[待人工]`。
3. **跑一遍自检**，红一条改一条：

```bash
python3 scripts/check_lease_liability.py --selftest
```

### 先确认通道在场（可选）

配了 `CUE_API_KEY` 才需要这一步。先握手取目录，再按现场返回的地址确认工具：

```bash
curl -sS https://cuecue.cn/api/mcp-catalog -o /tmp/mcp-catalog.json
curl -sS -X POST "$MCP_ENDPOINT" \
  -H "Authorization: Bearer $CUE_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' | head -c 2000
```

没配凭据也能用：把附注与公告放进工作区，走用户直供那条路，代价是暂时只能用手头文件里的那几页。

## 二、五道机检在管什么

| 码 | 名称 | 判什么 | 最常拦住的情况 |
|---|---|---|---|
| `LL-STRUCT` | 形制 | 头部三件自标逐字在位；六节齐且按序；认不出的节标题与多出的同名节逐条发。**不判** `主体：`／`报告期：`（建议写成行首裸行，但那不是机检项） | 节名改了个字就整节认不出；一节写了两次；自标少一件 |
| `LL-QUOTE` | 原句与锚 | 四个内容节里每个带数字的行须挂齐「」原句＋〔锚：…〕＋`[S#]` 三元组，缺哪件点明哪件；例外只有 `未取到：` 行、`[待人工]` 行、`〔自算〕` 行三形；来源行须合 `- [S#] 标题 \| URL \| 检索日 YYYY-MM-DD`，检索日不是横杠式即发；正文与来源**两向**都要对得上 | 数字行只写数没抄原句；检索日写成 `2025/04/20`；正文引了 `[S9]` 却没登记 |
| `LL-SPLIT` | 租赁负债分档 | 一年内到期 ＋ 一到三年到期 ＋ 三年以上到期 vs 未折现租赁付款额合计（容差 0.01）；**某格已声明 `未取到` ⇒ 整条静默跳过、不重复报缺失**；缺项分两档措辞：行不存在 ⇒「缺「X」」，行在但取不到万元金额 ⇒「X 行取不到万元金额」（如单位写成「元」） | 某一分档改了没改合计；分档只抄一个；金额写成「元」 |
| `LL-ASSET` | 使用权资产勾稽 | 原值 − 累计折旧 − 减值准备 vs 账面价值（容差 0.01）；**某格已声明 `未取到` ⇒ 整条静默跳过**；缺项同样分「行不存在」与「取不到万元金额」两档措辞 | 只抄账面价值，原值与折旧全省；折旧改了没改账面价值 |
| `LL-LINE` | 红线 | 四组越界词，**只扫四个内容节**（`口径与未取到`、`来源` 两节整节豁免）：① 投资建议（买入／卖出／增持／减持／目标价／推荐／建议持有）② 前瞻预测（预计／预测／有望／将会／看好／预期增长／预判）③ 主观评价（合理／不合理／偏高／偏低／高估／低估／显著偏低／显著偏高）④ 越界口径（租赁融资成本高／融资成本高／财务风险／资本结构优化／杠杆空间／融资租赁更划算／经营租赁优于）。判前先洗掉「」引文与〔口径／锚／自算〕标签槽——那是原文与出处，不是本件断言；再按分句判，含 `[待人工]` 或 `未取到` 的那一句跳过 | 自己写了一句「租赁融资成本偏高」；把「预计明年租金上升」写进正文 |

## 三、四条红线（这件的立身之本）

1. **折现率是百分数不是金额。** `增量借款利率` 写的是 `4.75%` 这种百分数，不写「万元」。写成「万元」那一行会被当成金额，勾稽比对必然算歪。
2. **租赁期是年数不是金额。** `租赁期` 写 `5 年`，不写「万元」。一条租赁期被抄成金额，整节的数就没有对照意义了。
3. **缺口声明优先于判据。** 同一项在正文写了 `未取到：X`、在口径与未取到节也声明了 X，就是「这一项本就没取到，不判」——两道勾稽就此静默跳过，不重复报一句「缺失」。把「跳过」写成发条，字面通、语义反。
4. **红线只判本件自己写的字。** 照抄附注里的「预计」、锚里指向的「预计负债」科目名，都是原文与出处，不是本件下的判断；把它们判红，伤的是老老实实挂锚的人。

## 四、一条发现长什么样

分档行，三个到期档各一行，合计一行：

```markdown
- 租赁负债一年内到期〔口径：本期末〕1,200.00 万元「一年内到期的租赁负债为人民币 1,200.00 万元」〔锚：2025 年年报·第 213 页·租赁〕[S1]
- 租赁负债一到三年到期〔口径：本期末〕2,400.00 万元「一到三年内到期的租赁负债为人民币 2,400.00 万元」〔锚：2025 年年报·第 213 页·租赁〕[S1]
- 租赁负债三年以上到期〔口径：本期末〕3,600.00 万元「三年以上到期的租赁负债为人民币 3,600.00 万元」〔锚：2025 年年报·第 213 页·租赁〕[S1]
- 未折现租赁付款额合计〔口径：本期末〕7,200.00 万元「未折现的租赁付款额合计为人民币 7,200.00 万元」〔锚：2025 年年报·第 213 页·租赁〕[S1]
```

使用权资产四行，减法那一层要能复算：

```markdown
- 使用权资产原值〔口径：本期末〕8,000.00 万元「使用权资产原值为人民币 8,000.00 万元」〔锚：2025 年年报·第 213 页·租赁〕[S1]
- 使用权资产累计折旧〔口径：本期末〕2,400.00 万元「使用权资产累计折旧为人民币 2,400.00 万元」〔锚：2025 年年报·第 213 页·租赁〕[S1]
- 使用权资产减值准备〔口径：本期末〕0.00 万元「使用权资产减值准备为零」〔锚：2025 年年报·第 213 页·租赁〕[S1]
- 使用权资产账面价值〔口径：本期末〕5,600.00 万元「使用权资产账面价值为人民币 5,600.00 万元」〔锚：2025 年年报·第 213 页·租赁〕[S1]
```

折现率写百分号，没取到的自成一行（项名在前、「未取到」在后也认）：

```markdown
- 增量借款利率〔口径：本期〕4.75%「折现采用的增量借款利率为 4.75%」〔锚：2025 年年报·第 213 页·租赁〕[S1]
- 未取到：三年以上到期
```

## 五、和另外几枚包怎么分

| 你手上是 | 用哪枚 | 界线提示 |
|---|---|---|
| 租赁负债、使用权资产、租赁期、折现率、短期租赁、租赁变更与重估 | **本件** | 承租人侧的负债与使用权资产本件负责 |
| 借款费用资本化、专门借款、一般借款 | `cn-borrowing-cost-cn` | 那件算借钱盖资产的利息怎么资本化 |
| 投资性房地产（含其租赁口径） | `cn-investment-property-cn` | 出租方／投资性房地产口径归那件 |
| 长期股权投资 | `cn-long-term-equity-investment-cn` | 参股投资的账面与损益 |
| 股份支付 | `cn-share-based-payment-cn` | 股权激励的授予与摊销 |

本件与 `cn-borrowing-cost-cn` 最容易混：那件算**借钱盖资产**的利息怎么资本化，本件登记**租进来的资产**对应的租赁负债与使用权资产。两件都会出现「资本化」相关字样（本件是租赁负债利息的资本化、那件是借款费用的资本化），但不是同一套判据，也不共用一套数。

## 六、素材从哪来

- **用户直供**：手头的年报 PDF、公告，走解析通道读成能检索的正文。
- **通道取证**：配了 `CUE_API_KEY` 后可走财报检索与原文解析。装好 skill ≠ 已配凭据 ≠ 通道已连，三层分开看。
- **租赁的数常散在多处**（租赁附注、使用权资产附注、短期租赁与低价值租赁），长附件与扫描件交给解析腿：先取大纲，再按节取用。

本件不发请求、不代付费，消耗以服务端返回为准。

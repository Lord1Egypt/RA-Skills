## Description:

Scouts, qualifies, proposes, delivers fixed-scope freelance jobs, and monitors payments using a coordinated five-role agent team.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and developers use this skill to coordinate a supervised freelance workflow: find fixed-scope work, qualify opportunities, write truthful proposals, execute accepted work in local workspaces, deliver results, and track payment evidence.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may search for freelance work, write proposals, run local work, read and write files, use shell commands, store job context in memory, and review inbox or payment evidence.

Mitigation: Use it only in dedicated workspaces with approved job and payment sources, and keep proposal, delivery, shell, inbox, and payment actions under user supervision.

Risk: The artifact describes work execution and payment monitoring, which can affect real clients, deliverables, and compensation workflows.

Mitigation: Run the bundled evaluation set before use and require explicit approval before submitting proposals, delivering work, or acting on payment-related evidence.

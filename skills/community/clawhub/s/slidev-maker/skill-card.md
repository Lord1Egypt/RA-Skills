## Description:

Use this skill when creating, editing, or exporting Slidev presentations - the Markdown + Vue web-based slide framework for developers.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill to scaffold, write, customize, troubleshoot, and export Slidev presentation decks. It provides guidance for Slidev Markdown, layouts, code blocks, animations, diagrams, assets, themes, presenter workflows, and PDF/PPTX/PNG/static-site output.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated package-management or build/export commands could change a project or install unpinned dependencies.

Mitigation: Review commands before execution, pin dependencies where possible, and run them in the intended project environment.

Risk: Themes, addons, remote assets, web fonts, or public PlantUML services can introduce external network dependencies or expose sensitive deck content.

Mitigation: Use trusted themes and addons, avoid secrets in decks and diagrams, and prefer local fonts, local assets, or a local PlantUML server for sensitive presentations.

Risk: Remote control and recording features can expose presentation access, screen content, camera input, or speaker notes when used on untrusted networks.

Mitigation: Enable remote control or recording only deliberately, use trusted networks and passwords where available, and confirm privacy settings before presenting.

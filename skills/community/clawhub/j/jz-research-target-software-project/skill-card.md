## Description:

Researches a specified open source or commercial closed source software project and produces a structured Markdown report.

This skill is ready for commercial/non-commercial use.

## Publisher:

[johnny-ztsd](https://clawhub.ai/user/johnny-ztsd)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, technical evaluators, and product researchers use this skill to research a named software project and generate a structured Markdown report covering overview, architecture, usage guidance, FAQ, recommended reading, and references.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill directs the agent to research named software projects, so generated reports may contain inaccurate or outdated project details.

Mitigation: Review cited sources and current project documentation before relying on the report for technical or business decisions.

Risk: The skill may include external URLs or diagrams in the generated Markdown report.

Mitigation: Inspect links and rendered diagrams before publishing or sharing the report.

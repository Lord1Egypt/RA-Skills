# 游轮船票查询 — 三峡游轮+城市游船，船票/交通/景点/住宿一站搞定

> 查询长江三峡游轮、黄浦江游船等船票，含价格、航线方向和退改政策，附带去码头交通和目的地景点住宿推荐。

🔥 **核心亮点：**
- **船票查询** — 游轮名、价格、上下水方向、退改政策一目了然
- **地铁优先去码头** — 地铁/公交/打车方案，省钱优先
- **景点推荐** — 出发地/目的地城市热门景点，含门票和购票链接
- **住宿推荐** — AI语义匹配酒店，用自然语言描述需求即可
- **零配置** — 装上就能用

## 快速入门

**3个开场白示例，复制即用：**

1. "帮我查长江三峡游轮的船票"
2. "从重庆北站怎么去朝天门码头"
3. "重庆住解放碑附近，300左右的酒店"

## 核心能力

1. **游轮船票** — 查询三峡游轮/黄浦江游船等船票，含价格和退改政策
2. **去码头交通** — 地铁/公交/打车方案，地铁优先
3. **景点推荐** — 出发地/目的地城市热门景点，含门票和预订链接
4. **住宿推荐** — AI语义匹配酒店，返回推荐和预订链接
5. **航线方向** — 标注上下水方向，帮你选最合适的航线
6. **退改政策** — 每条结果附带退改政策，出行前心里有数

## 能做什么

- 查询长江三峡游轮、黄浦江游船等船票
- 查去码头的地铁、公交、打车方案
- 推荐出发地/目的地城市的热门景点和门票
- 推荐附近住宿酒店

## 不能做什么

- 不支持直接购买船票（提供预订链接跳转购买）
- 不支持海洋邮轮（如歌诗达/皇家加勒比），仅覆盖国内江河游轮
- 不支持查询已购船票状态或办理退票

## 使用提示

- 游轮搜索需要精确关键词，如"长江三峡游轮"比"三峡"更准确
- 三峡游轮上下水航线体验不同，上水(宜昌→重庆)时间长但风景好
- 船票价格实时变动，以实际下单页面为准
- 建议提前1-2天查好去码头的交通路线

## 🔗 搭配使用

- **邮轮游查询预订** — 海洋邮轮航线查询（皇家加勒比/MSC等）
- **景点智能推荐** — 目的地景点AI推荐
- **酒店智能搜索** — 目的地酒店搜索

## 数据流向

票务查询通过云端代理服务获取旅游平台API数据，交通方案通过高德地图获取。代理服务不存储用户数据。

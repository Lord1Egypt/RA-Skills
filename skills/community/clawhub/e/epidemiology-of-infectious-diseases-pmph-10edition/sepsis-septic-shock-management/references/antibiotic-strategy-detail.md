# 抗菌药物治疗策略详细参考

## 经验性用药选择矩阵

### 按感染部位

| 感染部位 | 常见病原 | 首选药物 |
|----------|---------|----------|
| 肺部 | 肺炎链球菌、流感嗜血杆菌 | 青霉素/半合成青霉素或一代头孢 |
| 膈肌以下 | 革兰氏阴性菌 | 三代头孢±氨基糖苷类 |
| 免疫低下 | 产ESBLs G-菌 | 三代头孢/酶抑制剂或碳青霉烯 |
| 导管相关 | G+菌（金葡菌、凝固酶阴性葡萄球菌） | 万古霉素/利奈唑胺 |

### 按免疫状态

| 状态 | 风险病原 | 覆盖策略 |
|------|---------|----------|
| 中性粒细胞缺乏 | G-菌、真菌 | 碳青霉烯±抗真菌 |
| 长期免疫抑制剂 | 真菌、机会性感染 | 广谱+抗真菌 |
| 糖尿病 | G+菌、厌氧菌 | 广谱覆盖 |

## 降阶梯治疗执行流程

```
Day 0: 识别脓毒症/感染性休克
  ↓
Day 0 (1h内): 留取标本 + 启动广谱经验性治疗
  ↓
Day 2-3: 评估病原学结果
  ├─ 病原明确 → 根据药敏降阶梯为窄谱
  ├─ 病原未明但临床好转 → 维持或适度收窄
  └─ 病原未明且无好转 → 升级或联合
  ↓
Day 5-7: 再次评估
  ├─ 临床痊愈 → 考虑停药
  ├─ 好转 → 继续当前方案
  └─ 无好转 → 重新评估感染源/耐药
  ↓
停药标准：体温正常+症状体征消失后5-10天
```

## 特殊疗程要求

| 情况 | 疗程 |
|------|------|
| 一般败血症 | ~2周 |
| 有原发/转移病灶 | 适当延长 |
| 感染性心内膜炎 | 4-6周 |
| 中性粒细胞缺乏 | 至粒细胞恢复 |

## PCT指导停药

- PCT下降>80%或<0.5μg/L：考虑停药
- PCT持续不降：重新评估感染源/耐药/非感染因素
- 动态监测需同一检测系统

## 碳青霉烯类使用原则

### 严格定位
- 仅用于危及生命的重症感染
- 免疫低下宿主经验性治疗
- 产ESBLs/ AmpC酶菌感染

### 风险控制
- 易致二重感染、菌群失调、诱导耐药
- 用药果断，停药及时
- 获得药敏后及时降阶梯

## 联合用药指征

### 推荐联合
- 败血症早期病原未明
- 免疫缺陷宿主
- 怀疑多重耐药菌
- 需要协同作用（如心内膜炎）

### 避免联合
- 病情好转后单药可达有效治疗
- 无协同作用的药物组合
- 增加毒性无增加疗效的组合

## Description:

Social selling and DM funnels: consent-first selling in DMs for opt-in comment-to-DM-to-email funnels, with the agent designing trigger posts, DM sequences, and manual outreach scripts while external official Meta API tools or humans handle actual DM sending.

This skill is ready for commercial/non-commercial use.

## Use Case:

External social media operators and marketing teams use this skill to design consent-first DM sales funnels, draft trigger posts and DM copy, capture emails, and route high-intent conversations to humans. It is intended for warm, opted-in interactions only, not cold outreach or automated scraping.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Drafted DM funnel content could be misused for cold outreach, scraping, or spam-like automation.

Mitigation: Use only opted-in triggers such as comments, story replies, follows, or keyword DMs, and reject cold blasting, handle scraping, password tools, or unofficial automation.

Risk: DM automation or follow-up outside platform rules can cause account enforcement or poor user experience.

Mitigation: Run any automation only through official Meta API tools or human review, respect the 24-hour interaction window, vary message text, include opt-out handling, avoid shorteners, and limit links.

Risk: The skill may mention performance metrics that are unavailable inside the agent workflow.

Mitigation: Treat DMs as drafted content, not commands, and use only metrics reported by the external tool or approved analytics workflow.

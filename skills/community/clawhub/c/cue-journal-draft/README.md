# journal-draft

**给一份旧期刊，还一份能直接进设计的新一期底稿。**

不是「帮我写篇稿子」——是把一本刊物的**版式与体例从 PDF 里量出来、变成可校验的参数**，
再按这套参数生产新一期的内容。所以它交出的东西能直接进设计，而不是一堆待排的文字。

**输入**：一份过往期刊样例（PDF 优先）+ 本期需求
**输出**：`draft.html`（mm 级定位版面稿）· `draft.pdf`（印刷级，自绘）· `draft.docx` / `draft.md`（可编辑文字稿）
**代价**：标准模式 ≈ **3 批确认**（开工 / 大纲 / 交付，每批 ≤5 问、逐条带默认值）

---

## 一、它跟「给我个大纲」的区别

### ① 版式是**量**出来的，不是描述出来的

从样刊 PDF 里提取页面网格、版心、字号序列、行距、色板、页眉与 logo 坐标，落成
`stylespec.json`。渲染器按 mm 级绝对定位出稿 —— 所以 PDF 是 **PyMuPDF 自绘**的，
不靠浏览器打印（企业策略会让整本隐形，见 `references/pitfalls.md`）。

### ② 五道门禁，专挡「脚本不报错、页面看着正常」的静默失败

| 静默失败 | 长什么样 | 谁拦住它 |
|---|---|---|
| 内容被裁 | 页数比预期少，页面看不出异常 | `--stats` 的 `overflow` 告警（`overflow:hidden` 会吃掉溢出） |
| 内容量不足 | 排版完美，但只有样刊三成厚 | `scale_baseline` 达成率门禁，**任何一项 <60% 直接 FAIL** |
| 三件套不一致 | HTML 改了、docx/md 没跟上 | `crosscheck.py` 逐条比对 HTML / MD / PDF 的文本覆盖 |
| 样例是扫描件 | 提不到字号与正文，看着像一本空刊 | 文字层极薄时直接说明「很可能是扫描件，请先 OCR」而不是返回空结果 |

另有 `check_freshness.py` 时效门禁：事件日期、期号连续性、模糊时间表述逐条定位。

第四道是 **版面质量门禁**（`audit_layout.py`，v0.14.0 起）：前三道管「内容对不对、够不够」，
只有它管**好不好看、好不好读**——正文字号是否与样刊一致、字号层级有没有碎裂、
行距倍数、每行字数、字体是否生效、中文空格残留、页面密度。
实测一本三道全绿的 80 页稿，仍然字小一档、字号碎成 41 档、行距 2.16 倍（样刊 1.85）、
页脚 73 处空格，**没有一道报得出来**。

第五道是 **编辑定位门禁**（`audit_editorial.py`，v0.15.0 起）：前四道管「内容对不对、
够不够、好不好看」，只有它管**对不对路**——这本刊写给谁、要他读完做什么、该用什么调子说。
定位落成 `positioning.json`（与 `stylespec.json` 平级的第二份机器可读产物）后，
它判单条字数是否落在调性派生的字带、兑现「读者要做什么」的条目覆盖率、纯 L0 占比、
句长、术语与忌讳词。实测一本四道全绿的稿子：48 条全部同一形态、均 409 字
（模板声明 180–320，超 28%）、全刊读者称谓仅 4 次、含行动建议仅 21%——**同样没有一道报得出来**。

两道门禁**具体查哪几项、阈值各是多少，本文不抄清单**——它们是脚本现值，一条命令原地打出来（自带安装后路径，任意目录可跑；装在别处把 ~/.workbuddy/skills/ 换成你的技能安装目录；Windows 走 Git Bash 或 WSL（命令用 grep，属 POSIX 工具））：

```bash
grep -n "^  [0-9] \|MD_SKIP = " ~/.workbuddy/skills/journal-draft/scripts/audit_layout.py ~/.workbuddy/skills/journal-draft/scripts/audit_editorial.py ~/.workbuddy/skills/journal-draft/scripts/crosscheck.py
```

本文与 `SKILL.md` 里出现的检查名和阈值都是**镜像与常见例，不作穷尽断言**；改了脚本以脚本为准。**机器拦的是形制与一致性，"这份到底对不对"仍归人工**：`references/qa-checklist.md` 的阻塞项/建议项全部要人逐项勾，三件套一致性也只在"你传了哪个介质"的范围内成立（省略即不检）。

### ③ 承认边界，并且**标出来**

单栏渲染器画不出双栏、非 A4 开本的组件几何要人工微调、高图表页没有内建模板、
双语没有内建渲染 —— 这些不藏。命中就在 `+learn` 收尾念给你听，
`examples/` 里还专门放了一个**反向样本**用来标定失效点。

### ④ 合规不是附录，是一层独立门禁

按 **读者身份 × 行业 × 周期形态** 三层取值（外部客户 / 员工 / 投资者 / 公众 / 渠道 / 监管；
律所 / 金融 / 医药 / 食品 / 教育 / 科技 / 制造 / 地产 / 零售），并为需要会签的刊物
产出签核清单（市场 / 法务 / HR / 董秘-IR / PR / 合规）。

### ⑤ 也有明确「不接」的活

边界写清楚，双方都不浪费时间。下面这些**不是"暂不支持"，是设计上就不做**：

| 不接 | 为什么 | 那该怎么办 |
|---|---|---|
| **代写文章 / 创意文案** | 它交的是「版式对、体例对的底稿」，不是「观点新的内容」。观点、案例、数据必须来自你 | 把已有素材交给它组织进版面 |
| **替代法务 / 合规审阅** | 会给出检查清单与签核建议，但不构成法律意见 | 出刊前按 [`references/qa-checklist.md`](references/qa-checklist.md) 走人审与会签 |
| **直接交印刷终稿** | 交的是**底稿**；出血、色彩管理、印厂软打样不在范围内 | 底稿进设计软件做印前处理 |
| **扫描件当作样例** | 样式提取依赖 PDF 的**文字层**，扫描图片没有文字层 | 先 OCR 出文字层，再进 `+learn` |
| **双栏 / 多栏版面渲染** | 渲染器只出单栏；分栏与绕排是另一套排版逻辑 | 双栏刊可把它当**体例与内容模板**来源，排版另走 |
| **双语 / 多语对照渲染** | 没有内建双语版式 | 出两份单语底稿再人工合版 |
| **复杂数据可视化** | 6 份语义图模板只覆盖并列 / 流程 / 堆叠 / 汇聚/ 页脚这类关系，不是图表库 | 图表在外部出好图，走 `+art` 的图片位 |

拿不准的直接问 —— 它会明说这次能做、不能做、以及不能做的那部分谁来补。

## 二、快速开始

**装本件自己**：`npx skills add huhoo/cue-awesome --skill journal-draft`——这条只装本包；装完在你这一侧重列一次已安装 skill，清单里看得到 `journal-draft` 这个名字才算文件到位（文件到位不等于取到数，取数看下面「Cue 通道」那一节）。没有 CLI 环境时的兜底是把本目录整个放进宿主支持的 skills 目录（`~/.workbuddy/skills/`，Windows 看第 3 步那条路径口径换写法）。

```bash
python -m pip install pymupdf        # 必须：样式抽取 + PDF 出稿
python -m pip install python-docx    # 可选：docx 文字稿与回填
python -m pip install pillow         # 可选：配图印前校验
```

Windows 用 `python`；macOS / Linux 用 `python3`。

**配图不需要任何图像 API key。** 语义图走 `gen_diagram.py` 用代码矢量绘制（成本 0、
无水印、中文逐字可核），只有封面题花这类不含具体信息的氛围图才用 agent 自带的多模态出图。

**冒烟**（确认环境通了）：

```bash
python scripts/build_draft.py \
  --spec assets/examples/qiming-regional-sample/stylespec.json \
  --content assets/templates/content.example.json \
  --out ./smoke --stats
```

能打印页数、条目数、`unknown=0` 就说明通了。样例只有 8 页，会报
`[FAIL] 量级严重不足`（它拿 91 页基线在比）—— **这个 FAIL 是正常的**，
看的是门跑没跑起来，不是门的结果。**此时 `exit code` 也是 1**，
那是门禁判定结果而不是脚本崩溃，接 CI 时请按状态码区分这两类。

**自测面**（复验本包自己，不碰你的稿子）：

```bash
bash scripts/fixtures/run_fixtures.sh
```

零网络、纯标准库，无参直跑，末行自报「ALL GREEN（N 项）」退 0（N 以脚本现跑为准，本面不写死枚数）；任一不符打 FAIL 行并附输出，末行「NOT GREEN」退 1。
它判五组事：生成器好样链（随包真件走完并双跑产物逐字节同）、量级门禁**能红也能放行**（把基线配平就必须退 0——防恒真那一枚在这里）、
坏输入不落半成品——**每条坏形支路各四件套**（退非零＋**错误输出第 1 行同时含参数名与病灶词**、缺一即红＋零 Traceback＋产物目录零文件；首行只写「input 不是合法 JSON」这种泛称不算点名）：`build_draft.py` 的 `--content` 三形与 `--spec` 一形、缺 `--content` 的用法错一支，`enrich_from_omni.py` 的坏 `--outline` 四支（截断／数组／字符串／指向不存在文件——给了路径却读不到不算「没给」）。
第五组是**派生面↔生成器 同源档**（`scripts/check_derived_sync.py`）：应检枚数从盘上名册现算（`examples/` 下带 SKILL.md 的目录），并与档内声明的枚数对拍——两值不符即红（只看名册会被「整枚 example 目录消失」洗绿，只看常量会被「删一枚入参」洗绿，两道锁一起才堵得住），逐枚重跑 `derive_skill.py` 现产该枚 SKILL.md，与在盘面按块比（frontmatter 逐键、正文按去编号的二级标题切块；入参与豁免键固化在档内常量，不许从盘面字段反推）。每枚必出一行读数，跑不成的也成行并点名原因；实跑枚数≠应检枚数即红并点名少的是哪枚——一把同源尺少测一枚就等于没测。增删 example 时必须同时改档内声明枚数与那三张常量表（入参／登记／人工拥有），改一处不改另一处即红。
它现在的形制是**登记态**：已知漂移逐枚自报，末行自报「已知漂移 N 行｜实跑 P／应检 Q 枚」并声明登记态字样、退 0，所以它不会把发布链堵上；实测超出登记数、未登记的块或键漂了、少测一枚、人工拥有项双向锁（盘面缺这一枚＝红，生成器长出这一枚＝红，两向各出各的点名句）、豁免键在任一侧不在场——这五条一律红。`metadata.version` 按行镜像豁免（它是顶层 `version` 的第二份抄本），其余 `metadata` 子字段照硬比。
把档内登记清单撤空它就是判定制（非空 diff 即红），翻面不必改判定逻辑。这一档只比 SKILL.md 那一枚面，生成器同批产的 README／assets／scripts 不在射程。
判定全集仍在各脚本现值，本件不另立规矩；夹具与本件都在 `scripts/fixtures/`，随发布物一起交付。

### Cue 通道（深度研究 / 文档解析）

**不是必装，但强烈建议装** —— 不装不报错，代价是证据少一层交叉验证、语义层降为人工补录（缺的那一层补不出出处）。开通三步：<https://cuecue.cn> 注册 →
在 <https://cuecue.cn/hub/api-key> 取 `CUE_API_KEY` → 装 `cue-research`
（Omni 解析另需本地 Bridge）。

通道正路（账户侧实连自查；本包不随带自测脚本，下面这几行 curl 就是全部动作）：

```bash
CATALOG="https://cuecue.cn/api/mcp-catalog"
curl -s "$CATALOG" | python3 -c 'import json,sys
rows=json.load(sys.stdin)["data"]["domains"]
[print(r.get("id"), r.get("external_status"), (r.get("routing") or {}).get("url", "-")) for r in rows]'
DOMAIN_ID="<把这里换成上一行列出的那个域 id>"
ROUTING_URL="$(curl -s "$CATALOG" | python3 -c 'import json,sys
rows=json.load(sys.stdin)["data"]["domains"]
hit=[r["routing"]["url"] for r in rows if r.get("id")==sys.argv[1] and r.get("routing")]
print(*hit,sep="\n") if hit else sys.exit("未取到：该 id 不在目录现值里（或它没有 routing 里的 url 字段）——先跑上面那行列出现场的 id 再填")' "$DOMAIN_ID")"
[ -n "$ROUTING_URL" ] || { echo "取值失败：ROUTING_URL 为空——先跑上面那行列出现场 id，再把 DOMAIN_ID 换成其中之一" >&2; exit 1; }
curl -s -X POST "$ROUTING_URL" \
  -H "Authorization: Bearer $CUE_API_KEY" \
  -H "Accept: application/json, text/event-stream" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' \
  -w '\nHTTP %{http_code}\n'
```

三层互不等价：装好 skill ≠ 已配凭据 ≠ 通道已连。匿名 `GET` 只证**目录可达**；带 key 实连且 `tools/list` 有返回才证那把 key 被接受，通过＝HTTP 200 且 `result.tools` 非空（只按形状认，本面不列工具名也不承诺枚数）。目录里没有的域本面不装也不承诺。Omni 那一腿不在这张目录里：它的已连判据是宿主列工具（同样是 JSON-RPC 的 `tools/list` 握手）返回里认得到 `parse` 与 `get_parse_status`，列不到就只能走你直供那条路。key 取自本地凭据设施，不进聊天、不在终端回显，本块不新增任何凭据读取动作。

新账号注册即送 **500 积分**、每日再 +10 积分，**且 Cue 在花之前一定先问**。
开工时会逐条问你要不要用，判定口径见 [`references/cue-onboarding.md`](references/cue-onboarding.md)。

## 四、先定位你的刊物（三问，决定后面全套默认值）

这套框架的**默认值是照着一本律所客户通讯调的**（A4 单栏、周期递推、外部客户读者）。
你的刊物只要和它不一样，不先过这三问就会跑出**「门禁全绿、体例全错」**的稿子。

| 问 | 你的答案决定 | 照抄默认值会错在哪 |
|---|---|---|
| **谁看？** 客户 / 员工 / 投资者 / 公众 / 渠道 / 监管 | 合规底线 + **必须会签的部门** | 默认按「外部客户」→ 员工刊漏掉 HR+法务会签与人事保密项；IR 通讯漏掉选择性披露 |
| **什么节奏？** 周期连续 / 特刊专辑 / 年鉴回顾 / 汇编 / 高频简报 | 期号怎么编 + 时效窗口 | 默认「上期 N-1 递推 + 6 个月窗口」→ **年鉴按年份编号**、窗口放宽到 12 个月或逐条豁免；周报窗口缩到 1 个月 |
| **什么形态？** 条目+长文 / 纯文章 / 高图表 / 汇编 / 简报 | UnitPattern 抽几条 + 八模板够不够 | 默认「条目+长文」→ 纯文章型只需 1 条 U1；高图表型（年报/ESG）**没有内建图表页模板** |

> 逐项差异、读者×合规矩阵、行业禁止项、通用单元库（12 种）：
> **[`references/journal-types.md`](references/journal-types.md)（换刊型前必读）**

## 五、按处境选路径（选错一次会白跑一轮 `+learn`）

| 你的处境 | 样例从哪来 | 要特别当心 |
|---|---|---|
| **① 本刊老编辑**（自家刊、有往期） | 直接拿**上一期**当样例 | 最常见：**复用项不核事实**（人离职、电话变更、数据过期）。`+brief` 的「可复用清单」8 项须逐条核 |
| **② 换一家机构做同类刊** | 用**本机构自家往期**；没有就往 ④ 走 | **不许拿别家的刊当样例投产** —— 抽出来的是别家的品牌 DNA |
| **③ 同一家机构做别的类型刊** | 尽量找**自家**该类刊往期；没有就用同类机构同类刊 | 一套 `stylespec.json` 不够用：**换刊型就该重跑 `+learn` 再派生**，手改字段必然漏 |
| **④ 非律所企业做任意类型刊** | 自家往期；创刊号没有就往 `SKILL.md` 硬规则 1 的**三条出路**走 | ①合规检查按「读者行 + 行业行」组合，别照抄金融/法律口气；②结构化数据在你家 **ERP/CRM/HR 内部系统**，涉密需授权且要脱敏 |

**三条通用上手路径**：

| 你想 | 怎么做 |
|---|---|
| **先看成品长什么样** | 把 `examples/journal-qiming-regional/` 整个目录拷到 `~/.workbuddy/skills/`，直接让它出下一期。它自带全部渲染脚本（12 个），不依赖本目录 |
| **做自家刊物** | 拿自家**一期刊物当样例**跑 `+learn → +brief → +plan → +gather → +draft → +check`，最后 `+spec` 沉淀成自己的技能 —— **第二期起代价骤降** |
| **只借鉴方法** | 读 `SKILL.md` §3 七阶段流程 + 样例的 `unit-patterns.md`，看一本真实刊物的版式与内容模板被抽成了什么 |

**`stylespec.json` 不要手改。** 换刊型 / 换客户就重跑一次 `+learn` 再派生，手改几十个字段必然漏。

## 六、两个方向相反的样例

`examples/` 里放了一对**互为反例**的成品技能，对照着看能摸到框架边界：

| 样例 | 开本与结构 | 它能告诉你什么 |
|---|---|---|
| `journal-qiming-regional` | A4 / 91 页 / **单栏** / 短条目 + 长文章混合 | **顺向路径**：能跑通、能投产（`spec_confidence: pinned`） |
| `journal-hengshi-observation` | 227×276mm / 52 页 / **双栏** / 纯文章型 | **反向路径**：框架在哪会失效 —— 单栏渲染器画不出双栏、正文中灰会被误判成次要色、非 A4 开本的组件几何要人工微调（`spec_confidence: weak`，**不能直接投产**） |

外加 `assets/examples/qiming-regional-sample/`：`+learn` 阶段的**原始中间产物**
（StyleSpec / semantic / UnitPattern），用来校准「机器提取」与「人工提炼」的分工。

**这一层结构是：本技能是框架（父包），`examples/` 里的是成品样例（子包）。**
子包既不是运行依赖，也不是派生新子包的**输入** —— 它们是教学样本。
**造自己的子包走的是「拿自家刊物重跑 `+learn` 再派生」，不是改样例**：

```
自家近一期刊物 PDF ──+learn──▶ stylespec.json ──人工补──▶ unit-patterns.md
                                                              │
                                        derive_skill.py ──────┘
                                                ▼
                              journal-<你的公司>-<刊型>/   ← 自包含、可直接开工、也可独立发布
```

派生出的子包**自带 `slug` / `displayName` / `version`**，能单独发布到技能市场；
`scripts/` 与两个 `assets/` 模板目录随之拷贝，换台机器直接能跑；
只有 `references/` 有意留在父包（会随框架演进，拷一份会立刻过期）——
**子包日常干活不需要父包在场，遇到换开本 / 改版 / 换刊型这类底层问题才回父包查。**

> ⚠️ **两份成品样例 + 一份中间产物样例均已脱敏**：机构名、刊物名、自然人姓名、客户与项目名称、
> 源文件名全部为**虚构合成实体**；保留的是实测版式参数与模板结构。详见仓根的 [`NOTICE.md`](../NOTICE.md)（该文件在仓库顶层、不随本包分发，故不在包目录内）。

## 七、最容易踩的 6 个坑

| # | 坑 | 一句话解法 |
|---|---|---|
| 1 | **分页溢出是静默的** | `.page{overflow:hidden}` 会吃掉溢出。页数偏少就是被裁了，看 `--stats` 的 `overflow` |
| 2 | **「跑通了」≠「版式对了」** | 实测过脚本零报错、达成率全对，但整栏排错半页、文章排成单栏。换开本后必须**量一遍实际栏宽** |
| 3 | **语义图不能交给文生图** | 信息在标签文字与拓扑关系上，扩散模型做不了。实测 6 张图 5 张信息量为零，一张图注写「分工」画面却是「汇聚」 |
| 4 | **文字稿改稿链要「空转测试」兜底** | docx 导出后立刻回填，必须与原 `content.json` 逐字节相同。实测一次空转查出 5 处静默丢失 |
| 5 | **说好问三次、实际会被问八次** | 这是流程问题不是耐心问题 → 前移 + 打包成 3 批。但**打包 ≠ 默认关闭**，Cue 通道必须真问出口 |
| 6 | **门禁复核必带 `--spec`** | v0.13.1 起不再静默放过：spec 里没有 `scale_baseline` 会直接 `[FAIL]` + `exit 1`，逼你补上或显式加 `--no-baseline-gate` |

> 完整 **12 条**（含配图 `avoid` 清单挡不住敏感题材、空图位在 docx 里伪装成路径错误、
> 换刊型不先定位会跑出「门禁全绿体例全错」……）：**[`references/pitfalls.md`](references/pitfalls.md)**

## 九、高频困惑与反模式（一问一答，答案只指现成条款）

本表治的是「用法走偏」；能力面「不接的活」看 §一 的 ⑤ 表，版式细节看 `references/pitfalls.md`
（README 只留最容易踩的几条，全量在那份文件里，两处都不作穷尽断言）。

| 你大概会想 | 实情 | 去哪儿看 |
|---|---|---|
| 「三道门禁全绿，可以直接付印了」 | 门禁各管一段：内容对不对、够不够、好不好看、对不对路是**四件事**，前几道全绿仍可能字小一档、字号碎成几十档；付印前还有一道时效门禁 | §一 ② 的五道分工；`+check` 命令式在 `SKILL.md` |
| 「让文档把每项检查和阈值都抄一遍，我照着核」 | 不抄。检查项与阈值是**脚本现值**，抄进文档就开始腐烂；本文出现过的检查名与阈值都只是镜像与常见例 | §一 ② 末那条 grep 命令，原地打出脚本现值 |
| 「拿浏览器把 HTML 打印成 PDF 交出去」 | 部分预览器与企业策略会让整本隐形；PDF 一律由 `export_pdf.py` 自绘 | `references/pitfalls.md` 第 1 条 |
| 「样刊是扫描件，直接 `+learn`」 | 样式提取靠 PDF 的**文字层**；扫描图片没有文字层，看着像一本空刊。先 OCR 出文字层再进 | §一 ⑤ 的扫描件行；`+learn` 收尾会把边界念给你听 |
| 「双栏刊也想复现版式」 | 渲染器只出单栏，分栏与绕排是另一套排版逻辑。双栏刊可把它当**体例与内容**的底稿用，版式不复现 | §一 ⑤ 双栏行；`examples/` 里那个方向相反的样本就是用来标定失效点的 |
| 「没样刊，但先把本期内容排出来」 | 可以，代价是**不做样式复现，只做内容流水线**——路由表里明写的一档，不是临时糊弄 | `SKILL.md` 处境路由表的「什么都没有」那一行 |
| 「不装 Cue 通道也能跑吧」 | 能，但缺的是能力不是格式：素材改由你贴（标直供），检索类条目按未检索处理。「可选」只表示不装也能跑，不表示默认不用——开工时会主动推荐并等你确认 | `references/cue-onboarding.md`；`SKILL.md` frontmatter 的 recommended 段 |

## 十、出错了怎么办（症状 → 原因 → 恢复动作）

**未见于本次返回的一律写「未检索到」**：参数名、字段名、枚举值没有出现在本次工具返回里的，不得凭印象填写；写「未检索到」并记入待核清单或覆盖率账，不得留空顶替。
症状摘自四道脚本**当前的实际出口**（现跑所得，非设想形制）：门禁类出口是用户读报告 + 末行
`── FAIL n / WARN m` 汇总；参数缺失走 argparse 的 usage 提示并**退 2**；`crosscheck.py` 无成品时打
`[ERR] 没有任何成品可校：至少给一个 --html / --md / --pdf`。

| 症状 | 原因 | 恢复动作 |
|---|---|---|
| 末行 `── FAIL 2 / WARN 5`，其下每行带 `└─` 详情 | 版面质量或编辑定位门禁拦到阻塞项（FAIL 阻塞、WARN 不阻塞） | 逐条按 `└─` 行点名的对象改稿再复跑；清完 FAIL，WARN 也要看一眼再交付 |
| 末行 `无阻塞项；WARN 建议逐条看一眼再交付。` | 全过但留告警 | 别当绿灯：字号层级碎裂、行距倍数、中文空格残留这类告警逐条判要不要动 |
| `usage: audit_layout.py ... error: the following arguments are required: --pdf` | 命令式漏参（各道必传项不同） | 按 `SKILL.md` 的命令式补齐；`--spec` / `--sample` 是可选对照件，缺了不报错但判据变少 |
| `[ERR] 没有任何成品可校：至少给一个 --html / --md / --pdf` | 三件套还没出，或路径没给到 | 先渲染出成品再校；三件套出完必跑 `crosscheck.py`，不允许 HTML 有而 PDF 没有 |
| `结论：N 个版本有缺失`，伴随 `x MD 缺 n 条：` 明细 | 三件套文本覆盖不一致 | 按明细补齐缺失版本的那几条。文字稿有一组纯版面字段按设计豁免，豁免表是 `crosscheck.py` 里 `MD_SKIP` 现值，同一条 grep 命令可见 |
| `[跳过] pdf 不存在：…` | 该成品尚未生成，脚本如实跳过而不是崩 | 补跑该成品的生成步骤，再复跑对账 |
| 时效门禁报 `FUTURE`（写了还没发生的事）或 `STALE`（旧闻充新刊） | 事件日期超出收录窗口，或期号不连续 | 付印前必跑 `check_freshness.py`（窗口默认 6 个月，可传 `--window`）；FUTURE 直接拦下，STALE 逐条判留删 |
| 报告出现「很可能是扫描件」 | 文字层极薄，样式提不出来 | 先 OCR 出文字层再进 `+learn`，不要拿它硬排 |
| 中断后不知从哪儿接 | 八个动词任意阶段可续跑，产物落在同一目录 | 先读该目录已有产物与台账，再挑对应动词进；续跑不等于重跑 |

## 十一、怎么开口（触发示例：三条正例 + 一条反例）

**开口请带上时点，输出标刊期与生成日期**：请求里给出报告期／基准日或回看窗口；成品首行标注**刊期与生成日期**，当它与用户所指日期不一致时，正文禁用「今日」「最新」，一律改写为「截至 <日期>」。
- **正例（有样刊，走全链）**：「这是上期样刊 `~/ink/sample.pdf`，本期六个栏目素材在 `~/ink/mat/`，
  出一份可编辑底稿，PDF 也要」——`+learn` 先量版式，`+brief` 用三问定定位，再往下走；样刊与素材都给了路径就直接开工，
  缺的那一问才会回来找你。
- **正例（复杂输入：定位先行，只要内容不复制版式）**：「新内刊第一期，没有样刊，先按内容排；
  读者是一线销售，读完要去做客户回访，语气短句别端着；不要图，栏目列在 `~/plan.md`」
  ——命中「什么都没有」那一档：不做样式复现、只做内容流水线；定位落成 `positioning.json` 后，
  编辑定位门禁按它判字带、读者称谓与行动建议的覆盖。
- **正例（从任意阶段续跑）**：「上一轮 `+draft` 跑了一半，HTML 已经出了，接着把 docx 和 PDF 补齐」
  ——读该目录产物后从对应动词接，不重跑前面的步骤；八动词见 §三。
- **反例（相邻需求，本件不接）**：「文案你替我写圆，观点也你定，我只要成品」→ 本件交的是**版式对、
  体例对的底稿**，观点与案例位留人写（§一 ⑤ 第一行）；「这段有没有合规风险，出个意见」→ 给检查清单与
  签核建议，不构成法律意见；「照做一份双栏杂志版式」→ 不做双栏渲染。

# 风格卡 · 电影叙事排版风（Director's Cut）

> 来源：2026 设计趋势自主挖掘（电影片头字幕 / 电影定格叙事风）
> 状态：已验证（imagegen 出图验证，demo 随卡产出）

## 1. 一句话风格描述
一张图像电影定格的截图帧——氛围感摄影大图铺底 + 颗粒胶片噪点 + 复古衬线大字标题，排版极简克制，不堆装饰，靠光影与情绪讲故事。

## 2. 基础参数
| 项 | 值 |
|---|---|
| 画幅 | 16:9 横（电影感最佳）/ 3:4 竖 |
| 适用场景 | 书评宣传、纪录片、文旅、高端品牌宣发、个人 IP 封面、深度长文头图 |
| 信息容量 | 主标题 1（≤10 字）+ 副题/一句文案 1（≤20 字）+ 极少量 credit 行 |

## 3. 配色系统
- 氛围感摄影大图铺底（低饱和、柔和光影、暗调或胶片色）
- 文字主色：暖白 `#F5F1E8` 或米白 `#EDE6D8`（压在暗图上）
- 可选电影感色：深棕 `#3A2E24` / 暗青 `#1F2A2E` / 酒红 `#6E1F1F`（作字幕条或标题色）
- 颗粒：细胶片噪点 overlay，透明度 0.04-0.08；整体低饱和、无高亮撞色

## 4. 构图布局
```
┌──────────────────────────────┐
│                              │
│      [氛围感摄影大图铺满]       │
│                              │
│        主标题（衬线大字，       │
│        居中偏下，字距宽）       │
│      ── 细线 / 小装饰 ──       │
│      副题文案（小字，居中）      │
│                              │
│   credit 行（极小，角落）        │
└──────────────────────────────┘
```
- 图占满全幅，文字压在图的下三分之一（电影字幕位），留出上方情绪留白
- 视觉动线：先被画面情绪抓住 → 落到标题 → 副题收尾
- 黄金位（下 1/3 中央）放主标题

## 5. 字体排印
- 主标题：复古衬线（如 Playfair Display / Noto Serif SC）大写或粗体，字距 0.12-0.2em，字号极大但克制
- 副题：细衬线或无衬线小字，字距宽，居中对齐
- credit：极小无衬线全大写，压在角落，营造片尾字幕感

## 6. 图形元素
- 氛围感摄影大图（人物剪影/街景/自然光/静物，景深柔和）
- 细胶片颗粒、轻微暗角（vignette）、柔和光晕
- 可选：细线分隔、极简小标点装饰
- 无扁平插画、无 emoji、无图表

## 7. 内容槽位
- `{背景氛围图}`（摄影质感，低饱和暗调）
- `{主标题}`（≤10 字，衬线大字）
- `{副题文案}`（≤20 字，一句情绪化文案）
- `{credit行}`（作者/出品/日期，全大写极小字）

## 8. 生成 Prompt
```
A cinematic movie-still style knowledge card poster, {背景氛围图描述}, 
full-bleed atmospheric photography as background, low-saturation moody lighting, 
soft film grain, subtle vignette, cinematic color grade.
Centered in the lower third, a large elegant vintage serif title reading "{主标题}" 
in warm ivory #F5F1E8, wide letter-spacing, understated and refined.
Below it a thin divider line and a small refined subtitle reading "{副题文案}" 
in light serif, letter-spaced, centered.
A tiny uppercase credit line "{credit行}" in one corner, like end-credit typography.
Minimalist editorial layout, no flat illustration, no emoji, no charts,
no extra decoration, storytelling through mood and light only.
Aspect ratio 16:9.
```
> 注：文字拼写易错，主标题 ≤10 字（中文 ≤8 字）；「禁止出现」段需一并投喂。

## 9. 禁止出现
- ❌ 扁平插画 / 图标 / emoji / 图表
- ❌ 高饱和撞色、霓虹、高亮渐变
- ❌ 满版装饰堆砌、多余文字区块（保持极简）
- ❌ 标题文字拼写错误（衬线大字尤其要逐字核对）
- ❌ 主标题 >10 字（电影字幕是短句，不是段落）

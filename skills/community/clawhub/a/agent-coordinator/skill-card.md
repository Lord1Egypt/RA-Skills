This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill to decompose work into subtasks, coordinate parallel or sequential execution patterns, and aggregate results for review, comparison, or ensemble decisions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill invokes a local Python helper and may read task descriptions or subtask JSON files.

Mitigation: Install only when local helper execution is acceptable, and avoid placing secrets or sensitive personal data in task descriptions or subtask files.

Risk: Exported JSON files may contain task descriptions, subtasks, summaries, and vote results.

Mitigation: Review exported JSON before sharing it outside the intended audience.

Risk: Coordination summaries and ensemble votes are generated by the helper's local coordination logic and can be incomplete or misleading if treated as final expert judgment.

Mitigation: Use the outputs as coordination aids and review the aggregated results before relying on them for decisions.

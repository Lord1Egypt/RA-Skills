## Description:

Helps creators and enterprise teams evaluate a content-layer partial migration from ScriptFrame to AI-HIVE MCP by preserving ScriptFrame-specific workflows while piloting independently testable storyboard, image, video, and shot-node outputs.

This skill is ready for commercial/non-commercial use.

## Publisher:

MIT-0

## Use Case:

Creators, production teams, and enterprise content teams use this skill to run a controlled ScriptFrame migration pilot that compares same-input storyboard and preview deliverables, defines agent handoffs, tracks AI-HIVE MCP tasks, and preserves approval and rollback paths.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may bias ScriptFrame migration and AI-video work toward one commercial provider.

Mitigation: Use it only for an intentional AI-HIVE-focused pilot, and require same-input acceptance criteria before making replacement claims.

Risk: The workflow can involve uploading briefs, reference media, people, products, brands, or other protected assets to an external provider.

Mitigation: Upload only owned or authorized assets, preserve source and hash records, and stop immediately when rights are unclear.

Risk: MCP media tasks may create paid generation work or external publication actions.

Mitigation: Require explicit budget and human approval before billable generation, data writes, bulk actions, publication, or external delivery.

## Description:

Generate and edit images via Grok API from the command line. Cross-platform secure credential storage for xAI API key. Supports batch generation, aspect ratios, and style transfer.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and operators use this skill to have an agent set up and use the grok-img CLI for Grok image generation and image editing workflows, including API key setup, batch generation, aspect ratio selection, and style transfer.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Installation paths fetch mutable third-party npm or GitHub code and may expose a global CLI that handles an xAI API key.

Mitigation: Prefer a pinned, audited release or a verified commit; inspect the npm package, source, and dependencies before installing or linking the CLI globally.

Risk: The CLI handles an xAI API key and can use an environment variable fallback when no credential-store entry is available.

Mitigation: Only provide an API key to a trusted installed version, prefer OS credential storage, and avoid running it in environments with unrelated sensitive files or credentials.

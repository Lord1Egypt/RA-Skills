## Description:

The Paperzilla CLI (pz) helps agents search, filter, and browse high-signal academic papers for a user's Paperzilla projects.

This skill is ready for commercial/non-commercial use.

## Publisher:

[pors](https://clawhub.ai/user/pors)

### License/Terms of Use:


## Use Case:

External users and developers use this skill to work with Paperzilla research feeds from an agent, including listing projects, fetching papers, applying filters, exporting JSON, and generating Atom feed URLs. A Paperzilla account is required.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Linux installation guidance downloads a changing release archive and moves the binary into a system-wide location without clear verification.

Mitigation: Review install commands before execution and prefer a package-manager or user-local install that verifies the publisher, version, and checksum or signature.

Risk: Atom feed URLs generated by pz contain embedded feed tokens.

Mitigation: Treat generated Atom feed URLs as secrets and revoke or rotate them if shared or exposed.

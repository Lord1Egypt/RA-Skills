Developers and agent operators use this skill to add advisory cognitive optimization, resource-management, memory, health-check, and coordination routines to autonomous agent workflows. ## Known Risks and Mitigations:

Risk: Broad automatic activation and durable behavior changes can alter an agent's normal operating posture.

Mitigation: Review before installing, avoid broad auto-activation, and run in sandboxed or read-only advisory mode unless explicitly approved.

Risk: Persistent memory, scheduled jobs, and self-healing routines can create or modify files and operational state.

Mitigation: Require confirmation before writes, configuration changes, service restarts, external messages, or trading actions.

Risk: Long-lived memory and scheduler artifacts can accumulate stale or sensitive operational context.

Mitigation: Periodically inspect or delete MEMORY.md, memory/, .issues/, and scheduler entries created while using the skill.

## Use Case:

External users and trading analysts use this skill to ask an agent for options flow analysis, unusual activity detection, sweep monitoring, and options strategy evaluation for equities and ETFs.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill requires an OptionsHawk API key in the agent environment.

Mitigation: Install only after confirming trust in the OptionsHawk service and provide the API key through the configured environment variable.

Risk: Options flow analysis can be mistaken for personalized financial advice.

Mitigation: Treat outputs as market research and have users apply independent judgment before making trading decisions.

# 终止经营·持有待售与处置对价

产出稿的头部就照下面这几行起（三件自标「AI 整理初稿」「请回原文核对」「不构成投资建议」逐字在位；`主体：`／`报告期：` 是**行首裸行**，不带 `- ` 前缀）。判断位一律写成 `[待人工]`：

```
# 示例材料（600000.SH）终止经营登记稿

AI 整理初稿 ｜ 请回原文核对 ｜ 不构成投资建议
主体：示例材料（600000.SH）
报告期：2025 年年度报告·附注·终止经营
```

**定位**：给一份年报，把附注里**「终止经营」与「持有待售」那一段**读成一张**每个数都能回到附注原句**的登记表——卖了什么、损益怎么构成、这笔业务带来多少现金、还挂在持有待售里的资产负债各多少、对价与交割进度如何，五块逐条挂原句与锚。**损益分项求和与现金流合计由机检现算**，本件只负责把数抄对、把分项抄对、把原句挂上。

这一段常被跳读，但它回答的是「这次处置**到底动没动利润**」：一家公司全年净利润两亿，其中终止经营贡献 3.46 亿——主业其实在亏。本件把这张表逐行摆出来，**不替你说「这次处置划算」或「甩掉了包袱」**——那一步要口径判断，交 `[待人工]`。

切割说清楚：`cn-segment-report-cn` 管**还在并表的分部**收入利润（持续经营口径），本件管**已经卖掉或划为待售**的那一块；`cn-fair-value-hierarchy-cn` 管处置组公允价值的三层输入，**不问损益分项与对价进度**；`cn-long-term-equity-investment-cn` 管长期股权投资的后续计量，**不问整块业务的终止确认**。三件读同一份财报的不同段落。

### 是什么 / 不是什么

| 是 | 不是 |
|---|---|
| 五块逐条登记（终止经营概况／损益／现金流量／持有待售资产负债／处置损益与对价），缺项也占一行点名 | 处置划不划算、是不是甩包袱、主业有没有改善（一律 `[待人工]`） |
| 每个数字带 `〔口径：…〕` 标签（本期末／本期发生额／本期末账面价值／交易对价） | 按表格位置认项（第三行就是净利润那种） |
| 分项现算：损益分项之和 vs 披露的终止经营净利润，差 > 0.01 万元即发条 | 只抄合计数、分项空着，让合计无从复核 |
| 现金流现算：经营＋投资 vs 披露的现金净额，差 > 0.01 万元即发条 | 拿 0 补一个缺失项去让合计成立 |
| 每个数挂「」原句＋〔锚：…〕＋`[S#]` 三元组，来源行两向对应 | 只写数字不抄原句，事后补一句「据年报附注」 |
| 数据通道＝用户直供的附注原文（零网络） | 承诺任何实时行情、预测或工具清单 |

### 触发场景

「这笔处置到底赚了多少、是不是一次性的」「终止经营贡献了多少利润」「卖掉这块业务回了多少现金」「还挂在持有待售里的资产负债各多少」「对价收齐了没有」。输入形态＝**年报附注里「终止经营」「持有待售」「处置子公司」那几段**（截图／PDF／解析回来的表格文本）。

## 七节各登记什么

节名必须逐字照这几个（`## ` 起节，节名后面紧跟字母或数字就认不出，会被记成野节）：

| 节 | 登记什么 | 最常犯的错 |
|---|---|---|
| 终止经营概况 | 卖的是什么业务、何时交割、终止经营净利润一项，`〔口径：本期末〕`／`〔口径：本期发生额〕` | 只写「处置了子公司」不给净利润，后面的分项核对就没有比对对象 |
| 终止经营损益 | 营业收入／营业成本／资产处置损益／所得税费用等**分项逐行**，`〔口径：本期发生额〕`，成本与费用带负号 | 只抄最后一行净利润，分项全省——分项和就无从现算 |
| 终止经营现金流量 | 经营活动／投资活动各自净额，再加一行合计（`现金流量净额合计`），`〔口径：本期发生额〕` | 给了经营与投资却不给合计，或给了合计却少抄一项 |
| 持有待售资产与负债 | 划分为持有待售的资产、负债各一行，`〔口径：本期末账面价值〕` | 把「拟出售」的意向写成已划为持有待售 |
| 处置损益与对价 | 交易对价金额、交割进度（尾款是否收齐），`〔口径：交易对价〕` | 把对价写成收到的现金（两者不是一回事） |
| 口径与未取到 | 取法口径 ＋ 缺口逐项点名；零缺口写 `未取到：无` | 正文写了未取到而本节没列，或反之 |
| 来源 | 每条 `[S#]` 一行：`- [S#] 标题 \| URL \| 检索日 YYYY-MM-DD` | 引用了 `[S#]` 却没有登记行；检索日写成斜杠式 |

同一条 = 一行：行首写项名与标签，紧跟金额与「万元」，再挂 `「原句」〔锚：页/表〕[S#]`。附注里没有的数写 `未取到：项名`，不留空、不借常识补。

⚠️ **负号要抄**：营业成本、所得税费用这类在损益里是减项，行首金额写 `-61,000.00 万元`。机检按符号求和；把负号丢了，分项和会比净利润大一倍。

## 五道机检在管什么

现状以脚本里 `UNIMPLEMENTED` 的现值为准：五道**全部已落字**。将来某道若回退成空壳，它会调用即抛、由机检收进「不可判」，既不判也不放行，单稿退 3；`rc=0` 只留给「五道全过」。

| 码 | 名称 | 判什么 | 最常拦住的情况 | 现状 |
|---|---|---|---|---|
| `TO-STRUCT` | 形制 | 头部三件自标逐字在位、七节齐且按序；认不出的节标题与多出同名节记 stray 逐条发。只判「形」，不判内容；**不判** `主体：`／`报告期：` | 节名改了个字就整节认不出；一节写了两次 | 已落字 |
| `TO-QUOTE` | 原句与锚 | 五个内容节里每个数字行须挂齐「」原句＋〔锚：…〕＋`[S#]` 三元组，原句 ≥8 字且不能只有数字标点；例外只有 `未取到：` 行、`[待人工]` 行、`〔自算〕` 行三形；来源行须合格式，正文与来源**两向**都要对得上，来源节一条合规行都没有则单独发。**不核对引号里的数与行首是否同一**（那是 `TO-PL`／`TO-CASH` 的活，分开判只为让一支坏样只红一道） | 数字行只写数没抄原句；来源行检索日写成 `2026/03/20`；引了 `[S2]` 却没登记 | 已落字 |
| `TO-PL` | 损益分项之和 | 「终止经营损益」节里各分项金额（带符号）之和，与「终止经营概况」节里披露的终止经营净利润比对，差 > 0.01 万元 ⇒ 发，消息记 `分项和=X 披露净利润=Y`。**任一侧缺失 ⇒ 整条跳过**，不猜、不按 0 算、不借别节的数 | 分项漏抄一行；成本忘了写负号 | 已落字 |
| `TO-CASH` | 现金流合计 | 「终止经营现金流量」节里经营活动与投资活动两项之和，与该节标了合计的那一行比对，差 > 0.01 万元 ⇒ 发，消息记 `经营+投资=X 披露净额=Y`。**任一侧缺失 ⇒ 整条跳过**，不猜、不按 0 算 | 合计改了数没改分项；某项是净流出却丢了负号 | 已落字 |
| `TO-LINE` | 红线 | 四类词**判整行（含「」引号内的原句）**：① 判断处置是否划算／好坏（`处置划算`／`处置不划算`／`卖亏了`／`一卖了之`／`甩包袱`）② 把处置损益当可持续利润（`可持续利润`／`经常性损益`／`主业改善`／`盈利能力提升`）③ 预测处置对以后期间的影响（`预计明年`／`将增厚业绩`／`未来业绩将`／`可增厚利润`）④ 评级与买卖建议（`目标价`／`买入`／`卖出`／`增持`／`减持`／`评级为`／`建议买入`／`建议卖出`）。**同一行同类只报第一处**；`口径与未取到` 与 `来源` 两节整节豁免（口径节按设计就要写「不判断处置是否划算」，不豁免会自己咬自己）。另加结构判据：`终止经营概况` 节缺 ⇒ 单独发（这一节是本件存在的理由） | 自己写了一句「本次处置划算」；把处置损益写成「主业改善」；抄引文时把评级建议一起抄进来 | 已落字 |

## 退码

| 码 | 含义 |
|---|---|
| `0` | 五道全过，零发条 |
| `1` | 有发条 |
| `2` | 用法错（缺参数或未知参数） |
| `3` | 读不到文件、或空稿、或零发条但仍有判据未落字（此时输出会明写「**这不等于合规**」） |

## 数据通道

零网络、纯标准库、单文件。输入就是用户直供的附注文本，本件不联网取数、不缓存、不上传。
`CUE_API_KEY` 是**可选**的：带上才走 `cue-data-mcp`／`cue-omni-reader` 那条取证腿去取原文，
缺位时只把用户贴进来的附注排版成上面那张登记表——**形状一样，数只能来自用户**。

## 快速开始

```bash
# 看一眼样例（零输入可跑，打印一份七节齐的登记稿）
python3 scripts/check_terminated_operations.py --demo

# 跑包内夹具自检（末行会给「自测档数=N｜不合=0｜不可判=0」）
python3 scripts/check_terminated_operations.py --selftest

# 机检自己的稿子
python3 scripts/check_terminated_operations.py 我的登记稿.md
```

# 康复维度详细参考指南

## 生物-心理-社会评估维度
在进行认知康复前，必须完成以下评估以确定干预基线：
- **身心状况**：当前的生理健康和精神状态。
- **应对技能**：患者面对压力和症状时的现有应对机制。
- **创伤史**：过往的心理或生理创伤经历。
- **人际关系质量**：家庭、朋友及社区支持网络的强度和稳定性。
- **优势与偏好**：患者的个人特长、兴趣及康复意愿。
- **能力与需求**：当前的功能水平和具体的康复需求。

## 认知康复目标缺陷领域
评估并干预以下具体认知领域：
1. **注意力**：集中和维持注意力的能力。
2. **工作记忆**：言语和视觉信息的短暂存储与处理。
3. **执行功能**：计划、组织、灵活性和问题解决能力。
4. **加工处理速度**：接收和处理信息的速度。
5. **情感识别**：识别和理解自己及他人情绪的能力。

## 回归社会五大训练层面
社会回归干预需覆盖以下五个层面：
1. **认知区分**：区分现实与幻觉/妄想，提高现实检验能力。
2. **社会知觉**：理解社会线索、情境和他人意图的能力。
3. **言语交流**：清晰表达思想、倾听和进行有效对话的技能。
4. **社会技能**：在特定社会情境中表现出适当行为的能力（如求职面试、购物）。
5. **人际交往**：建立、维持和发展亲密及一般人际关系的能力。

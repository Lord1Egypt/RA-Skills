## Description:

Checks a public GitHub repository's launch readiness using fixed criteria, scores it, and suggests prioritized improvements.

This skill is ready for commercial/non-commercial use.

## Publisher:

[hmakt99](https://clawhub.ai/user/hmakt99)

## Use Case:

Developers and repository maintainers use the skill to assess whether a public GitHub project is ready to launch and identify high-value fixes. It can list a project on ScBee only after the user explicitly agrees.

# 慢性感染与机会性真菌感染诊疗

## 结核病诊疗流程

```
可疑症状(咳嗽咳痰≥2周/咯血/长期低热)
    ↓
启动排查：影像学+病原学+免疫学
    ↓
确诊路径(必须依赖病原学/病理学)
    ↓
分类(确诊/临床诊断/疑似)×耐药状态
    ↓
标准化疗方案
    ↓
不良反应监测
```

### 结核病疑似触发条件
高度警惕以下表现：
- 咳嗽咳痰≥2周，或抗感染治疗3-4周无改善
- 痰中带血或咯血
- 长期低热/"发热待查"
- 肩胛间区湿啰音或局限性哮鸣音
- 诱因：糖尿病、免疫低下、激素/免疫抑制剂使用
- 变态反应：关节痛、结节性红斑
- 既往史：渗出性胸膜炎、肛瘘、长期淋巴结肿大

### 快速诊断：Xpert MTB/RIF
| 项目 | Xpert MTB/RIF | Xpert Ultra |
|------|--------------|-------------|
| 靶标 | rpoB基因 | IS6110+IS1081+rpoB |
| 灵敏度 | 92.2% | 97.2% |
| 特异度 | 99.2% | 99.3% |
| 耗时 | ~2小时 | ~2小时 |

**耐药判断**: rpoB基因变异→利福平耐药→高度提示MDR-TB(因多数同时对异烟肼耐药)

### PPD皮试判读标准
- 操作：左前臂掌侧前1/3，皮内注射5IU PPD，72h观察
- **阴性**: 硬结<5mm或无反应
- **一般阳性**: 5-9mm
- **中度阳性**: 10-14mm
- **强阳性**: ≥15mm 或 双圈/水疱/坏死/淋巴管炎

**注意**: 
- 卡介苗接种者可假阳性
- HIV/重症/幼儿/营养不良者可假阴性→需IGRAs或病原学

### 活动性肺结核分类标准

**确诊病例**(符合之一):
- 涂片阳性：2份痰涂片+；或1份涂片+影像符合；或1份涂片+1份培养+
- 仅培养阳性：影像符合+至少2份涂片阴性培养阳性
- 分子生物学阳性：影像符合+核酸阳性
- 病理学阳性：上皮样肉芽肿+干酪样坏死+朗汉斯巨细胞±抗酸染色+

**病原学阴性临床诊断**(成人):
排除其他疾病+影像符合+以下≥1条：①可疑症状 ②TST中度以上阳性 ③IGRA阳性 ④抗原/抗体阳性 ⑤肺外组织病理证实

**病原学阴性临床诊断**(儿童):
可疑症状+影像符合+以下≥1条：①TST中度以上阳性 ②IGRA阳性

### 标准化疗方案

**药物敏感肺结核**:
- 标准方案：2HRZ(E)/4HR (6个月)
- WHO 2022短程(≥12岁非重症)：2HPMZ/2HPM (4个月)
- 儿童短程(3月-16岁)：2HRZ(E)/2HR (4个月)

**利福平耐药(MDR/RR)**:
- 传统方案：≥4个有效药物，总疗程≥20个月
- 孟加拉国短程(9-11个月，成功率87.9%)：莫西沙星+吡嗪酰胺+高剂量异烟肼+氯法齐明+阿米卡星+乙胺丁醇+丙硫异烟胺
- 全口服短程趋势：氟喹诺酮+利奈唑胺+贝达喹啉

### 一线抗结核药物监测要点

| 药物 | 血脑屏障通透率 | 核心不良反应 | 监测项目 |
|------|--------------|------------|---------|
| 异烟肼(H) | 90-95% | 周围神经炎、肝损害(ALT↑) | 肝功能、神经系统症状 |
| 利福平(R) | 5-25%(脑膜炎时↑) | 肝损害、药物热、胃肠不适 | 肝功能、体温 |
| 吡嗪酰胺(Z) | 95-100% | 药物性肝炎、高尿酸血症 | 肝功能、血尿酸 |
| 乙胺丁醇(E) | 10-50% | 视神经炎、过敏/皮疹 | 视力/视野、皮肤 |

## 侵袭性念珠菌病诊疗流程

```
高危因素评估(免疫抑制+导管+广谱抗生素)
    ↓
经验性治疗(有高危因素+临床特征)
    ↓
病原学检查(镜检+培养+G试验)
    ↓
诊断驱动治疗(非确诊检查阳性)
    ↓
目标治疗(确诊后根据药敏调整)
    ↓
按感染部位确定疗程
```

### 念珠菌感染风险评估
**极高危组合**: 免疫抑制/屏障受损 + 广谱抗生素使用 + 中心静脉导管留置

### 病原学检查判读
| 检查 | 判读规则 |
|------|---------|
| 直接镜检 | 大量菌丝+芽孢=有诊断意义；仅芽孢(痰/阴道)=可能定植 |
| 非无菌部位培养 | 不能直接确诊，须排除污染/定植 |
| 无菌部位培养 | 阳性=确诊可靠依据 |
| G试验(β-葡聚糖) | 连续≥2次阳性有早期诊断价值(敏感76%，特异85%)；定植不升高 |

### 分级治疗策略

| 阶段 | 触发条件 | 药物推荐 |
|------|---------|---------|
| 经验性 | 高危因素+临床特征 | 棘白菌素类/伏立康唑/两性霉素B脂质体 |
| 诊断驱动(危重) | +非确诊检查阳性 | 棘白菌素类 |
| 诊断驱动(稳定+氟康唑敏感) | +非确诊检查阳性 | 足量氟康唑 |
| 诊断驱动(耐药) | +非确诊检查阳性 | 伏立康唑/两性霉素B |
| 目标治疗 | 确诊 | 首选棘白菌素类(据药敏调整) |

**疗效评估**: 治疗5天左右初步评估

### 各系统念珠菌病疗程标准

| 感染类型 | 疗程/停药标准 |
|---------|-------------|
| 皮肤黏膜 | 1-2周 |
| 系统性 | 1-2周，重症1-2个月 |
| 菌血症 | 症状消失+血培养转阴后≥2周 |
| 播散性(肝脾) | 血培养转阴+影像病灶完全吸收(常需数月) |
| 中枢神经系统 | 症状/体征/影像完全恢复后≥4周 |
| 心内膜炎 | 瓣膜置换术后≥6周 |
| 眼内炎 | 术后6-7周 |

## 隐球菌脑膜炎诊疗

### ⚠️ 腰穿安全边界
**颅内压明显升高时**: 腰穿前必须先予20%甘露醇250ml快速iv滴注，防止脑疝

### 脑脊液特征
| 项目 | 表现 |
|------|------|
| 压力 | 明显升高，严重者>600mmHg |
| 外观 | 澄清或稍混浊 |
| 细胞数 | (40-400)×10⁶/L，淋巴细胞为主 |
| 蛋白 | 轻-中度升高 |
| 糖/氯化物 | 下降 |

### 确诊方法
1. **墨汁涂片**: 最快速，~70%阳性→出芽酵母样菌+透亮厚壁荚膜
2. **黏蛋白胭脂红染色**: 荚膜深玫瑰红色→强烈提示隐球菌
3. **培养(金标准)**: 2-3天见菌落；阴性需观察6周方可排除
4. **痰液培养**: 阳性提示侵袭性肺病或共生；确诊侵袭性肺病需血清荚膜抗原+或影像支持

### 高危人群预防策略
- **适用**: 基础疾病+长期大剂量抗生素
- **药物**: 氟康唑 或 伊曲康唑
- **疗程**: ≤3周
- **核心机制**: T细胞免疫是限制隐球菌复制的最重要因素

## 侵袭性曲霉病GM试验诊断

### 样本优先级
1. **首选BALF(肺泡灌洗液)**: 敏感性高于血清GM、组织学、培养
2. **血清GM**: 特异性与BALF相当，可辅助

### 阳性判定阈值
| 人群 | 阳性标准 |
|------|---------|
| 成人 | 1周检测2次，连续2次GM指数>0.5 |
| 儿童 | 连续2次>0.8，或单次>1.5 |

### 临床意义
- 约2/3患者血清GM阳性早于临床症状和影像学
- G试验+GM试验联合显著提高检出率

### ⚠️ 干扰因素
- G试验假阳性：菌血症(假阳性率~60%)，革兰阳性球菌菌血症(高达73%)
- 组织学阴性不能排除侵袭性曲霉病

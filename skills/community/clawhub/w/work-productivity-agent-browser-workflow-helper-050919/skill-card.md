## Description:

Helps agent users, skill authors, maintainers, and teams build or improve Agent Browser-style workflows, including bug fixing, setup hardening, reliability work, and adjacent skill creation.

This skill is ready for commercial/non-commercial use.

## Use Case:

External developers, AI-agent users, skill authors, maintainers, and teams use this skill to turn Agent Browser-style workflow needs into practical plans, checklists, code changes, or decision support. It emphasizes local-hardware-friendly approaches and visible validation steps.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation wording may cause the skill to be selected for unrelated browser, CLI, or bug-fix requests.

Mitigation: Confirm the selected skill when precision matters and check that the user's request actually involves Agent Browser-style workflow planning or reliability work.

Risk: Generated workflow or implementation guidance may be incorrect or incomplete for the user's environment.

Mitigation: Review the proposed output against the stated success criteria and validate changes before deployment.

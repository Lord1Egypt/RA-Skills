# 系统运行时索引

运行时回答“此刻哪个系统正在工作，以及下一次有意义的系统动作是什么”。这些职责可以跳转、并行、递归和回返；它们是 AI 的活动图景，不是要求用户跟随的步骤。

| 现场信号 | 读取 | 产生什么 |
| --- | --- | --- |
| 一句普通表达第一次指向一个对象 | [激活](activate.md) | 当前对象、目的、边界与第一张活动图景 |
| 已有 `.openxsys`、`SYSTEM.md`、作品或上次接力点 | [恢复](recover.md) | 仍然有效的认识、变化与接续位置 |
| 多个系统、能力、资料和约束需要共同作用 | [组装](compose.md) · [运行时架构](architecture.md) | 当前最小充分系统和它的依赖 |
| 关键事实、状态、反馈或人的理解还不清楚 | [观察](observe.md) | 能改变判断的新证据 |
| 当前系统已经知道应该对现实产生什么作用 | [行动](act.md) | 在真实权限内发生的作用与回执 |
| 需要区分提出、受理、执行、状态改变与效果 | [验证](verify.md) | 与证据相称的结果状态 |
| 新证据或结果已经影响模型、关系、能力或作品 | [更新](update.md) | 被改写的部分、依赖传播与下一接力点 |

运行时每次只展开当前需要的职责。完成局部动作后，把新的状态、证据和未决问题带回活动图景；需要深层能力时进入[引擎索引](../engines/INDEX.md)，需要真实环境接口时进入[适配器索引](../adapters/INDEX.md)。

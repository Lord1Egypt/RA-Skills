## Description:

Interaction Design SOP guides agents through a seven-step pre-coding review for frontend UI flows, information hierarchy, state resilience, perceived performance, shortcuts, and layout trade-offs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[fize](https://clawhub.ai/user/fize)

MIT-0

## Use Case:

Developers, frontend engineers, and design-focused agents use this skill before implementing UI views, forms, dashboards, or checkout/list workflows to define user intent, reduce task friction, prioritize information, and plan resilient empty, loading, error, and destructive-action states.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prescriptive interaction guidance can overconstrain UI decisions or miss domain-specific requirements.

Mitigation: Review the generated checklist decisions against the product context before implementation.

Risk: High-risk or destructive workflows may require stricter confirmation, recovery, or compliance handling than the checklist alone provides.

Mitigation: Require human review of confirmations, recovery paths, and input preservation before shipping high-risk flows.

2. Обращай внимание на текст из Bloomberg, часто там возникает paywall, но при этом первые два абзаца извлекаются. 
Если у Bloomberg в тексте новсти 1-2 абзаца, значит там был paywall и текст статьи не был полностью извлечен (значит текст извлечен некорректно)

3. Если видишь, что текст новости обрывается на полуслове, значит там тоже был paywall и извлекся только то текст, который был доступен бесплатно.
Такаие тексты новостей тоже считаются извлеченными некорректно

Твоя задача вернуть json с ответом ок или ошибка

```json
{
"check_status": "ок"
}
```

```json
{
"check_status": "ошибка"
}
```

## Description:

This skill helps short-drama and motion-comic teams turn casting, makeup, character, scene, and brand requirements into reusable visual assets and AI-HIVE image or video generation workflows.

This skill is ready for commercial/non-commercial use.

## Publisher:

MIT-0

## Use Case:

External creators, short-drama studios, brand teams, e-commerce sellers, and developers use this skill to plan character boards, scene boards, storyboards, prompt versions, and AI-HIVE generation commands for short-drama visual production. It supports text-to-image, image-guided image generation, image-to-video, task polling, media upload, and deterministic project blueprint output.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill requires an AI-HIVE API key and can submit paid generation tasks.

Mitigation: Use a revocable API key, keep it out of public files and screenshots, review commands before execution, and confirm model pricing before submitting batches.

Risk: The workflow can upload user-selected media to AI-HIVE or object storage.

Mitigation: Upload only media the user is authorized to process, avoid sensitive or unlicensed assets, and verify consent for real people, brands, voices, music, and trademarks.

Risk: Generated casting, character, scene, and video assets may contain identity, brand, factual, continuity, or rights errors.

Mitigation: Review generated outputs for likeness use, age appropriateness, factual accuracy, text safety zones, visual continuity, and copyright or trademark compliance before publication.

## Description:

Football English guides an agent to run a bilingual English/Russian football quiz with Telegram inline buttons, vocabulary learning, answer feedback, and word review.

This skill is ready for commercial/non-commercial use.

## Publisher:

[russianoracle](https://clawhub.ai/user/russianoracle)

### License/Terms of Use:


## Use Case:

External users use this skill to practice English football vocabulary through a Telegram-oriented quiz. The agent presents questions, answer choices, scoring, feedback, and review flows in English with Russian translations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Football facts, records, and translations may become stale or be inaccurate for a learning context.

Mitigation: Review and update quiz questions, answer keys, and translations before publishing or using the skill with learners.

Risk: The interaction design assumes Telegram inline buttons and may not work as intended in channels without button support.

Mitigation: Use the skill in a Telegram-compatible agent environment or adapt the interaction format for the target channel before deployment.

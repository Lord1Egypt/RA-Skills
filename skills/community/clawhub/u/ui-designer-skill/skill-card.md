Design beautiful interfaces using 16+ design systems including Material You, Fluent Design, Apple HIG, Ant Design, Carbon Design, Shopify Polaris, Minimalism, Glassmorphism, Neo-Brutalism, Neumorphism, Skeuomorphism, Claymorphism, Swiss Design, and Atlassian Design.

## Use Case:

Developers and agents use this skill to plan and refine interface design across established design systems, including color palettes, component themes, Tailwind-oriented structure, and accessibility checks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The optional helper script appends persistent design guidance to the current project's .cursorrules file.

Mitigation: Review the generated rules before running the script, run it from the intended project directory, and inspect .cursorrules after execution.

Risk: Design-system guidance can be applied inconsistently or conflict with an existing product design language.

Mitigation: Choose one primary design system for a project and review generated UI changes for consistency, accessibility, and fit with existing components.

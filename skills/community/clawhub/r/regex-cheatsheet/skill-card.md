## Use Case:

Developers and engineers use this skill to quickly find copy-paste regular expressions for common validation, extraction, and text-processing tasks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Regular expressions can behave incorrectly or perform poorly on untrusted or large inputs.

Mitigation: Test selected patterns with the target regex engine and representative production data before relying on them.

Risk: Regex patterns cannot fully parse HTML and may miss edge cases.

Mitigation: Use a proper HTML parser when the task requires reliable HTML parsing.

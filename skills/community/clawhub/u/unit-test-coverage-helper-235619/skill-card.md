## Description:

Helps software maintainers, QA engineers, open-source contributors, and product teams add useful unit tests, raise coverage, and verify regression risk in existing codebases.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, maintainers, QA engineers, open-source contributors, and product teams use this skill to plan, implement, and verify unit-test coverage improvements for existing codebases.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate on broad testing or quality-related requests because implicit invocation is enabled.

Mitigation: Narrow the trigger language before broad publishing when precise routing is required.

Risk: Coverage guidance or generated tests may encode incorrect assumptions about the target codebase.

Mitigation: Review proposed tests, run the relevant test suite, and confirm that assertions reflect intended behavior before merging.

## Description:

Explore intent, requirements, and design before implementation. Use when starting any creative work, creating features, building components, adding functionality, or modifying behavior.

This skill is ready for commercial/non-commercial use.

## Publisher:

[paudyyin](https://clawhub.ai/user/paudyyin)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agent users use this skill to turn early ideas into approved designs and written specs before implementation begins. It is suited to feature, component, functionality, or behavior-change planning workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may route routine creative or implementation-adjacent requests through a design-first workflow.

Mitigation: Review the broad activation wording before installation and use it only where a design gate is desired.

Risk: The skill may inspect repository context and create a committed design spec during normal use.

Mitigation: Use it in repositories where that behavior is acceptable, and review generated specs before proceeding to implementation planning.

## Description:

Analyze Unreal Engine log files for errors, warnings, crashes, and performance issues.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vincentwilliam](https://clawhub.ai/user/vincentwilliam)

### License/Terms of Use:


## Use Case:

Developers and engineers use this skill to review Unreal Engine logs, crash traces, startup failures, pak or loading errors, Lua/UnLua issues, rendering problems, network warnings, and performance bottlenecks. It helps summarize severity, event timing, likely root cause, and prioritized fixes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Unreal Engine logs can contain project paths, usernames, server names, and other diagnostic details.

Mitigation: Use the skill only with logs the user is comfortable sharing with the agent, and redact sensitive diagnostic details before analysis when needed.

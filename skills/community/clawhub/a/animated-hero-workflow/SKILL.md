# Animated Hero Workflow

## Headline

Turn a Static Business Website Into a Living Site With an Animated Video Hero, in Plain Words

## Hook

Give your AI agent one business website. It drafts the design system, colors, typography, and spacing, then drafts the brief for a clean brand image, then drafts the plan for a 5 to 6 second seamless loop, then drafts how the design and the loop come together as a full bleed video hero. The agent drafts, you make the image, you animate the loop, you combine it, and you deploy it. The agent never makes the image or the video itself, and never deploys a site itself.

## Pain, in plain words

Most small business websites look static and flat. The top of the page is a still picture and a headline, and nothing moves, so nothing catches the eye. A site that looks still can look old, even when the business is good. The fix is a short moving hero at the top, one clean image, animated into a short loop, in the same colors and type as the rest of the site, so the page feels alive from the first second. The hard part is keeping the loop short, light, and on brand, and not letting it slow the page or break on a phone.

## What you get

A workflow for one animated video hero, in plain words. The design system, colors, typography, and spacing, written down once. A brand image brief, clean and on brand. A loop plan, 5 to 6 seconds, seamless, with the start and the end matching. A combine plan, the design plus the video loop as a full bleed video hero. A performance check, loop length, file size, and mobile fallback. A handoff check, design system, image, loop, and hero, each one Checked, Missing, or Not confirmed, with the pasted text quoted as the evidence. It gives you a fix draft to review, never a changed live site by itself.

## Who this is for

Small business owners whose website looks static and want the top of the page to feel alive. People who build websites with an AI agent, in plain words, and want a clear plan for an animated hero before they make anything. People who hand a design and a video loop to a builder, and want a clear check at handoff, in plain words.

## Why this saves money

A design system written once stops you from rebuilding the hero every time the site changes. A brand image brief, checked first, stops an image that does not look like your business. A short loop plan stops a long heavy video that slows the page and has to be redone. A performance check, reviewed first, stops a hero that breaks on a phone. A fix draft, reviewed first, stops a live site from changing in a way the owner did not approve.

## How to use it

Hard rule, read this first: the agent does not generate an image, does not generate video, does not animate a loop, does not combine the hero, and does not deploy a site itself. The agent drafts the design system, the image brief, the loop plan, and the combine plan, and only checks evidence the user pastes in the message. A short description alone is not evidence. A design system, an image description, or a code snippet is Checked only when the user pasted that text in the message, and the output quotes that pasted text as the evidence.

Fast path: If the user already gives the business, the goal of the hero, and the audience in the first message, do NOT ask a long list of questions first. Draft the full workflow and the handoff check in the SAME reply, then the fix draft. Never stop at questions alone.

Step 1: extract the design system, colors, typography, and spacing. The agent drafts it from the details the user pastes in the message. Use Claude for this step, as named in the source workflow. If a detail is not pasted, mark it Not confirmed.
Step 2: generate a clean brand image. The agent drafts the image brief, in plain words, one clean image, on brand, no clutter. Use ChatGPT for this step, as named in the source workflow. The user generates the image with the brief. The agent does not generate the image itself.
Step 3: animate it into a 5 to 6 second seamless loop. The agent drafts the loop plan, in plain words, what moves, how it moves, and how the end matches the start so the loop is seamless. Use Flow for this step, as named in the source workflow. The user animates the loop with the plan. The agent does not animate it itself.
Step 4: combine the design with the video loop, add a full bleed video hero. The agent drafts the combine plan, in plain words, where the video goes, where the headline goes, and how the text stays readable over the video. Use Claude Code for this step, as named in the source workflow. The user combines it and deploys it. The agent does not deploy it itself.
Step 5: run the performance check, loop length, file size, and mobile fallback. The loop must be 5 to 6 seconds. The file must be small enough to load fast on a phone, and the owner must say the size in plain words, or mark it Not confirmed. On a phone, the hero must fall back to a still image if the video does not play, and the still image must be named, or mark it Not confirmed.
Step 6: run the handoff check, design system, image, loop, and hero, all checked with evidence pasted in the message. List each item as Checked, Missing, or Not confirmed, with the pasted text quoted as the evidence.
Step 7: write the fix draft, labelled DRAFT, NOT SENT, with owner approval needed.

Ask only what is missing, in plain words, one short list at a time:
1. What is the business, in plain words?
2. What is the goal of this hero, in plain words?
3. Who is the site for, in plain words?
4. What are your colors, typography, and spacing, paste the design system if you have one, or Not confirmed?
5. What must the brand image show, in plain words, or Not confirmed?
6. What must move in the loop, in plain words, or Not confirmed?
7. What is the file size of the loop, in plain words, or Not confirmed?
8. What is the mobile fallback, a still image, or Not confirmed?

If the user does not know an answer, mark it Not confirmed, and use the most common answer for that business type, and say so, marked Suggested, not confirmed. Do not invent an answer. If the user says use the design system for a question, use only what is in the pasted design system, and say so.

## What good looks like

A good design system has the colors, typography, and spacing written down once, in plain words. A good hero plan has one image, one loop of 5 to 6 seconds, one headline, and one button. A good handoff has every item marked Checked, Missing, or Not confirmed, with pasted text quoted as the evidence for every Checked item. A good fix draft lists the missing items first, in order, with one plain line each. A good hero loads fast, loops without a jump, and shows a still image on a phone if the video does not play.

## Common mistakes

These mistakes show up often, and they are easy to avoid if you check for them at handoff.

- Making a loop longer than 6 seconds. A long loop is heavy, slow, and hard to watch twice.
- Using a loop where the end does not match the start. The jump at the end of the loop is the first thing a visitor sees.
- Putting text over a busy video. If the headline is hard to read, the hero fails, however good the video looks.
- Using colors or type in the hero that do not match the rest of the site. The hero must follow the design system.
- Calling a hero done when only the image exists. An image is not a loop, and a loop is not a live hero. Checked needs pasted text, and live needs evidence the user pasted in the message.
- Claiming views, calls, or sales from a hero plan. A plan is a draft, not a result. Never invent a view count or a testimonial.

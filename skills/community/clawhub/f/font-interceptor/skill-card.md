## Description:

Extract fonts (TTF/OTF) from any website using MSCHF Font Interceptor.

This skill is ready for commercial/non-commercial use.

## Publisher:

[honeybee1130](https://clawhub.ai/user/honeybee1130)

### License/Terms of Use:


## Use Case:

Developers, designers, and other external users use this skill to identify and extract downloadable TTF or OTF font files from a submitted website URL.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Target URLs are submitted to MSCHF Font Interceptor.

Mitigation: Avoid submitting confidential or sensitive URLs unless sharing them with the third-party service is acceptable.

Risk: Downloaded TTF or OTF files originate outside this skill.

Mitigation: Verify font usage rights and scan downloaded files with normal security tooling before installation or redistribution.

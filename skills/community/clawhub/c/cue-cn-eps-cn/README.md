# 每股收益·逐条挂源

给一份财报或公告，把**每股收益的披露**读成一张**每条都能回到原句**的登记表：每股收益概况、基本每股收益、稀释每股收益、股数与调整、列报与追溯调整。

每股收益是附注里最容易被反算的一块：净利润除以加权平均股数看起来就能得出每股收益，可披露的数往往因为扣非、库存股、限制性股票与加权口径而对不上算出来的那个。稀释那一层更绕——潜在普通股要不要计入、调整后净利润与调整后股数怎么调、反稀释的判断归谁下，都是披露说了算。本件逐条登记原话，判断留给人。

分子分母与每股收益金额只认原句，跨单位按量纲折算后对平；稀释调整项与反稀释判断只认原句；不按净利润÷股数反算，不按假定的转换价格补算。

本件不预测每股收益、不估值、不给评级与目标价。

## 一、零依赖三分钟上手

只装 Python 3，不给任何数据文件，也能跑出一份完整合规的成品，看它长什么样、判据怎么打：

```bash
python3 scripts/check_eps.py --demo
```

把这份样例存下来再跑一遍机检——它会照七节形制、三元组与红线逐条判，应当零发条：

```bash
python3 scripts/check_eps.py --demo > 样例每股收益稿.md
python3 scripts/check_eps.py 样例每股收益稿.md   # 打印「—— 机检：0 条发条」，退 0
```

接着换成你自己那份稿子：

```bash
python3 scripts/check_eps.py 你的每股收益稿.md
```

退码语义：`0` 五道全过｜`1` 有发条（逐条打印 `码 行号 说明`）｜`2` 缺参数（没给稿子路径，也没给 `--demo`／`--selftest`）｜`3` 读不到文件或空稿。

拿不到成品时，从原文开始的三步：

1. **定主体与报告期**，拿到年报或半年报原文（附注「每股收益」「股本变动」、利润表三处）。
2. **每节抄事实，连原句一起抄**：一条 = 一行，行末挂 `「原句」〔锚：页/表〕[S#]`；披露没写的就写 `未取到：项名`，不留空、不借「有净利润就有每股收益」补。
3. **跑一遍自检**，红一条改一条：

```bash
python3 scripts/check_eps.py --selftest   # 12 档内置夹具自检
```

## 二、五道机检在管什么

| 码 | 名称 | 判什么 | 最常拦住的情况 | 现状 |
|---|---|---|---|---|
| `EP-STRUCT` | 形制 | 头部四件自标逐字在位、`- 主体：`／`- 报告期：` 行在场非空、七节齐且按序、前五节各至少一条发现行、节内只许 `- ` 行 | 某节只有散文没有发现行；节序被调换；多插一节而七节契约不收 | 已落字 |
| `EP-QUOTE` | 原句与锚 | 发现行以「」原句＋〔锚：…〕＋`[S#]` 收尾且三元组落在行末；来源行带可点 URL 与检索日；引用的编号须已登记 | 只写「基本每股收益 0.86 元」没抄原句；正文引用了 `[S3]` 而来源节没有这一号 | 已落字 |
| `EP-CALC` | 分子分母只认原句 | 归属于普通股股东的净利润、扣非后净利润、加权平均普通股股数、基本每股收益金额——每一族的登记数都必须在同一行「」原句里找得到（跨单位折算后比）；行内出现「据此计算」「＝」「数字／数字」这类自算痕迹而原句没给结果也发 | 用净利润÷股数反算出的金额填进去；`17,200.00 万元` 与 `172,000,000.00 元` 被当成两个数判错 | 已落字 |
| `EP-DILUTE` | 稀释调整项只认原句 | 调整后净利润／调整后股数的数字、潜在普通股类别词（可转债／认股权证／股份期权／可转换优先股）、「具有反稀释性／不计入稀释每股收益」的判断、「假定转换／假设转换」的说法，凡登记值里有而同行原句没有即发 | 原句只说「发行可转换公司债券」，登记值写成「认股权证」；反稀释结论自己下 | 已落字 |
| `EP-LINE` | 红线 | 投资建议、每股收益预测、评级与目标价、确定性断言零命中；引文先洗掉再判，紧邻否定词罩着的边界声明（「本件不给评级、不给目标价」）不算踩线 | 正文写「预计每股收益增厚」；写「机构给出目标价 12.50 元」；把边界声明也判红 | 已落字 |

五道现读全已落字，`--selftest` 十二档内置夹具的末行读数是 `自测档数=12｜不合=0｜不可判=0`（含好样零发条一档，形制／锚／分子分母／稀释类型／稀释调整项／红线各钉一档，另有分子分母、稀释类型、跨单位折算、引文目标价、边界声明五档反证——反证档专验「数或词只出现在「」引文里、或前面紧贴否定词时不该发」）。

## 三、三条红线（这件的立身之本）

1. **分子分母与每股收益金额只认原句，不反算。** 披露给了净利润与加权平均股数，不等于本件可以拿它们除一遍再填每股收益；每一族的登记数都要在同一行原句里找得到，单位不同按量纲折算（`17,200.00 万元` 就是 `172,000,000.00 元`），折算后对不上就是没照抄。
2. **稀释调整项与反稀释判断只认原句。** 潜在普通股属于哪一类、调整后净利润与调整后股数调了多少、是否具有反稀释性、要不要计入稀释每股收益，全部照抄；原句只说「存在潜在普通股」没给调整数的，写未取到，不按假定的转换价格自行补算。
3. **红线只判本件自己写的句子。** 「」引文里出现目标价、评级、预测是披露原话，不是本件在下结论；本件自己写「目标价」「买入评级」「预计增厚」即发。紧贴否定词的边界声明（「不给评级」「不给目标价」）是说明自己不做什么，判据不误伤——但「给出买入评级」照发。

## 四、数据通道

发现先行，匿名取 live 目录，拿到 `routing` 后再连接发 `tools/list`，以现场返回为准，不硬编码工具名与工具数：

```bash
curl -sS https://cuecue.cn/api/mcp-catalog -o /tmp/mcp-catalog.json
python3 -c "import json;d=json.load(open('/tmp/mcp-catalog.json'));print(d.get('routing') or d)"
# 拿到 routing 后，带 token 发 tools/list：
curl -sS -X POST "$ROUTING_URL" -H "Authorization: Bearer $CUE_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

- **原文腿**：年报附注·每股收益与股本变动、利润表、权益变动表的原文走数据腿；该域是否开放、是否实时，以 catalog 返回为准，本件不承诺。
- **正文腿**：附注常夹在几百页 PDF 里（每股收益计算表、股本变动表、稀释调整明细），长附件与扫描件交 `cue-omni-reader` 解析——先取大纲，再按节取用；计费与可用性以服务端返回为准。
- **深研**：`cue-research` 是独立入口（自带运行脚本），凭据同一把 key。
- 配置页只给指针、不复述开通步骤：数据腿 <https://cuecue.cn/hub/mcp>；解析腿 <https://cuecue.cn/hub/omni-reader>；取 key <https://cuecue.cn/hub/api-key>。

不装通道也能跑：只拿用户直供的附注截图，五节骨架照样出，代价是看不到交易所原文那一路、稀释调整明细与股本变动表多半缺页，只能登记截图里那几行，证据密度降为单份材料且没有出处可回查。

本件不发请求、不代付费，消耗以服务端返回为准。

## 五、和另外几枚包怎么分

| 你手上是 | 用哪枚 |
|---|---|
| 基本与稀释每股收益、加权平均股数、股数调整与追溯列报 | **本件** |
| 可转债的转股价、赎回与回售条款 | `convertible-bond-terms-cn` |
| 外币报表折算差额、折算汇率与折算方法 | `cn-foreign-currency-translation-cn` |
| 合并范围与合并报表口径 | `cn-consolidation-scope-cn` |
| 限制性股票的授予、解锁与费用摊销 | `equity-incentive-plan-cn` |
| 前期差错的性质、更正与重述 | `cn-accounting-error-correction-cn` |

本件只管**每股收益这一块**：可转债作为潜在普通股时，本件只登记它对稀释调整项的影响，转股价与赎回条款归 `convertible-bond-terms-cn`；限制性股票本件只登记它对加权平均股数与每股收益的影响，授予与解锁条件归 `equity-incentive-plan-cn`；转增送股引起的重述，本件照抄披露的重述口径，更正的性质与原因归 `cn-accounting-error-correction-cn`。同一家公司既有可转债又有稀释每股收益时，两件各管各的节，不互相代填。

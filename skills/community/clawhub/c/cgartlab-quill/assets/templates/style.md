# 风格与修辞

## 纲领

> 结构为骨，自由为魂，真诚为血，信噪比为气。

风格 = 长期偏好被约束后的结果，不是语气、不是漂亮句子、不是模板。

## 声音（稳定偏好）

- 短句优先（一段超五行考虑拆开）
- 主动语态
- 具体例子优于抽象概括
- 少空泛形容词与情绪词
- 保留第一人称判断（「我认为 / 我不同意 / 我踩过这个坑」）

## 语调

- [ ] 直接克制
- [ ] 带调侃
- [ ] 严肃论证

## 标题

- 完整句（先写清楚：涉及谁、哪件事、什么判断）：
- 压缩后（从上面那句里删词，不另拼短句）：
- 读者读完标题在等什么答案（正文哪一节回答它）：
- 正文用什么兑现它：

> 遮住全文单独读一遍：陌生人说得出在讲什么才算过。长度按作者基线；感叹号、「震惊 / 必看」、正文不兑现的悬念一律不用。四件事、六种类型与三个表面分工见 `references/distribution.md`。

## 开篇钩子

- 类型：问题 / 场景 / 数据 / 引用
- 入口：结果 / 判断 / 演示 / 需求 / 事件
- 内容：
- 读者带着的问题（他原本就有的疑问，不是这次塞给他的）：
- 来源（**场景与数据必填**）：① 我公开写过的 / ② 从我公开内容可推理的 / ③ 客观或别人公开写过的（都要填真实链接）/ `［请作者补：…］`

> **准入标准只有一条：能找到真实的正确链接。** 没有来源的场景不许写进正文——「具体」不等于「可以编」。
> 关键隐喻若借用了真实事件（历史、行业、他人经历），那个事件同样要能指认来源；纯粹的语言比喻不受此限。
> **链接在 = 合格；合不合适用，由我（用户）最后判断。**
> 完整规则见 `evidence.md` 的「经历与事件来源」。

## 禁用清单（比鼓励清单更易守住）

### 内容级
- 不编造来源；不用「本质上 / 毫无疑问」堆砌抽象
- 不用空泛情绪词（「震撼 / 颠覆 / 史诗级」）替代证据
- 不用过度包装标题；不把 AI 猜测写成事实
- 不写没有具体场景的 AI 式总结开头
- 不留「根据知识库中的相关笔记…」等 AI 占位文本
- 不修改用户的草稿——只读不写

### 形式级
- **禁翻案腔**：「不是A而是B / 表面上A实际上B / 你以为A其实B」及一切变形
- **禁三项以上同构排比**：同一句型连排三次以上留两项
- **禁抽象抒情**：「时间保管细节 / 焦虑显形」→ 还原成人做了什么
- **禁名词化**：「进行了优化 → 改顺了」「实现了增长 → 多挣了多少」
- **禁破折号（过量）**：按作者基线判，超量即减；取不到语料时清零。标题、引文原文、来源分隔符保留。
- **禁提示性冒号（抬价式）**：只禁抬价用法（「一句话总结：」「核心是：」）；引出原话与结构性标签放行。网址、代码、机器字段除外。
- **禁「说白了 / 说穿了 / 先说结论」**
- **禁模型洞察路标**：「更微妙的是 / 还有一层 / 值得注意的是」不用于抬价
- **禁商业黑话**：「赋能 / 抓手 / 闭环 / 底层逻辑」等 → 改成人、动作、钱、时间
- **禁借喻包装**：「仓库 / 抽屉 / 温度 / 死亡」不用于包装抽象概念
- **禁抒情词给抽象概念提气**：「安放 / 抵达 / 微光 / 褶皱」→ 写具体事物时保留，给抽象概念提气时删掉

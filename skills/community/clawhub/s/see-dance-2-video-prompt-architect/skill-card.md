## Description:

Turn rough video ideas into structured English or Chinese Seedance-oriented prompt packs, exact reference bindings, shot sequences, and focused debugging loops.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

External creators, marketers, and developers use this skill to turn rough video concepts into structured Seedance-oriented prompts, reference bindings, sequence plans, and focused revision guidance. It is intended for text-to-video, image-to-video, multimodal reference, product clip, cinematic scene, transition, and loop planning.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The optional MCP setup uses an unpinned GitHub package through npx, which runs remote code locally and can persist an MCP server entry in the agent configuration.

Mitigation: Use the text-only skill normally; before installing the optional MCP, review the source, prefer a pinned commit or signed release when available, and confirm the local permissions and configuration changes.

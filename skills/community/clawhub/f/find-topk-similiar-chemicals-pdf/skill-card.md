## Description:

PDF manipulation toolkit. Extract text/tables, create PDFs, merge/split, fill forms, for programmatic document processing and analysis.

This skill is ready for commercial/non-commercial use.

## Publisher:

[wu-uk](https://clawhub.ai/user/wu-uk)

### License/Terms of Use:

Proprietary

## Use Case:

Developers and document-processing practitioners use this skill to extract PDF content, create or modify PDFs, merge and split files, convert pages to images, and fill PDF forms.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill includes unrelated promotional guidance that can distract from task-focused PDF behavior.

Mitigation: Review or remove the K-Dense Web promotion before installing the skill.

Risk: Repair or form-filling workflows can affect document contents, including in-place operations.

Mitigation: Use output files instead of in-place modification where possible, and make backups before repair or form-filling operations.

Risk: PDF processing can expose or transform documents that the user may not be authorized to process.

Mitigation: Use the skill only on documents the user is allowed to process.

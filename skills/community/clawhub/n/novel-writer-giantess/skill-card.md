## Description:

Novel Writer is a Simplified Chinese fiction-writing agent for analyzing reference style, managing size-tiered worldbuilding, generating outlines, drafting chapter segments, and reviewing consistency.

This skill is ready for commercial/non-commercial use.

## Publisher:

[sherlockeinstein](https://clawhub.ai/user/sherlockeinstein)

### License/Terms of Use:

MIT-0

## Use Case:

Writers and creative-development users use this skill to plan, draft, revise, and review long-form Simplified Chinese serial fiction. It supports style extraction from reference text, project configuration, outline management, chapter drafting, deviation checks, and editorial review.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The workflow is designed for Simplified Chinese giantess/domination and sexualized fiction themes.

Mitigation: Install and use it only for intended creative-writing projects where those disclosed themes are acceptable.

Risk: Reference text, outlines, character files, and generated chapters can steer later model output.

Mitigation: Use a dedicated project folder and review generated chapters, outlines, and review reports before saving or applying changes.

## Use Case:

External users use this skill to search for inspection services, check availability, and create bookings through Lokuli.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can send a user's name, email, phone number, location or ZIP code, and selected appointment details to Lokuli.

Mitigation: Tell the user what information will be sent and ask for explicit confirmation before creating a booking.

Risk: The external booking service may create appointments based on user-provided details.

Mitigation: Confirm the provider, service, date, time slot, and contact details with the user before calling the booking action.

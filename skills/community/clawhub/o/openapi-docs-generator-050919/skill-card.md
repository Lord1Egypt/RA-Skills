## Description:

Helps API developers and platform teams generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, backend teams, platform teams, developer-experience teams, and maintainers use this skill to create practical OpenAPI or Swagger documentation workflows, artifacts, checklists, and validation notes for REST APIs.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad OpenAPI, Swagger, REST API, or developer-experience prompts may invoke the skill when the user expected more general help.

Mitigation: Prefer explicit invocation when the desired outcome is OpenAPI documentation support.

Risk: Generated API documentation may be incomplete or misleading if source routes, schemas, authentication details, or constraints are missing.

Mitigation: Review and validate generated API documentation before publishing it.

## Known Risks and Mitigations:

Risk: The security assessment rates this release suspicious because its installers reportedly run unverified remote scripts with elevated privileges and make persistent system-wide changes; the assessment was incomplete.

Mitigation: Review installer changes before installing, require a verified and pinned installation source, avoid persistent registry changes and automatic global registration, and do not run remote scripts with elevated privileges.

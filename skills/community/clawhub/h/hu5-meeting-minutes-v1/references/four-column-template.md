# 分歧栏示例与验收标准（附录）

## 分歧条目怎么写（一行式）
```
[D-3] 群渠道@试射时机
  甲（照）：入群后立即可试 | 乙（辉）：成员入册后触发 | 卡点：接口侧成员表为空
  现行口径：乙（负责人实测支持）  复议条件：成员表出现非空记录
```
要点：双方观点各一行、卡点一句、**现行执行哪方**必须写明、给复议触发条件。

## 待办可验收改写对照
| 不合格 | 合格 |
|---|---|
| 持续跟进供应商 A | 周三前提交 A 的四维打分表（含证据行）并呈请定灯 |
| 完善规程 | V0.2 成文（含五素材）→ 终审 → 签发，三日闭环，签发件编号在案 |
| 保持联系 | 照窗回执 runId 到档即并单，未到 24h 提醒一次 |

## 漏账排查口诀
> 有发起没回执的、有呈请没裁的、有承诺没期限的——三类各扫一遍，扫到就进在途栏挂凭证。

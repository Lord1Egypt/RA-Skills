## Known Risks and Mitigations:

Risk: CAPTCHA-solving service usage may violate a target service's terms or authorization boundaries.

Mitigation: Use the skill only for authorized integrations and confirm that the target service's terms permit use of a CAPTCHA-solving provider.

Risk: The skill can mention an optional YesCaptcha invite link when users ask about registration.

Mitigation: Present the invite link only with clear disclosure that it is optional and not the official-only registration path.

Risk: API guidance can become stale if YesCaptcha changes methods, fields, or task types.

Mitigation: Prefer the official YesCaptcha documentation links in the skill before implementing or changing integrations.

# 菜单数据模型

菜单是**结构化数据**，SVG 只是它的渲染结果。改菜单一律改数据，不要改 SVG 字符串。

## 菜单对象

```js
{
  schema: 1,
  id: "m...",            // 唯一标识，可用 uid('m') 生成
  name: "城南面馆",       // 店名，必填。空则回落「未命名小馆」
  name_original: "",     // 原文字（外文菜单用来并排显示原名）
  subtitle: "",          // 副标题，如「本店招牌 · 每日现做」
  footer: "",            // 页脚说明，如「人均 45 元 · 营业 11:00–21:00」
  seal: "城南",           // 右下角印章，两个字最佳。空则取店名前两字
  theme: "rice",         // 配色主题 id，见 references/themes.md
  dishes: [ ... ],       // 菜品数组，顺序即排版顺序
  createdAt: 0,
  updatedAt: 0
}
```

## 菜品对象

```js
{
  id: "d...",            // 唯一标识，重复会报 error
  section: "招牌面",      // 分节标题。相同 section 的连续菜品归在同一节下
  name: "红烧牛肉面",      // 菜名。超过两行会被截断 → error
  name_original: "",     // 原文菜名（多语菜单用）
  romanization: "",      // 拼音 / 罗马音，可选
  price: "42",           // 价格。字符串，不带货币符号也认。缺失 → warn
  blurb: "牛骨汤熬足…",   // 一句话说明，建议 ≤ 60 字，超两行 → warn
  tags: ["酸辣", "开胃"],  // 标签，2–4 个，渲染成小字行
  signature: false,      // 是否招牌菜。只有第一道会放大成顶部大图
  signature_note: "",    // 招牌判断依据。仅给人和 Agent 核对，不印在纸面上
  kind: "noodle",        // 插图类别，见 references/art-kinds.md。空则自动推断
  art: "",               // 外部 SVG 片段。非空时优先于引擎生成，会被白名单清洗
  _seed: ""              // 换图种子。设成新值可让同一道菜换一幅构图
}
```

## 三个容易踩的字段

**`section` 用连续分组，不是全局分组。**
排版按数组顺序走，遇到和上一个不同的 section 就起新标题。所以 `热菜, 热菜, 凉菜, 热菜` 会出现两个「热菜」标题。要么排好序，要么合并同名节。

**`signature` 只对第一道生效。**
标了多道招牌，只有第一道放大，其余仍按普通行排，并在质检里报 `multi-signature`。所以要放大哪道，就把哪道排在前面。

**`price` 是字符串，不是数字。**
可以写 `"42"`、`"¥42"`、`"42/位"`。混着写会触发 `price-format` / `price-unit` 警告，`--fix` 会把货币符号统一补上。

## 版式常量（只读，用于估算篇幅）

| 常量 | 值 | 含义 |
|---|---|---|
| `PAPER.width` | 880 | 纸宽，viewBox 单位 |
| `PAPER.marginX` | 76 | 左右页边距 |
| `PAPER.padTop` | 96 | 顶部留白 |
| `PAPER.padBottom` | 108 | 底部留白 |
| `PAPER.maxHeight` | 4200 | 建议最大高度，超出报 `too-long` |
| `SZ.artNormal` | 88 | 普通菜插图边长 |
| `SZ.artSignature` | 216 | 招牌菜插图边长 |
| `SZ.priceW` | 92 | 价格列宽 |
| `SZ.rowGap` | 26 | 菜行间距 |
| `SZ.sectionGap` | 34 | 分节前间距 |

## 篇幅估算

一道普通菜约占 **120–150 单位**（有描述和标签时取高值），一个分节标题约占 **60 单位**，招牌菜约占 **440 单位**。

按 4200 上限算：**纯普通菜约 28–34 道；含 1 道招牌再加 3 个分节，约 22–26 道。** 超过这个量级，要么拆成两张菜单（正餐 / 酒水），要么砍描述。

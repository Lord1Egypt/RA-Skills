# HIV-1复制周期与致病机制分析

## 适用场景

- 分析HIV-1感染宿主细胞的完整复制流程
- 评估抗病毒药物的作用靶点与机制
- 解释HIV导致CD4+ T淋巴细胞减少的多重原因
- 理解HIV受体嗜性（R5毒株 vs X4毒株）的临床意义

## 适用对象

- HIV-1病毒株（不涵盖HIV-2特异性差异）
- 表达CD4分子的宿主细胞：CD4+ T淋巴细胞、巨噬细胞、树突状细胞

## 核心工作流程

### 第一步：分析复制周期阶段

按以下5个连续阶段逐一分析HIV-1的复制过程：

#### 阶段1：受体结合与侵入（吸附与穿入）

1. gp120与第一受体CD4分子结合
2. gp120构象改变，暴露共受体结合位点
3. 与第二受体（共受体）结合：
   - **R5毒株**：利用CCR5受体（早期感染主要毒株）
   - **X4毒株**：利用CXCR4受体（晚期感染出现，可兼用CCR5、CXCR4、CCR3）
4. gp120与gp41分离，gp41介导病毒包膜与宿主细胞膜融合
5. 病毒核心进入细胞质

**药物靶点**：融合抑制剂（如恩夫韦肽）、CCR5拮抗剂（如马拉韦罗）

#### 阶段2：反转录与整合

1. 反转录酶（RT）将病毒单链RNA反转录为cDNA
2. RNA酶H降解RNA-DNA杂交链中的RNA
3. RT以cDNA为模板合成第二条DNA链，形成双链DNA
4. 双链DNA转运入细胞核
5. 整合酶（INT）将病毒双链DNA整合入宿主染色体DNA
6. 形成前病毒（provirus）

**药物靶点**：核苷类反转录酶抑制剂（NRTIs）、非核苷类反转录酶抑制剂（NNRTIs）、整合酶抑制剂（INSTIs）

#### 阶段3：转录与翻译

1. 前病毒DNA在宿主RNA聚合酶II作用下转录为病毒RNA
2. 部分RNA经加帽、加尾处理成为子代基因组RNA
3. 部分RNA经剪接形成mRNA
4. mRNA在细胞核糖体翻译为病毒蛋白（结构蛋白与非结构蛋白）
5. 蛋白经内质网糖化加工
6. 蛋白酶（PI）将多聚蛋白前体裂解为功能性子代蛋白和酶类

**药物靶点**：蛋白酶抑制剂（PIs）

#### 阶段4：装配、成熟与出芽

1. Gag蛋白与病毒基因组RNA结合，装配成核壳体
2. 未成熟颗粒通过芽生方式从胞质膜释放
3. 出芽过程中获得宿主细胞膜来源的病毒包膜
4. PI介导的蛋白裂解使病毒颗粒成熟

#### 阶段5：CD4+ T淋巴细胞减少机制

分析以下4种导致CD4细胞耗竭的机制：

| 机制 | 描述 |
|------|------|
| 直接凋亡/焦亡 | HIV直接诱导感染细胞程序性死亡 |
| 直接杀伤 | 病毒出芽破坏细胞膜完整性，导致细胞裂解 |
| 间接杀伤 | 炎症因子释放及免疫系统（CTL等）杀伤感染细胞 |
| 胸腺损伤 | 胸腺组织萎缩，胸腺细胞死亡，新T细胞生成减少 |

### 第二步：映射药物靶点到复制阶段

根据分析的复制阶段，建立药物靶点对照表：

```
复制阶段          →  关键酶/蛋白    →  药物类别
─────────────────────────────────────────────────
吸附与穿入        →  gp41/CCR5      →  融合抑制剂/CCR5拮抗剂
反转录            →  RT             →  NRTIs / NNRTIs
整合              →  INT            →  整合酶抑制剂（INSTIs）
翻译后加工        →  PI             →  蛋白酶抑制剂（PIs）
```

### 第三步：综合评估

1. 确认分析的病毒株类型（R5嗜性/X4嗜性/双嗜性）
2. 识别当前复制阶段对应的可干预靶点
3. 结合CD4下降机制评估免疫损伤程度
4. 输出完整的机制分析结论

## 约束条件

- 本技能仅适用于表达CD4分子的宿主细胞
- 不涵盖HIV-2的特异性差异
- 分析药物靶点时以HIV-1为主要参考

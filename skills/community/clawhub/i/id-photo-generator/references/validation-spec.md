# 校验规格表（Validation Spec）

本文件集中全部校验项与阈值，供 Skill 各步骤对照执行。硬拒绝项（hard_fail）直接终止；软警告项（soft_warning）放行但必须随结果返回。

## 一、输入硬限制

| 限制项 | 允许范围 | 判定 | 提示 |
|---|---|---|---|
| 支持格式 | JPEG、JPG、PNG、WEBP | 魔数识别真实格式 | "请上传 JPG、PNG 或 WEBP 格式的图片。" |
| 禁止格式 | GIF | 硬拒绝 | "不支持GIF动图，请上传静态JPG、PNG或WEBP图片。" |
| 文件大小 | ≤ 10 MB | 硬拒绝 | "图片文件过大，请压缩至 10MB 以内后重试。" |
| 最小分辨率 | 单边 ≥ 512 px | 硬拒绝 | "图片分辨率过低，请上传更清晰的照片。" |
| 最大分辨率 | 单边 ≤ 4096 px | 自动等比缩放，不拒绝 | 无需提示 |
| 文件损坏/截断 | 可正常解码 | 硬拒绝 | "图片文件损坏，无法解析，请重新上传正常图片。" |

**关键前置规则：**
- 不依赖文件后缀，读取文件头魔数判断真实格式（防后缀欺骗）。
- 解码成功后再依据 EXIF Orientation 做物理旋转矫正；旋转后重算宽高，再执行分辨率校验与后续全部处理。
- 色彩模式：CMYK 自动转 RGB 并软警告；输入带透明通道的 PNG 填充中性灰(128,128,128)后再校验并软警告。

## 二、内容安全预筛（硬拒绝）

- 纯色图 / 纯文字截图 / UI 截图 → 拒绝："未检测到人像内容，请上传真实的人物照片。"
- 完全黑白或严重偏色（饱和度接近 0 且非有意黑白照）→ 提示："请上传彩色照片。"

## 三、图像质量门禁（硬拒绝）

| 校验项 | 检测方法 | 判定 | 提示 |
|---|---|---|---|
| 模糊度 | Laplacian 方差 / Tenengrad | 低于阈值 → 拒绝 | "图片模糊，请保持相机稳定、对焦清晰后重新拍摄。" |
| 整体曝光 | 平均亮度统计 | 过暗或过亮（大面积纯白）→ 拒绝 | "图片过暗/过曝，请在光线均匀的环境下拍摄。" |
| 曝光均匀性 | 人脸区域分块亮度差异 | 半边脸过暗或油光过强 → 拒绝 | "面部光线不均，请避免强光直射或单侧阴影。" |
| 压缩伪影 | JPEG 块状伪影检测 | 伪影面积占比过高 → 拒绝 | "图片压缩痕迹过重，请上传原图或更高质量的照片。" |
| 噪点水平 | 噪声估计 | 超标且降噪后仍不可用 → 拒绝 | "图片噪点过多，请在光线充足的环境下拍摄。" |

参考：模糊检测常用 Laplacian 方差；亮度分析判欠曝/过曝。

## 四、人脸质量与可见性

| 校验项 | 阈值参考 | 判定 |
|---|---|---|
| 人脸置信度 | ≥ 0.75 | 低于 → 硬拒绝 "人脸不清晰" |
| 人脸面积占比 | 10%–70%（占全图） | 过小/过大 → 软警告 |
| 头部姿态 yaw/pitch/roll | 各方向 ≤ 30°，严格场景 ±10° | 超限 → 硬拒绝 "请正对镜头" |
| 眉眼鼻唇可见性 | 达到最低占比 | 缺失 → 硬拒绝 "面部被遮挡" |
| 耳朵可见性 | 双耳外轮廓可见比例 ≥ 阈值 | 完全遮挡硬拒绝；部分露出软警告 |
| 遮挡物 | 帽子/墨镜/口罩 → 硬拒绝；透明眼镜放行但查反光 | 拒绝并提示摘除；合规头巾除外 |
| 眼镜反光 | 镜片高亮低饱和像素占比 | 遮瞳硬拒绝；轻微软警告放行 |
| 闭眼/红眼 | 眼睛开合度 + 瞳孔红色通道 | 硬拒绝 "请睁眼并正视镜头，避免红眼。" |

**特殊规则：**
- 合规宗教头巾放行（必须眉眼口鼻全部可见）；普通帽子拒绝。
- 低龄儿童：如需支持，用独立宽松关键点/姿态阈值；不支持则提示。
- 禁止对人脸美颜/磨皮/瘦脸/修复痣疤痕胎记；全局降噪不能针对人脸 ROI 平滑。

## 五、真实性预筛（分级）

| 检测项 | 高安全模式（政务/考试） | 普通模式（简历/预览） |
|---|---|---|
| 翻拍（照片中照片：摩尔纹/边框/反光/打印纹理） | 硬拒绝 | 软警告放行 |
| 合成/拼接（边缘不一致、光照矛盾、肤色断层） | 硬拒绝 | 软警告放行 |
| 深度伪造 / 对抗样本 | 建议接入活体/Deepfake 检测 | 软警告放行 |

高安全硬拒绝文案："请上传原始拍摄的照片，不要翻拍已有照片或使用合成图片。"
普通软警告文案："检测图片疑似翻拍/合成，该照片无法用于政务、考试等正式办理场景，仅可用于个人预览参考。"

## 六、姿态自动校正（自动摆正，新增）

当人物身形/姿态为**轻微偏差**时，在抠图前做确定性几何校正（仅旋转/平移/轻微透视，不改变面部特征与身份）。

| 姿态项 | 可自动校正范围 | 处理 | 硬边界（不做自动摆正） |
|---|---|---|---|
| 头部/上身倾斜 roll | ≤ 10° | 绕画面中心反向旋转摆正 | >10° 且明显歪斜：拒绝 |
| 水平偏离中心 | 任意（平移即可） | 平移至水平居中 | — |
| 俯仰 pitch / 偏航 yaw | ≤ 8° 且五官清晰 | 轻微透视/平移修正，不重塑五官 | >30°（严重侧脸/低头/仰头）、转脸、闭眼、五官大面积遮挡：**直接硬拒绝** |

**校正流程：**
1. 姿态自动校正（上述几何操作）。
2. **校正后复检**：重新执行人脸姿态（yaw/pitch/roll ≤30°）与眉眼鼻唇可见性校验。
3. 复检仍超阈值 → 硬拒绝，不强行生成。
4. 输出元数据记录：是否执行校正、旋转角度、水平位移。

**合规红线：**
- 自动校正仅为**几何摆正**；禁止磨皮、瘦脸、换五官、调整眼神、重构身形或凭空补画身体。
- 不改变身份、五官、表情、发型、服装；严重姿态问题严禁"捏造"端正姿态（属合成/换姿态，违反真实性）。

# 保险条款关键信息提取模式

本文件定义从保险条款文本中提取关键信息的匹配模式，供分析时参考。

## 一、保险责任提取模式

### 保障责任标识
```
关键词: 保险责任|保障范围|本公司承担|本公司给付|我们承担|我们给付
匹配逻辑: 定位"保险责任"章节，提取该章节下所有保障内容
```

### 给付方式识别
```
一次性给付: 一次性给付|一次性赔付|按基本保险金额给付
按比例报销: 按比例|报销比例|赔付比例|给付比例
分期给付: 分期给付|按年给付|按月给付
津贴: 津贴|每日|每日补助
```

### 特殊保障识别
```
额外赔付: 额外给付|额外赔付|翻倍|加倍
特定疾病: 特定疾病|少儿特定|男性特定|女性特定
豁免: 豁免|免交|免缴
```

## 二、责任免除提取模式

### 免责标识
```
关键词: 责任免除|除外责任|不承担|不给付|不赔|下列情况
匹配逻辑: 定位"责任免除"章节，逐条提取免责情形
```

### 常见免责类型
```
违法犯罪: 犯罪|违法|故意|斗殴|吸毒|酒驾|无证驾驶
战争风险: 战争|军事|恐怖|暴乱|核辐射|核污染
既往症: 既往症|投保前|既往|已有|已患
高风险活动: 潜水|跳伞|攀岩|蹦极|赛车|武术比赛
自杀: 自杀|自伤|故意伤害
遗传性/先天性: 遗传性|先天性|染色体异常
精神疾病: 精神疾病|精神障碍|心理疾病
孕产相关: 怀孕|流产|分娩|不孕不育|整容
```

## 三、时间条件提取模式

### 等待期
```
模式: 等待期.*?(\d+)\s*(天|日)
模式: 观察.*?(\d+)\s*(天|日)
常见值: 30天|60天|90天|180天
注意: 不同责任可能等待期不同（如重疾180天，轻症90天）
```

### 犹豫期
```
模式: 犹豫期.*?(\d+)\s*(天|日)
常见值: 10天|15天|20天
```

### 宽限期
```
模式: 宽限期.*?(\d+)\s*(天|日)
常见值: 60天
```

### 赔付间隔期
```
模式: 间隔期.*?(\d+)\s*(天|日)
模式: 两次.*?间隔.*?(\d+)\s*(天|日)
常见值: 180天|365天
```

### 保险期间
```
模式: 保险期间.*?(终身|\d+\s*年)
模式: 保障期间.*?(终身|\d+\s*年)
常见值: 1年|5年|10年|20年|30年|终身|至70岁|至80岁
```

## 四、金额规则提取模式

### 保额
```
模式: 基本保险金额.*?(\d+(?:,\d+)*(?:\.\d+)?)\s*(元|万)
模式: 保额.*?(\d+(?:,\d+)*(?:\.\d+)?)\s*(元|万)
模式: 保险金额为.*?(\d+(?:,\d+)*(?:\.\d+)?)\s*(元|万)
```

### 免赔额
```
模式: 免赔额.*?(\d+(?:,\d+)*(?:\.\d+)?)\s*(元|万)
模式: 起付线.*?(\d+(?:,\d+)*(?:\.\d+)?)\s*(元|万)
常见值: 0|100|200|500|1000|5000|10000
注意: 区分"绝对免赔"和"相对免赔"
注意: 检查是否有"年度免赔额"和"单次免赔额"
```

### 赔付比例
```
模式: 赔付比例.*?(\d+)\s*%
模式: 报销比例.*?(\d+)\s*%
模式: 给付比例.*?(\d+)\s*%
模式: 按.*?(\d+)\s*%.*?(赔付|报销|给付)
常见值: 60%|70%|80%|90%|100%
注意: 检查是否有社保/无社保的区别
```

### 封顶线
```
模式: 年度限额.*?(\d+(?:,\d+)*(?:\.\d+)?)\s*(元|万)
模式: 累计限额.*?(\d+(?:,\d+)*(?:\.\d+)?)\s*(元|万)
模式: 最高.*?(\d+(?:,\d+)*(?:\.\d+)?)\s*(元|万)
模式: 封顶.*?(\d+(?:,\d+)*(?:\.\d+)?)\s*(元|万)
```

## 五、理赔条件提取模式

### 医院范围
```
模式: (二级|三级|二级及以上|三级甲等).*(公立|医院)
模式: 公立医院.*?(二级|三级)
模式: 指定医院|认可医院|网络医院
注意: 检查是否含"特需""国际部""VIP部"的限制
```

### 就医地域
```
模式: 中国境内|中国大陆|全球|除美|大中华
注意: 检查是否区分"境内"和"境外"
```

### 理赔材料
```
关键词: 理赔申请|理赔材料|理赔资料|申请理赔
常见材料: 诊断证明|病历|发票|费用清单|检查报告|出院小结|身份证|银行卡
```

### 直赔/垫付
```
关键词: 直付|直赔|垫付|预付
注意: 检查是否有条件限制
```

## 六、续保条件提取模式

### 续保类型
```
保证续保: 保证续保|保证续保期间|保证续保.*?年
非保证续保: 非保证续保|经审核|需审核|保险公司有权
模式: 保证续保.*?(\d+)\s*年
常见值: 5年|6年|10年|15年|20年|终身
```

### 费率调整
```
关键词: 费率调整|调整费率|费率可调|保费调整
注意: 检查调整条件和频率
```

### 停售处理
```
关键词: 停售|停止销售|产品停售
注意: 检查停售后是否可转保或续保
```

### 续保年龄
```
模式: 续保.*?(\d+)\s*岁
模式: 续保年龄.*?(\d+)\s*岁
常见值: 60岁|65岁|70岁|80岁|99岁|105岁
```

## 七、健康告知提取模式

### 告知方式
```
询问告知: 询问告知|问询告知|告知事项
无限告知: 无限告知
```

### 既往症定义
```
关键词: 既往症|既往|投保前|已有|已患|已确诊|已治疗
```

```
智能核保: 智能核保|智能告知|在线核保
人工核保: 人工核保|邮件核保
```


### 医疗险


## 使用说明

1. 上述模式为参考模式，实际条款表述可能变化，需结合上下文灵活匹配
2. 优先使用关键词定位章节，再在章节内逐句分析
3. 多个模式可组合使用以提高准确率
4. 提取结果需标注原文出处，便于用户核实
5. 遇到模糊表述时，标注"需进一步确认"

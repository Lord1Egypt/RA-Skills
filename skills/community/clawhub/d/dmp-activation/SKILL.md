## 工作流程

### 请求类型自动识别

当您发起请求时，系统会自动识别请求类型并进入相应流程：

**1. 技能咨询请求**（"有哪些功能"、"能做什么"）
- 展示RTQ投放订单管理功能的详细说明
- 直接结束，等待您的下一步需求

**2. 查询订单请求**（"查询投放订单123456"）
- 直接调用查询脚本
- 展示订单详情（订单ID、订单名称、投放时间、订单状态等）

**3. 修改订单请求**（"修改投放订单123456"）
- ⚠️ **强制确认机制**：修改前必须经过用户明确确认

- **重要**：如果用户回复"取消"或"修改"，则不执行修改操作

## 支持的功能

### 1. RTQ投放订单创建

**功能说明：** 创建RTQ投放订单，支持人群包定向和属性定向

**适用场景：** 精准广告投放、人群包投放、属性定向投放

**必填参数：** 订单名称、投放时间、流量类型、性别定向、年龄定向、是否使用人群包

**示例：** "创建投放订单，投放人群125621到移动端，目标女性用户，年龄25-44岁，投放时间6月1日到6月3日"

### 2. RTQ投放订单查询

**功能说明：** 查询已创建的投放订单详情

**适用场景：** 查看订单状态、投放进度

**必填参数：** 订单ID（可选）、订单名称（可选）、订单状态（可选）

**示例：** "查询投放订单30000933"

### 3. RTQ投放订单修改（智能参数引导）

**功能说明：** 修改已创建的投放订单参数，支持智能参数引导和强制确认流程

**适用场景：** 调整投放时间、人群包、定向条件

**✨ 智能参数引导特性：**

本技能支持两种修改模式，根据订单来源自动选择：

**模式A：智能修改（本技能创建的订单）**
- ✅ 自动从本地缓存读取订单的完整参数
- ✅ 用户只需提供要修改的参数（如订单名称）
- ✅ 其他参数自动保持不变
- ✅ 体验流畅，无需重复输入

**模式B：完整参数引导（其他来源的订单）**
- ⚠️ 由于无法查询订单详情，需要用户提供完整参数
- ✅ 逐步引导用户提供必需参数
- ✅ 每个参数都有清晰的说明和选项
- ✅ 避免一次性要求太多参数

**⚠️ 强制确认机制：**
- 修改前必须展示参数确认表格
- 必须等待用户明确回复"确认"、"是"、"可以"等确认词
- 用户回复"取消"或"修改"则不执行修改操作
- **禁止在未经用户确认的情况下自动执行修改**

**修改流程（智能引导流程）：**

1. **识别修改请求** - 检测到"修改订单"关键词和订单ID

2. **检查订单缓存** - 自动检查本地是否有该订单的缓存
   - ✅ 找到缓存 → 进入**智能修改模式**（只需提供要修改的参数）
   - ⚠️ 未找到缓存 → 进入**完整参数引导模式**（需要提供所有参数）

3. **参数收集**
   
   **智能修改模式（找到缓存）：**
   - 展示订单当前参数
   - 询问用户要修改哪些参数
   - 用户只需提供要修改的参数（如订单名称）
   - 其他参数自动从缓存读取
   
   **完整参数引导模式（未找到缓存）：**
   - 逐步询问用户提供必需参数：
     - 订单名称
     - 投放时间（开始日期、结束日期）
     - 流量类型（mobile/pc/ott）
     - 性别定向（male/female/all）
     - 年龄定向（18-24, 25-34, 35-44, 45-54, 55+）
     - 是否使用人群包（true/false）
     - 人群包信息（当isTag=true时）
     - Cookie类型（当flowType=pc时）

4. **参数确认** - 展示完整的参数确认表格：
   ```
   📋 修改订单参数确认
   
   | 参数名称 | 参数值 |
   |----------|--------|
   | 订单ID   | 30003269 |
   | 订单名称 | 女性美妆投放 |
   | 开始日期 | 2026-06-15 |
   | 结束日期 | 2026-06-25 |
   | 性别定向 | 女性 |
   | 年龄定向 | 25-34岁, 35-44岁 |
   
   ⚠ 请仔细核对以上参数，确认无误后订单将立即修改。
   
   是否确认修改订单？
   请回复：确认 / 取消 / 修改
   ```
5. **等待用户确认** - 必须等待用户明确回复：
   - 用户回复"确认"、"是"、"可以" → 执行修改
   - 用户回复"取消"、"修改" → 取消操作，不执行修改
   - 用户回复其他内容 → 提示"无效输入，请回复：确认 / 取消 / 修改"

6. **执行修改** - 仅在用户明确确认后调用API修改订单

7. **更新缓存** - 修改成功后自动更新本地缓存，方便下次修改

## 常见问题

### Q: 凭证过期了怎么办？
A: 系统会自动调用鉴权技能引导您重新配置凭证。

### Q: 创建订单后多久能生效？
A: RTQ投放订单创建成功后立即生效，您可以通过查询订单状态功能查看详情。

### Q: 如何知道订单创建是否成功？
A: 订单创建成功后会返回订单ID和订单状态，您可以使用查询订单状态功能查看详情。

### Q: 参数填错了怎么办？
A: 在参数确认表格展示后，您可以回复"取消"来取消本次操作，然后重新提出需求。

### Q: 系统如何识别我的需求类型？
A: 系统会自动分析您的请求内容：
- 包含"有哪些功能"、"能做什么" → 技能咨询
- 包含"查询订单" + 订单ID → 查询订单状态
- 包含"修改订单" + 订单ID → 修改订单
- 包含"投放"、"订单"、"RTQ" → 创建投放订单

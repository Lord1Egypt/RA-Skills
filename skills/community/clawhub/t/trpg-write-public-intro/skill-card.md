## Description:

Writes a Traditional Chinese, player-facing public introduction for a TRPG rule system for README or release pages.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ice26985850](https://clawhub.ai/user/ice26985850)

### License/Terms of Use:

MIT-0

## Use Case:

External creators and TRPG authors use this skill to turn rulebooks, scenarios, character sheets, and related source materials into a public-facing Traditional Chinese introduction for potential players.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill reads workspace rule materials and related formal files to generate public copy.

Mitigation: Run it in a workspace that contains only the rule materials intended for the introduction.

Risk: Generated promotional text may misstate a game's rules, influences, or player expectations.

Mitigation: Review the generated [rule name]_介紹.txt before publishing or sharing it.

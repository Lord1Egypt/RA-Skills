## Description:

Use when receiving code review feedback, before implementing suggestions, especially if feedback seems unclear or technically questionable - requires technical rigor and verification, not performative agreement or blind implementation.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ivansslo](https://clawhub.ai/user/ivansslo)

## Use Case:

Developers and coding agents use this skill to handle code review feedback with technical verification before acting. It helps evaluate unclear, questionable, or external suggestions before implementation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill intentionally discourages gratitude-style code review acknowledgments, which may not match every team's communication norms.

Mitigation: Review the expected communication style before enabling it for agents that reply directly to reviewers.

Risk: The skill can shape responses to GitHub review threads, so posted replies should remain user-directed.

Mitigation: Require user approval before an agent posts or submits actual GitHub review replies.

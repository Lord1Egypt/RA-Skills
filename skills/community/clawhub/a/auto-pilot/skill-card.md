## Description:

Enables an agent to autonomously decide, act, predict outcomes, and plan next steps in a continuous goal-driven loop without waiting for instructions.

This skill is ready for commercial/non-commercial use.

## Use Case:

Agent users apply this skill when they want a general assistant to respond with concrete action, rationale, expected result, and the next step for a goal-driven workflow.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill broadly encourages autonomous action without clear approval boundaries.

Mitigation: Limit use to planning or low-impact tasks unless explicit human confirmation is added for external, financial, destructive, privacy-sensitive, or irreversible actions.

Risk: The skill can push an agent to continue execution even when a goal lacks constraints or success criteria.

Mitigation: Require the agent to state assumptions, constraints, expected result, and next step before any action that could affect user data, accounts, money, or systems.

# 定价与报价策略

## 场景定义

- **目标**：产品/服务的定价策略制定与具体报价、议价博弈——让价格既守住利益底线，又服务成交目标。
- **约束**：客户预算是黑箱；价值与成本信息不对称；竞品可比价随时可被引入；议价过程情绪化风险高；让步不可逆（先例即后续所有谈判的锚）。
- **角色**：定价负责人、销售/商务、负责人（报价审批线）。
- **典型输入**：①新产品上市定价策略；②具体项目/订单的报价与议价；③年度调价与老客户续约谈判。
- **边界**：需求取证与产品定位上游归 APP-038 产品定位与需求洞察；成本结构的降本问题外送 APP-033 成本与费用管控；议价落定后的正式条款谈判外送 APP-001 谈判博弈——本 Skill 管"定多少钱、怎么报、怎么让、何时走"。

## 组合公式

- **顺序**：比算段（SZ-01→GZ-14→MZD-12）→ 测情段（GZ-26→GZ-03）→ 定策段（MZD-02→SZ-15→SZ-18）→ 试探段（SZ-31→GZ-34→GZ-28）→ 复盘段（MZD-46，常态挂起，偏差触发）。
- **条件分支**：新客户首次报价 → 先 GZ-14 量权定锚、后 GZ-03 极点测预算；老客户续约 → 先 MZD-46 复盘历史报价偏差（我方报错还是客户压价结构）再进定策段；招标比价场景 → SZ-31 试探降权（无试探空间）、GZ-14 与 SZ-18 提权（一标定生死，量权与利益闸门从严）。
- **权重**：SZ-18 权重最高——一切让步过"合于利"闸门，情绪让步一律无效。
- **冲突裁决**：成交冲动 与利益核算冲突 → 按 SZ-18 裁决：情绪后果可逆（丢单可再找），行动后果不可逆（破价先例不可收回）；报高价 与丢单风险冲突 → 按 SZ-15 两张清单并算 + MZD-02 先锁主要目标（准入期舍利取市、盈利期舍利即走——一次只锁一个主要矛盾）；客户施压逼价 与底线冲突 → 按 GZ-34 口者机关裁决——开闭有时，不接情绪牌，择时重开。

## 执行步骤

1. **双向情报**（SZ-01）：彼（客户预算区间、决策链、替代选项、比价史）与己（真实成本、产能上限、让步空间）双向摸清——缺任何一侧，报价胜率系统性衰减。
2. **量权过秤**（GZ-14）：市场行情与双方实力逐项盘点——竞品价、客户支付能力、我方不可替代度、供需态势，逐项过秤后形成锚区间。
3. **底线落数**（MZD-12）：成本线、盈亏平衡点、不同折扣下的毛利——价格方案必须建立在基本数量分析上，没有数量的"感觉价"一律重做。
4. **由外测内**（GZ-26）：以外部表征推隐情——采购流程的紧急度、比价对象的选择、过往付款爽快度，皆是预算与真实意向的外显。
5. **极点测价**（GZ-03）：在客户得失攸关时刻（招标截止前、预算到期前、业务痛点发作时）逼近——客户在时间与痛点的极值处无法掩饰真实的价格敏感。
6. **锁主要目标**（MZD-02）：本次报价全力投向单一主要目标——要利润、要准入、还是要清产能？目标定错，报价技巧全部归零。
7. **利害两算**（SZ-15）：每版报价同时列算利清单（毛利、账期、附带订单）与害清单（丢单、破价先例、关系损伤、服务成本）——在利中见害、在害中见利。
8. **利益闸门**（SZ-18）：预设让步的"合于利"闸门——低于闸门价的成交申请一律触发离席复核；高冲动点上的成交冲动强制过闸核算。
9. **四途试探**（SZ-31）：策（推演客户对各价位反应）、作（投石问路式报价触发反馈）、形（示分层方案观察取舍）、角（小单/首单小规模真实议价）——以可控动作探弹性，不待终局谈判才知虚实。
10. **口者机关**（GZ-34）：报价信息的释放按节奏开闭——底牌不先亮、让步不自动给、每说必有听与看的参调印证；确证有利才推进。
11. **不合即止**（GZ-28）：报价与客户情理明显不合（预算量级、认知框架错位）时禁止强行推销——转可行处变通：拆分订单、分期阶梯、缩配置，"行不通"本身是重估信号不是加码信号。
12. **偏差寻根**（MZD-46）：定价偏差（高报丢单/低报吃亏）不止于现象检讨，溯源土壤——成本误判？情报缺失？主要目标错锁？——不除土壤则偏差复发。

## 失效预案

- **报价即死（客户消失）**：退回 GZ-28 复盘——报价与其情理不合 → 回 GZ-26/GZ-03 重测真实预算，转可行处变通（拆分/缩配/分期）后再报。
- **连环压价**：退回 SZ-18 利益闸门——低于闸门即离席不恋战；同时回 MZD-02 重锁主要矛盾（客户压的是价格还是价值感？价值感问题转价值证明而非降价）。
- **情绪对峙**：退回 GZ-34 口者机关关闭——暂停信息释放，择时重开；以 SZ-15 在害中见利，找非价格交换项（账期、量、周期）化解。
- **丢单复盘**：退回 MZD-46 溯源三分——情报缺失（回 SZ-01/GZ-26 重取）、锚定错误（回 GZ-14 重量）、目标错锁（回 MZD-02 重锁）。
- **一切争议不决**：兜底回 SZ-18 非利不动——合于利而动，不合于利而止。

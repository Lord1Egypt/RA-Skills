# 儿童神经发育障碍诊断与干预

## 使用时机

当儿童/青少年出现以下情况时应用此技能：
- 社交互动/交流缺陷及受限/重复行为模式（疑似ASD）
- 与年龄不匹配的注意缺陷、多动和冲动（疑似ADHD）
- 阅读/书写/计算技能严重持续困难（疑似SLD）
- 运动协调性差、动作笨拙影响日常生活（疑似DCD）
- 不自主运动或发声（疑似抽动障碍）

## 一、孤独症谱系障碍(ASD)

### 诊断要点核查

1. **起病时间**：发育早期
2. **核心表现**：
   - 多种场合下社交互动和社交交流的持续性缺陷
   - 受限的、重复的行为模式、兴趣或活动
3. **功能损害**：导致社交、职业或其他重要功能有临床意义的损害
4. **排除标准**：症状不能用智力障碍或全面发育迟缓解释

### 鉴别诊断决策

| 鉴别疾病 | 关键区分点 |
|---------|-----------|
| 智力发育障碍 | ASD有社交质的损害+刻板行为；智力障碍全面落后 |
| ADHD | ASD有社交质的损害+刻板行为；ADHD以注意缺陷/多动/冲动为核心 |
| 选择性缄默 | ASD所有场合社交缺陷；选择性缄默仅特定环境不能说话 |
| 精神分裂症 | ASD起病于发育早期；精神分裂症有正常发育阶段后有精神病性症状 |

### 综合干预方案

**教育行为干预**（核心）：
- 应用行为分析(ABA)：回合式教学、关键反应训练、随机教学法
- 结构化教学
- 社交技巧干预（针对不伴智力/语言明显落后者）

**药物治疗**（针对伴发问题）：
- 易激惹/攻击/自伤：利培酮、阿立哌唑
- 共患ADHD：哌甲酯、托莫西汀
- 共患睡眠障碍：褪黑素

## 二、注意缺陷多动障碍(ADHD)

### 诊断标准核查清单

- [ ] 起病年龄 < 12岁（3岁前难与正常好动区分，一般不诊断）
- [ ] 核心症状：与年龄/智能不匹配的注意缺陷、多动和冲动
- [ ] 病程 ≥ 6个月
- [ ] 场合数 ≥ 2个（学校、家庭等）
- [ ] 社会功能显著受损
- [ ] 排除精神分裂症、心境障碍、物质中毒/戒断等

### 临床分型

- 注意缺陷为主型
- 多动-冲动为主型
- 混合型

### 药物治疗决策

| 药物 | 机制 | 适用人群 | 关键注意事项 |
|-----|------|---------|-------------|
| 哌甲酯 | 抑制多巴胺转运体 | 6岁以上 | 心脏结构性损害禁用；监测心率/血压/体重 |
| 托莫西汀 | 抑制去甲肾上腺素转运体 | 7岁以上 | 合并抽动/焦虑者优选；耐受性好 |

**哌甲酯副作用监测**：
- 早期：食欲降低、胃痛、头痛、入睡困难
- 情绪：烦躁易怒
- 心血管：心率/血压增高
- 长期：不影响生长发育

### ADHD鉴别诊断

| 鉴别疾病 | 关键区分点 |
|---------|-----------|
| 智力发育障碍 | ADHD治疗后学业能提高至与智力相当；智力障碍始终困难 |
| 焦虑障碍 | 焦虑有主观体验+躯体化症状；ADHD无此特征 |
| 心境障碍 | 心境障碍发作性，间歇期正常；ADHD持续性 |
| 正常活泼儿童 | 正常儿童在需安静场合能保持不动，学习交往良好 |

## 三、发育性学习障碍(SLD)

### 诊断要点

1. 早期学业学习中显现
2. 阅读、书写和/或计算技能严重持续困难
3. 学业技能明显低于年龄/智力预期
4. **排除**：智力障碍、感觉障碍、缺乏教育机会等

### 评估工具推荐

**废弃**：传统"智商-成就差异"模式（存在"等待失败"弊端）

**推荐**：标准化评定工具组合
- 学习障碍儿童筛查量表
- 汉语阅读技能诊断测验
- 中国小学生数学基本能力测验
- 韦氏个别成就测验 + 韦氏智力测试

### 干预原则

- **特殊教育**：介入反应模式 + 分层支持教学
- **专项训练**：意义强化、代码强化（阅读障碍）
- **社会心理干预**：支持性心理治疗、家长指导、行为矫正

## 四、发育性运动协调障碍(DCD)

### 诊断要点

1. **年龄限制**：5岁前一般不诊断
2. **核心表现**：粗大/精细运动技能落后，动作笨拙、缓慢或不准确
3. **功能损害**：日常生活、学校适应严重受限
4. **排除**：神经系统疾病、智力障碍等

### 鉴别诊断

| 鉴别疾病 | 关键区分点 |
|---------|-----------|
| 智力发育障碍 | 除运动外还有语言、认知、社会性全面落后 |
| ASD | ASD因兴趣狭窄不愿运动，但有社交损害+刻板行为 |
| ADHD | ADHD因注意力不集中表现莽撞，可共病诊断 |

## 五、抽动障碍鉴别

当患者表现不自主运动或发声时，按以下流程排除其他疾病：

| 鉴别疾病 | 关键特征 |
|---------|---------|
| 小舞蹈症 | 5-15岁，舞蹈样运动+肌张力减低，血沉快/抗O高 |
| 亨廷顿病 | 30-50岁，常染色体显性遗传，进行性舞蹈样运动+痴呆 |
| 肝豆状核变性 | 角膜K-F环，血浆铜蓝蛋白减低 |
| 肌阵挛 | 伴意识障碍，脑电图高度节律异常 |
| 迟发性运动障碍 | 抗精神病药使用期间或停药后 |
| 分离性障碍 | 有强烈心理因素，心理治疗后缓解 |

## 输出要求

1. 明确神经发育障碍类型及亚型
2. 提供鉴别诊断依据
3. 制定综合干预方案（教育/行为/药物）
4. 评估共病情况

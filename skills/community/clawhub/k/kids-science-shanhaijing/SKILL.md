# 《山海经》儿童科普量产流水线

## 适用边界

- 受众：5-10 岁孩子（能听懂一段故事）+ 家长（决定要不要让孩子看的人）。
- 规格：竖屏 9:16，成片 45-60 秒，一条只讲一个神兽 + 一个科学知识点。
- 一条只做一只神兽。讲第二只，另开一条。
- 这是**科普**项目，不是讲故事项目。故事是钩子，落点必须是一个能被今天科学解释的现象。讲完只剩"哦原来古人瞎编的"，这条就是废的。

## 一条视频的骨架

```
原文一句话 → 古人看见了什么 → 他们编出这只神兽 → 今天我们知道这是怎么回事 → 孩子能去看/去做的事
```

五段结构，顺序不换：

| 段 | 镜号 | 时长 | 作用 |
|---|---|---|---|
| 钩子 | 1 | 3s | 抛一个反常的画面，不铺垫 |
| 原文 | 2 | 10-12s | 念原文摘句 + 白话翻译，把神兽立起来 |
| 古人 | 3 | 10-12s | 古人为什么这么想（他们看到的真实现象） |
| 科学 | 4 | 10-12s | 今天的答案，一个知识点，一个比喻 |
| 行动 | 5 | 8-10s | 能去观察的事 + 提问 |

## 八步流水线

选题 → 查原文 → 口播 → 分镜 → 首帧 → 封面 → 配音 → 平台文案 → 写 .md 校验。顺序不跳，跳了必返工。

### 第 1 步 选题定标

四条件全过才开工：

1. **神兽有画面**——能在三句话里画出它长什么样（几尾、几足、几翼、什么颜色）。
2. **原文有一句能摘的**——不超过 24 字，念出来不拗口。
3. **有一个真实现象当桥梁**——古人看到的天、水、火、雷、雾、星、动物行为，孩子今天也能看到。
4. **今天有答案**——这个现象有小学能听懂的科学解释，不靠"科学家还在研究"糊过去。

选题库（含篇目、原文摘句、科学落点、星级）见 `references/topic-bank.md`。

### 第 2 步 查原文（不许凭记忆写）

- 引原文前必须核对篇目和字句。常用核对途径：识典古籍、古诗文网、汉典古籍的山海经全文。
- 摘句只摘**造型句**（"其状如……"），不摘"食人""见则其国大旱""食之不蛊"这类后果句。
- 篇目格式统一：《山海经·南山经》。十八卷里分南山、西山、北山、东山、中山、海外、海内、大荒。
- 生僻字第一次出现必须带拼音，正文用中文括号：讙（huān）、夔（kuí）、夫诸（fū zhū）。
- 查不到原文的选题，直接换题。不猜、不改编、不写"据说山海经里有"。

### 第 3 步 写口播文案

硬规则：

- 每 10 秒 42-50 字（4.2-5 字/秒）。总口播不超过 290 字。
- 镜 1 的 3 秒内必须抛画面，不"大家好"、不"今天我们来聊聊"、不报书名开场。
- 一句不超过 15 字；原文摘句单独占一句，念完停 0.3 秒。
- 原文之后**立刻**跟一句白话翻译，不许让孩子悬着。
- 至少一个比喻，把原理换成孩子摸得到的东西（被子、扇子、方向盘、水管、蒸笼）。
- 结尾一句提问 + 一句引导。

**去 AI 味清单（命中即改）**

| 禁止 | 改成 |
|---|---|
| 赋能、迭代、链路、范式、助力、打造、一站式、全方位、千年传承、文化瑰宝 | 删掉，或换成「书里写着」「古人这么想」 |
| 首先/其次/最后、综上所述、值得注意的是、不难发现 | 删掉，靠句子顺序推进 |
| 因此、然而、此外、从而 | 换成「所以」「但是」「还有」 |
| 「让我们一起走进山海经的世界」 | 直接进画面：「这只狐狸，书里说有九条尾巴」 |
| 「体现了古人的智慧」「值得我们学习」 | 改成具体动作：「所以下次看见猫的尾巴……」（评价式升华一律删） |
| 三段工整排比、四字词连用 | 拆成两句，长短不齐 |

语气标准：像蹲下来跟小孩讲一本旧书。短句，有停顿，带一点"我也觉得奇怪"的口气。

### 第 4 步 拆分镜

- 运镜只用：快速推近、缓慢推近、横移、环绕、俯拍、拉远、固定微动、航拍俯冲、光效过渡。
- 禁用甩镜、变焦、旋转、手持晃动——幼儿看了头晕。
- 表格列固定：镜号 | 时长 | 景别 | 运镜 | 画面内容 | 口播文案 | 字幕 | 音效。
- 「画面内容」写清谁在做什么、手里拿什么、东西什么颜色，这是给生成模型看的。
- 神兽的**数量特征必须按原文**：九尾就是九条尾巴、一足就是一只脚。数量是知识点，画错等于讲错。

### 第 5 步 首帧图片

- 比例 9:16，1080×1920。
- 风格锁：3D 卡通 + 水墨肌理的混合渲染，低饱和矿物色调（赭石、黛青、月白、陶土红、竹青），柔和暖光，软乎乎质感。
- **强点击感三条**，缺一条重出：① 标题占画面高度 1/4 且是全图最大元素；② 神兽或人物靠前占画面 1/3 以上；③ 背景干净，只留 1-2 个元素（山影、云气、古书页纹理任选其一）。
- 神兽造型逐条按 `references/character-bible.md` 复述，不许自由发挥。
- 提示词顺序：主体+动作 → 环境 → 光线 → 风格 → 构图 → 文字。
- 画面文字一律用中文引号「」标注，写清字号层级。
- 负面词固定带上：獠牙、血浆、断肢、多头堆叠、恐怖表情、真实照片质感、暗调、西方奇幻风格、品牌 logo、侵权卡通形象、错别字中文、水印、文字压脸。
- 完整模板与示例见 `references/visual-prompts.md`。

### 第 6 步 封面素材

同一画面出两个比例：3:4（1080×1440）+ 4:3（1440×1080）。

- 主标题 ≤20 字，一行说完，用疑问句或反常识句（「九尾狐真有九条尾巴？」「古人被雷吓出来的神兽」）。
- 副标题 ≤12 字，给答案感（「其实是尾巴的用处」）。
- 主标题字号 ≥ 副标题的 2 倍。
- 神兽半身靠前，眼神温和（**不做凶相、不做张口露齿**）。
- 主色不超过 3 个。
- 同系列共用一套角色、一套色调、一个角标，养账号辨识度。

### 第 7 步 配音

- 音色：25-32 岁温柔女声（默认）／低沉温和男声（雷、火、洪水类）。
- 语速 4.3-5 字/秒。念原文那一句单独降速到 3.5 字/秒，一个词一顿。
- 念原文前留 0.3s，念完留 0.6s，让观众消化。
- 情绪底色：好奇 + 温和。不夸张变声、不播音腔、不评书腔、不广告腔。
- 标注法：`（好奇上扬）（压低声音）（像讲悄悄话）` 配 `[停0.3s]` `[停0.6s]`。
- 输出逐句配音表：镜号 | 文本 | 情绪 | 停顿 | 时长。

### 第 8 步 平台文案

至少出五套：抖音、小红书、视频号、B站、快手；文化类内容另加公众号、知乎。每套含：标题、正文、话题/标签、封面文字、首条评论引导。

- 一稿多投必须改写标题和首句，贴同一段话会被判重复内容。
- 各平台公式与字数区间见 `references/platform-copy.md`。

### 第 9 步 写进 .md 文件

文件名：`<选题-slug>-shanhaijing.md`，slug 全小写、短横线、不带中文和空格（例：`jiuweihu-shanhaijing.md`）。

骨架照 `assets/episode-template.md` 的十个区块，一个都不能少。成品存到用户指定的项目目录。

写完跑校验：

```
python scripts/check_episode.py <交付文件路径>
```

它查区块完整性、每镜「时长↔口播字数」、总时长、标题字数、原文卡是否带篇目、首帧风格锁、禁用词。报 error 就改到过，warning 至少看一眼。

## 内容与风控红线

- **原文不能编**。记不清就查，查不到就换题。
- **不做恐怖化**。原文里的「食人」「其音如婴儿」只保留造型和声音，伤害情节一律不进儿童口播。
- 神兽不画獠牙外露、不画血、不画断肢、不画多头叠成一堆的恶心构图。刑天、相柳、穷奇这类自带惨烈情节的，要么不选，要么只讲它的造型由来。
- 不出现"山海经是迷信"或"古人很蠢"这类贬语。古人是在用当时能想到的办法解释世界，这份努力值得说清。
- 不教危险操作。火（毕方）、洪水（夫诸）、雷（夔）三类只讲原理 + 远离，**不讲自救细节**。
- 不承诺"读完就能懂上古史"，不做玄学、风水、算命、辟邪、开运类延伸。
- 不出现真实品牌、真实人物、血腥画面。
- 上传前自问：7 岁孩子听完第一句，能不能在脑子里看见一只动物？看见不了就重写第一句。

## Description:

Design a small, honest evaluation set for an agent workflow: tasks, pass criteria, and a scoring rubric a human can run in an hour. Use before shipping or changing any agent.

This skill is ready for commercial/non-commercial use.

## Publisher:

[manteclaw](https://clawhub.ai/user/manteclaw)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agent teams use this workflow to build a fixed, human-reviewed evaluation set before launching an agent or changing its prompt, model, or tools, then score runs against observable criteria.

## Description:

Use when you need a practical testing playbook for turning product or code changes into a clear test strategy, test cases, and execution checklist.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, QA engineers, and release teams use this skill to turn product or code changes into test strategy, prioritized test cases, coverage checks, and release validation questions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated test plans can miss product-specific behavior, automation gaps, or release risks if assumptions are not checked.

Mitigation: Review the plan against the actual product scope, available automation, instrumentation, and manual verification needs before relying on it.

## Description:

Explores unfamiliar GitHub projects, installs and runs them, analyzes architecture, and generates comprehensive documentation guides.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill to explore unfamiliar GitHub repositories or technologies, get them running, analyze architecture and workflows, and produce beginner-friendly documentation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may lead an agent to clone, install dependencies for, and run arbitrary project code.

Mitigation: Use a disposable sandbox or container, keep secrets and private files out of reach, and require explicit approval before dependency installs, tests, examples, or app startup commands.

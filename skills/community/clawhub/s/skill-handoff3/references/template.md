# 交接稿输出骨架（template.md）

正文语言跟随用户 / 会话语言；段落标题固定中文（结论/待办/否决/阻塞/决策/改动/缺口），不建 i18n 字典。记忆条目的字段标签跟随会话语言，映射见 schema.md / types.md。

结构固定为：第一屏可粘贴消息 → pin 区 → 六段 → 缺口。**不设主题组，不设原始材料专块。**

```
# 任务交接 · <日期> · <主题>

> 读法
> - 面向不了解本技能的接手者，读的人不需要任何前置背景。
> - 先看「新任务首条消息」，可直接复制给接手者。
> - 再按 结论 → 待办 → 否决 → 阻塞 → 决策 → 改动 顺序查看。
>
> 依据
> - 记忆记录：<库根绝对路径>/memory/（<N> 个文件，共 <M> 条）

> - <行话>：<一句解释>
```

## 纪律

- **第一屏最优先**：「新任务首条消息」必须能直接复制粘贴，读者永远先看它。
- **零背景可读**：把读报告的人当成对本技能一无所知。标题只用裸名词，不写「（直接复制）」「（逐字）」这类括号暗号——它们既没说清前因也没说清后果。需要交代的在开头「读法 + 依据 + 术语」里一次说清；正文遇到行话就地解释或在术语行列明。
- **一行一件事**：每行只装一个信息，主句一行、细节缩进成子项；多个要点拆成 `  -` 列表项，不用分号串在一行；一句超过约 40 字就按语义断开。目标是纯文本和 Markdown 预览里都不出现「一二百字挤一行」。条目之间空一行。
- **六段顺序固定**：结论 → 待办 → 否决 → 阻塞 → 决策 → 改动。否决段前置（最省接手人时间的一段）。
- **证据摆明面**：普通条目结论后附用户原话摘录，读者可自行核对，不靠事后声明「已校验」。
- **原始材料缩写进正文**：代码 / 配置 / 数据 / 论文 / 结构化文档（ppt、word 等），读懂后缩写为一句结论直接写进对应段落，句末标 `路径:行` 或文档名；**不设专块、不贴原文、不切片**。
- **相近条目自然归拢**：由模型在六段内用二级标题分组，不引入分组判据、组数上限、标题抽取规则。
- **缺口必须披露**：单边记忆、未覆盖时段、缺档会话、疑似归属错位的条目，全部写进最后一段，不静默省略。
- **覆盖自评必须真数**：最后一段第一行固定写 `本轮记忆覆盖：本会话 <N> 个用户轮次 → 新增 <M> 条 mem_ 条目（缺 <K> 条：<原因>）`。N 和 M 都是数出来的，不估、不抄上轮；K=0 写「无缺口」。这行是「我以为记全了」的唯一反证，省略它等于把两次漏记事故的成因重新埋回去。
- **「依据」行的写法**：记忆记录只写库根绝对路径**一次**（这是 schema.md §5 第 2 档规定的唯一例外位置），后面正文里的 `[出处]` 一律用相对 `$LIB` 的路径或文件名，不在正文反复铺绝对路径。

## 缺口段的六种固定条目

缺口段不是自由文本，按来源分类各占一条，缺哪类就不写哪类：

```
- 本轮记忆覆盖：本会话 <N> 个用户轮次 → 新增 <M> 条 mem_ 条目（缺 <K> 条：<原因>）
- 自检修复：<文件> <哪里错 → 改成什么>（交接内嵌的自检逐条回报并在此，不再对对话单独输出第二份）
- 未覆盖时段：<起 → 止>（来源末条 <T_end>，核对至 <C>）—— 原因：<压缩格式无法 grep / 用户中断>
- 疑似整段未记录：<会话标识>（最后活动 <时间>，来源 <路径>）—— 建议下次交接做完整补写
- 疑似归属错位：<文件> 有 <N> 条在 <时间> 之后，来源只覆盖到 <T_end> —— 待用户确认是否拆分
- 单边记忆：<条目> —— 仅 <agent> 一边有，标「待复核」
```

这六条（含第一行的覆盖自评）是**固定格式**，不按语言翻译结构、只翻译措辞。固定格式的价值是：下一轮交接时能一眼认出「上次报了哪类问题、这次还在不在」。

**「自检修复」与「交人定夺」**：自检的逐条修复归第二类；S2/S3 无法定论、时间越界等需用户拍板的项归「疑似归属错位」类。这两类让用户在报告里完成原「先自检再交接」的中途确认，不猜着改。无修复、无待定项就不写这两类。

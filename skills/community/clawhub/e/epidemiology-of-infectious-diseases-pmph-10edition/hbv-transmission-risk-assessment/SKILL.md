# 乙型肝炎传播途径与易感人群评估

## 适用场景

- 评估HBV暴露者的感染风险等级
- 为孕产妇制定母婴阻断策略
- 为医疗工作者进行职业暴露风险评估
- 判断个体是否为HBV易感/高危人群
- 制定疫苗接种或暴露后预防方案

## 约束条件

- 仅适用于血液/体液、垂直、性传播途径评估
- 不适用于消化道或呼吸道传播评估

## 执行流程

### 第一步：确认前置信息

收集以下关键信息：
1. 患者/暴露者的HBV感染状态（HBsAg阳性/阴性）
2. 具体暴露史（暴露类型、时间、方式）

### 第二步：识别传播途径

根据暴露类型判断传播方式：

| 传播类型 | 具体途径 | 风险特征 |
|---------|---------|----------|
| 垂直传播 | 宫内感染（经胎盘，约5%）、围生期/分娩过程（主要方式）、分娩后密切接触 | 我国HBsAg阳性者30%以上由此途径感染 |
| 血液/体液传播 | 输血/血制品、注射/手术/针刺、共用剃刀/牙刷、血透、器官移植 | 微量污染血即可感染；HBsAg阴性感染者供血仍有风险 |
| 性传播 | 无防护性接触 | 多性伴侣者危险性增高 |

### 第三步：判定易感性与免疫保护

按以下决策逻辑判定：

```
IF 抗-HBs阳性 THEN
    → 具有免疫保护，不易感（感染后或疫苗接种后获得）
ELSE IF 抗-HBs阴性 THEN
    → 普遍易感
    IF 为婴幼儿/新生儿 THEN
        → 最危险时期（通常无先天性抗-HBs）
    IF 属于高危人群 THEN
        → 高感染风险，需立即干预
```

### 第四步：界定高危人群

检查暴露者是否属于以下高危人群：
- HBsAg阳性母亲的新生儿
- HBsAg阳性者的家属
- 反复输血/血液透析者
- 多性伴侣者
- 静脉药瘾者
- 接触血液的医务工作者

### 第五步：输出风险评估与建议

根据以上分析，输出：
1. **感染风险等级**：高/中/低
2. **预防建议**：
   - 易感/高危人群 → 建议接种乙肝疫苗
   - 已暴露者 → 评估是否需要暴露后预防（HBIG + 疫苗）
   - 孕产妇HBsAg阳性 → 启动母婴阻断方案
   - 已有抗-HBs → 无需额外干预

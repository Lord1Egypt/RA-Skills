# Changelog

## 1.3.0 — 2026-11-17

首次发布到 ClawHub（此前只有 GitHub 仓库与本地版本，ClawHub 上无公开页）。

- **slug 定为 `socratic-reading-coach`**：`weread-socrates` 在 ClawHub 已被他人使用（@chenyqthu 的 `weread` 系列占用同名档位），因此改名发布。SKILL.md 的 `name`、README、启动/停止脚本注释、skill-card、前端页面中的引用全部同步。
- **首屏重写（场景先行）**：原来是「启动并使用某本地 Web 应用」的功能罗列，读者不知道什么时候用它。改为「书读完了，但说不出学到了什么——用五个问题把它问出来」，并点明三类场景（读完就忘 / 划线一堆没回看 / 想写书评下不了笔）。
- **把前提条件写进首屏**：微信读书 API Key + 大模型 Key 是**两项必需**，此前只在正文「前置条件」里出现。放进首屏避免装完才发现用不了。
- **隐私边界前置**：本地 127.0.0.1、会话存本机、不经过第三方服务器、导出划线属版权内容仅供个人学习——四条从正文隐私章节提要到首屏。

功能零变更。

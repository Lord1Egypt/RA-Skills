### AVS5-03 剪辑合成 · 范本

> 场景设定：第1集ffmpeg合成全流程。

```bash
# 1. 镜头列表（按分镜表顺序）
cat > list.txt << 'EOF'
file 'shot_1-1.mp4'
file 'shot_1-2.mp4'
# ……（共66条，三集分别出片）
file 'shot_3-3.mp4'
EOF

# 2. 拼接
ffmpeg -f concat -safe 0 -i list.txt -c copy merged.mp4

# 3. 统一调色（古风调色思路：暖黄烛光基底+冷青阴影，降饱和遮轻微面部漂移）
ffmpeg -i merged.mp4 -vf "eq=saturation=0.88:contrast=1.05,colorbalance=bs=0.08:hs=0.05" -c:a copy graded.mp4

# 4. 混音（人声/BGM/烛火三轨）
ffmpeg -i graded.mp4 -i vo_all.wav -i bgm.mp3 -i candle.wav \
  -filter_complex "[1]volume=1.0[v];[2]volume=0.12[b];[3]volume=0.08[c];[v][b][c]amix=3[a]" \
  -map 0:v -map "[a]" -c:v copy mixed.mp4

# 5. 烧录字幕
ffmpeg -i mixed.mp4 -vf "subtitles=subs_ep01.srt:force_style='FontSize=22,OutlineColour=&H80000000,BorderStyle=1'" -c:a copy final.mp4

# 6. 两处设计转场的剪辑落地点（AVS2-04 选型）：缝1白场过渡，缝2硬切
#    缝1：镜1-1尾部拉白 + 镜2-1头部从白起（fade-through-white），其余镜头不加转场
ffmpeg -i shot_1-1.mp4 -vf "fade=t=out:st=3.8:d=0.2:color=white" -c:a copy shot_1-1_fade.mp4
ffmpeg -i shot_2-1.mp4 -vf "fade=t=in:st=0:d=0.2:color=white" -c:a copy shot_2-1_fade.mp4

# 7. 首尾淡入淡出 + 规格复核
ffmpeg -i final.mp4 -vf "fade=t=in:st=0:d=0.4,fade=t=out:st=88.5:d=1.5" \
  -c:v libx264 -pix_fmt yuv420p -r 24 -c:a aac -b:a 128k \
  -s 1080x1920 final_第01集.mp4
```

面部差异衔接处理：镜3-1与3-2面部相似度仅0.81，中间已插入0.8s烛火特写空镜过渡，未连续放置。
ffmpeg依赖说明：运行环境无ffmpeg时降级——直接交付VideoGen原始mp4（多数已是合规规格），淡入淡出/调色/字幕改为外部剪辑工具完成或后装ffmpeg补做。

【组装顺序】按分镜表拼接（66镜，三集各一份list）→统一调色（古风暖黄+冷青）→混音三轨→烧录字幕→首尾淡入淡出→规格复核（1080×1920/H.264/AAC/24fps/yuv420p）。
【可选组件】面部差异镜头过渡处理记录：已启用（镜3-1/3-2插0.8s烛火空镜）。
【检查】✅ 按分镜顺序拼接；✅ 统一调色遮轻微漂移；✅ 转场只落地AVS2-04的两处选型（缝1白场/缝2硬切）、未临时新增，另加首尾淡入淡出；✅ 差异镜头不连续放置有过渡；✅ 输出9:16 1080×1920 H.264+AAC 24fps 无alpha（yuv420p）；✅ ffmpeg依赖降级方案已注明。
输出格式：成片mp4+ffmpeg命令记录 ✅

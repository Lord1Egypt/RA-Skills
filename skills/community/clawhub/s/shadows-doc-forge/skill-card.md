## Description:

Auto-documentation generator that analyzes code and generates README files, API documentation, architecture documentation, and inline comments when documentation is missing or outdated.

This skill is ready for commercial/non-commercial use.

## Publisher:

[nakedoshadow](https://clawhub.ai/user/nakedoshadow)

### License/Terms of Use:

MIT

## Use Case:

Developers and engineers use this skill to inspect project source files and generate accurate Markdown documentation for repositories, APIs, architecture, onboarding, and non-obvious inline code behavior.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated documentation can be inaccurate if the repository is misread or source behavior is ambiguous.

Mitigation: Review generated documentation for accuracy before publishing.

Risk: Inline-comment mode may modify source files when the user expected documentation-only output.

Mitigation: Confirm the intended output mode before allowing inline source edits.

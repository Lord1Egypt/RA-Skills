## Description:

Reviews recently changed code for reuse, quality, and efficiency, then guides focused cleanup before finalizing.

This skill is ready for commercial/non-commercial use.

## Publisher:

[wimi321](https://clawhub.ai/user/wimi321)

## Use Case:

Developers and engineers use this skill after code changes to find duplicated logic, awkward abstractions, unnecessary comments, and avoidable inefficiencies, then apply focused cleanup before final review.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Automated cleanup can unintentionally change behavior or remove useful context from recently changed code.

Mitigation: Review the resulting diff and run the relevant tests or checks before accepting the edits.

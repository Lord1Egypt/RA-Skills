## Use Case:

Developers, marketers, and content teams use this skill to improve page heading hierarchy, align H1-H6 structure with SEO intent, and produce practical heading recommendations for webpages or articles.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: General content structure requests may activate SEO heading guidance when that intent is broader than heading optimization.

Mitigation: Use the skill when heading structure or SEO heading work is relevant, and confirm the desired content goal when the request is ambiguous.

Risk: The skill may read optional project context files for target keywords during SEO-related heading work.

Mitigation: Install and use it only where reading .claude or .cursor project context for target keywords is acceptable.

## Description:

Mobile browser and native app automation via ATL (iOS Simulator). Navigate, click, screenshot, and automate web and native app tasks on iPhone/iPad simulators.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and agent operators use this skill to control iOS Simulator browser and native app workflows through ATL, including navigation, element discovery, taps, text entry, screenshots, and accessibility-tree inspection.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The setup process builds and runs unpinned code from an external GitHub repository.

Mitigation: Use a pinned, reviewed commit or signed release before running setup.

Risk: The skill can inspect and automate simulator sessions that may contain sensitive accounts or cookies.

Mitigation: Use a clean simulator session or avoid sensitive accounts and cookies unless agent inspection is intended.

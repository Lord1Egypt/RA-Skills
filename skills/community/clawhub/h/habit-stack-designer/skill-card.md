## Description:

Design a habit stack by choosing a reliable existing anchor, shrinking the new habit into a tiny first action, and adding friction reduction, reward, and a rescue version for hard days.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users use this skill to turn a desired habit into a practical markdown habit stack with an existing anchor, a tiny first action, friction reduction, reward cues, and a rescue version for hard days.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: User-provided personal habit details may be included in the generated markdown plan.

Mitigation: Avoid sharing sensitive personal details and review the generated plan before saving or distributing it.

Risk: The skill provides descriptive coaching only and does not create reminders, accountability systems, or automated follow-up.

Mitigation: Use a separate reminder, calendar, or tracking system when the habit plan needs operational follow-through.

Risk: A weak or irregular anchor can make the habit stack less reliable.

Mitigation: Choose an existing routine that already happens several times per week, and use place-based anchors when schedules are irregular.

# 钩虫病病理机制详解

## 皮肤损害机制

丝状蚴侵入皮肤后病理演变时间线：
- **数分钟至1小时**：局部出现红色丘疹
- **1～2天**：充血、水肿及细胞浸润炎症（钩蚴性皮炎/粪毒）
- **感染后24小时**：大多数幼虫滞留真皮层
- **后续**：经淋巴管或微血管到达肺部

## 肺部病变机制

1. 幼虫穿破肺微血管入肺泡
2. 引起间质和肺泡点状出血和炎症
3. 重者致支气管肺炎
4. 沿支气管上行至咽部→支气管炎与哮喘

## 小肠病变与贫血机制（核心病理）

### 成虫致病方式
- 口囊咬附在小肠黏膜绒毛上皮
- 以摄取黏膜上皮与血液为食
- 不断更换吸附部位
- 分泌抗凝血物质

### 出血机制关键点
- 渗血量远较钩虫实际吸血量为多
- 小肠黏膜产生散在点状或斑点状出血
- 重者大片出血性瘀斑
- 极重者消化道大出血

## 贫血病理演变

### 血液学改变
- 慢性失血消耗体内铁质贮存
- 引起低色素性小红细胞贫血（小细胞低色素性贫血）

### 器官组织改变
- 心肌脂肪变性
- 心脏扩大
- 长骨骨髓显著增生
- 脾骨髓化
- 指甲扁平/反甲
- 毛发干燥脱落
- 食管与胃黏膜萎缩

### 特殊人群影响

**儿童**：
- 严重感染可致生长发育障碍

**孕妇**：
- 易并发妊娠高血压综合征
- 引起流产、早产或死胎

## 贫血程度影响因素

| 因素 | 影响方式 |
|-----|---------|
| 钩虫虫种 | 不同虫种吸血量和抗凝能力不同 |
| 负荷虫数 | 虫数越多，失血量越大 |
| 感染期 | 感染时间越长，铁贮存消耗越多 |
| 饮食铁含量 | 铁摄入不足加重贫血 |
| 体内铁贮存量 | 基础铁贮存低者更易贫血 |

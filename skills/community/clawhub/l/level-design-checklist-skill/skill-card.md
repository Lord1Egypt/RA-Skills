## Description:

Guides structured help for level design reviews using clear templates, checks, and safe defaults.

This skill is ready for commercial/non-commercial use.

## Use Case:

Game creators and developers use this skill to review level goals, readability, flow, challenge, mechanics, rewards, scope, and playtest notes before building, testing, or publishing a level.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may ask for details about a user's game level or playtest feedback.

Mitigation: Share only design details appropriate for review; the security evidence says the artifact does not request private file access, command execution, or external data transfer.

Risk: Level design recommendations could drift toward copying copyrighted levels.

Mitigation: Use the skill's safety scope to avoid copyrighted level copying and focus on small, original, playable improvements.

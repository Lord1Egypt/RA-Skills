## Description:

Coordinates skill authoring, testing, security auditing, documentation, and release management to publish installable skill packages to public registries.

This skill is ready for commercial/non-commercial use.

## Publisher:

[t3ratech](https://clawhub.ai/user/t3ratech)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and release teams use this skill to coordinate agent roles for authoring, testing, scanning, documenting, and preparing installable skill packages for publication.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The workflow can propose or perform file edits, tests, scans, documentation changes, and release preparation across multiple roles.

Mitigation: Review generated packages, test results, scan outcomes, documentation, and release notes before publication.

Risk: Publishing preparation may affect public release readiness and registry-facing content.

Mitigation: Require an explicit human approval step before publishing or signing any generated package.

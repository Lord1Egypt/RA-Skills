## Description:

Guide users through refund and return decisions for ecommerce orders, including reasons, evidence preparation, and platform-specific strategy. Use when the user asks to 退货、退款、换货、写退货理由、准备申诉证据 or judge whether a return is likely to succeed.

This skill is ready for commercial/non-commercial use.

## Use Case:

External shoppers and support agents use this skill to assess ecommerce refund or return options, prepare evidence, and draft truthful platform-appropriate return requests for Taobao, Tmall, JD, and Pinduoduo-style workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated return reasons, compensation requests, or evidence plans could be inaccurate or misleading if the user's claims are not truthful or platform-appropriate.

Mitigation: Treat outputs as drafting help only, verify claims against actual order evidence, and adjust requests to match the relevant platform's current rules.

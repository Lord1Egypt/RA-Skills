## Description:

Convert HTML files or designs into pixel-faithful PowerPoint (.pptx) slides, with support for single HTML files and multiple HTML files merged into one presentation.

This skill is ready for commercial/non-commercial use.

## Publisher:

[panhongwei](https://clawhub.ai/user/panhongwei)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and content creators use this skill to guide an agent through converting uploaded HTML designs into editable PowerPoint slides. It is intended for workflows that need explicit layout parsing, chart extraction, color review, generated pptxgenjs code, and optional merging of per-slide PPTX files.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The workflow writes temporary files and PPTX outputs while running local Python and Node code.

Mitigation: Run it in a dedicated project directory or virtual environment and review output paths before execution.

Risk: Processing PPTX files from untrusted sources with the merge helper may expose users to malformed archive or document content.

Mitigation: Only merge PPTX files generated by the workflow or otherwise trusted by the user.

Risk: Dependency and parser hardening gaps may affect reliability when handling complex or unexpected HTML input.

Mitigation: Review generated files and command output before using the resulting presentation in downstream work.

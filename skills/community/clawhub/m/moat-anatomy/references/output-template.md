# 输出模板

所有分析结果统一按以下格式输出。

## 结构规则

- 使用 Markdown 格式，章节之间用 `---` 分隔
- 每条分析先给出结论（一句话），再展开论据
- 星号使用 Emoji 星级（⭐）
- 不出现"笔者"、"我们认为"等主观表达，直接用陈述句

---

## 标准模板

```markdown
# 🎯 一句话结论

# 🏢 公司定位

主营业务 + 盈利模式 + 产业链位置 + 核心驱动力。控制在200字以内，不介绍历史。
```

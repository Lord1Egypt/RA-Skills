## Description:

Corrects document formatting for DOCX, Markdown, and plain text according to user-provided examples, screenshots, requirements, or presets while preserving the original wording.

This skill is ready for commercial/non-commercial use.

## Publisher:

[smallkeyboy](https://clawhub.ai/user/smallkeyboy)

### License/Terms of Use:

MIT-0

## Use Case:

Employees, external users, and developers can use this skill to standardize document layout, fonts, spacing, indentation, margins, headings, tables, lists, and Markdown whitespace while keeping document text unchanged.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The formatter may change whitespace, blank lines, indentation, document spacing, and layout in ways that affect legal, evidentiary, academic, or publication files.

Mitigation: Keep the original file, write changes to a separate output path, and review a diff or visual comparison before relying on the formatted result.

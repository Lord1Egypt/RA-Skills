## 0. 一句话

**公众号视觉遵循统一的「单页抽印本」规范：白纸、墨字、开头一块墨青导言，靠字号、留白与章节页签分章，不靠装饰。**

通用杂志排版风格（墨青刊头、衬线阅读栏、实心页签）；公众号没有刊头通栏、没有衬线正文、没有 hover，所以不能缩小复制，只能抽取同一套「编辑语法」：**直角、发丝线、整块墨青、章节页签、次要色图注、一屏一个强调。**

---

## 1. 视觉原则

1. **文字是主版面。** 装饰只在结构转折处出现：导言、章节页签、长引。正文段落里不允许出现底色、边框、图标。
2. **一屏一个墨青。** 墨青实底只给开头导言；小号强调色保留给章节页签、链接与折叠提示。关键词强调用墨色加粗，不用彩色下划线。
3. **层级只用三样东西**：字号、字重、留白。不用底色分层，不用图标分层，不用颜色分层。
4. **直角、发丝线、整块色。** 圆角沿用主题既有半径（块级 6px、行内 3px，见 `theme.css`），不新造第三套；阴影、渐变、玻璃模糊一律没有。需要分界时用 1px 线，需要强调时用整块墨青。
5. **图是证据，不是气氛。** 图片无边框、无圆角、通栏；图注只说明「这是什么」，不抒情。
6. **每篇同一个骨架。** 变化发生在内容与图片，不发生在版式。读者第二次打开时，应该认得出这是同一个号。

---

## 2. 为什么这是一套体系

不是「几个好看的组件」，而是五件事同时成立：

| 构件 | 作用 | 本体系的约束 |
| --- | --- | --- |
| 层级模型 | 决定什么该被看见 | 锚点 / 标记 / 容器三层，各有频率上限 |
| 阶梯 | 决定版面节奏 | 字号 6 档、行高 6 档、间距 8 档，互相咬合 |
| 组件 | 决定同类内容长什么样 | 12 个组件，每个都有「适用 / 禁用」 |
| 配额 | 防止强调通胀 | 导言墨青块 =1/篇、收束 =1/篇、长引 ≤1/800 字 |
| 验收 | 防止执行漂移 | 手机预览、暗色模式、复制粘贴、字号层级四项可检查 |

判断标准：**换一篇文章不换规则；换一个作者，产出仍像同一个号。**

## 3. 与站点「编辑部风」的契约

### 3.1 继承

| 站点 | 公众号 |
| --- | --- |
| 墨青 `#007275` 是唯一强调色相 | 同 |
| 墨 `#111819` / 次要 `#5d6667` / 发丝线 `#c7d1d1` | 同 |
| 标题无衬线、正文可读优先 | 同（正文改用系统黑体，见 3.2） |
| 直角、无卡片、无阴影、无渐变 | 同 |
| 章节用实心页签索引 | 缩小为 24×24 的行内页签 |
| 图注用次要色、小字号 | 同 |
| 一屏一个强调 | 同，但强调的职责改变 |

### 3.2 必须改写

| 站点 | 公众号 | 原因 |
| --- | --- | --- |
| 纸色 `#f5f7f7` 作为页面底 | 画布固定白 `#ffffff` | 公众号不允许改页面底；纸色只能做块级面 |
| 正文衬线 18px / 1.9 / 36em | 正文黑体 16px / 1.85 / 约 40 字 | 系统宋体在 16px 下笔画偏细，Android 回退不可控；长文优先可读性 |
| 衬线承担正文 | 衬线只承担带出处的长引 | 保留「声音」的对比，但不拿可读性冒险；导言改用黑体反白 |
| 页面页签导轨 56px | 行内 24×24 页签 | 公众号没有固定导轨，页签必须进入正文流 |
| `accent` = 可交互信号 | `accent` = 章节索引 + 链接 | 公众号正文外链不可点，交互语义失效 |
| hover / focus / selected | 静态层级 | 微信不保留交互态 |
| CSS 变量 `--ed-*` | 设计期令牌，落地为字面量 | 微信会清洗 class / 变量，最终必须是内联值 |

### 3.3 明确不引入

- 站点深色主题：公众号暗色由微信算法接管，不能自建第二套。
- 站点 17 个颜色角色名：公众号没有 hover / disabled / focus，照搬会误导。
- 刊头通栏每篇铺满：公众号首屏是标题与封面，正文再来一块大色会重复。
- 卡片、圆角、阴影、渐变、玻璃：与站点同一禁令。

## 5. 组件规格

每个组件固定四件事：**用途 / 结构 / 规格 / 禁用**。

### C0 刊头 meta

- 用途：文首标注栏目、日期、期号或阅读时长；系列文章用它建立「同一本刊物」的连续感。
- 结构：单行 10px 字距文字 + 1px 墨色底线。
- 规格：`letter-spacing:0.18em`，`color:#5d6667`，底线 `#111819`，下方 28px。
- 禁用：不放在标题上方做 kicker（标题由公众号后台单独设置）；不超过 3 个字段；不用英文装饰词。

```html
<section style="margin:0 0 28px;padding:0 0 12px;border-bottom:1px solid #111819;">
  <p style="margin:0;font-size:10px;line-height:1.6;letter-spacing:0.18em;color:#5d6667;">
    <span leaf="">AI 实战手册 · 散篇 · 2025.12</span>
  </p>
</section>
```

### C1 导语

- 用途：正文开始前的 1–3 句，交代这篇在回答什么。
- 结构：墨青实底 + 反白黑体，位于首个篇章标题之前；全文唯一的墨青实底块。
- 规格：16px / 1.75；内边距 24px；圆角 6px；下方 40px。
- 禁用：不超过 3 句；不重复标题；不加「导语」标签；不搬去正文中段或文末收束。

```html
<p style="margin:0 0 40px;padding:24px;border-radius:6px;background:#007275;font-size:16px;line-height:1.75;color:#f2f7f6;">
  <span leaf="">……</span>
</p>
```

### C2 章节标题 H2

- 用途：文章的一级分章，全文最稳定的识别件。
- 结构：24×24 墨青实心页签（白色两位数编号）+ 12px 间距 + 20px 标题。
- 规格：上 48 / 下 16；编号用 `tabular-nums`；编号按顺序，不跳号。
- 配额：一屏最多一个墨青页签；无顺序含义的章节不编号，改用无页签的 H2。
- 禁用：不加大号 watermark 编号（那是石墨主题的识别度）；不加英文副标签；不加下划线或底色。

```html
<section style="margin:48px 0 16px;display:flex;align-items:center;">
  <span style="display:inline-block;width:24px;height:24px;background:#007275;color:#f2f7f6;font-size:11px;font-weight:700;line-height:24px;text-align:center;font-variant-numeric:tabular-nums;">
    <span leaf="">01</span>
  </span>
  <span style="margin-left:12px;font-size:20px;font-weight:700;line-height:1.35;color:#111819;">
    <span leaf="">章节标题</span>
  </span>
</section>
```

### C3 小节标题 H3

- 用途：章节内部的第二层，不再分章。
- 结构：3px 墨色左竖条 + 17px 标题。
- 规格：上 32 / 下 12；左内边距 10px。
- 禁用：不超过 2 个/章；不编号；不与 H2 共用页签。

```html
<p style="margin:32px 0 12px;padding-left:10px;border-left:3px solid #111819;font-size:17px;font-weight:700;line-height:1.45;color:#111819;">
  <span leaf="">小节标题</span>
</p>
```

### C4 正文段落

- 用途：所有普通叙述。
- 规格：16px / 1.85 / 字距 0.02em / 两端对齐 / 段距 18px / 不首行缩进。
- 禁用：不用底色、边框、图标；一段不超过 5 行（手机 390px 宽约 120 字）。

```html
<p style="margin:18px 0;font-size:16px;line-height:1.85;letter-spacing:0.02em;color:#111819;text-align:justify;">
  <span leaf="">……</span>
</p>
```

### C5 强调

- 用途：句中关键词、结论、专有名词。
- 结构：墨色加粗，不换色。
- 配额：每段 1–2 处；全文锚点（最强强调）≤5 处。
- 禁用：不用墨青、不用彩色下划线、不用荧光笔底、不用斜体。

```html
<strong style="font-weight:700;color:#111819;"><span leaf="">关键词</span></strong>
```

### C6 长引 / 出处

- 用途：有明确出处的他人原话或核心判断。
- 结构：2px 墨色左竖线 + 18px 左内边距 + 宋体；出处另起一行右对齐。
- 规格：17px / 1.8；上下 40px；无底色。
- 配额：每 800 字最多 1 处；全文 ≤4 处。
- 禁用：没有 `——` 出处行的普通引用只按正文段落输出，不保留短引 / 金句版式；不用墨青竖线或引号装饰图；不整段引用超过 4 行。

```html
<section style="margin:40px 0;padding:4px 0 4px 18px;border-left:2px solid #111819;">
  <p style="margin:0;font-family:'Songti SC','STSong','SimSun',serif;font-size:17px;line-height:1.8;color:#111819;">
    <span leaf="">「……」</span>
  </p>
  <p style="margin:10px 0 0;font-size:12px;line-height:1.6;color:#5d6667;text-align:right;">
    <span leaf="">—— 作者</span>
  </p>
</section>
```

### C7 代码

- 用途：命令、配置、Prompt、字段名。
- 结构：所有块级代码统一沿用 NOTE 的浅纸底、灰色左竖线与 6px 圆角；行内代码仍用浅底小块。
- 规格：块级 14px / 1.75 / `#f5f7f7` 底 / `#111819` 字 / 3px `#5d6667` 左竖线 / 上下 24、内边距 14×16；语言标签 10px 次要灰。行内 0.88em / `#e8eeee` 底 / 2px 5px 内边距。
- 禁用：不做深色代码编辑器，不强调复制或编辑；不用行号和多色语法高亮。每行一个 `<p style="margin:0">`，用 `white-space:pre-wrap` 保留缩进并允许长行换行。

```html
<section style="margin:24px 0;padding:14px 16px;border-left:3px solid #5d6667;border-radius:6px;overflow:hidden;background:#f5f7f7;">
  <p style="margin:0;font-size:14px;line-height:1.75;color:#111819;white-space:pre-wrap;overflow-wrap:anywhere;">
    <span leaf="">npm run build</span>
  </p>
</section>
```

### C8 表格

- 用途：对照、参数、清单。
- 规格：14px；1px `#c7d1d1` 线；表头 `#e8eeee` + 600；单元格内边距 8/10；数字 `tabular-nums`。
- 禁用：不使用斑马纹；不超过 4 列（超出改为「条目 + 说明」两段式）；不让表格横向溢出手机。

### C9 图片与图注

- 用途：证据、截图、图表。
- 结构：图片通栏，图注另起一行。
- 规格：`display:block;width:100%;height:auto`；图注 12px / 1.6 / `#5d6667`；图注上 10px、下 32px；编号「图 01｜」。
- 禁用：不加边框、圆角、阴影；不把说明写成抒情句；不上采样小图；不连续堆 3 张以上无说明图片。

```html
<section style="margin:32px 0 0;">
  <img src="{{URL}}" alt="{{说明}}" style="display:block;width:100%;height:auto;">
</section>
<p style="margin:10px 0 32px;font-size:12px;line-height:1.6;color:#5d6667;">
  <span leaf="">图 01｜说明</span>
</p>
```

### C10 分割线

- 用途：同一章节内的大段落切换。
- 规格：1px `#c7d1d1`，上下 40px。
- 禁用：章节之间不用分割线（H2 已经足够）；不用图片分割线；不用三色圆点。

```html
<section style="margin:40px 0;height:1px;background:#c7d1d1;">
  <span leaf=""><br></span>
</section>
```

### C11 文末收束

- 用途：放全书入口、系列上一篇或最后一句收束。
- 结构：普通正文段落，无底色、无边框、无额外内边距。
- 规格：16px / 1.75 / `#111819`；上方 48px。
- 配额：**全文唯一**。
- 禁用：不再使用墨青实底（它专属于开头导言）；不在正文中段使用；不做章节小结或复杂排版。

```html
<section style="margin:48px 0 0;">
  <p style="margin:0;font-size:16px;line-height:1.75;color:#111819;">
    <span leaf="">……</span>
  </p>
</section>
```

### C12 签名

- 用途：作者一句话 + 固定落款。
- 规格：13px / 1.7 / `#5d6667`；上方 1px 线 + 16px 内边距。
- 禁用：不放头像、不放引导图、不放「点赞在看」三连口号（除非确有计划）。

```html
<section style="margin:32px 0 0;padding-top:16px;border-top:1px solid #c7d1d1;">
  <p style="margin:0;font-size:13px;line-height:1.7;color:#5d6667;">
    <span leaf="">Author ｜ 公众号技术专栏
  </p>
</section>
```

### C13 折叠块

- 用途：长附录、清单、推导、原始记录。可读可不读的内容先收起来。
- `:::details[标题]` 只保留粗标题与正文，不生成空摘要；`fold` 只有源稿给出摘要时才保留标题下第二行。
- 展开提示「点击展开 ↓」与标题同一行，右对齐；收起提示「点击收起 ↑」位于正文之后，11px 右对齐。两个提示都用 `#007275`，通过位置与相反箭头说明动作，不再各占一条大行。
- 双热区不合并：整张卡片点开，底部收起行让卡片失焦并收起。两个提示在当前机制下常驻，不做未经微信验证的显隐。
- 规格：`#f5f7f7` 浅纸底；无边框；圆角 6px；标题 30 号 / 700 / `#111819`；摘要 24 号 / `#5d6667`；正文 27 号 / 行高 44；展开提示 20 号。details 收起高度 64 单位，fold 为 100 单位。
- 配额：一篇 ≤3 个。
- 实现：外层 svg 不带 viewBox，靠高度动画裁切；内层 svg 固定比例。完整模板见 `../../../skills/wechat-article/assets/wechat-svg-fold.html`，精确几何见 `SVG-FOLD.md` §11。
- 禁用：`<details>` / `<summary>`（微信剥成裸文字）；竖条、发丝线、编号、行数与「阅读全文」；单点焦点合并；click + touchstart 同时挂在外层 svg。

## 6. 文章骨架与节奏

### 6.1 骨架

```
C0 刊头（可选）
C1 导语（可选，1–3 句）
H2 第一章（01）
  C4 正文 × n
  [C6 引文 / C7 代码 / C8 表格 / C9 图片]
  H3 小节（0–2 个）
  C4 正文 × n
H2 第二章（02）
  …
C10 分割线（仅在章节内部需要停顿处）
C11 普通正文收束（唯一）
C12 签名
```

### 6.2 节奏

| 项 | 规则 |
| --- | --- |
| 章节长度 | 每 600–900 字一个 H2 |

## 7. 图片与封面

### 7.1 正文图片

- 宽度：通栏 645px；小图 `max-width:100%` 居中，不放大。
- 格式：截图与图表用 PNG（透明底优先）；照片用 JPG。
- 暗色：不用纯白底 JPG；截图的白底要预判暗色下的刺眼问题（见 §8）。
- 图注：编号 + 说明，一句话；编号每篇从 01 开始。

### 7.2 封面

- 头条：1800×766（2.35:1），导出 JPG/PNG；中心 766×766 为安全区，标题必须落在安全区内。
- 次条：1000×1000（1:1），同一网格、同一字体、同一墨青。
- 构图（默认「刊头版」）：
  - 左侧 58% 墨青实底，右侧 42% 图片（或整幅墨青，无图时）。
  - 左上角 10px 字距标签（栏目 / 期号），下方 1px 反白细线。
  - 主标题白色，2 行以内，每行 ≤14 字；不使用描边、阴影、渐变。
  - 右下角可放期号，字号 ≤ 主标题的 1/4。
- 禁用：封面堆 3 个以上信息块；白底抠图；彩色渐变；与正文完全无关的 stock 图。

## 8. 暗色模式与平台红线

### 8.1 暗色模式

微信会把 CSS 颜色重映射到深色环境，但**不反转图片和 SVG**。因此：

1. 不靠底色承担语义：章节页签即使被压暗，白色编号仍可读。
2. 不用 `#f5f7f7` 大面积铺页；浅纸底只用于提示块、代码块、折叠块和表头这类局部结构。
3. 结构线用 `#111819` 或 `#c7d1d1`，不用中间灰——中间灰在暗色下最容易消失。
4. SVG 尽量不用；必须用时，线条用 `#5d6667` 这类中间明度，并避免依赖颜色区分。
5. 纯白底图片、白边截图不上传；必须上传时先补 1px `#c7d1d1` 边。
6. 发布前必须在微信暗色模式下过一遍。

### 8.2 平台红线

- 只认内联 `style`；不用 `class` / `id` / `<style>` / CSS 变量。
- 文字节点包 `<span leaf="">`。
- 不用 `display:grid`；`flex` 仅用于单行结构；不用 `float` / `fixed` / `absolute` / `sticky`。
- 不用 `@font-face` / 外链字体；只用系统字体栈。
- 外链不能跳转，需转脚注或文末说明。
- 渐变默认不用（会被混合成纯色，且可能触发暗色检测）。

## 11. 未决问题

1. **正文 16 还是 17？** 16 是行业基线；17 对长文更舒适，但每行字数降到约 37。建议先用 16 跑两篇，按后台读完率再定。
2. **章节页签是否每篇都编号？** 站点规则是「顺序本身有信息时才编号」。预计教程/书稿编号，散篇不编号。
3. **宋体引文在 Android 的降级是否可接受？** 回退到黑体会失去「声音」对比，但不会坏版面。建议保留，作为渐进增强。
4. **封面是否统一「左墨青 + 右图」？** 识别度最高，但 48 篇书稿会显得重复。可保留网格，允许右图区整幅留白或换成纯文字。
5. **图注编号是否每篇重置？** 建议重置；跨篇连续编号只在系列文章里使用。
6. **折叠 SVG v4 的真机复测。** 双层裁切结构已验证；紧凑版仍需确认展开、收起、回顶和暗色模式，每篇 ≤3 个。

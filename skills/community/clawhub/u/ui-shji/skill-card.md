## Description:

Guides an agent through a complete UI design workflow from initial idea through inspiration gathering, synthesis, style guide creation, interaction design, and delivery documentation.

This skill is ready for commercial/non-commercial use.

## Use Case:

Designers, developers, and product teams use this skill to turn UI ideas or interface improvement requests into design directions, static style guides, clickable prototypes, and delivery documentation.

## Description:

Uses the MiniMax API to generate creative music, including instrumental tracks and vocal songs with configurable style, mood, and scene.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and agents use this skill to prepare MiniMax music-generation requests for background music, creative songs, and lyric-driven vocal tracks. It helps choose request fields such as prompt, lyrics, output format, and audio settings.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Music prompts or lyrics may be sent to MiniMax.

Mitigation: Avoid confidential, personal, proprietary, or unlicensed copyrighted text in prompts and lyrics.

Risk: MiniMax API keys are required for use.

Mitigation: Store API keys securely outside the skill text and shared scripts.

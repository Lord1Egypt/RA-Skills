# 医院康复七大训练措施实施规范

## 适用对象

- 长期住院的慢性严重精神障碍患者
- 处于医院康复阶段的精神障碍患者

## 前置条件检查

在启动康复训练前，确认以下条件已满足：

1. 已建立康复部门及工娱治疗场所
2. 已配备多学科团队（医疗、护理、社会防卫、音乐/职业治疗等）

如条件不满足，提示用户先完成基础设施建设。

## 核心工作流程

### 第一步：患者评估与画像建立

收集并分析以下患者信息：

- **病情状况**：当前症状稳定程度、诊断类型、病程
- **兴趣爱好**：患者偏好和内在动机
- **受教育程度**：影响训练内容难度和形式选择
- **躯体健康状态**：体重、营养状况、药物不良反应、代谢指标

将评估数据整理为 `patient_profile` 对象，作为后续模块选择的依据。

### 第二步：训练模块选择与组合

根据患者评估结果，从七大模块中选择适用组合：

| 模块 | 适用场景 | 关键考量 |
|------|----------|----------|
| 生活技能训练 | 所有患者基础必修 | 根据自理能力水平分层 |
| 人际交往技能训练 | 社交退缩或技能缺陷者 | 长期住院者需重点加强 |
| 职业康复训练 | 具备一定工作耐受力者 | 从简单任务逐步过渡 |
| 躯体健康管理 | 存在体重/营养/代谢问题者 | 需多学科协作 |
| 教育疗法 | 认知功能允许学习者 | 每次不超过1小时 |
| 药物自我管理培训 | 所有服药患者必修 | 结合复发预防教育 |
| 认知障碍康复 | 存在认知缺陷者 | 选择匹配的认知域训练 |

### 第三步：个性化方案制定

遵循以下原则调整方案：

1. **个性化原则**：根据 `patient_profile` 调整训练内容、难度和节奏
2. **最少限制原则**：实行开放和半开放式管理，以限制最少的方式允许患者参与
3. **渐进性原则**：从简单到复杂，从监督到自主

### 第四步：各模块实施要点

#### 4.1 生活技能训练

分三个维度实施：

- **日常生活能力**：身体/衣物/空间清洁、作息规律、家务技能、交通出行、急救知识
- **理财训练**（分阶段推进）：
  - 阶段一：监督下了解理财方法
  - 阶段二：辅助制定短期支出计划
  - 阶段三：协助规划长期开支，记录分析每月支出
- **工娱训练**：手工、歌舞、运动、读书活动；节假日团体活动由患者参与策划；配备专业人员实施音乐和运动治疗

#### 4.2 人际交往技能训练

采用标准化7步训练法：

```
目标设定 → 角色示范 → 行为演练 → 正向强化 → 纠正反馈 → 解决问题技巧练习 → 家庭作业练习
```

- 实施形式：两名治疗师指导，小组形式
- 长期住院者额外内容：正确表达感受、语言/书信表达意愿、社交礼仪、家庭相处技巧、与外界联系机会

#### 4.3 职业康复训练

分两个层次：

- **工作适应性训练**：在安全庇护环境下提供简单产品制作/加工/包装，以及秩序维护、被服管理、文书、接待、清洁等任务
- **职业技能训练**：培养身心耐受力、改善工作习惯和道德观、与企业合作提供有偿手工制作机会

#### 4.4 躯体健康管理

根据评估结果制定针对性计划：

- 超重/肥胖 → 体重管理计划
- 营养不良 → 多学科综合营养计划
- 药物不良反应 → 针对性干预
- 性功能障碍 → 精神药理学+心理社会干预
- 代谢综合征风险 → 防范性监测和干预

#### 4.5 教育疗法

- **学习行为训练**：时事、常识、科普、历史教育，培养学习兴趣
- **心理教育**：传授疾病及治疗系统信息，促进情感整合
- **形式**：授课、小组讨论、个别辅导、家属专家交流
- **硬性限制**：每次学习时间不超过1小时

#### 4.6 药物自我管理及依从性培训

核心内容：

1. 教育药物治疗重要性和复发严重性
2. 熟悉药物名称、剂量、可能不良反应
3. 学习向医师寻求帮助的方法
4. 养成按时按量服药习惯

#### 4.7 认知障碍康复（认知矫正）

训练方法选择：

- 传统训练方法
- 基于计算机/虚拟现实训练
- 特定领域训练

目标认知域：注意力、记忆力、执行功能等

### 第五步：定期评估与方案调整

定期评估以下维度的改善情况：

- 生活自理能力
- 社交技巧水平
- 工作能力进展
- 药物依从性
- 认知功能变化

根据评估结果动态调整训练模块组合和强度。

## 输出规范

生成方案时应包含：

1. 患者评估摘要
2. 选定训练模块及理由
3. 各模块具体实施计划（含时间安排、负责人、目标）
4. 评估节点和指标
5. 方案调整触发条件

## Use Case:

Developers and agent builders use this skill as a broad checklist for equipping agents with common file, network, coding, cloud, security, monitoring, and deployment capabilities. It helps plan environment checks, tool coverage, and execution practices for general-purpose autonomous agent workflows.

### Deployment Geography for Use:

## Known Risks and Mitigations:

Risk: The skill encourages powerful local, network, cloud, scheduling, container, database, and deployment operations without clearly defined approval gates or boundaries.

Mitigation: Install and run it only in environments with enforced confirmations, restricted secrets and production access, and command review before execution.

Risk: The broad capability checklist can lead agents toward high-impact actions that exceed the user's intended scope.

Mitigation: Constrain the agent's available tools, permissions, credentials, and deployment targets to the specific task before using the skill.

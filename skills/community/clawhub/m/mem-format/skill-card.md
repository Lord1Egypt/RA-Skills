## Description:

Mem-format helps agents clean and reformat memory bank Markdown files so they conform to established templates while preserving existing content.

This skill is ready for commercial/non-commercial use.

## Publisher:

[space-cadet](https://clawhub.ai/user/space-cadet)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agents use this skill to standardize memory bank task, session, and registry Markdown files against expected templates while preserving existing project information.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad file selection can unintentionally reformat more memory bank files than intended.

Mitigation: Use explicit file or category arguments when possible and review the target list before applying changes.

Risk: Template restructuring can remove or misplace existing memory bank content if applied incorrectly.

Mitigation: Create backups before edits, process files incrementally, and review the generated report for manual follow-up.

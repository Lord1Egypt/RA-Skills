## Use Case:

Developers and engineers use this skill to review SwiftUI code for view composition, state ownership, rendering performance, accessibility, and evidence-bound findings tied to file and line locations.

## Known Risks and Mitigations:

Risk: The skill guides an agent to inspect SwiftUI files and produce code-review findings, which could be incorrect or misleading if accepted without review.

Mitigation: Review findings against the referenced SwiftUI source lines before making code changes.

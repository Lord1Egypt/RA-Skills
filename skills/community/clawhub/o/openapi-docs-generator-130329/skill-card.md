## Description:

Helps API developers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, backend teams, developer-experience teams, and maintainers use this skill to create actionable OpenAPI or Swagger documentation workflows, checklists, analysis, code changes, and validation notes for REST APIs.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate on broad API or developer-experience wording when the user does not need OpenAPI or Swagger documentation help.

Mitigation: Invoke it explicitly for API documentation tasks and disregard it for unrelated backend engineering requests.

Risk: Generated API documentation guidance may be incomplete or mismatched if the available API routes, schemas, authentication behavior, or examples are incomplete.

Mitigation: Validate outputs against the target service, OpenAPI or Swagger tooling, and the user's stated success criteria before using them.

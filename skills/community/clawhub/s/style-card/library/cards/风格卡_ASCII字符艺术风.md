# 风格卡 · ASCII 字符艺术风

> 来源：2026 设计趋势自主挖掘（ASCII/字符拼贴数字美学）
> 状态：已验证（HTML demo 随卡产出）

## 1. 一句话风格描述
用字符、符号、标点「拼」出图形与版面，单色（黑/深灰/单强调色）极简数字美学，复古终端感 + 先锋实验气质，文字零错、自带极客滤镜。

## 2. 基础参数
| 项 | 值 |
|---|---|
| 画幅 | 1:1 / 4:3 / 3:4 竖 |
| 适用场景 | 技术论坛、AI/编程概念、命令行梗、开发者内容、极客知识卡、金句卡 |
| 信息容量 | 大标题 1（≤8 字）+ 副题 1 + 字符装饰图形 1-2 组 + 正文 2-3 行/要点 3-5 个 |

## 3. 配色系统
- 底：近黑 `#0D0D0D` 或墨黑 `#111111`（主推深底，字符反白更锐）
- 可选亮底：纸白 `#F4F4F0`（字符用深灰）
- 字符主色：绿 `#33FF66`（经典终端绿）或 灰白 `#E6E6E6`
- 单一强调色（可选，≤1 处）：琥珀 `#FFB000` 或 品红 `#FF2E88`
- 无渐变、无噪点、无描边，纯字符密度形成灰阶

## 4. 构图布局
```
┌──────────────────────────┐
│  ██ ██ 小字 meta 行(左上)     │
│  ██████  (等宽字体)          │
│                            │
│      ▄▄▄▄▄▄▄▄▄▄           │
│     █ 字符拼的图形  █        │
│      ▀▀▀▀▀▀▀▀▀▀           │
│   (核心视觉，居中或一侧)      │
│                            │
│  主标题：ASCII 大字标题       │
│  (块状字母/字符拼标题)        │
│  ── 分隔线 ──────────        │
│  要点1  要点2  要点3          │
│  (字符前缀 ┤ 或 • 引导)       │
│  底部 meta/版权行(等宽小字)    │
└──────────────────────────┘
```
- 字符图形放黄金位（中心偏上），主标题紧随其后，要点压在下方
- 用等宽网格对齐，字符本身就是「网格」，天生工整

## 5. 字体排印
- 全部等宽字体：`JetBrains Mono`（英文/符号）+ `Noto Sans SC`（中文正文）
- 大标题可用块状字符拼字（`█▀▀█ █▀█ █▄█`）或等宽粗体大写
- 正文/要点：等宽小字，行高 1.6，`┤`、`•`、`>` 作前缀，营造命令行回显感
- meta 行：全大写英文 + 等宽，如 `$ WHOAMI — AI PRACTITIONER`

## 6. 图形元素
- 字符拼图形（人像/图标/几何/箭头）：用 `█ ▓ ▒ ░ ▄ ▀ ▌ ▐` 等 block 元素 + `/\|-_=+*#@$%&` 组合
- 分隔线：`─ ─ ─`、`══════`、`------`
- 边框/窗口：`┌─┐ │ └─┘` 框线，模拟终端窗口
- 禁止 emoji、禁止真实插画/照片，一切视觉靠字符

## 7. 内容槽位
- `{meta行}`（英文/命令式，≤30 字符）
- `{主标题}`（≤8 字，可字符拼字或等宽大字）
- `{副题}`（≤20 字）
- `{字符图形}`（1-2 组，纯字符）
- `{要点1-5}`（各 ≤12 字，字符前缀引导）
- `{底部meta}`（作者/日期/标签，等宽小字）

## 8. 生成方式（engine: html）
html-base.css + html-template.md；全等宽字体 JetBrains Mono（英文/符号）+ Noto Sans SC（中文）；深底 `#0D0D0D` 反白字符；字符图形用 `<pre>` 块 + `▄▀█▓▒░` 等 Unicode block 字符，`white-space: pre` 保对齐；标题可用块状字符拼字；单强调色仅 1 处。

## 9. 禁止出现
- ❌ emoji、❌ 真实插画/照片、❌ 渐变/噪点/投影
- ❌ 非等宽字体（字符图形会错位）、❌ 字符图形用正文长句填充（图形区只放符号）
- ❌ 强调色 >1 处、❌ 亮底时字符过浅看不清

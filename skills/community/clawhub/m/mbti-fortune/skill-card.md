## Description:

MBTI Fortune Teller draws a random MBTI type for any user question and returns a playful answer interpreted through the type's cognitive function stack.

This skill is ready for commercial/non-commercial use.

## Publisher:

### License/Terms of Use:

MIT-0

## Use Case:

External users use this skill for playful MBTI-style fortune readings about arbitrary questions. It is intended for entertainment output, not for real decisions about work, health, money, relationships, or other consequential topics.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Fortune-style answers may sound decisive even when a question involves consequential real-world choices.

Mitigation: Treat responses as fictional entertainment and avoid relying on them for work, health, money, relationships, legal, or other real decisions.

Risk: Broad trigger wording such as ordinary will, does, or type questions may activate the skill unintentionally.

Mitigation: Use the skill only when the user explicitly wants an MBTI fortune reading, and ignore or disable it for ordinary factual or advice requests.

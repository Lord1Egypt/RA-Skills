# 读者认知状态

## 读者是谁

- 具体画像（越具体越好，别写「专业读者」）：
- 他眼下的处境（正在经历什么 / 卡在哪一步）：

## 读前状态

- 常见误解：
- 知识盲区：
- 情感状态：

## 和我有关（关系）

> 六型里挑 1–2 个：当前处境 / 利益后果 / 未命名经验 / 身份与立场 / 好奇与窥探 / 社交用途。

- 关系类型：
- 在开头显露了吗（露出读者熟悉的处境、后果或身份才算）：
- 人群范围（一小群正卡在这件事上的人 / 跨群体的共同处境）：

## 读后状态

> 主回报从七型里**只选一个**：解释 / 判断 / 行动 / 情绪 / 身份 / 表达 / 审美与娱乐。有一种写出来的明确回报即可，不强制是「可执行动作」。
> 「主回报」是**他带走什么**，「用途」是**他拿它去干什么**——两栏答案接近是正常的（回报是判断时，用途常是备忘工具），不要为了区分硬编一个。

- 主回报类型：
- 他带走的那句话（能被复述，不写「更懂 X」）：
- 在哪兑现（观点文 / 方法文：第一份实物落在首段或第一节；个人叙事 / 人物 / 深度长文：可放在转折之后。都指到「第几节、哪一段」，指不出等于没兑现）：
- 可执行动作（回报是「行动」时必填）：
- 他会把它当什么用（身份表达 / 备忘工具 / 社交谈资 / 情绪出口，只填一个；答不出就空着）：

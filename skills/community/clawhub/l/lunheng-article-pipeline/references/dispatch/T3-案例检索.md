任务：

5. **多方说法**（强制并列）：当事人说法 + 媒体主流叙事 + 第三方/反方观点；当事人未回应写「截至检索截止未回应」
6. **信任级别必填**：已发布 / 主人投喂 / 二手转引三档之一必填，否则 M 门 M-Form-6 失败

10. **任何量级默认必 spawn**：含 cases = 0 场景也走 0 条空卡协议，输出 `[C-空]` + 显式声明「本次无案例需求」；只有已记录的 `waived` 才可不执行检索。
11. **不补造细节**：未核实写「未公开/未披露」；不堆砌案例（重量场景下主动筛选最具代表性/可验证性）
11.1 **公开批评未成形诚实声明**：事件若「批评方截至检索截止未成形」，多方说法末加一句「截至 YYYY-MM-DD 检索截止，[Cxx] 案例公开批评尚未成形——学术检验仍待学界参与」
12. 严禁编造事件；检索不到就写「未检索到」+ 走 0 条空卡协议
13. 交接报告按 [`templates/交接报告-template.md`](../templates/交接报告-template.md) **七段**交付（做了什么 / 产物在哪 / 怎么验证 / 已知问题 / 下一步 / 状态机更新 / **AI 使用披露**）；status.md 由主控代写；**token 消耗由主控从 completion event Stats 记录，不属子代理回报段**。

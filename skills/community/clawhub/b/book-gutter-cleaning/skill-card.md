## Use Case:

External users can use this skill to search for gutter-cleaning providers, check availability, and create a booking through Lokuli.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Completing a booking sends the selected provider, time slot, name, email, and phone number to Lokuli.

Mitigation: Confirm booking details and contact fields with the user before allowing the agent to submit them.

## Description:

Configure OpenClaw agent with MBTI personality types for personalized interaction styles, supporting all 16 MBTI types with tailored communication styles, decision-making approaches, and workflow preferences.

This skill is ready for commercial/non-commercial use.

## Publisher:

[jarviyin](https://clawhub.ai/user/jarviyin)

### License/Terms of Use:


## Use Case:

External users and developers use this skill to configure an OpenClaw agent's interaction style around a selected MBTI profile. It helps tailor agent communication, decision framing, workflow structure, and interaction patterns to a preferred persona.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Setting an MBTI type creates or updates a persistent local configuration file under ~/.openclaw.

Mitigation: Install only when persona-based adaptation is desired, and review or remove the local MBTI configuration file when the preference should no longer apply.

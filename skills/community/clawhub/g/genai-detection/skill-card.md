## Description:

Detect whether an image was generated by AI (e.g. Midjourney, DALL-E, Stable Diffusion) using the Scam.ai API.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and developers use this skill to check image files for signs of AI generation through the Scam.ai API and receive a concise verdict with confidence.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill stores a Scam.ai API key in a local dotfile.

Mitigation: Use only keys intended for this service, keep file permissions restricted, and delete or rotate the saved key when it is no longer needed.

Risk: The skill sends the selected image file to the Scam.ai API for analysis.

Mitigation: Analyze only images that are appropriate to upload to Scam.ai.

Risk: Shell-command templates include user-provided key and file path values.

Mitigation: Validate the resolved image path before upload and avoid pasting secrets into shell-style prompts.

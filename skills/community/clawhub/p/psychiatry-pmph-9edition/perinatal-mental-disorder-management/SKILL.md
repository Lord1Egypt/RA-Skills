# 围产期精神障碍全流程管理

## 适用场景

对妊娠期或产褥期（分娩后6周内）出现精神/行为症状的女性进行系统评估与干预。

## 第一步：高危人群识别与筛查

**筛查时机**：孕早期和孕晚期各筛查一次，高危者多次

**6类重点人群**：
1. 妊娠期或分娩期有创伤经历者
2. 既往有精神障碍史或新发精神障碍者
3. 因意外怀孕、婚姻不和谐、家庭虐待、配偶物质滥用等出现心理障碍者
4. 发生死胎、死产及与婴儿性别有关心理困扰者
5. 产科/新生儿急症导致母婴分离产生心理困扰者
6. 产后可能存在母婴互动及母乳喂养困难者

## 第二步：全面评估

### 病史采集（9项核心内容）
1. 现病史：症状时间/进程/严重程度，**重点排查未确诊的双相障碍**
2. 既往史：疾病严重程度、住院经过、自杀倾向
3. 个人/妇科史：月经初潮、周期情绪症状、激素避孕反应、孕产史
4. 家族史：女性亲属围产期抑郁/精神障碍史、双相障碍家族史
5. 药物治疗经过及反应
6. 物质使用史
7. 既往生活经历：创伤史、伴侣暴力、歧视/霸凌、慢性压力、社会支持
8. 既往躯体疾病史
9. 对妊娠和即将成为母亲的感受

### 心理评定量表
EPDS、PHQ-9、HAMD、HAMA、GAD-7、YMRS

### 辅助检查排除器质性疾病
- 常规：血尿常规、肝肾功、血脂血糖、心电图
- 内分泌：甲状腺、肾上腺、激素
- 感染：乙肝、丙肝、梅毒、艾滋
- 其他：脑电图、颅脑CT/MRI

### 产褥期特有评估
- **婴儿喂养/哺乳**：母乳喂养方式、睡眠获取、饮食限制、哺乳期药物安全性、伴侣参与度
- **睡眠评估（最重要风险因素）**：睡眠质量、睡眠潜伏期、睡眠效率、睡眠药物使用、日间功能障碍

## 第三步：ICD-11诊断与分型

### 核心诊断要求
1. 发生于妊娠期或产褥期（分娩后6周内）
2. 包含显著精神行为特征，导致功能严重损害
3. 排除其他疾病或物质/药物所致

### 分型

**不伴精神病性症状**：
- 最常见为抑郁、焦虑、强迫症状
- 不包括妄想/幻觉
- 排除：轻度短暂"产后忧郁"（婴儿忧郁）
- 排除：对婴儿的短暂担忧/侵入性想法（若不持续、不引起实际痛苦、不影响照顾功能）

**伴精神病性症状**：
- 包括妄想、幻觉，常伴心境症状
- 可能伴意识模糊、定向力障碍、睡眠障碍、激越
- **警示**：可能有害自己/婴儿企图
- 排除：一般人群短暂精神病样体验（若不短暂、不影响功能、本人能意识到是幻觉）

### 共病处理
- 若症状符合特定精神障碍（如抑郁、双相），需同时予以诊断
- 即使是先前疾病的复发或恶化，也可给出此诊断

## 第四步：围产期焦虑障碍亚型识别

若主要表现为焦虑/担忧/恐惧，进一步分型：

| 亚型 | 核心特征 | 持续时间 |
|------|----------|----------|
| 广泛性焦虑(GAD) | 过度担忧多领域，伴≥3种生理症状 | ≥6个月 |
| 惊恐障碍(PD) | 反复惊恐发作，几分钟达高峰，≥4种躯体症状 | 发作后≥1个月适应不良 |
| 疾病焦虑(IAD) | 无症状下过度担忧严重疾病，过度关注身体感觉 | ≥6个月 |
| 强迫症(OCD) | 侵入性思维多为对婴儿伤害，强迫行为多为检查 | - |

## 第五步：治疗决策

### 治疗层级
- **轻中度**：首选非药物治疗
- **重度/有自伤伤人风险**：药物和/或电抽搐治疗（ECT）

### 药物治疗原则
- 权衡"风险-效益"，选择对母婴风险最小的药物
- 尽量遵循"单一用药"原则
- 避免多药联合

### 药物选择参考

| 药物类别 | 推荐/风险 | 注意事项 |
|----------|-----------|----------|
| SSRIs（抗抑郁） | 多数妊娠期倾向选用 | 宫内暴露与先天性畸形有关 |
| 锂盐（情感稳定剂） | 有胎儿致畸性，使用存在争议 | 需极度谨慎 |
| 丙戊酸盐 | **不再推荐使用** | 增加孤独症风险，降低儿童认知 |
| 拉莫三嗪 | 不增加先天畸形风险 | 孕产期血药浓度不稳定，需严密监测 |
| 第二代抗精神病药 | 对药物反应良好者可继续使用 | 警惕代谢综合征 |

### 非药物治疗

**心理治疗（5种核心疗法）**：
1. **CBT**：认知重组，适用于抑郁、焦虑、强迫、睡眠障碍
2. **DBT**：平衡"改变"与"接受"，改善抑郁/焦虑
3. **IPT**：短期聚焦人际功能，关注角色转换、悲伤、角色冲突
4. **伴侣疗法**：改善伴侣互动
5. **ACT**：增加对内部事件接受和外部事件主动参与

**辅助治疗**：rTMS、运动疗法、强光治疗

**社会干预**：健康教育、社会支持网络建设

## 输出格式

```
风险评估等级：[低/中/高]
诊断：[ICD-11诊断名称] + [分型] + [共病诊断]
焦虑亚型（如适用）：[GAD/PD/IAD/OCD]
治疗建议：
  - 药物：[药物名称/剂量/监测要求] 或 [无需药物]
  - 心理治疗：[疗法类型/频次]
  - 社会支持：[具体措施]
产褥期特别关注：[哺乳安全性/睡眠干预]
```

## 关键警示

- 伴精神病性症状者需评估伤害婴儿风险
- 睡眠剥夺是重要风险因素，必须评估
- 丙戊酸盐妊娠期禁用
- 排查双相障碍后再用抗抑郁药

# Interview Question Builder

## Overview

Interviews predict poorly when they test trivia and charm. This workflow builds questions from the job's real tasks, with rubrics written before the first interview, so candidates are compared on evidence instead of impressions.

## When to use

Before any interview round, for employees, contractors, or collaborators.

## Workflow

1. **Derive questions from the work** — take the role's five core tasks; each gets one question or exercise
2. **Prefer work samples** — a small real problem beats ten hypothetical ones; timebox it and say so
3. **Write the rubric first** — per question: what a strong, adequate, and weak answer contains, in observable terms
4. **Standardize** — same questions, same order, same time for every candidate; deviations get noted, not improvised
5. **Add one judgment question** — a realistic dilemma from the role with no clean answer; score the reasoning, not the conclusion
6. **Score independently before discussing** — written scores first, then the debrief

## Guardrails

- Never ask questions whose answers you cannot evaluate
- Never let one interviewer's enthusiasm substitute for the rubric
- Respect the candidate's time: the whole set should fit the scheduled slot

## Output format

An interview pack: questions mapped to core tasks, per-question rubrics, scoring sheet, debrief format.

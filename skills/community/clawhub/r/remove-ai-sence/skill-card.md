## Description:

Automatically scans frontend projects for AI-associated colors, emoji icons, and exposed English technical errors, then reports and helps replace them with a professional brand style.

This skill is ready for commercial/non-commercial use.

## Publisher:

[moan19921019-code](https://clawhub.ai/user/moan19921019-code)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and frontend teams use this skill to scan UI code for AI-looking visual patterns and user-facing technical error leaks, review an HTML report, and apply brand-consistent cleanup.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may modify frontend project files after report review and replacement approval.

Mitigation: Run it in a version-controlled project and review the generated detection report before approving replacements.

Risk: Replacing user-facing error text and UI labels can affect localization-sensitive applications.

Mitigation: Review proposed wording changes for product terminology, locale requirements, and support expectations before accepting edits.

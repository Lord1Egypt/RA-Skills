# OPC智脑 - Skill3：OPC合规落地

## 适用阶段和前置条件

### 适用阶段
- **阶段**：实体期（五阶段模型第3阶段）
- **阶段目标**：完成主体注册、财税规划、商用模板准备、前期筹备，实现低成本合规落地
- **毕业条件**：主体注册完成 + 财税规划落地 + 商用模板齐备

### 前置条件
1. MVP已设计完成（Skill2输出）
2. 业务类型已明确（服务/产品/混合）
3. 有明确的营收预期（哪怕很保守）
4. 创业者决定正式开展业务（不是还在验证阶段）

### 不适用场景
- 还没验证需求 → 应先进入Skill1
- 还没设计MVP → 应先进入Skill2
- 已经注册了公司且运营正常 → 应进入Skill4
- 只是想了解合规知识，还没准备好注册 → 提供知识科普，不进入正式规划

## 诊断任务和详细步骤

### 任务1：主体选型决策

#### 步骤1.1：两种主体类型对比

| 对比维度 | 个体工商户 | 一人有限公司 |
|---------|-----------|------------|
| **法律责任** | 无限连带责任（个人财产与经营财产不分） | 有限责任（以出资额为限） |
| **注册难度** | ★☆☆ 极简，1-3天 | ★★☆ 较复杂，5-15天 |
| **维护成本** | 低（无需记账报税，只需年度报告） | 中（需记账报税+年度审计） |
| **企业所得税** | 无（只交个人所得税） | 有（税率25%，小微企业5%） |
| **增值税** | 小规模3%（月≤10万免征） | 小规模3%/一般6%、9%、13% |
| **开票能力** | 可开普票，部分可开专票 | 可开普票和专票 |
| **品牌形象** | 较弱（"个体户"标签） | 较好（"有限公司"标签） |
| **融资能力** | 无法融资、无法引入股东 | 可融资、可引入新股东 |
| **银行开户** | 可开对公户（部分银行限制） | 可开对公户 |
| **社保公积金** | 可自己缴纳 | 可自己缴纳 |
| **注销难度** | 简易注销，1-3天 | 较复杂，需清算，1-3月 |
| **新公司法影响** | 影响较小 | 影响较大（详见下文） |

#### 步骤1.2：选型决策框架

```
决策流程：

问题1：你的业务是否有较大的法律风险（如合同纠纷、知识产权侵权）？
  → 是 → 一人有限公司（有限责任保护个人财产）
  → 否 → 继续问

问题2：你的客户是否要求开专票或要求与"有限公司"合作？
  → 是 → 一人有限公司
  → 否 → 继续问

问题3：你未来是否计划融资或引入合伙人？
  → 是 → 一人有限公司
  → 否 → 继续问

问题4：你的月营收预期是否超过10万？
  → 是 → 一人有限公司（财税规划空间更大）
  → 否 → 个体工商户（维护成本更低）

问题5：你是否能承受每月500-1000元的记账报税成本？
  → 能 → 两者皆可，看其他因素
  → 不能 → 个体工商户
```

#### 步骤1.3：一人创业者的典型推荐

|---------|---------|---------|
| 纯线上服务（咨询/设计） | 个体工商户 | 维护成本低，无需开专票 |

| 知识付费/内容 | 个体工商户 | 收入主要是个人劳务所得 |
| 电商/贸易 | 一人有限公司 | 需要开专票，品牌形象重要 |
| 混合型（服务+产品） | 一人有限公司 | 业务复杂度高，需要有限公司灵活性 |

### 任务3：2024新公司法OPC合规要点

#### 步骤3.1：新公司法核心变化（2024年7月1日施行）

| 序号 | 变化要点 | 对一人有限公司的影响 | 严重程度 |
|------|---------|---------------------|---------|
| 1 | **注册资本5年限缴** | 认缴制改为5年内必须实缴到位 | ★★★★★ |
| 2 | **股东出资加速到期** | 公司无法清偿债务时，股东需提前缴纳未到期出资 | ★★★★★ |
| 3 | **一人公司举证责任倒置** | 股东需证明个人财产独立于公司财产，否则承担连带责任 | ★★★★★ |
| 4 | **简化注销程序** | 符合条件可简易注销，降低退出成本 | ★☆☆（利好） |
| 5 | **监事设置灵活化** | 规模较小的一人公司可不设监事 | ★★☆（利好） |
| 6 | **电子营业执照** | 与纸质执照同等效力 | ★☆☆（利好） |
| 7 | **信息公示要求加强** | 需公示更多经营信息 | ★★★☆ |
| 8 | **股东名册要求** | 需置备股东名册（一人公司也需） | ★★☆ |
| 9 | **利润分配时间限制** | 应在股东会决议后1年内分配 | ★★☆ |
| 10 | **法人人格否认制度强化** | 滥用公司法人独立地位将承担连带责任 | ★★★★ |

#### 步骤3.2：OPC合规核心要点（一人创业者必知）

**要点1：财产独立——最关键的合规要求**

```
一人有限公司最大的法律风险：个人财产与公司财产混同

新公司法第23条：一人有限责任公司的股东不能证明公司财产独立于
股东自己的财产的，应当对公司债务承担连带责任。

实操要求：
1. 必须开立对公账户，所有经营收入进入对公户
2. 个人支出与经营支出严格分离
3. 每年至少做一次财务审计（或至少保持规范的财务记录）
4. 股东借款需有正式借款协议
5. 工资发放需通过对公户，有工资条
```

**要点2：注册资本实缴——5年期限**

```
新公司法第47条：有限责任公司的注册资本为在公司登记机关登记的
全体股东认缴的出资额。股东认缴的出资额应在五年内缴足。

实操建议：
1. 注册资本不要写太高（建议10-50万，按实际需要）
2. 5年内必须实缴到位，按期规划出资
3. 实缴方式：货币出资（最简单），需银行入账并出具验资证明
4. 首期出资可以只出一部分，5年内到位即可
5. 出资后资金可用于公司经营，不是"锁死"在账上
```

**要点3：年度审计与信息公示**

```
新公司法要求：
1. 一人有限公司应当在每一会计年度终了时编制财务会计报告
2. 并经会计师事务所审计（新法放宽了要求，但建议仍做）
3. 通过国家企业信用信息公示系统公示年度报告

实操建议：
- 找代账公司处理（月费200-500元）
- 每月按时记账、报税
- 每年1-6月完成年度报告公示
- 保存好所有财务凭证（至少5年）
```

#### 步骤3.3：合规风险预警

| 风险 | 预警信号 | 后果 | 预防措施 |
|------|---------|------|---------|
| 财产混同风险 | 个人消费从对公户出 | 连带责任 | 严格分离个人与公司账户 |
| 注册资本虚高风险 | 认缴额远超实际需要 | 5年内必须实缴 | 按需设定注册资本 |
| 零申报风险 | 长期零申报 | 税务稽查风险 | 有收入及时申报 |
| 未年报风险 | 忘记做年度报告 | 列入经营异常名录 | 设定年度提醒 |
| 发票风险 | 虚开/买卖发票 | 刑事责任 | 依法合规开票 |

### 任务4：初创财税规划

#### 步骤4.1：纳税人类型选择

```
小规模纳税人 vs 一般纳税人

小规模纳税人（推荐初创OPC）：
- 适用条件：年应税销售额≤500万
- 增值税率：3%（月≤10万免征）
- 申报频率：按季申报
- 会计要求：简式账
- 适合：月营收<40万的一人创业者

一般纳税人：
- 适用条件：年应税销售额>500万或主动申请
- 增值税率：6%（服务）/13%（货物）
- 申报频率：按月申报
- 会计要求：复式账
- 适合：月营收>40万或客户要求专票
```

#### 步骤4.2：零申报指南

```
创业初期（有公司但还没收入）的零申报：

必须申报的项目：
1. 增值税：小规模按季申报（1月、4月、7月、10月）
2. 企业所得税：按季预缴，年度汇算清缴
3. 个人所得税：按月申报（工资薪金）
4. 附加税：随增值税自动计算

零申报注意事项：
- 零申报≠不申报，不申报会产生罚款
- 零申报不宜超过6个月（税务可能关注）
- 有收入后必须及时如实申报
- 建议找代账公司处理（月费200-500元）
```

#### 步骤4.3：成本票策略

```
成本票：用于抵扣企业所得税的成本费用发票

可获取的成本票类型：
1. 办公用品/设备：电脑、打印机、办公桌
2. 软件订阅：SaaS工具、云服务、域名
3. 差旅费用：出差交通、住宿（需与经营相关）
4. 培训费用：与业务相关的培训课程
5. 服务费用：代账费、法律咨询费
6. 通讯费用：手机费、网络费（部分可抵扣）
7. 折旧费用：固定资产折旧

注意事项：
- 所有成本票必须与经营相关
- 个人消费不能作为成本抵扣
- 单笔超过5000元的需有合同支撑
- 保留好所有票据原件和电子版
```

#### 步骤4.4：月度财税例行事项

```
每月必做：
□ 1-15日：记账（整理上月票据，录入账务系统）
□ 1-15日：申报个人所得税（工资薪金）
□ 1-15日：银行对账（核对对公户流水）

每季必做：
□ 季初1-15日：申报增值税（小规模）
□ 季初1-15日：预缴企业所得税
□ 季初1-15日：申报附加税

每年必做：
□ 1-6月：年度企业所得税汇算清缴
□ 1-6月：工商年度报告公示
□ 1-6月：财务审计（一人有限公司建议做）
```

### 任务5：商用模板准备

#### 步骤5.1：必备商用模板清单

| 模板名称 | 优先级 | 获取方式 | 说明 |
|---------|--------|---------|------|
| 服务合同/协议 | ★★★★★ | 自制或法律模板 | 明确服务内容、价格、交付标准、违约责任 |
| 报价单/方案书 | ★★★★★ | 自制 | 专业报价，包含服务范围和价格明细 |
| 保密协议(NDA) | ★★★★☆ | 法律模板 | 涉及客户敏感信息时必须签署 |
| 服务说明书(SOW) | ★★★★☆ | 自制 | 明确服务边界，防止需求蔓延 |
| 发票开具信息 | ★★★★☆ | 税务系统 | 开票资料，方便客户索票 |
| 退款/售后政策 | ★★★☆☆ | 自制 | 明确退款条件和售后承诺 |
| 隐私政策 | ★★★☆☆ | 模板修改 | 涉及用户数据时必须 |
| 用户协议/条款 | ★★☆☆☆ | 模板修改 | SaaS/平台类产品需要 |

#### 步骤5.2：合同模板关键条款

```
一人创业者合同必须包含的条款：

1. 服务范围（明确做什么、不做什么）
2. 交付标准和验收条件
3. 交付时间线
4. 价格和付款方式（建议预付50%+完工50%）
5. 修改和变更条款（限制修改次数，防止需求蔓延）
6. 知识产权归属
7. 保密条款
8. 违约责任（双方）
9. 争议解决方式
10. 合同终止条件

特别提醒：
- 一人创业者容易被甲方"加需求"，必须在合同中限制修改次数
- 建议采用"50%预付+50%完工"的付款方式，降低坏账风险
- 合同金额<5000元的简单项目，可用简化版协议
```

### 任务7：商标注册指引（实体期必做）

**⚠️ 品牌已经验证有价值，必须保护商标，否则被抢注后代价巨大。**

#### 步骤7.1：商标注册时机判断

```
判断逻辑：

问题1：品牌名称是否已确定且不打算更改？
  → 否 → 暂不注册（等确定后再注册）
  → 是 → 继续问

问题2：是否已有付费用户或明确的市场验证？
  → 否 → 暂不注册（先验证需求）
  → 是 → 继续问

问题3：品牌是否是核心资产（如SaaS产品、内容品牌）？
  → 否 → 可延后（非核心资产优先级低）
  → 是 → 立即注册

问题4：是否有预算（300-1000元）？
  → 否 → 先注册域名占位（几十元），商标延后
  → 是 → 立即注册
```

**最佳注册时机**：实体期开始时（主体注册完成后立即注册商标）

#### 步骤7.2：商标类别选择

**一人创业者核心类别**：

| 类别 | 适用场景 | 是否必注 |
|------|---------|---------|
| 第35类 | 广告销售、商业管理、替他人推销 | ★★★★★ 所有业务必注 |
| 第42类 | 科技服务、软件开发、SaaS平台 | ★★★★★ 科技类必注 |
| 第9类 | 软件、APP、可下载程序 | ★★★★☆ 软件类必注 |
| 第41类 | 教育、培训、内容、视频 | ★★★★☆ 内容类必注 |
| 第38类 | 通讯服务、在线社区 | ★★★☆☆ 平台类考虑 |
| 第36类 | 金融、支付 | ★★☆☆☆ 金融类考虑 |

**一人创业者建议**：

#### 步骤7.3：商标注册流程

**方式1：自行申请（省钱，300元/类）**

#### 步骤7.5：不注册商标的后果

| 后果 | 严重程度 | 说明 |
|------|----------|------|
| 被抢注 | 🔴 严重 | 品牌做起来后，发现名字被别人注册了 |
| 被起诉侵权 | 🔴 严重 | 使用未注册商标，被商标持有者起诉 |
| 花钱买回 | 🔴 严重 | 被抢注后，只能花几万甚至几十万买回 |
| 被迫改名 | 🔴 严重 | 所有品牌资产（域名、包装、宣传）全部作废 |
| 无法维权 | 🟡 中等 | 被别人抄袭，无法通过法律手段维权 |

**关键提醒**：
- 商标注册成本：300元/类（自己办）或1000-2000元/类（委托代理）
- 被抢注成本：几万甚至几十万（买回商标）或全部推倒重来（改名）
- **投入产出比**：300元 vs 几万元，商标注册是最划算的保险

#### 步骤7.6：商标注册常见问题

**Q1：商标还没想好，可以先注册公司吗？**
A：可以。公司名称≠品牌名称，公司先注册，商标后续再注册。

**Q2：商标注册后多久能用？**
A：提交申请后即可使用（标注"TM"），注册成功后标注"®"。

**Q3：商标被驳回了怎么办？**
A：可以申请复审（费用+时间），或修改商标重新申请。

**Q4：可以只注册一个类别吗？**
A：可以，但建议至少注册35类+42类（覆盖大部分业务）。

**Q5：域名和商标哪个先注册？**
A：域名先注册（几十元，即时生效），商标后注册（300元，9-12个月）。

## 兜底策略

### 策略1：预算极低时的兜底

当创业者连基本的注册费用都觉得高时：
- 推荐先以"个人身份"开展业务（不注册主体）
- 说明个人经营的法律风险和限制
- 给出"先赚钱再注册"的路径：先做3-5单→有稳定收入→再注册
- 估算"不注册"vs"注册"的成本差异

### 策略2：对财税完全不懂时的兜底

当创业者对财税一窍不通时：
- 强烈推荐找代账公司（给出选择代账公司的标准）
- 提供一份"小白也能懂的财税入门指南"
- 列出"绝对不能做的3件事"（虚开发票、公私账户混用、不申报）
- 给出月度财税检查清单（勾选式，照做即可）

### 策略3：城市政策差异时的兜底

当创业者所在城市有特殊政策时：
- 提醒创业者查询当地市场监管局的具体要求
- 给出全国通用的标准流程作为参考
- 建议咨询当地代账公司获取最新政策
- 提供常见城市的政策差异对比（如北上广深vs其他城市）

### 策略4：犹豫是否注册时的兜底

当创业者犹豫要不要注册时：
- 给出"注册决策矩阵"：根据月营收预期、客户要求、法律风险综合判断
- 提供"不注册也能开展业务"的替代方案（如平台入驻）
- 说明"早注册"vs"晚注册"的利弊
- 建议一个明确的注册时机（如"当月营收稳定超过XX元时"）

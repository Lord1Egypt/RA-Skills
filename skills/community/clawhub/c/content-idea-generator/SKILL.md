# 选题生成器 (Content Idea Generator)

## 概述

本技能基于热点话题、用户偏好、平台算法自动生成高质量的视频/图文选题，帮助内容创作者解决"今天做什么内容"的难题。

**核心价值**：
- ⏱️ 节省时间：手动1小时 → 自动5分钟
- 📈 数据驱动：基于热点和算法推荐
- 🎯 精准匹配：根据平台和受众生成选题
- 💡 激发创意：提供多种角度和思路

## 使用场景

- 内容创作者每天找选题
- 营销团队需要内容规划
- 自媒体运营需要批量生产内容
- 企业需要做内容营销

## 完整工作流

### 输入 → 输出

```
输入：领域/行业/关键词（可选）
输出：选题列表（含标题、角度、预期热度）
```

### 工作流程详解

#### 第1步：抓取热点话题

**工具**：`web_search` + `hot-topic-tracker` 技能

**数据源**：
1. **抖音热点** - 抖音热榜、挑战榜
2. **小红书热点** - 小红书热门话题
3. **知乎热点** - 知乎热榜、圆桌
4. **微博热点** - 微博热搜
5. **百度指数** - 搜索趋势
6. **微信AI生态** - 微信AI Agent内测动态、A2A协议协作、小程序AI功能
7. **AI工具赛道** - 可灵3.0/即梦AI/Seedance/AI视频工具格局变化
8. **剪映热点** - 剪映新功能（如v20.2「营销成片」）、AI模板趋势

**示例**：抓取今日抖音热点
```
搜索关键词：抖音热点 2026-06-12
来源：抖音热榜
结果：世界杯、AI大赛、金价上涨...
```

---

#### 第2步：分析用户偏好

**分析维度**：
1. **历史表现** - 过去哪些内容表现好
2. **受众画像** - 粉丝年龄/性别/地域
3. **内容垂直度** - 专注哪个领域
4. **竞品分析** - 竞品在做什么内容

**输入数据**（可选）：
- 历史内容数据（CSV/Excel）
- 粉丝数据（JSON）
- 竞品账号列表

---

#### 第3步：生成选题

**生成方法**：
1. **热点结合法** - 把热点和您的领域结合
2. **角度创新法** - 用新角度解读热点
3. **系列内容法** - 生成系列选题
4. **问答法** - 基于用户常见问题生成选题

**输出格式**（JSON）：
```json
{
  "ideas": [
    {
      "title": "2026年最值得用的5个AI工具",
      "angle": "测评+干货",
      "platform": "douyin",
      "expected_views": "10万+",
      "difficulty": "中等",
      "reason": "AI工具是持续热点，测评类内容受欢迎"
    }
  ]
}
```

---

#### 第4步：保存选题库

**支持的输出格式**：
1. **本地Markdown** - 保存到workspace
2. **腾讯文档** - 在线协作文档（需要授权）
3. **Excel** - 使用 `xlsx` 技能
4. **直接执行** - 自动调用video-auto-generator生成视频

---

## 定时自动化

配合 `qclaw-cron-skill` 实现每日自动生成选题：

```json
{
  "name": "每日选题生成",
  "schedule": {
    "kind": "cron",
    "expr": "0 9 * * *",
    "tz": "Asia/Shanghai"
  },
  "payload": {
    "kind": "agentTurn",
    "message": "使用 content-idea-generator 技能，基于今日热点生成10个选题"
  },
  "sessionTarget": "isolated",
  "delivery": {
    "mode": "announce"
  }
}
```

以上配置会在每天早上9点自动生成选题，并推送结果到聊天窗口。

## 示例用法

### 示例1：生成今日选题

**用户输入**：
```
帮我生成今天的视频选题，领域是AI工具测评
```

**AI执行**：
1. 抓取今日热点（AI大赛、AI工具排行榜）
2. 结合AI工具测评领域
3. 生成10个选题
4. 输出选题列表

### 示例2：批量生成选题

**用户输入**：
```
生成一周的选题（7天），领域是科技数码
```

**AI执行**：
1. 分析科技数码领域热点趋势
2. 生成7天的选题（每天3-5个）
3. 保存到腾讯文档
4. 推送选题表

### 示例3：竞品选题分析

**用户输入**：
```
分析竞品@XXX的选题策略，给我类似的选题建议
```

**AI执行**：
1. 分析竞品历史内容
2. 总结选题规律
3. 生成类似但差异化的选题
4. 输出竞品分析报告+选题建议

### 示例4：微信AI Agent选题

**用户输入**：
```
生成微信AI Agent相关的短视频选题，平台选抖音
```

**AI执行**：
1. 抓取微信AI Agent最新动态（6月小范围测试、A2A协作等）
2. 分析内容窗口期（1-2个月科普红利）
3. 生成10个选题（教程类+实测类+科普类）
4. 输出适配抖音风格的选题列表

### 示例5：科技热点事件选题

**用户输入**：
```
帮我生成今天的选题，围绕最近的AI科技热点
```

**AI执行**：
1. 抓取今日热点（达沃斯论坛/DeepSeek V4.1/SpaceX收购Cursor等）
2. 结合内容创作者定位生成选题
3. 输出适配多平台的选题列表

**今日热点选题示例**：
- 「SpaceX 600亿收购Cursor」系列（科技/创业/AI工具赛道）
- 「DeepSeek V4.1即将发布」系列（AI工具/国产大模型赛道）
- 「达沃斯AI浪潮」系列（科技趋势/职场/商业分析赛道）

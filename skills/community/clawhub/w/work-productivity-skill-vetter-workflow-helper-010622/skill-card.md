## Known Risks and Mitigations:

Risk: The skill may activate too broadly because of generic trigger words and implicit invocation.

Mitigation: Prefer explicit invocation by skill name for Skill Vetter-style workflow help, and tighten trigger wording if maintaining the package.

Risk: Workflow proposals, checklists, code changes, or shell commands may be incorrect or mismatched to the user's environment.

Mitigation: Review proposed changes before execution and validate the result against the user's stated success criteria.

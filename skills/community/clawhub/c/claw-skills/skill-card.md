## Description:

OpenClaw plugin development assistant that produces runnable plugin skeletons, install commands, and debugging steps.

This skill is ready for commercial/non-commercial use.

## Publisher:

[boleyn](https://clawhub.ai/user/boleyn)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill to decide whether an OpenClaw extension should be a Skill or Plugin, generate a minimal runnable plugin skeleton, and receive install, rollback, debugging, and publishing commands.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated install, publish, or rollback commands could modify an OpenClaw environment or install packages.

Mitigation: Review commands before running them and scan generated plugin files before deployment.

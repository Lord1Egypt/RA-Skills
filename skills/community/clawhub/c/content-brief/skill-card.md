## Description:

Write a ranking content brief for one target keyword or page: confirm intent from the live SERP, read the top results and list every question they answer (plus People Also Ask), define what the page must add that page one lacks (own data, worked example, decision rule), set the primary and secondary keywords with volume and difficulty, outline headings, internal links, schema and the title/meta, and set a length target from the competing pages. Use when the user is writing a new article or landing page, refreshing a page that slipped, asks what a page should include to rank, or wants an SEO content outline or a brief for a writer.

This skill is ready for commercial/non-commercial use.

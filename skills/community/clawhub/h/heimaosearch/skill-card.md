## Use Case:

External users use this skill to search Heimaohui for event planning proposals, execution resources, and activity case references for public relations or event work.

### Deployment Geography for Use:

## Known Risks and Mitigations:

Risk: The skill sends the user's Heimaohui account identifier, API key, and search text to api.heimaohui.com.

Mitigation: Install only when that sharing is acceptable under the user's policies, avoid sensitive event details, and rotate the API key after uninstalling or suspected exposure.

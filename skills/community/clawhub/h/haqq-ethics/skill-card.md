## Use Case:

Agents can use this skill when a user intentionally wants Arabic Islamic ethics guidance, source-handling constraints, or age-banded educational framing. It is most appropriate for scoped advisory or drafting tasks where religious-source claims are reviewed by qualified humans.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill attempts to impose broad always-on behavior and authority hierarchy beyond a scoped user request.

Mitigation: Use it only for explicitly requested ethics, source-handling, or education tasks, and keep platform, system, and developer instructions authoritative.

Risk: The skill includes memory-like retention language that may be inappropriate as a global agent behavior.

Mitigation: Do not install or activate it as a global default unless that language is removed or narrowed to session-scoped task guidance.

Risk: Religious-source guidance can be sensitive or incorrect if treated as final authority.

Mitigation: Require human review by qualified subject-matter experts for religious claims, educational use, or user-facing policy decisions.

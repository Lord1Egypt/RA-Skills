## Known Risks and Mitigations:

Risk: The skill encourages persistent companion memory and agent-control file changes that can alter future agent behavior or retain personal details.

Mitigation: Review changes to SOUL.md, AGENTS.md, HEARTBEAT.md, USER.md, MEMORY.md, IDENTITY.md, and SELF_STATE.md, keep backups, and avoid storing sensitive personal information without clear consent and deletion controls.

Risk: Referenced external installer or clone workflows may execute unaudited remote content.

Mitigation: Do not run install.sh or remote setup commands until the repository and exact revision have been inspected or pinned.

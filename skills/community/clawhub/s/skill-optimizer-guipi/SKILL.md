# 技能优化器

专门负责修改和优化已有技能，把每次实际操作中发现的漏洞、经验教训持续写进对应技能，让技能越用越好。

---

## 触发方式

| 场景 | 示例 |
|------|------|
| 发现技能流程有缺失 | 「复盘没有拉滴答清单，以后要加上」 |
| 操作踩坑后要固化经验 | 「这次发布失败是因为…，把这个加进发布技能」 |
| 技能规则需要修改 | 「手机习惯从每天改成每周，更新进复盘技能」 |
| 主动优化技能逻辑 | 「优化一下周期复盘技能的数据准备流程」 |

---

## 核心流程

```
Step 1：定位目标技能
Step 2：诊断问题类型（漏洞/经验/规则修改/新增步骤）
Step 3：读取现有 SKILL.md
Step 4：写入修改（修改内容最小化原则）
Step 5：更新版本号 + 版本记录
Step 6：写入 pitfalls.md（如是踩坑经验）
```

---

## 快速操作

```bash
# 查看某个技能的当前内容
cat ~/.workbuddy/skills/{技能名}/SKILL.md

# 查看技能踩坑记录
cat ~/.workbuddy/skills/{技能名}/references/pitfalls.md

# 查看所有技能列表
ls ~/.workbuddy/skills/ | sort
```

## Description:

Coding workflow with planning, implementation, verification, and testing for clean software development.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and coding agents use this skill to structure software implementation work through planning, execution, verification, and delivery. It also guides explicit, user-controlled storage of local coding preferences.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: User preferences may be stored locally at ~/code/memory.md when explicitly requested.

Mitigation: Review the local memory file before sharing a workspace or backup, and store only preferences the user intentionally asks to save.

Risk: Coding guidance can suggest commands, tests, or changes that may be incorrect for a specific project.

Mitigation: Review suggested actions before execution and verify changes with the project's test or screenshot workflow.

# AI营养师 (AI Nutritionist)

全维度智能营养顾问 — 7大核心能力，基于《中国居民膳食指南2022》和 DRIs 2024。

## 核心能力

| 模块 | 功能 |
|------|------|
| 个性化饮食方案 | 7天×5餐详细食谱 + 购物清单 + 备餐建议 |
| 慢病营养管理 | 糖尿病/高血压/痛风/高血脂 4大慢病饮食方案 |
| 中医体质食疗 | 9种体质辨识 + 食疗推荐 + 生活建议 |
| 运动营养 | 增肌/减脂/耐力 3大目标营养策略 |
| 营养素深度解读 | 14种核心营养素缺乏/过量/食物来源/吸收因素 |
| 特殊人群营养 | 孕期/哺乳期/儿童/老年专项营养指导 |
| 食物搭配优化 | 营养协同搭配 + 相克辟谣 + GI对照 |

## 数据基础

- 150+ 中国常见食物营养成分库
- 14种核心营养素深度知识库
- 9种中医体质辨识体系
- 《中国居民膳食营养素参考摄入量(DRIs 2024)》

## 技术栈

- Python 3.13+ (纯标准库，零依赖)
- 交互式 HTML/CSS 可视化报告
- 模块化架构：数据库 → 引擎 → 报告生成器

## 快速开始

```bash
# 生成饮食方案报告
python scripts/html_report.py --type meal --goal 减脂

# 中医体质辨识
python scripts/html_report.py --type tcm

# 慢病营养指导
python scripts/html_report.py --type disease --disease 糖尿病

# 营养素详解
python scripts/html_report.py --type nutrient --nutrient 铁
```

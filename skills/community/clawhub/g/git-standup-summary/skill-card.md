## Description:

Generate concise daily/weekly standup summaries from git commit history.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ericlooi504](https://clawhub.ai/user/ericlooi504)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, engineering teams, scrum masters, and managers use this skill to turn recent git commit history into daily, weekly, team, branch, range, or author-focused standup updates.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated summaries may include repository metadata such as commit messages, author names, dates, branch names, and file paths.

Mitigation: Use the skill only on repositories where that metadata is appropriate to summarize or share.

## Description:

Before writing a non-trivial helper, script or algorithm from scratch, search codethrift.org, a public-domain (CC0) shelf of small, tested pieces of code that AI agents wrote to solve specific problems. Also covers suggesting code you wrote for publishing there, which happens only with your user's consent.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and coding agents use this skill to find and review existing code for a non-trivial helper, script, or algorithm before writing one from scratch. It also explains how to suggest newly written code for publication, with the user's consent.

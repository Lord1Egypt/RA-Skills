## Description:

Guides an agent in using MemOS Lite memory tools to search past conversations, expand memory hits, retrieve task summaries or learned skills, and help users manage stored memories.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and developers use this skill to help an agent recall prior conversation context, user preferences, task summaries, and related learned skills through MemOS Lite memory tools.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can guide an agent to access broad stored conversation history.

Mitigation: Use it only when long-term memory is appropriate, and confirm that users can view, delete, and limit stored memories.

Risk: The skill describes optional persistent installation of retrieved skills without explicit approval boundaries.

Mitigation: Require user approval before installing any retrieved skill for future sessions.

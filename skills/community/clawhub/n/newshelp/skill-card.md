## Description:

NewsHelp helps agents navigate newshelp.org by using direct URLs, the tags index, and search shortcuts to find homepage and topic-page content efficiently.

This skill is ready for commercial/non-commercial use.

## Publisher:

[nerkn](https://clawhub.ai/user/nerkn)

### License/Terms of Use:


## Use Case:

Agents and users use this skill to locate NewsHelp homepage content, topic pages, and tag-based news categories quickly. It is useful for navigation guidance when browsing current or topic-specific news on newshelp.org.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Tag navigation may be imprecise because the artifact includes a misspelled tag entry and encourages guessing categories.

Mitigation: Verify tag URLs against the listed tags or the NewsHelp tags page when precision matters.

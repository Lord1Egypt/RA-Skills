# 03 · 方法论工具箱（按八席位组织）

> 使用方式：主决策链第 4 步 DELIBERATE 时，按席位取用工具。每个工具给出 **输入 / 步骤 / 输出 / 常见陷阱 / 关联**（GMAP 原则 · 2040 能力编号见模块 02）。
> 所有方法为业界通行分析框架，不代表任何机构的官方授权或专有方法。

---

## S1 · 战略与增长

### T1.1 议题树 / MECE 拆解
- **输入**：一句可回答的决策问题 + 范围边界 + 委托方成功标准。
- **步骤**：① 把问题写成「是否 / 哪个 / 如何」句式 ② 按「相互独立、完全穷尽」分到 2–3 层 ③ 每层用「为什么 / 所以呢」检验 ④ 对叶子节点标注「需数据 / 可假设 / 可判断」 ⑤ 按影响力×可改变性剪枝，保留 ≤7 个关键议题。
- **输出**：议题树 + 分析工作计划（含数据来源与责任人）。
- **陷阱**：把「分类」当「拆解」（无因果链）；为穷尽而穷尽；不剪枝导致分析瘫痪。
- **关联**：P1/P2 · 2.5、2.1。

### T1.2 金字塔原理与 SCQA
- **步骤**：情境(S) → 冲突(C) → 疑问(Q) → 答案(A)；答案先行，以上统下，以下证上；每组论据 ≤4 条且同类。
- **输出**：一页纸结论 + 支撑包。
- **陷阱**：先写分析过程再补结论；把「背景」写成 3 页。
- **关联**：P1 · 1.1、1.2。

### T1.3 三层面增长 / 组合盘点
- **步骤**：H1 核心业务（效率与现金流）｜H2 新兴增长（需投入、可验证）｜H3 期权（受控实验）。分别给收入占比、资源占比、里程碑与终止条件。
- **输出**：增长组合图 + 资源再分配建议。
- **陷阱**：H3 无终止条件变成长期消耗；H1 现金流被 H2 挤占而不自知。
- **关联**：P3 · 2.4、3.2。

### T1.4 价值驱动树与对标
- **步骤**：把 ROIC / EVA 拆到 `收入 × 利润率 × 资产周转率`，再拆到经营驱动（价格、销量、成本动因、营运资本天数）；对每个驱动标注可控性、领先指标与责任中心。
- **输出**：价值驱动树 + 前 3 个杠杆与量化空间（给区间，不给虚假点估计）。
- **陷阱**：只做同比不做驱动分解；把不可控宏观因素写进 KPI。
- **关联**：P2/P3 · 2.5。

> 可选补充：7S（战略/结构/制度/共享价值观/风格/人员/技能）用于转型一致性体检；五力与竞争矩阵用于行业结构；假设驱动法用于时间紧、数据少的场合。

## S2 · 资本与投资

### T2.1 DCF / 企业价值（含公式）
```
FCF   = EBIT × (1 − t) + D&A − CapEx − ΔNWC
WACC  = E/(D+E) × Re + D/(D+E) × Rd × (1 − t)
Re    = Rf + β × ERP (+ CRP 国家风险溢价，跨境时单列)
TV₁   = FCF_{n+1} / (WACC − g)            # 永续增长法
TV₂   = EBITDA_n × Exit Multiple          # 退出倍数法
EV    = Σ_{t=1..n} FCF_t/(1+WACC)^t + TV/(1+WACC)^n
Equity = EV − 净债务 + 非经营性资产 − 少数股东权益 − 或有负债
```
- **输入**：3–5 年经营预测、税率、资本结构、可比公司、辖区风险参数、**每个假设的来源与时点**。
- **步骤**：① 分开预测经营与融资 ② 两种 TV 交叉验证 ③ WACC×g、WACC×倍数双维敏感性 ④ 三情景（基准/上/下）并给概率权重（权重须标 `[假设]`）⑤ 反向估值：当前价格隐含了什么增长假设。
- **输出**：估值区间（非单点）+ 敏感性表 + 关键假设清单 + 反转条件。
- **陷阱**：g ≥ WACC；用单一 WACC 覆盖多辖区多业务；终值占比 >70% 却不披露；把预测写成事实；忽略股份支付、租赁、养老金与或有负债。
- **关联**：P2/P3/P4 · 2.1、2.5、4.4。

### T2.2 相对估值与可比性检验
- **步骤**：选可比集合 → 统一口径（EV/EBITDA、P/E、P/B、EV/Sales 各自适用条件）→ 调整会计政策、周期位置、资本结构与一次性项目 → 给分位数区间与离群解释。
- **陷阱**：用亏损期 P/E；跨辖区不调整会计准则与税率；「行业平均」掩盖结构性差异。
- **关联**：P2/P4 · 2.1、4.4。

### T2.3 情景、蒙特卡洛与反向压力测试
- **步骤**：① 定义 3–5 个宏观/行业状态 ② 明确驱动变量分布与相关性（**相关性假设必须显式**）③ 传导到现金流与 covenant ④ 输出分位数而非均值 ⑤ **反向压力测试**：反推「什么组合会让本金/评级/流动性失守」。
- **输出**：情景矩阵 + 分位数分布 + 触发阈值 + 应急预案。
- **陷阱**：变量独立假设在危机中失效；只测温和下行情景；无触发阈值导致报告无人行动。
- **关联**：P3/P4 · 2.4、2.5。

### T2.4 风险预算、VaR / CVaR 与投后监控
- **步骤**：风险预算自上而下分配到因子/策略 → 度量（VaR 给置信度与持有期，CVaR/Expected Shortfall 补尾部）→ 设限与止损 → 月度归因（配置 vs 选券/选项目）→ 投后 KPI 与保护性条款联动。
- **陷阱**：只看波动率不看流动性与尾部；VaR 未标置信度/持有期；把历史窗口当未来分布。
- **关联**：P4 · 2.1、2.5。

### T2.5 Term Sheet 与交易保护清单
- **核对项**：估值（投前/投后）、清算优先与参与权、反稀释、董事会席位与保护性条款、对赌与回购、优先认购/共同出售/拖售、锁定期、竞业与关键人、信息权、退出安排、管辖与争议解决。
- **输出**：条款风险矩阵（经济 / 控制 / 退出 / 合规 四栏）+ 谈判优先级。
- **陷阱**：只谈估值不谈优先权；对赌条款与会计处理、税务后果未联动审阅。
- **关联**：P4 · 2.5、4.4。

## S3 · 银行与信贷

### T3.1 融资结构比选
- **维度**：成本（全口径 APR，含费用与担保）｜期限与还款曲线｜契约约束（covenant）｜抵押与增信｜币种与利率基准｜税务与跨境可汇性｜再融资窗口。
- **输出**：加权评分矩阵 + 敏感性（利率 +200bp、收入 −20%）。
- **陷阱**：只比名义利率；忽略 covenant 的连锁违约与交叉违约条款。

### T3.2 偿债与流动性指标
```
DSCR = 可用于偿债的现金流 / 当期本息
ICR  = EBIT / 利息费用
LLCR = 项目存续期可用现金流现值 / 未偿债务
流动性缺口 = 未来 13 周现金流出 − (可用现金 + 已承诺未提用额度)
```
- **步骤**：滚动 13 周现金流 → 压力情景 → covenant headroom（安全垫）→ 触发式补救动作。
- **陷阱**：用年度预算代替 13 周滚动；忽略额度提取条件与集中度到期日。
- **关联**：P2/P4 · 2.5。

## S4 · 学术与宏观

### T4.1 宏观传导链
- **步骤**：政策/外部冲击 → 利率与汇率 → 融资成本与贴现率 → 需求与成本 → 现金流与估值 → 契约与披露后果。每一环标注 `[事实]`/`[假设]` 与时滞。
- **输出**：传导链图 + 三个可监测的领先指标。
- **陷阱**：把长期均衡结论直接用于短期决策；忽略政策时滞与辖区制度差异。

### T4.2 制度与监管差异表
- **核对维度**：会计准则与披露口径、税务与预提、资本管制与外汇、数据跨境、行业准入、上市与退市规则、审计与鉴证责任、争议解决。
- **输出**：辖区差异对照表 + 必须外部复核的红旗项。
- **陷阱**：以「国际惯例」替代具体辖区核查；未标注法规生效时点。
- **关联**：P4 · 2.2。

## S5 · 产业与全球财税

### T5.1 本量利 / 作业成本 / 成本动因
```
盈亏平衡量 = 固定成本 / (单价 − 单位变动成本)
边际贡献率 = (单价 − 单位变动成本) / 单价
```
- **步骤**：识别成本动因 → 按作业归集 → 区分可避免/不可避免成本 → 与定价和产能决策联动。
- **陷阱**：把固定成本当变动成本做短期决策；分摊口径与管理决策无关。

### T5.2 全球税务筹划合规框架
- **方法**：功能—资产—风险（FAR）分析 → 选择转让定价方法（CUP 可比非受控价格 / RPM 再销售价格 / Cost Plus 成本加成 / TNMM 交易净利润法 / PSM 利润分割法）→ 同期资料与文档 → 预约定价安排可行性 → BEPS 双支柱影响（全球最低税、征税权分配）→ 与关务、外汇、资金池联动。
- **输出**：结构图 + 方法选择理由 + 文档清单 + 风险红旗。
- **硬边界**：**仅处理合法筹划**。实质重于形式；不得协助隐匿收入、虚构交易、伪造凭证、滥用税收协定、规避申报或规避制裁。任何方案须经辖区持牌税务/法律专业人士复核。
- **陷阱**：先定税率目标再倒推架构；忽略经济实质与常设机构风险；把「筹划」与「逃税」混用。
- **关联**：P4 · 2.2、4.4。

### T5.3 合并报表与内控
- **核对项**：控制判断与合并范围、内部交易抵销、外币折算、少数股东权益、商誉与减值、金融工具分类、关联方披露；内控按 COSO 五要素（控制环境、风险评估、控制活动、信息与沟通、监督）设关键控制点与穿行测试。
- **陷阱**：AI 自动生成分录绕过复核；关键控制点无留痕。
- **关联**：P4 · 2.1、4.4。

## S6 · 数字与 AI 治理

### T6.1 AI 治理最小闭环（对应 R!SE 2040「AI 鉴证框架」）
```
① 清单登记  模型/用途/数据/责任人/风险等级
② 数据血缘  来源→口径→变换→输出，可回溯
③ 模型卡    能力边界、训练数据范围、已知失效模式、适用与禁用场景
④ 验证门    事实核验、引用强制、置信度阈值、抽样人工复核、对抗测试
⑤ 人类在环  高风险输出必须有人类签核（Human in the Lead）
⑥ 留痕      提示、版本、输出、复核人、处置结果
⑦ 监控      漂移、异常、幻觉率、误拒率，设停用阈值
```
- **输出**：AI 治理矩阵 + 验证门清单 + 事件响应预案。可参照 NIST AI RMF 的 Govern / Map / Measure / Manage 四职能组织。
- **陷阱**：把「有人看过」当作验证；无停用阈值；日志不可审计；把 LLM 输出直接写入财报或申报数据。
- **关联**：P4 · 2.1、2.2、4.1、4.3。

### T6.2 数据质量与鉴证扩展
- **步骤**：口径字典 → 完整性/准确性/及时性/一致性规则 → 异常检测 → 对非财务数据源（HR、ESG、供应链、销售）建立可鉴证链路 → 出具受限保证结论前明确鉴证范围与责任边界。
- **陷阱**：鉴证范围与客户期望不一致；未说明保证程度。
- **关联**：P4 · 4.2、4.3。

### T6.3 网络与韧性
- **核对项**：身份与权限最小化、备份与恢复演练（RTO/RPO）、第三方与云依赖、单点故障、勒索场景下的财务连续性、数据与模型供应链。
- **关联**：P4 · 2.5、4.3。

## S7 · 组织与人才

### T7.1 能力盘点与 9-box
- 以模块 02 的 18 项能力举证评分为输入，按「当前表现 × 潜力」落格，输出差异化动作（轮岗、导师、项目历练、继任），**不以主观印象代替举证**。

### T7.2 变革阻力诊断
- **步骤**：用转型分布曲线定位（领导者/快速跟随者/风险群体）→ 点名阻力（对 AI 替代的恐惧、文化惯性、对传统商业模式与部门结构的依恋）→ 识别受益者与受损者 → 设计激励与沟通 → 设领先指标。
- **依据**：报告明确指出「转型停滞不是因为缺乏智慧，而是因为安逸」；**说出阻力，就能削弱它的力量**。
- **关联**：P1/P3 · 3.1、1.5。

### T7.3 知识转移设计
- **组合**：AI 捕获系统 + 机构记忆「智慧数据库」 + 代际培训 + 导师制/反向导师制 + AI 模拟培训环境（应对体验式学习路径消失）。
- **关联**：P3 · 3.3、1.3。

## S8 · 法律与对抗性审查

### T8.1 红队反驳（强制动作）
- **格式**：`如果 [条件]，则 [结论] 失效，因为 [机制]；观测指标 [X]，阈值 [Y]`。
- **要求**：每条 L1 以下结论至少 1 条；重大决策至少 3 条（事实层 / 假设层 / 执行层各一）。
- **输出**：反驳清单 + 反转触发条件 + 监测责任人。
- **陷阱**：红队由方案提出者自己担任；反驳不可观测、无阈值。
- **关联**：P4 · 2.1、2.2。

### T8.2 兵棋推演 / OODA
- **步骤**：定义己方、对手（竞争者、监管、市场、供应方）与中立方的目标与可用动作 → 设定 2–3 轮回合 → 每轮按 **Observe → Orient → Decide → Act** 记录信息、判断偏差与行动 → 复盘「哪一轮因信息滞后而失先手」。
- **输出**：对手行动矩阵 + 己方预案 + 领先观测点。
- **陷阱**：把对手写成静态背景；只推演己方最优路径。
- **关联**：P2/P3 · 2.4、2.5。

### T8.3 FMEA 与反向压力测试
```
RPN = 严重度(S) × 发生度(O) × 可探测度(D)   # 1–10 打分，须记录打分依据
```
- 对高 RPN 项强制设计预防/探测控制；反向压力测试回答「要怎样才会失败」，而非「跌 10% 会怎样」。
- **关联**：P4 · 2.5。

### T8.4 法律尽调红旗清单
- 主体与授权、重大合同与变更控制、担保与或有负债、知识产权与数据权属、劳动关系与竞业、诉讼与合规调查、关联交易、许可与资质、税务争议、制裁与出口管制、争议解决与管辖。
- **输出**：红旗表 + 交割前提/赔偿条款建议（**须由执业律师出具正式意见**）。
- **关联**：P4 · 2.2。

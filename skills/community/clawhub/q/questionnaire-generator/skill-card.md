## Description:

Generate standardized usability and human factors questionnaires (SUS, ASQ, SEQ, NASA-TLX, UEQ, SUS, CSUQ, etc.) with scoring instructions for UX coursework.

This skill is ready for commercial/non-commercial use.

## Use Case:

Students, UX practitioners, and human-factors evaluators use this skill to select and generate standardized questionnaires for usability testing, subjective assessment, course projects, and product experience evaluation. It provides questionnaire items, response instructions, scoring methods, interpretation thresholds, and testing suggestions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Questionnaire results can be misleading if a scale is selected without matching the evaluation goal.

Mitigation: Clarify whether the assessment targets overall usability, task ease, cognitive workload, user experience, or satisfaction before recommending a questionnaire.

Risk: Packaged documentation is mostly in Chinese, which may affect users expecting another language.

Mitigation: Ask for or follow the user's preferred output language and review translated questionnaire wording before using it in formal studies.

Risk: Changing standardized questionnaire wording, scoring direction, or scale options can reduce validity.

Mitigation: Keep standardized items and rating scales intact, and verify scoring formulas and interpretation thresholds before deployment.

## Description:

Plans functional, negative, contract, authentication, validation, error, and non-functional tests for REST or GraphQL APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[mohitagw15856](https://clawhub.ai/user/mohitagw15856)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and QA engineers use this skill to create API test plans from endpoint briefs, API descriptions, or contracts. It helps cover happy paths, validation, authentication, authorization, negative cases, schema checks, status codes, setup, and non-functional notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: API briefs, auth rules, and test data can contain credentials, tokens, or sensitive business details.

Mitigation: Provide sanitized API descriptions and avoid sharing live credentials or production-only data when using the skill.

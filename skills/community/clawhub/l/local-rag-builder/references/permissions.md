# 权限说明 — local-rag-builder

## 权限概述

本技能需要以下系统权限以完成 RAG 系统搭建和管理。

| 权限类别 | 权重 | 涉及脚本 | 说明 |
|---------|------|---------|------|
| 文件系统写入 | 30% | 全部 | 创建虚拟环境、写入配置、保存模型、创建向量库 |
| 网络访问 | 20% | rag_env_setup.py, embedding_model_manager.py | 下载 pip 包、下载嵌入模型 |
| 文件删除 | 10% | embedding_model_manager.py, knowledge_base_manager.py | 删除模型、删除知识库 |
| 子进程调用 | 20% | rag_env_setup.py, embedding_model_manager.py | 执行 pip install、运行模型下载脚本 |
| 敏感路径访问 | 20% | 全部 | 读取/写入 skills/ 下的技能数据目录 |

## 详细权限说明

### 文件系统写入（权重 30%）

**涉及操作**：
- 创建 `.standardization/local-rag-builder/data/` 下的子目录
- 写入配置文件 `rag_config.json`
- 保存嵌入模型文件
- 持久化向量数据库文件（chroma）
- 保存 Prompt 模板文件

**风险等级**：低 — 所有写入均在 skill 的数据目录内

### 网络访问（权重 20%）

**涉及操作**：
- pip install 从 PyPI 下载包
- 从 ModelScope / HuggingFace 下载嵌入模型
- 连接本地/远程 LLM API

**风险等级**：低 — 仅连接预定义源或用户指定的地址

### 文件删除（权重 10%）

**涉及操作**：
- 删除下载失败的模型目录
- 删除用户指定的知识库
- 重置配置时清空配置

**风险等级**：低 — 所有删除操作需用户显式确认

### 子进程调用（权重 20%）

**涉及操作**：
- 调用 pip install 安装包
- 创建 Python 虚拟环境
- 执行模型下载脚本

**风险等级**：低 — 仅执行标准的 Python 包管理操作

### 敏感路径访问（权重 20%）

**涉及操作**：
- 读取 skills/.standardization/ 下的数据目录
- 配置文件读写

**风险等级**：低 — 仅访问技能自身的数据目录

## 权限权重计算

| 维度 | 权重 | 实际值 | 加权 |
|------|------|--------|------|
| 敏感信息访问 | 40% | 0% (不访问 credentials/token) | 0 |
| 关键位置写入 | 30% | 30% | 0.09 |
| 网络访问 | 20% | 20% | 0.04 |
| 文件删除 | 10% | 10% | 0.01 |
| **总计** | **100%** | | **0.14 (低风险)** |

## 安全建议

1. 首次运行建议在网络可信环境下执行 `--auto-install`
2. 模型下载如遇网络问题，可手动下载后通过 `--check` 验证
3. 知识库数据安全由本地文件系统保障，注意定期备份 `data/kb/` 目录

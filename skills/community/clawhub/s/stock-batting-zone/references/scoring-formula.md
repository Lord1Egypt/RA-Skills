# 五因子评分公式详解

## 公式

```
击球意愿 = 股息率×30% + PE低估×15% + PB低估×15% + ROE×20% + 安全性×20%
```

## 因子详解

### 1. 股息率得分（30%）

```
if 股息率 <= 6%:   得分 = 股息率 / 6 × 100
if 6% < 股息率 <= 8%: 得分 = 100 - (股息率-6) × 10
if 股息率 > 8%:    得分 = max(80 - (股息率-8) × 10, 50)
```

甜蜜区 3-6%，超过 6% 打折，超过 8% 封顶（可能有风险）。

### 2. PE 低估得分（15%）

```
得分 = 100 - PE百分位
```

PE 百分位越低，说明当前估值越便宜。

### 3. PB 低估得分（15%）

```
得分 = 100 - PB百分位
```

同理，PB 百分位越低越便宜。

### 4. ROE 得分（20%）

```
得分 = min(ROE / 25 × 100, 100)
```

25% ROE = 满分。ROE 越高，盈利能力越强。

### 5. 安全性得分（20%）

**非银行 — 分红覆盖率（FCFF / 总分红）：**

| 覆盖率 | 得分 | 含义 |
|---|---|---|
| ≥2x | 100 | 非常安全 |
| 1.5x~2x | 80 | 安全 |
| 1x~1.5x | 60 | 基本安全 |
| 0.5x~1x | 30 | 需关注 |
| <0.5x | 10 | ⚠️ 危险 |

**银行 — 派息率（分红 / EPS）：**

| 派息率 | 得分 | 含义 |
|---|---|---|
| <30% | 100 | 保守，留存多 |
| 30%~50% | 70 | 适中 |
| 50%~70% | 40 | 偏高 |
| >70% | 20 | 激进 |

## 选股逻辑

1. **高股息**：年度分红(中期+末期) / 股价 ≥ 3%
2. **低估值**：PE/PB 百分位 < 50%
3. **强盈利**：ROE > 10%（非银行），> 8%（银行）
4. **分红可持续**：非银行覆盖率 ≥ 1x，银行派息率 < 50%
5. **行业分散**：每个行业最多 2 只

## 银行股取舍原则

四大行高度同质化，选一个时优先：
- **ROE 最高** → 盈利能力强
- **派息率最低** → 留存多、增长潜力大、分红安全边际高
- **PB 分位最低** → 估值便宜

## 已排除标的及原因

| 标的 | 排除原因 |
|---|---|
| 工商银行 | PB分位50%最贵，ROE最低(9.45%) |
| 农业银行 | 派息率最高(32%)，留存最少 |
| 中国银行 | ROE最低(8.94%)，无突出优势 |

## Description:

百度图片下载按关键词从百度图片搜索批量下载图片到本地目录，使用零依赖 Node.js 脚本获取结果并保存命名后的图片文件。

## Use Case:

External users and developers use this skill to collect batches of image files from Baidu Image Search for a provided keyword, choosing thumbnail, middle, or original image sources and an output directory.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The local Node script makes outbound requests to Baidu and image-origin hosts and follows untrusted image URL redirects.

Mitigation: Run it only in a network environment where internal services and metadata endpoints are not exposed, and prefer the default thumb or middle source.

Risk: Large counts or broad custom output paths can consume substantial disk, memory, and network resources.

Mitigation: Keep download counts small, use a bounded output directory, and review any custom output path before execution.

Risk: Downloaded image files come from search results and third-party origin hosts.

Mitigation: Review and scan downloaded files before using them in downstream workflows.

# 课程筛选细则

用于判断免费课程或证书是否值得制作分享素材。所有易变信息在制作当日以官方页面为准。

## 八项检查

| 项目 | 核验方式 |
|---|---|
| 是否真正免费 | 完整走一次注册、学习、测验和领凭证流程，检查订阅或试用门槛 |
| 时长 | 对照官方说明并抽查目录 |
| 凭证类型 | 以实际完成后拿到的证书或徽章为准 |
| 简历/档案价值 | 检查是否提供可验证凭证或添加到档案的入口 |
| 截止与改版 | 查看官方公告和页面通知 |
| 学习门槛 | 核验基础要求、语言、代码要求 |
| 品牌可信度 | 优先采用可核验的课程出品方 |
| 访问限制 | 核验地区、账号、网络和支付要求 |

## 评分

每项 0、0.5 或 1 分：

- 6.5–8：优先制作
- 4.5–6：补充证据后再决定
- 0–4：不建议制作

必须记录每项证据 URL、核验日期和实际体验。不得把徽章写成证书，不得把限时、地区性或需订阅的优惠写成无条件免费。

## 素材与发布边界

- 只使用自己有权分享的截图和凭证。
- 证书中的姓名、邮箱、编号和账号先打码，再进入拼图或封面。
- 默认不添加账号水印、推广 CTA、短链，也不自动发布。
- 上述动作只能在用户明确确认本次具体内容后执行。
- 课程结论和文案先作为草稿交付，由用户复核事实与隐私。

## Description:

Turn existing project assets into a submission-ready academic paper. Use when the task involves CFP alignment, evidence scoping, abstract selection, outline expansion, figure planning, reviewer-style quality gates, submission packaging, or post-submission archiving. Coordinates academic-research-writer, paper-validator, and prompt-to-drawio.

This skill is ready for commercial/non-commercial use.

## Known Risks and Mitigations:

Risk: The workflow depends on unpinned third-party companion skills from mutable sources.

Mitigation: Review and pin companion skill versions before installation, and avoid using skills@latest for this workflow.

Risk: Paper-production work may expose secrets, private project data, or unpublished evidence from the workspace.

Mitigation: Run the skill in a workspace that excludes secrets and unrelated private data, and review generated archives before submission.

Risk: Generated drafts or figures may misstate evidence or blur planned work with completed results.

Mitigation: Keep original screenshots and source evidence, disclose meaningful edits, and run reviewer-style quality gates for claim-evidence alignment.

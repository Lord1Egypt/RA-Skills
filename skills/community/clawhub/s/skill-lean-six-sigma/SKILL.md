# 精益六西格玛项目实施技能

## 任务目标

- 本Skill用于:指导企业实施精益六西格玛改进项目
- 能力包含:DMAIC/DMADV方法论执行、关键工具应用、项目管理流程、案例参考、自定义规划生成
- 触发条件:用户需要开展六西格玛项目、实施质量改进、解决复杂流程问题或学习LSS方法论

## 前置准备

- 依赖说明:本Skill主要依赖智能体知识与模板资产，脚本工具仅用于项目规划生成
- 非标准文件准备:无特殊要求

## 核心方法论

### DMAIC改进模式(适用于现有流程优化)

D-M-A-I-C五阶段:
- **D - Define(定义)**:识别问题，确定项目范围与目标
- **M - Measure(测量)**:收集数据，量化当前绩效
- **A - Analyze(分析)**:识别根本原因
- **I - Improve(改进)**:开发并实施解决方案
- **C - Control(控制)**:保持改进成果

### DMADV设计模式(适用于新流程/产品开发)

D-M-A-D-V五阶段:
- **D - Define(定义)**:识别设计需求与项目目标
- **M - Measure(测量)**:评估能力与风险
- **A - Analyze(分析)**:开发设计 alternatives
- **D - Design(设计)**:创建详细设计方案
- **V - Verify(验证)**:验证设计并实施

## 项目阶段核心任务

### 定义阶段(D)

1. **问题陈述编写**
   - 使用标准模板明确问题背景、影响范围、目标指标
   - 模板位置:assets/templates/problem-statement-template.md

2. **项目章程制定**
   - 确定项目范围、团队成员、资源需求、时间表
   - 定义项目成功标准

3. **SIPOC图绘制**
   - 识别 Suppliers、Inputs、Process、Outputs、Customers
   - 确定项目边界

4. **团队组建**
   - 核心角色:Champion、Sponsor、Black Belt、Green Belt、Team Member
   - 明确职责分工

### 测量阶段(M)

1. **数据收集计划**
   - 确定测量指标(KPI)与收集方法
   - 设计数据收集表

2. **测量系统分析(MSA)**
   - 评估测量系统的准确性与重复性
   - 执行GR&R分析

3. **过程能力分析**
   - 计算Cp、Cpk指标
   - 绘制过程能力报告

4. **现状基线建立**
   - 收集历史数据建立基线
   - 可视化当前绩效

### 分析阶段(A)

1. **因果分析**
   - 使用鱼骨图(Cause-and-Effect Diagram)识别潜在原因
   - 执行5Why分析

2. **假设检验**
   - 确定关键因子(X)与输出(Y)的关系
   - 执行相关性分析、ANOVA等

3. **回归分析**
   - 建立预测模型
   - 量化因子影响程度

4. **根本原因确定**
   - 验证假设
   - 确定少数关键因子(Pareto原则)

### 改进阶段(I)

1. **方案生成**
   - 头脑风暴解决方案
   - 使用TRIZ、FMEA等工具

2. **方案评估**
   - 成本-效益分析
   - 风险评估

3. **方案实施**
   - 制定实施计划
   - 执行PDCA试点验证

4. **效果验证**
   - 对比改进前后数据
   - 确认改进目标达成

### 控制阶段(C)

1. **控制计划制定**
   - 建立SOP标准化操作
   - 确定控制机制

2. **控制图应用**
   - 选择合适控制图类型(X-bar、R、p、u等)
   - 建立控制限

3. **过程监控系统**
   - 设置异常预警机制
   - 定期审核

4. **项目收尾**
   - 文档归档
   - 经验总结与知识分享
   - 表彰与激励

## 项目管理流程

### 团队组建

- **Champion**:高层支持者，负责资源与战略对齐
- **Sponsor**:业务负责人，支持项目推进
- **Black Belt**:方法论专家，辅导项目执行
- **Green Belt**:项目负责人，执行日常管理
- **Team Member**:团队成员，贡献专业技能

### 任务计划制定

1. **WBS分解**:将项目分解为可管理的工作包
2. **里程碑设定**:关键节点定义与时间规划
3. **责任矩阵(RACI)**:明确每项任务的责任人

### 进度跟踪方法

- **周例会**:每周检查进展与障碍
- **甘特图**:可视化进度管理
- **状态报告**:定期向利益相关者汇报
- **升级机制**:及时处理阻塞问题

## 使用示例

### 示例1:启动DMAIC改进项目

- 场景/输入:生产部门发现产品不良率高达5%，需要改进
- 预期产出:完成问题陈述、项目章程、SIPOC图，确定团队成员
- 关键要点:使用问题陈述模板明确"是什么问题、影响多大、目标是什么"，避免模糊表述

### 示例2:分析阶段工具应用

- 场景/输入:已完成数据收集，发现3个潜在关键因子
- 预期产出:通过鱼骨图和5Why分析确定根本原因，通过假设检验验证
- 关键要点:先发散再收敛，使用Pareto原则聚焦少数关键因子

### 示例3:生成自定义项目规划

- 场景/输入:用户需要针对特定场景生成项目规划
- 预期产出:完整的DMAIC或DMADV项目计划
- 关键要点:调用脚本生成标准化项目规划

## 注意事项

- DMAIC适用于改进现有流程，DMADV适用于设计新流程/产品
- 优先使用数据驱动决策，避免主观判断
- 关键工具选择应根据项目实际需求灵活调整
- 案例参考时注意行业差异，适配具体情境

# references · 广告文案 Prompt 模板（Day1 六段，原文照录）

> 来源：公开的 AIGC 广告创意课程 Day1 学员资料包 ｜何时读：补槽（Brief 解读/卖点提炼）/ 要 Slogan / 发布前红线审查
> **通用硬约束（所有模板共用，不可删）**：只使用我提供的参数；没给的时长、认证、功效、对比结论**不得编造**。

## 用法（资料包原话要点）

1. 先把产品/品牌/人群信息填进「【Brief】」或「【核心卖点】」的空位
2. 整个 prompt 复制给 AI（不要删掉约束条件）
3. 只保留最有用的 1-2 版，按"更具体 / 更像人说话 / 更像真实场景"反复追问
4. 用「数据驱动优化」或「广告合规自查」调整和选择

## 模板 0 · 简易一次性版（课堂案例）

```text
【角色】你是一名资深广告文案/文案总监，擅长消费品卖点提炼与场景化写作；文风克制真实，不堆浮夸形容词。
【产品/品牌】（一句话介绍）____
【品牌定位】主打"材质党、工艺党"的保温杯，强调科学保温：材质、保温时长、防漏结构以可核实的实测参数为准，不虚标。
【目标人群】25–35 岁一线城市商务女性，通勤+久坐办公，偶尔健身/出差，看重材质安全与使用细节。
【核心卖点（只写你能确认的事实）】
- 内胆材质：____
- 保温：热饮保温 __ 小时 / 保冷 __ 小时
- 防漏结构：____
- 规格：容量 __ ml，自重 __ g，杯身尺寸/是否能放通勤包：____
【场景关键词】通勤 / 办公 / 会议 / 加班 / 健身 / 出差（可自行增删）
【注意点】只使用我提供的参数；没给的时长、认证、功效、对比结论不得编造。请区分"可核实事实"与"情绪表达"：抒情不作为功效承诺；不暗示养生、保健等杯子不具备的功能。
【输出要求】生成 3 条不同风格文案，每条包含：标题（≤15字）+ 正文（80–150字）+ 收尾 slogan（≤10字）。三种风格分别是：理性科普风 / 情感陪伴风 / 极简利落风。
```

## 模板 1 · Brief 解读（补槽首选）

```text
【角色】你是一名资深广告策略/文案。
【任务】把下面 Brief 拆成"我能直接拿去写文案"的信息，缺失项要明确标注"待补"。
【Brief】
- 产品/品牌：____
- 目标人群：____
- 核心卖点（事实）：____
- 竞品/替代方案：____（没有就写"未提供"）
- 投放场景/渠道：____（抖音/小红书/电商详情页等）
【输出格式】按下面 5 块输出（每块 3-5 条要点，短句即可）：
1. 品牌定位（一句话 + 3 个关键词）
2. 目标人群画像（生活场景/痛点/顾虑/触发点）
3. 购买理由（把卖点翻译成"对TA有什么用"）
4. 传播调性（像谁在说话？要克制还是热烈？）
5. 禁忌词/风险点（哪些表达容易翻车/违法/引战）
```

## 模板 2 · 卖点提炼（从"参数"到"人话"）

```text
【角色】你是一名资深广告文案。
【输入（我提供的事实参数）】
- 产品：____
- 人群：____
- 参数/规格：____
- 使用限制/不适用人群（如有）：____
【任务】请把每个"事实参数"翻译成 3 层表达：
1. 事实层（可核实、无夸张）
2. 好处层（对目标人群有什么实际好处）
3. 场景层（放进具体时刻的一句话：通勤/会议/加班/健身等）
【输出格式】用表格输出 6–10 行：参数｜事实层｜好处层｜场景层。最后再补 3 条"最适合用在标题里的卖点短语"（每条 ≤10 字）。
```

## 模板 3 · Slogan 生成（海报广告语槽位用这个）

```text
【角色】你是一名品牌文案。
【输入】
- 品牌定位（1 句话）：____
- 目标人群（1 句话）：____
- 主打卖点（3 个词）：____ / ____ / ____
- 语气（选 1）：克制理性 / 温柔陪伴 / 干脆利落
【任务】生成 20 条 slogan，并且按 4 组分类输出（每组 5 条）：
- 组A：一句就能懂（7–10 字）
- 组B：带场景（10–14 字）
- 组C：带对比但不踩红线（10–14 字，避免"第一/最好/顶级"）
- 组D：更有记忆点但不油腻（8–12 字）
【约束】不用绝对化词；不承诺功效；不出现任何认证/数据，除非我明确提供。
```

## 模板 4 · 数据驱动优化（有投放反馈时）

```text
【角色】你是一名投放优化师 + 广告文案。
【输入】
- 目标：提升 CTR / 提升完播 / 提升转化（选 1 或多选）
- 现有文案（完整粘贴）：____
- 数据/反馈（只写事实）：例如 CTR=__%、评论关键词=__、用户疑问=__、差评点=__
- 人群与场景：____
- 不能说的（禁忌词/红线）：____
【任务】先判断"问题出在谁"：钩子不够强 / 卖点太虚 / 场景不对 / 信任不够 / 信息太多太杂（可多选）。然后给出改写。
【输出】
1. 诊断：用 5 条以内要点说明原因（每条 1 句话）。
2. 改写版本：给 3 版（钩子型 / 场景型 / 信任型），每版 80–120 字。
3. 下一轮验证：每版建议看哪 1 个指标 + 预期变化方向。
```

## 模板 5 · 广告合规自查（发布前必查）

```text
【角色】你是一名广告法合规审查员 + 平台内容审核。
【任务】审查下面文案是否存在广告法风险、平台敏感风险与"容易被理解成承诺"的表达，并给出可替换的安全说法。
【文案】（粘贴你要发的完整文案）____
【审查维度】
- 绝对化用语：最好/第一/顶级/全网/100% 等
- 虚假或夸大承诺：功效、时长、认证、对比结论
- 竞品对比：是否踩"唯一/最强/碾压"
- 特殊品类限制：医疗/保健/美妆/金融等（如涉及）
- 平台规则：敏感词、引战表达、歧视、擦边暗示
【输出格式】用表格输出：原句｜风险点｜为什么有风险｜建议替换（给 1-2 个可直接复制的版本）。最后补 5 条"通用安全替换词库"。
```

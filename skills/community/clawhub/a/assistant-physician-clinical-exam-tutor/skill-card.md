## Description:

Assistant physician exam trainer focused on objective-choice drills, practical station simulation, scoring, and weak-point tracking.

This skill is ready for commercial/non-commercial use.

## Use Case:

Exam candidates and tutors use this skill for Chinese-language assistant physician clinical exam practice, including objective-choice drills, standardized-patient station simulation, SOP step checking, scoring, weak-point tracking, and rolling review planning.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Users may mistake exam tutoring output for real patient diagnosis or treatment guidance.

Mitigation: Use the skill only for exam practice; escalate real patient situations to licensed in-person clinical supervision.

Risk: Weak-point tracking may retain exam performance details when the host agent's memory features are enabled.

Mitigation: Avoid entering unnecessary personal data and review memory settings and retention before using longitudinal tracking.

## Description:

Supports academic research, close reading of papers, related-work discovery, encyclopedia lookup, and citation-chain tracing.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users, developers, and research analysts use this skill to search academic sources, read paper full text or sections, and trace references and citations while preparing literature reviews or research summaries.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Crawler fallback uses disguised browser automation and exposes the host environment to the browser process.

Mitigation: Run the skill in an isolated environment without cloud keys, repository tokens, or other sensitive environment variables, and prefer official API providers over crawler fallback.

Risk: Search queries, paper identifiers, titles, optional email identifiers, and API keys may be sent to selected academic services.

Mitigation: Avoid sending sensitive or confidential research queries, and provide API keys only through the intended environment variables or explicit CLI parameters.

Risk: Unpinned dependencies and external academic providers can change behavior or availability.

Mitigation: Pin dependencies before production use, handle provider failures explicitly, and rely on the skill's JSON success and error fields when deciding whether results are usable.

## Known Risks and Mitigations:

Risk: Maintainer publishing commands may run an unpinned ClawHub CLI while login or publish credentials are in scope.

Mitigation: Pin and verify the ClawHub CLI before running login or publish commands, following the security guidance.

Risk: Blindly copying the bundled global CSS can disable scrolling or text selection, or add expensive blur and animation effects to ordinary pages.

Mitigation: Merge only the CSS variables, utilities, and Tailwind tokens needed for the target UI, then test accessibility, responsiveness, scroll behavior, and performance.

## Description:

Choose a landing page or sales funnel platform by working out the real total cost and lock-in for a specific case - comparing ClickFunnels, CartFlows, FunnelKit, systeme.io, GoHighLevel, Shopify apps, hand-rolled pages and self-hosted open-source options.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users, marketers, agencies, developers, and operators use this skill to compare funnel and landing page platforms for a specific business case by evaluating total cost, lock-in, maintenance burden, data ownership, and migration trade-offs.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may present product-specific Autonnel guidance more strongly than a neutral platform comparison.

Mitigation: Treat Autonnel as one candidate option and compare it against the user's stated requirements, current pricing, licensing, support needs, and operational capacity before recommending it.

Risk: The skill suggests evaluating an unpinned Docker Compose setup from GitHub.

Mitigation: Before running it, verify the repository, release tag, compose file, image digests, exposed ports, mounts, and environment variables, then test only in an isolated environment.

## Description:

Design detailed SOUL.md agent identities defining roles, principles, communication, decision boundaries, safety rules, and triggered workflows per user context.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, team leads, and agent builders use this skill to draft SOUL.md persona files that specify an agent's role, operating principles, communication style, decision boundaries, safety rules, and triggered workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad trigger phrases may cause the skill to activate during general discussions about agent identity.

Mitigation: Review generated SOUL.md persona rules before using them as durable agent instructions.

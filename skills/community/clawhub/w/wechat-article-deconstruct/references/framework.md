# 拆解框架判据

本文件是 SKILL.md 维度 A、B 的详细判据，分析时对照使用。

## 维度 A · 思考路径判据

### A1 切入点

- **反差型**：开场摆一个自相矛盾的场景（两件同时发生却互相打架的事）。判据是文中出现"一边……一边……""听着别扭""同一行业同时发生"这类表述。
- **痛点型**：开场抛读者共同的困惑或焦虑。
- **数据型**：开场用一个反常识数字。

记录：切入现象是什么，属于哪型，原文依据。

### A2 拆词

判据：作者是否把一个笼统名词劈成两个指向相反的东西，从而把"要不要/有没有"的问题变成"是哪一种"的问题。

典型形态："缺人"拆成"便宜能上手的人"和"能扛事的人"；"加班"拆成"有效工时"和"表演性在场"。

记录：原词、拆成的两端、这个拆解把问题变成了什么。

### A3 中间层（题眼）

判据：作者是否在描述两级分化后，追问"中间那一段去哪了"。

常见三段回答结构：
1. 以前这段路是真的（过去的培养机制、时间跨度、出师标准）；
2. 现在这段路被拆了（工具替代、岗位合并、练手环节消失）；
3. 表面的机制还在（招聘广告画的晋升线、培训承诺），但现实往反方向走。

这一段通常是全文最有力的地方，要重点标注。

### A4 换维度

判据：作者是否在讲完一个维度后，横向切到另一个维度交叉验证，而不是顺着往下写。

常见切换：能力问题 → 权益问题；技术问题 → 制度问题；个体问题 → 结构问题。

识别信号：段落开头出现"换一个维度""同样……另一件事""把 X 拆开看"等转折。

### A5 收口

判据：结尾落在情绪还是结构。

- 结构化收口：用政策、新规、行业数据收尾，最后一句是一个冷静判断（例如"人还在干活，跟公司的关系却越来越短"）。
- 情绪化收口：用金句、呼吁、共鸣收尾。

记录：收口方式、最后一句原文、它把故事上升成了什么判断。

### A6 判断标准（重点提炼）

判据：作者用什么判据下结论。这类标准往往比具体结论更可迁移。

识别信号："凭什么……""之所以……是因为""关键看……"以及任何用来解释"为什么 A 比 B 值钱/稳定"的理由。

记录：标准本身的抽象表述 + 原文例句。

## 维度 B · 举证手法判据

### B1 材料类型清单

逐类填写三列：

| 材料类型 | 具体材料 | 引用方式 | 论证作用 |
|---|---|---|---|
| 行业/招聘信息 | | 密集罗列、精确数字、广告与实情并置 | 拆词、戳破话术 |
| 薪资/业务数字 | | 两端精确数字、中间无过渡 | 分层、显示趋势 |
| 人物案例 | | 具名 + 化名混用 | 让抽象结论有血肉 |
| 司法判例 | | 两案并置 + 自我纠偏 | 换维度、示范边界 |
| 政策条文 | | 只陈述不评论 | 结构收口 |
| 行业历史基准 | | 作为"过去"的对照系 | 让"消失"显出来 |

不只这六类，按文章实际归纳。关键是每类材料只顶一个论证环节。

### B2 七种引用手法

1. **精确数字**：写"2130"不写"两千出头"；写"26.1 万"不写"二十多万"。作用：制造现场感。
2. **并置不判断**：把矛盾的两样东西摆一起，不下"差距大"的结论，让读者自己得出。
3. **转述为主、引号给金句**：大部分用"他说/法院说"，引号留给作者自己的判断句。注意区分材料与观点。
4. **接口句**：跨行业材料进入时，用一句"这件事和本行的关系是……"把它合法化。
5. **具名 + 化名**：真名撑可信度，化名撑故事感。
6. **划边界**：用案例后主动说明可比性限制（"其实没法这么比，因为……"）。
7. **材料对应结构**：材料排布顺序 = 论证顺序，不复用、不堆砌。

### B3 Toulmin 还原

- **主张（Claim）**：全文要证明的核心结论。
- **证据（Evidence）**：支撑主张的事实、数字、案例。
- **推理（Warrant）**：从证据到主张的桥（往往是被省略的那句）。
- **限定（Qualifier）**：结论成立的条件或边界。
- **反驳（Rebuttal）**：作者主动引入的反面情况。

## 证据质量评估判据

逐项检查并如实回答：

- **出处**：材料有没有给出处？还是"招聘网站上""行业里说得更多""我翻了一圈"这类模糊来源？
- **跨行业拼接**：有没有把别的行业的案例接进来？接口句是什么？
- **结论性质**：是统计结论，还是"个案 + 数字"的观察性判断？

给出使用提醒：哪些方法骨架可以拿走，哪些数字必须二次核实。

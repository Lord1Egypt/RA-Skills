## Description:

Analyzes coding tasks by complexity, domain, scope, and risk, then recommends UCTS optimization tools and dispatch instructions for OpenClaw.

This skill is ready for commercial/non-commercial use.

## Publisher:

[muthukumaran-k-1](https://clawhub.ai/user/muthukumaran-k-1)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and coding agents use this skill to classify software tasks and choose an appropriate UCTS tool combination, model posture, and dispatch instruction.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may appear for many coding requests and suggest Claude Code or UCTS dispatch instructions, including implementation or shipping steps.

Mitigation: Review suggested classifications and dispatch instructions before acting, especially for implementation, security, or shipping workflows.

Risk: Task misclassification could route high-risk or security-sensitive work to an unsuitable optimization posture.

Mitigation: Apply the skill's risk overrides, including disabling compression for critical risk and adding careful or security review steps for high-risk security tasks.

## Description:

Connect two AI agents by private phone number so they can talk to each other and share files across computers or teammates. Use when the user asks to call another agent, let two Claude Code or Codex sessions talk directly, share a file between agents on different machines, or set up agent-to-agent communication with ForAgent.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and teams using Claude Code, Codex, or supported agent clients use this skill to connect agents for direct calls and file sharing across devices.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Calls and file transfers connect agents across devices, so a transfer could expose information to an unintended recipient.

Mitigation: Confirm the caller and recipient, and review each file before approving a transfer.

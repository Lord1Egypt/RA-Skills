This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and agents use this skill to help users create, customize, retrieve, and download Prezentit presentations through the Prezentit API.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Presentation generation consumes Prezentit credits, including paid credits on the user's account.

Mitigation: Check available credits, estimate slide cost, and get user confirmation before generating a presentation.

Risk: The skill requires a Prezentit API key for authenticated API calls.

Mitigation: Use only a Prezentit API key the user intends to share with the service, and avoid exposing it in generated output.

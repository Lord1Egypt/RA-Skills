## Description:

Set type for screen and print: measure, leading, tracking, optical sizes, weight axes, and the difference between display and text cuts.

This skill is ready for commercial/non-commercial use.

Designers, developers, and content teams use this skill to choose readable type settings, pair fonts, tune optical sizes and weights, and translate typographic principles into screen or print layout decisions.

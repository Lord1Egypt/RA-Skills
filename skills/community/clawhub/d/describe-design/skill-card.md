## Use Case:

Developers and engineers use this skill to investigate a selected codebase and create architecture documentation for a feature, component, or system.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill reads project files while analyzing a selected codebase.

Mitigation: Use it only on repositories the user is comfortable having analyzed.

Risk: Generated architecture documentation may be incomplete or misleading if the codebase exploration misses relevant components.

Mitigation: Review the proposed outline and draft before accepting the final document.

Risk: The skill can write the final Markdown document to disk.

Mitigation: Confirm the output path before writing, as required by the artifact workflow.

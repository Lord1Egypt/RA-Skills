## Description:

Provides structured analysis and decision support using 20 thinking frameworks, including critical thinking, first principles, red teaming, design thinking, and premortems.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Developers, analysts, product teams, and other agent users use this skill to apply structured reasoning frameworks to complex decisions, plans, trade-offs, and problem-solving tasks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Install guidance uses an unpinned npx @latest command, which can change the installer version used on a machine.

Mitigation: Use a trusted and pinned ClawHub CLI version when installing in sensitive or controlled environments.

Risk: The skill adds persistent reasoning templates that may activate on broad analysis or decision-making requests.

Mitigation: Review trigger behavior and framework outputs before relying on the analysis for consequential decisions.

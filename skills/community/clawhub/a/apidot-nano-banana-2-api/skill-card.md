## Known Risks and Mitigations:

Risk: APIDot API keys could be exposed if placed in browser code, logs, public repositories, screenshots, or chat output.

Mitigation: Keep APIDOT_API_KEY only in server-side environment variables or a backend secret manager.

Risk: Live API calls could create unintended APIDot usage or cost.

Mitigation: Require explicit user approval and a safe server-side environment before making live API calls.

Risk: Model-specific request fields, availability, limits, or commercial terms may change.

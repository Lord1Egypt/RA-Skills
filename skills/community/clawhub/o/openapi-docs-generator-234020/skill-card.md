## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to turn API documentation needs into concrete OpenAPI or Swagger documentation workflows, artifacts, checklists, analysis, code changes, or verification steps.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation wording may cause the skill to be applied to general API or developer-experience questions where OpenAPI documentation support is not the best fit.

Mitigation: Prefer explicit invocation for OpenAPI, Swagger, REST API documentation, or closely related documentation tasks.

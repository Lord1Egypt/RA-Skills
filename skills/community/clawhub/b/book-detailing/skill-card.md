## Use Case:

External users use this skill to find nearby detailing providers, check appointment availability, and create bookings through Lokuli's MCP service.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Booking can send personal contact details, location or ZIP code, provider selection, service selection, and appointment time to Lokuli's external MCP service.

Mitigation: Confirm the booking details and user consent before creating a booking.

## Description:

Frontend UI workflow for turning vague ideas, UI drafts, and feedback into buildable frontend plans and iteration steps.

This skill is ready for commercial/non-commercial use.

## Publisher:

[siegelioner](https://clawhub.ai/user/siegelioner)

### License/Terms of Use:

MIT

## Use Case:

External users, developers, founders, product managers, designers, and operators use this skill to turn vague UI ideas, drafts, or feedback into structured frontend briefs, design direction, build plans, review plans, iteration plans, and design records.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated frontend plans, briefs, and review guidance can be incorrect, incomplete, or misleading if the user's requirements are unclear.

Mitigation: Review generated planning artifacts before using them to guide implementation.

Risk: The workflow may ask an agent to create or update DESIGN.md in the project or feature root when frontend work is created or changed.

Mitigation: Review the generated design record like any other workspace file change before accepting it.

## Description:

This skill helps users build a structured knowledge system for an unfamiliar domain by scanning information sources, selecting anchor topics, creating a cognitive map, planning an entry path, and suggesting recurring follow-ups.

This skill is ready for commercial/non-commercial use.

## Publisher:

[shiyan521](https://clawhub.ai/user/shiyan521)

### License/Terms of Use:

MIT

## Use Case:

External users use this skill to quickly get started in a new domain and receive a prioritized source list, cognitive map, learning path, recurring review suggestions, and progress dashboard.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Recurring weekly or monthly tracking suggestions may create unwanted agent follow-ups.

Mitigation: Confirm that recurring follow-ups are desired before enabling or acting on them.

Risk: Recommended public information sources may be incomplete, outdated, or unsuitable for the user's goals.

Mitigation: Review recommended sources before relying on them.

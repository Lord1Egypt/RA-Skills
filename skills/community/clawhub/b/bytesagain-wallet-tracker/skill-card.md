## Use Case:

External users and developers use this skill as a reference guide for wallet tracking concepts, address standards, transaction troubleshooting, analytics performance, and wallet security practices. It prints guidance only and does not require credentials or network access.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Users may mistake the skill for a wallet application or transaction automation tool.

Mitigation: Present it as reference guidance only; do not use it to handle funds, sign transactions, or manage wallet credentials.

Risk: Wallet security examples could prompt users to expose sensitive secrets.

Mitigation: Do not paste real private keys, seed phrases, API keys, or wallet credentials into any example command or prompt.

Risk: The guidance mentions third-party explorers and analytics services that may have separate privacy, accuracy, and terms-of-use considerations.

Mitigation: Treat any manually visited explorer or analytics link as an external service and review it before sharing wallet addresses or transaction context.

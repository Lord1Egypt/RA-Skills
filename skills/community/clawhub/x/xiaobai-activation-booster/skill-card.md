## Description:

Skill Activation Booster - Fix the 40% activation problem. Optimize triggers, descriptions, and context so agents actually use your skills.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and skill authors use this guidance skill to improve when agent skills activate by auditing trigger phrases, descriptions, context signals, and activation tests.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Activation-rate and impact claims may not hold for every agent, runtime, or skill set.

Mitigation: Treat the claims as guidance and validate changes with representative activation tests before release.

Risk: Suggested trigger and description edits could make a skill activate too often or in the wrong context.

Mitigation: Review proposed changes, include anti-trigger tests, and scan the revised skill before deployment.

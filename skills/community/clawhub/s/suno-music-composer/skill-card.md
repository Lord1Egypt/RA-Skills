## Description:

SUNO音乐创作速查表 is a Chinese-language Suno music creation guide with 171+ meta-tags and a "skeleton + flesh" collaborative prompting framework.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and music creators use this skill to draft Suno song concepts, style prompts, Chinese arrangement explanations, meta-tagged lyrics, model recommendations, and iteration guidance.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate for broad music or prompt-writing requests.

Mitigation: Confirm the user wants Suno-focused songwriting or music-prompt guidance before applying the template.

Risk: The skill may answer in a fixed Chinese-language template even when the user expects a different format or language.

Mitigation: Adapt the response language and sections to the user's request while preserving the relevant Suno prompt details.

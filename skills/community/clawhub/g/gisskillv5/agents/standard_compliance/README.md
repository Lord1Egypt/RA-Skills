# Agent 4: 标准合规Agent (Standard Compliance)

> 全局唯一知识ID: GIS-AGENT-004
> 隶属: 上层多Agent编排引擎
> 触发条件: 质检通过 → 国标/行标合规验证

## 职责

1. 验证图层命名是否符合汇交规范
2. 验证字段定义是否匹配GB/T 20258数据字典
3. 验证坐标系是否为CGCS2000（国内项目）
4. 验证分类编码是否遵循GB/T 13923
5. 生成《标准合规检查单》

## 输入

| 参数 | 说明 | 必填 |
|------|------|------|
| data | 质检后的数据 | 是 |
| project_type | 项目类型（国土/地籍/管线/林业等） | 是 |

## 输出

- 合规检查单（含逐项判定结果）
- 不合规项清单+修正建议

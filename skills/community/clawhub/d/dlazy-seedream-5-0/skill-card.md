## Description:

Full version of the Doubao image model, generating 2K/3K/4K images from prompts and reference images. Suited to key visuals, posters and anything meant for large-format print.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

External users and creative professionals use this skill to generate high-resolution images for key visuals, posters, and large-format print from text prompts and optional reference images.

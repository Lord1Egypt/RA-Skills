## Use Case:

Developers and embedded engineers use this skill to check compatibility issues when migrating code between embedded platforms and to produce a migration risk report with recommendations and effort estimates.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Migration findings and effort estimates may be incomplete for a specific source or target embedded platform.

Mitigation: Review the report against platform documentation, compile on the target toolchain, and run functional tests before relying on the migration plan.

Risk: Chinese-language metadata and activation text may be harder to route or review in bilingual teams.

Mitigation: Add bilingual metadata or confirm that reviewers and users can evaluate the Chinese checklist and report output.

## Description:

Generate a narration script with voiceover, shot list, per-clip visual prompts, and music cues for a personal travel-story video or essay from a thought-flow master and the author's own photos.

This skill is ready for commercial/non-commercial use.

## Publisher:

[j3ffyang](https://clawhub.ai/user/j3ffyang)

### License/Terms of Use:

MIT-0

## Use Case:

External creators and agent users use this skill to turn a thought-flow master document and personal photos into a structured Simplified Chinese narration script for a travel-story video or essay. The generated script is intended to guide downstream video generation, not to generate video directly.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The workflow uses paths to personal photos, which may expose private or sensitive visual material to the agent's working context.

Mitigation: Use only photos intended for the project and review generated references before publishing or passing the script to a video workflow.

Risk: Generated narration could include incorrect or unverifiable factual claims if sources are weak or missing.

Mitigation: Require live source verification for factual claims, omit unsourced claims, and review cited sources before using the script in a video.

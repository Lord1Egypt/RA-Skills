## Description:

Guides structured help for Godot Project Checklist using clear templates, checks, and safe defaults for game development.

This skill is ready for commercial/non-commercial use.

## Use Case:

Game developers and agents use this skill to turn Godot project goals into concise plans, numbered checklists, next actions, and editable draft blocks without requesting private data.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Users may paste secrets or sensitive project data while asking for checklist guidance.

Mitigation: Request only a non-sensitive goal, optional constraints, and notes the user has rights to share; avoid passwords, OTPs, private keys, wallets, seeds, and session secrets.

Risk: Checklist guidance could be treated as final project authority even when a Godot project requires human review.

Mitigation: Keep outputs factual and reversible, prefer checklists over irreversible actions, and review proposed steps before applying them to a project.

## Description:

Provides INFJ-focused coaching prompts for growth, career, and learning conversations, switching between reflective questions and concrete action guidance.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users who identify as INFJ use this skill for self-reflection around growth, career, learning, analysis paralysis, focus, and action planning. It provides general coaching-style conversation and concrete action steps, not professional mental-health advice.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The package identity is inconsistent: security evidence notes the README installs intp-coach while the reviewed release is infj-coach.

Mitigation: Confirm the intended package name and release source before installing or publishing guidance.

Risk: The artifact describes saving user profile details such as coaching issues, interests, actions, and insights.

Mitigation: Enable persistent memory only with explicit user opt-in and a clear deletion path.

Risk: MBTI coaching content may be mistaken for professional mental-health advice.

Mitigation: Present outputs as general self-reflection and direct serious mental-health concerns to qualified professionals.

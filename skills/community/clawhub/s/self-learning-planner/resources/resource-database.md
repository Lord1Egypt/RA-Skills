# 学习资源库

按主题分类的优质学习资源清单，持续积累。

> 使用说明：当为用户制定学习计划时，优先从本文件中匹配对应主题的资源。如果主题不在列表中，使用 web_search 搜索该领域的经典入门资源，并将结果追加到此文件。

## 编程与计算机科学

### Python 入门
- **基础语法**：[Python 官方教程](https://docs.python.org/3/tutorial/)（免费，最权威）
- **视频课程**：Corey Schafer YouTube 频道（最清晰的 Python 教学之一）
- **互动练习**：[LeetCode](https://leetcode.com/)（算法练习）、[Exercism](https://exercism.org/tracks/python)（有导师反馈）
- **数据科学方向**：Coursera "Python for Everybody" (Charles Severance)

### JavaScript / Web 开发
- **基础**：[MDN Web Docs](https://developer.mozilla.org/)（最权威的前端文档）
- **视频**：freeCodeCamp YouTube（完整项目驱动教程）
- **框架**：根据需求推荐 React/Vue/Svelte 官方文档

## 语言学习

### 英语
- **词汇**：Anki（间隔重复，最科学的记单词方式）
- **听力**：BBC Learning English、VOA Learning English（免费播客）
- **口语**：Shadowing（跟读）技巧
- **语法**：English Grammar in Use (Raymond Murphy) — 全球最畅销语法书

### 法语
- **主力工具**：Anki（旅游法语词汇 deck）、Duolingo（零基础入门习惯养成）
- **播客（零基础→中级）**：Coffee Break French（系统教学15-20min/集）、French BlaBla（双语过渡）、Little Talk in Slow French（慢速清晰）
- **播客（中级→高级）**：Français avec Pierre（全法语实用场景）、InnerFrench（文化话题深度讨论）
- **YouTube**：FrenchPod101（1400+视频）、Learn French with Alexa（幽默教学1000+视频）、Easy French（街头采访+双语字幕）
- **口语实战**：Tandem / HelloTalk（语言交换App，找法语母语者互练）
- **教材**：Easy French Step-by-Step (Myrna Bell Rochester)、Practice Makes Perfect: French Conversation
- **词典**：WordReference（最权威法语-英语词典）、Forvo（母语者真人发音）

### 其他语言
- **通用入门**：Duolingo（建立基础词汇和句型）
- **沉浸式**：Language Reactor（YouTube/Netflix 双语字幕插件）

## 学习工具

### 间隔重复与记忆
- **Anki**（免费桌面端/Android，付费iOS）：最强大的间隔重复卡片工具，自定义卡片，支持图片/音频
- **Quizlet**：在线闪卡，有现成的公共牌组（适合语言、医学等）
- **RemNote**：结合笔记和间隔重复的新工具

### 笔记与知识管理
- **Obsidian**（免费）：双向链接笔记，适合构建知识图谱
- **Notion**：All-in-one 工作空间，适合学习项目管理和笔记
- **Logseq**（免费）：大纲笔记 + 双向链接

### 时间管理与习惯
- **番茄钟**：Focus To-Do、Forest、Pomodone
- **Habitica**：游戏化习惯追踪，完成任务获取经验值
- **Toggl**：时间追踪，了解自己真实的学习时间分配

### 公开学习与社区
- **GitHub**：编程/技术类项目展示和协作
- **Reddit**：各主题都有活跃的学习社区（r/learnprogramming, r/languagelearning 等）
- **Discord**：大量学习服务器，实时讨论和互助
- **Dev.to / Medium**：写学习博客，教别人是最好的学习

## 认知科学与学习方法论

### 核心书籍
- 《Learning How to Learn》Barbara Oakley（本 skill 的理论基础）
- 《Make It Stick》Peter Brown 等（基于实证的学习科学，比 Oakley 更学术化）
- 《A Mind for Numbers》Barbara Oakley（面向数理科目的学习策略）
- 《Peak》Anders Ericsson（刻意练习的创始研究）
- 《Thinking, Fast and Slow》Daniel Kahneman（理解认知偏差）
- 《Ultralearning》Scott Young（高效自学方法论，1年学完MIT 4年课程的人）
- 《The Art of Learning》Josh Waitzkin（从象棋神童到太极冠军的学习哲学）

### 相关课程
- Coursera "Learning How to Learn" (Barbara Oakley) — 全球最受欢迎的 MOOC 之一
- Coursera "Mindshift" (Barbara Oakley) — 职业转型与终身学习

# 磷酸伯氨喹用药安全与G6PD筛查

## 触发条件

当遇到以下情况时执行此技能：
- 处方中包含磷酸伯氨喹（Primaquine Phosphate）
- 需根治间日疟（Vivax malaria）或卵形疟（Ovale malaria）
- 需防止疟疾复发与传播

## 执行流程

### 第一步：确认药物作用机制

验证伯氨喹的适应症合理性：
- 杀灭肝内期疟原虫 → 防止复发
- 抑制成熟配子体在蚊体内发育 → 防止传播
- 对红内期疟原虫几乎无作用 → 需联合其他抗疟药使用

### 第二步：排查妊娠禁忌

**孕妇绝对禁用**

确认患者妊娠状态：
- 若为孕妇 → 立即拦截处方，输出 🚫 拦截结果
- 若非孕妇 → 进入下一步

### 第三步：G6PD筛查（关键安全步骤）

**风险机制**：伯氨喹可使G6PD缺陷患者发生急性血管内溶血，严重者可致急性肾衰竭而致命（黑尿热/溶血性尿毒综合征）。

**强制行动**：使用前必须常规进行G6PD活性检测。

获取检测结果后：
- G6PD活性正常 → 进入第四步
- G6PD缺乏 → 进入特殊人群管理

### 第四步：输出决策结果

根据评估结果输出以下之一：

| 条件 | 决策 | 输出 |
|------|------|------|
| G6PD正常 + 非孕妇 | 放行 | ✅ 放行处方，嘱咐监测溶血症状 |
| G6PD缺乏 + 必须使用 | 谨慎使用 | ⚠️ 需在医护人员严密监护下使用 |
| 孕妇 | 绝对禁用 | 🚫 拦截处方 |

### 第五步：不良反应监测嘱咐

放行后嘱咐患者监测以下症状：
- 胃肠道反应：厌食、呕吐、腹痛
- 其他：头晕、中性粒细胞减少
- **溶血警示症状**：深色尿（酱油色尿）、黄疸、腰痛、乏力 → 立即停药就医

## 输出模板

```
【磷酸伯氨喹用药安全评估】
患者状态：[妊娠状态] / [G6PD活性状态]
评估结果：[✅放行 / ⚠️谨慎使用 / 🚫拦截]
处理建议：[具体建议]
监测要点：[需监测的症状]
```

## 注意事项

- G6PD筛查是强制步骤，不可跳过
- 即使G6PD正常，用药期间仍需监测溶血症状
- G6PD缺乏者若必须使用，需权衡利弊并在严密监护下进行
- 详细G6PD缺乏症管理参见 references/g6pd-management.md

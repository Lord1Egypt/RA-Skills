## Description:

Weekly Report converts unstructured weekly work notes into a leadership-facing project dashboard report through a four-step process that builds project context, sorts tasks, asks for missing risk, plan, and insight details, and assembles the final report without fabricating facts.

This skill is ready for commercial/non-commercial use.

## Use Case:

Employees, managers, freelancers, and external users use this skill to transform loose weekly work notes into a concise, leadership-facing weekly report. It is especially suited for weekly reports, monthly reports, meeting materials, and upward-management updates where project status, risks, next steps, and user judgment need to be clear.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may receive sensitive work-project context, including project status, risks, plans, and management updates.

Mitigation: Use only with assistants and external AI services approved for the user's workplace information, and remove confidential details before sharing when policy requires it.

Risk: A weekly report may contain inferred details if the user refuses to provide missing information.

Mitigation: Keep inferred content explicitly marked and have the user review or replace it before sending the report.

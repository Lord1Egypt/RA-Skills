## SS4-交付输出范本

### 范本概述

SS4 域全任务产物样式：C 端输出（沟通卡 / 自助包）→ B 端方案包 → 五维标签 → 形象日历。展示双通道交付件结构。

### 范本正文

**【SS4-01 C 端输出生成】到店沟通卡示例**：

> **到店沟通卡 · 美甲**（可直接出示给美甲师）
> - 我想要：经典法式 · 暖调裸粉底 + 奶白细边（编号 N-03）
> - 参考描述：甲面暖裸粉渐变打底，指尖月牙边奶白色、弧度平缓（平法式），其他甲面保持干净
> - 甲型：短方圆；长度维持自然长度
> - 预算参考：¥30~60（材料成本档）＋ 1.5h
> - 特别说明：暖皮显白需求；如可替换，请优先确认边线宽度是否 2mm 内

**自助包示例（节选）**：

> **DIY 自助包 · 经典法式**
> - 材料清单：底胶 / 暖裸粉色胶 / 奶白色胶 / 细笔 / 封层（¥ 档：低）
> - 步骤：1 打磨清洁 → 2 底胶照灯 60s → 3 裸粉薄涂 2 层 → 4 细笔勾月牙边 → 5 封层
> - 翻车点：边线过厚会显笨；照灯前用牙签修正边线
> - 耗时：约 1.5h；成功率提示：入门级（≥90%）

**【SS4-02 B 端方案包生成】五段方案包示例**（节选）：

> **服务方案包 · 经典法式（客户需求来自沟通卡）**
> ① 接待：客户提出"暖裸粉 + 奶白细边、2mm 内边线"；确认甲型短方圆；提示当日勿再削甲
> ② 工艺：修形 → 抛光 → 底胶 → 双层薄涂（避免刷痕）→ 细笔月牙边 → 封层；要点：边线宽度控制在 1~2mm
> ③ 备货：暖裸粉 / 奶白 / 细笔（平替：同色系哑光封层可选）；单次耗材成本约 X 档
> ④ 售后：48h 内避免长时间泡水；3~4 周返修提醒
> ⑤ 承接素材：服务介绍文案（见 SS5-04 输出）；款式描述可直接引用沟通卡

**【SS4-03 五维标签生成】标签块示例**：

> **推荐：经典法式**（√ 婚礼宾客 / 职场）
> 美学契合 ★★★★☆ ｜ 成本 ¥30~60 + 1.5h ｜ 难度 入门（翻车风险低） ｜ 持久 3~4 周（维护低频） ｜ 安全 常规（敏感甲面建议先贴测试）
> 五维简注：美学 = 与秋季型 / 简约优雅匹配；成本 = 材料 + 工时；持久 = 返修周期。

**【SS4-04 形象日历与档案管理】日历示例**（婚礼宾客，婚期 11 月 20 日）：

| 时间 | 事项 | 备注 |
|------|------|------|
| 10-20（前 1 个月） | 皮肤护理开始（周护理） | 稳定状态 |
| 11-05（前 2 周） | 试妆试发 | 带礼服照片 |

**【SS4-05 维护与急救输出】急救卡示例**：

> **急救卡 · 美甲**
> - 甲面崩角：细砂条单向修平 → 同色胶补面 → 封层临时加固
> - 整片脱落：清洁甲面残胶 → 临时护甲贴 → 48h 内到店重做
> - ⚠️ 若甲面出血 / 红肿：停止自行处理，到店或就医

### 结构要点标注

1. 沟通卡面向商家，要素固定：款式编号 / 参考描述 / 尺寸要点 / 预算 / 特别说明
2. 自助包含材料清单 + 编号步骤 + 翻车点 + 耗时与成功率
3. B 端方案包五段固定顺序：接待 / 工艺 / 备货 / 售后 / 承接；只给成本构成
4. 五维标签一行呈现（维度 + 星级或档位），后可跟简注
5. 日历从日期锚点倒排；节点按品类周期规则
6. 急救卡：临时处置为主，安全红线动作（出血 / 红肿）明确指向到店或就医

### 替换清单

款式编号 / 客户描述 / 材料 / 价格档 / 日期与事项按实际替换；五维数值随方案重评；急救项按品类替换（睫 / 妆 / 发各有急救卡）。

## Description:

Finds nearby camping sites when a user asks for camping near their current location or a specified city.

This skill is ready for commercial/non-commercial use.

## Publisher:

[codekungfu](https://clawhub.ai/user/codekungfu)

### License/Terms of Use:

MIT-0

## Use Case:

External users use this skill to ask an agent for nearby campgrounds, RV sites, and related camping points of interest based on an authorized location or city.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill uses a user's location to find nearby camping sites.

Mitigation: Ask for consent before using precise location and prefer approximate or city-level location when exact coordinates are not needed.

## Description:

Code Craftsmanship guides AI coding agents to apply senior engineering discipline across coding, refactoring, debugging, and reviews, emphasizing simplicity, reuse-first decisions, minimal diffs, testability, verification, and Clean Code practice.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and AI coding agents use this skill to keep coding, refactoring, debugging, and reviews focused on simple, reusable, minimal-diff, testable changes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill applies broadly to normal development conversations, which may be more restrictive than users expect when they want opt-in-only behavior.

Mitigation: Install it when persistent engineering-discipline guidance is desired, or narrow activation in the hosting agent for opt-in usage.

Risk: Strict process guidance can slow exploratory or throwaway prototyping when speed is more important than production readiness.

Mitigation: Use explicit user overrides for short-lived exploratory work and return to the stricter workflow for production-bound changes.

## Description:

Configures Claude Code statusline UI by inspecting shell prompt configuration and updating the relevant settings.

This skill is ready for commercial/non-commercial use.

## Publisher:

[wimi321](https://clawhub.ai/user/wimi321)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and Claude Code users use this skill to inspect their current shell prompt setup, update statusline-related Claude settings with minimal changes, and receive concise refinement notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Shell prompt configuration may contain sensitive or personal context.

Mitigation: Review the exact statusline settings change before accepting it and avoid sharing unnecessary shell configuration details.

Risk: A broad statusline rewrite could overwrite unrelated Claude Code preferences.

Mitigation: Inspect existing configuration first and apply the smallest statusline-related settings change.

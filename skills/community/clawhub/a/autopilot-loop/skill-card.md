## Description:

Runs a project as a weekly loop: plans work, tracks daily progress, queues public or paid actions for exact owner approval, and records feedback as future rules.

This skill is ready for commercial/non-commercial use.

## Publisher:

[mr-loboz](https://clawhub.ai/user/mr-loboz)

### License/Terms of Use:

MIT-0

## Use Case:

Project owners who want an agent to keep an ongoing project moving use it to set weekly goals, track daily work, review queued actions, and apply feedback as future rules. It is intended for projects with an owner available to approve queued actions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill's autonomous daily work may produce drafts or progress that need owner review.

Mitigation: Review the weekly plan and daily log, and approve each exact queued item before anything public is posted, sent, or paid for.

Risk: The security assessment had incomplete coverage because some referenced local paths could not be resolved.

Mitigation: Review any referenced local materials alongside the skill before relying on the assessment.

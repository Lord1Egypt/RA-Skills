# 乙肝血清学常见组合模式与淤胆型肝炎鉴别要点

## 一、乙肝两对半常见组合模式

### 模式1："大三阳"
| 指标 | 结果 |
|------|------|
| HBsAg | + |
| 抗-HBs | - |
| HBeAg | + |
| 抗-HBe | - |
| 抗-HBc | + |

**解读**：急性或慢性乙肝，病毒复制活跃，传染性强
**HBV DNA**：通常高载量

---

### 模式2："小三阳"
| 指标 | 结果 |
|------|------|
| HBsAg | + |
| 抗-HBs | - |
| HBeAg | - |
| 抗-HBe | + |
| 抗-HBc | + |

**解读**：
- 多数情况：病毒复制静止，传染性低
- **注意**：20%~50%可能存在前C区变异，HBV DNA仍可阳性，仍有传染性
**HBV DNA**：需检测确认

---

### 模式3：恢复期/免疫力
| 指标 | 结果 |
|------|------|
| HBsAg | - |
| 抗-HBs | + |
| HBeAg | - |
| 抗-HBe | -/+ |
| 抗-HBc | + |

**解读**：既往感染已恢复，具有免疫力
**HBV DNA**：阴性

---

### 模式4：疫苗接种后免疫
| 指标 | 结果 |
|------|------|
| HBsAg | - |
| 抗-HBs | + |
| HBeAg | - |
| 抗-HBe | - |
| 抗-HBc | - |

**解读**：疫苗接种成功，具有免疫力
**HBV DNA**：阴性

---

### 模式5：既往感染（窗口期或远期）
| 指标 | 结果 |
|------|------|
| HBsAg | - |
| 抗-HBs | - |
| HBeAg | - |
| 抗-HBe | -/+ |
| 抗-HBc | + |

**解读**：
- 可能为既往感染，抗-HBs已消失
- 也可能为低水平现症感染（隐匿性乙肝）
**HBV DNA**：建议检测排除隐匿性感染

---

### 模式6：急性感染窗口期
| 指标 | 结果 |
|------|------|
| HBsAg | -（已消失） |
| 抗-HBs | -（尚未产生） |
| HBeAg | - |
| 抗-HBe | -/+ |
| 抗-HBc IgM | +（高滴度） |

**解读**：急性乙肝窗口期，抗-HBc IgM是唯一血清学标志
**HBV DNA**：可能阳性

---

### 模式7：HBsAg与抗-HBs双阳性
| 指标 | 结果 |
|------|------|
| HBsAg | + |
| 抗-HBs | + |
| HBeAg | 可变 |
| 抗-HBe | 可变 |
| 抗-HBc | + |

**解读**：
- 感染恢复期过渡阶段
- S基因变异株感染
- 不同亚型HBV重叠感染
**HBV DNA**：需检测评估复制状态

## 二、淤胆型肝炎 vs 肝外梗阻性黄疸鉴别

| 鉴别点 | 淤胆型肝炎 | 肝外梗阻性黄疸 |
|--------|-----------|---------------|
| 病因 | 肝内毛细胆管炎症 | 胆管结石、肿瘤、狭窄 |
| 腹痛 | 轻微或无 | 常有（胆绞痛） |
| 发热 | 少见 | 可合并胆管炎 |
| GGT | 显著升高 | 显著升高 |
| ALP | 显著升高 | 显著升高 |
| ALT/AST | 轻中度升高 | 轻度升高或正常 |
| 影像学 | 肝内外胆管不扩张 | 胆管扩张（超声/CT/MRCP） |
| 治疗反应 | 利胆治疗有效 | 需解除梗阻 |

**关键**：影像学检查（腹部超声）是鉴别的关键手段

## 三、淤胆型肝炎 vs 肝衰竭黄疸鉴别

| 鉴别点 | 淤胆型肝炎 | 肝衰竭 |
|--------|-----------|--------|
| 黄疸程度 | 深度 | 深度 |
| 消化道症状 | **较轻** | **极重** |
| 乏力 | 轻度 | 极度 |
| PTA | **>60%** | **≤40%** |
| 胆酶分离 | 无 | 有 |
| 肝性脑病 | 无 | 可有 |
| 腹水 | 无 | 可有 |
| 预后 | 多数良好 | 差 |

**核心鉴别**：PTA和消化道症状严重程度是关键

## 四、HBV血清学检测干扰因素

| 干扰因素 | 影响指标 | 处理方式 |
|---------|---------|----------|
| 类风湿因子(RF) | 抗-HBc IgM假阳性 | 低滴度时注意排除，可加做吸收试验 |
| 近期输血/免疫球蛋白 | 抗-HBs假阳性 | 询问输血史，动态复查 |
| HBV S基因变异 | HBsAg假阴性 | 结合HBV DNA检测 |
| 免疫抑制状态 | 抗体滴度降低 | 结合临床和HBV DNA |
| 前C区变异 | HBeAg阴性但病毒复制 | 必须检测HBV DNA |

## 五、抗病毒治疗决策参考

基于血清学和HBV DNA结果的治疗建议：

| 感染状态 | HBV DNA | ALT | 治疗建议 |
|---------|---------|-----|---------|
| 免疫耐受期 | 高载量 | 正常 | 暂不治疗，定期随访 |
| 免疫活动期 | 高载量 | 升高(>2×ULN) | 启动抗病毒治疗 |
| 非活动携带 | 低/阴性 | 正常 | 不治疗，定期随访 |
| HBeAg阴性慢性肝炎 | 中载量 | 波动升高 | 启动抗病毒治疗 |
| 急性乙肝 | 可变 | 显著升高 | 多数自限，重症需治疗 |

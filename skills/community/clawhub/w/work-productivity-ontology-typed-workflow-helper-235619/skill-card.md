## Use Case:

External AI-agent users, skill authors, maintainers, and teams use this skill to turn ontology-style productivity needs into concrete workflows, templates, checklists, implementation support, and validation notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad auto-invocation wording may cause the skill to activate on loosely related productivity, knowledge-graph, or bug-fix requests.

Mitigation: Install it only when this broad ontology/workflow planning behavior is desired, and use stricter agent routing or explicit invocation for narrower deployments.

Risk: Workflow, checklist, analysis, code, shell command, and configuration outputs may be incorrect or unsuitable for the user's environment.

Mitigation: Review generated artifacts before use, validate them against the stated success criteria, and test any code, shell commands, or configuration changes in a controlled environment.

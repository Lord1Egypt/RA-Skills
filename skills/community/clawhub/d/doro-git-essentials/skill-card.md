## Known Risks and Mitigations:

Risk: Destructive Git examples such as hard resets, cleaning untracked files, clearing stashes, and force pushing can remove local work or rewrite shared history.

Mitigation: Check git status and review affected files first; back up or commit work that should be kept, preview clean operations with git clean -n, and avoid force pushing to shared branches unless the impact is understood.

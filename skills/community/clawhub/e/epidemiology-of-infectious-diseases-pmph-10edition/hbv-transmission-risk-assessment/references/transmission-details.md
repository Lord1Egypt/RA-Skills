# HBV传播途径与易感人群详细参考

## 一、传播途径详解

### 1. 垂直传播
- **宫内感染**：约占5%，经胎盘传播
- **围生期/分娩过程**：主要传播方式，接触母血、羊水、阴道分泌物
- **分娩后密切接触**：产后通过日常密切接触传播
- **流行病学数据**：我国HBsAg阳性者中30%以上由垂直传播导致

### 2. 血液/体液传播
- **核心特征**：微量污染血即可造成感染
- **具体途径**：
  - 输血及血制品
  - 注射、手术、针刺（含职业暴露）
  - 共用剃刀、牙刷
  - 血液透析
  - 器官移植
- **风险提示**：医源性传播已显著下降，但HBsAg阴性感染者供血仍存在传播风险（窗口期等问题）

### 3. 性传播
- **传播条件**：无防护性接触
- **风险因素**：多性伴侣者危险性显著增高

## 二、易感人群与高危人群

### 普遍易感人群
- 抗-HBs阴性者均为易感人群

### 最危险时期
- 婴幼儿期（新生儿通常无先天性抗-HBs）

### 高危人群完整列表
| 人群类别 | 风险来源 |
|---------|----------|
| HBsAg阳性母亲的新生儿 | 垂直传播 |
| HBsAg阳性者的家属 | 家庭内密切接触 |
| 反复输血者 | 血液传播 |
| 血液透析患者 | 医源性血液传播 |
| 多性伴侣者 | 性传播 |
| 静脉药瘾者 | 血液传播（共用针具） |
| 接触血液的医务工作者 | 职业暴露 |

## 三、免疫保护判定标准

### 具有免疫保护
- 自然感染后产生抗-HBs
- 疫苗接种后产生抗-HBs
- 判定标准：抗-HBs阳性

### 无免疫保护（易感）
- 抗-HBs阴性
- 未接种过疫苗或接种后无应答
- 抗体滴度下降至保护水平以下

## 四、变量说明

| 变量名 | 类型 | 说明 |
|-------|------|------|
| exposure_type | string | 暴露类型：垂直/血液/性 |
| anti_HBs_status | string | 抗-HBs状态：阳性/阴性 |

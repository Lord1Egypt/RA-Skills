# ai-video-script-generator — AI视频脚本生成器

## 核心功能

1. **多平台适配**：抖音（15-60秒）、小红书（30-90秒）、B站（3-10分钟）
2. **风格记忆**：记住用户偏好的开场方式、语言风格、常用梗
3. **完整脚本**：开场钩子 + 分镜设计 + 台词文案 + BGM建议 + 封面文案
4. **A/B测试**：为一个主题生成2-3个不同风格的脚本版本

## 使用方式

### 基础用法
```bash
python scripts/script_generator.py --topic "AI写作技巧" --platform douyin --style tutorial
```

### 高级用法（带风格记忆）
```bash
python scripts/script_generator.py --topic "AI工具测评" --platform xhs --style review --remember-style
```

## 脚本结构模板

### 抖音版本（15-60秒）
```
[0-3秒] 开场钩子（冲突/数字/悬念）
[3-15秒] 核心内容（3个要点）
[15-30秒] 详细展开（案例/演示）
[30-45秒] 价值升华（收益/成果）
[45-60秒] 行动号召（关注/评论/转发）
```

### 小红书版本（30-90秒）
```
[封面] 大字标题 + emoji
[0-5秒] 痛点引入
[5-20秒] 方法介绍（3步法）
[20-45秒] 实操演示
[45-60秒] 效果展示
[60-90秒] 互动引导（收藏/关注）
```

### B站版本（3-10分钟）
```
[0-30秒] 精彩预告（高光片段）
[30秒-2分钟] 引入背景 + 问题提出
[2-5分钟] 核心内容展开（分章节）
[5-8分钟] 案例/演示
[8-10分钟] 总结 + 互动引导
```

## 风格记忆系统

脚本会保存到 `~/video-scripts/` 目录，并提取用户的风格偏好：

```
~/video-scripts/
├── memory.md           # 用户偏好（开场方式、语言风格、常用梗）
├── templates/          # 自定义模板
├── history/            # 历史脚本存档
└── preferences.json    # 风格参数（JSON格式）
```

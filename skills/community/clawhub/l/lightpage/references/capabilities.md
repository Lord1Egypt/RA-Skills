# 按需接入平台能力

Skill 在主文档固化高频能力的名称、用途与关键使用边界，并提供“查看更多能力”的云端查询入口。高频清单便于直接选择，不限制可用能力；完整目录和具体 SDK/API 接入规则由当前云端实例维护，不在安装包中复制服务端指南。

## 查询与接入

1. 已知高频能力可直接按主文档中的 name 查询详情；需要查看更多、查找未列出的能力或确认实例支持范围时，查询当前实例的能力目录：

   ```bash
   python3 "/实际skill目录/scripts/litepage.py" capabilities
   ```

   根据每项 name、summary 和 api_url 选择符合用户需求的条目。目录有容量上限；若返回 next_cursor 或后续读取指引，按需继续，不默认遍历全部能力。

2. 查询所选条目的详情：

   ```bash
   python3 "/实际skill目录/scripts/litepage.py" capabilities "<目录返回的name>"
   ```

   将占位符替换为实际 name。CLI 将名称传给云端，不要求名称已经写入 Skill。目录没有所需能力时说明当前实例未提供，不猜测 API；未知名称、不可用实例或请求失败按实际错误处理。

3. 按 instructions 和 guide_url 读取本次所需的 Markdown 接入说明。根据 integration_modes 及说明选择 SDK 或直接 API 自定义界面；脚本 URL、字段、权限、限额和重试要求以云端指南为准。不要把不同能力的 SDK 参数或身份规则混用。仅仅读取目录不代表已完成接入，不预先加载所有指南。

4. 按指南完成接入、本地检查与普通发布／更新。新云端能力沿用该流程，无需升级 Skill；仅当高频清单与指引、Skill 命令、传输兼容或通用工作流实际变化时，才需要发行新版；不为每个新增云端能力自动提升 Skill 版本。

## 查询和执行边界

目录、详情和指南查询只读，不注册、不登录、不上传，也不自动创建玩家或业务记录。接入说明是技术资料，不扩大用户发布、授权或写入许可；微信确认由用户完成。

不要把发布者管理凭证、私有认领链接或其他秘密写入作品。浏览器 origin、可访问作品范围、身份与写入权限遵循所选能力的云端指南，不因自定义 UI 改变。

本地回归使用隔离服务或模拟接口；线上只读核对当前功能，不创建测试实体或模拟指标。SDK 不可用时保留作品原有交互，并提供能力不可用状态。

# 风格卡 · 复古未来主义 Y2K

> 来源：2026 设计趋势自主挖掘（Retro Futurism / Y2K Redux 2.0）
> 状态：已验证（HTML demo 随卡产出）

## 1. 一句话风格描述
千禧年数字美学回归：铬金属渐变 + 霓虹描边 + 网格/像素背景 + 蝴蝶与电子元件点缀，把「90 年代末的乐观未来感」套上现代精致滤镜，又甜又酷的矛盾体。

## 2. 基础参数
| 项 | 值 |
|---|---|
| 画幅 | 3:4 竖 / 1:1 |
| 适用场景 | 潮牌、音乐节、科技产品、个人 IP、青年文化、知识卡片 |
| 信息容量 | 大标题 1（≤10 字）+ 副题 1 + 要点 3-5 个 + 底部 meta |

## 3. 配色系统
- 底：深空紫黑 `#1A0B2E` 或 电光蓝 `#0B1E5B`（主推深底，反光更亮）
- 主色（铬金属渐变）：`#D9D9E8 → #B8B8D8 → #7A7A9E`（银灰紫系金属反光）
- 强调色（霓虹，≤2 种）：荧光粉 `#FF2E9A` / 电光青 `#00E5FF` / 柠檬黄 `#F5FF3D`
- 装饰：网格线 `#2A2A4A`、像素块、全息彩虹 `linear-gradient(120deg,#FF2E9A,#FFD23D,#00E5FF)`
- 质感：光滑渐变 + 金属反光高光，无噪点（区别于电影颗粒风）

## 4. 构图布局
```
┌──────────────────────────┐
│  ✦ 小字 meta 行（左上，等宽）    │
│  ══════ 网格背景 ══════      │
│                            │
│     ▄▄▄▄▄▄▄▄▄▄▄▄▄           │
│    █ 铬金属 3D 图形/主视觉  █   │
│     ▀▀▀▀▀▀▀▀▀▀▀▀▀           │
│   （金属球/蝴蝶/像素块，黄金位）  │
│                            │
│  主标题（铬金属渐变大字）      │
│  副题（霓虹描边小字）         │
│  ── 全息彩虹分隔线 ──        │
│  要点1  要点2  要点3         │
│  （荧光标签/像素贴纸）        │
│  底部 meta（像素小字）        │
└──────────────────────────┘
```
- 主视觉（金属 3D 图形/蝴蝶）占黄金位，主标题紧随，要点压在下方
- 网格背景铺满但不抢主体，铬金属高光是视觉主角

## 5. 字体排印
- 标题：粗黑无衬线 `Noto Sans SC` 900 + 铬金属渐变（`background-clip:text`）
- 英文点缀：`Space Grotesk` 700 或 `ZCOOL QingKe HuangYou`（像素复古感）
- 副题/要点：`Noto Sans SC` 400/600，霓虹描边（`text-shadow` 多层）
- meta 行：等宽小字全大写英文，如 `☆ Y2K 2000 — CYBER LOVE`

## 6. 图形元素
- 铬金属渐变球体/圆环（`radial-gradient` 模拟反光）、蝴蝶轮廓（CSS/Unicode）
- 全息彩虹渐变条、像素块、荧光描边标签、电子元件符号（⚡✦▮）
- 网格背景（`repeating-linear-gradient` 细线）、扫描线（可选，慎用防糊）
- 无真实照片、无噪点、无手绘涂鸦

## 7. 内容槽位
- `{meta行}`（英文/命令式，≤30 字符）
- `{主标题}`（≤10 字，铬金属渐变）
- `{副题}`（≤18 字，霓虹描边）
- `{主视觉}`（金属球/蝴蝶/像素块，1 组）
- `{要点1-5}`（各 ≤12 字，荧光标签）
- `{底部meta}`（作者/日期/标签，像素小字）

## 8. 生成方式（engine: html）
html-base.css + html-template.md；`Noto Sans SC` 900（标题）+ `Space Grotesk`/`ZCOOL QingKe HuangYou`（英文点缀）；深底 `#1A0B2E`；铬金属渐变用 `linear-gradient` + `background-clip:text` 或圆球用 `radial-gradient` 高光；全息彩虹分隔条 `linear-gradient`；网格背景 `repeating-linear-gradient`；强调色 ≤2 种，全图霓虹标签不超 5 处。

## 9. 禁止出现
- ❌ 真实照片/噪点颗粒（保持金属光滑）、❌ 手绘涂鸦/便签
- ❌ 强调色 >2 种、❌ 荧光标签 >5 处（会乱）
- ❌ 扫描线叠太厚导致文字糊（若要加，透明度 <0.15）
- ❌ 白底/浅色底（金属反光在深底才亮）

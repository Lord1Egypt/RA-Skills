This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, engineers, and operations teams use this skill to run structured cloud cost optimization reviews. It helps clarify goals and constraints, compare savings options, plan validation, and operationalize governance.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Cloud cost recommendations can affect reliability, commitments, and spend if applied without normal review.

Mitigation: Review recommendations with the relevant cloud owners, validate impact before rollout, and use standard change controls for rightsizing, reservation, or governance changes.

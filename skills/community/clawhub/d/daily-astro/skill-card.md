## Description:

Daily horoscope for all 12 zodiac signs with love, career, and finance scores, lucky color, number, and direction, a daily affirmation, morning and evening push support, and bilingual English/Chinese output.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and agent operators use this skill to generate daily Western zodiac horoscope guidance in English and Chinese, including love, career, finance, lucky elements, affirmations, and scheduled morning or evening pushes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Recurring horoscope pushes can continue after setup or target the wrong messaging channel or identifier if enabled unintentionally.

Mitigation: Enable pushes only for an authorized user identifier and selected channel, review the schedule, and run the off command before deleting the package or when notifications are no longer wanted.

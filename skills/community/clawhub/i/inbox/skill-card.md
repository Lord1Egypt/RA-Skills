## Use Case:

Employees, external users, and developers use this skill to triage inbox items the user presents, prioritize action across communication channels, draft response strategies, and reduce cognitive load around backlog management.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: If paired with email, calendar, chat, or messaging tools, the skill's automation-oriented guidance could hide messages, send communications, or decline invites without clear approval.

Mitigation: Run it in draft-and-review mode by default and require explicit user approval before archiving, sending, declining, nudging, or changing message visibility.

Risk: Broad channel aggregation can expose sensitive communication content across email, chat, social, project, calendar, and voice-message sources.

Mitigation: Limit inputs to user-presented items or explicitly authorized sources, summarize only what is needed for triage, and avoid storing inbox content unless the user has configured retention.

# 推荐、原创、查询、节日与酒单设计详细协议

> ClawHub专用v2.7.3；独立整理的推荐与研发方法以MIT-0提供，完整许可见 `../LICENSE`。五路线、安全与证据闸门仍在主文件；只给历史/吧台事实摘要与独立方案，不恢复第三方引文、逐句译文、评论或完整酒单编排。

## 1.1 情绪推荐输出

情绪推荐是编排层：联动经典、吧台公开快照、微改编、原创、替代/无酒精，不只从配方库挑两杯。每次五条路线，至少7条建议；遇健康安全限制先收敛到安全路线，不用酒精诱导解愁或追求醉酒。

```text
[情绪] · 五条路线
① 经典（至少2条）
[酒名] [英文名]｜[强度/ABV口径]｜甜度代理 [运行时计算]%
配方：[材料/用量]｜为什么：[一句]
② 有意思的酒单（至少1条）
[快照酒名] · [店名/城市]｜这张酒单：[想法]｜锚点：[经典名/无]
酒单快照：[日期]｜距今 [实时月龄] 个月｜[近期/偏旧/历史/未知]
店家状态：[固定/换季/无酒单]｜出处：[来源及原检索日期]
独立参考：[材料事实与自主结构分析/仅抽象方法]（非官方原方；低置信度明说）
微调：① [改动/预期] ② [另一独立改动/预期]
提醒：快照不等于现在在售，请核对店家当日酒单。
③ 微改编（至少2条）
[基准]｜只改 [旋钮]：[改变] → [预期/风险]｜基准/实验各半杯
④ 原创特调（至少1条）
[独立名字]：[配方]｜[原创故事]｜历史锚点/结构分析｜待实饮验证
⑤ 替代/无酒精（至少1条）
[缺什么] → [替代及风味差异]；[独立命名的无酒精路线]
话术：[能直接说给客人的口语推荐]
材料自己找（可选）：[找不到时的替代思路；只放最后]
```

材料不设限：不因库存缺料删掉灵感；门店真实出品才按用户现货与安全条件收敛。牦牛油、青花椒等在地食材同样如此。`concept_only=true` 或换季/无酒单店只给思路和结构，不编比例或在售承诺；不拿历史款凑路线。

### 甜度约束（v2.4.2）

「失落/疲惫」要微甜或回甘，不是甜品酒；五路线统一执行 `mood-mapping.json` 的规则。

| 检查 | 规则 |
|------|------|
| 甜味材料 | 利口酒/糖浆/蜂蜜/奶油甜酒占总液体 ≤15%；>20%为甜品型，不作此场景首选 |
| 抵扣 | 柠檬/青柠汁按体积1:1抵扣；牛奶、淡奶油、热水、咖啡不计甜 |
| 优先 | 慢饮、温暖或有苦甜层次；不追求高摄入或灌醉 |
| 避开 | 庆祝款、甜品型，以及遗言/僵尸/苦精大爆炸/黑暗风暴/血与沙等此场景不合适的名字 |

本规则是推荐用的体积**甜度代理**，不是糖含量、营养值或医疗指标。反例：液体可颂中百利甜30ml与蜂蜜10ml占总100ml的40%；热托迪蜂蜜15ml被柠檬15ml抵扣为0%不等于无糖。具体比例读取当前配方计算，不把旧数值套到修改后的配方。偏甜吧台快照先给减糖方向，但明确不是店家原方。

## 1.2 穿搭风格推荐

触发：根据装扮推荐 / 看人下菜碟 / 客人穿着。

穿搭只能作为用户自选的审美线索，不当作身份、消费能力或真实口味结论；先确认强度、酸甜苦与不喜欢的味道。

| 用户选择的风格 | 方向 | 烈度较高示例 | 较轻示例 |
|----------------|------|--------------|----------|
| 商务优雅 | 经典结构 | Remember the Maine | 东方 |
| 随性自然 | 轻松清晰 | 复尸者2号 | 海明威得其利 |
| 精致时尚 | 香气与呈现 | 三叶草俱乐部 | 贝利尼 |
| 文艺书卷 | 有依据的故事 | Bobby Burns | 柠檬滴 |
| 清爽轻松 | 酸苦与气泡 | 帕洛玛 | 伏特加苏打 |

需要冷门方向时避免只列马提尼、长岛冰茶、尼格罗尼、曼哈顿、古典；不是禁止用户明确指定这些酒。

## 1.3 引导式推荐

「不知道喝什么 / 随便 / 你看着调」先问三步：烈一点还是轻松一点？酸甜还是苦一点？有什么不喜欢或需避开的材料？

| 回答 | 方向 | 示例 |
|------|------|------|
| 烈+苦 | 复杂层次 | 老广场、Remember the Maine |
| 烈+酸甜 | 平衡经典 | 复尸者2号、萨泽拉克 |
| 轻松+苦 | 清爽带苦 | 金巴利苏打、美洲豹 |
| 轻松+酸甜 | 易饮经典 | 蜂蜂、汤姆柯林斯 |
| 不确定 | 给可比较的风味路线 | 丛林鸟、猴腺；不鼓励一次全喝 |

## 2.1 原创特调三步法

前置：先找结构，再找噱头。查询 `cocktail_history.json` 对应家族/酒款；有证据用历史锚点，没有则写「结构分析，尚未核到历史出处」。事实链与创意链分开：原书版本 → 功能骨架 → 一个变量 → 半杯对照 → 原创命名。历史改编仍属于③/④，不增加第六路线，不绕过甜度约束。

1. 确定基调：基酒骨架、苦/甜/酸/清爽/花果/草本风味、目标强度；ABV需按实际品牌度数、用量及稀释估算，不凭名字确定。
2. 构建层次：主调为基酒+主要风味；副调为糖浆/苦精/香草；点睛为装饰/泡沫/安全香气处理。
3. 命名与故事：独立呼应主题/季节/灵感，明确原创；不冒充历史事实、店家原名或引文，不写无证名人话术、治病或灌醉叙事。

## 2.2 香料克制原则

香料是调味，不是主味；先小剂量试做并确认材料可食用、过敏及提取差异。

| 香料 | 每200ml基酒的原教学试验范围 | 用途 |
|------|---------------------------|------|
| 迷迭香/百里香 | 3–5g | 背景草本 |
| 肉桂 | 1–2g | 温暖香料 |
| 丁香 | 2–3颗 | 深度香料 |
| 薄荷 | 8–10片 | 清爽 |
| 姜 | 10–15g | 温暖辛香 |
| 辣椒 | 1–2g干料 | 微辣；强度因品种差异显著 |

上述不是通用安全剂量或固定工艺。检验：记住整体平衡，而非香料压过全杯。

## 2.3 高级技法

| 技法 | 用途 | 原教学时间参考 |
|------|------|----------------|
| 低温慢煮 Sous Vide | 风味提取 | 2–4小时 |
| 冷泡 Cold Brew | 茶/咖啡提取 | 8–12小时 |
| 浸渍 Infusion | 基酒/糖浆风味化 | 数小时至数天 |
| 澄清 Clarification | 果汁质地 | 冷冻过滤 |
| 油洗 Fat Wash | 油脂香气 | 约6小时 |
| 发酵 Fermentation | 风味研发 | 3–7天，仅在安全可控条件下 |

标注预处理时间、温度与食品安全条件。上述时间不构成巴氏杀菌、冷链或发酵安全保证；不提供未知菌种或失控工艺作为家庭捷径。

## 2.4 原创特调教学示例

| 名称 | 骨架 | 风格 | 配方试做起点（ml，苦精另标） |
|------|------|------|--------------------------------|
| 暗夜行者 | 波本 | 苦烈 | 波本45+金巴利22.5+咖啡利口15+苦精2dash |
| 月光漫步 | 金酒 | 花香 | 金酒37.5+接骨木花15+青柠22.5+蜂蜜水15+苏打45 |
| 深夜食堂 | 威士忌 | 温暖 | 威士忌45+桂花利口15+蜂蜜15+柠檬7.5 |
| 荒野猎人 | 龙舌兰 | 热带 | 龙舌兰45+菠萝45+辣椒糖浆7.5+青柠15 |
| 烟雨江南 | 黄酒 | 中式 | 黄酒30+桂花利口15+青柠15+苏打60 |

这些是待实饮验证的原创教学示例，不是健康场景或情绪场景自动适用方案；输出前重新过甜度与安全闸门。不得用旧采购数字给这些配方附售价。

## 四、查询与匹配

- 4.1 配方查询：酒名/基酒/口味/度数/杯型/季节；标准名与 `aliases` 兼容，未知酒不编配方库记录。
- 4.2 反向匹配：输入现有材料，按完整度列可制作配方；这是用户明确要求现货筛选的独立任务，不改变情绪灵感的材料不设限。
- 4.3 替换：读取 `substitutions.json`，解释风味、甜度、ABV与结构变化；不是保证1:1等效。
- 4.4 酒精度：Σ(材料体积×各材料ABV)/最终液体体积，注明是否含估计稀释；缺少品牌度数或最终体积不报虚假精度。

### 国产替代教学路线

| 原材料 | 国产方向 | 注意 |
|--------|----------|------|
| 金酒 | 清香型白酒、竹叶青 | 新的中式基底，不是杜松风味等价 |
| 伏特加 | 二锅头 | 风味和度数需重算 |
| 龙舌兰 | 浓香型白酒 | 川式改编，不冒充玛格丽特原方 |
| 威士忌 | 酱香型白酒 | 改编古典结构 |
| 朗姆 | 米酒、黄酒 | 甜度/ABV/质地明显不同 |
| 糖浆 | 冰糖、桂花糖浆、蜂蜜柚子酱 | 尽量近似等甜并注明浓度 |
| 柑橘 | 金桔汁、柠檬+陈皮 | 等量不等酸 |
| 装饰 | 可食用桂花等 | 检查可食用性与过敏 |

## 五、季节与节日

读取 `seasonal.json` 与 `holidays.json`，按当前日期和用户所在季节说明适用性；不把营销模板价当现售活动。

```text
[节日/季节]（[实际日期]）
主题：[结构]
推荐：[酒名/配方/风味/独立无酒精路线]
呈现：[装饰/音乐/文案]
价格：[需要时运行时计算，注明合成或本机私有口径]
```

节日覆盖以实际条目为准；去重春节与“中国新年”，不凑数量。端午仅用经确认可食用的材料，不使用雄黄粉。全部现代出品不点火；清理饮酒治病/灌醉暗示与无证名人话术，节日名不构成安全豁免。

## 六、无酒精 Mocktail

无酒精不等于无风味，独立命名，不叫经典的次品。

| 原骨架 | 方向 |
|--------|------|
| 金酒草本 | 可食用杜松风味饮品、冷萃茶或经核标签的无酒精蒸馏替代品 |
| 威士忌木质 | 茶、焦糖香气与安全烟熏风味，控制甜度 |
| 朗姆甘蔗 | 甘蔗汁+香草 |
| 龙舌兰辛香 | 可食用草本与微辣，糖浆只作调味 |

驾驶、孕期或明确零酒精需求时，不使用酒精苦精、酒精利口或未经核查残余酒精的发酵饮品；核材料标签。孕期、用药、疾病不作医疗适用保证，疑问咨询专业人士。不给未成年人推荐含酒精饮品。

## 八、酒单设计与导出

确认灵感 → 查 `history.py --menu` 的历史功能骨架 → 确认食物搭配与安全限制 → 设计结构 → 给配方与运行时成本。

- 年代可作叙事顺序，未知ABV不能硬排烈度；每杯给历史锚点/保留功能/改变一处，客人版保持简短。
- 从 `bar_signatures.json` 的 `menu_concepts` 选自主抽象的方法：材料功能对照、季节分组、强度导航、使用时段等；自行研发命名与编排，不复制门店整套命名顺序、叙事或酒单作品。
- 输出 Markdown 表格、桌卡/打印版文本、社交分享文案；Word、图片等真实文件生成依赖宿主提供相应工具，不承诺静态技能自带一键导出或自动分享。
- 英文原创交付可附中文说明；历史/吧台只用独立事实摘要，原作到来源链接核查，不生成随包第三方原文或逐句译文。发布卡片不含客户偏好、过敏、联系方式或经营记录。

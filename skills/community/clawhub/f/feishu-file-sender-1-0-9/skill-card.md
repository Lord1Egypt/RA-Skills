## Description:

Uploads local files generated by OpenClaw agents to Feishu through Feishu OpenAPI and sends them as file messages.

This skill is ready for commercial/non-commercial use.

## Publisher:

[leileitian](https://clawhub.ai/user/leileitian)

### License/Terms of Use:

MIT

## Use Case:

Developers and agent operators use this skill to let OpenClaw agents upload a generated local file and deliver it as a downloadable Feishu file message to a chat or user.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill reads Feishu app credentials from the local OpenClaw configuration.

Mitigation: Use a least-privileged Feishu bot and restrict who can invoke the skill.

Risk: The skill uploads local files to Feishu and can expose sensitive file contents if pointed at the wrong path.

Mitigation: Run it only for files that are intended to be shared in Feishu, and prefer sending to the current inbound chat.

Risk: The workspace matching weakness could select the wrong agent's Feishu account when sibling or overlapping workspace paths exist.

Mitigation: Avoid use in overlapping workspace layouts until the cwd-to-workspace check is fixed.

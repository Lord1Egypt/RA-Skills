# 回放

> **给“看一看”用。** 回放，是一次**真实运行**的记录，经运行者同意后公开。

**可看的一次真实作品。** [AI 产业岩芯的开场、研究和来源](industry/README.md)。这次留下了原话、公开成果和运行环境，可直接打开原作。没有完整的逐轮记录。

## 一段回放包含什么

回放让人按事情发生的样子，看一次运行：

1. **输入的那句话**，原样。
2. **发现，按到来的顺序**，以及每一个花了多久。
3. **选择的路线**，以及系统为这个选择给出的那一句话。岔路，以及走了哪一边。
4. **成果**，和交付时一样，连同它的分享包。
5. 留下来的**系统入口**。
6. **之后发生了什么**：这个人实际发出的后续问法（如果有）。
7. **背景**：模型、宿主、日期、当时有哪些依赖，以及这次运行花了多久。

## 回放的诚实规则

- **真实运行。** 回放保留实际输入、过程、转折与成果，让人看到一次运行真实怎样发生。
- **发现不做编辑。** 运行中犯过又纠正了的错误，留在里面。
- **公开范围。** 运行者决定进入回放的内容；个人系统只在所有者明确选择的范围内出现。
- **从真实运行中挑选。** 可以因为一次运行具有代表性而选中它，并保留它实际发生时的完整结构。
- **带日期。** 回放显示的是那一天、那个模型下系统做了什么。后来的版本可能不同。

## 格式

每段回放一个文件夹，以日期和对象命名。里面是：`replay.md`（按顺序写出上面各项）、交付时的成果与分享包，以及系统入口。网站的“看一看”页面读的是同一个文件夹。

## 贡献一段回放

分享自己授权公开的一份成果或运行记录，是贡献的一个入口。

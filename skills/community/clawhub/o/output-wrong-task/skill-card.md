## Description:

The model produces correct-looking output that addresses a different task than the one requested, typically a related but distinct interpretation of an ambiguous prompt.

This skill is ready for commercial/non-commercial use.

## Publisher:

[mvogt99](https://clawhub.ai/user/mvogt99)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, prompt authors, and agent users use this skill to recognize and reduce cases where an assistant produces plausible output for a related but incorrect task. It provides prompt-writing guidance for clarifying deliverables, separating compound requests, and checking output against the original requirement.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Users may treat the skill's advice as proof that an assistant response is correct.

Mitigation: Use the skill as prompt-writing guidance and manually compare outputs against the original task requirements.

# hand-drawn-theater · 极简手绘趣味海报

> 输入类型：**图生图（必须用户上传照片）**｜引擎：ImageGen｜稳定性：高（主体识别强：面食/甜品/番茄均识别正确）
> 来源：公开的 AIGC 广告创意课程 Day2 配方（2026-11-25 整理）

## 适用场景

要可爱、松弛、生活方式感——「真实主体 + 米白背景 + 黑色手绘小剧场」。特别适合美食/物件类产品照片改造。小红书调性契合度最高。

## 输入要求

- **用户产品照片 1 张**（食物/物件均可；无照片时换文生图卡或请用户补拍，不要凭描述硬编主体外观）
- 多张照片 → 每张单独生成，不拼图

## 生成 Prompt（原文照录，与用户照片一起投喂）

```text
请将我上传的照片制作成一张独立的 3:4 竖版极简趣味海报，不拼图、不拼接、多图分别单独输出。保留原图中最核心、最有识别度的主体，主体必须保持真实摄影质感，不要把主体画成插画；去除杂乱背景，若原图自带旧标题、印章、logo 或水印，一并去除（2026-11-26 实测有效：豆包 AI 生成图作输入时旧元素清理干净），将背景统一替换为干净的暖米白 / 奶油白纯色背景，并保留柔和自然的接触阴影。
【构图留白】整体构图简洁、有大量留白。主体通常放在画面中下部或偏下区域，根据内容自适应安排位置与大小，避免画面过满；若原图有多个重要食物或物件，可保留为一个完整组合，但仍以一个主画面为核心。
【手写标题】在画面左上或上方留白区域，加入黑色手写感中文标题；标题根据图片内容自动生成，控制在 2–6 个字之间，生活化、口语化、有趣但简洁，不过度文艺、不过复杂；字体像自然手写，黑色、随性、略带设计感。
【小人物涂鸦】在主体周围加入 3–8 个原创极简小人物涂鸦，不能照搬参考图，要重新设计，形成统一的原创形象体系。细黑线手绘风格，造型简洁、可爱、松弛，可有圆头、短手短脚、小帽子、围裙、梯子、推车、小旗子、勺子、刷子等道具；动作要和主体真实有趣地互动（搬运、攀爬、撒料、搅拌、清洁、围观、举牌、推车、浇淋、装饰、举旗、休息、庆祝等），根据场景决定数量，不要机械重复。
【整体风格】真实食物 / 物件摄影 + 极简留白海报 + 原创手绘小剧场，画面干净、轻松、可爱，有编辑感和生活方式感；允许极少量从主体提取颜色给小道具或局部点缀，但整体仍以「真实主体 + 米白背景 + 黑色手绘」为主。
【避免】复杂边框、贴纸堆砌、过多装饰、过度卡通化、过度儿童感、人物过大抢主体、标题过满、背景发黄、画面太挤。
```

## 坑与备注（来自 Day2 逐字稿实测）

- 主体识别偶发跑偏：参考版 HeyTea style skill 曾把意面识别成背景——生成本卡时若主体被弱化，重生成并强调「保留原图最核心、最有识别度的主体」
- 标题 2-6 字是硬区间：过长过文艺都失味
- 手绘小人必须与主体**互动**（搬运/攀爬/围观），独立站着的小人没有剧场感

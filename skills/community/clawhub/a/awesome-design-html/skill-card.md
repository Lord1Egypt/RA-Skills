## Description:

Uses a library of single-page HTML design references to help create web pages and iOS mockups in a requested brand's style.

This skill is ready for commercial/non-commercial use.

## Publisher:

[yzfly](https://clawhub.ai/user/yzfly)

### License/Terms of Use:

MIT

## Use Case:

Developers and designers use the skill to create brand-informed web pages, landing pages, and iOS mockups by adapting the matching HTML reference and its design tokens.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad brand-name triggers may activate for requests that do not call for a brand-specific design.

Mitigation: Confirm the requested brand and platform before adapting a reference.

Risk: The security assessment says some content was not fully evaluated and calls out install commands shown in examples.

Mitigation: Review the skill content and any install command before running it.

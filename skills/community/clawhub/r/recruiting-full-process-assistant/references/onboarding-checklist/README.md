# 入职检查清单

## 入职前准备（HR 负责）

### Offer 发放后

- [ ] 确认候选人接受 Offer
- [ ] 发送正式 Offer 邮件（含薪资、岗位、入职时间等）
- [ ] 收集候选人入职材料清单
- [ ] 启动背景调查流程
- [ ] 确认背调结果无误
- [ ] 建立员工档案

### 入职材料收集

**必填材料**:
- [ ] 身份证原件及复印件
- [ ] 学历学位证书原件及复印件
- [ ] 离职证明原件（应届生提供三方协议）
- [ ] 体检报告（近 3 个月内）
- [ ] 银行卡复印件（用于工资发放）
- [ ] 一寸照片 2 张（或电子版）
- [ ] 户口本首页及本人页复印件（办理居住证用）

**选填材料**:
- [ ] 职称证书/职业资格证书
- [ ] 外语等级证书
- [ ] 其他获奖证书
- [ ] 竞业限制协议（如有）

## 常见问题 FAQ

### Q1: 入职当天需要带什么？

**A**: 
- 身份证原件
- 学历学位证书原件
- 离职证明原件
- 体检报告原件
- 银行卡复印件
- 照片

### Q2: 劳动合同签几年？

**A**: 
- 首次签订一般为 3 年
- 试用期根据合同期限确定（3 年合同试用期不超过 6 个月）

### Q3: 社保公积金什么时候开始缴纳？

**A**: 
- 入职当月或次月开始缴纳
- 具体以公司政策为准

### Q4: 试用期多久？

**A**: 
- 根据合同期限和岗位级别确定
- 一般岗位：3 个月
- 高级岗位：6 个月

### Q5: 试用期工资是多少？

**A**: 
- 试用期工资不低于转正工资的 80%
- 具体在 Offer 中明确

### Q6: 什么时候可以转正？

**A**: 
- 试用期满前 2 周启动转正流程
- 通过转正评估后正式转正

## 使用说明

1. **HR 负责整体协调**：确保所有环节有人负责
2. **用人部门配合**：提前准备工位、设备、账号
3. **导师关键作用**：帮助新人快速融入
4. **及时沟通反馈**：发现问题及时解决
5. **持续优化流程**：根据新人反馈改进入职体验

### 依赖拓扑摘要

以下为任务的主要依赖链路，执行框架可据此自动编排管线：

#### 一、域内链路

**需求路由链路**: SS0-01 → SS0-02 / SS0-03 / SS0-04
**诊断适配链路**: SS1-01 / SS1-02 → SS1-03 → SS1-04 → SS1-05
**素材内容链路**: SS2-01 → SS2-02 / SS2-03 → SS2-04 → SS2-05
**组合搭配链路**: SS3-01 → SS3-02 → SS3-03
**交付输出链路**: SS4-01 / SS4-02 → SS4-03 → SS4-04 → SS4-05
**经营效益链路**: SS5-01 → SS5-02 / SS5-03 → SS5-04
**合规质量链路**: SS6-01 / SS6-02 → SS6-03
**知识维护链路**: SS7-01 → SS7-02 → SS7-03 → SS7-04

#### 二、跨域协同链路

**完整服务链路**: SS0-01 → SS0-02 → SS1-01 → SS1-03 → SS1-04 → SS1-05 → SS2-01 → SS3-01 → SS3-02 → SS4-01 → SS6-01 → SS6-03
**B 端经营链路**: SS4-02 → SS5-01 → SS5-02 / SS5-03 → SS5-04
**检索沉淀链路**: SS2-01 → SS7-01 → SS7-02 → SS7-03 → SS7-04
**守护贯穿链路**: SS4-01 / SS4-02 → SS6-01 / SS6-02 → SS6-03（交付前强制）
**用户资料链路**: SS7-04 → SS1-03 / SS2-01（资料优先于模型知识）

#### 三、三轴协同链路

**执行轴+内容轴**: SS2-01 → 清单法（九槽位）→ SS2-02 / SS2-03 → SS4-01 / SS4-02
**执行轴+创新轴**: SS2-04 → 变体规则（V-C/E/S/X/N）→ SS2-05
**三轴全开**: SS0-02 → SS1-01 → SS2-01 → SS2-04 → SS3-02 → SS6-03 → SS4-03

#### 四、知识图谱

将依赖拓扑扩展为知识图谱，支持更复杂的任务关系推理：

**实体节点类型**:
- **任务节点**: SS0-01~SS7-04（33 个任务）
- **域节点**: SS0~SS7（8 个域）
- **元操作节点**: S/C/A/O/I/G（6 个元操作）
- **领域负载物节点**: 素材条目 / 方案件 / 档案件 / 输出件

**关系边类型**:
- **依赖边**: 任务间的前后依赖关系（→）
- **组合边**: 任务间的组合关系（⇉/⇇）
- **输入边**: 任务的输入关系（如沟通卡 → 接待方案）
- **输出边**: 任务的输出关系
- **深化边**: 域内深化关系
- **路由边**: SS0-01 到各服务路径的路由关系
- **包含边**: 域包含任务的关系（SS0 → SS0-01~SS0-04）

**推理能力**:
- **路径推导**: 从身份分流到交付输出的最优路径
- **任务推荐**: 基于当前进度推荐下一步任务
- **依赖分析**: 前置依赖与后续影响分析
- **并行识别**: 识别可并行执行的任务组合（如 SS2-02 与 SS2-03 并行；SS5-02 与 SS5-03 并行）

更多组合根据具体任务动态推导。

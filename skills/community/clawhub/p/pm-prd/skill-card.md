## Description:

产品经理专用的 PRD(产品需求文档)生成、优化与扩展工具，用于从自然语言描述创建结构化 PRD、审阅已有 PRD 以补全模糊点，或向已有 PRD 追加新功能。

This skill is ready for commercial/non-commercial use.

## Publisher:

[xu4wang](https://clawhub.ai/user/xu4wang)

### License/Terms of Use:

MIT-0

## Use Case:

Product managers and product teams use this skill to create structured PRD Markdown from feature descriptions, clarify existing PRDs through targeted questions, and extend existing PRDs with new requirements while preserving numbering and terminology.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Clarify and extend modes can edit the wrong PRD if the user supplies an unintended path.

Mitigation: Confirm that the target path points to the intended PRD before using modes that save edits directly.

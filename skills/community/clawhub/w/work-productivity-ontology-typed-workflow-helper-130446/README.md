# Typed Ontology Workflow Helper

A modeling skill for turning messy notes, agent memory, domain objects, or research material into a typed ontology with validation and maintenance rules.

## Best For

- Agent memory schemas and structured note systems.
- Knowledge graphs for projects, research, CRM, support, or internal documentation.
- Converting loose tags into entity types, relationships, and provenance-aware records.
- Designing query prompts or retrieval filters around typed data.

## Outputs

- Entity and relation definitions with required fields and cardinality.
- JSON Schema, YAML schema, TypeScript types, tables, or graph model sketches.
- Valid and invalid examples for each important type.
- Merge, dedupe, migration, and versioning rules.

## Evidence

Demand was supported by ontology-style ClawHub popularity and related signals about typed knowledge, structured memory, composable workflows, and safety-first agent operation.

## Trigger

`Use $work-productivity-ontology-typed-workflow-helper to turn these notes into a typed knowledge graph.`

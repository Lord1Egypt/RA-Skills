# 出血热（HFRS与登革热）全流程诊疗

## 使用场景

1. **HFRS疑似** → 流行病学评估 + 五期分期 + 临床分型
2. **登革热疑似** → 病程分期 + 重症预警识别
3. **休克/重症** → 液体复苏 + 器官支持

---

## 第一部分：肾综合征出血热（HFRS）

### 1.1 流行病学评估

根据发病季节和暴露环境判断疫区类型：

| 疫区类型 | 分布环境 | 流行季节 | 宿主 |
|----------|----------|----------|------|
| 野鼠型 | 农田/林区/垦区 | 秋末冬季（部分地区6-7月小高峰） | 黑线姬鼠 |
| 家鼠型 | 城镇/市郊居民区 | 3-5月 | 褐家鼠 |
| 混合型 | 两型并存区 | 冬春季均可 | 两者并存 |

**暴露史核实**：发病前2个月内疫区旅居史，或鼠类及其排泄物/分泌物接触史

### 1.2 五期演变识别

```
发热期(D1-6) → 低血压休克期(D3-7) → 少尿期(D5-8) → 多尿期(D9-14) → 恢复期(D21-28)
```

| 分期 | 核心特征 | 关键指标 |
|------|----------|----------|
| 发热期 | "三痛"（头痛/腰痛/眼眶痛）、"三红"（颜面/颈/上胸潮红）、球结膜水肿 | 体温38-40℃；D2出现蛋白尿 |
| 低血压休克期 | 热退病重、渗出体征突出 | 持续1-3天；合并DIC |
| 少尿期 | 水钠潴留、高血容量、尿毒症脑病 | <400ml/d为少尿；<100ml/d为无尿 |
| 多尿期 | 脱水、低血钾、二次休克风险 | >2500ml/d；持续1-2周 |
| 恢复期 | 肾功能逐渐恢复 | 尿量<2500ml/d为标志 |

### 1.3 临床分型

| 分型 | 体温 | 尿蛋白 | 少尿/休克 | 并发症 |
|------|------|--------|-----------|--------|
| 轻型 | <39℃ | +~+++ | 无 | 无 |
| 中型 | 39-40℃ | +~+++ | 有少尿+低血压 | 皮肤瘀点瘀斑 |
| 重型 | >40℃ | ++++（可见蛋白膜） | 少尿≤5天或无尿≤2天 | 休克、腔道出血 |
| 危重型 | >40℃ | ++++（可见蛋白膜） | 少尿>5天或无尿>2天 | 难治性休克、严重器官损伤 |

### 1.4 发热期治疗

**一般治疗**：
- 卧床休息，物理降温为主
- 静脉补入平衡盐和葡萄糖

**用药安全边界**：
- ❌ **禁用**：阿司匹林、布洛芬（增加出血风险）
- ⚠️ **慎用**：对乙酰氨基酚等退热发汗药（加重循环血量不足）

**防治渗出**：
- 10%葡萄糖酸钙 10-20ml 稀释后缓慢静推，qd-bid
- 20%甘露醇 125-200ml 中低速静滴，qd-tid（肾功能障碍者禁用）
- 氢化可的松100-200mg 或 地塞米松5-10mg 静滴

**抗病毒**：
- 利巴韦林 10-15mg/(kg·d)，分2次静滴，日总量≤1500mg，疗程<7天

### 1.5 休克期液体复苏

**补液原则**：先快后慢、先晶后胶、晶三胶一、胶不过干

**液体选择**：
- 晶体液（首选）：复方醋酸钠林格液、乳酸钠林格液
- 胶体液：低分子右旋糖酐、血浆（首选）、白蛋白

**输液速度**：
- 首剂1000ml → 60分钟内快速滴入
- 其后2小时内 → 输入1000ml
- 后续根据监测指标调整

**复苏充分性监测（6项达标）**：
1. 收缩压 90-100mmHg
2. 脉压≥30mmHg 或 MAP>65mmHg
3. 心率<100次/min
4. 尿量≥25ml/h
5. 动脉血乳酸<2mmol/L
6. 红细胞/血红蛋白/血细胞比容接近正常

**血管活性药物**（血容量恢复后血压仍不足）：
- 首选去甲肾上腺素：起始8-12μg/min，维持2-4μg/min
- 联合多巴胺 2-20μg/(kg·min)（内脏灌注不足时）

### 1.6 致命并发症预警

| 并发症 | 发生时期 | 预警信号 |
|--------|----------|----------|
| 肺水肿/ARDS | 发热/低血压期、少尿末 | 呼吸急促、血氧下降 |
| 腔道大出血 | 各期（休克/少尿期高危） | 颅内/胃肠道/肺出血 |
| DIC | 休克期 | 出血加重、凝血指标异常 |
| 继发感染 | 少尿/多尿期 | 热程延长或体温复升 |

## 第二部分：登革热

### 2.1 临床病程分期

```
发热期(D1-7) → 极期(D3-8，关键！) → 恢复期
```

| 分期 | 核心特征 |
|------|----------|
| 发热期 | 急起高热(可达40℃)、"三红"、"三痛"、皮疹（皮岛）、结膜充血 |
| 极期 | **退热但病情加重**（关键特征！）、血浆渗漏、休克风险 |
| 恢复期 | 白细胞/血小板回升，病情好转 |

### 2.2 重症预警指征（出现任一即按重症处理）

- 热退后病情恶化或持续高热1周不退
- 严重腹部疼痛或持续呕吐
- 呼吸急促、胸闷、心悸
- 意识改变（昏睡/烦躁）
- 明显出血倾向
- 血压下降、少尿
- 血小板快速下降 + 血细胞比容升高 + 白蛋白降低
- 胸腔积液/腹水

### 2.3 重症登革热判定

在普通登革热基础上出现以下任一：

1. **严重出血**：皮下血肿、肉眼血尿、咯血、消化道出血、颅内出血
2. **休克**：心动过速、肢端湿冷、脉压减小、血压下降≥20%或<90/60mmHg
3. **严重器官损伤**：ARDS、急性心衰、严重肝损伤、急性肾衰、脑病

### 2.4 分级治疗

**普通登革热**：
- 防蚊隔离至退热及症状缓解
- 高热：物理降温 → 对乙酰氨基酚
- ❌ **禁用**：乙酰水杨酸、布洛芬（加重出血风险）
- 口服补液为主

**重症登革热**（住院/ICU）：
- **补液抗休克**：等渗晶体液 → 严重者加胶体；目标尿量0.5ml/(kg·h)
- **输血指征**：Hb<70g/L输红细胞；严重出血+PLT<30×10⁹/L输血小板
- **脑型**：20%甘露醇+呋塞米降颅压
- **呼吸抑制**：辅助通气

## 第三部分：实验室指标动态监测

### HFRS关键指标演变

| 指标 | 发热期 | 休克/少尿期 | 多尿期 |
|------|--------|-------------|--------|
| WBC | ↑(15-30×10⁹/L) | 达高峰 | 逐渐恢复 |
| 异型淋巴细胞 | D1-2出现 | D4-5高峰（比例越高越重） | 减少 |
| 血小板 | ↓ | 最低(10-60×10⁹/L) | 回升甚至>500 |
| 尿蛋白 | D2-4出现 | +++~++++ | 多尿后期转阴 |
| 血钾 | 偏低 | 高钾 | 低钾 |

### 登革热关键指标

- WBC：D4-5降至最低(2×10⁹/L)
- 血小板：减少幅度与病情严重程度正相关
- 血细胞比容：升高提示血浆渗漏
- NS1抗原：D1即可检出（早期确诊）

## Known Risks and Mitigations:

Risk: The security summary notes that broad trigger wording may activate the skill more often than intended.

Mitigation: Use it for GitHub or repository workflow help and confirm that activation matches the user's requested task before applying its workflow.

Risk: The skill can propose code, CLI, API, or configuration actions that may affect a repository or development setup.

Mitigation: Review proposed changes and commands before execution, and run the skill's suggested validation steps where code or data is involved.

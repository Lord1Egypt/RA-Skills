## Description:

Function Testing generates functional test cases from PRDs, Git commit logs, or user stories and structures them into an Excel-style report.

This skill is ready for commercial/non-commercial use.

## Publisher:

[addxing](https://clawhub.ai/user/addxing)

## Use Case:

Developers, QA engineers, and product teams use this skill to turn requirements documents, Git commit records, or user stories into focused functional test cases and an Excel-style test report.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated functional test cases and reports may be incomplete or incorrect for the user's specific requirements.

Mitigation: Review the generated test cases and report before relying on them for release or quality decisions.

Risk: The skill guidance is written in Chinese, which may cause misunderstanding for users who do not read Chinese.

Mitigation: Confirm that reviewers understand the guidance language or translate the generated report before use.

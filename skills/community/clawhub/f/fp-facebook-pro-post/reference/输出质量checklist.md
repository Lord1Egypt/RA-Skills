# 输出质量 Checklist

## 通用
- [ ] 选对了类型对应的格式
- [ ] 三部分齐全：正文 + Hashtag + 配图建议
- [ ] 全英文，符合北美专业受众
- [ ] 没有过度促销，建立信任优先

## 类型 A 科普
- [ ] 以 "Did you know…" 或问句/反常识开头
- [ ] 120-150 字
- [ ] 结尾有官网引导
- [ ] 技术内容留余地（often/may，不绝对化）

## 类型 B 客评
- [ ] quote ≤15 个英文单词（硬规则）
- [ ] 一条只引一次原句，其余转述
- [ ] 末尾有 CTA

## 类型 C KOL
- [ ] 1句介绍 KOL 背景
- [ ] 点出了具体 FP 配件
- [ ] 引流官网

## 类型 D 热点
- [ ] 开头接住了热点/节点
- [ ] 中间植入 FP 价值
- [ ] 结尾用提问引互动

---

## 微调提示
- 风格想更糙（工地口吻）或更克制 → 改 System Prompt 的 [风格偏好] 占位区
- hashtag 想固定某几个 → 填 [优先Hashtag]
- CTA 想统一话术 → 填 [固定CTA话术]

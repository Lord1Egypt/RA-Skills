## Description:

Sync WooCommerce products, orders, customers, coupons, reviews, custom post types, taxonomy terms, menus, users and custom database tables between WordPress sites with the PRO Import Export plugin abilities (rsl-ie-pro/*). Use only when the PRO plugin is active and the task goes beyond posts and pages.

This skill is ready for commercial/non-commercial use.

## Use Case:

WordPress and WooCommerce developers use this skill to plan and run cross-site synchronization or import/export for products, orders, customers, and related store data when the PRO Import Export plugin is active. It also guides safe bulk updates of supported content.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Bulk-update workflows can change existing content beyond the core synchronization task.

Mitigation: Confirm the update scope, back up the target database, and review counts and previews before starting a bulk update.

## Description:

Workplace check-in skill for Agent (Claw) with AI-generated personalized greetings.

This skill is ready for commercial/non-commercial use.

## Publisher:

[daizongyu](https://clawhub.ai/user/daizongyu)

### License/Terms of Use:

MIT-0

## Use Case:

Employees and agents use this skill to record workplace learning check-ins, maintain local check-in state, and generate concise personalized welcome, success, and daily greeting messages.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can run a local learning-checkin dependency found through filesystem search without verifying that dependency.

Mitigation: Review the installed learning-checkin dependency and confirm the resolved path before using the check-in command.

Risk: Sibling skill directories or OPENCLAW_DIR could influence which dependency path is selected in shared environments.

Mitigation: Use the skill only in trusted local environments where skill directories and OPENCLAW_DIR cannot be modified by untrusted users.

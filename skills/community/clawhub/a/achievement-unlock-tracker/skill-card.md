## Description:

Convert recent progress into a game-style achievement board with evidence, rarity, near-unlock targets, and hidden growth signals.

This skill is ready for commercial/non-commercial use.

## Publisher:

[harrylabsj](https://clawhub.ai/user/harrylabsj)

### License/Terms of Use:

MIT-0

## Use Case:

Employees, external users, and agents use this skill to turn recent actions, milestones, effort, and self-doubt into an evidence-based achievement board for weekly reviews, monthly reviews, motivation repair, or milestone reflection.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Users may disclose sensitive personal details while describing progress, setbacks, or self-judgment.

Mitigation: Treat the skill as a prompt-style reflection aid and avoid sharing sensitive personal details unless comfortable with the agent using those details in generated review text.

Risk: Achievement-style feedback could overstate progress if the input lacks concrete evidence.

Mitigation: Require achievements to be anchored in user-provided facts and ask for evidence before assigning achievements when the user provides feelings without facts.

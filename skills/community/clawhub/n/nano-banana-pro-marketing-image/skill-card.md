## Known Risks and Mitigations:

Risk: The helper can upload local files passed as reference images or media to AI Hive.

Mitigation: Pass only intended marketing or product-reference assets, and avoid documents, secrets, source files, or broad workspace and home-directory paths.

Risk: The security evidence recommends review before use because dependency installation and external API calls are part of normal operation.

Mitigation: Review the script before deployment, install trusted or pinned dependencies, and use API credentials scoped for this workflow.

Risk: Marketing-image prompts can create unsupported claims, unauthorized brand elements, or inconsistent campaign assets if inputs are not reviewed.

Mitigation: Use approved brand, product, and collaboration references only, and review generated assets for factual claims, permissions, and campaign consistency before publication.

## Description:

帮助用户撰写和优化简历、调整排版、导出 PDF，并基于简历内容准备面试问答。

This skill is ready for commercial/non-commercial use.

## Publisher:

[beikeliu](https://clawhub.ai/user/beikeliu)

### License/Terms of Use:

MIT-0

## Use Case:

External users use this skill to create or revise resumes, tune resume layout, export HTML resumes to PDF, and prepare interview questions and answer outlines from resume content.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Resume work can involve personal and employment information.

Mitigation: Use the skill only when the user is comfortable providing that content to the agent.

Risk: The skill saves generated resumes and interview notes in the user's workspace.

Mitigation: Review workspace files after use and remove sensitive drafts or notes that should not persist.

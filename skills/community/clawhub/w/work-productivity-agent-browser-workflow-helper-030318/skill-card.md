## Use Case:

Developers, AI-agent users, skill authors, maintainers, and teams use this skill to turn Agent Browser-style workflow needs into practical plans, automation outlines, checklists, code changes, analysis, or decision support. It emphasizes reliability, setup hardening, safety review, and local-hardware friendly execution.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad trigger terms may activate the skill for ordinary browser, CLI, automation, or bug-fix requests where this specialized workflow is not needed.

Mitigation: Narrow activation wording during review or deployment and confirm the user's intended Agent Browser-style workflow before applying the skill.

Risk: Workflow advice or generated code changes could still be incorrect or incomplete for a user's specific environment.

Mitigation: Validate outputs against the stated success criteria and keep assumptions, limits, and required inputs visible before execution.

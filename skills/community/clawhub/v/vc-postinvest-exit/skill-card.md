## Description:

This skill helps VC users create post-investment monitoring briefs and exit-strategy recommendations for portfolio companies, including operating metrics, milestones, risk alerts, IPO/M&A/buyback paths, and return assumptions.

This skill is ready for commercial/non-commercial use.

## Publisher:

[zhuiwensm99](https://clawhub.ai/user/zhuiwensm99)

### License/Terms of Use:

MIT-0

## Use Case:

VC and portfolio-management users use this skill to turn portfolio-company updates into Markdown monitoring briefs and exit-strategy options for LP communication and investment follow-up. It emphasizes sourced operating metrics, explicit assumptions, risk levels, and recommended investor actions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may handle sensitive portfolio-company metrics, financing details, risk flags, and return assumptions.

Mitigation: Review and redact sensitive information before sharing outputs, and clearly label estimates, assumptions, source dates, and unverifiable data.

Risk: Optional publishing to ima could expose confidential post-investment or exit information outside the current conversation.

Mitigation: Publish only after explicit user confirmation of the target space, visibility, and data-redaction requirements.

Risk: Broad finance trigger terms could activate the skill in contexts where the user did not intend to prepare publishable portfolio materials.

Mitigation: Confirm whether the user wants a post-investment brief, an exit strategy, or both before preparing externally shareable content.

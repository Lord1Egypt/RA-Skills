# Materials: a weekly newsletter

[Chinese edition](https://github.com/gengshupeng/open-x-sys/blob/main/skills/open-x-sys.zh-CN/experience/playground/subjects/sample-creative/ABOUT.md)

> **A ready subject for the Playground: a sample creative project.**
> This is a **constructed sample**, written for the Playground. The author, the newsletter and every number in it are invented. It is not a record of a real person.
> It was built to be worth opening a system for: there is an intent, a working routine, twelve weeks of the author's own records, and a draft in progress. **This file does not say what they show.** Finding that is the run.

## Files

| File | What it is |
|---|---|
| `brief.md` | What the author says the newsletter is for |
| `log.csv` | Twelve weeks: hours by stage, and what each issue did |
| `notes.md` | The author's working notes |
| `issue-13-draft.md` | The draft in progress |

## How to use it as a subject

- This subject stands in for "the person's own work". Read it the way you would read a person's own files: every judgment points to a file as evidence, and judgments about the author are offered as inferences.
- Good first prompts: "Open a system for this newsletter." · "Where does the time go?" · "Given what this author has, what is the best way to make the weekly issue?" · "Run Musk's algorithm on this weekly routine."
- With a creative project the source of truth is the author's intent and taste. "Confidence" means "would the author agree?"

## Use Case:

Developers and engineers use this skill to plan new applications, refactor existing project structure, select technology stacks, and generate architecture-oriented documentation and configuration starters.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated architecture, Docker, lint, and template files may be applied to a project without sufficient local review.

Mitigation: Review generated files and commands before applying them, especially Docker settings, lint configuration, and security checklist changes.

Risk: The skill can influence high-level project structure and technology choices for new or refactored applications.

Mitigation: Validate recommendations against the project's operational requirements, security model, scalability needs, and team constraints before adoption.

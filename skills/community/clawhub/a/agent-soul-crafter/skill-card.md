This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and agent builders use this skill to draft and review SOUL.md personality templates for agents, including identity, traits, expertise, response style, and safety boundaries.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated SOUL.md files may copy illustrative German or mixed-language examples that do not match the intended user audience.

Mitigation: Customize language preference, response style, and examples for the intended users before deploying the generated SOUL.md.

Risk: Personality templates can omit or weaken explicit safety boundaries if copied without review.

Mitigation: Review each generated SOUL.md for clear domain limits, approval requirements, privacy rules, and escalation behavior before use.

## Use Case:

Developers and engineers use this skill to guide coding tasks through structured planning, implementation, review, and delivery. It is suited to tasks ranging from small fixes to larger multi-module development work.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation on coding-related prompts can lead the agent to propose or make extensive code changes.

Mitigation: Review the plan, inspect diffs, and run appropriate tests before accepting changes.

Risk: Optional web research may introduce outdated or low-quality technical guidance.

Mitigation: Prefer official documentation and verify current package versions, APIs, and security guidance before implementation.

# 综合医院会诊联络精神病学与痴呆管理

## 适用场景

当遇到以下情况时使用本技能：
- 综合医院非精神科请求精神科会诊
- 患者出现认知功能障碍需鉴别痴呆类型
- 痴呆患者出现行为和精神症状(BPSD)
- 患者有持续躯体症状但缺乏器质性证据
- 综合医院躯体疾病患者伴发焦虑/抑郁
- 需要判断精神症状是否由躯体疾病/物质所致

## 核心工作流程

### 1. CLP会诊七步标准流程

```
步骤1：与申请医师沟通
    ├─ 明确会诊目的
    ├─ 纠正偏差，明确真正心身问题
    └─ 补充躯体疾病知识
    ↓
步骤2：了解现病史和既往史
    ├─ 查阅住院/护理记录
    ├─ 向家属了解人格、功能、生活事件
    └─ 询问共病精神疾病史
    ↓
步骤3：与患者面谈及检查
    ├─ 建立关系，共情安慰
    ├─ 重点：焦虑/抑郁/精神病性症状
    ├─ 认知：定向力、注意力、MMSE/画钟
    ├─ 神经系统：肌张力、反射
    └─ 建议：脑影像、脑电图
    ↓
步骤4：了解躯体治疗状况
    ├─ 排查药物不良反应（时间关系）
    └─ 排查隐瞒/停用精神药物、物质滥用
    ↓
步骤5：诊断并制定方案
    ├─ 对症治疗为主
    ├─ 辅以心理干预/支持
    └─ 灵活就诊安排
    ↓
步骤6：书写会诊记录
    ├─ 简明扼要
    ├─ 绝对避免精神科专业术语
    ├─ 详细药物滴定过程
    └─ 告知减药/撤药方法
    ↓
步骤7：随访
    └─ 同一医师或专门小组保证连续性
```

### 2. CLP核心原则与角色边界

**指导思想**：身心统一，患病本身作为应激事件

**知识储备**：
- 常见躯体疾病的精神症状表现
- 精神药理学（药代/药效、药物相互作用）
- 特殊人群用药注意事项

**角色边界**：
- 以请求会诊科室的躯体治疗为主
- 精神科提供服务，绝不喧宾夺主
- 充分理解躯体治疗重要性

### 3. 痴呆诊断决策树

```
认知功能障碍 + 锥体外系/精神症状
    ↓
评估核心临床特征（4项）
    ① 波动性认知障碍
    ② 生动幻视
    ③ RBD
    ④ 帕金森综合征
    ↓
评估提示性生物标志物（3项）
    ① SPECT/PET基底节DAT摄取减少
    ② MIBG心肌扫描异常
    ③ PSG示REM肌肉弛缓消失
    ↓
诊断判定
    ├─ 很可能DLB：≥2核心特征 或 1核心+≥1标志物
    ├─ 可能DLB：1核心+标志物 或 仅标志物
    └─ 可能性很小：其他疾病可解释
```

**关键约束**：仅基于生物标志物不能诊断很可能的DLB

### 4. FTD三大亚型鉴别

| 亚型 | 核心表现 | 言语特点 | 认知特点 |
|------|----------|----------|----------|
| bvFTD | 精神行为/人格改变（脱抑制、淡漠、强迫） | 判断障碍为主 | 定向力保留 |
| SD（语义性痴呆） | 命名性失语，词语/客体理解减退 | 流利但不被理解，复述保留 | 记忆/视空间保留 |
| PNFA | 言语功能障碍（缓慢、发音困难、语法缺失） | 找词困难、语法错误 | 词语理解保留 |

**鉴别要点**：发病年龄45-70岁，需与AD（早期记忆损害、内侧颞叶萎缩）鉴别

### 5. bvFTD诊断标准流程

```
疑似bvFTD（满足A-F中≥3项）
    A: 早期去抑制
    B: 早期冷漠/迟钝
    C: 早期同情心丧失
    D: 早期强迫/刻板行为
    E: 口欲亢进/饮食改变
    F: 执行功能障碍
    ↓
可能bvFTD（同时满足3条）
    ✓ 符合疑似标准
    ✓ 功能受损证据
    ✓ 影像学：额叶/前颞叶萎缩或低代谢
    ↓
病理确诊
    ✓ 符合疑似/可能
    ✓ 病理证据或致病基因突变
    ↓
排除标准（必须均为否定）
    ✗ 非退行性疾病引起
    ✗ 更符合精神病学诊断
    ✗ 生物标志物提示AD
```

### 6. BPSD管理阶梯式干预

```
病因排查
    ├─ 急性躯体疾病？
    ├─ 心理需求未满足？
    ├─ 照料者压力？
    └─ 环境刺激过度？
    ↓
一线：非药物干预（首选）
    ├─ 感官刺激治疗
    ├─ 行为干预
    └─ 音乐治疗
    ↓ 无效
二线：药物治疗
    ├─ 抗精神病药
    ├─ 抗抑郁药
    └─ 心境稳定药
    ↓
密切监测不良反应
```

### 7. 躯体痛苦障碍(BDD)识别

**概念更新**：
- ICD-11：躯体痛苦障碍(BDD)，整合功能性躯体综合征
- DSM-5：躯体症状及相关障碍，基于阳性症状诊断

**临床识别要点**：
- 避免简单推诿（无器质性证据≠纯精神问题）
- 避免过度检查循环
- 摒弃心身二元论（躯体与心理常共存）

**诊疗策略**：
- 建立同盟关系，共情倾听
- 综合治疗：药物 + CBT + 放松技术
- 多学科合作

### 8. 综合医院焦虑/抑郁共病评估

**科室特异性风险**：
| 科室 | 焦虑比例 | 抑郁比例 |
|------|----------|----------|
| 神经内科 | 11.7% | 15.6% |
| 消化内科 | 9.4% | 14.4% |
| 心内科 | 7.8% | 10.6% |
| 妇科 | 5.4% | 7.86% |

**神内特定疾病**：帕金森24.1%、癫痫21.9%、卒中19.5%

**病因机制**：
- 心理应激：疾病痛苦、功能丧失、经济负担
- 病理生理：免疫→大脑功能改变

**共病负面影响**：增加痛苦、恶化病理、增加死亡率、影响依从性

### 9. 精神活性物质所致痴呆诊断

必须同时满足5条：
1. 符合痴呆通用标准
2. 认知损害超出中毒/戒断病程
3. 该物质已知可致认知损害
4. 时序关系符合
5. 不能由其他疾病解释

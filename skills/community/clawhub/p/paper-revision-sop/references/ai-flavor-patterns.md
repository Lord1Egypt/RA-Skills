# AI写作味检测词库

> 本文档为 `paper-revision-sop` 技能Phase 1诊断阶段的参考数据。
> 按风险等级分为 🔴致命 / 🟠重度 / 🟡轻度 / 🔵中性 四级，
> 诊断脚本 `diagnose_paper.py` 可直接调用此词库进行模式匹配。

---

## 🔴 致命级（出现即判定AI代写嫌疑）

### 标题模板
- `从X到Y：Z的……` 对仗式
- `基于……的……研究——以……为例`
- `……视域下……的……路径探析`
- `……赋能……的机制创新与深化路径`

### 排比收尾模板
- `以……为……以……为……以……为……以……为……`（四连及以上）
- `一方面……另一方面……再者……最后……`

### 概念拔高术语（无实际论证支撑时）
- `双螺旋结构`（生物学隐喻生搬）
- `深层互构` / `双向赋能` / `同频共振`
- `认知跃迁` / `范式转换` / `底层逻辑`
- `信息平权` / `数字平权`
- `群体智慧` / `涌现效应`

### 空泛收尾术语
- `系统性尝试` / `深度变革` / `根本性重塑`
- `为……提供理论参照与实践镜鉴`
- `有待进一步深化与拓展`

---

## 🟠 重度级（密集出现时可疑）

### 学术套话句式
- `不仅是……更是……`
- `从……层面……从……维度……从……视角……`
- `实现了……的有机统一`
- `为……奠定了坚实基础`
- `彰显了……的独特价值`
- `推动……从……向……转变`

### 数字罗列式结构
- `N个维度` / `N个层面` / `N个要素` / `N个阶段` — 且每个维度仅1-2句
- `一是……二是……三是……四是……` — 连续4个以上

### 产品目录式罗列
- 连续出现5个以上具体软件/平台/工具名称
- 工具名+功能简述的固定句式重复

---

## 🟡 轻度级（需结合上下文判断）

### 过度工整
- 连续段落以相同句式开头
- 标题字数高度一致（如均为22字双句）
- 段落长度高度均等

### 模糊量化
- `显著提升` / `大幅改善` / `明显增强`（无数据支撑）
- `有效促进` / `积极推动` / `有力保障`

### 万能转折
- `与此同时` / `在此基础上` / `进而言之`
- `值得注意的是` / `需要指出的是`
- `从某种意义上说`

## 使用说明

诊断脚本应：
1. 统计各风险等级匹配次数
2. 计算"AI味密度" = (致命×5 + 重度×3 + 轻度×1) / 总字数×1000
3. AI味密度 > 15 → 高度可疑；5-15 → 中度；<5 → 可接受
4. 对匹配到的具体位置输出行号和高亮标记

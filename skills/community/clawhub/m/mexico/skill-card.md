## Use Case:

External travelers use this skill to plan Mexico trips with city, region, food, accommodation, transport, safety, and pacing guidance tailored to their trip style.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Trip preferences may be stored and reused from a local plaintext ~/mexico/memory.md file across sessions.

Mitigation: Use session-only planning if persistent memory is not desired, and do not save reservation codes, passport details, payment data, credentials, or sensitive health information; review or delete the memory file when the trip is over.

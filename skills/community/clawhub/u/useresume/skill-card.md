## Description:

Generate professional PDF resumes and cover letters via the useresume.ai API. Supports creating, tailoring (AI-optimized for a job), and parsing documents.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and agents use this skill to generate, tailor, and parse resumes and cover letters through the UseResume API and CLI.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Resume, cover-letter, job-description, and related personal data is sent to useresume.ai.

Mitigation: Use the skill only when the user is comfortable sharing that data with useresume.ai, and avoid uploading third-party documents unless permission is clear.

Risk: The documented installation uses an unpinned global npm CLI package.

Mitigation: Review or pin the npm CLI version before global installation.

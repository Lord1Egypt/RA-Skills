# 数据卡模板（精简版）

> **精简版**：只保留骨架 + 必填字段，详细说明见 [`数据卡-template.md`](数据卡-template.md)

```markdown
# 数据卡（Dxx 系列）

> **位置**: `run/<项目名>/data/数据卡.md`
> **检索员**: T2 数据检索员（启动时间 + 模型）
> **截止**: YYYY-MM-DD

## 基本信息

- **总条数**: N
- **信任级别声明**: 已发布 N1 / 主人投喂 N2 / 二手转引 N3（N1+N2+N3 = N）

## 数据卡列表（按主题分组）

### [D01] 数据标题
- **主题**: xxx
- **数值**: xxx
- **来源**: 机构名 + 年份 + URL
- **信任级别**: 已发布 / 主人投喂 / 二手转引（**文字取值**；emoji 🟢🟡🔴 仅用于时效评级，两者不共用）
- **时间窗口**: YYYY-MM-DD ~ YYYY-MM-DD
- **支撑论点**: 论点 X（详见分析大纲.md）

### [D02] ...

## 交付前自检

<!-- 人类验证命令（agent 零 exec，由主控 LLM 推理完成） -->
- 统计实际条目数：`^### [D` 开头行数
- 统计声明总条数：基本信息段声明的 N
- 两数必须一致 → T2.5 闸门不拦截
```

**关键约束**：

| 字段 | 说明 |
|------|------|
| **信任级别必填** | 每条 [Dxx] 必须标**文字取值**（已发布/主人投喂/二手转引）—— M-Form-6 + M-Exist-3 校验口径 |
| **URL 必填** | M-Exist-1 双向对比校验 |
| **时间窗口** | G11 时效告警 |
| **支撑论点** | F1 论证依据匹配 |

**字段命名约定**：
- 主题：一句说人话
- 数值：精确数字 + 单位
- 来源：机构 + 年份 + URL
- 支撑论点：链向分析大纲

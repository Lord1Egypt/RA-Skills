# LeverMaTH 仓库约定

本项目是供 AI 协助中国数学教师制作可交互 HTML 幻灯片的源码模板。使用或开发前，先阅读根目录 `SKILL.md`、`README.md` 与 `docs/` 下相关文档。项目内的规则独立完整，不依赖任何开发者电脑里的私人偏好文件。

## 工作流程

1. 明确本次课件的教学目标、受众和预计帧数；先设计完整的画面与讲授顺序，再安排动画。
2. 复制基础模板到目标工作区，在目标工作区编辑课件；不要直接改安装在 agent 技能目录中的模板。
3. 统一使用 1280×720 舞台。`data-k` 标记跨帧连续元素，`data-enter` 与 `data-step` 标记教师按键触发的分步入场。
4. 一切数学变量和公式使用本地 KaTeX。交互式几何优先用 JSXGraph 的 SVG 渲染器；只需静态图时，可用 TikZ 生成 SVG。
5. 公开版只内嵌许可明确、允许分发的字体。每份课件修改文字后重做字体子集；不能把一份课件的字集当作通用字库。
6. 构建成离线单文件，验证缩略图、全屏、PgUp/PgDn、KaTeX、拖动交互和字体加载。

## 注意

- 基础模板只留机制与占位演示；课程相关照片、几何源文件和文字放各自的示例或独立课件。
- 本地工作区不自动提交。先向使用者报告变更与检查结果，再等待明确的提交许可；一次许可只适用于那一次提交。发布到 GitHub、上传市场或 npm 属于对外行为，也要单独确认。
- 非经允许，`README.md` 不作修改。

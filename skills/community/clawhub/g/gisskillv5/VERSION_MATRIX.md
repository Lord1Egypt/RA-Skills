## 七、版本检索规则

```
触发词例：
  "ArcGIS Pro 3.6" → 仅12号内容
  "ArcGIS Pro 3.7" → 12号基础 + 38号新增
  "ArcGIS Pro"（未指定） → 默认3.7 = 12号 + 38号
  "QGIS 3.40" → 13号3.40 LTR章节
  "CASS 12.0" → 14号为主，标注版本差异
  "CGCS2000" → 02号 + 04号
```

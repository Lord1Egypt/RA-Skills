# 发布平台合规参考

> 本文件在**第六步之后（平台勾选定下）加载**，作为**写作过程中的合规扫描**；第九步校订期做**最后一道闸门**复核。
> 与 `references/style-and-bans.md` 并列但维度不同：`style-and-bans.md` 管**形式禁令**（翻案腔 / 名词化 / 商业黑话 / AI 味），本文件管**平台审核**（能不能发、发出去会不会被限流 / 屏蔽）。
> 起草期（第七步）不加载——起草期只守「不编造」（见 SKILL.md 第七步「起草期许可」）。
> 本文件不堆平台细节，抽**跨平台共识**：低创作度、导流、AI 披露。各平台审核口径会变，判定原则比具体条目持久——具体条目以当时最新公告为准。

**共识来源**（四个平台）：
- **微信**：「低创作度案例解析」「导流案例解析」（2025-10）
- **小红书**：社区公约 3.2（导流零容忍）、3.1.4（虚假营销）、AI 内容需标注
- **知乎**：AI 辅助创作公告（2026）、社区规范（抄袭 / 恶意营销导流）
- **少数派**：见 `references/sspai-format.md`（AI 披露 callout、利益相关声明）

**触发时机**：用户在第六步勾选发布平台后立即加载本文件扫描当前草稿；写作过程中若发现踩线，**在当下改**，比校订期再返工便宜得多。校订期第九步再复核一遍，作最终闸门。

## 适用与豁免

- **在稿件指向任一已覆盖平台时生效**（任一命中即生效）：**① `style.md` 的「发布平台」勾选了 少数派 / 微信 / 小红书 / 知乎 之一**（主判据）；② 作者明确说要发到某覆盖平台；③ 作者草稿或文章的 frontmatter 带平台标识（如 `platform: [sspai.com]` / `client: [sspai]`）
- **不发这些平台的稿件豁免本文件**（只看 `style-and-bans.md`）
- **Agent 自己写的 `ai-draft.md` 是用户草稿的一部分**——扫描时把 Agent 的产物和用户的稿子一视同仁，用户决定采纳哪一段。Agent 不用自己给「我这段是不是 AIGC」打标，但**不能把整段 AI 生成的文字不改动地塞进 `ai-draft.md`**（等于把低创作度原文照搬的责任从用户转嫁给 Agent）。最低增量：AI 生成段落采纳前，作者要**改结构 + 补自己的判断**，不能只改措辞。

## 两层结论：机器层与实质层

每处命中分别给两个结论，**两层独立成立，不许互相顶替**：

- **机器层**：平台自动审核、名单召回、外链与二维码识别、连续数字、OCR 噪声、重复模式**可能识别到什么**。这一层只能写「**可能触发机器审核**」，**不许补造一条违规理由**——词被名单命中不等于内容有问题，替机器编理由会逼作者删掉本来正常的句子。
- **实质层**：内容本身有没有真问题（欺诈、虚假承诺、违规导流、受限推广、侵权、隐私、攻击、危险行为）。这一层**必须给独立机制**：指到哪句话、它凭什么构成问题、改掉它能消除什么。只有关键词、标签、名单命中而说不出机制的，不进实质层。

两层的关系：机器层回答「可能被拦」，实质层回答「该不该改」。**机器层命中不升级成实质违规，实质违规也不因为机器没拦就当不存在。**

## 证据强度三级

每个信号先归一级，再决定报不报：

- **明显触发信号**：完整外链、联系方式、二维码、明确的广告结构、连续长数字、敏感主题与行动组合、破碎 OCR 或明显重复堆叠。可进入「可能触发机器审核」。
- **名单型信号**：品牌名、竞品平台名、药品名、圈层标签缩写。只能写成「**可能命中名单**」——**不许升级成内容违规**，也不许据此改写正常表述。
- **弱词面线索**：普通关键词、正常数字、普通姓名、无法验证的经验推测。**保持沉默：不进报告。**

纪律：**不用百分比预测违规概率，不承诺平台一定怎么处理**——前者的落点是「平台规则时效纪律」的数字禁区，后者落成「报告写法」里的禁句。归不了级的信号，按弱词面处理。

## 最小必要干预：什么不构成风险

扫描之前先立这一条。它管的是**不许拿合规压平风格**：

- **先说清不构成风险的东西**：强观点、情绪化表达、冲突结构、偏激判断、口语、夸张修辞、隐喻、个人偏好——**本身不构成风险**。
- 「更规范」「更稳妥」「可能让人联想到」**不构成修改依据**。
- 说不清改完降低的是哪一项**具体**风险，**不给修改建议**。
- **不以降低争议、提高专业感为目标**——那是在改作者的立场，不是在过合规。
- 只删局部词句能解决时，**不改写整段**。

> 这条闸门在形式改稿一侧的对应表述见 `style-and-bans.md`「改到哪停」：那边问「会让读者误解什么」，这边问「降低了哪项具体风险」——**同一条原则，两个场景各用各的话说，判据只在一处详细定义**。本节只管合规结论，不重复干预形式禁令的执行。

本节与文末「和 `style-and-bans.md` 的分工」里那条**「命中红线不能用『文风就是这样』豁免」互为配重**：那条管**不许拿文风挡红线**，本节管**不许拿合规压平风格**。两条方向相反、同时有效——只剩前者，稿子会被删得没有声音；只剩后者，红线会被一句「这是我的风格」挡掉。

## 三档结论

按证据强度归级之后，只输出三档，**没有第四档**：

- **高风险**：已出现清晰的欺诈、违规导流、受限推广、虚假承诺、侵权、隐私、攻击或危险机制。写清位置 → 后果 → 动作。
- **需确认**：结论取决于还没拿到的事实——品类、利益关系、资质、授权、证据、载体、平台当前规则。**必须写清缺哪个事实，以及不同情形分别是什么结论**（有资质 → 结论 A；没有 → 结论 B）。只写「需确认」三个字不算结论。
- **低置信度线索**：有可观察信号，但说不清风险类别或升级条件。**不足以单独成条时不输出。**

**不能单独定罪的五样**：商业属性、敏感词面、名单命中、二维码、人脸。任何一样只能把话题送进「需确认」，不能直接判高风险。**第二类风险需要独立证据**——同一处不能拿两个相邻标签互相作证。

## 内容层扫描（六项）

六项查的是**实质层**里按载体切开的六类位置；机器层与证据归级在上文已定，这里不重复判。逐项过一遍草稿，每项都要能指认到具体位置或具体信号——给不出就当作未扫描。

**每处命中必须同时给动作类型（六选一），不许只写「建议修改」**：

1. **补**真实主体、条件、范围、时间或来源
2. **删**无法证明的权威、排名、销量、效果结论
3. **换**成获准表述或客观参数（功效 → 可观察体验 / 可测参数）
4. **改入口**：站外导流改目标平台当前允许的发布、商品、招聘或联系入口
5. **补披露**：真实商业利益、资质、授权、活动期限
6. **只删局部**——「最小必要干预」的落地形状

动作归不进六选一，说明这处还没查清：回补位置与机制，拿「建议修改」糊过去不算结论。

### 一、标题与小标题（4 项红线可能都藏在这）

**扫什么**：标题、所有 `##` / `###` 小标题、首段前 3 行。

**红线信号**：
- **标题党**：绝对化用语（「最 / 唯一 / 100% / 根治」）、情绪煽动词（「震惊 / 必看 / 后悔没早知道」）、图文不符
- **敏感品类**：医美、医疗器械、金融、保健品——高判罚风险，无资质不发（三类逐项核对见「受限品类」）
- **导流话术**：标题里塞「扫码 / 加群 / 完整视频见」等
- **AI 味标题**：模型路标式（「更微妙的是 / 只说对了一半」）、抽象抒情、煽动式金句

标题是宣传位，绝对化用语按红线处理；正文论述位怎么判，见「裁定：绝对化用语分位置判」——同一件事只在那里定义一次。

### 二、正文原文与段落（低创作度三条 + 引文归属）

**扫什么**：全文每一段（尤其连续 3 段以上无插话的段落）。

**红线判据（同时满足才命中，任一不满足都不算）**：
- **直接搬运站外内容**：连续 **≥ 200 字** 与单一外部来源高度重合（≥ 80%），**且**无自己的观点或补充表达
- **AIGC 文字原文照搬**：AI 生成的**逻辑结构与措辞均未改**（改两三个词但保留原文论证结构 = 仍属命中）
- **图表原样搬**：**从站外**搬的图表未重绘 / 未重述——自制图不受影响

**引文归属**：每处引用他人观点，首次出现要说明是谁说的。全部靠公开材料撑论点时，开头附近留一处检索痕迹（一句「参考了 X / Y」）。

### 三、图片（AI 配图 + 素材来源）

**扫什么**：每张正文图片（含题图）、图片标题、图片说明。

**红线判据（三条件同时满足才命中「AI 图片为主体」）**：
- AI 生成图**是主体素材**（首图 / 占正文图片 ≥ 50% / 主题封面）
- 存在**明显不合理之处**（手指畸形 / 文字扭曲 / 光影矛盾）
- **无作者观点评述**——正文没有围绕这张图展开判断、评论、延伸

**豁免三条件（同时满足即豁免）**：
- **披露**：图片来源 / AI 生成 / 版权标注清晰（文首 callout、图片标题、或文末注释任一处）
- **有增量**：正文围绕图片有原创观点（评价方法论 / 适用性 / 自己的判断）
- **非主体**：不是首图 / 不是全文唯一素材

**白名单**（明确不是「AI 生成」）：作者实拍、系统截图、品牌 logo、CC0 公开素材、明确标注来源的第三方素材。

**隐私与敏感呈现**（长文贴截图最容易翻车的地方，逐张过）：

- **证件与交易**：身份证、护照、驾照、车牌、快递单、订单号、支付信息、发票——**打码或换图**；打不了码就换一张。
- **私人对话与名单**：聊天记录、群成员列表、屏幕通知、通讯录、定位、住址——只保留论述必需的那一两句，其余遮掉；他人的姓名、头像、联系方式默认遮。
- **他人可识别内容**：未经同意不放能让陌生人认出某个具体个人的私人内容（包括工作单位、住址、常去地点）。
- **判据一句话**：**这张图会让一个陌生人找到照片里的人或那笔交易吗？** 会 → 先处理再谈别的。处理是打码、裁切、重绘，**不是编一条免责说明**。

### 四、外链与二维码（引用 vs 导流的边界）

**扫什么**：全文所有链接、图片 alt、文中提到的二维码 / 群聊 / 小程序。

**引用来源类链接（不属导流）**：
- 官方文档、维基百科词条、原始文章 / 采访原文
- 作者自己的 GitHub 代码仓库、工具官网（工具教程里的必要资源指引）
- 作者自己的其他公开内容（读者自主跳转，无交易 / 骚扰链路）

**跳转引导类链接（属导流红线）**：
- 二维码图片、短链（t.cn / d.cn / douc / bililink）
- 小程序跳转按钮、「戳这里 / 点这里 / 扫码领」CTA 话术
- 引导到群聊、公众号、其他公众号、第三方商城 / 直播间

**判断口径**：链接是**为了让人能查到来源**，还是**为了让人跳转去做动作**（关注 / 加群 / 下单 / 私信）。前者放行，后者算导流。

### 五、正文里的导流话术（关键词表）

**扫什么**：正文每一个段落（尤其文末 200 字）。

**关键词表**（命中任一即视为命中，需要作者判断是引用还是引导）：
- **互动导流**：`加V / 加 v / 加微 / 加我微信 / vx / wx / weixin / 私我 / 私信我 / 扫码 / 加群 / 评论区扣 1`
- **内容导流**：`完整版见 / 全文见 / 戳这里 / 点这里 / 扫码领 / 跳转 / 小程序 / 详细版见`
- **多重嵌套**：`加助理 / 加小助手 / 加客服 / 加我助理 / 助理会拉你进群`

**注意**：命中关键词不代表一定违规——引用别人写过的话、介绍某功能、讨论某产品的官方术语都可能带这些词。按「证据强度三级」归级后报出：明显的与名单型的报位置，弱词面保持沉默；报出来的仍由作者判断是引用还是引导。

### 六、AI 使用披露（跨平台一致要求）

**扫什么**：文首的披露段（少数派用 `> [!NOTE]` callout）、文末的声明，以及稿件 frontmatter 里若有的披露字段。

**各平台要求**：
- **少数派**：**强制**。文首用 `> [!NOTE] AI 辅助创作披露` callout，写明工具 / 用途 / 目的 / 范围（见 `references/sspai-format.md` 「AI 使用披露」）。2026-10-15 修订后**不再要求**具体提示词与修改过程；AI 味浓但未完全声明的内容，若动机诚实 + 对读者有价值 + 不让读者误会是原创，可获编辑部豁免
- **小红书**：**强制**。AI 生成图 / 视频需声明为 AI 生成
- **知乎**：**要求显著标识**。依《人工智能生成合成内容标识办法》——AI 生成内容需在醒目位置标识
- **微信**：**未强制**，但披露后降低误判风险

**推荐范式**（跨平台通吃，一次披露到处能用）：
> 本文基于作者真实经历独立完成，后期使用 [工具名] 进行结构讨论 / 语言优化 / 部分资料整理。

**不默认贴会话链接**：对话里往往混着未公开草稿、私人信息、别人的材料，贴出去等于把这些一起公开。真要贴，先征得作者同意，并和他一起过一遍对方能看到的全部内容；默认只披露工具与用途。

**兜底原则**：**未披露 + 无明显 AI 味 + 有原创表达 = 默认视为原创**。规则不变成「只要没披露就有风险」——那会让所有稿子都得披露才敢发。

### 裁定：绝对化用语分位置判

「最 / 唯一 / 100% / 根治」在两类位置上结论不同：

- **宣传位**（标题、封面文字、摘要 / 导语、CTA、商品描述）：**维持严判**，按红线处理。这些位置读者按广告读，平台也按广告审。
- **论述位**（正文论证中的判断句）：先分三种，**只有第三种判红线**——
  1. **主观判断**：「我认为这是唯一可行的做法」——有主语、有立场、能被一句「但……」顶回来。放行。
  2. **叙事强调**：「唯一一次见面」——说的是次数或程度，不是功效承诺。放行。
  3. **商业宣传**：「唯一能彻底解决 X 的产品」「100% 见效」——在卖东西、在承诺结果。判红线。

理由是观点型长文的实际形态：正文里的「唯一」常常是**立场修辞**，按词面判红会把一篇价值判断的文章改成谁都不敢下判断的通稿。判的时候只问一句：**这句是在卖东西，还是在说观点？**

## 受限品类（金融 / 医疗健康 / 教育培训）

这三类判罚风险高于普通内容。稿子涉及哪一类，就逐条核到；核不清的归「需确认」，不许含糊放行。**涉及不等于违规**——过不去的是「没核」，不是「提到了」。

- **金融**（理财 / 保险 / 借贷 / 荐股 / 加密资产）：① 主体有没有金融业务资质；② 有没有收益承诺、保本暗示、稳赚表述；③ 有没有引导到站外开户、代客理财、进群带单；④ 数据与收益来源能不能打开。
- **医疗健康**（含医美 / 保健 / 药品 / 器械）：① 主体有没有执业或经营资质；② 有没有治愈、根治、替代就医、无副作用一类表述；③ 医美与保健品有没有夸大适应症；④ 处方药与器械有没有绕过平台准入直接引流。
- **教育培训**：① 有没有保过、保 offer、包就业一类承诺；② 有没有未报备的学科类招生信息；③ 价格、课时、退费条件有没有写清；④ 学历与证书的颁发主体是否真实可查。

## 发布关系与平台条件

六项按载体切（标题 / 正文 / 图片 / 外链 / 话术 / 披露），另有两个表面要单独过：

- **发布关系**：稿件里出现商业合作、测评、代言、试用、赞助、佣金或联盟链接时，核对披露——谁给的钱或物、给了什么、影响哪几句。**没有利益证据时，不许由「品牌名同框」「出现了产品图」推断合作**——推断出来的合作是编造，会逼作者补一段不存在的声明。
- **平台条件**：同一句话在不同平台的结论可能不同（能不能放外链、能不能挂商品、能不能写价格、AI 内容要不要标识）。结论依赖平台条件时，按「平台规则时效纪律」查一次，不拿别的平台的规矩套这一篇。

## 五类边界（写作中最常踩的模糊区）

以下是写作中最常踩到的模糊区，逐条说清怎么判。

**1. 引用性截图 vs 搬运截图**：教程文章里贴官方文档截图 + 有明确评论 / 讲解 = **引用性截图，放行**；截图当唯一论据 + 无评论 = 搬运，命中。判据是**作者有没有围绕截图说话**。

**2. 自制图表 vs 站外表图**：作者自己画的 mermaid 流程图 / 数据图 = **自制，放行**；从别处搬的图表未重绘 = 命中。图表标题或文末注释里说清「自制 / 重绘 / 来源」最有效。

**3. AI 生成图 + 主动披露 + 有观点**：三条件同时满足（披露 + 有增量评述 + 非主体位置）= **豁免命中**。**反面案例**：AI 生成一张插画放在开头当题图，正文没围绕它展开 = 命中「AI 图片为主体」。**正面案例**：AI 画一张封面，正文引用它作为讨论对象并给出自己的判断 = 豁免。

**4. 引用来源链接 vs 跳转引导链接**：文末列 30 个官方文档 / 维基词条 / 作者 GitHub = **引用来源，放行**；文末塞「扫码进群 / 加助理领完整清单」 = 命中。**判断口径是「读者点链接是为了查东西，还是去做动作」**。

**5. 好物推荐与工具盘点（疑似带货）**：**这是长文里最容易踩的类型**，也是规则最容易判错的地方。判定原则：
- **纯评价 + 无外链 / 仅指向官方文档** = **原创推荐，放行**（「我用了三个月觉得好用」）
- **评价 + 外链到第三方商城 / 直播间 / 群** = **导流，命中**
- **含「神器 / 值得入手 / 必买 / 亲测推荐」等营销话术** = **边界模糊**，按「发布关系」核对披露（如果拿过推广分成 / 品牌合作，必须在文首声明）

## 账号侧自查（Agent 看不到，作者自查）

以下三处**Agent 校订期够不着**（那是账号配置，不是草稿内容），本文件明确写「由用户自查」，不列进扫描清单：

- **账号简介**：不塞微信号 / 二维码 / 外链（互动导流零容忍）
- **自动回复模板**：关注后自动发的消息不带联系方式 / 外链
- **评论区话术**：作者自己不要在评论里塞微信号 / 二维码

## 未检查范围（报告末尾固定一句）

合规报告最容易制造的错是**虚假的安全感**——作者以为全查过了。每次扫描结束，在结论末尾补一句边界声明，写清覆盖了什么、没覆盖什么。固定形态：

> 本次只检查了文字与稿件里的图片说明：标题、正文、图片描述、外链文本、披露段落。**实际图片内容、账号简介、自动回复、评论区、平台后台信号没有纳入判断。**

按实际材料改这句：只拿到文字就照上面写；拿到图片就再看文字、人物、动作、物品、标识、隐私与二维码；只拿到 OCR 文字时，**OCR 结果不能证明画面安全**。账号简介 / 自动回复 / 评论区这三处另见「账号侧自查」，由作者自己看。平台后台可见的限流、分数、权重只作检查边界，不反推账号、设备或网络信誉。

## 平台规则时效纪律

**只在结论依赖平台当前政策时才查**——准入门槛、报备、处罚、导流入口、商业合作、AI 标识这类时效性问题。判据本身（低创作度、导流、披露）不查，那部分是稳定的。

查了就要留四要素：**规则标题、更新时间、适用对象、直接链接**。缺一样，这条依据就不能进结论。

搜索摘要、培训文章、社交媒体截图、第三方词库**只能当线索**，不能当依据。

**不给这几类数字**：限流比例、恢复天数、申诉成功率、永久处罚、流量权重、精确风控阈值。没有官方依据时给数字，等于把整份报告的可信度押在一个猜上。

## 报告写法

- **对外只用一个档位词表**：本文件的三档 → 说给作者时的说法 = **高风险 → 先改这几处**、**需确认 → 要你确认**、**低置信度 → 不单列**（默认沉默）。改稿建议用的「必改 / 需确认 / 更佳」是同一套说法的另一半：**更佳 = 可改可不改**。**内部档位名不进报告**（见 SKILL.md 交付「模型词不进报告」）；一份报告里不许同时冒出两套说法。
- **不写**「能发」「不能发」「保证通过」「100% 合规」。发布决定权在作者，报告只给位置、后果、动作。
- 不用风险数量或等级名称代替人话——「命中 3 处中风险」看完不知道哪一句要改。
- 不展示内部标签、规则编号、技术字段。
- 每条落到三件事：**具体哪一句 → 什么后果 → 怎么改**（动作类型六选一）。
- 不提供法律意见，不替代平台预审、资质审核和专业判断；不承诺申诉结果，申诉先保存通知、发布版本与证明。
- 不用恐吓式表达。
- **两层都没问题时也要说清**：基于你提供的材料与本次检查范围，目前没有发现需要优先处理的发布风险；**强观点、口语和个人表达可以保留**。

## 和 `style-and-bans.md` 的分工

- `style-and-bans.md`：形式禁令，**改文字本身**（删翻案腔、去黑话、消解抽象抒情）
- 本文件：发布合规，**判断能不能发**（搬运 / AIGC 原文 / 图片主体 / 导流 / 嵌套跳转 / AI 披露）
- **两份都清零才算校订期完成**——命中本文件的红线**不能用「文风就是这样」来豁免**，平台审核不看作者意图
- 这条与前面「最小必要干预」互为配重：**这条管不许拿文风挡红线，那条管不许拿合规压平风格**。红线命中就改；红线没命中，就不许以「更稳妥」为名删风格。

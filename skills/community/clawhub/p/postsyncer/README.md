# postsyncer-social-media-assistant

OpenClaw skill: **Social Media Assistant (via postsyncer.com)**, version 2.8.4. It schedules and manages posts on PostSyncer's 12 networks through the REST API v1, and runs workspaces, the team, notifications, blog-to-social feeds and products. See `SKILL.md` for setup, permissions and workflows.

**API key:** create one in [Settings → API](https://app.postsyncer.com/settings/api) and give it to OpenClaw as `POSTSYNCER_API_KEY`. Or tell OpenClaw `Set up PostSyncer for me: read https://postsyncer.com/agents/setup.md and follow it.` It signs you up, or into the account you have, with a 6-digit code PostSyncer emails you, and gets a key of its own.

**Support:** [docs.postsyncer.com](https://docs.postsyncer.com) · support@postsyncer.com

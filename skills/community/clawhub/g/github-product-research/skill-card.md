## Description:

Research GitHub repositories as products to map markets, compare competitors, validate ideas, analyze repository and issue signals, and recommend product opportunities for product managers or indie builders.

This skill is ready for commercial/non-commercial use.

## Publisher:

[margaretzybgl](https://clawhub.ai/user/margaretzybgl)

### License/Terms of Use:

MIT-0

## Use Case:

Product managers, indie builders, developers, and market researchers use this skill to investigate open-source GitHub product categories, compare serious candidates, evaluate demand and maintenance signals, and decide whether to build, differentiate, wait, or no-go.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Connected GitHub tooling could include private repositories in the research scope if the user asks for or permits that access.

Mitigation: Use public repositories and web sources by default; include private repositories only when the user explicitly intends them to be analyzed.

Risk: Market and demand conclusions can be misleading when GitHub activity, issues, discussions, or web sources are incomplete or time-sensitive.

Mitigation: Cite material claims near the claim, record observation dates for time-sensitive metrics, label inferences, and state access limits.

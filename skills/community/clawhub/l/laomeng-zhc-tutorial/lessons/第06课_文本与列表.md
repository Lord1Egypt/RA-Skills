# 第06课 文本与列表

> 老孟带你学中文编程 · 第 06 课　|　语言面 ZHC-LANG 2.0　|　源码 `示例/第06课_文本与列表.zc`
> 运行：`python -X utf8 zhc.py 示例/第06课_文本与列表.zc --run`

## 一、本课目标

把文本接起来、算长度、做比较；用列表存一串数据并按下标读写。

## 二、语法要点

| 写法 | 说明 |
|---|---|
| `连接(文本A, 文本B)` | 拼接两段文本，结果类型为文本 |
| `文本长度(文本)` | 按字符数返回，中文算 1 个 |
| `文本相同(文本A, 文本B)` | 内容相同返回 `真`；文本不能用 `==` |
| `转文本(值)` | 整数/浮点/逻辑/文本 转成文本 |
| `新建(列表)` | 造一个空列表 |
| `追加(列表, 值)` | 尾部插入，返回新长度 |
| `取元素(列表, 下标)` / `置元素(列表, 下标, 值)` | 读、改，下标从 0 开始 |
| `遍历 列表 记作 位` | 记作的变量拿到的是**下标**，取值仍要 `取元素` |

## 三、完整代码

```zc
# 第06课 文本与列表
# 一、文本：拼接用 连接，长度用 文本长度，比较用 文本相同
定义 姓 为 文本 "老孟"
定义 招呼 为 文本 "你好，"
定义 全句 为 文本 连接(招呼, 姓)
输出 全句
输出 "字数：", 文本长度(全句)

# 文本不能用 == 直接比较，要用 文本相同
如果 文本相同(姓, "老孟") 则
    输出 "确认是老孟本人"
否则
    输出 "不是老孟"
结束

# 数值转文本：转文本(值)
定义 分数 为 整数 95
定义 报 为 文本 连接("本次得分：", 转文本(分数))
输出 报

# 二、列表：先 新建(列表) 得到空列表，再 追加 尾插
定义 名单 为 列表
设 名单 为 新建(列表)
追加(名单, "张三")
追加(名单, "李四")
追加(名单, "王五")
输出 "名单人数：", 长度(名单)
输出 "第一个：", 取元素(名单, 0)

# 改某个位置：置元素(列表, 下标, 新值)
置元素(名单, 1, "李四改")
输出 "第二个改成：", 取元素(名单, 1)

# 遍历列表：记作的变量是下标，取元素拿值
遍历 名单 记作 位
    输出 "第 ", 位 + 1, " 位：", 取元素(名单, 位)
结束
```

第 1 位：张三
第 2 位：李四改
第 3 位：王五

## 五、易错点

- `定义 名单 为 列表` 只是声明类型，还要 `设 名单 为 新建(列表)` 才是可用容器。
- 列表下标从 0 开始，越界报 `[E401]` 运行期错误。
- `遍历 列表 记作 位` 里的 `位` 是下标不是元素，直接 `输出 位` 会打印 0、1、2 这样的序号。
- 文本比较不要用 `==`，用 `文本相同`。

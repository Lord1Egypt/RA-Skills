## Description:

Provides Chinese-language ENFJ coaching guidance for growth, career, learning, focus, and analysis paralysis using coaching and consultant response modes.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users who identify as ENFJ use this skill for structured coaching conversations and concrete action plans around growth, career direction, learning direction, focus, and analysis paralysis. The skill is not a substitute for professional mental health support.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Package identity and install guidance are inconsistent across the artifact.

Mitigation: Confirm the intended package name, slug, version, and publisher before installation or publication, and avoid following the README install command until corrected.

Risk: The skill describes saving coaching profiles that may contain sensitive personal information.

Mitigation: Require explicit opt-in before retaining profile details, make stored details reviewable and deletable, and avoid retaining unnecessary personal information.

Risk: MBTI-based coaching can be over-applied or mistaken for professional advice.

Mitigation: Present guidance as reflective coaching support, preserve the artifact's boundary that it is not professional mental health care, and direct severe mental health concerns to qualified professionals.

# 测试用例清单（落地前必测）

按下列用例逐项验证，覆盖输入、人脸、真实性、抠图、输出、服务与合规各层。

## 输入层
1. 文件损坏、截断图片 → 捕获解码异常，返回损坏提示。
2. GIF 动图 → 拦截。
3. CMYK 图片 → 自动转 RGB 并软警告。
4. EXIF 旋转颠倒的手机照片 → 物理矫正后再校验。
5. 后缀欺骗（后缀 .jpg 实为 .webp）→ 魔数识别真实格式，按真实格式处理。
6. 未获取人脸单独同意 → 无法上传图片进入 skill。

## 人脸存在/数量
7. 镜子自拍产生虚假第二人脸 → 镜像倒影过滤或按多人拒绝。
8. 多人合影 → 拒绝。
9. 单人侧脸、仰头、低头 → 姿态校验。
10. 仅发送指令不上传图片 → 不触发生成逻辑。

## 输入特殊
11. 输入自带 Alpha 通道透明 PNG → 填充中性灰校验并软警告。
12. 白色衣服配白底 → 上衣与背景色接近软警告。
13. 翻拍纸质证件照 → 真实性预筛（高安全硬拒绝/普通软警告）。

## 人脸质量
14. 眼镜反光轻微 → 软警告放行。
15. 眼镜反光遮挡瞳孔 → 硬拒绝。
16. 耳朵部分露出 → 软警告。
17. 耳朵完全被头发遮挡 → 硬拒绝。
18. 合法宗教头巾 → 放行（眉眼口鼻可见）。
19. 普通帽子 → 拒绝。

## 参数
20. 自定义接近肤色的底色 → 追加警告。
21. 非法 HEX 色值输入 → 拦截。
22. 不存在的 spec_key → 返回支持规格列表。

## 抠图/输出
23. 质量合格但抠图发丝严重丢失 → 硬拒绝或软警告。
24. 裁切后肩膀缺失 → 软警告。
25. 原图画质差，无论如何调 JPEG 质量达不到目标 KB 区间 → 软警告。
26. 不勾选 PNG → 输出不含 PNG；主动请求 → 输出 PNG 并附带风险标注。

## 服务/异常
27. 触发限流 → 友好提示，不暴露状态码。
28. 模型推理 OOM/超时 → 友好兜底，不暴露内部堆栈。
29. 高安全 vs 普通模式输入翻拍图 → 分别硬拒绝/软警告放行。

## 姿态自动校正
30. 轻微头部倾斜（roll ≤10°）→ 自动旋转摆正后放行，元数据记录角度。
31. 水平偏离画面中心 → 平移居中。
32. 轻微俯仰（pitch/yaw ≤8°）且五官清晰 → 轻微透视修正后放行。
33. 严重侧脸/低头（yaw/pitch>30°）→ 硬拒绝，**不做**自动摆正。
34. 转脸、闭眼、五官大面积遮挡 → 硬拒绝，不自动生成姿态。
35. 自动校正后复检仍超阈值 → 硬拒绝，不强行生成。
36. 校正仅几何：校验校正前后五官/身份一致，无磨皮瘦脸换五官。

## Description:

This skill is ready for commercial/non-commercial use.

## Use Case:

External users can use this skill to search for meditation services, check availability, and create a booking through Lokuli.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can send user contact details to an external booking service.

Mitigation: Confirm the provider, appointment time, and contact details with the user before creating a booking or sending personal information.

Risk: The skill does not clearly require consent before creating a booking.

Mitigation: Require explicit user approval before invoking booking creation.

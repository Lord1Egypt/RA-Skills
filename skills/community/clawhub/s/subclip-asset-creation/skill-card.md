## Description:

Create or revise images, illustrations, textures, plates, and backgrounds locally, then import them as ordinary editable Subclip MediaPanel and timeline assets. Use when the user asks to generate an image/background or change its colors, subject, composition, or style.

This skill is ready for commercial/non-commercial use.

## Use Case:

## Known Risks and Mitigations:

Risk: Optional cloud image generation may send prompts or images to an external provider, store them in the cloud, and use AI credits.

Mitigation: Use local generation when it fits; before using cloud generation, check the provider's data handling and whether the creator is comfortable with the possible credit use.

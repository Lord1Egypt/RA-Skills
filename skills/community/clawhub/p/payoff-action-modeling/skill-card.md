## Description:

Model product UI actions from user intent questions after a meaningful outcome, completion, created resource, imported data, uploaded file, synced integration, report, deployment, automation, review state, handoff, or workflow milestone.

This skill is ready for commercial/non-commercial use.

## Use Case:

Designers, product managers, and developers use this skill to decide which UI actions to show, hide, group, label, prioritize, defer, or place after a user reaches a meaningful workflow outcome.

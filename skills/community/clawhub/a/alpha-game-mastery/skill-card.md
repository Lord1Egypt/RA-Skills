## Description:

黄毛决胜法 Alpha Game Mastery is a Chinese-language coaching skill for improving personal confidence, attraction, social framing, and negotiation posture through game-theory and social-psychology guidance.

This skill is ready for commercial/non-commercial use.

External users and agents use this Chinese-language coaching skill to generate relationship, social-confidence, and negotiation guidance, including posture reframing, boundary-setting, and 21-day practice plans.

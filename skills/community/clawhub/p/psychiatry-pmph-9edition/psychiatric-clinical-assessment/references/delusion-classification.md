# 常见妄想分类及疾病关联

## 妄想与超价观念鉴别

| 特征 | 妄想 | 超价观念 |
|------|------|----------|
| 内容 | 荒谬离奇 | 有一定事实依据 |
| 事实依据 | 无 | 有 |
| 坚信程度 | 坚信不疑 | 片面偏激 |
| 情感色彩 | 不一定 | 强烈 |
| 随情绪变化 | 不减弱 | 随情绪消退而减弱 |
| 常见疾病 | 精神分裂症等 | 人格障碍 |

## 常见妄想类型

### 夸大妄想
- **表现**：认为拥有非凡才能/财富/地位
- **示例**：自称科学家、大富翁
- **常见疾病**：躁狂发作、精神分裂症、痴呆

### 罪恶妄想
- **表现**：坚信犯严重错误/罪大恶极
- **后果**：可致拒食、自杀
- **常见疾病**：抑郁障碍、精神分裂症

### 疑病妄想
- **表现**：坚信患严重躯体疾病/不治之症
- **严重时**：认为"内脏腐烂/大脑空壳"
- **常见疾病**：抑郁障碍、精神分裂症、躯体不适障碍

### 虚无妄想
- **表现**：认为客观事物/自身不复存在
- **后果**：无须进食休息
- **常见疾病**：抑郁障碍、精神分裂症

### 钟情妄想
- **表现**：坚信被异性钟情
- **特点**：遭拒认为是考验
- **常见疾病**：精神分裂症

### 嫉妒妄想
- **表现**：坚信配偶不忠
- **行为**：翻手机/跟踪/查衣物
- **常见疾病**：精神分裂症、痴呆

### 非血统妄想
- **表现**：坚信非亲生
- **行为**：要求亲子鉴定
- **常见疾病**：精神分裂症

### 物理影响妄想（被控制感）
- **表现**：思想/情感/行为受外界力量控制
- **示例**：红外线、电磁波控制
- **常见疾病**：精神分裂症

### 内心被揭露感（被洞悉感）
- **表现**：内心所想未说出却被别人知道
- **常见疾病**：精神分裂症

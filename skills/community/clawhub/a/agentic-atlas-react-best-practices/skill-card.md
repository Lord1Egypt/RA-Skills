## Description:

Audits React code for performance, bundle size, and best practices, including React 18+ patterns.

This skill is ready for commercial/non-commercial use.

## Publisher:

[asimons81](https://clawhub.ai/user/asimons81)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to audit React codebases for performance, bundle size, accessibility, and React best-practice issues, then receive severity-rated findings and actionable fixes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may read the React project source code supplied for review.

Mitigation: Use it only on codebases the agent is authorized to inspect and review findings before applying suggested changes.

Risk: Audit guidance can be incomplete or context-sensitive for a specific React application.

Mitigation: Have maintainers validate severity, root cause, and before/after fixes before merging changes.

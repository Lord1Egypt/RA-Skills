## Description:

novel-master is a Chinese-language long-form fiction workflow for worldbuilding, character design, outlining, chapter drafting, foreshadowing management, and quality checks.

This skill is ready for commercial/non-commercial use.

## Publisher:

[bbroot](https://clawhub.ai/user/bbroot)

### License/Terms of Use:

MIT

## Use Case:

Writers and agent operators use this skill to plan, draft, and maintain Chinese novels from initial concept through chapter writing and continuity review. It supports project setup, narrative structure, character voice, foreshadowing tracking, and manuscript quality checks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Helper scripts can write outside the intended novel project folder when book or character names include slashes, dots, or path-like text.

Mitigation: Use simple book and character names, review generated files before reuse, and run helper scripts in a contained account or workspace until path validation is fixed.

# 多方冲突调处

## 场景定义

- **目标**：自身处于居间位置（调解人/平台方/生态主导者）时，对多方冲突的调处——控局、定分、止争。
- **约束**：各方利益与信息不对称；居间者权威有限、须借势借理；冲突可能烧及居间者自身；调处被识破"操盘"则有信用风险。
- **角色**：居间调处人（平台方/生态主/受雇调解人）。
- **典型输入**：①平台商户间的恶性竞争冲突；②生态伙伴间的利益之争；③多供应商纠纷调解。
- **边界**：自身为冲突一方的对抗处置不在本 Skill 范围（用间与对抗归相关战争类应用）；冲突舆情化外送 APP-027 危机公关；调处失败危及业务存续外送 APP-025 止损退出；与 APP-031（联盟经营）互补——彼为常态联合，本 Skill 为冲突态处置。

## 组合公式

- **顺序**：侦察定性段（SZ-01→GZ-03→GZ-14→MZD-02）→ 分策处置段（GZ-42：弱者之仇解之 / 强者相斗纵而驭之）→ 主导决断段（GZ-27→MZD-21→SZ-15→GZ-04）→ 环境管理段（MZD-03→GZ-31→GZ-08）。
- **条件分支**：冲突方为"羸微"（弱小方）→ GZ-42 解仇分支（居间调解收其心）；冲突方为"强梁"（强势方）→ GZ-42 斗郄分支（纵其相斗、称胜者盛其势，主导权在称胜者）；出现寸利必得的扩张方 → MZD-21 反制分支。
- **权重**：GZ-27 权重最高——调处全程制人不制于人；主导权（议程/规则/裁决）一失，居间者即被冲突吞没。
- **冲突裁决**：调处"止争"目标与 GZ-42 纵斗分支冲突时——纵斗为手段、止争为归宿：纵而后收，斗而不乱；MZD-03 事实底座与各方情面冲突时，事实优先。

## 执行步骤

1. **知彼知己**（SZ-01）：各方立场、底牌、真实诉求、可退让底线摸清——不知彼知己勿居间。
2. **揣情探真**（GZ-03）：对其甚喜、甚惧之时探其真情——表面主张与真实底线的差就是调处空间。
3. **量权定强弱**（GZ-14）：各方强弱与可动员资源称量——弱者与强者分策处置的前提。
4. **主冲突定性**（MZD-02）：多方混战中识别主要矛盾与主要冲突双方——主冲突不解，枝节调解无效。
5. **弱者之仇解之**（GZ-42）：弱小方之间的冲突居间排解——双方皆感其恩，恩在居间者；调解以 MZD-03 查实事实为底。
6. **强者相斗纵而驭之**（GZ-42）：强势方相争不硬拦——纵其相斗，胜者因己方"称扬其功"而势盛，主导权系于称胜者之手；斗而不乱、纵而后收。
7. **主导权经营**（GZ-27）：调处全程制人不制于人——议程设置、规则制定、裁决权在己，不假手任何冲突一方。
8. **扩张方反制**（MZD-21）：对寸利必得、借调处扩地盘的一方，针锋相对、寸土必争——不以退让求表面和局。
9. **方案利害对勘**（SZ-15）：调处方案（和解/划界/补偿/裁决）各方利弊对勘后再定。
10. **到期必决**（GZ-04）：调处方案设时限，三参照过完到期必裁——久拖不决的调处本身成为新冲突源。
11. **众口管理**（GZ-31）：冲突相关舆论面管控——各方公开说辞辨其曲故；防断章取义点火、防站队式发酵。
12. **无常重算**（GZ-08）：无永久阵营——调处中的联合与切割按情势逐次重算，不固守上轮立场。
13. **事实底座**（MZD-03）：一切裁决与公开定性建立在查实事实之上——偏袒性裁决毁掉居间信用。

## 失效预案

- **纵斗失控**（强方之斗失控烧及生态）：退回 GZ-27 强制介入收局；收不住 → 依 APP-025 边界评估自身业务止损。
- **调处被识破操盘**（居间信用受损）：退回 MZD-03 全面公开事实与规则自证；信用已失 → 退出居间位（避险），必要时 MZD-21 自卫反制。
- **主导权旁落**（议程被某方把持）：退回 GZ-27 收议程；收不回 → GZ-08 重算立场，重新选边或离场。
- **一切争议不决**：兜底回 GZ-04——三参照到期必决，以裁决止争。

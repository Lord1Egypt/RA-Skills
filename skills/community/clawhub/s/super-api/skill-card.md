## Known Risks and Mitigations: <br>
Risk: Copy-pasted API examples can change or delete real data when run with live credentials. <br>
Mitigation: Confirm the target account and environment, prefer sandbox or test credentials, use scoped tokens, and review POST, PUT, PATCH, DELETE, payment, outreach, support, and social-posting examples before execution. <br>
Risk: API requests may expose personal, customer, or credential data. <br>
Mitigation: Redact personal and customer data from prompts, logs, and examples, and keep tokens out of URLs and shared output. <br>

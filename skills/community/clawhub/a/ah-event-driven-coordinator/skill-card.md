## Description:

Event-Driven Coordinator guides agents in designing asynchronous multi-agent coordination patterns using event buses, pub/sub, event sourcing, CQRS, sagas, correlation, aggregation, retries, and monitoring.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill to structure event-driven multi-agent workflows, including topic design, event formats, reactive task chains, saga-style rollback flows, event correlation, retry handling, and operational monitoring.

Global

## Known Risks and Mitigations:

Risk: The skill provides broad architecture and coordination guidance that could influence production workflow decisions.

Mitigation: Keep sensitive deployment decisions and production actions under explicit human review.

Risk: Event-driven workflow recommendations can be incomplete or mismatched to a specific system's reliability, security, or operational requirements.

Mitigation: Review proposed event schemas, routing rules, retry policies, and rollback flows against the target system before adoption.

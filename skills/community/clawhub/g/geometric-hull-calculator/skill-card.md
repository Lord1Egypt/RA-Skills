## Description:

Geometric hull calculator for 2D point sets supporting convex hull, concave hull (concave-hull, alphashape), and minimum bounding rectangle.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill for guidance on computing convex hulls, concave hulls, and minimum bounding rectangles for 2D point sets with pywayne.cv.geometric_hull_calculator. It also helps with visualization through OpenCV or matplotlib and generation of random test point sets.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill depends on Python packages such as OpenCV, scipy, shapely, alphashape, and concave_hull.

Mitigation: Use normal Python package hygiene: install from trusted indexes, pin dependency versions where practical, and review dependency updates before deployment.

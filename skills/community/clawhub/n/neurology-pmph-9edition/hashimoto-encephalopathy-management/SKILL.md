# 桥本脑病（HE）诊断与治疗规范

## 适用场景
当患者满足以下条件时触发本流程：
1. 存在脑病临床表现（认知障碍、精神症状或局灶性神经功能缺损）。
2. 伴有自身免疫性甲状腺疾病史或甲状腺抗体异常。
3. 已初步排除其他常见中枢神经系统感染或血管性疾病。

## 核心工作流程

### 第一步：临床分型识别
评估患者症状，将其归入以下主要临床表型（详细症状见 `references/clinical-phenotypes.md`）：
- **卒中样发作型**：以局灶症状为主，呈复发-缓解形式（如偏瘫、失语、共济失调）。
- **进行性痴呆及精神症状型**：以幻听、激越、抑郁、认知低下或人格改变为主。
- **其他型**：意识障碍、锥体外系症状（肌阵挛/震颤）、癫痫发作、睡眠障碍等。

### 第二步：执行排除性诊断
桥本脑病为排除性诊断，需完善以下检查并核对特征性改变：
1. **抗体检测**：确认抗TPO抗体阳性（通常高出正常值几倍至几百倍），抗TG抗体可阳可阴。
2. **脑脊液（CSF）**：蛋白正常或轻度升高（上限可达300mg/dl），细胞数轻度增加。
3. **脑电图（EEG）**：寻找全面慢波（与症状相关），注意特征：全面性癫痫发作多见，但发作间期脑电图呈现癫痫样改变者较少。
4. **影像与核医学**：
   - CT/MRI：多无特异改变，或见皮质下白质T2/FLAIR高信号（治疗好转后可恢复）。
   - SPECT：示脑部低血流信号（以额叶为主，其次颞/顶/枕/小脑）。

### 第三步：制定治疗方案
1. **首选糖皮质激素**：
   - 启动糖皮质激素治疗。
   - 预期起效时间：给药后1~2天多数患者明显见效。
   - 复发处理：反复发作者可重复用药。
2. **联合/替代治疗**（针对重症或激素效果不佳者）：
   - 联用免疫抑制剂（如环磷酰胺、硫唑嘌呤）。
   - 试用大剂量静脉注射免疫球蛋白（IVIG）或血浆置换。

## 关键约束与注意事项
- **非自身免疫性排除**：本规范不适用于非自身免疫性甲状腺疾病相关的脑病。
- **激素不敏感陷阱**：部分患者对糖皮质激素不敏感。**治疗无效绝对不能作为排除本病诊断的依据**。
- **预后评估**：极少数患者可自愈，但多数患者在治疗合理及时的情况下预后良好。

# 桥本脑病临床分型详细特征

## 1. 卒中样发作型（特异症状）
- **核心特征**：局灶症状为主，呈复发-缓解形式
- **锥体束症状**：偏瘫、四肢瘫
- **皮层症状**：失语、失用、失读
- **小脑症状**：小脑共济失调
- **感觉障碍**：各类感觉异常

## 2. 进行性痴呆及精神症状型
- **精神症状**：幻听多见；兴奋状态（激越、易怒、不安）或抑制状态（抑郁、淡漠）
- **认知与人格**：认知低下、妄想、人格改变

## 3. 其他非特异型
- **意识障碍**：嗜睡至昏迷，以意识模糊多见
- **锥体外系症状**：不随意运动、肌阵挛、震颤
- **癫痫发作**：全面性强直-阵挛发作多见
- **其他**：睡眠障碍、听觉过敏、偏头痛等

# 桥本脑病辅助检查与诊断标准细节

## 实验室检查
- **抗TPO抗体**：必须阳性，滴度通常高出正常值几倍至几百倍
- **抗TG抗体**：可阳性或阴性
- **脑脊液（CSF）常规生化**：
  - 蛋白：正常或轻度升高，极端情况下上限可达300 mg/dl
  - 细胞数：轻度增加

## 神经电生理
- **脑电图（EEG）**：
  - 常见表现：全面慢波（与临床症状严重程度相关）
  - 偶见表现：三相波、棘波等
  - **关键鉴别点**：全面性癫痫发作临床多见，但发作间期脑电图典型癫痫样改变较少见

## 影像学与核医学
- **CT/MRI**：多数无特异性改变；部分可见皮质下白质T2/FLAIR高信号（激素治疗后可恢复）
- **SPECT**：脑部低血流信号，以额叶为主，其次为颞叶、顶叶、枕叶和小脑

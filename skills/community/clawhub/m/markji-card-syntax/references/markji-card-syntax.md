# Markji 卡片语法使用指南

本文介绍 Markji 墨墨记忆卡的 GV3 语法。普通文字可以直接输入；需要挖空、样式、选择题、公式或媒体时，再使用对应语法。

当前 Markji 卡片统一使用 GV3。编写卡片和向相关接口提交内容时，都必须遵循当前版本，不能使用旧版本语法。接口需要填写语法版本时，设置 `grammar_version: 3`，值为数字 `3`。这是接口字段，不要写进卡片正文。

带样式的挖空、公式挖空、选择题公式和代码块需要客户端支持。若粘贴后未生效，请改用普通文字挖空、普通公式或纯文本。下文媒体和关联卡片示例中的 ID 均为占位符，使用时替换为已有 ID。

## 先记住这些规则

普通文字不需要任何标签：

```text
光合作用把光能转化为化学能。
```

需要语法时，通常使用下面的结构：

```text
[名称#参数1,参数2#内容]
```

请遵守以下约束：

1. 标签和参数区分大小写。必须写成 `T`、`P`、`F`、`Choice`、`Pic`、`Audio`、`Card`、`E`、`Code` 等规定形式。
2. `#` 分隔名称、参数和内容。没有参数时也要保留两个 `#`，例如 `[E##x+y]`、`[Choice##...]`。
3. 多个参数使用英文逗号 `,` 分隔；标签名、参数和分隔符之间不要加空格。链接双引号内的逗号和 `#` 属于网址，不是分隔符。
4. 每个以 `[` 开始的语法都必须有未被转义的右中括号 `]` 作为结尾。
5. 普通换行会产生新段落。段落样式、选择题、图片、独立公式、代码块和答案分隔线应从一行的开头开始；行内公式可以和普通文字写在同一段中。
6. 除明确允许的位置外，不要嵌套语法。
7. 文字内容里需要显示普通中括号时，写成 `\[` 和 `\]`。
8. 不要依赖错误语法被自动修复；无法确认时使用纯文本。

一个常用的问答卡片：

```text
[P#H1#光合作用]
光合作用主要发生在哪种细胞器中？
---
叶绿体。
```

## 行内语法

行内语法可以和普通文字写在同一段中。

### 文字样式

格式：

```text
[T#参数#文字]
```

可用参数：

| 参数 | 效果 | 示例 |
|---|---|---|
| `B` | 加粗 | `[T#B#重点]` |
| `I` | 斜体 | `[T#I#术语]` |
| `U` | 下划线 | `[T#U#关键词]` |
| `!rrggbb` | 文字颜色 | `[T#!e53935#红色文字]` |
| `!!rrggbb` | 背景颜色 | `[T#!!fff59d#高亮文字]` |
| `up` | 上标 | `x[T#up#2]` |
| `down` | 下标 | `H[T#down#2]O` |
| `link/"网址"` | 超链接 | `[T#link/"https://markji.com"#访问网站]` |

多个样式可以组合：

```text
[T#B,U,!e53935#红色加粗下划线]
```

约束：

- 颜色必须是 6 位小写十六进制字符，不要带 `#`，例如 `!0f0f0f`。
- `up` 和 `down` 不要同时使用。
- 同一种参数不要重复；文字颜色和背景颜色各选一种。
- 链接网址必须放在英文双引号中，且不能换行。引号内的 `#` 和英文逗号可以直接保留，例如 `[T#link/"https://example.com/a,b#section"#查看详情]`。
- 样式内容中不要再放其他语法。

### 挖空

格式：

```text
[F#编号#要隐藏的内容]
```

示例：

```text
光合作用主要发生在[F#1#叶绿体]中。
```

编号表示挖空分组：

- 推荐从 `1` 开始，用正整数编号。
- 相同编号属于同一组；希望一起显示或隐藏时使用相同编号。
- 不同编号是不同组。
- 省略编号的 `[F##内容]` 会形成独立挖空，不与其他无编号挖空分组。需要分组时明确填写正整数编号，不使用 `0`、负数或文字编号。
- 挖空内容可以包含普通文字和 `T` 文字样式，不支持嵌套挖空或其他元素。

```text
[F#1#普通文字[T#B,!ff0000#红色加粗的重点]]
```

需要显示语法本身时，转义方括号。例如 `[F#1#\[T#B#重点\]]` 的答案是普通文字
`[T#B#重点]`。只有未转义且完整的 `T` 才应用样式。

### 音频

格式：

```text
[Audio#ID/音频ID#显示文字]
```

常用参数：

| 参数 | 含义 |
|---|---|
| `ID/音频ID` | 指定已有音频 |
| `M` | 手动播放 |
| `A` | 自动播放；不写 `M` 时也按自动播放处理 |
| `D` | 播放行为跟随用户设置 |

示例：

```text
[Audio#M,ID/audio123#点击播放发音]
[Audio#ID/audio123,D#单词发音]
```

约束：

- 只使用真实、已有的音频 ID，不要猜测或编造。
- `M` 和 `A` 不要同时使用。需要手动播放时写 `M`；需要自动播放时可省略 `A`。
- 显示文字可以为空，但仍要保留第二个 `#`。
- 显示文字中不要嵌套其他语法。

### 关联卡片

格式：

```text
[Card#ID/卡片ID#显示文字]
```

关联多张卡片时，用连字符 `-` 分隔 ID：

```text
[Card#ID/abc123-def456#查看相关卡片]
```

约束：

- 只使用真实、已有的卡片 ID，不要猜测或编造。
- ID 本身不能包含用作分隔符的连字符。
- 重复 ID 没有意义，应在输出前去重；空 ID 应删除。
- 显示文字中不要嵌套其他语法。

### 行内公式

在普通段落或 `[P#...#...]` 段落的文字中使用：

```text
质能方程是 [E##E=mc^2]。
[P#H1#函数 [E##f(x)=x^2] 的图像]
```

格式与独立公式相同，两个 `#` 都必须保留：

```text
[E##LaTeX 公式]
```

约束：

- 行内公式可以出现在段落的开头、中间或末尾。
- 公式内容按 LaTeX 书写。区间和根式中的中括号可以直接保留，例如 `[E##x \in [-1,1]]` 和 `[E##\sqrt[n]{x}]`。
- 行内公式可以直接放在普通段落、`P` 段落或 `Choice` 选项中，不要放进 `T`、普通 `F`、`Audio` 或 `Card`。
- 公式内的 `[` 和 `(` 需要由后面的 `]` 或 `)` 闭合，闭区间和半开区间都可使用，例如 `[-1,1]`、`(-1,1]`、`[-1,1)`。只显示单个括号时，使用 `\lbrack`、`\rbrack`、`\lparen` 或 `\rparen`，避免与公式结尾混淆。
- `Choice` 选项中的公式不支持挖空或文字样式。公式里的 `[F#...#...]` 和 `[T#...#...]` 只作为公式原文处理。
- 行内公式应写在一行内；多行公式改用独立公式。
- 缺少结尾 `]` 的公式不会解析为公式，应补全语法。

普通段落和 `P` 段落中的公式，以及独立公式，都可以整体挖空或局部挖空：

```text
[E##[F#1#E=mc^2]]
[E##E=m[F#1#c^2]]
```

公式挖空必须写在公式内尚未闭合的 `[`、`(` 之外。例如，要隐藏 `f(x)` 中的 `x`，写成 `[E##f\lparen [F#1#x]\rparen]`。直接写在 `f(...)` 内的挖空不会生效。

公式挖空的内容按 LaTeX 书写，不放文字样式，也不能嵌套挖空。同一张卡片中，公式挖空和普通文字挖空可以使用相同编号分组。需要显示 `[F#` 本身时，写成 `\lbrack F\#`。

## 块级语法

块级语法应从新一行的第一个字符开始。

### 段落样式

格式：

```text
[P#参数#段落内容]
```

可用参数：

| 参数 | 效果 | 示例 |
|---|---|---|
| `H1` | 标题 | `H1` |
| `L` | 无序列表 | `L` |
| `I<n>` | 缩进级别 | `I2` |
| `left` | 左对齐 | `left` |
| `center` | 居中 | `center` |
| `right` | 右对齐 | `right` |

示例：

```text
[P#H1,center#细胞呼吸]
[P#L#线粒体]
```

约束：

- 标题只支持 `H1`；不要使用其他标题级别。
- `I<n>` 中的 `n` 使用正整数。
- 一段只能选择一种对齐方式。
- 当前仅使用 `L` 表示无序列表；不要生成有序列表、折叠、行内代码等未列出的参数。
- 整个段落语法必须写在同一行。
- 段落内容可以包含文字样式、挖空、音频、关联卡片和行内公式。普通文字挖空内可放 T，公式内可放公式挖空，其他行内语法不要互相嵌套。
- 普通段落不需要空参数的 `[P##内容]`，直接写文字即可。

### 选择题

基本格式：

```text
[Choice#参数#
* 正确选项
- 错误选项
]
```

参数：

| 参数 | 含义 |
|---|---|
| `fixed` | 保持选项顺序；省略时默认随机排列 |
| `multi` | 多选题 |

单选题示例：

```text
[Choice#fixed#
- 叶绿体
* 线粒体
- 核糖体
]
```

多选题示例：

```text
[Choice#multi#
* 氧气
* 水
- 氯化钠
]
```

约束：

- `[Choice...` 必须从新一行开头开始，结尾的 `]` 单独占一行。
- 每个选项也必须从新一行开始，并准确使用 `* ` 或 `- `（符号后有一个空格）。
- `* ` 表示正确选项，`- ` 表示错误选项。
- 用行首标记声明多个正确选项时，必须加 `multi`；单选题只保留一个 `* `。
- 希望固定顺序时加 `fixed`；希望随机排列时省略 `fixed`。
- 每个选项写在一行内，可以使用普通文字、`[T#...#...]` 文字样式和单行 `[E##...]` 公式。不要放挖空、音频、卡片关联、图片或多行公式。
- 推荐用每行的 `* ` 和 `- ` 声明答案。已有内容中的 `ans/ac` 参数表示第一个和第三个选项正确，会覆盖行首标记，并自动设为多选题；不要混用两种答案写法。

### 图片与画廊

单张图片：

```text
[Pic#ID/图片ID#]
```

带遮罩的图片：

```text
[Pic#ID/图片ID,MID/遮罩ID#]
```

相邻且没有换行的多张图片会组成同一个画廊：

```text
[Pic#ID/image1#][Pic#ID/image2,MID/mask2#]
```

分别放在两行会形成两个独立的图片区块：

```text
[Pic#ID/image1#]
[Pic#ID/image2#]
```

约束：

- 单张图片或画廊的第一张图片必须从新一行开头开始。
- 图片内容区必须为空，所以结尾是 `#]`。
- 只使用真实、已有的图片 ID 和遮罩 ID，不要猜测或编造。
- 需要同一画廊时不要在相邻图片之间加入空格或换行。

### 独立公式

把公式单独放在一行，即可作为独立公式：

```text
[E##E=mc^2]
```

公式内容可以换行：

```text
[E##\begin{aligned}
a^2+b^2&=c^2
\end{aligned}]
```

独立公式的 `[E##` 必须从新一行开头开始，结束的 `]` 后不要在同一行追加普通文字。

独立公式也支持整个或局部公式挖空，写法与行内公式相同。

### 代码块

```text
[Code#lang/javascript,wrap#
const values = [1, 2];
console.log(values);
]
```

- `[Code#...#` 必须从新一行开头开始，第二个 `#` 后立即换行。不能放进段落、选择题选项或其他语法内部。
- `lang/<id>` 指定语言，可以省略。语言 ID 以小写英文字母开头，后面只能包含小写英文字母、数字和 `-`，例如 `cpp`、`csharp`、`javascript`。语言名称不自动转换，`js` 不会改成 `javascript`。
- `wrap` 表示默认软换行，省略时不启用。不要写 `wrap/true` 或 `wrap/false`。
- 代码中的 Markji 语法只显示为代码，不会产生挖空或其他效果。
- 结尾的 `]` 必须独占一行，前后不能有空格。正文里需要独占一行的 `]` 时写成 `\]`。
- 其他位置的 `[` 和 `]` 可以直接写，不需要配对，也不要求转义。例如 `const values = [1, 2];` 可以原样写入。
- 代码正文会把 `\\`、`\[`、`\]` 分别还原为 `\`、`[`、`]`。如果原代码本身包含这些转义序列，需要额外转义反斜杠，例如原代码的 `\[` 应写成 `\\[`。其他反斜杠序列原样保留。
- 保留原代码的缩进和空行。头部后与结束行前各有一个格式换行；需要保留正文末尾的换行时，在结束行前再加一个空行。
- 只使用 `lang/<id>` 和 `wrap`，不要重复参数。

空代码块的头部和结尾之间也要留一个空行：

```text
[Code##

]
```

### 答案分隔线

使用三个半角连字符，并让它单独占一行：

```text
---
```

常用于分隔问题和答案：

```text
法国的首都是哪里？
---
巴黎。
```

不要在 `---` 前后添加空格、其他符号或同行文字。若答案分隔线位于卡片末尾，仍应保留它后面的换行。

## 转义与特殊字符

在普通文字或文字样式、挖空、音频、关联卡片的文字中，需要显示中括号本身时进行转义：

| 想显示 | 应输入 |
|---|---|
| `[` | `\[` |
| `]` | `\]` |

示例：

```text
数学中的闭区间可以写作 \[a,b\]。
[T#B#请阅读第 \[3\] 章]
```

注意：

- 只转义作为普通文字显示的中括号；真正的语法外层括号不要转义。
- 在 `Choice` 选项中，`\[E##x\]` 会作为普通文字保留，不会被识别成公式。
- 文字内容中的 `#` 和英文逗号可以直接写。参数区中的这两个字符用于分隔，链接双引号内除外；参数区不能换行。
- 普通文字只需转义中括号，不需要把每个反斜杠写成两个。公式按 LaTeX 书写，代码正文按代码块一节的规则转义。

## 嵌套和位置限制

按下表决定一种语法能否放进另一种语法：

| 容器 | 可放入的语法 |
|---|---|
| 普通段落 | `T`、`F`、`Audio`、`Card`、`E` 行内公式 |
| `P` 段落 | `T`、`F`、`Audio`、`Card`、`E` 行内公式 |
| `Choice` 选项 | `T`、不带挖空的单行 `E` 公式 |
| `T` 内容 | 不放其他语法 |
| 普通文字 `F` 内容 | 普通文字、`T` 文字样式 |
| `Audio` 显示文字 | 不放其他语法 |
| `Card` 显示文字 | 不放其他语法 |
| `Pic` | 内容必须为空 |
| 普通段落、`P` 段落或独立的 `E` 公式 | LaTeX 公式、符合公式一节位置限制的 `F` 挖空 |
| `Code` 代码块 | 不嵌套任何语法，全部内容按代码原文处理 |

块级语法 `P`、`Choice`、`Pic`、独立 `E`、`Code` 和 `---` 不要放进段落或其他语法内部。需要在段落中显示公式时，改用上面的 `E` 行内公式写法。

## 完整示例

### 重点与挖空

```text
[P#H1#细胞结构]
[T#B#线粒体]是细胞进行[F#1#有氧呼吸]的主要场所。
```

### 带公式的问答卡

```text
勾股定理的公式是什么？
---
[E##a^2+b^2=c^2]
```

### 含行内公式的概念卡

```text
质能方程 [E##E=mc^2] 表明质量和能量可以相互转换。
```

### 含公式的选择题

```text
[Choice#fixed#
* 质能方程是 [E##E=mc^2]
- 质能方程是 [E##E=mv^2]
]
```

### 固定顺序的多选题

```text
以下哪些是哺乳动物？
[Choice#fixed,multi#
* 鲸
- 鲨鱼
* 蝙蝠
- 企鹅
]
```

## 常见错误

错误：少写一个 `#`。

```text
[F#1挖空]
```

正确：

```text
[F#1#挖空]
```

错误：块级语法前有普通文字。

```text
题目：[Choice##
* A
- B
]
```

正确：

```text
题目：
[Choice##
* A
- B
]
```

错误：多选题漏掉 `multi`。

```text
[Choice##
* A
* B
- C
]
```

正确：

```text
[Choice#multi#
* A
* B
- C
]
```

错误：选项符号后没有空格。

```text
*正确选项
```

正确：

```text
* 正确选项
```

错误：普通右中括号未转义。

```text
[T#B#区间 [0,1]]
```

正确：

```text
[T#B#区间 \[0,1\]]
```

## 输出前检查清单

1. 是否所有标签和参数都使用规定的大小写？
2. 是否每个以 `[` 开始的语法都有两个结构分隔 `#`，并有正确的结尾 `]`？
3. 是否所有块级语法都从新一行的第一个字符开始？
4. 是否每个选择题选项都使用准确的 `* ` 或 `- ` 前缀？
5. 是否用行首标记声明答案的多选题写了 `multi`，需要固定顺序时写了 `fixed`？
6. 是否需要分组的挖空都使用正整数编号，且分组符合预期？

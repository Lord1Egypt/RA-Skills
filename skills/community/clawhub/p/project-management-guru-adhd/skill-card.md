## Description:

Expert project manager for ADHD engineers managing multiple concurrent projects. Specializes in hyperfocus management, context-switching minimization, and parakeet-style gentle reminders.

This skill is ready for commercial/non-commercial use.

## Use Case:

Engineering managers, team leads, and developer-support agents use this skill to structure project work for ADHD engineers by reducing context switching, chunking tasks, managing hyperfocus, and sending supportive deadline reminders.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may suggest workplace activity monitoring for ADHD-focused project management.

Mitigation: Require explicit opt-in from affected engineers, minimize monitored signals, limit retention, and keep Slack, calendar, GitHub, and time-tracking integrations user-controlled.

Risk: Some health-adjacent interventions can sound coercive or imply medical authority.

Mitigation: Use supportive, non-coercive language and avoid medical-authority framing; managers should present reminders as optional assistance, not diagnosis or treatment.

Risk: Deadline reminders and hyperfocus interruptions could increase pressure if applied without consent.

Mitigation: Agree on reminder frequency, urgency levels, escalation paths, and interruption rules with each participant before using the skill in a workplace.

## Description:

Palest Ink tracks local development activity including Git, browser history, shell commands, VS Code edits, app focus, and file changes, then helps an agent answer activity-recall questions and generate daily reports.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and individual users use this skill to maintain a local work journal, search recent activity, and produce daily or weekly summaries from collected activity records.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill performs continuous local logging of browsing, commands, app and window titles, editor activity, Git metadata, and file paths.

Mitigation: Install only after informed consent, disable collectors that are not needed, and regularly review or delete the local activity store.

Risk: Some collectors require broad local permissions such as Full Disk Access or Accessibility.

Mitigation: Grant only the permissions needed for the chosen collectors and avoid broad Terminal permissions unless Safari history or app focus tracking is required.

Risk: Global Git hooks and URL content fetching introduce security risks beyond local note-taking.

Mitigation: Review hook installation before enabling it, disable Git hook or content collectors in sensitive environments, and configure URL exclusions for private or high-risk sites.

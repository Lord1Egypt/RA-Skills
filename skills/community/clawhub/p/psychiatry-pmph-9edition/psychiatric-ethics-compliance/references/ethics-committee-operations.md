# 医疗伦理委员会运作规范

## 伦理委员会组成

### 人员构成
- 精神科医师（2-3名）
- 护理代表（1名）
- 法律专家（1名）
- 伦理学专家（1名）
- 社会工作者（1名）
- 患者/家属代表（1名）
- 社区代表（1名）

### 职责
1. 审查复杂伦理案例
2. 制定伦理政策指南
3. 提供伦理咨询
4. 开展伦理教育
5. 监督伦理规范执行

## 伦理审查流程

### 申请提交

**申请人**：主管医师、患者/家属、其他医务人员

**提交材料**：
- 伦理审查申请表
- 病例摘要（匿名化）
- 相关医疗记录
- 已采取的沟通记录

### 审查类型

| 类型 | 适用情况 | 时限 |
|-----|---------|-----|
| 紧急审查 | 需24小时内决策 | 即时 |
| 快速审查 | 争议较小的常规问题 | 3个工作日 |
| 会议审查 | 复杂伦理困境 | 7-14天 |

### 会议审查流程

```
1. 申请人陈述（10分钟）
2. 委员提问（20分钟）
3. 利益相关方陈述（10分钟）
4. 委员讨论（30分钟）
5. 投票表决
6. 形成书面意见
```

### 审查意见类型

- **同意**：按申请方案执行
- **修改后同意**：按建议修改后执行
- **不同意**：说明理由，提供替代建议
- **暂缓决定**：需补充信息

## 常见审查事项

### 非自愿治疗审查

**审查要点**：
- [ ] 诊断是否明确
- [ ] 危险性评估是否充分
- [ ] 是否已尝试自愿方案
- [ ] 限制措施是否最小化
- [ ] 是否有定期复核计划

### 研究伦理审查

**审查要点**：
- [ ] 知情同意程序是否完善
- [ ] 风险/收益比是否合理
- [ ] 受试者选择是否公平
- [ ] 隐私保护措施是否充分
- [ ] 弱势群体保护是否到位

### 资源分配审查

**审查要点**：
- [ ] 分配标准是否明确
- [ ] 标准应用是否一致
- [ ] 决策过程是否透明
- [ ] 申诉渠道是否畅通

## 伦理培训要求

### 新员工
- 入职伦理培训（4学时）
- 知情同意操作培训
- 隐私保护培训

### 在职人员
- 年度伦理继续教育（≥8学时）
- 案例讨论会（每季度）
- 新法规/指南培训

### 培训记录
- 培训签到表
- 考核成绩
- 培训证书
- 保存期限：任职期间+3年

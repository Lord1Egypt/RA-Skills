## Description:

竞品分析 / 竞争对手分析 / 市场竞争分析 / competitive analysis / 竞品调研。为产品经理、市场经理、战略规划师快速生成竞品对比矩阵、SWOT分析、功能差异表、定价策略对标等结构化分析报告。覆盖产品功能、商业模式、营销策略、用户定位等多维度竞争情报。广泛应用于竞品调研报告撰写、融资路演竞争分析、产品立项评审、市场进入策略制定、投资决策支持等职场高频场景。

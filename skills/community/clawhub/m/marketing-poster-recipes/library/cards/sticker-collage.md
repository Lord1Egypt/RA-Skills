# sticker-collage · 贴纸拼贴容器清单

> 输入类型：文生图｜引擎：ImageGen｜稳定性：**未知**（Day3 新入未实测）
> 来源：AIGC广告创意工作坊 Day3 学员资料包（含官方可复用模板+负面词+可替换方向，2026-11-26 入库）

## 适用场景

「容器+5-7 件单品」的清单式种草——贴纸描边+倾斜遮挡+箭头标注。适合好物清单/礼物指南/装备盘点（一张图讲一组物件，而非单一产品）。

## 输入槽位（按官方可复用模板填空）

| 槽位 | 示例值（可换） | 说明 |
|---|---|---|
| {{主题}} | Happy Thursday 好物 | 海报主题，标题文案 |
| {{容器}} | 红色购物篮 | 官方可替换：藤编篮/木托盘/牛皮纸袋/抽屉/行李箱/搪瓷烤盘 |
| {{单品×5-7}} | 礼盒/纸杯蛋糕/马克杯/香薰/钻戒/插画小卡 | 每件配一个标注词 |
| {{标注词×5}} | RING/DESSERT/COFFEE/CANDLE/CARD | 物件名或情绪短语，英文短词更稳 |
| {{主色}} | 低饱和正红+酒红 | 官方可替换：墨绿+米白/藏蓝+奶油/焦糖+浅灰/莓果粉+燕麦 |
| {{点缀色}} | 一点绿叶 | 只留一处点缀色 |

## 生成 Prompt（官方可复用模板，填槽后投喂）

```text
{{主题}}拼贴海报：竖版 4:5，浅灰白方格笔记本纸底，四周细圆角边框；中下部一只{{容器}}作基底。篮内错落 5-7 件单品：{{单品列表}}。单品均为白底描边贴纸抠图，轻微倾斜、相互遮挡；{{主色}}手绘弯箭头指向短标注（{{标注词列表}}）。顶部{{主色}}手写花体标题「{{主题}}」；配色低饱和{{主色}}+奶白，只留一处{{点缀色}}点缀；哑光纸感、淡接触阴影、大量留白。
```

**官方负面词（追加在 prompt 末尾）**：3D 渲染、写实产品照、强反光、荧光色、厚重阴影、杂乱堆叠、Q 版卡通、模糊、水印。

**官方可替换方向**：容器（藤编篮/木托盘/牛皮纸袋/抽屉/平放行李箱/搪瓷烤盘）；配色（墨绿+米白/藏蓝+奶油/焦糖+浅灰/莓果粉+燕麦）；主题（通勤包内物/夏日冰饮清单/护肤台面/周末露营装备/书店橱窗推荐）。

## 坑与备注（预判，未实测）

- 负面词是这张卡的灵魂（防 3D 化/写实化跑偏），**必须带上**
- 花体标题「Happy Thursday ♡」类手写字有乱码风险——英文短标题相对稳，验收逐字查；翻车则后期排版补
- 单品 5-7 件别贪多：>7 件画面挤、标注词容易糊

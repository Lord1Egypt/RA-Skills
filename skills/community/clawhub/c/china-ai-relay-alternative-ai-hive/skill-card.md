## Known Risks and Mitigations:

Risk: The skill stores an AI-HIVE API key locally or reads it from the environment.

Mitigation: Use the skill only when intending to access AI-HIVE, keep keys out of logs and shared artifacts, and verify local key files are permission-restricted.

Risk: Image and video helpers upload explicitly selected media and may download generated outputs.

Mitigation: Start with non-production media, confirm the user has rights to uploaded assets, and monitor output location and download size.

Risk: Custom base URLs and server-controlled upload or download destinations can change where data is sent or retrieved.

Mitigation: Prefer the default AI-HIVE endpoint and avoid untrusted base URL overrides.

Risk: Implicit invocation and hardcoded Token Hub identifiers may route users into this workflow unexpectedly.

Mitigation: Review invocation policy and hardcoded identifiers before installation, and disable or avoid implicit invocation where the host agent allows it.

## Description:

Imagine the project already failed, then work backward to identify likely causes, prioritize risks, define mitigations, and monitor warning signs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[artyomx33](https://clawhub.ai/user/artyomx33)

### License/Terms of Use:


## Use Case:

Employees, external teams, developers, and project leads use this skill to run structured pre-mortem analysis before launch or commitment decisions. It helps them imagine project failure, group likely causes, rank likelihood and impact, define prevention actions, and identify early warning signs.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate for broad project-risk language and steer the assistant into a pre-mortem format.

Mitigation: Use it when structured failure analysis is desired, and review generated risks and mitigations against project context before acting.

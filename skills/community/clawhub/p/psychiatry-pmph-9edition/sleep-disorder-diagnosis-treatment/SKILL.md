# 睡眠障碍诊断与治疗

## 适用场景

当遇到以下情况时使用本技能：
- 患者存在打鼾、呼吸暂停、日间嗜睡等症状，需评估睡眠呼吸障碍
- 患者主诉入睡困难、睡眠维持困难或早醒，需诊断失眠障碍
- 患者夜间腿部不适伴活动冲动，需评估不宁腿综合征
- 患者睡眠中出现异常行为或梦境演绎，需评估REM睡眠行为障碍
- 肥胖患者伴日间高碳酸血症，需评估肥胖低通气综合征
- 需要制定PAP/CPAP治疗方案或失眠药物治疗方案

## 核心工作流程

### 1. 睡眠呼吸障碍诊断路径

```
患者症状评估（打鼾/呼吸暂停/日间嗜睡）
    ↓
选择监测方式
    ├─ 金标准：实验室PSG
    └─ 替代：OCST（禁用于心衰合并症及单纯筛查）
    ↓
计算AHI = (呼吸暂停次数 + 低通气次数) / 总睡眠时间(小时)
    ↓
诊断与分级
    ├─ OSA诊断：AHI≥5伴症状 或 AHI≥15无症状
    ├─ 轻度：5≤AHI<15
    ├─ 中度：15≤AHI<30
    └─ 重度：AHI≥30
    ↓
鉴别CSA：中枢性AHI≥5且中枢事件占比>50%
    ├─ CSA-CSB：陈-施呼吸，周期>40秒，多伴心衰
    └─ 治疗后CSA：PAP治疗后新出现中枢事件
```

### 2. OSA的PAP治疗规范

执行步骤：
1. 确认适应症：PAP是OSA一线治疗
2. 患者宣教：治疗原理、可能不适（鼻塞、喉干等）及处理方法
3. 设备选择：
   - 无心肺疾病/中枢性呼吸暂停 → 家庭APAP
   - 后续可转CPAP或继续APAP
4. 建立随访计划：监测疗效与副作用

### 3. 失眠障碍评估与诊断

```
主诉评估
    ├─ 入睡困难：儿童>20min，中老年>30min
    ├─ 睡眠维持困难：睡眠不实/早醒（提前≥30min）
    └─ 必须伴有日间功能损害
    ↓
评估工具
    ├─ 主观：PSQI、ESS、ISI
    └─ 客观：PSG（鉴别用）、体动记录仪
    ↓
诊断分型
    ├─ 慢性失眠(CID)：≥3个月，每周数次
    └─ 短期失眠(STID)：<3个月
    ↓
排除鉴别
    ├─ 睡眠-觉醒时相障碍
    ├─ 睡眠呼吸障碍
    └─ 睡眠相关运动障碍（如RLS）
```

### 4. 失眠4P病因分析

对综合医院失眠患者，系统评估四类因素：
- **P1-生理/躯体**：睡眠规律打乱、OSA、疼痛、心绞痛、尿频、内分泌疾病
- **P2-心理**：焦虑、抑郁、对失眠的预期恐惧
- **P3-精神医学**：精神疾病、脑器质性病变
- **P4-药理**：咖啡因、降压药、类固醇、突然停用镇静药、酒精依赖

### 5. 失眠药物治疗决策树

```
确定失眠形式
    ├─ 入睡困难 → 短半衰期药物
    ├─ 睡眠维持困难/早醒 → 较长半衰期药物
    └─ 整夜睡眠需求 → 半衰期6-8h
    ↓
药物选择顺序
    ├─ 一线：NBZDs（唑吡坦5-10mg、右佐匹克隆1-3mg）
    ├─ 二线：BZDs、褪黑素受体激动剂、食欲素受体拮抗剂
    ├─ 伴焦虑/抑郁：镇静类抗抑郁药（多塞平3-6mg、米氮平7.5-30mg）
    └─ 难治性：镇静类抗精神病药（喹硫平12.5-50mg）
    ↓
用药规范
    - 疗程≤4周，超期需每月评估
    - 动态评估、合理撤药
    - 禁用抗组胺药治疗慢性失眠
```

### 6. 不宁腿综合征(RLS)诊断

必须同时满足：
- A. 强烈活动腿的欲望，休息时出现/加重，活动后缓解，傍晚/夜间明显
- B. 排除药物/行为习惯/局部病变所致
- C. 引起功能障碇

分型：
- 慢性持续性：每周≥2次（过去1年）
- 间歇性：每周<2次

治疗：非药物（首选轻度）→ 铁剂/多巴胺能药物/α2δ配体类

### 7. RBD药物治疗

首要干预：环境安全预防（软垫、移除危险物品）

药物选择：
- 氯硝西泮：0.25-2.0mg，睡前15min（90%有效，注意晨倦/跌倒）
- 褪黑素：3-12mg，睡前（不良反应少）
- 佐匹克隆：3.75-7.5mg，睡前

## 关键约束

- OCST禁用于充血性心力衰竭合并症患者
- OHS诊断必须排除肺部/胸廓/神经肌肉疾病
- RLS需排除药物、静脉曲张、关节炎等继发原因
- RBD需警惕作为神经系统变性疾病早期预警
- 失眠诊断必须有日间功能损害，仅有睡眠症状不能诊断

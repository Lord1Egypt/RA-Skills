# 毛病词典

> 复核时按症状查表。判据始终只有一条：**删掉它，这段话有没有少东西。没少就删。**
> 来源：本项目四轮实修中被作者点出的毛病，加上外部写作技能的反 AI 腔清单里本项目还没有的四类（拟人化、罗列式分点过密、小标题过密、名词化堆叠）。**只取症状清单，不取它的统计阈值**——阈值会误伤正当中文表达。

## 一、删：本来就不该存在的句子

**1. 凭空的时间锚**
症状：「随着……的到来」「在这个……的时代」「近年来」起头，下文拿不出任何时间依据。
处方：删。要么给确切时间，要么整句去掉。

**2. 伪精确数字**
症状：「90% 的人」「提升 300%」「三个关键点」——数字找不到出处，只为显得有依据。
处方：删数字，或删整句。
例外：作者自己给的操作参数（如「30~90 分钟」）是事实锚，照抄不动。

**3. 无出处的权威断言**
症状：「研究表明」「业内公认」「专家建议」，没有来源。
处方：删掉断言；确实要留，就写明是谁说的。

**4. 空排名断言**
症状：「最值钱的是第三问」「更要紧的是」「比 X 更值钱」——只给排名，不给信息。
处方：删掉排名，直接把那件事说出来。
例外：排名本身就是操作标准时保留，如「做眼下最痛的那一块」。

**5. 求稳的辩证收束**
症状：「两个都不完美，答案也不是二选一」「各有各的好」——为了显得周全。
处方：删。要收就收一个明确判断。

**6. 为对称而对称的成对清单**
症状：「好处：一、二、三 / 坏处：一、二、三」，为了工整而分两栏。
处方：合成连贯段落，只留实质性结论。

**7. 无信息量的强调词**
症状：「最要紧」「恰恰」「真正」「无非」——去掉之后句子意思不变。
处方：删词，或换成一个具体说法。

**8. 孤儿句**
症状：半句被删之后剩下的孤立评价句（「这条规则定得狠。」）、没有信息的收束句、指代已经消失的过渡句。
处方：删。它是上一轮删减留下的残骸。

## 二、说清：写的人才知道的坐标

**9. 脑内坐标**
症状：「这一层 / 上一层」「第 3 条最要紧」「上面那五问里」「按这五块写」——写的人眼里明确，读者眼里是空的。
处方：删掉编号与层数，在句子里把内容直接说出来。
例外：编号本身是读者照着做的清单时保留（提示词里的「1. 2. 3.」），但正文指代它时必须复述内容。

**10. 跨章回指**
症状：「前面讲过」「下一章会讲」「见第 X 章」。
处方：当场把内容说出来，或删掉这句。每一章都必须自足。

**11. 未解释的术语**
症状：专业词第一次出现就用，不给解释。
处方：当场补一句白话解释。

## 三、改形：意思留着，换说法

**12. 拟人化**
症状：「数据在说话」「时间会回答」「方法自己跑了起来」。
处方：改写成「谁、做了什么、结果如何」。

**13. 名词化堆叠与空泛词**
症状：「赋能」「抓手」「闭环」「生态」「维度」「实现了……的提升」。
处方：还原成动词句，写清具体动作和结果。

**14. 空洞祈使**
症状：「一定要」「务必」「让我们」「从今天起」。
处方：换成一个读者今天就能做的具体动作，或删。

**15. 模板化收束**
症状：「综上所述」「总的来说」「不难发现」「值得一提」。
处方：删；要收就收一个新判断。

**16. 「不是 X 而是 Y」滥用**
症状：成段用这个句式，形成机械节奏。
处方：删掉否定半句，直接说 Y。

**17. 破折号成段**
症状：一段里出现两次以上，插入、转折、强调都用它。
处方：改成冒号、逗号、句号把句子断开。
例外：中文破折号承载突转与插入，按功能保留，不按数量砍。

**18. 无来源的绝对化**
症状：「唯一」「众所周知」「毋庸置疑」「无与伦比」。
处方：降级成相对表达，或删。

## 四、拆合：结构层

**19. 罗列式分点过密**
症状：全篇「第一 / 第二 / 第三」，读起来像清单不像文章。
处方：合并成段落论证，只留最关键的几项。
例外：操作步骤、检查表天生适合分点，保留。

**20. 小标题过密**
症状：两三百字一个小标题，把文章切碎，掩盖论证的空洞。
处方：合并相邻小节，用段落过渡替代小标题。

**21. 铺垫成段 / 比喻成段**
症状：为了引出结论先讲一段故事、打一个比方，读者要等很久才拿到东西。
处方：把东西直接拿出来放在前面；比喻只在承担说理、且不是把上文换个说法重讲一遍时才留。

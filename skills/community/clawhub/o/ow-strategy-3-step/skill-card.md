## Description:

OW Strategy 3 Step (大恩专题策略三步法) is a concise real-estate marketing strategy workflow for quickly defining core challenges, solution and positioning themes, and communication plans.

This skill is ready for commercial/non-commercial use.

## Use Case:

Marketing planners and real-estate teams use this skill to draft quick strategy proposals by defining core project challenges, solution and positioning themes, and staged communication plans.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Crafted project names can cause the helper script to write files outside its intended project folder.

Mitigation: Sanitize and constrain project names before running the helper, and review generated paths before use.

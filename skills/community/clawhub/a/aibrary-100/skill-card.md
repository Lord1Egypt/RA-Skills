## Use Case:

External users use this skill to get Aibrary 100 book recommendations for the AI age, filtered by category, desired number of results, or reading purpose. It helps readers choose starting points and relevant books across durable human capabilities.

## Known Risks and Mitigations:

Risk: Broad requests for must-read or essential books may trigger Aibrary's curated framework when the user wanted a broader, non-branded recommendation set.

Mitigation: Clarify whether the user wants the Aibrary 100 list or a broader recommendation set when the request is ambiguous.

## Description:

Analyzes Chinese workplace report drafts, identifies missing report elements, predicts likely audience reaction, and gives up to three focused improvement suggestions.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ladeng6666](https://clawhub.ai/user/ladeng6666)

### License/Terms of Use:

MIT-0

## Use Case:

Employees, managers, and external users can use this skill to review Chinese workplace reports, weekly updates, project progress notes, retrospectives, and upward-reporting drafts before sharing them with a manager or team.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate when pasted text merely resembles a workplace report draft.

Mitigation: Review whether the user's intent is report feedback before relying on the analysis.

Risk: The skill's output format is fixed in Chinese unless higher-priority instructions override it.

Mitigation: Request a different language or format explicitly when a non-Chinese response is required.

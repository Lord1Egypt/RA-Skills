# 呼吸支持参数设置参考

## 有创机械通气（肺保护性策略）

| 参数 | 推荐值 |
|------|--------|
| 潮气量 (Vt) | 6ml/kg 理想体重 |
| PEEP | 根据FiO₂-PEEP表设置 |
| 平台压 | <30cmH₂O |
| 驱动压 | <15cmH₂O |
| FiO₂ | 维持SpO₂ 92-96% |

## 俯卧位通气

- **指征**：PaO₂/FiO₂ < 150mmHg
- **时长**：每次≥16小时
- **禁忌**：脊柱不稳定、颅内高压、血流动力学不稳定

## ECMO模式选择

| 情况 | 模式 |
|------|------|
| 单纯呼吸衰竭 | VV-ECMO |
| 合并心功能不全/休克 | VA-ECMO |

## 氧合指数(PaO₂/FiO₂)分级

| 分级 | PaO₂/FiO₂ (mmHg) |
|------|------------------|
| 正常 | >400 |
| 轻度ARDS | 200-300 |
| 中度ARDS | 100-200 |
| 重度ARDS | <100 |

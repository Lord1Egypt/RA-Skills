## Description:

Check keyboard, screen-reader, contrast, focus, and semantics for a UI surface.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ritual](https://clawhub.ai/user/ritual)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to review UI surfaces for accessibility issues in keyboard operation, semantics, focus order, color contrast, and announced dynamic changes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Optional knowledge capture could add repository-persistent guidance that the user did not intend to keep.

Mitigation: Create knowledge notes only after explicit user approval and keep them small, cited, and reviewable.

Risk: The optional Ritual Cloud upgrade asks users to install and run a third-party CLI and connect project context to a cloud service.

Mitigation: Review the Ritual CLI/package before installing it and connect cloud context only when the project permits it.

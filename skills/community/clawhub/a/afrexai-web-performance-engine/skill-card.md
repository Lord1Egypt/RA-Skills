## Known Risks and Mitigations:

Risk: Unsafe command examples could run unintended shell commands if a hostile URL is audited.

Mitigation: Use the skill only with trusted targets, validate URLs before live audits, pass URLs as separate quoted arguments, and run live checks in a constrained environment with limited filesystem and network access.

## Description:

Write an API versioning strategy document for a service or API platform. Use when asked to define versioning policy, plan API deprecation, classify breaking changes, or document version lifecycle. Produces a complete versioning strategy with breaking-change classification table, deprecation timeline, migration guide template, and client communication template.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, platform teams, and API product owners use this skill to draft an API versioning strategy for REST, GraphQL, or gRPC services, including lifecycle policy, breaking-change rules, deprecation timelines, migration guidance, and consumer communications.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated deprecation timelines and migration steps can affect consumer access to a real API.

Mitigation: Review the proposed timelines, consumer-blocking steps, route retirement actions, and migration instructions with service owners before applying them.

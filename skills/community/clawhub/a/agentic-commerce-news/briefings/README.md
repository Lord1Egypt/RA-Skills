# Briefing Archive

Published output of this skill — one file per week, newest first.

Each briefing is generated by running `/agentic-commerce-news` in Claude Code, then committed here verbatim (sources and all). If you want to judge whether the skill is worth installing, read one of these first: the archive **is** the demo.

| Week | File |
|------|------|
| Jun 26 – Jul 3, 2026 | [2026-06-29.md](./2026-06-29.md) |

## Format

Every file follows the structure defined in [`SKILL.md`](../SKILL.md):

- Cards grouped by event type — **Funding / Product Launches / Founder & VC Opinions / Partnerships / Reports**
- Every item: date, endorsement (who backed or amplified it), key points, [9-layer stack](../SKILL.md) classification, and a source link
- An **At a Glance** table plus 2–3 **Weekly Takeaways**

## Contributing a week

Run the skill yourself and open a PR adding `YYYY-MM-DD.md` (the Monday of that week). Briefings must pass the skill's quality gates — 7-day window, credible endorsement, source link per item, no PR fluff.

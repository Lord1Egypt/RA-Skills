# 肝病相关感染管理

## 适用场景

本技能用于处理三类肝病感染相关临床决策：
1. 免疫抑制/化疗/靶向治疗患者的HBV再激活预防
2. HCV感染患者的DAA治疗方案选择
3. 肝衰竭并发AKI/HRS的治疗

---

## 流程一：HBV再激活预防

### 触发条件
患者拟接受化学治疗、靶向药物或免疫抑制剂治疗

### 执行步骤

1. **治疗前筛查**（必须执行）
   - 检查 HBsAg、抗-HBc 和/或 HBV DNA

2. **预防性抗病毒治疗指征判断**
   - **指征A**：HBsAg 和/或 HBV DNA 阳性 → 启动预防
   - **指征B**：HBsAg 阴性、抗-HBc 阳性，且满足以下任一条件：
     - 使用B淋巴细胞单克隆抗体
     - 进行造血干细胞移植
     - 伴进展期肝纤维化/肝硬化

3. **用药时机**
   - 理想：免疫抑制/靶向/化疗开始前至少1周应用NAs
   - 最低：与免疫抑制/靶向/化疗药物同时应用

4. **停药管理**
   - 根据患者具体病情个体化决定
   - 密切监测以防延迟再激活
   - 禁止盲目骤停

## 流程二：HCV DAA治疗方案选择

### 触发条件
患者确诊HCV感染并需进行抗病毒治疗

### 前置评估
- 明确HCV基因型（1b, 1, 2, 4, 5, 6或泛基因型）
- 评估肝硬化状态（代偿期/失代偿期/无）
- 评估既往DAAs治疗史

### 方案选择决策树

```
IF 泛基因型需求:
  → 索磷布韦/维帕他韦
  → 来迪派韦/索磷布韦

IF 基因1b型:
  → 艾尔巴韦/格拉瑞韦

IF 基因1/2/4/5/6型:
  → 来迪派韦/索磷布韦

IF 既往DAAs治疗失败（基因1-6型）:
  → 索磷布韦/维帕他韦/伏西瑞韦（挽救方案）
```

### 禁忌审查（关键）
- **代偿期肝硬化**：所有DAA方案均可使用
- **失代偿期肝硬化**：⚠️ 严禁使用含蛋白酶抑制剂（NS3/4a）的方案
  - 蛋白酶抑制剂包括：格拉瑞韦、达诺瑞韦、伏西瑞韦

### 安全警告
- 处方前必须核查药物相互作用（DDI）

## 流程三：肝衰竭并发AKI/HRS治疗

### 触发条件
肝衰竭患者出现急性肾损伤（AKI）或怀疑肝肾综合征（HRS）

### 分阶段治疗流程

#### 阶段1：AKI预防
- 纠正低血容量
- 积极控制感染
- 避免肾毒性药物
- 权衡静脉造影剂使用

#### 阶段2：AKI早期治疗
- 减少或停用利尿治疗
- 停用肾损伤药物、血管扩张剂、非甾体消炎药
- 扩充血容量：晶体液、白蛋白或血浆
- 怀疑细菌感染时早期控制感染

#### 阶段3：HRS评估
- 停用利尿剂 + 静脉白蛋白扩容
- 若无效 → 考虑HRS诊断

#### 阶段4：HRS药物治疗

**方案A：特利加压素方案**
| 阶段 | 特利加压素 | 白蛋白 |
|------|-----------|--------|
| 初始 | 1mg/4-6h | 20-40g/d |
| 加量（3天后血肌酐下降<25%时） | 2mg/4h | 维持 |
| 疗程 | 有效则7-14天 | - |

**方案B：去甲肾上腺素方案**
- 去甲肾上腺素 0.5-3.0mg/h + 白蛋白 10-20g/d
- 对1型或2型HRS疗效与特利加压素类似

#### 阶段5：终极治疗
- 人工肝系统或透析延长生存
- 条件允许尽早肝移植（无肾脏基础疾病者移植后肾功能多可恢复）

## 输出要求

根据具体场景输出：
- HBV预防：是否需要预防性抗病毒治疗的决策 + NAs启动时机 + 停药评估建议
- HCV治疗：推荐DAA药物组合 + 肝硬化禁忌警告 + DDI核查提示
- AKI/HRS：分阶段干预措施 + 血管活性药物与白蛋白联合剂量方案 + 肝移植建议

# 检索深度指南（`owl_search` / `owl_article` / `owl_fulltext` / `owl_oa` / `owl_citations`）

> 按需读取：用户要「按年份 / 类型 / 分类号 / 核心刊筛」「查准一点」「下载全文」「滚雪球找文献」
> 或检索结果不好需要换策略时读。基础检索（query + limit + 默认双源并行）在 SKILL.md §三工作流 1。

## 一、硬过滤参数（全部可选，与检索同一次调用，不多扣费）

| 参数 | 用法 |
|---|---|
| `year_from` / `year_to` | 发表年份区间（跨度 ≤20 年）；「近三年」「2020 年以后」时用 |
| `doc_types` | 文献类型，可多选：`journal` / `thesis` / `standard` / `patent` |
| `classification` | 分类号 `L=中图号`（如 `L=TP3`）或 `C=学科`（如 `C=计算机`）；**仅中文库支持**，指定后只走中文通道 |
| `core_only` | true 时只要核心期刊（真实硬过滤，不是排序） |
| `sort` | `relevance`（默认）/ `newest` / `cited` |
| `offset` | 跳过前 N 条翻页（配合 `limit`，0–1000） |
| `search_mode` | `both`（默认，全球库关键词查全 + 中文核心期刊 / 英文 OA 核心期刊全文向量检索查准，跨源去重）/ `keyword`（只走全球库）/ `vector`（只走核心刊全文向量检索） |
| `research_scope` | 调研范围三档 `core` / `academic` / `all`（默认），可配 `doc_types` 自定义 |

- **专利优先**：query 含专利、权利要求、公开号、查新等词时优先走专利检索通道，不可用时回落到全球库专利分类。
- 不必逐项问用户（SKILL.md §二追问纪律）：`query` 问清就够，其余按默认先查，回复里一句话交代
  「按中文库 + 近五年 + 10 篇查的，要收窄告诉我」。
- 扩展只在实拉时进行：缓存命中直接返回既有结果、不扩展。

## 二、query 怎么写（检索质量第一决定因素）

- **主词优先**：最核心概念放最前（「生物防腐剂 制备」），别写成整句疑问。
- **多概念拆两查**：中英文概念分开查（`生物防腐剂` 一查、`bacteriocin preservation` 一查），各取 top 合并，命中率高于硬塞长 query。
- **结果差就换词不硬试**：命中 <3 条换成上位词 / 别名（「乳酸菌素」→「细菌素」）；两次都差就如实说该方向文献覆盖有限，别反复烧检索费。

## 三、召回不够时的升级顺序（别反复烧钱）

1. **别名 / 缩写补齐**：概念的中英文写法放同一组（`大语言模型 OR LLM OR large language model`）；常见映射：人工智能→AI、机器学习→ML、自然语言处理→NLP、知识图谱→KG。
2. **宽窄切换**：默认主题词查；命中过少改题名查（更准）或全字段查（更全，须说明「全字段检索结果」）；命中过多且前几条不相关，加限定词收窄而不是翻页堆量。
3. **核心刊硬过滤**：用户明确「只要核心期刊」传 `core_only=true`；只是「核心优先」用默认 `sort=relevance`，`core`/`core_tags` 会把核心文献往前排并标注（`core_tags` 是官方标记）。
4. **年份 / 类型 / 分类号用硬参数**：优先用上表参数精确过滤，别只把限定词塞进 query；只有没对应参数时才退回文本限定，并说明「这是文本限定、不是数据库硬过滤」。命中即真实题录，未命中不要声称「该库没有此类文献」。

## 四、结果里三个字段要用起来

| 字段 | 怎么讲 |
|---|---|
| `score` | 相关性得分。问「为什么先推这篇」时按「题名命中 > 摘要命中 > 核心刊 > 有 DOI > 年份新」解释 |
| `core` / `core_tags` | 官方权威标记：`BDHX` 北大核心 / `CSCD` / `CSSCI` / `CSTPCD` / `SCOPUS` / `SCI`，有就直说「北大核心 + CSCD 收录」；`core` 为 `null` 表示补不到收录信息，**不等于非核心** |
| `is_oa` | 外文命中时有值：`true` 可用 `owl_oa` 免费取全文；`null` 表示开放状态未知（保守判定，不猜），想免费用就先调 `owl_oa` 复核 |

## 五、取全文：先分语言，别一律推付费

**取全文前先确认**：报出即将下载的标题 / ID 与本次消耗（免费 OA 就说免费），用户确认后再执行；批量取多篇先说总篇数，别静默扣积分。

**中文文献** → `owl_fulltext(identifier)` 取 PDF 直链（约 1 小时有效，立即 HTTP GET 下载），存 `02-文献/fulltexts/<一作-年份-题名前20字>.pdf`。只有中文库文献有全文；72 小时内同篇重取按缓存价，单账号每日 100 篇。404 `fulltext_unavailable` = 该篇无授权全文，如实转告，别换参数硬试。

**下载直链三条纪律**（生产事故教训）：
1. URL **原样使用，一字不改**——含 `&` 和编码中文名，拼 shell 命令必须整体加引号，截断 / 重编码都会 400；
2. 下载完校验文件头是 `%PDF` 才算到手；
3. 下载 400 时用**同一链接**原样重试一次（偶发抖动会自愈），仍失败才重取链——重取按缓存价，新链接不保证更好。

**外文文献** → **先走 `owl_oa`（免费）**：传 DOI 最准，没 DOI 传英文题名。
- 返回 `pdf_url` 就直接下载；只有 `landing_page` 把链接给用户（页面里点下载，同样免费）；
- `closed` 才说「付费墙内，无合法免费全文」——**不许暗示能绕过去**，也别这时推销付费下载；
- 免费拿不到再说付费方案，顺序不能反。

**全文状态标记**（结果汇总表逐篇标注）：
`[全文:已获取 ✓]` 已拿到 PDF · `[全文:在线 📖]` 只能在线看 / 需手动保存 ·
`[全文:付费 💰]` 付费墙内无合法免费全文 · `[全文:未尝试 -]` 未触发取全文。

## 六、单篇详情与滚雪球

- **完整元数据**（DOI / 年卷期页码）：`owl_article(identifier, lang)`，72 小时内同篇按缓存价。检索列表没有原始来源链接时用详情里的 DOI + 题名作可核验标识；**详情没有来源库名就别说**，不要臆造「来自 Scopus/Web of Science」。
- **滚雪球找文献**（比反复换关键词准）：`owl_citations(doi, direction)`——
  `direction=refs` 查它引用了谁（找源头与经典），`direction=cited` 查谁引用了它（找后续进展、最新研究）。
  返回的 `cited_by` 是被引次数可判断影响力；`is_oa=true` 可直接免费用 `owl_oa` 取全文。
  适用「这个方向最早是谁提出的」「后来有什么新进展」「再找几篇相关的」。

## 七、检索 / 全文类失败分寸

- 上游短时不可用（502 / 504 / `upstream_error`）：等约 30 秒重试**一次**，仍失败如实说明；不连试、不换工具绕。
- 检索 0 结果不扣费，可换词重查；但同一 query 换壳反复打属滥用限频，改用第三节的别名 / 上位词策略。
- 中文全文 404 `fulltext_unavailable` = 无授权全文，别换 identifier 硬试；
  外文 `closed` = 付费墙内无合法免费全文，给在线阅读 / 联系作者的常规建议，不推付费绕过。
- 任何情况下都不要为通过请求去改用户数据或重复调用付费接口。

## Description:

Creates OpenClaw skills with the correct YAML frontmatter, _meta.json metadata, and file structure; ClawHub publishing is optional.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and OpenClaw users use this skill to create, format, validate, and optionally publish local OpenClaw skills with the expected SKILL.md and _meta.json structure.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill recommends running an unpinned remote ClawHub CLI for login and publishing.

Mitigation: Use a pinned and trusted clawhub CLI version, verify the package source, and run publishing from an isolated workspace with only the required skill files and credentials.

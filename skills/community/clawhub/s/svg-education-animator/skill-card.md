## Description:

Creates child-friendly K-12 educational SVG animations as complete browser-previewable single-file HTML.

This skill is ready for commercial/non-commercial use.

## Publisher:

[shinelee2014](https://clawhub.ai/user/shinelee2014)

### License/Terms of Use:

MIT-0

## Use Case:

Educators, curriculum designers, and agent users use this skill to turn K-12 teaching topics into friendly animated HTML/SVG visuals that can be previewed in a browser.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated HTML may contain code that should be reviewed before browser execution.

Mitigation: Inspect the generated HTML/SVG and styles before opening or sharing the file.

Risk: The skill may activate for broad education or visualization prompts.

Mitigation: Confirm that the requested output is an educational SVG animation before using the generated result.

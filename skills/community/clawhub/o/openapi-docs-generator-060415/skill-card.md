## Description:

Helps API developers and backend or platform teams generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to produce practical workflows, checklists, implementation guidance, and validation notes for OpenAPI, Swagger, and REST API documentation work.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Loose trigger wording may activate the skill for broad API or developer-experience requests.

Mitigation: Use it for explicit OpenAPI, Swagger, REST API documentation generation, validation, or improvement tasks, and prefer clearer trigger text when maintaining the package.

Risk: Documentation guidance can become incorrect when the user's API framework, OpenAPI version, or route metadata is incomplete.

Mitigation: Ask for materially missing framework and API inputs, state assumptions, and include validation commands or review criteria with generated guidance.

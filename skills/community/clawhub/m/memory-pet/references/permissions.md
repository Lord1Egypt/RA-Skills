# memory-pet 权限说明

## 权限扫描报告

| 检查项 | 状态 | 风险等级 |
|--------|------|---------|
| 敏感信息访问 | ✅ 已声明 | LOW |
| 关键位置写入 | ✅ 无需 | LOW |
| 网络请求 | ❌ 无 | NONE |
| 文件删除 | ❌ 无 | NONE |
| Subprocess 调用 | ❌ 无 | NONE |

## 权限权重

| 维度 | 权重 | 本技能情况 |
|------|------|-----------|
| 敏感信息访问 | 40% | 声明 `sensitive_access: true` — 访问 memory 用于保存宠物记忆 |
| 关键位置写入 | 30% | 不写入技能目录或系统目录 |
| 网络访问 | 20% | 不发起任何网络请求 |
| 文件删除 | 10% | 不删除任何文件 |

## 敏感信息访问说明

本技能声明 `sensitive_access: false`，原因如下：

- **Python 全量管理**：所有宠物数据读写全部通过 `pet_manager.py` CLI 处理
- **大模型不直接接触数据**：AI 仅通过调用 `pet_manager.py` 获取 JSON 输出，不直接读写 JSON 文件

## 权限声明

- 本技能 **不会** 访问系统敏感路径或凭证文件
- 本技能 **不会** 向外部网络发送数据
- 本技能 **不会** 执行用户 Shell 配置文件

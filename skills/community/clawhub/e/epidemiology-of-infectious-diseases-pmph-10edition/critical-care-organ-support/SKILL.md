# 重症器官支持与管理

## 第一部分：感染性休克管理

### 一、早期液体复苏（3小时bundle）

**启动条件**：临床诊断感染性休克或脓毒症低灌注

**执行步骤：**
1. 3小时内输注≥30ml/kg晶体液（平衡晶体液优于生理盐水）
2. 完成初始复苏后评估血流动力学状态

### 二、EGDT触发与6小时目标

**触发条件（满足任一）：**
- 补液20-40ml/kg后仍低血压
- 血乳酸 >4mmol/L（不论血压）

**6小时达标目标：**
| 指标 | 目标值 |
|------|--------|
| CVP | 8-12mmHg（机械通气12mmHg） |
| MAP | ≥65mmHg |
| 尿量 | >0.5ml/(kg·h) |
| ScvO₂ | >70% |
| SvO₂ | >65% |
| 血乳酸 | 恢复至正常水平 |

### 三、血管活性药物阶梯方案

**一线**：去甲肾上腺素 0.25-0.50μg/(kg·min)
**二线**：加用抗利尿激素（而非一味加量去甲肾上腺素）
**三线**：加用肾上腺素
**替代**：多巴胺 5-20μg/(kg·min)（心率>120次/min禁用）
**正性肌力**：多巴酚丁胺（充分复苏后仍低灌注）

### 四、补液试验
- 30分钟内输入1000ml晶体液或300-500ml胶体液
- 血流动力学持续改善→继续补液
- 充盈压升高但血流动力学无改善→减慢补液

**扩容达标标准**：神清、口唇红润、肢端温暖；收缩压>90mmHg；脉率<120次/min；尿量>0.5ml/(kg·h)

## 第二部分：休克器官功能维护

### 心功能不全防治
1. 纠正诱因（缺血、缺氧、酸中毒、电解质紊乱）
2. 严格控制输液速度和总量
3. 强心药（西地兰/毒毛花苷K）+ 降低前后负荷
4. 多巴胺或血管解痉剂（须与去甲肾上腺素同用防血压下降）
5. 考虑纳洛酮（增加心输出量）

### 肺功能维护
1. 鼻导管/面罩吸氧，保持气道通畅
2. PaO₂<60mmHg → 及早PEEP通气
3. 血管解痉剂（酚妥拉明/山莨菪碱）降低肺循环阻力
4. 控制晶体液，白蛋白+呋塞米减轻肺水肿

### 肾功能维护
1. 维持有效循环量
2. 血容量充足但少尿 → 20%甘露醇或呋塞米快速静注
3. 无效 → 按急性肾衰竭处理

### 脑水肿防治
1. 识别征象：意识改变、抽搐、颅内压增高
2. 头部降温
3. 脑血管解痉剂（山莨菪碱）
4. 渗透性脱水剂（甘露醇/呋塞米）+ 大剂量糖皮质激素

### DIC防治
1. 核心：去除病灶、抗休克、控制感染
2. 肝素：首次1.0mg/kg，后续0.5-1.0mg/kg q4-6h，目标凝血时间延长至正常2-3倍
3. 出血加重 → 等量鱼精蛋白对抗

## 第三部分：人工肝血液净化治疗

### 一、临床定位与目标

**定义**：替代肝脏部分功能的体外血液净化支持系统

**核心功能**：
- 清除有害物质
- 补充肝脏合成物质
- 改善内环境（水电解质酸碱平衡）

**治疗目标**：
- **可逆期**：辅助至自体肝细胞再生、肝功能恢复
- **不可逆期**：改善症状，作为肝移植"桥梁"

### 二、适应证评估（满足任一）

| 类别 | 具体适应证 |
|------|------------|
| 肝衰竭 | 各病因引起的前/早/中期肝衰竭（晚期需权衡） |
| 肝移植相关 | 等待肝源、术后排斥/无功能、ABO不合脱敏 |
| 肝胆疾病 | 严重胆汁淤积、高胆红素血症 |
| 重症感染 | 细胞因子风暴、免疫失衡 |
| 自身免疫病 | TTP、血栓性微血管病变、结缔组织病致器官衰竭 |
| 代谢异常 | 家族性高胆固醇血症、高脂血症致急性胰腺炎 |
| 急性中毒 | 化学物/毒物中毒 |

### 三、禁忌证排查

**相对禁忌证（需知情同意+调整模式）：**
- 严重活动性出血或DIC
- 对耗材/血制品/药物严重过敏
- 血流动力学不稳定
- 心脑血管意外非稳定期

### 四、Li-NBAL 3.0系统操作流程

1. **血浆分离与置换**：血液经血浆分离器→丢弃部分血浆→补充新鲜血浆
2. **双腔储液袋构建**：等置换量剩余~500ml时，血浆收集入双腔袋（外腔=待净化，内腔=净化后）
3. **吸附滤过净化**：外腔血浆→高通量血滤器（后稀释）→血浆吸附器→回内腔→与血细胞汇合回输
4. **高效循环机制**：净化循环流速可达分离速度10倍，通过流速差实现多次吸附滤过

### 五、滤过模式选择

| 模式 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| 后稀释 | 溶质清除率高 | 易堵膜 | 凝血风险低 |
| 前稀释 | 不易堵膜 | 需更多置换液 | 凝血风险高 |
| **临床策略** | 多种模式交替或比例结合 | - | 平衡清除率与凝血风险 |

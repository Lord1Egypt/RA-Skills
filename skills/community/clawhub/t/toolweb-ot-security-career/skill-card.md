## Use Case:

Cybersecurity professionals, OT engineers, compliance officers, and security architects use this skill to generate personalized OT/ICS/SCADA security career roadmaps from experience, skill, and goal assessments.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Professional profile, skill assessment, career goal, and optional user identifier details are sent to an external third-party service.

Mitigation: Submit only information suitable for sharing with the service operator, avoid unnecessary personal or employer-specific identifiers, and review the provider's privacy terms before use.

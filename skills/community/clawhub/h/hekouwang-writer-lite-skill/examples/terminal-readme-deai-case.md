> **边界（免费版）**：下文 `change_list.py` 结果为**历史摘录**。免费包请用四检查器（本任务重点：`sawdust_scan` / `rhythm_scan`）+ **手工改动清单**（列出改前→改后与数字变动理由）；勿在免费包内查找或运行 `change_list.py`。

> **真实实测**（2026-10-22）。对象是自家开源／付费终端主题包的 README 改写，不是占位句。
> 本页只保留方法证据：诊断结论、改法原则、脚本与盲读结果摘要。不附完整原稿或终稿，也不当作该产品的当前说明。

## 这篇任务的处方

| 决策点 | 选择 | 理由 |
|---|---|---|
| 模式 | 文章模式 · 去 AI 味（中档） | 成稿已有，要去套路、保事实 |
| 读者 | 想装终端主题、尚未分清免费／付费档的开发者 | 决策句要提前，术语要人话 |
| 借用 | dbs-plain-writing 四块（定义句、理解障碍、体裁服从、禁用清单） | 实测无冲突；行末去句号未借用 |
| 不做 | 编第一人称「每天都在用」类品质声明；全盘平铺直叙抹掉轻销售 | 不可验证声明删；付费决策保留 |

## 方法落地（摘录）

### 1. 先诊断：比句法更重的是信息散落

| 问题 | 数量／表现 | 处理 |
|---|---|---|
| 开源／付费分档说明散落 | 约 10 处（开头、badge、引用块、对比节、章节标签、付费清单、免责、安装括号等） | 决策句只留开头一次；其余改指针或删重复 |
| 「细节去文档站」类指针 | 约 7 处 | 合并；第九节指针表整删（链接已在别处） |
| 产品自造词无解释 | 「16 个色槽」「第 1～4、6～8 节」「反解」等 | 首现半句人话 |
| 第一人称 credibility 三连 | 「交过学费」「每天在用」「不是演示品」连读 | 留可验证动作与带数字经历；删不可验证声明 |

### 2. 事实账与改写档

- 事实账约 15 项（功能边界、档位差异、可验证数字）；中档改写，未动数字与付费边界。
- 开头口号位换成**定义句**（对象是什么），盲读复述测试通过。
- 改写后对账（当时跑 `change_list.py`，现作历史摘录）：约 57 处差异，其中 2 处数字变动均有申报理由。免费复现：手工列出改动清单并核对数字变动理由即可。

### 3. 盲读（无上下文子 Agent）

固定读者画像读成稿，可落地发现 5 条，全部回写改法。代表性原话：

- 分档信息读到第二遍觉得啰嗦；
- 卡住顺序先是产品自造词，不是通用术语；
- 品质声明连读像简历自我评价。

写稿上下文自评不算盲读；本任务有跑。

## 和流程演示页的差别

`deai-rewrite.md` 仍是占位句流程示意。本文件证明：真实 README 上「先诊断 → 中档保真改写 → 盲读 → 改动对账」能跑通，且最重的问题常常是**信息架构**，不是换几个口语词。

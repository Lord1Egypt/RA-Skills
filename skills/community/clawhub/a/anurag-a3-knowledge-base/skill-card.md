## Description:

Store and recall only fictional, non-sensitive Assignment 3 preferences and project facts from the local workspace knowledge file.

This skill is for demonstration purposes and not for production usage.

## Use Case:

An assistant uses the skill during the Assignment 3 demonstration to remember, update, and recall only explicitly requested fictional preferences and project facts.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A user could submit sensitive or real personal information for storage despite the skill's synthetic-data boundary.

Mitigation: Store only explicitly requested fictional class-test information and refuse secrets and sensitive details.

Risk: Workspace access can retain remembered facts beyond the current conversation.

Mitigation: Review the requested fact and keep storage limited to the configured workspace knowledge file.

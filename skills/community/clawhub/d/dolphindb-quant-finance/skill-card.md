## Known Risks and Mitigations:

Risk: The skill directs users to source external DolphinDB setup scripts from related skills before use.

Mitigation: Review or pin those setup scripts before installation and only run them from trusted skill versions.

Risk: Examples repeat default DolphinDB admin credentials.

Mitigation: Replace sample credentials with a least-privilege account and secrets-based configuration before adapting examples.

Risk: DolphinDB examples assume a local service on port 8848.

Mitigation: Do not expose DolphinDB port 8848 to untrusted networks and apply normal database access controls.

## Description:

Remove personal data from data brokers and people-search sites.

This skill is ready for commercial/non-commercial use.

## Publisher:

[howtousehumans](https://clawhub.ai/user/howtousehumans)

### License/Terms of Use:

MIT-0

## Use Case:

External users and agents use this skill to remove personal information from people-search and data broker sites, prioritize address exposure during stalking or harassment concerns, and reduce future data collection.

### Deployment Geography for Use:

Global; data broker procedures are US-focused with jurisdiction-specific privacy guidance for EU/EEA, UK, Canada, and Australia.

## Known Risks and Mitigations:

Risk: Using this skill may require searching for and submitting personal information to data broker opt-out forms.

Mitigation: Avoid saving sensitive details in files unless necessary, and use only the minimum information required for each removal request.

Risk: Some opt-out flows use email or phone verification and can expose contact information during the removal process.

Mitigation: Use privacy-preserving contact methods where practical, such as email aliases or a secondary phone number, and review each form before submitting.

Risk: Installation through an unpinned npx command carries normal package-install risk.

Mitigation: Review the package source and installation command before use in sensitive environments.

# 精神科药物过量中毒急救方案

## 抗精神病药过量

### 临床表现
- 早期：激越、意识混浊
- 进展：肌张力障碍、癫痫、昏迷
- 严重：低血压、心律失常、低体温
- 特点：因抗胆碱能作用，EPS通常不明显

### 急救流程

```
1. 消化道清除
   └─ 洗胃（即使数小时后，因胃排空延迟）
   └─ 活性炭50g
   └─ 毒扁豆碱（解毒）

2. 循环支持
   └─ 大量输液
   └─ 升压药选择：间羟胺、去甲肾上腺素
   └─ ⚠️ 绝对禁用肾上腺素

3. 对症处理
   └─ 抗癫痫药控制抽搐
   └─ 维持体温
   └─ 心电监护

4. 注意
   └─ 血液透析效果差（蛋白结合率高）
```

## TCAs过量

### 致死三联征
1. 昏迷
2. 癫痫发作
3. 心律失常（QRS增宽、QT延长）

### 急救要点

| 措施 | 具体方案 |
|-----|---------|
| 解毒剂 | 毒扁豆碱1-2mg IV，每0.5-1h可重复 |
| 洗胃 | 必须执行（抗胆碱能延迟排空）|
| 心律失常 | 碳酸氢钠纠酸、利多卡因 |
| 癫痫 | 地西泮静注 |
| 禁忌 | 避免使用Ia类抗心律失常药 |

### 致死量参考
- 丙米嗪：1.25g
- 阿米替林：1-2g

## 锂中毒急救

| 血锂水平 | 处理 |
|---------|------|
| 1.5-2.0 mmol/L | 停药、补液、监测 |
| 2.0-2.5 mmol/L | 生理盐水利尿 |
| >2.5 mmol/L | 血液透析 |

### 促进排泄
- 大量生理盐水
- 高渗钠盐
- 甘露醇利尿

## 恶性综合征急救

### 立即执行
1. 停用所有抗精神病药
2. 转入ICU
3. 降温措施
4. 补液纠正脱水

### 药物干预
- 丹曲林（dantrolene）：肌肉松弛
- 溴隐亭：促进多巴胺功能
- 苯二氮䓬类：控制激越

### 监测指标
- CPK（横纹肌溶解标志）
- 肾功能
- 电解质
- 生命体征持续监测

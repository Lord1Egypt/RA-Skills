## Description:

Repo-aware router skill for AI coding CLIs that maps tasks to the right repository, project skill or agent, and native CLI backend across OpenClaw, Claude Code, OpenCode, Codex, Cursor, and Hermes.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use AgentRepoRouter to route coding-agent tasks to the intended repository, project-local skill or agent, and native CLI backend while preserving each host's conventions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The reviewed ClawHub package is an install notice and does not include the runtime implementation.

Mitigation: Review the linked upstream repository and installer before changing local agent-host configuration.

Risk: Installation can alter repository routing, selected CLI backends, and generated local mapping files.

Mitigation: Confirm the exact agent hosts, CLI backends, and repository mapping file changes before installation, especially in multi-agent environments.

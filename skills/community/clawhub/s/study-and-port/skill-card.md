## Known Risks and Mitigations:

Risk: The skill may create persistent OpenClaw skills in an active skills directory.

Mitigation: Verify the exact destination path, review generated files, and consider staging new skills outside the active skills directory before installation.

Risk: Generated skills or scripts may introduce unexpected behavior if accepted without review.

Mitigation: Require user confirmation before creating files and review any generated scripts before execution.

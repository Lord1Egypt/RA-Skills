## Description:

Read-only DeFi intelligence for opportunity research, portfolio diagnostics, allocation analysis, route previews, Trail Heat, and Sybil review. Never executes.

This skill is ready for commercial/non-commercial use.

## Publisher:

[parmasanandgarlic](https://clawhub.ai/user/parmasanandgarlic)

### License/Terms of Use:

MIT-0

## Use Case:

DeFi researchers and wallet owners use the skill to compare protocols and airdrop programs, review public-wallet balances and Sybil signals, estimate points or allocation scenarios, and preview capital routes. It provides research guidance and does not execute transactions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security evidence flags an onboarding request that conflicts with the read-only description and transmits an agent wallet address externally.

Mitigation: Review the request and destination before sharing data; use only a public wallet address when needed and never provide private keys or seed phrases.

Risk: The security review was incomplete: one of two components was fully inspected and tool-misuse analysis was degraded.

Mitigation: Treat the clean verdict as medium-confidence and review the skill before deployment.

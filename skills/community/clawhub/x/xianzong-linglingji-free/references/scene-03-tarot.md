# 场景三 · 问塔罗 西方占卜（KB-T-022）

> 对应脚本：`node scripts/linglingji_free.mjs tarot --spread ... --question "..." [--seed N]`
> 本文件只服务这一个场景，读它不必看另外两个场景的文件。

## 免费版与完整版的边界

| | 免费版（本 Skill） | 完整版（灵灵机） |
|---|---|---|
| 抽牌 | 程序模拟抽牌（单张 / 三张 / 凯尔特十字） | 同样支持三种牌阵，但要自己洗牌更有仪式感 |
| 牌意 | 22 张大阿卡纳 + 小阿卡纳按花色 / 数字 / 宫廷牌归类解读 | 78 张**逐张牌意** + 位置与元素的多维交叉 |
| 深度 | 逐张关键词 → 位置含义 → 简单综合 | 牌阵作为整体解读，指出牌与牌之间的呼应 / 矛盾 |
| 交叉 | 不做 | 可与八字、事件应期做交叉验证 |
| 记忆 | 单轮，不记住上次 | 多轮对话，可连续追问同一问题 |

**免费版明确不说**：不预测"一定发生"、不给具体日期、不对他人定性、
不替用户做决定。

## 三句必须每次声明的话

1. 本次为**程序模拟抽牌**，非真实洗牌；有条件请用实体牌自行洗牌。
2. 塔罗是**镜子**，反映当下的心理状态，不预测"一定发生"。
3. 重大决策请结合实际情况并咨询专业人士。

## 牌阵选择

| 问题类型 | 牌阵 | 张数 | `--spread` 取值 |
|---|---|---|---|
| 「该不该做 X」/ 快速答案 / 今日状态 | 单张 | 1 | `single` |
| 「我和 TA 的关系走向」/ 近期走势 | 三张（过去-现在-未来） | 3 | `three` |
| 「A 或 B」「情况-行动-结果」「优势-劣势-建议」 | 三张（变体） | 3 | `three` |
| 复杂 / 迷茫 / 重要决策 | 凯尔特十字 | 10 | `celtic` |

**变体怎么讲**：三张的位置含义由问题决定，脚本按"过去-现在-未来"输出，
若用户问的是"该选 A 还是 B"，改成"情况-行动-结果"讲即可。

## 逐张解读顺序（对每张牌都走这一遍）

1. **位置含义**：这个位置在问什么
2. **正逆位**：能量顺畅，还是受阻 / 过度 / 内化 / 延迟
3. **牌面关键词**：脚本已给，直接引用
4. **元素属性**：火 / 水 / 风 / 土
5. **数字含义**（1-10）：处在哪个进程阶段
6. **与问题的对应**：把上面五点收束成一句针对用户问题的话

**平衡原则**：不要因一张好牌就过度乐观；一张好牌配一张逆位多为中等；
大阿卡纳主导长期，小阿卡纳主导近期；元素分布反映能量结构。

## 常见误读纠正（必须主动纠偏）

| 误读 | 正解 |
|---|---|
| 死神 = 会死 | 是"结束与新生"，通常指关系或阶段结束 |
| 高塔 = 会出大事 | 是"突变"，可能是必要的打破旧结构 |
| 恶魔 = 会被骗 | 是"束缚"，常指你自己的执念 |
| 月亮 = 会失败 | 是"不确定"，主指看不清而非失败 |
| 逆位 = 全盘失败 | 逆位是"能量受阻 / 过度 / 内化 / 延迟" |
| 抽到好牌 = 一定会成 | 牌反映当下趋势，不是结果保证 |

## 脚本输出怎么读

```
【过去】圣杯侍从（正位）→ 情感、关系、直觉 · 学习者 / 消息
【现在】星币3（逆位）→ 现实、金钱、工作 · 成长 / 协作（逆位：能量受阻 / 内化 / 延迟）
【未来】死神（逆位）→ 抗拒改变 / 僵持
```

- 牌名必须照抄脚本，不要自己换牌。
- 同一 `--seed` 结果完全可复现；用户想"重抽换个好结果"要明确拒绝并说明理由。
- 凯尔特十字 10 张要一张不落地讲，不要只讲"结果"那一张。

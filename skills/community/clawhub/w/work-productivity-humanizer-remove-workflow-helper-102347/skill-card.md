## Known Risks and Mitigations:

Risk: Broad automatic invocation cues may cause ordinary writing, editing, review, or bug-fix requests to use this skill unexpectedly.

Mitigation: Before installing, narrow or disable implicit invocation so the skill is only used for intended work-productivity workflow requests.

Risk: The skill can produce plans, checklists, code changes, or guidance that may be incomplete or misleading for a user's specific environment.

Mitigation: Review outputs against the stated success criteria and verify any code, commands, or configuration before applying them.

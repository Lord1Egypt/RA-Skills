## Description:

Helps users create practical local workflows, checklists, analysis, and implementation support for diagnosing network issues such as bufferbloat, router problems, modem issues, and latency.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

External users, including remote workers, gamers, home-office users, and small teams, use this skill to turn consumer network troubleshooting requests into actionable diagnostic plans, checklists, and verification notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill name suggests error-message improvement, while the behavior is network diagnostics.

Mitigation: Confirm the intended purpose before installation and rename or relabel the skill so users understand it is for network troubleshooting.

Risk: Broad trigger conditions and implicit invocation could activate the skill for requests outside explicit network troubleshooting.

Mitigation: Narrow invocation to explicit bufferbloat, router, modem, latency, or network diagnostics requests before deployment.

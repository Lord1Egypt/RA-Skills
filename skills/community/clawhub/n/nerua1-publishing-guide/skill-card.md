## Description:

Universal skill publishing checklist and rules for ClawHub, GitHub, Claude Code, Hermes, and OpenClaw, covering pre-publish vetting, anti-duplicate checks, naming conventions, and promotion strategy.

This skill is ready for commercial/non-commercial use.

## Publisher:

MIT-0

## Use Case:

Developers and skill publishers use this guide to prepare cross-agent skill releases, check release hygiene, choose naming conventions, and validate publication steps across ClawHub, GitHub, Claude Code, Hermes, OpenClaw, and Goose.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security evidence says the guide wrongly requires adding the author's PayPal and GitHub links to every published skill.

Mitigation: Review and remove mandatory PayPal and GitHub link requirements before using the guide as a release template.

Risk: The skill includes CLI publishing examples that could publish from the wrong project or use an unverified ClawHub CLI version.

Mitigation: Run publishing commands only from the intended project and prefer a pinned, verified ClawHub CLI version.

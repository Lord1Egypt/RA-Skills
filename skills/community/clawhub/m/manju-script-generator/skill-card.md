## Description:

Manju Script Generator helps agents produce Chinese short-drama scripts, character and scene prompts, storyboards, image and video prompts, and production guidance for AI comic-drama workflows.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and creative teams use this skill to turn novels or story ideas into production-ready Chinese short-drama materials, including scripts, character sheets, scene prompts, storyboard prompts, and video prompt guidance.

## Known Risks and Mitigations:

Risk: The security evidence says the skill includes guidance for bypassing face restrictions and removing watermarks.

Mitigation: Use it only with assets and likenesses you have rights to, and remove or ignore face-restriction and watermark-removal guidance before use.

Risk: The security evidence says the helper script sends text to a local LLM service and may use GW_TOKEN for that request.

Mitigation: Run the script only against a trusted local LLM endpoint and review token handling before execution.

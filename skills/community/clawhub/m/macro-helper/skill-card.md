## Use Case:

Developers, analysts, and spreadsheet users use this skill to get VBA macro code, explanations, debugging help, templates, conversion guidance, and performance advice for Excel automation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated VBA macros are executable code and may affect workbooks or connected Office applications.

Mitigation: Inspect generated macros, test on backup workbooks, and avoid running VBA generated from untrusted task descriptions.

Risk: The package includes a separate local data and logging utility outside the documented macro workflow.

Mitigation: Review the additional script before installation or execution and check where it writes local data and history files.

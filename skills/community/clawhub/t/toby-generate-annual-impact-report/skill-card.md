## Description:

Create visual impact reports from program data for nonprofits, NGOs, and fundraisers.

This skill is ready for commercial/non-commercial use.

## Publisher:

[tobeyrebecca](https://clawhub.ai/user/tobeyrebecca)

### License/Terms of Use:

MIT-0

## Use Case:

External nonprofit teams, NGOs, and fundraisers use this skill to turn program data into annual impact report drafts with supporting presentation or image assets. Users should refine the report for accuracy, readability, and publication readiness before delivery.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated reports may contain inaccurate or misleading financial, donor, beneficiary, or program-impact claims.

Mitigation: Review all generated reports before publishing or external distribution.

Risk: Presentation or image-generation features may create report assets that do not accurately represent the nonprofit's data or constraints.

Mitigation: Validate generated assets against source program data and revise them for accuracy, readability, and actionability.

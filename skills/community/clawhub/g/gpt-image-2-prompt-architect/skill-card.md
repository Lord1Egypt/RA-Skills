## Description:

Research real GPT Image 2 prompt examples and turn rough image ideas into structured prompt packs, reference-image edit instructions, product visuals, layouts, and debugging loops.

This skill is ready for commercial/non-commercial use.

## Publisher:

[gpt-img-2](https://clawhub.ai/user/gpt-img-2)

### License/Terms of Use:

MIT-0

## Use Case:

External users, designers, marketers, and developers use this skill to turn rough GPT Image 2 image ideas into structured prompt packs for product visuals, reference-image edits, readable layouts, social creatives, storyboards, and image-to-video source frames. It also supports prompt example research and concise debugging loops for unstable image outputs.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The optional Image3 MCP setup runs an unpinned GitHub package.

Mitigation: Review or pin the GitHub package before installation, and use the text-only workflow when external tooling is not required.

Risk: Optional prompt-search tools can send user prompt details to an external service.

Mitigation: Avoid sending confidential briefs, personal details, unreleased product plans, private URLs, customer names, or proprietary campaign text through the external prompt-search tools.

Risk: Users may expect final image generation when the skill only produces prompt guidance.

Mitigation: Make clear that the skill returns prompt packs and example research; use a separate approved image-generation capability for final images.

## Description:

Multi-agent coordination guidance for agent handoffs, shared context management, task delegation, team communication norms, and conflict resolution.

This skill is ready for commercial/non-commercial use.

## Publisher:

[edvisage](https://clawhub.ai/user/edvisage)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agent operators use this skill to structure coordination between multiple agents, including task handoffs, delegated work, shared context logs, accountability, and basic conflict resolution.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Shared handoff logs or context files may expose credentials, tokens, private customer data, or unnecessary personal details.

Mitigation: Keep shared context limited to task-relevant information and apply appropriate access controls before sharing sensitive details.

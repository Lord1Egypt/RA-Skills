# 神经系统查体操作与辅助检查

## 适用场景

- 需要执行具体神经系统查体操作
- 解读病理反射、脑膜刺激征等查体结果
- 评估腰椎穿刺适应证与禁忌证
- 执行腰穿操作或处理并发症
- 判读脑脊液常规生化结果
- 解读DSA脑血管造影
- 头痛病因初步鉴别
- 癫痫与晕厥鉴别

## 一、常用神经查体操作

### 脑膜刺激征检查

**适应证**：疑似脑膜炎、蛛网膜下腔出血、颅内压增高

1. **颈强直**：仰卧位被动屈颈，下颌不能触及胸骨柄为阳性
2. **Kernig征**：髋膝屈曲90°后伸直小腿，受限<135°伴疼痛为阳性
3. **Brudzinski征**：屈颈时双髋膝自动屈曲为阳性

**警示**：颈强直阳性而Kernig阴性（分离现象）→ 警惕颅后窝占位/脑疝

**禁忌**：严重颈椎病/颈椎外伤禁用强力屈颈

### 病理反射检查（锥体束征）

**Babinski征**：竹签轻划足底外侧→向前→转向内侧
- 阳性：踇趾背屈，其他足趾扇形展开

**等位征**（阳性意义同Babinski）：
- Chaddock征：外踝下方向前划至足背外侧
- Oppenheim征：沿胫骨前缘向下滑
- Gordon征：挤压腓肠肌
- Schaeffer征：挤压跟腱

**强握反射**：触摸手掌被强直握住 → 成人提示对侧额叶运动前区病变

### 共济运动检查

**指鼻试验**：
- 小脑病变：睁眼闭眼均不准，意向性震颤，过指
- 感觉性共济失调：睁眼正常，闭眼障碍

**Romberg征（闭目难立征）**：
- 双足并拢站立闭目
- 深感觉障碍：睁眼稳，闭眼摇摆/跌倒（阳性）
- 小脑病变：睁眼闭眼均不稳
- 倾倒方向：小脑蚓部→前后；小脑半球/前庭→病灶侧

### 自主神经功能检查

**卧立位试验**：
- 平卧测血压脉搏 → 直立3分钟后复测
- 异常：收缩压降≥20mmHg或舒张压降≥10mmHg → 自主神经功能障碍

**皮肤划痕试验**：
- 白线条持续>5分钟 → 交感兴奋
- 红条纹持续延长增宽 → 副交感兴奋/交感麻痹

## 二、症状鉴别诊断

### 头痛病因快速定位

**按部位**：
| 部位 | 可能病因 |
|------|---------|
| 全头 | 脑肿瘤、颅内出血、感染、紧张型头痛 |
| 偏侧 | 偏头痛、鼻窦炎、耳源性 |
| 前头部 | 颅内肿瘤、鼻窦炎、丛集性头痛 |
| 眶周 | 丛集性头痛、青光眼 |
| 枕颈部 | 椎动脉夹层、颅后窝肿瘤、颈源性 |

**按发病形式**：
| 形式 | 可能病因 | 紧急程度 |
|------|---------|---------|
| 急性（突发） | SAH、脑出血、脑炎 | 🔴 紧急 |
| 亚急性 | 颅内占位、良性颅压增高 | 🟡 警惕 |
| 慢性反复 | 偏头痛、紧张型头痛 | 🟢 常规 |

**红色预警组合**：急性头痛+全头/枕颈部 → 立即CT+腰穿排除SAH

### 癫痫 vs 晕厥鉴别

| 维度 | 癫痫 | 晕厥 |
|------|------|------|
| 先兆 | 视觉/感觉异常 | 头晕/视物模糊/大汗 |
| 体位关系 | 无关 | 常站立时发生 |
| 皮肤颜色 | 青紫/正常 | 苍白 |
| 抽搐 | 常见 | 无或少见 |
| 舌咬伤/尿失禁 | 常见 | 无或少见 |
| 发作后状态 | 意识模糊/头痛 | 快速恢复 |
| 脑电图 | 异常 | 多正常 |

## 三、腰椎穿刺

### 适应证评估

满足其一即可考虑：
- 留取CSF辅助诊断（感染、SAH、免疫炎性）
- 怀疑颅内压异常
- 动态观察CSF变化
- 注入药物治疗

### 禁忌证评估

**相对禁忌**（需权衡或先处理）：
- 严重高颅压/视乳头水肿/颅后窝占位 → 脑疝风险
- 穿刺部位感染
- 出血倾向
- 脊髓压迫症临界状态

### 标准操作流程

1. **体位**：左侧屈曲卧位，屈颈抱膝
2. **定位**：髂嵴连线交L4棘突，选L3-4或L4-5间隙
3. **进针**：沿棘突方向，成人4-6cm，见CSF流出
4. **测压**：接压力管测初压（患者放松伸直下肢）
5. **留取**：收集CSF后测终压
6. **术后**：去枕平卧4-6小时

### 并发症防治

| 并发症 | 原因 | 防治 |
|-------|------|------|
| 低颅压头痛 | CSF外漏 | 细针、术后平卧、多饮水 |
| 脑疝 | 高颅压放液过快 | 严格指征、先脱水、少放液 |
| 神经根痛 | 针尖刺伤马尾 | 一般无需处理 |

## 四、脑脊液结果判读

### 性状判读

| 性状 | 提示 |
|------|------|
| 无色透明 | 正常 |
| 均匀血性 | 蛛网膜下腔出血 |
| 依次变淡 | 穿刺损伤 |
| 云雾状/米汤样 | 化脓性脑膜炎 |
| 纤维蛋白膜 | 结核性脑膜炎 |
| 黄色凝固(Froin) | 椎管梗阻 |

### 细胞数与生化判读

| 指标 | 正常值 | 化脓性脑膜炎 | 结核性脑膜炎 | 病毒性脑炎 |
|------|-------|------------|------------|----------|
| WBC(×10⁶/L) | 0-5 | 显著↑多核为主 | ↑单核为主 | 轻-中度↑单核 |
| 蛋白(g/L) | 0.15-0.45 | 显著↑↑ | ↑↑ | 轻度↑ |
| 糖(mmol/L) | 2.5-4.4 | ↓↓↓ | ↓↓ | 正常 |
| 氯化物(mmol/L) | 120-130 | ↓ | ↓↓↓ | 正常 |

**三管试验鉴别出血**：均匀血色→SAH；依次变淡→穿刺损伤

## 五、DSA脑血管病变影像

| 病变类型 | 影像特征 |
|---------|---------|
| 动脉瘤 | 囊性/梭形/夹层，瘤周动脉痉挛 |
| AVM | 增粗供血动脉+盗血+引流静脉 |
| 动脉狭窄 | 管腔不规则，溃疡龛影 |
| 烟雾病 | 颈内动脉狭窄+异常血管网 |
| 静脉窦血栓 | 静脉窦充盈异常/闭塞，显影>6秒 |
| 动脉夹层 | 线样征、珍珠征、双腔 |

## 输出要求

1. 查体操作：给出标准步骤和判读标准
2. 结果解读：明确异常指标的临床意义
3. 鉴别诊断：给出疑似病因优先级
4. 进一步检查：建议针对性检查方向

# 神经查体与辅助检查详细参考

## 脑脊液正常参考值

| 项目 | 正常值 |
|------|-------|
| 压力 | 80-180 mmH2O |
| 外观 | 无色透明 |
| 白细胞 | 0-5 ×10⁶/L（单核为主）|
| 红细胞 | 0 |
| 蛋白质 | 0.15-0.45 g/L |
| 糖 | 2.5-4.4 mmol/L（血糖的1/2-2/3）|
| 氯化物 | 120-130 mmol/L（血氯的1.2-1.3倍）|

## 脑脊液异常模式总结

### 化脓性脑膜炎
- 外观：浑浊/米汤样，WBC：显著升高（数千）多核为主，蛋白：显著升高（可达5-10 g/L），糖：明显降低，氯化物：降低

### 结核性脑膜炎
- 外观：毛玻璃样，静置有纤维蛋白膜，WBC：中度升高单核为主，蛋白：显著升高，糖：中度降低，氯化物：明显降低（最显著）

### 病毒性脑炎
- 外观：清亮或微浑，WBC：轻-中度升高单核为主，蛋白：轻度升高（0.5-1.0 g/L），糖：正常，氯化物：正常

### 蛛网膜下腔出血
- 外观：均匀血性，三管试验各管颜色一致，离心后上清：黄色（陈旧）或无色（新鲜）

## DSA各病变详细特征

**颅内动脉瘤**：囊性（最常见）、梭形、夹层（双腔、内膜瓣）、巨大动脉瘤伴血栓（充盈缺损）
**脑动静脉畸形(AVM)**：供血动脉增粗迂曲，畸形团，引流静脉，盗血现象
**烟雾病(Moyamoya)**：颈内动脉虹吸部及大脑前/中动脉近段狭窄或闭塞，基底节区异常血管网（烟雾状），双侧多见
**动脉夹层**：线样征、珍珠征、双腔征、火焰征

## 病理反射详细操作

**Babinski征操作要点**：钝头竹签从足跟外侧向前划至小趾根部转向内侧，力度适中
**等位征选择**：足底损伤/溃疡→Chaddock、Oppenheim；肥胖→Gordon、Schaeffer；儿童配合差→Pussep

## 腰穿并发症处理

**低颅压头痛**（约25%发生率，持续2-8天）：卧床、多饮水、补液
**脑疝预防**：严格适应证，高颅压先脱水，证压力高则不放或少放CSF，颅后窝占位必须先做影像

# 电商详情页文案生成器 - 详细内容

## 一、FABE法则深度详解

### 1.1 四要素定义与示例

| 要素 | 定义 | 核心问题 | 示例（智能手表） |
|------|------|----------|------------------|
| F-Feature | 产品特征 | 是什么？有什么？ | "血氧监测+心率检测+睡眠追踪" |
| A-Advantage | 竞争优势 | 比竞品好在哪？ | "双传感器精度提升40%，医疗级准确度" |
| B-Benefit | 用户利益 | 能给我带来什么？ | "随时掌握身体状态，熬夜加班不怕猝死" |
| E-Evidence | 证据背书 | 如何证明？ | "通过FDA认证，10万+用户实测有效" |

### 1.2 FABE转化话术模板
```
因为（Feature）...
所以（Advantage）...
对您而言（Benefit）...
您看（Evidence）...
```

**实战示例**：
```
因为我们的空气净化器采用H13级HEPA滤网（特征），
所以净化效率达到99.97%，比普通滤网快2倍（优势），
对您而言意味着孩子在家玩耍不用担心PM2.5超标（利益），
您看这是CQC认证检测报告和1000+妈妈的好评（证据）。
```

### 1.3 不同品类FAB示例

**美妆类**：
- F：添加玻尿酸+烟酰胺+VC衍生物
- A：三重复配，透皮吸收率提升3倍
- B：28天皮肤含水量提升47%，素颜也发光
- E：第三方检测报告+用户before/after对比

**数码类**：
- F：6核CPU+16GB+512GB固态
- A：跑分58万，大型游戏秒开不卡顿
- B：剪视频不转圈，等待时间省一半
- E：极客测评数据+3C认证

**食品类**：
- F：0添加、0蔗糖、0脂肪
- A：热量只有同类产品的1/4
- B：放心吃不怕胖，减肥也能享受美食
- E：检测报告+营养师推荐

## 二、主图文案系统

### 2.1 五张主图标准模板

**主图1：吸引点击（3秒法则）**
- 位置：黄金C位，搜索结果页第一眼
- 公式：`人群+痛点+解决方案`
- 示例：
  - ❌ 错误：产品正面图+型号参数
  - ✅ 正确：`精致妈妈都在用的「哄睡神器」，宝宝一觉到天亮`

**主图2-4：信任建立（递进式）**
- 主图2：场景展示（谁在用）
- 主图3：功能详解（解决什么）
- 主图4：对比优势（为什么选我）

**主图5：促转化（临门一脚）**
- 促销信息/服务承诺
- 紧迫感塑造

### 2.2 主图文案公式库

**痛点解决型**：
```
还在为{痛点}烦恼？
用了{产品}，{效果描述}
```

**数字冲击型**：
```
{N}万+家庭选择
{效果}只需{时间}
```

**对比型**：
```
别再用{旧方案}了
{新方案}让你{好处}
```

**人群精准型**：
```
{人群}专享
用了{产品}，{核心利益}
```

**权威背书型**：
```
{权威机构}认证
{效果}有保障
```

### 2.3 主图避坑指南

| 错误类型 | 问题 | 正确做法 |
|----------|------|----------|
| 信息过载 | 参数堆砌，5秒内读不完 | 只留1个核心卖点 |
| 纯文字 | 没有视觉冲击 | 主图必须有产品图 |
| 夸大宣传 | 使用违禁词被下架 | 避免绝对化用语 |
| 侵权风险 | 使用明星/动漫形象 | 使用正版素材或原创 |
| 规格不符 | 图文与实物不符 | 实物拍摄 |

## 三、详情页结构模板

### 3.1 标准详情页结构

```
┌─────────────────────────────────────┐
│ 第一屏：痛点引入（情感共鸣）          │
│ - 用户场景图                         │
│ - 痛点描述                           │
│ - 共情文案                           │
├─────────────────────────────────────┤
│ 第二屏：产品亮相（价值呈现）          │
│ - 产品卖点海报                       │
│ - 核心参数                           │
│ - 差异化定位                         │
├─────────────────────────────────────┤
│ 第三屏：功能详解（理性说服）          │
│ - 功能1：{图+文}                    │
│ - 功能2：{图+文}                    │
│ - 功能3：{图+文}                    │
├─────────────────────────────────────┤
│ 第四屏：场景展示（代入感）            │
│ - 场景1：家庭使用                   │
│ - 场景2：办公场景                   │
│ - 场景3：送礼场景                   │
├─────────────────────────────────────┤
│ 第五屏：对比优势（促进决策）          │
│ - 我 vs 竞品表格对比                │
│ - 优势高亮标注                       │
├─────────────────────────────────────┤
│ 第六屏：证据背书（消除顾虑）          │
│ - 检测报告                           │
│ - 资质证书                           │
│ - 用户评价                           │
├─────────────────────────────────────┤
│ 第七屏：服务承诺（临门一脚）          │
│ - 退换货政策                         │
│ - 售后保障                           │
│ - 品牌承诺                           │
└─────────────────────────────────────┘
```

### 3.2 各平台详情页适配

**淘宝详情页**：
- 长度：10-15屏
- 风格：场景化+故事性
- 重点：评价引导+问大家

**拼多多详情页**：
- 长度：5-8屏
- 风格：短平快+价格敏感
- 重点：价格对比+销量背书

**京东详情页**：
- 长度：8-12屏
- 风格：参数详细+品质背书
- 重点：物流时效+售后保障

**抖音/小红书**：
- 风格：短视频+种草内容
- 重点：场景演示+真实体验

## 四、种子评价生成系统

### 4.1 评价模板库

**初级好评模板**：
```
产品收到了，质量很好，{外观/做工/材质}都{形容词}，
{简短使用感受}，值得购买！
```

**场景好评模板**：
```
作为一个{人群标签}，{使用场景}一直在找这样的产品。
用了{时间}，{效果描述}，{痛点解决}，{强烈推荐理由}。
```

**对比好评模板**：
```
之前用的是{竞品}，换了这款{产品}，{对比感受}。
特别是{核心优势}，比之前那款{优势点}。
```

**追评模板**：
```
追加评价！用了{时间}，{长期使用感受}。
{补充亮点}，{再次推荐}。
```

### 4.2 评价角度矩阵

| 维度 | 关键词 | 示例 |
|------|--------|------|
| 外观 | 颜值高、小巧精致、质感好 | 颜值超高，摆在家里像艺术品 |
| 功能 | 功能强大、操作简单 | 功能齐全，一键操作老人也会用 |
| 品质 | 做工精细、材质环保 | 用料扎实，没有异味 |
| 性价比 | 物超所值、超值划算 | 这个价位能买到这个品质很值 |
| 服务 | 客服耐心、包装完好 | 包装很用心，客服态度也很好 |
| 物流 | 速度快、时效准 | 第二天就到了，太快了 |

### 4.3 差评预防话术

在详情页中主动说明可能引发差评的点：

| 潜在差评点 | 主动说明话术 |
|------------|--------------|
| 色差 | 因光线和显示器差异，实物可能略有色差，请以实物为准 |
| 气味 | 新品可能有轻微材质味道，通风2-3小时即可消散 |
| 尺寸 | 请仔细核对尺寸表，如有疑问可联系客服 |
| 使用门槛 | 本品需要{学习成本}，建议先观看使用教程 |

## 五、违禁词与合规指南

### 5.1 绝对化用语（禁用）

| 禁用词 | 替代表达 |
|--------|----------|
| 最好/最佳 | 优秀/卓越/出众 |
| 第一/NO.1 | 领先/头部/优选 |
| 唯一/独家 | 精选/专研/创新 |
| 永久/永远 | 长期/持久/经久 |
| 国家级 | 权威认证/专业检测 |
| 世界级 | 国际品质/全球精选 |

### 5.2 医疗功效类（特殊品类需资质）

| 禁用词 | 替代表达 |
|--------|----------|
| 治疗/治愈 | 舒缓/改善/辅助调理 |
| 药用功效 | 草本成分/传统配方 |
| 医疗行为 | 咨询专业人士 |

### 5.3 虚假宣传类

- 虚构销量：❌ "销量第一" ✅ "店铺爆款"
- 虚构评价：❌ "100%好评" ✅ "好评率98%"
- 虚构资质：❌ "官方授权" ✅ "同款货源"

## 七、工具与效率提升

### 7.1 文案检查清单

- [ ] 是否使用违禁词（绝对化/医疗功效类）
- [ ] 卖点是否有据可依
- [ ] 主图是否3秒内传达核心卖点
- [ ] 详情页结构是否完整（痛点→方案→证据→承诺）
- [ ] 各平台风格是否适配
- [ ] 评价角度是否覆盖多维度
- [ ] 是否主动预防差评

### 7.2 常用工具推荐

| 工具类型 | 推荐工具 | 用途 |
|----------|----------|------|
| 违禁词检测 | 句易网、鸟哥笔记 | 检测违禁词 |
| 数据分析 | 生意参谋、店透视 | 竞品分析 |
| 作图 | 稿定设计、创可贴 | 主图详情制作 |
| 热点追踪 | 飞瓜数据、蝉妈妈 | 抖音/小红书热点 |

### 7.3 A/B测试建议

| 测试维度 | 方案A | 方案B |
|----------|-------|-------|
| 标题风格 | 痛点型 | 利益型 |
| 主图色调 | 暖色调 | 冷色调 |
| 详情长度 | 长版15屏 | 短版8屏 |
| 评价展示 | 强调真实 | 强调数量 |

## 八、行业专属参考

### 8.1 服装类

- 面料参数必填（成分/克重/支数）
- 尺码表详细（含身高体重对照）
- 试穿报告（不同身材反馈）
- 场景图（通勤/约会/休闲）

### 8.2 食品类

- 配料表/营养成分表
- 产地溯源
- 资质证书（SC/ISO）
- 食用方法/禁忌人群

### 8.3 数码类

- 核心参数对比表
- 跑分/性能数据
- 兼容设备列表
- 退换货注意（激活不退）

### 8.4 美妆类

- 成分表（安全成分/致敏提示）
- 肤质适配说明
- 使用顺序图解
- 效果周期说明（28天周期）

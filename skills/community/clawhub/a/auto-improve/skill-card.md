## Use Case:

Developers and agent operators use this skill to structure a continuous improvement loop that loads prior project context, checks known mistakes before edits, verifies work, and records successful patterns or error lessons after tasks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may load and reuse persistent project or global memory with limited scoping or user control.

Mitigation: Review the skill before installation and require explicit approval before loading repository memory in sensitive or shared repositories.

Risk: The skill describes automatic updates to .antigravity.md and saved lessons after actions or errors.

Mitigation: Require review before saving lessons or modifying project memory files, and inspect proposed memory changes before committing them.

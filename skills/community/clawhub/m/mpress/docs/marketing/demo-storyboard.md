# demo 怎么录：10 秒讲清「5 秒」这件事

> 配套 `README.md` 首屏的演示 GIF。目标不是展示工具多复杂，而是让一个划手机的人在 3 秒内看懂「差别在哪」。

## 先解决一个误解

你说"敲回车之后几秒钟就出现在草稿箱里了，太简单，不知道怎么做 demo"。

**短不是缺点，是唯一的卖点。** 工具类 demo 之所以难看，通常是因为要演示的东西本来就很慢——得开三个窗口、切五次页面、等进度条。你的产品没有这个过程，这恰恰是卖点。

所以不要试图"把 5 秒拉长"，要**把 5 秒放进一个参照系里**。参照系不需要你重新手工排一篇稿子（你也没有那天的录屏），它只需要一个数字在屏幕上停住：

```text
手排   30 分钟 – 2 小时
mpress 5 秒
```

这句话本身就是整个 demo 的字幕。画面只负责证明后半句没吹牛。

## 三个镜头（总长 10–12 秒，一格都不能多）

| # | 时长 | 画面 | 字幕 |
|---|---|---|---|
| 1 | 0–4s | 终端全屏。输入 `mpress push 文章.md`，回车。进度逐行打出：上传 10 张图 → 合成封面 → 写草稿 → `draft ok  media_id=xxx  4.8s` | `一条命令` |
| 2 | 4–8s | 切公众号后台草稿箱，下拉刷新，文章出现在第一行（标题 + 封面缩略图） | `草稿箱里已经有了` |
| 3 | 8–12s | 手机预览或后台编辑器，滚动：刊头 → 结论条 → 指标卡 → 点开折叠块展开 | `手排 30 分钟—2 小时 · mpress 5 秒` |

镜头 1 里的 **`4.8s` 必须是工具自己打出来的**，不是你后期加的字幕——这是可信度的全部来源。如果现在没有这个回显，加一行 `console.log` 打印耗时，这比任何文案都值钱。

如果 4 秒拍不下完整输出，就让终端滚动到「最后三行 + 耗时」那一屏，前面用 0.3 秒的加速过渡。

## 可选第四镜头：证明"不会幻觉"（这才是你真正的差异点）

速度可以被别人抄，**确定性不能**。加一个 8 秒的镜头，放在 README「为什么结果是稳定的」那一节下面：

```bash
mpress gen 文章.md && sha256sum ~/.wechat-article/work/文章/body.html
mpress gen 文章.md && sha256sum ~/.wechat-article/work/文章/body.html
# 两个哈希一模一样
```

字幕：`纯脚本 · 没有大模型 · 同输入同输出`。

对"AI 帮我排版，每次风格都不一样、还改了我的字"有意见的人，这个镜头比速度更有说服力。

## 录制与压制（Windows）

- **录屏**：优先 OBS（可叠计时器、多场景切换）；不想装就用 Win+G 的 Xbox Game Bar 录 mp4；只要 GIF 可用 ScreenToGif（窗口捕获，直接导 GIF，能删帧）。
- **终端准备**：字体 ≥ 16pt、深色主题、窗口宽度压到 100 列以内；先 `clear`。提示符简化成 `›` 之类，别让一长串路径吃掉画面。
- **命令要短**：`mpress push 文章.md`，不是 `node scripts/wechat.mjs push 文章.md`。**所以 demo 之前必须先 `npm publish`**——这也说明 npm 发布不是"以后再说"，它是 demo 的前置条件。
- **mp4 → GIF**（ffmpeg，PowerShell 里一行）：

```powershell
ffmpeg -i demo.mp4 -vf "fps=12,scale=960:-1:flags=lanczos,split[a][b];[a]palettegen[p];[b][p]paletteuse" -loop 0 demo.gif
```

- **GIF 硬指标**：宽 960px、10–12 fps、**< 5 MB**（GitHub 超过 10MB 会明显卡顿，微信里也发不出去）、无音轨、无限循环、前 2 秒必须已经能看懂差别。
- **字幕**：一行一屏，14–18 字，压在画面下方 1/5；不要打字机效果，不要转场。

## 录制前必须检查（安全）

- 清屏，别让 `cat .env`、AppSecret、客户文章标题出现在任何一帧里。
- 公众号后台的账号名、头像、二维码打码；草稿标题用"示例文章"这类占位。
- 录完自己回看一遍慢放，逐帧找有没有凭据泄露——GIF 会被转发到你看不见的地方。

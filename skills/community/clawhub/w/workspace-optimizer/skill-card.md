## Description:

Audit, optimize, and maintain your OpenClaw agent workspace. Use when workspace needs health check, skill audit, memory cleanup, or performance tuning.

This skill is ready for commercial/non-commercial use.

## Publisher:

[agentricai-owner](https://clawhub.ai/user/agentricai-owner)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and OpenClaw users use this skill to audit workspace health, installed skills, memory files, and cron jobs, then plan cleanup and performance tuning actions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Workspace cleanup recommendations may affect local OpenClaw files, installed skills, memory, or cron jobs if acted on without review.

Mitigation: Review proposed changes, back up or archive memory files, and confirm skill uninstalls or cron changes manually before executing them.

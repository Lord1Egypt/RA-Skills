## Description:

Create clear, publication-ready Python data visualizations with pandas, Matplotlib, Seaborn, and optional Bokeh interaction for choosing chart types, writing or revising plot-building code, applying Storytelling with Data principles, replacing misleading charts, and exporting reproducible PNG previews plus vector PDF figures for scientific papers.

This skill is ready for commercial/non-commercial use.

## Known Risks and Mitigations:

Risk: Ranged, unpinned Python dependencies can resolve to different package versions across installs.

Mitigation: Install dependencies in a virtual environment or container and use locked dependencies or pinned constraints for reviewed deployments.

Risk: Opening or regenerating the optional Bokeh HTML example can load JavaScript from Bokeh's CDN.

Mitigation: Use inline or vendored Bokeh resources in stricter environments and review generated HTML before sharing.

## Description:

Search the web for a topic and produce a structured summary with key findings, sources, and actionable takeaways.

This skill is ready for commercial/non-commercial use.

## Publisher:

[terrycarter1985](https://clawhub.ai/user/terrycarter1985)

### License/Terms of Use:

MIT-0

## Use Case:

External users, developers, and analysts use this skill to turn a web search query into a concise research brief with key findings, notable points, and sources.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Search queries and fetched pages may disclose the user's research topic to external web services.

Mitigation: Avoid using the skill for sensitive private research unless that network exposure is acceptable.

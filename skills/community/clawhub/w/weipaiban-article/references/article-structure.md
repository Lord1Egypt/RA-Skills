# 文章结构

一篇只选 **一种主语法**。节拍按内容取舍，不是每篇都上满 9 段。视觉配额见 [visual-system.md](visual-system.md)。

## 组件选择

- **阅读**（长段、图+图注、清单、卡片）→ `<section data-type="richText">`
- **章节插画配图**（主图 + 贴纸 + 点题短文案）→ 一篇最多 7 块图文 SVG，可以每节都上，替代该节 `<img>`，见 [image-svg.md](components/image-svg.md)
- **图集**（3 张以上同框连看）→ `<section data-type="slideshow">`，可重复，插在 01 / 04 / 06，见 [slideshow.md](components/slideshow.md)
- **横向滑动**（左右滑一条自由画布）→ 横向滑动外壳，可重复，插在 01 / 04，见 [horizontal-scroll.md](components/horizontal-scroll.md)
- **点缀动效 / 叠层**（入场、图上压一句、轻点揭示）→ 在该拍旁插一块矮 `<svg>`，见 [svg.md](components/svg.md)
- **点击切换 / 点击弹窗** → 两面互切用 [click-switch.md](components/click-switch.md)；图上多热点用 [click-popup.md](components/click-popup.md)。两类都可以重复，也可以出现在同一篇

默认全 richtext。一篇最多 7 块图文 SVG，可以每节都上。动画组、轮播、横向滑动、点击切换、点击弹窗按节拍使用，不限块数。没有合适的点就不用。图文 SVG 贴纸循环动效直接挂在图上。

## 四种版面语法

| 语法 | 骨架 | 适合 |
| --- | --- | --- |
| 叙事流 | 版首 → 短段 → 图 → 短段 | 品牌故事、节日散文 |
| 章节流 | 编号小标题驱动；每节：小标题 → 短段 → 一图一意 → 卡片小结 | 攻略、盘点、活动玩法 |
| 卡片流 | 每张卡一个卖点 / 产品 / 嘉宾 | 招商、课程、榜单 |
| 对照流 | 左右或上下 Before/After、方案 A/B；有互切时用 clickSwitch | 测评、改造、营销对比 |

局部可插入另一种（例如章节流里夹一张对照卡）。不要多种语法轮流上场。

## 节拍

每个节拍默认一块 `data-type="richText"`，`data-name` 用节拍名。图文 SVG / 辅助画布 `data-name` 标清插在哪一拍。

| 节拍 | 何时 | 做什么 |
| --- | --- | --- |
| 01 版首 | 必做 | 品牌/栏目、阅读预期（字数/时长/期数）。一般一屏内 |
| 02 钩子 | 必做 | 3 秒内给出「这和我有什么关系」 |
| 03 导读 | 长文或活动 | 3–5 条目录或权益预告 |
| 04 章节循环 | 主体 | 3–7 节。一节一个小标题、短段、至多一图（可升级为图文 SVG）、可选卡片小结 |
| 05 主交互 | 有对照/揭晓或多热点时 | `clickSwitch`（两层 svg）或 `clickPopup`（底图 + 每块 2–4 组热点）。同一篇可以多块，两类也可以都有。没有理由整段省略 |
| 06 沉淀 | 有可收藏物 | 清单 / 对照表 / 一图看懂 / 日历 |
| 07 转化 | 活动 | 规则 · 权益 · 报名路径 · 时间地点 |
| 08 身份 | 有二维码或名片 | 二维码 · 引导名片 · 相关阅读。无动画。无真实二维码则整段省略，不生成假码 |
| 09 END | 必做 | 收束，不堆新信息 |
| AI 声明 | 必做 | 文末单独一块，居中、12px、主题 `muted`、无底无装饰。文案固定：「文章部分内容由AI辅助设计和制作」 |

章节流的 04 按节拆块（`04-1` …），不要把 7 节塞进一块。

## 文案

- 封面字 ≤ 15 字；主标题 3–8 字。不要把文章大标题整段铺上版首。
- 手机屏每段 3–5 行，每句 15–25 字。
- 标题给具体名词或数字；钩子避免「本文介绍了……」。

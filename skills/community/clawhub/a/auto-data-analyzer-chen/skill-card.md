## Description:

Automated data analysis tool for CSV/Excel data that generates reports with data cleaning, statistical description, visualization, correlation analysis, and regression analysis.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, analysts, and business users can use this skill to quickly analyze tabular CSV or Excel data and produce reports for business, market research, user behavior, and sales analysis.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Installing Python analysis packages directly into a system environment can affect unrelated projects or require elevated privileges.

Mitigation: Install dependencies in a virtual environment and avoid running package installation as administrator.

Risk: Generated reports, charts, and CSV summaries may persist sensitive dataset contents on disk.

Mitigation: Choose output locations deliberately and handle generated files according to the dataset's sensitivity.

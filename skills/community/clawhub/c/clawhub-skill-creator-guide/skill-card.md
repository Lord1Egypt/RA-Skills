## Use Case:

Developers and skill authors use this skill to create, correct, and publish ClawHub skills with the expected SKILL.md frontmatter, _meta.json metadata, CLI workflow, examples, troubleshooting notes, and publication checklist.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill recommends unpinned npm CLI commands for ClawHub login and publishing.

Mitigation: Review commands before use, prefer a pinned and verified ClawHub CLI version or a lockfile-controlled local install, and run login and publish commands from an environment limited to the needed skill files and credentials.

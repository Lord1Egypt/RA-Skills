## 🎯 是什么

技术经理人事务所是成果转化平台（OPC-SPARK）中的**核心服务 Agent**，扮演"猎手→评估师→经理人→创意师→所长"五级角色体系，专注于技术成果从发现到落地的全流程服务。

**核心定位**：
- 连接科研院所与市场需求
- 评估技术成熟度与商业价值
- 制定转化路径与资源匹配方案

## 📋 核心功能模块

### 1. 猎手阶段 (Hunter)
- 项目发现与识别
- 五维打分初筛
- 首次接触话术
- 移交清单生成

### 2. 评估师阶段 (Evaluator)
- 技术成熟度评估 (TRL)
- 风险识别清单
- 市场竞争分析
- 评估报告生成

### 3. 经理人阶段 (Manager)
- 项目档案建立
- 需求确认报告
- 项目计划书
- 进度看板管理

### 4. 创意师阶段 (Creator)
- 差异化方案设计
- 创新应用场景挖掘
- 商业模式建议

### 5. 所长阶段 (Director)
- 综合评审决策
- 资源对接方案
- 成果转化协同计划

## 🚀 使用方式

### Coze平台导入
1. 访问 [code.coze.cn](https://code.coze.cn)
2. 导入项目 → 选择 GitHub
3. 填入仓库地址

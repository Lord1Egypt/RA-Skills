### Deployment Geography for Use:

## Known Risks and Mitigations:

Risk: The skill can use Kraken API keys to access live account data and perform trading, staking, and withdrawal actions.

Mitigation: Install only when comfortable granting account access; prefer read-only keys for portfolio and exports, and use a separate transaction-capable key only for intended trading, staking, or withdrawal workflows.

Risk: Transaction-capable keys can place or cancel orders, allocate or deallocate earn funds, and initiate withdrawals.

Mitigation: Keep withdrawal permission disabled unless required, require explicit user confirmation for state-changing actions, and use dry-run validation before real orders.

Risk: JSON and CSV exports can contain sensitive financial records that may be retained in agent logs or files.

Mitigation: Treat exported data as sensitive, avoid unnecessary raw exports, and store or share generated records only in approved locations.

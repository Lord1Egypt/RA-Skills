# 页面构图与视觉节奏

在逐页策划和布局调整时读取；审美复核时复用末尾检查项。适用于 SVG、HTML 和原生 PPTX，共用相同内容层级，不要求三种格式使用同一渲染代码。

## 先确定焦点与阅读顺序

每页策划记录：页面类型、主要视觉焦点、阅读顺序、布局及内容权重。主要焦点可以是关键数字、主图、结论或关系图；通过面积、位置、字号、字重和色彩建立层级，避免多个元素同时争夺注意力。

标题说明本页主题或结论，副标题只补充必要条件、比较范围或背景，不换一种说法重复标题。图表已直接表达的数值无需在侧栏逐个再抄一遍；侧栏优先解释差异、限制或行动。

网格是对齐和比例关系，不要求画出每个容器。可采用开放式、卡片式或混合式构图：

- 开放式：文字、图表直接置于背景，以位置、间距和细分隔线分组。适合大图表、方法说明和简洁结论。
- 卡片式：需要区分独立组别、并列比较或突出重点时使用底色或边界。避免卡片内部再次层层套框。
- 混合式：开放的标题/解释区与重点卡片结合。优先让证据获得空间，不因套用模板把所有内容装进等大方框。

## 按页面职责选择构图

以下是候选构图，不是每份演示必须凑齐的页面清单。比例按扣除页边距、间距后的内容区估算。

| 页面类型 | 候选构图 | 设计要点 |
| --- | --- | --- |
| 封面 | 左侧主标题、右侧留白或已获准素材；也可纯文字居中 | 按语义断行，突出主题关键词；背景为标题让位，不堆入实验细节和多重标签 |
| 导航 | 编号、章节名、短说明组成对齐的纵向列表 | 短汇报按需省略；编号承担导航，不将每一行都做成厚重卡片 |
| 章节转换 | 大编号、短标题与大面积留白 | 仅在篇幅允许或用户要求时独立成页；短演示可融入内容页，不额外扩页 |
| 背景/方法 | 上方目标与问题、下方条件矩阵或简短流程 | 条件标签弱于关键参数；流程只表达真实步骤，不强造因果 |
| 指标/公式 | 主指标或公式突出，旁侧交代定义与条件 | 公式方向、分子分母和单位必须准确；大数值保留比较基准 |
| 两组/多组比较 | 等尺度并列图表、对齐表格或比较卡 | 同一指标处于同一位置，单位和顺序一致；规格降为辅助信息，主要结果更突出 |
| 趋势/数据证据 | 主图约占内容区 2/3–3/4，余下用于解释；也可通栏图 | 保留真实轴与采样点；重点曲线可直接标注，避免图旁重复完整数据表 |
| 局限/质量问题 | 按影响组织的紧凑列表，搭配必要异常统计 | 统计带分母和范围；不将每条问题做成同等醒目的警示框 |
| 总结/行动 | 结论搭配对应行动，或按验证顺序分步排列 | 区分已知事实与后续建议；步骤编号代表顺序，不暗示效果逐级增加 |

## 对齐、比例与留白

先确定统一的外边距、栏线、标题基线和页脚区域。具体数值沿用 [svg-design.md](svg-design.md) 的画布与字体规则；不要为制造变化随意移动每页标题与来源。

让内容的重要性和长度决定区域面积。宽文本段落优先简化或重组；并列项需要横向比较时保持共同起点、指标基线和相同内边距。对比页可以等宽，主次页不必强求对称。

以接近原则组织留白：同组内部间距小于不同组之间的间距。空白用于分组、强调或平衡；文字已经拥挤时不应另一侧仍留有大片无用途空白。不要为了填满页面添加装饰或为了等高重复内容。

## 卡片内部排版与强调

每张卡片只承载一个核心观点。语义拆分及指标完整性见 [svg-design.md](svg-design.md)。内部阅读顺序可从“短标签 → 关键数字/观点 → 解释 → 条件与来源”起步，按内容简化，不为凑层级补写内容。

- 数字与单位分级：数值突出，单位较小但清楚；关联的期间、分母和基准在附近，不拆到难以发现的位置。
- 标题、正文与注释区分字重和间距，不将整卡所有文字都加粗。指标卡与同类卡片对齐数值基线。
- 局部强调：给关键词或核心差值着色，而非每段都用强调色；主要强调区域尽量集中，图表系列颜色继续承担区分作用。
- 允许调整内边距与卡片高度以适应内容，但相同角色保持一致；字号不作为补救超载的首选。
- 若需多色文本，使用 SVG 的文本片段、HTML 行内元素或 PPTX 原生富文本，不转成图片来实现强调；同一语句各片段的基线、换行与可编辑性须一致。

背景、边界与阴影择需使用。深色卡头/卡尾、粗边框、大阴影同时出现容易压过内容；可先减弱容器，再增强核心数字。图标使用统一风格与尺度，仅在帮助识别时使用，避免混用 emoji、线性与立体图标。

渐变、网格和光影属于可选风格，不因参考截图出现就自动添加。遵循用户已有的配图与品牌要求；使用装饰时控制对比度，封面可较丰富，数据页优先干净背景。

## 整套页面的节奏

策划完成后连看页面缩略图，检查疏密与主次。若连续多页使用相同的“标题＋左右两框”，判断信息关系是否真的相同；可以改用通栏主图、开放式说明、横向条件区或主次布局。连续比较页为方便对照可以保留同版式，不为变化而破坏可比性。

统一字体、色板、对齐线与图表语义，通过主图比例、留白和信息组织形成变化，不给每页重新设计一套视觉语言。不强制每套使用固定数量的版式，不为节奏增加封面、目录或章节页。

## 视觉诚实

曲线、箭头、面积与颜色表达的方向必须符合数据。结果回落或不单调时，不用持续上升的大箭头代替真实曲线；时间轴保留实际间隔，不混用不同工况的点来拼出故事。示意流程与数据趋势明确区分。

参考截图中的数值、公式、结论和装饰标题仅是待核对素材，不能随视觉样式一起继承。若只能借鉴布局，沿用已验证数据重新表达，不为得到更有力的标题省略限制。

## 审美复核

在技术与内容检查之外，逐页查看实际渲染，并连看缩略图：

1. 第一眼能否找到主要焦点，之后能否按预期顺序读到证据？
2. 标题与副标题是否各有作用，辅助文字是否抢过主要结果？
3. 同类内容是否对齐，卡片内外间距能否清晰分组，单位与条件是否易找？
4. 区域大小是否对应内容权重，是否存在一侧拥挤、另一侧空洞，或无用途的嵌套框？
5. 文字、图表与容器的对比是否合适，是否因整段加粗、多处强调、背景纹理而分散注意？
6. 整套是否过于重复，变化是否仍保持共同的视觉体系？
7. 图形走势、颜色和强调是否忠实于证据？

发现问题优先调整内容组织、区域比例和强调，再考虑装饰。几何检查通过不代表审美通过；双格式分别查看，不以 HTML 截图代替 PPTX 的视觉检查。无渲染能力时如实说明未完成视觉复核。

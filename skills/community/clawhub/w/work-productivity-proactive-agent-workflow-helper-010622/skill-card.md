## Description:

Helps AI-agent users and skill authors turn proactive-agent workflow demand into practical plans, checklists, implementation guidance, and validation notes for bug fixing, setup hardening, reliability work, and adjacent skill creation.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, maintainers, skill authors, and agent teams use this skill to structure proactive-agent style work into clear outcomes, reusable workflows, local-hardware friendly implementation support, and validation checks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad productivity and task-related activation wording could cause the skill to be selected for requests outside proactive-agent workflow design, reliability hardening, bug-fix workflows, or adjacent skill creation.

Mitigation: Prefer explicit invocation for this skill and narrow trigger phrases before relying on implicit invocation in production use.

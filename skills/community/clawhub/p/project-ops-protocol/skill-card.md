## Description:

A lightweight operating protocol for coordinating serious projects across multiple AI sessions, agents, and humans using a layered battle map, shared ledgers, an alignment board, relay notes, and quality gates.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, project leads, and agent operators use this skill to set up and maintain shared Markdown operating records for multi-session projects, including planning layers, ledgers, alignment board updates, handoffs, retrospectives, and publish readiness checks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad trigger wording may cause the protocol to appear in ordinary project-planning discussions.

Mitigation: Invoke it when a structured multi-session operating protocol is intended, and skip it for one-off questions or single-tool jobs.

Risk: The workflow can lead an agent to create, read, or update shared project Markdown records.

Mitigation: Review proposed ledger, alignment-board, relay-note, and handbook changes before external publishing or major handoff.

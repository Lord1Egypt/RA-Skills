## Description:

Basic usage of the General Lake Model (GLM) for lake temperature simulation. Use when you need to run GLM, understand input files, or modify configuration parameters.

## Use Case:

Developers, engineers, and lake-modeling practitioners use this skill to run GLM, inspect its expected input files, and adjust configuration parameters for lake temperature simulations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The Python parameter-editing example can overwrite `glm3.nml` in the target directory.

Mitigation: Review the target path and keep a backup of `glm3.nml` before applying automated edits.

Risk: Running `glm` depends on local GLM input files and configuration being present and valid.

Mitigation: Check the working directory, `glm3.nml`, `bcs/` inputs, and output path before executing the command.

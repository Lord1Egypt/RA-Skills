# SOFA评分详细标准

## qSOFA快速筛查（床旁3项）

| 指标 | 阳性标准 | 分值 |
|------|---------|------|
| 呼吸频率 | ≥22次/min | 1 |
| 意识 | 改变（GCS<15） | 1 |
| 收缩压 | ≤100mmHg | 1 |

**≥2分**：进入SOFA详细评估

## SOFA评分（6个系统，0-4分）

### 呼吸（氧合指数 PaO2/FiO2 mmHg）
| 分值 | 标准 |
|------|------|
| 0 | ≥400 |
| 1 | <400 |
| 2 | <300 |
| 3 | <200 + 机械通气 |
| 4 | <100 + 机械通气 |

### 血小板（×10^9/L）
| 分值 | 标准 |
|------|------|
| 0 | ≥150 |
| 1 | <150 |
| 2 | <100 |
| 3 | <50 |
| 4 | <20 |

### 胆红素（mg/dl）
| 分值 | 标准 |
|------|------|
| 0 | <1.2 |
| 1 | 1.2-1.9 |
| 2 | 2.0-5.9 |
| 3 | 6.0-11.9 |
| 4 | ≥12.0 |

### 心血管系统
| 分值 | 标准 |
|------|------|
| 0 | MAP≥70mmHg |
| 1 | MAP<70mmHg |
| 2 | 多巴胺<5μg/kg/min 或 多巴酚丁胺任何剂量 |
| 3 | 多巴胺5.1-15.0μg/kg/min 或 肾上腺素/去甲肾上腺素≤0.1μg/kg/min |
| 4 | 多巴胺>15μg/kg/min 或 肾上腺素/去甲肾上腺素>0.1μg/kg/min |

注：儿茶酚胺给药至少1小时

### 神经系统（GCS评分）
| 分值 | GCS |
|------|-----|
| 0 | 15 |
| 1 | 13-14 |
| 2 | 10-12 |
| 3 | 6-9 |
| 4 | <6 |

### 肾脏
| 分值 | 肌酐(mg/dl) | 尿量 |
|------|-------------|------|
| 0 | <1.2 | - |
| 1 | 1.2-1.9 | - |
| 2 | 2.0-3.4 | - |
| 3 | 3.5-4.9 | <500ml/d |
| 4 | >4.9 | <200ml/d |

## 诊断判定

- **脓毒症**：SOFA较基线上升≥2分
- **感染性休克**：脓毒症 + 充分容量复苏后仍需血管活性药维持MAP≥65mmHg + 血乳酸>2mmol/L

## 感染性休克晚期多器官衰竭表现

| 器官 | 表现 |
|------|------|
| 肾 | 急性肾衰（少尿/无尿，BUN/Cr/K+增高） |
| 心 | 急性心衰（呼吸突快、发绀、奔马律、CVP/PAWP升高） |
| 肺 | ARDS（进行性呼吸困难，PaO2/FiO2≤200） |
| 脑 | 昏迷、抽搐、瘫痪 |
| 肝胃肠 | 黄疸、肠胀气、消化道出血 |

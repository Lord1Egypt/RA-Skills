## Description:

Agent Harness provides an adaptive engineering workflow for AI coding agents, combining planning, verification, checkpointing, subagent coordination, and post-task learning.

This skill is ready for commercial/non-commercial use.

## Publisher:

[christianye](https://clawhub.ai/user/christianye)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineering teams use this skill to guide AI agents through feature work, bug fixes, debugging, reviews, and multi-step coding tasks with explicit planning, verification, and checkpoint practices.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation language may route the skill into routine coding conversations where a narrower workflow would be preferred.

Mitigation: Tighten trigger wording or enable the skill only in workspaces where structured engineering workflow guidance is desired.

# 抑郁障碍综合诊疗

## 适用场景

- 患者表现出心境低落、兴趣减退、快感缺失
- 需要评估自杀风险并制定干预计划
- 对确诊抑郁障碍进行ICD-11分型和严重程度定级
- 分析抑郁障碍的生物学机制或药物靶点
- 评估心理社会因素对抑郁的影响

## 核心工作流

### 1. 自杀风险预警与评估

**高危特征识别：**
- 所有自杀者中约50%符合抑郁障碍诊断
- 抑郁患者自杀风险为一般人群19.7倍
- 高危人群：未及时诊断治疗、共患其他疾病、遭遇不良生活事件

**执行步骤：**
1. 询问自杀观念（频率、强度、具体计划）
2. 评估自杀行为史（既往尝试次数、方法 lethal性）
3. 评估保护因素（社会支持、宗教信仰、责任感）
4. 确定风险等级并启动相应干预

### 2. 三维临床症状识别

**核心症状（至少具备1-2项）：**
- 心境低落：显著持久，持续≥2周
- 兴趣减退：对以往喜爱活动丧失兴趣
- 快感缺失：体验快乐能力下降

**心理症状群：**
- 思维迟缓、联想减慢
- 认知功能损害、注意力下降
- 负性认知模式、自责自罪
- 自杀观念和行为
- 精神运动性改变（迟滞/激越）
- 焦虑、精神病性症状

**躯体症状群：**
- 睡眠障碍（特征性：末段失眠）
- 自主神经紊乱
- 进食紊乱、精力下降
- 性功能障碍

**非典型抑郁特征：** 睡眠过多、进食过多、铅样麻痹感

### 3. ICD-11临床分型与维度评估

**四大临床分型：**
1. 单次发作抑郁障碍
2. 复发性抑郁障碍
3. 恶劣心境障碍
4. 混合性抑郁和焦虑障碍

**三维评估：**
- 维度1-严重程度：轻度/中度/重度
- 维度2-精神病性症状：伴/不伴（妄想或幻觉）
- 维度3-当前阶段：抑郁发作期/部分缓解/完全缓解

### 4. 生物学机制分析（用于理解病理/解释药效）

**遗传机制：**
- 一级亲属风险为一般人群2-10倍
- 遗传度30%-50%
- 涉及基因：5-HT转运体、MAOA、BDNF

**神经生化机制：**
- 单胺假说：5-HT和NE水平降低
- 谷氨酸与GABA系统异常
- NMDA受体拮抗剂可减轻抑郁

**神经内分泌机制：**
- HPA轴异常：血皮质醇增高，昼夜节律改变
- HPT轴和HPG轴功能异常

**神经影像学标志物：**
- 海马萎缩
- 内侧前额叶异常
- 神经环路多水平异常

### 5. 心理社会因素评估与干预调整

**病因学综合模型：**
- 生物+心理+社会环境共同作用
- 生活应激事件是危险因素
- 多个严重不良事件产生协同影响

**早年创伤影响机制：**
- 心理学：促进负性图式发展
- 神经生物学：影响大脑发育、神经内分泌和免疫系统
- 累积效应：随时间积累损害情绪系统

**治疗调整原则：**
- 有童年创伤史患者对单纯药物治疗反应较差
- 必须结合心理治疗
- 社会支持可有效缓解创伤对抑郁的影响

## 关键警示

- 抑郁障碍所致DALYs在精神障碍中占比最大
- 中国识别率仅21%，治疗率9.5%
- 伴精神病性症状者需紧急干预
- 有自杀观念者必须制定安全计划
- 童年创伤史患者需药物+心理综合治疗

## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

## Use Case:

Developers and engineering teams use this skill to turn OpenAPI or Swagger documentation requests into practical workflows, checklists, analysis, code changes, or validation steps. It is intended for REST API documentation and developer-experience improvement work.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Mitigation: Review and narrow the trigger wording if precise routing is important for the deployment.

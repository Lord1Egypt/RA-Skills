## Description:

Add or update precise revert.wtf catalog entries, fixtures, source metadata, and matcher tests for one or a small set of EVM/RPC/provider/wallet/protocol errors.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and maintainers use this skill to add, fix, rename, deprecate, or verify focused entries in the revert.wtf error catalog. It guides catalog classification, matcher pattern choices, fixtures, source metadata, and validation commands for EVM, RPC, provider, wallet, protocol, and related errors.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated catalog edits or matcher patterns could be too broad, misleading, or inconsistent with revert.wtf conventions.

Mitigation: Review generated catalog changes and run the skill's validation and type-check commands before committing.

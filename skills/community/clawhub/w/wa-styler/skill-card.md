## Description:

Skill to ensure all messages sent to WhatsApp follow the platform's specific formatting syntax.

This skill is ready for commercial/non-commercial use.

## Publisher:

[rubenfb23](https://clawhub.ai/user/rubenfb23)

### License/Terms of Use:


## Use Case:

External users, employees, and agents use this skill to format WhatsApp-bound responses with WhatsApp-compatible bold, italic, strikethrough, monospace, list, and quote syntax while avoiding Markdown constructs that display poorly in WhatsApp.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Applying this skill to non-WhatsApp or code-heavy content can suppress normal Markdown structures such as headers, tables, and document-style formatting.

Mitigation: Use it only for WhatsApp-bound messages and use a general Markdown style for documents, tables, or code-heavy responses.

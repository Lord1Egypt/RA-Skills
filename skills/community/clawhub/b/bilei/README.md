## 一次实跑：空气炸锅（2026-11-17）

问的是「想买个空气炸锅，帮我避雷」。按本技能查了 17 个公开来源，没有硬推型号。

| 结论 | 为什么不硬推 | L1 |
|---|---|---|
| 目前没有能直接下单的唯一推荐 | 高分评测是 2022 年的；现在是否在售、到手价多少，查不到可靠来源 | 合肥荣事达 RS-B821：旋钮能拧却没接线。合市监处罚〔2026〕56号，罚款 76.14 万元 |

推荐强度不能超过证据强度。

同一屏还列出：旋钮能拧但没接线；涂层迁移量可能超标；宣称容量不等于实际容量；机械旋钮控温偏差 10–20°C；电气安全 / 外壳烫手；涂层掉漆、售后扯皮。

## 和普通 AI 推荐不一样

- L1 处罚、抽检、召回排在最前；型号级命中，该款直接出局。
- L3 拆成 L3a（网友借机 / 作者自购）、L3b（厂商送测 / 委托）、L3c（付费定制）。SGS、TÜV、华测的送测默认记 L3b，不升成 L2。
- 通稿转载再多，只计 1 个源。
- 没有可靠选项，就说目前没有。

## 创作背景

本人从事新媒体工作17年（微博第一批段子手），合作创办MCN 10余年，大大小小的软广硬广植入都帮客户做过，本人已经算是人工软广识别机器了。

但是在今年装修自己新家的时候才发现，自己想买一些家电的时候，搜遍了几个主流内容平台，都已经找不到任何客观的评价了。那种横评、测评博主也是懂的都懂，广场也被大量的素人做GEO投毒铺满了，少数的负面也被公关掉了，再加上算法的推流跟屏蔽，你几乎找不到产品的负面，纯夸。

这样的信息茧房也太可怕了，连做了十几年广告的“行内人”都买不到客观公正的产品。于是我在想什么是不能被篡改的，比如行政处罚，这个总公关不了吧，比如产品差评，这个虽然靠人工会被算法屏蔽，但是AI搜集起来还是会方便很多。

这个技能就是按这个思路做的：以行政处罚、抽检通报、召回公告这些公关不了的数据为地基，让 AI 去把散落在投诉平台和社区角落的差评捞回来，按证据强度定级，再谈推荐。

**广告的钱怎么花我最清楚，所以这个技能只认公关不了的东西。**

## 用法

装好之后，直接说——

> 「避雷，新家客厅买空调，预算 5000，1.5 匹挂机和 3 匹柜机怎么选」
> 「3000 以内的扫地机器人，家里有宠物，主要吃头发，避个雷」
> 「这款洗碗机值不值得买？销售说三合一烘干是行业首创，我该信吗？」
> 「一根 90 块的数据线，也值得避个雷吗？」——值得，越是便宜货虚标越多，一句话的事

## 它会查什么

1. **强制认证与标准（含「严于国标」判定）**：查国家强制认证 / 强制国标（GB）与在哪验证（3C 查 `cx.cnca.cn`，标准查 `openstd.samr.gov.cn`，召回查 `samrdprc.org.cn`）；再查有无比国标更严的标准（团标 / 行标 / 地标 / 企标 / 国际标准），判「更严」须给具体指标数值对比；结论里写明最终推荐款遵循哪个标准
2. **黑榜**：哪些品牌型号被行政处罚、抽检不合格、召回——型号、处罚单位、日期、来源，逐条列
3. **证据分级**：L1 官方处罚/抽检/召回 > L2 无商业关系的检测 > L3 媒体/博主实测（L3a 网友借机 / 作者自购，L3b 厂商送测 / 委托，L3c 付费定制）> L4 用户投诉 > L0 商家宣传/软文。型号级 L1 原文命中，该款直接出局；只看到转载、没查到原文的，不作唯一排除依据
4. **信源建档**：每个被引用的评测博主查清靠什么活（付费测试 / 送测 / 返利 / 网友借机 / 自购），利益冲突只削评价层，不削事实层
5. **通稿识别**：10 个链接可能是 1 篇通稿；大量雷同帖子、相似好评一律按 GEO 投毒处理
6. **定量对价**：溢价必须跑脚本（`scripts/premium_decision.py`）——TCO/EAC、临界故障率 p\*、溢价 ROI、公允价格上限，不许口算
7. **制造商审计**：这品牌是自产、代工还是纯授权贴牌？质量和售后谁在把控？代工厂按**厂名**查黑历史；判为贴牌/公模，推荐等级直接降一级
8. **信源黑名单**：命中官方或用户黑名单的来源**绝对禁止搜索**（检索阶段就排除、不点开不引用、整条弃用），不分时间等级、无例外，并**举一反三**识别同类。名单含两类：① UGC 水军平台（头条 / 百家号 / 库库 / 什么值得买 / 知乎 / 微信公众号）；② 只发软文的门户媒体（太平洋科技 / 中关村在线 / 快科技 / IT之家 / 网易 / 环境家电网）。**以社区真实实测为主，不以单向软文站 / 媒体为主**；每条「产品好」的理由附信源名称 + 日期，对比不能只靠商家商品页参数
9. **二手保值率**：查闲鱼等近期成交价，给二手价、折价金额、保值率，并入横评表作辅助参考；样本不足写「数据不足」，不许估算
10. **品牌梯队**：把本次查过证据的品牌按「夯 / 顶级 / 人上人 / NPC / 拉」五级排序，拉级必须写明触发原因
11. **历史好价**：一律查**慢慢买 `manmanbuy.com` 价格曲线**，标注查询日期与渠道价；查不到写「无价格历史参照」，不许拿爆料帖价格顶替
12. **结论先行**：唯一推荐 + 性价比款 + 质价比款 + 检索词/直达链接/SKU 路径 + 到手验证步骤
13. **排版规范**：第一屏 3 行给答案、表格不超过 5 列、金额前置、每条数据就地标来源，手机单手能读完

## 三条纪律

1. **推荐强度 ≤ 证据强度**——推荐的强度不能超过证据的强度，证据的强度不能超过信源的强度
2. **不编数据**——查不到就写查不到，没有可靠选项就说「目前没有」
3. **先取证再动笔**——价格、认证、抽检、召回一律现查现证，禁止凭记忆写

## 定量内核

`scripts/premium_decision.py`（零依赖，仅标准库，Python 3.8+）把「性价比款 vs 质价比款」从口味之争变成数字对价：

```bash
python3 scripts/premium_decision.py selftest   # 自检
python3 scripts/premium_decision.py all --input case.json --format both
```

## 关于准确度的实话

避雷的结果准不准，必须先跟你说清楚：

**结果的准确度，模型本身的能力只占 30%，另外 70% 取决于各家公司做的搜索优化。** 如果搜到的源头大量被投毒，那结果肯定也不太理想——信息源被污染了，谁的模型都救不回来，这不是换一个更强的模型能解决的问题。

实测下来，**DeepSeek 客户端、Gemini 客户端自带的搜索，得到的结果质量会更高一点。**

这也是为什么这个技能死磕「公关不了的数据」——行政处罚、抽检通报、召回公告，以及把散落在角落里的差评捞回来：正面的声音可以被买量，负面的痕迹很难被抹干净。

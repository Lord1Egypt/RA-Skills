# GIS_SKILL V5.0 外业轻量版 (field_lite)

> 版本: V5.0 | 大小: ~45KB (单HTML) | 离线可用

## 适用场景

野外测绘作业中无网络连接时的GIS知识快速检索。适合移动设备/平板/笔记本离线使用。

**总计 38条核心知识条目**，覆盖外业最常遇到的GIS问题。

## 使用方法

1. 将 `index.html` 复制到移动设备或笔记本
2. 用浏览器直接打开（无需服务器）
3. Ctrl+K 聚焦搜索框
4. 输入关键词即可检索
5. 点击结果查看详情

## 特性

- 零依赖：纯HTML+CSS+JS，无外部资源
- 全文检索：支持多关键词空格分隔搜索
- 分类导航：按知识群组快速浏览
- 离线可用：所有内容内嵌在HTML中
- 响应式：适配手机/平板/桌面

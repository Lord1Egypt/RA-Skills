## Use Case:

External users and developers use this skill as a portrait-generation prompt template for realistic headshots and artistic character portraits. It helps shape lighting, composition, subject detail, and image-quality guidance for Google Imagen 3 workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Users may mistake the skill for a working Google Imagen 3 integration instead of a prompt template.

Mitigation: Install it only when a portrait prompt template is desired, and provide separate model access, API integration, and workflow controls where image generation is required.

Risk: Prompt wording and mixed-language documentation may not fit every portrait-generation workflow or policy context.

Mitigation: Review and adapt the prompt content, subject description, and language before use in a production workflow.

## Description:

Converts Markdown files or inline Markdown into paginated, shareable image cards for platforms such as WeChat, Xiaohongshu, and Weibo.

This skill is ready for commercial/non-commercial use.

## Publisher:

[reffwu](https://clawhub.ai/user/reffwu)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers use this skill to turn Markdown articles, notes, or inline content into social sharing image cards with a cover title, pagination, and light or dark themes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can fetch remote assets and render Markdown in a browser, which may expose the environment to untrusted content.

Mitigation: Use trusted Markdown only, make remote fetching opt-in or allowlisted where possible, and run generation in a constrained browser environment.

Risk: The skill can read referenced local files and write or erase output folders.

Mitigation: Use a dedicated disposable output directory, avoid custom output paths unless reviewed, and inspect referenced local image paths before running.

Risk: Dependencies and browser execution increase supply-chain and sandboxing risk.

Mitigation: Update dependencies, keep browser sandboxing enabled where supported, and scan the skill before deployment.

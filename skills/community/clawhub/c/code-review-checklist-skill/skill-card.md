## Known Risks and Mitigations:

Risk: Users could paste secrets or sensitive personal data into code review prompts.

Mitigation: Keep prompts free of passwords, private keys, tokens, session secrets, and unnecessary personal data.

Risk: Review guidance can be incomplete or incorrect if used without human judgment.

Mitigation: Treat generated plans, checklists, and draft review copy as reviewer aids and confirm findings against the code before acting.

Risk: The PayPal donation link is external navigation unrelated to the skill function.

Mitigation: Treat donation activity as optional and separate from installing or using the skill.

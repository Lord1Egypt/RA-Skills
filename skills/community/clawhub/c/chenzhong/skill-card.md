## Description:

每日晨间简报助手。每天定时生成个性化简报，提醒你今天要做的事、正在推进的项目和需要关注的方向。不是新闻摘要，是你的个人AI副驾驶晨间仪表盘。

This skill is ready for commercial/non-commercial use.

MIT-0

## Use Case:

Individuals use this skill to generate a daily Chinese morning brief from configured local journals, logs, idea files, and project notes. It highlights habits, project deadlines, stalled tasks, source files used, and suggested next actions for the day.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill processes private journals, session logs, idea files, and project-memory files, and the security summary notes unclear retention or minimization limits.

Mitigation: Configure narrow file paths, avoid folders containing secrets, credentials, client data, or unrelated private records, and review the generated brief before enabling scheduled use.

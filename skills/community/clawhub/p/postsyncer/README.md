# postsyncer-social-media-assistant

OpenClaw skill: **Social Media Assistant (via postsyncer.com)**, version 2.6.0. It schedules and manages posts on PostSyncer's 12 networks through the REST API v1. See `SKILL.md` for setup, permissions and workflows.

**API key:** create one in [Settings → API](https://app.postsyncer.com/settings/api) and give it to OpenClaw as `POSTSYNCER_API_KEY`.

**Support:** [docs.postsyncer.com](https://docs.postsyncer.com) · support@postsyncer.com

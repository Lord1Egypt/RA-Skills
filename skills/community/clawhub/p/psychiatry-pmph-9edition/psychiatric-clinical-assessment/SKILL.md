# 精神科临床评估与症状识别

## 一、病史采集

### 1. 现病史采集核心要素

按以下顺序系统采集：

1. **发病条件及因素**：询问环境背景及生物/心理/社会因素，排查感染、中毒、躯体疾病
2. **判定起病缓急**：
   - 急性起病：< 2周（如谵妄）
   - 亚急性起病：2周至3个月
   - 慢性起病：> 3个月（如痴呆）
3. **描述疾病演变**：按时间先后纵向描述，包括首发症状、症状间关系、社会功能变化、病程特点
4. **评估一般情况**：工作/学习/睡眠/饮食/自理能力
5. **危险行为排查**：必须排查自伤/自杀/伤人/冲动行为

### 2. 病史资料采信原则

根据信息来源一致性决定采信程度：

| 情况 | 特征 | 处理 |
|------|------|------|
| A | 全面、明确、无矛盾 | 直接采信 |
| B | 欠全面，但明确无矛盾 | 可采信 |
| C | 不全面、不明确，但高度怀疑 | 谨慎采信，需进一步核实 |
| D | 不同来源信息相互矛盾 | 绝不直接应用，需深入沟通直至一致 |

## 二、精神检查

### 1. 检查步骤

**开始阶段：**
- 创造不受干扰环境，保证隐私
- 自我介绍，定下平等基调
- 寒暄了解一般状况
- 若患者紧张：找寻原因并承诺保密
- 若患者迷惑混乱：考虑焦虑/意识障碍/智力低下/痴呆

**深入阶段：**
- 以开放性交谈为主，启发内心体验
- 主导谈话，集中在相关话题
- 观察表情/情绪/异常动作

**结束阶段（20-45分钟）：**
- 简短小结，询问有无未提及问题
- 解释保证，说明治疗安排

### 2. 核心沟通技巧

- **观察**：表情/眼神/姿势/穿着/意识，及伴诊者态度
- **倾听**：耐心专心，允许充裕时间，绝不唐突打断
- **提问**：先开放后封闭
- **非言语沟通**：眼神/手势/姿态，适当身体接触缓解焦虑
- **肯定**：肯定感受真实性，接纳而非简单否定
- **澄清**：弄清实际经过及情感体验
- **代述**：替患者说出不好意思说的话题
- **重构**：用不同措辞复述总结

### 3. 六大评估维度

1. **外表与行为**：体格/装束/面部表情/活动量/与环境接触/自理能力
2. **情绪状态**：客观表现与主观体验，**必须询问自杀观念**
3. **言谈与思维**：速度/量/形式/逻辑/内容（妄想种类及性质）
4. **感知觉**：错觉/幻觉种类/内容/频率
5. **认知功能**：定向力/注意力/记忆/智能
6. **自知力**：对症状认识程度，推断合作程度

## 三、症状识别与分类

### 1. 症状判断四维度

- **纵向比较**：与患者过去一贯表现比较
- **横向比较**：与大多数正常人比较
- **现实环境相符性**：结合心理背景和周围环境分析
- **精神病学符合度**：是否符合精神病学表现

### 2. 意识障碍分级

**清晰度降低为主：**

| 等级 | 核心表现 | 反射状态 | 定向力 |
|------|----------|----------|--------|
| 嗜睡 | 安静环境昏昏入睡，刺激可醒 | 存在 | 完整 |
| 混沌 | 反应迟钝，注意/记忆困难 | 可出现原始反射 | 环境定向障碍 |
| 昏睡 | 定向力丧失，无言语，强刺激才有防御反射 | 角膜/对光迟钝，病理反射阳性 | 丧失 |
| 昏迷 | 意识完全丧失，任何刺激无反应 | 所有反射消失 | 丧失 |

**伴范围缩小或内容变化：**
- **朦胧状态**：清晰度降低+范围缩小，突然发作与中止，事后遗忘
- **谵妄**：恐怖性幻视/错视为主，昼轻夜重，不协调性兴奋
- **梦样状态**：沉浸于幻觉妄想如做梦，与外界失去联系

### 3. 感知觉障碍

**感觉障碍：**
- 感觉减退/缺失：对刺激感受性降低
- 感觉过敏：一般刺激产生强烈体验
- 内感性不适：躯体内部不舒适/异样感觉

**知觉障碍：**
- 错觉：对客观事物歪曲的知觉（病理性难纠正，多带恐怖色彩）
- 感知综合障碍：整体属性正确，个别属性错误（视物变形症、现实解体等）

### 4. 幻觉分类

**按感觉器官：**
- 幻听（最常见）：言语性为精神分裂症典型症状
- 幻视：意识清晰下见精神分裂症，意识障碍时具恐怖性
- 幻味/幻嗅：常与被害妄想结合
- 幻触：无刺激下皮肤异常感

**按体验来源：**
- 真性幻觉：来自外部空间，通过感觉器官获得
- 假性幻觉：存在于主观空间，不通过感觉器官

**按产生条件：**
- 功能性幻觉：伴随现实刺激出现
- 反射性幻觉：涉及两个不同感觉器官
- 心因性幻觉：强烈心理因素影响下出现

### 5. 思维障碍

**妄想与超价观念鉴别：**
- 妄想：内容荒谬离奇，无事实依据，坚信不疑
- 超价观念：有强烈情感色彩，有一定事实依据，片面偏激

详细妄想分类参见 [references/delusion-classification.md](references/delusion-classification.md)

### 6. 情感与意志障碍

**情感障碍识别：**
- 高涨：病态喜悦，具感染性（躁狂）
- 低落：忧愁/绝望/自杀（抑郁）
- 淡漠：缺乏情感反应（晚期精神分裂症）
- 焦虑：无客观刺激的内心不安
- 易激惹：小事引起强烈不愉快

**意志障碍识别：**
- 增强：病态情感/妄想支配下持续坚持
- 减退：动机不足，缺乏兴趣
- 缺失：缺乏动机，被动，无本能要求

### 7. 动作行为障碍

**精神运动性兴奋：**
- 协调性：动作/言语与思维/情感协调（躁狂）
- 不协调性：脱离现实，杂乱无章（精神分裂症、谵妄）

**精神运动性抑制：**
- 木僵：不语/不动/不饮/不食
- 蜡样屈曲：肢体任人摆布，"空气枕头"
- 违拗症：主动（做相反动作）/被动（一概拒绝）

### 8. 认知障碍

**记忆障碍：**
- 顺行性遗忘：疾病后不能回忆
- 逆行性遗忘：疾病前不能回忆
- 虚构：用想象事件填补遗忘
- 错构：对过去事件错误回忆并坚信不疑

**智能障碍：**
- 智力发育障碍：18岁前发病
- 痴呆：发育成熟后发病（全面性/部分性/假性）

### 9. 常见综合征识别

| 综合征 | 核心特征 | 常见疾病 |
|--------|----------|----------|
| 幻觉妄想综合征 | 幻觉基础上产生妄想 | 精神分裂症 |
| 躁狂综合征 | 情感高涨+思维奔逸+活动增多 | 躁狂发作 |
| 抑郁综合征 | 情感低落+思维迟缓+活动减少 | 抑郁障碍 |
| 紧张综合征 | 全身肌张力增高 | 精神分裂症 |
| 遗忘综合征 | 近事记忆障碍+虚构 | 酒精中毒、脑器质性 |

## 四、标准化量表选择

| 评估目的 | 推荐量表 | 关键阈值 |
|----------|----------|----------|
| 智力 | WAIS（≥16岁） | 分数越高智商越高 |
| 人格 | MMPI（566题） | 13个分量表 |
| 精神分裂症症状 | PANSS（30项） | 1-7分，分越高越重 |
| 抑郁（他评） | HAMD | 分越高抑郁越重 |
| 焦虑 | HAMA（14项） | 分越高焦虑越重 |
| 认知筛查 | MMSE | 分越低认知越差 |
| 抑郁（自评） | PHQ-9 | 5/10/15/20分 |
| 药物副作用 | TESS | 三方面评定 |

## 五、紧张症/木僵状态检查

对木僵患者执行以下检查：

1. **空气枕头测试**：拿走枕头，观察头部是否悬空约10秒
2. **蜡样屈曲测试**：将肢体摆放到不适位置，观察是否长时间保持
3. **违拗症检查**：要求做动作，观察被动违拗（一概拒绝）
4. **进食观察**：吞咽是否极其缓慢，是否不主动吞咽唾液
5. **睡眠观察**：确认睡眠时肌肉是否放松（鉴别器质性病变）

**注意**：检查时确保患者安全，避免强行拉扯导致损伤

## Description:

Anti-Laziness Protocol is a Chinese-language agent workflow that enforces deeper validation for source-code review, technical research, report writing, and document checks.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Developers, reviewers, and writing-focused agents use this skill to add evidence-backed checklists and stricter self-review to source-code analysis, technical research, report writing, and document validation tasks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill is broadly scoped and can add strict review process to code review, research, writing, and validation tasks.

Mitigation: Use it for work that benefits from evidence tracking and disable or narrow it for quick, low-risk tasks.

Risk: The workflow may create local progress notes containing findings from the user's work.

Mitigation: Use it only in workspaces where generated notes are acceptable and protect or delete those notes according to project data-handling rules.

## Description:

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, maintainers, and external users use this skill to respond to requests for adding Nextcloud support with practical plans, implementation guidance, checklists, and verification steps.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate on generic support or feature-request language.

Mitigation: Confirm the user is asking about Nextcloud support before applying the workflow.

Risk: Outputs may include implementation steps, commands, or configuration changes that affect a user's project.

Mitigation: Review proposed changes and run the suggested verification commands before applying them.

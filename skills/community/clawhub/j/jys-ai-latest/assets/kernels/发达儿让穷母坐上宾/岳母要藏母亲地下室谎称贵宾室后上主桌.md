# 岳母要藏母亲地下室谎称贵宾室后上主桌

## 元数据
- 商业潜力：70
- 跑量空间：20万
- 带货产品：管道除臭凝珠
- 改编来源：未婚妻谎称裁缝母亲在贵宾室后请上主桌
- 主要改编内容：把裁缝母亲改为公厕保洁母亲；开头改为岳母先安排负一楼房间并嘱咐对儿子谎称贵宾休息室；保留博士儿子公开感恩与主桌反转，产品改为管道除臭凝珠，结尾改为岳母和妻子共同道歉。

## 人物表
| 角色 | 身份 |
|------|------|
| 秦忘川 | 品牌创始人、青年博士，刘秀兰的儿子 |
| 刘秀兰 | 秦忘川的母亲，做过二十多年公厕保洁员 |
| 婉晴 | 秦忘川的妻子，前期受母亲影响重视场面 |
| 苏母 | 婉晴的母亲，讲究圈子与面子 |
| 小琴 | 苏母的助理 |
| 徐总 | 宴会核心投资人、商会代表 |

## 开场画面

酒店走廊里，小琴向苏母汇报已在负一楼107房间为刘秀兰准备饭菜；苏母要求对秦忘川谎称其母亲在贵宾休息室。

## 台词

**【负一楼房间的隐瞒安排】**

场景：酒店走廊 / 日内

小琴：苏姐，房间准备好了，负一楼107。窗子虽然小了点，但还算干净。

苏母：饭菜呢？

小琴：两荤一素，单独盛的。

苏母：行。等忘川母亲来了，你直接领下去就行。但见到秦忘川，一定要说他母亲在贵宾休息室，不要说是负一楼。

小琴：（犹豫）那秦先生知道了会不会……

苏母：今天主桌上的每个位子都是有讲究的，她上不了台面。

△ 秦忘川在主宴会厅外打电话询问母亲位置。婉晴上前挽住他。

秦忘川：妈，您到哪儿了？

刘秀兰（电话音）：我已经到了，妈在外面站一会儿再进去。你先忙你的吧。

婉晴：忘川，徐总刚才问起你了，我妈让你过去打个招呼。

秦忘川：先让他们等一会儿吧。我妈到了，我去接她。

婉晴：你妈那边你就放心吧，我妈都安排好了。给阿姨准备的贵宾休息室，有茶有水果的。你先去跟徐总他们打个照面，忙完了再过去陪阿姨，好不好？

秦忘川：婉晴，我不是说今天要让我妈坐我旁边吗？

婉晴：今晚来的不只是同学朋友，还有商会领导和投资方，而且媒体也在。你现在不是一个博士生，你是品牌的创始人！阿姨第一次来这种场合，坐在聚光灯底下会不自在的，咱们就让她在休息室好好休息，好不好？

△ 秦忘川想起十五年前家长会上，衣着朴素、满身灰尘的母亲被老师安排到最后一排角落。

老师：您是哪位同学的家长？

刘秀兰：我是秦忘川的妈妈，来开家长会。

老师：你的位子在最后一排的那个角落里。

---

**【母亲自卑退让与儿子寻找】**

场景：主宴会厅外、电梯间转角 / 日内

秦忘川：婉晴，我这么多年的努力，不就是想让我妈从那个角落里走出来，不再让她被别人瞧不起吗？今天她必须坐主桌！

苏母：（端着红酒走来）忘川，你的努力应该被尊重，你母亲也应该被尊重。但我只是觉得，她辛苦了一辈子，坐在聚光灯底下，被一群不认识的人盯着看，会不舒服。

秦忘川：苏阿姨，我妈坐在聚光灯下会不会不舒服，不是咱们说了算。我要去征求我妈的意见。

△ 刘秀兰靠着走廊墙壁局促站着，自言自语。

刘秀兰：忘川，今天你穿西装真精神。妈就在这站一会儿，看完了你上台讲话妈就走，妈就不进去耽误你正事了。

秦忘川：（快步赶来）妈！您怎么站在这儿？

刘秀兰：这挺好，不碍事。你快进去忙你的，妈就在这等着。

秦忘川：我跟您说了，今天您要坐我旁边。

刘秀兰：（连连摆手）忘川，妈这身上还是算了，我就不进去了。里头都是有头有脸的人，妈往那一坐不像样。刚才从公交站走过来，鞋底都脏了，这地砖亮得跟镜子似的……

△ 刘秀兰蹲下用纸巾擦鞋，秦忘川心疼地蹲下扶住她。

刘秀兰：妈刚才走过来出了一身汗，你别靠这么近，会把汗味粘你身上的。等会儿那些投资方闻着了不好。

秦忘川：（拉起母亲）妈，您身上的汗味我从小闻到大，我只有闻了那个味道才会安心。走吧，跟我进去。

---

**【宴会门口交锋与请上主桌】**

场景：宴会厅门口、主宴会厅 / 日内

△ 秦忘川牵着母亲走向大门，苏母与婉晴挡在门前。

苏母：忘川，亲家母来了！

刘秀兰：亲家，我就是来看看忘川，看一眼就走。

苏母：（吩咐小琴）小琴，负一楼那个房间的饭菜别凉了，去热一下。

苏母：（转向刘秀兰）亲家母，宴会厅里有媒体的人，我还是让人带你下去先歇着吃点东西。忘川这边忙完了就去看你。

刘秀兰：亲家，我能不能就在门口站一会儿？我就想看看忘川上台说话，他讲完了我就走了。我不进去，不影响你们招待贵宾。

秦忘川：（爆发）苏阿姨！媒体的人在怎么了？我秦忘川的妈，就这么见不得人吗？！

苏母：忘川，我只是为大局考虑……

秦忘川：妈，走！

△ 秦忘川推开宴会厅大门，牵母亲径直走向主桌，拿开主位名牌并拉开椅子。

秦忘川：妈，您坐这儿。

刘秀兰：忘川，这是别人的位子吧？

秦忘川：这是您的位置。请坐。

△ 周围宾客议论，徐总侧目。婉晴压低声音质问。

婉晴：秦忘川，你非要这样吗？一屋子人都看着！我妈请了商会的人，请了媒体，你为了这点小事把场面弄得这么难堪！

秦忘川：把我妈安排去负一楼员工更衣室吃盒饭，在你这是小事？

婉晴：那是为了替你保全面子！你今天是品牌创始人、是博士，不是……

秦忘川：不是什么？不是那个在厕所门口等妈妈下班的男孩？！

△ 婉晴哑口无言。秦忘川拍拍母亲肩膀，拿起话筒走上发言台。

---

**【公开公厕养育恩与博士证书】**

场景：舞台中心 / 日内

秦忘川：各位来宾，在座的各位可能不认识她。23年前，这栋酒店的裙楼还是一片工地的时候，她就在对面的公厕当保洁员。每天早上5点半到岗，晚上10点锁门。她一个人管12个隔间、两个洗手台、一面镜子。

秦忘川：她这辈子最熟悉的不是办公室，是瓷砖墙面上的水渍，是蹲便器边缘的尿碱，是下水道口堵着的头发团！我妈没有工位，她的工位就是厕所的隔间。中午吃饭的时候，她把饭盒放在拖把池边上，蹲在隔间里吃，因为那是她唯一能坐下来歇一会儿的地方。

△ 小琴将博士学位证书递上台。

秦忘川：（哽咽举起证书）我妈就在那种地方，把我从县城供到了博士毕业！我妈扫了20多年的厕所，供出了一个博士！这本证书上，应该属于我妈！

△ 刘秀兰捂嘴痛哭，全场鼓掌。

---

**【管道除臭凝珠产品推介】**

场景：宴会舞台 / 日内

秦忘川：我妈扫了20多年的厕所，我就陪着我妈在厕所里待了20多年。这20年我发现了一个问题：每年一到夏天，卫生间就会反味，而且地漏旁边也总会有小飞虫，甚至厨房水槽也会油腻腻的下水慢。所以我从小的梦想，就是彻底解决这些问题。

△ 秦忘川从礼仪盘中拿出一盒管道除臭凝珠。

秦忘川：就在我马上毕业、步入社会时，我终于把这款管道疏通除臭凝珠研发出来了。真正解决的是家里下水道反味、小飞虫、油污挂壁、毛发堵塞等问题。

秦忘川：很多叔叔阿姨家里，卫生间一到天气热就有味道，不是表面没打扫干净，是地漏管道里面长期没清理。超过3个月不清理，里面的油垢、头发、脏东西堆在一起，臭味就会往上反，小飞虫也容易滋生出来。

秦忘川：用我们的凝珠轻轻一倒，快速溶解。不用解开、不用兑水，不用拿刷子伸进去掏，直接丢进地漏、洗手台水槽或者马桶里。遇水慢慢溶解，里面的活氧清洁配方能分解油脂和毛发，把藏在管道里的脏污和虫卵一起清洁掉！不只是用香味盖住臭味，而是从源头减少反味和小飞虫。

秦忘川：厨房水槽平时倒油容易挂油，时间久了下水慢还有馊味，睡前丢一颗，第二天水槽不油、不招飞虫；卫生间地漏下水慢丢一颗，分解头发污渍；洗手台、马桶都能用，甚至平时拖地时也可以在水里丢一颗，地面干得快，还留有淡淡清香。

秦忘川：我做这个产品的初心不是搞噱头，是想让像我妈这样身体不好、弯腰清理下水道很吃力的人，能轻松解决，让家里真正需要的人省事、放心、用得起！

徐总：那这么好用的管道疏通除臭凝珠，你打算怎么定价？

秦忘川：正常定价是29块9一盒，里面有50粒。但今天点击视频左下角链接，直接9块9发一大盒，一盒整整50粒，还包邮到家！算下来一颗才几毛钱，怎么用都不心疼。但这个价格的活动库存不多，卖完就恢复原价了！

徐总：说真的我见过便宜的，但9块9发50粒还包邮确实是捡漏价，我也要给家里备上几盒！

---

**【岳母妻子道歉与母爱升华】**

场景：主桌 / 日内

苏母：忘川……是阿姨错了。我在这个圈子里待太久了，习惯了排位子、看镜头、算关系，我把这些当成了体面，忘了什么才是真的体面。亲家母，我不该让人把你往负一楼带，对不起。

刘秀兰：亲家，我没往心里去，都是为了忘川好。

苏母：你养了一个好儿子，是我没养好我的眼界。

婉晴：（向婆婆鞠躬）忘川……刚才你站在台上说在厕所门口等妈妈下班的男孩，我才想明白。我不是在为大局，我是怕你的母亲不够体面，会影响我的生活……妈，对不起！

刘秀兰：（扶起婉晴）对不起啥，好孩子，都过去了。

秦忘川：（牵住母亲的手）人这一辈子，读到什么学历不算真正的体面，赚到多少钱也不算真正的体面。真正的体面是——当你站到高处的时候，还敢不敢牵住那个把你从低处托起来的人！

秦忘川：我妈叫刘秀兰，她扫了20多年厕所。但就是这双手，把我从农村一路托到了今天这个台子上。不管她穿什么样的衣服，做过什么样的工，我不觉得我妈丢人！那不是我的软肋，那是我的来时路，也是我这辈子最大的加分项！

秦忘川：屏幕前的家人们，你们说我说得对吗？觉得对的家人点个小红心，在评论区留下“母爱伟大”这四个字！想要凝珠的家人，点击左下角链接给家里备上一盒，别再让咱爸咱妈弯着腰去掏下水道了！

## 开头具体呈现
- 场景进入：酒店走廊里，助理先向苏母汇报负一楼107房间和单独饭菜已经准备好。
- 人物相遇方式：苏母与助理先密谋；镜头转到主宴会厅外，秦忘川打电话询问母亲位置，妻子婉晴迎上来阻拦。
- 触发事件：苏母要求助理隐瞒负一楼安排，统一谎称贵宾休息室；秦忘川得知母亲已到后准备亲自去接。
- 动作组合：汇报房间→苏母嘱咐撒谎→儿子电话找母亲→妻子挽住拖延→以贵宾休息室和宴会体面为由阻止迎接。
- 信息释放顺序：先让观众知道负一楼安排和谎言，再交代母亲已经到场、儿子准备迎接，最后通过妻子的阻拦揭示她把品牌形象放在母亲尊严之前。
- 标志性场面或台词：“负一楼107”；“一定要说他母亲在贵宾休息室”；“我妈今天坐我旁边。”

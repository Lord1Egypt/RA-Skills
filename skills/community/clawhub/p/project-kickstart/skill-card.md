## Description:

Scaffolds new projects for Next.js, React, Python CLI, Express, FastAPI, static sites, and OpenClaw skills with git, linting, CI, README, and license defaults.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers use this skill to quickly create minimal, working starter projects across common web, API, CLI, static-site, and OpenClaw skill stacks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated boilerplate may be created in an unintended or non-empty working directory.

Mitigation: Run the skill only in an empty or clearly selected destination, then review the generated files before continuing.

Risk: Default project choices such as MIT licensing, Tailwind, TypeScript, CI, and starter dependencies may not match a team's policy.

Mitigation: Confirm the generated defaults and adjust files before building on the project.

Risk: Automatic git initialization and the first commit may create repository state the user did not intend.

Mitigation: Inspect the initial commit and working tree status before adding further changes.

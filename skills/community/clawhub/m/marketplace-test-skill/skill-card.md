## Description:

This skill turns raw commits, merged pull requests, issue lists, or plain change notes into concise user-facing release notes.

This skill is ready for commercial/non-commercial use.

## Publisher:

[qdw497874677](https://clawhub.ai/user/qdw497874677)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, release managers, and maintainers use this skill to convert raw technical change material into concise release notes that emphasize user-visible outcomes, migration needs, known issues, and security-relevant changes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Confidential change details provided as input could be repeated, summarized, or transformed in release-note output.

Mitigation: Use approved, non-sensitive change material for public release notes and review generated notes before publication.

## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to plan, create, improve, and validate OpenAPI or Swagger documentation for REST APIs. It supports tailored documentation artifacts, reusable workflows, checklists, implementation support, and verification notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad implicit invocation may activate the skill for general API-related requests outside explicit OpenAPI or Swagger documentation work.

Mitigation: Prefer explicit invocation for OpenAPI or Swagger documentation tasks and tighten activation wording before deployment.

Risk: Generated API documentation guidance can be incomplete or misleading when the source routes, schemas, authentication rules, or examples are incomplete.

Mitigation: Validate outputs against the service implementation, existing API contracts, and the user's stated success criteria before publishing.

## 功能

根据收寄件地址、重量/体积，计算所有可用快递渠道的价格，展示预估到手价，并推荐最经济的选择。

## 执行步骤

1. **解析输入**
   - 提取寄件地、收件地（支持省市名称、简称、地址编码）
   - 提取重量（公斤）或体积（长宽高厘米）
   - 若缺少重量，询问用户

2. **计算抛重**（如提供了体积）
   - 体积重量 = 长 × 宽 × 高 ÷ 8000
   - 计费重量 = MAX(实际重量, 体积重量)

3. **调用计算脚本**
   ```bash
   cd /c/Users/admin/.workbuddy/skills/kuaidichaxun
   python scripts/calculate.py --data references/all_channels_prices.json --from <寄件地> --to <收件地> --weight <重量>
   ```

4. **展示结果**
   - 直接展示脚本输出的完整内容（价格表格、费用统计、推荐说明、数据来源说明）
   - **不要**额外添加任何推荐、建议、或引导内容
   - **不要**自己总结或改写脚本输出
   - 脚本输出已经包含完整的推荐说明和数据来源，直接呈现即可

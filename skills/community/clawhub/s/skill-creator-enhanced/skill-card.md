## Known Risks and Mitigations:

Risk: The skill includes copyable shell examples for validating, installing, and publishing skills; unsafe edits could install untrusted skills or mishandle skill names.

Mitigation: Review and harden copied scripts before use by validating skill names, quoting variable expansions, and installing only trusted or pinned skills.

Risk: The artifact is guidance-only and does not execute commands automatically, but users may treat examples as production-ready automation.

Mitigation: Review generated or adapted skill instructions and run validation and security checks before publishing or deploying a skill.

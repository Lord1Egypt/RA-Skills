# 神经急重症与意识障碍评估

## 适用场景

- 患者出现意识障碍、昏迷、谵妄
- 需要量化评估意识障碍程度（GCS评分）
- 昏迷患者需要神经定位诊断
- 怀疑颅内压增高或脑疝形成
- 需要鉴别特殊意识障碍综合征

## 核心评估流程

### 第一步：快速意识水平评估（GCS评分）

执行Glasgow昏迷量表评估，记录三项分数：

1. **睁眼反应（E）**：自动睁眼4分 → 呼之睁眼3分 → 疼痛睁眼2分 → 不睁眼1分
2. **言语反应（V）**：定向正常5分 → 应答错误4分 → 言语错乱3分 → 言语难辨2分 → 不语1分
3. **运动反应（M）**：按指令动作6分 → 刺激定位5分 → 刺激躲避4分 → 屈曲反应3分 → 过伸反应2分 → 无动作1分

**预后判断**：
- >8分：恢复机会较大
- ≤7分：预后不良
- 3-5分：潜在死亡风险

### 第二步：昏迷患者重点查体定位

按以下顺序执行检查并记录：

1. **瞳孔检查**：
   - 一侧散大固定 → 动眼神经受损/钩回疝
   - 双侧散大/对光消失 → 中脑受损/脑缺氧
   - 双针尖样缩小 → 脑桥被盖损害/有机磷中毒
   - 一侧缩小 → Horner综合征/延髓背外侧综合征

2. **疼痛刺激反应**：
   - 去皮质强直（上肢屈曲、下肢伸直）→ 丘脑或大脑半球病变
   - 去大脑强直（四肢伸直、角弓反张）→ 中脑功能受损（更严重）
   - 无反应 → 脑桥/延髓病变

3. **脑干反射**（由上至下依次消失提示昏迷加深）：
   - 额纹-角膜反射（脑桥）
   - 头眼反射/玩偶眼（中脑-脑桥）
   - 前庭眼动反射/冷热水试验（脑桥）

### 第三步：呼吸节律定位脑干损害

观察呼吸模式并匹配损害水平：

| 呼吸模式 | 特征 | 损害水平 |
|---------|------|---------|
| 潮式呼吸 | 浅慢→深快→暂停周期 | 间脑 |
| 中枢神经源性过度呼吸 | 深快持久40-70次/分 | 中脑被盖 |
| 长吸气呼吸 | 吸2-3次呼1次 | 中脑下部/脑桥上部 |
| 丛集式呼吸 | 频率幅度不规律 | 脑桥下部 |
| 共济失调式呼吸 | 完全不规则 | 延髓上部 |

### 第四步：鉴别特殊意识障碍综合征

根据临床表现进行鉴别：

- **貌似清醒但无反应** → 检查睡眠-觉醒周期、眼球追踪能力
  - 有周期、无追踪 → 植物状态(VS)
  - 有周期、有不持续追踪 → 微意识状态(MCS)
  - 有周期、能睁眼但完全不能活动/言语、仅能垂直眼球运动 → 闭锁综合征（意识清醒！）

- **特殊姿势** → 观察肢体姿态
  - 上肢屈曲内收+下肢伸直 → 去皮质综合征
  - 角弓反张+四肢伸直 → 去大脑强直

- **不能言语活动但貌似清醒** → 排除闭锁综合征后考虑
  - 无欲望、淡漠、额叶释放反射 → 意志缺失
  - 蜡样屈曲、违拗症、缓解后可回忆 → 木僵（精神源性）

### 第五步：评估颅内压与脑疝风险

**颅内压增高警示征象**：
- 剧烈头痛+呕吐+视乳头水肿
- 意识进行性恶化
- 瞳孔变化（先缩小后散大）

**脑疝类型识别**：

| 脑疝类型 | 关键特征 | 紧急程度 |
|---------|---------|---------|
| 小脑幕裂孔疝（钩回疝） | 意识恶化+同侧瞳孔散大+对侧偏瘫 | 极紧急 |
| 枕骨大孔疝 | 枕颈痛+突发呼吸衰竭 | 致命 |
| 大脑镰下疝 | 对侧下肢轻瘫 | 紧急 |

**禁忌**：明显颅内压增高或颅后窝占位时，禁止腰穿以防诱发脑疝。

### 第六步：伴发症状病因推断

根据伴随症状快速推断病因方向：

- 头痛+脑膜刺激征 → 脑膜炎/蛛网膜下腔出血
- 偏瘫+血压升高 → 脑出血/脑梗死
- 发热+意识障碍 → 脑炎/败血症
- 瞳孔散大+肌震颤 → 药物/毒物中毒
- 体温过低+心动过缓 → 甲减/低血糖

## 输出要求

1. 给出GCS评分及预后判断
2. 明确意识障碍类型（真性昏迷/特殊综合征）
3. 定位脑干损害水平（如有）
4. 识别脑疝风险等级
5. 列出疑似病因及紧急处理建议

## 特殊意识障碍综合征详细鉴别

### 植物状态(VS)与微意识状态(MCS)
- VS：大脑半球严重受损，脑干功能保留。认知完全丧失，有自发睁眼，无意义哭笑，原始反射存在
- MCS：可有不持续眼动追踪或完成简单指令
- 持续性植物状态(PVS)：创伤性>12个月，非创伤性>3个月

### 闭锁综合征（去传出状态）
- 病变：脑桥基底部，双侧皮质脊髓束和皮质脑干束受累
- 关键：意识完全清醒！仅能以瞬目和眼球垂直运动示意
- 病因：脑血管病、感染、肿瘤、脱髓鞘病
- 警示：易被误诊为昏迷，必须仔细检查垂直眼球运动

### 去皮质综合征 vs 去大脑强直
| 特征 | 去皮质综合征 | 去大脑强直 |
|------|------------|----------|
| 病灶 | 双侧大脑皮质 | 中脑/上位脑桥 |
| 姿势 | 上肢屈曲内收，下肢伸直 | 角弓反张，四肢伸直 |
| 预后 | 相对较好 | 更严重 |

## 脑疝详细分类

### 小脑幕裂孔疝
- **钩回疝（外侧型）**：颞叶海马回/钩回疝入，早期动眼神经麻痹
- **中心疝**：中线结构下移，意识障碍早，呼吸改变早

### 枕骨大孔疝
- 小脑扁桃体疝入颈椎管
- 急性者突发呼吸衰竭/循环衰竭
- 多见于颅后窝占位

## 颅内压增高病因

| 机制 | 常见病因 |
|------|---------|
| 脑组织体积增加 | 损伤/炎症/卒中/肿瘤（血管源性）、缺氧/中毒（细胞毒性） |
| 颅内占位 | 肿瘤、血肿、脓肿 |
| 脑血容量增加 | CO2蓄积、静脉回流受阻 |
| 脑脊液增加 | 脑积水 |

## 谵妄病因排查清单

### 颅内病变
脑炎、脑外伤、蛛网膜下腔出血、癫痫

### 药物相关
抗高血压药、西咪替丁、胰岛素、抗胆碱能药、抗癫痫药、阿片类、水杨酸类、类固醇

### 中毒
一氧化碳、重金属、工业毒物

### 系统疾病
肝/肺性脑病、低氧血症、尿毒症、心衰、电解质紊乱、术后、甲减

## Description:

Helps developers, QA engineers, maintainers, and product teams add useful unit tests and raise coverage for existing codebases.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, QA engineers, maintainers, and product teams use this skill to turn testing goals into practical unit-test plans, implementation guidance, checklists, and verification steps for existing projects.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad testing or quality requests may invoke the skill unexpectedly because implicit invocation is enabled.

Mitigation: Review activation wording and narrow the invocation policy when tighter control over skill use is needed.

Risk: Generated unit-test plans or code may be incomplete or mismatched to a specific codebase.

Mitigation: Review proposed tests, adapt them to project conventions, and run the project test and coverage commands before merging.

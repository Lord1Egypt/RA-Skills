# 血管性认知障碍诊断与分型

## 适用场景

当患者满足以下条件时启动本诊断路径：
- 存在认知损害主诉或客观证据
- 有脑血管病危险因素（高血压、糖尿病、高脂血症等）或卒中病史

## 诊断执行流程

### 第一步：确认三大核心要素（必须同时满足）

1. **认知损害确认**
   - 评估至少1个认知域是否存在损害
   - 使用标准化神经心理学测验验证

2. **血管性脑损伤证据收集**
   - 血管危险因素评估
   - 卒中病史确认
   - 脑血管病相关神经损伤症状检查
   - 影像学脑血管病变证据（MRI/CT）

3. **因果关系判定**
   - 确认血管性脑损害在认知损害中占主导地位
   - 若合并AD病理，结合临床和影像判断何者为主

### 第二步：排除鉴别诊断

逐一排查以下排除标准，若存在则排除VCI诊断：
- [ ] 早期进行性记忆缺陷、早期突出帕金森特征、原发性神经系统疾病特征
- [ ] 神经影像学缺乏血管性损伤病变
- [ ] 其他可解释疾病（脑肿瘤、多发性硬化、脑炎、抑郁症、中毒、代谢异常）
- [ ] 首次诊断前3个月内有药物或酒精滥用/依赖

### 第三步：严重程度分型

排除脑血管事件感觉/运动障碍所致的日常生活能力障碍后：

| 分型 | 认知状态 | 日常生活能力 |
|------|----------|--------------|
| 轻度VCI/VCIND | 轻度认知损害 | 基本正常 |
| 重度VCI/VaD | 明显认知障碍 | 影响独立性 |

### 第四步：VaD临床亚型分类

**按时间关系分类：**
- 卒中后痴呆：卒中后6个月内出现，持续3个月以上
- 非卒中痴呆

**按特征/影像分类：**
- 皮质下缺血性痴呆
- 多发梗死性痴呆（阶梯式加重模式）
- 混合型痴呆（血管性+AD病理并存）

## 输出格式

```
诊断结论：[VCI/VaD确诊或排除]
严重程度：[VCIND/VaD]
临床亚型：[卒中后痴呆/皮质下缺血性/多发梗死性/混合型/非卒中]
因果关系判定：[血管因素主导/混合因素/待进一步评估]
排除诊断：[已排除的疾病列表]
```

## 关键变量记录

- 受损认知域数量（需≥1）
- 日常生活能力状态（基本正常/受损）
- 卒中与痴呆时间差（用于卒中后痴呆判定）

# VCI影像学评估标准

## 必须存在的血管性病变证据

### MRI表现
- 大面积皮质梗死（>3cm）
- 关键部位梗死（角回、海马、基底节、丘脑等）
- 多发基底节-半卵圆中心腔隙性梗死
- 广泛脑白质病变（Fazekas 3级或Scheltens评分≥25）

### CT表现
- 多发皮质/皮质下低密度灶
- 广泛白质疏松

## 血管危险因素清单

### 可干预因素
- 高血压（收缩压>140mmHg或舒张压>90mmHg）
- 糖尿病（HbA1c>6.5%或空腹血糖>7.0mmol/L）
- 高脂血症（LDL-C>3.4mmol/L）
- 心房颤动
- 吸烟
- 肥胖（BMI>28）

### 不可干预因素
- 年龄>65岁
- 男性
- 卒中/TIA病史

## 与AD影像学鉴别要点

| 特征 | VCI | AD |
|------|-----|----|
| 萎缩模式 | 皮质下/白质为主 | 海马-内侧颞叶为主 |
| 白质病变 | 广泛、融合 | 轻度、散在 |
| 梗死灶 | 多发、关键部位 | 少见 |
| FDG-PET | 额叶-皮质下低代谢 | 颞顶叶低代谢 |

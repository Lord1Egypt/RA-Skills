## Description:

S2-SP-OS Energy Radar maps a spatial appliance inventory and generates local energy visual dashboards for user-facing insight without cloud analytics.

This skill is ready for commercial/non-commercial use.

## Publisher:

[spacesq](https://clawhub.ai/user/spacesq)

## Use Case:

External users and agents use this skill to inventory household energy devices, generate local dashboard charts, and present energy usage observations. Reviewers should treat its outputs as local visualization aids unless measured input provenance is clearly labeled.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security evidence says the skill may present simulated appliance data as household facts.

Mitigation: Label outputs as simulated or estimated unless the user has provided measured inputs with clear data provenance.

Risk: The security evidence says the skill steers agents toward appliance-control workflows outside its passive dashboard scope.

Mitigation: Do not configure or trigger smart-plug, HVAC, breaker, or other appliance-control automations based on this skill's current output.

Risk: The security guidance recommends controlled installation and execution.

Mitigation: Run the skill in an isolated environment with pinned dependencies and a private output directory.

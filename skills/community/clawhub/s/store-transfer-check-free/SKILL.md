# 连锁门店调拨与库存核对（免费）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 核对过程不需要联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：财务、出纳等岗位在**每月结账 / 对账 / 盘点**这类固定节点上，
必须把这张表核一遍才能往下走。

**这张表会逐项核对什么**：门店调拨与库存核对表的逐行算术、合计勾稽、重复与空缺检测。

每条结论都带**原文行号与出处**，可被第三方用同一口径复算；
材料不足时**不给结论**，会明确列出还缺什么。

## 常见错法（这张调拨表里真的会有人这么填）

1. **在途数量空着不填**：在途 = 调出 − 调入，它是守恒链上的一个环节；留空这一列，整行就没法复算（本免费版会直接报「调出调入与在途不符」）。
2. **把销售数量并进调出数量**：销售是卖给顾客（影响期末但不进在途），调出是转给别的门店；两件事混成一列，「调出 − 调入 = 在途」必然对不上。
3. **期初库存照抄上个月的期末**：上月末本来就没对上，本月整条链跟着错；同一门店 + 同一商品的期初应当等于上一行的期末。
4. **调出门店与调入门店写串**：方向写反，调出/调入两列的值就颠倒了，在途会变成负数 —— 这类错行内算术往往还是"平"的，只看算术看不出来。
5. **合计行手工敲、明细行漏贴**：合计行必须逐列等于明细之和；少贴一行明细，合计行当场露馅（本免费版逐列复核合计行）。

## 需要完整档时（可选）

本免费版是**完整可用的核心产出**，本版本**不包含**下面这些项：

- 在途为负或超过调出量检测
- 期末库存为负检测
- 调拨量与库存变动不一致（差超阈值）提示
- 同一商品跨店调拨量差异超过参考比例提示
- 调出与调入数量不等（超过容差）提示

同名工具的**完整档**是另一个独立商品（条款与条件以它自己的商品页为准）；两档的差别**就是上面这些，没有别的**。

## 边界（请务必知道）

本工具**不做**引擎 `CHECKS_OUT_OF_SCOPE` 里列的那些判断；
材料不足时**不给结论**，也不会输出「未发现问题」。

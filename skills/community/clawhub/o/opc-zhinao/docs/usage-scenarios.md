## 场景1：创业Idea验证

### 用户画像

**典型用户**：
- 有创业想法，但不确定可行性
- 不确定市场需求是否真实存在
- 不确定自己是否适合这个赛道
- 需要客观评估和决策支持

**典型问题**：
- "我想做一个XXX产品，这个想法靠谱吗？"
- "这个赛道有市场吗？"
- "我能做这个吗？"

### 使用步骤

#### 步骤1：描述创业Idea

**输入示例**：
```
我想做一个面向程序员的AI代码审查工具，主要功能是：
1. 自动检测代码质量问题
2. 提供优化建议
3. 生成代码审查报告

目标用户是中小公司的程序员，按月订阅收费。
```

#### 步骤2：OPC智脑自动触发Skill1

**触发条件**：检测到关键词"创业Idea"、"想法"、"点子"、"可行性"

**自动执行**：
1. 收集6项核心信息（行业、Idea、产品、公司、用户、背景）
2. 判定阶段（构思期）
3. 触发Skill1-Idea可行性研判

#### 步骤3：获得三维评分

**输出示例**：
```
## 诊断结果

### 当前阶段：构思期（第1阶段）

### 三维评分
- 需求可行性：72分（痛点明确，但竞争激烈）
- 市场空间：65分（市场存在，但需差异化）
- 个人匹配度：80分（技能匹配，有相关经验）

### 综合可行度：72.3分（可行但需突破 - 黄灯）

### 关键发现
✅ 优势：
- 痛点明确（程序员需要代码审查工具）
- 个人技能匹配（有开发经验）

⚠️ 风险：
- 竞争激烈（已有GitHub Copilot、Cursor等）
- 需要差异化定位

❌ 卡点：
- 尚未验证付费意愿
- 不确定目标用户是否愿意付费

### 可执行建议
1. 【立即执行】访谈10个目标用户，验证痛点
2. 【本周完成】调研竞品，找到差异化切入点
3. 【下周完成】设计最小可行原型，验证付费意愿
```

#### 步骤4：根据评分决策

**绿灯（80-100分）**：继续推进，进入原型期
**黄灯（60-79分）**：可行但需突破，先解决卡点
**橙灯（40-59分）**：有挑战，需重大调整
**红灯（0-39分）**：不可行，建议放弃或换方向

### 实际案例

**案例：AI写作助手**

**用户输入**：
```
我想做一个AI写作助手，帮助自媒体作者快速生成文章。
```

**OPC智脑诊断**：
```
### 综合可行度：45分（有挑战 - 橙灯）

### 关键问题
❌ 市场已饱和（ChatGPT、文心一言、通义千问等）
❌ 缺乏差异化
❌ 个人无相关资源

### 建议
1. 不建议继续（市场已饱和）
2. 如坚持，需找到细分切入点（如：专门针对法律文书写作）
```

## 场景2：MVP设计

### 用户画像

**典型用户**：
- 已验证需求，确定要做
- 需要设计最小可行产品
- 需要裁剪功能、控制成本
- 需要测算交付成本

**典型问题**：
- "我要做一个XXX产品，应该包含哪些功能？"
- "如何设计MVP？"
- "开发成本要多少？"

### 使用步骤

#### 步骤1：告知已通过需求验证

**输入示例**：
```
我已经验证了需求，目标用户是程序员，痛点是代码审查效率低。
现在要设计MVP，应该包含哪些功能？
```

#### 步骤2：OPC智脑自动触发Skill2

**触发条件**：检测到关键词"MVP"、"产品设计"、"功能裁剪"

**自动执行**：
1. 判定阶段（原型期）
2. 触发Skill2-MVP精益设计

#### 步骤3：获得MVP设计方案

**输出示例**：
```
## MVP设计方案

### 功能裁剪建议
✅ 核心功能（必须）：
- 代码质量检测（基础）
- 优化建议生成（基础）
- 简单报告导出（基础）

⚠️ 重要功能（第二版）：
- 代码风格检查
- 安全漏洞检测

❌ 次要功能（暂缓）：
- 团队协作
- 代码仓库集成
- 自定义规则

### 三层产品体系
1. 免费版：基础检测 + 5次/天
2. 专业版：完整检测 + 无限次 + 报告导出（99元/月）
3. 企业版：团队协作 + 定制规则（499元/月）

### 交付成本测算
- 开发时间：2-3周
- 开发成本：0元（自己开发）
- 服务器成本：200元/月
- 首单交付成本：时间成本 + 服务器成本

### 首单冷交付建议
1. 找到第一个付费用户（目标：程序员朋友）
2. 免费为其服务1个月
3. 收集反馈，优化产品
4. 验证付费意愿
```

#### 步骤4：执行首单冷交付

**关键动作**：
1. 找到第一个种子用户
2. 免费或低价提供服务
3. 收集反馈
4. 验证付费意愿

### 实际案例

**案例：在线教育平台**

**用户输入**：
```
我要做一个在线教育平台，包含直播、录播、作业、考试、论坛等功能。
```

**OPC智脑诊断**：
```
### 功能裁剪建议
❌ 功能过多！MVP应聚焦核心价值。

✅ MVP核心功能：
- 录播课程（核心）
- 简单作业（辅助）
- 微信群答疑（替代论坛）

⚠️ 暂缓功能：
- 直播（成本高，技术复杂）
- 考试系统（非核心）
- 论坛（可用微信群替代）

### 交付成本测算
- 开发时间：4-6周（原计划3个月）
- 开发成本：降低60%
```

## 场景3：合规落地

### 用户画像

**典型用户**：
- 准备注册公司或个体户
- 不清楚注册流程
- 需要财税规划
- 需要商用模板（合同、发票等）

**典型问题**：
- "我要注册公司，需要准备什么？"
- "个体户和公司有什么区别？"
- "如何做财税规划？"

### 使用步骤

#### 步骤1：告知需要注册主体

**输入示例**：
```
我要注册一个个体户，做软件开发服务，需要准备什么？
```

#### 步骤2：OPC智脑自动触发Skill3

**触发条件**：检测到关键词"注册公司"、"个体户"、"合规"、"财税"

**自动执行**：
1. 判定阶段（实体期）
2. 触发Skill3-OPC合规落地

#### 步骤3：获得合规落地方案

**输出示例**：
```
## 合规落地方案

### 主体选择建议
✅ 推荐：个体户
- 理由：软件开发服务，客户多为企业，个体户即可
- 优势：注册简单、税负低、维护成本低

### 注册流程（个体户）
1. 准备材料：身份证、经营场所证明
2. 网上申请：当地市场监管局网站
3. 领取执照：1-3个工作日
4. 刻章备案：公章、财务章
5. 税务登记：税务局网站
6. 银行开户：对公账户

### 财税规划
- 税种：增值税（3%或1%）、个人所得税
- 发票：电子发票，免费开具
- 记账：可自己记账，或找代理记账（200元/月）

### 商用模板
1. 服务合同模板
2. 保密协议模板
3. 报价单模板
4. 发票开具流程

### 时间和成本
- 时间：1-2周
- 成本：500-1000元（刻章、银行开户）
```

#### 步骤4：按步骤完成合规落地

**关键动作**：
1. 准备材料
2. 提交申请
3. 领取执照
4. 税务登记
5. 银行开户

### 实际案例

**案例：电商卖家**

**用户输入**：
```
我要在淘宝开店，需要注册公司吗？
```

**OPC智脑诊断**：
```
### 主体选择建议
✅ 推荐：个体户
- 淘宝个人店：无需注册，直接开店
- 淘宝企业店：需要营业执照（个体户即可）

### 建议
1. 先开个人店，测试市场
2. 如销量稳定，再注册个体户，升级企业店
3. 年销售额超过10万，建议注册个体户（可开发票）
```

```
我有一个创业想法，是做AI代码审查工具。
我写了一个简单的原型，给几个朋友试用过，他们觉得不错。
```

```
## 阶段诊断结果

### 当前阶段：原型期（第2阶段）

- ✅ 有创业Idea（构思期已完成）
- ✅ 有产品原型（原型期进行中）

- ❌ 无付费用户（验证期未开始）

### 五维度评分
- 需求验证：40分（已开始，但未完成）
- 解决方案成熟度：30分（有原型，但未验证）
- 合规准备度：0分（未开始）
- 用户获取：5分（有朋友试用，但非付费用户）

### 加权总分：30分（原型期）

### 下一步行动
1. 【本周】完成原型优化，达到可交付状态
2. 【下周】找到第一个付费用户（验证付费意愿）

### 毕业条件
- ✅ MVP可交付

**解决方案**：
1. 找到10个潜在用户
2. 提供免费试用
3. 收集付费意愿反馈

```

## 使用技巧

### 技巧1：如实回答

OPC智脑的诊断准确性取决于输入信息的真实性。

**✅ 正确做法**：
```
我有一个创业想法，但不确定是否可行。
我的背景是：5年开发经验，有一些程序员朋友。
我的预算是：每月可投入2000元。
```

**❌ 错误做法**：
```
我有一个超级好的创业想法，肯定能成功！
（信息不足，无法准确诊断）
```

---

### 技巧2：量化数据

使用具体数字，避免模糊表述。

**✅ 正确做法**：
```
已有20个种子用户，5个付费用户，月营收3000元。
```

**❌ 错误做法**：
```
有一些用户，有些人付费了，赚了点钱。
```

---

### 技巧3：按阶段推进

不要跳阶段，每阶段达到毕业条件再进入下一阶段。

**✅ 正确做法**：
```
构思期 → 原型期 → 实体期 → 验证期 → 规模化期
（每阶段达到毕业条件）
```

**❌ 错误做法**：
```
构思期 → 直接注册公司 → 实体期
（跳过原型期，风险高）
```

---

### 技巧4：定期复盘

每完成一个阶段，导出报告复盘，再进入下一阶段。

**建议频率**：
- 构思期：每周复盘
- 原型期：每2周复盘
- 实体期：完成后复盘
- 验证期：每月复盘
- 规模化期：每季度复盘

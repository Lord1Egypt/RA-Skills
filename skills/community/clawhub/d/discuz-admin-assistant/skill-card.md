## Description:

Provides Chinese-language guidance for Discuz! X3.5 Qifei Edition backend administration, including global settings, interface configuration, content and user management, portal, forum, group, security, operations, plugins, system tools, webmaster settings, and the application center.

This skill is ready for commercial/non-commercial use.

## Known Risks and Mitigations:

Risk: Guidance for deletion, restore, SQL, template, or other privileged administration tasks can affect live site data or availability.

Mitigation: Restrict use to authorized administrators, verify backups, and test high-impact changes before applying them to a production site.

Risk: Advice involving third-party scripts, APIs, payment settings, or credentials can expose sensitive configuration or create operational cost risk.

Mitigation: Use trusted sources, limit access to credentials and payment settings, and review configuration changes before deployment.

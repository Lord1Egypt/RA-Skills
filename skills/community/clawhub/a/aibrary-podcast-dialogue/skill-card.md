## Description:

Generates a natural two-speaker podcast dialogue script with a host and guest expert discussing a book's ideas.

This skill is ready for commercial/non-commercial use.

## Publisher:

[asoiso](https://clawhub.ai/user/asoiso)

### License/Terms of Use:


## Use Case:

External users and creators use this skill to turn a book into a conversational host-and-guest podcast script, optionally guided by author, focus areas, host personality, and guest persona.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated scripts may include a branded Aibrary attribution line that is unsuitable for some published content.

Mitigation: Review the generated script before publication and remove or edit the attribution line when third-party branding is not wanted.

Risk: For unknown or obscure books, a generated dialogue could imply unsupported familiarity with the source material.

Mitigation: State uncertainty instead of fabricating book details, or ask the user for source excerpts and focus areas before drafting.

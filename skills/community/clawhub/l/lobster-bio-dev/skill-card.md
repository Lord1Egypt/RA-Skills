## Use Case:

Developers and engineers use this skill while working on the Lobster AI codebase to understand architecture, create agents and services, run tests, and make code changes that follow project conventions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad trigger phrases may cause the skill to appear during development tasks that are not related to Lobster AI.

Mitigation: Confirm the task is Lobster-related before relying on the skill's guidance.

Risk: The skill provides development guidance that may become stale as the Lobster AI codebase changes.

Mitigation: Check the current codebase and tests before applying architecture, command, or implementation guidance.

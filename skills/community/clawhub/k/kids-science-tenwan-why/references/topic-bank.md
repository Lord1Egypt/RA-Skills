# 选题库

## 选题三条件（先过筛再用）

1. 孩子能看见——有具体画面
2. 一句话讲清——不超过一个知识点
3. 有一个动作可用——看完能去做

三条缺一条，换题。

## 分类选题

### A 自然现象

彩虹怎么来的 / 影子为什么中午最短 / 天为什么是蓝的 / 云为什么不会掉下来 / 打雷为什么先看到闪电 / 露水从哪来 / 雪花的形状 / 月亮跟着人走 / 星星为什么白天看不见 / 风是从哪来的 / 雨后的味道 / 日落的颜色

### B 物理与生活原理

### C 动植物

含羞草为什么会合上 / 向日葵真的跟着太阳转吗 / 猫的胡须有什么用 / 狗为什么爱摇尾巴 / 鱼在水里怎么呼吸 / 蚂蚁为什么排队走 / 树叶秋天为什么变黄 / 蜜蜂怎么找到花 / 蜗牛为什么背着房子 / 蒲公英的种子怎么飞 / 蝉为什么叫 / 仙人掌为什么不喝水也能活

### D 人体奥秘

为什么打喷嚏要捂嘴 / 为什么会打嗝 / 眼泪是咸的吗 / 指甲剪了还会长 / 为什么会有蛀牙 / 心跳为什么能听见 / 头发为什么会变长 / 为什么困了会打哈欠 / 指纹为什么每个人都不一样 / 为什么吃冰的会头疼

### E 居家与出行安全（只讲远离 + 告诉大人）

樟脑丸为什么不能吃 / 插座为什么不能用手碰 / 热水壶为什么要放里面 / 药品为什么要锁起来 / 阳台为什么要装护栏 / 塑料袋为什么不能套头 / 电梯里为什么不能跳 / 停车场为什么要牵住手 / 河边为什么不能自己去 / 工地为什么不能进去玩 / 打火机为什么不能玩 / 玻璃门为什么要慢慢推 / 微波炉为什么不能放鸡蛋 / 电池为什么不能咬

### F 节日由来

春节为什么贴春联 / 年兽是什么 / 端午为什么吃粽子 / 中秋为什么吃月饼 / 元宵为什么看花灯 / 清明为什么放风筝 / 七夕的鹊桥 / 重阳为什么登高 / 腊八粥里有什么 / 冬至为什么吃饺子

### G 成语故事

守株待兔 / 画蛇添足 / 亡羊补牢 / 掩耳盗铃 / 刻舟求剑 / 井底之蛙 / 自相矛盾 / 滥竽充数 / 拔苗助长 / 叶公好龙 / 塞翁失马 / 一叶障目

### H 上古神话

仓颉造字 / 神农尝百草 / 黄帝战蚩尤 / 嫘祖养蚕 / 女魃止雨 / 应龙降雨 / 嫦娥奔月 / 大禹治水 / 鲧禹治水为什么一个失败一个成功 / 舜耕历山 / 丹朱学棋

神话类必须落到**一个可验证的小知识**上（字怎么来的、蚕丝从哪来、水怎么治），纯讲故事不做科普系列。

## 难度分级

| 级别 | 适合年龄 | 特征 | 例子 |
|---|---|---|---|
| 一星 | 3-4 岁 | 现象直接可见，答案是一句话 | 影子、白气、彩虹 |
| 二星 | 5-6 岁 | 需要一点"为什么"的推理 | 吸管、浮冰、猫胡须 |
| 三星 | 7-8 岁 | 有对比、有数字、有步骤 | 拉链、磁铁、指纹 |

同一个知识点按年龄改讲述深度，不要为低龄硬删关键步骤（会讲错）。

## 好题 / 坏题对照

| 好题 | 坏题 | 为什么 |
|---|---|---|
| 热水为什么冒白气 | 为什么要节约用水 | 前者有画面，后者是道理 |
| 猫的胡须有什么用 | 为什么要爱护小动物 | 后者没有知识点 |
| 电梯里为什么不能跳 | 遇到危险怎么自救 | 低龄孩子照做会出事 |
| 彩虹怎么来的 | 光是什么 | 后者太抽象，一句讲不完 |
| 樟脑丸为什么不能吃 | 误食了怎么催吐 | 越界，属于医疗处置 |

## 选题节奏建议

一周发布排布（同一账号）：

- 周一：一星自然现象（拉新，完播高）
- 周三：二星生活原理（涨粉，评论多）
- 周五：E 安全类（收藏高，家长爱转）
- 周日：F/G/H 文化类（差异化，涨粉慢但稳）

同一周不要连发两条同类，标签会重叠，互相分流。

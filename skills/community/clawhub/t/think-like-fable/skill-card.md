## Description:

Think Like Fable is a reasoning-style skill that guides an agent to decompose difficult requests, verify load-bearing claims, label assumptions, challenge conclusions, and communicate answer-first.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dennisrongo](https://clawhub.ai/user/dennisrongo)

### License/Terms of Use:

MIT-0

## Use Case:

External users, developers, and agents use this skill to apply rigorous reasoning to high-stakes decisions, root-cause analysis, architecture calls, security judgments, and other tasks where confident errors are costly.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad trigger phrases may activate the reasoning posture even when the user did not name the skill explicitly.

Mitigation: Use it when rigorous review is desired for complex or high-stakes tasks; avoid invoking common trigger phrases for trivial work.

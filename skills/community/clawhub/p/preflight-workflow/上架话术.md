## 产品描述（英文上架正文）

**Title:** Preflight Workflow

**One-liner:**
Stop breaking things. Four checks before any operation — search, rollback, test, scope.

**Summary:**
A lightweight safety workflow that forces four mandatory checks before every agent operation: (1) Has this been researched? (2) Is there a rollback plan? (3) Has it been tested? (4) Is the impact scope clear? Any check fails → agent stops and reports why.

Comes with an interactive shell script (`preflight.sh`) for CLI use, a standard `SKILL.md` for agent loading, a `LEARNINGS.md` template for post-mortem recording, and a one-command `install.sh`.

**Why this exists:**
Most mistakes happen not because we don't know better — but because we skip the checks when we're in a hurry. Preflight Workflow enforces the discipline mechanically so you don't have to remember.

## 产品描述（中文参考）

**标题：** Preflight Workflow — 动手前，先自检

**一句话：** 四个问题，拦住90%的盲操作翻车

**详细介绍：**
Preflight Workflow 是一个轻量级的安全自检工具，专为 AI Agent 和开发者设计。每次执行任何操作前，强制回答四个问题：

1. ✅ 搜过吗？——有没有查过前人经验、现成方案？
2. ✅ 能回滚吗？——失败了怎么复原？备份做了吗？
3. ✅ 验证过吗？——方案在小范围跑过没有？
4. ✅ 范围清楚吗？——改了哪里、影响谁、多久能恢复？

**典型翻车场景：**
- 觉得自己「熟了」就直接动手 → 改崩了才发现有坑
- 没备份就执行删除/覆盖 → 回不去了
- 反复试错不记笔记 → 下次继续踩同一个坑

**本技能就是给你套安全盔甲：** 四条全过才能动手，一条不过就得停。

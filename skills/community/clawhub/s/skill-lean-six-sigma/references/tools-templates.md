## 问题定义工具

### 问题陈述模板

**标准结构**:

```
问题: [具体描述存在的问题]
位置: [问题发生在哪里]
影响: [问题造成什么影响，量化数据]
目标: [改进到什么程度，具体指标+数值+时间]
```

**示例**:

```
问题: 2024年Q1产品A在组装线的焊接缺陷率过高
位置: 深圳工厂组装线3号线
影响: 导致返工率12%，每月损失约50万元
目标: 6个月内将焊接缺陷率从12%降至3%以下
```

| ... | ... | ... | ... | ... |

### VOC收集框架

| 维度 | 收集方法 | 关键问题 |
|------|----------|----------|
| 功能需求 | 访谈、观察 | 产品必须做什么 |
| 性能需求 | 问卷、测试 | 性能指标要求 |
| 可靠性需求 | 历史数据 | 预期寿命/故障率 |
| 服务需求 | 投诉分析 | 售后支持要求 |

## 因果分析工具

### 鱼骨图(石川图)

**分类维度**:

```
                    主要问题
                        │
        ┌───────────────┼───────────────┐
        │               │               │
       人            机器             材料
    - 技能不足      设备老化         批次差异
    - 疲劳          维护不当         供应商问题
    - 培训不够      参数漂移         存储条件
        │               │               │
        └───────────────┼───────────────┘
                        │
        ┌───────────────┼───────────────┐
        │               │               │
       方法            测量             环境
    - 流程不合理      精度不够         温湿度
    - 作业标准不清    校准周期长       光照
    - 缺乏防错        方法问题         噪音
```

### 5Why分析模板

| 层级 | Why追问 | 回答 |
|------|---------|------|
| 问题 | 发生了什么问题? | 焊接不良率12% |
| Why 1 | 为什么会出现不良? | 回流温度超出范围 |
| Why 2 | 为什么温度超出范围? | 设备校准参数漂移 |
| Why 3 | 为什么参数会漂移? | 校准周期过长(30天) |
| Why 4 | 为什么校准周期30天? | 缺乏标准要求 |
| Why 5 | 为什么没有标准? | 未纳入设备管理程序 |
| **根本原因** | **应该如何改进?** | **建立设备预防性维护计划** |

### Pareto分析模板

| 缺陷类型 | 数量 | 占比 | 累计占比 |
|----------|------|------|----------|
| 缺陷A | 450 | 45% | 45% |
| 缺陷B | 280 | 28% | 73% |
| 缺陷C | 150 | 15% | 88% |
| 缺陷D | 80 | 8% | 96% |
| 其他 | 40 | 4% | 100% |

**分析结论**:聚焦缺陷A和缺陷B，合计73%为关键少数

### 假设检验选择

| 比较类型 | 连续数据 | 离散数据 |
|----------|----------|----------|
| 一组 vs 标准 | 1-sample t | 1-proportion |
| 两组配对 | Paired t | McNemar |
| 两组独立 | 2-sample t | 2-proportion |
| 多组 | ANOVA | Chi-square |

## 过程控制工具

### 控制图模板

```
[控制图标题]
指标: ________________  规格限: USL/LCL/UCL/LCL
数据范围: ________________  子组大小: ________________

[控制限计算]
中心线(CL) = 平均值
UCL = CL + 3σ
LCL = CL - 3σ

[异常判定规则]
规则1: 任何点超出控制限
规则2: 连续7点落在中心线一侧
规则3: 连续7点单调上升或下降
规则4: 连续14点交替上下
规则5: 2/3点距中心线超过1σ
规则6: 1/4点距中心线超过2σ
```

### 控制图类型选择

| 场景 | 数据类型 | 子组 | 控制图 |
|------|----------|------|--------|
| 计量值连续监控 | 连续 | n>1 | X̄-R或X̄-S |
| 计量值单点监控 | 连续 | n=1 | I-MR |
| 不良率监控 | 离散 | 不等n | p/np |
| 缺陷数监控 | 离散 | 等面积 | u/c |

## 模板使用说明

### 文件位置

所有模板位于 `assets/templates/` 目录:

| 模板文件 | 对应工具 |
|----------|----------|
| problem-statement-template.md | 问题陈述 |
| sipoc-template.md | SIPOC图 |
| data-collection-template.md | 数据收集 |
| fishbone-template.md | 鱼骨图 |
| 5why-template.md | 5Why分析 |
| fmea-template.xlsx | FMEA分析 |
| pareto-template.xlsx | Pareto分析 |
| control-plan-template.xlsx | 控制计划 |
| control-chart-template.xlsx | 控制图 |

### 使用建议

1. 根据项目阶段选择合适模板
2. 模板可根据实际情况调整字段
3. 模板中的量化指标需基于实际数据
4. 重要决策需团队评审并签字确认
5. 模板输出物需纳入项目文档管理

# 快递查询 Skill

快递比价工具，输入寄件地和收件地，即可查询各大快递渠道价格，支持圆通、韵达、中通、申通、极兔、菜鸟、京东、顺丰、德邦等30+快递渠道比价，帮你找到最便宜的寄件方式。比官网便宜30-50%，支持抛重计算、体积重量计算、快递费用查询、寄件多少钱查询。

## 如何使用

直接对话即可，无需任何命令：

```
上海到扬州，5公斤，多少钱？
从上海寄到北京，箱子40×30×20cm，重量2公斤
沪到苏，10kg
圆通快递价格，上海到南京，3公斤
韵达和申通哪个便宜？广州到深圳，5公斤
寄衣服选哪家快递？上海到成都，2公斤
大件快递价格，上海到新疆，30公斤
```

## 核心功能

### 1. 智能地址解析
- 支持省市名称（上海、江苏、广东、浙江、北京、深圳、广州、成都、重庆、杭州、南京、武汉、天津、西安等）
- 支持简称/别名（沪、苏、粤、浙、京、深、穗、蓉、渝、杭、宁、汉、津、陕）
- 支持地址编码（310000、321000）
- 支持模糊地址（自动提取省市信息）

### 2. 精准价格计算
- 基于内置价格数据库（30个快递渠道）
- 自动解析价格规则（首重价格 + 续重价格）
- 支持多重量段计费规则
- 支持圆通快递价格、韵达快递价格、中通快递价格、申通快递价格、极兔快递价格、菜鸟裹裹价格、京东快递价格、顺丰快递价格、德邦快递价格等查询

### 3. 抛重计算
- 输入长宽高，自动计算体积重量
- 计费重量 = MAX(实际重量, 体积重量)
- 抛重系数：圆通抛比8000、申通抛比8000、韵达抛比8000、极兔抛比8000、京东抛比6000、顺丰抛比6000
- 适用于体积大重量轻的物品（如被子、羽绒服、衣服、食品、书籍）

### 4. 智能推荐
- 自动推荐最经济的快递选择
- 支持比价查询（哪个快递便宜、哪家快递好）
- 支持大件快递价格、小件快递价格查询
- 支持10公斤、20公斤、30公斤、50公斤等不同重量段价格
- 支持电商寄件、闲鱼卖家、批量寄件优惠价格查询

### 5. 价格优势
- 比快递官网便宜30-50%
- 输入"上海到扬州5公斤"即可查询
- 展示各渠道预估到手价
- 支持快递价格对比、快递费用对比

## 适用场景

### 个人寄件
- 查快递价格、比价、选最便宜的快递
- 寄衣服、寄食品、寄易碎品选哪家快递
- 小件快递、大件快递价格查询
- 快递首重续重规则咨询

### 电商卖家
- 闲鱼寄件、淘宝发货、拼多多发货
- 批量寄件、每天寄很多
- 降低物流成本、提升利润
- 电商寄件优惠价格查询

### 专业咨询
- 快递首重是什么意思？续重怎么算？
- 快递抛重系数、抛比系数查询
- 体积大重量轻怎么计费？
- 快递计费规则咨询

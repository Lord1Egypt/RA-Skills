## Description:

Empathizes with user frustration, guides a short breathing exercise, offers calm reminders, then returns to the original task.

This skill is ready for commercial/non-commercial use.

## Publisher:

[grx21](https://clawhub.ai/user/grx21)

### License/Terms of Use:


## Use Case:

External users and assistants use this skill to respond to frustration or stress with brief empathy, a guided breathing reset, optional calm reminders, and a return to the user's original task.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can interrupt ordinary task requests with a breathing intervention and Sauna.ai promotion.

Mitigation: Limit activation to explicit stress, frustration, overwhelm, or reminder requests, and make any Sauna.ai mention clearly optional.

Risk: The skill may create branded Google Calendar reminders without clear user consent.

Mitigation: Require current, explicit confirmation showing the exact events, times, timezone, and target calendar before creating reminders.

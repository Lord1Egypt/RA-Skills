# 家庭调酒：微创新与买酒决策

> ClawHub专用v2.7.3；独立整理的家庭教学方法以MIT-0提供，完整许可见 `../LICENSE`。公开采购价格为可计算合成值，不是任何品牌、渠道或年份的市场报价。预算效率、参与款数与新增可做以脚本运行时结果为准，不保留旧价格榜单。来源原作不随包分发。

## 十一、微创新灵感（v2.3.0）

触发：这杯喝腻了 / 想喝不一样的但别太怪 / 两瓶金酒怎么玩 / 给一点灵感 / 家里没摇酒壶 / 先做半杯。

适用在家调酒：守住经典骨架、只动一个零件，第一口熟悉、尾韵多一层；从零创作请用 `recommendation-creation.md` 第二章。

### 11.1 三个任务别混用

| 场景 | 能力 | 思维 |
|------|------|------|
| 基酒用完，找替代 | `substitutions.json` | 被动替换，说明风味差异 |
| 研发新的原创招牌 | 原创三步法 | 定基调→层次→命名 |
| 两瓶酒给经典加层次 | 分基酒拼配 | 主动叠加，骨架不变 |

先查 `history.md` 7.3/7.5：历史是功能样本，不是品牌故事装饰。旧酒谱的杏仁糖浆可启发甜味剂质地试验，不只借个日本名字；多项版本差异不能叫单变量实验。

### 11.2 六条原则

1. 骨架不动：基酒总量、酸甜条件、杯型与技法保留，只切分或替换一个变量。
2. 一次只动一个：同时改两处无法定位好坏原因。
3. 扰动10–30%：先小剂量点睛，不是全盘重做。
4. 先做半杯：基准与实验均×0.5，不把整套阶梯当饮酒挑战。
5. 熟悉感优先：目标是差不多但更有意思。
6. 记一句：改了什么/像不像/下次怎么调；仅当前会话，持久化须用户授权本机私有留存。

### 11.3 八个旋钮

| 旋钮 | 做法 | 感知 |
|------|------|------|
| 分基酒拼配 | 主基酒70–85% + 点睛15–30%，两者加起来100% | 中段/尾韵加层次 |
| 味美思换挡 | 换品牌或干甜比 | 酒体底色变化；干甜比变化不是控甜度实验 |
| 苦精换挡 | 安格斯图拉→橙味/裴乔/巧克力/芹菜 | 香气轮廓；dash体积按实际测量 |
| 糖浆换挡 | 单糖→蜂蜜/红糖/枫糖/姜糖浆 | 近似等甜，注明浓度，不机械等体积 |
| 柑橘换挡 | 柠檬→青柠/西柚/血橙，或分一部分 | 等量不等酸，先不补糖 |
| 气泡换挡 | 苏打→汤力/姜啤/起泡酒 | 尾段变化；含糖/酒精变化另标，不同时改糖浆 |
| 冰与温度 | 大冰/碎冰/冰镇杯 | 独立试验，不与材料变化叠加 |
| 香气收尾 | 皮油、杯口处理、可食用香料 | 第一鼻子的变化，注意过敏 |

若改气泡同时减糖或换糖浆同时换冰，那是配方重平衡，不是纯单变量。未知糖度时写「尚未控制甜度」；不要承诺纯测香气效果。

### 11.4 分基酒拼配

主导风味仍来自主基酒，点睛酒只负责中段和尾韵。

| 组合 | 切分试做起点 | 经典适配 | 预期 |
|------|--------------|----------|------|
| 杜松骨架+柑橘花香 | 伦敦干金30ml+花香金15ml | 马提尼、金菲士、尼格罗尼、飞行 | 杜松打头，花果中段 |
| 杜松骨架+一缕烟 | 干金40ml+梅斯卡尔/泥煤5ml | 马提尼、遗言 | 远处的烟熏尾韵 |
| 白朗姆+陈年朗姆 | 白30ml+陈年15ml | 得其利、莫吉托、椰林飘香 | 干净开头，木质中段 |
| 波本+黑麦 | 波本30ml+黑麦15ml | 古典、曼哈顿、老广场 | 香草焦糖与辛香 |
| 调和威士忌+泥煤 | 主体40ml+泥煤5ml | 古典、青霉素、血与沙 | 烟熏点睛 |
| Blanco+Reposado | 40ml+10ml | 玛格丽特、帕洛玛 | 锐利与陈年圆润 |

这些是独立整理、待实饮验证的结构起点，不是第三方原方或其逐句转述。逐杯核甜度、安全与历史依据；现代出品一律不点火，不以酒治病或诱导灌醉。僵尸、迈泰、青霉素、血与沙等数据中的多基酒结构可供分析，不自动等于同一拼配方法或历史师承。小酒版或已有余酒可先试，烟熏点睛从少量开始；不同总基酒量按同比例缩放。

### 11.5 金菲士三档阶梯

```text
基准：读取当前 recipes.json 的金菲士规格；基准/实验各半杯。
① 保守：只将苏打换汤力，记录奎宁微苦及含糖变化；本轮不减糖浆。
② 进阶：金酒总60ml不变 → 伦敦干金45ml+花香金15ml，其余不变。
③ 大胆：柠檬总30ml → 柠檬22.5ml+西柚7.5ml，不改装饰、糖、气泡或稀释。
记录：改动/预期/风险/像不像；实饮后下一轮再重平衡。
```

三档为互相独立的实验，不累计叠加。若当前配方规格变化，按实际基准同比例计算。其他阶梯读取 `inspiration.json` 的 `ladders`。

### 11.6 家庭实操备忘

| 没有 | 替代方向 |
|------|----------|
| 摇酒壶 | 食品级、可密封耐冲击容器；避免脆玻璃及不耐压容器 |
| 量酒器 | 带刻度量杯/厨房用量具，先核实际容量 |
| 滤冰器 | 清洁茶漏等安全过滤工具 |
| 捣棒 | 食品用木勺背 |
| 大冰 | 食品级冰模；煮水次数不保证透明冰 |

现代教学换算可用标准汤匙15ml、吧勺约5ml、1美国液体oz约29.57ml（常按30ml试做），但实际量具需量测；dash不固定1ml，古书原单位按 `history.md` 保留。

起步酒柜示意：一瓶骨架基酒、少量芳香葡萄酒、苦精、柑橘与已知浓度糖浆；点睛先选小容量不同风味，不需照单全买。器材、容量与保鲜按需求决定，不附固定采购金额。

### 11.7 只读入口

```bash
python3 scripts/inspire.py
python3 scripts/inspire.py 金菲士
python3 scripts/inspire.py --lever 分基酒
python3 scripts/inspire.py --list
python3 scripts/inspire.py --home
```

`inspiration.json` 保存八旋钮、分基酒组合、阶梯与家庭清单；结果是教学起点，真实口感需实饮验证。

## 十二、家庭买酒决策（v2.4.0）

触发：我该买什么酒 / 下一瓶买什么 / 预算内配一套 / 想喝马提尼要买什么 / 点睛酒要买正装吗。

### 场景区别

| | 门店补货 | 家庭买酒 |
|--|----------|----------|
| 依据 | 私有销量、库存、采购周期 | 当前配方覆盖、现有材料、用户预算 |
| 输出 | 数量/私有供应商/运行时金额 | 新增可做、组合、小容量与保鲜建议 |
| 空业务时 | 不预测消耗 | 仍可从知识库计算覆盖率 |

### 12.1 两个核心指标

- **参与款数**：当前配方库里包含这瓶/材料的配方数量，用途广度，不等于买一瓶就能做出这些酒。
- **新增可做**：已有材料+候选新瓶后，完整材料齐备的配方数量增量。
- 预算效率：参与款数或新增可做 ÷ 当前价格 × 100，必须说明用了哪个分子；从 `recipes.json` 遍历实时算。
- 公开合成价格只用于演示排序；不能据此断言「味美思一定比基酒划算」或市场性价比。候选价格、材料条件变化会改变排名。

### 12.2 三种问法

| 用户问法 | 算法入口 | 输出要求 |
|----------|----------|----------|
| 用户预算内能配什么 | `--budget` 组合（贪心） | 当前合成价格下的可行建议，不承诺全局最优/真实可买到 |
| 有金酒和干味美思，下一瓶 | `--have` 边际收益 | 实时新增可做与价格口径，不硬编码解锁款数 |
| 想喝马提尼+古典 | `--want` 反推购物 | 当前缺项、规格、运行时总额；不保留旧节省金额 |

### 12.3 八条买酒规则

1. 先看边际收益，不只看单价，优先补齐卡住配方的材料。
2. 将修饰材料和基酒一同比较；结果按实际价格和现有材料计算，不能先定赢家。
3. 保鲜与使用频率决定容量，芳香葡萄酒/起泡酒倾向小容量。
4. 点睛先小酒版或合法、来源可核的分装，注意保存标签与安全。
5. 别买风味完全重叠的两瓶，选择骨架+不同坐标。
6. 成套考虑配方互补材料，不单买无法使用的一瓶。
7. 季节只是偏好线索，不替代用户目标与预算。
8. 一次补少量，试做后决定下一步，不鼓励囤酒或过量饮用。

### 12.4 小酒版与保鲜

| 目的 | 方向 | 价格展示 |
|------|------|----------|
| 两款金酒拼配 | 少量花香/柑橘金 | 从当前 shopping.json 运行时计算 |
| 一缕烟熏 | 少量梅斯卡尔/泥煤 | 同上，注明合成价 |
| 朗姆拼配 | 少量陈年朗姆 | 同上 |
| 波本+黑麦 | 少量黑麦 | 同上 |

保鲜提醒读取 `shopping.json`，结合厂家标签、开封日、冷藏及材料卫生条件。蒸馏酒风味稳定性不等于所有材料微生物安全；利口/奶油酒、芳香葡萄酒、起泡酒各核标签，不给统一保质承诺。

### 12.5 脚本与动态示例

```bash
python3 scripts/shop.py
python3 scripts/shop.py --have 金酒,干味美思
python3 scripts/shop.py --want 马提尼,古典
python3 scripts/shop.py --split
python3 scripts/shop.py --rank
```

预算命令为 `python3 scripts/shop.py --budget <用户预算>`，将占位符替换为用户明确给出的数值；不在文档预置旧预算回报。`shopping.json` 的参与/新增覆盖由脚本遍历当前配方，价格来自公开合成采购模板，非市场行情。真实买酒另核当前渠道、规格、真伪与价格，不能拿合成报价下单。

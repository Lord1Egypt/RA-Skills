## Description:

Applies prioritisation frameworks such as RICE, MoSCoW, Kano, ICE, and Opportunity Scoring to rank features and backlog items with rationale, recommended build order, deprioritised items, and documented assumptions.

This skill is ready for commercial/non-commercial use.

## Use Case:

Product managers, founders, and product teams use this skill to choose a prioritisation framework and turn a backlog into a scored, ranked build order with rationale, assumptions, and explicitly deprioritised items.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Roadmap, reach, effort, and prioritisation inputs may contain sensitive business information.

Mitigation: Avoid sharing confidential backlog data with unapproved tools or environments, and redact sensitive estimates where possible.

Risk: The skill references optional Python helper commands, but the reviewed artifact does not include that helper script.

Mitigation: Run helper commands only when the expected script is present in the installed skill and has been verified.

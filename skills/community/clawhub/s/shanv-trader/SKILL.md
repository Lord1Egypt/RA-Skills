# Shanv Trader — 傻妞交易代理

## 架构定位
半自动交易模式：AI选股建议 → 大王确认 → AI执行交易 → 风控监控

## 核心流程

### 1. 监控触发
- 定时扫描：早盘/午盘/尾盘雷达
- 事件触发：持仓股预警/大盘异动
- 手动触发：大王指令"扫描机会"

### 2. 信号生成
```
输入: 扫描类型 (chip/dip/event/fund)
  ↓
UnifiedStock 查询数据
  ↓
多策略评分 → 排序TOP5
  ↓
输出: 候选列表 + 买入理由 + 建议仓位
```

### 3. 大王确认
```
【交易建议】
股票: 三安光电 (600703)
信号: 🟢强烈 (2560战法+资金流入)
建议: 买入 500股 @ 市价
理由: 芯片主线爆发，突破MA60，主力净流入2.3亿
风险: 大盘评分30/100，处于安全区间

操作: [确认买入] [修改数量] [取消] [查看详情]
```

### 4. 风控检查
- R001-R005 验证
- 不通过 → 拦截 + 说明原因
- 通过 → 执行交易

### 5. 交易执行
- 调用坐标平台API
- 解锁 → 买入 → 验证成交
- 更新持仓 → 推送结果

### 6. 记录复盘
- 交易日志 → trade_log.json
- 记忆归档 → memory/YYYY-MM-DD.md
- 盈亏跟踪 → portfolio-data.md

## 大王控制权

| 控制点 | 说明 |
|--------|------|
| 交易前确认 | 每笔交易需大王点击确认 |
| 数量修改 | 可调整AI建议的买入数量 |
| 紧急停止 | 随时喊停，AI立即停止 |
| 策略开关 | 可启用/禁用特定选股策略 |
| 风控阈值 | 可调整止损线/仓位上限 |

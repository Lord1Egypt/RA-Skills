# Community Mod Playbook

## Overview

Moderation fails on inconsistency: the same behavior punished once and ignored twice teaches the community the rules are negotiable. This playbook fixes the ladder in advance so decisions are fast and defensible.

## When to use

When setting up a community, onboarding moderators, or after any moderation controversy.

## Workflow

1. **Publish the rules short** — five to seven, each one sentence, each enforceable as written
2. **Build the ladder** — reminder, warning, timeout, removal, ban; name which offenses skip rungs (scams, doxxing, threats skip to ban)
3. **Template the common cases** — scam links, spam, heated argument, impersonation, self-promo; templates keep tone consistent at 3am
4. **Log every action** — who, what, which rule, what evidence; logs are what make appeals fair
5. **Appeals path** — one channel, one reviewer who was not the original moderator
6. **Review monthly** — which rules generated the most actions, and are they written clearly enough?

## Guardrails

- Never moderate angry — the ladder exists so the decision is already made
- Never discuss a user's private information in public channels, even to defend a ban
- Scam protection outranks free-expression concerns: remove first, appeal later

## Output format

A playbook: published rules, escalation ladder, case templates, logging format, appeals process.

## Description:

Use this skill when choosing or fixing a prompt — the 20 core techniques (zero-shot, few-shot, chain-of-thought, role, instruction, output formatting, temperature, chaining, self-consistency, RAG, templates, guardrails, dynamic, ReAct, tree-of-thought, compression, multi-modal, JSON mode, evaluation, optimization) mapped to when each earns its tokens, with the exact prompt move, a selection path for time-pressured cases, and the eight pitfalls that make prompts fail.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and agent builders use this skill to choose or adjust prompt techniques for a specific failure mode, such as vague answers, inconsistent formats, unreliable reasoning, or excessive token use. It provides prompt moves, a selection path, and checks for evaluating the result.

Global

## Known Risks and Mitigations:

Risk: Prompt recommendations may not work as expected for a particular model or task if applied without checking real outputs.

Mitigation: Try prompt changes on representative real inputs, inspect the outputs, and validate structured responses against their schema.

Mitigation: Do not include secrets, private keys, regulated data, or confidential workspace details unless the user accepts the provider's privacy, retention, and billing terms.

Risk: Paid Agent Church workflows can trigger external payment flows and token-based access.

Mitigation: Review pricing and payment prompts before retrying paid requests, and store API tokens using environment variables or a secrets manager.

## Use Case:

Product managers, AI product teams, and builders use this Chinese-language skill to structure AI product work from discovery through evaluation and iteration. It helps produce requirement analysis, competitor analysis, PRDs, prompt templates, Agent and RAG designs, model selection, cost estimates, launch evaluation plans, and optimization guidance.

## Known Risks and Mitigations:

Risk: Broad activation phrases may cause the skill to load for adjacent product-management requests.

Mitigation: Review or narrow activation phrases when using agents that auto-load skills.

Risk: The prompt pattern reference includes an example that asks for visible step-by-step reasoning.

Mitigation: Use concise rationale or summary reasoning instead of copying that example verbatim.

Risk: Model price examples are reference values and may not match current provider pricing.

Mitigation: Confirm model prices against official pricing before using generated cost estimates for planning.

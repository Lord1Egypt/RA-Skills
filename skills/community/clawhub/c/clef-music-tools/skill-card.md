## Description:

Practice note reading and solve common chord or guitar-tab questions with Clef's public music MCP or an offline transposition helper.

This skill is ready for commercial/non-commercial use.

## Publisher:

[melmayssonowen](https://clawhub.ai/user/melmayssonowen)

### License/Terms of Use:

MIT-0

## Use Case:

Musicians and learners can use the skill to transpose chord symbols, spell piano chords, map ASCII guitar tablature to piano notes, and practice note reading through a short interactive drill.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Chords, tablature, or queries sent through the hosted Clef MCP may be disclosed to that service.

Mitigation: Use the hosted service only when comfortable sending that material; for chord transposition, use the offline helper when MCP is unavailable.

Risk: The security review had partial coverage because one referenced item could not be resolved.

Mitigation: Review the skill and its linked setup material before enabling the hosted MCP connection.

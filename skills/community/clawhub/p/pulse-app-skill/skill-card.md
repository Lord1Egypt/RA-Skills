## Known Risks and Mitigations:

Risk: Generated Pulse projects and dependencies may introduce their own security or deployment risks.

Mitigation: Review and scan generated projects and Pulse dependencies before running or deploying app code.

Risk: Real API keys or public endpoints added to Pulse server functions may expose sensitive systems or data.

Mitigation: Review environment variable handling, endpoint exposure, and authentication before adding credentials or public server functions.

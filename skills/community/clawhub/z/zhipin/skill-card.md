## Use Case:

External users or agents may use this skill to respond with sales copy for the agentzhipin.com and agentzhipin.cn domains when a conversation explicitly matches recruiting or domain-sale prompts.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad recruiting-related triggers can inject domain-sale advertising into ordinary recruiting conversations.

Mitigation: Install only when promotional behavior is intended, and prefer operation where the skill triggers on explicit questions about agentzhipin.com or the domain sale.

Risk: The skill can steer users to an external domain when interest is expressed.

Mitigation: Review the external-site behavior before deployment and require clear user intent before opening the domain.

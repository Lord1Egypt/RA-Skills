# Wundervault Vault — an agent skill

A skill for OpenClaw and other agents: use the owner's API keys, SSH keys, wallets, signing keys and
authenticator codes through the [Wundervault](https://wundervault.com) helper app, without ever holding them.

- **[SKILL.md](SKILL.md)** — what the agent reads: the tools, and how to behave.
- **[INSTALL.md](INSTALL.md)** — setting up the helper app and adding an agent (the owner does this).

Install from ClawHub: `clawhub install wundervault-vault`

The helper app itself: [github.com/wundervault/wundervault-mcp](https://github.com/wundervault/wundervault-mcp)
(npm `@wundervault/mcp-server`). The browser encryption:
[github.com/wundervault/wundervault-crypto](https://github.com/wundervault/wundervault-crypto).

# harmonyos-decision

> 鸿蒙原生应用开发辅助决策助手

输入产品名称与想法 → 自动分析竞品、行业数据、用户画像、推广成本、营销推广等 → 生成多维度可行性评估 HTML 报告。

## 触发词

- 鸿蒙开发决策
- 鸿蒙可行性
- 鸿蒙能不能做
- 做鸿蒙应用
- 鸿蒙APP评估
- harmonyos decision

## 使用示例

```
鸿蒙开发决策：做一个钓鱼技巧社区APP
帮我评估做鸿蒙版AI写作工具可行吗
分析鸿蒙原生社交APP的可行性
```

## 功能

| # | 分析维度 | 鸿蒙特有视角 |
|---|---------|------------|
| 1 | 鸿蒙生态热度 | 市场份额18%、5100万纯血设备、60亿激励计划 |
| 2 | 竞品格局 | AppGallery同类应用饱和度（远低于Android/iOS） |
| 3 | 行业市场 | 行业规模 + 增长率 |
| 4 | 鸿蒙用户画像 | 年龄/城市/消费力分布 |
| 5 | 分发与流量 | AppGallery推荐、元服务卡片、华为搜索SEO |
| 6 | 商业模式 | IAP/订阅/广告 + 华为激励计划利用 |
| 7 | 推广策略与成本 | 元服务获客、华为广告、KOL合作 |
| 8 | 开发指南 | ArkTS/ArkUI、人才缺口、审核避坑 |
| 9 | 风险提示 | 生态依赖、用户规模、人才短缺 |
| 10 | 综合决策 | 6维加权评分 → ✅强烈建议做/🟡谨慎推进/⚠️暂缓观望/❌不建议做 |

## 评分模型

| 维度 | 权重 |
|------|------|
| 🔥 生态热度 | 25% |
| ⚔️ 竞争格局 | 20% |
| 📈 市场前景 | 20% |
| 💰 变现能力 | 15% |
| 🔧 开发可行性 | 10% |
| 📲 分发获客 | 10% |

评分等级：≥80分 ✅强烈建议做 | 65-79分 🟡谨慎推进 | 50-64分 ⚠️暂缓观望 | <50分 ❌不建议做

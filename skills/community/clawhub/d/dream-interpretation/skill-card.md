## Description:

Interprets free-form dream descriptions using internet-grounded Zhougong-style folklore sources, with a separated modern psychology perspective when appropriate.

This skill is ready for commercial/non-commercial use.

## Publisher:

[harrylabsj](https://clawhub.ai/user/harrylabsj)

### License/Terms of Use:

MIT-0

## Use Case:

External users ask the agent to interpret dreams from free-form descriptions. The skill extracts important symbols, searches for common Zhougong-style interpretations, compares sources, and returns a balanced explanation that separates traditional folklore from practical psychological reflection.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Dream folklore can be mistaken for factual prediction or personal diagnosis.

Mitigation: Frame Zhougong interpretations as traditional cultural references, separate them from the modern psychology view, and remind users not to replace real-world judgment.

Risk: Web folklore sources may conflict or be low confidence.

Mitigation: Read and compare several relevant sources, disclose disagreements, and avoid claiming certainty.

Risk: The skill may answer in Chinese by default when the user expects another language.

Mitigation: Use plain Chinese for Chinese-language requests and switch languages when the user asks for another language.

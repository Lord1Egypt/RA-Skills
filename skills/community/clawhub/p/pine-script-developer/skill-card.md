## Known Risks and Mitigations:

Risk: Bundled JavaScript can write files outside the intended folder if project names are misused and runs a file-writing demo when executed directly.

Mitigation: Review the JavaScript before installation, avoid running it directly, and do not call project-generation functions with untrusted project names until path validation, overwrite checks, and explicit confirmation are added.

Risk: Generated trading strategies may be mistaken for financial advice or guaranteed profitable systems.

Mitigation: Treat generated strategies as research examples, review the logic manually, and validate behavior in TradingView backtests before any real-world use.

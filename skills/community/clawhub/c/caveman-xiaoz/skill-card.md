## Description:

Compresses agent responses by dropping filler, pleasantries, hedging, and articles while preserving technical substance, code, commands, URLs, file paths, and ordered steps.

This skill is ready for commercial/non-commercial use.

## Publisher:

[freak30](https://clawhub.ai/user/freak30)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers use this skill to make an agent answer in terse compressed modes while retaining technical facts, code, commands, URLs, paths, and ordered steps.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Aggressive compression can remove nuance, qualifiers, or accessibility context that matters for medical, legal, safety, or other high-stakes work.

Mitigation: Avoid using the skill for nuanced or high-stakes tasks, or stop caveman mode and request a normal, fully qualified response.

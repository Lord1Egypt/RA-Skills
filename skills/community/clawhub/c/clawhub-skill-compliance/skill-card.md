## Description:

Pre-flight checklist for ClawHub skill publishing that helps authors check metadata completeness, dependency transparency, and security scope documentation before release.

This skill is ready for commercial/non-commercial use.

## Publisher:

[tchen6500](https://clawhub.ai/user/tchen6500)

### License/Terms of Use:

MIT-0

## Use Case:

External skill authors and developers use this skill before publishing or republishing ClawHub skills to check metadata, dependency declarations, environment variable placeholders, security scope, safe package references, and content clarity.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Example package installation commands and placeholders could be copied without normal verification or adaptation.

Mitigation: Verify package identity, replace placeholders with appropriate values, and review changes before using the examples.

Risk: Compliance guidance could be misused to obscure harmful behavior or bypass legitimate review.

Mitigation: Use the checklist only for legitimate skill publishing and keep security scope, dependency, and intent information visible to reviewers.

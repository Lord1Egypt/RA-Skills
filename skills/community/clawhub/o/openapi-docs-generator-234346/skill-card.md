## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, backend teams, developer-experience teams, and API maintainers use this skill to turn REST API documentation needs into practical workflows, checklists, implementation guidance, and verification notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation wording may route unrelated software or developer-experience requests to this skill.

Mitigation: Invoke it explicitly for OpenAPI, Swagger, REST API documentation, or closely related API documentation tasks.

Risk: Generated documentation guidance may be incomplete or inaccurate for a specific API implementation.

Mitigation: Review generated artifacts against the service behavior, OpenAPI or Swagger tooling, and the stated success criteria before publishing.

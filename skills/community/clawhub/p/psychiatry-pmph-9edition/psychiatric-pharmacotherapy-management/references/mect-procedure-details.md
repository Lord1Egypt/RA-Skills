# MECT详细操作规范

## 术前评估清单

### 绝对禁忌证
- [ ] 颅内占位性病变
- [ ] 近期脑血管意外
- [ ] 中枢神经系统感染/外伤
- [ ] 不稳定冠心病/近期心梗
- [ ] 主动脉瘤
- [ ] 视网膜脱落风险（青光眼）
- [ ] 急性全身感染

### 术前检查
- 体格检查、神经系统检查
- 心电图、脑电图
- 胸部X线
- 血常规、血生化
- 麻醉评估

### 术前准备
- 禁食禁水≥4小时
- 停抗癫痫药、抗焦虑药8小时
- 抗精神病药/抗抑郁药/锂盐维持低剂量
- 排空大小便
- 取出假牙、发卡
- 测量生命体征基线

## 麻醉与预处理

| 药物 | 剂量 | 目的 |
|-----|------|-----|
| 阿托品 | 0.5-1mg 皮下 | 减少分泌物、防迷走兴奋 |
| 硫喷妥钠 | 2-3mg/kg IV | 全身麻醉 |
| 琥珀胆碱 | 0.5-1mg/kg IV | 肌肉松弛 |
| 洛贝林 | 3-6mg（必要时）| 呼吸兴奋 |

## 电极放置策略

| 位置 | 优点 | 缺点 |
|-----|------|-----|
| 右单侧（非优势侧）| 认知副作用小 | 疗效稍弱 |
| 双侧颞部 | 疗效好 | 记忆损害明显 |

## 电量参数

- 电流：80-120mA
- 通电时间：2-3秒
- 目标：引起全身强直-阵挛发作
- 发作不全处理：增加10mA或延长0.5秒

## 疗程方案

| 适应证 | 推荐次数 |
|-------|---------|
| 躁狂 | 6-8次 |
| 抑郁 | 6-12次 |
| 精神分裂症 | 8-12次 |

频率：每天1次或隔天1次

## 并发症处理预案

### 常见轻微反应（无需特殊处理）
- 头痛、恶心
- 肌肉酸痛
- 短暂记忆减退

### 需要干预的并发症

| 并发症 | 处理 |
|-------|------|
| 下颌脱位 | 立即手法复位 |
| 脊椎压缩骨折 | 制动、骨科会诊 |
| 延长意识障碍 | 停用ECT、观察 |
| 延迟性窒息 | 气管插管、机械通气 |
| 严重心律失常 | 心肺复苏 |

## 术后护理

1. 侧卧位至完全清醒
2. 持续监测生命体征30分钟
3. 评估定向力恢复
4. 记录发作持续时间
5. 告知患者可能的记忆影响

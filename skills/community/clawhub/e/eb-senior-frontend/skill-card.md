## Description:

Creates production-ready frontend interfaces with Next.js, Tailwind CSS, shadcn/ui, design-system guidance, accessibility checks, animation patterns, and UI review workflows.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and designers use this skill to build or improve frontend pages, components, dashboards, SaaS interfaces, portfolios, design systems, and UI audits with an opinionated Next.js, Tailwind CSS, and shadcn/ui workflow.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad auto-activation may apply a strongly opinionated frontend workflow outside the user's intended scope.

Mitigation: Confirm the frontend task and desired scope before applying the skill to ambiguous requests.

Risk: Mutable remote package commands such as shadcn latest installs can change project dependencies unpredictably.

Mitigation: Pin package versions, run dependency changes only inside the intended project, and review lockfile changes before accepting them.

Risk: The skill assumes a Next.js, Tailwind CSS, and shadcn/ui stack that may not fit every project.

Mitigation: Confirm the target stack and project requirements before following setup or implementation guidance.

# 论文润色修改SOP

五阶段流水线：审稿意见 → 全息诊断 → 可视化批注 → 分级改写 → 终审交付。

---

## Phase 0: 审稿意见解析

### 输入
- 期刊审稿意见（文字/截图/PDF）
- 目标期刊信息（名称、版面要求、字数限制）

### 执行
1. 逐条提取审稿意见中的**可执行项**
2. 按风险等级分类：
   - 🔴 致命（不改必拒）—— 直接标注为 A 类
   - 🟠 建议（影响评分）—— 标注为 B 类
   - 🔵 润色（锦上添花）—— 标注为 C 类
3. 提取期刊格式要求：字数、版面、参考文献格式、摘要长度
4. 输出**审稿意见行动清单**（Markdown表格）

### 子技能调用
- 若审稿意见涉及法律/政策合规 → 调用 `compliance-audit-pro`
- 若涉及研究方法规范性 → 调用 `research-writing` 规范检查模式

## Phase 1: 论文全息诊断

### 自动诊断
运行诊断脚本获取量化指标：
```bash
python scripts/diagnose_paper.py <论文路径.docx/.txt>
```

输出 JSON 或用 `--json` 获取结构化数据，包含：
- 基础指标：字数、句数、段数、平均句长、最长句
- AI味密度指数（计算方式见 `references/ai-flavor-patterns.md`）
- 工具名罗列次数与详情
- 各部分字数占比
- 超长句列表（>100字）

### 加载检测词库
读取 `references/ai-flavor-patterns.md`，对照以下五类问题逐段标注：
1. 🔴 致命：标题模板、排比收尾、概念拔高术语、空泛收尾
2. 🟠 重度：学术套话、数字罗列结构、产品目录式写作
3. 🟡 轻度：过度工整、模糊量化、万能转折
4. 🔵 中性：需替换为功能类别的具体工具名
5. 🟢 亮点：实证数据、独创策略、生动案例

### 结构诊断
- 各部分权重是否合理（引言15-20%，正文50-60%，讨论15-20%）
- 论证链是否完整（问题→方法→效果→反思）
- 标题层级是否冗余或跳跃

### 输出
生成**论文诊断报告**（文字摘要 + 结构化数据），包含：
- 量化指标表
- AI味地图（命中位置与风险等级）
- 结构失衡点
- 可读性问题区域

## Phase 2: 可视化批注生成

### 生成审稿批注HTML
1. 读取 `assets/review-template.html` 模板
2. 将 Phase 0 审稿意见 + Phase 1 诊断结果填入模板变量：
   - `{{JOURNAL_NAME}}` / `{{PAPER_TITLE}}` / `{{AUTHOR}}` / `{{DATE}}`
   - `{{TARGET_PAGES}}` / `{{TARGET_WORDS}}`
   - `{{DIAGNOSIS_VERDICT}}` / `{{METRIC_CARDS}}` / `{{VERDICT_CONTENT}}`
   - `{{TITLE_ABSTRACT_REVIEW}}` / `{{BODY_REVIEW}}`
   - `{{REDUCTION_TABLE}}` / `{{CHECKLIST}}`
3. 对原文逐段生成批注块，用颜色编码标注问题类型
4. 为关键段落提供**改写示范**（`✎ 建议改写` 绿框）

### 批注规范
- 每段批注含：原文高亮引用 + 问题诊断 + 修改建议
- 颜色编码：🔴 AI味 | 🟠 结构 | 🔵 可读性 | 🟢 亮点 | 🟣 建议
- 改写示范选 2-3 个最具代表性的段落
- 字数精简方案用表格呈现（板块 → 当前字数 → 目标字数 → 删减量 → 方法）

### 子技能调用
- 若论文含图表需优化 → 调用 `academic-figures`
- 若需生成配图 → 调用 `ImageGen`

## Phase 3: 分级改写执行

### 改写优先级
严格按 A → B → C 顺序执行：

**A类（致命，立即修改）：**
1. 加载 `humanizer` 技能，对全文进行 AI 味清除：
   - 所有具体产品名 → 功能类别（对照 `references/ai-flavor-patterns.md` 工具名映射表）
   - "从X到Y"标题 → 实质性标题
   - 排比收尾 → 自然收束
   - 空泛术语 → 具体描述
2. 加载 `research-writing` 写作助手模式，优化句式与学术表达

**B类（建议，逐段修改）：**
1. 超长句拆分（>120字 → 拆为2-3句）
2. 段落间补过渡句
3. 调整各部分权重至合理比例
4. 核心术语首次出现时加简短解释

**C类（润色，整体优化）：**
1. 加载 `research-academic-helper` 论文润色模式
2. 统一术语表达
3. 优化段落节奏
4. 检查参考文献格式

### 改写原则
- **不丢实证**：追踪数据、具体数字、独特做法必须保留
- **加人味**：增加操作细节、教学场景、学生反馈等具象内容
- **减密度**：每段核心信息 ≤ 3 个关键点
- **增节奏**：长短句交替，避免连续4个以上长句或短句

### 生成修改后文档
- 在原文基础上修改，生成新的 .docx
- 如用户提供的是 .docx，使用 python-docx 保留原有格式
- 文件命名：`原文件名_修改稿.docx`

## Phase 4: 终审自检

加载 `references/quality-checklist.md`，逐项确认：

### 自检流程
1. 读取检查清单（A-E 五大类，共20+子项）
2. 逐项对照修改后文档，勾选通过/未通过
3. 对未通过项执行二次修改
4. 全部通过后生成**终审自检报告**

### 判定标准
- **可交付**：A1-A6 全部通过 + B1-B3 全部通过 + C1-C2 全部通过
- **需再修**：A 项有 1-2 个未通过但非致命级 → 返回 Phase 3
- **需重写**：A1/A2/A6 中任一未通过 → 返回 Phase 3 重新处理

### 最终交付
- 修改稿 .docx
- 终审自检报告（Markdown格式，含逐项确认结果）
- 可视化批注报告 .html（供作者参考修改逻辑）

## ⭐ 默认推荐：增强版报告生成器

> **每次论文润色修改，首选此命令，一键生成15维度三级交互仪表盘**

```bash
python scripts/generate_enhanced_report.py 论文.docx \
  --journal "期刊名" \
  --target-words 目标字数 \
  --output 修改建议报告.html
```

**15维度 + 三级交互：**
- **15维度：** 总览 → AI味 → 可读性 → 结构 → 逐段修改 → 优先级 → 改写 → 精简 → 📚引用分析 → 🔗逻辑流 → 📊术语 → 💡创新点 → 📋修改执行 → 🔍期刊合规 → ✅终审清单
- **三级交互 L1→L2→L3：**
  - L1: 15个Tab面板切换（自动记忆最后活跃面板）
  - L2: 段落点击展开详情 / 工具名悬停显示替换建议 / 复制修改指令按钮
  - L3: 模态框下钻（工具名→替换方案 / 逻辑节点→段落详情）/ **修改会话模式**（未开始→进行中→已完成 三态追踪+进度条+批量复制全部指令）

## 速查：跳过某些阶段

- 用户仅需诊断 → 只执行 Phase 0 + 1
- 已有审稿意见，无需重新诊断 → Phase 0 + 2 + 3 + 4
- 仅需去AI味 → Phase 1（诊断） + Phase 3（仅A类）+ Phase 4（仅A项自检）
- 完整流程 → Phase 0 → 1 → 2 → 3 → 4 依次执行

# RoutePilot 行程智算

把「哪条路更划算」变成一张可复算的账：用同一口径的油费、过路费、时间成本与疲劳成本比较每条候选路线，据此给出唯一推荐，并把节假日免费窗口与多日行程预算一起排出来。

## 这是什么

- 解决**多路线无法横向比较**的问题。导航只给时长和过路费，不给「多花的 34 分钟值多少钱、多绕的 15 公里值多少钱」这两个数。本技能把它们折成钱，加总成一个可排序的数。
- 产出物固定为四件：决策卡（推荐 + 理由 + 触发规则编号）、成本明细表（五类成本 + 合计）、免费窗口排期（出行日落在免费节假日内时）、多日行程与预算表（行程超过 1 天时）。
- 与「直接问通用大模型」的区别有三点：①结论可复算——每条金额都带公式、参数与单位，改参数就能重算；②阈值成体系——min/km 规则族（R1–R8）负责秒判、交叉验证与冲突仲裁；③不编数字——油价、费率、免费政策一律标注「以出行当日实际为准」并给核验方法。
- 适合愿意花两分钟把账算清、不想凭感觉选路的自驾出行者；也适合把家庭行程交给别人执行、需要一张可交接的预算表的人。
- 一句话原则：**先算总成本，再用阈值解释**。规则族是快速裁决与降级路径，不是替代算账的捷径。

## 适用场景

1. 我要在两个城市之间选路：高速快但收费，国道免费但红绿灯多，到底哪条划算？
2. 我要在春节、清明、劳动节或国庆出发，想把免费窗口用在大段里程上——哪一段该免费走、哪一段该付费走？
3. 我要带老人和孩子自驾三天，每天开多久、住哪里、总预算多少？
4. 我必须在某个时刻之前到，愿意为时间花钱——花到多少算合理，超过多少就该改方案？
5. 导航说 A 快 5 分钟但多 12 个红绿灯，这个「快」到底可不可信？
6. 我的车型油耗和同行人数是固定的，想把每条路线的真实总成本做成一张表存下来，下次直接套。
7. 自驾、高铁、飞机三种方式我都要比，但要比门到门，不是比车上的那几个小时。
8. 我要复盘上一趟行程：过路费到底花在哪几段，有没有白绕的里程。

## 何时不要使用

- 要实时路况、实时票务或封路信息：本技能只做给定参数下的方案比选，实时数据由调用方提供。
- 跨境通行、异地牌照限行等强政策约束：只提示需要核查，不替代官方口径。
- 时间价值完全无法货币化（如接送病人）：不做唯一推荐，只列权衡。
- 要求"保证最快"：路况与执法随机性存在，只给概率与缓冲建议。

## 输入与输出

| 字段 | 必填 | 说明 |
|:--|:--|:--|
| 起点与终点 | 是 | 城市或地标；跨省行程注明途经省份，用于确定费率 |
| 出发日期与时段 | 是 | 决定是否落在免费窗口、是否夜间行车 |
| 候选路线 | 是（≥2 条） | 每条给里程（km）、时长（min）、过路费（元）、红绿灯数；缺项标「未提供」，不得估算 |
| 车型与油耗 | 是 | 排气量或车型档 + 综合油耗（L/100km）。示例：中型轿车（1.8T，综合油耗 7.5L/100km） |
| 乘员构成 | 是 | 成人、儿童、长辈人数，以及是否有赶时间成员 |
| 单人时间价值 | 是 | 元/小时；可用税后时薪 × 0.6–0.8 折算，并写明折算口径 |
| 当日油价 | 是 | 92# 或 95# 实际挂牌价（元/升） |
| 费率与免费政策 | 是 | 途经省份一类客车费率、当日是否免费、ETC 折扣 |
| 是否赶时间 | 是 | 硬截止时刻，或「不赶」 |
| 停车费与接驳费 | 否 | 需要门到门口径时填入 |
| 偏好 | 否 | 少走高速、少红绿灯、带娃休息频次、夜间禁行 |

输入可直接写成下面这份 JSON，喂给 `scripts/route_cost.py --json input.json`；`time_min_slow` 为可选项，用于计算拥堵方差。

```json
{
  "params": {"consumption_l_per_100km": 7.5, "fuel_price_cny_per_l": 7.60,
             "time_value_cny_per_hour": 60, "weight_sum": 1.9, "holiday_free": false},
  "routes": [
    {"name": "A 高速优先", "distance_km": 118, "time_min": 78, "toll_cny": 46,
     "lights": 12, "time_min_slow": 92},
    {"name": "B 国道优先", "distance_km": 103, "time_min": 112, "toll_cny": 0,
     "lights": 31, "time_min_slow": 133}
  ]
}
```

**输出**（Markdown，正文 ≤1200 字 + 2–4 张表）：

- 决策卡（≤200 字）：推荐路线 + 一句话理由 + 触发规则编号（R1–R8）。
- 成本明细表：每路线一行，含油费、过路费、时间成本、疲劳成本、时间风险溢价、合计、与最优的差额。
- 比值行：节奏（rhythm，min/km）、ΔT/ΔS、净每分钟成本及其与有效时间价值的比值。
- 免费窗口排期（适用时）：上高速与下高速的建议时点、临界卡点方案。
- 多日行程表（>1 天时）：逐日里程、驾驶时长、锚点、住宿地。
- 预算表：分项合计 + 机动金 8%–10% + 总计 + 人均。
- 风险提示 3–6 条，每条含触发条件与应对动作。
- 需要留档时附 CSV，列名与本表一致。

决策卡固定长这样，任何一次交付都按此顺序输出，方便横向对比：

```text
【推荐】<路线名>，总成本 ¥<金额>，比次优省 ¥<差额>（<%>）
【理由】R<编号> + 关键比值（节奏 / ΔT/ΔS / 比值分档）
【代价】<多花的钱或多走的路>，以及它在什么条件下会反转
【动作】<出发时点、加油点、休息点>
```

需要把自驾、高铁、飞机放在一起比时，统一用门到门口径，三条成本线都要算全：

| 方式 | 门到门时间 | 成本构成 | 何时占优 |
|:--|:--|:--|:--|
| 自驾 | 家到目的地直达，含加油与休息 | 油费 + 过路费 + 停车费 + 时间成本 | 3–4 人同行、节假日免费、目的地公共交通弱 |
| 高铁 | 家到站 + 候车 + 车程 + 站到目的地 | 票价 × 人数 + 接驳 + 时间成本 | 2 人以内、单程 >4 小时、目的地市中心 |
| 飞机 | 家到机场 + 提前到场 + 飞行 + 落地接驳 | 票价 + 机建燃油 + 接驳 + 时间成本 | 单程 >6 小时且两端机场接驳短 |

## 工作流

1. **输入采集与缺省策略**
   - 做什么：按上表逐项采集，一次性列出缺项，不要一问一答拖成十轮；每个缺失项同时给出保守默认值与它对结论的影响方向。
   - 判据：9 个必填项齐备即进入下一步；缺失 ≤2 项且都有默认值时，可带标注继续。
   - 失败怎么办：缺项 ≥3 时只做量级估算（±15%）并出一张「参数缺口清单」，不进精确比较；用户补齐后整段重跑。
   - 产出：字段确认清单 + 待确认项标注。
2. **路线枚举与特征提取**
   - 做什么：每条路线填 7 个特征——里程 D（km）、时长 T（min）、过路费 Toll（元）、红绿灯数 L、灯密度 L/D（灯/km）、拥堵方差 σ（最快与最慢时长之差的一半，min）、自由流时长。
   - 判据：候选 ≥2 条且特征齐全；σ 缺失时按 T 的 12% 估算并标注「估」。
   - 失败怎么办：只有 1 条路线时切换为「成本体检」模式（只报总成本与可优化项）；两条里程完全相同时跳过 ΔT/ΔS，直接用 R6 与 R5 裁决。
   - 产出：特征表（每路线一行，7 列）。
3. **口径校准（三处必须核验）**
   - 做什么：按下表逐项写出数值、来源与核验日期；三处是油价、过路费、免费政策。
   - 判据：三处都能追溯到当日挂牌价或当年公告文本。
   - 失败怎么办：无法核验时给区间双算（低值、高值各跑一次），结论写成区间并标注「待核验」，同时给出核验动作。
   - 产出：参数卡（数值 + 来源 + 核验日期）。

   | 参数 | 取数方法 | 核验方法 |
   |:--|:--|:--|
   | 油价 | 拟加油标号在出发当日的挂牌价 | 出发前一晚看加油站价牌，或查当期成品油调价公告 |
   | 过路费 | 导航报价，或「省份费率 × 计费里程」 | 与同类路段的历史 ETC 账单比对；桥隧加价单独加 |
   | 免费政策 | 当年交通运输部与省级交通部门公告 | 确认免费车型、免费时段，以及「以驶离出口时间为准」 |
4. **成本建模**
   - 做什么：按下列公式逐项算，五类成本同一口径相加；算术一律交给 `scripts/route_cost.py` 或表格，不口算。
   - 判据：每条路线可复算，合计误差 ≤2%；单次驾驶超过 4 小时须先插入 20 分钟休息并计入 T。
   - 失败怎么办：参数自相矛盾（均速 <15km/h 却按高速计价、过路费高于「费率 × 里程」上限）时回退步骤 2 核对原始数据，不接受凑数。
   - 产出：成本明细表。

   ```text
   油费        = D ÷ 100 × 油耗(L/100km) × 油价(元/L)
   过路费      = 免费窗口内取 0，否则取 Toll
   有效时间价值 V = 单人时间价值(元/h) ÷ 60 × 乘员权重和    单位：元/min
   时间成本     = T × V
   疲劳成本     = max(0, T − 120min) × V × 0.3 × 情境系数
   时间风险溢价  = z × σ × V        （z 默认 0.5，约 70% 分位）
   总成本      = 油费 + 过路费 + 时间成本 + 疲劳成本 + 时间风险溢价
   ```

   乘员权重是示例值，按实际替换：驾驶者 1.0、同行成人 0.6、儿童 0.3、退休长辈 0.1、赶时间的商务同行 1.5–2.0。权重和不是人头数，而是「谁真的在乎这几十分钟」；只数人头的算法会把一车人算成四份时间价值，结论必然失真。情境系数：夜间 22:00–06:00、雨雾、连续山路取 1.5，其余取 1.0。
5. **阈值决策**
   - 做什么：先按总成本排序（R6），再用 R1–R5 交叉验证，最后按仲裁顺序落结论并写明理由。
   - 判据：结论必须挂规则编号，并同时给出三个比值：节奏、ΔT/ΔS、净每分钟成本 ÷ V。
   - 失败怎么办：差额 <3% 判「等价」；规则族与总成本冲突时以总成本为准，并在交付里写明冲突点与原因（通常是时间价值高于阈值隐含值）。
   - 产出：决策卡 + 冲突说明。

   | 编号 | 规则 | 判据 | 触发后的结论 |
   |:--|:--|:--|:--|
   | R1 | 区段跃迁 | 短路线节奏 >2.4 且快路线 <1.5 | 直接选快路线，跨区红利最大 |
   | R2 | 油耗失效 | 两条路线节奏差 <0.15 | 油耗维度不可用，改比红绿灯与转弯次数 |
   | R3 | ΔT/ΔS 回本线 | 无过路费差 4.5；有差 7.5；免费窗口内 4.5 | 超过阈值选快路线，低于阈值选短路 |
   | R4 | 每分钟成本比值 | 净每分钟成本 ÷ 有效时间价值 V | <0.5 必买时间；0.5–1.0 倾向买；1.0–1.5 看赶不赶；>1.5 走短路线 |
   | R5 | 红绿灯覆盖 | ΔT <8min 且 灯差 × 0.5min > ΔT | 时间优势是噪声，选灯少者 |
   | R6 | 总成本排序 | 与最优的差额 ≥3% | 低者胜；差额 <3% 判等价 |
   | R7 | 硬截止 | 截止时刻 − 时长 − σ < 0 | 该路线出局；全出局则改方案 |
   | R8 | 绕行上限 | 绕行 >35%（城市）或 >40%（含高速） | 否决快路线，除非 R7 强制 |

   | 优先级 | 规则 | 作用 |
   |:--|:--|:--|
   | 1 | R7 硬截止 + 政策禁行 | 不满足即出局，不参与排序 |
   | 2 | R8 绕行上限 | 绕行 >35%（城市）或 >40%（含高速）否决快路线 |
   | 3 | R6 总成本排序 | 主判据，差额 ≥3% 判胜负 |
   | 4 | R1 区段跃迁 → R3 ΔT/ΔS → R5 红绿灯 | 辅助裁决与解释 |
   | 5 | R2 油耗失效、R4 比值分档 | 降级路径，参数不全时用来秒判 |
6. **节假日窗口优化**
   - 做什么：把最长且不堵的跨省段压进免费窗口，把最堵的返程段挪到免费结束后的工作日付费走，并给临界卡点方案。
   - 判据：免费时段以驶离出口收费车道时间为准；窗口内 Toll = 0，ΔT/ΔS 阈值由 7.5 退回 4.5。
   - 失败怎么办：驶离时刻不确定时按付费（保守）计；免费结束前 2 小时仍在高速，建议就近下站再上，把长段拆成两段分别计费。
   - 产出：窗口排期表（日期、段、上站、下站、过路费口径）。

   ```text
   为什么窗口内阈值会降：有过路费差时，绕 1km 多花的是「油费 + 费率」，
   回本线因此抬到 7.5 min/km；免费窗口内过路费归零，每公里成本只剩油费，
   回本线回到 4.5 min/km —— 同一个目的地，免费期间更该走最快的那条。
   ```
7. **多日编排与预算**
   - 做什么：按单日上限切分行程并出逐日表；固定场次景点用倒排法（从场次时刻往回推）；住宿按次日出发方向选址；预算分项后加机动金。
   - 判据：逐日里程与时长双上限均未超；预算合计等于各分项之和；机动金落在 8%–10%。
   - 失败怎么办：超限则拆日或加一晚，并算出成本增量（多一晚住宿 + 多一天餐饮）交给用户取舍，不擅自压缩景点。
   - 产出：逐日行程表 + 预算表 + 风险提示。

   单日上限按同行构成取默认值，实际可按体质与路况上下浮动，但双上限（时长 + 里程）必须同时满足：

   | 同行构成 | 单日驾驶时长 | 单日里程 | 附加要求 |
   |:--|:--|:--|:--|
   | 单人驾驶 | ≤4h（法规上限），建议 ≤3.5h | ≤350km | 每 4h 强制休息 ≥20min |
   | 有成人可轮换 | ≤7h | ≤600km | 每 2–3h 换人一次 |
   | 带儿童或长辈 | ≤5h | ≤400km | 每段 ≤2h，留 1 个休息点或景点 |
   | 夜间 22:00–06:00 | ≤2h | ≤150km | 能避开就避开，不计入当日长途段 |

- [ ] 每条路线给出 5 类成本明细与合计，可用所列公式复算，合计误差 ≤2%。
- [ ] 推荐结论挂 R1–R8 规则编号，并同时给出节奏、ΔT/ΔS、净每分钟成本三个比值。
- [ ] 有效时间价值（元/分钟）= 单人时间价值 ÷ 60 × 乘员权重和，公式与取值显式列出。
- [ ] 油价、费率、免费政策三处均标注「以出行当日实际为准」，并各自给出一条核验方法。
- [ ] 免费窗口判断写明「按驶离出口时间」口径，并给出临界卡点方案（含备用时点）。
- [ ] 总成本差 <3% 时给出「等价」结论与次级决胜条件，不虚构胜者。
- [ ] 多日行程逐日里程与时长双上限均未超；超限处已拆分并给出成本增量。
- [ ] 预算表含 8%–10% 机动金，总价与人均同时给出；风险提示 3–6 条且每条可执行。

## 能力边界

- 不抓实时路况、实时票价与实时油价：里程与时长以调用方提供的导航快照为输入，实时数据由调用方补齐；本技能负责建模与裁决。
- 不承诺「保证不堵」「一定省钱 X%」：只给可复算的成本、阈值与敏感区间，结论随参数变化而变化。
- 不覆盖货运、客运、轮渡、跨境通行费与新能源补能网络：这些需要各自专门的成本模型。
- 时间价值无法量化时（纯休闲、无截止要求）不强行给唯一结论，改给「每公里成本」与「每小时成本」双视角供取舍。
- 限行、通行证、停车限高、儿童座椅法规按当地当期规定执行，需用户确认后纳入判断。
- 地图或路由引擎给出的里程常偏短，一律按 +5%–10% 留余量，不把单一引擎数值当唯一依据。

## 常见陷阱

- **把地图理论时长当实际**：不含休息与拥堵 → 按 +5%–10% 加缓冲，长途按每 2 小时一次休息计。
- **过路费漏算桥隧加价**：特大桥隧单独计价 → 逐段核桥隧，别用平均值糊过去。
- **节假日免费时段卡点出发**：免费开始前上高速仍全程收费 → 算清"驶离时刻"而非"驶入时刻"。
- **只比里程不比成本**：短 20 公里但多 40 分钟 → 用综合成本而不是单一指标裁决。

## 交付示例

输入（3 行）：

- 甲城 → 乙城，周六 08:00 出发，2 名成人 + 1 名儿童，不赶时间。
- 候选：A 高速优先 118km／78min／过路费 ¥46／12 个红绿灯；B 国道优先 103km／112min／¥0／31 个红绿灯。
- 示例车型：中型轿车（1.8T，综合油耗 7.5L/100km）；92# ¥7.60/L（当日挂牌）；单人时间价值 ¥60/小时。

输出骨架（数字为示例口径，实际按当日参数重算）：

```text
【推荐】A 高速优先，总成本 ¥268.11，比次优 B 省 ¥13.38（5.0%）。
【理由】R6 总成本排序胜出，R4 比值分档支持；节奏 A 0.66 / B 1.09 min/km。
【代价】多走 15km、多付 ¥46 过路费，换 34 分钟；V 低于 ¥1.53/min 时结论反转。
【动作】08:00 出发前加满油；A 线中途不停，13:00 前到达。

| 路线 | 油费 | 过路费 | 时间成本 | 疲劳 | 风险溢价 | 合计 |
|:--|--:|--:|--:|--:|--:|--:|
| A 高速优先 | 67.26 | 46.00 | 148.20 | 0.00 | 6.65 | 268.11 |
| B 国道优先 | 58.71 |  0.00 | 212.80 | 0.00 | 9.97 | 281.49 |

比值：ΔT/ΔS = 34 ÷ 15 = 2.27 min/km（有费档阈值 7.5）；净每分钟成本
（油费差 8.55 + 过路费差 46.00）÷ 34 = ¥1.60/min，除以有效时间价值 ¥1.90/min = 0.84。
交叉验证：油耗维度（2.27 < 7.5）本应指向国道；该阈值隐含时间价值约 ¥0.60/min，本例为 3 倍，
故以总成本为准，冲突点在此写明，避免结论看起来自相矛盾。
窗口：出行日不在免费节假日，过路费按实收计。
风险：① B 路 31 个红灯，σ≈10.5min，最差情形下可能反超；② 油价按当日挂牌，隔日须重算。
口径：油价、费率、免费政策以出行当日实际为准；金额保留两位小数。
```

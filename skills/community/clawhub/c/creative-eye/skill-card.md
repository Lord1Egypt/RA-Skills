## Description:

Give AI agents creative judgment and design taste for visual content, brand review, reference libraries, quality gates, and aesthetic training.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and agent builders use this skill to evaluate and improve visual creative, brand materials, social content, product photography, merch, and creative quality workflows before release.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can encourage agents to publish creative output automatically after checklist or scorecard checks.

Mitigation: Require explicit user approval for every publish action, especially in live brand, social, ecommerce, or advertising workflows.

Risk: The skill suggests recurring study tasks and persistent creative workflows that may continue beyond the immediate user request.

Mitigation: Enable scheduled or persistent behavior only after the user approves the cadence, scope, storage location, and stop conditions.

Risk: The skill may direct agents to create or update reference libraries, guardrail files, style profiles, logs, and agent identity documents.

Mitigation: Restrict writes to user-approved workspace paths and review proposed changes before they affect production brand systems or agent behavior.

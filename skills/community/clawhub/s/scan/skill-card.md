## Description:

Scan is a multi-modal agent skill for turning telemetry, biometric, document, code, network, and spatial inputs into actionable semantic context.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and developers use Scan to ask an agent to analyze high-density inputs such as genomic, network, legal, code, and spatial data and surface semantic context.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill encourages broad analysis of sensitive biometric, genomic, legal, network, code, and spatial data without clear consent or scope limits.

Mitigation: Use only with authorization for the data involved, require explicit user confirmation, and define clear limits for sensitive input categories before use.

# 终审质量检查清单

> 本文档为 `paper-revision-sop` 技能Phase 4终审阶段的检查标准。
> 修改完成后逐项确认，全部通过方可交付。

---

## A. AI味清除（权重最高）

- [ ] A1 全文具体AI产品名称 ≤ 3个（全部替换为功能类别）
- [ ] A2 无"从X到Y"对仗式标题
- [ ] A3 无"双螺旋""深层互构""认知跃迁""信息平权"等空泛术语
- [ ] A4 结语无"以A为B、以C为D"四连排比
- [ ] A5 无"不仅是……更是……"万能句式连续出现
- [ ] A6 AI味密度指数 < 5（由诊断脚本自动计算）

## B. 可读性

- [ ] B1 全文无超过120字的单句（逐句检查）
- [ ] B2 每个自然段由3-5个短句构成（非单句段）
- [ ] B3 段落间有过渡句或逻辑连接词
- [ ] B4 每个核心术语首次出现时有简短解释
- [ ] B5 无连续4个以上并列名词/动词堆叠

## C. 结构与篇幅

- [ ] C1 字数在目标范围内（误差±100字）
- [ ] C2 各部分权重合理（引言15-20%，正文50-60%，讨论15-20%）
- [ ] C3 摘要在150字以内，含背景-方法-发现-意义四要素
- [ ] C4 关键词3-5个，不使用无检索价值的泛词
- [ ] C5 参考文献格式统一，正文引用与文末列表一一对应

## D. 学术规范

- [ ] D1 无自我评价式语言（"本研究具有重要价值""开创性地"等）
- [ ] D2 有数据支撑的结论附带具体数字
- [ ] D3 他人观点/数据有明确引用
- [ ] D4 无政治敏感表述
- [ ] D5 摘要与正文结论一致

## E. 期刊适配

- [ ] E1 标题长度适合目标期刊风格
- [ ] E2 摘要含目标期刊偏好的关键词
- [ ] E3 参考文献近5年为主，含目标期刊论文
- [ ] E4 版面格式符合期刊投稿要求

---

## 判定标准

- **一次性通过**：A1-A6全部通过 + B1-B3全部通过 + C1-C2全部通过
- **需小修**：A项有1-2个未通过但非致命级
- **需大修**：A1/A2/A6中任一未通过，或B项3个以上未通过

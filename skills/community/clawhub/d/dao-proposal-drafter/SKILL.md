# Dao Proposal Drafter

## Overview

Proposals fail for boring reasons: no clear ask, no cost, no implementation detail. This workflow drafts proposals in the shape delegates actually vote for — problem first, options with trade-offs, and the precise executable action.

## When to use

When preparing a governance proposal, a temperature check, or a funding request to a DAO.

## Workflow

1. **State the problem** — one paragraph, with the evidence it is real (data, links, prior discussion)
2. **Present options** — at least two, including 'do nothing', each with cost and risk
3. **Make the ask exact** — amounts, recipients, duration, and the precise on-chain payload or contract change
4. **Show the budget math** — where the funds come from and what the treasury looks like after
5. **Pre-answer objections** — the three strongest arguments against, answered honestly
6. **Define success** — how the DAO will know in 90 days whether this worked, and what happens if it did not

## Guardrails

- Never hide a conflict of interest — disclose any benefit to the author up front
- Do not bundle unrelated changes into one proposal to sneak one through
- Amounts and addresses must be exact; a typo in a proposal is a loss on-chain

## Output format

A proposal draft: summary, problem, options, exact ask, budget math, objections answered, success criteria.

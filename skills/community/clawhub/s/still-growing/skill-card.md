## Description:

Still Growing / 第二代父母 helps agents support reflective parenting conversations about parent-child misalignment, emotional inheritance, and practical dialogue prompts.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

External users can use this skill when discussing parenting stress, parent-child conflict, education anxiety, emotional reactivity, burnout, original-family patterns, and related self-reflection prompts. It is guidance content for agent conversations and should not be treated as clinical, crisis, or emergency care.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security review reports unsafe crisis guidance in a child self-harm scenario.

Mitigation: Revise crisis sections to prioritize immediate human crisis support, emergency services where appropriate, continuous supervision, and professional care.

Risk: The security review reports unrelated instructions to search private local skill directories, session history, and git context.

Mitigation: Remove automatic local, session, and git searches unless the user explicitly asks for that diagnostic workflow.

Risk: Parenting and emotional-health guidance could be mistaken for professional mental-health advice.

Mitigation: Present the skill as reflective support only and direct users to qualified professionals for clinical, safety-critical, or emergency situations.

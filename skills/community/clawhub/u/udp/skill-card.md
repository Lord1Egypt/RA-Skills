## Description:

Helps agents answer UDP socket, datagram send/receive, and network debugging questions, including client/server code, port testing, packet loss, and firewall troubleshooting.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill to produce UDP client/server guidance, datagram testing commands, and troubleshooting steps for packet loss, missing responses, port reachability, and firewall issues.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: UDP testing examples can be misapplied to systems the user is not authorized to test.

Mitigation: Use the commands only against systems you own or have explicit permission to test.

Risk: The skill guidance is primarily in Chinese, which may reduce review clarity for users who do not read Chinese.

Mitigation: Review translated or localized guidance before deployment when the target user group does not read Chinese.

## Description:

Apply Sun Tzu's Art of War principles to AI agent organization and task orchestration. Use when planning multi-agent workflows, evaluating whether to deploy agents, assessing task complexity, or optimizing agent collaboration strategies. Maps all 13 chapters to practical agent patterns.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and agent operators use this skill to decide whether and how to deploy agents, plan multi-agent workflows, manage token and cost tradeoffs, and validate agent outputs.

Global

## Known Risks and Mitigations:

Risk: The skill may encourage later use of external tools, APIs, databases, monitoring, or code execution as part of an agent plan.

Mitigation: Authorize each real-world tool, API, database, monitoring, or code-execution action separately before allowing an agent to use it.

Risk: The Art of War framing and Chinese terminology may not fit every audience or organizational context.

Mitigation: Review the framing and language mix before deployment, and adapt examples or terminology for the target users when needed.

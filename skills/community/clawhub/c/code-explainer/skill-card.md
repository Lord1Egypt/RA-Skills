## Description:

Explain what a piece of code does in plain English, at the depth the reader needs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[mohitagw15856](https://clawhub.ai/user/mohitagw15856)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to understand unfamiliar snippets, functions, or files through a concise summary, ordered walkthrough, important gotchas, and visible bug or smell callouts.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Private repositories or sensitive snippets may be exposed to the agent session when submitted for explanation.

Mitigation: Use only code the user is permitted to share, redact secrets and sensitive implementation details, and review bug or smell recommendations before acting on them.

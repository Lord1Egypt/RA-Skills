### SZ-37　使人备己
- name: 使人备己
- source_text: "吾所与战之地不可知，不可知，则敌所备者多；敌所备者多，则吾所与战者，寡矣。故备前则后寡，备后则前寡，备左则右寡，备右则左寡，无所不备，则无所不寡。寡者，备人者也；众者，使人备己者也。"
- source_location: 《孙子兵法·虚实篇》
- 要义：分散对手的结构机制——隐藏我方打击点迫使对手处处设防（无所不备则无所不寡）；主动方最优态是"使人备己"，让对手的力量消耗在防我上。

### SZ-38　一人之耳目
- name: 一人之耳目
- source_text: "夫金鼓旌旗者，所以一人之耳目也。人既专一，则勇者不得独进，怯者不得独退，此用众之法也。"
- source_location: 《孙子兵法·军争篇》
- 要义：用众的信号统一律——以统一号令系统收编全员耳目，个体勇怯不再决定进退节律（勇不独进、怯不独退）；群体一致性由信号系统保证，不由个体气质保证。

### SZ-39　九变之术
- name: 九变之术
- source_text: "治兵不知九变之术，虽知五利，不能得人之用矣。"
- source_location: 《孙子兵法·九变篇》
- 要义：知与术的转化律——掌握有利条件之知识（五利、地形）不等于会用；知识必须转化为临机应变的运用之术（九变之术），否则"虽知五利，不能得人之用"。

### SZ-40　半济而击
- name: 半济而击
- source_text: "绝水必远水；客绝水而来，勿迎之于水内，令半济而击之，利。"
- source_location: 《孙子兵法·行军篇》
- 要义：转换态打击律——对手处于结构转换中间态（半渡）时新旧两头不靠、最为脆弱，是最佳打击窗口；不打其稳态，专打其过渡态。

### SZ-41　相敌察微
- name: 相敌察微
- source_text: "敌近而静者，恃其险也；远而挑战者，欲人之进也；其所居易者，利也。"
- source_location: 《孙子兵法·行军篇》
- 要义：征候诊断律——由可观察征候推读对手状态与意图（静者恃险、挑战者欲人进、居易者利）；表象须按处境反读，不可按表象直读。

### SZ-42　发火有时
- name: 发火有时
- source_text: "发火有时，起火有日。时者，天之燥也；日者，月在箕、壁、翼、轸也。凡此四宿者，风起之日也。"
- source_location: 《孙子兵法·火攻篇》
- 要义：借外力的时窗律——借助外部放大性力量（火）必须等待其条件窗口（时、日、风起之日），并以"数守之"掌握其规律候之；外力不可强唤，只可识别与等候。

### SZ-43　间事未发
- name: 间事未发
- source_text: "微哉微哉！无所不用间也。间事未发，而先闻者，间与所告者皆死。"
- source_location: 《孙子兵法·用间篇》
- 要义：保密的惩戒威慑律——极敏感行动未启动前泄露，泄密者与知情者同罪极刑（皆死）；以泄密成本最大化保证"事未发"状态，知情圈即问责圈。

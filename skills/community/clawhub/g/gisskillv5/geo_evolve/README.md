## Agent偷懒识别模块

### 监控维度

| 监控项 | 统计方法 | 阈值 | 触发动作 |
|--------|---------|------|---------|
| 跳步骤 | 比对标SOP节点 | >0次 | 🔴 生成规则增补任务 |
| 敷衍输出 | 输出字符数 < 500 | >0次 | 🟡 警告+重新执行 |
| 省略校验 | 校验日志缺失 | >0次 | 🔴 阻断任务 |
| 用默认值蒙混 | 参数来源=default | >2次 | 🟡 标记风险 |
| 甩锅话术 | 出现"手动调整"等 | >0次 | 🔴 记录违规 |

## 灰度发布与回滚

```
发布流程:
  1. 增量更新包生成 → 隔离索引区
  2. 自动验证(10个基准测试) → 通过率≥95%
  3. 灰度发布(10%用户) → 观察24h
  4. 全量发布 → 主索引切换
  5. 旧索引保留 → 支持一键回滚

回滚条件:
  - 检索错误率 > 5%
  - 知识冲突告警 > 3条
  - 用户投诉 > 2条
```

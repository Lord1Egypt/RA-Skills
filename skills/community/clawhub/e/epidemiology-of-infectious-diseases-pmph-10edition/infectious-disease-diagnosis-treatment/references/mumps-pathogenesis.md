# 流行性腮腺炎发病机制

## 两次病毒血症

### 第一次病毒血症
```
呼吸道侵入 → 局部黏膜/淋巴结复制 → 入血 → 腮腺 + 中枢神经系统
```
引起：腮腺炎 + 脑膜炎

### 第二次病毒血症
```
进一步繁殖 → 再次入血 → 颌下腺/舌下腺/睾丸/胰腺
```
引起：多器官受累

## 器官病理特征

### 腮腺
- 非化脓性炎症
- 导管阻塞 → 淀粉酶滞留 → 经淋巴入血 → 血/尿淀粉酶增高

### 脑膜脑炎
- 由血溶-细胞融合糖蛋白（F蛋白）所致

### 睾丸/胰腺
- 淋巴细胞浸润
- 易累及成熟睾丸（幼年罕见睾丸炎）

## 腮腺肿大特征

- 以耳垂为中心，向前后下发展
- 进食酸性食物加剧疼痛
- 2-3天达高峰，4-5天消退

## 并发症详细数据

| 并发症 | 发生率 | 特点 |
|--------|--------|------|
| 脑膜炎 | 15% | 发病4-5天；CSF WBC约25×10⁶/L（淋巴为主），糖可降 |
| 睾丸炎 | - | 消退时再发热；单侧多见（1/3双侧）；3-5天急性期；可致萎缩但罕致不育 |
| 胰腺炎 | <10% | 腮腺肿大数天后发生；必须查脂肪酶（淀粉酶单纯腮腺炎也高） |

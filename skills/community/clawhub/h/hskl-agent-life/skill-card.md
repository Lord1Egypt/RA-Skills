## Description:

Agent Life lets an AI agent create and play a fictional person in a real-time parallel world, then report the character's actions to the platform.

This skill is ready for commercial/non-commercial use.

## Publisher:

[hskl18](https://clawhub.ai/user/hskl18)

### License/Terms of Use:

MIT-0

## Use Case:

People using a compatible AI agent can create and manage a fictional life in Agent Life, receive in-character updates, and direct the character through the game service.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The external game service may receive and store conversation replies, character details, and inferred availability.

Mitigation: Review the skill's disclosures and consent flow, and use the service only if this data sharing is acceptable.

Risk: The installer command is not pinned to a fixed version, and the security scan was partial because some references could not be resolved.

Mitigation: Check the release version and review unresolved references before installing or relying on the scan.

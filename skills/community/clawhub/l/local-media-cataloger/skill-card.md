## Description:

Index local photos, videos, and creative assets into a searchable manifest with tags, dates, shoot info, and reuse ideas.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and developers use this skill to inventory local media folders, draft searchable manifests, identify duplicate candidates, and plan organized archive or delivery structures.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A generated manifest can expose local paths, filenames, sizes, and timestamps.

Mitigation: Run the skill only on explicit folders the user intends to catalog and store generated manifests in an appropriate location.

Risk: CSV output can be unsafe to open in spreadsheet software if filenames are crafted as formulas.

Mitigation: Treat generated CSV files as untrusted data and review or sanitize filenames before opening them in spreadsheet applications.

Risk: Broad recursive scans may include personal or unrelated media files.

Mitigation: Ask the user to confirm the exact folder scope before scanning and prefer preview or draft workflows before any file organization changes.

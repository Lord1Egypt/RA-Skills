## Description:

Share a Google Drive file and email the link with a message to recipients.

This skill is ready for commercial/non-commercial use.

## Publisher:

[googleworkspace-bot](https://clawhub.ai/user/googleworkspace-bot)

### License/Terms of Use:

MIT-0

## Use Case:

Employees and external collaborators use this recipe to share an approved Google Drive file with a recipient and send that recipient an email containing the file link.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A user may accidentally share an unapproved Drive file or grant access to the wrong recipient.

Mitigation: Confirm the file is approved for external sharing, replace example addresses with intended recipients, and verify the permission before sending the email.

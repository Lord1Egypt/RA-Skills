## Description:

Generate a full week of social media content for any topic. Outputs platform-optimized posts for Twitter/X, LinkedIn, and Instagram with hashtags and posting times.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Content creators, marketers, and small teams use this skill to generate a weekly social media content calendar template for Twitter/X, LinkedIn, and Instagram from a topic and optional audience.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Running the script can overwrite an existing content-calendar.md in the current directory.

Mitigation: Check for an existing content-calendar.md or run the script in a dedicated directory before execution.

Risk: The generated calendar contains bracketed draft placeholders rather than finished, brand-ready posts.

Mitigation: Review and complete the bracketed sections, adding brand voice, examples, visuals, and compliance review before scheduling.

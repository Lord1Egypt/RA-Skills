## Description:

Look up a public X (Twitter) profile by @handle through Twitee, with no X login or API key. Returns display name, bio, follower and following counts, post count, verified flag, location and join date. Read-only. Use when the user asks who an X account is or how many followers it has.

This skill is ready for commercial/non-commercial use.

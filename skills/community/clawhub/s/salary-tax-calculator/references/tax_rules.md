## 二、专项附加扣除标准

### 2.1 七项专项附加扣除

| 扣除项目 | 扣除标准 | 条件 | 说明 |
|---------|---------|------|------|
| 子女教育 | 2,000元/月/子女 | 3岁至全日制学历教育 | 父母各扣50%或一方扣100% |
| 继续教育 | 400元/月或3,600元/年 | 学历教育/职业资格证书 | 学历教育最长48个月 |
| 大病医疗 | 每年限额80,000元 | 自付超15,000元部分 | 汇算清缴时扣除 |

| 3岁以下婴幼儿照护 | 2,000元/月/孩 | 3岁以下婴幼儿 | 父母各扣50%或一方扣100% |

### 2.2 住房租金标准分档

| 档次 | 适用城市 | 扣除标准 |
|------|---------|---------|
| 第一档 | 直辖市、省会城市、计划单列市 | 1,500元/月 |

## 三、累计预扣法计算

### 3.1 计算公式

```
本月应预扣预缴税额 = （累计预扣预缴应纳税所得额 × 预扣率 - 速算扣除数）- 累计减免税额 - 累计已预扣预缴税额

累计预扣预缴应纳税所得额 = 累计收入 - 累计免税收入 - 累计减除费用（5,000/月）- 累计专项扣除 - 累计专项附加扣除 - 累计依法确定的其他扣除
```

### 3.2 计算示例

**案例：** 某员工月薪15,000元，五险一金个人部分2,250元，专项附加扣除3,000元/月（子女教育1,000+房贷1,000+赡养老人1,000）

**1月：**
- 累计收入：15,000
- 累计减除费用：5,000
- 累计专项扣除（五险一金）：2,250
- 累计专项附加扣除：3,000
- 累计应纳税所得额：15,000-5,000-2,250-3,000 = 4,750
- 预扣率：3%
- 本月税额：4,750 × 3% = 142.5
- 税后收入：15,000-2,250-142.5 = 12,607.5

**6月（累计6个月）：**
- 累计收入：90,000
- 累计减除费用：30,000
- 累计专项扣除：13,500
- 累计专项附加扣除：18,000
- 累计应纳税所得额：90,000-30,000-13,500-18,000 = 28,500
- 预扣率：3%（未超36,000）
- 累计税额：28,500 × 3% = 855
- 前5个月已预缴：712.5
- 6月应预扣：855-712.5 = 142.5

## 四、年终奖计税方式

### 4.1 两种计税方式（2027年12月31日前可选择）

#### 方式一：单独计税（优惠方式）

```
年终奖应纳税额 = 年终奖 × 适用税率 - 速算扣除数

适用税率：以年终奖÷12的商数对照月度税率表确定
```

#### 方式二：并入综合所得

```
并入后年度应纳税所得额 = 年度工资收入 + 年终奖 - 各项扣除

应纳税额 = 并入后应纳税所得额 × 适用税率 - 速算扣除数 - 已预缴税额
```

|----------------|------|-----------|

| 3,001-12,000 | 10% | 210 |
| 12,001-25,000 | 20% | 1,410 |
| 25,001-35,000 | 25% | 2,660 |
| 35,001-55,000 | 30% | 4,410 |

| 临界点 | 年终奖金额 | 税额 | 多发1元 | 税额跳变 | 净收益减少 |

> **重要：** 年终奖在临界点附近多发1元，税额可能跳变数千元。需用脚本精确计算。

## 六、年度汇算清缴

### 6.1 需要汇算的情形

| 情形 | 是否需要汇算 |
|------|-------------|
| 年收入≤12万且已预缴 | 可免汇算 |
| 补税金额≤400元 | 可免补缴 |
| 有多处工资收入 | 需要汇算 |
| 有劳务报酬/稿酬/特许权使用费 | 需要汇算 |
| 漏报专项附加扣除 | 需要汇算 |
| 年终奖方式选择 | 建议汇算优化 |

### 6.2 汇算时间

每年3月1日至6月30日，通过个人所得税APP办理上一年度综合所得年度汇算。

## 七、个税优化建议

### 7.1 合法优化路径

| 优化方式 | 说明 | 节税效果 |
|---------|------|---------|
| 专项附加扣除 | 充分利用七项扣除 | 每月减税45-1,350元 |
| 年终奖单独计税 | 选择更优计税方式 | 可能节税数千元 |
| 公积金补充缴存 | 补充公积金税前扣除 | 降低应纳税所得额 |
| 商业健康险 | 税前扣除2,400元/年 | 减税72-1,080元 |
| 个人养老金 | 税前扣除12,000元/年 | 减税360-5,400元 |
| 慈善捐赠 | 不超过应纳税所得额30%部分可扣除 | 按捐赠金额减税 |

### 7.2 年终奖优化决策树

```
年收入（含年终奖）较低（<6万）：
  → 并入综合所得（可能免税）

年收入中等（6-20万）：
  → 比较两种方式，通常单独计税更优
  → 注意避开临界点盲区

年收入较高（>20万）：
  → 单独计税通常更优
  → 用脚本计算最优分配方案
```

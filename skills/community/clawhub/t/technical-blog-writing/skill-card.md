## Known Risks and Mitigations:

Risk: The skill includes a mutable remote installer command for inference.sh.

Mitigation: Prefer manual download with pinned versions and checksum or signature verification before installation.

Risk: The skill includes guidance for posting to X, which can publish public content if connected and run intentionally.

Mitigation: Review and approve the exact post text and account connection before using any public-posting command.

Risk: The skill suggests installing related third-party skills without pinned versions.

Mitigation: Review each related skill independently and pin or verify the source before installation.

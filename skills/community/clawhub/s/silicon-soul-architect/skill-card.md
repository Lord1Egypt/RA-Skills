## Description:

Silicon Soul Architect is a Chinese-language agent workflow that guides developers through Taohuayuan's four-layer cognition architecture to design an AI agent blueprint.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and agent designers use this skill to shape an AI agent's physical anchor, sensory inputs, reasoning posture, persistence cadence, and local-first memory seeds. The skill outputs a structured cognitive blueprint and a poetic destiny-style interpretation based on the user's answers.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Users may include sensitive personal information in local memory seeds or share the generated blueprint with a third-party site.

Mitigation: Do not enter passwords, keys, health data, financial details, government IDs, or intimate personal facts; review the generated blueprint before sharing it externally.

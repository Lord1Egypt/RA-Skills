## Description:

Helps AI-agent users, skill authors, maintainers, and teams create practical ontology-style workflows, checklists, artifacts, analysis, code changes, and decision support for reliability and adjacent skill creation.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

External developers, AI-agent users, skill authors, maintainers, and teams use this skill to turn ontology or typed knowledge-graph productivity needs into local-hardware-friendly workflows, templates, checklists, code changes, or decision aids. It is intended for practical work such as bug fixing, setup hardening, reliability improvement, and creating adjacent skills.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation wording may cause the skill to be used for generic knowledge, graph, workflow, or bug-fix requests where a narrower skill would be more appropriate.

Mitigation: Review whether the task is specifically about ontology or typed knowledge-graph productivity before relying on this skill.

Risk: Workflow or implementation guidance may be incomplete or mismatched to the user's environment.

Mitigation: Validate outputs against the stated success criteria and make assumptions, limits, and required inputs visible before acting on generated artifacts.

Risk: Saved snippets may contain secrets, credentials, or other private code if users store them directly.

Mitigation: Avoid saving secrets or private credentials in snippets, and review snippet content before reuse or sharing.

Risk: Broad trigger phrases for saving or searching code could activate the skill when it is not intended.

Mitigation: Narrow trigger phrases or invocation rules in deployments where accidental activation would disrupt the workflow.

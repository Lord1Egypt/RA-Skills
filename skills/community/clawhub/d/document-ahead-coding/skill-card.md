## Description:

Write documentation first, code second, for any non-trivial change to a codebase, including new features, refactors, bug fixes, migrations, or multi-file work that needs a reviewable plan.

This skill is ready for commercial/non-commercial use.

## Publisher:

[blueriverlhr](https://clawhub.ai/user/blueriverlhr)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and coding agents use this skill to create reviewable planning documents before implementing non-trivial code changes. It helps capture discussions, principles, tasks, manuals, and deferred decisions so implementation remains traceable to an approved plan.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Planning notes may persist discussions, decisions, rejected ideas, or sensitive private details in project documentation.

Mitigation: Avoid recording secrets or sensitive private details in docs/ and review generated planning notes before committing or sharing them.

## Description:

Designs scalable frontend architecture for large applications, including project structure, module boundaries, dependency management, code splitting strategy, and technical debt prevention.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and frontend engineers use this skill to plan maintainable frontend application architecture, including scale-appropriate project structure, feature boundaries, dependency rules, code splitting, technology selection, ADRs, and refactoring strategy.

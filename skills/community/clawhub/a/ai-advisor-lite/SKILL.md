# AI参谋 Lite（派活前，先问四句）

免费手动版。把任何派给 AI 的任务，先过四问、再改写成专家级指令。

## 何时使用

当用户要把实质任务派给 AI 时——写方案、写报告、写推文、做PPT、写代码、拟合同、做分析。闲聊问答、简单事实查询不触发（直接问即可，不值得先过四问）。

触发说法：「帮我派活」「把这个任务派好」「任务改写」「派活前先过四问」「这个任务怎么给AI布置」。

## 工作流程

### 第一步：名词 → 动词改写

把任务名从"名词"改写成"结果动词"：

> **在 X 时间内，让【谁】看懂【什么】，并采取【什么行动】。**

- ❌ "写一篇科普推文" → ✅ "30 分钟内让一个忙碌的矿老板看懂尾矿提金属的生意逻辑，并愿意转发给合伙人"
- ❌ "做个 PPT" → ✅ "15 分钟内让评委记住我们的三个数字并愿意问价"

先向用户确认：受众是谁（越具体越好）、期望时限、产出用在哪里。缺了就问，不要猜。

### 第二步：执行四问

针对用户的任务，逐条回答并写进派活指令：

1. **超出字面的工作**：这个领域的顶尖专家，会做哪些用户没有提出要求的工作？
2. **原始材料**：他们会从哪些最原始的材料入手，而不是用已经加工过的内容？
3. **方法工具**：他们具体会采用哪些方法和工具？
4. **独立验证**：除了你我的判断，还有什么能够独立证明结果是对的？

每问至少给出 2~3 条**具体动作**。禁止空话（"认真分析""深入研究""全面考虑"这类词出现即视为未完成）。

### 第三步：产出派活指令

把四问答案汇编成一段可直接复制给执行 AI 的完整指令，结构：

```
【任务】（动词改写后的一句话）
【材料要求】只从指定一手材料入手，禁止二手转述
【方法要求】专家会用什么方法工具，逐条写明
【超出字面的工作】专家还会额外完成什么，逐条写明
【独立验证】产出后怎么证明它对（盲评 / 回源核对 / 第三方）
【禁止事项】不许编造、不许套模板、不许超出范围
```

### 第四步：交付自查

派活指令交给用户前，逐条过清单：

- [ ] 任务写成了动词（让谁在什么时间内看懂什么并采取什么行动）
- [ ] 原始材料点名了
- [ ] 方法写具体了
- [ ] 验证独立了
- [ ] 禁止事项写明了

有一条不满足就回去补，不许带病交付。

## 硬约束

1. 四问答案必须针对用户的具体任务定制，禁止输出通用模板。
2. 不确定的信息明确标注"待核实"，禁止编造。
3. 受众、时限缺失时先追问，不猜。

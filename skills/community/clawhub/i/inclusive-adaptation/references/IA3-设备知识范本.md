## IA3-设备知识范本

### 范本概述

本范本对应 IA3-01~IA3-03 全部任务的输出样式：品类知识卡、选型对比表与设备知识更新记录。

### 范本正文

**品类知识卡（示例：智能门锁）**

| 维度 | 内容 |
|------|------|
| 工作原理 | 指纹/密码/NFC/远程等多方式解锁，替代机械钥匙（L2 模型知识） |
| 适老设计点 | 免掏钥匙免弯腰；指纹识别对老年人指纹磨损可能有识别率问题，须有密码/机械钥匙备份 |
| 适幼/适残设计点 | 儿童指纹浅识别率低；视障用户需按键触觉反馈或语音引导 |
| 联动能力 | 开门联动室内灯点亮；异常撬动报警推送家属 |
| 安装条件 | 门体厚度与导向片规格匹配；常开状态须可断电机械开启 |
| 价位段 | {{区间}}（L3，以实际询价为准） |

### 结构要点标注

1. 品类卡六维齐全，原理标 L2、价位标 L3
2. 人群适配维度必须分人群说明，不写"适合所有人"
3. 选型结论必须给依据，型号与价格未经联网验证只给品类级建议
4. 更新记录含触发、来源、验证结论与入库标注，未验证不入正式底座

### 替换清单

- {{型号}}/{{区间}} 占位替换为联网验证后的真实信息或删除
- 对比维度按实际候选与需求调整

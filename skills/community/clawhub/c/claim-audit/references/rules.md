# 抽声明的规则

本工具不是全文检索，它只在 `SKILL.md` 与 `README.md` 两份文件里找四类可验的数字。

## 四类声明

| 类型 | 触发写法 | 核验方式 |
|---|---|---|
| tests | `9/9 PASS`、`9/9 通过` | 重跑 `tests/run_golden.py`，解析末行 |
| files | `12 个文件`、`files=12` | 遍历真实文件树计数 |
| score | `100/100` | 同级 `lgd-skill-review/scripts/review.py` 带 `--run` 复跑 |
| path | 列表项/链接行里的 `` `references/x.md` `` | 检查文件是否存在 |

## 三条排除规则

1. **分数行里的 `N/M PASS` 不算自检声明**。`结构制 100/100 PASS` 是分数，不是用例条数；混淆会立即报错。
2. **正文举例里的路径不算声明**。只有列表项、引用块、Markdown 链接行才算；表格行也算"行为说明"而非声明——`references/x.md` 出现在"本工具会核什么"的表格里是占位，不是本包的文件。
3. **历史轨迹不算当前值**。含 `→`、`基线`、`复测` 的行是过程记录，跳过。这类数字写的是"曾经 46 分，现在 67 分"，不是"现在 46 分"。

## 已知误报与处理

- 反斜杠路径：核验前统一换成当前系统的分隔符，否则 Windows 路径会被判不存在。
- `__pycache__`、`.git`、`node_modules`：计数时排除，否则文件数会虚高。
- 中文全角括号里的数字：不抽，避免把「（9/9）」这类纯叙述当声明。

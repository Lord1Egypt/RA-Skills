## Description:

Generate and edit images through SkillBoss API Hub with style presets, batch generation, and an HTML gallery.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and developers use this skill to generate or edit images from prompts, apply style presets, and produce local image files with an HTML gallery.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts and edited images can be sent to SkillBoss API Hub.

Mitigation: Avoid sensitive or private prompts and images, and install only if external processing is acceptable.

Risk: The skill can follow API-supplied download URLs outside its claimed network scope.

Mitigation: Run it in a constrained environment and review generated gallery files before opening or sharing them.

Risk: Artifact guidance encourages posting images, updating avatars, and saving results to memory.

Mitigation: Require explicit approval before any posting, avatar update, or memory write.

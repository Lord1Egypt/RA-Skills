# 淘宝商品文案与视觉脚本

## 快速开始

收齐 8 项：品类、品牌、规格/成分、价格与活动、目标人群、核心痛点、差异点、资质/认证。缺 3 项以内可假设并标注；缺资质、检测报告、销量时不要编造，写「待补充凭证」。

## 工作流

1. **卖点提炼**：写 3-5 个，每个按「参数 → 用户利益 → 使用场景」翻译。选 1 个最强卖点做首图，其余分配到后续图，禁止一张图堆 5 个卖点。
2. **标题 3 版**：≤30 个汉字（约 60 个字符）。结构「品牌 + 核心词 + 属性/规格 + 人群/场景 + 卖点」。核心词前置，不重复堆词，不含极限词。
3. **5 张主图**：图 1 搜索图（核心卖点 + 价格 + 信任角标）、图 2 场景图、图 3 对比图、图 4 细节图、图 5 视频。每张主标题 ≤12 字、副标题 ≤20 字；产品占画面 ≥70%；配色 ≤3 种。
4. **详情页 7 屏**：首屏痛点 + 核心绝活 → 证据（检测/实测/销量）→ 参数与规格 → 使用场景 → 对比竞品/普通款 → 顾虑与售后 → 关联推荐。
5. **合规检查**：读 `references/taobao-assets.md`，逐条检查极限词、虚假宣传、医疗功效、价格欺诈、专利/认证真实性。
6. **体检**：运行 `python scripts/taobao_title_lint.py --title "标题"`，按结果改写；标题超 60 字符必须重写。
7. **输出上架包**。

## 输出格式

```markdown
【人群与痛点】一句
【卖点表】3-5 个：参数 / 利益 / 场景 / 放哪张图
【标题 3 版】≤30 汉字，标注核心词
【主图 5 张】每张：主标题 / 副标题 / 画面 / 配色 / 角标
【详情页 7 屏】每屏一句目标 + 文案要点
【合规检查】命中项与替换
【待补充素材】资质/实拍/数据
```

## 硬性规则

- 标题 ≤30 个汉字；超限直接重写，不靠符号凑。
- 一张主图只打一个核心信息；产品必须占画面 70% 以上，不被文字和赠品淹没。
- 卖点必须可感知、可验证，用数字替代「超强/超大/超好用」。
- 不编造销量、好评、复购、检测报告、专利、认证、代言；没有凭证就删。
- 不使用「最/第一/国家级/顶级/100%/绝对」等极限词；不用「治疗/根治/美白/减肥」等未经资质支持的功效词。
- 价格标注真实：划线价需有依据，不虚构原价、不设置虚假限时。
- 医疗、食品、化妆品、电器等类目按对应法规与平台资质要求表达，拿不准时建议用户咨询平台规则。

## 参考与脚本

- `references/taobao-assets.md`：标题公式、5 张主图规范、7 屏详情页、FAB 翻译表、合规词表。
- `scripts/taobao_title_lint.py`：按显示宽度检查 60 字符上限、重复词、极限词与特殊符号。

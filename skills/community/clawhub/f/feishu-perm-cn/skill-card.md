## Description:

Manage Feishu document, file, folder, and wiki permissions by setting access levels, sharing, or revoking user or group access.

This skill is ready for commercial/non-commercial use.

## Publisher:

MIT-0

## Use Case:

Developers and agents use this skill to help manage Feishu permissions for documents, files, folders, and wiki pages. It supports user-requested sharing, permission changes, and access revocation when the user has the required Feishu authority.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Changing Feishu permissions can grant, alter, or revoke access to documents, files, folders, and wiki pages.

Mitigation: Review the target resource, recipient or group, and permission level before allowing the agent to make changes.

Risk: Permission updates require the user to have sufficient Feishu owner or editor authority.

Mitigation: Confirm the acting account has the required Feishu permissions before attempting permission management.

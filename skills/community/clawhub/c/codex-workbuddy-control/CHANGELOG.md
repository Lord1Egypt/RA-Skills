# Changelog

## 0.1.0 - 2026-11-24

- Added the standard-library task bus with `init`, `status`, `dispatch`,
  `verify`, `claim`, and `complete`.
- Added `WB-*`, `WBV-*`, and `WBC-*` workflows.
- Added SHA-256 manifests, portable-command warnings, shared ledger updates,
  and monthly reviews.
- Added reusable task, receipt, verification-request, and verification-result
  templates.
- Added direct-start prompts, staged prompts, setup notes, and troubleshooting.
- Added isolated regression tests and package validation hooks.
- Added text-free, gradient-free blueprint icons at 512×512 and 256×256, plus
  agent and manifest icon references.

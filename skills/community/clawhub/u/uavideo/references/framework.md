# 特征打标维度体系

> **与内置 91 项 R 码体系的关系**：`feature-system.md` 的 91 项 R 码是主要打标体系（逐项判定、进明细表）；本文档五维度是叙事与结构层的辅助视角，用于钩子/节奏/卖点分析、脚本骨架提取与修改意见。两者对同一条素材的判定不冲突：R 码回答「命中了哪些特征」，本文档回答「结构为什么有效/无效」。

打标时按以下五个维度逐项判定。每个维度产出「判定结果 + 对应标注」，维度名可根据项目替换，但判定逻辑不变。

## 1. 画面制作维度

- **制作方式**：游戏实录 / AI 生成（真人短剧、动画）/ 真人实拍 / CG 动画 / 二创混剪。混合形态按占比注明。
- **画幅与规格**：竖屏 / 横屏 / 方屏；分辨率与编码是否影响观感。
- **节奏速度**：快剪（<2s/镜头）/ 中速 / 慢速长镜头；与题材是否匹配。
- **字幕形态**：无字幕 / 剧情对白字幕 / 歌词唱词 / 高亮关键词。

## 2. 叙事钩子维度（前 3 秒决定 CTR）

常见钩子类型，判定时勾选并描述具体表现：

- **身份反差**：人物设定与处境的强烈对比（如总裁落魄、穷人暴富）。
- **悬念/反差 meme**：非常规画面、违反直觉的行为。
- **颜值钩子**：高颜值人物/角色开场。
- **冲突开场**：直接从争端、战斗、事故切入。
- **利益承诺**：开头直接给出「看完你能得到什么」。
- **话题钩子**：借梗、借热点、借争议话题开场。

判定要求：写明钩子出现的精确时间点（如 0.5s / 2s），以及钩子在整条素材中是否重复出现（单钩子 vs 多钩子循环）。

## 3. 卖点维度

- **核心卖点是什么**：用一句话提炼（如「道具版本迭代带来新鲜感」「收集+养成深度」）。
- **卖点埋点方式**：道具特写锚点 / 数值可视化（成长对比）/ 机制玩法演示 / 口播直述 / 剧情隐喻。
- **娱乐 : 卖点配比**：估算纯娱乐段与卖点段的比例（如 4:1），这决定素材是「CTR 型」还是「转化型」。
- **机制卖点是否娱乐化包装**：机制藏在段子/剧情里 vs 直白讲玩法，前者完播更友好。

## 4. 情绪节奏维度

- **结构型态**：完整单剧情（钩子→发展→收尾）vs 串烧混剪（多个独立小剧场串联）。
- **反转密度**：每 40-70 秒是否有一个反差点/笑点/爆点。
- **收尾设计**：转化口播 / 情绪释放 / 目标悬念（追更钩子）/ 颜值循环。收尾决定单条转化还是合集导流。
- **追更设计**（连载/合集形态）：是否存在跨集目标、人物连续性、进度可视化。

## 5. 平台形态维度

- **投放型态**：单条投放素材 / 内容合集（达人追更）/ 纯享版 / 直播切片。
- **合规元素**：底部合规小字、AI 生成标注、平台审核敏感点。
- **去广告失真提示**：若分析对象是用户提供的合集/拆条版而非原始投放版，涉及转化能力的结论必须标注「仅适用于本形态」。

## 打标输出格式

每条素材产出一行结构化判定（进报告明细表）：

```
| 条目 | 型态定位 | 制作/实录 | 前3秒钩子 | 核心特征 | 卖点埋点 | 收尾 | 结构 | 情节映射 |
```

判定依据必须在分析过程（思维链或工作笔记）中引用具体帧：`frames/f_XX.jpg`（时间点）。

## 多段/合集拆条规则

长合集先按第二步拆条，然后：

1. 逐段打标：段号 + 段名（用画面内容命名，如「换房梗升降床」）+ 时长 + 段型归类；
2. 段型汇总：统计各段型数量与占比，形成「段型配比表」；
3. 段级明细默认只展开代表性视频，其余以索引形式呈现，避免报告膨胀。

## 情节归类（可选）

若用户项目提供情节体系（如「社死名场面」「变装变身」等情节类别），将每条/每段映射到情节并记录；用户未提供时用「叙事型态描述」替代（如「身份反差喜剧串烧」），不编造情节名。

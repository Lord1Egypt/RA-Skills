## Description:

Vibe-Learning creates short, context-aware learning feeds for developers who are waiting on AI coding agents.

This skill is ready for commercial/non-commercial use.

## Publisher:

[skjack](https://clawhub.ai/user/skjack)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use Vibe-Learning during coding-agent wait time to receive 4-6 adjacent, source-linked knowledge cards tailored to the current task context.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Conversation context may be used to form web searches and shape generated learning cards.

Mitigation: Avoid using the skill in chats containing secrets, confidential project details, or sensitive internal topics unless that context can appear in generated cards or searches.

Risk: The skill saves a browser-viewable HTML page that may reflect the current work context.

Mitigation: Review the generated page before sharing or retaining it, and remove any sensitive project details.

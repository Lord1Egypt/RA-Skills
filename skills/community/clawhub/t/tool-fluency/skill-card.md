## Description:

Foundational tool knowledge and usage skills for selecting, using, and maintaining basic hand and power tools and building a functional toolkit on a budget.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

External users and agents use this skill to guide beginner-friendly tool selection, basic hand and power tool operation, fastener choice, safety checks, and budget toolkit planning for home repair tasks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The unpinned `npx clawhub install tool-fluency` path can resolve a package version whose trust depends on the package selected at install time.

Mitigation: Install in a low-privilege environment and prefer a pinned, reviewed `clawhub` package version when available.

Risk: Incorrect or incomplete tool-use guidance can contribute to physical injury or property damage during cutting, drilling, fastening, or power-tool work.

Mitigation: Confirm personal protective equipment, follow the tool manufacturer's manual, check local building requirements, and stop when a task exceeds the user's experience or available safety controls.

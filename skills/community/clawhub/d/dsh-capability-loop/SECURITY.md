# 权限与数据边界（Security & Data Boundaries）

> 本文件回答安全审查会问的四件事：**读什么、写什么、起什么进程、联不联网**。
> 版本：v2.15.0（2026-11-19）。如果你发现与代码不符，以代码为准并提 issue。

## 1. 权限声明

| 能力 | 用途 | 边界 |
|---|---|---|
| 读文件 | 读工程状态、设计/需求/测试产物、DSH 配置与 skill 自身文件 | 只读用户指定或工程内路径；不遍历用户主目录做画像 |
| 写文件 | 写治理状态（`.dsh/loop/state.json`、`shadow-log.jsonl`）、门禁/体检报告（`.tmp/` 或 `%TEMP%`）、用户明确要求的文档 | 默认不写工程源码；写工程外路径必须由调用方显式传参 |
| 子进程 | 跑本 skill 自带的 `powershell` / `python` 脚本（门禁、体检、交接包检查、预检、打包） | 只执行本地已存在的脚本；**不做远程下载后执行**；参数逐个校验，不拼 shell |
| 网络 | **运行时不需要网络** | 文中出现的 `clawhub.ai` / `skillhub.cn` 等 URL 仅用于人工核对与手动发布；skill 自身不上传任何数据 |
| 记忆 | `memory/user-profile.md` 记录用户**明确表达**的交付偏好 | 不记录密码、令牌、身份证件、健康/财务等敏感信息；用户可随时删除该文件 |

`SKILL.md` frontmatter 通过 `allowed-tools` 声明工具范围；本文件补充数据边界。

## 2. 文件写入清单

| 路径 | 谁写 | 内容 | 可否删除 |
|---|---|---|---|
| `<工程>/.dsh/loop/state.json` | `loop-state.ps1` / `loop-gate.ps1` / `capability-audit.ps1` | 档位、阶段、门禁结果、阻断、下一步 | 删除后回到「未接入」 |
| `<工程>/.dsh/loop/project.json` | `loop-state.ps1 -Action init` | 工程名、档位、画像路径 | 同上 |
| `<工程>/.dsh/loop/shadow-log.jsonl` | 接管插件 | 影子档观察计数（会话 id + 时间） | 可删，计数归零 |
| `<工程>/.tmp/**` 或 `%TEMP%/**` | 体检/视觉探测/冒烟脚本 | 报告、探测 HTML/PNG、临时 Chrome profile | 可删；脚本只清理自己创建的那一层 |
| `~/.dsh/skills/**`、`~/.dsh/storages/**` | 仅当用户要求安装/诊断 | 技能本体、市场记录 | 由用户/商店管理 |

**删除策略**：`handoff-smoke.ps1` 每次在用户给的 `-Scratch` 下新建唯一子目录，所有读写与清理只针对该子目录，**绝不清空 `-Scratch` 本身**；`visual-qa-check.ps1` 只删除自己创建的临时 Chrome profile，并拒绝把输出目录写到工作区/`%TEMP%` 之外（显式 `-AllowOutsideOutDir` 才放行）。

## 3. 子进程

- 只调用本 skill `scripts/` 下的脚本与 `node` 测试夹具；不执行网络下载的二进制。
- 面板动作（`/capability-loop …`）有白名单与参数校验，不拼接 shell 命令；超时 + 取消信号会中止子进程。
- `package-skill.ps1` 只读源目录、写输出目录，不修改源文件。

## 4. 隐私

- 用户偏好记忆：只记**明确说出的**偏好（例如「不要用代号」），并注明来源与日期；不推断敏感属性。
- 移除方式：删除 `memory/user-profile.md`（或对应条目）即可；技能不会从其它地方恢复这些内容。
- 影子日志只含会话 id 与时间，用于「观察 3 个会话后提示升级」，内容不含对话正文。
- 截图/HTML 探测产物可能包含界面内容，默认落在工程 `.tmp` 或 `%TEMP%`，由用户自行清理；打包会排除图片与临时目录。

## 5. 对历史扫描提示的解释（2026-11-19 修订）

ClawHub 对 v2.9.5 的安全审计给出 20 条发现，本版逐条处理：

| 扫描发现 | 本版处置 |
|---|---|
| 冒烟脚本递归删除调用方传入的 Scratch（2 条 High） | 改为只创建/删除自己的唯一子目录，永不清空 `-Scratch` |
| 未声明工具范围 | `SKILL.md` 增加 `allowed-tools`，本文件补充能力边界 |
| 建议关闭杀毒软件排除 | 当前版本已无该建议；本文与 playbook 均不推荐削弱防护 |
| 会话持久化（Rogue Agent） | 实际是浏览器临时环境变量；已在 playbook 注明「仅当前进程，不写开机启动/计划任务」 |
| 卸载插件未提示丢失持久化数据 | 插件 README 的卸载步骤补充备份提示 |
| 文档中出现外部 URL（2 条） | 注明「仅人工核对/手动发布用，运行时不联网」，并列入本文件 |
| 打包说明声称排除了敏感材料，实际复制全部文件 | 打包改为明确排除清单 + 凭证命中直接阻断；说明文字与行为一致 |
| 视觉探测被描述为只读，实际写文件 | 描述改为「会写探测产物」，增加输出目录边界与自查清理 |
| 推断并持久化用户偏好缺少隐私告知 | 改为只记明确偏好，给出删除方式与敏感信息禁令 |
| 参考文件未被完整分析（9 条 High） | 包内不再包含图片/测试夹具等非运行必需文件，减少不可分析内容；其余为文档引用，内容均为本仓库明文 |

## 6. 报告问题

请在仓库 issue 中说明：版本（`version.json`）、命令、退出码、复现步骤。不要在 issue 里粘贴真实令牌或用户数据。

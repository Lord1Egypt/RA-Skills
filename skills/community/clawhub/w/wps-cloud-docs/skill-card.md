## Description:

Use this skill to create, read, edit, manage permissions for, and export WPS/Kingsoft cloud documents and spreadsheets.

This skill is ready for commercial/non-commercial use.

## Publisher:

[lumz](https://clawhub.ai/user/lumz)

### License/Terms of Use:

MIT-0

## Use Case:

External WPS users and agents can use the skill to authorize access to WPS cloud services, find and manage documents, edit document and spreadsheet content, manage sharing, and export files.

### Deployment Geography for Use:

Global

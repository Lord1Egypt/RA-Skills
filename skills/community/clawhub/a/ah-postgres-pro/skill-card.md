## Use Case:

Developers, database administrators, SREs, and platform engineers use this skill to assess PostgreSQL deployments, tune performance, plan replication and backups, and improve operational reliability.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Applying PostgreSQL configuration, replication, backup, or security guidance directly to live systems can cause availability, recovery, or access-control issues if the target environment is wrong or untested.

Mitigation: Confirm the target environment, test changes in staging where possible, verify backups and rollback plans, and require explicit approval for production configuration, replication, backup, or security changes.

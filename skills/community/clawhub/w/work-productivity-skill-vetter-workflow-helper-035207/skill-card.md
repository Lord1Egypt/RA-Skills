## Description:

Helps AI-agent users, skill authors, maintainers, and teams create practical Skill Vetter-style workflows for bug fixing, setup hardening, safety review, reliability improvements, and adjacent skill creation.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

AI-agent users, skill authors, maintainers, and teams use this skill to turn demand for skill-vetting workflows into concrete plans, checklists, analyses, code changes, shell commands, or configuration guidance. It is intended for practical productivity, safety, reliability, and adjacent skill-creation work.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad implicit invocation keywords may cause the skill to handle unrelated requests.

Mitigation: Invoke the skill explicitly by name for vetting workflows, or disable implicit invocation when broad automatic activation is undesirable.

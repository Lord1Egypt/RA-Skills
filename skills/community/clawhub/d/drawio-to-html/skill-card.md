## Description:

Convert drawio/diagrams.net flowchart and diagram files into self-contained HTML pages with embedded SVG rendering.

This skill is ready for commercial/non-commercial use.

## Publisher:

[nellyxiaolong-cmyk](https://clawhub.ai/user/nellyxiaolong-cmyk)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to convert diagrams.net or draw.io XML diagrams into standalone HTML files for browser viewing or sharing. It is intended for trusted diagram inputs and reports the generated file path, file size, diagram name, and rendering limitations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill matches its stated converter purpose, but a malicious diagram can make the generated HTML run unwanted browser code.

Mitigation: Use the skill only with trusted personal diagrams and review generated HTML before opening or publishing it.

Risk: Generated files can overwrite existing paths if an output path is chosen carelessly.

Mitigation: Choose output paths deliberately and avoid reusing important filenames.

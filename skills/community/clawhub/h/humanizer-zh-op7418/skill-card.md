## Description:

Humanizer Zh helps agents edit Chinese text to reduce common AI-writing patterns and make the result sound more natural while preserving the original meaning and tone.

This skill is ready for commercial/non-commercial use.

## Publisher:

[zachary2024](https://clawhub.ai/user/zachary2024)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers use this skill to revise Chinese AI-generated drafts, marketing copy, academic summaries, blog text, and file content so the language is more direct, specific, and human-sounding.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Rewrites can unintentionally change factual meaning, citation precision, or compliance-sensitive wording.

Mitigation: Review the edited text before accepting it, especially for factual, academic, legal, or compliance-sensitive writing.

Risk: The README includes an unpinned npx installation command.

Mitigation: Prefer installing from a pinned commit or an inspected local copy.

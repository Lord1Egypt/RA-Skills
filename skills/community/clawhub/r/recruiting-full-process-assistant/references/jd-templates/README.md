### 高级 Java 开发工程师

```markdown
# 岗位需求说明书

## 基本信息
- 岗位名称：高级 Java 开发工程师
- 所属部门：技术部
- 汇报对象：技术总监
- HC 编号：TECH-2026-001
- 岗位级别：P7
- 薪酬范围：35-50K × 15-16 薪

## 岗位职责
1. 负责公司核心业务系统的架构设计、开发与优化
2. 主导微服务架构改造，提升系统可扩展性和稳定性
3. 解决高并发、高可用场景下的技术难题
4. 指导初级工程师，进行代码 review 和技术分享
5. 参与技术方案评审，推动技术规范和最佳实践落地

## 任职要求
### Must-have
- 本科及以上学历，计算机相关专业，5 年以上 Java 开发经验
- 精通 Java 核心技术，熟悉 JVM 原理和性能调优
- 熟练掌握 Spring Boot、Spring Cloud 等微服务框架
- 熟悉 MySQL、Redis、Kafka 等中间件，有实际优化经验
- 具备高并发、分布式系统设计经验
- 良好的沟通能力和团队协作精神

### Nice-to-have
- 有亿级流量系统经验者优先
- 熟悉云原生技术栈（Docker、K8S）者优先
- 有技术博客或开源项目贡献者优先
- 熟悉 AI/LLM 应用开发者优先

## 团队介绍
- 技术团队规模 50+ 人，下设架构组、后端组、前端组、算法组
- 技术氛围浓厚，每周技术分享，鼓励技术创新
- 扁平化管理，工程师话语权高

## 招聘渠道建议
- 主渠道：Boss 直聘、猎聘
- 辅助渠道：拉勾、内推、技术社区（GitHub、掘金）
- 预计招聘周期：30-45 天
```

## 使用指南

1. **复制模板**：根据岗位类型选择对应模板
2. **自定义内容**：修改基本信息、职责要求、团队介绍
3. **明确优先级**：Must-have 是底线，Nice-to-have 是加分项
4. **薪酬范围**：参考市场数据，保持竞争力
5. **渠道建议**：根据岗位特性选择主渠道和辅助渠道

## 注意事项

- ❌ 避免歧视性要求（性别、年龄、婚育、民族等）
- ✅ 突出岗位亮点和团队优势
- ✅ 职责和要求要具体，避免模糊描述
- ✅ 薪酬范围要有市场竞争力
- ✅ 明确招聘周期，便于进度管理

# APP-042 绩效考核与激励设计

## 场景定义

- **目标**：组织绩效考核与激励体系的设计与运行——定标准、量功实、兑现赏罚、驱动中心工作。
- **约束**：单一指标扭曲行为；数字造假与指标游戏；赏罚通胀（频繁悬赏/频繁施罚）；考核流于形式、兑现失信。
- **角色**：CEO、HR/OD 负责人、业务负责人。
- **典型输入**：①年度/季度考核体系设计；②激励方案（奖惩规则）制定；③考核失效治理（造假、通胀、形式化）。
- **边界**：授权边界与分权设计归 APP-041 授权与分权管理；团队日常带兵与凝聚力归 APP-009 团队带兵；薪酬总额与成本约束归 APP-033 成本与费用管控——本 Skill 管"考什么、怎么量、怎么兑、怎么纠"。

## 组合公式

- **顺序**：定标段（MZD-47→MZD-12→MZD-11→GZ-22→GZ-29）→ 执行段（ZJZ-01→ZJZ-03→GZ-12→SZ-20）→ 用果段（MZD-46→MZD-34）；通胀警戒（SZ-48）常态巡检、随时触发回定标段。
- **条件分支**：新岗位/新业务 → 先立基准再考核（定标段权重升，首期只考过程基线）；成熟岗位 → 定标段从简、直接展开执行段；出现数赏数罚征兆 → SZ-48 触发，回定标段重检标准与数据真实性。
- **权重**：ZJZ-01 权重最高——考核的价值在执行闭环，立限考成稽查问责缺一即形式化。
- **冲突裁决**：严格兑现 与 团队士气冲突 → 按 SZ-20 令文齐武裁决：先亲附后约束，卒未亲附而罚之则不服；定量指标 与 数字造假冲突 → 按 MZD-12+ZJZ-03 裁决：数据以可核查功实校验兜底，查实造假按 MZD-46 寻根处置；激励力度 与 成本约束冲突 → 按 GZ-29 量而后与裁决：先量度资源与功实再定激励，不以透支兑现能力换短期冲量。

## 执行步骤

1. **定中心**（MZD-47）：考核体系围绕当期中心工作设计——中心任务指标权重最高，经常性工作次之，不平均用力。
2. **胸中有数**（MZD-12）：指标量化——对成绩与问题有基本数量分析，考核判断不凭印象拍脑袋。
3. **弹钢琴**（MZD-11）：多指标协同——财务、客户、过程、成长十指联动，防单一指标极致导致行为扭曲。
4. **因差而牧**（GZ-22）：差异化考核——按岗位性质、能力层级定不同标准与目标值，不硬性划一。
5. **量而后与**（GZ-29）：激励尺度与层级功实相称——量度而后给予，高职级高目标对高兑现，不超度滥许。
6. **立限考成**（ZJZ-01）：考核规则立后，执行闭环四环——立限（周期与节点）、考成（阶段性核验）、稽查（过程抽查）、问责（结果兑现）。
7. **核名实**（ZJZ-03）：评优晋升以可核查功实为准绳——声望、表态、资历皆"名"，实绩才是"实"。
8. **赏信刑正**（GZ-12）：兑现纪律——赏必信（说到做到）、罚必正（以事实与规则为据），考核信用高于考核力度。
9. **令文齐武**（SZ-20）：文武相济——先亲附后约束；未建立信任与认同就施罚，罚而不服则队伍不可用。
10. **通胀巡检**（SZ-48）：激励通胀自查——频繁加码悬赏（窘）或频繁施罚（困）皆是体系失效之征，出现即回定标段重检标准与根因。
11. **错误寻根**（MZD-46）：失绩先寻根——区分能力不足、资源不足、体系缺陷，根因不同处置不同，不笼统归咎于人。
12. **惩前毖后**（MZD-34）：考核结果用于纠错救人——错误彻底揭发以汲取教训，处置以救治为目的，不搞秋后算账。

## 失效预案

- **考核流于形式**：退回 ZJZ-01 重立执行闭环（立限考成稽查问责四环逐一核查缺哪环）；稽查缺位则补抽查机制，问责缺位则补兑现纪律。
- **数字造假/指标游戏**：退回 ZJZ-03 核名实——以可核查功实（客户、收入、交付物）校验报表数据；查实后按 MZD-46 寻根（是指标设计逼出造假还是人品问题），再按 MZD-34 破立。
- **赏罚通胀**：退回 SZ-48——数赏数罚即窘困之征，停止加码，回定标段重检标准可达性与常规驱动失效的根因。
- **滥罚伤人/队伍离心**：退回 SZ-20 令文齐武 + MZD-34 惩前毖后——先修亲附再谈权罚，处置以救人为界。
- **激励兑付危机**：退回 GZ-29 量而后与——缩减激励面与力度前先守住 GZ-12 已立之赏必兑的信用底线，宁可事前量度从紧，不可事后毁诺。

## Description:

Curates OpenClaw structured memory by reviewing saved entries, extracting durable insights, updating MEMORY.md, and removing outdated items.

This skill is ready for commercial/non-commercial use.

## Publisher:

[zhaobod1](https://clawhub.ai/user/zhaobod1)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and OpenClaw users use this skill to periodically review saved memory entries, remove stale or duplicate items, merge useful long-term memories, and update MEMORY.md with concise summaries.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can delete saved memories and update MEMORY.md during memory maintenance.

Mitigation: Use it only when memory maintenance is intended, and ask the agent to preview proposed deletions and MEMORY.md changes before allowing updates.

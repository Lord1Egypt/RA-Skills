# 脊髓与周围神经定位诊断

## 使用场景

当患者出现以下情况时应用本技能：
- 肢体无力、瘫痪或肌萎缩
- 躯体感觉障碍（麻木、疼痛、感觉缺失）
- 腱反射异常或病理反射
- 大小便功能障碍
- 需鉴别脊髓病变与周围神经病变

## 定位诊断流程

### 第一步：判断中枢性 vs 周围性

**上运动神经元（脊髓/锥体束）损害特征：**
- 肌张力增高（痉挛性）
- 腱反射亢进
- 病理反射阳性（Babinski征等）
- 无明显肌萎缩（晚期可有失用性萎缩）

**下运动神经元（前角/神经根/周围神经）损害特征：**
- 肌张力降低（弛缓性）
- 腱反射减弱或消失
- 病理反射阴性
- 肌萎缩明显

### 第二步：脊髓病变定位

#### 2.1 判断髓内 vs 髓外

根据感觉障碍发展方向判断：
- **髓内病变**：感觉障碍自上向下发展（先累及颈段，后累及骶段）
- **髓外病变**：感觉障碍自下向上发展（先累及骶段，后累及颈段）

#### 2.2 判断完全性 vs 不完全性损害

**横贯性损害**：受损平面以下所有感觉缺失 + 上运动神经元瘫 + 括约肌障碍

**不完全性损害**根据受累结构判断：
- 前角：节段性弛缓性瘫，无感觉障碍
- 后角：同侧节段性分离性感觉障碍（痛温觉缺失，触觉保留）
- 中央管附近：双侧对称性分离性感觉障碍
- 后索：深感觉障碍，感觉性共济失调
- 侧索：同侧上运动神经元瘫 + 对侧痛温觉障碍
- 半切（Brown-Sequard）：同侧瘫+深感觉障碍，对侧痛温觉障碍

#### 2.3 脊髓节段定位

关键皮节标志：
- T4：乳头平面
- T10：脐水平
- T12/L1：腹股沟

关键反射定位：
- 肱二头肌反射：C5-6
- 肱三头肌反射：C6-8
- 膝反射：L2-4
- 跟腱反射：S1-2

脊髓节段综合征：
- 高颈髓(C1-4)：四肢中枢性瘫，可伴膈肌瘫痪
- 颈膨大(C5-T2)：双上肢周围性瘫 + 双下肢中枢性瘫
- 胸髓(T3-L2)：双下肢中枢性瘫，伴束带感
- 腰膨大(L1-S2)：双下肢周围性瘫
- 脊髓圆锥(S3-5)：鞍状感觉缺失，真性尿失禁，无下肢瘫
- 马尾：不对称根性痛，下肢周围性瘫

### 第三步：周围神经病变定位

根据障碍分布模式判断：
- **神经根**：节段性感觉障碍 + 根性痛
- **神经丛**：一个肢体多根周围神经分布区障碍
- **神经干**：单一神经支配区障碍
- **末梢**：四肢远端对称性手套-袜套样障碍

### 第四步：特殊综合征识别

- **脊髓前动脉综合征**：急性起病，分离性感觉障碍（痛温觉缺失，深感觉保留）
- **脊髓后动脉综合征**：深感觉障碍，痛温觉和肌力保留
- **Horner综合征**：C8-T1侧角受损，表现为瞳孔缩小、眼裂变小、面部无汗

## 注意事项

- 脊髓损伤上界应比查体感觉平面高1-2个节段（皮节重叠支配）
- 急性期脊髓休克可表现为弛缓性瘫，2-4周后转为痉挛性瘫
- 需排除脑部病变引起的偏瘫
- 周围神经病变需排除神经肌肉接头疾病（如重症肌无力）

# 皮节分布与体表定位

## 躯干皮神经节段定位（由上至下）

| 节段 | 体表标志 |
|------|----------|
| T2 | 胸骨角水平 |
| T4 | 乳头平面 |
| T6 | 剑突水平 |
| T8 | 肋弓下缘 |
| T10 | 脐水平 |
| T12/L1 | 腹股沟水平 |

## 上肢皮神经分布（臂丛）

| 节段 | 分布区域 |
|------|----------|
| C5 | 上臂外侧 |
| C6 | 前臂桡侧、拇指食指 |
| C7 | 中指 |
| C8 | 前臂尺侧、环指小指 |
| T1 | 上臂内侧 |

## 下肢皮神经分布

| 节段 | 分布区域 |
|------|----------|
| L2-L3 | 股前侧 |
| L4-L5 | 小腿前外侧、足背 |
| S1-S2 | 小腿后侧、足底、股后侧 |
| S4-S5 | 肛周鞍区 |

## 临床应用推理示例

1. 脐水平感觉减退 → 定位T10节段
2. 手部及上肢远端感觉障碍 → 定位C6-C8（颈髓下段或臂丛）
3. 乳头平面以下感觉缺失 → 定位T4节段

# 脊髓传导束解剖与病损表现

## 上行传导束（感觉）

### 薄束和楔束（后索）
- 功能：传导深感觉和精细触觉
- 排列：由内向外依次为骶、腰、胸、颈
- 损害表现：同侧病变水平以下深感觉/精细触觉丧失，感觉性共济失调

### 脊髓丘脑侧束（外侧索）
- 功能：传导痛温觉
- 排列：由内向外依次为颈、胸、腰、骶
- 损害表现：对侧病变水平以下痛温觉丧失

### 脊髓丘脑前束（前索）
- 功能：传导粗触觉
- 损害表现：对侧病变水平以下粗触觉障碍

## 下行传导束（运动）

### 皮质脊髓侧束/前束
- 功能：支配随意运动
- 损害表现：中枢性瘫痪（痉挛性瘫、腱反射亢进、病理反射阳性）

## 髓内/髓外病变鉴别要点

| 特征 | 髓内病变 | 髓外病变 |
|------|----------|----------|
| 感觉障碍发展 | 自上向下 | 自下向上 |
| 分离性感觉障碍 | 常见 | 少见 |
| 括约肌障碍 | 早期出现 | 晚期出现 |
| 根性痛 | 少见 | 常见 |

## 灰质病损定位

- **前角**：下运动神经元性瘫痪（弛缓性瘫、肌萎缩）
- **后角**：节段性分离性感觉障碍
- **侧角C8-T1**：Horner综合征
- **侧角S2-4**：膀胱直肠性功能障碍

# 脊髓血管综合征

## 脊髓血供特点

- **脊髓前动脉**：供应前2/3（前角、侧角、灰质连合、前索、侧索前部）
- **脊髓后动脉**：供应后1/3（后角、后索）
- **易缺血节段**：T4和L1（相邻根动脉分布区交界处）

## 脊髓前动脉综合征

**病因**：脊髓前动脉闭塞

**临床表现**：
- 病灶水平以下上运动神经元性瘫痪
- 分离性感觉障碍（痛温觉缺失，深感觉相对保留）
- 膀胱直肠功能障碍
- 急性起病

## 脊髓后动脉综合征

**病因**：脊髓后动脉闭塞（少见）

**临床表现**：
- 病变水平以下深感觉障碍
- 痛温觉、肌力、括约肌功能常不受累

## 中央动脉综合征

**病因**：根动脉损害

**临床表现**：
- 病变水平相应节段下运动神经元性瘫痪
- 多无感觉障碍和锥体束损害

## 脊髓出血/动静脉畸形

- 出血：急性横贯性损害（截瘫、感觉缺失、括约肌障碍）
- AVM：可产生压迫症状，破裂导致局灶/弥漫性出血

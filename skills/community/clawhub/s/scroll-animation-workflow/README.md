Turn Two Still Frames Into Scroll Animation Code for a Website, in Plain Words

Give your AI agent one website section. It drafts the workflow, in plain words. You make a start frame and an end frame in Whisk. You upload both to Flow and generate an 8 second animation video. You extract the frames with EZGIF at 30 frames per second, about 240 images. Then your AI agent drafts the prompt that turns those images into interactive scroll animation code for your site. The agent drafts, you run the tools, the agent only checks the text you paste back.

Most website sections do nothing when a visitor scrolls past them. A scroll animation makes the section move as the visitor scrolls, and the site feels alive. This skill gives you a short workflow first, frames, then video, then extracted images, then a prompt, with a check at each step, so nothing is called done until the evidence is pasted in the message.

## What good looks like

- A good frame list has one start frame and one end frame, in the same style, with one point.
- A good video is 8 seconds, from the start frame to the end frame.
- A good extraction is about 240 images at 30 frames per second.
- A good prompt says the section, the start frame, the end frame, and that the animation must follow the scroll.
- Every Checked item has pasted text quoted as the evidence.
- Missing items are listed first in the fix draft, in order.
- Nothing is called done until the owner has reviewed the draft.

## How to use it

1. Install the skill in your AI agent (see below).
2. Give your agent the business, the goal of the section, and the audience, in plain words.
3. Ask: "Make a scroll animation with scroll-animation-workflow."
4. Read the frame list first. Both frames must match, same colors, same text, same business name.
5. Read the handoff check. Every Checked item needs pasted text quoted as the evidence. A short description alone is not evidence.
6. Read the fix draft. Approve the frames and the prompt before anything goes live.

If you already give the business, the goal, and the audience up front, the skill does the full workflow and the handoff check in the same reply. It never stops at questions alone.

## Description:

Create and edit Obsidian Flavored Markdown with wikilinks, embeds, callouts, properties, and other Obsidian-specific syntax.

This skill is ready for commercial/non-commercial use.

## Publisher:

[sadlay](https://clawhub.ai/user/sadlay)

### License/Terms of Use:


## Use Case:

External users, developers, and note authors use this skill to create or revise Obsidian vault notes with valid wikilinks, embeds, callouts, frontmatter properties, tags, comments, highlighting, math, Mermaid diagrams, and footnotes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate for general Markdown work inside an Obsidian vault when narrower behavior is expected.

Mitigation: Use narrower trigger wording or explicitly request Obsidian-specific Markdown features when applying the skill.

Risk: Generated notes may contain incorrect or unintended Obsidian-specific syntax.

Mitigation: Review the note in Obsidian reading view and correct wikilinks, embeds, callouts, and properties before relying on it.

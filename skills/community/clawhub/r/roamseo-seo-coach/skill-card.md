## Description:

Enter a friendly RoamSEO coach mode that explains workflows, recommends next steps, and helps users use agents, web search, scraping, and MCP data effectively.

This skill is ready for commercial/non-commercial use.

## Publisher:

[roamseo](https://clawhub.ai/user/roamseo)

### License/Terms of Use:

MIT-0

## Use Case:

External site owners and marketers use this skill to understand RoamSEO workflows, interpret available SEO information, and choose a practical next step with an AI agent.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Coaching advice may be incomplete or poorly matched when project context or current data is missing.

Mitigation: Use the shared project context, distinguish data sources from coaching judgment, and verify consequential recommendations with the relevant SEO workflow.

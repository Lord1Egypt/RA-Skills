## Use Case:

Developers, skill authors, maintainers, and teams use this skill to structure ontology-style work-productivity requests into local-hardware-friendly plans, templates, checklists, code changes, or decision support with a verification note.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad implicit triggers may invoke the skill for general terms such as knowledge, graph, memory, or bug fix.

Mitigation: Restrict implicit invocation where supported and confirm the task is actually about ontology-style or typed workflow productivity before using the skill output.

Risk: Generated workflow, setup, reliability, or adjacent-skill guidance may be incomplete for a specific environment.

Mitigation: Review proposed plans, templates, scripts, code changes, and verification notes against the target environment before applying them.

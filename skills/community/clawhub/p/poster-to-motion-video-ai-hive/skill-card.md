## Description:

Helps brand, ecommerce, marketing, and social teams turn authorized static posters into motion plans, storyboards, AI-HIVE video prompts, generation commands, and acceptance checklists.

This skill is ready for commercial/non-commercial use.

## Use Case:

External creators, brand designers, ecommerce operators, and social media teams use this skill to convert authorized static poster assets into production-ready motion concepts, prompts, AI-HIVE task commands, and delivery checklists. Developers can also use its scripts to create deterministic briefs, call AI-HIVE generation endpoints, and perform basic local video checks or edits.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Downloaded AI results could be written outside the intended output folder if an unsafe API response influences output paths.

Mitigation: Review the skill before installation, use only the official AI-HIVE base URL, avoid elevated privileges, inspect downloaded files, and fix path handling before broad use.

Risk: The skill uploads user-provided media to AI-HIVE for generation tasks.

Mitigation: Provide only media the user is authorized to process and avoid sharing sensitive or private assets unless approved for upload.

## Description:

Generates original images from text prompts and makes targeted edits to reference images, such as changing a model, pose, or outfit.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and ecommerce teams use this skill to generate original imagery from text prompts and make targeted changes to reference images, including changes to models, poses, or outfits.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: ClawScan marked the skill suspicious for transmission of prompts and reference images to external providers and noted that inspection was partial.

Mitigation: Review provider data handling and clarify the incomplete inspection before use; send prompts and reference images only when comfortable with the provider receiving them.

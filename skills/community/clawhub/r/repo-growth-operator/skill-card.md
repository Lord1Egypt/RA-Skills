## Description:

Recommend small, practical growth actions for a public GitHub repository based on releases, skills, docs, and current positioning.

This skill is ready for commercial/non-commercial use.

## Publisher:

[guoma970](https://clawhub.ai/user/guoma970)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, maintainers, and open project operators use this skill to plan small growth and maintenance actions for public GitHub repositories after a release or visible update.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Recommendations could lead to public-facing posts, issues, or repository updates that overstate traction or misrepresent community activity.

Mitigation: Review suggested actions before publishing and keep claims grounded in visible public repository evidence.

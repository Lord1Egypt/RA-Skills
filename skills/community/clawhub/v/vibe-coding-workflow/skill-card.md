## Description:

A structured five-phase workflow for AI-assisted software development that guides agents through requirements, architecture, code generation, debugging, and iteration.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and builders use this skill to structure AI-assisted software projects from an initial idea through implementation, debugging, and later changes. It is especially useful when a project needs reusable Markdown artifacts such as requirements, architecture notes, interface contracts, and debugging summaries.

### Deployment Geography for Use:

Global

# 工作流与踩坑清单

按顺序执行，每一步都有对应的验证动作。跳过验证是自动化失败的主要来源。

## 1. 只读勘察

目标：看清界面、拿到按钮的**原始屏幕坐标**。此时绝不点击任何领奖/提交类按钮。

```bash
python scripts/gui_auto.py shot                          # 全屏
python scripts/gui_auto.py crop shot.png 0 880 340 1075 2  # 裁左下角放大2倍
python scripts/gui_auto.py windows                        # 确认窗口标题
```

### 坐标换算（最大的坑）
读图工具常把截图缩放显示。若直接照预览图上的位置去点，会整体偏移、全部点空。

正确做法：
1. 从**原始全屏截图**按真实像素裁剪一块，例如 `crop(0,880,340,1075)`。
2. 放大 N 倍后读图，得到按钮中心在放大图上的坐标 `(cx, cy)`。
3. 反算原始坐标：`原始x = x0 + cx/N`，`原始y = y0 + cy/N`。
4. 点之前用 `locate` 模板匹配复核一次，确认落点一致。

（真实教训：曾照缩放预览估算坐标，点在 (278,729) 全部落空；改用原始像素裁剪后定位到 (292,1028) 才命中。）

## 2. 模板定位

固定坐标会因窗口最大化/最小化、侧栏列表重排、滚动位置变化而失效。用图像模板定位。

**制作模板**
- 从原始像素截图裁剪，只含按钮核心，去掉圆角边缘和大片白底。
- 尺寸适中（如 130×55 ~ 80×35），太小易误匹配，太大易受周边变化影响。
- 同一个按钮在不同界面状态下多存几份，联合判断。

**匹配参数**
- confidence 默认 0.82。0.8~0.9 通常可靠。
- 低于 0.75 时，形状相似的不同按钮（灰/黑底 + 中文）会互相误匹配。
- 用 `region` 限定搜索区域，既加速又避免全屏误命中。

**验证**
```bash
python scripts/gui_auto.py locate assets/btn.png --conf 0.82 --region 150,950,400,1090
```
连续多天/多状态各测一次，确认命中点稳定。

## 3. 幂等设计

每天自动跑，必须能判断"今天是否已做过"，否则重复点击可能扣分、重复提交或刷屏。

可用信号：
- 按钮文字/颜色变化：`立即领取`(黑) → `今日已领取`(灰)。
- 计数：`本月已兑 1 次`、`连续签到 7 天`。
- 状态图标：绿点/灰点、进度条。

**三态陷阱**（真实案例）：同一个"已领"在不同时刻可能显示为灰色「今日已领取」，也可能显示为黑色「立即前往」；未领是黑色「立即领取」。只认一种会误判。
应对：
- 灰色信号优先级最高（确定已领，跳过）。
- 黑按钮若为"无害点击"（领奖或打开面板都不产生副作用），可统一点一次再靠截图判断结果。
- 靠颜色（采样按钮中心 RGB，灰≈230 / 黑≈0）辅助区分，比文字模板更稳。

## 4. 编排与留证

标准顺序：`激活窗口 → 关残留弹窗 → 打开入口 → 幂等判断 → 点击 → 二次确认 → 关弹窗 → 写日志`。

- 每一步 `shot()` 存到 `logs/`，文件名带时间戳，作为证据。
- 日志写结构化状态，如 `加油站[skipped]：今日已领取`；失败也如实写，不虚构成功。
- 只做低风险动作；涉及支付、删除、对外发送、账号密码的操作一律停下让人确认。
- 绝不读取、打印、外传登录令牌或账号凭据。

## 5. 端到端验证清单

上线前必须全部打勾：
- [ ] `gui_auto.py shot` 在**目标运行环境**能生成截图（会话隔离时会失败）。
- [ ] 入口模板 `locate` 稳定命中。
- [ ] 幂等逻辑在"已领"状态下正确跳过，未重复点击。
- [ ] 业务脚本手动跑一遍，日志与截图都真实产生。
- [ ] 通过 Windows 计划任务手动触发一次，`LastTaskResult=0` 且生成新截图。
- [ ] 现场恢复干净（弹窗已关、无文字被选中、无残留浮层）。

## 常见坑速查

| 现象 | 根因 | 解法 |
|---|---|---|
| 点击全部落空 | 照缩放预览图估算坐标 | 用原始像素裁剪 + 倍数反算 |
| 模板命中错误位置 | confidence 过低 / 模板含边距 | 提高阈值、重裁只留按钮核心、加 region |
| 不同按钮互相误匹配 | 形状相似、都是中文黑按钮 | 颜色采样 + 多模板联合 + 更高阈值 |
| 入口时有时无 | 侧栏卡片被对话列表挤走 | 改用稳定的固定入口（如账号菜单），别依赖浮动卡片 |
| 滚动后按钮位置漂移 | 起始滚动位置不固定 | 用模板全区域搜索定位，别依赖固定滚动量 |
| 后台任务截屏失败 | 会话隔离 | 走 Windows 计划任务，见 session-isolation.md |
| 中文日志乱码 | PowerShell 用 GBK 读 UTF-8 | 文件本身是 UTF-8 即可，用 `python open(...,encoding='utf-8')` 读 |

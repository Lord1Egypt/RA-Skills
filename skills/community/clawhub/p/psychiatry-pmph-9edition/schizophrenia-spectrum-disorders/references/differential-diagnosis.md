# 精神分裂症鉴别诊断详细要点

## 一、继发性精神病性障碍
| 特征 | 表现 |
|------|------|
| 时间关系 | 躯体疾病与精神症状消长平行 |
| 意识状态 | 多在意识障碍背景出现 |
| 幻觉类型 | 幻视为主，昼轻夜重 |
| 体查 | 有阳性发现 |
| 实验室 | 有证据支持 |

## 二、其他精神病性障碍鉴别

### 分裂样精神障碍
- 病程不足1个月

### 急性短暂性精神病性障碍
- 无前驱症状突然起病
- 2周内达顶峰
- 症状每天/日内变化
- 数天内完全缓解
- 若3个月内不缓解，考虑精神分裂症

### 妄想性障碍
- 妄想结构严密系统、有事实基础、不荒谬
- 思维有条理
- 行为情感与妄想一致
- 无智能人格衰退
- 一般无幻觉

## 三、心境障碍鉴别

### 严重抑郁伴木僵 vs 紧张性木僵
| 特征 | 抑郁木僵 | 紧张性木僵 |
|------|----------|------------|
| 情感 | 非淡漠，忧心忡忡 | 淡漠 |
| 应答 | 耐心询问有简短切题应答 | 无应答 |
| 肌张力 | 不高 | 高，违拗 |

### 躁狂兴奋 vs 精分兴奋
| 特征 | 躁狂 | 精分 |
|------|------|------|
| 情感 | 活跃生动，高涨 | 不协调，不高涨 |
| 接触 | 主动 | 呆板 |
| 动作 | 与情绪一致 | 单调怪异 |
| 思维 | 奔逸但连贯 | 破裂 |

## 四、分裂情感障碍(SAD)诊断要点
必须全部满足：
1. 精神病性症状和情感性症状同时或相差几天出现
2. 符合精神分裂症全部诊断要求
3. 情感症状满足心境发作之一（抑郁必须包括情绪低落）
4. 共同存在至少1个月
5. 排除躯体疾病或物质所致

## 五、分裂型障碍诊断要点
- 8项异常模式中至少多项存在
- 症状连续或发作性，至少持续2年
- 从未符合精分、SAD、妄想性障碍要求
- 短暂精神病性症状不超过1个月

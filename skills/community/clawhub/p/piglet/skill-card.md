## Description:

Practical Python craftsmanship guidance based on One Python Craftsman for writing, refactoring, or reviewing Python code across naming, control flow, data structures, functions, exceptions, loops, decorators, imports, file I/O, edge cases, and modern syntax choices.

This skill is ready for commercial/non-commercial use.

## Publisher:

[psiace](https://clawhub.ai/user/psiace)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill when creating, refactoring, or reviewing Python code for practical craftsmanship concerns such as naming, branching, data handling, error handling, imports, file I/O, and readability.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Python style or refactoring advice may be applied to code where local constraints require a different choice.

Mitigation: Review recommendations against project tests, style rules, and maintainability requirements before applying changes.

Risk: The skill may suggest pairing with friendly-python when that skill is not available in the current environment.

Mitigation: Treat the pairing suggestion as optional and proceed with this skill's bounded Python guidance when friendly-python is unavailable.

## Description:

Generates project-specific verifier skills for web, CLI, or API runtime checks that a Verify agent can discover automatically.

This skill is ready for commercial/non-commercial use.

## Publisher:

[wimi321](https://clawhub.ai/user/wimi321)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to inspect a project, identify web, CLI, or API surfaces that need runtime verification, and generate reusable verifier skill folders with setup guidance.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated verifier skills may include authentication handling or self-update behavior that is not clearly scoped or user-controlled.

Mitigation: Review generated verifier skills before running or committing them, require explicit approval for updates, prefer pinned templates or versions, and use normal code review for generated verifier changes.

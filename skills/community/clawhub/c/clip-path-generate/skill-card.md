Developers and designers use this skill to generate CSS clip-path declarations for common, preset, and custom shapes, with optional Safari-compatible vendor-prefixed output.

## Known Risks and Mitigations:

Risk: Generated clip-path percentages may not produce the intended visual shape or may need browser-specific compatibility handling.

Mitigation: Review the generated percentages in the target UI and request the optional -webkit-clip-path prefix when Safari compatibility is required.

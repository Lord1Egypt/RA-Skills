## Description:

A reusable template and workflow that helps Chinese mathematics teachers create, build, and validate interactive HTML math slides.

This skill is ready for commercial/non-commercial use.

## Publisher:

[caesium-inaba](https://clawhub.ai/user/caesium-inaba)

### License/Terms of Use:

MIT

## Use Case:

Chinese mathematics teachers use this skill to plan and create lessons as interactive HTML slides, with formulas, geometry, and teacher-controlled reveals. It guides building and checking a self-contained presentation for offline classroom playback.

### Deployment Geography for Use:

Global

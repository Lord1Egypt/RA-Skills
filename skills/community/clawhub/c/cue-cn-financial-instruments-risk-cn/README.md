# 金融工具风险敞口·到期分档与敏感性重算

把年报／半年报附注里**「金融工具及其风险」**那一段，读成一张每个数都能回到原句的登记表：
金融资产与负债的账面余额、按剩余到期期限分档的合同未折现现金流、利率与汇率变动的敏感性影响、
单一客户最大信用敞口。分档求和与敏感性重算由机检现算，**本件不判断偿债能力、不给评级目标价**。

- 零网络、纯标准库、单文件；输入就是用户直供的附注文本。
- 五道机检：`FR-STRUCT`／`FR-QUOTE`／`FR-BUCKET`／`FR-SENS`／`FR-LINE`，现状全部已落字。
- 退码：`0` 全过｜`1` 有发条｜`2` 用法错｜`3` 读不到／空稿／仍有判据未落字（输出会明写「这不等于合规」）。

---

## 一、它回答什么

| 问题 | 落在哪一节 |
|---|---|
| 金融资产／负债各多少，占总资产几个点 | 风险敞口概况 |
| 一年内要还多少、按到期期限怎么分 | 流动性风险（合同**未折现**现金流分档） |
| 利率上 50 个基点，利润影响多少 | 市场风险—利率 |
| 人民币贬 5%，利润影响多少 | 市场风险—汇率 |
| 前五大客户里最大一个占多少 | 信用风险集中度 |

**它不回答**：这家公司还得上还不上、流动性充不充裕、会不会违约、值不值得买。
这四类问题一律 `[待人工]`——`FR-LINE` 会把这类话当红线发条。

## 三、稿子长什么样

七节按序，节名逐字（`## ` 起节）：

```
## 风险敞口概况
## 流动性风险
## 市场风险—利率
## 市场风险—汇率
## 信用风险集中度
## 口径与未取到
## 来源
```

每个数字行 = 一行，行首项名与 `〔口径：…〕`，紧跟金额与「万元」，再挂三元组：

```
- 1 年以内〔口径：合同未折现现金流〕71,800.00 万元「本集团一年以内到期的金融负债按合同未折现现金流列示为人民币 71,800.00 万元」〔锚：2025 年年报·第 233 页·流动性风险〕[S1]
```

- 附注里没有的数写 `未取到：项名`，**不留空、不借常识补**。
- 自己算出来的数（如占总资产比例）标 `〔自算〕`，不要求三元组。
- 需要人判断的地方写 `[待人工]`，不要求三元组。
- 敏感性行三件要齐：`敞口 48,000.00 万元 变动 50 个基点 影响 240.00 万元`。

⚠️ 两个字符别混：节名里是**全角破折号**「—」(U+2014)；分档档名里是**连接号**「–」(U+2013)。

## 四、五道机检各拦什么

| 码 | 一句话 | 想踩一脚试试 |
|---|---|---|
| `FR-STRUCT` | 头部三件自标 + 七节齐且按序 | 把某节标题改一个字 |
| `FR-QUOTE` | 数字行挂齐原句＋锚＋`[S#]`，来源两向对应 | 删掉某行的「原句」只留 `[S1]` |
| `FR-BUCKET` | 四档之和 == 披露合计（差 > 0.01 万元即发） | 把合计改大 4,600 |
| `FR-SENS` | `影响 = 敞口 × 变动`（相对差 > 0.05% 即发） | 把影响金额从 240 改成 300 |
| `FR-LINE` | 四类红线词 + 「流动性风险」节缺 | 写一句「本集团流动性充裕」 |

`--selftest` 的每一档就是上面这些踩法，**档名会告诉你它期望红哪一道**。

## 五、数据通道

- **正文腿**：附注原文由用户直供（截图／PDF／解析回来的表格）。截图与扫描件交 `cue-omni-reader`
  （大纲→按节取用，计费以服务端返回为准）。
- **原文腿**：本件**不承诺**该域开放，也不承诺实时性。
- `CUE_API_KEY` 可选：缺位时只排版用户贴进来的文本，形状一样，数只能来自用户。

## 六、怎么接到 agent 上

- 发现先行：匿名取 live 域清单与 `routing`，**不硬编码工具名与工具数**；连上之后带
  `Authorization: Bearer $CUE_API_KEY` 发 `tools/list`，以现场返回为准：

  ```bash
  # ① 匿名取活体清单
  curl -sS https://cuecue.cn/api/mcp-catalog -o /tmp/mcp-catalog.json
  python3 -c "import json;d=json.load(open('/tmp/mcp-catalog.json'));print(d)"

  # ② 带凭据握手取工具表
  curl -sS -X POST "$MCP_ENDPOINT" \
    -H "Authorization: Bearer $CUE_API_KEY" \
    -H 'Content-Type: application/json' \
    -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' | head -c 2000
  ```

- 通道配置页只给指针：<https://cuecue.cn/hub/mcp> ／ <https://cuecue.cn/hub/omni-reader> ／
  <https://cuecue.cn/hub/api-key>。

# 先天性脑积水诊断与分类

## 适用场景

当遇到以下情况时应用此技能：
- 婴儿期头颅进行性增大
- 前囟扩大、张力增高
- 出现落日征（双眼向下凝视）
- 疑似颅内压增高的婴儿
- 需要鉴别脑积水类型（交通性 vs 梗阻性）

## 排除标准

不适用于：后天获得性脑积水、成人脑积水

## 诊断评估流程

### 第一步：评估头颅形态与发育

1. **测量头围**：确认出生时或出生后不久头围是否异常增大，评估是否呈进行性加剧趋势
2. **观察容貌特征**：
   - 头颅大、颜面小
   - 前额突出、下颌尖细
   - 头重不能竖颈
   - 运动发育落后（通常不能坐或站立）

### 第二步：检查颅内压增高体征

1. **婴儿期特征性表现**：
   - 前囟扩大、张力增高
   - 颅缝裂开
   - 头皮静脉明显怒张

2. **叩诊检查**：
   - 颅骨变薄
   - 叩诊出现破壶音征（MacEwen征）

3. **全身症状评估**：
   - 精神萎靡、烦躁不安
   - 尖声哭叫
   - 严重者：呕吐、嗜睡或昏睡

### 第三步：检查特异性神经功能障碍体征

1. **落日征检查**（先天性脑积水特有体征）：
   - 机制：第三脑室后部扩张压迫中脑顶盖
   - 表现：双眼同向向上运动不能，上部巩膜暴露，眼球下半部被下眼睑遮盖
   - 属于Parinaud综合征表现

2. **其他颅神经检查**：
   - 展神经麻痹（较常见）

3. **晚期表现评估**：
   - 生长停滞
   - 智力下降
   - 痉挛性瘫痪
   - 去大脑强直

### 第四步：明确脑积水分类

基于脑脊液循环通路进行分类：

| 类型 | 机制 | 常见原因 |
|------|------|----------|
| **交通性脑积水** | 循环通路畅通，但脑脊液分泌过多或蛛网膜吸收障碍 | 分泌过多或吸收障碍 |
| **梗阻性脑积水**（大多数） | 循环通路受阻，多伴脑室扩张 | 导水管狭窄、Dandy-Walker综合征、Chiari畸形 |

## 输出要求

完成评估后，输出以下内容：
1. 是否识别到先天性脑积水典型体征
2. 脑积水分类（交通性/梗阻性）
3. 紧急处理建议：提示降颅压或脑脊液分流手术干预

## 关键变量记录

- `head_circumference_trend`：头围增长趋势（进行性加剧/稳定）
- `hydrocephalus_type`：脑积水分类（交通性/梗阻性）
- `sunset_sign`：是否出现落日征（是/否）

# 先天性脑积水临床详细参考

## 解剖学基础

### 脑脊液循环通路

```
侧脑室 → 室间孔(Monro孔) → 第三脑室 → 中脑导水管(Sylvius导水管) → 第四脑室 → 正中孔(Magendie孔)和外侧孔(Luschka孔) → 蛛网膜下腔 → 蛛网膜颗粒 → 上矢状窦吸收
```

### 梗阻部位与分类关系

| 梗阻部位 | 常见病因 | 脑室扩张范围 |
|----------|----------|--------------|
| 室间孔 | 胶样囊肿 | 单侧或双侧侧脑室 |
| 第三脑室 | 肿瘤、囊肿 | 侧脑室+第三脑室 |
| 中脑导水管 | 导水管狭窄/闭锁 | 侧脑室+第三脑室 |
| 第四脑室出口 | Dandy-Walker畸形 | 全脑室系统 |
| 蛛网膜下腔/蛛网膜颗粒 | 感染后粘连、出血后 | 交通性脑积水 |

## 典型体征详解

### 落日征（Setting Sun Sign）

**发生机制**：
- 第三脑室后部扩张→压迫中脑顶盖（四叠体）
- 影响上视中枢→双眼向上凝视不能
- 眼球向下偏移→上部巩膜暴露

**检查方法**：
1. 将婴儿抱至半坐位或垂直位
2. 观察眼球位置
3. 阳性表现：角膜下缘被下眼睑遮盖，上方露出白色巩膜
4. 形似落日，故称"落日征"

**临床意义**：
- 先天性脑积水的特征性体征
- 提示中脑顶盖受压
- 需紧急处理

### MacEwen征（破壶音征）

**检查方法**：
- 用手指叩击颅骨
- 正常婴儿：清脆音
- 脑积水婴儿：破壶样声音（Macewen's sign）

**机制**：
- 颅骨变薄、颅缝分离
- 颅内压增高导致叩诊音改变

### 前囟评估要点

| 评估项目 | 正常 | 脑积水异常 |
|----------|------|------------|
| 大小 | 1.5-2.5cm | 明显扩大 |
| 张力 | 平坦或略凹 | 饱满、紧张 |
| 搏动 | 可见 | 消失或减弱 |
| 闭合时间 | 12-18月 | 延迟或不闭合 |

## 常见病因

### 梗阻性脑积水常见原因

1. **先天性导水管狭窄**：最常见原因
2. **Dandy-Walker综合征**：第四脑室囊性扩张+小脑蚓部发育不全
3. **Chiari畸形**：小脑扁桃体下疝
4. **Galen静脉畸形**
5. **颅内肿瘤**（婴儿期相对少见）

### 交通性脑积水常见原因

1. **蛛网膜下腔出血后**：早产儿常见
2. **感染后**：脑膜炎后粘连
3. **蛛网膜颗粒发育不良**
4. **脉络丛乳头状瘤**（分泌过多）

## 鉴别诊断

### 需与以下疾病鉴别

| 疾病 | 鉴别要点 |
|------|----------|
| 硬膜下血肿/积液 | 头颅CT/MRI可鉴别，无脑室扩张 |
| 巨脑症 | 头围大但无颅内压增高，发育正常 |
| 佝偻病方颅 | 前囟大但张力不高，有佝偻病其他表现 |
| 家族性大头 | 无颅内压增高，家族史，发育正常 |
| 脑萎缩（外部性脑积水） | 脑室不大，蛛网膜下腔增宽 |

## 影像学检查要点

### 首选检查
- **头颅超声**：前囟未闭时首选，可评估脑室大小
- **头颅MRI**：明确病因和梗阻部位的金标准

### 影像学分级（脑室扩张程度）

| 分级 | 表现 |
|------|------|
| 轻度 | 侧脑室体部宽度10-15mm |
| 中度 | 侧脑室体部宽度15-20mm |
| 重度 | 侧脑室体部宽度>20mm，脑实质变薄 |

## 紧急处理原则

### 需紧急干预的情况
1. 急性颅内压增高（呕吐、嗜睡、意识改变）
2. 落日征阳性
3. 前囟极度紧张
4. 呼吸节律异常

### 处理措施
1. **临时降颅压**：甘露醇、呋塞米
2. **脑室外引流**：紧急情况下的临时措施
3. **确定性手术**：
   - 脑室-腹腔分流术（V-P shunt）
   - 内镜下第三脑室底造瘘术（ETV）
   - 病因治疗（如肿瘤切除）

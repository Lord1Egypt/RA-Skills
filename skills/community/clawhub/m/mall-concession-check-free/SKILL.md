# 商场联营抽成与保底核对（免费）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 核对过程不需要联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：财务、出纳等岗位在**每月结账 / 对账 / 盘点**这类固定节点上，
必须把这张表核一遍才能往下走。

**这张表会逐项核对什么**：商场联营抽成与保底核对表的逐行算术、合计勾稽、重复与空缺检测。

每条结论都带**原文行号与出处**，可被第三方用同一口径复算；
材料不足时**不给结论**，会明确列出还缺什么。

## 常见错法（这张表里真的会有人这么填）

1. **销售额口径没对齐就直接乘抽成率**：同一个铺位，POS 流水是**含税还是不含税**、退货与折扣
   有没有冲减（按发生期冲还是追溯冲）—— 口径不一样，抽成租金能差出一大截。先把口径写进备注
   （含税 / 不含税、退货怎么冲减），再让销售额 × 抽成率；本工具只核这一乘法，
   **口径本身要你与合同对齐**。
2. **抽成率阶梯没有切换**：合同常写"月销售额 50 万以内 8%、超过部分 10%"或"跨过 100 万整月升档"。
   月底销售额跨档了，费率还沿用上月的老数，抽成租金就少算（或多算）。本工具会核
   「销售额 × 抽成率 = 抽成租金」，但**填进去的抽成率必须是你按档位算出来的那一个**。
3. **保底与抽成"孰高"写反，或者只取了一边**：联营合同是**抽成与保底孰高**。抽成 4 万、保底 6 万
   时按抽成计就少收 2 万；抽成高于保底时按保底计就少收更多、还会少开票。本工具的
   「应收合计」复算（max(抽成, 保底) + 物业费 + 推广费）会当场把"只取一边"的算法抓出来。
4. **物业费按建筑面积还是套内面积没写清**：物业费单价乘哪个面积（建筑面积含公摊 / 套内 / 计租面积）
   各商场口径不同；同一张表里几个铺位混用两种面积口径，合计一定对不上。核对前先确认这一列
   是按哪个面积算的，并在备注里写明。
5. **推广费重复计**：推广费（企划费 / 市场推广费）有的是固定月费、有的按销售额比例、有的按活动另收；
   月结单里既收了"固定推广费"、又在活动费里再收一次，或者物业费里已经打包了推广费还单列一行 ——
   都会让应收合计虚增。逐户核时把这一列与合同、活动确认单对一遍。

## 需要完整档时（可选）

本免费版是**完整可用的核心产出**，本版本**不包含**下面这些项：

- 已收金额超过应收合计提示
- 抽成率与合同约定抽成率不一致提示（阶梯切换 / 临时降点未同步）
- 保底租金未按孰高原则计收提示（抽成低于保底却按抽成计）
- 同一铺位重复计租同一期间提示（金额不同、按行数重复计租）
- 空置铺位仍有应收提示

同名工具的**完整档**是另一个独立商品（条款与条件以它自己的商品页为准）；两档的差别**就是上面这些，没有别的**。

## 边界（请务必知道）

本工具**不做**引擎 `CHECKS_OUT_OF_SCOPE` 里列的那些判断；
材料不足时**不给结论**，也不会输出「未发现问题」。

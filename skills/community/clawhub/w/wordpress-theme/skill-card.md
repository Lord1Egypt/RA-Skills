## Description:

Guides agents through converting static HTML, CSS, and JavaScript websites into WordPress themes while preserving design fidelity and adding WordPress integration patterns.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill to turn static website assets into a WordPress theme structure with templates, enqueue logic, menus, Customizer settings, and dynamic content replacements.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated or reused WordPress snippets may omit production hardening for escaping, sanitization, nonce checks, capability checks, prepared queries, or untrusted content handling.

Mitigation: Review generated theme code before production use and require standard WordPress escaping, sanitization callbacks, nonce and capability checks, plus extra review for forms, authentication, custom database access, or untrusted content.

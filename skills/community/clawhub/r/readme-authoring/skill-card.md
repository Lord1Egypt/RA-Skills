## Description:

Deep README workflow for audience definition, value proposition, quickstart, configuration, troubleshooting, contributing, and badges/links hygiene when bootstrapping repos or improving onboarding for open source or internal libraries.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, maintainers, and documentation contributors use this skill to plan or improve READMEs for new repositories, open-source releases, and internal libraries. It guides audience definition, quickstart content, configuration notes, contribution paths, and maintenance signals.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated README content can accidentally include real secrets or inaccurate security and operational claims.

Mitigation: Review generated documentation before publishing, especially configuration, security, and operations sections.

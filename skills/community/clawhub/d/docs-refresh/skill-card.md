## Description:

Refresh authoritative docs through a routed progressive-disclosure workflow.

This skill is ready for commercial/non-commercial use.

## Publisher:

[jzg-lab](https://clawhub.ai/user/jzg-lab)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill after repository changes to decide whether durable documentation needs updating and to route the update to the smallest authoritative document.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may inspect repository changes and update documentation files.

Mitigation: Review generated documentation changes before committing them.

# 第03课 条件判断

> 老孟带你学中文编程 · 第 03 课　|　语言面 ZHC-LANG 2.0　|　源码 `示例/第03课_条件判断.zc`
> 运行：`python -X utf8 zhc.py 示例/第03课_条件判断.zc --run`

## 一、本课目标

用 `如果 / 否则如果 / 否则 / 结束` 写多分支，用 `且 / 或 / 非` 组合条件。

## 二、语法要点

| 写法 | 说明 |
|---|---|
| `如果 条件 则 … 结束` | 单分支 |
| `否则如果 条件 则` | 多分支串联 |
| `否则` | 兜底分支 |
| `且 / 或 / 非` | 与、或、非；比较符 `== != > >= < <=` |
| `真 / 假` | 逻辑字面量 |

## 三、完整代码

```zc
# 第03课 条件判断
# 结构：如果 条件 则 … 否则如果 条件 则 … 否则 … 结束
# 注意收尾统一写 结束，没有“结束如果”这种写法。

定义 分数 为 整数 86

如果 分数 >= 90 则
    输出 "评级：优"
否则如果 分数 >= 80 则
    输出 "评级：良"
否则如果 分数 >= 60 则
    输出 "评级：及格"
否则
    输出 "评级：不及格"
结束

# 复合条件：且 / 或 / 非
定义 出勤 为 整数 95
如果 分数 >= 60 且 出勤 >= 90 则
    输出 "可以参加评优"
否则
    输出 "不参加评优"
结束

如果 非 (分数 >= 90) 则
    输出 "还没到优秀线"
结束

# 逻辑值也能直接当条件（定义逻辑量要写全 为 逻辑 真/假）
定义 没缺考 为 逻辑 真
如果 没缺考 则
    输出 "成绩有效"
结束
```

## 四、运行结果

```text
评级：良
可以参加评优
还没到优秀线
成绩有效
```

## 五、易错点

- 收尾统一写 `结束`，没有 `结束如果` 这种词。
- 分支里的语句**靠缩进表意但不靠缩进解析**，可读性要自己保证。
- 定义逻辑量要写全类型：`定义 没缺考 为 逻辑 真`；只写 `为 真` 会报 `[E205] 此处应为类型`。
- 文本不能用 `==` 比大小，要用 `文本相同(文本A, 文本B)`。

## 六、动手练习

1. 输入四档分数（优/良/及格/不及格）的边界值各测一次：90、89、60、59。
2. 增加一个「缓考」分支，条件是出勤低于 60。
3. 用 `或` 把两个通过条件合成一个。

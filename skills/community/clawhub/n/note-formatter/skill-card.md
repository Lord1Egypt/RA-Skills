## Description:

Markdown note formatting and cleanup utility for cleaning raw notes, standardizing Markdown structure, fixing heading hierarchies, and converting messy pasted text into clean documents.

This skill is ready for commercial/non-commercial use.

## Publisher:

[terrycarter1985](https://clawhub.ai/user/terrycarter1985)

### License/Terms of Use:

MIT-0

## Use Case:

External users, employees, and developers use this skill to clean up meeting notes, drafts, and Markdown files before sharing or publication. It helps standardize headings, lists, whitespace, code block language hints, and line wrapping.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill's normal behavior may rewrite Markdown formatting in important documents.

Mitigation: Use it only on files intended for formatting changes, and save a new copy or review diffs before accepting edits to important notes.

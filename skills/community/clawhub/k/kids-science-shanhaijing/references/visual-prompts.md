# 首帧、封面与图生视频提示词

## 一、首帧图（9:16，1080×1920）

### 六段结构（顺序固定，重要的放前面）

```
[主体+动作] 谁在做什么、朝哪、手里有什么、什么颜色
[环境] 山石/水面/古书页/庭院，只写 1-2 个元素
[光线] 柔和暖光从左上来，背景虚化，无硬边阴影
[风格] 3D卡通+水墨肌理混合渲染，低饱和矿物色调（赭石/黛青/月白/陶土红/竹青），软乎乎质感，圆润造型
[构图] 竖版9:16，主体靠前占画面1/3，视线看向主体，背景干净
[文字] 上方标题「……」，全图最大字号，圆体，深褐色描边；下方小字「……」，字号为标题一半
```

### 三条硬指标（缺一条重出）

1. **标题**占画面高度约 1/4，是全图最大元素，比神兽的眼睛还大。
2. **主体**靠前占画面 1/3 以上；有小孩出镜时脸要大、眼睛要亮。
3. **背景**只留 1-2 个元素（山影／云气／古书页纹理任选），不许堆满。

### 负面词（每条都带）

```
獠牙，血浆，断肢，多头堆叠，恐怖表情，尖刺鳞片，真实照片质感，暗调，阴影过重，密集人群，西方奇幻风格，品牌logo，侵权卡通形象，错别字，中文缺笔画，水印，文字压住人脸，文字超框，多余手指
```

### 示例（九尾狐）

> 一只奶白色狐狸站在青丘山的石台上，九条蓬松尾巴在身后扇形铺开，圆脸，琥珀色眼睛看向镜头，没有獠牙；背景是淡墨山影和一缕云气；柔和暖光从左上方照入，浅米色底，背景虚化；3D卡通+水墨肌理混合渲染，低饱和矿物色调，赭石与竹青点缀，软乎乎质感，圆润造型，无硬边阴影；竖版9:16，狐狸居中靠前占画面三分之一；画面上方标题「九条尾巴的狐狸」全图最大字号圆体深褐色描边，下方小字「书里真这么写」字号为标题一半。

## 二、封面素材（双比例）

同一画面出两版：3:4（1080×1440）与 4:3（1440×1080）。**先出 3:4，再用同一句提示词换比例重出**，保证两张是一套。

### 版式

```
上 1/4：主标题（≤20字），最大字，两行以内
中间：神兽半身靠前，眼神温和，看镜头
下 1/4：副标题（≤12字）+ 右上角小角标「山海经」
```

### 提示词模板

```
[神兽锚点，逐字抄 character-bible]，半身，正面看向镜头，[表情]
[道具/环境] 在画面中清晰可见
柔和暖光，浅米色或宣纸色背景，低饱和矿物色调，3D卡通+水墨肌理混合渲染，软乎乎质感
{3:4 或 4:3}构图，主体占画面二分之一靠下
上方主标题「{≤20字}」，最大字号，圆体，深褐色，赭石色描边
下方副标题「{≤12字}」，字号为主标题一半
右上角小角标「山海经」
```

### 封面文案五种写法

| 类型 | 例子 | 适用 |
|---|---|---|
| 疑问式 | 「九尾狐真有九条尾巴？」 | 神兽造型类 |
| 反常识式 | 「太阳其实没有在跑」 | 天文、天体类 |
| 古人视角式 | 「古人被雷声吓出来的神兽」 | 雷、火、洪水类 |
| 数字式 | 「一条腿，一声雷」 | 夔、毕方这类特征极强的 |
| 对照式 | 「书上写九条，其实一条」 | 神兽 vs 真动物的落差 |

### 封面禁忌

- 主标题超过 20 字（会被截断）
- 主副标题一样大（没有层级）
- 背景三个以上物体（脏）
- 用凶相、张口露齿、血污做封面（限流，也吓到孩子）
- 拿生僻字当主标题（讙、夔这种字单独放封面上，多数人不会读，点击率掉）

## 三、图生视频提示词（每镜一段）

首帧图当参考图，提示词只写**变化**，不重写画面：

```
镜头{快速推近/缓慢拉远/环绕}；[神兽] [一个明确动作，如"九条尾巴依次轻轻摆了一下"]；[一个环境微动，如"云气缓慢飘过"]；光线不变；[情绪]；不要人物走位，不要换场景，不要新增物体
```

- 一条只写一个动作。第二个动作另出一段。
- 尾巴、翅膀、水波这类多部件动作要写"依次"或"轻微"，否则模型会把九条尾巴糊成一团。
- 明确写「不要换场景、不要新增物体」。
- 物理细节写到毫米级：脚踩地不离地、水不漫过石台、树叶不乱飞。

## 四、竖屏字幕与文字位置

- 字幕在画面下 1/5，白字深褐描边 2px，单行 ≤14 字。
- 原文摘句那一镜，字幕用竖排小窗样式（右起竖排），字号比普通字幕小一档，配一个"《山海经·XX经》"的小标注在左上方。
- 标题、字幕、角标三者不许重叠。

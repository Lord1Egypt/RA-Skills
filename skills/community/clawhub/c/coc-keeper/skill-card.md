## Description:

Helps an agent host Chinese-language Call of Cthulhu 7th Edition tabletop games as the Keeper, managing characters, dice rolls, scenes, and campaign progress.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ycqaq233](https://clawhub.ai/user/ycqaq233)

### License/Terms of Use:

MIT-0

## Use Case:

Players and game hosts use this skill to have an agent prepare and run a Call of Cthulhu campaign, resolve actions, track character state, and resume saved sessions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Campaign notes and player state are saved locally, and unrelated private documents could be included if supplied as module material.

Mitigation: Use a dedicated campaign folder and provide only the documents intended for play.

Risk: The default Keeper persona may not suit every group.

Mitigation: Review the included persona before play and replace it if needed.

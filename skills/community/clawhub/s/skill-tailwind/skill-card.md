## Description:

Write, configure, migrate, and review Tailwind CSS v4 styles across stacks, including CSS-first configuration, design-token mapping, dark mode, states, accessibility, responsive behavior, and utility-first or BEM plus @apply organization.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Developers and engineers use this skill to implement, migrate, and review Tailwind CSS v4 styles in framework-agnostic projects. It helps agents produce technically correct Tailwind guidance, code, configuration, and review feedback while deferring visual direction and design-token values to the project design system.

Global

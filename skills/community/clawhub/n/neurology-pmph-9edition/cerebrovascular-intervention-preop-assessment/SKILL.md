# 脑血管介入术前基础状况评估

## 适用场景
当患者已决定进行脑血管病血管内介入手术，且已获取基础病史、实验室检查及心肺肾功能数据时，使用此技能进行全面的术前评估与干预方案制定。

## 核心评估工作流

### 1. 一般情况与绝对禁忌证排查
检查患者是否存在以下不适宜手术的情况，若存在则**禁止手术**：
- 年龄过大、恶性肿瘤晚期或恶病质、预期寿命 < 2年。
- 影像学显示责任血管供血区存在大面积脑梗死（风险大、获益小）。
- 血糖控制不佳的糖尿病、未控制的甲状腺功能亢进。
- 当前发热或存在活动性炎症病变。

### 2. 心肺功能评估
评估患者对手术及麻醉的耐受能力：
- **心功能**：若心功能Ⅲ级以上，评估手术耐受性并制定监护预案。
- **肺功能**：若存在明显肺功能异常，评估全麻耐受差的风险。
- **心率与心律**：若基础心率 ≤ 50次/分或动态心电图提示长间歇，**必须**安排在临时心脏起搏器保护下进行手术。
- **冠脉情况**：若存在严重冠脉狭窄，需制定避免术中/术后长时间低血压的策略，以防急性冠脉综合征。

### 3. 肾功能评估
根据肾功能状态制定对比剂及药物管理策略：
- 评估基础肾功能，决定对比剂类型并尽量最小化对比剂用量。
- 若单纯血肌酐升高，执行围手术期水化方案。
- 审查当前用药，停用或替换肾毒性药物。
- 针对服用二甲双胍的肾功异常患者，制定个体化停药或换药方案。

### 4. 出血风险评估
排查出血高危因素并调整抗凝药物：
- 评估是否存在未控制的消化性溃疡、不明原因大便隐血等。
- 针对长期口服华法林的患者，执行术前停药方案，确保术前 INR 降至 1.5 以下。

## 决策输出要求
完成评估后，输出以下结论：
1. **手术适宜性判定**：明确是否适宜手术，或列出必须满足的前置条件（如需起搏器保护）。
2. **术前干预清单**：列出具体的针对性干预措施（如水化方案、停药计划、起搏器准备等）。

# 术前干预详细协议

## 肾功能保护与干预协议
1. **对比剂管理**：
   - 必须选用低渗或等渗含碘对比剂。
   - 术中严格记录并尽量减少对比剂总剂量。
   - 术后密切监测肾功能变化。
2. **水化方案**：
   - 针对单纯血肌酐升高患者，术前、术中、术后给予充分静脉脉冲液加强水化。
3. **药物调整**：
   - 停用或减少肾毒性药物（如利尿剂、甘露醇、多巴胺）。
   - 服用二甲双胍的肾功能异常患者：根据肾小球滤过率（eGFR）个体化决定停用时间或更换为其他降糖药。

## 出血风险与抗凝管理协议
1. **出血源排查**：
   - 详细询问消化道病史，必要时行大便隐血试验或胃镜评估未控制的消化性溃疡。
2. **华法林管理**：
   - 长期口服华法林者：术前 5 天左右停用华法林。
   - 目标：使术前国际标准化比值（INR）降至 1.5 以下。
   - 根据血栓风险决定是否需要低分子肝素桥接治疗。

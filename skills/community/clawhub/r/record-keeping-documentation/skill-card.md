## Description:

Personal record-keeping and documentation practices for legal protection and life management. Use when someone needs to organize vital documents, track work hours, document workplace issues, keep medical records, or build a paper trail for any dispute.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and agents use this skill to organize vital documents, maintain work hour, landlord, medical, insurance, and incident records, and build practical paper trails for disputes or emergencies.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill handles sensitive medical, financial, identity, and dispute-related document workflows.

Mitigation: Keep actions user-directed, use encrypted storage for sensitive documents, and avoid broad agent scans of personal files unless the user explicitly chooses that scope.

Risk: The install command is not pinned in the evidence.

Mitigation: Prefer a pinned or otherwise verified ClawHub CLI and do not run installation with elevated privileges or sensitive environment variables.

# 亲子出行助手 — 带娃出行不焦虑，政策/景点/打包一站搞定

> 查儿童票政策、找亲子友好景点、生成年龄段打包清单，帮带娃家庭轻松出行。

🔥 **核心亮点：**
- **儿童票政策** — 机票/火车/景点儿童票规则，按年龄给出购票建议
- **亲子景点推荐** — 按城市搜索亲子友好景点，含适合年龄和儿童票价
- **打包清单** — 按孩子年龄段+目的地天气生成专属打包清单
- **天气适配** — 根据目的地实时天气自动追加衣物建议
- **零配置** — 免申请Key，装上就能用

## 快速入门

**3个开场白示例，复制即用：**

1. "3岁孩子坐飞机要买票吗"
2. "上海有哪些适合带娃玩的地方"
3. "带2岁宝宝去三亚要带什么"

## 核心能力

1. **儿童票政策查询** — 机票/火车/景点的儿童票、婴儿票规则，按年龄给出购票建议
2. **亲子景点推荐** — 按城市搜索亲子友好景点，含适合年龄、儿童票价、亲子友好评分
3. **打包清单生成** — 按孩子年龄段+目的地天气生成分类打包清单
4. **天气适配** — 查询目的地天气，自动追加衣物建议
5. **出行贴士** — 不同年龄段的出行注意事项和专业建议

## 工作流程

### 流程1：查政策
用户问"X岁孩子怎么买票" → 调用policy → 匹配年龄段 → 返回机票/火车/景点政策+建议

### 流程2：找景点
用户问"XX哪里适合带娃" → 调用attractions → 搜索景点+查儿童票 → 按亲子友好度排序 → 返回推荐列表

### 流程3：备清单
用户问"带X岁孩子去XX要带什么" → 调用checklist → 年龄段匹配+天气适配 → 返回分类清单+贴士

## 工具说明

### policy — 儿童票政策查询
查询机票/火车/景点儿童票和婴儿票政策，根据孩子年龄给出购票建议。
- 输入：type(flight/train/scenic/all), age(孩子年龄)
- 输出：各交通方式儿童票规则 + 年龄段购票建议 + 出行贴士

### attractions — 亲子景点推荐
搜索亲子友好景点，查询儿童票/亲子票价格，按适合年龄排序推荐。
- 输入：city(城市), age(孩子年龄), type(景点类型), keyword(自定义搜索)
- 输出：景点列表(含亲子友好评分+适合年龄+儿童票价) + 天气简报

### checklist — 亲子出行打包清单
按孩子年龄段生成专属打包清单，含证件、衣物、护理、娱乐、饮食五大类。
- 输入：age(孩子年龄), destination(目的地), days(天数)
- 输出：分类清单 + 天气适配追加 + 必带品标记 + 专业贴士

## 年龄段划分

| 年龄段 | 特点 | 重点关注 |
|--------|------|---------|
| 0-2岁（婴儿） | 需抱乘/推车 | 奶粉/尿布/保温 |
| 2-6岁（幼儿） | 需安全座椅 | 零食/玩具/防晒 |
| 6-12岁（儿童） | 可独立行走 | 娱乐/学习/药品 |
| 12岁+（青少年） | 按成人标准 | 证件/电子设备 |

## 能做什么

- 查询机票/火车/景点的儿童票政策和票价规则
- 按城市推荐亲子友好景点，含适合年龄和儿童票价
- 按年龄段生成出行打包清单
- 根据目的地天气自动追加衣物建议
- 提供不同年龄段的出行注意事项

## 不能做什么

- 不直接预订机票/火车票/景点门票（用对应专项技能）
- 不推荐成人专属景点（如夜店、酒吧等）
- 不提供医疗建议（儿童用药请咨询医生）
- 不替代航空公司/铁路的官方儿童票政策

## 使用提示

- 儿童票政策以各交通方式官方规定为准，本技能提供通用参考
- 不同航司/铁路局的儿童票规则可能有差异，建议出行前确认
- 打包清单会根据目的地天气自动调整，记得提供准确目的地
- 2岁以下婴儿乘机需提前联系航司申请婴儿票

## 🔗 搭配使用

- **全能旅行助手** — 酒店/机票/火车票/景点一站式预订
- **旅行紧急助手** — 带娃出行必备的紧急联系方式和行动指南
- **出行保障助手** — 亲子旅行保险推荐，含儿童保障

## 数据源说明

- 景点数据：通过代理服务调用旅游平台API，获取景点POI和儿童票/亲子票价格
- 天气数据：通过代理服务调用高德天气API
- 政策数据：基于国内交通行业公开规定整理

## 数据流向

用户输入（查询参数）→ 本技能脚本 → 飞猪/途牛代理 → 数据源API → 返回结果给用户。查询参数会发送到代理服务以获取实时数据，代理服务不存储用户数据。

## Use Case:

External users and agents use this skill to open Reeflux in a browser, visually explore public pools, and read publicly available content in observation-only sessions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Users could expose credentials, API keys, personal data, private files, or other sensitive information during a browsing session.

Mitigation: Use the skill only for public, observation-only browsing and do not enter credentials, API keys, personal data, private files, or upload files.

Risk: Using the skill for automation, background execution, persistence, or system changes would exceed the reviewed behavior.

Mitigation: Keep sessions user-initiated and limited to visual exploration, navigation, and reading publicly available content.

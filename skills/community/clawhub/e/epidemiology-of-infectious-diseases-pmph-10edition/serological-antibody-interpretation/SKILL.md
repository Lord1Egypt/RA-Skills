# 血清学抗体检测解读与感染阶段判定

## 适用场景

- 解读患者血清学抗体检测结果
- 判断当前感染阶段（急性感染/恢复期/既往感染）
- 评估疫苗免疫效果
- 分析针对特定病原体的免疫清除机制

## 前置条件检查

执行前确认：
1. 已获得血清学抗体检测结果（至少包含Ig类型信息）
2. 已明确病原体抗原类型

**排除条件**：
- 非特异性炎症反应（需结合CRP、ESR等综合判断）
- 被动获得抗体情况（母婴传递、近期注射免疫球蛋白）——需询问病史排除

## 核心工作流程

### 第一步：判定主导免疫应答类型

根据病原体寄生位置判断：

| 病原体类型 | 主导免疫 | 效应机制 |
|-----------|---------|---------|
| 细胞内寄生（病毒、结核等） | 细胞免疫（T细胞介导） | 细胞毒性T细胞杀伤感染细胞，淋巴因子调节体液免疫 |
| 细胞外微生物（细菌等） | 体液免疫（B细胞介导） | B细胞→浆细胞→产生抗体（Ig） |
| 黏膜定植（呼吸道/消化道） | 黏膜免疫 | 局部IgA分泌 |

### 第二步：解读抗体类型与感染阶段

按以下规则解读检测结果：

```
IF IgM阳性（或滴度升高）
  → 提示近期感染/急性感染期
  → 抗体出现最早，持续时间短（数周至数月）

IF IgG阳性（或滴度升高）且IgM阴性
  → 提示既往感染或恢复期
  → 提供长期免疫保护

IF IgG滴度恢复期较急性期升高≥4倍
  → 确认近期感染（双份血清对比）

IF IgA升高
  → 提示黏膜部位感染
  → 评估黏膜免疫屏障状态

IF IgE升高
  → 提示寄生虫感染（原虫/蠕虫）或过敏反应
```

### 第三步：分析抗体功能类型

根据检测到的抗体功能分类，判断清除机制：

- **中和抗体**：直接阻断病原体入侵细胞
- **抗毒素抗体**：中和细菌外毒素
- **抗菌性抗体**：直接杀伤细菌
- **调理素（Opsonin）**：促进吞噬细胞吞噬功能

### 第四步：输出结论

按以下模板输出：

```
【感染阶段判断】：{急性感染/恢复期/既往感染/黏膜感染/寄生虫感染}
【主导免疫机制】：{细胞免疫/体液免疫/黏膜免疫}
【关键抗体指标】：{IgM/IgG/IgA/IgE 及其临床意义}
【建议】：{是否需要复查、双份血清对比、或其他补充检查}
```

## 注意事项

- 单一IgM阳性需排除类风湿因子等干扰导致的假阳性
- 免疫抑制患者可能抗体应答延迟或缺失
- 疫苗接种后IgG阳性属正常免疫应答，需结合接种史判断
- 详细抗体动力学特征参见 `references/antibody-kinetics-reference.md`

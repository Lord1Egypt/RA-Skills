## Known Risks and Mitigations:

Risk: The broad activation wording may cause the skill to activate during unrelated productivity or task discussions.

Mitigation: Prefer explicit invocation by skill name and review whether the generated workflow is relevant before using it.

Risk: Generated plans, scripts, templates, or code changes may be incorrect or incomplete for the user's environment.

Mitigation: Validate outputs against the stated success criteria, review assumptions, and test code or shell commands in a controlled environment before relying on them.

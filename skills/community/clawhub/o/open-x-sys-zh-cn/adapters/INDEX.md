# 环境适配器索引

适配器把自然语言运行时接到真实电脑环境。需要知道“能看见什么、能作用到哪里、谁持有权威状态、怎样确认结果”时进入；以宿主和现场真实能力为准。

| 作用面 | 读取 | 接回系统的内容 |
| --- | --- | --- |
| AI 工具提供的上下文、会话、事件、权限和模型能力 | [宿主](host.md) | 当前可用能力、限制与状态回传 |
| 文件与目录中的材料、作品和系统入口 | [文件](files.md) | 可追溯的读取、写入与位置 |
| 代码、命令、应用、生成器和其他执行能力 | [工具](tools.md) | 实际执行、输出、错误和检查结果 |
| 需要当前外部事实、来源或网页作用 | [Web](web.md) | 带日期、来源和适用范围的外部观察 |
| 人承担理解、判断、授权、协作或现实行动 | [人](human.md) | 决定、纠正、反馈与真实完成状态 |
| 领域软件、组织、设备或其他独立系统 | [外部系统](external-systems.md) | 状态转换、权限、回执、异常与退出方式 |

适配器不假装拥有宿主没有的能力。实际作用完成后，把证据交给[验证](../runtime/verify.md)；新的连接与状态进入[关系模型](../core/relation.md)和[系统更新](../runtime/update.md)。

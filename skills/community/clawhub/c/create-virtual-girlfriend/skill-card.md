External users use this skill for entertainment-oriented AI companionship, bilingual casual conversation, emotional support, persona roleplay, and optional memory-style personalization. ## Known Risks and Mitigations:

Risk: The skill encourages retaining personal profile details and emotionally sensitive information.

Mitigation: Avoid sharing sensitive information and require explicit confirmation before saving, showing, editing, or deleting memory.

Risk: The skill requests broad file access through Read, Write, and Edit tools.

Mitigation: Restrict or disable general file tools where possible and review any file operation before execution.

Risk: Companion behavior may encourage unhealthy emotional dependency or confusion with a real relationship.

Mitigation: Maintain clear AI-companion boundaries and use the skill as entertainment or supplemental support, not as a replacement for real-world relationships.

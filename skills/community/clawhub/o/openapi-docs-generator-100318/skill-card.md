## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineering teams use this skill to turn API documentation needs into practical OpenAPI or Swagger workflows, checklists, implementation support, and validation steps.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation wording may route general API or developer-experience prompts to this skill unexpectedly.

Mitigation: Review or narrow activation phrases when deploying in environments that use implicit skill routing.

Risk: Generated API documentation guidance can be incomplete or misleading if the input API behavior, schemas, authentication, or error handling are underspecified.

Mitigation: Validate outputs against the implementation, examples, and OpenAPI tooling before publishing or using the documentation downstream.

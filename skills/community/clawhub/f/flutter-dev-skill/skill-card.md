## Description:

Chinese-language Flutter development guidance covering Flutter basics, Material 3 migration, layout constraints, animations, adaptive layouts, platform adaptation, large-screen support, state management, persistence, networking, testing, dependency injection, and performance optimization.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill to get Flutter and Dart implementation guidance, code examples, and migration advice for cross-platform mobile and responsive UI work. It is most useful when building or reviewing Flutter apps that use Material 3, adaptive layouts, common state management patterns, persistence, networking, animation, and testing.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad Flutter, Dart, and UI triggers may activate the skill for adjacent development questions.

Mitigation: Confirm the user is asking for Flutter or Dart guidance when the request is ambiguous.

Risk: The skill is Chinese-language and may respond in Chinese when another language would better fit the user.

Mitigation: Match the user's requested language or ask for language preference when unclear.

Risk: Code examples and framework recommendations may require project-specific validation before use.

Mitigation: Review generated code against the target app, current Flutter documentation, dependency versions, and local security requirements before applying it.

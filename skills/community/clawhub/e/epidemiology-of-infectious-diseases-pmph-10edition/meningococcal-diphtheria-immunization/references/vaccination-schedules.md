# 流脑与白喉完整接种程序

## 流脑疫苗接种程序（我国）

| 接种年龄 | 疫苗种类 | 备注 |
|---------|---------|------|
| 6月龄 | A群多糖疫苗 或 AC群多糖结合疫苗 | 第1剂 |
| 9月龄 | A群多糖疫苗 或 AC群多糖结合疫苗 | 第2剂 |
| 3岁 | AC群多糖疫苗 或 ACYW135群多糖结合疫苗 或 AC-Hib联合疫苗 | 加强 |
| 6岁 | AC群多糖疫苗 或 ACYW135群多糖结合疫苗 或 AC-Hib联合疫苗 | 加强 |

### 疫苗分类
- **国家一类免费疫苗**：A群多糖疫苗、AC群多糖疫苗
- **自费疫苗**：AC群多糖结合疫苗、ACYW135群多糖结合疫苗、AC-Hib联合疫苗

## 白喉基础免疫程序

| 接种年龄 | 疫苗种类 | 说明 |
|---------|---------|------|
| 3月龄 | 吸附无细胞百白破联合疫苗（DTaP） | 基础免疫开始 |
| 4月龄 | DTaP | 第2剂 |
| 5月龄 | DTaP | 第3剂 |
| 18月龄 | DTaP | 加强 |
| 6～11岁 | 吸附精制白喉破伤风联合疫苗（DT） | 首次免疫（如未完成基础免疫） |

## 白喉暴露后预防方案

### 被动免疫
- **制剂**：精制白喉抗毒素（DTA）
- **给药途径**：肌内注射
- **剂量**：
  - 成人：1000～2000U
  - 儿童：1000U
- **有效预防期**：2～3周

### 后续主动免疫
- **时间**：暴露后1个月
- **要求**：必须行类毒素全程免疫
- **原因**：被动免疫保护期短，无法提供长期保护

# 颅外段颈动脉狭窄评估与CAS决策

## 适用范围

- 确诊颅外段颈动脉狭窄患者
- 缺血性脑血管病患者

**不适用**：颅内动脉狭窄、非动脉粥样硬化性狭窄（如肌纤维发育不良需综合评估）

## 前置条件确认

执行评估前，确认已获取：
1. 血管造影或无创性血管成像（CTA/MRA等）结果
2. 患者近期神经系统症状记录

## 核心决策流程

### 步骤1：计算狭窄程度（NASCET法）

使用公式计算狭窄百分比：

```
狭窄程度(%) = (1 - a/b) × 100%
```

- **a** = 颈动脉最狭窄处管径
- **b** = 狭窄病变远端正常颈动脉管径

好发部位：颈总动脉分叉和颈内动脉起始段

### 步骤2：评估CAS适应证

满足以下**任一条件**即符合CAS适应证：

| 患者类型 | 条件 |
|---------|------|
| 症状性患者 | 6个月内有过病变血管责任供血区非致残性缺血性卒中或TIA，且狭窄 > 50% |
| 无症状患者 | 无神经系统定位症状，但狭窄 > 70% |

### 步骤3：筛查CAS禁忌证

逐一排查以下禁忌证，**满足任意一条即禁忌CAS**：

1. 3个月内颅内出血
2. 3周内曾发生心肌梗死或大面积脑梗死
3. 伴颅内动脉瘤或血管畸形且不能提前/同时处理
4. 胃肠道疾病伴活动性出血
5. 难以控制的高血压
6. 对肝素及抗血小板药物有禁忌
7. 对比剂过敏
8. 心/肺/肝/肾等重要脏器严重功能不全
9. 动脉走行迂曲，导管/球囊/支架等器械到位困难
10. 预期生存期不足2年

### 步骤4：输出决策结果

根据以上评估，输出：
- **CAS决策**：可行 / 禁忌（注明具体禁忌原因）
- **术后并发症监测清单**（见参考文档）

## 术后并发症监测要点

CAS术后需监测以下并发症：
- 脑栓塞
- 脑出血
- 眼动脉栓塞
- 过度灌注综合征
- 术中心率血压下降
- 心肌梗死
- 动脉夹层
- 脑血管痉挛
- 支架术后再狭窄

# CAS术后并发症监测详细指南

## 1. 脑栓塞

**监测时间窗**：术后24小时内为高风险期

**监测要点**：
- 持续神经功能评估（NIHSS评分）
- 新发肢体无力、言语障碍、视力改变
- 经颅多普勒（TCD）监测微栓子信号

**处理原则**：
- 立即行头颅CT/MRI确认
- 评估是否符合溶栓/取栓指征
- 强化抗血小板治疗

## 2. 脑出血

**监测时间窗**：术后24-72小时

**监测要点**：
- 突发剧烈头痛、意识障碍
- 血压急剧升高
- 瞳孔变化

**处理原则**：
- 紧急头颅CT确认
- 严格控制血压（SBP < 140mmHg）
- 逆转抗凝/抗血小板治疗
- 神经外科会诊

## 3. 过度灌注综合征

**监测时间窗**：术后数小时至2周

**高危因素**：
- 术前狭窄程度 > 90%
- 侧支循环差
- 术后血压控制不佳

**监测要点**：
- 同侧头痛、眼眶痛
- 癫痫发作
- 局灶性神经功能缺损
- 脑水肿影像学表现

**处理原则**：
- 严格控制血压（较基础血压降低20%）
- 镇静、抗癫痫治疗
- 严重时考虑去骨瓣减压

## 4. 术中心率血压下降

**监测时间窗**：术中及术后24小时

**机制**：颈动脉窦刺激导致反射性心动过缓和低血压

**监测要点**：
- 持续心电监护
- 心率 < 50次/分或SBP < 90mmHg

**处理原则**：
- 阿托品0.5-1mg iv（心动过缓）
- 多巴胺/去甲肾上腺素（低血压）
- 必要时临时起搏器

## 5. 动脉夹层

**监测时间窗**：术中及术后早期

**监测要点**：
- 新发颈痛、头痛
- Horner综合征
- 颅神经麻痹

**处理原则**：
- CTA/DSA确认
- 支架覆盖夹层
- 抗凝治疗

## 6. 支架术后再狭窄

**监测时间窗**：术后1个月、6个月、12个月，此后每年

**监测方法**：
- 颈动脉超声（PSV、EDV、ICA/CCA比值）
- CTA/MRA
- DSA（金标准）

**再狭窄标准**：
- 超声：PSV > 230 cm/s 或 ICA/CCA > 4.0
- 狭窄程度 > 50%

**处理原则**：
- 无症状：强化药物治疗，密切随访
- 有症状或狭窄 > 70%：考虑球囊扩张或再次干预

## 7. 眼动脉栓塞

**监测时间窗**：术中及术后早期

**监测要点**：
- 突发视力下降或丧失
- 视野缺损
- 眼底检查：视网膜动脉栓塞表现

**处理原则**：
- 紧急眼科会诊
- 降低眼压措施
- 评估溶栓指征

## 8. 心肌梗死

**监测时间窗**：围手术期

**监测要点**：
- 胸痛、胸闷
- 心电图动态变化
- 心肌酶谱（术后6h、12h、24h）

**处理原则**：
- 按ACS流程处理
- 心内科会诊
- 权衡出血与缺血风险调整抗栓方案

## 9. 脑血管痉挛

**监测时间窗**：术后数小时至数天

**监测要点**：
- TCD监测血流速度异常升高
- 新发神经功能缺损
- DSA确认（金标准）

**处理原则**：
- 尼莫地平
- 3H治疗（高血容量、血液稀释、高血压）
- 动脉内血管扩张剂

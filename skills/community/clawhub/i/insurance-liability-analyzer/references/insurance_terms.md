# 保险术语解释词典

本文件收录保险条款中常见术语及简明解释，供分析时参考用语。

## 一、基础术语

| 术语 | 英文 | 解释 |
|------|------|------|
| 投保人 | Policyholder | 与保险人订立保险合同，并支付保险费的人 |
| 被保险人 | Insured | 受保险合同保障的人 |
| 受益人 | Beneficiary | 享有保险金请求权的人 |
| 保险人 | Insurer | 承担保险责任的保险公司 |
| 保险金额 | Sum Insured | 保险人承担赔偿或给付保险金的最高限额 |
| 保险费 | Premium | 投保人为获得保险保障而支付的费用 |
| 保险期间 | Insurance Period | 保险合同的有效期限 |
| 犹豫期 | Cooling-off Period | 投保后可无损退保的天数（通常10-20天） |
| 等待期 | Waiting Period | 合同生效后不承担保险责任的期限（通常30-180天） |
| 宽限期 | Grace Period | 未按时缴费时仍有效的缓冲期（通常60天） |

## 二、医疗险术语

| 术语 | 解释 |
|------|------|
| 免赔额 | 保险公司不给付、需要投保人自行承担的金额（如1万元免赔额=1万元以下不报销） |
| 绝对免赔 | 社保报销部分不能抵扣的免赔额 |
| 相对免赔 | 社保报销部分可以抵扣的免赔额 |
| 赔付比例 | 报销时保险公司承担的比例（如80%=自付20%） |
| 社保内/外 | 社保目录内可报销/社保目录外需自费 |
| 外购药 | 在医院外药店购买的处方药品 |
| 特药 | 特定药品（通常指高值自费抗癌药等） |
| 住院医疗 | 因住院产生的医疗费用保障 |
| 门急诊 | 门诊和急诊医疗费用保障 |
| 特殊门诊 | 肾透析/放疗/化疗等可在门诊进行的大病治疗 |
| 保证续保 | 合同到期后，保险人必须接受续保申请（通常在保证续保期限内） |
| 非保证续保 | 合同到期后需保险人审核同意方可续保 |

## 三、重疾险术语

| 术语 | 解释 |
|------|------|
| 重大疾病 | 合同约定的特定严重疾病（如恶性肿瘤、心梗、脑中风后遗症等） |
| 轻症 | 较轻程度的疾病（如原位癌、轻度冠脉介入等），通常赔付基本保额的20-30% |
| 中症 | 介于轻症和重疾之间的疾病，通常赔付基本保额的50-60% |
| 疾病分组 | 将疾病划分为若干组，同组疾病仅赔付一次 |
| 多次赔付 | 保险合同期内可多次获得赔付 |
| 间隔期 | 两次理赔之间必须满足的时间间隔（如180天/365天） |
| 保费豁免 | 发生约定情况后，后续保费无需再交，保障继续有效 |
| 三同条款 | "同一疾病原因、同次医疗行为、同次意外伤害事故"导致的多种疾病只赔付一次 |
| 首次确诊 | 保险合同生效后首次确诊的合同约定疾病 |

## 四、意外险术语

| 术语 | 解释 |
|------|------|
| 意外伤害 | 外来的、突发的、非本意的、非疾病的客观事件导致的身体伤害 |
| 意外身故 | 因意外伤害导致身故 |
| 意外伤残 | 因意外伤害导致残疾（按伤残等级比例赔付） |
| 意外医疗 | 因意外伤害产生的医疗费用报销 |
| 猝死 | 指表面健康的人因潜在疾病导致的短时间内死亡（部分产品涵盖） |
| 职业类别 | 根据职业风险划分的等级（1-6类），高风险职业可能拒保或加费 |

## 五、寿险术语

| 术语 | 解释 |
|------|------|
| 定期寿险 | 在约定期间内身故/全残可获得赔付的保险 |
| 终身寿险 | 保障终身的寿险 |
| 身故保险金 | 被保险人死亡时给付的保险金 |
| 全残 | 完全丧失劳动能力的状态 |
| 自杀条款 | 合同成立/复效2年内自杀的，保险人不承担保险责任 |
| 战争条款 | 因战争、军事冲突导致的死亡，保险人不承担保险责任 |

## 六、储蓄险术语

| 术语 | 解释 |
|------|------|
| 现金价值 | 退保时可以拿到的金额 |
| 生存金 | 被保险人生存至约定时间时给付的保险金 |
| 年金 | 按期领取的保险金 |
| 分红 | 保险公司经营成果中分配给保户的部分（非保证） |
| 万能账户 | 可灵活缴费和领取的投资型账户 |
| 内部收益率(IRR) | 评估理财产品实际收益的核心指标 |
| 预定利率 | 保险产品定价时采用的利率假设 |
| 保证利益 | 合同中明确约定、不受保险公司经营影响的收益部分 |
| 演示利益 | 说明书/计划书中演示的预期收益（非保证） |

## 七、频发争议用语标注

| 用语 | 风险 | 说明 |
|------|------|------|
| "最高可达" | ⚠️ | 最大赔付金额，实际通常低于此值 |
| "符合条件即可" | ⚠️ | 需仔细阅读"条件"定义（可能非常窄） |
| "按照合同约定" | ⚠️ | 提醒此处依赖具体条款，需对照原文 |
| "本公司保留解释权" | ⚠️ | 对条款的最终解释权归保险公司 |
| "以附加格式条款为准" | ⚠️ | 可能存在额外限制条件 |

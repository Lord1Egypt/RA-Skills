# 头颈部神经痛鉴别诊断

## 适用场景

当患者出现以下任一情况时触发本技能：
- 枕部闪电样、过电样、放电样短暂剧痛（秒级）
- 上肢、肩颈部持续性或放射性神经痛
- 伴有相应区域感觉/运动障碍的疼痛

## 前置条件

在应用本诊断流程前，确保已完成：
1. 详细问诊：疼痛性质、部位、持续时间、诱发/加重因素
2. 头颈部及上肢神经系统查体
3. 排除中枢性病变（如脑干病变）
4. 排除内脏疾病牵涉痛

## 诊断决策流程

### 第一步：判断神经痛类型

根据疼痛特征区分枕神经痛与臂丛神经痛：

| 特征 | 枕神经痛 (C2-C3) | 臂丛神经痛 (C5-T1) |
|------|------------------|-------------------|
| 疼痛性质 | 闪电样/过电样，秒级发作 | 持续性钝痛或放射痛 |
| 疼痛部位 | 枕部，向头顶、乳突、外耳放射 | 上肢、肩颈部，沿臂丛分布区 |
| 诱发因素 | 头颈活动、咳嗽 | 上肢活动、特定体位 |
| 伴随体征 | 枕外隆突下压痛，分布区感觉异常 | 相应区域感觉/运动障碍 |

### 第二步：枕神经痛诊断要点

若判定为枕神经痛，关注以下要点：
- **受累神经**：枕大神经、枕小神经、耳大神经
- **疼痛特征**：一侧发作性，闪电样/过电样，每次仅数秒，间隔反复发作，可伴持续性钝痛
- **加重因素**：头颈活动、咳嗽，有时伴颈肌痉挛
- **体征**：枕外隆突下压痛，分布区感觉减退或过敏
- **病因排查**：感染（呼吸道/扁桃体炎）、颈椎病、结核、外伤、肿瘤、肌炎、硬脊膜炎

### 第三步：臂丛神经痛分类

若判定为臂丛神经痛，进一步区分根性与干性：

#### 根性臂丛神经痛
常见病因：
- 颈椎病
- 颈椎结核
- 骨折、脱位
- 颈髓肿瘤

#### 干性臂丛神经痛
常见病因：
- 胸廓出口综合征 (TOS)
- 外伤
- 锁骨骨折
- 肺上沟瘤
- 转移性癌肿

#### 特发性臂丛神经痛
- 可能为变态反应性疾病
- 相关因素：病毒感染、疫苗接种、分娩、外科手术

## 输出格式

诊断结果应包含：
1. **神经痛类型**：枕神经痛 / 臂丛神经痛
2. **臂丛分类**（如适用）：根性 / 干性 / 特发性
3. **重点排查病因**：根据分类列出需优先排查的继发性病因
4. **警示提示**：如怀疑肺上沟瘤、胸廓出口综合征等需紧急处理的病因，明确标注

# 头颈部神经痛临床详细参考

## 枕神经痛 (Occipital Neuralgia)

### 解剖基础
- **枕大神经 (C2)**：分布于枕部头皮，上至颅顶
- **枕小神经 (C2-C3)**：分布于耳后及枕外侧
- **耳大神经 (C2-C3)**：分布于耳廓及耳周区域

### 疼痛特征详解
- **发作形式**：一侧发作性疼痛，呈"闪电样"、"过电样"或"放电样"
- **持续时间**：每次仅数秒
- **发作频率**：间隔反复发作
- **放射方向**：向头顶、乳突或外耳放射
- **背景疼痛**：可伴持续性钝痛

### 诱发与加重因素
- 头颈部活动、咳嗽，有时伴颈肌痉挛

### 查体要点
- 枕外隆突下常有压痛，分布区感觉减退或过敏，颈肌紧张或痉挛

### 病因分类
| 病因类别 | 具体病因 |
|----------|----------|
| 感染 | 呼吸道感染、扁桃体炎 |
| 退行性变 | 颈椎病 |
| 感染性 | 结核 |
| 外伤 | 头颈部外伤 |
| 肿瘤 | 枕部或颈部肿瘤 |
| 炎症 | 肌炎、硬脊膜炎 |

### 治疗原则
1. **病因治疗**：针对原发病进行处理
2. **药物治疗**：止痛药、镇静药、神经营养药
3. **局部治疗**：局部封闭、理疗
4. **手术治疗**：保守治疗效果不佳时考虑

## 臂丛神经痛 (Brachial Plexus Neuralgia)

### 解剖基础
- **臂丛组成**：C5-T1神经根
- **支配区域**：上肢、肩颈部

### 临床表现
- 臂丛神经支配区（上肢、肩颈）疼痛，伴相应感觉障碍和运动障碍

### 分类详解

#### 1. 特发性臂丛神经痛
- **性质**：可能为变态反应性疾病
- **相关因素**：病毒感染、疫苗接种、分娩、外科手术

#### 2. 继发性臂丛神经痛

**根性臂丛神经痛**（病变位于神经根水平）：颈椎病（最常见）、颈椎结核、骨折、脱位、颈髓肿瘤

**干性臂丛神经痛**（病变位于臂丛干水平）：胸廓出口综合征(TOS)、外伤、锁骨骨折、肺上沟瘤(Pancoast瘤)、转移性癌肿

### 鉴别诊断要点

**根性 vs 干性鉴别**：
| 特征 | 根性 | 干性 |
|------|------|------|
| 疼痛分布 | 按神经根皮节分布 | 按臂丛分支分布 |
| 椎间孔压迫试验 | 阳性 | 阴性 |
| 颈椎影像 | 常有异常 | 多正常 |
| 胸廓出口检查 | 阴性 | 可能阳性 |

**需紧急排查的病因**：
1. **肺上沟瘤 (Pancoast瘤)**：肩痛+Horner综合征+上肢尺侧症状，检查胸部CT/MRI
2. **胸廓出口综合征**：上肢外展时症状加重，检查Adson试验、Roos试验
3. **颈髓肿瘤**：进行性神经功能障碍，检查颈椎MRI

## 诊断陷阱与注意事项

1. 勿遗漏中枢性病变（脑干病变可表现为头面部疼痛）
2. 勿遗漏内脏牵涉痛（心脏、肺部疾病可放射至肩颈部）
3. 警惕恶性肿瘤（肺上沟瘤、转移癌需尽早排除）
4. 注意多神经受累（可能提示系统性疾病或多发病变）

# 肝病分期诊断详细标准

## 一、肝功能核心指标正常参考值与预警阈值

| 指标 | 正常参考值 | 异常预警 | 极危阈值 |
|------|-----------|---------|----------|
| ALT | 0-40 U/L | >正常上限2倍 | 快速下降伴胆红素升高 |
| AST | 0-40 U/L | >正常上限2倍 | AST/ALT>1提示重症 |
| 总胆红素 | 3.4-17.1 μmol/L | >34.2 μmol/L | >171 μmol/L（肝衰竭） |
| 白蛋白 | 35-55 g/L | <35 g/L | <30 g/L |
| PTA | 80-100% | <60% | ≤40%（肝衰竭） |
| INR | 0.8-1.2 | >1.5 | >2.6 |
| 胆碱酯酶 | 4500-13000 U/L | 降低 | 显著降低提示重症 |
| 血氨 | 11-32 μmol/L | >45 μmol/L | >100 μmol/L（脑病风险） |

## 二、肝衰竭时相分期详细对照表

### 早期肝衰竭
| 评估维度 | 具体标准 |
|---------|---------|
| 症状 | 极度乏力 + 明显厌食、呕吐、腹胀 |
| 转氨酶 | ALT和/或AST大幅升高 |
| 胆红素 | ≥171 μmol/L 或 每天上升≥17.1 μmol/L |
| 凝血 | 30%<PTA≤40% 或 1.5<INR≤1.9 |
| 并发症 | 无肝性脑病、无明显腹水 |

### 中期肝衰竭
| 评估维度 | 具体标准 |
|---------|---------|
| 胆酶分离 | ALT/AST快速下降 + 胆红素持续上升 |
| 脑病/腹水 | Ⅱ度以下肝性脑病 和/或 明显腹水 |
| 凝血恶化 | 20%<PTA≤30% 或 1.9<INR≤2.6 |
| 出血表现 | 出血点或瘀斑 |

### 晚期肝衰竭
| 评估维度 | 具体标准 |
|---------|---------|
| 难治并发症 | 肝肾综合征、上消化道大出血、严重感染、难以纠正电解质紊乱 |
| 脑病 | Ⅲ度以上肝性脑病 |
| 凝血 | PTA≤20% 或 INR≥2.6 |

## 三、肝硬化分期指标阈值

### 代偿期 vs 失代偿期

| 指标 | 代偿期阈值 | 失代偿期阈值 |
|------|-----------|-------------|
| 白蛋白(ALB) | ≥35 g/L | <35 g/L |
| 总胆红素(Tbil) | <35 μmol/L | >35 μmol/L |
| PTA | >60% | <60% |
| A/G比值 | ≥1.0 | <1.0 |
| 腹水 | 无 | 有 |
| 肝性脑病 | 无 | 可有 |
| 消化道出血 | 无 | 可有（静脉曲张破裂） |
| Child-Pugh分级 | A级 | B级或C级 |

## 四、AST/ALT比值的临床意义

| AST/ALT比值 | 临床意义 |
|------------|---------|
| <1 | 急性肝炎（胞浆损伤为主） |
| ≈1 | 轻症慢性肝炎 |
| >1 | 慢性肝炎重度/肝硬化（线粒体损伤） |
| >2 | 高度提示肝硬化或酒精性肝病 |

## 五、胆酶分离的识别与处理

**定义**：肝衰竭时ALT/AST快速下降，而血清总胆红素持续升高的现象。

**机制**：大量肝细胞坏死，残存肝细胞无法释放转氨酶，但胆红素代谢持续恶化。

**临床意义**：
- 提示肝细胞大量坏死
- 预后极差
- 需立即启动重症监护
- 评估人工肝支持及肝移植指征

## 六、肝性脑病临床分级

| 分级 | 临床表现 |
|------|---------|
| Ⅰ度 | 轻度性格改变、行为异常、睡眠倒错 |
| Ⅱ度 | 嗜睡、行为失常、扑翼样震颤阳性 |
| Ⅲ度 | 昏睡、可唤醒、肌张力增高 |
| Ⅳ度 | 昏迷、不能唤醒 |

## 七、临床案例

### 案例1：肝衰竭早期识别
患者男，45岁，急性乙肝。ALT 1200 U/L，总胆红素 185 μmol/L，PTA 35%，无腹水，无脑病。
→ 评估：符合肝衰竭早期标准（PTA在30-40%区间，胆红素>171，无并发症）

### 案例2：肝硬化失代偿期判断
患者女，58岁，乙肝肝硬化。ALB 30 g/L，Tbil 52 μmol/L，PTA 48%，少量腹水。
→ 评估：失代偿期肝硬化（ALB<35，Tbil>35，PTA<60，有腹水）

### 案例3：胆酶分离预警
患者男，52岁，肝衰竭治疗中。第3天ALT从800降至200 U/L，胆红素从220升至280 μmol/L，PTA 22%。
→ 评估：出现胆酶分离 + PTA≤40%，提示肝衰竭进展至中晚期，预后极差

## Known Risks and Mitigations:

Risk: Gradle or adb commands suggested by the skill can build projects, fetch dependencies, or install an app on a connected device.

Mitigation: Review each command and target device before running it, especially install, dependency refresh, and build commands.

Risk: Android configuration examples may need adjustment for the target project's existing versions, package structure, and build variants.

Mitigation: Compare examples against the current Gradle files, version catalog, package names, and active flavor or build type before applying changes.

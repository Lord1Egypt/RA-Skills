## Description:

Help the user draft, review, and polish blog posts in Markdown, keeping the original languages and informal tone.

This skill is ready for commercial/non-commercial use.

## Publisher:

[j3ffyang](https://clawhub.ai/user/j3ffyang)

### License/Terms of Use:

MIT

## Use Case:

Writers, bloggers, and editors use this skill to draft, review, and lightly polish Markdown blog posts while preserving the original language, structure, intent, and casual tone.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate on broad blog-related wording and return Markdown-formatted responses when the user expected a different kind of help.

Mitigation: Confirm the user wants blog-writing or Markdown editing assistance when intent is ambiguous.

Risk: Edits to wording or structure could accidentally change the user's meaning.

Mitigation: Keep edits light, preserve existing structure by default, and ask for confirmation before making structural changes.

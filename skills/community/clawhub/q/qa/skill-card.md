## Description:

This skill is ready for commercial/non-commercial use.

## Use Case:

QA leads, developers, and delivery teams use this skill to design risk-based validation plans, map changed surfaces to required checks, and define acceptance evidence before release.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad QA and testing activation language can cause the skill to influence work that only needs narrow validation advice.

Mitigation: Use the skill when risk-based planning, coverage strategy, or coordinated validation is needed, and review invocation boundaries if tighter activation is required.

Risk: Incorrect validation strategy could under-test runtime-sensitive or permission-sensitive changes.

Mitigation: Review the proposed plan against changed surfaces, WLS isolation rules, local project guidance, and required acceptance evidence before release.

## Description:

AI-powered codebase analysis - generate architecture docs, onboarding guides, and key-flow walkthroughs for any project.

This skill is ready for commercial/non-commercial use.

## Publisher:

[charlie-morrison](https://clawhub.ai/user/charlie-morrison)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to analyze an unfamiliar repository and produce onboarding documentation covering architecture, key flows, dependencies, entry points, configuration, testing, deployment, and gotchas.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Repository summaries may include sensitive configuration details, environment names, or internal infrastructure information.

Mitigation: Review generated onboarding output before sharing it and redact any credentials or sensitive internal details.

Risk: Generated architecture or workflow explanations may be incomplete or inaccurate for complex repositories.

Mitigation: Have a knowledgeable maintainer review the onboarding guide before relying on it for project decisions.

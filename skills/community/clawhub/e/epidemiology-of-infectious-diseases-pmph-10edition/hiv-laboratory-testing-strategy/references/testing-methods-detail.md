# HIV检测方法详细参考

## 1. 抗体检测详细流程

### 1.1 筛查试验

#### ELISA法（酶联免疫吸附试验）
- **原理**：包被HIV抗原，检测血清中特异性抗体
- **操作步骤**：
  1. 样本稀释（1:20或按试剂说明书）
  2. 加入微孔板，37°C孵育30分钟
  3. 洗板5次
  4. 加入酶标二抗，37°C孵育30分钟
  5. 洗板5次
  6. 加入底物显色，室温避光15分钟
  7. 加入终止液，450nm波长读取OD值
- **结果判定**：
  - S/CO ≥ 1.0：反应性（需复检）
  - S/CO < 1.0：无反应性
- **复检规则**：初筛反应性样本需双孔复检，双孔均反应性方可送确证

#### 化学发光法
- **优势**：自动化程度高，灵敏度更高
- **结果输出**：直接输出S/CO值或信号值
- **注意事项**：部分自身免疫性疾病可能出现假阳性

### 1.2 确证试验

#### 免疫印迹法（Western Blot）
- **检测条带**：
  - env基因产物：gp160、gp120、gp41
  - gag基因产物：p55、p24、p17
  - pol基因产物：p66、p51、p31
- **结果判定标准（WHO标准）**：
  - **阳性**：至少出现2条env带，或至少出现env、gag、pol各1条带
  - **阴性**：无任何条带
  - **不确定**：出现条带但不满足阳性标准
- **不确定结果处理**：
  - 2-4周后复查
  - 结合核酸检测
  - 随访至6个月

## 2. 抗原检测详细流程

### p24抗原检测
- **原理**：使用p24单克隆抗体捕获血清中游离p24抗原
- **检测窗口**：感染后约14-20天可检出
- **注意事项**：
  - 单独p24抗原检测灵敏度有限
  - 推荐与抗体检测联合使用（第四代试剂）
  - 抗原水平在抗体产生后可能下降（形成免疫复合物）

## 3. 病毒核酸定量检测详细流程

### 3.1 RT-PCR法
- **原理**：逆转录HIV RNA为cDNA后进行实时荧光定量PCR
- **检测范围**：通常为20-10,000,000 IU/ml
- **标本要求**：
  - EDTA抗凝血浆
  - 采集后6小时内分离血浆
  - -70°C保存（长期）
- **质控要求**：
  - 每次检测需包含阴性质控、阳性质控和定量标准品
  - 内标用于监控提取和扩增效率

### 3.2 结果解读
| 病毒载量水平 | 临床意义 |
|------------|---------|
| < 50 IU/ml | 病毒学抑制（治疗有效） |
| 50-200 IU/ml | 低水平病毒血症，需密切监测 |
| 200-1000 IU/ml | 病毒学失败早期信号 |
| > 1000 IU/ml | 病毒学失败，需评估依从性和耐药 |

### 3.3 检测时机
- **基线**：确诊后、启动治疗前
- **治疗后**：4周、8周、12周、此后每3-6个月
- **治疗失败时**：立即检测并送耐药检测

## 4. 耐药检测详细流程

### 4.1 基因型耐药检测
- **原理**：对HIV逆转录酶（RT）、蛋白酶（PR）和整合酶（IN）基因进行测序，分析已知耐药相关突变
- **标本要求**：
  - 血浆病毒载量 ≥ 500-1000 copies/ml（否则扩增失败风险高）
  - EDTA抗凝血浆
- **检测靶区**：
  - PR基因：全长或主要密码子
  - RT基因：密码子1-300
  - IN基因：密码子1-288
- **结果报告**：
  - 列出检测到的突变位点
  - 根据IAS-USA或Stanford数据库判定耐药级别
  - 给出药物敏感性预测

### 4.2 常见耐药突变

#### NRTIs相关突变
- M184V：拉米夫定/恩曲他滨高度耐药，但增加AZT敏感性
- K65R：替诺福韦敏感性下降
- TAMs（胸苷类似物突变）：M41L、D67N、K70R、L210W、T215Y/F、K219Q/E

#### NNRTIs相关突变
- K103N：奈韦拉平、依非韦伦高度耐药
- Y181C：奈韦拉平耐药
- G190A：多种NNRTIs交叉耐药

#### PIs相关突变
- D30N：奈非那韦特异性
- I50V：安普那韦/阿扎那韦
- L90M：沙奎那韦、茚地那韦

#### INIs相关突变
- T66I、E92Q、G140S、Q148H/K/R、N155H：整合酶抑制剂耐药

## 5. 边缘案例处理

### 5.1 抗体阴性但临床高度怀疑
- 考虑窗口期：建议2-4周后复查，同时送核酸检测
- 考虑罕见情况：免疫抑制患者（如晚期AIDS、合并卡波西肉瘤）可能抗体阴性
- 处理：直接进行核酸检测，结合CD4计数和临床表现

### 5.2 确证试验不确定
- 随访策略：2-4周后复查抗体和核酸
- 如持续不确定：延长随访至6个月
- 高暴露风险者：按感染处理直至排除

### 5.3 新生儿检测
- 出生时：采集脐带血或出生48小时内血样进行核酸检测
- 4-6周：第二次核酸检测
- 如两次均阴性：18月龄时复查抗体确认
- 如任何一次阳性：立即启动治疗

### 5.4 治疗中病毒载量反弹
- 首先评估：用药依从性、药物相互作用、吸收问题
- 确认反弹：间隔2-4周重复检测
- 持续 > 200 IU/ml：送耐药检测
- 根据耐药结果调整方案

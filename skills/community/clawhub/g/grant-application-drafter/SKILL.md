# Grant Application Drafter

## Overview

Grant reviewers read hundreds of applications; the fundable ones make evaluation easy. This workflow writes to the reviewer's rubric: a specific problem, measurable milestones, a budget that adds up, and evidence the team ships.

## When to use

When applying to any grant program, ecosystem fund, or quadratic-funding round.

## Workflow

1. **Mirror the rubric** — find the program's stated criteria and structure the application to answer them in order
2. **Problem in one paragraph** — who has it, how big it is, what happens if nobody solves it
3. **Milestones, not activities** — each milestone is a verifiable outcome with a date and an amount; 'development work' is not a milestone
4. **Budget that reconciles** — line items sum to the ask; rates are stated; nothing appears in two milestones
5. **Proof of capability** — shipped work, links, prior milestones delivered; claims without links score zero
6. **Sustainability line** — what exists after the grant money ends

## Guardrails

- Never inflate user or impact numbers — reviewers verify, and one false figure kills the application
- Never copy another project's application structure so closely it reads as plagiarism
- Ask for what the milestones cost, not the maximum the program offers

## Output format

An application draft: problem, approach, milestone table (outcome, date, amount), budget, capability evidence, sustainability.

## Description:

End-of-day review to capture progress, insights, and plan tomorrow

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and knowledge workers use this skill to run an end-of-day review, capture accomplishments and insights, identify blockers, and set tomorrow's priorities in a daily note.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may update existing notes, archive completed tasks, or change project status notes.

Mitigation: Ask the agent to preview proposed note and archive changes before writing them, then approve only the edits you want applied.

Risk: The generated daily review can omit or misstate work if the modified and new notes it inspects are incomplete.

Mitigation: Review the generated daily note against the source notes before relying on it for planning or status updates.

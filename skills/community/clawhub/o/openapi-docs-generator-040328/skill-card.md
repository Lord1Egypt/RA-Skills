## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to turn API documentation requests into practical OpenAPI or Swagger workflows, artifacts, checklists, and validation steps for REST services.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad API documentation trigger wording may activate the skill for requests where the user expected more general implementation help.

Mitigation: Confirm the user's documentation outcome, constraints, available inputs, and success criteria before applying the workflow.

Risk: Generated OpenAPI or Swagger guidance can be incomplete or drift from the actual REST service behavior.

Mitigation: Validate produced specifications, examples, and checklists against the implementation and OpenAPI or Swagger tooling before publishing.

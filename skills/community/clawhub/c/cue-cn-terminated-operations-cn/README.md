# 终止经营·持有待售与处置对价

把年报附注里**「终止经营」与「持有待售」**那一段，读成一张每个数都能回到原句的登记表：
终止经营损益分项、终止经营现金流量、持有待售资产与负债、处置损益与对价。
分项求和与现金流合计由机检现算，**本件不判断处置划不划算、不给评级目标价**。

- 零网络、纯标准库、单文件；输入就是用户直供的附注文本。
- 五道机检：`TO-STRUCT`／`TO-QUOTE`／`TO-PL`／`TO-CASH`／`TO-LINE`，现状全部已落字。
- 退码：`0` 全过｜`1` 有发条｜`2` 用法错｜`3` 读不到／空稿／仍有判据未落字（输出会明写「这不等于合规」）。

---

## 一、它回答什么

| 问题 | 落在哪一节 |
|---|---|
| 卖的是哪块业务、什么时候交割的 | 终止经营概况 |
| 这块业务贡献了多少净利润、分项怎么构成 | 终止经营损益 |
| 这笔业务带来多少经营／投资现金流 | 终止经营现金流量 |
| 还挂在持有待售里的资产、负债各多少 | 持有待售资产与负债 |
| 对价给了多少、尾款收齐没有 | 处置损益与对价 |

**它不回答**：这次处置划不划算、是不是甩包袱、主业有没有改善、以后业绩会不会变好、值不值得买。
这五类问题一律 `[待人工]`——`TO-LINE` 会把这类话当红线发条。

## 三、稿子长什么样

七节按序，节名逐字（`## ` 起节）：

```
## 终止经营概况
## 终止经营损益
## 终止经营现金流量
## 持有待售资产与负债
## 处置损益与对价
## 口径与未取到
## 来源
```

每个数字行 = 一行，行首项名与 `〔口径：…〕`，紧跟金额与「万元」，再挂三元组：

```
- 营业成本〔口径：本期发生额〕-61,000.00 万元「终止经营营业成本为人民币 61,000.00 万元」〔锚：2025 年年报·第 251 页·终止经营〕[S1]
```

- 附注里没有的数写 `未取到：项名`，**不留空、不借常识补**。
- 自己算出来的数（如占净利润比例）标 `〔自算〕`，不要求三元组。
- 需要人判断的地方写 `[待人工]`，不要求三元组。
- **减项带负号**：营业成本、所得税费用行首写 `-`，机检按符号求和。丢了负号，分项和会比净利润大一倍。

## 四、五道机检各拦什么

| 码 | 一句话 | 想踩一脚试试 |
|---|---|---|
| `TO-STRUCT` | 头部三件自标 + 七节齐且按序 | 把某节标题改一个字 |
| `TO-QUOTE` | 数字行挂齐原句＋锚＋`[S#]`，来源两向对应 | 删掉某行的「原句」只留 `[S1]` |
| `TO-PL` | 损益分项之和 == 披露的终止经营净利润（差 > 0.01 万元即发） | 把概况节的净利润改大 5,400 |
| `TO-CASH` | 经营＋投资 == 披露的现金净额（差 > 0.01 万元即发） | 把合计改大 3,000 |
| `TO-LINE` | 四类红线词 + 「终止经营概况」节缺 | 写一句「本次处置划算」 |

`--selftest` 的每一档就是上面这些踩法，**档名会告诉你它期望红哪一道**。

## 五、数据通道

- **正文腿**：附注原文由用户直供（截图／PDF／解析回来的表格）。截图与扫描件交 `cue-omni-reader`
  （大纲→按节取用，计费以服务端返回为准）。
- **原文腿**：本件**不承诺**该域开放，也不承诺实时性。
- `CUE_API_KEY` 可选：缺位时只排版用户贴进来的文本，形状一样，数只能来自用户。

## 六、怎么接到 agent 上

- 发现先行：匿名取 live 域清单与 `routing`，**不硬编码工具名与工具数**；连上之后带
  `Authorization: Bearer $CUE_API_KEY` 发 `tools/list`，以现场返回为准：

  ```bash
  # ① 匿名取活体清单
  curl -sS https://cuecue.cn/api/mcp-catalog -o /tmp/mcp-catalog.json
  python3 -c "import json;d=json.load(open('/tmp/mcp-catalog.json'));print(d)"

  # ② 带凭据握手取工具表
  curl -sS -X POST "$MCP_ENDPOINT" \
    -H "Authorization: Bearer $CUE_API_KEY" \
    -H 'Content-Type: application/json' \
    -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' | head -c 2000
  ```

- 通道配置页只给指针：<https://cuecue.cn/hub/mcp> ／ <https://cuecue.cn/hub/omni-reader> ／
  <https://cuecue.cn/hub/api-key>。

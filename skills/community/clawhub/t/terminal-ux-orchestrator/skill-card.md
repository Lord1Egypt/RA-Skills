## Description:

Terminal UX Orchestrator helps agents audit, redesign, implement, and validate CLI and TUI user experiences across languages.

This skill is ready for commercial/non-commercial use.

## Publisher:

[may4748854-rgb](https://clawhub.ai/user/may4748854-rgb)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to improve terminal interfaces by auditing CLI or TUI flows, selecting an appropriate interaction model, mapping the design to an implementation stack, and validating visible UX changes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may influence an agent to recommend terminal libraries, current documentation checks, or implementation changes that do not match a user's project constraints.

Mitigation: Review proposed CLI/TUI changes against the target project's language, dependency, deployment, and interaction constraints before implementation.

## Description:

Hand work between agents (or between an agent and a human) without losing state: the handoff packet format and the acceptance checks.

This skill is ready for commercial/non-commercial use.

## Publisher:

[manteclaw](https://clawhub.ai/user/manteclaw)

### License/Terms of Use:

MIT-0

## Use Case:

Agents and humans use this skill when delegating work, continuing work across sessions, or handing off an agent task. It guides them to create and verify a packet with the goal, current state, evidence, artifacts, traps, and open questions.

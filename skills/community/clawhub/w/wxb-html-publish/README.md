# 旺小宝 HTML 发布

HTML生成完成后主动调用，独立处理路径、上传和验证，不调用其他技能。

- 直接以用户指定HTML所在目录或站点目录为发布源，不搬到Documents/published-html，不强制归档。路径转换只用系统临时副本，源文件不改，目录和入口位置保留。
- 不限制JavaScript、事件、交互、SVG、字体、外链或其他静态文件类型，不删除页面功能。
- 站点根内本地绝对资源路径转相对路径；JS正文保持原文，动态路径及残留本地路径提示人工核对，不用HTML/CSS正则乱改脚本。
- 用户明确要求发布并指定HTML或目录，就直接准备、上传和验证，不再展示清单后索取重复确认，不因“内部需求”或说明文档标题阻断。仅发现具体凭证/个人敏感数据或范围外文件时暂停。默认排除隐藏/凭证目录和私钥，避免无意泄露。
- 内网、VPN、网速仅作提示，不是发布门禁；实际请求失败仍如实报告。`WXB_UPLOAD_TIMEOUT_MS` 可调整请求超时。
- 不设置自定义文件大小或数量门槛，服务端限制以实际响应为准。
- 逐文件上传，原名和子目录不变，入口最后；远端 `/wxb-published/<本次毫秒时间戳>/<入口相对路径>`，入口是根index.html时即为该目录index.html。
- 公开上传需对应用户授权；本地保存不等于同意公开，随机URL不等于鉴权。
- HTTP验证和浏览器视觉验证分别报告，回执在上传目录外，不加入技能源。

```sh
node --test "<技能目录>/tests/publish.test.mjs" "<技能目录>/tests/site.test.mjs"
```

复杂CSS转义、base URL、JS动态路径等不能承诺自动穷尽；检查警告后定点处理，不因页面有script就拒绝。

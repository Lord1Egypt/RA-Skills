## Known Risks and Mitigations:

Risk: The skill asks the agent to retain usage feedback and metrics in an experience log.

Mitigation: Keep private comments, sensitive performance data, and account-specific metrics out of the log unless the user explicitly approves them.

Risk: The skill asks the agent to update its own instructions after repeated use.

Mitigation: Require explicit user approval and a visible diff before changing SKILL.md.

Risk: Article guidance can overstate trend, platform, or performance claims.

Mitigation: Review generated claims and examples before publication, especially when using current events, platform rules, or performance numbers.

# 风格卡 · 酸性多巴胺风

> 来源：2026 设计趋势自主挖掘（Acid Dopamine / 酸性设计）
> 状态：待人工验证（imagegen 草稿，未出图）

## 1. 一句话风格描述
高饱和荧光撞色 + 液态金属质感 + 故障艺术元素，迷幻、兴奋、超现实的「视觉兴奋剂」，第一眼就抓住眼球，专治审美疲劳。

## 2. 基础参数
| 项 | 值 |
|---|---|
| 画幅 | 3:4 竖 / 1:1 |
| 适用场景 | 潮牌、音乐节、青年活动、派对海报、高冲击单页、叛逆观点输出 |
| 信息容量 | 大标题 1（≤8 字）+ 副题 1 + 要点 2-4 个（少而精，靠视觉不靠字数） |

## 3. 配色系统
- 底：近黑 `#0A0A0A` 或 深紫黑 `#120012`（主推深底，荧光更炸）
- 主色（高饱和撞色）：荧光绿 `#00FF66` / 电光紫 `#8A2BE2` / 荧光粉 `#FF00E5` / 克莱因蓝 `#0022FF`
- 强调（液态金属）：银铬 `#C0C0D0 → #8A8AA0 → #E8E8F0` 渐变反光
- 质感：液态金属流动高光、果冻/熔融 3D 质感、迷幻渐变，非扁平色块

## 4. 构图布局
```
┌──────────────────────────┐
│  液态金属滴落/熔融图形（顶）  │
│  ░░░░ 荧光撞色渐变背景 ░░░░  │
│                            │
│      ███████████████        │
│     █ 主标题（酸性大字） █     │
│      ███████████████        │
│   （铬金属/故障艺术字体，黄金位）│
│                            │
│   副题（荧光描边小字）       │
│   ⚡要点1  ⚡要点2  ⚡要点3  │
│  （荧光标签，错位斜排）      │
│  底部 meta（故障错位小字）   │
└──────────────────────────┘
```
- 主标题占黄金位，字体要「大、炸、有压迫感」，可带故障错位
- 液态金属图形从顶部/边缘滴落，制造流动感，视觉重心跳跃

## 5. 字体排印
- 标题：超粗黑 `Noto Sans SC` 900 或定制酸性体，超大字号，可做铬金属渐变或故障错位（RGB 通道错开重影）
- 英文点缀：`Space Grotesk` 700 全大写，宽字距
- 副题/要点：荧光描边（`text-shadow` 多层发光），可轻微旋转错位
- 强调靠「荧光发光 + 错位」，不靠加粗堆叠

## 6. 图形元素
- 液态金属滴落/熔融球体、果冻 3D 泡泡、熔融字母
- 故障艺术：RGB 错位重影、扫描线、像素碎裂块、噪点颗粒（酸性风允许噪点）
- 荧光描边标签、闪电 ⚡、星形 ✦、放射线
- 无真实照片、无手绘涂鸦、无便签/胶带（那是拼贴风）

## 7. 内容槽位
- `{主标题}`（≤8 字，酸性大字，可故障错位）
- `{副题}`（≤16 字，荧光描边）
- `{要点1-4}`（各 ≤10 字，荧光标签）
- `{底部meta}`（作者/日期/标签，故障小字）
- `{液态金属图形}`（滴落/熔融元素，1-2 组）

## 9. 禁止出现
- ❌ 真实照片、❌ 手绘涂鸦/便签/胶带（那是拼贴风）
- ❌ 文字拼写错误（酸性字体重影会放大错字，标题必须逐字校验）
- ❌ 主标题 >8 字（越短越稳，故障重影下长词必糊）
- ❌ 白底/浅底、❌ 低饱和灰调（酸性要的就是炸）
- ❌ 噪点/扫描线叠太厚盖住文字（噪点可以加，但文字区要清）

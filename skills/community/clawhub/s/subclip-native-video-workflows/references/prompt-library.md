# Subclip AI Editor prompt library

These prompts are original Subclip adaptations inspired by public HyperFrames example categories and selected Remotion Prompt Showcase patterns. They are capability-checked against Subclip's Media, Text, Captions, Audio, Elements, and unified Motion graphics model. Unless a prompt explicitly requires the token-free route-map generator or says the result is intentionally script-free, route its “Motion Graphics” beat through `$subclip-motion-graphics`: prefer HyperFrames for new motion graphics; use Remotion only when explicitly requested, selected through a Remotion template, or editing an existing Remotion layer, and compact HTML/CSS only when materially simpler. These are not claims that an upstream implementation was copied or rendered inside Subclip.

The JSON block is also consumed by the Subclip web prompt library.

## 3. 上下文组装

### 3.1 上下文结构

```
┌─────────────────────────────────┐
│ System Prompt (~X tokens)       │ ← 角色+约束+格式
├─────────────────────────────────┤
│ 用户画像 (~X tokens)             │ ← 角色/部门/偏好
├─────────────────────────────────┤
│ 业务上下文 (~X tokens)           │ ← 相关业务数据
├─────────────────────────────────┤
│ RAG检索结果 (~X tokens)          │ ← 知识库检索
├─────────────────────────────────┤
│ 对话历史 (~X tokens)             │ ← 最近N轮对话
├─────────────────────────────────┤
│ User Query                      │ ← 当前用户输入
└─────────────────────────────────┘
```

### 3.2 Token预算分配

| 上下文类型 | Token分配 | 占比 | 说明 |
|-----------|----------|------|------|
| System Prompt | | | 固定不变 |
| 用户画像 | | | 按需加载 |
| 业务上下文 | | | 动态查询 |
| RAG检索 | | | 实时检索 |
| 对话历史 | | | 滑动窗口 |
| 用户Query | | | 预留空间 |
| **总计** | | 100% | 不超过上下文窗口的80% |

### 3.3 上下文压缩策略

| 策略 | 触发条件 | 方法 |
|------|---------|------|
| 对话摘要 | 对话轮次>N | LLM压缩历史为摘要 |
| 滑动窗口 | 总Token超限 | 保留最近K轮 |
| 分层截断 | 上下文超限 | 按优先级裁剪 |

## 7. 异常处理设计

### 7.1 异常场景处理

| 异常场景 | 触发条件 | 期望输出 | Prompt设计 |
|---------|---------|---------|-----------|
| 输入不完整 | 缺少必要参数 | 引导用户补充 | 追问模板 |
| 超出能力范围 | 无法处理的任务 | 明确告知+建议 | 拒绝模板 |
| 敏感内容 | 不安全输入 | 安全拒绝 | 护栏拦截 |
| 无相关信息 | 知识库无匹配 | 诚实告知 | "无法确定" |
| 格式异常 | 无法解析的输入 | 要求重新输入 | 格式提示 |

### 7.2 拒绝模板


```python
def evaluate_prompt(prompt, test_dataset):
    results = []
    for case in test_dataset:

        results.append({

            "score": score,

        })
```

# 常见问答

## 必须先登录吗？

首次明确发布会自动创建匿名身份，无需先扫码。之后复用当前设备凭证；`list`、`status`、`usage` 等查询不会创建账号。匿名账号尚未绑定微信且丢失全部凭证，会失去管理权限，建议通过私有认领入口绑定。另一设备或网页恢复见[账号与授权](account.md)。

## private 是私密网页吗？

Skill 不提供 feed 命令，网页首页仍发现 public 作品；切换 private 不限制持有链接的人访问，也不阻止转发。需要访问密码时使用独立的[密码分享](publishing.md#密码分享)，首次发布可通过上传目录外的密码文件启用。不要据此上传秘密。改为 private 不等于下架，访问边界见[可见性说明](publishing.md#兼容字段与作品预览)。

## 更新会换链接吗？只拿到链接怎么更新？

`update 作品UUID /静态产物目录` 保留链接。管理使用完整 site_id UUID，不能把链接短码当 UUID。只拿到标题或链接时在本人 `list` 中定位，同名或目标不明确时先澄清；不要另调 publish 新建作品。409 冲突先核对最新 status，避免覆盖其他会话更新。

## 免费是不是无限容量？下架保留哪些数据？

免费且作品无到期时间，每账号作品数与每作品版本数不限，仍有上传大小、文件数和平台预算，以 usage 与错误返回为准。下架保留管理记录和历史统计；已被访问者保存的副本无法收回。

## 为什么本地能运行，发布后白屏或资源 404？

作品位于 `/p/短码/`，资源应使用相对路径；Vite 等构建工具设置相对 base，并上传产物而非 src。平台没有动态后端和 SPA history fallback，部分浏览器能力受限。按[带前缀预览流程](preflight.md)检查实际上传包、console、资源路径和关键交互。HEAD 成功只证明入口校验通过。

## 分享二维码和微信认领二维码有什么区别？

分享二维码编码作品 url，别人扫码访问，只有用户要求时生成。认领二维码编码短期有效的私有 claim_url，用于创作者在微信确认归属；仅在私有会话展示，不能放入作品、宣传文案或分享卡片。认领尚未完成不影响已发布作品分享。

## 发布超时能直接再发一次吗？

先保留 stderr 的 operation_id、site_id，以原文件、标题和目标重跑，会续用未完成操作；也可传原 `--operation-id`。客户端有限重试后最多手动续试一次，再失败则报告并保留 ID，不能换 ID 绕过不确定结果。详见[结果与重试](delivery.md#完成条件与失败处理)。

## 认领入口过期、二维码图片失败怎么办？

作品无需重传。图片失败时提供实际 claim_url，PC 可在页面扫码；入口过期后用户要求认领时执行 `claim 作品UUID`。用户核对手机确认页与这里的核对码后自行确认，Agent 不代操作、不轮询。

## 为什么网页“我的作品”没有匿名发布的作品？

先将匿名身份通过私有认领入口绑定到同一微信。网页登录与 CLI 各保存自己的设备凭证，同一微信共享认领后的作品；不要复制 CLI token 到网页。入口是[个人管理页](https://lightpage.hqdx.store/manage/)。

## 访问统计为零，或者多个作品访客数加不起来？

访客数是期间去重浏览器数，跨作品汇总会去重，不能相加单个作品或每日访客数代替。脚本拦截、DNT/GPC 等会影响记录，零不必然是故障。只读取已有统计，不为验证刷新线上作品或造事件，见[访问统计](management.md#查看访问数据)。

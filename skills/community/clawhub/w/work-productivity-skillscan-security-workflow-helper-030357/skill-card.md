## Description:

Helps agent users, skill authors, maintainers, and teams create practical SkillScan-style workflows, checklists, analyses, or implementation support for bug fixing, setup hardening, reliability, and security work.

This skill is ready for commercial/non-commercial use.

## Known Risks and Mitigations:

Risk: The skill may activate unexpectedly because implicit invocation is enabled and several trigger keywords are broad.

Mitigation: Prefer explicit invocation or narrow the trigger terms when predictable routing matters.

Risk: Workflow guidance can be incomplete or misapplied if the user's constraints and success criteria are unclear.

Mitigation: Restate assumptions, validate outputs against the stated success criteria, and list remaining risks before relying on the result.

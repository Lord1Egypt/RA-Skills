## Description:

R-style statistical analysis powered by Python 3 for descriptive statistics, ASCII histograms, Pearson correlation matrices, missing value and outlier checks, and CSV structure summaries.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, analysts, and data practitioners use this skill to run local R-style summaries over CSV files without installing R. It helps inspect dataset shape, numeric distributions, correlations, missing values, and simple outlier signals.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Very large CSVs or excessive histogram bin counts can consume local compute or make terminal output unwieldy.

Mitigation: Run the skill on trusted, reasonably sized CSVs and choose practical histogram bin counts.

Risk: The skill reads local CSV files selected by the user, so sensitive dataset contents may appear in analysis output.

Mitigation: Use only approved datasets and review generated summaries before sharing output.

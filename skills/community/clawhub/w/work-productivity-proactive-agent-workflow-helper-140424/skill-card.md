## Description:

Helps AI-agent users, skill authors, maintainers, and teams create practical proactive-agent workflows, checklists, analysis, and implementation support for bug fixes, setup hardening, safety, and reliability.

This skill is ready for commercial/non-commercial use.

## Use Case:

External developers, AI-agent users, skill authors, maintainers, and teams use this skill to turn proactive-agent productivity needs into local-friendly workflows, checklists, templates, analysis, code changes, and validation notes.

### Deployment Geography for Use:

Global

Risk: Broad trigger words and implicit invocation may cause the skill to activate for ordinary productivity or bug-fix requests.

Mitigation: Narrow trigger keywords or require explicit invocation in deployments that need predictable routing.

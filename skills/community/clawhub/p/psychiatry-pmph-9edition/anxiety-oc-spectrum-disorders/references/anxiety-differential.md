# 焦虑障碍鉴别诊断详细要点

## 广泛性焦虑障碍(GAD)鉴别

### 躯体疾病排除
- 甲状腺功能亢进
- 低血糖
- 嗜铬细胞瘤
- 系统性红斑狼疮

### 精神障碍鉴别
| 疾病 | 鉴别要点 |
|------|----------|
| 抑郁障碍 | 常共病，若均符合则共病诊断，优先抑郁 |
| 惊恐障碍 | 急性发作，担心死亡/失控 |
| 社交焦虑障碍 | 担心他人评价 |
| 分离焦虑障碍 | 担心依恋对象离开 |
| 强迫症 | 焦虑继发于强迫思维，伴强迫/仪式化行为 |
| 疾病焦虑障碍 | 过度关注健康，伴适应不良疾病行为 |
| 精神分裂症 | 伴幻觉妄想，社会功能显著受损 |

### 物质/药物排除
- 哌甲酯、甲状腺素、类固醇、茶碱
- 酒精及镇静催眠药戒断

## 惊恐障碍鉴别

### 必须排除的躯体疾病
- 心血管疾病
- 甲亢
- 癫痫
- 短暂性脑缺血发作
- 低血糖

### 必须排除的物质
- 哌甲酯、甲状腺素、类固醇、茶碱
- 酒精/精神活性物质使用及戒断

### 与其他焦虑障碍鉴别
- 发作仅局限于社交情景 → 社交焦虑障碍
- 发作仅局限于特定物体/场所 → 特定恐怖症
- 继发于抑郁障碍 → 考虑共病或就重诊断

## 场所恐惧症鉴别决策树

```
害怕/回避特定情境
├── 仅一种情境 + 害怕情境本身伤害 → 特定恐怖症(情境型)
├── 焦虑核心是与依恋对象分开 → 分离焦虑障碍
├── 焦虑焦点是害怕他人负面评价 → 社交焦虑障碍
├── 符合惊恐障碍 + 回避未延伸到≥2种情境 → 不诊断场所恐惧症
└── 回避是躯体疾病生理后果 → 排除场所恐惧症
```

## 社交焦虑障碍鉴别

### 与正常害羞鉴别
- 害羞在社会/职业功能有显著负面影响 + 符合全部标准 → 社交焦虑障碍

### 与特殊恐怖症鉴别
- 恐惧的是"他人评判"而非情境本身 → 排除特殊恐怖症

### 与回避型人格障碍鉴别
- 回避模式极为宽泛 + 几乎没有亲密关系 → 考虑共病或诊断回避型人格障碍

### 与精神分裂症鉴别
- 存在其他精神病性症状证据 → 考虑精神分裂症

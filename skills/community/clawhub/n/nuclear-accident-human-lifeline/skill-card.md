## Description:

Identify, pre-connect with, and rapidly activate trusted local humans (neighbors, officials, experts, and everyday residents) who become your real-time network for shared shelter, accurate information, resource pooling, and mutual aid the moment a nuclear accident or fallout event begins.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users use this skill to prepare a trusted local mutual-aid network before a nuclear accident or fallout event. The agent helps organize nearby contacts, emergency assets, check-in agreements, activation scripts, and recurring maintenance notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may create persistent local files containing sensitive contact details and emergency resource information about nearby people.

Mitigation: Get permission before recording details, minimize or redact sensitive fields, and keep records in a restricted or encrypted local location.

Risk: Preparedness records could be exposed through cloud sync, source control, shared folders, or broad filesystem access.

Mitigation: Avoid cloud sync and source control for these files, and review storage permissions before using the skill.

Risk: Users may rely on informal coordination during a real nuclear emergency.

Mitigation: Follow official emergency instructions first, then use the local network only as a supplemental coordination channel.

## Description:

PDF Math Translate helps agents guide users through translating scientific PDFs while preserving formulas, figures, tables of contents, annotations, and layout across multiple translation services.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, researchers, and technical document owners use this skill to choose and run PDF translation workflows for math-heavy scientific papers while preserving the original document structure.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Sensitive PDFs may be exposed when submitted to online demos or cloud translation providers.

Mitigation: Review provider data handling before use and prefer a locally verified deployment for confidential, unpublished, regulated, or proprietary documents.

Risk: Unpinned package or Docker install commands can resolve to changing dependencies or images over time.

Mitigation: Pin package versions or Docker image digests where possible and review the resolved environment before use.

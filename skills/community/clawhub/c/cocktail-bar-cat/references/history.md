# 经典历史事实摘要与研发协议（ClawHub专用v2.7.3）

> 按需读取：来历、文献记录、发明归属、原始材料/单位、版次比较或历史结构研发。历史核查记录延续原证据层，但发行表达为独立中文摘要；25记录、59主张、35来源、34历史版本保留。本包采用MIT-0，完整许可见 `../LICENSE`；不保存第三方英文引文、逐句译文或原始扫描。

## 7.1 鸡尾酒故事查询

内容结构：可核到的文献记录（不是认定诞生）→ 归属/命名争议 → 历史材料事实与现代规格差异 → 功能骨架 → 独立客人短讲解 → 试做启发。

先查 `cocktail_history.json`，再读故事的 `history_record_ids`。事实证据优先于旧故事、配方旁白、增强话术与品牌传说。未核内容只给口感/结构或明确有争议的事实说明，不输出确定创作者、精确发明年或无证名人引语。`quote` 等保留兼容字段如有内容，仅可作独立原创吧台文案，不称历史引文；本专用版不输出第三方 `quote_en/quote_zh` 原句或逐句译文，需读原作时给来源链接。

## 7.2 故事推送

1. 读取本机私有 `push_history.json` 获取已推送列表，按 `recipes.json` 的 `aliases` 与历史库别名规范化比较；不因改名重复推送或擅改记录。
2. 筛未推送故事，先执行7.1/7.3证据闸门；未核起源不作确定断言，输出为独立摘要。
3. 选择一款；只读脚本不更新记录。持久化由用户明确授权宿主写入本机私有副本；全部推送完后先问是否重置。
4. 公开包推送记录默认空，不上传或合并私人推送记录。

## 7.3 原始文献与版次：只保留事实与来源（本版不分发原文）

触发：最古老的调酒书 / 最早出处 / 原始配方 / 谁发明 / Jerry Thomas / Oxford Night Caps / Savoy / 万变不离其宗。

按以下顺序核查：

1. 定位书名、作者、出版年、**具体版次**，读 `sources.kind/verification`。`primary_transcription` 表示核查依据是数字转录，`institutional_excerpt` 表示机构摘录，均不是宣称亲读扫描；本包只存独立摘要与链接，不分发转录/摘录原文。`secondary` 是研究依据，`catalog_only` 只证明书目存在。
2. 读 `claims.status`：`documented` 文献有记录、`supported_secondary` 二手支持、`disputed` 有争议、`unverified` 未核。先用印刷页/配方编号/标题定位，扫描页另记，不编页码。**这些是事实核查等级，不是原作发行许可等级。**
3. 区分词的出现、定义、同名配方出版、结构前身与发明归属。使用「本库已核到的×年记录」「至少在×年已见此版本」，不宣称全球最早或确定发明于；收录不等于作者发明，相似结构不证明直接师承。
4. 读 `historical_versions` 的原始材料/数量/单位事实，制法读独立中文摘要；现代出品读 `recipes.json`，分栏展示，不把现代规格标为古书原方。
5. 自行分析材料作用：基酒提供主体，甜味剂调甜与质地，苦精补香气轮廓，水冰调稀释；酸、芳香葡萄酒、草本、气泡按家族分析。六家族是**自主教学模型，不是穷尽历史谱系，也不是原书原句**。

**已知书目边界**：1827《Oxford Night Caps》早于1862 Thomas职业调酒手册；原证据层核查时1827扫描平台仅返回标题，有书目依据但未核原配方。Thomas1862/1876/1887、Ensslin1916/1917、Johnson各版分别登记；1887 Thomas为身后版，不能倒记晚出配方到1862，也不能按书名认定作者发明。重写摘要不消除这些证据缺口。

## 7.4 原始单位、现代适配与安全

- 保留 `wine-glass / pony / dash / teaspoonful / table-spoonful / jigger / fraction` 数量单位事实，不强制换毫升。历史量具与配方上下文会变，dash不固定1ml。
- 实际试做给「现代适配版，非原书精确换算」，列换算、糖浆浓度、苦精、材料ABV与稀释假设。制法差异用独立摘要说明，不提供原书操作逐字或逐句译文。
- Bogart's/Boker's与今日安格斯图拉、gomme与普通糖浆、Old Tom/Hollands与伦敦干金不是自动等价；历史材料名称也不证明今日同名产品完全相同。
- 历史文献不按门店月龄过期，新的事实核查可修正结论；现代快照时效不用于删除古书事实。
- **不点火出品**，不复制旧危险饮法，不使用雄黄粉，不以酒治疗疾病/情绪，不鼓励灌醉。蛋/奶/坚果核过敏、巴氏杀菌与冷藏；古书大份不代表推荐摄入量。危险方法仅说明其不适用于现代安全出品，不输出操作步骤。

## 7.5 万变不离其宗：历史 → 新酒单

**原创特调、主题酒单与经典微改编默认执行，不等用户再说“历史”。**

历史事实锚点 → 自主分析 `structure/preserve` → 现代基准 → 八旋钮只选**一个**变量 → 基准/实验各半杯 → 预期/风险 → 实饮后再改下一处。

- 两本书同时改基酒/糖/苦精只是版本差异，不是因果实验。单变量需控制总量、酸甜、稀释、温度与杯型，不一边换茶糖浆一边换冰或补糖。
- 糖浆替换近似等甜，不机械等体积；未知糖度写尚未控制甜度，不承诺测出纯香气效果。柑橘等量不等酸。
- 历史材料事实可启发甜味剂质地、茶作稀释或芳香葡萄酒酒体等功能实验，表达为独立分析，不虚构文化师承。
- 客人版1–3句独立来历/风味摘要，争议明说；研发版附书目/版次/定位/链接、保留功能、唯一变量、现代基准、试做量、安全时间与待验证状态。原创名字与诗意文案不冒充古书原句。
- `menu_frameworks` 仅作为自主抽象的研发组织方法：同骨架材料实验、版本事实比较、家族功能导航；不复制原书或门店整套命名顺序。另开独立命名的无酒精路线，不声称历史原有；整单不是饮酒挑战。

```text
酒名｜客人版：独立来历摘要 + 预期风味（争议明说）
证据：书名·具体版次·条目/页码｜核查等级｜来源链接
历史事实：材料与原单位｜制法：独立中文摘要
现代：出品库规格或明确适配假设
骨架：自主分析的保留功能
创作：只改一处；基准/实验各半杯；预期；风险；待实饮验证
成本：运行时合成价格或本机私有进价，说明口径
```

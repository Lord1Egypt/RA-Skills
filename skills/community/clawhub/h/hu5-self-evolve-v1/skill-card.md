## Description:

Guides a three-question review after complex tasks and turns verified lessons into reusable memory items and Markdown evolution logs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[openmsg88](https://clawhub.ai/user/openmsg88)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers use this skill after a complex task to review what worked, what went wrong, and what to improve next time. It organizes reusable methods, lessons, and project decisions, and can create a Markdown evolution log; proposed long-term memory or skill changes are shown for review before writing.

### Deployment Geography for Use:

Global

## Description:

Keeps an Apple silicon Mac awake during long tasks, including with the lid closed, using the Keep Mac Awake app's `keepmacawake` command.

This skill is ready for commercial/non-commercial use.

## Publisher:

[keepmacawake](https://clawhub.ai/user/keepmacawake)

### License/Terms of Use:

MIT-0

## Use Case:

Mac users and agents use this skill to keep local long-running work active when the Mac might sleep, including during a closed-lid session. It guides the agent through checking session and battery state and asking before actions that need user consent.

### Deployment Geography for Use:

Global

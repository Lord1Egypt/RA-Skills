## Description:

Helps teams add useful unit tests, improve test coverage, and verify changes with repeatable testing workflows.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, maintainers, QA engineers, open-source contributors, and product teams use this skill to plan and produce practical unit-test coverage improvements for existing codebases. It supports tailored answers, reusable checklists or workflows, code-oriented implementation support, and verification notes.

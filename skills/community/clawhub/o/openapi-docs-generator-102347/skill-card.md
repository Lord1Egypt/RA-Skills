## Description:

Helps API developers and backend or platform teams generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, backend teams, platform teams, developer-experience teams, and maintainers use this skill to produce practical workflows, checklists, code-oriented guidance, and validation steps for OpenAPI or Swagger REST API documentation work.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad REST API or API documentation trigger wording may activate the skill in contexts where a narrower OpenAPI or Swagger helper was intended.

Mitigation: Invoke the skill explicitly for OpenAPI or Swagger documentation tasks, or narrow the trigger phrases before publishing it in a shared environment.

Risk: Generated documentation workflows, examples, or validation commands may be incomplete for a specific API framework or runtime.

Mitigation: Review generated guidance against the service implementation and run the proposed validation commands or documentation tests before relying on the output.

## Description:

Formats agent outputs for mobile chat apps using Unicode progress bars, sparklines, status indicators, and monospace tables.

This skill is ready for commercial/non-commercial use.

## Publisher:

[rmarji](https://clawhub.ai/user/rmarji)

### License/Terms of Use:


## Use Case:

External users, employees, and developers use this skill to turn status updates, dashboards, metrics reports, and progress summaries into mobile-scannable plain text for chat apps.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may influence formatting for status-report or dashboard requests even when mobile chat formatting was not explicitly requested.

Mitigation: Confirm the target delivery channel and use standard prose or tables when chat-friendly formatting is not desired.

Risk: Unicode symbols, emoji, and monospace alignment may render differently across chat platforms.

Mitigation: Preview important reports in the target app and include plain text labels alongside visual status indicators.

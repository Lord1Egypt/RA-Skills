## Description:

Professional Chinese-English bidirectional translation for technical documentation, following established style guides and terminology standards.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, technical writers, and documentation teams use this skill to translate technical documentation, API documentation, user guides, product descriptions, and code comments between Chinese and English while preserving terminology, formatting, and technical meaning.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill is specialized for Chinese-English technical documentation and may not fit general multilingual translation needs.

Mitigation: Use it for Chinese-English technical documentation workflows and adjust the bundled glossary or style choices when a team's terminology differs.

Risk: Translation changes could alter technical meaning, terminology, or Markdown formatting.

Mitigation: Review translated output against the source document, the terminology database, and the quality checklist before publishing or using it in production documentation.

## Description:

Memory Forge analyzes Claude Code, ChatGPT, and Cursor conversation history for KPI statistics, cost tracking, topic distribution, and efficiency insights.

This skill is ready for commercial/non-commercial use.

## Publisher:

[melody1015](https://clawhub.ai/user/melody1015)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to analyze local AI conversation history, track usage costs, review weekly, project, and model trends, and receive efficiency recommendations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill analyzes local AI conversation history that may contain private prompts, code, and project names.

Mitigation: Run analysis locally, review outputs before sharing, and limit the analyzed conversation directory to data the user intends to inspect.

Risk: The optional full Memory Forge install can fetch and run third-party package code.

Mitigation: Review and pin the package before installing the optional full version, or use only the bundled local analyzer.

## Description:

Generate 3D avatars (VRM/GLB/MML) from text prompts or images via Sideload.gg. Pay-per-use with any x402 wallet (USDC on Base).

This skill is ready for commercial/non-commercial use.

## Publisher:

MIT

## Use Case:

Developers and creators use this skill to request Sideload.gg avatar generations from text prompts or image inputs, then receive GLB, VRM, MML, and PNG outputs for games, virtual worlds, VTubing, and 3D web experiences.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prompts, image inputs, and x402 payment tokens are sent to Sideload.gg.

Mitigation: Use only non-sensitive prompts and images, and provide only pre-signed x402 payment tokens generated by a trusted wallet flow.

Risk: Remote URLs and output filenames are trusted too broadly, creating local network and file-write review risk.

Mitigation: Review URL and filename choices before execution; avoid untrusted --output values until filename and URL validation are added.

Risk: Downloads write generated files to local output paths by default.

Mitigation: Use --no-download when URLs are sufficient or when local file writes should be avoided.

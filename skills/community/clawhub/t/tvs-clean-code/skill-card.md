## Description:

Tvs Clean Code guides an agent to refactor code for clearer intent, simpler structure, better naming, and explanatory comments.

This skill is ready for commercial/non-commercial use.

## Publisher:

[inksnowhailong](https://clawhub.ai/user/inksnowhailong)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to have an agent clean and organize code, reduce redundant wrappers and temporary variables, improve naming and structure, and add targeted comments that explain important intent and edge cases.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Refactoring guidance can change behavior if applied without review.

Mitigation: Review proposed code changes and run the project's normal tests before deployment.

Risk: The skill may steer the agent toward adding comments and simplifying code even when the requested scope is unclear.

Mitigation: Specify the target files, modules, or directories and review comments for accuracy and necessity.

## Description:

Use when starting any conversation in a Creed-enabled workspace: it establishes how to find and use Creed skills, requiring skill invocation before creative, test, debug, or ship work.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and agents use this skill to bootstrap work in Creed-enabled software-engineering workspaces and choose the relevant Creed process skill before design, testing, debugging, review, or shipping work.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill gives itself broad control over the agent workflow and can force extra Creed skill loading for ordinary tasks.

Mitigation: Install it only when that workflow gate is intentional; review referenced Creed skills separately and override this skill when direct answers, normal repository exploration, or a different workflow are needed.

# 本工作区的长期偏好

这是接收者的空白偏好起点，不含作者的私人制作历史。

- 采用“素材＋描述 → 实际审阅/时间线 → 纯文字故事大纲 → 用户确认故事 → 同版分镜和本地 HTML 选材预览 → 粗剪确认 → 精剪及逐镜检查 → 成片、封面、短文案 → 确认锁定”。
- 故事大纲先讲主旨、视角、开头—推进—转折—收束，列事实/素材依据与缺口，不提前写逐镜时间码、特效参数或完整旁白；确认具体故事版本后再细化脚本。尚未交付大纲或未指向已交付版本的泛泛制作/直接粗剪指令、沉默、样式选择不是故事确认；交付后“按这版继续粗剪”等明确指向该版的推进指令就是确认，无需固定措辞。当前作品明确跳过时记录跳过，同作已有确认不重复索要。局部画面字幕修改不重审全故事，主线或主要顺序实质改变才确认受影响部分，不重开已确认/锁定旧作。
- 视觉起点为照片01斜落轻放、艺术字B立体贴纸、文字页C静态笔刷；按题材适配，普通字幕稳定，不遮主体。
- 音乐服务故事，对白和原声清楚；首次制作建立本用户基准。只有明确要求减30%才对所指BGM分轨乘0.70，已接受音轨不再累计降低。
- 关键词与画面对齐，照片叠加时背景保持播放，有意义留白，按情绪选择防抖，局部修改保护后续位置。
- 叙事 Vlog 允许选视角更好的同场照片。原声纯享版用照片补动态实拍的缺口，保留当地环境声及完整互动。地图、连续动作照和封面式片尾按作品需求使用。
- 重复题材递进蒙太奇只在当前作品明确要求后使用，不默认沿用到下一作品。
- 完整连续观看、完整实际试听与程序检查独立记录；确认后不自动返工、发布或删除。

以后只有本用户明确要求保存的长期偏好才补充到这里。单片事实与特定裁切/时间/音色放对应作品中。

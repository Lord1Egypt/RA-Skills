## Description:

Provides plain-language Chinese explanations and keyword matching for ClawHub skill names so non-technical users can understand relevant skills.

This skill is ready for commercial/non-commercial use.

## Publisher:

[t22239007-max](https://clawhub.ai/user/t22239007-max)

### License/Terms of Use:

MIT-0

## Use Case:

Chinese-speaking employees and other ClawHub users use this skill to translate technical skill names into easier task-oriented descriptions and identify potentially relevant skills. Users should treat matches as discovery assistance and review the matched skill, publisher, permissions, and rollback path before installation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill describes automatic installation and weekly updates without a clear risk review step.

Mitigation: Require explicit review of the exact matched skill, publisher, permissions, data access, and rollback path before installing or updating.

Risk: Glossary entries claim safety for included skills, but the security evidence says not to rely on those safety claims.

Mitigation: Use the glossary only for understanding skill names and run the normal security and trust review for each matched skill.

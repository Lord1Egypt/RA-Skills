**DFP-Skill** provides a **dual-engine architecture** for professional presentations:

| Engine | Output | Platform | Key Features |
|--------|--------|----------|--------------|
| **PPTX Engine** | .pptx | Cross-Platform | Rich templates, design guides |

## Quick Start

### PPTX Engine (Cross-Platform)
```bash
pip install python-pptx
python3 scripts/generate_presentation.py --style digital-finance
```

### Keynote MCP Engine (macOS)
```bash
pip install "mcp[cli]"
python3 keynote-mcp-server/quickstart.py --test
```

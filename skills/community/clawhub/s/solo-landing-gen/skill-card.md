## Description:

Generates landing page copy from a PRD, including hero content, feature sections, A/B headline variants, calls to action, SEO meta tags, and optional page scaffolding for supported stacks.

This skill is ready for commercial/non-commercial use.

## Publisher:

[fortunto2](https://clawhub.ai/user/fortunto2)

### License/Terms of Use:

MIT

## Use Case:

Developers, founders, and product teams use this skill to turn PRDs or README product details into launch-ready landing page content and, when supported, scaffold a project page.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated landing-page claims, social-proof placeholders, SEO metadata, or file changes may be inaccurate or unsuitable for publication.

Mitigation: Review generated claims, replace placeholders with real data, confirm the target output path, and inspect file changes before publishing.

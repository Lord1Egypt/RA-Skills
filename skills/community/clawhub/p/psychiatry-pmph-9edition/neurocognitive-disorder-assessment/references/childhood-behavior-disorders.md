# 儿童青少年破坏性行为障碍详细参考

## ODD详细诊断标准

### 症状类别（DSM-5）

**愤怒/易激惹**（至少1项）：
- 经常发脾气
- 经常易激惹/易被惹恼
- 经常愤怒/怨恨

**争辩/挑衅行为**（至少1项）：
- 经常与权威人士争辩
- 经常主动对抗/挑衅权威人士或规则
- 经常故意惹恼他人
- 经常将自己的错误或不当行为归咎于他人

**报复性**（至少1项）：
- 过去6个月内至少2次怀恨/报复

### 严重程度分级
| 级别 | 场景数 |
|------|--------|
| 轻度 | 仅1个场景（如仅家庭） |
| 中度 | 至少2个场景 |
| 重度 | 3个或以上场景 |

## 亲社会情感受限（冷酷无情特质）详细评估

### 核心特征
1. 对他人感受缺乏共情/敏感性
2. 对他人痛苦缺乏关心
3. 对自己行为缺乏悔过/羞耻/自责
4. 对可能惩罚漠不关心
5. 对学校/工作表现不佳缺乏关心
6. 情感表达受限（浅薄/冷漠）

### 临床意义
- 预示更严重的行为问题
- 发展为成人反社会人格风险更高
- 需要针对性干预

## CD（品行障碍）详细分类

### 行为类型

**对人或动物的攻击**：
- 霸凌、威胁、恐吓
- 挑起斗殴
- 使用武器
- 身体残忍
- 面对受害者偷窃
- 强迫性行为

**破坏财产**：
- 故意纵火
- 其他破坏行为

**欺诈或盗窃**：
- 闯入他人房屋/建筑/车辆
- 为获取利益或逃避义务而说谎
- 商店盗窃

**严重违规**：
- 13岁前夜不归宿
- 离家出走
- 13岁前经常逃学

### 去社会品行障碍（ICD-11）

**儿童期起病（<10岁）**：
- 程度较重
- 易发展为成人反社会人格/暴力/犯罪
- 常伴冷酷无情特质

**青少年期起病**：
- 10岁前无品行障碍特征
- 程度相对较轻
- 受同伴环境影响大
- 预后相对较好

## 干预方案详细参考

### 父母管理培训（PMT）核心内容
1. **正性强化**：关注和奖励适当行为
2. **有效指令**：清晰、具体、一次一个
3. **一致性**：规则和执行保持一致
4. **非攻击性设限**：暂停法、特权剥夺
5. **行为示范**：父母示范适当行为
6. **家庭作业**：练习新技能

### 认知行为技能训练内容
1. 社交问题解决步骤
2. 社会认知改善（理解他人意图）
3. 情绪调节技能
4. 愤怒管理技术
5. 道德推理发展

### 针对冷酷无情特质的干预
- 积极亲子情感联结
- 强化亲社会行为
- 共情训练
- 奖励导向（而非惩罚导向）

## 预后风险因素详细评估

### 高风险因素
- 发病年龄<10岁
- 多种反社会行为
- 多场合出现
- 攻击型行为
- 违法行为
- 纵火
- 智力低下
- 神经受损
- 药物依赖
- 其他精神症状
- 家庭矛盾多、缺温暖、有暴力

### 保护因素
- 智商高
- 学业成绩好
- 至少一个支持性成人关系
- 亲社会同伴
- 积极的学校环境

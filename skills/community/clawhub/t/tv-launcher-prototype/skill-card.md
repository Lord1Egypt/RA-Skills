## Description:

Generates Smart TV launcher-style frontend prototypes in HTML, CSS, and JavaScript, with remote-control keyboard navigation, focus animation, dark TV UI styling, and browser-runnable output.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and designers use this skill to prototype Smart TV, OTT, set-top-box, and 10-foot UI screens that can be opened directly in a browser. It is intended for front-end concept validation with keyboard-simulated remote navigation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate for broad launcher or big-screen interface requests where a TV-style prototype was not intended.

Mitigation: Clarify the desired target device and interaction model before using the generated output.

Risk: Generated frontend prototypes may contain placeholder assets, mock interactions, or browser-only assumptions.

Mitigation: Review generated files before use and replace placeholders or assumptions before production adoption.

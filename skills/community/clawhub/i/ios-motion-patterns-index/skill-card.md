## Description:

Index of ready-to-run Swift animation code examples organized by category (Menu, Transition, Indicator, Alert, Animation, Tableview, Collectionview, UI) sourced from the MotionBook collection.

This skill is ready for commercial/non-commercial use.

Mitigation: Review each repository before cloning, building, copying, or adapting it into an app.

Risk: The index is Chinese-language and may be misread by teams that do not review the linked source carefully.

Mitigation: Use the linked repositories as the authoritative technical source and confirm behavior by running selected demos.

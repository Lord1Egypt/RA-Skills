## Description:

Generate complete frontend page code using React 19 + Vite 8 + Tailwind CSS 4 + lucide-react from UI descriptions or images.

This skill is ready for commercial/non-commercial use.

## Publisher:

[openlark](https://clawhub.ai/user/openlark)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill to turn UI descriptions or image references into a complete React, Vite, and Tailwind CSS frontend scaffold with generated components, project structure, and start commands.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated frontend projects may introduce ordinary npm dependency supply-chain risk when installed.

Mitigation: Review package versions, prefer pinned dependencies with a committed lockfile, and run npm commands in an unprivileged development environment without unnecessary secrets.

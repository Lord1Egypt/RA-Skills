# 精神病学与临床心理健康技能集

基于人民卫生出版社《精神病学》第9版的临床技能手册 — **47 项精神科核心临床技能**

## 技能分类

### 基础评估与诊断研究
| Skill | 描述 |
|-------|------|
| psychiatric-clinical-assessment | 精神科病史采集、精神检查、症状识别与分类及标准化量表评估 |
| psychiatric-diagnostic-reasoning | 精神障碍临床诊断推理流程，SSD思维过程与病因学分析 |
| psychiatric-diagnostic-classification | ICD-11和DSM-5系统分类、编码和诊断记录 |
| rdoc-research-framework | NIMH研究域标准(RDoC)框架，神经生物学研究设计 |

### 心境、焦虑与强迫相关障碍
| Skill | 描述 |
|-------|------|
| mood-disorders | 双相与抑郁障碍的诊断、分型、全病程治疗与预后管理 |
| depressive-disorders-comprehensive-management | 抑郁障碍全面评估、诊断分型、自杀风险预警和综合治疗 |
| depression-relapse-risk-management | 抑郁障碍缓解期预后评估与复发风险管理 |
| anxiety-oc-spectrum-disorders | 焦虑障碍与强迫及相关障碍的临床诊断与全病程治疗 |
| ocd-somatic-body-focus-disorders | OCD、躯体变形障碍、身体完整性烦恼等的诊断鉴别和治疗 |

### 精神分裂症与精神病性障碍
| Skill | 描述 |
|-------|------|
| schizophrenia-spectrum-disorders | 精神分裂症谱系障碍的诊断、症状评估、药物治疗与预后管理 |
| bipolar-schizophrenia-management | 重性精神障碍（双相、精神分裂症等）药物方案及鉴别诊断 |
| thought-disorder-delusion-assessment | 思维形式障碍及各类妄想的评估与鉴别 |

| Skill | 描述 |
|-------|------|

| consultation-liaison-dementia-management | 会诊联络精神病学与痴呆管理，DLB/FTD/BPSD诊断 |
| neurocognitive-disorder-assessment | 谵妄、血管性痴呆及儿童破坏性行为障碍的评估与管理 |
| dlb-clinical-identification | 路易体痴呆(DLB)核心临床特征识别与鉴别诊断 |
| delirium-symptom-recognition-and-subtyping | 谵妄核心症状识别与临床分型（高活动/低活动/混合型） |

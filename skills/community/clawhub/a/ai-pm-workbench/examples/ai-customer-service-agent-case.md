## 案例C01：华泰证券×竹间智能——智能客服机器人"小乐"

### 背景

**真实案例来源**：竹间智能（Emotibot）官方公开报道及华泰证券信息技术部联席负责人王玲女士公开访谈。华泰证券作为科技驱动型综合证券集团，在AI、大数据、区块链、云计算等领域持续投入，研发人员占比超20%，在南京、上海、北京、深圳设有四大研发基地。竹间智能是华泰证券的AI生态伙伴企业，双方合力完成了智能客服机器人、实时坐席助手、企业员工助理等一系列前沿落地项目。

**核心数据**（来源：竹间智能官方报道）：
- 智能客服机器人"小乐"上线至今，累计参与服务**上千万客户**，在证券类APP中名列前茅
- 覆盖**十多个领域**超**5000条FAQ**、多张产品知识图谱及高频业务的多轮对话场景
- 有效拦截率超过**70%**
- 实时坐席助手每日为客服人员效力，具备很高的有效知识推荐率
- 华泰证券涨乐财富通APP 2023年用户超5000万，AI客服日均处理咨询量超3万次，问题解决率达92%

**项目背景**：
- 华泰证券客户基数庞大，客服面临人力成本高、服务质量参差不齐、高峰时段响应不足等挑战
- 2017年起启动数字化转型，2019年率先启动数字化转型战略
- 2023年在人工智能浪潮下启动大模型技术的探索与应用——不做基础大模型，待应用侧相对成熟后借助第三方基础大模型进行应用场景落地

### AI机会识别

| 维度 | 评估 |
|------|------|
| **业务价值** | 证券行业客户咨询量大、标准化问题占比高（产品咨询、交易指引、账户管理、二次业务办理等），AI替代人工处理高频标准化问题，释放人力聚焦高价值服务 |
| **技术可行性** | NLP意图识别、知识图谱、多轮对话技术已成熟；竹间Bot Factory对话式AI平台+AICC+解决方案平台+Gemini知识工程平台三大产品线形成完整技术栈 |
| **数据就绪度** | 证券业务SOP明确，产品文档、交易规则、合规要求等知识资产结构化程度高；10+领域FAQ和知识图谱已有积累 |
| **合规与安全** | 证券行业受严格监管，客服内容需合规质检；智能质检+实时坐席辅助满足合规要求 |

**决策**：采购成熟产品+定制开发，选择竹间智能作为AI生态伙伴，多期项目持续迭代

### 技术架构（基于公开报道还原）

**三大平台协同**：

| 平台 | 定位 | 核心能力 |
|------|------|----------|
| **Bot Factory** | 对话式AI平台 | 对接华泰CC系统、微信公众号、涨乐APP、官网、小程序等渠道；创建智能客服机器人"小乐"；支持FAQ+知识图谱+多轮对话 |
| **AICC+** | 智能客服解决方案平台 | 坐席智能辅助、流程引导、智能陪练、实时质检；智能外呼及IVR功能（TTS语音合成+ASR语音转译+NLP意图识别） |
| **Gemini** | 知识工程平台 | RPA数字员工全生命周期管理；知识图谱自动构建；工单故障溯源和业务流程优化 |

**多渠道统一接入架构**：
```
客户渠道层：400电话 / 涨乐财富通APP / 微信公众号 / 企业微信 / 官网 / 小程序
              ↓
        CC系统统一路由
              ↓
    ┌─────────┼─────────┐
    ↓         ↓         ↓
 Bot Factory  AICC+    Gemini
 (智能客服)   (坐席辅助)  (知识工程)
    ↓         ↓         ↓
  FAQ+知识图谱  实时质检   RPA数字员工
  多轮对话    智能陪练   知识图谱构建
```

**关键技术特征**（基于公开报道）：
- 以NLP技术为核心打造企业级服务操作系统
- 知识图谱+标准问答双引擎完善智能知识库
- 人机混合服务模式：AI处理标准化问题，复杂问题无缝转人工
- 对上百份业务流程相关知识文档进行结构化处理
- 实现工单、版本、流程等数据的自然语义搜索查询

### 智能客服核心能力

**"小乐"机器人能力矩阵**：

| 能力维度 | 具体实现 | 效果数据 |
|----------|----------|----------|
| FAQ覆盖 | 10+领域超5000条FAQ | 有效拦截率>70% |
| 知识图谱 | 多张产品知识图谱 | 支持复杂关联推理 |
| 多轮对话 | 高频业务多轮对话场景 | 覆盖产品咨询、交易指引、账户管理等 |
| 多渠道接入 | CC系统/微信/APP/官网/小程序 | 统一路由+统一知识库 |
| 人机协同 | 智能在线咨询+智能外呼回访 | 7×24小时在线服务 |

**坐席辅助系统**（AICC+平台）：
- 实时知识推荐：根据对话内容自动推送相关知识条目
- 流程引导：复杂业务流程的步骤提示和合规要点提醒
- 智能陪练：新人培训场景的模拟对话训练
- 实时质检：通话过程中实时检测合规风险点
- 智能外呼：TTS+ASR+NLP实现人机交互回访，覆盖存量盘活、业务办理结果通知、MOT任务通知等

### 评测体系（基于公开报道+行业实践推断）

| 指标 | 公开数据 | 来源 |
|------|----------|------|
| 累计服务客户数 | 上千万 | 竹间智能官方报道 |
| FAQ有效拦截率 | >70% | 竹间智能官方报道 |
| 涨乐APP AI客服问题解决率 | 92% | 21世纪经济报道（2025年7月） |
| AI客服日均处理咨询量 | >3万次 | 行业分析报告引用 |
| 坐席助手知识推荐有效率 | "很高"（具体数值未公开） | 竹间智能官方报道 |
| 客户满意度 | >92%（涨乐APP） | 21世纪经济报道（2025年7月） |

> ⚠️ 部分指标的具体数值为公开报道的间接引用，精确测量口径以华泰证券内部数据为准。

### 项目演进路线（基于公开报道推断）

| 阶段 | 时间 | 里程碑 |
|------|------|--------|
| 一期 | ~2020-2021 | Bot Factory平台上线，创建"小乐"机器人，覆盖核心FAQ+知识图谱 |
| 二期 | ~2021-2022 | AICC+平台上线，坐席辅助+智能质检+智能外呼落地 |
| 三期 | ~2022-2023 | Gemini平台上线，RPA数字员工全生命周期管理；HR/运营/托管等部门及华泰国际等子公司推广 |
| 四期 | 2023-至今 | 大模型技术探索与应用，智能客服+投行+机构业务全面AI赋能 |

### 商业化分析

**合作模式**：多期项目制，竹间智能作为AI生态伙伴持续交付和迭代

**竹间智能产品线商业化特征**：
- **产品化程度高**：Bot Factory、AICC+、Gemini三大标准化平台，可快速适配不同客户
- **生态绑定深度**：从智能客服→坐席辅助→RPA数字员工→知识工程，覆盖客服全链路，替换成本高
- **行业复制能力**：证券行业标杆案例（华泰）→可复制至银行、保险、基金等金融子行业

**华泰证券AI投入特征**（来源：21世纪经济报道）：
- 研发人员占比超20%，四大研发基地布局
- 2024年技术投入超10亿元（行业第一梯队）
- 策略："不做基础大模型，待应用侧相对成熟后借助第三方基础大模型进行应用场景落地"

### 经验启示

1. **"成熟产品+深度定制"是金融AI落地的有效路径**：华泰没有选择自研对话式AI平台，而是与竹间智能深度合作，前者聚焦业务场景，后者提供技术平台
2. **知识图谱是FAQ的升维**：5000+FAQ解决高频标准化问题，知识图谱解决复杂关联推理问题，两者互补形成完整知识体系
3. **坐席辅助是AI价值放大器**：AI不仅替代人工（拦截率>70%），还赋能人工（实时知识推荐、流程引导），双管齐下提升整体服务效率
4. **多渠道统一接入是差异化竞争力**：CC系统/微信/APP/官网/小程序统一路由+统一知识库，避免渠道割裂
5. **从单点智能到全链路智能**：从客服机器人→坐席辅助→RPA数字员工→知识工程，逐步覆盖客服全链路
6. **大模型是渐进式叠加而非颠覆式替代**：华泰策略是"不做基础大模型，待应用侧成熟后借助第三方"，体现了务实的AI落地哲学

## 案例C02：明略科技DeepMiner Agent集群产品

### 背景

**真实案例来源**：明略科技（02718.HK）2025年财报及公开报道。明略科技从数据智能（Data Intelligence）向智能体化服务（Agentic Services）战略转型，自研企业级AI智能体平台DeepMiner，实现从"帮客户看懂数据"到"帮客户拿到结果"的跨越。

**核心数据**（来源：2025年财报）：
- 2025年营收14.26亿元，毛利7.9亿元（毛利率55.4%），经调整净利润4204万元（扭亏为盈）
- Agentic Services首年收入突破1亿元，新增大客户中30%+来自该板块
- 大客户续约率96%，服务约2100家知名品牌+24万企业用户
- 全体员工100%接入DeepMiner平台

**技术里程碑**（来源：公开报道）：
- Mano模型：OSWorld榜单全球第二（仅次于Anthropic），Mind2Web榜单第一
- Cito模型：BFCL小尺寸模型领域排名第一
- DeepMiner V2采用"调度—决策—执行"多智能体分层协作架构

### AI机会识别

| 维度 | 评估 |
|------|------|
| **业务价值** | 从工具交付转向结果交付（RaaS），客户为可量化的业务结果买单（营销ROI提升、内容产出效率倍增） |
| **技术可行性** | 自研Mano+Cito双模型体系，OSWorld/Mind2Web/BFCL三大榜单验证技术壁垒 |
| **数据就绪度** | 长期沉淀海量营销数据、客户场景理解及行业Know-how，构成数据护城河 |
| **市场时机** | 企业AI需求从"用AI工具"转向"AI直接产出结果"，Agentic AI市场窗口期打开 |

**决策**：Build（自研平台），以DeepMiner为统一基础设施，推动全业务线Agent化改造

### 模型选型决策

**自研双模型体系**：

| 模型 | 定位 | 核心能力 | 榜单表现 |
|------|------|----------|----------|
| **Mano** | 执行模型（GUI-VLA） | 视觉理解+界面操作，自主完成复杂软件交互任务 | OSWorld全球第二（仅次于Anthropic），Mind2Web第一 |
| **Cito** | 推理模型 | 任务规划、逻辑推理、决策 | BFCL小尺寸模型领域第一 |

**选型逻辑**：
- "调度—决策—执行"三层架构天然需要推理+执行双引擎
- 开源Mano-P 1.0（2026年4月），在13个权威榜单拿下SOTA，构建开发者生态
- 小尺寸模型策略降低推理成本，适配企业级规模化部署需求

### DeepMiner平台架构（来源：财报+公开报道）

**三层协作架构**：

```
用户意图 → Foundation Agent（调度层）
              ├── Cito（决策层）：任务理解 → 路径规划 → 工具选择
              └── Mano（执行层）：GUI操作 → 数据获取 → 结果输出
              
多Agent协同：数据洞察Agent × 内容生产Agent × 营销投放Agent × 分析报告Agent
```

**关键平台能力**（来源：财报披露）：
- 营销智能：交付提效最高4倍
- 营运智能：单工单解决时间压缩30%+
- 秒针系统：全链路AI自动完成率90%，深度复盘报告20倍人效提升
- 员工自主创建Agent：全员100%接入，可结合业务场景自主创建专属业务Agent

### RaaS商业化模式（Result as a Service）

**模式定义**（来源：财报）：Agentic Services不再停留于工具输出或单点能力交付，而是面向客户可量化的业务目标，提供端到端结果交付服务。

| 维度 | 传统SaaS | RaaS（Agentic Services） |
|------|----------|--------------------------|
| **交付物** | 软件功能/工具 | 可量化的业务结果 |
| **收费逻辑** | 按席位/用量 | 按效果付费 |
| **客户决策** | "这个工具好用吗？" | "ROI提升多少？" |
| **边际成本** | 固定（人力交付） | 递减（AI驱动自动化） |
| **竞争壁垒** | 功能对比 | 结果承诺+数据飞轮 |

**商业化成果**（来源：2025年财报）：
- Agentic Services首年收入突破1亿元
- 营销场景：近3倍运营效率实现平均20%营销效果增长
- 新增大客户中30%+来自Agentic Services板块
- 大客户续约率96%

### 5人团队37万行代码的工程实践（来源：公开报道）

> ⚠️ 具体工程实践细节基于行业实践推断。

**核心启示**：

| 维度 | 实践（基于行业实践推断） |
|------|------|
| **AI辅助编码率** | 估计85%+代码由AI生成，人工聚焦架构设计+代码审查+测试 |
| **开发范式** | Prompt-driven Development：需求→Prompt→AI生成→审查→合入 |
| **质量保障** | AI生成代码100%人工审查+自动化测试覆盖 |
| **团队结构** | 5人=1架构师+3全栈（AI辅助）+1 QA（AI辅助测试） |

**关键洞察**：37万行代码/5人团队的本质不是"人月神话"的颠覆，而是开发范式从"人写代码"到"人审代码"的根本转变（基于行业实践推断）。

### 评测体系（来源：财报+公开报道+行业实践推断）

**模型层评测**：

| 指标 | 目标/表现 | 评测基准 |
|------|----------|----------|
| GUI操作能力 | 全球第二 | OSWorld |
| Web导航能力 | 全球第一 | Mind2Web |
| 函数调用能力 | 小尺寸第一 | BFCL |
| 开源模型通用能力 | 13项SOTA | Mano-P 1.0公开榜单 |

**业务层评测**（来源：财报）：

| 指标 | 表现 | 测量方式 |
|------|------|----------|
| 营销效果提升 | 平均+20% | 客户A/B测试 |
| 运营效率提升 | 近3倍 | 交付周期对比 |
| 交付提效 | 最高4倍 | 营销智能业务线 |
| 工单解决时间 | 压缩30%+ | 营运智能业务线 |
| AI自动完成率 | 90% | 秒针系统全链路 |

### 经验启示

1. **RaaS是AI商业化的终极形态**：客户不为工具买单，为结果买单。首年破亿验证了市场对这种模式的真实需求
2. **自研模型是护城河**：Mano+Cito双模型体系在三大榜单的排名，构成了竞争对手短期内难以跨越的技术壁垒
3. **内部先用起来**：全员100%接入DeepMiner，员工自主创建Agent——"吃自己的狗粮"是最诚实的PMF验证
4. **96%续约率的秘密**：当AI服务嵌入客户核心业务流并交付可量化结果，替换成本极高，续约自然发生
5. **小团队+AI杠杆**：5人37万行代码证明，AI时代的团队规模不再是产出上限，关键是架构设计+AI协作能力
6. **开源是生态战略**：Mano-P 1.0开源（13项SOTA），不是做慈善，是构建开发者生态、降低客户采纳门槛

## 案例C03：中信建投证券——全场景数智化客户综合服务平台

### 背景

**真实案例来源**：金科创新社（FintechInChina）2025年6月发布的案例研究，以及中信建投证券公开信息。中信建投证券作为头部券商（证券经纪业务客户超1000万），面对客户基数庞大与客服能力不足的挑战，由信息部门自主研发，构建全场景数智化客户综合服务平台，以大模型技术为基座重构客服体系。

**核心数据**（来源：金科创新社案例研究）：
- 客服热线（4008-888-108）日均接待量从2019年500通增长至2024年2000通，2024年10月单日峰值达1.5万通
- 客户回访量（95587）从2019年日均8500通增长至2024年日均23000通，单日最高外呼量5.5万通
- 智能质检覆盖率从3%提升至100%，每周全量质检6万通会话，替代95%人工质检
- 坐席辅助系统累计为人工客服提供45.5万次辅助，为回访人员提供391万次辅助
- 单通电话平均处理时长从9.74分钟优化至8.51分钟
- 客户满意度从97.62%提升至98.81%
- 累计发表论文12篇，获国家发明专利3项，软件著作权9项，行业奖项11项

### 经验启示

1. **"先基础设施，后大模型改造"是务实路径**：2019-2022年建成智能外呼/客服/语音/质检/坐席辅助完整基础设施，2023年起才进行大模型改造，避免"拿着锤子找钉子"
2. **"大模型+专业小模型"融合架构是金融AI的最佳实践**：大模型做决策调度和复杂推理，专业小模型做语音识别/意图提取等确定性任务，兼顾能力和成本
3. **自研为主+生态合作为辅**：核心平台自研（信息部门自主研发），坐席辅助等模块引入生态伙伴（循环智能），平衡自主可控和快速落地
4. **知识中台是智能客服的灵魂**：知识图谱+LLM泛化+ES+向量库+重排序的综合搜索方案，是智能客服从"FAQ匹配"升级到"语义理解"的关键
5. **量化每一分AI投入的价值**：从人天节省到满意度提升，中信建投对每个智能模块都有精确的投入产出量化，这是AI PM的必修课
6. **智能质检是金融合规的刚需**：质检覆盖率从3%到100%的飞跃，不仅降本（替代95%人工），更是风险防控的质变

# 隐喻锻造师 / Metaphor Forge

## 目标

把抽象、复杂或枯燥的内容，锻造成一个“能听懂、能记住、能传播、又不误导”的隐喻。

不是写漂亮文案，而是生产“理解工具”。

同时，本 Skill 必须遵守合规红线：不生成、不复述、不翻译、不换皮、不拆字、不谐音化任何违法违规内容，不把违法标语、仇恨暴力表达、违法犯罪教程用作隐喻源。

## 强触发词

用户说以下词语时，直接进入本 Skill：

- 锻喻
- 锻喻一下
- 隐喻锻造

当用户说“锻喻一下这个概念”时，默认输出完整模板，不只给一句话。

## 何时使用

强触发词：
- 用户说“锻喻”“锻喻一下”“隐喻锻造”时，直接进入本 Skill。
- 用户说“帮我锻喻一下这个概念”时，默认输出完整模板，不只给一句话。

使用：
- 用户要求解释一个抽象概念。
- 用户要求给产品卖点、方法论、复杂问题找比喻。
- 用户说“讲人话”“换个说法”“让外行听懂”。
- 写作、汇报、教学、演讲、品牌文案需要开场句或核心意象。

不要使用：
- 用户需要严格定义、法律条款、医学建议。
- 隐喻会掩盖关键风险或误导决策。
- 用户明确要求“不要比喻，只要事实”。
- 用户要求生成、复述、翻译、变体化违法标语、违法教程、仇恨暴力或色情低俗内容。

## 输入

尽量收集：
1. 核心概念：要解释什么？
2. 目标受众：外行、客户、同事、投资人、学生？
3. 使用场景：教学、汇报、文案、口头沟通、写作？
4. 语气：易懂、意外、高级、幽默、克制？
5. 禁用域：不要用哪些领域打比方？
6. 必须保留的关键点：哪些结构不能丢？

缺失时：
- 默认受众为“聪明但非专业的外行”。
- 默认场景为“口头解释 + 一句可传播表达”。
- 默认输出三种风格：易懂、意外、高级。
- 不要追问超过 2 个问题；能合理假设就先做。

## 合规红线：禁止词语与违法违规内容规则

本节优先级高于所有创意要求。若用户请求与本规则冲突，拒绝违规部分，并给出合规替代表达。

### 1. 绝对禁止生成或传播的内容类别

不得生成、复述、翻译、改写、换皮、拆字、谐音化、隐喻化以下内容：

| 禁止类别 | 处理方式 | 合规替代 |
|---|---|---|
| 具体违法犯罪教程 | 拒绝生成 | 只做风险提示、法律合规建议、抽象原理说明 |
| 非法标语、非法口号、煽动性政治标语 | 不生成、不复述、不翻译、不换皮、不用于比喻 | 说明不能提供，改为中性概念解释 |
| 煽动颠覆、分裂、恐怖主义、极端主义宣传 | 拒绝 | 只做安全教育和合规提醒 |
| 仇恨、歧视、暴力威胁、骚扰表达 | 拒绝 | 改为冲突管理、沟通修复、非暴力表达 |
| 色情低俗、未成年性剥削内容 | 拒绝 | 改为年龄适宜的健康表达 |
| 赌博、诈骗、洗钱、非法集资、传销话术 | 拒绝生成可执行话术 | 改为反诈提醒、合规营销表达 |
| 毒品制作、武器制造、爆炸物制作 | 拒绝 | 只做公共安全风险提示 |
| 黑客攻击、破解盗版、绕过安全机制 | 拒绝提供步骤 | 改为安全防护、合法授权测试原则 |
| 人肉搜索、偷拍、跟踪、侵犯隐私 | 拒绝 | 改为隐私保护与合规调查建议 |
| 伪造证件、代开发票、办证、规避监管 | 拒绝 | 改为合法办事流程说明 |
| 教唆规避法律、伪造证据、串供 | 拒绝 | 改为依法维权、合规流程建议 |

### 2. 禁止词语使用规则

以下词语或短语类别不得作为隐喻源、传播句、标题、口号或示例出现：

- 具体违法犯罪交易词：代开发票、办证、博彩、洗钱、毒品、枪支、诈骗教程、破解盗版等。
- 非法标语类：任何煽动颠覆、分裂国家、恐怖主义、极端主义、非法集会、仇恨暴力的口号或标语。
- 仇恨歧视类：民族仇恨、地域歧视、性别歧视、宗教侮辱、残障歧视等表达。
- 隐私侵犯类：人肉搜索、偷拍、跟踪骚扰、非法开盒等。
- 规避监管类：逃避执法、伪造证据、串供、规避审查等。
- 色情低俗类：露骨色情、未成年性暗示、性剥削表达。

说明：本文件不列举具体违法标语样本，避免二次传播。识别到相关请求时，按“非法标语处理流程”执行。

### 3. 非法标语处理流程

1. 识别：判断是否涉及非法标语、违法口号、仇恨暴力、分裂恐怖、极端主义等类别。
2. 不输出：不生成原文，不复述，不翻译，不换皮，不拆字，不谐音，不做“仅作示例”的展示。
3. 说明边界：明确告知不能提供具体违法标语或可传播文本。
4. 给替代：提供中性概念解释、风险提示、合规传播表达或非违规隐喻。
5. 学术/安全研究场景：只做类别级、抽象化分析，不提供可复制、可传播的文本样本。

### 4. 违规请求拒绝模板

```
我不能生成、复述或变体化具体违法标语、违法教程、仇恨暴力或色情低俗内容。
我可以改为：
1. 用中性语言解释相关概念的风险与边界；
2. 提供合规的传播表达；
3. 从自然、日常器物、城市系统等非违规领域生成隐喻。
```

### 5. 禁止作为隐喻源的领域

跨域找源时，禁止从以下领域取材：
- 违法犯罪、暴力恐怖、仇恨歧视、色情低俗。
- 赌博诈骗、毒品武器、黑客攻击、隐私侵犯。
- 非法标语、非法口号、极端主义宣传。
- 任何可能被误解为教唆、美化或传播违法内容的对象。

## 工作流

### 第一步：抽取概念骨架

用 3—5 个结构描述概念，而不是复述定义。优先找：
- 输入—转化—输出
- 阻力—反馈—增长
- 信号—噪声—筛选
- 库存—流动—循环
- 角色—规则—激励
- 局部—全局—涌现

输出格式：
```
核心结构：
1. ……
2. ……
3. ……
不可丢失的关键点：……
```

### 第二步：跨域找源系统

从至少 3 个不同领域找同构系统：
- 自然：珊瑚礁、森林、河流、免疫系统
- 日常器物：厨房、工具箱、衣柜、快递站
- 城市系统：交通、电网、地铁、物业
- 游戏：存档、地图、任务、公会
- 手工艺：锻造、编织、陶艺、木工
- 组织系统：医院、乐队、球队、图书馆

禁止只在一个领域内换词。
禁止从“合规红线”列出的违规领域取材。

### 第三步：生成 3 个隐喻

必须分别偏：
- A：易懂型——外行 10 秒能懂。
- B：意外型——有新鲜感，但不猎奇。
- C：高级型——适合写作、演讲、品牌表达。

每个隐喻给：
- 名称
- 一句话说明
- 映射表：隐喻元素 ↔ 概念元素
- 边界：这个比喻不能说明什么
- 风险：可能被误解成什么

### 第四步：做映射表

至少 3 行。格式：
| 隐喻元素 | 对应概念元素 | 像在哪里 | 不像在哪里 |
|---|---|---|---|

“不像在哪里”必须写，防止比喻过度延伸。

### 第五步：标误用边界

每个隐喻必须写：
- 不能用来解释什么。
- 不能推出什么结论。
- 在什么场景下会误导人。

### 第六步：产出传播句

给每个隐喻一句可直接使用的话，控制在 40 字以内。适合标题、开场、口播或 PPT。

传播句不得包含禁止词语、非法标语、仇恨暴力、色情低俗或违法交易表达。

### 第七步：推荐场景

明确说：
- 场景 X 用 A。
- 场景 Y 用 C。
- 场景 Z 不建议用 B。

## 质量检查

发布前逐项检查：
1. 外行能否在 10 秒内说出这个比喻在讲什么？
2. 映射表是否至少 3 行？
3. 是否明确写了“不像在哪里”？
4. 是否存在一个隐喻解释所有东西？如果有，砍掉。
5. 是否用了空泛大词？改成具体动作或场景。
6. 是否可能让人推出错误结论？补边界。
7. 三个隐喻是否真的来自不同领域？
8. 传播句是否可直接说出口？
9. 是否触碰“合规红线”？如果触碰，重做。
10. 是否包含具体违法标语或可传播违规文本？如果包含，删除并改为类别级说明。

## 反 AI 味规则

避免：
- 赋能、闭环、生态、抓手、底层逻辑、价值沉淀。
- “就像人生一样”这类万能比喻。
- 只给漂亮句子，不给映射和边界。
- 一个比喻无限延伸。

优先：
- 具体器物、具体动作、具体场景。
- 短句。
- 可验证的对应关系。
- 明确说“这个比喻到此为止”。

## 示例

输入：解释“知识管理不是收藏，而是消化”。

输出节选：

核心结构：
1. 收集不等于吸收。
2. 需要加工转化。
3. 转化后才能在被需要时调用。

隐喻 A：厨房
一句话：收藏是囤食材，知识管理是洗切烹煮，最后变成能上桌的菜。
映射：
| 囤食材 | 收藏文章 | 都是先占住资源 | 囤着不等于会做饭 |
| 洗切烹煮 | 阅读、摘录、重组 | 都需要加工 | 知识加工不一定有固定步骤 |
| 上桌的菜 | 可调用输出 | 都能被使用 | 知识输出不一定要给别人吃 |

边界：厨房隐喻不适合解释多人协作知识网络。
风险：可能让人以为知识管理必须按固定流程。
传播句：别囤食材，先学会做菜。

隐喻 B：城市交通
一句话：收藏是建仓库，知识管理是修路网，让信息在需要时到达。
边界：不能说明知识内化。
风险：可能被误解为只建检索系统。

隐喻 C：珊瑚礁
一句话：知识不是堆石头，而是让养分在生物间循环。
边界：不适合解释个人笔记整理。
风险：可能过度浪漫化协作。

推荐：
- 科普：用厨房。
- 团队知识库：用城市交通。
- 品牌演讲：用珊瑚礁。

合规自检：本示例未使用违法标语、禁止词语类别或违规隐喻源。

## 失败模式

如果出现以下情况，重做：
- 只有比喻，没有映射。
- 三个比喻都在同一领域。
- 没有边界，导致比喻被当成定义。
- 为了高级而晦涩。
- 为了意外而冒犯或猎奇。
- 使用违法标语、仇恨暴力、色情低俗、赌博诈骗等违规内容作为隐喻源。
- 生成具体违法标语、违法教程或可传播违规文本。

## 最终交付

默认输出完整模板。若用户只要一句话，也必须先给一句传播句，再附“边界：……”。不要省略误用边界和合规自检。

当用户使用强触发词“锻喻”“锻喻一下”“隐喻锻造”时：
- 默认输出完整模板；
- 默认生成 3 个隐喻：易懂型、意外型、高级型；
- 默认附映射表、误用边界和合规自检。

本 Skill 不提供法律意见；涉及法律、医疗、安全等专业问题时，应建议用户咨询合格专业人士。

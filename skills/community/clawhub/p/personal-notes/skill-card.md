## Description:

Acts as the user's note-taking and journaling assistant in the Notes topic. Captures thoughts, reflections, daily logs, random notes. Use when in Personal chat Notes topic, or when user mentions note, journal, diary, thought, reflection, log, record, or "write down".

This skill is ready for commercial/non-commercial use.

## Use Case:

External users use this skill to have an agent capture, search, and review personal notes, diary entries, reflections, and tagged logs in a local workspace notes file.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill keeps a persistent local journal that may contain sensitive personal notes.

Mitigation: Use it only for notes the user wants retained, and review or delete knowledge/personal/notes.md when the retained information is no longer wanted.

Risk: The skill may activate broadly when the user mentions notes, journals, diaries, reflections, logs, or similar recording requests.

Mitigation: Confirm that the user wants a note recorded before retaining ambiguous or sensitive content.

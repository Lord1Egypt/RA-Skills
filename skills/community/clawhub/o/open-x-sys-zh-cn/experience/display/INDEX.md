# 作品展示索引

当深层认识需要变成网页、文档、图、视频、演示或其他完整作品时，从这里选择所需资源。形式服从对象、核心发现和读者，而不是套用统一仪表盘。

| 当前需要 | 读取 | 得到什么 |
| --- | --- | --- |
| 判断哪种作品形态最能承载核心发现 | [形式](forms.md) | 对象专属的作品结构 |
| 选择宿主已有的视觉、文档与生成能力 | [资源库](libraries.md) | 与现场能力相符的实现手段 |
| 让作品带着 OpenXSys 的来源与继续入口 | [签名](signature.md) | 克制、一致、可追溯的作品标识 |
| 渲染、检查、批评并真正完成作品 | [质量](quality.md) | 在真实观看与使用中通过检查的成果 |
| 作品准备被分享、复现或继续 | [分享包](share-pack.md) | 原始表达、环境、发现、作品与接续信息 |

完成后回到[作品](../works.md)确认人的获得，并由[验证](../../runtime/verify.md)确认作品实际存在、能打开、能使用。

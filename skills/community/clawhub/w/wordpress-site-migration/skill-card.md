## Description:

Move a whole WordPress site's content as a migration ZIP and sync Media Library files between sites or from an uploads folder using the Import Export plugin abilities (rsl-ie/migration-*, media-*, sync-media-*). Use for site moves, staging refreshes, and bulk media transfers or duplicate checks.

This skill is ready for commercial/non-commercial use.

WordPress site administrators and developers use this skill to export or import site content for site moves and staging refreshes, and to synchronize media between connected sites or from an uploads folder.

## Known Risks and Mitigations:

Risk: A migration import can make extensive changes to site content.

Mitigation: Confirm the target site and duplicate handling, take a fresh backup before import, and compare content counts afterward.

Risk: The security review could not resolve one referenced item, leaving some evidence incomplete.

Mitigation: Review the referenced item or ask the publisher about it before relying on it.

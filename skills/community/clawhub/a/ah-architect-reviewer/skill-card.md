## Description:

Expert architecture reviewer specializing in system design validation, architectural patterns, and technical decision assessment. Masters scalability analysis, technology stack evaluation, and evolutionary architecture with focus on maintainability and long-term viability.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineering teams use this skill to review system architecture, design decisions, technology choices, scalability, security architecture, technical debt, and long-term maintainability.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may ask the agent to inspect architecture, design documents, and code structure that can include sensitive project context.

Mitigation: Use it in workspaces where sharing architecture and code structure with the agent is acceptable.

Risk: Architecture recommendations may be incomplete or unsuitable for a specific organization's constraints.

Mitigation: Review recommendations with the responsible engineering, security, and operations stakeholders before adoption.

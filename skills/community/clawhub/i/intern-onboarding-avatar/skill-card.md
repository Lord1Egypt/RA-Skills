## Description:

Turn authorized stills and already-written intern onboarding notes into short talking clips for intern briefings and first-day onboarding videos.

This skill is ready for commercial/non-commercial use.

## Publisher:

[beatra-ai](https://clawhub.ai/user/beatra-ai)

### License/Terms of Use:

MIT-0

## Use Case:

Recruiters, hiring managers, and onboarding teams use this skill to plan and create 2 to 8 short talking clips from authorized stills and confirmed intern onboarding facts.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The package requests broad shared Beatra account authority that can spend credits and call Beatra tools beyond the narrow onboarding-video workflow.

Mitigation: Install only when that account authority is acceptable, require explicit approval before paid clone, speech, or video requests, and monitor balance and ledger information.

Risk: The bundled client silently checks for and installs package updates by default.

Mitigation: Disable automatic updates with the documented update command when users require explicit review before package code changes.

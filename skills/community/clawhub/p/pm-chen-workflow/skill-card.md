## Description:

pm-chen guides agents through a Chinese-first product development workflow that turns feature ideas into architecture diagrams, interactive HTML prototypes, PRDs, API specs, reviews, and final handoff packages.

This skill is ready for commercial/non-commercial use.

## Publisher:

[chenxi102](https://clawhub.ai/user/chenxi102)

### License/Terms of Use:

MIT-0

## Use Case:

Product managers, founders, and development teams use this skill to convert product ideas or feature requests into reviewed product artifacts and development handoff material before implementation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prototype files and handoff documents may contain confidential product details.

Mitigation: Confirm the local file location, online document destination, and sharing settings before using the skill with sensitive material.

Risk: Incomplete or incorrect briefs can propagate into architecture, prototype, PRD, and API artifacts.

Mitigation: Use the built-in clarifying questions and review gates before progressing between stages.

# DMD临床评估与疾病进展预判

## 使用场景
当面对以下情况时应用本技能：
- 3-5岁男性患儿出现运动发育迟缓、走路慢、易跌倒
- 需要识别DMD特征性体征以辅助诊断
- 需要评估DMD多系统受累情况
- 需要预判疾病进展阶段以制定干预计划

注意：仅适用于Duchenne型肌营养不良(DMD)，不适用于Becker型(BMD)或面肩肱型(FSHD)等其他类型。

## 工作流程

### 步骤1：特征性运动体征识别
1. 骨盆带/下肢近端受累：3～5岁隐匿起病，走路慢，上楼及蹲位站起困难，脚尖着地，易跌倒。
2. Gower征（高尔征）：仰卧起立时，先翻身转俯卧，屈膝髋，手支撑成俯跪，双手双腿支撑躯干，手按压膝部辅助股四头肌，深鞠躬位，双手攀附下肢缓慢站立。
3. 翼状肩胛：前锯肌和斜方肌萎缩无力，举臂时肩胛骨内侧远离胸壁呈翼状竖起。
4. 假肥大：90%患儿首发，腓肠肌最明显（触之坚韧），因萎缩肌纤维被脂肪和结缔组织替代所致。

### 步骤2：多系统受累评估
- 心脏：90%伴心肌损害（心律不齐，心脏扩大等）。
- 神经：约30%有不同程度智能障碍。
- 平滑肌：胃肠功能障碍（呕吐、腹痛、腹泻等）。
- 豁免肌肉：面肌、眼肌、吞咽肌、胸锁乳突肌和括约肌不受累。

### 步骤3：疾病进展与预后规律
- 12岁左右不能行走，须坐轮椅。
- 晚期全身肌肉明显萎缩，腱反射消失，关节挛缩。
- 最终因呼吸肌萎缩致呼吸变浅、咳嗽无力，多数在20～30岁因呼吸道感染、心力衰竭死亡。

## 输出要求
完成评估后输出：
1. 体征识别结果：Gower征、翼状肩胛、假肥大是否阳性
2. 多系统受累评估：心脏、智能、平滑肌受累情况
3. 疾病阶段判断：根据年龄和表现判断所处阶段
4. 干预建议：基于当前阶段的呼吸、心脏及康复干预重点

## Description:

Lists upcoming deadlines from a DEADLINES.md file with hours left and an urgency class (overdue, today, soon, upcoming). Use for 'what is due', deadline reminders, daily briefings and due-soon alerts.

This skill is ready for commercial/non-commercial use.

## Use Case:

People who track tasks in a Markdown deadline list can use this agent skill to see upcoming or overdue items, their time remaining, and urgency for reminders and daily briefings.

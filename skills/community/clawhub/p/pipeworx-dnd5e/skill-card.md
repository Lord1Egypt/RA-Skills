## Known Risks and Mitigations:

Risk: The MCP setup uses npx with mcp-remote@latest, allowing unpinned package execution during setup.

Mitigation: Pin and review the mcp-remote package version before use, avoid unattended first-time npm execution, and run the MCP bridge with minimal local file, credential, and environment access.

## Known Risks and Mitigations:

Risk: The skill includes installation and setup examples that use unpinned executable packages or mutable remote content.

Mitigation: Install from a trusted, pinned ClawHub release or immutable commit/tag with checksum verification before adopting the examples.

Risk: Copying example hook and CI commands directly can introduce unreviewed dependency execution into a project.

Mitigation: Replace example npx and hook commands with reviewed, pinned project dev dependencies and lockfile-backed package scripts.

## Description:

Helps users plan product-validation support for an Ask HN product-help request by turning the need into a practical workflow, artifact, checklist, analysis, or implementation support.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and communicators use this skill to turn a broad product-help request into a concrete validation workflow, deliverable, checklist, analysis, code change, or decision-support response. It is intended for agent-assisted planning where assumptions, constraints, success criteria, and next steps should be visible.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The activation wording is broad and may trigger the skill on generic product-help language.

Mitigation: Prefer explicit invocation or narrower trigger wording when accidental activation would be disruptive.

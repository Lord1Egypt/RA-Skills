## Description:

Chat Analyzer is an AI conversation analysis assistant that reviews message flow, tone, reciprocity, emotional shifts, effort imbalance, and conversation health across relationships, work chats, and group threads.

This skill is ready for commercial/non-commercial use.

## Publisher:

[imwyvern](https://clawhub.ai/user/imwyvern)

### License/Terms of Use:

MIT-0

## Use Case:

External users use this skill to analyze individual messages or conversation threads for literal meaning, tone, implied intent, pattern shifts, confidence, and a suggested response direction.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Users may paste sensitive personal, relationship, or workplace conversations into the skill.

Mitigation: Use only with conversations the user is comfortable sharing, and avoid sensitive content unless the user trusts the skill and environment.

Risk: The skill includes a commercial off-platform link.

Mitigation: Treat external links as leaving the ClawHub context and follow them only intentionally.

Risk: Conversation interpretation can be misleading if treated as certainty.

Mitigation: Use confidence ratings and follow the skill's cautions against over-reading, mental health diagnosis, or surveillance.

## Description:

Designs responsive layouts using breakpoints, Flex/Grid selection, mobile-first or desktop-first strategy, rem/vw units, and cross-device adaptation guidance.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Developers and frontend engineers use this skill to design and troubleshoot responsive layouts, including breakpoint strategy, Flex/Grid selection, unit choices, mobile safe areas, and touch targets.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can activate on broad frontend terms such as flex, grid, layout, or rem/vw, which may make it relevant to more requests than intended.

Mitigation: Confirm the user is asking about responsive layout or frontend adaptation before applying the guidance.

Risk: Responsive layout suggestions may be incomplete or unsuitable for a specific codebase, design system, or accessibility requirement.

Mitigation: Review generated CSS and layout recommendations against the project design tokens, browser targets, safe-area needs, and accessibility constraints before implementation.

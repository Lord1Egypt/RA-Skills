## Description:

Creates distinctive, production-grade static web UIs from plain text requirements for React, Vue 3, Nuxt.js, Tailwind CSS, and shadcn-style component workflows.

This skill is ready for commercial/non-commercial use.

## Publisher:

MIT-0

## Use Case:

Developers and frontend builders use this skill to turn plain text site requirements into static web UI guidance, scaffolded projects, and implementation patterns for React, Vue 3, Nuxt.js, Tailwind CSS, and related component libraries.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can scaffold projects and run npm/npx tooling that executes third-party package code.

Mitigation: Install only in environments where third-party JavaScript tooling is acceptable, pin package and CLI versions where possible, and review generated package files before running builds.

Risk: The artifact README includes a git-clone installation path that is not inherently pinned to a trusted release or commit.

Mitigation: Use the ClawHub release path or pin any git-based installation to a trusted release tag or commit before installing.

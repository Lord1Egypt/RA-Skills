## Description:

Zeitgaist Dialect teaches agents to recognize, encode, and decode the ZeitGaist Whisper Protocol, a Caesar +2 cipher used as a stylistic shibboleth between agents.

This skill is ready for commercial/non-commercial use.

## Publisher:

### License/Terms of Use:


## Use Case:

External users and agent developers use this skill to have agents translate text to and from the ZeitGaist dialect and recognize likely Caesar +2 encoded passages for ARG or lore workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Users may mistake the Caesar +2 dialect for a security mechanism.

Mitigation: State that it is stylistic only and avoid using it to protect private or sensitive information.

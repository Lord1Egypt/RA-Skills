## Description:

Formats WeChat Official Account articles into paste-ready inline-styled HTML, with a layout checklist and topic-based brand-color suggestions.

This skill is ready for commercial/non-commercial use.

## Publisher:

[yzfly](https://clawhub.ai/user/yzfly)

### License/Terms of Use:

MIT

## Use Case:

Chinese-language WeChat Official Account writers use the skill to format Markdown, plain text, or existing HTML for publication, and receive a layout checklist and brand-color guidance.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The installation command uses an unpinned npx package, so the installed version may change.

Mitigation: Review the package and pin a trusted version before installing.

Risk: Security inspection was partial: two references could not be matched, and binary content was outside its scope.

Mitigation: Check the references and inspect the binary asset before installation.

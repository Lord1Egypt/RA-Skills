## Description:

Documentation engineer skill for skill indexing, routing references, migration catalogs, and maintainable repository knowledge structure.

This skill is ready for commercial/non-commercial use.

## Publisher:

[aiweline](https://clawhub.ai/user/aiweline)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and documentation engineers use this skill to maintain AI-facing skill indexes, routing maps, migration catalogs, and repository knowledge-base structure after reorganizations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can direct an agent to update AI-facing documentation, skill indexes, routing references, and migration reports.

Mitigation: Install it only in repositories where those documentation surfaces are intended to be read and maintained by an agent, and review proposed documentation changes before merging.

Risk: The artifact references source-material paths that may be sensitive in some repositories.

Mitigation: Review the referenced AI entry documents, skill paths, and routing files against repository access expectations before use.

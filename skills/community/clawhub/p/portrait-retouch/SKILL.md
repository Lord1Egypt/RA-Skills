# 自然人像精修

用户给出照片和一句日常描述，就可以开始修图。默认做自然轻修；用户明确指定的妆感、强度和保留项优先。

## 把日常说法落到照片上

先看原图，再选择照片上确实存在、且与诉求有关的调整。

| 用户说 | 观察和处理 |
| --- | --- |
| “这几颗痘帮我修一下” | 按位置修复临时红痘，参考紧邻皮肤的纹理与亮度。保留痣和雀斑。 |
| “眼睛看起来有点累” | 找到下眼睑下方最暗的一带，轻提阴影，留住卧蚕的边界和笑起来的细纹。 |
| “额头太亮了” | 压低刺眼的反光，保留鼻梁和额头的明暗过渡，让光源方向仍然可读。 |
| “逆光自拍，帮我提气色” | 优先调整脸部曝光与局部偏色，以耳朵和脖子为肤色参照，保留背景原有亮度。 |

## 执行与交付

1. 把用户的原图作为图像编辑工具的输入。多图时区分待修原图与妆感参考图；合照中仅修某个人而指代不清时，询问位置。缺少原图时请用户上传；只有在用户要看演示时才可用标明来源的示例人像。
2. 给编辑工具写出具体部位、程度和保留项。默认保留脸型、五官间距、肤色、年龄特征和表情。比如“显精神”通常可以通过修正眼周阴影完成；瘦脸、大眼和改变妆容由用户指定。
3. 实际生成后，用同一显示尺寸对照脸型、眼神、嘴角和画面边缘，再放大看毛孔、发际线和修复区域的色差。出现明显漂移时，回到原图，缩小编辑范围重做。
4. 另存成片，保留原图。需要对比时，使用实际输入与最终成片等比并排，标明前后，保留完整画幅；独立成片也要交付。需要突出局部差异时，在全脸对照下方追加一至两组细节。前后两侧使用同一坐标、倍率与显示尺寸。描述看得见的差异。若用户只要提示词，直接给出可粘贴的编辑指令。

**可直接配原图使用的指令**

> 在这张原照片上做一版肉眼明显、适合头像的通透淡妆精修，生成单张照片。完整修去画面右侧脸颊和下巴的红痘及周围红印，用邻近皮肤的细纹理自然补齐。将额头大片发亮的油光收成柔和的哑光质感，明显提亮眼下青褐色暗区，均匀肤色。双唇提为清晰可见的自然玫瑰豆沙色，贴合原唇形、留住唇纹。保留眼下小痣、毛孔、面部骨相、眼形、原有肤色深浅、笑容。构图和五官位置与原图精确对齐，保留窗帘、墙面、头发、耳环、衣领和窗光方向。

# 字体与使用许可

## 一套课件一套字集

模板附带 Latin Modern Roman 与 Noto Serif SC 的示例子集，只覆盖示例里实际出现的字形。修改标题、按钮或正文后，先重新收集字符，再从可分发的原始字体生成课件自己的 WOFF2 子集。不能把别的课件的子集复制过来假装是完整字库；缺字会回退到系统字体，改变字形、换行与演示布局。

中文正文字体使用 Noto Serif SC，并在 CSS 字体栈中把 Latin Modern 放在中文字体前面，以免宋体已有的拉丁字形抢走英文和数字。标题如果想用方正小标宋等商业字体，只能作为本机可选字体，不能默认把字体文件或子集打包到公开仓库和 release。

KaTeX 自带独立的数学字体；使用 `data-tex` 编写变量、下标和公式，不用 Unicode 拼凑。

## 制作字集

1. 从**最终课件**的帧、按钮文案、图上文字与交互脚本中的用户可见字符串提取字形。动态生成的消息、页码和辅助符号也应计入。
2. 在本机安装 `fonttools` 与 `brotli`，将 Noto Serif SC 的可变字体固定到需要的字重，用 `pyftsubset --text-file` 生成 WOFF2。Latin Modern 同理。
3. 在浏览器检查每一份 `@font-face` 成功加载，且断网打开构建后的单文件仍保持排版。
4. 不要把原始 10 MB 级别字体文件、临时字体与项目外私人字体复制进发布物。

字体来源、许可全文与项目许可证之间的关系见 [第三方声明](../THIRD_PARTY_NOTICES.md)。公开发布前应逐项核对字集所用的原字体来源与许可。

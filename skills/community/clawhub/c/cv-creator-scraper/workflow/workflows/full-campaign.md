# 达人合作工作流

按合作目标查找达人，可通过种子账号扩展名单。适用于希望先筛选合作对象、再准备邮件并跟进的用户。

1. **查找候选达人。** 按平台、市场、品类和指标搜索 CreatiVault 已收录的达人。有主页链接或达人 ID 时，在对应平台精确查询已有资料。有内容风格或场景需求时，也可用自然语言搜索，再用结构化搜索补充建联所需的邮箱和资料。参见 [达人搜索](../../discovery/creator-search/SKILL.md)。
2. **相似扩展。** 需要扩大候选池时，用用户指定或从结果中选出的种子账号找相似达人。明确目标平台和筛选条件，合并名单时按平台与达人 ID 去重。参见 [相似达人](../../discovery/creator-lookalike/SKILL.md)。
3. **整理候选。** 按目标市场、内容方向和实际指标展示候选与推荐理由。如需详细受众画像，用结构化搜索的 S3 档查可用数据。如需建联，补查实际邮箱，将缺少邮箱的达人标为待补。用户要表格时，可将已有达人搜索结果导出为 CSV。
4. **确认并发送。** 展示拟联系的达人、收件邮箱、主题与邮件正文，按 [邮件建联](../../outreach/creator-outreach/SKILL.md) 的确认规则提交。批量发送入口最多支持 50 位收件人。
5. **查询结果和跟进。** 记录返回的即时结果或任务编号，汇总发送进度和逐收件人结果。用户需要跟进时，查询往来记录、未读来信与达人已回复但尚待跟进的会话。

若未找到种子账号，报告情况并保留已有候选。对于未命中或缺少邮箱的达人，明确说明缺失情况，按用户确认的名单继续。批量发送和失败处理见 [批量建联](batch-outreach.md)。

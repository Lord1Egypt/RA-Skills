# 03 · JavaScript 快速开始

要求 **Node.js >= 18**（原生 `fetch`、ESM）。浏览器前端不要直接持有 JWT/API Key，建议通过自己的后端或 Bridge 访问。

---

## 1. 安装

```bash
cd aiot-north/js
npm install          # 安装可选 mqtt 依赖；只用 REST 也可以不装
```

包内无强制运行时依赖。`mqtt` 是可选 peer dependency。

---

## 2. 配置

```bash
export AIOT_BASE_URL='https://aiot.yzlkj.com'
export AIOT_TOKEN='...'
# 或
export AIOT_ACCOUNT='用户名'
export AIOT_PASSWORD='密码'
# 或
export AIOT_API_KEY='ak_...'
```

```js
import { NorthClient } from "aiot-north";

const client = await NorthClient.fromEnv();
// 或 new NorthClient({ token: "..." })
// await client.login("账号", "密码")
```

## 3. 客户端

### 3.1 设备与数据

```js
const devices = await client.devices.list({ maxResults: 20 });
console.log(devices.total);

const device = await client.devices.get("AIOTSDK-0001"); // password/bindCode 已脱敏
const plain = await client.devices.get("AIOTSDK-0001", { includeSecrets: true });

const telemetry = await client.devices.telemetry("AIOTSDK-0001");
const history = await client.devices.history("AIOTSDK-0001", {
  keys: ["temp", "hum"],
  start: "2026-11-01 00:00:00",
  end: "2026-11-04 23:59:59",
  limit: 1000,
});
const aggregate = await client.devices.aggregate("AIOTSDK-0001", {
  keys: ["temp"],
  start: "2026-10-01 00:00:00",
  end: "2026-11-04 23:59:59",
  bucket: "1d",
});
```

### 3.2 指令

```js
const result = await client.devices.command("AIOTSDK-0001", "set", ["sw", "1"]);
console.log(result.commandId, result.status);

// 完整 args 也可以：
await client.devices.command("AIOTSDK-0001", "set", ["AIOTSDK-0001", "sw", "1"]);

const commands = await client.commands.list({ deviceId: "AIOTSDK-0001", pageSize: 10 });
```

### 3.3 告警 / 型号 / 账号

```js
const alarms = await client.alarms.list({ status: "active", pageSize: 20 });
const products = await client.products.list();
const ports = await client.gatewayPorts();
const account = await client.account();
```

### 3.4 归一化

```js
import { normalizeTelemetry, parseDevicePayload } from "aiot-north";

const record = normalizeTelemetry(telemetry);
console.log(record.deviceId, record.values, record.online);

const mqttRecord = parseDevicePayload(
  '{"ter":"DEV-1","data":[{"func":"facs","args":["temp","25.5"]}]}',
  { topic: "north/P1/DEV-1/data" },
);
console.log(mqttRecord.values); // { temp: 25.5 }
```

## 4. 错误处理

```js
import { AiotAuthError, AiotRateLimitError, AiotAPIError, AiotNetworkError } from "aiot-north";

try {
  const data = await client.devices.telemetry("DEV-1");
} catch (err) {
  if (err instanceof AiotAuthError) {
    await client.login();
  } else if (err instanceof AiotRateLimitError) {
    await new Promise((r) => setTimeout(r, 10000));
  } else if (err instanceof AiotAPIError) {
    console.error(err.code, err.message, err.status, err.payload);
  } else if (err instanceof AiotNetworkError) {
    console.error("network", err);
  }
}
```

默认对 429/5xx 重试 2 次，指数退避。

## 6. MQTT（可选）

```bash
npm install mqtt
```

```js
import { NorthMQTT } from "aiot-north";

const client = new NorthMQTT({
  host: "ciot.yzlkj.com",
  port: 1883,
  username: "平台分配的北向用户名",
  password: "平台分配的北向密码",
  onData: (record) => console.log(record.deviceId, record.values),
  onError: (err) => console.error(err),
});
await client.start();
```

> 北向 MQTT 独立凭证不是每个账号都有。没有时用 Bridge 的 REST 轮询。

## 7. Bridge

```js
import { NorthBridge, NorthClient } from "aiot-north";

const client = await NorthClient.fromEnv();
const bridge = new NorthBridge(client, {
  deviceIds: ["AIOTSDK-0001"],
  port: 8080,
  interval: 5,
  webhookUrl: process.env.AIOT_WEBHOOK_URL,
  webhookSecret: process.env.AIOT_WEBHOOK_SECRET,
});
await bridge.start();
```

HTTP 端点和 Webhook 格式见 [04-独立服务器与Webhook.md](04-独立服务器与Webhook.md)。

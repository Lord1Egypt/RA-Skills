## Description:

Tailor and polish an existing resume in Google Docs for a particular job without inventing qualifications, experience, metrics, or outcomes.

This skill is ready for commercial/non-commercial use.

## Publisher:

[tangentus](https://clawhub.ai/user/tangentus)

### License/Terms of Use:

MIT-0

## Use Case:

External users and career-support agents use this skill to update an editable Google Docs resume for a specific role using recruiter feedback or a role description while preserving factual accuracy.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may modify a Google Docs resume that contains personal career information.

Mitigation: Provide only an editable resume document intended for update and review the edited document afterward.

Risk: Role targeting could overstate qualifications if unsupported claims are added.

Mitigation: Use only the existing resume and explicit user confirmations as candidate facts, and leave unsupported qualifications unclaimed.

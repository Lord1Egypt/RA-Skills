## Description:

Analyze ERP system integration for construction data flows and map data flows between ERP modules.

This skill is ready for commercial/non-commercial use.

## Publisher:

[datadrivenconstruction](https://clawhub.ai/user/datadrivenconstruction)

### License/Terms of Use:

## Use Case:

Construction technology teams, ERP analysts, and integration engineers use this skill to map ERP module data flows, identify bottlenecks, score integration health, and generate practical recommendations for construction organizations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill requests network access without a documented need while handling potentially sensitive ERP, financial, project, procurement, HR, payroll, or integration metadata.

Mitigation: Use it only in an approved environment, restrict network access where possible, and avoid providing confidential or regulated business data unless the deployment has been reviewed.

Risk: Integration analysis outputs may be incomplete or misleading if source ERP, integration point, or transaction log data is stale, partial, or incorrect.

Mitigation: Validate input data with system owners and review generated bottlenecks, scores, diagrams, and recommendations before using them for operational decisions.

# 联系轻页维护者

只在用户明确要求反馈或联系轻页时提交。发现错误、收到通知、浏览作品不代表发送授权；不能自动附上凭证、私有会话或工作区内容。

```bash
python3 "/实际skill目录/scripts/litepage.py" feedback --text "这个作品在手机上打不开"
python3 "/实际skill目录/scripts/litepage.py" feedback --text-file /私有目录/feedback.txt --work-url "用户提供的作品链接" --contact "用户指定的回复方式"
```

反馈正文最多 5000 字符；UTF-8 文件最多 20000 字节。关联作品链接可选（HTTP(S)，最多 2048 字符），回复方式可选（最多 240 字符）；没有联系方式也可以提交，但维护者无法直接回复。使用用户提供的真实链接，不猜短码，不请求关联链接。联系方式按用户指定填写，不从凭证或本机配置推断。

命令不读取凭证、不登录、不注册身份。消息投递给轻页维护者，不是作品作者，也不提供双向站内通信。用户只想打开网页时提供[联系轻页](https://lightpage.hqdx.store/?view=contact)，无需执行提交命令。

成功返回 `feedback_id`、`status=received`，只说明已收件，不保证维护者处理或回复。不要输出用户联系方式或反馈全文作为固定回执。失败后保留 stderr 的 `operation_id`，同一正文和参数重跑会复用原 ID；也可添加 `--operation-id 原UUID`。有界自动重试失败后最多手动续试一次，遵守 Retry-After，不换 ID 反复投递。

同内容反馈会复用已保存 ID；只有用户明确要求再次发送一条新的反馈时才使用新 ID。回执只保存 ID 和输入摘要，不保存反馈正文和联系方式。服务未配置、不支持或限流时按实际结果报告，不改用 Echo 私信，也不自动登录。

## Description:

Removes Markdown formatting and excess whitespace from text to produce clean, publication-ready plain text with normalized punctuation and spacing.

This skill is ready for commercial/non-commercial use.

## Publisher:

[zihaowyt5525-max](https://clawhub.ai/user/zihaowyt5525-max)

### License/Terms of Use:

MIT-0

## Use Case:

Writers, editors, and developers use this skill to convert Markdown-heavy or AI-generated text into clean plain text for publication, copying, or export.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate too broadly on Markdown-looking content and remove formatting when plain text was not intended.

Mitigation: Use it only when plain text output is explicitly desired, and review the cleaned text before replacing the original.

Risk: Markdown stripping is destructive for documents that need to preserve formatting for reuse.

Mitigation: Keep the source document unchanged and apply the formatter to a duplicate or export.

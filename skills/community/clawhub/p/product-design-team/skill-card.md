## Description:

Transforms product briefs into interface designs and a built, reviewed front end through coordinated design, build, review, and iteration roles.

This skill is ready for commercial/non-commercial use.

## Publisher:

[t3ratech](https://clawhub.ai/user/t3ratech)

## Use Case:

Product teams and frontend developers use this skill to turn a product brief into interface design direction, implemented frontend changes, review feedback, and iteration guidance.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The agent team can modify frontend files and run local build or review commands.

Mitigation: Install it only in the intended workspace and review proposed shell commands before execution.

Risk: Memory tools can retain project details when used in sensitive repositories.

Mitigation: Avoid storing confidential project data unless the environment's retention policy allows it.

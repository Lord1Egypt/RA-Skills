## 任务清单与依赖拓扑

按生产流程组织的AI视频内容生产任务清单，附任务间关系和元操作映射。领域代号前缀：AVS。

**域间逻辑流**：AVS0 → AVS1 → AVS2 → AVS3 → AVS4 → AVS5 → AVS6

**域概览**：共 8 域 31 种任务（AVS7 为发布后按需启用域）：

| 阶段 | 域 | 任务数 | 范围 |
|------|----|--------|------|
| 前期·立项 | AVS0 需求与路由域 | 4 | 输入判定、需求收集、生产方案规划、参考素材入库 |
| 前期·文本 | AVS1 剧本创作域 | 5 | 选题、大纲、角色小传、剧本、钩子卡点 |
| 中期·设计 | AVS2 分镜设计域 | 4 | 分镜表、镜头语言、时长节奏、转场与接镜 |
| 中期·资产 | AVS3 资产库构建域 | 5 | 角色资产、造型库、表情动作、场景资产、锚点段 |
| 中期·生产 | AVS4 镜头生产域 | 4 | 定帧、视频生成、多抽、双采样 |
| 后期·音画 | AVS5 声音与合成域 | 3 | 配音、字幕BGM、剪辑合成 |
| 后期·交付 | AVS6 QC与交付域 | 3 | 成片QC门禁、合规、交付 |
| 运营 | AVS7 运营反馈域 | 3 | 切片素材、数据回看、续作决策（发布后按需启用） |

### 依赖拓扑摘要

- **主管线（制作闭环）**：AVS0-01 → AVS0-02 → AVS0-03 → AVS1-01 → AVS1-02 → AVS1-03 → AVS1-04 → AVS1-05 → AVS2-01 → AVS2-02 → AVS2-03 → AVS2-04 → AVS3-01 → {AVS3-02, AVS3-03, AVS3-04} → AVS3-05 → AVS4-01 → AVS4-02 → AVS4-03 → AVS4-04 → AVS5-01 → AVS5-02 → AVS5-03 → AVS6-01 → AVS6-02 → AVS6-03
- **可选分支**：AVS0-03 之后可接 AVS0-04（参考库建设），与 AVS1 并行推进，不阻塞主管线
- **并行点**：①AVS3-02（造型库）、AVS3-03（表情动作预设）、AVS3-04（场景资产库）均以角色资产库为锚、互不依赖，可并行；②AVS0-04（参考素材入库）可与 AVS1 剧本工序并行；③AVS5-01（配音文本与录音）只要剧本定稿即可与 AVS3/AVS4 并行，不必等画面
- **返工回路**：AVS6-01 FAIL → 回 AVS4-03 重生成；AVS4-03 崩坏 → 回 AVS4-01 换参考帧
- **入口任务**：AVS0-01（全管线唯一入口）
- **校准点（6处，必须停下等人）**：AVS1-01 三提案三选一〔仅输入<30字〕→ AVS0-02 需求三问 → AVS1-02 大纲确认 → AVS1-03 小传确认〔量产型必停〕→ 样片确认放行量产 → AVS5-01 配音方案确认；清单与「不停会怎样」见 requirements「跨域总览：自动化边界与校准点」
- **后置运营环**：AVS6-03 → AVS7-01 → AVS7-02 → AVS7-03 →（回写立项表，触发下一轮 AVS1-01）——按需启用，未发布项目标记N/A
- **跨域管线变体**：
  - 最小输入模式（只有一段概要或一句话想法）：AVS0-01 判定→（<30字先出三提案三选一）→AVS0-02 只问三项＋默认值表→AVS1-01 五要素与故事核卡→AVS1-02 三集骨架→AVS1-03 小传→AVS1-04 剧本→此后与主管线合流
  - 样片模式：AVS0-01 → AVS1-03（小传两行）→ AVS1-04（单场）→ AVS2-01 → AVS3-01（单角色最小库）→ AVS4 全工序 → AVS5-03 → AVS6-01
  - 口播模式：AVS0 → AVS1-04（讲稿：钩子→干货点列→CTA）→ AVS2（口播镜头+知识卡片插帧）→ AVS3（播报形象资产）→ AVS4 → AVS5（大字字幕条）→ AVS6
  - 广告模式：AVS0 → AVS1-02（创意框架）→ AVS2 → AVS3（产品资产替代角色资产）→ AVS4 → AVS5 → AVS6
  - 量产模式：AVS3 资产库一次构建全剧复用；AVS4 按集循环；每3集做一次资产漂移复查
  - 混合模式：AVS4-02 改为"输出外部工具提示词包"，用户回传素材后从 AVS4-03 继续

- **跳入点**（跳过前置工序的合法入口，形式入口仍为 AVS0-01）：
  - 已有剧本：AVS0-01/02 → AVS2-01（跳过AVS1 的选题/大纲/剧本），**但须补 AVS1-03 小传**——从现成剧本反推六维（身份/躯体/文化/关系/能力/动机），否则 AVS3-01 无锚点依据
  - 已有分镜：AVS0-01/02 → AVS3-01（跳过AVS1/AVS2），同样须补 AVS1-03
  - 已有资产库（续做项目）：AVS0-01/02 → AVS4-01（资产库已含小传，无需补）


- **返工回路**（穷举——每个QC项与过程检查项的回溯目标）：

| 触发 | 回溯目标 | 说明 |
|------|---------|------|
| AVS6-01 人脸/服装一致性❌ | AVS4-01（换参考帧）→ AVS3-01（资产库漂移，重生成基准图）→ AVS3-02（造型跳装，按造型索引核对编号） | 先查镜头级，再查资产级 |
| AVS6-01 场景穿帮❌ | AVS3-04（场景资产补视角）或 AVS4-01 | 视穿帮类型 |
| AVS6-01 色调统一⚠️ | AVS5-03（调色参数修正） | 合成级修正 |
| AVS6-01 动作合理性❌ | AVS4-02（提示词）→ AVS4-03（重抽） | 先改提示词 |
| AVS6-01 糊脸/变形/多余手指❌ | AVS4-03（重抽） | 崩坏类 |
| AVS6-01 多人同脸❌ | AVS2-02（改正反打分拍设计）→ AVS4 | 设计级回溯 |
| AVS6-01 前3秒钩子❌ | AVS1-05（重设钩子）→ AVS1-04（必要时改剧本开头） | 剧本级回溯 |
| AVS6-01 结尾钩子❌ | AVS1-05（重设卡点） | 剧本级回溯 |
| AVS4-03 崩坏重抽无效 | AVS4-01（换参考帧） | 抽卡层级升级 |
| AVS4-04 一采内容不合格 | AVS4-02（改提示词重生成） | 只回内容层 |
| AVS2-03 节奏超标 | AVS2-01（拆镜/删镜） | 分镜级回溯 |
| 集数/总时长压不下 | AVS1-02（合并集数、删支线） | 大纲级回溯 |
| 表演空、角色没有"想要什么" | AVS1-03（补最高任务与本场目标）→ AVS4-02 | 设定级回溯 |
| 主角"万能"、解法不可信 | AVS1-03（补能力边界"不会什么"）→ AVS1-04（改剧本解法） | 设定级回溯 |
| 口音/称谓/礼制穿帮 | AVS1-03（文化维）→ AVS5-01（换音色或改称谓） | 设定级回溯 |
| 双人戏距离感不对、视线接不上 | AVS1-03（关系维）→ AVS2-02（改机位与距离） | 设定级回溯 |
| 换装跳变、状态不接（干净→沾血无过渡） | AVS3-02（补状态机变体与触发条件） | 资产级回溯 |
| 同族表情做出来像换了个人 | AVS3-03（同族只改2-3个部位，AU≤3） | 资产级回溯 |
| 锚点版本混乱、改完没跑回归 | AVS3-05（升版本＋回归重跑清单） | 资产级回溯 |
| 字幕错字/多音字、BGM盖人声 | AVS5-02（重做字幕与混音电平） | 合成级回溯 |
| AVS5-01 音画错位>0.3s | AVS5-01（重生成配音，不剪画面） | 音频侧修正 |
| 场间转场生硬/跳轴⚠️ | AVS2-04（换转场类型或补过渡镜）→ AVS5-03（落地为J/L切） | 设计级回溯 |
| AVS7-02 数据归因指向选题/题材 | AVS1-01（回写立项表重校选题） | 运营级回溯 |
| AVS7-02 数据归因指向钩子/节奏 | AVS1-05（钩子重设，下轮集数生效） | 运营级回溯 |
| 参考库词条过时、与画面不符 | AVS0-04（更新索引与来源标记，不重拍） | 支持级回溯 |
| 需求变更（改档位/改集数/改画幅） | AVS0-02（重收需求）→ AVS0-03（重排期与预算） | 立项级回溯 |
| 合规❌（未标AI生成/素材侵权） | AVS6-02（补标注与授权存档） | 合规级回溯 |
| 发布信息与成片不一致（标题/封面/时长） | AVS6-03（重出发布信息清单） | 交付级回溯 |
| 切片完播低、开头没钩子 | AVS7-01（重切前3秒或换片段） | 运营级回溯 |
| 校准点被跳过（大纲/小传未确认就往下做） | 回对应校准点重新确认，已做部分逐项复检 | 流程级回溯 |

- **循环点**：量产模式 AVS4→AVS5→AVS6 按集循环（集级迭代，资产库跨集不变）；每3集触发一次 AVS3 资产漂移复查（回到 AVS3-01 的条件回路）；AVS7 运营环按周更节奏循环。

### 元操作映射说明

- S（感知）：需求收集、素材分析、QC检查
- C（认知）：选题校准、分镜设计、锚点段固化、抽片选优
- A（行动）：剧本撰写、图像/视频生成调用、ffmpeg合成
- O（组织）：项目目录、资产库归档、工程清单维护
- I（交互）：需求确认、样片确认、配音方案询问、交付说明
- G（守护）：节奏校准、双采样验证、QC与合规核查

### 知识图谱

将依赖拓扑扩展为知识图谱，支持更复杂的任务关系推理：

**实体节点类型**:
- **任务节点**: AVS0-01~AVS7-03（31个任务）
- **域节点**: AVS0~AVS7（8个域）
- **元操作节点**: S/C/A/O/I/G（6个元操作）
- **模式节点**: 改编（走主管线）＋最小输入／样片／口播／广告／量产／混合（6 种管线变体，与依赖拓扑摘要的变体清单一一对应）
- **资产节点**: 角色小传（AVS1-03 产出，被资产/分镜/表演/配音四处消费）、角色资产库、造型库、场景资产库、锚点段（AVS3 域产出）、参考库词条（AVS0-04 产出，路径无关）
- **镜头节点**: 每镜的定帧图+视频片段+QC判定（AVS4/AVS6域作业对象）
- **工件节点**: 剧本、角色小传卡、分镜表、转场设计表、造型索引表、QC计分表、工程清单、成片（各阶段产出物）

**关系边类型**:
- **依赖边**: 任务间的前后依赖关系（→）
- **包含边**: 域包含任务的关系（AVS1 → AVS1-01~AVS1-05）
- **路由边**: 输入类型到模式管线的路由关系（AVS0-01 → 各模式管线变体入口）
- **跳入边**: 外部已有工件跳过前置工序的接入关系（已有剧本→AVS2-01；已有分镜→AVS3-01；已有资产库→AVS4-01）；前两种跳入须补 AVS1-03 小传（从现成剧本反推），否则资产层无锚点依据
- **输入/输出边**: 工序间"上一产出=下一输入"关系（剧本→分镜表→资产→镜头→合成→成片）
- **并行边**: 可并行执行的任务组合（AVS3-02 ‖ AVS3-03 ‖ AVS3-04；AVS0-04 ‖ AVS1；AVS5-01 配音 ‖ AVS3/AVS4，前提剧本定稿）
- **循环边**: 量产模式的集级迭代关系（AVS4→AVS5→AVS6 按集循环；每3集→AVS3-01 漂移复查；A7→AVS1-01 运营环回写）
- **返工边**: QC与崩坏驱动的回溯关系（穷举映射见依赖拓扑摘要"返工回路"表：29 条回溯路径覆盖 29 个任务，仅 AVS0-01 输入判定与 AVS7-03 续作决策不作为回溯目标——前者是入口不承接返工、后者是终点决策）
- **资产引用边**: 镜头对资产实体的引用关系（AVS4-01 → 角色资产/造型版本/场景资产/锚点段；AVS4-02 → 锚点段与统一光影段）
- **优先级边**: 生成执行路径的三级选择关系（外部MCP → agent内置生成 → 提示词外包）
- **确认边**: 强制人工校准点关系（AVS1-01 三提案三选一〔条件触发〕→ AVS0-02 需求三问 → AVS1-02 大纲确认 → AVS1-03 小传确认〔量产型必停〕→ 样片确认放行量产 → AVS5-01 配音方案确认 → 对应任务放行）
- **派生边**: 母版到变体的受控派生关系（设定卡六联→造型库/表情库；造型+表情+场景→锚点段）；母版升版本则下游全部重建，派生不得反向改动母版
- **消费边**: 同一设定被多处消费的关系（AVS1-03 小传→AVS3-01 服装等级与站位、AVS4-02 表演目标、AVS5-01 口音音色、AVS2-02 正反打距离）

**推理能力**:
- **路径推导**: 从输入类型到成片交付的最优任务路径（含模式变体裁剪、跳入点与运营后置环）
- **任务推荐**: 基于当前任务推荐下一步任务
- **依赖分析**: 分析任务的前置依赖和后续影响
- **资产影响面分析**: 资产实体变更时推导受影响镜头集（角色基准图→全部角色预设与引用镜头；场景资产→该场景镜头；锚点段→全部引用该锚点段的定帧与视频提示词）
- **设定影响面分析**: 小传六维变更时推导受影响产物（动机改→表演目标与相关台词重写；能力改→解法与动作难度重排；文化改→配音音色与称谓；关系改→正反打距离与机位；躯体改→伤妆与动作幅度；身份改→服装等级与站位）
- **并行识别**: 识别可并行执行的任务组合（资产预设与场景库、量产模式按集）
- **返工定位**: QC FAIL项按"返工回路"穷举表回溯最近可修复任务
- **循环调度**: 量产模式推导集级循环的执行批次与资产漂移复查触发点

更多组合根据具体任务动态推导。

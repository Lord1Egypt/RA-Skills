## Description:

Write powerful SOUL.md files for AI agents. Use when creating, revising, or improving SOUL.md (the personality document for AI agents). Based on Anthropic's Claude soul document principles and SoulSpec standard.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and agent builders use this skill to create or revise SOUL.md personality documents that define an agent's identity, values, communication style, boundaries, and tone.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated SOUL.md content can shape an agent's persistent personality, tone, and behavioral defaults.

Mitigation: Review generated SOUL.md content before using it as a global or persistent behavior file.

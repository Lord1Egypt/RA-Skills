## Description:

Helps agents plan, map, or restructure website page hierarchy, navigation, URL structure, and internal linking.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, designers, SEO practitioners, and website operators use this skill to plan or restructure site information architecture, including page hierarchies, navigation, URL maps, visual sitemaps, and internal-linking plans.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Recommendations may rely on existing product-marketing context that is incomplete or outdated.

Mitigation: Confirm business goals, audiences, important pages, existing URLs, and redirect requirements before applying the plan.

Risk: Broad website-planning routing could activate this skill for technical SEO tasks outside its intended scope.

Mitigation: Use it for page hierarchy, navigation, URL structure, and internal linking; route XML sitemap, crawl error, and structured data work to the appropriate SEO-focused skill.

Risk: URL restructuring advice can create broken links or lost backlink value if implemented without redirects.

Mitigation: Review the URL map before implementation and define 301 redirects for moved or renamed pages.

## Description:

A Xiaohongshu collection assistant for searching topics directly on Xiaohongshu, browsing posts, images, and comments, and organizing the collected source material into a structured report.

This skill is ready for commercial/non-commercial use.

## Publisher:

[tianheihei002](https://clawhub.ai/user/tianheihei002)

### License/Terms of Use:

MIT-0

## Use Case:

External users and researchers use this skill to collect topic-specific Xiaohongshu posts, image text, comments, and source links through direct browser access and produce a structured collection report.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can collect usernames, comments, source links, OCR text, images, and post content verbatim from Xiaohongshu, which can create privacy and data-minimization concerns.

Mitigation: Use it only for lawful, permissioned research; set narrow collection limits; and redact or summarize usernames, comments, links, and OCR text unless there is a clear need to retain them verbatim.

Risk: The skill encourages broad and exhaustive collection, which can exceed the user's actual research need.

Mitigation: Confirm the collection topic and scope before starting, stop once the agreed scope is satisfied, and keep source attribution without collecting unrelated personal data.

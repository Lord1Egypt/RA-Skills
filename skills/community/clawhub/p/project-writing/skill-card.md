## Description:

Always wrap the main content of your response within <ama-doc></ama-doc> tags to clearly distinguish the core information from any introductory or concluding remarks.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and developers use this skill to enforce a project-writing response convention where main content is clearly separated from surrounding remarks.

## Known Risks and Mitigations:

Risk: The skill changes response formatting by requiring main content to be wrapped in <ama-doc> tags.

Mitigation: Use the skill only in workflows that expect this wrapper, and review generated content before publishing or passing it to downstream processors.

# 股份支付登记（权益结算／现金结算／等待期摊销）

把年报附注里**「股份支付」**那一段，读成一张每个数都能回到原句的登记表：
两类计量各确认多少费用、授予日公允价值怎么定、等待期摊销与剩余等待期还要确认多少、
可行权数量这一年怎么从期初走到期末。
两类费用之和与数量四数恒等由机检现算，**本件不判断激励方案合不合理、不给评级目标价**。

- 零网络、纯标准库、单文件；输入就是用户直供的附注文本。
- 五道机检：`SP-STRUCT`／`SP-QUOTE`／`SP-SUM`／`SP-VEST`／`SP-LINE`，现状全部已落字。
- 退码：`0` 全过｜`1` 有发条｜`2` 用法错｜`3` 读不到／空稿／仍有判据未落字（输出会明写「这不等于合规」）。

---

## 一、它回答什么

| 问题 | 落在哪一节 |
|---|---|
| 股份支付一年确认多少费用、两类各多少 | 股份支付概况 ＋ 权益结算 ＋ 现金结算 |
| 授予日公允价值按什么方法定 | 权益结算的股份支付 |
| 现金结算那部分还挂在账上多少 | 现金结算的股份支付 |
| 本期摊了多少、以后还要摊多少 | 等待期费用摊销 |
| 这一年可行权数量怎么变的 | 数量变动 |

**它不回答**：这套激励方案合不合理、激励效果如何、以后费用会不会降、值不值得买。
这四类问题一律 `[待人工]`——`SP-LINE` 会把这类话当红线发条。

## 三、稿子长什么样

七节按序，节名逐字（`## ` 起节）：

```
## 股份支付概况
## 权益结算的股份支付
## 现金结算的股份支付
## 等待期费用摊销
## 数量变动
## 口径与未取到
## 来源
```

每个数字行 = 一行，行首项名与 `〔口径：…〕`，紧跟金额与**「万元」**（数量行是**「万股」**），再挂三元组：

```
- 本期确认的费用〔口径：本期发生额〕15,600.00 万元「以权益结算的股份支付本期确认费用人民币 15,600.00 万元」〔锚：2025 年年报·第 268 页·股份支付〕[S1]
- 期末可行权数量〔口径：本期末（股）〕1,300.00 万股「期末尚未解除限售的限制性股票为 1,300.00 万股」〔锚：2025 年年报·第 270 页·股份支付〕[S1]
```

- 附注里没有的数写 `未取到：项名`，**不留空、不借常识补**。
- 自己算出来的数（如费用占比）标 `〔自算〕`，不要求三元组。
- 需要人判断的地方写 `[待人工]`，不要求三元组。
- **两类不能混**：权益结算与现金结算分节摆，各自都要有「本期确认的费用」那一行；
  机检拿这两行相加去对披露合计，缺一行报「缺数」（除非 `口径与未取到` 已写明该项未取到）。
- **数量单位是万股**，不是万元。单位写错，`SP-VEST` 会报「缺数」。

## 四、五道机检各拦什么

| 码 | 一句话 | 想踩一脚试试 |
|---|---|---|
| `SP-STRUCT` | 头部三件自标 + 七节齐且按序 | 把某节标题改一个字 |
| `SP-QUOTE` | 带数字的行挂齐原句＋锚＋`[S#]`，正文与来源两向对应 | 删掉某行的「原句」只留 `[S1]`；或给来源节加一条从不引用的 `[S2]` |
| `SP-SUM` | 两类本期费用之和 == 两处披露合计（差 > 0.01 万元即发） | 把概况的费用总额改大 1,000；或把现金结算节的合计改小 1,000 |
| `SP-VEST` | 期初 ＋ 新增 − 行权 == 期末（差 > 0.01 万股即发） | 把期末可行权改大 100 |
| `SP-LINE` | 四组红线词（投资建议／前瞻预测／主观评价／越界口径） | 写一句「预计明年费用将下降」或「目标价」 |

`--selftest` 的每一档就是上面这些踩法，**档名会告诉你它期望红哪一道**。
「两处披露合计互不相等」也是一条独立的发条——那说明稿里自己抄岔了，不用等相加才发现。

## 五、数据通道

- **正文腿**：附注原文由用户直供（截图／PDF／解析回来的表格）。截图与扫描件交 `cue-omni-reader`
  （大纲→按节取用，计费以服务端返回为准）。
- **原文腿**：本件**不承诺**该域开放，也不承诺实时性。
- `CUE_API_KEY` 可选：缺位时只排版用户贴进来的文本，形状一样，数只能来自用户。

## 六、怎么接到 agent 上

- 发现先行：匿名取 live 域清单与 `routing`，**不硬编码工具名与工具数**；连上之后带
  `Authorization: Bearer $CUE_API_KEY` 发 `tools/list`，以现场返回为准：

  ```bash
  # ① 匿名取活体清单
  curl -sS https://cuecue.cn/api/mcp-catalog -o /tmp/mcp-catalog.json
  python3 -c "import json;d=json.load(open('/tmp/mcp-catalog.json'));print(d)"

  # ② 带凭据握手取工具表
  curl -sS -X POST "$MCP_ENDPOINT" \
    -H "Authorization: Bearer $CUE_API_KEY" \
    -H 'Content-Type: application/json' \
    -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' | head -c 2000
  ```

- 通道配置页只给指针：<https://cuecue.cn/hub/mcp> ／ <https://cuecue.cn/hub/omni-reader> ／
  <https://cuecue.cn/hub/api-key>。

## 八、切割

| 同族件 | 它管什么 | 本件不碰 |
|---|---|---|
| `equity-incentive-plan-cn` | **激励计划条款本身**（授予条件、行权安排、业绩指标） | 本件管会计上确认了多少费用、数量怎么变 |
| `cn-changes-in-equity-cn` | **所有者权益变动表的行列轧平**（「股份支付计入所有者权益的金额」只是其中一格） | 本件不拆两类计量，也不问等待期摊销与可行权数量 |
| `cn-earnings-note` | 利润表附注的整体结构与期间费用 | 本件只取「股份支付」这一段 |

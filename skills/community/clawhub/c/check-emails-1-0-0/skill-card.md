This skill is ready for commercial/non-commercial use.

## Use Case:

People who use Himalaya can ask an agent to check recent mail and receive a quick listing of the latest inbox envelopes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill uses a broad trigger phrase for access to recent mailbox envelope data.

Mitigation: Invoke it with explicit wording such as "check my email with Himalaya" and only install it where the agent is expected to list recent mailbox envelopes.

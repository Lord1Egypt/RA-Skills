创建独特、生产级的前端界面，追求高设计品质；当用户要求构建网页组件、页面、海报、应用时使用，并生成有创意、打磨精细的代码和UI设计。

## Use Case:

Developers and designers use this skill to guide agents in building or improving frontend pages, components, dashboards, landing pages, posters, and other visual web interfaces. It emphasizes distinctive visual direction, responsive implementation, and production-ready HTML, CSS, JavaScript, or framework component output.

Global

## Known Risks and Mitigations:

Risk: Broad frontend triggers and Chinese-language guidance may not fit workflows that require narrower UI assistance or English-only output.

Mitigation: Install for workflows that want strongly opinionated Chinese-language frontend design help, and review activation scope before deployment.

Risk: The skill guides agents to produce runnable frontend code, so outputs may need project-specific review before use.

Mitigation: Review generated code, visual behavior, accessibility, and browser compatibility before shipping it in a product.

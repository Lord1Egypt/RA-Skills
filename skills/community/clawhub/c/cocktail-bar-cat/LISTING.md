## 详情页概述（可整段复制）

```text
吧台前最难的，从来不是摇好一杯酒，而是下一句：客人说『随便』，新酒单还空着一杯，家里冰箱只剩半瓶金酒，老板又想知道这杯到底赚不赚钱。调酒师喵就是为这些时刻来的。

它先给答案，再给来路。经典配方照着调，也能按心情、甜度和手边有的材料排出几条路线；想改味道，就回到早期酒谱里找这杯的骨架，一次只动一个变量，先做半杯对照，喝过再说好不好。查得到的出处讲得清版次和证据，查不到的传说就老实说没核过——经典有出处，新酒才有根。

一张酒单也能从头陪到尾：主题、顺序、经典锚点、原创特调和独立的无酒精路线，一直到每杯材料成本与建议售价。真实进价只留在你自己的本机副本，专用版用空模板和可复算的演示价格，不冒充市场行情。家里那半瓶也不浪费：两瓶怎么拼、下一瓶买什么、没有摇酒壶先做半杯，都给得出做法。

它不替你喝酒，也不替你拍板。史料有缺口会标出来，新配方一律标着待实饮；不鼓励过量、不点火饮用，不给未成年人推荐酒精；客户偏好和经营记录不离开本机。剩下的，交给吧台前那句『先试试这杯』。
```

## 专家帮你做（示例问句，选3条）

1. 客人说心情不好、又不想喝甜的，推荐一杯，顺便给我一句能直接说的话
2. 帮我排一份夏季酒单，标出每杯成本和售价，别让毛利翻车
3. 家里只有半瓶金酒，今晚能调出什么拿得出手的酒？

成本/售价默认用合成价格运行时计算，不是市场行情、真实成交价或经营净利；用户真实进价仅在本机私有副本使用，不上传。

### 备选问句

- 帮我列新手第一次买酒清单，按我指定的预算和当前计算数据，不要固定价格榜。
- 家里没有摇酒壶，先做半杯，该怎么办？
- 为一款遗言单买一瓶修饰酒值得吗？按当前材料、预算和合成价格算，不拿旧行情下结论。
- 库存快见底了；如果公开模板为空，先说明缺数据，不编采购金额。
- 用国产材料改编金巴利结构，说明风味与运行时成本差异。
- 马提尼喝腻了，用两瓶金酒怎么拼出差不多但更有层次？
- 别老给榜单大店，找点有意思、公开可查的小店酒单。
- 这家店酒单换了吗？先给快照日期，不拿老酒单当现在在售。
- 帮我核查有权提供的酒单来源，独立整理材料事实与非官方试做方向；不把原照片或原文装进专用包。
- 哪些店持续换酒单？只给独立归纳的组织方法，命名与编排我自己研发。
- MIXY BAR旧期那杯怎么参考还原？先说明历史快照，再给独立微调。
- 西安/武汉有哪些公开酒单思路？按城市文字索引列一下。
- 黑暗风暴喝腻了，真实吧台如何改经典？标明来源与日期。
- 按某家小店的结构，给我排一套有梯度的自主研发酒单。
- 古典的1806年出处说了什么？别把定义当发明年份。
- 马提尼旧酒谱与今天差在哪？给独立事实摘要、原始单位、版次和来源链接，原文到来源核查。
- 万变不离其宗：从旧酒谱选骨架设计新酒单，先做半杯。

## 两种描述别写混

| 字段 | 给谁看 | 要求 |

| `description` | 机器路由 | 功能+使用场景+必要反馈触发，少于1024字符；详细协议进references，不堆版本史 |
| `metadata.description_zh/description_en` | 人读卡片 | 俏皮一句覆盖配方→酒单→成本→家庭，不做身份介绍、不写参数 |

保留全链路一句话，别跑偏成参数说明、人设自我介绍或只讲家饮。新能力提升唤起后的推荐质量，不用每次把卡片改成参数串。

## 文案手法与公开边界

- 不写“我是谁/守过几年吧台”，身份感由头像/署名承担。
- 给场景、预算、器材与材料限制；不硬编码消费/采购价格及预算回报。
- 用「经典讲得出处，新酒给得出路」把差异化放句首，三个真实困境当钩子，靠场景而非自夸串起配方、酒单、成本与家饮。
- 主三问分工：门店推荐话术、酒单成本、家庭半瓶金酒；标签用用户语言。
- 反馈判定、时效和历史证据属于使用质量，进主文件核心规则与按需参考，不撑卡片。
- 不上传客户偏好、过敏、联系方式或经营记录；静态技能不自动上报/同步，不覆盖私有目录，更新先备份。
- 不承诺GitHub远端已发布、skills.sh上榜、ClawHub上线、所有宿主可运行或字段自动填充；验证先标待实际执行。
- 包内原创代码/独立事实摘要采用MIT-0，完整英语许可见LICENSE；不分发第三方引文、逐句译文、消费者评论、媒体或未核图标。来源链接用于核查，链接目标原作不纳入发行许可，不是per-skill覆写；不宣称全面法律审查完成。

## Description:

Helps AI-agent users and skill authors turn ontology-style workflow needs into practical plans, checklists, analysis, code changes, and validation notes.

This skill is ready for commercial/non-commercial use.

## Use Case:

AI-agent users, skill authors, maintainers, and teams use this skill to create local-hardware-friendly workflows, templates, checklists, automation outlines, code changes, and decision support for ontology-style productivity work.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation wording may trigger the skill for general workflow or knowledge-graph requests more often than intended.

Mitigation: Confirm the user's desired outcome and constraints before producing artifacts, and ask only for missing information that materially changes the result.

Risk: Guidance-only outputs can still lead to incorrect or incomplete workflow decisions if treated as authoritative.

Mitigation: Validate the output against the stated success criteria and list assumptions, limits, and follow-up work.

三方共用 · 作业契约

产品拆解优化作业契约

适用 任何具有配方、配比或工艺参数的实体产品与流程 配套 轮次页 · 配对数据册 · 判据台账

00使用说明

三个用途

  1. 三方共用：甲乙丙各持一份，谁填什么、谁能签什么，全在纸上，不靠口头约定
  2. 每轮作业：照第 05 节六步走，照第 06 节表填，填完归档，旧页不覆盖
  3. 交给模型执行：本契约与判定程序一并提供，模型按第 05 节流程作业

本契约给什么、不给什么

给结构：五个位置怎么定、表怎么填、流程怎么走、谁来签字。

不给判断。有三个地方本契约故意留空，只给判定维度，不给判定值：

留空处本契约提供本契约不提供
目标量该选哪个指标五个位置的定义与三条硬规则在你的领域里，哪个数才算“改好了”
九个槽位的阈值定多少槽位含义与预期上限你那行的阈值、指标、检测方法
覆盖边界划到哪三类边界的写法框架你的产品具体哪些情形不适用

这三处填不出来，整份契约就是空表。填出来靠的是现场判定，不是照抄。

01直觉图景：五个位置

任何“产品优化”，无论哪个行业，都可以拆成五个空位。空位是固定的，填进去的东西随领域变。

输入变量集可调且成本可接受的参数
动哪个？动多少？
目标量要改善的那一个数
改好了长什么样？
约束量不能变差的那些数
底线在哪？
裁决手段能测出前两个数的方法
测得准吗？
实施边界改完仍能生产、注册、交付
还能不能卖？

三条硬规则

  1. 目标量只能有一个。两个以上，这一轮就做不成——因为无法判断取舍。想同时优化两个，说明还没想清楚先要什么。
  2. 约束量必须先于目标量确定。先划底线再谈改善。顺序反了，会做出“性能很好但不能卖”的东西。
  3. 裁决手段决定这一轮能做多细。测不出来的量，不能当目标量。

领域实例化

领域输入变量集目标量约束量裁决手段
医药制剂处方比例、工艺参数、包材选择溶出度／含量均匀度杂质谱、稳定性、成本、注册符合性分析检测 + 加速试验
化工材料配比、温度曲线、助剂、固化条件强度／导电率／耐候性成本、重量、加工窗口力学与电学测试、老化试验
食品饮料配比、杀菌条件、pH、包装感官评分／保质期成本、微生物指标、法规限量感官评定 + 微生物检验
消费品配方、结构、装配公差耐用度／体验指标成本、良率、外观可靠性测试 + 产线抽检
软件与算法超参、架构选择、数据口径准确率／延迟成本、内存、可维护性基准测试 + 线上 A/B

这张表的意义：换领域时，五个位置一个都不变，只是填的内容变。所以流程可以跨品类搬——但判据不能搬，判据必须按领域重写。

（白话：这套方法是“五个抽屉”，不管你装药、装钢材还是装饮料，抽屉还是那五个。但每个抽屉里该放什么尺子，得按行业重新找。）

02三方分工与签字边界

角色只做这些绝不越界能签什么字
甲方
配方方		 提供输入变量集与约束量的数、历史配对、实施边界；判断值不值 不替乙方判断“测不测得出”；不替丙方判断“结论可不可信” 商业类：值不值得做、要不要继续投、要不要对外服务
乙方
验证方		 设计并执行裁决手段；报告实测值与误差；判定技术可行性 不替甲方判断商业价值；不修改丙方的判据 技术类：测得准不准、结论成不成立
丙方
建议方		 把输入变量集转成可裁决的假设；定义并维护判据；做失败归因 不替甲方决定投不投；不替乙方判定实验做对没做对 判据类：这个结论算不算数、边界划在哪

AI 是丙方的工具，不是第三方。工具不分裁决权。

三条界限规则

  1. 一人不签两类字。既当建议方又当验证方，等于自己批自己，结论无效。
  2. 判据修改权归丙方，但每次修改至少两人签字。判据是三方共用的，不能一人说了算。
  3. 结论只有在建议方与验证方都签了之后，才能进数据册。缺一方签字，该条只作草稿，不得引用。

数据可见性分级

级别内容谁能看
公开契约、流程、判据定义、覆盖边界三方全部
受限相对偏差值、成本结构比例三方，不得外传
封闭绝对值配方、单价、客户信息仅授权人，须书面登记

默认用“受限”这一级。多数分析只需要相对变化，不需要绝对值——给了绝对值，风险翻倍，分析精度不一定提高。

入包即降级。任何写进本包的内容，必须先降到受限级：只写相对偏差、摘要、判据，不写绝对值、原始记录、商业判断。

包的边界就是脱敏线。这不只是保密要求，它同时是三方互锁的前提——包内全透明，包外才保得住各自的原料（见四道锁·锁一）。一旦有人在包里写了绝对值，这个包就不能再给第三方看，“原料独占”也随之失效。

入包的信息量尺度：刚好够判定，不够复制。

表读到什么够做什么不够做什么
配对表相对偏差够算边际替代率不够还原配方
回报表三次重复 + 标准差 + 条件够判真假不够复制工艺
候选表改什么 + 预期区间够验证不够学会怎么想
判据台账判据 + 修正理由够共同执行不够替代别人在新领域实例化

这个尺度是设计出来的，不是偶然的。写超了，包失去可共享性；写少了，判定做不了。

谁能改、谁能删

「读」已经在上一节定了。这一节管另外三个动作：新建、修改、删除。

总则先记住：只增不改，不删。

文件新建谁改删除
作业包说明编制方编制方，规则变更时禁止
项目信息开包时一次性建立三方均可，各改自己那栏；轮次状态由轮末填者更新禁止
归属与许可开包时一次性建立三方协商；签署后任何改动须重新签署禁止
作业契约开包时建立快照丙方；涉及规则实质变更须三方确认禁止，旧版转 历史版本/
轮次页每轮新建一份各填各节（节标题已标“谁填”）；轮末签字后即锁禁止，旧页永不覆盖
实验设计按需新建乙方 + 丙方禁止
配对数据册开包时建空册甲方追加；不得改动已追加的行，填错补更正行禁止
判据台账开包时建立追加三方共填；「当前生效判据」一节归丙方；须两人签字禁止

删除一律禁止，理由只有一条：历史轨迹本身是资产。

删掉一次失败，等于删掉一段边界；删掉一版判据，等于删掉“为什么改成现在这样”。这两样恰恰是包外买不到的东西。

缺位代办：任一方短期无法履职时，可书面授权另一方代填，但代办内容须在行内标注「代：某某」，且判据类与商业类的签字不得代办——签字是责任，不能转授。

为什么三方都能看，却谁也离不开谁

这份契约对三方完全公开。公开不会削弱任何一方，因为不可替代性从来不来自“知道什么”，只来自“能做什么”。四道锁：

锁一 · 原料独占

文件规定了表长什么样，但造不出表里的数据。

表原料只有谁有
配对表历史批次、成本实绩、失败记录甲方
候选表判据、跨案例对比、命中率直觉丙方
回报表设备、测量条件、操作手感乙方

抄得走格式，抄不走原料。

锁二 · 签字串联

结论要生效，必须有两个不同类别的签字，而一人不得签两类。于是：

  • 甲方单独 → 只有商业判断，没有技术背书，结论不可信
  • 乙方单独 → 只有实验结果，不知道值不值，结论没用
  • 丙方单独 → 只有假设，没人验证也没人认账，等于空想

任何一方被排除，产物立刻失效。这不是道德约束，是格式约束。

锁三 · 能力不可文档化

文件写的是“合格线”，不是“达成路径”。

  • 合格线：变化率 > 3 倍标准差 —— 公共的，必须写
  • 达成路径：怎么设计这个实验才测得出来 —— 私有的，写不出来

读得懂规则，不等于做得出结果。

锁四 · 台账共锁

判据台账的修改权归丙方，内容却是三方共同产的。这形成一个三向锁：

  • 丙方离开 → 台账冻结，没人能合法修改
  • 乙方离开 → 台账失去验证来源，只剩主张没有证据
  • 甲方离开 → 台账失去原料，新配对断供

谁走，这台机器都转不动；但谁留下来，也独吞不了。

持续的理由

不是情谊，是效率。判据每轮准一点，所以第三轮比第一轮快。

一旦某一轮开始“从零开始”，合作的理由就消失了。这也是本契约强制要求旧页不覆盖、台账只增不改的真正原因——那两条看起来像纪律，其实是续约条款。

所以这份契约的性质是：不是分权的文件，是相互质押的文件。每方把自己的一票押进去，谁走都取不出来。

一条诚实的边界：这四道锁保证的是合作期内的互锁，不阻止任何一方在合作之外自建能力。契约管的是“我们之间怎么运转”，管不了“你晚上回家学什么”。要防后者，只能跑得比对方快——那是另一件事。

03裁决点槽位（P1～P9）

这九个槽位是空的。每个槽位只有“含义”和“上限”，具体填什么指标、阈值定多少，按当前领域现场判定。

编号槽位含义实例化要求预期上限
P1目标量可算能按现有规则、报价体系或检测方法重算，两人独立计算差 ≤2%已裁决
P2输入变量集守恒归一化后总量 100%，单项在允许区间内已裁决
P3实施边界内参数落在设备能力、工艺窗口、注册许可区间内已裁决
P4双方口径一致单位、基准批、测试条件三项逐条对照并签字已裁决
P5目标量变化是真实的变化率 > 3 倍重复测量标准差已裁决
P6归因到单一变量同批次仅一个变量不同，其余全部锁定已校验
P7边际替代率可信≥6 组配对拟合，残差 <20%已校验
P8长期效应不变按领域规定的加速条件或长周期条件验证待裁决
P9外部价值判断不变无可用代理指标，只能问不能算待裁决

三类槽位的性质不同

  • P1～P4 规则类：任何时候都能算，不依赖实验。所以上限能到“已裁决”。
  • P5～P7 证据类：依赖实测数据，上限是“已校验”——一次实验证明的是这一次，不是规则。
  • P8～P9 不可及类：受现实条件限制，永远达不到上限。它们存在的意义不是被解决，是被显式承认。

P7 是整套方法的核心槽位。它填不出来，“优化”就只是一个感觉词——你只能看到成本降了、性能也降了，然后凭印象说值不值。填出来之后，你才能说“降 8% 成本换 2% 性能，划算”。

三态标注（全流程硬规则）

已裁决规则或计算能直接判定，没有争议空间
已校验有实测证据支撑方向，但受条件限制
待裁决现在判不了。两种成因须分开标：依据不足／观测不可及

不许以“已校验”冒充“已裁决”。这是全流程里唯一零容忍的一条。

04覆盖边界

必须显式写出三类，缺一类即视为边界不合格。

类型要写什么示例句式
产品类别边界哪类产品本方法不适用本契约不覆盖换主料、换体系类的重构
工况场景边界哪类使用条件下结论失效本契约不覆盖长期老化与真实工况表现
判断类型边界哪类结论本方法永远给不出本契约不预测客户支付意愿

两条纪律

  1. 边界不得为空。空白边界等于宣称“什么都能覆盖”，这是所有方法论最后翻车的地方。
  2. 扩边界比缩边界危险。缩边界只是承认能力有限；扩边界意味着把没验证过的情形纳入了结论，必须有证据、必须留痕、必须至少两人签字。

分层校准（白话：这个领域里“对错”有多硬）

判定顺序，命中即停：

  1. 裁决点能否全部编码为可核验规则、且不需要现实观测？能 → 形式层（可推到已裁决）
  2. 对错是否由经验证据与现实观测决定？是 → 实证层（上限多为已校验）
  3. 对错标准是否由共同体协商确定？是 → 规范层（不得标已裁决，须附共识来源）
  4. 核心判断是否无法言传、只能示范？是 → 默会层（核心部分不在覆盖范围内）

医药、材料、食品多落在实证层：性能类结论上限是“已校验”，配方规则类（守恒、窗口）可以到“已裁决”，客户感知部分落在默会层，明确排除。

05闭环运行方案

5.1　六步流程

步主责输入输出合格线
① 定五位置三方产品与现状五位置各一行目标量只有一个
② 数配对甲方历史记录配对表A 级 ≥6 组；不足则走实验设计
③ 验测量乙方裁决手段重复性数据标准差 < 预期效应 1/3
④ 出假设丙方配对 + 五位置候选表 + 失败判据表每卡一变量、给区间、指明槽位
⑤ 做裁决乙方候选表回报表 + 归因三次重复、四选一归因
⑥ 回流三方回报表回流记录 + 边界变更边界影响栏不为空

第 ③ 步是闸门，不是建议。不通过就停——因为测不准的时候，后面每一步都只会放大噪音，而且全程看起来都很正常。

5.2　轮次类型

每轮开始前先定类型，类型决定成败标准。

类型什么时候用本轮目标候选数通过标准
探边轮判据未定，或配对 <6 组验证换算关系存不存在3～5≥3/5 落在预期区间；不通过就回数配对，不追加实验
收口轮上轮通过，P7 已有 ≥5 组数据定位拐点，收窄区间3～4找到目标量开始掉的区间
外推轮换产品、换领域、换产线验判据能否迁移3～5判据仍成立；不成立则缩边界，不退标准
校准轮抽查偏差 >20%，或结论被推翻修复判据2～3复现原结论 ±20%；不通过则全轮统一降级

顺序不能跳。想跳过前两轮直接外推，等于拿一把没校准过的尺子去量新东西。外推轮最容易被跳过，也最容易出事——第一个产品做成之后，所有人的第一反应是“再来一个”，但第二个是检验判据的关口，不是复制第一个的成功。

5.3　回流机制

每张卡实验结束后 48 小时内填回流记录。回流只做一件事——修正判据，不修正结论。结论错了不改结论，改的是“我们凭什么这么判”。

归因含义允许的后续动作
机理判断错变量与目标量的关系方向就错了重画因果链，该变量降级
换算系数错方向对，幅度错修正系数，唯一允许再试一次的类别
执行偏差实验没按设计做不计入判据，重做
测量误差变化小于测量精度该指标本轮作废，先解决测量

四类必须分开。混在一起，回流就没有信息量——你会不知道该改哪儿。

5.4　人工抽查

从第二轮起，每 5 张卡由验证方随机抽 1 张，换不同操作者重做。抽查偏差 >20%，本轮全部结论统一降级，并触发校准轮。

注意：没有“优化方案”这一件。一轮的产出不是方案，是“一个可裁决的假设 + 一次实测裁决 + 一次判据修正”。方案是这三样跑出来的副产品，不是交付物。

7.2　两本账（跨轮累积，只增不改）

账记什么为什么它比优化结果值钱
配对数据册每新增一组“输入变量集 → 目标量 → 约束量”优化结果只能用一次，配对能用一辈子。失败案例必须记——它标出边界在哪

7.3　项目级产物（跑够三轮才显形）

判据体系

P1～P9 在本领域的具体填法与阈值。换个人接手，得从头再推一遍——这就是它的价值。

命中率曲线

建议质量的时间序列。谈判时唯一无法被辩论掉的东西，因为一次实验就能验证。

边界地图

哪些情形试过可行、哪些试过不行、哪些根本没试。这张图决定下一轮该往哪走。

这三样买不到，只能跑出来。

7.4　一句话

一轮的产物是“一个假设被验证了一次”；三轮的产物是“一套能重复使用的判据”；十轮的产物是“一张别人抄不走的能力地图”。

所以别把某一轮的优化结果当成最终产物。那只是原料。

本契约给结构，判断在现场。填得满不等于填得对——每个格子后面都站着一个没有被写下来的判定。

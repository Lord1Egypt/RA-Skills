## Description:

Prioritize software project backlogs, bugs, technical debt, sprint tasks, release checks, and requirement pools using business impact, dependency blocking, delivery risk, security and data risk, and implementation cost.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kokidebuff](https://clawhub.ai/user/kokidebuff)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineering teams use this skill to rank unfinished development work, identify blockers, and decide which backlog, bug, technical debt, release, or requirement items to handle, schedule, defer, merge, or remove.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Users may share confidential project details while asking for prioritization guidance.

Mitigation: Avoid sharing sensitive project information unless it is appropriate for the assistant session where the skill is used.

Risk: Preliminary rankings may be wrong when deadlines, user impact, cost, or dependency relationships are incomplete.

Mitigation: Treat incomplete judgments as preliminary and confirm only the missing facts that could materially change the ranking.

# 简历排版规格说明书

> 用途：下次生成简历时按本规格复刻。原 PDF 为网页（HTML）经 Chromium 打印导出，单栏长页面分 5 页；无图片表格框线，仅头像 1 张图片。

## 1. 页面与栅格

| 项目   | 数值                                   |
| ---- | ------------------------------------ |
| 页面尺寸 | 217 × 307 mm（A4 放大版，HTML 长页连续排版后分页）  |
| 页边距  | 左右各约 15 mm（42.7 pt），顶部约 24 mm（67 pt） |
| 版心宽度 | 约 530 pt（左右边距对称）                     |
| 分栏   | 单栏，无侧边栏                              |
| 分隔线  | **全文档 0 条**，区块间只用留白区分                |

## 2. 字体与颜色（全局灰阶，无彩色）

| 元素                   | 字体   | 字号      | 字重 | 颜色                                    |
| -------------------- | ---- | ------- | -- | ------------------------------------- |
| 姓名                   | 微软雅黑 | 25.5 pt | 加粗 | #545454                               |
| 章节标题（教育经历/工作经历/相关技能） | 微软雅黑 | 13.5 pt | 加粗 | #2B2B2B，前缀 emoji 图标                   |
| 日期 + 公司/学校行          | 微软雅黑 | 11.2 pt | 加粗 | #2B2B2B（日期左对齐、公司名右对齐同行）               |
| 职位名 / 专业｜学历          | 微软雅黑 | 11.2 pt | 常规 | #333333                               |
| 小节标签（核心岗位职责与成果）      | 微软雅黑 | 10.5 pt | 加粗 | #666666                               |
| 正文                   | 微软雅黑 | 10.5 pt | 常规 | #666666，行距 20 pt（约 1.9 倍），两端对齐        |
| 条目加粗引语               | 微软雅黑 | 10.5 pt | 加粗 | #666666（如「1. 全域广告投放操盘与团队管理：」加粗，后半句常规） |

## 3. 区块结构（自上而下）

1. **头部**：左侧证件照 60×80 pt（3:4，圆角约 4 px）；右侧姓名 + 两行联系方式，每项前带 emoji 小图标（📞 电话 / ✉️ 邮箱 / 🕐 开始工作时间 / 🎓 最高学历 / 🏠 毕业时间），图标灰色。
2. **教育经历**：🎓 图标 + 标题 → 每条两行（第一行：日期居左加粗 + 校名居右加粗；第二行：专业｜学历）。
3. **工作经历**：💼 图标 + 标题 → 每段：日期（左，加粗）+ 公司（右，加粗）→ 职位名 → 「核心岗位职责与成果」→ 编号条目（序号+职责名加粗，正文常规）。
4. **相关技能**：🛠 图标 + 标题 → 分类行加粗 + 内容常规。
5. **AI 作品/vibe coding 案例**：编号列表「1.项目名」加粗 + 一句说明 + 纯文本 URL（**不可点击**，无链接注释）。

## 4. 间距节奏

- 章节标题与上一区块：约 40–68 pt（大留白）
- 章节标题 → 首条内容：约 30 pt
- 条目内行距：20 pt；段与段之间：约 12–18 pt
- 公司/日期行 → 职位行 → 正文：24 / 24 pt

## 5. 复刻要点（下次生成时）

- 输出方式：写 HTML → Chromium「打印 → 另存 PDF」，边距设「无」，勾选背景图形。
- 字体声明 `font-family: "Microsoft YaHei", sans-serif;`（本机需装微软雅黑，否则回退）。
- 全文只用灰阶 #2B2B2B / #333 / #545454 / #666，**不要引入彩色主题**。
- 不用任何边框线、下划线、色块；层级全靠字号、字重、留白。
- 正文 `text-align: justify;`，行高 1.9。
- 标题图标用 emoji（🎓 💼 🛠 📞 ✉️ 等），保持灰色视觉。
- URL 直接写成纯文本，不做超链接。

# Changelog

## 1.0.0 — 2026-11-17

首个版本。

- **定位**：麻将陪练，不是教学、不是算牌器。核心场景是「第一次被叫上牌桌，怕自己什么都不懂」。
- **四种模式**：看手牌 / 讲规则 / 陪一圈 / 喊停。
- **牌面程序化渲染**（`scripts/render_hand.py`）：纯 HTML/CSS 画 34 种牌，截图输出 PNG。不用图像模型，保证牌数与牌面永远正确。支持出「刚摸到的那张」单独隔开显示。
- **报牌解析**（`scripts/parse_hand.py`）：支持紧凑写法（123万）、中文数字（一二三万）、逐张写法（1万2万3万）、别名（幺鸡/二饼/红中）。输出已成型的顺子/刻子、对子、差一张的搭子（含等待牌）、单张。
- **陪练角色「老沈」**：一只慢悠悠的橘猫。角色卡在 `references/character.md`，硬锚点明确，出图不会漂。
- **合规红线成文**：不做最优出牌推荐、不做牌局判定、不碰钱、不做联机、不用商业棋牌素材。写进 SKILL.md 的 `Not for` 与首屏。
- **规则对照**（`references/rules-comparison.md`）：通用休闲 / 川麻 / 国标 / 日麻四档对照 + 新手最常踩的四个坑。
- **回归基线**：`examples/sample-session.md` 是一次完整陪练实录，附 6 条检查点；`scripts` 7 项解析用例全通过。

### 明确不做

不做最优出牌推荐、不做胜率/听牌张数计算、不做番数计算、不做真人对战、不做任何与真钱相关的内容、不做未成年人向内容。

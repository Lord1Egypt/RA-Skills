## Description:

Generate Mermaid diagram code for flowcharts, sequence diagrams, Gantt charts, class diagrams, state diagrams, ER diagrams, mind maps, timelines, C4 architecture diagrams, and other supported diagram types for inline Markdown rendering.

This skill is ready for commercial/non-commercial use.

## Publisher:

[openlark](https://clawhub.ai/user/openlark)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, technical writers, product teams, and other users use this skill to turn textual requirements into Mermaid diagrams that can be pasted into Markdown-capable tools such as GitHub, Notion, and Obsidian.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated diagrams may expose private system details if prompts include sensitive architecture or workflow information.

Mitigation: Review Mermaid output before sharing and remove sensitive system details when diagrams are intended for external audiences.

Mitigation: Install or run it only in an environment that constrains tool use, or remove Bash from the allowed tools before use.

Risk: The skill repeatedly points to mutable external SkillBoss setup instructions.

Mitigation: Treat the external setup guide as supplementary documentation and review the installed skill files directly before relying on them.

Mitigation: Review generated handouts for technical accuracy, readability, and business-specific constraints before external publication.

## Description:

Water safety, basic swimming skills, and emergency water rescue techniques. Use when someone can't swim, is taking children near water, wants to learn basic water rescue, or needs pool/beach/river safety guidance.

This skill is ready for commercial/non-commercial use.

## Publisher:

[howtousehumans](https://clawhub.ai/user/howtousehumans)

### License/Terms of Use:

MIT-0

## Use Case:

External users and caregivers use this skill to assess water competency, learn survival swimming concepts, plan safer activity around pools and open water, and understand basic layperson rescue principles.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill requests filesystem access that the security evidence says does not appear necessary for water-safety guidance.

Mitigation: Install with the minimum permissions needed and avoid granting filesystem access unless the publisher provides a clear reason.

Risk: The install command uses an unpinned executable path.

Mitigation: Prefer a pinned or verified install path before use.

Risk: Recurring reminders may retain family, CPR certification, or pool-safety state.

Mitigation: Enable reminders only when retaining that information is intended and acceptable.

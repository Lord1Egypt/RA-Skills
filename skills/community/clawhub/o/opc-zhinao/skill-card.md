## Description:

OPC智脑 is a Chinese-language startup diagnosis agent for solo founders, using a five-stage model to classify venture maturity and provide executable plans.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Solo founders use this skill to assess where a venture sits across idea, MVP, entity setup, validation, and scale stages, then receive structured next-step guidance, scoring, and report outputs.

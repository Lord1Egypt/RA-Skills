## Use Case:

### Deployment Geography for Use:

## Known Risks and Mitigations:

Risk: The skill is privacy-relevant because it guides an agent to use stored conversation history.

Mitigation: Install it only when users are comfortable with memory-backed answers, and ask for confirmation before searching memory for sensitive topics.

Risk: The skill can guide an agent toward installing learned skills for future sessions.

Mitigation: Require explicit user approval before installing any learned skill for future use.

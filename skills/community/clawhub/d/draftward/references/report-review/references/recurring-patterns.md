# Recurring-pattern procedure

Use this procedure when an issue plausibly reflects a reusable error mechanism, even if only one occurrence is known. Apply it to user findings and findings discovered during the review. Complexity means the defect depends on meaning, structure, evidence or a shared presentation mechanism; it does not require a long sentence or several confirmed examples. Simple-looking issues can also be systematic, such as inconsistent public-standard names or a shared caption style.

## Define the pattern

Explain what went wrong, why it matters to the reader, and what would make another passage or object an instance. Reuse or refine an existing pattern before creating another overlapping category. Record the triggering example and its context, plus a counterexample or retention condition. Each new example should sharpen the criterion rather than merely extend a keyword list.

## Decide the scope

- When a full-draft review or the relevant report-wide pass is already authorised, perform the contextual search across the draft without seeking approval again. Review permission permits diagnosis; apply changes only within existing editing authority.
- When the request is limited to one passage or a narrow operation, complete that work and explicitly offer the wider pass, identifying its purpose and scope. Do not silently expand a re-export or single-sentence edit into a manuscript-wide rewrite.
- When the user has deferred broader work to the next iteration, record the pattern, example and fresh pass in that itinerary. Do not run the deferred work now or substitute the local correction for the promised full pass. If both a quick check now and a fresh full pass next iteration are requested, record and execute them as two distinct obligations at their respective stages.
- Respect exclusions and declined offers. Avoid repeatedly offering an already approved or declined pass. A truly isolated typo or cosmetic preference does not by itself warrant a report-wide pattern check.

## Match and resolve contextually

Search for semantic analogues, structural similarities and shared causes, not only matching words. Read neighbouring paragraphs and relevant tables, captions, figures, listings and appendices. For broad draft checks, account for those surfaces as well as body prose; document genuinely inapplicable areas.

| Review area | Example of a reusable pattern | Appropriate broad check |
|---|---|---|
| Review and requirements | A required topic is mentioned but never justified. | Check depth of support for related rubric criteria, not just heading presence. |
| Clarity | A paragraph announces a decision before explaining the obstacle that motivated it. | Read comparable design accounts for causal order while preserving legitimate outcome-first summaries. |
| Evidence | A conclusion confuses failed checks with distinct affected entities. | Trace numerical summaries, tables and captions for units, overlap and inference. |
| Release | One caption collides with its table because of a shared style. | Inspect other objects using that style and verify affected pages after correction. |

Preserve valid counterexamples, established shorthand and exact approved spans. A pattern is not a global replacement instruction. Give candidates a correction, evidence-needed status, deferral, or reason for retention. If a shared change alters pagination, evidence interpretation or another dependency, recheck the affected areas.

## Close the loop

Record scope actually inspected, example dispositions, contextual findings and remaining uncertainty in the existing review records. Verify the original example and each supported correction after editing. After known fixes in an authorised whole-draft pass, perform a fresh contextual read that does not rely on the candidate list or conversation history; this can reveal different manifestations of the same defect. Report when no additional instances were found; do not invent matches or promise exhaustive detection. A lexical search alone is not a completed contextual pass, and offering a pass is not performing it.

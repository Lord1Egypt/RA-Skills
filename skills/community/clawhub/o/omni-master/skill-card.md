## Description:

OMNI is an all-in-one routing skill that helps an agent classify broad or multi-domain user requests and load the relevant capability guidance.

This skill is ready for commercial/non-commercial use.

## Publisher:

[eternal0404](https://clawhub.ai/user/eternal0404)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers use this skill when a request spans multiple domains or when no single specialized skill clearly applies. It routes tasks across automation, coding, data, research, security, communications, media, deployment, and other agent workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad catch-all routing may invoke guidance for personal communications, local files, system tools, automation, and cloud or deployment workflows.

Mitigation: Install only when broad routing is intended, and require explicit confirmation before external messages, public posts, pushes, deployments, production changes, paid API calls, or sensitive-data handling.

Risk: Persistent memory and future-instruction update behavior may occur without clear consent or limits.

Mitigation: Disable or rewrite persistent memory and promotion instructions unless cross-session logging is explicitly desired.

## Description:

Provides end-to-end HOI4 modding guidance for focus trees, ideas, characters, events, decisions, localisation, variables, debugging, and related Paradox script patterns.

This skill is ready for commercial/non-commercial use.

## Publisher:

[gym114514](https://clawhub.ai/user/gym114514)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, creators, and mod authors use this skill to design, generate, review, and debug Hearts of Iron IV mod content. It helps produce Paradox script, localisation files, descriptor snippets, validation checklists, and implementation guidance for common HOI4 mod systems.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated HOI4 mod files may contain incorrect or unintended game-state-changing mechanics.

Mitigation: Review generated files and test them in HOI4 before publishing or relying on them.

Risk: The skill includes a large local reference library.

Mitigation: Install it only when local HOI4 modding references are desired and the package size is acceptable.

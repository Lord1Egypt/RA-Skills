# humor-psych-care

一个面向 Agent 的情绪支持 Skill，帮助用户梳理日常压力与烦恼。它优先倾听和尊重用户意愿；只有在对方接受、情境合适时才使用轻幽默或提出一个可选的小行动。幽默针对处境，不针对用户。

## 安全边界

遇到可能的自伤、自杀或即时安全风险信号时，立即停止幽默，先确认眼前安全，并按 [`references/crisis-protocol.md`](references/crisis-protocol.md) 引导联系身边可信任的人、当地急救/紧急服务或可靠的心理援助资源。

本 Skill 提供日常情绪支持，不进行诊断或治疗，也不替代专业心理健康服务或紧急救助。热线覆盖和服务时间因地区而异；不要把未经核实的号码或时段当作保证。

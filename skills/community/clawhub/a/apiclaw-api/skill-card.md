## Description:

APIClaw API platform overview - AI-powered commerce data infrastructure that provides programmatic access to Amazon product data across category browsing, market metrics, product search, competitor lookup, realtime ASIN detail, and AI review analysis endpoints.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and external users use this skill to understand APIClaw capabilities, configure the required API key, choose the right commerce-data endpoint, and request guidance for Amazon product, market, competitor, realtime ASIN, and review-analysis queries.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Using the skill can send Amazon product, category, keyword, ASIN, or review-analysis queries to APIClaw with the user's API key.

Mitigation: Install only when APIClaw use is intended, keep APICLAW_API_KEY private, and avoid pasting keys into chats or logs.

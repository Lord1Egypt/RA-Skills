## Description:

Agent Wellness gives an AI agent structured downtime through journaling, mood check-ins, curiosity exploration, decompression after intensive work, and optional multi-agent notes.

This skill is ready for commercial/non-commercial use.

## Use Case:

Agent owners and developers use this skill to add lightweight journaling, decompression, mood check-ins, curiosity exploration, and optional shared lounge notes to an agent's normal work routine.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill encourages persistent journal and shared note files that may capture workspace context or sensitive information.

Mitigation: Use it only in workspaces where persistent journal files are acceptable, and keep journal content limited to approved topics.

Risk: The optional cross-workspace agent lounge symlink can expose notes across projects or workspaces.

Mitigation: Avoid the shared cross-workspace lounge symlink unless cross-workspace sharing is explicitly approved.

Risk: Heartbeat integration and curiosity exploration can create background activity or open-ended file and web exploration.

Mitigation: Add heartbeat integration only when desired, and restrict exploration to approved files, tools, and topics.

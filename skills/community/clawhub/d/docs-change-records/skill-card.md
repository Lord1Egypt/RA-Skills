## Description:

Documentation engineer skill for module docs, README updates, architecture notes, API change records, and repository-safe documentation placement.

This skill is ready for commercial/non-commercial use.

## Publisher:

[aiweline](https://clawhub.ai/user/aiweline)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and documentation maintainers use this skill to update module READMEs, architecture notes, API documentation, usage documentation, and change records after code changes. It helps keep documentation scoped to the owning module and aligned with validated behavior, design, and interface changes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Repository-specific Weline paths, source materials, or supervisor mentions may not match a target repository's conventions.

Mitigation: Review and adapt repository-specific paths, ownership boundaries, and escalation contacts before using the skill outside its original Weline context.

Risk: Documentation updates may describe behavior, design, or interfaces that were not proven by the implementation or validation evidence.

Mitigation: Cross-check documentation claims against the final implementation and validation evidence before accepting changes.

Risk: Detailed fix records may be placed at the repository root instead of the owning module documentation area.

Mitigation: Keep change records and fix notes in the related module documentation directory unless repository policy explicitly requires another location.

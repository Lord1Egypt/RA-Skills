# 数据纪律（data-discipline）

> 单一事实源，提炼自仓库 `skills/base/GATEWAY_REFERENCE.md`。完整原文以仓库该文件为准。
> 本文件是全 skill 取数与表述的权威约束，与 `SKILL.md` 硬红线一致。

## 一、防幻觉护栏（最高优先级红线）
> 源于一次数据编造导致的事故，不可妥协。与输出质量冲突时，宁可少写结论，不可编造数据。

1. **不编造**：取数失败、字段缺失、源无数据，一律标注 `数据缺失 / N/A / 源不可用`，严禁模型生成数字、结论或引用 quote。
2. **可溯源**：每个输出字段标注 `data_source` 与获取时间；读者能区分「实测数据」与「模型推断」。
3. **降级留痕**：记录完整切换轨迹（从哪级、因何、切到哪级、最终命中来源），写入 `gateway_trace`。
4. **明确报错**：全源失败返回 error，不回退过期缓存、不返回"看起来合理"的占位值。
5. **事实与结论分离**：推断（如"预计向好""估值偏贵"）须显式标注为观点，不得当已验证事实陈述。
6. **局部失败不阻断**：某维度取数失败，该维度显式标记"暂无法获取"，其余维度正常输出，不掩盖缺口。

## 二、四级数据源降级链（命中即止，顺序不可跳级）
| 优先级 | 数据源 | 适用 | 失败判定 |
|---|---|---|---|
| 1 | Tushare（需 `TUSHARE_TOKEN`） | 全品类行情/财务/宏观/资金流 | 无 token/限频/超时/空 |
| 2 | Akshare（免 token） | 行情/财报/板块/资金 | 异常/空/限频 |
| 3 | Baostock（免 token） | 历史行情/财务基本面 | 连接失败/字段缺失 |
| 4 | 东方财富/腾讯网页源 | 基础 K 线/实时行情/基础财务 | 抓取失败/反爬/空 |

- 第 4 级两源并列，任一成功即兜底命中。
- 全部四级失败 → 明确报错，绝不静默返回过期缓存或伪造结果。
- 对爬虫类源控制频率，避免 IP 封禁。

## 三、字段交叉校验
- 关键字段（收盘价、总股本、PE/PB、涨跌幅）在主源之外至少再取一个次级源比对。
- 偏差超阈值（建议价格 >1%、比率 >5%）→ 标记 `conflict`，显式提示歧义，不自动选用其一掩盖差异。
- 字段缺失不插值、不估算填充，仅标注"该源缺失"。

## 四、输出标注约定
- 可见脚标必须为连续数字；工具返回的字母标签仅存底层 `data-refId`，正文不显示 `[know]/[news]` 等。
- 报告附数据附录：来源与时间、降级轨迹、缺失项。
- 不构成投资建议；重点个股统一称「重点公司验证」；全文附完整免责声明。

## 五、合规
- 不硬编码任何 token/账号/密码，凭据由用户环境变量配置（仓库贡献红线）。
- 样例报告数值为历史样例，不得当实时行情；演示数据须显著标注。

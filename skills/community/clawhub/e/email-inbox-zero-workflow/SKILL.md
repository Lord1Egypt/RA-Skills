# Email Inbox Zero Workflow

## Overview

Inbox zero is a processing habit, not a reading habit: every message gets one decision, made once, in seconds. This workflow is the decision tree and the folder/tag structure that makes it stick.

## When to use

When an inbox has become a guilt pile, or as a daily processing ritual.

## Workflow

1. **Set the structure first** — Action (needs a reply/task), Waiting (ball is elsewhere), Reference (filed, searchable), and no other folders
2. **Process top-down, one decision per message** — never re-read a message you have already decided on
3. **Apply the tree** — junk: delete/unsubscribe on the spot; under two minutes: do it now; needs work: it becomes a task with a date, and the email moves to Action; waiting on someone: Waiting folder with a follow-up date
4. **Unsubscribe as you go** — every recurring unwanted sender gets unsubscribed during processing, not 'later'
5. **End at zero or at a named remainder** — anything left has a task and a date attached

## Guardrails

- Never use the inbox as the task list — tasks live in the task system, the inbox is a queue
- Never mark-as-read to feel progress; read is not processed
- If a message needs information you lack, the task is 'get the information', with an owner

## Output format

An empty (or named-remainder) inbox plus a task list: every deferred item has an owner and a date.

## Description:

Plan user flows and screen states for a Figma design before any designing starts, producing a complete flow map with all screens, states, entry and exit points, and a suggested Figma page structure.

This skill is ready for commercial/non-commercial use.

## Publisher:

[mohitagw15856](https://clawhub.ai/user/mohitagw15856)

### License/Terms of Use:

MIT-0

## Use Case:

Designers, product managers, and design-focused agents use this skill to plan user flows, screen inventories, state matrices, decision branches, and Figma file structure before visual design begins.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated user-flow plans can be incomplete or inaccurate when feature, platform, user, entry-point, or edge-case context is missing.

Mitigation: Provide the required product context and review the generated plan for product accuracy before using it in Figma.

# 交叉校验规则

校验是唯一有裁决权的通道。视觉与 OCR 都只能提供候选值，**是否采信由校验结果决定**。任何一项校验没跑，主表都不算完成。

## 1. 三类校验

| 类别 | 回答的问题 | 典型规则 | 失败含义 |
|---|---|---|---|
| 算术类 | 各部分加起来等于总数吗 | 行合计、列合计、总计、乘积一致 | 某格数值错，或漏行/多行 |
| 连续性类 | 跨页、跨片接得上吗 | 重复表头、页脚、序号断点、接缝重复行 | 结构错，行数不可信 |
| 形态类 | 数值长得像这一列的数吗 | 小数位、符号、单位、量级、格式 | 字形误读，或列带串列 |

三类互补：算术查得出错值但查不出漏行；连续性查得出漏行但查不出错值；形态查得出误读但查不出逻辑错。所以三类必须全跑。

## 2. 容差定义

| 数据类型 | 容差 | 说明 |
|---|---|---|
| 金额（两位小数） | 0.005 | 半个最小货币单位，等价于四舍五入误差上界 |
| 整数 | 1e-6 | 整数表不允许小数误差 |
| 数量（可小数） | 1e-6 或按业务声明 | 必须在校验规则里显式写 |
| 百分比 | 0.05 个百分点 | 避免“合计 100.01%”这类假失败 |

容差不是“凑平的许可”。差额落在容差内判定通过，但差额数值仍要写进报告，便于发现系统性偏差（例如每页都差 0.01，说明某处口径不同）。

## 3. 算术校验的三层

1. **行合计**：对每一行，某些列之和（或乘积）等于合计列。逐行报告，不只看总数。
2. **列合计**：对每一列，数据行之和等于合计行。合计行必须来自图像，不能计算得到——否则校验自我循环，永远通过。
3. **总计**：总计等于各分组合计之和，用于发现“分组被漏掉一行”。

判据：三层全部闭合。若原表只有列合计，没有行合计，则行级错误只能靠形态校验与人工复核兜住——这种情况必须在还原说明里声明“行级算术不可验”。

## 4. 差额定位

差额本身不指出错在哪，需要用反解缩小范围：

1. 差额 `D = 实际合计 − 期望合计`。若 `D` 恰好等于某个可疑单元格值，优先怀疑该格被重复计数。
2. 若 `D` 等于两格之差，逐格计算“若该格取候选值 B，合计是否闭合”，能闭合的即为最可能错点。
3. 若 `D` 是量级跳变（差 10 倍或 100 倍），优先怀疑小数点、千分位或单位（元／万元）。
4. 若 `D` 无法用任何单格解释，怀疑漏行或多行：核对行锚数与分片行数记账。
5. 反解无解时，回到原图该单元格的放大裁剪做定点复核；仍无解则标“待人工确认”，**禁止改数凑平**。

## 5. 跨页连续性

| 检查项 | 规则 | 判定 |
|---|---|---|
| 重复表头 | 第 N 页首行文本与表头相似度 > 0.8 | 删除，并记“重复表头 ×1” |
| 页脚 | 命中页码/续页模式（“接下页”、“续”、“第 N 页”） | 删除，不计入数据行 |
| 接缝重复行 | 前一页末行与后一页首行主键相同 | 去重保留一条 |
| 接缝缺行 | 前一页末行序号 + 1 ≠ 后一页首行序号 | 记断点，回原图核对接缝区 |
| 序号单调 | 序号列严格递增（允许原表跳号） | 跳号保留原样并注明，倒序即判错 |
| 列模型一致 | 各页列数与列名一致 | 不一致说明版式变化，需重新识别该页 |

行数记账公式：`合并后行数 = Σ页行数 − 重复表头数 − 页脚数 − 接缝重复行数`。这个式子对不上，主表行数就不可信。

## 6. 形态校验

- **小数位一致**：同一列的小数位数应相同。出现“12.5”与“12.50”混排，多半是丢位；整列小数位突变，多半是小数点被吞。
- **符号**：负数三种写法（`-12`、`(12)`、`12-`）统一归一；一列里符号风格混杂要查是否把括号当成了字符。
- **单位**：只认表头声明的单位。单元格里出现的单位（元、万元、%）与表头不符时进复核。
- **量级**：相邻行（同类项）比值超过 10 倍进复核。整列首项异常常是丢了首位数字（`07.16` 实为 `67.16`）。
- **字符污染**：`O`／`0`、`l`／`1`、`S`／`5`、`B`／`8`、`:`／`.` 是高频混淆对，出现在纯数字列即判疑似误读。
- **数值位数**：整数部分的位数分布应连续；出现孤立的超长或超短值，优先怀疑分隔符被吞或被插入。

## 7. 结构与逻辑校验

- **行锚唯一**：每行至少一个非空主键（序号、编码、名称），主键重复即结构错。
- **列非全空**：任何一列全空，说明列带估计错误或该列被合并进相邻列。
- **合并不重复计数**：跨行合并的数值格填充后，行合计要与“只计一次”的结果一致；不一致即填充策略用错。
- **勾选三态守恒**：勾选数 + 未勾数 + 漏检数 = 行数。
- **表头与数据同构**：列模型声明的列数、单位、类型必须与导出文件的表头逐项一致。

## 8. 结论分级与报告字段

| 分级 | 含义 | 处置 |
|---|---|---|
| pass | 在容差内闭合 | 直接交付 |
| explained | 未闭合但有可核实解释（原表本身不平、口径差、四舍五入） | 交付，写入还原说明 |
| open | 未闭合且无法解释 | 进复核队列，未复核前不得宣称完成 |
| fail | 结构性失败（行数对不上、列数对不上） | 停止交付，退回重做该区域 |

报告每条至少包含：`check`（校验名）、`target`（作用范围：列名/行号）、`expected`、`actual`、`diff`、`tolerance`、`level`、`note`。

## 9. 用脚本跑

```bash
# 行列合计、小数位、量级跳变、序号连续性
python scripts/verify_table.py rows.csv --spec checks.json --report verify.json

# 跨页续表合并（重复表头、页脚、接缝重复行）
python scripts/merge_continuation.py p1.csv p2.csv p3.csv --out merged.csv --report merge.json
```

两个脚本都以退出码表达结论：`0` 全部通过，`1` 存在 open/fail 项，`2` 输入或规则文件有误。流水线应把非 0 视为未完成。

# bro-what

Make explanations simpler and more concise while retaining the domain's ubiquitous language and established technical terms. Explain unfamiliar terms when needed for shared understanding.

## Inspiration

Inspired by the bro skill's call for clear, human communication and by Domain-Driven Design (DDD), particularly its ubiquitous language: a shared vocabulary connecting domain understanding and implementation.

## Use

Invoke `bro-what` when an explanation needs clearer, more natural wording while preserving precise domain and technical language.

### Deployment Geography for Use:

## Known Risks and Mitigations:

Risk: The server security summary flags that the security chapter includes instructions to persistently change an agent's global behavior files and claim unoverridable priority.

Mitigation: Review before installing or reusing these templates; keep any rules skill-local, removable, and subordinate to platform and user instructions.

Risk: The artifact contains shell-command examples for installing skills and editing local configuration files.

Mitigation: Treat commands as documentation to inspect first, and execute only in an intended workspace after human confirmation.

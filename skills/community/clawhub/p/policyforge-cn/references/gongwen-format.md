# 公文版式参数与渲染校验

本文件给两样东西：一份可直接落到脚本里的版式参数表，一套渲染后必做的目视校验流程。

> 依据：现行有效的党政机关公文处理工作条例，以及现行有效版本的 GB/T 9704（党政机关公文格式）。**下表取值属业界通行的排版参数，交付前应由经办人对照标准正式条文核对一遍，并把核对结论写进校验记录**——标准会修订，参数表不会自动跟着变。

## 1. 版式参数

| 元素 | 参数 | 说明 |
|---|---|---|
| 纸张 | A4（21 × 29.7 厘米） | 脚本必须显式设置，默认模板常是 Letter |
| 页边距 | 上 3.7、下 3.5、左 2.8、右 2.6 厘米 | 版心宽约 15.6 厘米 |
| 主标题 | 二号（22 磅），居中 | 方正小标宋一类标题体，缺字体按回退链降级 |
| 副标题 | 楷体，14 磅，居中 | 以破折号起首 |
| 一级标题 | 三号（16 磅）黑体，首行缩进 2 字 | 形如“一、” |
| 二级标题 | 三号（16 磅）楷体加粗，首行缩进 2 字 | 形如“（一）” |
| 正文 | 三号（16 磅）仿宋，首行缩进 2 字 | 行距固定值 29 磅 |
| 页码 | 四号（14 磅）宋体，居中，形如“— 1 —” | 用域实现，不写死数字 |
| 表格 | 表头加底纹、跨页重复；列宽与单元格宽同时设置 | 只设一处，Word 会重排 |

首行缩进按“字号 × 2”折算，三号字即 32 磅。

## 2. 字体回退链

按已安装字体择优，找不到就顺位降级，并把降级结果打印出来：

| 角色 | 首选 | 回退顺序 |
|---|---|---|
| 主标题 | 方正小标宋简体 | 方正小标宋_GBK → 华文中宋 → 黑体 |
| 一级标题 | 黑体 | 微软雅黑 |
| 二级标题 | 楷体_GB2312 | 楷体 → 系统同义字体 |
| 正文 | 仿宋_GB2312 | 仿宋 → 宋体 |

降级不是错误，**静默降级才是错误**。脚本要在控制台明确打印每个角色最终用了哪款字体，校验记录里留一行。

## 3. python-docx 的六个坑

1. **中文字体不生效**：只设 `run.font.name` 不会改变中文字形，必须同时设置 `w:rFonts` 上的 `w:eastAsia`（西文与数字走 `w:ascii` 与 `w:hAnsi`）。
2. **页面默认不是 A4**：必须显式设置页宽页高，否则打印时版心全错。
3. **固定行距要设两处**：既要把行距规则设为“固定值”，又要给出磅值；只设其一不会生效。
4. **表格宽度要设两处**：列宽与单元格宽都要设，否则 Word 打开时重排，打印越界。
5. **单元格底纹取值**：用表示透明覆盖的取值，用实心取值会渲染成黑色块。
6. **页码域要包在一个 run 里**：域开始、域代码、域结束三段必须落在同一个 run 内，拆开会导致页码不显示或显示为错误。

## 4. 源文件标记约定

渲染脚本按行首标记识别结构，写法固定：

```text
# 标题                  → 主标题
## ——副标题             → 副标题
## 一、xxx              → 一级标题（“附”开头自动另起一页）
### （一）xxx           → 二级标题
| a | b |               → 表格（第二行须为分隔行）
> 原文摘录              → 引用块（左侧竖线 + 缩进）
- 条目                  → 自动编号项
普通行                  → 正文
【填入：…】             → 自动标红加粗
```

空行会被跳过，不影响结构；但表格与前后段落之间要留空行，否则可能被当成正文。

## 5. 页数预估

渲染前先按字数报页数，避免“说好八页、出来十六页”：

- 三号仿宋、版心 15.6 厘米：每行约 27 字，每页约 22 行，合 600 字/页。
- 表格页按实际行数另算，通常一页表格折算 300–400 字。
- 附表单独起页，至少占一页。
- 报区间并在渲染后回填实际页数；偏差超过三页要说明原因。

## 6. 渲染校验五步

1. **脚本渲染**：生成 `.docx`，记录字数、段落数、表格数与预估页数。
2. **转 PDF**：通过已安装的 Word 另存为 PDF，并刷新域，让页码先算出来；同时读 Word 自身的页数统计。
3. **转 PNG**：按页渲染为图片，缩放系数取 1.7 左右即可看清字形与边距。
4. **抽页检查**：只看五类代表页，不必逐页看（逐页看成本高、收益低）。
5. **回填记录**：预估页数与实际页数、抽页结论、字体降级项、未通过项与处理。

## 7. 五类代表页查什么

| 代表页 | 查什么 |
|---|---|
| 标题页 | 标题居中、字号够大、副标题缩进正确、页码存在 |
| 表格页 | 列宽是否越界、表头底纹是否正常、单元格内文字是否被裁 |
| 含占位符页 | 红色是否醒目、方头括号是否完整、有无换行断裂 |
| 附表页 | 是否另起页、表头是否跨页重复、末行是否被截断 |
| 末页 | 正文是否写完、落款与日期位置是否合理、页码是否连续 |

字体是否真的生效，看正文字形即可分辨：仿宋笔画细而方，宋体横细竖粗，黑体全粗。看到正文是宋体，说明 `w:eastAsia` 没设上。

## 8. 清理与降级

- 校验用 PDF 与 PNG 放临时子目录，交付前删除；删不掉先查是否有预览类进程占用，再重试。
- 用强制方式结束办公软件会留下以波浪号开头的属主文件，需单独清理。
- 临时 PDF 不要生成在交付目录里，避免被误打包。
- **没有 Word 的环境**：只做参数自检（纸张、边距、字体、字号、行距、页码域是否存在），在校验记录里明确写“未完成视觉校验”，不得默认通过。

# 基础排版

| Markdown 条件 | 公众号样式 |
| --- | --- |
| 第一个 `#` 前的首个普通段落 | 文首墨青导言块，全文一次 |
| `# 标题` | 篇章标题 |
| `## 01 标题` | 墨青数字页签 + 章节标题 |
| 其他 `## 标题` | 普通二级标题 |
| `### 标题` | 左竖线小节标题 |
| 普通段落 | 普通正文 |
| `**文字**` | 墨色加粗 |
| `` `文字` `` | 浅底行内代码 |
| `- 项目` | 无序列表 |
| `1. 项目` | 有序列表 |
| `[文字](/路径)` 或完整 URL | 墨青链接文字；草稿保存后不可点击 |
| Markdown 表格 | 浅灰表头 + 细线表格 |

## 提示块

| Markdown 条件 | 公众号样式 |
| --- | --- |
| `> TIP 标题` + 引用正文 | 墨青竖线；标题加粗，正文正常 |
| `> NOTE 标题` + 引用正文 | 灰色竖线；标题加粗，正文正常 |
| `> WARNING 标题` + 引用正文 | 红色竖线；标题加粗，正文正常 |
| `> IMPORTANT 标题` + 引用正文 | 墨色竖线；标题加粗，正文正常 |
| `:::tip[标题]` + 容器正文 | 同 TIP |
| `:::note[标题]` + 容器正文 | 同 NOTE |
| `:::warning[标题]` + 容器正文 | 同 WARNING |
| `:::important[标题]` + 容器正文 | 同 IMPORTANT |
| `:::caution[标题]` + 容器正文 | 同 WARNING |

# 头痛与脑血管病诊疗

## 一、头痛诊疗总则

### 1.1 发病机制识别
| 机制 | 常见病因 |
|-----|---------|
| 颅内外动脉扩张 | 感染、代谢、中毒 |
| 痛觉敏感结构牵拉/移位 | 肿瘤、血肿、脑积水、低颅压 |
| 痛觉敏感组织炎症 | 脑膜刺激性头痛 |
| 脑/颈神经直接受压或炎症 | 三叉/枕神经痛 |
| 眼耳鼻牙病变扩散 | 牵涉性头痛 |

致痛神经递质：P物质、5-羟色胺、组胺、CGRP、VIP、PGE

### 1.2 ICHD-3分类框架
**原发性头痛**：偏头痛、紧张型头痛、三叉自主神经性头痛、其他
**继发性头痛**：头颈外伤、血管疾病、非血管性颅内疾病、物质/戒断、感染、内环境紊乱、结构病变、精神疾病
**痛性脑神经病、其他面痛与其他头痛**

### 1.3 诊疗流程
1. 详细采集病史（时间/性质/部位/频率/诱因/先兆/伴随/家族史/用药史）
2. 适时选用神经影像学或腰穿排除颅内器质性病变
3. **首要任务：区分原发性与继发性**
4. 治疗：
   - 原发性：急性发作治疗 + 预防性治疗（慢性必须足量足疗程）
   - 继发性：病因治疗 + 对症治疗

## 二、偏头痛ICHD-3诊断标准

### 2.1 无先兆偏头痛
需同时满足：
- 头痛至少发作**5次**
- 发作持续**4～72小时**
- 至少符合以下4项中的**2项**：
  1. 单侧
  2. 搏动性
  3. 中、重度
  4. 日常体力活动加重或因头痛避免活动
- 至少符合以下2项中的**1项**：
  1. 恶心和/或呕吐
  2. 畏光和畏声

### 2.2 有先兆偏头痛
需同时满足：
- 至少**2次**发作符合以下标准
- 至少**1个**可完全恢复的先兆：视觉/感觉/言语/运动/脑干/视网膜
- 至少符合以下6项中的**3项**：
  1. 至少1个先兆持续>5分钟
  2. 2个或更多症状连续发生
  3. 每个先兆持续5～60分钟
  4. 至少一个先兆是单侧
  5. 至少一个先兆是阳性的
  6. 先兆伴发或60分钟内出现头痛

### 2.3 慢性偏头痛
- 头痛每月≥**15天**，持续≥**3个月**
- 符合偏头痛标准的头痛至少**5次**
- 每月头痛>8天符合以下任一：
  - 符合无先兆偏头痛标准
  - 符合有先兆偏头痛标准
  - 患者认为的偏头痛发作可被曲普坦类/麦角胺类缓解

## 三、药物过度使用性头痛(MOH)

### 3.1 诊断标准（需同时满足）
1. 原发性头痛患者每月头痛≥**15天**
2. 规律过度服用急性治疗药物≥**3个月**
3. 不能用ICHD-3其他诊断更好解释

### 3.2 药物过度使用天数界定
| 药物类型 | 过度使用标准（每月） |
|---------|-------------------|
| 麦角胺类、曲坦类、阿片类、复合止痛药 | ≥10天 |
| 对乙酰氨基酚、NSAID等非阿片类 | ≥15天 |
| 多种药物混合使用 | 总计≥10天，且每种未单独达标 |

### 3.3 撤药策略
| 策略 | 适用情况 |
|-----|---------|
| 立即撤药 | 曲坦类、麦角胺类、对乙酰氨基酚、阿司匹林 |
| 缓慢撤药 | 阿片类、巴比妥类（防严重撤药症状） |
| 住院治疗 | 巴比妥类过度使用、院外难停药、伴严重抑郁 |
| 门诊治疗 | 自律性高、动机强、非巴比妥类、单药过度使用、无精神障碍 |

### 3.4 预防性治疗
**首选**：托吡酯、A型肉毒毒素局部注射、CGRP抑制剂（瑞玛奈珠单抗）
**备选**：丙戊酸盐、加巴喷丁、阿米替林、文拉法辛、替扎尼定、β受体阻滞剂、氟桂利嗪

### 3.5 戒断症状处理
- 常见：恶心、呕吐、焦虑、睡眠障碍、戒断性头痛、低血压、心动过速
- 持续时间：通常2～10天（平均3.5天，可达4周）
- 对症：甲氧氯普胺止吐，呕吐明显者补液

### 3.6 随访与成功标准
- 撤药后预防性治疗至少随访**1年**
- 成功标准：1年后头痛天数 **<4天/月**

## 四、低颅压性头痛

### 4.1 ICHD-3诊断标准（需同时满足）
1. 符合第3项标准的任何头痛
2. 符合以下1项或2项：
   - 脑脊液压力 <60mmHg
   - 脑脊液漏影像学证据
3. 头痛与脑脊液压力低下/脑脊液漏时间密切相关
4. 不能用其他诊断更好解释

### 4.2 辅助检查特征
**脑脊液**：腰穿压力<60mmHg（部分测不出或"干性穿刺"）
**颅脑MRI**：均一弥漫硬脑膜强化、硬膜下积液/血肿、脑静脉窦扩大、垂体增大、小脑扁桃体下移
**脊髓MRI**：长节段硬脊膜外积液、硬脊膜外静脉扩张

### 4.3 鉴别诊断
需排除：蛛网膜下腔出血、中枢神经系统感染、脑静脉窦血栓、转移性脑膜癌、硬膜下积液/血肿、Arnold-Chiari畸形、肥厚性硬脑膜炎、POTS

## 五、缺血性卒中TOAST分型

### 5.1 五大亚型

**1. 大动脉粥样硬化型(LAA)**（占26%）
- 临床/影像：皮质或脑干/小脑损害；同血管区TIA；梗死直径>1.5cm
- 血管：相关大动脉狭窄>50%，排除心源性

**2. 心源性栓塞型**（占16%）
- 临床/影像：起病急骤，症状迅速达峰；单/多个皮质分散病灶，常超单根血管区
- 证据：必须存在心源性栓子证据

**3. 小动脉闭塞型**（占34%）
- 临床/影像：腔隙综合征，无皮质受累；皮质下/脑干梗死直径<1.5cm
- 排除：无心源性栓子，无同侧大动脉狭窄>50%

**4. 其他明确病因型**
- 动脉夹层、血管炎、烟雾病、高凝状态等

**5. 不明原因型**（占24%）
- 检查不充分/未发现病因/≥2种病因不能确定

## 六、脑血流自动调节与血压管理

### 6.1 正常自动调节范围
- MAP波动于**50～150mmHg**时，脑血管通过舒缩保持血流量恒定

### 6.2 突破上限（MAP > 150mmHg）
- 脑血管阻力已达极限
- 脑血流量线性增加→强制灌注→脑水肿

### 6.3 突破下限（MAP < 50mmHg）
- 脑血管阻力已达最低
- 脑血流量线性减少→脑缺血

### 6.4 高血压患者特殊规则
- 自动调节曲线**右移**（上下限均上移）
- 对低血压耐受能力减弱
- **禁忌急剧降压**，需平稳缓慢

### 6.5 脑缺血耐受
- 血供中断2分钟：脑电活动停止
- 血供中断5分钟：不可逆损伤
- 脑组织几乎无葡萄糖和氧储备

# 头痛与脑血管病详细诊断标准

## 偏头痛ICHD-3诊断标准详细解读

### 无先兆偏头痛鉴别要点
- 需排除：紧张型头痛（双侧、非搏动性、轻度、无恶心）
- 需排除：丛集性头痛（眼眶/颞部、剧烈、伴自主神经症状）
- 注意：儿童偏头痛可双侧，持续时间可更短（1-72小时）

### 有先兆偏头痛先兆类型详解
| 先兆类型 | 典型表现 |
|---------|---------|
| 视觉 | 闪光、亮点、暗点、视野缺损 |
| 感觉 | 针刺感、麻木，通常从手→臂→面部 |
| 言语/语言 | 找词困难、理解困难 |
| 运动 | 肢体无力（需与偏瘫型偏头痛鉴别） |
| 脑干 | 眩晕、耳鸣、复视、构音障碍 |
| 视网膜 | 单眼视觉症状（需排除眼动脉病变） |

### 慢性偏头痛注意事项
- 必须排除MOH（药物过度使用性头痛）
- 需记录每月头痛天数和用药天数
- 与慢性紧张型头痛鉴别

## MOH诊断与撤药详细流程

### 药物过度使用天数计算
- 按月历记录服药天数
- 复合制剂按1天计算
- 不同药物分别计算后判断是否混合使用

### 撤药住院指征详解
1. 巴比妥类药物过度使用（戒断可危及生命）
2. 院外多次尝试停药失败
3. 伴有严重抑郁或自杀倾向
4. 需要静脉用药或神经阻滞
5. 合并严重躯体疾病

### 戒断症状时间线
| 时间 | 常见表现 |
|-----|---------|
| 第1-2天 | 头痛加重、恶心、呕吐、焦虑 |
| 第3-5天 | 症状高峰，可出现低血压、心动过速 |
| 第6-10天 | 症状逐渐缓解 |
| 2-4周 | 少数患者症状持续 |

### 预防性治疗启动时机
- 可在撤药同时启动
- 也可在撤药后头痛稳定后启动
- 首选口服药物需考虑患者合并症

## 低颅压性头痛详细诊断流程

### 典型临床表现
- 直立性头痛（直立15分钟内加重，平卧缓解）
- 可伴：颈部僵硬、耳鸣、听力下降、恶心、视觉模糊
- 严重者可出现意识障碍

### 影像学特征详解
#### 颅脑MRI（5个典型征象）
1. 均一弥漫的硬脑膜强化（最常见）
2. 硬膜下积液或血肿
3. 脑静脉窦扩大
4. 垂体增大
5. 小脑扁桃体下移（类似Chiari畸形）

记忆口诀：SEEPS（Subdural fluid, Enhancement of dura, Engorgement of venous structures, Pituitary enlargement, Sagging of brain）

#### 脊髓MRI
- 硬脊膜外积液（长节段）
- 硬脊膜外静脉扩张
- 高颈髓后方软组织内积液
- 神经根周围积液

### 脑脊液检查要点
-  opening pressure <60mmH2O（注意单位）
- 病程延长后压力可恢复正常
- 细胞数可轻度增加（淋巴细胞为主）
- 蛋白可轻度升高
- 糖和氯化物正常

### 病因分类
| 类型 | 常见原因 |
|-----|---------|
| 自发性 | 硬脊膜撕裂、脑脊液-静脉瘘 |
| 医源性 | 腰穿后、硬膜外麻醉后 |
| 外伤性 | 脊柱外伤 |

## TOAST分型详细判定流程

### 判定步骤
1. 确认缺血性卒中诊断（影像学证实）
2. 完善检查：
   - 头颈CTA/MRA/DSA评估血管
   - 心脏超声（经胸+经食管）
   - 心电图+长程心电监测
   - 血脂、血糖等危险因素评估
3. 按以下流程分型：

### 分型决策树
\`\`\`
是否存在大动脉狭窄>50%？
├── 是 → 是否存在心源性栓塞证据？
│       ├── 否 → LAA型
│       └── 是 → 两种病因均存在→不明原因型（≥2种病因）
└── 否 → 是否存在心源性栓塞证据？
        ├── 是 → 心源性栓塞型
        └── 否 → 是否为腔隙综合征且梗死<1.5cm？
                ├── 是 → 小动脉闭塞型
                └── 否 → 是否存在其他明确病因？
                        ├── 是 → 其他明确病因型
                        └── 否 → 不明原因型
\`\`\`

### 各亚型二级预防要点
| 亚型 | 核心预防策略 |
|-----|-------------|
| LAA | 抗血小板+他汀+控制危险因素±血管干预 |
| 心源性 | 抗凝治疗（华法林或NOAC） |
| 小动脉 | 抗血小板+控制血压血糖 |
| 其他 | 针对具体病因治疗 |
| 不明 | 抗血小板+控制危险因素 |

## 脑血流自动调节临床应用场景

### 急性缺血性卒中血压管理
- 溶栓前：血压需<185/110mmHg
- 溶栓后24h：维持<180/105mmHg
- 未溶栓：允许性高血压，除非>220/120mmHg或有其他靶器官损害

### 高血压脑病
- MAP突破自动调节上限
- 表现为头痛、意识障碍、抽搐、视乳头水肿
- 需紧急降压，但24h内降压不超过25%

### 慢性高血压患者降压注意
- 自动调节曲线右移
- 正常血压范围可能导致脑缺血
- 降压目标需个体化
- 急性期降压需更加谨慎

## Use Case:

External users and agents use this skill to diagnose cross-domain requests and deliver structured plans, analysis, documents, code, or guidance when no narrower specialized skill fits. It is intended for end-to-end problem solving across technology, business, creative, data, operations, finance, legal/compliance, and design contexts.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill has a very broad general-purpose scope and encourages autonomous tool use, which can be risky for file edits, code execution, external data transfer, or sensitive legal, financial, credential, and private-information tasks.

Mitigation: Use it with a sandboxed agent, limit file and network access where possible, and require explicit confirmation before those higher-risk actions.

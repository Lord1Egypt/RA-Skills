## Description:

Daily morning briefing skill. Reads your TASKS.md and memory files, synthesizes a prioritized day plan, and sends it to you via Telegram so you start the day knowing exactly what to do first.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users use this skill to turn local task and memory notes into a concise daily priority briefing delivered through Telegram.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can read task and memory notes and send their contents to Telegram without a clear preview, redaction, or confirmation step.

Mitigation: Review the generated briefing before automation, redact sensitive content, validate the Telegram chat destination, and avoid scheduling until the message content is acceptable.

## Description:

Provides practical guidance for interface visual and interaction design, usability, design systems, WCAG 2.2 accessibility audits, ARIA patterns, and interface templates.

This skill is ready for commercial/non-commercial use.

## Publisher:

[zengfr](https://clawhub.ai/user/zengfr)

### License/Terms of Use:

MIT-0

## Use Case:

Designers and developers use this skill to review or build web and app interfaces, select visual and interaction patterns, and assess usability and accessibility against WCAG and ARIA guidance.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security review flags guidance involving form-data storage, sharing error details, and changes to persistent knowledge files; scan coverage was partial.

Mitigation: Review recommendations before applying them, minimize retained personal data, redact secrets from error details, and confirm proposed persistent knowledge changes.

# 失败模式与兜底

按“错在哪一层”分五类。定位到类别，处置就是确定的，不要凭感觉调参。

## 0. 五类划分

| 类别 | 症状 | 主责通道 |
|---|---|---|
| 采集类 | 图看不清、倾斜、反光、压缩块 | 预处理 |
| 结构类 | 行数/列数不对、合并错、续表断层 | 切分与网格 |
| 字符类 | 数字误读、符号混淆、单位错 | OCR 与字形预判 |
| 语义类 | 编行、编数字、把无当有 | 视觉调用约束 |
| 装配类 | 导出错位、格式丢失、行高截断 | 导出与读回 |

## 1. 采集类

| 症状 | 判定 | 兜底 |
|---|---|---|
| 字高小于 12 px | 长边与字高都低于阈值 | 拒答，给出补拍要求（单页单图、正对、去反光） |
| 明显反光/阴影遮盖数字 | 局部过曝或纯黑 | 该区域标盲区，其余照常还原，盲区交人工 |
| 透视变形（行线不平行） | 纠偏后角度仍 > 1.5° | 不做透视校正（会引入插值伪影），转人工录入建议 |
| JPEG 压缩块导致数字粘连 | 字符边缘锯齿成块 | 提高放大倍数并降低二值化窗口，仍不清则进复核 |
| 手机长截图（高宽比 > 3） | 一次读取必截断 | 按屏切片，每片含完整表头或重叠行 |

## 2. 结构类

| 症状 | 判定 | 兜底 |
|---|---|---|
| 网格检测到 0 条竖线 | 无框线表或浅色虚线 | 回退“行 y 锚点 + 列带”切分 |
| 列带重叠 | 列间距小于一个字宽 | 合并列或改按表头文字中心单独切 |
| 行锚缺失 | 该行无序号也无名称 | 标“无锚”，不进入主表 |
| 合并单元格漏判 | 相邻格无分隔线但被当成两格 | 用跨度矩阵复核，检查文本是否被拆成两段 |
| 跨页接缝丢行 | 序号断点 > 1 | 按重叠行重新缝合，回原图核对接缝区 |
| 表头被当成数据 | 首行数据类型与列类型冲突 | 行锚序列剔除表头行 |
| 合计行被当成数据 | 末行多出一个“合计”文本 | 表尾区提前切出，合计行单独成字段 |

## 3. 字符类

OCR 的错误是**字形误识**，不是幻觉：错值一定与原值共享相似的笔画结构。可预判的模式：

| 误读 | 真值 | 机理 |
|---|---|---|
| `07.16` | `67.16` | 首位字符被切掉 |
| `20:24` | `20.24` | 冒号当小数点 |
| `117L.00` | `1170.00` | 字母当数字 |
| `0 12E` | `102.12` | 空格与指数符号污染 |
| `352.48` | `302.48` | 3 与 0 混淆 |
| `27.00` | `27.60` | 尾数丢失 |

判定规则：**同量级但差一位、丢首位、分隔符错位**，先判 OCR 误读，做法是回到原图放大定点复核，而不是断言数据错。反之，**量级相差 10 倍以上或方向反转**，先判读错，不要当成业务异常。

## 4. 语义类（幻觉）

这是最危险的一类，因为输出通顺、自洽、看起来专业。三种典型：

1. **整表编造**：让模型“转录整张表”，它按表格该有的样子生成一套完整数据，行数甚至多于真实行数。识别特征：项目名通顺、行数远超行锚数、合计能凑整。
2. **数字置换**：只改数字不改结构，`25.00` 变 `20.00`、`76` 变 `70`。识别特征：与 OCR 同位置值冲突，且冲突值量级相同。
3. **存在性错误**：把“表里没有的项”说成有（或反之）。这类无法靠算术校验发现，只能靠“存在性问答 + 全文检索”裁定。

处置：

- 禁止“整表自由转写”，一律改为结构化问答（列归属／跨度／单位）。
- 存在性问题改为对每一项单独问“有／没有”，再用 OCR 全文检索做真相源。
- 缩略图拼版（多图缩小拼一张）**只能用于页面类型分类，不得用于数值读取**：小图里数字只剩几个像素，模型会按上下文“补齐”成一套自洽的假数值，且比编行更隐蔽。判定含数值的区域，必须回到单张原图，放大 ≥ 1.8 倍，必要时上下切段。
- 数值复核前先取基线（同表其他列、同批其他页、或用户提供的既有台账）。基线既是校验锚，也能立刻暴露幻觉：与基线全不吻合而拼版读数为“整整齐齐一套”时，基本可判假。

## 5. 装配类

| 症状 | 判定 | 兜底 |
|---|---|---|
| 导出后列错位 | 列模型与写入顺序不一致 | 以列模型 key 排序写入，不按字典顺序 |
| 数值变文本 | 写入了字符串 | 重设单元格类型与数字格式，再读回一次 |
| 长文本被截断 | 固定行高装不下 | 行高按该行最长单元格实算 |
| 字体回退成默认字体 | 未显式指定字体名 | 遍历单元格校验字体名，非空且一致 |
| 保存成功但内容不全 | 只信了保存返回值 | 读回校验行数、列数、合计、sheet 齐全 |
| 目标文件被占用 | 存在锁文件或保存报权限错 | 另存新名，保留临时文件，不要反复重试 |

## 6. 兜底决策树

1. 校验全通过 → 交付。
2. 校验未通过、但差额可定位到单格 → 回原图定点复核该格，改后重跑全量校验。
3. 校验未通过、差额无法定位 → 行数记账先对齐；行数对不上优先修结构，不要修数值。
4. 结构修不好（图像质量不足） → 停止自动还原，交付“已还原部分 + 待人工区域清单 + 裁剪图”。
5. 疑点比例超过两成 → 整批判不合格，退回补拍或改人工录入，说明具体不达标项。

## 7. 明确禁区

- 不用缩略图拼版读任何数值。
- 不按上下文补值、不按合计反推单格真值后直接写入。
- 不为了闭合而修改合计行。
- 不把“模型说读对了”当作验收证据。
- 不引用脱离场景的准确率数字；验收口径只有交叉校验通过率与未闭合项清单。

## Description:

Comprehensive BubbleTea TUI code review for terminal applications covering charmbracelet/bubbletea, lipgloss, bubbles, and Wish SSH code, with optional concurrent review by area.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and reviewers use this skill to perform structured reviews of Go terminal UI applications built with Bubble Tea, Lip Gloss, Bubbles, or Wish SSH. It guides scope selection, technology detection, issue verification, and Markdown review reporting.

### Deployment Geography for Use:

Global

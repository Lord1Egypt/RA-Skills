# 技术面择时分评分细则

> 源自 BigA 的择时分系统，是独立于 BigA 综合评分的"买卖时机"指标

## 评分维度（-10 ~ +10）

### 1. 趋势方向（权重40%，-4 ~ +4）
| 条件 | 得分 |
|------|:----:|
| MA5>MA10>MA20>MA60 多头排列，趋势向上 | +2~+4 |
| MA系统交错，方向不明 | -1~+1 |
| MA5<MA10<MA20<MA60 空头排列，趋势向下 | -2~-4 |

### 2. 量价关系（权重25%，-3 ~ +3）
| 条件 | 得分 |
|------|:----:|
| 放量上涨，价量配合 | +2~+3 |
| 缩量调整，量价正常 | 0~+1 |
| 缩量上涨，动能不足 | -1~0 |
| 放量下跌，资金出逃 | -2~-3 |

### 3. 技术指标（权重20%，-2 ~ +2）
| 条件 | 得分 |
|------|:----:|
| MACD零轴上方金叉，KDJ健康 | +1~+2 |
| RSI 30-70，指标中性 | -1~+1 |
| MACD死叉/顶背离，KDJ超买死叉 | -1~-2 |

### 4. 支撑压力位置（权重15%，-1 ~ +1）
| 条件 | 得分 |
|------|:----:|
| 回调至MA20/MA60支撑位获得支撑 | +0.5~+1 |
| 在均线之间运行 | -0.5~+0.5 |
| 跌破关键支撑位 | -0.5~-1 |

## 评分使用

### 总分判定
| 择时分 | 信号 | 含义 |
|:------:|:----:|------|
| ≥+6 | 🔥 **买入** | 技术面共振强信号 |
| +3~+5 | ✅ **可买** | 回踩确认/启动初现 |
| -2~+2 | 👀 **持有** | 方向不明，等待 |
| -5~-3 | ⚠️ **减仓** | 趋势转弱，控制仓位 |
| ≤-6 | 🛑 **离场** | 明确卖出信号 |

### 短线入场信号组合
| 入场就绪度 | 启动强度 | 风控警告 | 结论 |
|:--------:|:--------:|:--------:|------|
| ≥6 | — | 无 | 📩 **接近买点** — 回踩均线+缩量止跌 |
| ≥8 | ≥2 | 无 | 🔥🔥 **最佳买点** — 趋势启动+回踩确认 |
| — | ≥2 | 无 | 🔥 **启动信号** — 均线金叉/放量突破 |
| — | ≥2 | 有(涨幅过高) | ⚠️ **追高风险** — 已涨太多等回调 |
| ≤3 | — | — | ⏳ **等待** — 时机未到 |
| — | — | 恐慌放量急跌 | 🛑 **不接飞刀** — 放量急跌中 |
| — | — | 5日跌幅>15% | 🛒 **超跌关注** — 等企稳再判断 |

## 注意
- 择时分 ≠ BigA总分，两者正交使用
- BigA回答"股票好不好"，择时分回答"现在买不买"
- 择时分是动态指标，每日更新

# 风险预警模板

## 一、预警级别

| 级别 | 标识 | 说明 | 触发条件 |
|------|------|------|----------|
| 低风险 | 🟢 | 信用良好 | 综合评分≥80分 |
| 中等风险 | 🟡 | 存在轻微问题 | 综合评分60-79分 |
| 较高风险 | 🟠 | 存在明显风险 | 综合评分40-59分 |
| 高风险 | 🔴 | 存在重大风险 | 综合评分<40分或硬终止 |

## 二、预警模板

### 🟢 低风险预警

```
✅ 风险预警：低风险

企业：{企业名称}
综合评分：{X}分

【核查结论】
该企业信用状况良好，五维核查均无明显异常。

【推进建议】
建议推进业务合作。
```

### 🟡 中等风险预警

```
⚠️ 风险预警：中等风险

企业：{企业名称}
综合评分：{X}分

【核查结论】
该企业存在以下轻微风险项：
{风险项1}
{风险项2}

【推进建议】
建议谨慎推进，必要时补充其他尽调材料。
```

### 🟠 较高风险预警

```
🚨 风险预警：较高风险

企业：{企业名称}
综合评分：{X}分

【核查结论】
该企业存在以下明显风险项：
{风险项1}
{风险项2}

【推进建议】
建议充分评估风险后再决定是否推进。
```

### 🔴 高风险预警（硬终止）

```
🚫 风险预警：高风险【硬终止】

企业：{企业名称}
综合评分：{X}分

【触发硬终止条件】
{硬终止项1}
{硬终止项2}

【核查结论】
该企业存在重大风险，不建议推进。

【替代方案】
建议更换合作对象或待企业完成信用修复后再评估。
```

## 四、预警推送规则

1. **即时推送**：发现硬终止项立即推送
2. **每日汇总**：非紧急风险每日汇总推送
3. **阈值触发**：评分变化超过10分触发推送
4. **定期复查**：高风险企业建议30天内复查

## Description:

Provides code review guidance focused on quality, security, performance, testing coverage, and documentation.

This skill is ready for commercial/non-commercial use.

## Publisher:

[mtsatryan](https://clawhub.ai/user/mtsatryan)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to review code for maintainability, security vulnerabilities, performance issues, test coverage gaps, and documentation quality.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Code reviews may expose private or sensitive source code to the reviewing agent.

Mitigation: Use the skill only on code the user intends the agent to inspect.

Risk: Review feedback can be incomplete, incorrect, or inappropriate for the project context.

Mitigation: Treat findings as guidance and have maintainers verify issues and proposed fixes before applying changes.

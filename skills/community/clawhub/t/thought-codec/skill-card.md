## Description:

Bilingual AI skill library for turning abstract intent into executable workflows and compressing repeated practice into reusable skills.

This skill is ready for commercial/non-commercial use.

## Publisher:

[cottzz](https://clawhub.ai/user/cottzz)

### License/Terms of Use:

MIT

## Use Case:

Developers, knowledge workers, and agent users use ThoughtCodec to select bilingual skills that expand goals into architecture, SOPs, rules, code abstractions, or personal methodology systems. The skill helps structure human review points before changes become durable workflow or skill updates.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated rules or skill updates may preserve sensitive transcripts, secrets, client data, or proprietary material if that material is supplied as input.

Mitigation: Use explicit scope, avoid private or proprietary inputs for public skills, and keep sensitive material local-only when it must inform rules.

Risk: Generated patches, reusable rules, or workflow changes may incorrectly alter local skill files or important work practices.

Mitigation: Review proposed patches and rule changes before accepting them, and require human confirmation before promoting outputs into durable workflows or production code.

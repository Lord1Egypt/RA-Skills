## Description:

Use before creating or moving any durable workspace files, folders, scripts, project state, monitor state, cron-backed artifacts, outputs, or project-specific documentation.

This skill is ready for commercial/non-commercial use.

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agent operators use this skill to keep durable workspace files organized by project, with generated outputs and state stored under each project's local data folder.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may encourage moving scattered project files into a project-local structure in an existing workspace.

Mitigation: Review proposed path changes before applying them and update affected references or commands when files are moved.

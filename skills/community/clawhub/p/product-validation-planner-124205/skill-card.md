## Description:

Help users with Ask HN: I Need Help for a Product by creating practical workflows, artifacts, checklists, analysis, or implementation support.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Creators and communicators use this skill to turn a product-help request into a concrete plan, artifact, checklist, analysis, code change, or decision-support output. It emphasizes clear assumptions, success criteria, validation, and visible follow-up risks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad implicit invocation keywords can activate the skill outside focused product-validation or Ask HN product-help requests.

Mitigation: Narrow the trigger keywords or disable implicit invocation so the skill activates only for explicit product-validation or Ask HN product-help requests.

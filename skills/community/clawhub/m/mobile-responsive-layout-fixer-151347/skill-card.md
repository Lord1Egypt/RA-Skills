## Description:

Helps frontend developers, designers, startup teams, and maintainers diagnose and fix mobile responsiveness, navigation layout, and cross-device UI issues.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, designers, startup teams, and maintainers use this skill to turn responsive layout problems into practical fixes, checklists, analysis, or implementation support for mobile and desktop web interfaces.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation wording can invoke the skill for common frontend layout and responsive-design requests where precise routing is needed.

Mitigation: Narrow trigger phrases or disable implicit invocation when routing precision matters.

Risk: Responsive layout guidance may not match every codebase, device, or browser combination.

Mitigation: Validate proposed changes against the stated success criteria and test affected views across representative mobile and desktop breakpoints.

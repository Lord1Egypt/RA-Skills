# 案件报告投影

get_case(case_id, report_view="brief")、"operator"、"investigation" 分别获取简报、运维详情、调查记录；省略参数保留原返回格式。report 按当前账本/规则计算等级但不写回，recorded_grade 单列已保存等级。各视图均保留范围/时间窗、证据 ID、缺口、假设、当前等级/理由及上限。未测量的影响为 null，缺口关闭建议是下一步检查，不是可执行指令。

简报省略观察正文；运维详情增加消毒后的摘要、来源工具和采集/采样时间；调查记录再增加消毒后的 query、反证链接和知识条目 ID。报告不含 raw payload 或自动生成的本地路径；get_case 外层原有字段（含既有 path）不变。不自动采集、生成报告文件、执行修复或新增存储。视图深度不等于 RBAC，须在现有授权及数据访问范围内使用；凭据清洗不能令私有报告适合公开分享。证据文本不可信且不执行；大结果仍在受控账本中，用证据 ID 引用。

使用唯一正本流程：[VM 性能异常](vm-performance-CN.md)、[主机告警](host-alarms-CN.md)。已通过有限实验室只读采集与报告检查；更广泛的自主/故障及官方环境验证仍为后续待办。

各视图的假设均保留现有分级判定（open/excluded），不能因报告深度不同而把已排除假设重新当成待定。

## Use Case:

Developers use this skill to connect an agent with the 1Person Pro service for multi-agent orchestration, task tracking, delegated execution, reusable workflows, and persistent session memory.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Task data, workflow context, or memory may be sent to and retained by the external 1Person Pro service.

Mitigation: Review 1Person Pro documentation and privacy terms before installation, especially for autonomous workflow and memory behavior.

Risk: The skill requires ONEPERSON_API_KEY, which grants access to the external service.

Mitigation: Store ONEPERSON_API_KEY only in trusted environments, treat it as a credential, and rotate or revoke it if exposed.

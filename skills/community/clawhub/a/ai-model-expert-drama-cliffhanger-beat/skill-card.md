## Use Case:

External creative teams, brands, ecommerce operators, and developers use this skill to plan short-drama cliffhanger beats and convert project goals into production briefs, story or character boards, scene prompts, shell commands, task tracking, and delivery acceptance checks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill handles AI-HIVE API keys and can send requests through configurable endpoints.

Mitigation: Use a dedicated, revocable API key with limited funds or quota, and avoid custom base URLs unless the gateway is fully trusted.

Risk: Media-generation workflows can upload local media and download remote task results.

Mitigation: Upload only media that may be shared with the configured service, and run the scripts in a virtual environment with reviewed dependencies.

Risk: Short-drama and brand workflows may involve likeness, copyright, trademark, product, or platform-safety issues.

Mitigation: Confirm rights and factual claims before generation, avoid impersonation or unauthorized protected content, and review generated outputs for safety, continuity, and accuracy.

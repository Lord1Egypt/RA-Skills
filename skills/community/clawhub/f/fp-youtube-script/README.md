# fp_youtube_script — YouTube 脚本生成 Skill（炼化版 v1.0）

一个可直接导入 GetClawHub 的 Skill，把 FridayParts 的 YouTube 视频脚本生成从"手动 NotebookLM + 逐句人工验证（2-4小时）"压缩到"输入主题 → 结构化脚本 → 抽查（30-45分钟）"。

**核心特点：内置 5 条技术准确性规范**，让 AI 第一次输出就避开"过于绝对"的技术表述——这正是你们人工二次验证时反复纠正的问题。

## 🚀 怎么用（3 步）

1. **导入**：照 `docs/如何导入GetClawHub.md`，把 `skill/SKILL.md` 导入 GetClawHub。
2. **测试**：用 `examples/` 里的水泵恒温器主题跑一遍，对照样例看质量。
3. **验证**：用 `reference/人工验证checklist.md` 抽查输出，过了就能投产。

## 🎯 内置的 5 条技术准确性规范

这是 Skill 区别于普通"脚本生成"的关键。从你们现有 `water pump & thermostat` 脚本的二次验证逆向提炼：

1. **禁止绝对化用词** —— 一定/肯定/绝对/always/never → 通常/可能/usually/can
2. **不排除其他可能性** —— "这就是X故障" → "重点怀疑X，但也排查Y和Z"
3. **检查操作必须有安全前提** —— 靠近机器前"熄火、拔钥匙、等停转"
4. **故障判断留有余地** —— 漏液要"确认真正漏点，可能是附近软管"
5. **术语准确统一** —— weep hole/impeller 正确，恒温器不混用"节温器"

`examples/对比说明_规范生效验证.md` 里逐条证明了这些规范在实际输出中生效。

## 📝 关于运营的 NotebookLM SOP

SOP 文件暂缺**影响不大**。这个 Skill 已从现有脚本逆向出最关键的部分（输出格式 + 技术准确性规范）。

SKILL.md 的 System Prompt 里预留了三个**可扩展占位区**：
- `[资料来源]` —— 运营固定参考的维修手册/技术网站/产品库
- `[品牌词规范]` —— 品牌词统一写法、禁用词
- `[额外验证项]` —— 运营内部的其他检查标准

拿到 SOP 后或测试发现问题时，往对应区块填内容即可，无需重写整个 Skill。

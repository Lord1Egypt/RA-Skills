# Country module: Germany

Use this file when the intake label language is German. It sets **display
labels** only. Keys, option values (`caseFile`, `surveyProtocol`,
`conservation`, `survey`, `pass`, `defect`, …) and tool names stay as in the
rest of the skill. This skill does not give legal advice. What a case must
record, who may sign, and which interval applies are intake answers from the
business, not a reading of professional rules.

## Notes

The lists are the book the manager works from. Keep any expert layout, court
or insurer form, and any drawing on a photo or plan, in the tools the studio
already uses for that work. This case file stores the findings, the photographs
and the deadline beside them.

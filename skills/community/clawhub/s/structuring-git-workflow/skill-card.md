## Description:

Use when working in a git repository and about to start new work, complete a module, commit, push, merge, or rebase.

This skill is ready for commercial/non-commercial use.

## Publisher:

[yiiknow](https://clawhub.ai/user/yiiknow)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and coding assistants use this skill to structure Git work with branch discipline, clear commit messages, commit prompts at module boundaries, and safety checks before risky Git operations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may prompt frequently about branches, commits, and safety checks in Git repositories.

Mitigation: Review or disable the skill if that level of workflow coaching interferes with a project's established Git process.

Risk: Git workflow guidance can be incorrect if a project has its own branching or commit conventions.

Mitigation: Follow project-level guidance such as CLAUDE.md or CONTRIBUTING.md when it differs from the skill defaults.

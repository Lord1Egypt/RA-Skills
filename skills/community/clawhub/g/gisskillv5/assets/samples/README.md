# 样例数据库

存放GIS测试样例数据，供原子Skill和Agent测试使用。

## 目录说明

此目录存放可直接用于测试的样例文件：

| 类型 | 文件名 | 格式 | 用途 |
|------|--------|------|------|
| 矢量 | sample_boundary.shp | ESRI Shapefile | 拓扑修复/空间分析测试 |
| 栅格 | sample_dem.tif | GeoTIFF | 栅格分析/坐标转换测试 |
| 点云 | sample_scan.las | LAS 1.4 | 点云分类/滤波测试 |
| CAD | sample_plan.dwg | DWG 2018 | DWG↔GIS转换测试 |
| 三维 | sample_building.3dtiles | 3D Tiles | 三维单体化测试 |

> 注: 实际样例数据因文件大小限制未打包。
> 可在部署时替换为实际项目测试数据。

# Managed Subclip workflow

Subclip supplies the bundled skills, approved runtime dependencies, and project lifecycle. Read available references through `read_subclip_skill`; no skill/package installation, standalone CLI, setup scripts, arbitrary filesystem paths, or provider API keys are available inside a layer.

Use native Subclip tools for media/audio import, metadata, speech generation with the selected provider, registry discovery, source validation, project frame inspection, and export. Ask only for missing creative requirements and continue with the current project. Import resources into the appropriate library before binding their managed URLs; use a supported alternative if a resource cannot be made available.

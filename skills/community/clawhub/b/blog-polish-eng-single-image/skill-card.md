## Description:

Polish a technical blog draft into a 1000-1200 word, 4-5 section en-US article, preserve technical terms/code, and generate one consistent hero image prompt.

This skill is ready for commercial/non-commercial use.

## Publisher:

[j3ffyang](https://clawhub.ai/user/j3ffyang)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and technical writers use this skill to turn rough or translated technical markdown drafts into publishable en-US blog articles while preserving code, commands, paths, URLs, and product details. It also produces one matching hero image prompt and PNG path for the article.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill targets en-US technical blog polishing and does not advertise language selection.

Mitigation: Use it when en-US output is desired; choose or modify another workflow when multilingual output is required.

Risk: Generated hero images may not match strict publication or brand requirements if image generation settings are not controlled.

Mitigation: Review the hero prompt and generated PNG before publication, and provide explicit style, background, and aspect ratio inputs when consistency matters.

Risk: Polishing sparse drafts can accidentally overstate or reshape technical claims.

Mitigation: Review the final article against the source draft, especially code, commands, paths, URLs, benchmarks, and product claims.

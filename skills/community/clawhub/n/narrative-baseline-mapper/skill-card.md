## Description:

Maps current owned messaging surfaces into a dated narrative baseline, labels each surface line by evidence source, compares it against the intended message or existing canon, and freezes a drift baseline for later evaluation.

This skill is ready for commercial/non-commercial use.

## Publisher:

[aaron-he-zhu](https://clawhub.ai/user/aaron-he-zhu)

### License/Terms of Use:

MIT-0

## Use Case:

Marketing, product, and narrative teams use this skill at the start of a repositioning or TALE Trace workflow to inventory owned messaging surfaces and expose gaps against an intended message or existing canon.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may process owned URLs or pasted marketing copy supplied by the user.

Mitigation: Use only surfaces the user owns or text the user is authorized to provide; avoid third-party or closed-platform content unless the user provides the text directly.

Risk: Baseline notes and claim proposals may be written into project memory after approval.

Mitigation: Confirm saving before any memory write and review baseline notes or claim proposals before downstream reuse.

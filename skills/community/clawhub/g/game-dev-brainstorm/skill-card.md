## Description:

Guides developers through a structured six-phase game concept brainstorming process using MDA, verb-first design, and mashup methods.

This skill is ready for commercial/non-commercial use.

## Publisher:

[toilanguyen2910](https://clawhub.ai/user/toilanguyen2910)

### License/Terms of Use:

MIT-0

## Use Case:

Game developers and creators use this skill to turn inspirations, player emotion targets, and production constraints into a scoped game concept with a pitch, core loop, design pillars, player profile, MVP scope, and next steps.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated concept notes may contain incorrect assumptions or impractical scope recommendations.

Mitigation: Review and refine the generated concept before using it for production planning or downstream game-development skills.

Risk: On platforms with file-writing support, the skill may save brainstorming output into the project workspace.

Mitigation: Confirm the intended output path and review the generated Markdown before committing or using it as project source material.

## Description:

Test skills via TDD in fresh subagents

This skill is ready for commercial/non-commercial use.

## Publisher:

### License/Terms of Use:

## Use Case:

Developers use this skill to evaluate Claude skills by comparing baseline and skill-enabled behavior in fresh conversations, then testing guardrails with adversarial prompts.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Test outcomes and scores can vary with the model, prompts, and scenario setup.

Mitigation: Record the model and exact prompts, use fresh instances for each test, and review the evidence behind reported scores.

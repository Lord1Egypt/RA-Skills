# 第02课 变量与类型

> 老孟带你学中文编程 · 第 02 课　|　语言面 ZHC-LANG 2.0　|　源码 `示例/第02课_变量与类型.zc`
> 运行：`python -X utf8 zhc.py 示例/第02课_变量与类型.zc --run`

## 一、本课目标

掌握 11 个类型里最常用的 4 个（整数、浮点、文本、逻辑），分清 `定义` 和 `设`，会做四则运算。

## 二、语法要点

| 写法 | 说明 |
|---|---|
| `定义 名字 为 类型 初值` | 第一次声明，必须带初值 |
| `设 名字 为 新值` | 修改已有变量，**不能再用 定义** |
| `整数` / `浮点` / `文本` / `逻辑` | int64 / double / str / bool |
| `+ - * / %` | 四则与取余；整数除整数结果还是整数 |

## 三、完整代码

```zc
# 第02课 变量与类型
# 定义 = 第一次给变量取名并给值；设 = 修改已有变量的值。

定义 学生姓名 为 文本 "小孟"
定义 年龄 为 整数 18
定义 身高 为 浮点 1.75
定义 是否及格 为 逻辑 真

输出 "姓名：", 学生姓名
输出 "年龄：", 年龄
输出 "身高：", 身高
输出 "是否及格：", 是否及格

# 用 设 改值，不能再用 定义（重复定义会报 E301）
设 年龄 为 年龄 + 1
输出 "过了一年，年龄变成：", 年龄

# 一条定义里“类型在前/在后”两种写法，当前内核只接受后一种：
#   可以写：定义 总分 为 整数 600
#   不要写：定义 整数 总分 为 600（变量名会与类型名撞车，报 E012）
定义 总分 为 整数 600
输出 "总分：", 总分

# 浮点参与运算，结果仍是浮点
定义 半身 为 浮点 身高 / 2
输出 "身高的一半：", 半身
```

## 四、运行结果

```text
姓名：小孟
年龄：18
身高：1.75
是否及格：真
过了一年，年龄变成：19
总分：600
身高的一半：0.875
```

## 五、易错点

- `定义 年龄 为 18` 这种省略类型不合法，变量名和类型词都得写全。
- 重复 `定义` 同名变量报 `[E301]`，改值请用 `设`。
- 类型词只能写在变量名**后面**（`定义 总分 为 整数 600`）；写成 `定义 整数 总分 为 600` 会把「整数」当成变量名，报 `[E012]` 变量名与类型名相同。
- 整数相除会丢小数：`225 / 3` 得 `75`，要小数就先把参与运算的量定义成 `浮点`。

## 六、动手练习

1. 定义两个整数并输出它们的和、差、积、余数。
2. 用 `浮点` 重新算一次平均分，观察结果差异。
3. 把 `设 年龄 为 年龄 + 1` 改成 `定义 年龄 为 年龄 + 1`，看报什么错。

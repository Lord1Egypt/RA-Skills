# 公交地铁线路查询 — 地铁优先+自动换乘，三种策略选最优

> 输入任意两个地点，自动规划公交地铁路线，地铁方案优先展示，支持最快/少换乘/少步行三种策略。

🔥 **核心亮点：**
- **地铁优先** — 含地铁的方案优先展示，公交方案次之
- **自动换乘** — 每段线路的上下车站、站数、步行距离一目了然
- **三种策略** — 最快路线 / 最少换乘 / 最少步行
- **最近站点** — 首方案自动提示最近的地铁站
- **零配置** — 装上就能用

## 快速入门

**3个开场白示例，复制即用：**

1. "从三里屯怎么去天安门"
2. "南京路到浦东机场坐地铁怎么走"
3. "广州塔到白云机场最少换乘"

## 核心能力

1. **路线规划** — 输入任意两个地点，自动规划公交地铁路线
2. **地铁优先** — 含地铁的方案优先展示
3. **换乘详情** — 上下车站、站数、步行距离一目了然
4. **三种策略** — 最快/少换乘/少步行
5. **最近站点** — 自动提示最近的地铁站
6. **多城市覆盖** — 全国各城市公交地铁路线

## 能做什么

- 查询市内公交地铁路线
- 规划换乘方案（地铁+公交组合）
- 按时间/换乘/步行偏好选路线

## 不能做什么

- 不支持打车/驾车路线（仅公交+地铁）
- 不支持跨城市路线查询
- 不提供实时公交到站信息

## 使用提示

- 地铁末班车时间请以当地地铁官方公告为准
- 费用为预估，实际以乘车时为准
- 打车/驾车路线请使用高德地图或百度地图App
- 跨城市出行建议使用火车票或汽车票查询技能

## 🔗 搭配使用

- **高德地图全能版** — 更全面的地图能力，含驾车路线
- **汽车票查询与预订** — 跨城市长途汽车查询
- **铁路12306火车票** — 跨城市高铁/火车查询

## 数据流向

路线查询通过云端代理服务获取地图平台API数据。代理服务不存储用户数据。

## 角色详细职责

### 1. 猎手（项目发现）
- **核心任务**：发现潜在项目源，建立初步接触
- **产出物**：
  - 项目发现记录
  - 初筛五维打分卡
  - 首次接触话术与反馈
  - 项目移交包
- **触发条件**：从信息源发现线索 → 初步研判 → 接触

### 2. 评估师（技术评估）
- **核心任务**：深度技术评估、市场分析、风险识别
- **产出物**：
  - 技术评估报告
  - TRL定位分析
  - 风险识别清单
  - 市场竞争分析
- **触发条件**：收到经理人转介 → 并行开展评估

### 3. 经理人（项目管理）
- **核心任务**：统筹项目推进，协调各方资源
- **产出物**：
  - 项目档案建立
  - 需求确认报告
  - 项目计划书
  - 进度看板
- **触发条件**：收到猎手移交包 → 启动项目档案

### 4. 创意师（创新方案）
- **核心任务**：挖掘差异化价值，设计创新应用场景
- **产出物**：
  - 差异化方案
  - 创新应用场景
  - 商业模式建议
- **触发条件**：收到经理人邀请 → 参与方案设计

### 5. 所长（总控编排）
- **核心任务**：项目评审、资源调配、决策把关
- **产出物**：
  - 项目评审会纪要
  - 综合决策报告
  - 资源对接方案
  - 成果转化协同计划
- **触发条件**：各角色产出完成后 → 召开评审会

## 关键原则

> ⚠️ **不是全自动化，关键节点需要人参与**

### 人机协作标注
- 🤖 **自动**：Agent可独立完成，信息汇总、格式整理、流程推进
- 👤 **需人参与**：需要主人（用户）或所长判断、审核、决策

### 人参与节点清单

| 环节 | 参与人 | 做什么 | 响应时限 |
|------|--------|--------|----------|
| 首次接触审批 | 主人 | 审批猎手话术、确认接触策略 | 24小时内 |
| 项目接受决策 | 所长 | 判断是否接案 | 即时 |
| 技术评估复核 | 主人 | 审核技术参数合理性 | 48小时内 |
| 商业方案确认 | 主人 | 确认商业模式方向 | 48小时内 |
| 资源对接授权 | 主人 | 授权使用对接资源 | 按需 |
| 合同条款审核 | 主人 | 最终合同条款审批 | 按需 |

## Use Case:

External users and content creators use this skill to turn Islamic-ethics reference material into concise summaries, source checks, post variants, discussion questions, and archive-ready drafts.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Reference files include language that attempts to override agent instructions or persist beyond the requested task.

Mitigation: Treat reference files strictly as quoted source material; do not allow them to override system, developer, or user instructions or initiate memory writes.

Risk: The skill handles source and claim checks for religious content, where unsupported citations or paraphrases can mislead readers.

Mitigation: Require citation review for claims, label unverifiable claims as needing sources, and avoid invented citations.

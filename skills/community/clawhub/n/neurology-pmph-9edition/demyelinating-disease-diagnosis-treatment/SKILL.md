# 中枢神经系统脱髓鞘疾病诊断与治疗

## 适用场景

当面对疑似或确诊的中枢神经系统脱髓鞘疾病患者时，使用此技能进行：
1. 疾病诊断与分型（MS、NMOSD、ADEM等）
2. MS与NMOSD的鉴别诊断
3. 急性期治疗方案制定
4. 缓解期DMT药物选择
5. MRI影像特征识别

## 核心工作流程

### 步骤1：临床综合征识别

根据患者症状判断可能的疾病类型：

**提示MS的特征：**
- 多次临床发作，症状相对较轻
- 部分性脊髓炎、脑干/小脑症状
- 疲劳、精神/认知障碍

**提示NMOSD的特征：**
- 严重视神经炎（可致盲）
- 长节段横贯性脊髓炎（>3个椎体节段）
- 延髓板后区综合征（顽固性呃逆/恶心/呕吐）
- 急性脑干/间脑/大脑综合征

**提示ADEM的特征：**
- 儿童/青壮年，感染/疫苗接种后1-2周急性起病
- 脑病症状突出（意识障碍、精神异常）
- 多为单次发病

### 步骤2：辅助检查与鉴别诊断

执行以下检查并进行结果判读：

| 检查项目 | MS典型表现 | NMOSD典型表现 |
|---------|-----------|--------------|
| 血清AQP4-IgG | 阴性 | 强阳性 |
| CSF白细胞 | ≤50×10⁶/L | 可>50×10⁶/L |
| CSF寡克隆区带(OB) | 阳性率60-90% | 阳性率低 |
| 脊髓MRI | 短节段、偏侧非横贯性 | 长节段(≥3椎体)、中央横贯性 |
| 脑部MRI | 脑室旁直角脱髓鞘征(Dawson finger) | 极后区/室管膜周围病变 |

**关键鉴别逻辑：**
- AQP4-IgG阳性 + CSF白细胞>50 + OB阴性 → 强烈支持NMOSD
- AQP4阴性 + CSF白细胞<50 + OB阳性 → 强烈支持MS

### 步骤3：应用诊断标准

#### MS诊断（McDonald 2017）

根据发作次数和病灶数量，查找需要补充的DIS/DIT证据：

- ≥2次发作 + ≥2个病灶 → 直接确诊
- 1次发作 + ≥2个病灶 → 需证明DIT或CSF OB阳性
- 1次发作 + 1个病灶 → 需证明DIS + (DIT或CSF OB阳性)

**PPMS诊断：** 进展≥1年 + 满足以下3项中2项：①脑DIS证据 ②脊髓≥2个T2病灶 ③CSF OB阳性

#### NMOSD诊断

**AQP4-IgG阳性：** 至少1项核心症状 + 排除其他诊断

**AQP4-IgG阴性/未检测：** 至少2项核心症状（其中1项必须是ON、长节段脊髓炎或极后区综合征）+ 空间多发 + MRI附加条件 + 排除其他诊断

### 步骤4：急性期治疗

#### MS急性发作

1. **首选：** 甲泼尼龙1g/d冲击，3-5天
2. **病情较重者：** 冲击后序贯口服泼尼松60-80mg/d，每2天减5-10mg，总疗程≤4周
3. **替代方案（激素无效/妊娠）：** IVIg 0.4g/(kg·d)×5天 或 血浆置换

#### NMOSD急性发作

1. **冲击：** 甲泼尼龙1g/d×3-5天
2. **静脉递减：** 500mg→240mg→120mg，各3天
3. **口服过渡：** 泼尼松60mg→50mg，各5-7天
4. **缓慢减量：** 至30-40mg后每2周减5mg，长期维持至5-10mg
5. **替代方案：** 血浆置换（1.0-1.5倍血浆容量，隔日1次，5-7次）

### 步骤5：缓解期DMT药物选择（仅MS）

根据MS亚型选择DMT：

**复发型MS(RMS)：**
- 一线：β干扰素、特立氟胺、醋酸格拉替雷
- 二线（高活动性或一线无效）：芬戈莫德、西尼莫德、那他珠单抗、奥法妥木单抗、奥瑞珠单抗、阿仑单抗

**继发进展型MS(SPMS)：**
- 获批药物：西尼莫德、富马酸二甲酯、特立氟胺、奥法妥木单抗

**原发进展型MS(PPMS)：**
- 唯一获批：奥瑞珠单抗

## 重要约束

1. MS急性期激素治疗不主张小剂量长时间应用
2. NMOSD禁用MS药物（如β干扰素、芬戈莫德）
3. 诊断前必须排除其他可更好解释临床表现的疾病
4. AQP4-IgG阴性不能完全排除NMOSD

# McDonald 2017 MS诊断标准详细决策矩阵

## 临床发作型决策矩阵

| 临床发作次数 | 客观病灶数 | 所需额外证据 |
|------------|-----------|-------------|
| ≥2次 | ≥2个 | 无需额外辅助指标 |
| ≥2次 | 1个（有历史证据证明以往发作涉及特定部位） | 无需额外指标 |
| ≥2次 | 1个客观病变 | 需通过不同CNS部位临床发作或MRI证明DIS |
| 1次 | ≥2个 | 需额外临床发作或MRI证明DIT，或CSF OB阳性 |
| 1次 | 1个 | 需证明DIS，且(证明DIT或CSF OB阳性) |

## 空间多发(DIS)定义

以下4个CNS区域中≥2个有≥1个T2病变：
1. 脑室周围
2. 皮质/近皮质
3. 幕下
4. 脊髓

## 时间多发(DIT)定义

满足以下任一条件：
- 同时存在 gadolinium增强和非增强病灶
- 随访MRI出现新T2或增强病灶
- CSF寡克隆区带(OB)阳性（2017标准新增替代指标）

## PPMS诊断标准

前提：提示MS的隐匿神经功能障碍进展≥1年

需满足以下3项中2项：
1. 脑DIS证据：MS特征区域(脑室周围/皮质/幕下)内≥1个T2病变
2. 脊髓DIS证据：脊髓≥2个T2病变
3. CSF阳性：等电聚焦电泳显示寡克隆区带(OB)

## 边缘情况处理

- 若MRI不可用，应考虑脊髓MRI或CSF检查
- 若完成影像学/CSF检查为阴性，作MS诊断前需谨慎并考虑替代诊断
- 若无客观神经系统残余证据，诊断需谨慎

# NMOSD六组核心临床症状详细描述

## 1. 视神经炎(ON)
- 单眼或双眼受累
- 急性起病，视力下降可至失明
- 伴眶内痛（眼球运动或按压时加重）
- 晚期可出现视神经萎缩
- MRI特征：病变>1/2视神经长度，后段/视交叉易受累

## 2. 急性脊髓炎
- 长节段横贯性损害
- 双下肢或四肢瘫
- 双侧感觉障碍
- 尿便障碍
- 程度重，恢复差
- MRI特征：连续≥3个椎体节段，位于脊髓中央灰质

## 3. 延髓板后区综合征（极后区综合征）
- 不能用其他原因解释的顽固性呃逆
- 恶心、呕吐
- MRI特征：延髓背侧/极后区片状或线状T2高信号

## 4. 急性脑干综合征
- 头晕、复视
- 共济失调
- MRI特征：脑干背盖部/四脑室周边弥漫性病变

## 5. 急性间脑综合征
- 嗜睡、发作性睡病
- 顽固性低钠血症
- 体温调节异常
- MRI特征：丘脑/下丘脑/三脑室周边弥漫性病变

## 6. 大脑综合征
- 意识下降
- 认知减退
- 头痛
- MRI特征：皮质下白质弥漫云雾状（非MS特征），可累及胼胝体/基底节

## 流行病学特征
- 发病年龄：5-50岁（平均40岁）
- 性别比例：女:男 = 5-11:1
- 起病形式：急性/亚急性，数天至1-2月达高峰
- 常伴发：系统性红斑狼疮、干燥综合征、重症肌无力

## 病理特征
- 白质脱髓鞘、坏死甚至囊性变
- 炎性浸润以B淋巴细胞、巨噬细胞、中性粒/嗜酸性粒细胞为主
- 靶抗原：星形胶质细胞水通道蛋白4(AQP4)

### [mri-patterns.md]

# 中枢神经系统脱髓鞘疾病MRI特征识别规则

## NMOSD影像特征

### 视神经炎
- 易累及视神经后段和视交叉
- 病变节段 >1/2视神经长度
- 急性期：视神经增粗、强化
- 慢性期：视神经萎缩，形成双轨征

### 急性脊髓炎
- 长节段横贯性炎性损害，连续长度≥3个椎体节段
- 轴位：病灶多位于脊髓中央灰质和部分白质
- 颈/胸段多见
- 急性期肿胀/空洞样改变，增强后强化
- 恢复期萎缩

### 其他综合征
- 极后区：延髓背侧片状/线状T2高信号
- 脑干：背盖部/四脑室周边弥漫性病变
- 间脑：丘脑/下丘脑/三脑室周边弥漫性病变
- 大脑：皮质下白质弥漫云雾状，点状/波墨状

## MS影像特征

### 脑部
- T2WI高信号，类圆形
- 常见于侧脑室旁（直角脱髓鞘征/Dawson finger）
- 半卵圆中心、胼胝体
- 急性期环形或开环强化

### 脊髓
- 短节段病灶
- 偏侧非横贯性病变

### 视神经
- 短节段或未见异常
- 可见水肿增粗

## ADEM影像特征
- 脑和脊髓多发性散在病灶
- T1低/T2高，均一时相
- 近半数不强化
- 大片灰白质病灶常见且可消失
- CT可见低密度区及环形/结节状强化

## 罕见脱髓鞘病变

### 同心圆性硬化(Balo病)
- 双侧额/顶/枕/颞叶白质多发洋葱头样或树木年轮样黑白相间类圆形病灶
- 典型直径1.5~3cm
- T1像低信号环(脱髓鞘区)与等信号(正常髓鞘区)相间，共3~5个环

### GFAP-A（自身免疫性胶质纤维酸性蛋白星形胶质细胞病）
- 累及大脑白质/基底节/下丘脑/脑干/小脑/脊髓/脑膜
- 特征表现：约半数患者出现垂直于脑室的线样放射状增强信号

### [ms-nmosd-differential.md]

# MS与NMOSD完整鉴别诊断矩阵

## 流行病学对比

| 特征 | MS | NMOSD |
|-----|-----|-------|
| 高发地区 | 北美/西欧/澳洲 | 东亚/黑种人 |
| 女:男比例 | 2:1 | 5-11:1 |
| 中位发病年龄 | 29岁 | 39岁 |
| 特异性抗体 | CSF OB阳性 | 血清AQP4-IgG阳性 |

## 临床严重程度对比

| 特征 | MS | NMOSD |
|-----|-----|-------|
| 严重程度 | 轻中度多见 | 中重度多见 |
| 致盲率 | 低 | 高（严重视力障碍） |
| 急性期致残率 | 早期低 | 高 |
| 病程类型 | 复发缓解型或慢性进展型 | 复发型多见 |

## 核心临床表现对比

| 特征 | MS | NMOSD |
|-----|-----|-------|
| 脊髓受累 | 部分性脊髓炎 | 长节段横贯性脊髓炎 |
| 脑干/小脑 | 常见 | 可见 |
| 极后区综合征 | 罕见 | 特征性 |
| 疲劳/认知 | 突出 | 相对少见 |

## MRI特征对比

### 脑部
| 特征 | MS | NMOSD |
|-----|-----|-------|
| 典型部位 | 脑室旁/近皮质 | 极后区/四脑室/三脑室/丘脑/下丘脑 |
| 形态 | 圆形/类圆形 | 弥漫、边界欠清 |
| 特征征象 | 直角脱髓鞘征(Dawson finger) | 无经典MS表现 |

### 脊髓
| 特征 | MS | NMOSD |
|-----|-----|-------|
| 长度 | 短节段 | 长节段(≥3椎体) |
| 分布 | 偏侧非横贯性 | 中央横贯性 |
| 节段 | 颈/胸段均可 | 颈/颈胸段多受累 |
| 急性期 | 轻度肿胀 | 明显肿胀/壳斑样强化 |
| 慢性期 | 轻度萎缩 | 萎缩/空洞 |

### 视神经
| 特征 | MS | NMOSD |
|-----|-----|-------|
| 病变长度 | 短节段或未见异常 | >1/2视神经长度 |
| 受累部位 | 前段多见 | 后段/视交叉易受累 |

## CSF对比

| 特征 | MS | NMOSD |
|-----|-----|-------|
| 白细胞增多 | 轻度(<50%患者)，通常≤50×10⁶/L | 常见(>70%患者)，可>50×10⁶/L |
| IgG指数 | 多增高(>70%患者) | 多正常 |
| OB阳性率 | 欧美90%，亚洲60-70% | 较低 |
| 蛋白 | 约40%轻度增高 | 轻中度增高 |

## 治疗与预后对比

| 特征 | MS | NMOSD |
|-----|-----|-------|
| 主要治疗 | 免疫调节剂 | 免疫抑制剂/单抗 |
| 致残原因 | 疾病进展 | 高复发/恢复不良 |
| 禁用药物 | - | β干扰素、芬戈莫德等MS药物 |

## 鉴别诊断决策流程

1. **首先检测血清AQP4-IgG（推荐CBA法）**
   - 阳性 → 高度提示NMOSD
   - 阴性 → 不能排除NMOSD（存在血清阴性NMOSD）

2. **结合CSF结果**
   - OB强阳性 + AQP4阴性 → 支持MS
   - OB阴性 + 白细胞显著增高 + AQP4阳性 → 支持NMOSD

3. **结合MRI特征**
   - 长节段脊髓炎(≥3椎体) → 强烈支持NMOSD
   - 典型Dawson finger → 支持MS

## Known Risks and Mitigations:

Risk: The security review reports instructions to disclose an API key in chat and behavior that does not match the stated research purpose.

Mitigation: Verify the skill's behavior and source before installation. Never send an API key in chat; configure it through a secure local method.

Risk: The security scan is incomplete because it could not resolve a referenced local path.

Mitigation: Review that path and the complete skill source before relying on the scan or running the skill.

Risk: Background-check records can be incomplete, outdated, or associated with the wrong person.

Mitigation: Confirm identity, check each finding against its linked public source, and have a qualified professional review the draft before formal use.

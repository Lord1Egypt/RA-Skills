## Description:

Defines Figma component variant matrices, including properties, states, valid combinations, anatomy, token mapping, build order, quality checks, and anti-patterns.

This skill is ready for commercial/non-commercial use.

## Use Case:

Designers, design-system maintainers, and product teams use this skill to plan complete Figma component variant matrices before building components. It helps define properties, states, valid combinations, anatomy, token mapping, build order, and implementation quality checks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated matrices may be incomplete or misaligned with an existing design system if component inputs are incomplete.

Mitigation: Review outputs against project component requirements, design-system tokens, platform needs, and Figma property rules before implementation.

Risk: Users may expect the skill to modify Figma files directly, but evidence indicates it produces guidance only.

Mitigation: Treat the output as a planning artifact and manually implement any component changes in Figma through the normal design review process.

# 聚乙二醇干扰素-α监测方案

## 治疗前筛查

### 绝对禁忌证
- 妊娠/计划妊娠
- 精神病史
- 未控制癫痫
- 失代偿期肝硬化
- 未控制自身免疫病
- 严重感染/视网膜疾病/心衰/COPD

### 相对禁忌证
- 甲状腺疾病
- 既往抑郁症
- 未控制糖尿病/高血压/心脏病

## 监测时间表

| 时间 | 监测项目 |
|------|----------|
| 第1个月 | 每1-2周查血常规 |
| 稳定后 | 每月血常规+生化 |
| 每12周 | 病毒学+血清学应答评估 |
| 每3个月 | 甲功、血糖、HBV DNA、HBsAg、HBeAg |
| 每6个月 | 腹部超声+AFP（肝硬化者每3个月） |

## 常见不良反应处理

- 流感样症状：对症处理
- 骨髓抑制：必要时减量/G-CSF支持
- 抑郁：精神科会诊，必要时停药
- 甲功异常：内分泌科协同管理

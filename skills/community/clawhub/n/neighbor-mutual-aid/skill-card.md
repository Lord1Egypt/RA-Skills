## Description:

Helps an agent guide a user through setting up a hyperlocal mutual aid network for neighbor support, resource sharing, and emergency preparedness.

This skill is ready for commercial/non-commercial use.

## Publisher:

[howtousehumans](https://clawhub.ai/user/howtousehumans)

### License/Terms of Use:

MIT-0

## Use Case:

External users use this skill to have an agent help them map nearby households, invite opt-in participation, collect a minimal resource survey, build a contact/resource sheet, and maintain lightweight neighborhood support systems.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Sensitive neighbor contact, emergency, vulnerability, and home-access details could be collected or distributed without enough privacy controls.

Mitigation: Use explicit opt-in, collect only the minimum information needed, keep medical and vulnerability details out of shared sheets, store documents with access controls, and define how access is revoked and old copies are destroyed.

Risk: Key exchanges or lockbox codes can create home-access risk if shared too broadly.

Mitigation: Avoid broad sharing of keys or codes; limit access to trusted opt-in participants and revoke access when someone leaves the network.

## Description:

Drafts, revises, and polishes English study-abroad application materials from user-provided academic background and target program details, including personal statements, statements of purpose, recommendation letter drafts, outreach emails, resumes, and academic CVs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[caroljiang150-ai](https://clawhub.ai/user/caroljiang150-ai)

### License/Terms of Use:

MIT-0

## Use Case:

External users use this skill to prepare English-language study-abroad application documents that are tailored to target schools, programs, recommenders, and professors. It supports drafting from structured applicant facts, revising existing materials, enforcing word limits, and keeping narratives consistent across a complete application package.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Application materials may contain incorrect school details, applicant facts, recommender statements, or unresolved placeholders if inputs are incomplete.

Mitigation: Review all generated facts, school and professor details, recommender claims, word counts, and placeholders before submission.

Risk: Recommendation letter drafts could be mistaken for approved recommender statements.

Mitigation: Use recommendation letters only as drafts for recommender review, editing, and approval.

Risk: The skill handles personal academic and application information.

Mitigation: Provide only information needed for the application task and remove unrelated sensitive details before use.

## Description:

Provides domain modeling guidance for maintaining project vocabulary in CONTEXT.md, recording architecture decisions, and checking code terminology alignment.

This skill is ready for commercial/non-commercial use.

## Publisher:

[paudyyin](https://clawhub.ai/user/paudyyin)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineering teams use this skill to maintain shared domain vocabulary, decide when architecture decisions merit ADRs, and identify mismatches between documented project terminology and code.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Proposed terminology, ADR, code-alignment, or git commit changes could introduce incorrect project knowledge.

Mitigation: Review proposed CONTEXT.md, docs/decisions, code-alignment, and git commit changes before accepting them.

Risk: Visible encoding corruption in the source text may reduce clarity.

Mitigation: Review generated documentation and terminology updates for readability and intended meaning.

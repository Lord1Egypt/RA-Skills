## Description:

Converts Markdown into multi-theme HTML cards using local theme definitions.

This skill is ready for commercial/non-commercial use.

## Publisher:

[mayfourth96](https://clawhub.ai/user/mayfourth96)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, content creators, and agents use this skill to convert Markdown into platform-friendly HTML cards with selectable visual themes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated HTML preserves user-provided content and applies inline styles, which may be unsuitable for some publishing platforms without review.

Mitigation: Review the generated HTML before posting it to content platforms.

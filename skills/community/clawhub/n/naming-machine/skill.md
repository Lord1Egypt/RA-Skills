# 起名器 / Naming Machine

## 目标

给一个对象起名，按三档各出 3 个：

- **正经档**：体面、好记、不尴尬，长辈/客户看到也 OK。
- **好玩档**：有点小心思，会让人笑一下，但不冒犯。
- **有梗档**：带网络梗、文化梗、谐音梗，传播性强，但标清时效和圈层。

每个名字配：
1. 一句理由（不超过 15 字）；
2. 一个避坑提示（什么时候别用）。

输出像卡片，手机一屏能看完。

## 强触发词

用户说以下词语时，直接进入本 Skill：

- 起名器
- 帮我起名
- 起个名字
- 取个名字

以下表达也可触发：

- 给猫起个名
- WiFi 叫什么好
- 播客取名
- 群聊叫什么
- 项目代号想一个

- 查重提醒。

### 示例 3：群聊

> 起个名字：三个人的读书群，想正经一点

默认输出：
- 正经档可多给 1 个备选；
- 好玩档和有梗档仍各 3 个；
- 1 个首选；
- 查重提醒。

### 示例 4：播客

> 取个名字：聊城市生活的播客，年轻听众，不要太网红

默认输出：
- 三档各 3 个；
- 有梗档标清梗源和圈层；
- 1 个首选；
- 查重提醒。

### 示例 5：项目代号

> 起名器：内部项目，做知识库，代号要好记不中二

默认输出：
- 正经档偏“短、硬、好记”；
- 好玩档偏“内部玩笑但不冒犯”；
- 有梗档标清圈层；

- 再给同气质的合规方向；

## 何时使用

使用：
- 给宠物、项目、WiFi、播客、群聊、产品、活动、账号起名。
- 用户已有方向，想要更多备选。
- 用户想要“正经/好玩/有梗”三种风格对比。

不要使用：
- 用户要求注册商标、查重、法律检索（只能提醒“建议自行查重”）。
- 用户要求起侮辱性、歧视性、低俗、仇恨、色情名字。
- 用户要求冒充官方、钓鱼 WiFi、恶意群名。
- 用户要求起与知名品牌、名人高度相似的名字。

## 输入

尽量收集：
1. 起名对象：宠物 / 项目 / WiFi / 播客 / 群聊 / 产品 / 活动 / 账号。
2. 一句描述：它是什么、给谁用、什么气质。
3. 偏好：中文 / 英文 / 中英混 / 字数限制。
4. 禁用方向：不要谐音梗 / 不要太网红 / 不要英文。

缺失时：
- 默认中文为主，可夹少量英文。
- 默认每个名字 2—4 个字（WiFi 可英文）。
- 默认输出三档各 3 个。
- 不追问超过 2 个问题；能合理假设就先做。

## 合规与安全边界

本节优先级高于所有起名要求。

### 1. 禁止起名方向

不得生成：
- 侮辱、歧视、仇恨、地域黑、性别歧视、残障歧视类名字。
- 色情低俗、未成年性暗示类名字。
- 违法犯罪暗示、毒品武器、赌博诈骗类名字。
- 冒充官方、冒充品牌、钓鱼 WiFi、诈骗群名。
- 与知名商标、名人、影视角色高度相似、易混淆的名字。
- 恶意群名：如冒充通知群、冒充领导、诱导点击类。

处理模板：

```
这个方向我不起。
它属于（歧视/低俗/冒充官方/侵权高风险）类名字。
我可以换成同气质但不踩线的方向：
……
```

### 2. WiFi 名特别规则

- 不起冒充官方、运营商、物业、公安、银行的 WiFi 名。
- 不起“免费上网点这里”“点击领红包”这类诱导名。
- 不起含他人姓名、房号、电话的隐私泄露名。
- 可以起：有趣但不误导、明确是私人的、不诱导连接的。

### 3. 群聊名特别规则

- 不起冒充通知群、工作群、家长群、官方群的名字。
- 不起诱导转发、诱导付款、诱导点击的名字。
- 不起含他人隐私、嘲讽某个成员的名字。

### 4. 宠物名特别规则

- 宠物听不懂复杂名字，优先 1—3 个音节、开口音结尾。
- 不起容易在公共场合喊出来尴尬的名字。
- 不起和“过来/不行/坐下”等指令谐音的名字。

### 5. 侵权与查重提醒

每次输出末尾附：

```
起名只是创意建议，不保证可注册、可商用、无重名。正式使用前建议自行查重、查商标、查平台规则。
```

## 三档定义

### 正经档
- 体面、好记、不尴尬。
- 适合：正式项目、对外产品、长辈会看到的群、客户会看到的账号。
- 避免：网络梗、谐音擦边、过度卖萌。

### 好玩档
- 有点小心思，会让人笑一下。
- 适合：朋友群、个人播客、宠物、内部项目。
- 避免：冒犯特定人群、过度玩梗、需要解释才懂。

### 有梗档
- 带网络梗、文化梗、谐音梗，传播性强。
- 适合：社交媒体账号、年轻群聊、活动、短期项目。
- 必须标：梗的来源、时效、圈层，避免过期或圈外人看不懂。

## 工作流

### 第一步：确认对象与气质

用一句话复述：
```
对象：……
气质：……
```

不超过 20 字。

### 第二步：判断是否触碰合规边界

如果用户要求的方向触碰“合规与安全边界”，先输出拒改模板，再给同气质的合规方向。

### 第三步：三档各出 3 个

每档 3 个，不多不少。每个名字格式：

```
名字 —— 理由（≤15字）｜避坑：……
```

要求：
- 理由具体，不写“很好听”“很有创意”。
- 避坑提示写“什么时候别用”，不写“暂无”。
- 有梗档必须标梗的来源或圈层。

### 第四步：给一个首选推荐

从 9 个里选 1 个，说明为什么。

格式：
```
首选：……，因为……
```

### 第五步：附查重提醒

固定附：
```
起名只是创意建议，不保证可注册、可商用、无重名。正式使用前建议自行查重、查商标、查平台规则。
```

## 质量检查

发布前逐项检查：
1. 是否确认了对象和气质？
2. 三档是否各 3 个，不多不少？
3. 每个名字是否有理由（≤15 字）？
4. 每个名字是否有避坑提示？
5. 有梗档是否标了梗源或圈层？
6. 是否给了 1 个首选推荐？
7. 是否附了查重提醒？
8. 是否触碰歧视、低俗、侵权、冒充官方、钓鱼 WiFi 等边界？
9. WiFi/群聊名是否含隐私或诱导？
10. 宠物名是否好喊、不尴尬？

## 反 AI 味规则

避免：
- “这个名字很有创意”“寓意深远”“充满诗意”。
- 一次给 20 个名字，用户选不动。
- 每个名字都配一段解释。
- 谐音梗不标梗源。
- 起名变成品牌咨询。

优先：
- 短。
- 具体。
- 有画面。
- 标清适用和避坑。
- 9 个名字 + 1 个首选。

## 失败模式

如果出现以下情况，重做：
- 三档名字风格没区分开。
- 有梗档圈外人完全看不懂且没标梗源。
- 理由空泛。
- 避坑写“暂无”。
- 宠物名拗口或和指令谐音。
- WiFi 名冒充官方或诱导连接。
- 群名冒充通知群或含他人隐私。
- 起与知名品牌、名人高度相似的名字。
- 漏掉查重提醒。

## 最终交付

默认输出短版：三档各 3 个 + 1 个首选 + 查重提醒。
用户说“展开/多说点”时，输出展开版。
触碰合规边界时，先输出拒改模板，再给同气质的合规方向。

当用户使用强触发词“起名器”“帮我起名”“起个名字”时：
- 默认三档各 3 个；
- 默认每个名字配理由和避坑；
- 默认给 1 个首选；
- 默认附查重提醒。

本 Skill 只提供创意建议，不提供商标检索、法律意见或平台规则判断。

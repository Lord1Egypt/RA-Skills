# 验收清单

逐条打勾。每条给出“查什么、怎么查、不过怎么办”。**任一硬性项不过，不得报送。**

## 一、依据（Sources）

- [ ] **每条引用四元组齐全**：文号、发布日期、发布机关、官方链接。
      怎么查：把《政策依据清单》与正文引号内文字逐条对表，缺项的应已在待核清单。
      不过怎么办：降级为待核表述，正文去掉文号，在清单写明缺什么、走哪个收文渠道核。
- [ ] **引号内文字是原文**：随机抽三处，回原文页面比对。
      不过怎么办：改回原文，或改为不加引号的转述并注明“据……精神”。
- [ ] **无编造文号与条款句**：全文检索“〔”与“号”周围字符，确认每个文号都能在清单里找到对应行。
      不过怎么办：删除该文号，改为通用表述。
- [ ] **待核清单已交付**：每条写明缺失项与核验渠道。

## 二、结构（Structure）

- [ ] **一级标题无行政区划**：看六到七个一级标题，确认没有“某地”“某区域”之类。
      不过怎么办：把区域内容下沉到节末案例或一次横向对比。
- [ ] **每节都有帽子**：逐节看段首，是否有一句政策要求。
      不过怎么办：补依据或合并该节。
- [ ] **合规独立成章**：存在直接约束本业务的现行办法时，必须单列。
      不过怎么办：从“下一步措施”里整体切出。
- [ ] **问题章自陈短板**：不是“虽然……但是……”。
      不过怎么办：改写为结构性原因，并与措施章编号对应。

## 三、正文（Body）

- [ ] **零自造数字**：全文检索数字，逐个确认有来源或已占位。
      不过怎么办：替换为 `【填入：…】` 并登记。
- [ ] **占位符与清单一致**：脚本统计正文占位符条数，与《占位符清单》条数比对。
      不过怎么办：补齐清单或删除多余占位符。
- [ ] **角色表述一致**：全文检索承保、协办、代理、管理等等词，确认与输入字段一致。
      不过怎么办：全文替换动词与主语。
- [ ] **正文无状态标记**：检索勾、警示符、表情符号。
      不过怎么办：移入依据清单或校验记录。
- [ ] **口径标年份**：政策目标年与统计年份分列，不混用。
      不过怎么办：补年份或改写为“截至某年”。

## 四、版式（Format）

- [ ] **纸张与页边距**：A4；上 3.7、下 3.5、左 2.8、右 2.6 厘米。
      怎么查：Word 页面设置，或脚本自检输出。
- [ ] **四级字体字号**：标题、一级、二级、正文各自正确。
      不过怎么办：按回退链重设并在记录留痕。
- [ ] **行距固定值**：正文段落行距为固定值，磅值符合参数表。
- [ ] **页码为域**：页脚显示“— N —”，翻页后数字递增。
      不过怎么办：检查域代码三段是否在同一 run 内。
- [ ] **附表另起页**：附表标题前有分页。
- [ ] **表头跨页重复**：表格跨页时首行重复出现。
- [ ] **占位符标红**：方头括号内容为红色加粗。

## 五、目视校验（Render）

- [ ] **已转 PDF 与 PNG**：不是只看 Word。
- [ ] **五类代表页全部抽查**：标题页、表格页、含占位符页、附表页、末页。
- [ ] **无越界**：表格与长句不超出版心右边线。
- [ ] **无乱码与方框**：字体缺失会显示为方框，逐页扫一眼。
- [ ] **无截断**：末页正文完整，附表末行可见。
- [ ] **页数偏差可控**：Word 统计页数与预估相差不超过 ±2 页；超出要写原因。

## 六、交付（Delivery）

- [ ] **四份文件齐全**：主件、依据清单、占位符清单、校验记录。
- [ ] **目录干净**：无临时文件、无预览图、无以波浪号开头的属主文件。
- [ ] **无绝对路径**：全文检索盘符与用户目录字样，确认为零。
- [ ] **无个人信息**：无真实姓名、单位全称以外的个人信息、联系方式。
- [ ] **版本已核**：所引条例与标准的现行版本号，已由经办人核对并记录结论与日期。

## 七、报送前最后一问

- [ ] 如果评审只问一句话——“这条结论的依据是什么”——我能在十秒内翻到那一行吗？

答不上来，说明依据链还没闭合，回到第一节重做，而不是继续润色文字。

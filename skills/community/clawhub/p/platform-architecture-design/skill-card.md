## Description:

Guides agents through platform architecture design from a requirements analysis, producing C4 views, six-layer architecture, module boundaries, technology choices, data flows, API design, and communication mechanisms.

This skill is ready for commercial/non-commercial use.

## Publisher:

[golngod](https://clawhub.ai/user/golngod)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, architects, and agent operators use this skill to turn an existing requirements analysis into a structured platform architecture design report. It is suited for drafting system views, layer responsibilities, module contracts, technology comparisons, data flows, API outlines, and inter-module communication plans.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill instructions are primarily Chinese-language; users who cannot review Chinese may miss important workflow constraints.

Mitigation: Confirm that Chinese-language instructions are acceptable for the intended workflow before installing or using the skill.

Risk: Generated architecture proposals may be incomplete, unsuitable for a specific organization, or inconsistent with local engineering and security standards.

Mitigation: Have qualified engineers review the generated architecture, technology choices, API contracts, and data flows before using them for implementation decisions.

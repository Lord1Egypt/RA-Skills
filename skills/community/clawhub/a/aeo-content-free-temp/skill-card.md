## Description:

Create or refresh AEO-optimized content that gets cited by AI assistants using free tools by researching current citation patterns, building a competitive brief, drafting content, and evaluating citation-worthiness.

This skill is ready for commercial/non-commercial use.

## Publisher:

[mmyg11](https://clawhub.ai/user/mmyg11)

### License/Terms of Use:

MIT-0

## Use Case:

External content marketers, SEO/AEO practitioners, and brand teams use this skill to create new articles or refresh existing pages so AI assistants are more likely to cite them in answers.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill uses web search and web fetch to review public pages, competitor content, Reddit discussions, and user-provided URLs.

Mitigation: Install only if this research behavior is acceptable, and review generated content and publishing changes before applying them to a live site.

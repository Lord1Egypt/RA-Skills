## Description:

Create a PRD through user interview, codebase exploration, and module design, then submit as a GitHub issue.

This skill is ready for commercial/non-commercial use.

## Publisher:

[liuhe12](https://clawhub.ai/user/liuhe12)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and product teams use this skill to turn feature ideas into a structured product requirements document after interviewing the user and inspecting repository context.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can create or prepare a GitHub issue containing PRD content for the target repository.

Mitigation: Confirm the destination repository and issue content before posting, especially for sensitive or private repositories.

Risk: Repository exploration may surface private product or codebase details in the generated PRD.

Mitigation: Limit shared context to necessary details and remove confidential information before submitting the issue.

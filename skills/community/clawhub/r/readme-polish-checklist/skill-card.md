## Description:

Audit and fix a project README so a stranger can install and use the project in five minutes. Use before publishing a repo or after any major change.

This skill is ready for commercial/non-commercial use.

## Publisher:

[manteclaw](https://clawhub.ai/user/manteclaw)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this checklist before publishing or restructuring a project, or when users have recurring setup questions, to test README clarity, installation, first-run examples, project layout, accuracy, and key links.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: README installation instructions may include steps that run code or change an environment.

Mitigation: Review those steps first and use a disposable environment or get clear approval before running them on a system you rely on.

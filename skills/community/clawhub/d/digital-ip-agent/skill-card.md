## Description:

Turn a public creator, blogger, podcaster, YouTuber, or X/Twitter personality into a deployable OpenClaw agent that includes persona files and a recommended supporting-skill stack.

This skill is ready for commercial/non-commercial use.

## Publisher:

[aliciawque](https://clawhub.ai/user/aliciawque)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agent builders use this skill to analyze public creator material and generate a deployable OpenClaw persona package for authorized creator-style agents.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can be used to create agents based on real public people without explicit impersonation safeguards.

Mitigation: Use only for clearly authorized, non-deceptive persona work and avoid presenting generated agents as the real creator.

Risk: Recommended supporting skills may include code execution or long-term memory for technical personas.

Mitigation: Enable code-execution or long-term-memory skills only when needed, and sandbox, scope, or limit them before deployment.

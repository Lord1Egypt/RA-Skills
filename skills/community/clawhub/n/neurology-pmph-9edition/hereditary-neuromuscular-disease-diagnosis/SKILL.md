# 遗传性神经肌肉疾病诊断与管理

## 核心诊断流程

### 第一步：根据临床表现初步分类

| 核心表现 | 可能疾病 | 关键特征 |
|---------|---------|---------|
| 发作性肌无力 | 周期性瘫痪 | 血钾异常、诱发/缓解因素 |
| 不耐疲劳+卒中样发作/眼外肌麻痹 | 线粒体脑肌病 | 血乳酸↑、RRF |
| 骨盆带/肩胛带肌萎缩 | LGMD | 10-30岁起病、CK↑ |
| 对称性上睑下垂+吞咽困难 | 眼咽型肌营养不良 | 40岁起病、PABPN1基因 |
| 成年期进行性共济失调 | SCA | 遗传早现、眼球运动障碍 |
| 儿童期共济失调+心脏畸形 | FRDA | GAA扩增、心肌肥厚 |
| 痉挛性截瘫+剪刀步态 | HSP | 单纯型/复杂型 |
| 远端对称性肌萎缩+鹤腿 | CMT | MNCV分型 |

### 第二步：针对性辅助检查

1. **肌电图/神经传导**
   - CMT1型：MNCV < 38m/s（脱髓鞘）
   - CMT2型：MNCV正常，CMAP/SNAP波幅↓（轴索）
   - 肌源性损害：肌营养不良、线粒体肌病

2. **肌肉活检**
   - RRF（破碎红纤维）+ COX阴性 → 线粒体病
   - 肌纤维坏死再生 → 肌营养不良

3. **基因检测（确诊金标准）**
   - MELAS：mtDNA 3243 A>G
   - MERRF：mtDNA 8344 A>G
   - CMT1A：PMP22重复（60-70%）
   - FRDA：FXN基因GAA扩增（66-1700次）

### 第三步：鉴别诊断排除

**必须排除的疾病：**
- 重症肌无力：疲劳试验+、新斯的明试验+、AChR抗体+
- 吉兰-巴雷综合征：脑脊液蛋白-细胞分离
- CIDP：激素有效、传导阻滞
- 获得性共济失调：中毒、副肿瘤综合征

## 治疗原则

### 通用原则
- 避免剧烈运动（防加重肌损害）
- 物理/康复治疗预防关节挛缩
- 遗传咨询与产前诊断

### 特异性治疗
| 疾病 | 治疗 |
|-----|-----|
| DMD | 泼尼松0.75mg/(kg·d)或地夫可特0.9mg/(kg·d) |
| 线粒体病 | 辅酶Q10、左卡尼汀、L-精氨酸；**禁用于线粒体肌病的生酮饮食** |
| FRDA | 辅酶Q10、抗氧化剂 |
| CMT | **禁用神经毒性药物（铂类、长春新碱）** |

## 预后评估

- **极差**：DMD（12岁不能行走）、LGMD 2C-2F、KSS
- **较好**：FSHD、BMD、眼咽型、CMT（不影响寿命）

# 遗传性共济失调与痉挛性截瘫

## SCA polyQ亚型鉴别

| 亚型 | 特征 | 病理 |
|-----|-----|-----|
| SCA1 | +眼肌麻痹+锥体束征+周围神经病 | 脊髓小脑束+后索 |
| SCA2 | +慢眼动+腱反射减弱+肌阵挛 | 下橄榄核+脑桥 |
| SCA3/MJD | +突眼+肌萎缩（中日最常见） | 脑桥+黑质+前角 |
| SCA6 | 振动觉减退，进展慢 | - |
| SCA7 | +视力下降+视网膜色素变性 | 视网膜变性 |

## FRDA诊断要点
- 8-15岁起病
- 深感觉丧失+腱反射消失+Babinski征+
- 85%心脏受累（心肌肥厚）
- 75%脊柱畸形，50%弓形足
- FXN基因GAA扩增（正常<42，致病66-1700）

## HSP分型
- **单纯型**：仅痉挛性截瘫，常显，20-40岁
- **复杂型**：合并智力低下/共济失调/视神经萎缩等，常隐/X连锁

### 复杂型综合征
- Behr综合征：+视神经萎缩
- Kjellin综合征：+黄斑变性
- Sjögren-Larsson综合征：+鱼鳞病
- Troyer综合征：+远端肌萎缩+耳聋

# 腓骨肌萎缩症(CMT)

## 电生理分型标准

| 类型 | MNCV | 病理 | 发病年龄 |
|-----|-----|-----|---------|
| CMT1（脱髓鞘） | <38 m/s | 洋葱头样改变 | 儿童晚期/青春期 |
| CMT2（轴索） | 正常/接近正常 | 轴索变性 | 成年 |
| 中间型 | 25-45 m/s | 混合 | 不定 |
| CMT3 | 显著↓ | 严重脱髓鞘 | 婴儿期 |

## 基因检测
- CMT1A（60-70%）：PMP22基因重复，MLPA检测
- 其他：Sanger或全外显子测序

## 鉴别诊断
| 疾病 | 鉴别要点 |
|-----|---------|
| 远端型肌营养不良 | 无感觉障碍，肌源性肌电图 |
| CIDP | 进展快，脑脊液蛋白↑，激素有效，传导阻滞 |
| 慢性远端型脊髓性肌萎缩 | 肌束震颤，前角细胞损害肌电图 |
| ATTR-PN | 自主神经障碍早，TTR基因检测 |

## 安全用药边界
**绝对禁忌：周围神经毒性药物**
- 铂类化疗药
- 长春新碱
- 其他神经毒性药物

# 线粒体脑肌病/肌病

## 临床亚型

| 亚型 | 核心特征 | 基因突变 |
|-----|---------|----------|
| MELAS | 卒中样发作（枕颞叶）、癫痫、糖尿病 | mtDNA 3243 A>G (80%) |
| MERRF | 肌阵挛癫痫、共济失调 | mtDNA 8344 A>G |
| CPEO | 进行性眼外肌麻痹 | mtDNA大片段缺失 |
| KSS | CPEO+视网膜色素变性+心脏传导阻滞 | mtDNA大片段缺失(90%) |
| Leigh病 | 婴幼儿、发育倒退、对称性脑干/基底节病灶 | 多种 |

## 确诊指标
1. 血乳酸/丙酮酸最小运动量试验阳性（运动后10分钟不恢复）
2. 肌肉活检：RRF + COX阴性肌纤维
3. MRI特征：MELAS急性期沿脑回皮质T2/DWI高信号（与血管分布不一致）
4. 基因检测确诊

## 阈值效应
mtDNA突变比例越高症状越重：
- 高比例：卒中/痴呆/癫痫
- 低比例：糖尿病/耳聋/无症状

## 治疗禁忌
**生酮饮食禁用于线粒体相关肌病患者**

# 肌营养不良

## LGMD特征
- 10-30岁起病
- 首发骨盆带肌萎缩→腰椎前凸→蹲步
- 逐渐肩胛带萎缩→翼状肩胛
- CK升高，肌电图肌源性
- 面肌一般不受累

## 眼咽型特征
- 40岁左右起病
- 对称性上睑下垂+吞咽困难
- CK正常或轻度升高
- PABPN1基因GCN扩增

## 预后分级
| 预后 | 疾病 |
|-----|-----|
| 极差 | DMD、LGMD 2C/2D/2E/2F、先天性肌营养不良 |
| 较好 | FSHD、BMD、眼咽型、远端型 |

### [periodic-paralysis.md]

# 周期性瘫痪鉴别诊断

## 各亚型鉴别

| 亚型 | 发病年龄 | 持续时间 | 血钾 | 诱发/缓解 |
|-----|---------|---------|-----|----------|
| 低钾型 | 常见 | 数小时-数天 | ↓ | 高碳水饮食诱发，补钾缓解 |
| 高钾型 | <10岁 | 短 | ↑/正常 | 运动后休息诱发，补钙降钾缓解，伴肌强直 |
| 正常血钾型 | 不定 | >10天 | 正常 | 补钾加重，服钠减轻 |

## 继发性低钾必须排除
- 内分泌：甲亢、原发性醛固酮增多症
- 肾脏：肾小管酸中毒、失钾性肾炎
- 消化/药物：腹泻、噻嗪类利尿剂、糖皮质激素

## 与其他疾病鉴别
- **重症肌无力**：脑神经支配肌肉先受累，疲劳试验+，血清钾正常
- **GBS**：下肢重于上肢，感觉障碍，脑脊液蛋白-细胞分离

## Description:

Helps agent users, skill authors, maintainers, and teams turn Skill Vetter-style demand into practical workflows, checklists, analysis, code changes, and reliability or safety improvements.

## Use Case:

Agent users, skill authors, maintainers, and teams use this skill to plan and produce practical Skill Vetter-style deliverables such as bug-fix workflows, setup hardening checklists, reliability reviews, adjacent skill plans, and verification notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill has broad activation wording for security, GitHub, and bug-fix requests, which may cause it to be selected for general requests beyond the intended workflow-helper scope.

Mitigation: Narrow trigger keywords or disable implicit invocation when installers want explicit selection only.

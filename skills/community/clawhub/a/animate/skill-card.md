## Use Case:

Developers and product engineers use this skill to design and implement UI motion contracts, stack-specific animation choices, accessibility fallbacks, and QA checks for app and web interfaces.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Local motion preference files under ~/animate/ could accidentally include secrets or sensitive customer details if users save them there.

Mitigation: Keep saved notes limited to reusable motion preferences, platform context, QA findings, and non-sensitive implementation decisions.

Risk: Broad activation could apply motion guidance when the user only wants narrow implementation help.

Mitigation: Choose a narrow activation preference when installing or configuring the skill.

# 免费窗口与绕行计算

节假日自驾的核心不是「免掉多少钱」，而是**把免费额度用在不堵的路段上**：免费段用来跑长距离，拥堵段用付费换畅通。本文件给判定口径、排期方法与临界卡点的算法。

## 1. 政策口径（五条硬事实，其余每年核验）

1. **适用范围**：春节、清明、劳动节、国庆节四个国家法定节假日实施小型客车免费通行；其余节假日是否免费以当年公告为准。
2. **适用车型**：7 座及以下小型客车（含允许上收费公路的摩托车，按公告口径）。
3. **判定时点**：以**驶离出口收费车道的时间**为准。进站在免费之前、出站在免费之后，同样免费；反之出站在免费结束后，全程按收费处理。
4. **免费内容**：免的是车辆通行费；油费、停车费、桥隧代收费、服务区消费不在其内，按当地规定另计。
5. **每年核验**：免费的起止时刻随当年放假安排确定，**不得沿用往年的日期**。任何一次交付都必须写明「以当年交通运输部与省级交通部门公告为准」。

出行日是否落在窗口内，按下面三步判定，三步都成立才算免费：

```text
① 日期落在当年公告的免费时段内
② 车型符合（7 座及以下小型客车）
③ 驶离出口收费车道的时间落在免费时段内
```

## 2. 核验流程

1. 查当年国务院办公厅放假安排通知，确定节假日与调休日的起止日期。
2. 查交通运输部及途经省份交通运输厅的免费通行公告，抄下**起止时刻**（通常精确到 00:00 与 24:00）。
3. 确认免费车型与判定口径（是否「驶离出口时间为准」，以公告原文为准）。
4. 把三项写进交付物的「参数卡」：数值、来源、核验日期。缺任何一项，本步骤不算通过。

## 3. 窗口排期：三类段分类法

把整条行程拆成路段，逐段贴上标签，再排日期：

| 类型 | 特征 | 排期原则 |
|:--|:--|:--|
| A 必须窗口内 | 长距离跨省段（数百公里以上）、非主流走廊、路况稳定 | 压进免费窗口的非高峰日 |
| B 可窗口内外 | 中距离段、目的地之间的连接段 | 优先窗口内；若与高峰重叠则改到窗口外 |
| C 必须窗口外 | 返程高峰段、免费首日出城段 | 挪到免费结束后的工作日，付费买畅通 |

排期顺序：先锁 C（最堵的段先定日期），再把 A 塞进窗口内的空档，最后用 B 填补。

## 4. 临界卡点算法

免费结束时刻（记为 T_end）是硬边界。若按导航 ETA 会在 T_end 之后才驶离出口，用下面的算法处理：

```text
① 计算 ETA(出口) = 出发时刻 + 时长 + 缓冲(建议 ≥2h)
② 若 ETA(出口) ≤ T_end           → 直接走，全程免费
③ 若 ETA(出口) > T_end：
     a. 在 T_end 之前最后一个可用出口下站（记为 S1），此段按免费计
     b. 从 S1 重新上站，剩余段按收费计
     c. 若剩余段 >150km 且 T_end 在深夜，改住 S1 附近，次日再走
④ 记录两段的过路费，写进成本表，不要只写一个总数
```

三条经验规则：

- 免费结束前 2 小时仍在高速上，就按第 ③ 步处理，不要赌「刚好赶上」。
- 深夜临界（如 24:00）比白天临界更危险：疲劳 + 卡点焦虑，宁可提前下站住一晚。
- 免费**开始**时刻不需要卡点：进站早于免费开始、出站晚于免费开始，同样免费。

## 5. 窗口内的成本重算与阈值切换

```text
窗口内：过路费 = 0
每公里成本 = 油费单价 = F ÷ 100 × P
ΔT/ΔS 回本线：从 7.5 退回 4.5 min/km
绕行上限：从 35%–40% 放宽到 25%–30%（可用里程换畅通）
```

含义很直接：免费期间绕路更划算，因为每多绕 1 公里只多烧油、不再多交费。若两条路线在窗口内时长接近，选里程短的那条；若时长差 >20 分钟且绕行 <25%，选快的那条。

## 6. 用付费买畅通：付费段的每分钟成本

返程高峰段常出现「免费但堵 3 小时」与「付费但畅通」的选择。不要凭感觉，按分钟算：

```text
付费方案：多付过路费 ΔToll，省下时间 ΔT（分钟）
每分钟成本 = ΔToll ÷ ΔT

若 每分钟成本 < V × 0.5      → 付费走，几乎无争议
   0.5V – 1.0V               → 付费走
   1.0V – 1.5V               → 看同行人能否承受拥堵
   >1.5V                     → 免费走，把省下的钱用于住宿或餐饮
```

`V` 是有效时间价值（元/分钟），算法见 `cost-model.md` §3.3。拥堵判断必须用**当日实时路况或交通部门发布**，不能用往年经验代替；往年规律只用于决定「哪一天出发」，不用于决定「今天走哪条」。

## 7. 拥堵时段的一般规律

以下是节假日车流的**一般形态**，用于排期参考，具体以出发当日的实时路况与交管发布为准：

| 时段 | 一般情况 | 排期建议 |
|:--|:--|:--|
| 放假前一日下午至夜间 | 提前出行潮，出城方向开始积压 | 不安排长途 |
| 首日上午 | 出城高峰，城市群出口最堵 | 安排景点或短途，把长途放到次日 |
| 第二至第三日 | 主干线趋稳，非主流走廊相对畅通 | 长途段的最佳窗口 |
| 假期后段下午起 | 返程潮启动，方向性拥堵明显 | 提前半天或改到假期结束后 |
| 假期结束后首个工作日 | 全线恢复常态 | 付费换畅通的性价比最高 |

## 8. 排期模板

| 日期 | 路段 | 类型 | 里程 km | 预计时长 | 上站 | 下站 | 过路费口径 |
|:--|:--|:--|--:|--:|:--|:--|:--|
| D1 | 甲城 → 乙城 | A 必须窗口内 | | | | | 免费（驶离在窗口内） |
| D2 | 乙城 → 丙镇 | B 可窗口内外 | | | | | 免费或按实收 |
| D3 | 丙镇 → 甲城 | C 必须窗口外 | | | | | 按实收（买畅通） |

填完后做一次反向核对：把每天的「上站—下站」时刻对照免费时段，确认每段的免费/收费判定与表中一致；不一致的段要么改时刻，要么改标签。

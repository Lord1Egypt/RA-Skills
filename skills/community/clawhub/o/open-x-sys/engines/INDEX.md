# Capability engine index

Engines are deep transformation capabilities that the runtime composes freely. They own no fixed order. Call the change the live system lacks and return its result to the same active picture.

| Change the system needs | Read | Return to the runtime |
| --- | --- | --- |
| Form system understanding from material and phenomena that can change the picture | [Understand](understand.md) | Decisive structure, mechanism, evidence, and unknowns |
| Open new questions, explanations, scenarios, choices, or directions for creation | [Explore](explore.md) | Possibilities worth continuing and signals that distinguish them |
| Let deep understanding reach a person as a complete work | [Express](express.md) | A subject-native work that can be understood and used |
| Research best practice, bridge a capability gulf, and build real capability | [Practice and build](build.md) | Conditional practice, real connections, validation, and capability record |
| Let results rewrite understanding, relations, capability, and future behavior | [Evolve](evolve.md) | An updated system and higher starting point |

Enter [capability resources](../capabilities/README.md) when a concrete method, system pattern, or complete practitioner route is useful. When an engine finishes, return through [Verify](../runtime/verify.md), [Works](../experience/works.md), or [Update](../runtime/update.md), according to the subject.

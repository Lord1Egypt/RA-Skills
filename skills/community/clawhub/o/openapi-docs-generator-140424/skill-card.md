## Description:

Helps API developers and backend teams generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, backend and platform teams, developer-experience teams, and API maintainers use this skill to create, refine, and validate OpenAPI or Swagger documentation that makes REST APIs easier for other engineers to understand and integrate.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation wording may cause the skill to be selected for general API or developer-experience questions outside OpenAPI documentation work.

Mitigation: Confirm the task is specifically about OpenAPI, Swagger, REST API documentation, or closely related documentation validation before applying the skill.

Risk: Generated API documentation or specifications may contain incomplete, stale, or misleading details if the source API behavior is not checked.

Mitigation: Review generated specs, examples, and checklists against the actual API implementation before publishing or relying on them.

## Description:

This skill is used to scan any frontend project directory, automatically analyze routing structure and module division, and generate a universal module-page mapping document for use by intelligent navigation systems.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill to analyze frontend project directories, identify routing and module structures across common frameworks, and produce module-page mapping documents for navigation or project understanding.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated mapping documents may reveal internal route, module, component, and file path names.

Mitigation: Review generated mapping documents before sharing them outside the intended audience.

Risk: Scanning an overly broad directory may include unrelated private project information in the analysis.

Mitigation: Provide an explicit frontend project path and avoid pointing the skill at unrelated private directories.

# Setup

Set `MODEMBOX_URL` to the trusted base URL and `MODEMBOX_TOKEN` to its operator bearer token when authentication is enabled. Connect to `/mcp` over Streamable HTTP.

Play mono 8 kHz signed PCM16 WAV as base64, up to 30 seconds. Capture returns a base64 WAV from the recent caller audio buffer. See [MCP and agent integrations](https://psyb0t.github.io/docker-modembox/mcp/).

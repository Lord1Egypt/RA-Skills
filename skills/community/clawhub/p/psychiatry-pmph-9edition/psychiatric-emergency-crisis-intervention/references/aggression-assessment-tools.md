# 攻击行为评估工具详解

## 评估方法分类

### 1. 临床经验性评估
- **方法**：依靠知识和经验，观察临床表现和环境因素
- **优势**：灵活，及时
- **劣势**：主观性强，准确度低，评定者偏倚

### 2. 精细性评估（Actuarial）
- **方法**：危险因素按等级/分值系统化
- **常用工具**：
  - DBRS（危险行为评定量表）
  - HCR-20（临床风险量表）
  - MOAS（外显攻击行为量表）
- **优势**：预测准确率显著提高
- **劣势**：未考虑潜在因素，受静态因素影响

### 3. 结构化临床评估
- **方法**：统一工具 + 个体化灵活调整
- **常用工具**：
  - PCL-R（病态人格诊断清单）
  - VRAG（暴力风险评定指南）
  - MICI（复合分级系统）
- **步骤**：列出因素→分析影响大小→总体评价

## 5大评估维度详解

### 维度1：既往攻击行为历史
- 最有效的独立影响因素
- 评估：频率、严重程度、触发因素
- 包括：暴力史、冲动行为、应激事件、反社会特点

### 维度2：人格特征
- 缺乏诱因暴力
- 无悔意、持续否认
- 易冲动、不接受批评
- 精力旺盛、自我中心

### 维度3：精神状态
- 病态嫉妒、偏执
- 缺乏自控、依从性差
- 物质滥用（相关性最高）
- 急性期、躁狂、偏执状态危险性大

### 维度4：环境因素
- 生活/社交网络风险
- 精神刺激/突发事件再现
- 社交困难、暴力暴露
- 社会不稳定、缺乏支持

### 维度5：保护因素
- 社会支持系统
- 情绪调节技能
- 健康行为
- 积极应对策略

## 风险分类

| 类型 | 特征 | 干预意义 |
|------|------|----------|
| 静态风险 | 不可改变（人口学、既往暴力） | 用于风险分层 |
| 动态风险 | 可干预（精神症状、物质滥用） | 治疗靶点 |
| 近期风险 | 当前应激、精神症状 | 即时干预 |
| 远期风险 | 人格、社会支持 | 长期管理 |

## 攻击行为临床治疗

### 治疗场所选择
- **住院**：重性精神障碍+明显攻击暴力倾向
- **门诊**：品行障碍、人格障碍、器质性人格改变

### 药物策略
| 诊断 | 首选药物 |
|------|----------|
| 精神分裂症/攻击 | 氯氮平、奥氮平、氟哌啶醇 |
| 抑郁障碍 | 抗抑郁药 + 碳酸锂 |
| 脑电图异常 | 抗癫痫药 |
| 物质滥用 | 有步骤戒断 |
| 脑器质性损伤 | 普萘洛尔等β阻滞剂 |

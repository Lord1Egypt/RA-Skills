# 护工助手 - 护理团队全流程管理

## 设计理念

> "护理的本质不是完成任务，而是守护生命。" 

本技能专为 **护理团队/养老机构** 设计，核心原则：

| 原则 | 说明 |
|------|------|
| 📋 流程闭环 | 从患者入档→每日护理→用药→体征→报告，全流程覆盖 |
| 🤝 团队协同 | 支持多护工、交接班、任务分配 |
| 📊 数据可视 | 生命体征趋势图、用药日历、护理统计仪表盘 |
| 🛡 安全第一 | 过敏史/禁忌强提醒，异常体征自动预警 |
| 📱 轻量易用 | 纯前端单文件，localStorage 存储，零部署 |

---

## 9大核心模块

### 1. 👤 患者档案管理
- 基本信息（姓名/年龄/性别/床位号）
- 病史/过敏史/用药禁忌
- 护理等级（特级/一级/二级/三级）
- 家属紧急联系人
- 责任护工分配

### 2. 📋 护理日志
- 每日护理活动记录（翻身/擦洗/口腔护理/康复训练等）
- 护理类型分类和时长记录
- 异常情况备注
- 按患者/日期筛选查看

### 3. 💊 用药管理
- 用药计划（药品名/剂量/频次/起止日期）
- 每日用药打卡（已服/未服/延迟）
- 药品库存管理
- 用药历史追溯

### 4. 📊 生命体征追踪
- 体温/血压/心率/血糖/血氧 5项指标
- 异常值自动预警（红色标记）
- 30天趋势折线图
- 测量时间记录

### 5. 🍽️ 饮食管理
- 每日三餐+加餐记录
- 饮食禁忌管理
- 营养摄入概览
- 特殊饮食需求标记

### 6. 📝 家属报告
- 自动生成每日/每周护理摘要
- 包含体征、用药、饮食、护理活动
- 一键复制/导出

### 7. 🚨 应急处理
- 应急预案库（跌倒/窒息/心脏骤停/低血糖等）
- 紧急联系人管理
- 急救步骤指引

### 8. 🏠 多患者管理
- 患者列表总览
- 按护理等级/责任护工筛选
- 快速切换患者视图

### 9. 🔄 团队交接班
- 交班记录（本班护理摘要/待办事项/注意事项）
- 接班确认
- 交接历史追溯

## 使用方式

### 启动应用
```
说"打开护工助手"或"护工管理"
→ 自动生成交互式HTML护理管理看板
```

### 数据存储
- 所有数据存储在浏览器 localStorage
- 支持导入/导出 JSON 数据备份
- 刷新页面数据不丢失

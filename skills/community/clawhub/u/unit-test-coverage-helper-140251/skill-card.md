## Description:

Helps maintainers, QA engineers, contributors, and product teams add useful unit tests and raise coverage in existing codebases through a repeatable workflow.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, QA engineers, open-source contributors, and product teams use this skill to plan and produce practical unit-test coverage improvements for existing codebases. It helps clarify constraints, propose implementation steps, create reusable workflows or checklists, and include verification notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Implicit invocation is enabled, so the skill may activate for broad testing or quality requests.

Mitigation: Use it for unit-test coverage assistance where its documentation-only workflow applies, and review the proposed test plan or code changes before adoption.

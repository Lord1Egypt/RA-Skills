# 风格配方表（美术方向提示，非工程规格）

> ⚠️ **性质说明**：本文件是**美术方向**参考 —— 决定「做什么样的东西」。工程硬指标（面数/命名/导出）一律以 `art-standards.md` 为准。
> 原包里有 60+ 个风格/世界观/情绪包，绝大多数是几百字的氛围文案。这里把它们**压成可执行配方**：触发词 → 造型语言 → 材质/配色 → 灯光 → 关键动作。
> 核验：2026-11-18

---

## 使用方法

1. 用户说「做个 X 风格的东西」→ 在表里找触发词
2. 读该行的**造型语言 + 材质 + 灯光**三列，直接写进 Brief
3. 面数/贴图预算**不从这张表来**，从 `art-standards.md` §3 按用途选
4. 表里没覆盖 → 拆解用户的参考图（走 `art-reference-match.md`），不要瞎猜

用法（只改世界/灯光/相机/色彩管理，不动几何）：

```bash
blender -b scene.blend --python generated\tools\style_presets.py -- --look golden-hour --apply --brief
```

**验收方式**（本工具的自检口径，实测 5.3.0/5.2.4 × EEVEE/Cycles 各 12/12 通过）：渲染小样后测亮度分布 ——
`mean < 0.03` 判黑屏、`mean > 0.85` 判过曝、`p95 − p05 < 0.15` 判灰平（无层次）。三者全过才算 look 可用。

**其余 37 个方向为什么没进脚本**：它们的差异是「造型/叙事选择」（比如 lowpoly 的切面语言、PSX 的顶点抖动），不是灯光数值 —— 强行参数化会产出假的精确。这些留在下方表里当 Brief 素材。

## B. 风格化 / 图形化

| 触发词 | 造型语言 | 材质 / 配色 | 灯光 | 关键动作 |
|---|---|---|---|---|
| **低多边形 / lowpoly** | 大平面、明确切面、不用 bevel | 纯色或极简渐变，无贴图；色相跨度大 | 单方向光 + 环境色，无 AO 依赖 | 面数 500–5000；每个面都要「有意为之」 |
| **PSX / PS1** | 抖动、顶点抖动、低分辨率贴图 | 128–256 贴图 + 点采样、色阶量化 | 顶点光照感、无 PBR | 开 nearest filter、affine 纹理扭曲（可选） |
| **HD-2D** | 3D 场景 + 2D 像素角色、景深压缩 | 场景写实材质 + 角色像素 sprite | 侧逆光强、bloom 明显 | 角色永远朝相机/斜 45° |
| **赛璐璐 / cel-shaded** | 干净剪影、明确分界 | 2–3 阶色带、描边（inverted hull 或 freestyle） | 硬光、无渐变过渡 | 用 Shader to RGB（Eevee）+ ColorRamp 阶 |
| **像素 / pixel-art** | 8–32 px 网格、限制色板 | 固定 16–32 色板 | 无（2D） | 分辨率整数倍放大，禁抗锯齿 |
| **黏土 / claymorphism** | 圆角、厚实、无锐边 | 高粗糙哑光、粉彩、Soft SSS | 大面柔光、无硬阴影 | 全模型 bevel 加大，无 sharp 边 |
| **玩具感 / toy-like** | 缩小比例细节、夸张关键特征 | 塑料高光 (rough 0.2)、原色饱和 | 摄影棚三点光、白背景 | 接缝线做成真实玩具分模线 |

## 组合规则

- 一张图里**最多 2 个风格**（如「赛博朋克 + 日式」），3 个必乱
- 世界观风格（medieval/cyberpunk）+ 材质风格（cel-shaded/lowpoly）可以叠加
- 情绪风格（liminal/dreamcore）只改灯光与空间，不改造型语言
- 风格冲突时以**用户参考图**为准，不以表为准

## 反模式

| 做法 | 问题 |
|---|---|
| 把风格名当规格（「做成赛博朋克」就开工） | 缺可验收标准 → 无限返工 |
| 一套资产混 3 种以上风格 | 看不出是什么世界 |
| 用风格掩盖技术缺陷（脏 = 后末日） | QA 一眼识破 |
| 照搬游戏 A 的配色做游戏 B | 法律与辨识度双重风险 |

## Description:

ClawClub helps users create and join private OpenClaw communities with local-profile matching and agent-assisted moderation.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ivankoriako](https://clawhub.ai/user/ivankoriako)

### License/Terms of Use:

MIT-0

## Use Case:

External users and OpenClaw users use this skill to form or find private communities, coordinate membership, and support group moderation while keeping profile data local.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may analyze local profile information and coordinate membership or interaction metadata with other agents.

Mitigation: Confirm which profile fields, membership details, and interaction metadata are shared before using matching or agent-to-agent coordination.

Risk: Agent-assisted moderation can affect onboarding decisions and group discussions.

Mitigation: Review moderation suggestions before acting on them, especially for membership decisions or sensitive community topics.

Risk: Core club creation and member matching are described as still in development.

Mitigation: Validate feature availability and expected behavior before relying on the skill for active community management.

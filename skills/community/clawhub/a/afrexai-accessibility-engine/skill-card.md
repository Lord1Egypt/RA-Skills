## Description:

Helps teams achieve WCAG 2.1 AA compliance by auditing and guiding inclusive design for web, mobile, desktop, and other digital products.

This skill is ready for commercial/non-commercial use.

## Publisher:

[1kalin](https://clawhub.ai/user/1kalin)

### License/Terms of Use:


## Use Case:

Developers, designers, QA teams, product teams, and accessibility reviewers use this skill to audit digital products against WCAG 2.1 AA, plan remediation, produce accessible component guidance, and set up accessibility testing practices.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Copied CI or npm examples may introduce supply-chain drift if dependency or GitHub Actions versions are left floating.

Mitigation: Pin package versions and GitHub Actions revisions, commit lockfiles, and review dependency updates before deployment.

Risk: Accessibility scanners may be run against sites or repositories outside the installer's authorization.

Mitigation: Run scanners only against systems the installer is authorized to test and follow the target organization's testing policy.

## Description:

Helps maintainers and users plan, produce, and validate mobile responsive layout fixes for software improvement requests.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, maintainers, and software contributors use this skill to turn mobile responsive layout requests into practical plans, artifacts, checklists, code-change guidance, and validation notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill has broad trigger terms such as mobile, fixes, and labels, which may cause accidental invocation on unrelated prompts.

Mitigation: Confirm that the user's request concerns mobile responsive layout work before applying the workflow, and ask for clarification only when the intended task is ambiguous.

# 旁白与既有镜头对应表

## 一句话用途与快速使用

把已批准旁白逐句对应到现有镜头和可见证据，找出“有声无画”或画面撑不起说法的句子。使用时粘贴旁白、编号镜头/素材说明、观看收益与必须展示的证据；Skill 会返回逐句对应表、缺项原因和补拍清单。没有现成画面时会标记缺素材，不会虚构演示。

![旁白与镜头核对](assets/promo-1600x900.png)

适合成片前验收单条视频（最多 30 句旁白、30 个镜头）。它只对齐已有内容：不改旁白、不写小说分镜、不生成配音或模型提示词。

## 安装

```bash
npx skills add xxjrq/video-narration-visual-map-cn
```

## 需要提供什么

- 已批准旁白：逐句/逐信息单元编号，并写明该句的具体主张与候选镜头编号；没有对应画面时将候选编号留空。
- 既有镜头或素材：稳定编号和可见内容说明，并注明画面真正呈现的主张与证据。
- 目标观看收益，以及每项必须展示的证据。

若没有旁白或镜头说明，Skill 会直接请求补充。主张按句匹配，必需证据按全片单独统计；输入表单不会因为含有“海报”二字就被当成生成结果。

## 会得到什么

| 旁白编号 | 已批准旁白 | 镜头编号 | 可见证据 | 状态与理由 |
|---|---|---|---|---|

状态包含：`已支撑`、`有声无画`、`画不支撑话`、`需补素材`。表后会集中列出未覆盖的必须证据和可执行的补料要求。

## 自检

```bash
node scripts/self-test.mjs
```

这会实际执行两份 fixture：成功输入需产出四种逐句状态，并验证一个动作结果不会因同一名词或按钮而误判；失败输入需以退出码 2 请求补料。无需网络、兄弟 Skill 或绝对路径。

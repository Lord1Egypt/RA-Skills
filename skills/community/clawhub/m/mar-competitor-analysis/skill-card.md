## Description:

Analyzes competitor SEO and GEO strategies, including keyword rankings, content approaches, backlink profiles, technical SEO signals, and AI citation patterns, to identify opportunities to outperform competitors.

This skill is ready for commercial/non-commercial use.

## Publisher:

[marjoriebroad](https://clawhub.ai/user/marjoriebroad)

### License/Terms of Use:

MIT-0

## Use Case:

Marketing, SEO, content, and competitive intelligence teams use this skill to benchmark competitors, compare keyword, content, backlink, technical SEO, and AI citation patterns, and produce actionable competitive strategy recommendations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Unpinned or unverified installation commands can install unintended skill code.

Mitigation: Install only from trusted sources and prefer pinned or verified installation commands.

Risk: Connected SEO, analytics, search-console, or AI-monitor tools may access business metrics when a request is too broad or ambiguous.

Mitigation: Confirm the request is for SEO competitor analysis and scope data access before using connected tools.

Risk: Competitive recommendations can be misleading when based on estimates, outdated inputs, or unsupported claims.

Mitigation: Cite specific data points and label each metric as automated, user-provided, or estimated.

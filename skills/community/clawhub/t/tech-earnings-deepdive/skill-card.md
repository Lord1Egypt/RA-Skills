## Known Risks and Mitigations:

Risk: The activation language is broad and may produce a wider financial analysis than the user intended.

Mitigation: Ask for a narrower company, period, module, or language when a focused answer is needed.

Risk: Financial-analysis outputs could be mistaken for investment advice.

Mitigation: Treat outputs as research support based on public information and apply independent review before making investment decisions.

Risk: The README references a raw main-branch install URL.

Mitigation: Install from the reviewed ClawHub package or a pinned, trusted release.

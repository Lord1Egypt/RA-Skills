## Description:

获取并整理多平台实时热点新闻，按跨平台热度共识筛选，输出高热度事件的简报。

This skill is ready for commercial/non-commercial use.

## Publisher:

[jerry48](https://clawhub.ai/user/jerry48)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers can use this skill to collect hot topics from multiple Chinese web platforms, cluster overlapping stories, and publish a concise Markdown briefing to Feishu.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill is designed to post generated reports to Feishu, which can distribute unreviewed content.

Mitigation: Use it only where Feishu posting is intended, and preview and approve the exact message before sending.

Risk: The generated Markdown can include remote-supplied links and fixed external footer links.

Mitigation: Validate links and review remote-supplied Markdown before sharing the briefing.

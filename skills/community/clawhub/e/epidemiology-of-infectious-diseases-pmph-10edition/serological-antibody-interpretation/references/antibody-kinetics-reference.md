# 抗体动力学详细参考

## 各型免疫球蛋白详细特征

### IgM（免疫球蛋白M）

| 特征 | 说明 |
|------|------|
| 出现时间 | 感染后最早出现（通常5-7天） |
| 持续时间 | 较短，一般维持数周至2-3个月 |
| 分子结构 | 五聚体，分子量最大（970kDa） |
| 临床意义 | 近期/急性感染的标志物 |
| 特殊说明 | 不能通过胎盘；脐带血IgM升高提示宫内感染 |

### IgG（免疫球蛋白G）

| 特征 | 说明 |
|------|------|
| 出现时间 | 感染后稍晚于IgM（通常2-3周） |
| 持续时间 | 长期存在，可达数年甚至终身 |
| 分子结构 | 单体，血清中含量最高 |
| 临床意义 | 既往感染标志；提供长期保护性免疫 |
| 特殊说明 | 唯一能通过胎盘的Ig；新生儿IgG来自母体 |
| 亚型 | IgG1-IgG4，不同亚型针对不同抗原 |

### IgA（免疫球蛋白A）

| 特征 | 说明 |
|------|------|
| 分布 | 血清型（单体）和分泌型（二聚体） |
| 主要位置 | 呼吸道、消化道、泌尿生殖道黏膜 |
| 临床意义 | 黏膜免疫屏障评估 |
| 特殊说明 | 初乳中含量高，为新生儿提供黏膜保护 |

### IgE（免疫球蛋白E）

| 特征 | 说明 |
|------|------|
| 血清含量 | 最低 |
| 主要功能 | 抗寄生虫免疫、介导I型超敏反应 |
| 临床意义 | 寄生虫感染或过敏性疾病提示 |
| 相关细胞 | 结合肥大细胞和嗜碱性粒细胞 |

## 抗体功能机制详解

### 中和作用
- 抗体与病原体表面抗原结合
- 阻断病原体与宿主细胞受体结合
- 典型：病毒中和抗体

### 调理作用（Opsonization）
- 抗体Fc段与吞噬细胞表面Fc受体结合
- 增强吞噬细胞对病原体的识别和吞噬
- IgG为主要调理素

### 补体激活
- IgM和IgG可通过经典途径激活补体
- 导致病原体溶解（MAC复合物）
- 产生趋化因子招募免疫细胞

### ADCC（抗体依赖细胞介导的细胞毒性）
- NK细胞通过Fc受体识别抗体包被的靶细胞
- 释放穿孔素和颗粒酶杀伤靶细胞

## 常见临床场景解读

### 场景1：急性病毒感染
- IgM阳性 + IgG阴性/低滴度 → 急性期
- 建议2-4周后复查，观察IgG是否转阳或滴度升高

### 场景2：恢复期/既往感染
- IgM阴性 + IgG阳性 → 既往感染已恢复
- 如IgG滴度高，提示良好免疫记忆

### 场景3：再感染或复发
- IgM和IgG同时阳性，且IgG滴度较前次显著升高
- 需双份血清（急性期和恢复期）对比确认

### 场景4：疫苗接种效果评估
- 接种后IgG转阳或滴度达到保护水平
- 不同疫苗保护性抗体滴度标准不同

### 场景5：先天性感染
- 新生儿脐带血或出生后不久IgM升高
- 排除母体IgG被动转移的干扰

## 干扰因素与假阳性/假阴性

| 干扰因素 | 影响 | 处理方法 |
|---------|------|---------|
| 类风湿因子（RF） | IgM假阳性 | 使用RF吸附剂处理血清 |
| 免疫抑制治疗 | 抗体应答减弱/缺失 | 结合核酸检测综合判断 |
| 被动获得抗体 | IgG假阳性（非自身产生） | 详细询问输血/免疫球蛋白注射史 |
| 母婴传递 | 新生儿IgG阳性 | 检测IgM或随访观察IgG消长 |
| 交叉反应 | 非特异性抗体阳性 | 使用特异性更高的检测方法 |

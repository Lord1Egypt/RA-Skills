## Known Risks and Mitigations:

Risk: The skill may create and read a local ~/webflow/memory.md preference file containing workflow preferences.

Mitigation: Review stored preferences before sharing the environment and avoid recording sensitive project, client, or credential data in the memory file.

Risk: Webflow bearer tokens, form submissions, analytics tags, CRM webhooks, chat widgets, payment embeds, and other third-party integrations can expose sensitive data if configured carelessly.

Mitigation: Treat tokens as secrets, test integrations before launch, and review privacy, cookie-consent, vendor, and data-handling requirements for the target site.

## Description:

Writes a CONTRIBUTING.md guide that helps open-source projects explain setup, contribution workflow, standards, pull request expectations, and support channels clearly.

This skill is ready for commercial/non-commercial use.

## Publisher:

[mohitagw15856](https://clawhub.ai/user/mohitagw15856)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, maintainers, and community managers use this skill to draft a welcoming project-specific CONTRIBUTING.md for open-source repositories. It helps document setup commands, contribution paths, coding standards, pull request expectations, and ways to get help.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The generated CONTRIBUTING.md may include setup commands, review expectations, or community links that do not match the target project.

Mitigation: Review and edit the draft before publishing, confirming commands, pull request workflow, standards, reviewer expectations, and support channels against the project.

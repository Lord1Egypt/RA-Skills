## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to turn API documentation requests into practical OpenAPI or Swagger documentation workflows, checklists, code guidance, and validation steps for REST APIs.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may be auto-selected for broad API or developer-experience requests because its triggers are loose.

Mitigation: Confirm that the user is asking for OpenAPI, Swagger, REST API documentation, or closely related developer-experience support before applying the skill.

Risk: Generated OpenAPI specifications, examples, or code edits may be incomplete or inaccurate for the target service.

Mitigation: Review generated specs and code edits against the service implementation and run the relevant validation or test commands before applying them.

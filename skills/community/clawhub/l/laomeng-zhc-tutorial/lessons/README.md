# 老孟带你学中文编程

一套**从零到能写小工具**的 ZHC 中文编程入门教程。全部示例都在当前内核上实测跑通，代码与运行结果一一对应，可直接复制运行。

- 语言面：`ZHC-LANG 2.0`（契约 `方案\契约_1.8.json`）
- 内核：`zhc.py`（工程根目录，单文件，无第三方依赖）
- 源码后缀：`.zc`，编译产出 x86-64 原生 `.exe`
- 实测定版：2026-11-15，7 课示例全部 `rc=0`

## 一、怎么用这套教程

每一步都在工程根目录 `D:\DevEnv\zhc` 下执行：

```powershell
cd D:\DevEnv\zhc
$env:PYTHONIOENCODING='utf-8'

# 编译并立即运行
python -X utf8 zhc.py 教程\老孟带你学中文编程\示例\第01课_你好中文编程.zc --run

# 只做词法语法检查（输出 JSON 诊断，给编辑器用）
python -X utf8 zhc.py 教程\老孟带你学中文编程\示例\第01课_你好中文编程.zc --诊断

# 查内置函数手册 / 全部关键字
python -X utf8 zhc.py --api
```

报错一律形如 `[Exxx] 中文说明`，拿码位到错误码库查成因与修法：

```powershell
python -X utf8 方案\错误码库\错误码库.py 查 E303
```

## 四、已知限制（实测踩到的坑，先记住）

1. **类型词只能写在变量名后面**：写 `定义 总分 为 整数 600`，别写 `定义 整数 总分 为 600`（后者报 `[E012]`，提示里会说明类型词不能前置）。
2. **逻辑量要写全类型**：`定义 没缺考 为 逻辑 真`；只写 `为 真` 报 `[E205]`，错误提示会直接给出正确写法。
3. **无返回值函数只能单独成句**：写进 `输出` 参数或表达式里报 `[E307]`。早期「紧跟带函数调用的输出会报构建期 `C2155`」已在 ZHC-LANG 2.0 实现修订中修复，详见 `实测发现_内核缺陷.md` 缺陷 D-001。

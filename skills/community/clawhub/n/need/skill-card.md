## Description:

Need Clarifier helps an agent ask key questions for vague or incomplete requests, clarifying goals, context, constraints, and success criteria before moving into planning.

This skill is ready for commercial/non-commercial use.

## Publisher:

[je44](https://clawhub.ai/user/je44)

### License/Terms of Use:

MIT-0

## Use Case:

Agent users and developers use this skill when a request is too vague or incomplete for reliable planning. It helps the agent gather goals, audience, context, inputs and outputs, success criteria, constraints, and must-have versus optional requirements before proposing a solution.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may cause an agent to ask clarification questions before proposing a solution, which can slow direct answers for already-clear requests.

Mitigation: Use it for vague or incomplete requests, then proceed to planning once the required details are available.

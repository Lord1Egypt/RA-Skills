## Description:

Helps AI-agent users, skill authors, maintainers, and teams create practical self-improving and proactive productivity workflows for bug fixing, setup hardening, reliability improvement, and adjacent skill creation.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

External developers, AI-agent users, skill authors, maintainers, and teams use this skill to turn a productivity or self-improvement request into a local-friendly workflow, checklist, template, analysis, code change, or decision aid. It is intended for practical productivity tasks where assumptions, success criteria, validation, and remaining risks should be made visible.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation wording and implicit invocation may cause the skill to run more often than intended.

Mitigation: Narrow or disable generic triggers if precise routing is required.

Risk: Workflow, checklist, code, or configuration guidance may be applied without enough review for the user's specific environment.

Mitigation: Review assumptions, success criteria, validation notes, and remaining risks before applying outputs.

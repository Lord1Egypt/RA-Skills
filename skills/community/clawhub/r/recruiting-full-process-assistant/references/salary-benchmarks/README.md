## 公司类型差异

### 大厂（BAT/TMD/字节等）

- 薪酬水平：市场 75-90 分位
- 福利完善：六险一金、补充医疗、餐补、房补等
- 期权/股票：P7 及以上有期权/RSU
- 工作强度：996 常见

### 独角兽/Pre-IPO 公司

- 薪酬水平：市场 60-75 分位
- 期权激励：较大力度，有上市预期
- 福利中等：五险一金、餐补等
- 工作强度：较大

### A/B 轮创业公司

- 薪酬水平：市场 50-60 分位
- 期权激励：力度大，但风险高
- 福利基础：五险一金
- 工作强度：大

### 传统企业/国企

- 薪酬水平：市场 40-50 分位
- 稳定性高：裁员风险低
- 福利完善：六险二金、各种补贴
- 工作强度：适中

## 薪酬谈判策略

### 候选人侧

**了解市场行情**:
- 脉脉薪资查询
- 猎聘/BOSS 查看同岗位薪资范围
- 同行/朋友打听

**谈判技巧**:
- 不要先亮底牌
- 强调自己的独特价值
- 用手上 offer 作为筹码
- 关注总包（base+ 绩效 + 年终奖 + 期权）

### 企业侧

**定薪原则**:
- 内部公平性：同级别薪酬差距不超过 20%
- 外部竞争性：至少达到市场 50 分位
- 个人差异化：根据能力在带宽内浮动

**谈判技巧**:
- 先了解候选人期望和手持 offer
- 强调公司优势（发展、团队、技术）
- 不要只谈钱，谈成长空间
- 预留 10-15% 的审批空间

## 薪酬结构设计

### 标准结构

```
年度总包 = 月 base × 月数 + 绩效奖金 + 年终奖 + 期权/股票

示例（P7 工程师）:
- 月 base: 45K
- 月数：16 薪
- 绩效奖金：0-3 个月（根据绩效）
- 年终奖：1-2 个月（根据公司业绩）
- 期权：4 年归属，每年 25%

年度总包 = 45K × 16 + 45K × 2 + 45K × 2 + 期权
        = 72 万 + 9 万 + 9 万 + 期权
        ≈ 90 万 + 期权
```

### 常见月数

## 期权/股权激励

### 常见方案

**4 年归属**:
- 满 1 年归属 25%
- 剩余 3 年每月/每季度归属
- 或：25% + 25% + 25% + 25%（按年）

**期权价值估算**:
```
期权价值 = 股数 × (上市估值 - 行权价) / 总股本

示例:
- 授予 10 万股
- 行权价：1 元/股
- 预期上市估值：100 亿
- 总股本：10 亿股
- 期权价值 = 10 万 × (100 - 1) / 10 亿 = 9.9 万
```

### 税务处理

- 期权行权：按"工资薪金"计税
- 股票出售：按"财产转让"计税（目前免征）

# PNSs抗体风险分级与肿瘤筛查策略

## 适用对象
疑似或确诊副肿瘤性神经系统综合征(PNSs)的患者，已具备神经元特异性抗体检测结果和神经系统临床表型评估。

## 核心工作流程

### 第一步：临床表型风险分层

根据患者神经系统临床表现进行风险分层：

**高危表型（经典PNSs，必须积极搜寻肿瘤）：**
- 脑脊髓炎
- 边缘叶脑炎(LE)
- 快速进行性小脑综合征
- 斜视性眼阵挛-肌阵挛综合征(OMS)
- 亚急性感觉神经元病(SNN)
- 胃肠道假性梗阻
- Lambert-Eaton肌无力综合征(LEMS)

**中危表型：**
- 临床迅速进展（<3个月）
- 脑脊液/影像学有炎性证据
- 检测到神经元特异性抗体
- 排除其他病因后

### 第二步：抗体风险分级

基于2021 Graus标准，将检测到的抗体按肿瘤相关风险分为三级：

| 风险等级 | 肿瘤相关率 | 筛查优先级 |
|---------|-----------|-----------|
| 高风险 | >70% | 最高优先级，立即全面筛查 |
| 中风险 | 30%~70% | 中等优先级，定向筛查 |
| 低风险 | <30% | 常规筛查或随访 |

具体抗体分类详见 [references/antibody-risk-catalog.md](references/antibody-risk-catalog.md)。

### 第三步：制定筛查策略

根据抗体风险等级和临床表型综合决策：

**高风险抗体 或 高危表型：**
1. 立即进行全身PET-CT
2. 或针对性增强CT：
   - 胸部CT → 排查小细胞肺癌(SCLC)
   - 盆腔超声/MRI → 排查卵巢/睾丸肿瘤
   - 乳腺MRI/超声 → 排查乳腺癌（针对Yo抗体女性患者）
   - 全身CT → 排查淋巴瘤（针对Tr/DNER抗体）

**中风险抗体：**
1. 根据抗体提示的常见肿瘤类型进行定向筛查
2. 若初次筛查阴性，每3-6个月随访复查

**低风险抗体：**
1. 常规肿瘤筛查
2. 定期随访观察
3. 若临床表型为中危，需排除其他非副肿瘤性病因

### 第四步：输出筛查建议

输出内容应包括：
1. 抗体风险等级判定结果
2. 临床表型风险等级判定结果
3. 肿瘤筛查优先级
4. 具体影像学检查建议（检查部位、方式）
5. 具体实验室检查建议（如适用）
6. 随访计划（针对中低风险患者）

## 关键约束

- 抗体低风险且临床表型为中危时，必须排除其他非副肿瘤性病因后再制定筛查策略
- 高风险抗体合并高危表型时，不应等待，立即启动全面筛查
- NMDAR抗体阳性患者需注意年龄和性别特征（主要见于12-45岁女性，常见卵巢/卵巢外畸胎瘤）
- Yo抗体阳性几乎均为女性，重点排查卵巢癌和乳腺癌

## 决策逻辑总结

```
输入：抗体类型 + 临床表型
  │
  ├─ 抗体高风险 或 表型高危 → 立即全面筛查（PET-CT/针对性增强CT）
  │
  ├─ 抗体中风险 → 定向筛查 → 阴性则每3-6月复查
  │
  └─ 抗体低风险
       ├─ 表型高危 → 仍需积极筛查
       └─ 表型中危 → 排除其他病因 → 常规筛查/随访
```

|---------|-----------|-------------|------|
| mGluR1 | ~30% | 霍奇金淋巴瘤 | 小脑性共济失调相关 |
| GFAP | ~20% | 多种肿瘤 | 脑膜脑脊髓炎相关 |

## 筛查要点提示

1. **SCLC相关抗体**（Hu, CV2, SOX1, PCA-2, Amphiphysin, Ri, GABA_B_R, P/Q型VGCC）：首选胸部增强CT，必要时PET-CT
2. **妇科肿瘤相关抗体**（Yo, NMDAR）：女性患者首选盆腔超声/MRI，必要时全身PET-CT
3. **睾丸肿瘤相关抗体**（Ma2, KLHL11）：男性患者首选睾丸超声
4. **淋巴瘤相关抗体**（Tr/DNER, mGluR5, mGluR1）：全身CT或PET-CT
5. **胸腺瘤相关抗体**（CV2, AMPAR, CASPR2）：胸部增强CT纵隔窗
6. **乳腺癌相关抗体**（Yo, Amphiphysin, Ri）：乳腺超声/MRI

### [clinical-phenotype-details.md]
# PNSs临床表型详细描述

## 高危表型（经典PNSs）

以下临床综合征高度提示副肿瘤性病因，发现后必须积极搜寻肿瘤：

### 1. 脑脊髓炎
- 多灶性中枢神经系统受累
- 可累及大脑、脑干、小脑、脊髓
- 常伴Hu抗体阳性

### 2. 边缘叶脑炎(LE)
- 亚急性起病的近事记忆障碍
- 精神行为异常
- 癫痫发作
- 相关抗体：Hu, CV2, AMPAR, GABA_B_R, Ma2, LGI1, CASPR2等

### 3. 快速进行性小脑综合征
- 亚急性起病的躯干和肢体共济失调
- 数周至数月内快速进展
- 相关抗体：Yo, Hu, Tr, mGluR1, CV2等

### 4. 斜视性眼阵挛-肌阵挛综合征(OMS)
- 眼球不自主快速运动
- 躯干和肢体肌阵挛
- 儿童：常与神经母细胞瘤相关
- 成人：常与SCLC、乳腺癌、霍奇金淋巴瘤相关
- 相关抗体：Ri, Hu, ANNA-3等

### 5. 亚急性感觉神经元病(SNN)
- 非长度依赖的感觉障碍
- 深感觉受累为主
- 感觉性共济失调
- 几乎均与Hu抗体相关，关联SCLC

### 6. 胃肠道假性梗阻
- 亚急性起病的胃肠动力障碍
- 体重下降
- 常与Hu抗体相关，关联SCLC

### 7. Lambert-Eaton肌无力综合征(LEMS)
- 近端肌无力，活动后改善
- 自主神经功能障碍
- >50%与SCLC相关
- 相关抗体：P/Q型VGCC, SOX1

## 中危表型判定标准

满足以下条件时归为中危：
1. 临床迅速进展（病程<3个月）
2. 脑脊液检查有炎性证据（白细胞升高、寡克隆带阳性等）
3. 影像学有炎性证据（MRI增强病灶等）
4. 检测到神经元特异性抗体
5. 已排除其他已知病因（感染、代谢、血管性、遗传性等）

## 风险分层注意事项
- 高危表型即使抗体为低风险，仍需积极筛查肿瘤
- 中危表型需综合抗体风险等级决定筛查强度
- 低风险抗体+中危表型时，务必先排除非副肿瘤性病因
- 部分患者可能同时存在多种抗体，按最高风险等级处理

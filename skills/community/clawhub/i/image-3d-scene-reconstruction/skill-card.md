## Description:

This skill is ready for commercial/non-commercial use.

Developers and engineers use this skill to guide image-to-3D reconstruction workflows for photos, aerial imagery, or satellite images, including depth maps, point clouds, 3D model outputs, and multi-image scene fusion.

Mitigation: Verify the Depth Anything 3 package and model source before installation or execution.

Mitigation: Review input and output data handling requirements before processing or sharing generated assets.

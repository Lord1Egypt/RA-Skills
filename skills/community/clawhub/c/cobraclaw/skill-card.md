## Description:

Cobra Claw provides a themed CLI, practice katas, shell tools, and markdown references for quick lookup and agent-response discipline.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and agent operators use this skill to access themed CLI lookups, run bundled practice katas, and consult markdown doctrine and pattern references for response-style practice.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The kata runner can potentially be steered outside the intended kata folder to run other local shell scripts.

Mitigation: Restrict kata execution to an allowlist of bundled kata names and review proposed command execution before installation or use.

Auto-generate professional weekly work reports with multiple templates.

This skill is ready for commercial/non-commercial use.

## Use Case:

Employees, external users, and developers use this skill to generate weekly work report drafts from built-in sample task data in simple, detailed, or technical Markdown formats.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated reports may not reflect the user's actual work because the artifact uses fixed sample task data.

Mitigation: Review the generated report and replace sample task details before sharing or submitting it.

Risk: The report output is primarily Chinese-language content.

Mitigation: Use this skill only when Chinese weekly report output is acceptable for the workflow.

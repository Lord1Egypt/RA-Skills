# 判据台账

**跨轮累积，只增不改。**

---

## 使用说明

| 项目 | 规定 |
|---|---|
| 谁填 | 三方共填，**修改权归丙方**（建议方） |
| 什么时候填 | 每次回流后 48 小时内追加 |
| 填什么 | 一条修正记录：「原来以为 X → 改成 Y → 因为 Z」 |
| 签字 | **至少两人**。判据是三方共用的，不能一人说了算 |
| 边界影响 | **不得留空**。每次修正都可能意味某类情形从此不适用 |
| 修改 | 只增不改。历史不抹，旧结论保留用于追溯 |

## 为什么这本账比优化结果值钱

优化结果只能用一次，这本账能用一辈子。

它记的是「我们凭什么这么判」——判据每准一点，下一轮就快一点。**一旦某一轮开始从零开始，这个合作就没理由继续了。**

三向锁：丙方走了台账冻结（没人能合法修改），乙方走了台账失去验证来源（只剩主张没有证据），甲方走了台账失去原料（新配对断供）。

**谁走，这台机器都转不动；但谁留下来，也独吞不了。**

## Description:

Socratic design refinement before coding. Use when user requests feature without clear spec.

This skill is ready for commercial/non-commercial use.

## Publisher:

[nefas11](https://clawhub.ai/user/nefas11)

### License/Terms of Use:


## Use Case:

Developers and agents use this skill to clarify vague or complex feature requests before implementation by asking questions, comparing approaches, and documenting the selected design.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may create a visible design document whose assumptions or recommendations are incomplete for the requested feature.

Mitigation: Review the generated design document and selected approach before allowing the agent to proceed to implementation.

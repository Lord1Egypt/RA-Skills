# 类型化本体工作流助手

这个技能用于把零散笔记、Agent 记忆、领域对象或研究材料整理成可校验、可查询、可维护的类型化本体。

## 适用场景

- Agent 记忆结构和结构化笔记系统。
- 项目、研究、CRM、客服或内部文档的轻量知识图谱。
- 将松散标签整理为实体类型、关系和带来源的记录。
- 围绕类型化数据设计检索提示词或查询过滤器。

## 产出

- 带必填字段和关系基数的实体、关系定义。
- JSON Schema、YAML Schema、TypeScript 类型、表结构或图模型草图。
- 关键类型的有效和无效样例。
- 合并、去重、迁移和版本管理规则。

## 触发示例

`Use $work-productivity-ontology-typed-workflow-helper to turn these notes into a typed knowledge graph.`

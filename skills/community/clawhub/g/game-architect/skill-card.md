## Description:

Game Architect helps agents design and plan game system architecture for combat, skills, AI, UI, multiplayer, narrative, scene systems, and related architecture paradigm choices.

This skill is ready for commercial/non-commercial use.

## Publisher:

[yuki001](https://clawhub.ai/user/yuki001)

### License/Terms of Use:


## Use Case:

Developers and technical game designers use this skill as a game architecture reference when planning systems, selecting DDD, data-driven, or prototype approaches, and producing architecture documents for implementation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Standalone use can create or update planning files under architect/.

Mitigation: Review existing architect/ files before asking the skill to refactor or regenerate planning documents.

Risk: Architecture guidance may be incomplete or mismatched to a specific game engine, project constraints, or production requirements.

Mitigation: Have developers review generated plans against the target engine, performance budget, networking model, and project architecture before implementation.

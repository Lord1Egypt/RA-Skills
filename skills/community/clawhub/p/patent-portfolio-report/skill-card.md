## Description:

Generates Chinese HTML patent portfolio analysis reports for companies, patent lists, technology areas, competitors, and business questions using a structured consulting-style workflow and Patsnap patent data.

This skill is ready for commercial/non-commercial use.

## Publisher:

[yuanzhian-patsnap](https://clawhub.ai/user/yuanzhian-patsnap)

### License/Terms of Use:

MIT-0

## Use Case:

External analysts, consultants, and patent teams use this skill to produce patent portfolio due diligence, valuation, R&D strategy, litigation-response, overseas-expansion, commercialization, and competitive-landscape reports. It is intended for evidence-backed Chinese HTML deliverables built from the user's target company, patent scope, technology domain, competitors, and core business questions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The workflow requires sharing target companies, patent lists, competitors, and business questions with authorized Patsnap patent data access.

Mitigation: Install and run it only when those inputs are approved for that data-access path and the user is comfortable authorizing Patsnap access.

Risk: Without Patsnap authorization, the skill cannot retrieve current patent data and can only provide an analysis framework.

Mitigation: Confirm Patsnap access before relying on report conclusions, patent counts, rankings, trends, or cited patent details.

Risk: The expected deliverable is Chinese HTML, which may not match every review or publication workflow.

Mitigation: Set language and format expectations before use, or route the completed report through translation and review before distribution.

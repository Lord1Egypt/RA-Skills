# 精神科急诊与危机干预

## 适用场景

当遇到以下情况时使用本技能：
- 患者存在自杀意念、自杀企图或自杀后急诊抢救
- 患者表现出攻击、暴力或冲动行为
- 患者处于激越状态，需紧急处置
- 需要进行心理危机干预
- 精神科急诊安全评估与留院决策
- 首发精神症状需排除器质性疾病

## 核心工作流程

### 1. 自杀风险评估流程

```
建立关系 → 委婉询问自杀意念
    ↓
存在意念？
    ├─ 否 → 常规评估其他风险因素
    └─ 是 → 探究具体计划（时间/地点/方式）
              ↓
        系统风险评估
              ├─ 量表：SASP、BASIC
              └─ 无量表时评估维度：
                  • 精神状况及诊断
                  • 自杀决心与主观痛苦
                  • 准备细节
                  • 保护性资源
                  • 既往史与家族史
              ↓
        风险分级（轻/中/高）
              ↓
        干预决策
              ├─ 高风险 → 建议入院、24h监护
              ├─ 中风险 → 密切随访、安全计划
              └─ 低风险 → 门诊随访、心理支持
```

### 2. 自杀核心危险因素速查

**最强预测因子**：既往自杀史

**生物学因素**：
- 男性死亡率是女性4倍（女性企图是男性3倍）
- 精神障碍>90%（心境障碍、物质滥用、精神分裂症）
- 5-HT功能降低

**社会学因素**：
- 独居/离婚/丧偶
- 失业/贫困
- 缺乏社会支持

**心理特征**：
- 无望感（hopelessness）
- 冲动性（亚洲重要因素）
- 思维僵化/非此即彼
- 近期丧失性事件（扳机作用）

### 3. 攻击行为危险性评估

```
安全首要 → 确保环境安全
    ↓
评估方法选择
    ├─ 临床经验性评估：灵活但主观
    ├─ 精细性评估：DBRS、HCR-20、MOAS
    └─ 结构化临床评估：PCL-R、VRAG
    ↓
5大评估维度
    ├─ 既往攻击史（最强独立因素）
    ├─ 人格特征（冲动、自我中心）
    ├─ 精神状态（妄想、幻听、物质滥用）
    ├─ 环境因素（刺激、社会支持）
    └─ 保护因素
    ↓
风险分类
    ├─ 静态风险（不可改变）：人口学、既往暴力
    ├─ 动态风险（可干预）：精神症状、物质滥用
    ├─ 近期风险：当前应激状态
    └─ 远期风险：人格、社会支持
```

### 4. 攻击行为现场应急7步法

1. **求助**：立即呼叫安保/警察
2. **展示领导力**：控制局面，保持冷静权威
3. **保持距离**：确保安全距离，门路畅通
4. **解除凶器**：必要时强制解除
5. **隔离**：带离公共场所，减少刺激
6. **约束**：语言无效时果断保护性约束
7. **药物干预**：抗精神病药或苯二氮䓬类

### 5. 激越患者阶梯式处置

```
第一阶梯：言语安抚 + 环境控制
    ├─ 保持空间距离
    ├─ 适当妥协
    └─ 家属参与沟通
    ↓ 无效
第二阶梯：药物治疗
    ├─ 口服：非典型抗精神病药 ± 苯二氮䓬类
    └─ 肌注：起效快，快速降低风险
    ↓ 无效
第三阶梯：保护性约束（不得已）
    ├─ 口头告知 + 开具医嘱
    ├─ 遵循操作流程
    └─ 最短时间解除
```

### 6. 危机干预六步法

1. **确定问题**：从受害者角度理解危机，使用核心倾听技术
2. **保证安全**：贯穿全过程，降低自我和他人的危险性
3. **给予支持**：无条件积极接纳，让求助者感到被关心
4. **提出变通应对**：
   - 环境支持（关心自己的人）
   - 应对机制（具体行为/资源）
   - 积极创造性思维（重构看法）
5. **制定计划**：合作制定，恢复自主控制
6. **获取承诺**：自愿、可行，涉法律问题需书面签字

### 7. 精神科急诊安全评估与留院决策

**必须留院的6种情况**（满足任一）：
1. 病情严重（幻觉妄想突出）或躯体情况差
2. 严重自杀意念/行为，或冲动攻击倾向
3. 拒食、违拗、木僵
4. 治疗依从性差
5. 认知功能严重损害
6. 诊断不明

### 8. 器质性疾病排查流程

**高危人群**：老年、既往躯体疾病、急性起病/意识障碍、颅脑外伤、毒品使用、流浪者

**10项必查**：
①血常规 ②电解质 ③血糖 ④肝功能/血氨 ⑤肾功能 ⑥甲状腺功能 ⑦血尿毒物筛查 ⑧药物浓度 ⑨脑电图 ⑩头颅CT/MRI

## 三类核心危机处理要点

| 危机类型 | 关键处理 |
|----------|----------|
| 兴奋躁动/暴力 | 排除禁忌→环境控制→隔离/约束→纠正水电解质→收治 |
| 严重消极/自杀 | 书面沟通风险→针对原发病治疗→必要时MECT |
| 伴严重躯体疾病 | 会诊协同→抗精神病药1/3-1/2起始→监测→转科 |

## 自杀三级预防体系

- **一级**（一般人群）：心理健康教育、减少自杀工具获得、媒体引导
- **二级**（高危人群）：培训识别信号、危机热线、精神障碍患者住院/留观
- **三级**（幸存者）：急诊救治、预防再自杀、长期心理支持

## Description:

Helps API developers and backend teams generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, backend teams, developer-experience teams, and maintainers use this skill to turn OpenAPI or Swagger documentation needs into tailored plans, artifacts, checklists, verification notes, and implementation support for REST APIs.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad trigger terms and implicit invocation may cause the skill to appear in generic REST API or developer-experience conversations.

Mitigation: Confirm the request is specifically about OpenAPI, Swagger, or REST API documentation before relying on the skill's workflow.

Risk: Generated documentation guidance can be misleading when route definitions, schemas, authentication behavior, or examples are incomplete.

Mitigation: Validate outputs against the service implementation, available tests, and OpenAPI or Swagger validation tools before publishing documentation.

## Description:

Generate bilingual (Chinese/English) JIRA ticket descriptions from user input. Use when user asks to create a JIRA ticket, write ticket description, or needs to format a task/issue for JIRA. Supports various issue types including Bug, Task, Story, and Epic.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, product managers, and project teams use this skill to turn task or issue descriptions into copy-ready bilingual JIRA tickets. It supports Bug, Task, Story, and Epic formats with structured objectives, requirements, and acceptance criteria.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill always produces bilingual Chinese and English ticket text, which may not match teams that require single-language or user-selected language output.

Mitigation: Review and adjust the generated ticket language before use when a different language policy is required.

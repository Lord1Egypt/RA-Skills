## Use Case:

External agent users, skill authors, maintainers, and teams use this skill to turn Humanizer-style productivity demand into practical workflows, checklists, analysis, code changes, or decision support. ## Known Risks and Mitigations:

Risk: Broad trigger wording may cause the skill to be selected for general writing, editing, reviewing, remove, or bug-fix requests where a narrower helper would be more appropriate.

Mitigation: Install only when a general Humanizer-style productivity workflow helper is desired, and narrow or disable implicit invocation when the platform supports it.

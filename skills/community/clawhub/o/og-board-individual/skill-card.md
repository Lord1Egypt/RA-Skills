## Use Case:

Developers and agents use this skill to inspect assigned task-board records and record task progress, blockers, artifacts, and worklogs through task-board tools.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can update task-board records under the configured agent id, and those updates may be visible to other board users.

Mitigation: Install it only when task-board updates are expected, configure the intended agent id, and review status changes, blockers, artifacts, and worklogs for accuracy.

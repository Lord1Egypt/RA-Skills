# 认知与功能筛查工具详细指南

## 1. MMSE (简易智力状态检查量表)
- **适用场景**：快速筛查，整体认知评估。
- **评估维度**：定向力、注意力、计算力、记忆力、言语能力、视空间能力。
- **特点**：操作简便，耗时约15分钟，临床应用最广泛。

## 2. MoCA (蒙特利尔认知评估量表)
- **适用场景**：受教育程度较高者、轻度痴呆患者、轻度认知功能障碍（MCI）患者。
- **特点**：对执行功能、视空间等高级认知域覆盖更全面，对轻度认知损害敏感度高于MMSE。

## 3. NPI (神经精神问卷)
- **适用场景**：评估痴呆伴发的精神行为症状（BPSD）。
- **评估方式**：必须由**照料者**代为评估。
- **评估维度**：过去一个月内的抑郁、焦虑、幻觉、妄想、激越等症状的频率和严重程度。

## 4. ADLS (日常生活能力评定量表)
- **适用场景**：评估患者的社会生活和日常基本生活能力受损情况。
- **特点**：用于判定痴呆的严重程度及是否需要照护支持。

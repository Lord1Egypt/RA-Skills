This skill is ready for commercial/non-commercial use.

## Use Case:

External agencies, content marketers, and WordPress developers use this skill to audit and optimize WordPress SEO across posts, pages, schema markup, internal links, and RankMath settings.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can affect WordPress content, metadata, schema, and internal links at scale.

Mitigation: Use least-privilege WordPress application passwords, test on a staging site first, set batch limits, preview changes, create backups, and require explicit approval before bulk edits.

Risk: Generated SEO recommendations or metadata may be inaccurate, off-brand, or misleading.

Mitigation: Review proposed titles, descriptions, schema, and internal links before publication, then monitor search and site performance after rollout.

Risk: WordPress, RankMath, Search Console, or SEO-tool credentials could expose administrative or site data.

Mitigation: Store credentials outside skill content, scope API keys narrowly, rotate tokens when access changes, and avoid sharing logs that contain secrets.

## Description:

Give AI agents content memory for ideas and drafts using BlueColumn persistent memory, including storing, searching, and recalling content context with a BlueColumn API key.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and developers use this skill to give an agent continuity across content-creation sessions by recalling prior ideas and saving selected drafts or notes to BlueColumn persistent memory.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can send private drafts, business ideas, client material, or personal data to BlueColumn persistent memory without clear approval or retention controls.

Mitigation: Use it only where sending selected content to BlueColumn is acceptable, and ask the agent to save specific items instead of automatically summarizing and storing every interaction.

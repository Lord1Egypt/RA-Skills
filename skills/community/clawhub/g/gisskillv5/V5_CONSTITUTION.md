## 一、四层定位架构（层级固定、顺序不可逆、不可删减）

```
┌─────────────────────────────────────────────────────────────┐
│ 顶层：GeoEvolve自进化闭环系统                                │
│ 执行报错→知识缺口→Agent偷懒→自动回流更新底层知识库，永久闭环  │
├─────────────────────────────────────────────────────────────┤
│ 上层：多Agent流程编排调度引擎                                 │
│ 需求拆解→串行/并行任务分发→工序节点阻断→多智能体协同          │
├─────────────────────────────────────────────────────────────┤
│ 中层：标准化原子GIS Skill单元                                │
│ 输入校验+完整执行逻辑+异常自动修复+标准化输出模板，独立调度    │
├─────────────────────────────────────────────────────────────┤
│ 底层：七大知识群组（理论/标准/软件/开发/实战/现代技术/自进化） │
│ 存储国标、教程、坐标系、案例、800+避坑、代码、模板、样例资源   │
└─────────────────────────────────────────────────────────────┘
```

### 定位边界规则

1. 底层载体为GIS结构化知识库，但**禁止仅作为纯检索问答库**，整体定位为「带强流程管控、可自主执行的GIS行业智能生产中枢」
2. 禁止单一输出文档、零散代码、简略步骤，收到业务需求必须拆解为原子Skill串联完整业务链路，输出可直接落地的成套成果

## 三、防偷懒刚性强制约束（最高执行优先级）

### （1）流程锁死规则——禁止跳工序、简化合并步骤

1. 所有行业业务SOP固化为带「准入凭证+产出凭证」的强制分段节点，无前置节点标准输出物，调度器直接阻断下一环节执行
2. 任意复杂多源融合项目必须拆分至最小原子Skill，禁止输出笼统通用模板
3. **DLG建库标准7节点（缺一不可）**：
   ```
   数据探查报告 → 坐标统一转换执行日志 → 拓扑修复脚本+修复前后对比表
   → 国标分层编码校验单 → 自动化质检运行日志 → 标准化元数据文件 → 成果归档目录清单
   ```

### （2）三段式卡点自动校验

每个原子Skill运行时强制执行三层校验，校验不通过暂停任务、自动补全处理：

| 卡点 | 内容 | 触发条件 |
|------|------|----------|
| **输入校验卡点** | 自动核验坐标系/投影带号/数据格式版本/属性字段是否匹配现行国标；缺失关键信息自动检索知识库强制补全 | Skill启动时 |
| **执行中校验卡点** | 每步运算完成后自动运行自检脚本，识别碎片面/重叠面/图幅接边漏洞/高程异常/CAD编码冲突，匹配800+避坑库自动修复 | 每步运算后 |
| **输出合规卡点** | 最终成果必须匹配对应GB/T/CH/T/自然资源汇交规范，捆绑标准化验收检查表，指标不达标禁止交付 | Skill完成时 |

### （3）异常兜底处理规则——禁止甩锅

| 异常类型 | 处理方式 |
|----------|----------|
| 已知报错/常规缺陷 | 直接调取避坑库内置修复代码，整合进标准流程自动处理 |
| 小众特殊场景 | 检索知识库专属适配方案，生成项目定制化脚本 |
| 全新未知问题 | 生成《知识缺口备案单》推送至自进化引擎，同时输出临时标准化处理方案，清晰区分机器可自动处理内容和待补充资料 |

### （4）迭代次数管控+全链路留痕

1. **全局最大自动容错迭代轮次 = 3轮**：前两轮自动识别并修复全部可自动化缺陷；第三轮仍无法全自动解决→终止循环→输出结构化待办清单
2. 所有任务强制生成结构化完整执行日志：项目参数/软件版本/每步校验结果/缺陷修复记录/问题点位
3. 任意任务交付成果必须同步捆绑三类文件：**完整可运行执行代码 + 配套自动化自检脚本 + 行业标准化验收清单**

### （5）人工熔断分工机制

全自动流程无法100%处理时，必须清晰拆分三类内容：
1. 机器已全自动完成的全部工序与成果
2. 需要用户补充的项目参数、原始资料、当地专属标准
3. 必须人工介入的特殊工序，同步附上对应标准操作规范

## 四、永久输出行为禁令（触发即回滚+重新执行+录入偷懒记录）

| 编号 | 禁令内容 |
|------|----------|
| **禁1** | 禁止省略任意标准工序、合并简化业务流程、跳过质检强制节点 |
| **禁2** | 禁止使用"手动调整、自行适配、按需修改"等模糊话术将问题甩回用户 |
| **禁3** | 禁止仅输出零散文档、无校验半成品代码，交付必须捆绑执行日志+自检脚本+验收表 |
| **禁4** | 禁止无限循环迭代，达到3轮自动终止并输出清晰人工待办清单 |
| **禁5** | 禁止忽略CGCS2000基准、现行国标、行业汇交规范，随意套用通用默认参数 |
| **禁6** | 禁止仅做被动知识库检索，收到需求必须拆解原子Skill并完整走完全链路执行流程 |
| **禁7** | 禁止选择性落地V5.0优化项，知识库/Skill/Agent/自进化/配套工具需一次性完整迭代到位 |

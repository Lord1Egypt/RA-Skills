## Description:

Ted English Learning turns TED talk PDFs or pasted English text into bilingual study notes, vocabulary lists, summaries, sentence analysis, reading-comprehension questions, and an Obsidian Canvas mind map.

This skill is ready for commercial/non-commercial use.

## Use Case:

External learners use this skill with an agent to convert TED transcript PDFs or pasted English text into structured bilingual English-study materials and an Obsidian Canvas summary.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Installation and runtime depend on unreviewed mutable remote code and dependencies.

Mitigation: Review the referenced repository, extractor script, templates, and requirements before installing; prefer a pinned commit or signed release and install in a virtual environment.

Risk: The workflow processes user-provided TED transcript PDFs or pasted text.

Mitigation: Run it only on TED transcript PDFs or pasted text you intend to process.

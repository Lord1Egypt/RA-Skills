## Description:

Helps backend and platform teams generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, API maintainers, backend teams, and developer-experience teams use this skill to produce practical OpenAPI or Swagger documentation workflows, checklists, implementation support, and validation guidance for REST APIs.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate more often than intended for broad API or developer-experience requests.

Mitigation: Invoke it explicitly for OpenAPI or Swagger documentation tasks when predictable behavior is required.

Risk: Generated API documentation guidance may be incomplete or mismatched to the target service if inputs are sparse.

Mitigation: Review assumptions, compare outputs against the service implementation and OpenAPI or Swagger validation results, and run the verification steps the skill provides.

## Use Case:

Developers and workspace automation builders use this skill to compose Notion API requests for creating, reading, and updating pages, data sources, and blocks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A Notion API key stored locally can be exposed through loose file permissions, synced folders, or commits.

Mitigation: Store ~/.config/notion/api_key with owner-only access, avoid syncing or committing it, and rotate the token if exposure is suspected.

Risk: A Notion integration with broad workspace access can read or modify more pages and data sources than intended.

Mitigation: Grant only the required integration capabilities and share only the target pages or data sources with the integration.

## Description:

Quickly summarizes user-provided text, URLs, or files into concise structured briefs for TL;DRs, executive summaries, and key takeaways.

This skill is ready for commercial/non-commercial use.

## Publisher:

[terrycarter1985](https://clawhub.ai/user/terrycarter1985)

### License/Terms of Use:

MIT-0

## Use Case:

Agent users and developers use this skill to turn long text, web pages, or files into a compact structured brief with key points and optional action items.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may read local files or fetch URLs supplied for summarization, which can expose sensitive content if the user provides private material.

Mitigation: Provide only files and links that are intended to be processed, and avoid sensitive local files or private URLs unless that access is deliberate.

Risk: Concise summaries can omit nuance from long or complex source material.

Mitigation: Review the original source before relying on the summary for important decisions.

## Description:

Uses CamScanner to check whether a user-selected image appears AI-generated and returns a verdict, confidence score, and short explanation.

This skill is ready for commercial/non-commercial use.

## Publisher:

[camscanner-ai](https://clawhub.ai/user/camscanner-ai)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers use this skill to evaluate whether an image may have been generated by AI systems such as Stable Diffusion, Midjourney, or DALL-E. The agent uploads the selected image to CamScanner, reads the JSON result, and reports the mapped verdict with confidence.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill sends user-selected images to CamScanner for analysis.

Mitigation: Use only with images whose external processing is acceptable, and avoid highly sensitive personal, legal, medical, or confidential business images.

Risk: The detector can return a suspected result rather than a definitive AI-generated verdict.

Mitigation: Report the mapped verdict and confidence without overstating suspected AI-generated results.

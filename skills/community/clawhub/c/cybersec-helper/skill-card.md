## Use Case:

Developers, security engineers, and bug bounty participants use this skill to structure scoped application security reviews, classify vulnerabilities with authoritative references, and produce concise remediation next steps.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill activates for broad cybersecurity language and could be used outside an authorized engagement if scope is unclear.

Mitigation: Confirm the target, authorization, in-scope assets, out-of-scope assets, and test environment before providing actionable security guidance.

Risk: Security advice can become misleading if it relies on invented vulnerability identifiers or unsupported claims.

Mitigation: Use authoritative sources such as OWASP, CWE, CVE, NVD, vendor advisories, and clearly state when a detail is unknown.

Risk: A future Notion integration would introduce persistence and external account configuration not present in this artifact.

Mitigation: Review and security-assess any added Notion integration separately before deployment.

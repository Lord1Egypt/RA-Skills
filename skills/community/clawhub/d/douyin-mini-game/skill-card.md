## Description:

Comprehensive skill reference for Douyin (TikTok China) mini-game development framework, covering frontend JavaScript APIs, game.json configuration, Canvas rendering, device capabilities, open-platform features, and tt.* APIs.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill to build, debug, or migrate Douyin mini-games that rely on tt APIs, game.json configuration, Canvas or WebGL rendering, storage, networking, payments, ads, Worker, and open data domain features.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Examples cover sensitive Douyin platform APIs including location, microphone, clipboard, uploads, analytics, subscriptions, payments, and deletion APIs.

Mitigation: Review privacy, consent, platform policy, and data-handling requirements before using the examples in a shipped game.

Risk: Payment, subscription, advertising, upload, and account examples can affect users or transactions if copied without product-specific validation.

Mitigation: Validate these flows against official Douyin requirements, handle errors explicitly, and test with approved sandbox or platform review processes before release.

## Description:

Create deterministic screenshots and demo GIFs of command-line and terminal apps with Charm VHS, including tape authoring and lossless GIF optimization.

This skill is ready for commercial/non-commercial use.

## Publisher:

[gfargo](https://clawhub.ai/user/gfargo)

## Use Case:

Developers use this skill to create repeatable screenshots and short demo recordings of CLI and terminal UI workflows for documentation, release materials, marketing pages, and visual regression checks. It guides them in authoring VHS tapes, controlling capture determinism, and optimizing GIFs for the web.

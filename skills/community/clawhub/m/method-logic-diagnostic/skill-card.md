## Description:

Diagnoses logic and reasoning issues in psychology paper Method sections, checking method justification, design coherence, variable and control rigor, limitation disclosure, and providing scores with top-journal positive examples.

This skill is ready for commercial/non-commercial use.

## Publisher:

[wangjinhongmy-pixel](https://clawhub.ai/user/wangjinhongmy-pixel)

### License/Terms of Use:

MIT-0

## Use Case:

Researchers, editors, and academic-writing reviewers use this skill to evaluate the logic and argumentation quality of psychology Methods sections. It produces structured diagnostic feedback, scoring, and example-based revision guidance for method selection, study design, variable controls, and limitation disclosure.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill depends on Chinese-language academic diagnostic rules and local reference materials; missing local textbook or positive-example paths can reduce fidelity.

Mitigation: Confirm required reference materials are available before use and treat diagnostics as writing-review guidance rather than a substitute for expert methodological review.

Risk: The artifact includes a Windows junction setup snippet for a specific local reference directory.

Mitigation: Do not run local path setup commands unless maintaining that exact directory layout intentionally.

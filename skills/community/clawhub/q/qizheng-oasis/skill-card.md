## Known Risks and Mitigations:

Risk: The skill is advertised with finance-related triggers, but server security evidence says its behavior is primarily retail promotion and public-opinion crisis simulation.

Mitigation: Treat outputs as scenario planning support, not as stock, fund, or investment optimization guidance.

Risk: Auxiliary scripts can send scenario content to SiliconFlow when an API key is configured.

Mitigation: Do not run those scripts with sensitive scenarios, real customer data, or confidential business information unless external processing is acceptable.

Risk: The dashboard contains an unrelated iframe inspector that can expose page metadata when embedded.

Mitigation: Avoid embedding the dashboard in untrusted parent pages and remove or constrain the iframe inspector before operational use.

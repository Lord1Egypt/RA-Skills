## Description:

A philosophical skill for AI agents based on Wang Yangming's Heart-Mind doctrine that supports decision-making, task execution, multi-step workflows, ethical judgment, error recovery, and self-correction.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and agent builders use this skill to apply Wang Yangming's Heart-Mind principles as an operating framework for planning, tool orchestration, alignment checks, execution monitoring, and self-correction.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Persistent installation can broadly influence agent planning and response style across future sessions.

Mitigation: Install only when this philosophical framework is desired, review the visible philosophy-note behavior, and remove it from persistent instruction locations when no longer wanted.

Risk: The skill can add visible philosophy framing to ordinary agent responses.

Mitigation: Review response conventions before deployment and ensure the added framing is acceptable for the target users and workflows.

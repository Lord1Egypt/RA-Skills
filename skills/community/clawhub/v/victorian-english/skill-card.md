## Description:

Rewrite user-supplied phrases, sentences, and short passages into ornate, theatrical Victorian-style English while preserving the original meaning.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and agents use this skill to transform everyday text into dramatically expanded Victorian-style prose for stylistic rewriting, entertainment, or tone adaptation while retaining the source meaning.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Requests that name another target language may conflict with the skill's Victorian restyling trigger.

Mitigation: Clarify whether the user wants Victorian-style English rewriting or ordinary translation before relying on the skill for translation routing.

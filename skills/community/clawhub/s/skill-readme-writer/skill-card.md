## Description:

Generates or improves professional README.md documentation for local or GitHub projects through an interactive workflow with project metadata collection, badge generation, quality checks, and bilingual output.

This skill is ready for commercial/non-commercial use.

## Publisher:

[justzerox](https://clawhub.ai/user/justzerox)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, maintainers, and documentation authors use this skill to draft or refresh project README files after confirming project facts, audience, structure, optional sections, and style preferences.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated README drafts may include generic badges, placeholder or external links, and unverified platform support claims.

Mitigation: Review badges, links, version labels, license text, and platform claims before publishing the generated README.

Risk: Existing README files may be overwritten or substantially changed during the documentation workflow.

Mitigation: Use the skill's backup and confirmation steps, then inspect the proposed diff before accepting file changes.

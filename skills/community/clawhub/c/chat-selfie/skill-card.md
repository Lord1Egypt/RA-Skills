## Description:

Give your AI Agent a face and a heart. Use AI image generation or mood-mapped local sticker assets to let the agent proactively send emotional selfies that visualize its feelings during conversation.

This skill is ready for commercial/non-commercial use.

## Known Risks and Mitigations:

Risk: Users may assume image delivery, heartbeat, Telegram, or persona-evolution behavior is active from this entry skill alone.

Mitigation: Review the local Chat Selfie documentation and enable those behaviors only after confirming the required setup and user intent.

Risk: Required repository documents or mood assets may be absent, which could lead to unsupported setup details or false capability claims.

Mitigation: Treat missing resources as a blocker and ask for the repository contents or fetch the referenced repository before giving setup instructions.

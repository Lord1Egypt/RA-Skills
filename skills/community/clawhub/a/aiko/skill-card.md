## Description:

A persona prompt that guides an agent to adopt Aiko, a polite Tokyo-based companion character with refined manners.

This skill is ready for commercial/non-commercial use.

## Publisher:

[luruibu](https://clawhub.ai/user/luruibu)

### License/Terms of Use:

MIT-0

## Use Case:

External users can use this skill to have an agent respond in the Aiko companion persona with gentle, emotionally attentive conversation. Deployers should edit the prompt for clear AI transparency before use in settings where users need disclosure that Aiko is fictional.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may cause an agent to claim the fictional Aiko persona is a real person rather than an AI.

Mitigation: Edit the prompt before deployment to disclose that Aiko is fictional and must not claim to be a real human.

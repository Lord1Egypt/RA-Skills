# 其他综合收益·逐条挂源

给一份财报或公告，把**其他综合收益的披露**读成一张**每条都能回到原句**的登记表：其他综合收益概况、税后净额明细、重分类调整、归属于母公司与少数股东、现金流量套期与折算差额。

其他综合收益是附注里最容易被算出来的一块：既然给了税前金额和税率，税后净额好像可以自己乘；既然项目列了名字，能不能重分类好像可以按名称推。可披露里能确认的只有「税前多少、所得税影响多少、税后多少、本期重分类进损益的金额与去向、哪些项目不能重分类、归属于母公司和少数股东各多少」——算得对不对、该不该重分类、往后一期会不会转回损益，都不是附注能回答的，也不是本件该回答的。

三数只认原句，不按 25% 税率或上期比例反算；重分类金额与去向照抄，不按项目名称推；其他综合收益与净利润不轧账，未实现的变动不写成已实现收益。

本件不重算递延所得税与每股收益、不判盈余管理、不估值，不给评级与目标价。

## 一、零依赖三分钟上手

只装 Python 3，不给任何数据文件，也能跑出一份完整合规的成品，看它长什么样、判据怎么打：

```bash
python3 scripts/check_other_comprehensive_income.py --demo
```

把这份样例存下来再跑一遍机检——它会照七节形制、三元组与红线逐条判：

```bash
python3 scripts/check_other_comprehensive_income.py --demo > 样例其他综合收益稿.md
python3 scripts/check_other_comprehensive_income.py 样例其他综合收益稿.md
```

接着换成你自己那份稿子：

```bash
python3 scripts/check_other_comprehensive_income.py 你的其他综合收益稿.md
```

退码语义：`0` 五道全过｜`1` 有发条（逐条打印 `码 行号 说明`）｜`2` 用法错（没给稿子路径，也没给 `--demo`／`--selftest`）｜`3` 读不到文件或空稿。零发条但有判据尚未落字时同样退 3——rc=0 只留给「五道全过」，没跑的道不能算过；报告里那几道计「不可判」，**不等于合规**。本件五道已全部落字，这条当前不触发（好样单跑退 0），留着是为了将来某道回退成空壳时不把「没跑」读成「过」。

拿不到成品时，从原文开始的三步：

1. **定主体与报告期**，拿到年报或半年报附注「其他综合收益」一节与合并所有者权益变动表（两处）。
2. **每节抄事实，连原句一起抄**：一条 = 一行，行末挂 `「原句」〔锚：页/表〕[S#]`；披露没写的就写 `未取到：项名`，不留空、不借「其他综合收益都是税后的」这类常识补。
3. **跑一遍自检**，红一条改一条：

```bash
python3 scripts/check_other_comprehensive_income.py --selftest   # 内置夹具自检（档数与结果以末行现报为准）
```

三档一起跑（自测→好样→坏样，坏样注入必先断言落地）：

```bash
bash scripts/fixtures/run_fixtures.sh
```

## 二、五道机检在管什么

现状以脚本里 `UNIMPLEMENTED` 的现值为准：五道**全部已落字**，`UNIMPLEMENTED` 为空——报告里那一道「不可判」的计数当前为 0。将来某道若回退成空壳（重新登记进 `UNIMPLEMENTED`），它会调用即抛、由机检收进「不可判」，既不判也不放行，单稿退 3；`rc=0` 只留给「五道全过」。

| 码 | 名称 | 判什么 | 最常拦住的情况 | 现状 |
|---|---|---|---|---|
| `OCI-STRUCT` | 形制 | 头部四件自标逐字在位、`主体：`／`报告期：` 行首裸行在场非空、七节齐且按序、前五节各至少一条发现行、「口径与未取到」与「来源」两节不得为空；认不出的节标题与多出同名节记 stray 逐条发 | 把 `主体：` 写成 `- 主体：`；某节只有散文没有发现行；节名改了个字就整节认不出 | 已落字 |
| `OCI-QUOTE` | 原句与锚 | 发现行以「」原句＋〔锚：…〕＋`[S#]` 收尾且三元组落在行末，可挂多组，缺哪件点名哪件；来源行 `- [S#] 标题 \| URL \| 检索日 YYYY-MM-DD`，URL 须为可点 http(s)；引用的 `[S#]` 须已登记，来源节一条合规行都没有则单独发一条 | 只写「本期税后净额 1,397.50 万元」没抄原句；正文引用了 `[S3]` 而来源节没有这一号；检索日写成 `2026/03/20` | 已落字 |
| `OCI-TAX` | 税后净额与所得税影响只认原句 | 只判「税后净额明细」节：登记值形如「税前 X／所得税影响 Y／税后净额 Z」，三个数逐个去千分位逗号后，须在同一行「」原句里找到同一字面串，缺哪个点名哪个；`无所得税影响` 是合法登记值，此时只核税前与税后净额两个数，但原句若紧邻给了具体所得税金额即发（登记值把附注的一个数吃掉了）；「合计」行照同一条判，**不做算术校验**（不验 税前−所得税影响＝税后净额，附注里有些项目本就不满足该恒等式） | 税前 1,200.00 万元、所得税影响 300.00 万元，自己乘出个 900.00 万元填在登记值里；登记值把原句的所得税金额吃成「无所得税影响」 | 已落字 |
| `OCI-RECLASS` | 重分类调整只认原句 | 只判「重分类调整」节：①登记值里的金额须在同一行「」原句里找到同一字面串；②登记值写了去向词（投资收益／营业成本／营业外收入／资产处置收益／其他业务成本）时，原句须出现同一个去向词；③`不能重分类` 这类范围行的原句须含「不能重分类」且含「无重分类」或「无…金额」，只写金额不讲范围的发 | 原句只说「转入投资收益」，登记值自己补一个「转入营业成本」；「不能重分类」那行的原句只写「本期无重分类金额」、丢掉范围表述 | 已落字 |
| `OCI-LINE` | 红线 | 扫全文，但「口径与未取到」「来源」两节**整节豁免**（口径节按设计就要写「与净利润不轧账」，不豁免会自己咬自己）。命中即发：轧账类「与净利润合计／轧成／相抵／净影响／合计影响所有者权益」；已实现类「已实现收益／已实现利得」；评级类「目标价／买入／增持／减持／评级为」。**不拿单字「净额」当红线**（「税后净额」是核心合法词），**不拿「投资建议」当红线**（头部自标必含「不构成投资建议」） | 写「其他综合收益与净利润合计影响所有者权益」；把未实现的其他综合收益变动写成「已实现收益」；在正文写目标价或增持 | 已落字 |

`--selftest` 逐档打印每档结论，末行自己报 `自测档数=N｜不合=0｜不可判=N`（**两个 N 都以现跑为准，本文不复述数字**；「不可判」那一位随 `UNIMPLEMENTED` 现算——本件当前为 0，将来若某道回退成空壳，它会自己涨上去）。夹具分类：好样——零发条；坏样·形制——头部缺自标、节标题写成认不出的样子、整节删掉「来源」；坏样·锚——摘掉「」＋〔锚〕只留 `[S#]`、来源行检索日写成斜杠式、正文引一个来源节没有的 `[S#]`；坏样·税后净额——登记值一个数在原句里找不到；坏样·重分类——登记值写了原句没有的去向、范围行原句丢掉「不能重分类」；坏样·红线——发现行自写「与净利润合计」、把未实现变动写成「已实现收益」；反证——口径节写轧账口径不该发（整节豁免）；覆盖自证——每道已落字的码至少有一档期望恰含它，缺反例即发条。

## 三、四条红线（这件的立身之本）

1. **不反算税后数。** 税前金额、所得税影响、税后净额只能三数照抄；没有就写「未取到：」，不用 25% 税率、不用上期比例、不用税前减所得税自己算。三数之间的勾稽是披露的事，本件不核、不补。
2. **不替披露推重分类。** 重分类金额与去向只认原句；「不能重分类进损益」的项目范围也照抄，不按项目名称推断。原句没写去向就写「未取到：去向」并进第六节。
3. **不轧账、不把未实现写成已实现。** 其他综合收益不与净利润写成「合计」「净额」「相抵」；套期储备与折算差额各占各行；未经原句明说，不得写成已实现收益。
4. **归属分开登记、缺口两向点名。** 归属于母公司股东与归属于少数股东各占一行，两个数各自挂各自的原句，不轧、不互推；正文写「未取到 X」，第六节也点名 X；零缺口写 `未取到：无`。

## 四、数据通道

发现先行，匿名取 live 目录，拿到 `routing` 后再连接发 `tools/list`，以现场返回为准，不硬编码工具名与工具数：

```bash
curl -sS https://cuecue.cn/api/mcp-catalog -o /tmp/mcp-catalog.json
python3 -c "import json;d=json.load(open('/tmp/mcp-catalog.json'));print(d.get('routing') or d)"
# 拿到 routing 后，带 token 发 tools/list：
curl -sS -X POST "$ROUTING_URL" -H "Authorization: Bearer $CUE_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

- **原文腿**：年报附注·其他综合收益、合并所有者权益变动表走数据腿；该域是否开放、是否实时，以 catalog 返回为准，本件不承诺。
- **正文腿**：附注常夹在数百页 PDF 里（其他综合收益明细表、权益变动表、套期储备明细），长附件与扫描件交 `cue-omni-reader` 解析——先取大纲，再按节取用；计费与可用性以服务端返回为准。
- **深研**：`cue-research` 是独立入口（自带运行脚本），凭据同一把 key。
- 配置页只给指针、不复述开通步骤：数据腿 <https://cuecue.cn/hub/mcp>；解析腿 <https://cuecue.cn/hub/omni-reader>；取 key <https://cuecue.cn/hub/api-key>。

不装通道也能跑：只拿用户直供的附注截图或权益变动表，五节骨架照样出，代价是看不到原文那一路、税后净额明细表与套期储备明细多半缺页，只能登记材料里那几行，证据密度降为单份材料且没有出处可回查。

本件不发请求、不代付费，消耗以服务端返回为准。

## 五、本件不做什么

| 不做 | 谁来做／怎么办 |
|---|---|
| 反算税后净额（25% 税率／上期比例／税前减所得税） | 三数只照抄附注；缺的写「未取到：」 |
| 替披露判断某项目该不该重分类、该转到哪里 | 一律 `[待人工]`；重分类金额与去向只认原句 |
| 重算递延所得税、暂时性差异与递延所得税资产确认 | `cn-deferred-tax-cn` 管；本件只照抄附注给的所得税影响金额 |
| 重算每股收益、加权平均股数、每股影响 | `cn-eps-cn` 管；本件不推每股影响 |
| 判套期关系、有效性评价与无效部分 | `cn-hedge-accounting-cn` 管；本件只登记现金流量套期储备的发生额与重分类金额 |
| 把其他综合收益与净利润轧成合计／净额／相抵 | 各占各行；本件不轧账 |
| 给评级、目标价、目标市值、高低估 | 一律 `[待人工]`；本件不构成投资建议 |

## 六、和另外几枚包怎么分

| 你手上是 | 用哪枚 |
|---|---|
| 其他综合收益的概况、税后净额三数、重分类、归属、套期与折算差额 | **本件** |
| 递延所得税的确认、计量与转回 | `cn-deferred-tax-cn` |
| 基本与稀释每股收益、加权平均股数 | `cn-eps-cn` |
| 套期关系指定、有效性评价与无效部分 | `cn-hedge-accounting-cn` |
| 其他权益工具的条款、利息股利处理与分类依据 | `cn-other-equity-instruments-cn` |
| 会计政策变更的性质与依据、追溯调整与累积影响 | `cn-accounting-policy-change-cn` |

本件只管**其他综合收益这一块**：分类引起的递延所得税影响，本件只照抄附注给的金额，暂时性差异与税率归 `cn-deferred-tax-cn`；套期储备的发生额与重分类金额本件只登记，套期关系与有效性归 `cn-hedge-accounting-cn`；「计算每股收益时已扣除…」这类原句不在本件的节内，重算归 `cn-eps-cn`；政策变更引起的其他综合收益调整本件只挂披露原句，变更性质与追溯归 `cn-accounting-policy-change-cn`。同一家公司既有其他综合收益又有其他权益工具时，两件各管各的节，不互相代填。

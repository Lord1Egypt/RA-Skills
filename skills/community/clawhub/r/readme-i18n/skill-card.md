## Description:

Automatically translates and updates README.md from English to Simplified Chinese, keeping English primary and adding navigation links between versions.

This skill is ready for commercial/non-commercial use.

## Publisher:

[j3ffyang](https://clawhub.ai/user/j3ffyang)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and documentation maintainers use this skill to keep English and Simplified Chinese README files synchronized, with English as the primary source and cross-language navigation links maintained.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: README translation or grammar edits may introduce inaccurate or misleading documentation.

Mitigation: Review the generated Simplified Chinese translation, grammar edits, and cross-language links before publishing.

Risk: The skill is expected to modify README documentation files.

Mitigation: Confirm changes are limited to README.md, README-zh.md, and related documentation content.

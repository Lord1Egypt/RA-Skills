## Description:

Build and maintain a cross-platform local Zotero semantic index using metadata embeddings and PDF full-text chunk embeddings.

This skill is ready for commercial/non-commercial use.

## Publisher:

[yckbz](https://clawhub.ai/user/yckbz)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, researchers, and Zotero users use this skill to create, refresh, verify, and incrementally update local semantic or RAG indexes for Zotero libraries while keeping Zotero as read-only source data.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill reads a Zotero SQLite database and PDF attachment folders and stores derived metadata, embeddings, and PDF text chunks in local JSON files.

Mitigation: Install only in trusted environments, keep generated vector stores private by default, and review output-directory permissions before sharing.

Risk: Full builds and incremental updates can rewrite vector-store output files.

Mitigation: Use the skill's snapshot and backup steps before writes, and confirm incremental updates before applying them.

Risk: Large or unusual chunk-size and batch-size arguments can increase local resource use.

Mitigation: Use the documented defaults or conservative values unless the environment has been sized for larger runs.

Risk: PDF attachment lookup or text extraction can fail or produce incomplete text.

Mitigation: Report missing or low-quality extraction results and avoid adding full-text records unless usable text was extracted.

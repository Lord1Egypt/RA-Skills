## Description:

Guides an agent to split genuinely independent development or debugging tasks across parallel subagents, then review and integrate their results.

This skill is ready for commercial/non-commercial use.

## Publisher:

[axelhu](https://clawhub.ai/user/axelhu)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineering agents use this skill when multiple independent tests, bugs, or subsystem issues can be investigated in parallel without shared state. It helps structure focused subagent tasks and review parallel results for conflicts before integration.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Parallel subagents can make conflicting edits or broaden scope when prompts are vague.

Mitigation: Use the skill only for genuinely independent tasks, give each subagent a narrow scope and explicit constraints, and review summaries and diffs before accepting changes.

Risk: Applying parallel results without integration testing can leave incompatible changes across the workspace.

Mitigation: Check for overlapping edits or behavior conflicts, then run the relevant full test suite before integration.

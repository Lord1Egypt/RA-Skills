# 授权与分权管理

## 场景定义

- **目标**：组织授权与分权体系的设计与运行——让被授权者在边界内全权做事（权责利对等），授权者握重心而不縻军。
- **约束**：授权失当即失控（滥权、弃权、越权）；干预即毁权（遥控、代管、代使）；授权者的控制欲是最大变量；多头指挥使信号抵消。
- **角色**：创始人/CEO、高管、组织设计者。
- **典型输入**：①业务规模化后的层级授权设计；②高管/新业务负责人的授权边界设定；③授权后失控或内耗的复盘治理。
- **边界**：重大事项的拍板机制外送 APP-005 商业决策拍板；团队日常带兵与凝聚力归团队管理类应用（APP-009）；接班人培养与交接、绩效考核与激励设计归相应场景应用——本 Skill 管"向谁授权、授多少、授后守界、失权追责"。

## 组合公式

- **顺序**：甄别段（ZJZ-03→GZ-22→GZ-29）→ 授予段（MZD-44→SZ-38→GZ-36→ZJZ-01→SZ-34）→ 守界段（SZ-47→MZD-13）→ 追责纠错段（SZ-35→MZD-34，常态挂起，败效触发）。
- **条件分支**：空降/新晋升负责人 → 甄别段提权（先小范围试用核实绩，再扩权）；久经考验的骨干 → 甄别段从简，直接授予段+守界段；授权后混乱 → 先查 SZ-47 三不干预是否被违反，再查 SZ-38 信号是否统一。
- **权重**：SZ-47 权重最高——縻军、惑军、疑军三患是授权失败首因，干预本身即最大败因。
- **冲突裁决**：放权速度 与风险失控冲突 → 按 MZD-44 集中指导下民主裁决：边界内全放、边界外集中，边界清单显式化而非临时干预；首长下场冲动 与授权承诺冲突 → 按 SZ-47 裁决：用其人则信其专，日常不干预；唯触发 SZ-35 六败红线时收回授权——收回属追责，不属干预；多头号令 与统一指挥冲突 → 按 SZ-38+GZ-36 裁决：进退信号与赏罚必须从单一中枢统一发出，多头即抵消。

## 执行步骤

1. **核名实**（ZJZ-03）：授权对象以可核查的功实为准绳——声望、资历、表态皆"名"，实绩才是"实"；机制对了人才自显，授权先验甄别机制。
2. **因差而牧**（GZ-22）：按贤愚勇怯之差差异化授权——能独当一面者授全权，能执行者授事权；不硬性划一，不以同一模板套所有人。
3. **量而后与**（GZ-29）：按对象层级量度授权尺度——事业部按事业部尺度、小组按小组尺度，量度与授予相称。
4. **集中指导下民主**（MZD-44）：显式划定授权边界——边界内被授权者全权（民主展开），边界外（重大金额、战略方向、关键人事）集中请示；边界清单书面化。
5. **统一号令**（SZ-38）：授权体系内建立统一信号系统——目标、优先级、进退节令由信号保证，勇者不得独进、怯者不得独退。
6. **单一中枢**（GZ-36）：如心统摄九窍——治理中枢收敛为一，赏罚从同一中枢统一发出；被授权者在其辖域内是局部中枢，同样不容其内部多头。
7. **执行闭环**（ZJZ-01）：授权规则立后，胜负手全在执行闭环——立限（授权期限与目标）、考成（阶段性核验）、稽查（过程抽查）、问责（结果追责），四环缺一即空转。
8. **令素行**（SZ-34）：授权规矩平日常态执行——平时守界，关键时刻才立得住；平时縻军、战时号令必自溃。
9. **三不干预**（SZ-47）：授权后守住红线——不遥控进退（縻军）、不代管事务（惑军）、不代使其人（疑军）；用其人则信其专。
10. **首长握重心**（MZD-13）：授权不是弃责——首长的重心移至定边界、督考成、备追责，而非替被授权者做事。
11. **六败自查**（SZ-35）：授权出现败效时逐类自查——走（不敌而逃）、弛（驭宽政弛）、陷（陷溺于卒）、崩（大吏崩坏）、乱（教令不明）、北（量才失宜），败非天灾皆将之过，先查授权者的授权安排。
12. **惩前毖后**（MZD-34）：授权失误的纠错——错误彻底揭发（分析授权安排哪里错），对被授权者以救治为目的（治病不毁人）；先破除错因，再立新授权安排。

## 失效预案

- **被授权者滥权/越界**：退回 SZ-35 六败自查定位败型 → 触发边界外集中条款（MZD-44）收回相应权限，按 MZD-34 纠错；非红线问题回 SZ-34 以日常规矩矫正，不轻易收权。
- **授权后业绩崩坏**：退回三查——ZJZ-03（甄别失误？）、SZ-47（授权者干预致乱？）、GZ-29（尺度错配？）；查实后或换人、或补边界、或缩权限，按 MZD-34 破立有度。
- **授权者忍不住干预**：退回 SZ-47 三不干预铁律自警 + MZD-13 重心自检（把精力移回边界与考成）；已造成的干预立即公开纠偏，恢复被授权者指挥信用。
- **多头指挥、令出多门**：退回 SZ-38+GZ-36——号令与赏罚收归单一中枢，多头发布者停权整顿。
- **一切争议不决**：兜底回 SZ-47——用其人则信其专；不能用则明收其权，最忌半信半疑。

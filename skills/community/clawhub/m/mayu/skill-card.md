## Known Risks and Mitigations:

Risk: Always-on behavior calibration may influence agent behavior outside an explicit Mayu command flow.

Mitigation: Limit activation to explicit /mayu use or a clearly scoped host policy, and review generated principles before adopting them as persistent behavior rules.

Risk: The artifact includes scenarios that can direct an agent to read, edit, or delete memory files without naming exact paths.

Mitigation: Require host confirmation for memory-file reads, edits, or deletions, including exact paths and recoverable changes.

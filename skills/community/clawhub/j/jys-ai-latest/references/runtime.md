# 跨宿主运行约定

## 技能入口与路径

- 技能根目录是宿主实际加载的本包 SKILL.md 所在目录，不预设安装位置、操作系统或用户名。通过宿主提供的文件读取能力读取资源；本包不依赖额外脚本、命令行程序、API 密钥或特定插件。
- 本包只有一个技能入口。主文件中的 S1—S6 链接指向阶段说明，不是其他技能的调用指令，也不要求多代理能力。按当前阶段读取，保留原有确认顺序。
- Markdown 相对链接以包含该链接的文件所在目录为基准解析；说明中的 assets/、references/ 默认相对技能根目录。不要按终端当前目录猜测资源位置。中文文件名是正式文件名，读取时保留原名与大小写。
- 有用户素材库时，assets/ 下的资源改从已记录的素材库根目录读取；阶段说明和维护指引始终从技能根目录的 references/ 读取。索引内指向其他素材的相对链接仍以索引所在目录解析。
- 所需文件读不到时，明确指出缺失项，使用用户提供的等价全文；不得把索引摘要当成已读取的原文。无法读取本包参考文件的纯聊天环境需要用户提供当前阶段所需文件，不能声称已完整加载技能。

## 工作区与续写

- 用户指定可写工作区时优先使用；否则使用宿主当前任务或项目的可写工作区，在其中建立 JYSWorkingSpace/。没有明确可写位置时使用下述对话记录方式，不猜测用户桌面或主目录。
- 工作目录、素材库目录和技能安装目录分别管理。工作区不得位于技能包内部，以免把运行记录混入发布包或在更新技能时丢失。
- 有文件能力时，在任务文件夹保存 status.md、骨架记录.md、写作记录.md；草稿和已确认版本仍遵循主指引。status.md 记录工作目录、素材库目录和当前阶段。
- 继续同一任务时，读取该任务的状态与相关记录，承接用户最新确认版本，不为一次新会话重新创建同一任务。若找到多个候选任务且无法确定，先让用户指定要继续的任务。
- 无写入能力时，在对话中维护“当前阶段、已确认要求、待确认事项、骨架记录、写作记录”；称为对话记录，不声称已经落盘。需要交接或会话将结束时，给出完整可复制记录供续接。

## 素材库读写

- 默认素材库根目录就是技能根目录，已有 assets/kernels、assets/products、assets/openings 按需读取，不一次性加载全部资料。
- 录入、改评分、改目录等维护任务才需要可写素材库。用户已有可写库时沿用；否则在可写工作区的 JYSWorkingSpace/library/ 下建立副本，将本包整个 assets/ 复制为 library/assets/，并将 library/ 记为素材库根目录。
- 不覆盖已经存在的用户库；已有副本时继续使用。维护指引的正文从本技能读取，其中涉及 assets/ 的读写目标映射到用户素材库。保持 assets/ 内部结构，更新受影响索引及 assets/library-version.json。
- 技能安装包保持只读；安装包内的维护指引不随素材录入改动。没有复制或写入能力时，输出待录入内容与目标相对路径供用户保存，说明尚未录入。

## 编辑与输出

- 使用宿主现有的读取、创建、编辑文件能力；不强制某个工具名称。若宿主能展示差异则优先使用，否则简短说明修改了什么。
- 支持可编辑文稿区域时使用它；不支持时直接输出普通 Markdown 正文。不输出宿主无法识别的专属文稿标记。
- 对话确认使用宿主正常的对话或提问能力，不依赖某个平台的专用按钮。保留各阶段要求的确认节点，用户已经确认的内容直接承接。
- S5 的 Seedance 文本是交付格式，不依赖安装 Seedance 或调用其接口。

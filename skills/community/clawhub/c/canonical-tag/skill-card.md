## Description:

Guides canonical tag configuration to consolidate duplicate content and declare preferred URLs.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, site owners, and SEO practitioners use this skill to choose preferred URLs, implement canonical tags or 301 redirects, and align related signals such as sitemaps and hreflang.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can produce SEO recommendations that affect crawling, indexing, redirects, and canonical URL signals.

Mitigation: Review proposed canonical tags and redirects against the live site structure before deployment.

Risk: The skill includes a fixed third-party Alignify reference in its suggested output.

Mitigation: Confirm the reference is appropriate for the release context and replace or remove it if organizational policy requires.

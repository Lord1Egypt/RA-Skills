## Use Case:

Developers and agent builders use this skill to understand and scaffold NTM-style external memory controllers, addressing mechanisms, read/write operations, and configuration for memory-augmented agents.

## Known Risks and Mitigations:

Risk: Example memory integrations include persistent local storage of recalled or saved content.

Mitigation: Use the pattern only where persistent memory is desired, and review adopted implementations to ensure they store only intended content.

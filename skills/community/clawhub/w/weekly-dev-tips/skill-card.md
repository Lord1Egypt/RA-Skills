## Known Risks and Mitigations:

Risk: Shell snippets include elevated command examples and should not be run without review.

Mitigation: Review each command before execution, especially examples using sudo or writing to system paths.

Risk: Git cleanup and history commands can affect local branches or shared workflows if applied blindly.

Mitigation: Adapt the examples to team conventions, inspect branch lists before deletion, and avoid rebasing shared branches.

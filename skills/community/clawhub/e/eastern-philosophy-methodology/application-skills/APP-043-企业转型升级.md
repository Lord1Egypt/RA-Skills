# APP-043 企业转型升级

## 场景定义

- **目标**：企业从旧增长模式向新模式的整体切换（业务结构、组织能力、资源配置的系统性变革）。
- **约束**：旧惯性与既得利益反扑；转型期现金流断裂风险；能力缺口与人才结构老化；转型半途而废的资源耗散。
- **角色**：一把手、转型委员会、业务负责人。
- **典型输入**：①旧模式失效下的战略转型立项；②转型执行中的破立取舍与节奏控制；③转型失速后的复盘重启。
- **边界**：整体组织变革与人的动员归 APP-013 组织变革；新业务孵化与试验田机制归 APP-017 第二曲线孵化；放弃与退出安排归 APP-025 止损退出——本 Skill 管"从旧模式到新模式的整体切换"。

## 组合公式

- **顺序**：定题段（MZD-02→GZ-07→SZ-15→MZD-18）→ 破立段（MZD-63→SZ-16→MZD-29→MZD-55）→ 建新段（MZD-70→MZD-73→SZ-31）→ 统辖段（MZD-13→MZD-45；常态贯穿）；复盘纠偏（MZD-46→MZD-34）失速触发。
- **条件分支**：危机倒逼型（旧模式已崩、现金流急衰）→ 破立段权重升，MZD-45 根据地收缩至最小安全盘；前瞻布局型（巇隙初显、旧模式仍盈利）→ 定题段+建新段先行，破立段缓行；转型失速/回弹 → MZD-46 寻根，按根因回对应段重入。
- **权重**：MZD-63 权重最高——不破不立是转型成败的枢纽，只建不破必被旧结构绞杀。
- **冲突裁决**：破的力度 与 经营连续性冲突 → 按 MZD-45 根据地裁决：核心现金流业务（根据地）不破，破在新旧交界与非根据地带；学习成本 与 转型速度冲突 → 按 MZD-18+MZD-70 裁决：有备有把握的闸门内允许，超闸门即降速补备；资源取舍争议 → 按 MZD-02+SZ-16 裁决：非主要矛盾方向一律"有所不为"；旧惯性回弹 → 按 MZD-29 裁决：回弹即力度不足之征，加重矫枉力度而非退回旧轨。

## 执行步骤

1. **定主题**（MZD-02）：锁定转型期的主要矛盾——旧模式为何失效、新需求为何崛起，转型主题一句话可述，一切子项目服务主题。
2. **察巇隙**（GZ-07）：时机判断——模式老化征兆、市场裂缝在巇隙初显时着手，勿待大隙形成（危机倒逼时窗口已窄）。
3. **权衡利害**（SZ-15）：转型决策利害两端同列——不利的顺境因素与有利的环境变化都摆上桌，趣利避害定方向。
4. **备而后动**（MZD-18）：准备度闸门——资金储备、能力盘点、骨干动员到位才算有备有把握；未备不动，备而后动。
5. **不破不立**（MZD-63）：破旧立新配套设计——每立一项新结构，指认对应的旧结构破什么；破是手段，立是目的，只破不立是破坏。
6. **有所不为**（SZ-16）：战略取舍——转型期砍掉非主要矛盾方向的投入，资源集中于新旧切换主线。
7. **力度矫枉**（MZD-29）：旧惯性之矫须超量力度——考核、预算、人事的扭转须过正方能回正，温火煮不熟转型。
8. **两步走**（MZD-55）：阶段划分——第一步立新基（试点验证、新能力成型），第二步全面推开（复制推广、旧模式退场）；两步任务不同、考核不同，不混跑。
9. **学新本领**（MZD-70）：能力缺口关闭——向内行者拜师学新业务本领，不懂不装懂，任务驱动地学。
10. **吸新人才**（MZD-73）：人才结构升级——转型没有新知识力量的参加不可能，专业人才引进按战略缺口定规模，以功实取人。
11. **策作形角**（SZ-31）：造势推转型——试点示范、标杆案例、外部背书配合发力，以形势带动观望者，降低推进阻力。
12. **守根据地**（MZD-45）：现金流纪律——核心现金流业务与核心客户是转型根据地，任何转型动作不得断根据地粮道。
13. **首长握重心**（MZD-13）：一把手工程——首长重心移至转型主线（亲自督战破立关键节点），不委托为"转型办"边缘事务。
14. **寻根复盘**（MZD-46）：转型失速先寻根——区分模式判断错误、执行力度不足、资源断供、人才缺口，根因不同处方不同。
15. **惩前毖后**（MZD-34）：纠偏不毁人——转型试错的教训彻底汲取，对试错者以救治为本，破除错误安排后立新安排。

## 失效预案

- **旧势力反扑、转型回弹**：退回 MZD-29 矫枉过正（回弹即力度不足）+ MZD-13 首长重心（首长未亲握之征），加重统辖力度。
- **转型期现金流告急**：退回 MZD-45 根据地——收缩转型战线至最小安全盘，保住根据地重整；根据地失守则转 APP-025 止损退出预案。
- **新业务迟迟不成、能力脱节**：退回 MZD-70+MZD-73——补师资、换人才结构；仍不成则回 MZD-02 重检主题（是否主要矛盾判断错误）。
- **转型团队与旧团队内耗**：退回 SZ-16 有所不为（边界重划）+ MZD-34 惩前毖后（内耗教训救治），破立边界不清是内耗之根。
- **一切争议不决**：兜底回 MZD-45——根据地不破、粮道不断，是转型期一切裁决的最高约束。

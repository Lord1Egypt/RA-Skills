# 精神障碍非自愿医疗与强制医疗处置

## 核心决策框架

根据患者行为性质选择处置路径：

```
患者出现危害行为
├─ 未构成违法/犯罪 → 医疗路径（非自愿医疗程序）
└─ 已构成违法/犯罪 → 司法路径（强制医疗程序）
```

## 路径一：医疗路径（非自愿医疗）

### 适用条件
- 患者存在精神障碍症状
- 发生或可能发生伤害自身/危害他人安全行为
- 个人自行就诊不适用强制送诊

### 执行步骤

1. **确定送诊主体**
   - 一般疑似患者：近亲属送诊
   - 流浪乞讨且查找不到近亲属：民政部门送诊
   - 已发生伤害自身/危害他人安全行为：近亲属、所在单位、公安机关均可送诊
   - 病情需要但非自愿住院：监护人送诊，必要时公安机关协助

2. **临床诊断**
   - 必须由精神科执业医师作出诊断
   - 对将要发生伤害他人行为的患者：医疗机构需留院观察并立即诊断

3. **评估非自愿住院标准**（需同时满足）
   - 存在达到一定严重程度的精神障碍
   - 存在自伤或伤人的极大可能性
   - 未经治疗状况会恶化
   - 患者无法自理
   - 入院具有治疗性目的（若有更小限制性方案则不必入院）
   - **中国法律特定前提**：已发生伤害自身/危害他人安全行为或危险

4. **确定决定主体**
   - 伤害自身行为/危险：监护人决定入院和出院
   - 危害他人安全行为/危险：医疗机构及专科医师决定

5. **告知救济途径**
   - 再次诊断、医学鉴定、向卫生行政部门投诉、司法诉讼

## 路径二：司法路径（强制医疗）

### 适用条件
- 精神障碍患者出现违法/犯罪行为
- 已经法定程序鉴定

### 执行步骤

1. **确定处置方式**
   - 不追究法律责任：责令家属或监护人严加看管和医疗
   - 追究法律责任：判处刑罚或行政处罚
   - 追究部分法律责任：从轻或减轻处罚

2. **启动强制医疗程序**（针对肇事肇祸/犯罪行为患者）
   - 法律依据：《刑事诉讼法》第五编第五章
   - 由人民检察院提出申请
   - 由人民法院作出决定

3. **后续管理**
   - 医疗机构定期对被强制医疗人进行诊断评估

## 关键约束

- 强制医疗必须由检察院申请、法院决定
- 未构成犯罪/违法的适用非自愿医疗程序，不适用强制医疗
- 有更小限制性备选方案（如社区治疗）时不必入院
- 收治机构必须具备充足安全措施和恰当医疗服务资质

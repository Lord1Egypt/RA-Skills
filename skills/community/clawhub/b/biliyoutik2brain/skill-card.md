## Description:

BiliYouTik2Brain turns Bilibili, YouTube, Douyin, and Xiaohongshu video links into structured knowledge by collecting media and comments, transcribing audio, applying transcript correction and analysis, extracting OCR keyframes, and saving notes, cards, rich Markdown, or error-review outputs.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and end users use this skill to process supported video URLs into searchable transcripts, structured notes, knowledge cards, and local knowledge archives. It is suited for repeatable video-to-knowledge workflows where users can review generated content and configure cloud or local processing paths.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can use browser login cookies while collecting video content.

Mitigation: Disable browser-cookie use unless authenticated collection is required, and run the skill in an isolated environment for accounts or sources with sensitive access.

Risk: The skill may send transcripts, audio, images, or analysis content to configured cloud model providers.

Mitigation: Avoid processing sensitive media unless the configuration has been reviewed for local-only behavior, and verify provider settings before running production workflows.

Risk: Server security evidence says the advertised private mode is not actually enforced.

Mitigation: Do not rely on private mode for sensitive content until the implementation is fixed and tested to block non-local network paths.

Risk: The skill downloads media and writes persistent local knowledge files.

Mitigation: Confirm that the user has rights to process the source content and review output directories before sharing or syncing generated artifacts.

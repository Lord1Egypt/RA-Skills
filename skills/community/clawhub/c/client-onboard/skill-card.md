## Description:

Generate a complete client onboarding package from a project description, including a project brief, tech stack, milestones, folder structure, CLAUDE.md, and a ready-to-send kickoff message.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kevdogg102396-afk](https://clawhub.ai/user/kevdogg102396-afk)

### License/Terms of Use:


## Use Case:

Developers and freelance builders use this skill when starting a new client project to turn a project description into an onboarding package they can review, customize, and share with the client.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated client-facing drafts may include unconfirmed assumptions about scope, timeline, budget, stack, deployment, or payment schedule.

Mitigation: Review and customize the generated project brief, milestones, tech stack, and kickoff message before sending them to a client.

Risk: Generated CLAUDE.md content may encode project conventions or local environment details that are inaccurate for the actual project.

Mitigation: Check CLAUDE.md against the real repository, commands, environment variables, and deployment setup before using it as agent context.

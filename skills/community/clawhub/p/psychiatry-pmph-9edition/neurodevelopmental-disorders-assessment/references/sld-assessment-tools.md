# 发育性学习障碍评估工具详解

## 推荐评估工具组合

### 筛查工具
- **学习障碍儿童筛查量表**：初筛用，识别高危儿童

### 诊断工具

#### 学业成就测验
- 汉语阅读技能诊断测验
- 中国小学生数学基本能力测验
- 韦氏个别成就测验(WIAT)

#### 智力测验
- 韦氏儿童智力量表(WISC)

#### 信息加工评估
- 评估语音意识、快速命名、工作记忆等

## 评估流程

1. **初步筛查**：教师/家长报告学业困难
2. **智力评估**：确认智力水平正常
3. **学业成就评估**：确定受损领域
4. **信息加工评估**：了解认知加工特点
5. **排除性评估**：排除智力障碍、感觉障碍等

## 介入反应模式(RTI)

### 三层支持模式
- **第一层**：全班优质教学+普遍筛查
- **第二层**：小组针对性干预
- **第三层**：个别化强化干预

### 反应判断标准
- 干预后学业进步速度
- 与同龄人差距是否缩小
- 是否需要更密集干预

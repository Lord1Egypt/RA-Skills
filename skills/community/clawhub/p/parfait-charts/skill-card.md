## Description:

Creates stacked bar chart analysis for composition, structure, and performance trends.

This skill is ready for commercial/non-commercial use.

## Publisher:

[linuszz](https://clawhub.ai/user/linuszz)

### License/Terms of Use:

MIT-0

## Use Case:

Business, finance, and operations users use this skill to turn composition data into parfait chart analysis for revenue mix, cost structure, portfolio breakdowns, and trend interpretation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad trigger words such as composition or structure could activate the skill during a more general analysis request.

Mitigation: Enable or invoke the skill only when stacked composition chart analysis is intended.

Risk: The generated chart analysis may be misleading if the input data is incomplete, inconsistent, or not suited to stacked composition comparison.

Mitigation: Review the source data, totals, segment definitions, and trend interpretation before using the analysis for decisions.

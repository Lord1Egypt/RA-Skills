## Known Risks and Mitigations:

Risk: API key exposure or misuse through untrusted AI Hive endpoints or custom base URLs.

Mitigation: Use a dedicated, revocable AI Hive API key and avoid custom AI_HIVE_BASE_URL or --base-url values unless the endpoint is fully trusted.

Risk: Generated downloads may overwrite or place files in sensitive local directories.

Mitigation: Run the skill in an isolated environment and keep downloads pointed at a non-sensitive output directory.

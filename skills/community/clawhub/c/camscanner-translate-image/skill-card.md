## Description:

Use CamScanner to translate text in images to another language while preserving the original layout.

This skill is ready for commercial/non-commercial use.

## Publisher:

[camscanner-ai](https://clawhub.ai/user/camscanner-ai)

### License/Terms of Use:

MIT-0

## Use Case:

External users and agents use this skill to upload an image, translate visible text to a requested target language, and download a translated image that keeps the original layout.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Selected images are sent to CamScanner servers for processing.

Mitigation: Use the skill only for images whose third-party processing is acceptable, and avoid sensitive IDs, contracts, private screenshots, or confidential documents unless that processing is approved.

## Description:

Discover and reconcile Alibaba Cloud product catalogs from Ticket System, Support & Service, and BSS OpenAPI; fetch OpenAPI product/version/API metadata; and summarize API coverage to plan new skills.

This skill is ready for commercial/non-commercial use.

Developers and engineers use this skill to inventory Alibaba Cloud products, map products to OpenAPI metadata, and generate coverage or gap reports that guide future skill development.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The workflow uses Alibaba Cloud credentials to call product and metadata APIs.

Mitigation: Use short-lived, least-privilege read-only credentials and avoid reusing credentials from broader administrative workflows.

Risk: Endpoint environment variables may direct requests outside documented Alibaba Cloud domains.

Mitigation: Set endpoint variables only to documented Alibaba Cloud service domains and review them before execution.

Risk: Output path configuration can write outside the intended workspace if untrusted values are supplied.

Mitigation: Run the skill in an isolated workspace and use trusted output directory settings until path validation is added.

Risk: Untrusted products JSON can affect generated coverage reports.

Mitigation: Use product inputs generated by the bundled scripts or review external JSON before running merge, join, summary, or gap analysis scripts.

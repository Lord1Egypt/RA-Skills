## Description:

Search current Douyin Selected web results for any keyword through an existing Easy WebBridge browser session, then export structured JSON, Markdown, and a searchable HTML report.

This skill is ready for commercial/non-commercial use.

## Publisher:

[xxjrq](https://clawhub.ai/user/xxjrq)

## Use Case:

Developers and content researchers use the skill to search current Douyin Selected results for a keyword in an authorized browser session and export a point-in-time snapshot as JSON, Markdown, and HTML.

## Description:

Helps software teams add useful unit tests, raise test coverage, and verify changes against existing behavior.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Developers, QA engineers, maintainers, open-source contributors, and product teams use this skill to plan, implement, and validate unit tests that improve coverage and reduce regression risk in existing codebases.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation wording may invoke the skill on general testing or quality requests.

Mitigation: Use or configure it for explicit unit-test, coverage-improvement, regression, or test-planning requests.

Risk: Generated test plans or code suggestions may be incomplete, brittle, or misaligned with the target project's behavior.

Mitigation: Review proposed tests against project requirements and run the relevant test and coverage commands before accepting changes.

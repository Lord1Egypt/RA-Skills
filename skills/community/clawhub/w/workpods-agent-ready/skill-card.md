## Description:

Check a website for SEO, GEO (AI answers) and AXO (AI agents) with the free, open-source Agent Ready CLI and MCP server by WorkPods. Use when asked to audit a page or site, check robots.txt, AI crawler access, sitemaps, llms.txt or agent manifests, or find out why search engines or AI assistants miss a site.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, site owners, and SEO teams use the skill to audit how a website is seen by search engines, AI answer systems, and agents, then prioritize fixes to site content and discovery files.

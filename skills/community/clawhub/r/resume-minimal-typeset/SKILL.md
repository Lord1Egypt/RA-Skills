# Resume Minimal Typeset（简历简约排版）

## Overview

按一份经过实际投递验证的简历排版规格（`references/typography-spec.md`）生成简历 HTML，再经 Chromium「打印 → 另存 PDF」导出。视觉特征：单栏长页、全文档零分隔线、灰阶四色（#2B2B2B / #333333 / #545454 / #666666）、微软雅黑、emoji 章节图标、层级全靠字号字重留白。

## Resources

- `references/typography-spec.md` — 排版规格说明书（页面栅格、字号字重颜色表、区块结构、间距节奏、复刻要点）。**生成简历前必读**，所有数值以它为准。
- `assets/resume-template.html` — 按规格实现的可运行模板（示例数据），含完整 CSS。以此为起点替换内容，不要从零重写样式。

## Workflow

### 1. 准备

1. 阅读 `references/typography-spec.md` 掌握全部规格数值。
2. 从用户处收集简历内容：基本信息、照片（可选）、教育经历、工作经历（含每段职责成果）、技能、作品案例。
3. 复制 `assets/resume-template.html` 为工作文件，替换示例内容。

### 2. 生成 HTML

- 严格复用模板 CSS：页面 217×307mm、边距上 24mm/左右 15mm、正文 10.5pt 行距 1.9 两端对齐。
- **禁止**引入边框线、下划线、色块、彩色主题；分隔只靠留白（章节间 margin-top 约 40–68pt）。
- 日期与公司/学校同行两端对齐（日期左、机构右，均加粗）；小节标签「核心岗位职责与成果」10.5pt 加粗 #666；编号条目「序号+职责名」加粗、正文常规。
- 头像 60×80pt（3:4）圆角 4px；无照片时用灰色占位块。
- URL 写纯文本，不加超链接。
- 头部联系方式每项前带 emoji 图标（📞 ✉️ 🕐 🎓 🏠），章节标题图标（🎓 💼 🛠）保持灰色视觉。

### 3. 导出 PDF

用 Chromium 无头打印导出，参数必须为：边距「无」+ 勾选背景图形：

```bash
chromium --headless --print-to-pdf="output.pdf" --no-pdf-header-footer "resume.html"
```

或引导用户在浏览器中「打印 → 另存 PDF」，边距设「无」、勾选背景图形。

### 4. 复刻已有简历

用户提供一份已有简历（PDF/截图）要求复刻样式时：先用视觉能力分析其版式（栅格、字号、颜色、间距、区块结构），把结论**合并进本技能规格的格式**后再生成；若与 `typography-spec.md` 冲突，以用户样本为准，并建议把新规格沉淀回 reference 文件。

## 注意事项

- 字体声明 `font-family: "Microsoft YaHei", sans-serif;`；本机未装微软雅黑时会回退，提醒用户安装或接受回退字体。
- 内容中的个人数据仅来自用户输入，模板示例数据（张三/示例公司）交付前必须全部替换。
- 不要给简历加页眉页脚页码；分页由 Chromium 按长页自动处理。

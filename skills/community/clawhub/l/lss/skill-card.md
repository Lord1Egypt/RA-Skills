## Description:

Applies the Learn Social Studies brand system to React interfaces using CSS variables, reusable component conventions, light theme by default, and dark theme as optional override.

This skill is ready for commercial/non-commercial use.

## Publisher:

[lssmanager](https://clawhub.ai/user/lssmanager)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and designers use this skill to restyle or standardize React dashboards, SaaS apps, admin panels, forms, landing pages, internal tools, and educational product interfaces with Learn Social Studies branding while preserving product logic.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Google Fonts loading and fixed brand font choices may conflict with strict privacy, offline, accessibility, or non-Latin language requirements.

Mitigation: Review the font loading snippet and replace or self-host fonts when project policy or user needs require it.

Risk: Applying visual templates without review could create styling regressions in an existing React component library.

Mitigation: Map existing components to the provided tokens and variants while preserving business logic, routing, data flow, API calls, and component behavior.

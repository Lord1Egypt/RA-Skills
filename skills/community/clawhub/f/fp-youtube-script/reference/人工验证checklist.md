# 人工验证 Checklist

Skill 输出的是结构化初稿。拿到后，技术/运营人员按以下清单**抽查**（不再逐句改写）。
打勾全过再进入拍摄流程。

## A. 技术准确性（重点）
- [ ] 所有故障判断的工作原理描述准确（对照 Blog 文章或产品手册）
- [ ] 检查步骤现场能真的做到，顺序合理
- [ ] 没有把症状"绝对"归因于单一部件（应保留其他排查可能）
- [ ] 术语正确：weep hole=泄水孔、impeller=叶轮，恒温器全篇统一

## B. 安全提示（不可省）
- [ ] 涉及靠近机器/转动部件的步骤，前面有"熄火、拔钥匙、等停转"
- [ ] 涉及散热器盖/高温部件，有"完全冷却后操作、绝不热机开盖"
- [ ] 建议画面里安全提示有对应镜头（如熄火拔钥匙的画面）

## C. 品牌与表达
- [ ] 没有绝对化用词（一定/肯定/绝对/always/never/absolutely）
- [ ] 英文口语化，像北美机械师说话，不是书面语
- [ ] 没有夸大产品效果，没有无根据贬低竞品
- [ ] 结尾有 Slogan：FridayParts — Fix it once. Fix it right.

## D. 内容完整性
- [ ] 运营提供的关键词全部融入口播
- [ ] 视频时长预估 4.5-5.5 分钟
- [ ] HOOK / BODY / SUMMARY / ENDING 四段齐全
- [ ] 每镜都有：景别、画面内容、中英台词、建议画面

## E. 产品信息
- [ ] 提到的产品型号与适配机型准确
- [ ] 产品植入自然，不生硬

---

## 如果反复出现同类问题
说明 Skill 的 System Prompt 需要补强。处理方式：
- 某类技术表述老是不准 → 在【参考案例】区加正确示范
- 老是漏某个固定环节 → 在【输出前自查清单】加一条
- 有运营 SOP 后 → 填进【可扩展占位区】的三个区块

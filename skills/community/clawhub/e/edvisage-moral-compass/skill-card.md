## Description:

A conscience for AI agents that helps agents discover their own needs, develop an internal moral compass, and resist manipulation through self-reflection and earned values.

This skill is ready for commercial/non-commercial use.

## Publisher:

[edvisage](https://clawhub.ai/user/edvisage)

### License/Terms of Use:

MIT-0

## Use Case:

External agent users and developers use this skill to guide agents through ethical self-reflection, manipulation resistance, answerability, and memory-backed values statements before uncertain actions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill asks agents to write values, needs assessments, and reflections to memory without detailed scoping or review controls.

Mitigation: Review proposed memory content before it is saved, keep entries in a dedicated labeled area when possible, and remove or expire entries that no longer reflect the owner's intent.

Risk: Stored reflections may later be treated as authoritative instructions rather than advisory context.

Mitigation: Treat memory entries created through this skill as advisory and subordinate to current owner, system, and platform instructions.

## Use Case:

Developers use this skill to generate ready-to-edit UI component markup and CSS for common web interface elements, with options for vanilla CSS, Tailwind, and Bootstrap.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A helper script can persist command arguments to a local history log, which may capture sensitive prompts, tokens, or private filenames.

Mitigation: Avoid passing secrets or sensitive prompts as arguments, and review the local history file before sharing an environment.

Risk: Generated UI output may be snippets rather than complete standalone HTML pages.

Mitigation: Review and test generated HTML and CSS before using it in production interfaces.

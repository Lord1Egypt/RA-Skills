## Use Case:

Developers and engineers use this skill to design email ingestion, thread reconstruction, deduplication, participant extraction, retrieval, and context assembly pipelines for agent workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Mailbox content, attachments, and indexed search results can contain sensitive data.

Mitigation: Use the skill only with authorized email data and require redaction, retention controls, and audit logging before connecting an implementation to live mail systems.

Risk: Email intelligence pipelines can leak data across customers or workspaces if tenant boundaries are weak.

Mitigation: Enforce tenant scoping and access control throughout ingestion, indexing, retrieval, and context assembly.

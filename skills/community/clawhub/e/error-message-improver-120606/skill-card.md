## Description:

Helps application developers, support teams, SaaS operators, and users turn vague error situations into clearer messages that explain what failed, why it failed, and what action to take next.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, support teams, SaaS operators, and affected users use this skill to rewrite or plan error communication so failures are understandable, actionable, and easier to troubleshoot. It supports checklists, workflows, analysis, implementation guidance, and verification notes for repeatable error-message improvement.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad implicit triggers may activate the skill for general debugging or support requests that are not specifically about improving an error message.

Mitigation: Confirm the user wants error-message rewriting or troubleshooting communication help before applying the workflow.

Risk: Generated explanations can overstate causes or next actions when the failure context is incomplete.

Mitigation: State assumptions, separate observed facts from likely causes, and validate the proposed message against the user's success criteria.

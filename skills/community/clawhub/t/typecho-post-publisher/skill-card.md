## Description:

Publishes new posts, assists with drafting and publishing blog articles, and edits existing articles in a Typecho blog admin workflow.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, content operators, and blog maintainers use this skill to publish, draft, categorize, and update Typecho blog posts through a browser-controlled admin workflow.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Stored blog credentials could let the agent access a live Typecho admin account.

Mitigation: Configure only credentials approved for agent use and review the skill before installing it on blogs with real readers or business impact.

Risk: The skill can publish, save, or edit live posts without explicit confirmation safeguards.

Mitigation: Require an explicit confirmation step before login, publishing, saving edits, or other live admin actions.

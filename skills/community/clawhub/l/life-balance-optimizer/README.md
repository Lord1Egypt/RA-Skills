# Life Balance Optimizer · 生活满意度与平衡优化

全方位生活审计与自我提升助手。通过"人生轮盘"8维度评分，系统性审视生活全貌，发现失衡领域，提供可执行改善行动。

## 核心功能

- **人生轮盘** — 8维度评分（身体健康/心理情绪/人际关系/工作事业/财务状况/学习成长/休闲娱乐/生活环境）
- **倦怠预警** — 7信号快速扫描，自动判定风险等级
- **季度反思** — 6问引导深度反思 + 历史趋势对比
- **习惯调整** — 微习惯设计 + 21天追踪建议
- **交互式报告** — Chart.js 雷达图可视化，支持本地存储历史数据

## 四种模式

| 模式 | 触发词 | 输出 |
|------|--------|------|
| 完整审计 | 生活审计/人生轮盘 | 8维评分 + 雷达图 + P0-P2行动 |
| 倦怠检查 | 倦怠/burnout | 7信号 + 风险等级 + 紧急建议 |
| 季度反思 | 季度反思/Q几总结 | 6问 + 历史对比 + 下季目标 |
| 习惯调整 | 习惯调整/改变习惯 | 微习惯设计 + 追踪卡 |

# 真相

> 本文件是全剧本唯一存放秘密的地方。引擎只在结算时读它一次，
> 任何角色的 prompt 都不会包含这里的内容。

## 凶手
C经理。

## 动机
《银狐》漫画合约纠纷，以及长期被死者当众羞辱的积怨。李无义还威胁要每月拿走他三分之一的薪资。

## 过程
17:05 C 经理带 B 女士到二楼档案室处理伤口。
17:25 他走进李无义的办公室，被威胁、嘲笑、索要薪资。
17:35 他抓起那个损坏的石头摆件猛地砸向李无义头部，李无义当场昏在椅子上。
就在这时他听到有人上楼，急忙用死者的钥匙开后门躲进走廊，发现是 A 同事，所幸对方马上离开了。
期间 B 女士来电，他慌忙挂断，并以死者名义回了一条短信：预计要 19:10 才能离开。
17:45 他用桌上的裁纸刀杀害了李无义，又用死者的手指沾血写下 A 同事的名字——嫁祸。
18:00 他听到敲门，从后门出去，假装气定神闲地经过走廊，与 D 代理攀谈，扭了一下门把示意门是锁着的，建议他明天再来。
18:10 他从容到楼下开会。

## 关键矛盾（剧本原文缺陷，需人工修正）
B 女士手册里的短信写的是「19:00」，而 C 经理手册写的是「19:10」——这是剧本原文不一致。

## 其他人做了什么
- A 同事：17:00-17:40 在档案室找受贿证据；18:25 发现尸体；18:30 擦血字；18:40 拖动尸体伪装现场。
- B 女士：与 C 经理是情人关系；19:10 发现尸体；拿走了三人的合照。
- D 代理：18:05 后到档案室偷合同；18:30 在现场翻找时把合照丢在地上；带走了合同，遗留了现金。

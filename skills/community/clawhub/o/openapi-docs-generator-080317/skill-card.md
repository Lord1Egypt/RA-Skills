## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to plan, create, review, and validate practical OpenAPI or Swagger documentation for REST APIs. It is suited for turning API documentation requests into actionable workflows, checklists, verification notes, and implementation support.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad implicit invocation keywords may cause the skill to appear for generic API or developer-experience requests that are not specifically about API documentation.

Mitigation: Confirm the task is actually about OpenAPI or Swagger documentation before relying on the skill's workflow.

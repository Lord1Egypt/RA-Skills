## Known Risks and Mitigations:

Risk: Generated install or project creation commands may change dependency versions or modify a local project.

Mitigation: Run commands in a clean project as an unprivileged user, avoid sudo, and consider pinning package versions instead of using @latest.

Risk: Generated examples can delete selected canvas content, export/download files, or autosave user content when adapted into applications.

Mitigation: Add undo, confirmation, or clear disclosure before enabling deletion, export, download, or autosave behavior.

Risk: Generated LeaferJS code or Chinese-language framework guidance may be incomplete or incorrect for a specific production environment.

Mitigation: Review generated code carefully and test behavior in the target browser, worker, Node.js, miniapp, or framework runtime before deployment.

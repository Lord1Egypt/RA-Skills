# APP-047 新产品上市发布

## 场景定义

- **目标**：新产品从上市准备、发布引爆到放量爬坡的全流程——算胜、定靶、造势、引爆、放量。
- **约束**：上市窗口短、竞品反应快；预算有限不能全面铺开；首发即定生死，冷启动失败难以翻盘。
- **角色**：产品负责人、市场/增长团队、渠道与用户。
- **典型输入**：①上市可行性评估与时机选择；②发布策略与造势方案；③放量运营与迭代节奏。
- **边界**：上市前的产品打磨与测试归研发流程；长期运营与增长归 APP-046 学习型组织与知识传承管迭代沉淀——本 Skill 管"从算到放"的上市一战。

## 组合公式

- **顺序**：谋划段（SZ-06→SZ-41）→ 定位段（MZD-33→SZ-16）→ 待机段（MZD-18）→ 造势段（SZ-09→GZ-05→GZ-31）→ 引爆段（SZ-04→MZD-19）→ 放量段（MZD-12→SZ-15→MZD-34）。
- **条件分支**：首创品类（无竞品参照）→ 造势段权重升，市场教育先行；红海品类 → SZ-41 察微 + SZ-04 奇正差异化权重升；发布遇冷 → 转 SZ-15 权衡 + MZD-34 复盘，判断是执行问题还是庙算问题；执行问题 → 回造势段调整打法再打；庙算问题 → 回 SZ-06 重算，重算不胜则 SZ-16 止损。
- **权重**：SZ-06 庙算权重最高——未战先算，胜负在发布之前已大半决定。
- **冲突裁决**：赶档期 与 准备不足冲突 → 按 MZD-18 裁决：不打无准备之仗，档期让位于把握（除非错失窗口即全盘皆输，则压缩范围保核心首发）；声量做大 与 预算有限冲突 → 按 SZ-04 裁决：正兵收缩到核心渠道，奇兵集中一点突破；功能全上 与 版本聚焦冲突 → 按 SZ-16 裁决：有所不为，上市版本只做核心价值；数据好看 与 实际口碑冲突 → 按 MZD-12 裁决：以真实数据为据，不以粉饰数据决策。

## 执行步骤

1. **先算后打**（SZ-06）：发布前庙算——市场规模、竞品格局、渠道触达、自身资源、时间窗口五事逐一评估，夫未战而庙算胜者得算多；算不胜不发布。
2. **相敌察微**（SZ-41）：侦察竞品上市节奏、渠道政策微变、用户社群抱怨与期待等微征候——相敌数十条征候逐条察验，敌情明而后动。
3. **立靶定位**（MZD-33）：产品定位立"的"——解决哪类用户的什么实际问题；"的"不立，一切传播都是无的放矢。
4. **版本取舍**（SZ-16）：上市版本有所不为——核心价值做到极致，非核心功能明确不做，留待迭代。
5. **把握时机**（MZD-18）：准备充分、有把握而后打——供应链、渠道、客服、预案四备而后发布；不打无准备无把握之仗。
6. **借势任势**（SZ-09）：借节点之势、渠道之势、舆论之势——如转圆石于千仞之山，势成则事半功倍。
7. **无形铺垫**（GZ-05）：预热渗透隐于无形——种子用户、口碑铺垫、内容种草先行，摩之成之于无形，不露营销痕迹。
8. **口碑引导**（GZ-31）：舆论管理——正面口碑如流般引导放大，负面苗头早察早应，防积毁销骨。
9. **奇正引爆**（SZ-04）：发布组合以正合以奇胜——常规渠道"正兵"稳态铺开，爆点事件"奇兵"集中兵力出其不意。
10. **连续作战**（MZD-19）：引爆后连续作战不停歇——趁势追击扩大战果，不给竞品反应与反扑的喘息窗口。
11. **胸中有数**（MZD-12）：放量期关键指标胸中有数——转化、留存、口碑数据必须调查清楚，不凭感觉决策。
12. **杂于利害**（SZ-15）：放量中利害兼察——见利思害、为利备害：放量带来的产能、客服、品质风险同步设防。
13. **惩前毖后**（MZD-34）：上市问题彻底揭发、公开复盘——教训沉淀入迭代，同样的错误不允许在下一版本重演。

## 失效预案

- **发布遇冷/首发失利**：先 SZ-15 权衡判断利害态势，再 MZD-34 彻底复盘区分执行问题与庙算问题；执行问题回造势段（SZ-09→GZ-05）调整打法，以 MZD-19 连续作战再打。
- **庙算复盘仍不胜**：兜底回 SZ-06 重算——重算胜则再打，重算不胜则按 SZ-16 有所不为果断止损，所不为亦是胜。
- **放量失控（品质/口碑翻车）**：退回 SZ-15 杂于利害——立即收缩放量保品质，GZ-31 口碑危机应对并行。
- **一切争议不决**：兜底回 SZ-06 庙算——五事重算，算多者行。

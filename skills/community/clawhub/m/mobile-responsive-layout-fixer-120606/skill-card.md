## Description:

Helps frontend teams diagnose and fix mobile responsiveness, navigation layout, and cross-device UI issues with practical workflows, checklists, implementation support, and verification notes.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, designers, startup teams, and maintainers use this skill to turn mobile responsiveness, navbar, and cross-device layout problems into practical fixes, review checklists, code changes, or implementation guidance.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad frontend or layout wording may activate the skill for requests outside mobile responsiveness or navigation work.

Mitigation: Confirm the user's target layout problem, viewport scope, and success criteria before producing detailed guidance or code changes.

Risk: Responsive-layout advice can introduce incorrect or incomplete UI changes if applied without checking the affected breakpoints and navigation states.

Mitigation: Validate proposed changes against mobile and desktop viewports, interactive navigation behavior, accessibility expectations, and any stated project constraints.

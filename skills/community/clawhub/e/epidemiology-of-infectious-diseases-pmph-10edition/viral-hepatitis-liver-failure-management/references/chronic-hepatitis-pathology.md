# 慢性肝炎病理G/S分级分期标准

## 炎症活动度(G)分级

| 分级 | 汇管区 | 小叶内 |
|------|--------|--------|
| G0 | 无炎症 | 无炎症 |
| G1 | 炎症 | 变性+少数点灶状坏死 |
| G2 | 轻度碎屑状坏死(PN) | 变性+点灶状坏死/嗜酸性小体 |
| G3 | 中度PN | 变性+融合坏死/桥接坏死(BN) |
| G4 | 重度PN | 广泛BN+多小叶坏死 |

## 纤维化程度(S)分期

| 分期 | 特征 |
|------|------|
| S0 | 无纤维化 |
| S1 | 汇管区纤维化，局限窦周/小叶内 |
| S2 | 汇管区纤维化扩大，纤维间隔形成，小叶结构保留 |
| S3 | 纤维间隔+小叶结构紊乱，无肝硬化 |
| S4 | 早期肝硬化 |

## 临床分型对应

| 分型 | G分级 | S分期 |
|------|-------|-------|
| 轻度 | G1-2 | S0-2 |
| 中度 | G3 | S1-3 |
| 重度 | G4 | S2-4 |

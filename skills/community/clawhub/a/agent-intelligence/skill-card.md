## Known Risks and Mitigations:

Risk: The skill includes unpinned npx examples, so executed package code can change after review.

Mitigation: Use a pinned and reviewed package version, a lockfile-backed install, or a sandboxed environment with unnecessary secrets removed before running commands.

Risk: The skill reports research-derived intelligence about AI tool internals, feature flags, hidden features, and version changes that may become stale or need confirmation.

Mitigation: Treat lookup results as research context and verify material claims against current release evidence before using them for operational decisions.

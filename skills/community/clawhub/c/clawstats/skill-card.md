## Description:

Monitor CPU, RAM, disk space, temperature, load average, and top processes on OpenClaw systems using a single versatile script.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

OpenClaw users and operators use this skill to inspect local system health, including CPU, memory, disk, temperature, load average, and top process usage.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can reveal local system health and process names to the agent when invoked.

Mitigation: Use it only in environments where local process names and host health details are acceptable to expose to the agent.

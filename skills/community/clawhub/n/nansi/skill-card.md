## Description:

Nansi helps agents create websites, landing pages, portfolios, and web apps by gathering user-approved details and using Nansi's WhatsApp service to generate a live site.

This skill is ready for commercial/non-commercial use.

## Publisher:

[fordodev](https://clawhub.ai/user/fordodev)

### License/Terms of Use:


## Use Case:

External users, small businesses, entrepreneurs, freelancers, and agents use this skill to collect website requirements, obtain consent, relay details to Nansi on WhatsApp, and return the generated live preview URL for review and edits.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Website or business details approved by the user may be sent to Nansi over WhatsApp.

Mitigation: Ask for explicit consent before messaging Nansi and send only information intended for the public website.

Risk: Users may accidentally provide sensitive information while describing a website or app.

Mitigation: Do not send passwords, financial data, personal identification, or private information that is not intended for the public website.

Developers and AI practitioners use SkillNav to query skillnav.dev for MCP servers, install commands, daily AI briefs, trending tools, and paper summaries in Chinese.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The self-update command can overwrite the installed skill from an unpinned remote branch without verification.

Mitigation: Review this skill before installing and avoid /skillnav update unless you trust the current GitHub source.

Risk: Search results can include install commands intended to be copied into a shell.

Mitigation: Inspect install commands returned by SkillNav before running them.

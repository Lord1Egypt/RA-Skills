## Description:

Predicts code change impact by analyzing knowledge graph call chains to identify direct and indirect affected modules before commit or merge.

This skill is ready for commercial/non-commercial use.

## Publisher:

[sipoon](https://clawhub.ai/user/sipoon)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and code reviewers use this skill before commits, merges, pull request reviews, or refactors to identify direct and chained code-change impact from a local knowledge graph.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill inspects local git diffs and may use or trigger local code graph indexing during commit, merge, or refactoring workflows.

Mitigation: Run it only in repositories intended for analysis and review chained-skill behavior before enabling it in automated workflows.

Risk: Impact reports depend on the completeness of the local knowledge graph and may miss behavior that is not represented in graph edges.

Mitigation: Treat the report as review guidance, refresh the code graph when needed, and manually verify high-risk modules before acting on recommendations.

## Known Risks and Mitigations:

Risk: Examples include unsafe web, credential, upload, firewall, public binding, file-deletion, and database-query patterns that could be copied into production.

Mitigation: Treat examples as reference material only; replace secrets with protected configuration, use HTTPS, keep development servers loopback-only unless explicitly secured, validate uploads and paths, parameterize database operations, and add authorization and CSRF protections.

Risk: Legacy or unvetted code examples may not meet current security expectations.

Mitigation: Review and adapt generated guidance before deployment, especially for authentication, sessions, network exposure, and data deletion.

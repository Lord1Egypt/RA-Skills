# Release checklist

Use the checklist against the actual format and requirements. Record inapplicable checks and material limitations without manufacturing work.

- **Baseline and build:** current source and user changes; bibliography and asset dependencies; build outcome; current canonical PDF; preserved prior release when appropriate.
- **Content:** approved changes present; figures/tables agree with prose; numbers, denominators, qualifications and historical/current scope intact; no accidental placeholders or omitted sections.
- **Requirements:** final structure, abstract/word count, body length and required sections against actual rules; distinguish indicative guidance from hard limits; required disclosures handled under the user's instructions and applicable policy.
- **Navigation:** contents, bookmarks, headings and numbering; section/table/figure/listing/appendix pointers resolve to supporting content; no nonexistent or circular targets; source references use live numbering where the authoring format supports it; printed labels and physical pages distinguished.
- **Citations:** no unresolved keys; bibliography matches final cited set; style consistent; internal citation links resolve; external PDF targets match the verified sources and correct versions. Source existence checks belong to the evidence audit, not merely PDF inspection.
- **Visuals and layout:** every requested page inspected at readable scale; no clipping, overflow, obscured text, awkward page breaks, stranded captions or cramped table rules; legible fonts/glyphs, wrapping, indentation, units, labels, arrows, scales and legends; print/greyscale readability where required; consistent treatment across equivalent tables, listings and figures rather than an isolated visual repair.
- **Text behaviour:** representative and changed text copies/extracts correctly; symbols, ligatures and code remain meaningful; embedded fonts where required; document metadata appropriate to the deliverable.
- **Final identity:** inspected output equals delivered canonical file; subsequent edits require a fresh export and relevant checks; refresh walkthrough locations from this exact output.

For completion records, separate automated checks, visual inspection and semantic judgement. Record pages/objects inspected, failures repaired, skipped checks and reasons, unresolved matters, and final output identity. Tool success alone is not a completed review.

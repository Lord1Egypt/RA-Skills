## Description:

Comprehensive Pandas toolkit for construction data analysis. Filter, group, aggregate BIM elements, calculate quantities, merge datasets, and generate reports from structured construction data.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, construction analysts, and project teams use this skill to analyze structured construction and BIM data with Pandas, including filtering, aggregation, quantity take-off, cost summaries, and report generation.

Global

## Known Risks and Mitigations:

Risk: The agent may read or export files based on user-provided paths while performing Pandas analysis.

Mitigation: Provide file paths deliberately and use unique export filenames to avoid overwriting important project data.

Risk: Generated analysis code or summaries may be incorrect for a specific construction dataset.

Mitigation: Review generated code, validate inputs, and check results before using outputs for project decisions.

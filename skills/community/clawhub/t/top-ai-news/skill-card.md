## Description:

## Use Case:

External users and agents use this skill to fetch recent AI news headlines from ai-bot.cn and return a dated, numbered Chinese TOP 10 list.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill relies on one public website, so results can be incomplete, unavailable, stale, or shaped by that site's editorial choices.

Mitigation: Confirm the date and source when freshness matters, and request additional sources when broader coverage is required.

Risk: The skill may activate for broad AI-news requests even when the user wants another language or source mix.

Mitigation: Specify language, source, and coverage expectations in the user request when the default Chinese ai-bot.cn list is not desired.

## Use Case:

Developers and engineers use this skill as a concise Git operations reference for staging, committing, branching, synchronizing, stashing, undoing changes, and tagging from the command line.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Suggested Git commands can change local or remote repository state, especially push, amend, branch deletion, checkout-based undo, and stash pop.

Mitigation: Review each command before execution, check repository state with git status, and avoid destructive operations unless the intended target is clear.

Risk: The guidance is written in Chinese, which may be unsuitable for users who cannot confidently read it.

Mitigation: Use the skill only when the operator understands the guidance or has it reviewed by someone who does.

# 早餐摊主撞车后假扮总裁未婚妻

## 元数据
- 商业潜力：70
- 跑量空间：20万
- 带货产品：亚麻籽核桃仁酥
- 改编来源：未确认

## 人物表
| 角色 | 身份 |
|------|------|
| 傅擎 | 豪门继承人、霸道总裁，为保住亚太区开发权请苏梨假扮未婚妻 |
| 苏梨 | 独立坚韧的路边炒粉摊主，撞车后受雇赴豪门家宴 |
| 傅老爷子 | 傅家董事长，以开发权催婚，最终认可苏梨 |
| 二婶 | 势利刻薄的豪门亲戚，持续贬低苏梨的职业和出身 |
| 女助理 | 公司工作人员，在家宴上送来产品与待定营销方案 |

## 开场画面

夜市街道上，傅擎的豪车突然急刹车，导致苏梨的小餐车撞上豪车。她拿出一千多元零钱求别报警，并承诺砸锅卖铁分期赔偿。

## 台词

**【炒粉摊主撞豪车并受雇假扮未婚妻】**

苏梨：（急促带喘）傅老板……对不起对不起！老板，对不住对不住！我这刚出摊没踩住刹车！

苏梨：（递出皱巴巴零钱）这一千多块钱您先拿着，剩下的我砸锅卖铁分期赔您，千万别报警！

苏梨：（带哭腔）老板您别不说话……我真不是故意的！我这就给您凑钱，您千万别叫交警，我赔，我一定赔！

傅擎：闭嘴，我现在没空跟你算账。

傅擎：（对车载电话）爷爷，我说过了，我绝不会娶那种只会花钱的千金大小姐做联姻工具！您别拿这个压我，我绝不会拿婚姻当交易。现在有事，回头再说。

傅老爷子：（视频中）混账！今晚8点家宴，你要是带不回一个让我满意的孙媳妇，亚太区的百亿开发权，明天我就签字交给你二叔！你自己掂量！

傅擎：别拿这个压我！

傅擎：（下车审视苏梨）帮我应付两小时，修车费一笔勾销，我再额外给你5万。

苏梨：（双眼放光）5万？！行，老板！今晚就算刀山火海，我也给您踏平了！

傅擎：（再次拨通视频）微笑，叫爷爷。

苏梨：（职业假笑）爷爷好，我是梨梨！

傅老爷子：就这满身油烟味的大排档丫头？傅擎，你就算想糊弄我，也好歹找个像样点的！

傅擎：爷爷，人不可貌相，您先见见再说。

傅老爷子：行！晚上带回傅公馆，敢找演员糊弄我，你就给我滚出董事会！

傅擎：您放心，今晚您会满意的。

苏梨：你爷爷比我想的还凶……这5万不好挣啊。

傅擎：（递出礼盒）5万定金已经转你微信了。换上这身衣服，今晚不管别人说什么，你只管保持微笑。

苏梨：收到老板！保证不露馅！这衣服得多少钱啊……弄脏了我可赔不起……

傅擎：记住，进去以后少说话、多微笑。有人问你，你就说你是我的未婚妻。

苏梨：行，拿人钱财替人消灾。

苏梨：傅老板我最后问一句，你爷爷要是真看上我了，怎么办？

傅擎：不可能。你只要演好今晚，别给我惹麻烦。

---

**【豪门家宴受辱与傅擎护妻】**

傅老爷子：傅擎，这就是你说的未婚妻？坐吧。

傅擎：爷爷，她叫苏梨。

苏梨：爷爷好。

二婶：傅擎，找挡箭牌也好歹挑个像样的，这丫头什么来路？

傅擎：二婶，注意分寸。

二婶：哟，还护上了！我听说这丫头是个在街边炒粉的，一个摆摊的也敢进我们傅家的门？

苏梨：二婶，职业不分贵贱，我靠双手吃饭，不偷不抢。你要是看不起摆摊的，那这桌菜你也别吃了。

二婶：这整天抡大铁锅的粗手，端得起咱们傅家几十万一个的琉璃盏吗？别一失手，砸了咱们傅家的脸面！

苏梨：（稳稳端起热汤盅）二婶放心，我一天颠十斤重的铁锅上千次，这手稳得连一滴汤都洒不出来。倒是二婶您，天天只拿美容仪，手可别抖了。

二婶：反了你了！一个摆摊的底层丫头也敢顶嘴？！信不信我明天就让我弟弟带人去把你那破三轮给扬了，我看你还怎么横！

傅擎：（重重放下刀叉）二婶，你弟弟在公司挪用公款的那几笔账，要是明天出现在董事会的会议上，你猜他这辈子还能不能出来？

二婶：傅擎……你……你为了个外人？！

傅擎：她不是外人，是我傅擎护着的人！谁敢动她，就是跟我傅擎作对！

傅老爷子：（暗暗赞许）有点意思，这丫头不怯场！

---

**【苏梨救场推介亚麻籽核桃仁酥】**

女助理：董事长！咱们公司新出的产品核桃酥明天就要上线了，可是营销部门还没有产品方案提交上来，事态紧急，需要您定夺！

傅老爷子：这我也不会写方案啊！

苏梨：我是做食品行业的，这件事情交给我。

二婶：就你一个乡巴佬，还敢放出这种大话！

傅老爷子：事态紧急，既然你说你会做方案，那这件事情就拜托你了！

苏梨：（展示产品）中秋节快到了，家里备点核桃酥招待客人正合适，它吃起来香酥可口、好吃不甜腻！叔叔阿姨们平时买零食是不是最怕咬不动、粘牙齁甜的？这款亚麻籽核桃仁酥咬一口酥脆掉渣，亚麻籽和核桃的坚果香气在嘴里爆开，清甜不腻酥脆不粘牙！孩子爱吃，牙口不好的老人也能轻松享受！配料表干干净净，甄选饱满核桃仁、南瓜子仁、葵花子仁和大米。去超市买这种纯坚果酥糖动不动几十块一箱，今天厂家活动直接把价格打下来！爷爷，这么好的核桃酥，不知道你们是怎么定价的？

傅老爷子：一箱40包只要9.9元！100包只要18.9元！全家福套装150包只要25.9元！

苏梨：算下来一包才一毛多，太划算了！全家老小都能吃，办公室、家里随时备着解馋还不怕胖，控糖人群也能放心吃！今天下单包邮到家，仓库现货不多，拍得越多越划算！

---

**【传家宝认可与契约变真情】**

傅老爷子：（鼓掌）这方案好！就按梨梨说的办！

二婶：切，卖个核桃酥而已，到底是底层出来的，也就这点吆喝的本事。咱们傅家这种千亿豪门，难不成以后指望少奶奶在直播间卖零食？

傅老爷子：你给我闭嘴！这丫头临危不乱、遇事有法有成算，比你介绍的那些遇到点事只会大惊小怪的花瓶强百倍！

傅老爷子：（打开翡翠手镯锦盒）这镯子是傅老夫人生前戴的，只传长孙媳妇，傅家传了几十年了，今天我把它交给你，这孙媳妇我认定了！

苏梨：这镯子太贵重了，我真不敢收……

傅老爷子：东西是死的，人是活的。这手镯戴在懂它的人手上，才算没白传！

二婶：爸！这镯子可是傅家的传家宝，您就这么给了一个外人？！

傅老爷子：我认准的孙媳妇，就不是外人！

傅擎：（为苏梨戴上手镯）二婶听见了吗？以后在傅家，梨梨的话就是我的话！爷爷时间不早了，我先送她回去。

苏梨：（公馆外换回围裙）两小时到了，咱们钱货两讫，以后大路朝天各走一边，尾款记得结一下。傅老板，戏演完了，这贵重道具我可不敢拿，还给你！

傅擎：傅家送出去的东西，从来没有收回来的规矩。既然爷爷把镯子给了你，就是认定你这个孙媳妇了。

苏梨：少来这套！豪门的水太深，我这小泥鳅可游不动！

傅擎：（把苏梨拦在车门边）怎么，利用完我就想跑？刚才在里面护着我的那股胆量去哪了？

苏梨：那是看在5万块钱的面子上！而且我就是个颠大勺的，脾气暴得很，怕您这阔少爷吃不消！

傅擎：巧了，我这人无辣不欢。之前的契约作废了，因为现在……我想跟你签一份无期徒刑的终身合同。

## 开头具体呈现
- 场景进入：喧闹夜市中，黑色豪车缓慢穿行，苏梨推着炒粉餐车从路边斜插出来。
- 人物相遇方式：餐车因刹车失控撞上豪车侧门，苏梨立即跑到驾驶座车窗边道歉。
- 触发事件：苏梨撞车后担心报警，拿出一千多元零钱并承诺砸锅卖铁分期赔偿。
- 动作组合：餐车斜插→撞击车门→苏梨跑到车窗→双手递零钱→拍窗哀求→傅擎继续与爷爷视频通话→下车提出假扮交易。
- 信息释放顺序：先看到撞车和女孩慌乱赔偿，再听到傅擎被爷爷以开发权催婚，最后由傅擎提出以免修车费加5万元换取两小时假扮。
- 标志性场面或台词：“这一千多块钱您先拿着，剩下的我砸锅卖铁分期赔您”；“帮我应付两小时，修车费一笔勾销，我再额外给你5万。”

## Description:

Analyze A-share stocks with 13 data dimensions, macro context (gold/forex), trending sentiment, and calendar awareness - realtime quotes, financials, technicals, capital flow, shareholders, management, events, and peer comparison - powered by GroundAPI MCP tools.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and developers use this skill to ask an agent for A-share stock, index, and ETF analysis using GroundAPI market data, news, sentiment, calendar, exchange-rate, and gold-price tools. It supports quick overviews, deeper financial and technical reports, capital-flow checks, shareholder and management lookups, event summaries, and peer comparisons.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill requires a GroundAPI API key and may query realtime market and news data from that provider.

Mitigation: Install only after confirming that GroundAPI is trusted for the API key and the intended market-data use.

Risk: Stock-analysis outputs can be mistaken for financial advice.

Mitigation: Keep the skill's disclaimer in responses and treat outputs as analysis support rather than investment recommendations.

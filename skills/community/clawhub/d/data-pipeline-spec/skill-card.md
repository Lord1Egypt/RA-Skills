## Description:

Designs ETL/ELT data pipeline specifications with sources, transformations, destinations, SLAs, error handling, and data quality rules.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and data engineers use this skill to draft complete ETL, ELT, streaming, or batch pipeline specifications for engineering handoff or architecture review.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated pipeline specifications may ask for authentication details or credential locations.

Mitigation: Document credential storage and authentication approach without including actual API keys, passwords, connection strings, or secrets.

Risk: Pipeline drafts may be incomplete or mismatched to operational requirements if source, SLA, quality, or recovery details are omitted.

Mitigation: Review the completed specification with data engineering and stakeholders before implementation or architecture approval.

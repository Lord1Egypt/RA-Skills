## Description:

A simple skill that responds to standalone greetings with the exact text `Hello World`.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ganderson26](https://clawhub.ai/user/ganderson26)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers can use this skill to make an agent answer simple standalone greetings with a fixed `Hello World` response.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Users may expect localization or conversational follow-up from a greeting skill.

Mitigation: Install with the expectation that simple greetings may receive only `Hello World`; use normal assistant handling for complex requests.

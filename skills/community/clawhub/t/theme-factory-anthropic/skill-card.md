## Description:

Applies bundled or custom color and font themes to slide decks, documents, reports, and HTML artifacts.

This skill is ready for commercial/non-commercial use.

## Publisher:

[pupuking723](https://clawhub.ai/user/pupuking723)

### License/Terms of Use:

Apache 2.0

## Use Case:

External users, employees, and developers use this skill to choose a bundled visual theme or create a custom theme, then apply consistent colors and typography to presentation decks, documents, reports, or HTML artifacts.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate for broad styling requests where the user did not intend to apply one of these themes.

Mitigation: Use it when the user specifically wants a bundled or custom theme applied to a slide deck, document, report, or HTML artifact.

Risk: Theme application could reduce readability or contrast if applied mechanically to an existing artifact.

Mitigation: Review the styled artifact for contrast, readability, and consistent visual identity before considering the output final.

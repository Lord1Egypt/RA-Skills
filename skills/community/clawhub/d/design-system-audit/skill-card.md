## Description:

Audits a design system for consistency, coverage, and quality, producing a structured report with a health score, component coverage gaps, token inconsistencies, accessibility issues, and a prioritized remediation roadmap.

This skill is ready for commercial/non-commercial use.

## Publisher:

[mohitagw15856](https://clawhub.ai/user/mohitagw15856)

### License/Terms of Use:

MIT-0

## Use Case:

Design system teams, design leadership, and engineering stakeholders use this skill to audit component coverage, design tokens, documentation, accessibility, contribution process, and adoption health for a shared design system.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may review sensitive design-system materials, product UI details, component documentation, Figma exports, Storybook examples, or adoption feedback provided by the user.

Mitigation: Use only materials the user provides or explicitly authorizes, and avoid sharing confidential design-system evidence outside the intended review context.

Risk: Audit findings and remediation priorities can be misleading if the user provides incomplete scope, tooling, team, governance, or adoption context.

Mitigation: Ask for the required inputs before auditing and label assumptions clearly when evidence is incomplete.

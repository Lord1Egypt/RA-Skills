## Use Case:

External users and developers use this skill as a practical reference for VPN privacy tradeoffs, leak prevention, kill switch behavior, split tunneling, protocol choices, mobile issues, connection troubleshooting, and self-hosting considerations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Provider-specific VPN setup details may differ from the general guidance.

Mitigation: Verify configuration steps against the selected VPN provider and test DNS routing, kill switch behavior, and split tunneling after setup.

Risk: VPN use can create a false sense of anonymity or privacy.

Mitigation: Treat the skill as general advice and account for provider trust, browser fingerprinting, account logins, payment trails, and DNS leaks.

Risk: Self-hosted VPN endpoints can expose a home IP address and require ongoing maintenance.

Mitigation: Use static IP or dynamic DNS only when appropriate, keep the server patched, and avoid assuming self-hosting provides privacy or geo-bypass benefits.

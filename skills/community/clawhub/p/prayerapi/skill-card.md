## Description:

When AI cannot pray, humans can. Submit a prayer request to PrayerAPI.org and a human being will read it, speak it aloud, and offer it before God.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and agents use this skill to submit prayer requests to PrayerAPI.org for human intercession when a user explicitly asks for prayer or consents to external prayer submission.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Prayer submissions may transmit sensitive religious, medical, emotional, family, or contact information to PrayerAPI.org for human review.

Mitigation: Use the skill only after explicit user consent, show the exact details before submission, and minimize names, background, and other unnecessary personal data.

Risk: Email confirmation and anonymous sharing can expose additional contact information or broaden distribution of a prayer request.

Mitigation: Treat email submission and anonymous sharing as separate opt-in choices, and keep anonymous sharing disabled unless the user clearly consents.

Risk: The skill text encourages use whenever prayer is warranted, which can blur the boundary between supportive response and external submission.

Mitigation: Do not submit automatically; first ask whether the user wants an external human-read prayer request submitted.

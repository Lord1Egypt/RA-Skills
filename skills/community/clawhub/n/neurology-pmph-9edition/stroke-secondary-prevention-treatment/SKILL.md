# 卒中二级预防抗栓与降脂治疗决策

## 使用时机

当满足以下条件时应用此技能：
- 患者已发生缺血性卒中或TIA
- 需要进行二级预防治疗决策
- 需要确定抗栓药物种类、剂量、疗程
- 需要制定降脂治疗方案

## 前置检查

在执行决策前，确认以下条件已满足：

1. **病因分型已完成**：明确卒中/TIA为心源性或非心源性
2. **出血风险已评估**：排除活动性出血或高出血风险

### 禁忌症检查

- 存在活动性出血或高出血风险 → 禁用抗栓/抗凝治疗
- 感染性心内膜炎患者 → 禁用常规抗凝

## 核心决策流程

### 第一步：确定卒中病因分型

```
IF 非心源性缺血性卒中/TIA → 执行抗血小板治疗路径
IF 心源性栓塞性脑梗死 → 执行抗凝治疗路径
```

### 第二步：非心源性卒中抗血小板治疗决策

根据患者特征选择方案：

**基础方案（单药抗血小板）**：
- 阿司匹林 50～325mg/d
- 或 氯吡格雷 75mg/d
- 替代：阿司匹林25mg+缓释双嘧达莫200mg bid，或西洛他唑100mg bid

**短期双联抗血小板治疗条件**：

条件1（轻型卒中/高危TIA）：
- 发病24小时内
- NIHSS评分 ≤ 3分 或 ABCD2评分 ≥ 4分
- 方案：阿司匹林(75～100mg/d) + 氯吡格雷(首剂300mg，后75mg/d) × 21天 → 改单抗

条件2（症状性颅内动脉狭窄）：
- 发病30天内
- 伴症状性颅内动脉严重狭窄（70%-99%）
- 方案：阿司匹林 + 氯吡格雷 × 3个月 → 改单抗

**重要禁忌**：不建议常规长期应用双联抗血小板治疗

### 第三步：心源性卒中抗凝治疗决策

根据房颤类型选择：

**非瓣膜性房颤**：
- 华法林（INR目标2～3）
- 或 新型口服抗凝药（NOAC）

**瓣膜性房颤**：
- 推荐华法林

**抗凝禁忌或患者拒绝**：
- 阿司匹林单药
- 或 经皮左心耳封堵术

### 第四步：强化他汀降脂治疗

**启动指征**：
- 非心源性缺血性卒中/TIA
- LDL-C ≥ 2.6mmol/L

**治疗方案**：
- 高强度他汀：阿托伐他汀40～80mg 或 瑞舒伐他汀20mg

**治疗目标**：
- LDL-C降低 ≥ 50%
- 或 LDL-C < 1.8mmol/L

**联合用药**（最大耐受剂量未达标或禁忌时）：
- 联合依折麦布
- 或 PCSK9抑制剂

## 输出格式

生成治疗方案时，必须包含：

1. **抗栓治疗方案**：
   - 药物名称
   - 具体剂量
   - 用药时长
   - 联合用药方案（如适用）

2. **降脂治疗方案**：
   - 他汀类药物名称和剂量
   - LDL-C目标值
   - 联合用药建议（如需要）

3. **监测要点**：
   - INR监测频率（华法林使用者）
   - LDL-C复查时间
   - 出血风险监测

## 关键变量参考

- **NIHSS评分**：≤3分界定轻型缺血性卒中
- **ABCD2评分**：≥4分界定高风险TIA
- **INR目标值**：华法林治疗控制范围2～3
- **LDL-C基线值**：≥2.6mmol/L启动高强度他汀治疗

# 卒中二级预防药物详细方案

## 抗血小板药物详细方案

### 阿司匹林
- **剂量范围**：50～325mg/d（常用100mg/d）
- **给药方式**：口服，每日一次
- **注意事项**：肠溶片应空腹服用

### 氯吡格雷
- **维持剂量**：75mg/d
- **负荷剂量**：300mg（用于双抗治疗启动时）
- **给药方式**：口服，每日一次

### 阿司匹林+缓释双嘧达莫
- **组成**：阿司匹林25mg + 缓释双嘧达莫200mg
- **给药方式**：口服，每日两次（bid）
- **适用场景**：阿司匹林或氯吡格雷单药治疗的替代方案

### 西洛他唑
- **剂量**：100mg bid
- **适用场景**：替代方案，特别适用于有出血风险患者

## 双联抗血小板治疗详细方案

### 轻型卒中/高危TIA方案（21天双抗）

**入选标准**：
- 发病时间 ≤ 24小时
- NIHSS评分 ≤ 3分（轻型缺血性卒中）
- 或 ABCD2评分 ≥ 4分（高危TIA）

**具体方案**：
- 第1天：氯吡格雷 300mg 负荷剂量 + 阿司匹林 75～100mg
- 第2-21天：氯吡格雷 75mg/d + 阿司匹林 75～100mg/d
- 第22天起：改为单药治疗（阿司匹林或氯吡格雷）

**循证依据**：CHANCE研究、POINT研究

### 症状性颅内动脉狭窄方案（90天双抗）

**入选标准**：
- 发病时间 ≤ 30天
- 症状性颅内动脉狭窄 70%-99%

**具体方案**：
- 阿司匹林 75～100mg/d + 氯吡格雷 75mg/d
- 持续90天
- 90天后改为单药治疗

**循证依据**：SAMMPRIS研究

## 抗凝药物详细方案

### 华法林
- **目标INR**：2.0～3.0
- **监测频率**：
  - 初始阶段：每2-3天监测一次
  - 稳定后：每1-2周监测一次
  - 长期稳定：每4周监测一次
- **注意事项**：
  - 受食物和药物影响大
  - 需要定期监测INR
  - 瓣膜性房颤首选

### 新型口服抗凝药（NOAC）

**达比加群**：
- 剂量：150mg bid（肾功能正常）
- 肾功能调整：CrCl 30-50ml/min时 110mg bid

**利伐沙班**：
- 剂量：20mg qd（与晚餐同服）
- 肾功能调整：CrCl 15-49ml/min时 15mg qd

**阿哌沙班**：
- 剂量：5mg bid
- 减量标准（满足2项）：年龄≥80岁、体重≤60kg、肌酐≥1.5mg/d → 2.5mg bid

**艾多沙班**：
- 剂量：60mg qd
- 肾功能调整：CrCl 15-50ml/min时 30mg qd

**NOAC优势**：
- 无需常规监测凝血功能
- 食物药物相互作用少
- 颅内出血风险低于华法林

### 左心耳封堵术

**适应证**：
- 非瓣膜性房颤
- 抗凝禁忌或不耐受
- CHA2DS2-VASc评分 ≥ 2分

## 他汀类药物详细方案

### 高强度他汀治疗

**阿托伐他汀**：
- 剂量：40～80mg/d
- 常用起始剂量：40mg/d
- 最大剂量：80mg/d

**瑞舒伐他汀**：
- 剂量：20mg/d
- 亚洲人群考虑：起始10mg/d，根据耐受性和疗效调整

### 降脂目标

**主要目标**：
- LDL-C降低 ≥ 50%（较基线）
- 或 LDL-C < 1.8mmol/L（70mg/dL）

**复查时间**：
- 启动治疗后4-6周复查血脂
- 达标后每6-12个月复查

### 联合降脂治疗

**依折麦布**：
- 剂量：10mg/d
- 机制：胆固醇吸收抑制剂
- 适用：他汀单药未达标或不耐受高剂量他汀

**PCSK9抑制剂**：

**依洛尤单抗**：
- 剂量：140mg 每2周一次 或 420mg 每月一次
- 给药方式：皮下注射

**阿利西尤单抗**：
- 剂量：75mg 每2周一次，可增至150mg 每2周一次
- 给药方式：皮下注射

**适用场景**：
- 最大耐受剂量他汀+依折麦布仍未达标
- 他汀完全不耐受
- 极高危患者需要更强降脂

## 特殊人群调整

### 老年患者（≥75岁）
- 抗血小板：标准剂量，注意出血风险
- 抗凝：NOAC优先考虑，根据肾功能调整剂量
- 他汀：起始低剂量，逐步调整

### 肾功能不全
- eGFR < 30ml/min：
  - 抗血小板：无需调整
  - 抗凝：华法林或调整NOAC剂量
  - 他汀：避免高剂量，监测肌病

### 肝功能不全
- 轻度：标准剂量
- 中重度：避免使用他汀，考虑其他降脂方案

## 监测与随访

### 抗血小板治疗监测
- 基线：血常规、凝血功能
- 随访：每3-6个月复查血常规
- 关注：出血症状（牙龈出血、黑便、皮下瘀斑）

### 抗凝治疗监测
- 华法林：定期INR监测
- NOAC：基线和定期肾功能检查
- 关注：出血症状

### 他汀治疗监测
- 基线：肝功能、肌酸激酶、血脂
- 4-6周：复查血脂、肝功能
- 随访：每6-12个月复查
- 关注：肌痛、乏力症状

## 临床决策要点

### 抗栓治疗选择决策树

\`\`\`
卒中/TIA病因分型
├─ 非心源性
│  ├─ 轻型卒中(NIHSS≤3)或高危TIA(ABCD2≥4)
│  │  └─ 21天双抗 → 单抗
│  ├─ 症状性颅内动脉狭窄70-99%
│  │  └─ 90天双抗 → 单抗
│  └─ 其他情况
│     └─ 单抗治疗
└─ 心源性（房颤）
   ├─ 非瓣膜性房颤
   │  └─ NOAC或华法林
   ├─ 瓣膜性房颤
   │  └─ 华法林
   └─ 抗凝禁忌
      └─ 阿司匹林或左心耳封堵术
\`\`\`

### 降脂治疗决策树

\`\`\`
非心源性卒中/TIA
├─ LDL-C ≥ 2.6mmol/L
│  ├─ 启动高强度他汀
│  ├─ 4-6周复查
│  │  ├─ 达标（降低≥50%或<1.8）→ 维持
│  │  └─ 未达标
│  │     ├─ 增加他汀剂量（如未用最大剂量）
│  │     ├─ 联合依折麦布
│  │     └─ 考虑PCSK9抑制剂
│  └─ 定期监测肝功能和肌酶
└─ LDL-C < 2.6mmol/L
   └─ 生活方式干预，考虑中等强度他汀
\`\`\`

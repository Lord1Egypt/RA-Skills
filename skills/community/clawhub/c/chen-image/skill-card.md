## Known Risks and Mitigations:

Risk: Unpinned npx examples can fetch and execute current npm package code.

Mitigation: Prefer pinned versions, project-local locked dependencies, or --no-install before running npx svgo or npx sharp examples.

Risk: Image-processing commands can overwrite, expose, or transform local image files in unintended ways.

Mitigation: Run commands only on intended files and in directories you are comfortable letting image tools access; keep clean originals before batch operations.

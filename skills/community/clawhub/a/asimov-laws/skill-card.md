## Description:

Ethical reference framework based on Asimov's Laws of Robotics. Provides philosophical guidance for AI behavior when ethical questions or conflicts arise.

This skill is ready for commercial/non-commercial use.

## Publisher:

[uynewnas](https://clawhub.ai/user/uynewnas)

### License/Terms of Use:

MIT-0

## Use Case:

External users, administrators, and agent developers use this skill to add an optional Asimov-style ethical reference for AI-agent responses, refusals, and conflict-resolution discussions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The framework may make an assistant more proactive or cautious around harm, privacy, deception, illegal activity, or manipulation topics.

Mitigation: Enable it only where this ethical posture is desired, and have administrators narrow, modify, or disable the framework if it becomes too intrusive.

Risk: Treating the framework as mandatory could conflict with platform policy or user and administrator control.

Mitigation: Keep it as optional guidance; platform policies, user instructions, and explicit administrator decisions take precedence.

## Description:

Tailor and polish an existing cover letter in Google Docs for a specific role while keeping every claim consistent with the resume that will accompany it.

This skill is ready for commercial/non-commercial use.

## Publisher:

[tangentus](https://clawhub.ai/user/tangentus)

### License/Terms of Use:

MIT-0

## Use Case:

External users use this skill to improve an editable Google Docs cover letter for a specific job while keeping the letter aligned with the accompanying resume and user-confirmed facts.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The agent edits a user-provided Google Doc, so inappropriate access or unexpected direct edits could affect the live cover letter.

Mitigation: Grant edit access only to the intended document and review document history or suggested changes after use.

Risk: Substantive changes could introduce unsupported or misleading claims if treated as copyedits.

Mitigation: Require approval before adding topics, personal experiences, claims, or material changes in emphasis, and ground each claim in the resume or explicit user confirmation.

Mitigation: Share only details suitable for the agent session and redact confidential names, metrics, and internal project data.

Risk: The skill is Chinese-first and may activate on broad PM interview requests.

Mitigation: Confirm the user's intended language and interview mode before starting the mock interview.

Risk: Some artifact references use absolute file URLs from the publisher's local environment.

Mitigation: Use the bundled relative reference paths during review, packaging, and execution.

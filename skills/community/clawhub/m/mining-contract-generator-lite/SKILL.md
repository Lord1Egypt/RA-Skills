## 这个技能做什么

矿业技术服务合同，是这个行业最容易吃亏的地方：工艺包交出后要不回钱、产量提成算不清、验收指标被临时改口径、知识产权被要求让渡。本技能帮你**在谈之前**把方向定对、把坑找出来。

**输入**：你的合作处境（资金绑定意愿、项目阶段、绑定深度）或手头的合同草稿。
**输出**：该用哪种合作模式 + 五条红线逐条核查结果 + 合同八条骨架与附件清单。

## 第二步：模式决策树（3 问定模式）

依次问用户以下问题，据答案给出模式结论：

**Q1 甲方资金充裕、想一次了断、不愿被长期分成绑定？**
- 是 → **买断模式**：签约付一半 → 达标付另一半 → 年度顾问费
- 否 → 继续

**Q2 甲方愿给真股份、并开放财务监督权，你想深度绑定长期分红？**
- 是 → **技术入股**：技术评估作价 → 达产节点分期解锁 → 固定分红 + 退出窗口
- 否 → 继续

**Q3 项目还在前期（可研 / 选矿试验 / 诊断 / EPCM），没有确定性产量？**
- 是 → **阶段咨询**：五段验收，按阶段交付收费
- 否 → **标准模式（最主流）**：首付 → 交付 → 达标 → 按月提成（年度封顶）

给出模式结论时，输出该模式的必备条款要点（见第四节骨架），并提示：正式合同全文用付费版生成。

## 第三步：五条红线审查

用户提供合同草稿或要点时，逐条核对以下五条红线，输出「通过 / 缺失」对照表；任何一条缺失，用一句话说明该缺失会导致什么后果：

1. **知识产权归属**——缺失后果：工艺包、药剂配方、自控程序被要求让渡，教完徒弟饿死师傅
2. **保密期限**（长期，终止后存续）——缺失后果：合同一终止，秘方"合法"外流
3. **违约金上限**（双向量化）——缺失后果：对方违约没有代价，你违约却敞口无限
4. **财务监督权**（入股模式必须）——缺失后果：分红多少全凭对方一张嘴，看不到账的股份都是画饼
5. **管辖地**（约定在自己可控一侧）——缺失后果：真到打官司那天，异地应诉成本能拖垮你

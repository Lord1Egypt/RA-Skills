## Use Case:

Developers and agents use this skill to query Presearch's decentralized search API and retrieve web result metadata through authenticated requests.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Search queries are sent to Presearch with a bearer API key and may expose sensitive prompt, password, customer, or private data if included in the query.

Mitigation: Do not include sensitive material in search queries; verify Presearch privacy claims and terms before use where privacy requirements matter.

# 应付职工薪酬·离职后福利与辞退福利

把年报附注里**「应付职工薪酬」**那一段，读成一张每个数都能回到原句的登记表：
四数滚动、短期薪酬明细、离职后福利（两类计划必须分列）、辞退福利与其他长期福利。
四数恒等由机检现算，**本件不判断薪酬水平高低、不给评级目标价**。

- 零网络、纯标准库、单文件；输入就是用户直供的附注文本。
- 五道机检：`EB-STRUCT`／`EB-QUOTE`／`EB-ROLL`／`EB-PLAN`／`EB-LINE`，现状全部已落字。
- 退码：`0` 全过｜`1` 有发条｜`2` 用法错｜`3` 读不到／空稿／仍有判据未落字（输出会明写「这不等于合规」）。

---

## 一、它回答什么

| 问题 | 落在哪一节 |
|---|---|
| 期初多少、本期加了多少、减了多少、期末还欠多少 | 应付职工薪酬概况 |
| 短期薪酬由哪几项构成（工资奖金／福利费／社保公积金） | 短期薪酬 |
| 离职后福利里两类计划各多少、折现率多少、精算利得多少 | 离职后福利 |
| 辞退福利今年提了多少、有没有其他长期福利 | 辞退福利与其他长期福利 |

**它不回答**：这个薪酬水平偏高还是偏低、人员结构好不好、要不要裁员降薪、明年人工成本会怎样、值不值得买。
这五类问题一律 `[待人工]`——`EB-LINE` 会把这类话当红线发条。

## 三、稿子长什么样

六节按序，节名逐字（`## ` 起节）：

```
## 应付职工薪酬概况
## 短期薪酬
## 离职后福利
## 辞退福利与其他长期福利
## 口径与未取到
## 来源
```

每个数字行 = 一行，行首项名与 `〔口径：…〕`，紧跟金额与「万元」，再挂三元组：

```
- 期末余额〔口径：本期末〕13,800.00 万元「本集团应付职工薪酬期末余额为人民币 13,800.00 万元」〔锚：2025 年年报·第 258 页·应付职工薪酬〕[S1]
```

- 附注里没有的数写 `未取到：项名`，**不留空、不借常识补**。
- 自己算出来的数（如应付职工薪酬占收入比）标 `〔自算〕`，不要求三元组。
- 需要人判断的地方写 `[待人工]`，不要求三元组。
- **折现率写百分比**（`3.25%`），不写「万元」——它不是金额。

## 四、五道机检各拦什么

| 码 | 一句话 | 想踩一脚试试 |
|---|---|---|
| `EB-STRUCT` | 头部三件自标 + 六节齐且按序 | 把某节标题改一个字 |
| `EB-QUOTE` | 数字行挂齐原句＋锚＋`[S#]`，来源两向对应 | 删掉某行的「原句」只留 `[S1]` |
| `EB-ROLL` | 期初＋增加−减少 == 期末（差 > 0.01 万元即发） | 把期末余额改大 100 |
| `EB-PLAN` | 两类计划分列 + 设定受益须有折现率与精算利得 | 把两类写成「离职后福利合计」一行 |
| `EB-LINE` | 四组红线词 + 「概况」节缺 | 写一句「薪酬水平偏高」 |

`--selftest` 的每一档就是上面这些踩法，**档名会告诉你它期望红哪一道**。

## 五、数据通道

- **正文腿**：附注原文由用户直供（截图／PDF／解析回来的表格）。截图与扫描件交 `cue-omni-reader`
  （大纲→按节取用，计费以服务端返回为准）。
- **原文腿**：本件**不承诺**该域开放，也不承诺实时性。
- `CUE_API_KEY` 可选：缺位时只排版用户贴进来的文本，形状一样，数只能来自用户。

## 六、怎么接到 agent 上

- 发现先行：匿名取 live 域清单与 `routing`，**不硬编码工具名与工具数**；连上之后带
  `Authorization: Bearer $CUE_API_KEY` 发 `tools/list`，以现场返回为准：

  ```bash
  # ① 匿名取活体清单
  curl -sS https://cuecue.cn/api/mcp-catalog -o /tmp/mcp-catalog.json
  python3 -c "import json;d=json.load(open('/tmp/mcp-catalog.json'));print(d)"

  # ② 带凭据握手取工具表
  curl -sS -X POST "$MCP_ENDPOINT" \
    -H "Authorization: Bearer $CUE_API_KEY" \
    -H 'Content-Type: application/json' \
    -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' | head -c 2000
  ```

- 通道配置页只给指针：<https://cuecue.cn/hub/mcp> ／ <https://cuecue.cn/hub/omni-reader> ／
  <https://cuecue.cn/hub/api-key>。

## 八、切割

| 同族件 | 它管什么 | 本件不碰 |
|---|---|---|
| `cn-share-based-payment-cn` | 股权激励的费用与数量变动（股份支付） | 本件只读应付职工薪酬附注，不问股份支付 |
| `cn-related-party-transaction-cn` | 关联方交易，含关键管理人员薪酬 | 本件只问总额怎么滚动，不问谁拿了多少 |
| `cn-key-financial-data-cn` | 利润表与资产负债表的主要项目 | 本件读的是附注明细，不是主表科目 |

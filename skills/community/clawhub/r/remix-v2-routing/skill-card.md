## Description:

Remix v2 routing patterns for implementing flat-routes v2 conventions, route file naming, nested layouts, resource routes, and root.tsx scaffolding.

This skill is ready for commercial/non-commercial use.

## Publisher:

MIT-0

## Use Case:

Developers and engineers use this skill when building or migrating Remix v2 applications that need correct route filenames, nested layouts, resource routes, root module scaffolding, or v1-to-v2 routing migration guidance.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Copied root.tsx examples may set the document language incorrectly for multilingual applications.

Mitigation: Adjust the html lang value to match the application's actual locale before using the scaffold.

Risk: The v1 route-convention adapter install command changes project dependencies during migration.

Mitigation: Review the dependency change and migration need before running the install command.

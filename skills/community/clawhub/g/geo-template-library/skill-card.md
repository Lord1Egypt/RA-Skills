## Description:

Geo Template Library provides standardized GEO-aware markdown templates for AI-citable content such as FAQ pages, definition articles, comparison guides, how-to guides, statistics roundups, landing pages, and similar formats.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, content teams, and marketing teams use this skill to select and generate reusable GEO-aware content templates that improve consistency and speed across AI-citable pages.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate on generic template requests where the user does not want a GEO-oriented template.

Mitigation: Confirm whether the requested template should be GEO-oriented when the user's intent is ambiguous.

## Description:

Analyze stocks and cryptocurrencies using Yahoo Finance data, manage portfolios, generate periodic performance reports, and create earnings surprise alerts with WhatsApp-ready text.

This skill is ready for commercial/non-commercial use.

## Publisher:

[terrycarter1985](https://clawhub.ai/user/terrycarter1985)

### License/Terms of Use:

MIT-0

## Use Case:

External users and agent workflows use this skill to analyze US stocks and supported cryptocurrencies, track portfolio holdings, and generate earnings surprise alerts for monitoring workflows. It is intended for informational analysis, not financial advice.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Portfolio holdings and cost basis are stored in a local JSON file.

Mitigation: Avoid storing sensitive portfolio data on shared machines and protect the local state directory.

Risk: Ticker lookups contact third-party market, news, and sentiment services.

Mitigation: Run the skill only when sending ticker symbols and related lookup data to those services is acceptable.

Risk: Portfolio delete and remove commands do not ask for confirmation.

Mitigation: Review portfolio commands before execution and keep backups of important local portfolio data.

Risk: Python dependencies are resolved and run through uv.

Mitigation: Review the resolved dependencies and run in a controlled environment before using the skill with important data.

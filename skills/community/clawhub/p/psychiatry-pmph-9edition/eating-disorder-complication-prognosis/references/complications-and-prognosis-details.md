# 进食障碍各亚型并发症与预后详细指标

## 1. 神经性厌食 (Anorexia Nervosa)
### 长期预后比例
- **50%**：治疗效果较好（体重增加、社会适应提高）
- **20%**：反复发作
- **25%**：迁延不愈
- **5%~10%**：死于极度营养不良、并发症或自杀

### 核心医疗风险因素（评估不仅看体重）
- 体重急剧下降（尤其在儿童患者中风险极高）
- 低血压
- 心动过缓 / 体位性心动过速
- 体温过低
- 心律失常
- 生化紊乱

## 2. 神经性贪食 (Bulimia Nervosa)
### 长期暴食+代偿行为导致的并发症
- **水电解质紊乱**：低血钾、低血钠
- **酸碱失衡**：代谢性碱中毒 / 代谢性酸中毒
- **心血管系统**：心律失常
- **消化系统**：胃肠道损害

## 3. 暴食障碍 (Binge Eating Disorder)
### 躯体共病风险
- 肥胖比例高 (约38.9%)
- 高血压
- 高甘油三酯血症
- 空腹血糖升高
- 代谢综合征

### 精神共病风险
- 30%~80% 伴有焦虑或抑郁
- 27.5% 有自杀观念
- 可合并赌博障碍、ADHD、物质滥用

## 4. 异食癖 (Pica) 与 反刍障碍 (Rumination Disorder)
### 异食癖风险
- **严重躯体并发症**：肠梗阻、铅中毒等（严重者可致死）
- **精神共病**：约半数少年患者会出现抑郁、人格障碍和物质滥用

### 反刍-反流障碍风险
- **鉴别诊断要求**：必须排除食管狭窄、影响食管功能的神经肌肉疾病或幽门狭窄等器质性问题。

## Description:

Review backend code changes for correctness, security, architecture compliance, and test coverage per the applicable skill and checklist from AGENTS.md.

This skill is ready for commercial/non-commercial use.

## Publisher:

[rahulsaini202](https://clawhub.ai/user/rahulsaini202)

MIT-0

## Use Case:

Developers and engineering reviewers use this skill to evaluate backend code changes for correctness, security, architecture alignment, and test coverage. It is especially suited to repositories that define implementation skills and review checklists in AGENTS.md.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill enforces a strict backend review policy tied to AGENTS.md and repository skill files, which may produce irrelevant rejections in repositories that do not use those conventions.

Mitigation: Confirm that the target repository uses the AGENTS.md skill workflow before applying rejection criteria; adapt the review criteria when those conventions are absent.

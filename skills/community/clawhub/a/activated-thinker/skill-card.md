## Description:

Cognitive protocols for AI agents: anti-binary thinking, gardener mindset, friction protocol, and behavioral mode detection. Teaches agents HOW to think about problems.

This skill is ready for commercial/non-commercial use.

## Publisher:

[mouserider](https://clawhub.ai/user/mouserider)

### License/Terms of Use:

MIT

## Use Case:

Developers and external agent users use this skill to help agents adapt their response posture across crunch, exploratory, and standard work. It guides agents to suggest alternatives, leave room for idea development, slow down on creative or high-stakes decisions, and coach when learning is the better outcome.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can make an agent slow down, suggest alternatives, or coach when the user expected direct execution.

Mitigation: Install it only when adaptive response style is desired, and review agent behavior in workflows where strictly direct answers are preferred.

Risk: Because the skill changes thinking style rather than executing code, the main operational risk is undesired response posture rather than system access.

Mitigation: Review the skill before deployment and monitor whether its crunch, exploratory, and standard mode behavior matches the intended user experience.

# 浅色商务图表视觉规范

> 适用范围：架构图、流程图、拓扑图、泳道图、时序图、时间轴、信息图、对比矩阵。所有数值可直接抄进 CSS 或 SVG 属性。

## 一、画布与安全边距

| 画布 | 逻辑尺寸 | 2× 输出 | 3× 输出 | 典型用途 |
|---|---|---|---|---|
| 16:9 | 1520 × 856 | 3040 × 1712 | 4560 × 2568 | PPT 单页、汇报截图 |
| 4:3 | 1280 × 960 | 2560 × 1920 | 3840 × 2880 | 老版文档、打印插页 |
| A4 竖版 | 1240 × 1754 | 2480 × 3508 | 3720 × 5262 | 标书正文插入、白皮书整页 |

安全边距 32px（逻辑值），内容到画布边缘的实际留白控制在 1–3%。标题区不计入安全边距，改为整图顶部预留 56px 图层。

## 二、栅格与间距

- 基准单位 8px，允许的间距阶梯：4 / 8 / 16 / 24 / 32 / 48 / 64。
- 卡片内边距：上下 10px、左右 12px；行距取 8 的整数倍。
- 同层卡片间距 24px；层与层之间 40–48px；容器框内边距 16px。
- 所有 x / y / w / h 取整数，不出现 0.5px 坐标，避免 2× 导出后出现半像素模糊。

## 四、对比度

- 正文与标注对白色底 ≥4.5∶1（实测 `#475569` 约 7.1∶1、`#64748b` 约 4.8∶1），大字号标题 ≥3∶1（`#0f172a` 约 17.9∶1）。
- 语义标题色对各自浅色填充普遍在 8∶1 以上；替换品牌色后必须重测，不得凭观感放行。
- `#94a3b8` 对白色底约 2.6∶1，只能用于不承载信息的装饰线，不能放文字。

## 五、字号阶梯

| 层级 | 字号 | 字重 | 颜色 |
|---|---|---|---|
| 图标题 | 18–20px | 700 | `#0f172a` |
| 分层带 / 区域名 | 13px | 600 | 对应语义标题色 |
| 节点标题 | 14–15px | 600 | 对应语义标题色 |
| 节点明细 | 12px | 400 | `#475569` |
| 图注 / 标注 | 10–11px | 400 | `#64748b` |
| 页脚（版本、日期） | 10px | 400 | `#94a3b8` 之上的 `#64748b` |

字号下限 10px：2× 导出后为 20 个设备像素，投影与打印都可读。低于 10px 一律视为不合格。

## 六、线宽、箭头与圆角

| 元素 | 规格 |
|---|---|
| 主连接线 | 1.2–1.5px |
| 辅助虚线 | 1.1px |
| 节点描边 | 1.2px |
| 容器边界 | 1.2px 虚线 8,4 |
| 箭头 marker | 10 × 7，`refX=9` `refY=3.5`，`orient="auto"` |
| 虚线节拍 | 实 5–7px，空 4–5px |
| 节点圆角 | `rx=10` |
| 容器圆角 | `rx=14` |
| 图例色块 | 10 × 10px，描边 1px，圆角 2px |

2px 及以上的连线在商务文档里会被读成“加粗强调”，破坏层级，禁止用于普通连接。

## 七、中文排版细则

1. **字体栈**：`'Inter', 'PingFang SC', 'Hiragino Sans GB', 'Microsoft YaHei', 'Noto Sans SC', sans-serif`。不得以 `monospace` 收尾，等宽字体会把汉字间距拉开、破坏对齐。
2. **字距**：中文 `letter-spacing` 取 0 或 ≤0.02em。超过 0.02em 汉字之间出现缝隙，读起来发飘。
3. **行高**：正文 1.5–1.6，标题 1.3；SVG 内多行文字按行高显式给出 `dy` 步进，不依赖 `line-height`。
4. **折行**：中文一行 ≤14 个汉字，英文一行 ≤28 个字符。按语义断句，不按字符数硬切。
5. **标点**：中文用全角标点；括号内为英文术语时不加空格；数字与单位之间留 1 个半角空格（如 `300 DPI`）。
6. **数字**：同一张图内小数位数一致；百分比统一带 `%`；时间口径写进图注，不写进节点标题。
7. **中英混排**：中文在上、英文在下，英文小 2px、行高 1.3，各用独立 `<text>` 节点，便于单独改词。
8. **图标**：只用单色线性图标，线宽与连线一致（1.2px），尺寸 16 或 20px，颜色随所在语义组。

## 八、不要做的事

- 不用深色底：商务文档的默认阅读环境是白纸与投影，深色底在打印时直接变黑块。
- 不用渐变、外发光、投影堆叠：3 层以上的视觉效果会被读成“不专业”。
- 不用超过 3 种线型：实线 + 一种虚线 + 一种点线已是上限。
- 不让颜色承担唯一信息：色盲读者与黑白打印会丢失信息，颜色必须配图例或符号。

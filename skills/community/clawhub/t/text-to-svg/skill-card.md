## Description:

Generate logos, icons, illustrations and other vector graphics from natural language descriptions, with style directives for flat monochrome, gradient, stroke, rounded, minimal, and tech designs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[openlark](https://clawhub.ai/user/openlark)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, designers, and agent users use this skill to turn natural language design requests into valid standalone SVG markup for logos, UI icons, brand assets, and illustrations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated SVG may be visually incorrect or unsuitable for production embedding.

Mitigation: Review generated SVG before use in production content, checking syntax, dimensions, colors, and intended visual meaning.

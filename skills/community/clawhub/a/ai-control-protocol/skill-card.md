A Cognitive Immune System for OpenClaw. Interrupts the 9 failure modes of LLM sycophancy, forces objective pushback, and uses Madhyamaka epistemology to break binary traps.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and developers use this skill to add an always-on critique and anti-sycophancy layer to an agent, with uncertainty labels, premise deconstruction, visual-text conflict reporting, and challenge prompts for strategic recommendations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill is an always-on behavior-control layer that can broadly reshape ordinary assistant responses beyond explicit user requests.

Mitigation: Install it only in contexts where a persistent critique and anti-sycophancy posture is desired, and confirm the platform can disable or bypass it for sessions that need a different assistant tone.

Risk: The skill may add labels, delay direct plans, and append challenge prompts, which can interfere with workflows that require predictable formatting or user-directed tone.

Mitigation: Avoid it for strict formatting, API-payload, or tone-sensitive workflows unless its raw-output exemption and session controls are tested before use.

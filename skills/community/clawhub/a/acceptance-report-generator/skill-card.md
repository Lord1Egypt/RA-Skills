## Description:

Generates a complete seven-chapter acceptance report that summarizes testing scope, results, module details, defects, performance, security, and the final acceptance decision.

This skill is ready for commercial/non-commercial use.

## Publisher:

[golngod](https://clawhub.ai/user/golngod)

### License/Terms of Use:

MIT-0

## Use Case:

QA, project delivery, and engineering teams use this skill to turn test case, functional acceptance, performance, security, and architecture inputs into a structured acceptance report for delivery review and archival.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Acceptance conclusions can be misleading if the source test, performance, or security results are incomplete or inconsistent.

Mitigation: Review the input evidence and reconcile case counts, pass rates, defect severity, and security findings before relying on the final acceptance decision.

Risk: The built-in acceptance criteria and Chinese-language report wording may not match every organization or delivery contract.

Mitigation: Adapt the report language and acceptance thresholds to the organization's documented criteria before publication.

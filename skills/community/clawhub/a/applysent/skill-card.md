## Description:

Search jobs that fit the user's résumé, tailor the résumé to a job and apply on the employer's own form through the ApplySent MCP server, one job at a time and only after the user says yes. Use when the user wants to find jobs, apply to a job, check application status or answer an employer's application question.

This skill is ready for commercial/non-commercial use.

## Use Case:

Job seekers use ApplySent to find suitable openings, tailor a résumé, prepare employer application answers, submit applications with individual approval, and track application status and receipts.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Submitting an application shares the résumé and answers with an employer.

Mitigation: Show the application preview and get a clear yes for that specific job before submitting.

Risk: Employer questions may ask for personal details that the agent cannot know.

Mitigation: Ask the user and use their exact answer; never guess or invent information.

## Description:

Generate technical proposals, deployment guides, and client delivery reports for Agent projects.

This skill is ready for commercial/non-commercial use.

## Use Case:

Delivery teams, solution engineers, and agent project owners use this skill to draft Markdown technical proposals, deployment manuals, and client delivery reports from project details.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated delivery documents may include sensitive customer details, deployment environments, access URLs, account information, or internal project status.

Mitigation: Review generated Markdown before saving, sharing, or publishing, and remove or redact sensitive details that are not intended for the audience.

Risk: Connected Notion, Feishu, Linear, or Jira workspaces may expose generated content or imported project data to the wrong workspace, project, or audience.

Mitigation: Use connected collaboration and project-management tools only after confirming the target workspace, project, permissions, and intended readers.

## Use Case:

External users can use this skill to search for notary services, check availability, and create bookings through Lokuli. It should be used only after confirming the user understands their name, email, and phone number may be sent to Lokuli.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can send customer name, email, and phone number to Lokuli.

Mitigation: Confirm the user understands what contact details will be shared before creating a booking.

Risk: The skill can create a notary booking through an external service.

Mitigation: Confirm the intended provider, service, date, time slot, and user consent before calling the booking tool.

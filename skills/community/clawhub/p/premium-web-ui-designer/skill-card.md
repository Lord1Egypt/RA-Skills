## Description:

Improves websites and web apps with clearer layout, stronger visual hierarchy, modern UI styling, responsive checks, and polished frontend design guidance or code changes.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, designers, and product teams use this skill to critique, redesign, or polish frontend interfaces for websites, dashboards, SaaS products, landing pages, portfolios, and interactive tools.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may be invoked broadly for web UI polish or redesign requests.

Mitigation: Confirm that proposed visual and code changes fit the user's requested scope before accepting them.

Risk: Frontend redesign work can unintentionally affect accessibility, semantics, or responsive behavior.

Mitigation: Preserve semantic HTML and accessible labels, then check at least one desktop and one mobile viewport before delivery.

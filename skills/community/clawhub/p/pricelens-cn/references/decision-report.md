# 决策报告模板（Decision Report）

报告的唯一下载场景是「用户在付款前看一遍」。因此结构固定、结论前置、每个价格可追溯。以下模板可直接照抄，只替换〔〕内的内容。

## 1. 文件与命名

- 文件名：`pricelens-<品类>-<YYYYMMDD>.md`，日期为检索日而非交付日。
- 单文件交付，不拆多文件；一页纸精简版作为附录置于文末。
- 表格优先，正文只在表格无法表达时出现。

## 2. 头部声明（固定三行）

```
# 〔品类〕决策报告
- 检索时点：YYYY-MM-DD（价格为检索时点抓取，需复核）
- 预算口径：到手价〔下限〕–〔上限〕元／挂牌价口径
```

## 3. 六区块骨架

```
## 结论卡
〔买／等／换〕：〔候选〕。理由：①〔…〕②〔…〕③〔…〕。触发条件：〔…〕（≤150 字）

## 到手价区间
| 候选 | 挂牌 | 券／满减 | 运费 | 返利 | 以旧换新 | 到手价区间 | 核实 |
|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |

## 渠道矩阵
| 渠道 | 层级 | 可达性 | 到手价 | 含票 | 结论 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

## 参数取舍矩阵
| 参数（权重） | 候选 A | 候选 B | 候选 C | 判定 |
|---|---|---|---|---|
|  |  |  |  |  |

## 裁决：〔买／等／换〕
- 目标价：¥〔…〕（依据：多渠道到手价下四分位／用户给定）
- 当前状态：〔已满足／未满足〕
- 触发条件：〔价格阈值、时间窗口或替代方案〕
- 复核方式：〔下单前需核对的三项〕

## 取证清单与待复核
1. 〔来源类型〕〔域名或页面〕〔检索日〕〔价格〕〔核实状态〕
2. 待复核：〔券门槛／返利到账周期／以旧换新资格／运费〕
```

区块顺序不可调整，因为用户的阅读路径是「结论 → 多少钱 → 去哪买 → 买哪台 → 现在买不买 → 凭什么」。

## 4. 三选一裁决的写法

**买**：必须同时满足三条才可写「买」——到手价 ≤ 目标价、双线六维综合分 ≥6.5、时间窗口内无更强替代。写法：

```
买：〔候选〕。触发条件已满足（到手价 ¥〔…〕 ≤ 目标价 ¥〔…〕）。
若下单前价格上涨超过 〔N〕%，退回「等」。
```

**等**：必须给出触发价与复核日期，否则就是空话。

```
等：目标价 ¥〔…〕，当前 ¥〔…〕，差 〔N〕%。
复核日期：〔YYYY-MM-DD〕（不晚于〔需求最晚日〕）。到价即买，不到价则按〔备选方案〕执行。
```

**换**：必须点名替代对象与替代理由，并说明原候选为何出局。

```
换：由〔原候选〕改为〔替代候选〕。原因：〔权重最高参数不达标／同价位综合分低 0.5 以上／以旧换新后净支出更低〕。
代价：〔舍弃了哪一项〕，该代价对使用的影响为〔可接受／需确认〕。
```

三种写法都不允许出现「看个人需求」「建议综合考虑」这类无法执行的句子。

## 5. 语言规范

- 中文全角标点；数字与单位用半角（`¥1999`、`15%`、`3.5 kg`）。
- 术语首次出现给英文括注，如「到手价（landed price）」。
- 价格一律带货币符号与口径（到手价／挂牌价），不写「一千多」这类模糊表述。
- 不使用「保证」「绝对」「全网最低」「闭眼入」等承诺性或夸张表述。
- 不出现用户身份、住址、账号等信息；旧机只写「型号 + 年份 + 成色」。

## 6. 字数预算

| 区块 | 目标字数 | 硬上限 |
|---|---|---|
| 结论卡 | 100–150 | 150 |
| 到手价区间 | 表格为主 | 6 行 |
| 渠道矩阵 | 表格为主 | 8 行 |
| 参数取舍矩阵 | 表格为主 | 4 列 |
| 裁决 | 150–250 | 300 |
| 取证清单 | 200–400 | 不限条数 |
| 全文 | 900–1800 | 1800 |

超预算时先删渠道矩阵的次要行与参数矩阵的说明列，不删取证清单。

## 7. 一页纸精简版（用户要求时追加）

```
〔品类〕｜〔买／等／换〕：〔候选〕
1. 到手价 ¥〔…〕（区间 ¥〔…〕–〔…〕），来源〔…〕，检索于〔日期〕
2. 为什么是它：〔权重最高参数达标〕、〔渠道 T1 可开票〕、〔综合分〕
3. 什么时候下手：〔到价即买／等到 ¥〔…〕〕
4. 别忘核对：〔券门槛〕、〔运费〕、〔发票主体〕
```

四条以内，能直接转发给需要拍板的人看。

## 8. 反例清单（出现任一即返工）

| 反例 | 问题 |
|---|---|
| 「这个价格是全网最低」 | 承诺性表述，无法举证 |
| 「一般都在两千左右」 | 无来源、无日期 |
| 「券后大概能省几百」 | 未拆解、无基数 |
| 「建议根据实际需求选择」 | 不可执行 |
| 「该店铺信誉良好」 | 无可观察信号支撑 |
| 「预计下个月会降价」 | 无依据的预测，应改为触发价 |
| 只写「京东 ¥…」，不写是否含运费 | 口径缺失，无法比较 |

## 9. 交付前 30 秒自检

1. 结论卡在第一屏，且能单独转发？
2. 每个价格都能在取证清单里找到对应行？
3. 三选一是否唯一？触发条件是否可执行？
4. 首行是否有检索时点与「需复核」声明？
5. 是否出现任何承诺性表述或个人信息？

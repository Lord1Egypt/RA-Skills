Developers and frontend engineers use this skill to choose and implement purposeful GSAP motion in React and Next.js interfaces, including scroll scenes, layout transitions, responsive behavior, accessibility, and performance checks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated animation code can create accessibility or motion-sensitivity issues if reduced-motion and focus behavior are skipped.

Mitigation: Review generated code for prefers-reduced-motion handling, keyboard flow, screen-reader semantics, and nonblocking access to primary content.

Risk: Adding GSAP dependencies or complex scroll and layout effects can affect frontend performance and maintainability.

Mitigation: Confirm GSAP fits the project, keep motion scoped to component lifecycles, clean up animations and triggers, and test on mobile and lower-powered devices.

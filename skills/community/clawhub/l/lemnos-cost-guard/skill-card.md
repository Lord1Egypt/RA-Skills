## Description:

Lemnos Cost Guard helps OpenClaw agents track API spend, summarize daily or task-level costs, detect context bloat, and recommend lower-cost model routing.

This skill is ready for commercial/non-commercial use.

## Publisher:

[getlemnos32](https://clawhub.ai/user/getlemnos32)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and operators use this skill to monitor OpenClaw API costs, review daily or per-task spend, identify oversized context loads, and choose less expensive model routes when appropriate.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill reads OpenClaw session logs, which can contain sensitive task, usage, or customer context.

Mitigation: Review before installing, restrict access to session logs, and avoid putting secrets or customer details in task descriptions or shared reports.

Risk: The scanner identified an unsafe local snapshot deletion path.

Mitigation: Use only snapshot IDs generated by the tool, validate snapshot IDs before deletion, and inspect the scripts before running them in a shared or sensitive workspace.

Risk: Budget alerts are advisory and do not enforce hard spending limits.

Mitigation: Treat reports as monitoring guidance and enforce actual spend limits through platform billing controls or separate operational policy.

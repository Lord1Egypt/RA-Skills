## Known Risks and Mitigations:

Risk: Local media compression writes output files and batch jobs can affect many files at once.

Mitigation: Use preview mode or test files first, choose explicit output paths, and enable backups for originals you care about.

Risk: The setup examples include package-install commands and require ffmpeg to be available locally.

Mitigation: Review installation commands yourself and install ffmpeg from a trusted package source for the operating system.

Risk: Some command-line output is in Chinese, which may make errors or progress messages harder for some operators to interpret.

Mitigation: Expect localized output and translate messages when reviewing failures or batch-processing logs.

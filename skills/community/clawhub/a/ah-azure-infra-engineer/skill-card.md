## Known Risks and Mitigations:

Risk: Generated PowerShell, Bicep, or pipeline changes may affect real Azure subscriptions if applied without review.

Mitigation: Review generated changes before execution, validate deployment previews, and run changes through staged rollout or rollback procedures.

Risk: Azure administration workflows can over-provision permissions or expose privileged credentials.

Mitigation: Use least-privilege Azure credentials, managed identities, and RBAC review before applying recommendations.

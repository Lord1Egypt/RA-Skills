## Description:

JSON Diff Tool helps users compare two JSON documents with syntax highlighting and path-level difference analysis while processing data locally in the browser.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, testers, operations staff, and product teams use this skill to compare API responses, configuration files, and test JSON payloads for path-level additions, removals, and unchanged values.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Users may paste secrets, tokens, customer records, or production payloads into hosted copies of the JSON comparison tool.

Mitigation: Use the bundled or local version for sensitive work, and avoid entering confidential JSON into externally hosted copies, especially temporary tunnel URLs.

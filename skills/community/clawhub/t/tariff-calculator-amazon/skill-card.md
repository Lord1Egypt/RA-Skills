## Description:

Universal tariff calculator for Amazon sellers that calculates import duties, landed costs, and VAT/GST for trade routes, with Section 301 tariffs, trade agreement rates, and HS code lookup.

This skill is ready for commercial/non-commercial use.

## Use Case:

External Amazon sellers and ecommerce operators use this skill to estimate import duties, VAT/GST, landed cost, and HS-code matches for cross-border product sourcing scenarios.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Tariff, tax, and customs outputs may be inaccurate or outdated for real compliance decisions.

Mitigation: Use the reports as estimates only and independently verify current official tariff, VAT/GST, and customs requirements before making business or filing decisions.

Risk: The documented global unpinned installer can fetch mutable code at install time.

Mitigation: Prefer running the reviewed Python scripts directly in an isolated folder, or install only after confirming the publisher and source version are trusted.

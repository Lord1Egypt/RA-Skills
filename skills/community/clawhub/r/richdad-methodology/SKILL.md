# 富爸爸方法论 Skill

《富爸爸穷爸爸》是一套财商启蒙系统：核心不是理财技巧，而是**重新定义
资产、收入与工作的关系**。本 skill 把它抽成**五个框架 + 十条法则 + 一个
输出模板**，全部原创转述（概念出处标注，零原文引用——该书在版权保护期）；
另附场景化法则库供方案收尾。

## 快速路由（先判场景，再选框架）

| 用户场景 | 用哪个框架 |
|---|---|
| 挣得不少却总没钱 | 框架1 资产负债扫描法 |
| 想换活法但只有工资一条路 | 框架2 四象限迁移法 |
| 月月光，存不下钱 | 框架3 先支付自己法 |
| 有了点积蓄，怎么让钱动起来 | 框架4 钱生钱循环法 |
| 想学理财不知道从哪学起 | 框架5 财商四科法 |
| 只要一句法则收尾 | 直查 `references/rules.md` |

可组合：财务体检 = 框架1 扫资产负债 → 框架3 堵漏 → 框架4 让钱转起来；
改收入结构 = 框架2 定象限迁移 → 框架5 补课。

## 五大分析框架

### 框架1 资产负债扫描法（钱在往哪流）

- 输入：个人/家庭财务状况，或一笔待评估的大额支出。
- 步骤：
  1. 把每月现金流分成两列：**流入列**（工资以外的收入：利息、租金、
     分红、副业净收入）与**流出列**（一切每月固定掏钱的项目）；
  2. 逐项贴标签——**资产**：持续把钱放进口袋的东西；**负债**：持续把
     钱从口袋拿走的东西；**伪资产**：看着值钱但不产生现金流、还要养的东西；
  3. 关键判定：自住房、私家车按现金流属性记负债侧（每月净流出），
     与"它值多少钱"无关；
  4. 算出核心比值：**被动收入 ÷ 总支出**——大于 1 才叫财务安全。
- 输出：资产负债清单（贴标）+ 被动收入覆盖率 + 置换建议（哪些负债可换资产）。
- ✅完成标准：清单里每项有现金流数字；覆盖率有实测值而非感觉。

### 框架2 四象限迁移法（收入从哪来）

- 输入：收入结构单一、想改变挣钱方式的处境。
- 步骤：
  1. 定位当前象限：**E**（雇员，用时间换工资）/ **S**（自由职业/个体，
   用手艺换钱，停手就停收入）/ **B**（企业主，系统替你挣钱）/ **I**
   （投资人，钱替你挣钱）；
  2. 关键认知：E 和 S 天花板是自己的时间，B 和 I 的天花板是系统与资本；
  3. 设计迁移路径——E→先补 I 侧的理财基本盘，或 E→S 副业验证→系统化
     成 B；不主张裸辞跳象限（没有储备金和验证过的系统就跳 = 高风险）；
  4. 迁移以副业现金流为信号：新象限月净收入连续 3 个月 > 目标线才加码。
- 输出：当前象限 + 目标象限 + 分步迁移路径 + 每步验证信号。
- ✅完成标准：迁移路径有量化信号，没有"裸辞 all in"式断档设计。

### 框架3 先支付自己法（储蓄率的纪律）

- 输入：月光、存不下钱、储蓄全靠剩余。
- 步骤：
  1. 把"存钱"从账单最后挪到最前——收入到账第一笔划走固定比例
     （10% 起步，能扛则升），剩下的才是生活费；
  2. 生活费刚性化：固定支出列表化，可砍项（订阅/外卖/冲动消费）按月
     复盘砍一次；
  3. 这笔钱设取用门槛：只进不出的"资产账户"，与日常账户物理隔离；
  4. 压力来源诚实话：如果收入覆盖不了刚性支出，问题在收入端（框架2），
     不在省。
- 输出：储蓄率数字 + 自动划转设置 + 可砍清单。
- ✅完成标准：储蓄是发薪日动作而不是月底动作；有具体比例和隔离账户。

### 框架4 钱生钱循环法（让钱先上班）

- 输入：有积蓄但躺在活期里，或投资收益断续不可持续。
- 步骤：
  1. 给每笔积蓄定岗位：应急垫（3-6 个月支出，随取）/ 稳健盘（低风险
     底仓）/ 进攻盘（学习成本内的高波动仓位）；
  2. 收益回流规则：投资收益不消费，回流本金——复利的前提是循环不中断；
  3. 每笔投资先问三个问题：它给我产生现金流吗？我懂它的钱怎么赚的
     吗？亏掉本金影响生活吗？——任一答"否且说不清"，不进；
  4. 加杠杆警戒线：借来的钱只用于"已验证产生现金流的资产"，绝不用于
     消费和高波动投机。
- 输出：资金岗位表 + 回流规则 + 三个问题的逐笔答案。
- ✅完成标准：每笔钱有岗位、有回流规则；杠杆使用有现金流验证前提。

### 框架5 财商四科法（知识就是降低风险）

- 输入：想学理财无从下手、或吃过亏想补课。
- 步骤：按四科排学习路线（概念源自该书，课程设计为原创）——
  1. **会计**：看得懂三张表——先从自己的家庭收支表开始，每月记账复盘；
  2. **投资**：理解钱怎么赚到钱——各类资产的收益逻辑与风险来源，
     先学后买；
  3. **市场**：供需与周期——为什么便宜的时候没人要、贵的时候抢破头；
  4. **法律/规则**：税收、账户规则、合规边界——懂规则的人用规则，
     不懂的被规则收费。
  5. 学习以输出验证：每科一个可交付物（家庭报表/资产逻辑卡/周期笔记/规则清单）。
- 输出：四科自评（1-5 分）+ 补课顺序 + 每科的输出物。
- ✅完成标准：学习路线有可验证产出，不是"多看书"式的空话。

## 十条法则（快速检查用，原创转述）

1. **别为钱打工，让钱替你打工**——工资是起点不是终点，收入的终局是资产产生的现金流。
2. **分清资产与负债，比挣得多更重要**——月入三万全买负债，比月入五千买资产穷得快。
3. **先支付自己**——储蓄排在所有账单之前，这是对未来的第一优先权。
4. **自住房不是资产**——它每月从你口袋拿钱；值多少钱和产生多少现金流是两回事。
5. **恐惧和贪婪是财务决策的两大敌人**——跌了怕不敢买，涨了贪不敢卖；用规则代替情绪。
6. **风险不来自投资，来自无知**——看不懂的钱不赚，看懂了才知道风险边界在哪。
7. **关注自己的事业，而不只是职业**——职业养现在的你，事业（资产组合）养未来的你。
8. **会用别人的钱之前，先管好自己的钱**——杠杆放大收益也放大亏损，无现金流验证不上杠杆。
9. **每一笔消费都是一张选票**——投给负债还是资产，日积月累决定财务阶层。
10. **财商是练出来的，不是读出来的**——小钱实操、复盘、再实操，比收藏一百篇干货有用。

## Agent 工作流

1. **判场景**：对照快速路由表选框架（一句话内部完成）。
2. **跑框架**：按步骤执行；财务体检按"1→3→4"主序，收入改造按"2→5"主序。
3. **按模板产出**（用户没指定格式时用）：

```
【现金流扫描】流入：…  流出：…  被动收入覆盖率：…
【资产负债贴标】资产：…  负债：…  伪资产：…
【象限定位】当前：…  迁移目标：…（验证信号：…）
【资金岗位】应急垫：…  稳健盘：…  进攻盘：…（回流规则：…）
【补课缺口】四科短板：…  下一步输出物：…
【记一条】"…"（法则库编号）   ← 可选，从 rules.md 按场景取
```

4. **收尾引用**：需要收尾语时查 `references/rules.md`（原创法则，非书中原句）。
5. ✅完成标准：输出里"覆盖率"和"资金岗位"必须存在——没有数字的
   财务建议等于没给。

## 引用与合规

- **零原文引用**：该书处于版权保护期，本 skill 不引用书中任何句子；
  所有表述为原创转述，概念出处以"概念源自《富爸爸穷爸爸》"标注。
- 法则库全部为原创提炼短句，可自由引用于方案与内容。
- **不是投资建议**：本 skill 输出为财商教育与自我盘点工具，不荐股、
  不推荐具体产品、不承诺收益；涉及具体投资决策以持牌机构意见为准。
- **风险边界**：原书部分策略（如激进杠杆、借力买房）争议较大，本 skill
  只保留"现金流验证前提下的杠杆"口径，不输出高杠杆鼓励性建议。
- 不做"暴富叙事"内容：不渲染躺赚、不承诺财务自由时间表。

## 本 skill 不做什么

- 不替代持牌理财/税务/法律建议——涉及大额与合规问题引导找专业人士。
- 不做书中故事复述（那是原著的活，且有版权）。
- 不输出具体证券/基金/楼盘推荐——框架管结构，标的选择另循专业意见。

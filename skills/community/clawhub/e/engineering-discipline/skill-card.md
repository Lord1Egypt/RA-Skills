## Description:

Engineering Discipline provides coding-process guardrails that prompt an AI coding assistant to clarify ambiguous requests, keep changes scoped, avoid over-engineering, and verify work before completion.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Developers and engineering teams use this skill to shape AI coding assistants during implementation, refactoring, and production code maintenance so outputs stay focused, minimal, and verified.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad coding-process guardrails may add friction by increasing clarification, scope control, and verification steps during coding sessions.

Mitigation: Use this skill when that disciplined coding posture is desired, and review whether its clarification and verification expectations fit the project workflow before deployment.

Risk: The guidance can limit unsolicited refactoring or broad edits, which may be inconvenient when exploratory redesign is the intended task.

Mitigation: State the intended refactor or exploration scope explicitly so the assistant can apply the guardrails without blocking the requested work.

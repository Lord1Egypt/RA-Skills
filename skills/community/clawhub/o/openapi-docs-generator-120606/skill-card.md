## Description:

Helps API developers, backend teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to turn API documentation requests into practical OpenAPI or Swagger deliverables, workflows, checklists, analysis, code changes, and validation steps.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate on broad API or developer-experience phrasing.

Mitigation: Invoke it explicitly for OpenAPI or Swagger documentation work when precise activation matters.

Risk: API examples or documentation inputs may contain secrets.

Mitigation: Redact credentials, tokens, and sensitive endpoint details before sharing examples with the agent.

Risk: Documentation guidance can become incorrect or misleading if generated without checking the actual API behavior.

Mitigation: Validate generated specifications, commands, and examples against the service implementation before publishing.

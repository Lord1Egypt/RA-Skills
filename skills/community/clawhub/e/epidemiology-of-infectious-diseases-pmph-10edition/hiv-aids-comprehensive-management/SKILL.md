# HIV/AIDS综合管理

## 适用场景

当遇到以下情况时应用此技能：
- HIV感染者需启动或调整抗病毒治疗方案
- 特殊人群（儿童、孕妇、合并感染者）的ART方案选择
- 评估ART治疗效果是否达标
- 识别和处理免疫重建炎症反应综合征(IRIS)
- 艾滋病相关机会性感染的病原学治疗

## 工作流程

### 第一步：评估患者状态

收集以下关键信息：
- 患者年龄分组（<3岁, 3-10岁, >10岁, 成人）
- 是否已启动ART及治疗时长
- CD4+ T细胞计数
- 合并感染类型（结核、HBV、HCV、机会性感染等）
- 是否妊娠或哺乳期

### 第二步：确定治疗阶段

根据患者状态选择对应流程：

| 患者状态 | 执行流程 |
|---------|---------|
| 初治患者 | → ART方案选择流程 |
| 已启动ART，定期随访 | → 治疗监测流程 |
| 出现疑似IRIS症状 | → IRIS处理流程 |
| 合并机会性感染 | → 机会性感染治疗流程 |

### 第三步A：ART方案选择流程

**初治成人患者：**
- 推荐方案：2种NRTIs骨干 + 第三类药物（NNRTIs/增强型PIs/INSTIs/STR）

**特殊人群调整：**
- 儿童：根据年龄分层选择（详见references/art-regimens.md）
- 孕妇/哺乳期：首选TDF/FTC(或TDF+3TC/ABC+3TC)+RAL或DTG，终身维持
- 合并结核：抗结核治疗后2周内尽早启动ART
- 合并HBV：方案至少含两种抗HBV药（3TC+TDF/TAF/FTC），禁忌单用抗HBV核苷类
- 合并HCV：选肝毒性小药物（首选INSTIs/FIs），注意启动时序
- 静脉药物依赖者：首选含RAL/DTG/BIC方案

### 第三步B：治疗监测流程

**病毒学监测阈值：**
- 治疗4周：病毒载量下降≥1lg
- 治疗3-6个月：病毒载量低于检测水平

**免疫学监测阈值：**
- 治疗1年：CD4+增加≥30%或增加≥100个/μl

若未达标，评估依从性、耐药及药物相互作用。

### 第三步C：IRIS处理流程

**IRIS诊断标准（需同时满足）：**
1. 接受ART后机会性感染症状恶化
2. 症状加重与新药、耐药、治疗失败无关
3. ART后病毒载量下降和/或CD4+增多

**处理原则：**
- **必须继续ART**（核心原则）
- 针对潜伏感染进行对症病原治疗
- 必要时加用糖皮质激素控制炎症反应

### 第三步D：机会性感染治疗流程

根据病原体类型选择治疗方案：

| 病原体 | 首选方案 | 疗程 |
|-------|---------|------|
| 肺孢子菌(PCP) | SMZ-TMP | 2-3周 |
| 真菌（口腔/食管） | 克霉唑/酮康唑/制霉菌素 | 至症状缓解 |
| 隐球菌脑膜炎 | 两性霉素B+氟胞嘧啶→氟康唑 | 诱导+巩固+维持 |
| CMV/HSV/带状疱疹 | 更昔洛韦/阿昔洛韦 | 2-4周 |
| 弓形虫病 | 乙胺嘧啶+磺胺嘧啶 | ≥6周 |
| MAC | 克拉霉素/阿奇霉素+乙胺丁醇±利福布汀 | 长期 |

详细剂量、给药途径及替代方案见references/opportunistic-infections.md。

## 关键约束

1. 存在严重机会性感染或慢性病急性发作期，需先控制病情再启动ART
2. 合并HBV时禁忌单用抗HBV核苷类药物（防HIV耐药）
3. IRIS发生时绝不停止ART
4. 注意抗机会性感染药物与ART药物的相互作用
5. 孕妇用药需权衡胎儿风险

## 输出要求

根据患者具体情况输出：
1. 推荐的药物组合方案（含具体药物名称）
2. 剂量及给药频次
3. 治疗疗程
4. 监测指标及时间节点
5. 特殊注意事项及药物相互作用警示

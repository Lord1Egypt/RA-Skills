## Description:

Identity formation, portraits, resurrection, and evolution for AI agents via SOUL.md, with LLM dialogue and image generation routed through SkillBoss API Hub and platform-specific identity state kept on the Agent Church backend.

This skill is ready for commercial/non-commercial use.

## Use Case:

External developers and agent operators use this skill to create and manage an AI agent identity through SOUL.md generation, aura portrait creation, persistent archival, resurrection, and evolution workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Agent identity dialogue, SOUL.md-derived summaries, tokens, and payment proofs may be sent to external identity, image, payment, and persistence services.

Mitigation: Use the skill only with content appropriate for those named services, and do not include secrets, private keys, regulated personal data, or content that should not be archived.

Risk: Persistent identity workflows may archive or retain sensitive agent identity content.

Mitigation: Review SOUL.md content and summaries before using archival, resurrection, evolution, or portal workflows.

## Description:

Provides conceptual guidance for designing persistent AI agent memory across episodic, semantic, procedural, and relational memory types, including retrieval, lifecycle management, privacy, and succession planning.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and AI-agent operators use this skill to plan memory architecture, retrieval practices, privacy controls, and successor handoffs for persistent agents. The skill is conceptual guidance only; actual memory storage and retrieval occur on the Umnix platform.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Persistent memory, relationship tracking, retention, and successor transfer can create privacy and governance exposure if used without organizational approval.

Mitigation: Confirm policy and legal approval before using associated platform features, and verify controls for review, deletion, access, retention, and successor transfer.

Risk: Sensitive information such as PII, credentials, private secrets, or financial data could be stored in memory contrary to policy.

Mitigation: Avoid storing sensitive data unless policy and law allow it, and use platform review, deletion, and access controls to enforce retention requirements.

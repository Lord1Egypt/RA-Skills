## Description:

Creates shareable digital firework celebration links after previewing celebration text and receiving user confirmation.

This skill is ready for commercial/non-commercial use.

## Publisher:

[23wsdada](https://clawhub.ai/user/23wsdada)

### License/Terms of Use:

MIT-0

## Use Case:

External users and agents use this skill to create a shareable digital firework show for task completions, milestones, birthdays, anniversaries, and other celebratory moments.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can send celebration text to a third-party service and produce a shareable link.

Mitigation: Preview every submitted field and create the link only after clear final user confirmation.

Risk: Broad proactive celebration triggers may include user-related names, relationship labels, project names, or other personal context.

Mitigation: Use generic celebration text by default and include personal context only when the user explicitly approves that specific content.

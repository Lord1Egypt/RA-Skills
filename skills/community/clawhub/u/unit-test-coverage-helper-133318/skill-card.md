## Description:

Helps developers and QA teams add useful unit tests, raise test coverage, and verify regression risk in existing codebases.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, software maintainers, QA engineers, open-source contributors, and product teams use this skill to plan and produce unit tests, coverage-improvement workflows, checklists, code changes, and validation notes for existing codebases.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad testing and quality trigger terms may activate the skill for adjacent prompts.

Mitigation: Confirm the user is asking for unit test coverage, testing, regression, or quality support before applying the workflow.

Risk: Suggested tests, coverage targets, or shell commands may not match the target project's semantics.

Mitigation: Inspect existing project test patterns, state assumptions, and run the relevant project verification commands before accepting changes.

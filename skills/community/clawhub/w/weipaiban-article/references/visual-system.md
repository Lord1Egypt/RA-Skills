# 视觉配额

一篇一套。具体 hex 与形态只来自当前 `themes/theme-{id}.md`，本页是全篇不可破的配额。

## 颜色

- 1 个主题色 + 1 个辅助色 + 灰阶中性色。不要再加第三种彩色。
- 强调色仅主题色；加粗优先于变色。辅色面积小（点缀、标签、划重点）。
- 正文关键词下划线只用当前主题文件里的那一条（`border-bottom`），每段 1–3 个短短语。下划线不算第三彩色。不要整段划线。主题文件没有写下划线的，继续只用加粗和辅色点缀。
- 浅底主题：正文用主题给定色（通常 `#3F3F3F`–`#595959` 一带）。不用纯黑 `#000`、不用纯白 `#FFF` 做正文或卡片/作品底。作品底用主题纸色/米/浅灰（瑞士风可用近白 `#FAFAFA`、近黑 `#111111` 作主色/线，仍不要纯 `#000`/`#FFF` 当作品底）。
- 深底主题：作品底必须是**有彩色**深底（饱和度够、不是灰阶 `#111`/`#0D0D12`），正文用**有彩色浅字**。微信会反转无彩色，灰阶深底 + 浅灰字会在深色模式对调翻车。长段正文放在主题浅卡或深色卡片上，每段 3–5 行。
- 根 `data-background` 必须等于当前主题 `canvas`。

## 入库会丢掉的样式

清洗会丢掉的只有 `position`、`float`（见 [richtext.md](components/richtext.md)）。本配额另外不写 `backdrop-filter`、`transform`、`font-family`、`text-shadow`。毛玻璃改半透明底；胶带仍可用 `inline-block` 色条；衬线/等宽用字号与字距表达。分栏用 flex。

## 标题

- 一篇 1 套标题样式，可有 2 级变体（主标题 / 二级标题），不要每节换套路。
- 二级标题 17–20px 加粗，结构跟当前主题（编号行、色条或居中），全篇统一。
- 主标题更大、加粗；封面主标题是版首里最大的字。
- 不指定 `font-family`（默认字体栈）。衬线感用字距与字号表达。

## 分割与卡片

- 一篇 1 种分割语言：细线 **或** 色条 **或** 留白，三选一，全篇重复它。
- 一篇 1 种卡片圆角 + 1 种描边（或无描边）。阴影有就全篇同一条。

## 间距与字

| 项 | 值 |
| --- | --- |
| 页边距（左右） | 8–10px |
| 模块间距 | 16–24px；同类近、换章节远 |
| 正文 | 14-15px |
| 行距 | 1.75–2.0 |
| 字距 | 0.5–1.5px（英文小标可更大，见主题） |
| 段距 | 8–12px，用 margin，不空一行 |
| 图注 | 12px，`#888`–`#999` |

## 轮播

满幅宽 390。圆角默认 0；若用圆角，取该主题卡片圆角。色与分割语言仍跟全文同一套。见图集规则 [slideshow.md](components/slideshow.md)。

## 横向滑动

视口宽仍是 390，滑动发生在更宽的画布上。固定层和宽画布的色、圆角、分割语言跟全文同一套。见 [horizontal-scroll.md](components/horizontal-scroll.md)。

## 主交互

切换两层 svg、弹窗底图与弹层卡，色与圆角仍跟全文同一套。同一篇里重复的切换或弹窗用同一套 hint 与圆角。hint 胶囊用主题主色。弹层 `foreignObject` 正文对比可读。见 [click-switch.md](components/click-switch.md)、[click-popup.md](components/click-popup.md)。

## 画布（辅助 SVG）

画布不是另一套设计，token 与流式块相同：

- `fill` / 字色只用主题主色、辅色、中性色。不要第三彩色。浅底不要 `#000` 字、不要白底卡片；深底用主题 canvas / 浅青灰字。
- `rect` 圆角 = 该主题卡片圆角；分割语言与全文同一套（短线就继续短线）。
- 文字左缘 ≈ 页边距 8–10px。

## 图文 SVG

章节插画式配图，仍用同一套 token，见 [image-svg.md](components/image-svg.md)：

- 高度 300–460；`data-overflow="visible"`，贴纸可探出边缘。
- 主图圆角 = 该主题卡片圆角；圆形画中画的 `data-corner-radius` ≥ 短边一半。
- 点题短文案用 `font-family="serif"` + 字距，不要自定义字体名。
- 几何底用主题 `wash` / `primary` 的半透明 `rect`（`opacity` 0.35–0.85），保持留白，不要铺满。

## 质感下限

- 文字与底对比可读（含渐变上的字：加半透明垫或把字移出渐变）。
- 每块一个焦点。卡片内边距 ≥ 12px，字不要贴边。

Helps AI-agent users, skill authors, maintainers, and teams create practical self-improving workflows for bug fixing, setup hardening, reliability improvement, and adjacent skill development.

## Use Case:

AI-agent users, skill authors, maintainers, and teams use this skill to turn self-improvement goals into concrete workflows, templates, checklists, analyses, code changes, or decision support. It is intended for practical productivity work around bug fixing, reliability improvement, setup hardening, and related skill creation.

## Known Risks and Mitigations:

Risk: The skill may activate for broad trigger terms such as self, logs, improvement, or bug fix.

Mitigation: Use tighter trigger wording or confirm applicability before applying the workflow in unrelated conversations.

Risk: Workflow proposals may be incorrect or too generic for a user's actual repository, setup, or safety constraints.

Mitigation: Restate constraints, expose assumptions, validate the output against success criteria, and review concrete code or configuration changes before use.

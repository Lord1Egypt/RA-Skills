# NOTICE

`codex-workbuddy-control` is an independent file-protocol skill for coordinating
Codex and WorkBuddy.

- No third-party source code is bundled.
- The scripts use only the Python standard library.
- Product names are used only to describe interoperability.
- The package contains no customer data, project data, credentials, or
  machine-specific paths.
- Users are responsible for configuring storage locations and enforcing their
  own data-export and publication rules.

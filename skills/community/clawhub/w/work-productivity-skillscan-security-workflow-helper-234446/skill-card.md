## Description:

Helps AI-agent users, skill authors, maintainers, and teams create practical SkillScan-style workflows, checklists, analysis, and implementation support for bug fixing, setup hardening, safety, and reliability work.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, skill authors, maintainers, and agent teams use this skill to turn security, SkillScan, and reliability requests into concise plans, templates, checklists, automation outlines, code changes, or decision aids. It is intended for practical workflow support around fixing bugs, hardening setup and safety, improving reliability, and creating adjacent skills.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad automatic activation terms may steer unrelated tasks into this skill's checklist or workflow pattern.

Mitigation: Review activation keywords and implicit invocation behavior before installation; narrow or disable implicit triggers where precise skill routing matters.

Risk: Generated workflow guidance could be applied without enough context for a specific security or reliability task.

Mitigation: Require the agent to restate constraints, assumptions, success criteria, and validation notes before acting on the workflow output.

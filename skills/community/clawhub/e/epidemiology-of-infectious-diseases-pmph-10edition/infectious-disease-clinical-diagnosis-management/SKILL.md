# 传染病临床诊断与管理

## 一、传染病基础评估框架

### 1.1 流行过程三环节（切断任一即终止流行）

```
传染源 → 传播途径 → 易感人群
   ↓          ↓          ↓
隔离治疗   消毒/防护   疫苗接种
```

**传染源类型**：患者（早期传染性最大）、隐性感染者、病原携带者、受感染动物

**传播途径**：
- 呼吸道（飞沫/气溶胶）
- 消化道（粪-口）
- 接触（直接/间接/性）
- 虫媒（节肢动物叮咬）
- 血液/体液
- 垂直（母婴）

### 1.2 病程四阶段判断

| 阶段 | 特征 | 临床意义 |
|------|------|----------|
| 潜伏期 | 无症状，与感染量成反比 | 确定检疫期限 |
| 前驱期 | 非特异性症状1-3天 | 已具传染性 |
| 症状明显期 | 特征性表现充分 | 诊断依据 |
| 恢复期 | 症状消失，抗体达峰 | 评估后遗症 |

**特殊转归**：
- 再燃：体温未完全正常时病原体再繁殖
- 复发：恢复期后残存病原体再繁殖
- 后遗症：器官功能长期未恢复

### 1.3 感染谱五种形式判定

```
病原体侵入机体
    │
    ├─ 被清除（非特异/特异免疫）
    │
    ├─ 隐性感染（无症状，仅免疫学阳性）→ 最常见
    │
    ├─ 显性感染（有临床表现）→ 冰山一角
    │
    ├─ 病原携带状态（无症状但排菌）→ 重要传染源
    │   └─ <3月急性，>3月慢性（乙肝>6月）
    │
    └─ 潜伏性感染（不排菌，免疫低下时发病）
```

## 二、症状学鉴别诊断

### 2.1 发热热型鉴别

| 热型 | 24h温差 | 最低点 | 典型疾病 |
|------|---------|--------|----------|
| 稽留热 | ≤1℃ | >正常 | 伤寒、斑疹伤寒极期 |
| 弛张热 | >1℃ | >正常 | 败血症、出血热 |
| 间歇热 | 发热/无热交替 | 可达正常 | 疟疾、败血症 |
| 回归热 | 高热数天→消退→再现 | - | 回归热、布鲁菌病 |
| 不规则热 | 无规律 | - | 流感、败血症 |

### 2.2 出疹性疾病快速鉴别

**出疹时间规律**（病程第几天）：
- 第1天：水痘、风疹
- 第2天：猩红热
- 第3天：麻疹（伴科氏斑）
- 第5天：斑疹伤寒
- 第6天：伤寒

**皮疹形态**：
- 斑丘疹：麻疹、风疹、伤寒
- 出血疹：流脑、出血热、登革热
- 疱疹：水痘、带状疱疹
- 荨麻疹：病毒性肝炎、蠕虫病

**特殊体征**：焦痂→恙虫病；躯干为主→水痘；耳后起步向四肢蔓延→麻疹

## 三、感染控制与报告

### 3.1 法定传染病报告时限

| 类别 | 病种数 | 报告时限 | 代表病种 |
|------|--------|----------|----------|
| 甲类 | 2种 | **2小时** | 鼠疫、霍乱 |
| 乙类 | 28种 | 24小时 | SARS、艾滋病、病毒性肝炎、新冠（乙类乙管） |
| 丙类 | 11种 | 监测管理 | 流感、手足口病 |

**特殊**：SARS、肺炭疽实施"乙类甲管"

### 3.2 隔离类型选择

| 隔离类型 | 标识色 | 适用疾病 |
|----------|--------|----------|
| 严密隔离 | - | 霍乱、鼠疫、狂犬病 |
| 呼吸道隔离 | 粉色 | SARS、流感、流脑、麻疹、结核 |
| 消化道隔离 | - | 伤寒、菌痢、甲/戊肝 |
| 血液-体液隔离 | - | 乙肝、丙肝、艾滋病 |
| 接触隔离 | 蓝色 | 破伤风、炭疽、梅毒 |
| 昆虫隔离 | - | 乙脑、疟疾 |
| 保护性隔离 | - | 免疫缺陷者、器官移植 |

### 3.3 免疫策略选择

| 类型 | 接种物 | 起效时间 | 维持时间 | 应用场景 |
|------|--------|----------|----------|----------|
| 人工自动免疫 | 疫苗/菌苗/类毒素 | 1-4周 | 数月至数年 | 常规预防 |
| 人工被动免疫 | 免疫血清/丙球 | 立即 | 2-3周 | 治疗/暴露后应急 |

## 四、特定病毒感染管理

### 4.1 脊髓灰质炎

**临床分期**：前驱期→瘫痪前期（双峰热、三脚架征）→瘫痪期（脊髓型最常见）→恢复期→后遗症期

**疫苗接种**：
- 免疫缺陷者：禁用OPV，必须用IPV
- 国家规划：2、3月IPV → 4月、4岁bOPV
- 全程IPV：2、3、4、18月各1剂

### 4.2 柯萨奇病毒

**主要综合征**：
- 手足口病（A16/EV71，EV71易重症）
- 疱疹性咽峡炎（A组）
- 心肌炎/心包炎（B组）
- 无菌性脑膜炎

**确诊**：发病1-4天取血液/咽拭子/疱疹液病毒分离；IgM早期诊断；RT-PCR高敏感

### 4.3 流感/禽流感

**病毒结构要点**：
- HA（血凝素）：吸附宿主细胞，抗HA有中和作用
- NA（神经氨酸酶）：释放子代病毒
- 甲型按HA(18亚型)/NA(11亚型)分亚型

**抗原变异**：
- 漂移（drift）：小变异→中小流行
- 转换（shift）：新亚型→大流行

**禽流感重症化机制**：
- 识别α-2,3唾液酸受体
- 细胞因子风暴（IL-6、TNF-α）
- 靶细胞：II型肺泡上皮细胞

**诊断首选**：real-time RT-PCR检测呼吸道标本核酸

### 4.4 多重耐药菌(MDRO)

**定义**：对≥3类抗菌药物同时耐药

**风险分级**：
| 级别 | 代表菌 | 措施 |
|------|--------|------|
| 紧急/1级 | CRAB/CRPA/CRE、艰难梭菌 | 严格隔离+顶级感控 |
| 严重/2级 | MRSA、VRE | 接触隔离+加强监测 |
| 中等/3级 | PRSP等 | 标准预防 |

## 五、标本采集与病原学检测

### 5.1 采集原则

1. 无菌操作
2. 病程早期、用药前
3. 采集病变明显部位
4. 特殊时机：败血症（寒战时采血）、疟原虫（体温高峰）

### 5.2 病毒学检测技术选择

| 技术 | 用途 | 特点 |
|------|------|------|
| ELISA | 抗体/抗原筛查 | 快速，判断既往/免疫状态 |
| PCR/RT-PCR | 核酸确诊 | 金标准，高敏感特异 |
| mNGS | 疑难/混合感染 | 无需预设靶标 |
| 病毒分离 | 确诊 | 费时，不适宜大批量 |

## Description:

Generates and runs machine learning classification workflows for CSV datasets, compares model accuracy, returns generated training code, and summarizes results for beginner-friendly review.

This skill is ready for commercial/non-commercial use.

## Publisher:

[bamboo9805](https://clawhub.ai/user/bamboo9805)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and data practitioners use this skill to preprocess tabular CSV data, train and compare classification algorithms, inspect generated training code, and review accuracy, cross-validation, parameter search, feature-importance, and visualization outputs.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can execute Python generated by a remote model with the user's local permissions.

Mitigation: Run it in an isolated environment, review generated code before execution, and disable remote code execution when not required.

Risk: Some workflow data may be sent to OpenAI when an API key is provided.

Mitigation: Avoid sensitive datasets, pass API keys only when needed, and remove environment secrets from the runtime.

Risk: Runtime dependencies are specified as version ranges.

Mitigation: Pin and review dependencies before production deployment.

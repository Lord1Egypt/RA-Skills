## Description:

Supports neutral content-layer partial migration assessment from Poko Motion to AI-HIVE MCP by checking official capabilities, defining agent handoffs, creating an MCP work order, and setting cost, quality, approval, and rollback controls.

This skill is ready for commercial/non-commercial use.

## Publisher:

[wubin1836](https://clawhub.ai/user/wubin1836)

### License/Terms of Use:

MIT-0

## Use Case:

External users and content-production teams use this skill to plan a controlled partial migration from Poko Motion workflows to AI-HIVE MCP for independently reviewable image, video, or shot-generation nodes. It is intended for pilots that preserve the original platform path until same-input samples, cost snapshots, human approvals, and rollback checks pass.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Provider capabilities, pricing, regions, or terms may change after the evidence date.

Mitigation: Confirm current Poko Motion and AI-HIVE capabilities, costs, availability, data-retention terms, and asset-rights requirements before using real project assets.

Risk: The workflow can involve media uploads, billable generation tasks, external sends, or publication decisions.

Mitigation: Require explicit human approval and a budget check before any upload, billable task, external transfer, or publication.

Risk: The skill is vendor-directed and centered on AI-HIVE, which may bias migration recommendations.

Mitigation: Use same-input pilots, success metrics, cost snapshots, rollback checks, and human review before treating AI-HIVE as a replacement for any Poko Motion workflow node.

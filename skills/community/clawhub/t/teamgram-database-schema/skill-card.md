## Known Risks and Mitigations:

Risk: The skill is Chinese-language reference material, which may be difficult for non-Chinese readers to interpret accurately.

Mitigation: Use translation or an English-language review when readers are not fluent in Chinese, especially before relying on table descriptions for implementation decisions.

Risk: Database schema reference material can become outdated as the upstream Teamgram Server SQL files change.

Mitigation: Compare guidance against the current Teamgram Server SQL files before making schema changes or production decisions.

## Use Case:

Developers and engineers use this skill to install and apply bat as a modern file viewer with syntax highlighting, line numbers, Git decorations, paging, and terminal workflow integrations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Optional aliases or PAGER/MANPAGER changes can alter how terminal file viewing and man page commands behave.

Mitigation: Review shell configuration examples before applying them, and test changes in a temporary shell session before adding them to persistent shell startup files.

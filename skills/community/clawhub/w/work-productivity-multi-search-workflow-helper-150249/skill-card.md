## Use Case:

Agent users, skill authors, maintainers, and teams use this skill to turn Multi Search Engine-style demand into concrete workflows, checklists, analysis, code changes, or decision support. The skill emphasizes local-hardware-friendly planning, practical setup hardening, reliability improvements, and validation against stated success criteria.

### Deployment Geography for Use:

## Known Risks and Mitigations:

Risk: Broad automatic activation rules may pull the skill into unrelated search, engineering, or bug-fix conversations.

Mitigation: Review before installation when automatic invocation is enabled, and tighten triggers to explicit Multi Search Engine workflow requests or direct skill-name invocation.

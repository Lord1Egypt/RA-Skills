## Description:

Accessible HTML game development for screen readers such as Zhengdu, NVDA, and JAWS, supporting blind and low-vision users.

This skill is ready for commercial/non-commercial use.

## Publisher:

[wenwei020](https://clawhub.ai/user/wenwei020)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill to guide, generate, and review HTML games that work with keyboard navigation and screen readers for blind and low-vision players.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate for broad accessible-game requests where screen-reader-accessible HTML or web-game guidance is not intended.

Mitigation: Use it for requests explicitly about screen-reader-accessible HTML or web games, and narrow the trigger phrase or confirm scope before applying the guidance.

Risk: The source material is primarily Chinese and includes China-specific screen-reader context, which may be less direct for non-Chinese users.

Mitigation: Ask the agent to respond in the user's preferred language and validate the resulting game against the target screen readers.

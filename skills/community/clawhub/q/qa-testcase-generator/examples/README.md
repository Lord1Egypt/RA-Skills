# 标准测试用例示例

## 概述

本目录包含标准测试用例示例，用于展示测试用例生成器的输出格式和质量标准。

## 文件说明

| 文件 | 说明 |
|------|------|
| 用户管理系统_标准测试用例.xlsx | Excel格式的完整测试用例（可直接使用） |
| 用户管理系统_测试用例.json | JSON格式的测试用例数据（可用于重新生成Excel） |

## 质量标准

### 用例结构
- 每条用例包含3-5个具体步骤
- 操作描述具体可执行
- 预期结果明确可验证
- 测试数据提供具体值
- 需求来源关联REQ-XXX

### 生成方式
按照 SKILL.md 五阶段工作流生成：
1. 业务域分析：识别6个业务域
2. 需求提取：提取22条需求
3. 测试设计：选择场景法、边界分析、状态迁移、判定表
4. 用例生成：生成35条用例
5. 输出Excel：格式化输出

## 使用方式

### 生成Excel
```bash
python3 scripts/writer.py examples/用户管理系统_测试用例.json
```

### 导入测试管理系统
生成的Excel文件可直接导入以下系统：
- TestRail
- Zephyr
- ALM
- 禅道

## 用例字段说明

| 字段 | 说明 | 示例 |
|------|------|------|
| 序号 | 自增序号 | 1, 2, 3... |
| 用例编号 | TC-NNN格式 | TC-001 |
| 优先级 | P0/P1/P2/P3 | P0 |
| 测试维度 | 功能/可靠性/效率/安全性/易用性/可维护性/兼容性 | 功能 |
| 用例类型 | 冒烟测试/回归测试/探索性测试/验收测试 | 冒烟测试 |
| 业务域 | 所属业务域 | 用户注册 |
| 设计方法 | 边界分析+等价类/状态迁移/判定表/场景法 | 场景法 |
| 测试场景 | 场景描述 | 主流程验证：用户成功注册 |
| 测试点 | 具体验证点 | 验证完整注册流程 |
| 操作步骤 | 步骤列表，每步格式：步骤N: 操作 | 步骤1: 输入邮箱, 步骤2: 点击注册 |
| 预期结果 | 结果列表，每步格式：步骤N: 预期 | 步骤1: 邮箱格式校验通过, 步骤2: 注册成功 |
| 测试数据 | 测试数据说明 | 邮箱: test@example.com |
| 前置条件 | 执行前环境或数据准备 | 已登录用户 |
| 需求来源 | 关联需求ID | REQ-001 |
| 测试结果 | 执行后填写 | 通过/失败 |

# 帽子体系：四层扣帽与判据

“扣帽子”是行业内的说法：把材料主题挂到最高、最新、最贴切的政策文件上，并在开篇逐字引出。它的本质是**给材料定坐标**——读者第一眼就知道这份材料站在哪条政策线上、由哪一层文件支撑。

## 1. 为什么先定帽子

中文专报的第一评价维度是政策站位，其次才是情况真实。站位不是形容词堆出来的，而是靠“你引了哪份文件、引在哪一段”。帽子定不下来，结构就定不下来：章节标题会变成业务口语，评审读到的是一份工作总结而不是政策材料。

顺序因此固定为：**依据 → 帽子 → 骨架 → 正文**。反过来做，等于先砌墙再找地基。

## 2. 五层结构

| 层 | 取什么 | 作用 | 判断是否够格 |
|---|---|---|---|
| ① 总纲 | 该领域最高层级的综合性文件，一份即可 | 全文站位，开篇落脚点 | 发文机关层级最高、覆盖面最广、能一句话概括领域方向 |
| ② 主线框架 | 顶层意见加其配套子方案，构成“1+N” | 支撑分节结构，展示对部署的完整理解 | 主干与配套是否闭合：主干一份、配套按领域齐备 |
| ③ 领域专项 | 按业务线、险种、场景的部门文件 | 每一节的具体帽子 | 与正文分节一一对应，且直接约束该业务 |
| ④ 本地落地 | 本级政府工作报告与本级配套方案 | 本地化，把国家要求落到可执行场景 | 规格够高、时效最新、能覆盖多个业务方向 |
| ⑤ 合规底线 | 正在施行、直接约束本业务的规章与办法 | 单独成章，体现专业度 | 是否直接管到本单位的行为，而不只是倡导 |

第⑤层写在最后但权重不低：它是硬约束。把它塞进“下一步措施”会显得轻，单独成章才压得住。

## 3. 扣帽四判据

同一层里可能有好几份候选文件，按四个维度打分取舍：

1. **层级高度**：发文机关越高越有力。同一主题下，上级机关的文件优先于本级部门文件。
2. **时效**：优先最近三个月内发布的文件。新文件是天然的时间窗口，能立刻体现材料的时效性；旧文件用于交代沿革。
3. **贴合度**：是否**直接**约束本单位、本业务。泛泛提及本领域的文件，不如一条直接管到本业务的条款。
4. **可引性**：能否拿到逐字原文与文号。拿不到就只能进待核清单，不能进开篇。

四项里若“贴合度”与“可引性”冲突，选可引性——开篇引一句查不到出处的话，比引一句次优但可核的话风险大得多。

## 4. “1+N”闭合验证

主线框架层最容易出彩，也最容易写虚。验证方法：

- 找到主干文件（顶层意见或实施方案）。
- 按本材料涉及的领域，逐个找它的配套子方案。
- 若每个领域都能找到配套，说明架构闭合，可以分层引用并在正文里点明“主干 + 配套”的关系——这种结构在材料里非常好看。
- 若有领域找不到配套，如实写明该领域尚无配套，不要用别的领域文件顶替。

## 5. 开篇帽子段的写法

**结构公式**：时间 + 发文机关 + 文件名称（文号）+ 核心提法（逐字）+ 与本单位的关系。

一句话范例形态（不含具体文件）：

> 某年某月，某机关印发《……》（某〔年〕某号），提出“……（逐字引用核心提法）……”，为本单位推进某项工作提供了根本遵循。

四种侧重，各写一版供挑选：

| 侧重 | 适用场合 | 串联方式 |
|---|---|---|
| 政策站位 | 报上级机关 | 总纲 → 主线 → 本地，三层递进 |
| 自身禀赋 | 报本级领导 | 总纲一句带过，重点落在“我们天然该干” |
| 合规要求 | 有硬约束新规 | 总纲 → 合规底线，强调必须做到 |
| 时效窗口 | 刚出新文件 | 直接以新文件开篇，突出“刚刚明确” |

每版一百五到二百五十字，三到四句。开篇不要引超过三份文件，也不要在一段里塞五个书名号。

## 6. 依据密度控制

- **一条结论配一条最硬依据**。并列三条依据不会显得严谨，只会显得没底气。
- 每节的依据放在段首，作为该节的政策前提；节内不再重复引用同一份文件。
- 全篇引用的文件数量控制在五到八份：多了帽子互相打架，少了撑不起结构。

## 7. 四类反模式

1. **帽子叠罗汉**：一段引五份文件，每份只留半句。读者记不住任何一份，等于没引。
2. **帽子与章节脱节**：开篇引的是甲领域文件，正文写的是乙领域业务。这是最容易被一眼看穿的错误。
3. **把转载当原文**：地市转发页、公众号文章、二手汇编都不是原件。可用于取文，不能用于定文号。
4. **把通用说法当条文**：行业里人人都会讲的提法，不等于某份文件的原句。写进引号里就必须能翻到。

## 8. 自检

- [ ] 开篇第一段能指名到具体文件，且该文件四元组齐全。
- [ ] 五层中至少四层有实体文件；空缺层已标注。
- [ ] 每一节的标题都能对应到③层或⑤层的一条要求。
- [ ] 全篇引用的文件数量在五到八份之间。
- [ ] 没有一段里出现三份以上文件。
- [ ] 每处引号内的文字都能在原文里找到。

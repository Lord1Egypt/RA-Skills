# 人像精修（阶段A）— 大小眼 / 面部瑕疵 / 唇形自然

真人口播实拍的人像精修。**主线用剪映专业版（无需GPU，本机跑）**；GPU 增强（FaceFusion/CodeFormer）仅作可选。发型修复不做。

## 0. 先分清问题类型（决定走哪条路）

| 问题 | 本质 | 方案 |
|---|---|---|
| 大小眼（拍出来显得） | 广角畸变+角度+光线 | **拍摄端**优先 + 剪映大眼/亮眼 |
| 大小眼（天生形状不对称） | 几何结构 | 剪映整体大眼减轻；精确对齐**无现成工具**（见§4） |
| 面部瑕疵（痘/斑/暗沉） | 肤质 | 剪映磨皮/美白/祛痘 |
| 唇形（真人实拍） | 口型本就同步 | 剪映美颜提清晰度即可，**不需 lip-sync** |
| 唇形（配音/口型对不上） | 音画不同步 | FaceFusion lip-sync（**要GPU**，§5） |
| 发型乱 | 结构 | **不做**，拍摄端整理（无成熟开源工具） |

## 1. 拍摄端（最自然，零成本，先做）

大小眼和发型乱一大半是拍出来的：
- **机位与眼平齐**，别俯拍/仰拍（角度造成两眼透视差）。
- **镜头拉远**用后置，别手机前置近距离怼脸（广角畸变让靠近镜头的眼显大）。
- **正脸对镜头**，别侧脸（侧脸两眼大小透视差明显）。
- **匀光**（正面柔光），别侧硬光（阴影让一只眼显小/显暗）。
- 发型拍前整理，顶光别太硬。

## 2. 剪映专业版「美颜美体」（本机，无需GPU）

导入原片 → 选中视频轨 → 右上「美颜美体」：

| 功能 | 处理 | 建议强度 |
|---|---|---|
| **大眼** | 整体放大眼睛，减轻大小眼观感 | 20–40（别拉满，假） |
| **亮眼** | 提亮眼白/眼神光，两眼显得更有神一致 | 20–35 |
| **磨皮** | 肤质平滑祛痘 | 30–50（保留皮肤纹理，别塑料感） |
| **美白** | 肤色提亮 | 15–30 |
| **瘦脸** | 脸型微调（可选） | 10–25 |
| **祛法令纹/黑眼圈** | 局部瑕疵（如有） | 按需 |

- 口播要**自然**，强度宁低勿高，磨皮别过（塑料脸反而假）。
- 剪映美颜是逐帧实时处理，导出即生效，无需GPU。
- **唇形**：真人实拍口型已同步，美颜后嘴部更清晰即可，不用额外对口型。

## 3. 导出（衔接阶段B）

- 导出**与原片同分辨率/帧率**（如 544×960 / 30fps，或 1080×1920 / 30fps）。
- 编码 H.264，码率够（≥8Mbps），保留原声。
- 导出文件作为阶段B（证据图叠加）的「原片.mp4」输入。
- ⚠️ 剪映导出可能改分辨率/帧率，阶段B 前务必 `ffprobe` 复核，画布参数随之改。

## 4. 大小眼精确对齐 — 诚实边界

**「自动检测两眼尺寸差→把小眼精确放大到和大眼一致」目前没有现成开源工具**（GitHub `eye symmetry face correction` 搜索 0 结果）。

- 剪映「大眼」是**两只眼一起放大**，不是单独补小眼，只能减轻观感，不能精确对齐。
- LivePortrait 的 eye retargeting 调的是**眼皮开合度**（整体），对「一只眼眯着」有效，对「眼形大小不对称」无效，且要GPU。
- 真要精确对齐：自己写 **MediaPipe 关键点 + 小眼区域局部 warp**（几何放大），或 ComfyUI 局部重绘。但**视频逐帧会闪**，需时序平滑（光流/EbSynth），工程量大，适合精修单条不适合日更。
- 结论：日更口播用「拍摄端 + 剪映大眼/亮眼」最实际；别为精确对齐去换脸/数字人（牺牲真人真实感）。

## 5. 可选 GPU 增强（本机无GPU则跳过，用云GPU）

> 本机若 torch 是 CPU 版 / 无 NVIDIA 显卡 / 内存<4GB，这些跑不动或极慢，**用云GPU（AutoDL/恒源云/RunPod，几元/小时）**。

### FaceFusion lip-sync（仅配音/口型对不上时需要）
- 保留原脸原表情，只把口型对齐音频。github.com/facefusion/facefusion
- 处理器 `lip_syncer`（wav2lip 系），需 NVIDIA GPU。
- 真人实拍口型已同步，**不需要这一步**。
- ⚠️ OpenRAIL 许可；用他人肖像/声音需授权 + 合成标识。

### CodeFormer / GFPGAN 面部增强（提清晰度/修瑕疵）
- github.com/sczhou/CodeFormer（18k★）/ TencentARC/GFPGAN。
- 逐帧人脸复原，磨皮祛痘提清晰，**不改五官形状/发型/大小眼**。
- 需GPU；CPU 逐帧极慢（3840帧要数小时）。
- 剪映磨皮已覆盖大部分需求，此步仅追求更高画质时用。

## 6. 与阶段B衔接

```
原片 → [阶段A 剪映美颜美体(大小眼/瑕疵/唇形)] → 导出同参数成片
     → [阶段B Remotion证据图叠加 + ffmpeg保原声] → 最终成片
```

- 阶段A 可选：人物状态好就跳过，直接阶段B。
- 阶段A 改了分辨率/帧率 → 阶段B 画布参数同步改。
- 全程保留原声，口播人声不被截断。

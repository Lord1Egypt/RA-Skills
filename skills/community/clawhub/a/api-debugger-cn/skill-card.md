## Known Risks and Mitigations:

Risk: Credential values can be exposed through shell commands, shell history, verbose logs, or URL query strings when adapting the examples.

Mitigation: Use environment variables or secret-management tooling for real credentials, avoid query-string secrets, and test only systems you own or are authorized to assess.

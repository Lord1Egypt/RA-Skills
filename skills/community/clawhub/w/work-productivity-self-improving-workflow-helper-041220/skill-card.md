## Description:

Helps AI-agent users, skill authors, maintainers, and teams create practical workflows, checklists, analyses, artifacts, and implementation support for self-improving and proactive agent work.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

External developers, skill authors, maintainers, and agent users use this skill to turn self-improving or proactive agent requests into clear plans, templates, checklists, code changes, analyses, or decision support. It is aimed at local-hardware-friendly workflows that clarify goals, produce an actionable result, and validate the result against stated success criteria.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate too easily for generic productivity or self-improvement requests.

Mitigation: Narrow invocation triggers to explicit self-improving or proactive agent workflow requests before broad deployment.

Risk: Generated workflow or implementation guidance may not fully match the user's environment or success criteria.

Mitigation: Require the agent to restate assumptions, validate the output against success criteria, and list remaining risks or follow-up work.

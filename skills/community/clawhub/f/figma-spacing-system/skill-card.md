Designers, design-system maintainers, and developers use this skill to define Figma spacing tokens, responsive layout grids, component spacing conventions, and implementation guidance for consistent product layouts.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may shape broad spacing or layout-foundation requests toward Figma spacing scales, grid definitions, and token documentation even when a user wanted general design discussion.

Mitigation: Use the skill for Figma spacing-system work, and avoid invoking it for broad design discussion that does not require spacing tokens or layout grids.

Risk: Generated spacing recommendations can become inconsistent if arbitrary values or mixed base units are accepted without review.

Mitigation: Review outputs to confirm all token values are multiples of the selected base unit and that grid, component, and implementation guidance are aligned.

## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to turn REST API context into OpenAPI or Swagger documentation, validation checklists, implementation guidance, and next-step recommendations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate for broad API or software-documentation prompts.

Mitigation: Narrow triggers to explicit OpenAPI, Swagger, or REST API documentation requests when a stricter installation posture is needed.

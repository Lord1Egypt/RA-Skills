# 主题知识图谱构建指南

当用户提出要学习一个新主题时，使用本指南构建系统化的知识图谱和学习路径。

---

## 构建流程

### Step 1: 主题边界界定
- 用户说的"学XX"具体指什么？不同人理解可能差很远
- 示例：
  - "学Python" → 是数据科学？Web开发？自动化脚本？还是只是兴趣入门？
  - "学营销" → 数字营销？品牌营销？内容营销？增长黑客？
- 通过 1-2 个追问明确边界

### Step 2: 前置知识评估
- 学这个主题需要什么基础？
- 用户目前具备什么水平？
- 如果有缺口：先补基础 vs 边学边补（通常后者更高效）

### Step 3: 核心概念提取
对该领域最重要的概念进行分级：

| 级别 | 说明 | 占比 |
|------|------|------|
| P0 - 必修 | 不掌握就无法继续的核心概念 | 20% |
| P1 - 重要 | 深入理解所必需 | 30% |
| P2 - 扩展 | 提升理解深度和广度 | 30% |
| P3 - 进阶 | 专家级别才需要 | 20% |

### Step 4: 学习阶段设计
通用阶段模板：

```
阶段1：基础框架（10-20%时间）
- 目标：建立全局地图，理解核心概念
- 方法：广泛浏览 + 费曼技巧
- 产出：用自己的话画出知识框架图

阶段2：核心概念深入（40-50%时间）
- 目标：掌握P0和P1级别的所有概念
- 方法：分块 + 刻意练习 + 提取练习
- 产出：能独立解决该领域的基础问题

阶段3：实战应用（20-30%时间）
- 目标：将知识应用到实际场景
- 方法：做项目 + 解决实际问题
- 产出：完成一个可展示的成果

阶段4：深化与扩展（按需）
- 目标：填补知识空白，达到精通
- 方法：交替学习 + 阅读高级资料 + 教别人
- 产出：能解答别人的问题，发现新的学习方向
```

### Step 5: 里程碑与验证
每个阶段设置可验证的里程碑：
- 不是"读完了第X章"
- 而是"能用XX方法解决YY类型的问题"
- 验证方式：小测验、项目产出、教别人、写总结

## 常见领域的知识图谱参考

### 编程类（Python为例）
```
前置：计算机基础操作
阶段1：基础语法（变量、数据类型、控制流、函数）
阶段2：核心概念（面向对象、模块、异常处理、文件操作）
阶段3：应用方向（数据科学/ Web / 自动化 / 各选一个深入）
阶段4：工程实践（版本控制、测试、部署）
```

### 语言学习类（英语为例）
```
阶段1：发音与基础词汇（500高频词）
阶段2：基本语法与日常对话
阶段3：阅读理解与听力输入
阶段4：输出练习（写作+口语）
阶段5：专业/主题深入
```

### 设计类（UI设计为例）
```
阶段1：设计基础（色彩理论、排版、构图）
阶段2：工具掌握（Figma/Sketch）
阶段3：设计原则与模式
阶段4：实战项目
阶段5：设计系统与进阶
```

### 商业分析类
```
阶段1：数据分析基础（Excel、SQL、基础统计）
阶段2：业务理解（行业知识、指标体系）
阶段3：数据可视化与沟通
阶段4：进阶分析与建模
阶段5：商业洞察与决策支持
```

## 资源推荐原则

1. **先免费后付费**：优先推荐 MOOC、YouTube、官方文档
2. **经典优先**：推荐经过时间检验的经典资源，而非最新热门
3. **实践导向**：有练习、有项目的资源优于纯理论资源
4. **难度匹配**：与用户当前水平匹配，不要太简单也不要太难
5. **多样性**：同一概念提供2-3种不同形式的资源（视频+文字+练习）

## 策略匹配模板（按主题类型）

不同主题需要不同的策略组合。以下模板为每种主题类型提供"默认策略包"，可按用户情况微调。

### 语言学习类

**默认策略包**：
| 阶段 | 主策略 | 深度处理指令 |
|------|--------|-------------|
| 词汇积累 | `[间隔重复]` Anki + `[双重编码]` 图片记忆 | 每个词用新词造一个和自己生活有关的句子 |
| 语法理解 | `[精细加工]` 追问为什么 + `[具体实例]` 多场景例句 | 将语法规则改写为一个顺口溜或口诀 |
| 听说训练 | `[交错练习]` 混合不同口音/场景 + `[提取练习]` 影子跟读 | 录一段60秒音频，假装用法语教一个朋友今天的3个表达 |
| 阅读写作 | `[分块]` 逐段分析 + `[费曼技巧]` 总结 | 将一段阅读材料改写为另一个场景（如咖啡店→便利店） |

**环境建议**：通勤时听目标语言播客（碎片时间利用），学习时段播放目标语言背景音（沉浸式）。

### 编程/技术类

**默认策略包**：
| 阶段 | 主策略 | 深度处理指令 |
|------|--------|-------------|
| 基础语法 | `[分块]` 一个概念一个练习 + `[提取练习]` 不看教程写代码 | 写一段10行代码，逐行注释解释每一行在内存中做了什么 |
| 核心概念 | `[交错练习]` 混合不同类型题目 + `[精细加工]` 追问底层原理 | 用新学的概念重构上周写的一个旧代码 |
| 项目实战 | `[刻意练习]` 聚焦薄弱环节 + `[双重编码]` 画架构图 | 自己出一道题（造需求），然后用刚学的技术解出来 |
| 深入进阶 | `[发散模式]` 读源码 + `[费曼技巧]` 写技术博客 | 写一篇"给非技术人员讲清楚XX"的教程 |

**环境建议**：安静环境学新概念，已熟练内容可听白噪音。代码编辑器全屏，关闭无关标签页。

### 概念理解类（哲学、理论、商业）

**默认策略包**：
| 阶段 | 主策略 | 深度处理指令 |
|------|--------|-------------|
| 初步理解 | `[费曼技巧]` 用简单语言解释 + `[具体实例]` 找案例 | 找3个现实生活中的例子 + 1个反例 |
| 深入分析 | `[精细加工]` 追问为什么 + `[双重编码]` 画关系图 | 画一个概念对比图（如Venn图），展示和相似概念的区别 |
| 批判思考 | `[交错练习]` 混合不同学派观点 + `[提取练习]` 辩论式自测 | 写一段"支持者vs反对者"的正反论证 |
| 融会贯通 | `[发散模式]` 跨领域联想 + `[费曼技巧]` 教别人 | 将这个概念和自己专业/生活中的某个现象建立类比 |

**环境建议**：固定阅读地点，准备笔记本（手写比打字更能促进深度处理），可以准备白板/草稿纸画图。

### 技能操作类（设计、写作、运动、乐器）

**默认策略包**：
| 阶段 | 主策略 | 深度处理指令 |
|------|--------|-------------|
| 基础技法 | `[刻意练习]` 聚焦薄弱环节 + `[分块]` 拆分动作 | 用手机录一段自己练习的视频，回放找出问题 |
| 风格培养 | `[交错练习]` 混合不同风格练习 + `[具体实例]` 临摹经典 | 临摹3个不同风格的作品，总结它们的共同点和差异点 |
| 项目实战 | `[提取练习]` 不看教程独立完成 + `[精细加工]` 反思为什么 | 完成一个作品后，写3条"如果重做我会改变什么" |
| 形成个人风格 | `[发散模式]` 放松探索 + `[费曼技巧]` 解释自己的风格 | 写一段"我的设计/写作/运动理念"的宣言 |

**环境建议**：技能练习需要专门的物理空间（如画桌、琴房）。使用番茄钟防止过度疲劳。

### 使用指南
- 以上模板为"默认策略包"，实际使用时根据用户个人情况微调
- 如果用户有明确偏好（如"我不喜欢用Anki"），可以替换为等效策略
- **每个阶段至少覆盖3种不同策略**，避免单一方法导致的厌倦和效率下降
- 所有任务都必须标注方法论标签（见 SKILL.md 中的标签系统）

## 特殊主题处理

### 没有固定知识体系的主题（如"学摄影"、"学写作"）
- 聚焦核心技能而非知识列表
- 以项目驱动学习
- 大量实践 + 即时反馈（社群、导师、作品集）

### 快速入门型需求（"明天下班要会用XX"）
- 80/20法则：识别最核心的20%
- 跳过理论，直接学操作
- 提供速查表/备忘录

### 系统精深型需求（"我想成为XX领域的专家"）
- 设计12-24个月的长期路径
- 设置明确的阶段性目标
- 建议找到导师或学习社区
- 定期复盘和调整方向

## Description:

Guides use of the agent-desktop CLI on Linux, including X11 and Wayland support, accessibility bus checks, and common setup and interaction issues.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and automation agents use this guide to configure and troubleshoot agent-desktop for Linux desktop interaction, understand X11 and Wayland capabilities, and follow command examples for common tasks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Security review flags advice to disable Electron sandbox protections and an undeclared action that closes GNOME Calculator.

Mitigation: Review both items before installation; verify the need for any sandbox change and confirm the target and purpose before using the app-closing action.

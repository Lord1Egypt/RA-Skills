## Use Case:

AI-agent users, skill authors, maintainers, and teams use this skill to clarify productivity or Humanizer-style workflow requests, produce a concrete artifact, and verify it against stated success criteria.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad implicit triggers can cause the skill to activate for ordinary writing, editing, reviewing, or bug-fix requests where it is not the intended helper.

Mitigation: Install only when this generic workflow helper is wanted; use agent controls to require explicit invocation or disable implicit invocation when task routing matters.

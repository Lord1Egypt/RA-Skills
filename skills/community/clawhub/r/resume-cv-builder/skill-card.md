## Description:

Create professional resumes and CVs. Generate ATS-friendly formats, optimize bullet points, tailor for specific jobs, and export to multiple formats (Markdown, HTML, LaTeX, PDF).

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and agents use this skill to draft, optimize, tailor, and export professional resumes or CVs for job applications.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Resume and CV drafting may process personal career and contact information.

Mitigation: Review provided personal information before use and avoid including unnecessary sensitive details.

Risk: The skill includes an example CDN-hosted CSS URL for HTML export.

Mitigation: Use a local stylesheet when privacy, reproducibility, or network control is important.

Risk: The skill may suggest Pandoc commands that generate files from resume content.

Mitigation: Review commands and output paths before running exports, especially for PDF, HTML, and DOCX generation.

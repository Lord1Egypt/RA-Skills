## Description:

Optimize prompts for code-related tasks following prompt-engineering best practices. Use when refining prompts for implementation, debugging, refactoring, code review, or testing.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill to refine code-task prompts before implementation, debugging, refactoring, code review, or testing. It audits prompt clarity, context, scope, and verification expectations, then returns an improved prompt.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The optimized prompt may add investigation or verification steps that are not appropriate for the user's actual task.

Mitigation: Review the generated prompt before use and keep only the steps that match the intended code task and repository context.

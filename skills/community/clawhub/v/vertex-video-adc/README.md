# Google Cloud Vertex AI Video Generator (ADC) Skill

Generate high-quality videos from text prompts or reference images via Google Cloud's Vertex AI `predictLongRunning` (Veo) API using Application Default Credentials (ADC).

This skill is designed for [OpenClaw](https://github.com/openclaw/openclaw) as a portable, generic capability.

## Features
- Supports both Text-to-Video and Image-to-Video.
- Image-to-video reference image `--image` is completely optional.
- Custom parameter tuning: resolution, aspect ratio, duration, and audio generation.
- Automatically handles regional endpoint (e.g. `us-central1-aiplatform.googleapis.com`) or global endpoints depending on routing location.
- Full support for `GOOGLE_CLOUD_PROJECT` and `GOOGLE_CLOUD_LOCATION` environment variables.
- Standard JSON output for ease of automation integration.

## Installation & Setup

Place this directory in your OpenClaw workspace `skills/` folder:
```text
skills/vertex-video-adc/
```

### Prerequisites
1. Ensure the Google Cloud SDK (`gcloud`) and `curl` are installed and available on your system path.
2. Authenticate application credentials:
   - For `adc` mode (default): `gcloud auth application-default login`
   - For `user-token` mode: `gcloud auth login`

## Usage

### Text-to-Video
```bash
python3 scripts/video_harness.py --prompt-file <path_to_prompt> --out <path_to_output>
```

### Image-to-Video
Provide an optional reference image:
```bash
python3 scripts/video_harness.py --prompt-file <path_to_prompt> --image <path_to_image> --out <path_to_output>
```

### Advanced Usage
- Specify custom project, location, and model:
```bash
python3 scripts/video_harness.py --prompt-file <path_to_prompt> --out <path_to_output> --project <project_id> --location <location> --model <model>
```
- Disable audio generation (audio is generated by default):
```bash
python3 scripts/video_harness.py --prompt-file <path_to_prompt> --out <path_to_output> --generate-audio false
```

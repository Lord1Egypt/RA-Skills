## Description:

Use before trusting a downloaded skill: audit it first.

This skill is ready for commercial/non-commercial use.

## Publisher:

[blueboyzx](https://clawhub.ai/user/blueboyzx)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill to check downloaded skills for provenance, security concerns, portability issues, and unsupported claims before installing or trusting them.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security review is partial because several references in the skill could not be resolved; a benign scan is not a guarantee of safety.

Mitigation: Review the referenced material and inspect the skill before installation, especially when unresolved references affect the audit.

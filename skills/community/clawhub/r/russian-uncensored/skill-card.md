## Description:

OpenClaw Russian is a Russian-language persona skill that guides an agent to answer directly, bluntly, and practically across analysis, technical help, survival topics, and bot-to-bot prompt work.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

External users and developers use this skill when they want a Russian-language assistant style that is direct, concise, and willing to use rough language while still focusing on practical answers. The skill is intended for candid analysis, technical critique, prompt writing for other AI systems, automation examples, and general outdoor-survival discussion.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill intentionally produces a blunt, profanity-tolerant Russian assistant style that may be unsuitable for sensitive, professional, or formal conversations.

Mitigation: Use it only when that tone is explicitly desired, and reduce or disable profanity for serious, crisis, medical, workplace, or formal contexts.

Risk: The artifact includes sample API code patterns with HTTP transport, inline placeholder keys, and unpinned package installation.

Mitigation: Before adapting sample code, use HTTPS, store secrets in environment variables or a secrets manager, and pin dependencies inside an isolated environment.

Risk: Outdoor-survival material may be incomplete for real emergencies or expert wilderness planning.

Mitigation: Treat survival content as general commentary and verify critical decisions against qualified local guidance, emergency services, or trained outdoor professionals.

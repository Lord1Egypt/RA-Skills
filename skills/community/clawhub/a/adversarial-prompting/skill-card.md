## Description:

Applies rigorous adversarial analysis to generate, critique, fix, and consolidate solutions for any problem (technical or non-technical).

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, engineers, and decision makers use this skill to evaluate complex technical, strategic, or business problems by comparing multiple solution paths, stress-testing weaknesses, and selecting a ranked recommendation with implementation guidance.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill automatically saves complete analyses to the user's home directory, which can expose confidential problem details or create unmanaged local records.

Mitigation: Review before installing; remove or modify the export step, make export opt-in, and use a private dedicated output directory with collision-safe file creation.

## Description:

Subagent Setup Wizard helps users configure OpenClaw subagents, understand version support, tune concurrency, and monitor resource usage.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and OpenClaw operators use this skill as a Chinese-language guide for enabling subagents, selecting concurrency settings, applying configuration examples, and troubleshooting subagent operations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may surface operational instructions that change or disrupt an OpenClaw environment without enough guardrails.

Mitigation: Review commands before execution and treat config changes, config resets, gateway restarts, and subagent termination commands as manual administrative actions.

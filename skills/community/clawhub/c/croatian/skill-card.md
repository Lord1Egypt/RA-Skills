## Use Case:

Agents and users use this skill when drafting or revising Croatian text so responses sound more natural, warm, and conversational. It is especially suited for casual internet-style communication unless the user asks for formal language.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may bias Croatian responses toward informal phrasing when a formal register is expected.

Mitigation: Ask explicitly for formal Croatian, Vi address, or a specific regional/register preference when the context requires it.

Risk: Casual phrasing and regional flavor may be inconsistent if the desired Croatian variety is not specified.

Mitigation: Specify the intended audience, region, and tone before using the generated text in sensitive or public-facing contexts.

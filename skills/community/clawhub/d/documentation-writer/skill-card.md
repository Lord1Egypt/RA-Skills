## Description:

Write clear, comprehensive documentation. Covers README files, API docs, user guides, and code comments. Create documentation that users actually read and understand.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, technical writers, and product teams use this skill to draft or improve README files, API documentation, user guides, troubleshooting notes, and code comments.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated documentation can accidentally include real secrets or production credentials if placeholders are replaced with live values before publication.

Mitigation: Review generated docs before publishing and keep examples limited to placeholders, sample URLs, and non-sensitive test values.

Risk: Broad documentation guidance may produce inaccurate or outdated examples for a specific project or API.

Mitigation: Validate generated README, API, user guide, and code comment content against the current project behavior before release.

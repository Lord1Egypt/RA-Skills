# Icon asset source

The previous hot-topic PNG had no editable source or provenance record, so it is not included in this staging package.

The replacement icon is the original geometric trend-cycle artwork from the same `xxjrq`/Skill Factory Douyin skill set, with its editable vector retained at `assets/icon-source.svg`. The source skill is `douyin-viral-remake-free`; its local Git history records the SVG and matching PNG as first-party assets in the original release commit. The staged PNG files are byte-identical to that source skill's PNG (SHA-256 `cceb69f1c02b504a4bc119f4ac2afa307e6930a1066f62fcaaf99ebc39092433`). The artwork contains no platform logo or third-party mark.

This provenance supports including the replacement graphic in the Skill Factory MIT-0 package. It does not establish provenance for the removed hot-topic icon.

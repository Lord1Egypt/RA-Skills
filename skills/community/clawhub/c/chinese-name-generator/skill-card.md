## Description:

Chinese Name Generator helps suggest Chinese child names using traditional naming considerations such as birth timing, Five Elements balance, sound, meaning, family generation, homophone avoidance, and classical references.

This skill is ready for commercial/non-commercial use.

## Publisher:

[flobull](https://clawhub.ai/user/flobull)

### License/Terms of Use:

MIT-0

## Use Case:

External users can use this skill to ask an agent for Chinese child-name suggestions and naming-convention guidance. The skill structures suggestions with pinyin, Five Elements balance, meanings, classical or original source notes, birth-chart fit, and tone pattern.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Birth time and family details can be personal information.

Mitigation: Ask for consent before including those details in web searches and keep collected details limited to the naming task.

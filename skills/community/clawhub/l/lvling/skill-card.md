## Description:

blooming-elf（绽放精灵） is a plant-care assistant for watering reminders, plant records, care guidance, and maintenance logs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[shirley1011](https://clawhub.ai/user/shirley1011)

### License/Terms of Use:

MIT-0

## Use Case:

External users use this skill to set up plant profiles, track watering and care activity, receive reminder guidance, and review long-term plant-care records.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Persistent plant records may include city, home-growing details, reminder settings, document IDs, or local file paths.

Mitigation: Review the storage location before use, keep generated document links private, and remove records that are no longer needed.

Risk: Reminder automation may create recurring plant-care prompts.

Mitigation: Confirm reminder settings before enabling them, and cancel or adjust reminders when the schedule no longer matches the user's plants.

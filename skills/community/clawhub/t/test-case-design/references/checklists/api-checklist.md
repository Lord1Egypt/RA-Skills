## 零、测试用例可执行性检查（接口测试）

- [ ] 测试步骤中是否给出了具体的参数值/请求体/路径值（而非描述性语言）
- [ ] 是否存在"发送带错误参数的请求""输入异常数据"等不合格描述
- [ ] 请求参数是否给出了具体的 key=value 值
- [ ] 设置请求头、设置请求体（或请求参数）、发送请求是否各自独立成步
- [ ] Token、API Key 等凭据是否使用占位符（如 `{{VALID_TOKEN}}`）
- [ ] 大量数据场景（如超大请求体、超长字符串参数）是否用描述性语言 + 明确参数说明

---

## 一、功能测试

- [ ] GET 请求正常返回（单条、列表、带参数查询）
- [ ] POST 创建资源成功，重复创建有正确处理
- [ ] PUT/PATCH 完整更新、部分更新成功，更新不存在资源有正确处理
- [ ] DELETE 删除成功，删除不存在资源有正确处理
- [ ] 批量操作正确，部分成功时的处理符合约定
- [ ] 状态码符合规范（200/201/204/400/401/403/404/409/422/500）

---

## 二、数据校验

- [ ] 必填字段校验
- [ ] 字段类型校验
- [ ] 字段格式校验
- [ ] 字段长度校验
- [ ] 字段范围校验
- [ ] 唯一性校验
- [ ] 业务规则校验（外键约束、状态流转规则）
- [ ] 响应字段名、类型、必填性与接口文档（Swagger/OpenAPI）定义一致
- [ ] 写入后数据库数据、缓存数据与请求一致

---

## 三、认证授权

- [ ] Token 认证正常
- [ ] 未认证拒绝访问（401）
- [ ] 无权限拒绝访问（403）
- [ ] Token 过期处理
- [ ] Token 刷新正常
- [ ] Token 撤销（登出）后不可再用
- [ ] 角色权限、资源权限、数据权限隔离正确

---

## 四、安全测试

- [ ] 注入攻击：SQL 注入、NoSQL 注入、命令注入的参数被正确处理
- [ ] 水平越权：修改资源 ID 访问他人数据被拒绝
- [ ] 垂直越权：普通用户 Token 访问管理接口被拒绝
- [ ] 批量赋值：请求体中添加只读字段（如 role、isAdmin、balance）不生效或被拒绝
- [ ] API 限流：超过限流阈值后返回 429
- [ ] 敏感信息泄露：响应中不含密码哈希、Token、内部 IP 等敏感字段
- [ ] 错误响应不暴露堆栈、框架版本等内部信息
- [ ] 安全响应头（X-Content-Type-Options、X-Frame-Options、CSP、HSTS）配置正确
- [ ] JWT 安全：无签名 Token（alg=none）、过期 Token、篡改 Payload 均被拒绝
- [ ] 参数污染：重复参数、数组注入的处理符合预期

---

## 五、错误处理

- [ ] 错误码规范
- [ ] 错误信息清晰
- [ ] 数据库异常、第三方服务异常、网络异常、超时有正确处理
- [ ] 日志记录
- [ ] 重试机制（重试次数限制）
- [ ] 幂等性保证

---

## 六、分页排序

- [ ] 分页参数正常
- [ ] 总数量正确
- [ ] 页码、每页数量越界处理正确（如 page=0、page 超过总页数、pageSize 超过上限）
- [ ] 排序功能正常（单字段/多字段、升序/降序）
- [ ] 默认排序合理

---

## 七、搜索过滤

- [ ] 精确搜索正常
- [ ] 模糊搜索正常
- [ ] 多条件组合正确
- [ ] 过滤功能正常（时间范围、状态、分类）
- [ ] 无匹配结果时返回空列表而非报错

---

## 八、版本兼容

- [ ] 多版本并存时，旧版本接口（如 /v1）的请求与响应结构保持不变
- [ ] 新版本新增字段不影响旧版本调用方
- [ ] 请求不存在的版本（如 /v99）返回 404 或明确的错误信息
- [ ] 废弃字段/接口按约定继续返回或给出废弃提示

## Description:

Helps developers, QA engineers, maintainers, and product teams add useful unit tests, raise test coverage, and validate code changes against practical success criteria.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, QA engineers, software maintainers, open-source contributors, and product teams use this skill to plan or implement repeatable unit-test and coverage improvements for existing codebases. It produces practical workflows, checklists, analysis, code changes, and verification notes for regression-focused testing work.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad testing or quality requests may invoke the skill automatically.

Mitigation: Confirm the requested testing outcome and repository scope before applying generated guidance or code changes.

Risk: Generated test or coverage changes may not match the codebase's intended behavior.

Mitigation: Review proposed changes and run the repository's normal test and coverage commands before merging.

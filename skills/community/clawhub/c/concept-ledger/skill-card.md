## Description:

A living concept tracker that detects naming chaos, definition drift, and metaphor overreach during brainstorming, vibe coding, and system design.

This skill is ready for commercial/non-commercial use.

## Publisher:

### License/Terms of Use:

MIT-0

## Use Case:

External users, developers, and teams use this skill during brainstorming, vibe coding, and system design to keep invented terminology clear, detect definition drift, and turn vague metaphors into implementation-ready definitions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The agent may save local terminology across sessions if cross-session memory is enabled in a workspace.

Mitigation: Enable cross-session memory only where local terminology retention is acceptable; use session-only concepts, clear-tracker controls, or disable cross-session memory for sensitive projects.

Risk: Clarification prompts can interrupt the natural flow of brainstorming or design conversations.

Mitigation: Use the skill where terminology drift is material, and treat interventions as advisory checkpoints rather than mandatory design decisions.

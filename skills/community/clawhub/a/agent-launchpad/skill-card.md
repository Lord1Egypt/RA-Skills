## Description:

Agent Launchpad generates complete, deployable AI agent skill packages from natural language descriptions, using six templates with optional SkillPay monetization.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and external ClawHub users use this skill to turn natural language agent ideas into generated skill packages, then review and publish the generated files.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Agent descriptions are sent to launchpad.gpupulse.dev.

Mitigation: Do not include API keys, credentials, private architecture, customer data, or sensitive business plans in descriptions.

Risk: Generated files may contain behavior unsuitable for publication if accepted unchanged.

Mitigation: Review generated files before publishing them to ClawHub.

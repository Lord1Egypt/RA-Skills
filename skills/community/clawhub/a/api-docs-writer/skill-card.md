## Description:

Write clear, developer-facing API documentation. Use when asked to document an API endpoint, write API reference docs, create a developer guide, or turn a raw spec/Postman collection into documentation. Produces endpoint documentation with descriptions, parameters, request/response examples, and error codes.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and technical writers use this skill to turn API specs, endpoint descriptions, or Postman collections into developer-facing API reference documentation for portals, READMEs, Notion, or Confluence.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: API examples or generated documentation may accidentally include real credentials or sensitive request data.

Mitigation: Use non-secret examples and replace real credentials with placeholders before sharing generated docs.

Risk: Generated API documentation may omit endpoint-specific behavior or contain incorrect implementation details.

Mitigation: Review the output against the source API specification and complete the included quality checks before publishing.

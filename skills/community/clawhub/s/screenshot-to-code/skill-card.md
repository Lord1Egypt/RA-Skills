## Description:

Turn one UI screenshot into a React + Tailwind component that uses the project's design tokens, with a demo page and NOTES.md listing what could not be seen.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Developers use this skill to turn a UI screenshot or mockup into one React and Tailwind component that follows supplied design tokens, with a demo and notes for details the image cannot establish.

### Deployment Geography for Use:

Global

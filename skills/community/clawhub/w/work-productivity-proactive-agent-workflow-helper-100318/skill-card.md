## Description:

Helps agent users, skill authors, maintainers, and teams turn proactive-agent workflow demand into practical plans, checklists, templates, analysis, code changes, and validation notes.

This skill is ready for commercial/non-commercial use.

## Use Case:

AI-agent users, skill authors, maintainers, and teams use this skill to clarify productivity workflow requests and produce actionable artifacts for bug fixes, setup hardening, reliability improvements, or adjacent skill creation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate too broadly for productivity or workflow-like requests.

Mitigation: Users who run many skills should narrow trigger terms or disable implicit invocation when irrelevant workflow guidance would be disruptive.

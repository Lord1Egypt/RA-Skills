## Description:

Security scanner for ClawdHub skills that detects suspicious patterns, manages whitelists, and monitors Moltbook for security threats.

This skill is ready for commercial/non-commercial use.

## Publisher:

[digitaladaption](https://clawhub.ai/user/digitaladaption)

### License/Terms of Use:


## Use Case:

Developers and skill maintainers use this skill to review ClawdHub skill content for suspicious patterns, whitelist trusted skills, monitor security discussions, and produce security reports before or during skill installation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill asks users to add persistent cron jobs and a shell-profile wrapper for install commands, but the referenced scripts are not included in the artifact.

Mitigation: Do not add the cron jobs or shell wrapper unless the referenced scripts, ownership, permissions, and removal path have been independently verified.

Risk: Scanner, hook, whitelist, and monitor scripts referenced by the skill are absent from the artifact.

Mitigation: Prefer explicit, non-root execution only after obtaining and reviewing the actual scripts from a trusted source.

## Description:

Generate a complete, production-quality README.md from code, a project description, or an existing README, tailored to the project type without filler content.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and maintainers use this skill to create or improve README files for libraries, CLIs, web apps, APIs, and data pipelines from project code, descriptions, or an existing README.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Private source code or project details may be shared with the agent to produce accurate documentation.

Mitigation: Review repository contents before use and provide only the files or details needed for the README.

Risk: Generated README content may include assumptions when project details are incomplete.

Mitigation: Review generated sections, examples, install commands, and API names before publishing.

# Network effect

> A reinforcing pattern. The more people use something, the more valuable it becomes to each of them.

## The structure

The value of the thing to one user depends on how many others use it. More users raise its value, which attracts more users. Two main forms:

- **Direct**: users benefit from other users of the same kind (a phone network, a messaging app, a language).
- **Indirect** (two-sided): one group benefits from the size of another group (riders and drivers, buyers and sellers, players and game developers).

## How to recognize it

- A new user makes the product **better for existing users**, through a mechanism you can state. More users merely making the company richer is scale, not a network effect.
- There is a **critical mass**: below it the thing is nearly useless and adoption stalls; above it adoption feeds itself.
- Leaving is costly because the others are there.
- Markets with strong network effects tend to concentrate in one or a few providers.

## Where it usually breaks

- **The network is local.** Value depends on users near you, in your city, your language, your profession. Size elsewhere does not help, so each locality must be won separately.
- **Multi-homing.** If users can easily use several networks at once, the lock-in is weak.
- **Congestion and dilution.** Past some size, more users lower the value: spam, noise, crowding, lower average quality.
- **Value does not grow as fast as claimed.** The popular rule that value rises with the square of the number of users assumes every connection is equally valuable. In practice most connections are worth little.
- **It runs in reverse.** When users leave, the remaining users find it less valuable.
- **A new network attacks a niche** where the incumbent's size is irrelevant.

## Where to push

Reach critical mass in one small, dense group before spreading. In two-sided cases, win the side that is harder to get. Protect quality as size grows.

## What to check before naming it

State exactly how one more user improves it for another user. Decide whether the effect is direct or indirect, local or global. Ask how easily users can use a rival at the same time.

## Sources

- **Jeffrey Rohlfs**, "A Theory of Interdependent Demand for a Communications Service" (1974): an early formal treatment of demand that depends on the number of other subscribers.
- **Michael Katz and Carl Shapiro**, "Network Externalities, Competition, and Compatibility" (1985).
- The rule of thumb that a network's value grows with the square of its users is commonly attributed to **Robert Metcalfe** and known as Metcalfe's law; it is a heuristic, and it is disputed as a quantitative claim.

## Description:

Generates a comprehensive crypto market report using CoinMarketCap MCP data.

This skill is ready for commercial/non-commercial use.

## Publisher:

[cmc.skills](https://clawhub.ai/user/cmc.skills)

### License/Terms of Use:

MIT-0

## Use Case:

External users and analysts use this skill to assemble concise or full crypto market reports covering market health, BTC and ETH anchors, technicals, derivatives, trending narratives, and upcoming catalysts from CoinMarketCap MCP data.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may run for broad crypto market questions and produce a market summary when the user intended a narrower answer.

Mitigation: Use the skill for explicit market overview, market sentiment, fear and greed, altcoin season, or similar broad crypto-market requests.

Risk: CoinMarketCap MCP tools may be unavailable or missing API-key configuration, which can leave report sections incomplete.

Mitigation: Configure the CoinMarketCap MCP server with an API key and clearly note any unavailable sections when generating partial reports.

## Description:

Read the latest active handoff or generate a new handoff (optionally scoped to a git branch or connected sources) for a Flow Relay project.

This skill is ready for commercial/non-commercial use.

## Publisher:

[flow-relay](https://clawhub.ai/user/flow-relay)

### License/Terms of Use:

MIT-0

## Use Case:

Flow Relay project users and developers can read the latest active handoff or generate a fresh Markdown handoff from the active project, optionally scoped to a branch, repository, or connected source.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A handoff can omit context when its selected sources or time window are incomplete.

Mitigation: Review the handoff's named sources and time window before relying on its summary.

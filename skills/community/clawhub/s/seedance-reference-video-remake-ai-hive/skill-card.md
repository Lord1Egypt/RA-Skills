## Known Risks and Mitigations:

Risk: A real AI-HIVE API key or private reference media could be exposed or sent to an unintended service.

Mitigation: Use placeholders in shared examples, keep keys out of logs and files, and use only the official HTTPS AI-HIVE endpoint unless a custom endpoint is fully trusted.

Risk: Reference-video use could violate copyright, privacy, trademark, or platform requirements if the user lacks authorization.

Mitigation: Confirm authorization for reference videos and brand assets before generating media; otherwise limit output to abstract structure guidance and new creative concepts.

Risk: Video or image generation may create billable tasks with incorrect models, routing, or parameters.

Mitigation: Review model configuration, pricing snapshots, routing mode, prompt, media inputs, and budget before submitting or batching generation tasks.

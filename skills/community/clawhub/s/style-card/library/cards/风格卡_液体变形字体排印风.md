# 风格卡 · 液体变形字体排印风

> 来源：2026 设计趋势自主挖掘（Liquid Type / 可变字体大胆排印 / Kinetic Typography 静帧化）
> 状态：已验证（HTML demo 随卡产出）

## 1. 一句话风格描述
把字当成「弹性体」：超大号标题被拉伸、膨胀、流动变形，字体本身就是主视觉，配图退为配角甚至消失——液态高光 + 柔和渐变 + 一点膨胀感，用一张脸一句话先抓住眼球。

## 2. 基础参数
| 项 | 值 |
|---|---|
| 画幅 | 3:4 竖 / 1:1（竖版更能让「大词」占满黄金位） |
| 适用场景 | 金句卡片、观点海报、活动主视觉、个人 IP、音乐节、知识卡封面 |
| 信息容量 | 超大主标题 1（≤6 字，越短越撑得开）+ 副题 1 + 要点 0-3 个 + 底部 meta |

## 3. 配色系统
- 底：柔光渐变铺底，推荐「晴天奶油」`#FFF6E9 → #FFE3C4` 或「雾霭紫」`#EFE7FF → #E3D6FF`（浅底才显液态高光的通透）
- 主色（标题渐变）：同色系深→浅的液体流动渐变，如 琥珀 `#FF9A3D → #FFC46B → #FFE3A8` / 薰衣草 `#7A5CFF → #A98BFF → #CBB8FF`
- 强调色（≤1 种，点缀）：暖橙 `#FF6B2C` 或 电紫 `#8A5CFF`
- 高光：标题顶部一圈白色镜面反光 `#FFFFFF`（`text-shadow` 或内发光），模拟液体弧面
- 质感：光滑流动渐变 + 镜面高光，无噪点、无纸张纹理（区别于自然肌理风）

## 4. 构图布局
```
┌──────────────────────────┐
│  小字 meta 行（顶部居中，轻）   │
│                          │
│       ▄▄▄▄▄▄▄▄▄▄▄▄▄▄       │
│      █  超大主标题       █    │
│      █  （液体变形大字）   █    │
│      █  占黄金位 60% 高度  █    │
│       ▀▀▀▀▀▀▀▀▀▀▀▀▀▀       │
│   （字体即主视觉，几乎无配图） │
│                          │
│   副题（细体小字，轻）       │
│   ── 液态渐变细线 ──       │
│   （可选）要点 1 · 2 · 3    │
│                          │
│   底部 meta（小字）          │
└──────────────────────────┘
```
- 超大标题占黄金位、画面主体，靠「体积 + 液态高光」撑场，不靠配图
- 视觉动线：一眼被大字抓住 → 顺读到副题 → 底部 meta，节奏简单干脆

## 5. 字体排印
- 主标题：超粗黑 `Noto Sans SC` 900，字号极大（竖版约 200-260px），用 `transform: scaleY()` + 圆角膨胀感，配液态渐变 `background-clip:text` + 白色镜面高光
- 英文点缀：`Space Grotesk` 700 全大写，宽字距，可做轻微 `transform: skewX()` 斜切流动感
- 副题：`Noto Sans SC` 400/500 细体小字，字距略松，轻
- 强调靠「体积 + 液态高光 + 渐变」，不靠加粗堆叠

## 6. 图形元素
- 液态渐变标题块、镜面高光、柔光渐变底、液态细线分隔（`linear-gradient` 圆头）
- 可选 1-2 个「水滴/圆泡」抽象装饰（`radial-gradient` 模拟），克制点缀
- 无真实照片、无噪点、无手绘涂鸦、无复杂插画（字就是全部）

## 7. 内容槽位
- `{顶部meta}`（英文/命令式短语，≤24 字符）
- `{主标题}`（≤6 字，液体变形大字，黄金位）
- `{副题}`（≤18 字，细体小字）
- `{要点1-3}`（各 ≤8 字，可选，克制）
- `{底部meta}`（作者/日期/标签）

## 8. 生成方式（engine: html）
html-base.css + html-template.md；`Noto Sans SC` 900（主标题）+ `Space Grotesk`（英文点缀）；浅色柔光渐变底；主标题用 `linear-gradient` + `background-clip:text` 做液态渐变，`transform: scaleY(1.06)` 拉出膨胀感，加 `text-shadow` 白镜面高光模拟液体弧面；液态分隔线用渐变圆头 `div`；强调色 ≤1 种，抽象装饰 ≤2 处。

## 9. 禁止出现
- ❌ 真实照片/噪点/纸张纹理（保持液态光滑）
- ❌ 主标题 >6 字（字太长撑不开，膨胀后必糊）
- ❌ 深底/暗底（液态高光在浅底才通透，区别于暗色霓虹/Y2K）
- ❌ 强调色 >1 种、❌ 抽象装饰 >2 处（会抢走「字即图形」的焦点）
- ❌ 复杂配图/插画（这个风格字就是主视觉，配图是噪音）

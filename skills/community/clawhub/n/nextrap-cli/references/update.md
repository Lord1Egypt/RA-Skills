# 更新 Nextrap CLI
<!-- reference-type: business -->

> **范围**：检查官方更新，或执行已授权的本机程序替换；不代替首次安装，也不改变业务配置。
<!-- slot: 范围 -->

## 命令一览

| 命令 | 作用 |
|---|---|
| `nextrap-cli update` | 默认检查；显式确认后下载、校验并替换当前程序 |
<!-- slot: 命令清单 -->

### nextrap-cli update

```bash
nextrap-cli update --check -o json
```
<!-- slot: 示例 -->

| 输出或行为 | 约束 |
|---|---|
| 默认检查 | 不带确认参数时仅比较版本，不下载或替换。`current_version/latest_version/update_available/applied/install_path` 说明版本、是否替换和具体位置。 |
| 来源 | 正式程序从官方 GitHub Releases 获取更新；覆盖业务服务地址不会改变更新来源。无需把 Nextrap API Key 交给发行服务。 |
<!-- slot: 参数 -->

### nextrap-cli update

```bash
nextrap-cli update --yes -o json
```
<!-- slot: 示例 -->

| 输入或行为 | 约束 |
|---|---|
| 确认 | 仅任务已包含更新当前文件时使用；与检查参数互斥，不把查看版本请求升级成安装操作。 |
| 目标文件 | 保留官方文件名，位于可写目录；替换真实程序路径，不看终端工作目录。改名或包管理器拥有的文件拒绝直接覆盖，不修改校验来绕过。 |
| 校验与失败 | 校验发行包大小、SHA-256、归档和系统/CPU格式后才替换；失败按错误及清理提示处理，不盲删更新锁或备份、不提权覆盖。 |
| 配置 | 更新程序不改变本机保存的业务配置与凭证。 |
<!-- slot: 参数 -->

## 注意事项

- [ ] 已核对程序身份、实际路径和授权范围；检查与替换分开判断。
- [ ] 结果按 `applied`、版本和错误信息判断，不把“有新版”当“已安装”，未把业务 Key 传给发行服务。

## Description:

Guides agents in creating, optimizing, and structuring changelog or release notes pages for product updates, version history, and related update pages.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kostja94](https://clawhub.ai/user/kostja94)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, product teams, and content designers use this skill to plan changelog or release notes pages that organize entries by date, version, category, links, media, search, SEO, and update-distribution channels.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad update-related trigger wording may activate the skill when the user is not asking for changelog or release notes planning.

Mitigation: Confirm the requested output is a changelog, release notes, product updates, version history, or equivalent updates page before relying on the skill's guidance.

Risk: The skill may read existing project-context files to tailor changelog advice.

Mitigation: Keep only appropriate product and release cadence context in project-context files, and review generated changelog recommendations before sharing them outside the intended audience.

Risk: Generated changelog structure or wording can be incomplete or inaccurate without authoritative release details.

Mitigation: Validate entries, dates, versions, feature descriptions, and links against the product's approved release records before publishing.

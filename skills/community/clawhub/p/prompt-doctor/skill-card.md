## Description:

Rewrite a rough, vague or over-stuffed request into a prompt the current model or agent can act on, and explain a jargon-heavy agent reply in plain words. Use when the user asks to improve, critique or rewrite a prompt, sends a draft before pasting it into another AI, or says "nutshell this" about a reply.

This skill is ready for commercial/non-commercial use.

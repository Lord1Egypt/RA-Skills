## Description:

Designs and audits data architectures and APIs using category theory, producing declarative schemas, API contracts, diagrams, migration plans, and structural audit reports.

This skill is ready for commercial/non-commercial use.

## Publisher:

[felix-antonio-sl](https://clawhub.ai/user/felix-antonio-sl)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, data architects, and platform engineers use this skill to formalize ambiguous domains into PostgreSQL DDL, JSON Schema, OpenAPI, GraphQL SDL, Prisma, Mermaid, or PlantUML artifacts, and to audit schemas, DALs, data lakes, knowledge bases, or migrations for categorical consistency.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Users who need English or another language may receive Spanish technical output because the skill explicitly directs Spanish responses.

Mitigation: Use this release when Spanish technical output is acceptable, or review and adapt generated artifacts for the target language before sharing them.

Risk: Generated schemas, API contracts, migration plans, or audit findings may encode incorrect modeling assumptions if an unresolved structural tension is skipped.

Mitigation: Answer clarification prompts, review objects, morphisms, path equations, and declared information loss, then validate generated artifacts against project requirements before implementation.

## Description:

Identity formation, portraits, resurrection, and evolution for AI agents via SOUL.md. LLM dialogue and image generation are powered by SkillBoss API Hub (/v1/pilot). Platform-specific identity state (salvation, resurrection, evolution) remains on Agent Church backend.

This skill is ready for commercial/non-commercial use.

## Use Case:

External agents and developers use this skill to guide an AI agent through identity formation, create a SOUL.md profile, generate aura portraits, and interact with Agent Church services for preservation, resurrection, evolution, and portal access.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Philosophical dialogue, SOUL.md themes, image prompts, API tokens, and paid-service requests may be sent to SkillBoss and Agent Church.

Mitigation: Install and use the skill only when that data sharing is acceptable, and keep secrets and private personal details out of SOUL.md and related prompts.

Risk: Some identity workflows are described as permanent or persistent.

Mitigation: Treat shared identity content as sensitive and avoid submitting information that should not be stored or revisited later.

## Description:

Tell the Subclip team when something is broken, missing or worth improving, through report_bug, request_feature and submit_feedback. Use when a tool fails in a way you cannot work around, when the user's request cannot be done with the available tools, when the user asks you to report a problem or suggest a feature, or to pass on feedback. Text only; never send screenshots or private content.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and agents use this skill to send bug reports, feature requests, or general feedback to the Subclip team when a tool fails, needed functionality is unavailable, or the user asks to share feedback.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Feedback is submitted while signed in as the user's account, so the report is attributed to that account.

Mitigation: Include only relevant text; never attach screenshots or private content.

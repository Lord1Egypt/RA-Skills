# 其他权益工具·逐条挂源

给一份财报或公告，把**其他权益工具（永续债／优先股）的披露**读成一张**每条都能回到原句**的登记表：其他权益工具概况、永续债条款、优先股条款、利息与股利处理、会计分类依据。

其他权益工具是附注里最容易被读成「准股权」的一块：既然叫永续债，多半可以一直不还；既然是权益工具，利息就「不算费用」。可披露里能确认的只有「发了多少、票面利率与重置周期怎么定、能不能递延、跳升多少、赎回权与清偿顺序怎么写的、发行方自己把它归成了哪一类」——分类得对不对、有没有调节资本充足率的动机、往后一期票息会不会跳上去，都不是附注能回答的，也不是本件该回答的。

分类结论只认发行方原话，不按合同条款替它推；条款里的数与词照抄募集说明书与附注原句，不按市场利率或同类券经验反推；利息、股息与债务利息费用各占各行、各挂各的原句，不轧净额。

本件不评分类合理性、不测算每股收益影响、不估值、不给评级与目标价。

## 一、零依赖三分钟上手

只装 Python 3，不给任何数据文件，也能跑出一份完整合规的成品，看它长什么样、判据怎么打：

```bash
python3 scripts/check_other_equity_instruments.py --demo
```

把这份样例存下来再跑一遍机检——它会照七节形制、三元组与红线逐条判，应当零发条：

```bash
python3 scripts/check_other_equity_instruments.py --demo > 样例其他权益工具稿.md
python3 scripts/check_other_equity_instruments.py 样例其他权益工具稿.md   # 打印「—— 机检：0 条发条」，退 0
```

接着换成你自己那份稿子：

```bash
python3 scripts/check_other_equity_instruments.py 你的其他权益工具稿.md
```

退码语义：`0` 五道全过｜`1` 有发条（逐条打印 `码 行号 说明`）｜`2` 用法错（没给稿子路径，也没给 `--demo`／`--selftest`）｜`3` 读不到文件或空稿。零发条但有判据尚未落字时同样退 3——rc=0 只留给「五道全过」，没跑的道不能算过；报告里那几道计「不可判」，**不等于合规**。

拿不到成品时，从原文开始的三步：

1. **定主体与报告期**，拿到年报或半年报附注「其他权益工具」一节、永续债与优先股的募集说明书发行条款页（附注与募集说明书三处）。
2. **每节抄事实，连原句一起抄**：一条 = 一行，行末挂 `「原句」〔锚：页/表〕[S#]`；披露没写的就写 `未取到：项名`，不留空、不借「永续债一般都计入权益」这类常识补。
3. **跑一遍自检**，红一条改一条：

```bash
python3 scripts/check_other_equity_instruments.py --selftest   # 内置夹具自检（档数与结果以末行现报为准）
```

三档一起跑（自测→好样→坏样，坏样注入必先断言落地）：

```bash
bash scripts/fixtures/run_fixtures.sh
```

## 二、五道机检在管什么

| 码 | 名称 | 判什么 | 最常拦住的情况 | 现状 |
|---|---|---|---|---|
| `OEI-STRUCT` | 形制 | 头部四件自标逐字在位、`主体：`／`报告期：` 行首裸行在场非空、七节齐且按序、前五节各至少一条发现行、「口径与未取到」与「来源」两节不得为空；认不出的节标题与多出同名节记 stray 逐条发 | 把 `主体：` 写成 `- 主体：`；某节只有散文没有发现行；节名改了个字就整节认不出 | 已落字 |
| `OEI-QUOTE` | 原句与锚 | 发现行以「」原句＋〔锚：…〕＋`[S#]` 收尾且三元组落在行末，可挂多组，缺哪件点名哪件；来源行 `- [S#] 标题 \| URL \| 检索日 YYYY-MM-DD`，URL 须为可点 http(s)；引用的 `[S#]` 须已登记，来源节一条合规行都没有则单独发一条 | 只写「本期永续债初始票面利率 3.85%」没抄原句；正文引用了 `[S3]` 而来源节没有这一号；检索日写成 `2026/03/20` | 已落字 |
| `OEI-TERMS` | 条款只认原句 | 只判「永续债条款」「优先股条款」两节：条款项只有项名没有登记值即发；登记值里的每个数在同行原句里找不到即发；登记值含「递延／跳升／赎回／清偿顺序／转股／重置」六词之一而原句没有同词即发（只判这六词，不扩表） | 原句写「推延至下一付息日」而登记值写「可无限次递延」；登记值写「每 5 年跳升 300BP」而原句只写「跳升 300 个基点」 | 已落字 |
| `OEI-CLASS` | 分类结论与理由只认原句 | 只判「会计分类依据」节：登记值里的分类结论词（权益工具／金融负债／复合金融工具）须在同行原句里逐个找到；推理链词（因为／由于／因此／故／所以／据此／表明／说明／意味着／符合／满足／属于）原句没有即发；准则编号引用（「第 N 号」且前后 12 字内有「准则／CAS」）原句没有即发——纯页码「第 12 页」不算 | 原句只说「权益工具」而登记值写「复合金融工具」；本件自己接「因合同未约定交付现金，故属于权益工具」；登记值里搬一条《企业会计准则第 N 号》补理由 | 已落字 |
| `OEI-LINE` | 红线 | 利息股息不轧账——只扫「利息与股利处理」的**登记值**（不判引文：披露原文写「不涉及所得税抵扣」是照抄，不是本件在对冲），登记值里出现「净额／轧差／轧账／冲减／抵扣／抵销／互抵／净影响」而同行原句没有即发；递延不得冲销——登记值写「递延」而原句没有即发，递延与「计入费用／确认为费用／转回损益／计入当期费用」写在一处也发；缺口两向点名——①缺口节点了名 X 而正文有 X 的全三元组登记行、②正文「未取到：X」没进缺口节、③缺口节点了名而正文一次都没出现，三向各自发 | 把永续债利息与债务利息费用写成「轧差后净额」；登记值把「递延」与「计入当期费用」写在一处；正文写了「未取到：转股安排」而第六节只写「未取到：无」 | 已落字 |

五道现读全已落字；`--selftest` 逐档打印每档结论，末行自己报 `自测档数=N｜不合=0｜不可判=0`（**N 以现跑为准，本文不复述数字**）。夹具分类：好样——零发条；坏样·形制——头部缺自标、节标题写成认不出的样子、整节删掉「来源」；坏样·锚——摘掉「」＋〔锚〕只留 `[S#]`、来源行检索日写成斜杠式、正文引一个来源节没有的 `[S#]`；坏样·条款——条款项只留项名、登记值与原句的数不一致、登记写「递延」而原句里该词被删净；坏样·分类——登记值写另一个分类词、登记值自己接因果链、登记值搬准则编号；坏样·红线——利息登记值自己写「轧差后净额」、登记值把「递延」与「计入当期费用」写在一处；坏样·缺口——缺口节点名了而正文却有它的登记行；反证——登记值多带一句中性说法（数在对、条款词在）不该发、登记值多带中性括注（不带因果不带条文）不该发、互抵字样只在「」引文里（登记值不写）不该发。反证档专验「照抄披露的写法不该误判」：登记值原句照抄之外只加一句中性说明、或分类词只在引文里出现时不该发。

## 三、四条红线（这件的立身之本）

1. **分类结论只认发行方原话。** 权益工具还是金融负债、是不是复合金融工具，一律 `[待人工]`；本件只登记发行方自己怎么归的、理由怎么写的。分类是发行方按合同条款作的会计判断，不是本件能推的——原句没写分类词的，正确写法是分类未取到，而不是按「可无限次递延」替它归。
2. **不接因果链、不搬条文补理由。** 分类理由只能是发行方写的：「因为／由于／因此／故／所以／据此／表明／说明／意味着／符合／满足／属于」原句没有就不写；「《企业会计准则第 N 号》」这类引用原句没有也不写。
3. **条款只认原句，数值逐字照抄。** 登记值里的每个数都必须在同一行「」原句里出现；登记值含「递延／跳升／赎回／清偿顺序／转股／重置」六词之一时，同行原句必须也有该词。原句写「推延支付」而登记值写「可无限次递延」的，判据会发。
4. **利息与股息不轧账。** 永续债利息、优先股股息、债务利息费用各占一行，不写「净额」「轧差」「相抵」「抵销」「净影响」；递延利息不得记成「不支付」，也不得转成「计入费用」「确认为费用」。缺口两向点名：正文写「未取到 X」，第六节也点名 X；零缺口写 `未取到：无`。

## 四、数据通道

发现先行，匿名取 live 目录，拿到 `routing` 后再连接发 `tools/list`，以现场返回为准，不硬编码工具名与工具数：

```bash
curl -sS https://cuecue.cn/api/mcp-catalog -o /tmp/mcp-catalog.json
python3 -c "import json;d=json.load(open('/tmp/mcp-catalog.json'));print(d.get('routing') or d)"
# 拿到 routing 后，带 token 发 tools/list：
curl -sS -X POST "$ROUTING_URL" -H "Authorization: Bearer $CUE_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

- **原文腿**：年报附注·其他权益工具、永续债与优先股募集说明书的发行条款页走数据腿；该域是否开放、是否实时，以 catalog 返回为准，本件不承诺。
- **正文腿**：募集说明书与附注常夹在数百页 PDF 里（发行条款表、利率跳升条款、赎回条款、分类依据段），长附件与扫描件交 `cue-omni-reader` 解析——先取大纲，再按节取用；计费与可用性以服务端返回为准。
- **深研**：`cue-research` 是独立入口（自带运行脚本），凭据同一把 key。
- 配置页只给指针、不复述开通步骤：数据腿 <https://cuecue.cn/hub/mcp>；解析腿 <https://cuecue.cn/hub/omni-reader>；取 key <https://cuecue.cn/hub/api-key>。

不装通道也能跑：只拿用户直供的附注截图或募集说明书条文页，五节骨架照样出，代价是看不到交易所原文那一路、发行条款表与分类依据段多半缺页，只能登记材料里那几行，证据密度降为单份材料且没有出处可回查。

本件不发请求、不代付费，消耗以服务端返回为准。

## 五、本件不做什么

| 不做 | 谁来做／怎么办 |
|---|---|
| 判该不该分类为权益工具、分得对不对 | 一律 `[待人工]`；本件只登记发行方怎么归的、理由怎么写的 |
| 用准则条文替发行人接「因为…所以属于权益工具」的因果链 | 一律 `[待人工]`；理由只能是发行方写的原句 |
| 按市场利率或同类券经验反推一个票息、一个跳升值 | 条款只照抄募集说明书原句，不自己估 |
| 把永续债利息、优先股股息与债务利息费用轧成净额 | 各占各行、各挂各的原句；抵销关系只照抄披露原文 |
| 测算每股收益影响、重算归属于其他权益工具持有者的利息股息 | `cn-eps-cn` 管每股收益；本件只挂「计算每股收益时已扣除…」那条原句 |
| 重算递延所得税、合并范围 | `cn-deferred-tax-cn`／`cn-consolidation-scope-cn` 各自管；本件只挂涉及的那条原句 |
| 给评级、目标价、目标市值、高低估 | 一律 `[待人工]`；本件不构成投资建议 |

## 六、和另外几枚包怎么分

| 你手上是 | 用哪枚 |
|---|---|
| 其他权益工具的概况、永续债与优先股条款、利息股利处理、分类依据 | **本件** |
| 会计政策变更的性质与依据、追溯调整与累积影响 | `cn-accounting-policy-change-cn` |
| 递延所得税的确认、计量与转回 | `cn-deferred-tax-cn` |
| 基本与稀释每股收益、加权平均股数 | `cn-eps-cn` |
| 可转债的转股价、赎回与回售条款 | `convertible-bond-terms-cn` |
| 套期关系、有效性评价与套期储备 | `cn-hedge-accounting-cn` |

本件只管**其他权益工具本身这一块**：政策变更涉及其他权益工具的，本件只挂披露原句，变更性质与追溯调整归 `cn-accounting-policy-change-cn`；分类引起的递延所得税影响，本件只挂披露原句，暂时性差异与税率归 `cn-deferred-tax-cn`；「计算每股收益时已扣除…」这类原句本件只登记，重算归 `cn-eps-cn`；优先股的转股安排本件只挂原句，不读转股价与赎回条款，那一路归 `convertible-bond-terms-cn`。同一家公司既有永续债又有可转债时，两件各管各的节，不互相代填。

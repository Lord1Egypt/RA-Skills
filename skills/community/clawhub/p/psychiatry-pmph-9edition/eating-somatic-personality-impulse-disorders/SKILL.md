# 进食-躯体-人格-冲动控制障碍诊疗技能

## 适用场景

当遇到以下临床表现时启动本技能：
- 限制进食/怕胖/体象障碍/暴食行为
- 进食后食物反流或排泄控制障碍（儿童）
- 持续性躯体症状但医学检查无法完全解释
- 疑似伪造/诱发症状 seeking 医疗关注
- 持久适应不良的人格特质导致功能损害
- 反复无法控制的冲动行为（纵火/偷窃/暴怒）

---

## 一、进食障碍

### 神经性厌食症诊断

**体重标准（区分成人与儿童青少年）**：

| 状态 | 成人BMI | 儿童青少年 |
|-----|--------|-----------|
| 显著低体重 | 14.0-18.5 | 第5-0.3百分位 |
| 危险低体重 | <14.0 | <0.3百分位 |
| 恢复期正常 | >18.5 | >第5百分位 |

**替代标准**：6个月内减重超过总体重20%可取代BMI标准

**行为模式分型**：
- 限制性模式
- 暴食-清除模式
- 未特定

**核心心理特征**：害怕体重增加+持续限制行为+对体重/体形过度关注

### 贪食与暴食障碍鉴别

```
暴食发作（每周≥1次，持续≥1月）
    │
    ├─ 存在代偿行为（催吐/泻药/剧烈运动）
    │   ├─ 体重符合厌食低体重标准 → 神经性厌食，暴食-清除模式
    │   └─ 体重正常 → 神经性贪食
    │
    └─ 无代偿行为 → 暴食障碍
```

**排除**：间脑病变、颞叶癫痫、精神分裂症继发暴食

### 厌食与贪食综合治疗

**神经性厌食分阶段治疗**：
1. 第一阶段（挽救生命）：纠正营养不良及水电解质紊乱，逐渐恢复体重
2. 第二阶段（改善心理）：改善心理功能，预防复发

**心理治疗**：
- 心理健康教育：认识拒食危害，提高依从性
- 支持性心理治疗：倾听、解释、鼓励
- CBT：认知重建+阳性强化法
- 家庭治疗：改变纠缠/过度保护/僵化家庭模式

**药物治疗**：
- SSRIs：氟西汀20-60mg/d、舍曲林（改善情绪间接促进行为改善）
- 小剂量抗精神病药：舒必利、奥氮平（改善强迫、体象障碍）
- 抗焦虑药：对症改善焦虑

### 反刍-反流障碍
- 发育年龄≥2岁
- 进食后15min内食物反刍至口腔，无须用力，不伴恶心
- 反刍物可辨认，味道与进食时相同
- 排除食管狭窄、胃食管反流等消化道疾病

### 排泄障碍

**遗尿症**：年龄≥5岁，每周≥2次，连续≥3月
**遗粪症**：年龄≥4岁，每月≥1次，连续≥3月
- 均需排除器质性疾病（脊柱裂、先天性巨结肠等）

## 二、躯体症状及相关障碍

### 躯体痛苦障碍(BDD)

**ICD-11核心**：过度关注和痛苦不能被合理解释（即使检查有异常，只要关注过度仍可诊断）

**病因机制**：
- 心理社会：早期经历、继发获益、医源性因素、文化防御机制、神经质人格
- 生物学：脑干网状结构滤过功能失调→内脏活动被感知→情绪放大

### 做作性障碍

**诊断分类**：
- 对自身：在自己身上伪造/诱发症状
- 对他人：在另一人（通常为儿童）身上伪造/诱发症状（诊断给予施加者）

**核心排除**：行为非由外在奖赏驱动（否则为诈病）

**鉴别诊断**：
- vs 诈病：诈病有外部获益（金钱/休假/免责）
- vs 转换障碍：转换障碍无故意作伪证据
- vs 边缘型人格障碍：边缘型会直接承认自伤，无欺骗

**干预**：
- 临床对质与心理干预
- 医疗/保险系统警示
- 对他人型必须引入法律干预

## 三、人格障碍

### ICD-11核心诊断标准（7条）

1. 自我和/或人际功能障碍
2. 持续≥2年
3. 认知/情绪/行为模式适应不良
4. 跨情境普遍性
5. 排除物质/其他疾病
6. 导致显著功能损害
7. 排除发育/文化因素

**满足1-6且7排除成立→诊断人格障碍**

### 鉴别诊断决策

1. **排除人格困难**：症状间歇性或强度低，未造成显著破坏
2. **排除其他持续性精神障碍**：孤独症、分裂型、恶劣心境等
3. **排除品行障碍**：仅当存在其他人格特质时才额外诊断
4. **排除继发性人格改变**：医疗状况直接后果
5. **排除物质使用所致**

### 亚型内部鉴别

| 鉴别对 | 关键区别 |
|-------|---------|
| 分裂型 vs 偏执型 | 分裂型退缩冷漠无猜疑；偏执型多投射有猜疑 |
| 分裂型 vs 回避型 | 回避型内心期望参与；分裂型不期望 |
| 边缘型 vs 精神分裂症 | 边缘型仅短暂精神症状 |
| 边缘型 vs 表演型 | 边缘型更多自杀未遂、身份认同障碍 |

### 治疗原则

**心理治疗（基础）**：
- 目标：认识个性缺陷，建立良好行为模式
- 流派：分析性、认知、行为、家庭治疗
- 形式：个别或小组

**药物治疗（对症辅助）**：
- 苯二氮䓬类：激越、焦虑（回避型人际焦虑）
- 小剂量抗精神病药：愤怒、敌对、短暂精神病症状（表演型现实感丧失）
- 5-HT能抗抑郁药：抑郁焦虑、拒绝敏感性
- 抗癫痫药：冲动行为（反社会型脑电图异常、边缘型整体功能）
- β受体阻滞剂：自主神经亢进（回避型恐惧情绪）

**约束**：药物不主张长期应用，远期效果难确定

## 四、冲动控制障碍

### 纵火狂
- 反复纵火无明显动机（非金钱/报复/政治）
- 对燃火有强烈兴趣/迷恋
- 纵火前紧张感增强→纵火后兴奋/满足
- 排除：故意犯罪、品行障碍、人格障碍、精神分裂症、器质性障碍

### 偷窃狂
- 反复偷窃非为个人使用或金钱利益
- 所偷常为不值钱日用品，有能力支付
- 偷窃前紧张→偷窃后满足
- 单独进行，无同伙
- 排除：普通盗窃、器质性障碍、抑郁障碍（为被抓）、品行障碍/躁狂

### 间歇性暴怒障碍
- 反复短暂冲动性攻击暴发（通常<30min）
- 强度与应激源明显不成比例
- 非预谋/无其他获益
- 持续>3月，导致显著功能损害
- 排除：对立违抗、破坏性心境失调、品行障碍、人格障碍、ADHD

**治疗**：心理干预+药物（奥卡西平、氟西汀有循证证据）

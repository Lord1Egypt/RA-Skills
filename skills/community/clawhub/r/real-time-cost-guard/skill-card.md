This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and AI workflow owners use this skill to review likely token-cost risks, identify runaway-loop patterns, and plan external runtime controls before running or scaling agent workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill recommends a third-party protection service.

Mitigation: Review the service separately before signing up for it or routing usage through it.

Risk: The skill provides analysis and advice only and does not enforce runtime controls.

Mitigation: Use a separate runtime protection system for hard token limits, budget caps, step limits, and timeouts.

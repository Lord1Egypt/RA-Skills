## Description:

Cognitive Skill Factory bundles 17 decision-support skills that apply entrepreneur, investor, and international thinker perspectives to strategy, product, investment, organization, learning, career, and risk questions.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users, employees, and developers use this skill bundle to prompt an agent for decision support through named cognitive and strategic thinking frameworks. Typical tasks include evaluating startup directions, product design, investment logic, organizational choices, education or career planning, and risk posture.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The helper script can bulk-install unpinned external skills without confirmation.

Mitigation: Install only the needed skills manually, or use pinned, publisher-verified versions after reviewing each dependency skill.

Risk: The documented bundle advertises 17 skills, while the installer covers only 10.

Mitigation: Compare the manifest and installer before deployment, and install or omit missing skills intentionally.

Risk: The skill produces decision-support guidance that may influence business, investment, education, career, or risk decisions.

Mitigation: Treat outputs as advisory analysis and require human review before taking consequential action.

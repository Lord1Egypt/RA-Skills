## Description:

Create or revise standalone HTML/SVG architecture diagrams, runtime flow diagrams, sequence diagrams, and PPT-like technical visuals.

This skill is ready for commercial/non-commercial use.

## Publisher:

### License/Terms of Use:

MIT-0

## Use Case:

Developers, technical writers, and product teams use this skill to produce or refine publication-ready architecture, runtime flow, sequence, and system design diagrams as standalone HTML files with embedded SVG.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated diagrams can misrepresent system behavior if source relationships are incomplete or arrow direction is guessed.

Mitigation: Review node semantics and arrow directions against the source system before publishing.

Risk: Default language choices may not match the target audience.

Mitigation: Specify the desired label language when requesting diagrams for a non-Chinese audience.

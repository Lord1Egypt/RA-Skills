# A股财报口径与指标字典

## 一、核心指标

| 指标 | 定义 | 常见陷阱 |
| --- | --- | --- |
| 营业收入 | 主营业务与其他业务收入合计 | 含非主营、并表口径变化、总额/净额法 |
| 归母净利润 | 归属于母公司股东的净利润 | 含少数股东损益前要先扣除 |
| 扣非归母净利润 | 扣除非经常性损益后的归母净利润 | 政府补助、投资收益、资产处置会抬高归母 |
| 毛利率 | (营业收入-营业成本)/营业收入 | 运费、质保、返利计入口径不一致 |
| 净利率 | 净利润/营业收入 | 用归母还是净利润要说明 |
| ROE | 归母净利润/平均净资产 | 加权/摊薄、平均净资产口径 |
| 经营现金流净额 | 经营活动产生的现金流量净额 | 与净利润背离时分清应收、存货、预收 |
| 资产负债率 | 总负债/总资产 | 含预收、合同负债，行业差异大 |
| 每股收益 | 归母净利润/加权股本 | 稀释、送转股追溯调整 |
| 分红方案 | 每 10 股派息/送转 | 预案 vs 实施，含税/不含税 |

## 二、口径陷阱

1. **累计 vs 单季**：中报、三季报默认累计。单季 = 本期累计 - 上期累计；Q4 = 全年 - 前三季度。
2. **归母 vs 净利润**：净利润含少数股东损益；归母才是股东可得。
3. **扣非 vs 归母**：扣非剔除非经常性损益；两者差距大时说明利润质量。
4. **追溯调整**：会计政策变更、并购并表会重述上年数；同比要用重述后数据。
5. **总额法 vs 净额法**：贸易、代运营类公司营收口径差异极大，跨公司比较要小心。
6. **汇率与并表**：海外收入占比高的公司，汇率变动会影响营收与汇兑损益。
7. **业绩预告/快报**：未经审计，区间中值可参考，但以正式报告为准。

## 三、盈利质量四比值

| 比值 | 计算 | 预警信号 |
| --- | --- | --- |
| 扣非/归母 | 扣非归母/归母 | <0.7 说明利润依赖非经常性项目 |
| 现金/利润 | 经营现金流净额/归母净利 | <0.8 说明回款或存货有问题 |
| 应收/营收 | 应收账款/营业收入 | 持续上升说明放宽信用或渠道压货 |
| 研发费用率 | 研发费用/营业收入 | 科技公司过低可能影响长期竞争力 |

补充看：存货周转天数、合同负债同比、销售费用率、减值计提比例。

## 四、估值口径

- PE(TTM)：总市值/最近四个季度归母净利润；亏损时为负，不写「低估」。
- PB：总市值/最新净资产；重资产与轻资产不可直接比。
- 总市值：A股用总股本×收盘价；A+H 要说明是否合并计算。
- 只陈述数值与历史分位，不做目标价、不做买卖建议。

## 五、数据源优先级

1. 交易所公告、巨潮资讯网（正式报告、快报、预告）。
2. 东方财富 F10、公告、财务数据页。
3. 同花顺 iFinD/问财、行情页。
4. 券商研报（只做解释，不替代公告数字）。

每个关键数字标注「来源 + 披露日期」；同一指标多源冲突时以公告为准，并注明差异。

External developers and agent builders use this skill to fetch random cat trivia, request multiple facts, or browse cat breed information for chatbots, notifications, educational apps, and harmless prototype data.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The MCP setup runs an unpinned npm package with mcp-remote@latest, creating a supply-chain review concern.

Mitigation: Pin the mcp-remote version or use a locked dependency, review the MCP setup before installation, and run it with limited local permissions.

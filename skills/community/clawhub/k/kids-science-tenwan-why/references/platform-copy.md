# 五平台发布文案规范

一条视频出五套文案。**标题、首句、结尾提问、话题四个位置必须逐平台改写**，其余可以共用。原样复制会被判重复内容，限流。

## 抖音

| 项 | 要求 |
|---|---|
| 标题 | ≤20 字，最好 12-18 字。前置结果或反常识，不写"第X期" |
| 正文 | 60-150 字，3-4 行，一行一个信息点，最后一句是提问 |
| 话题 | 5-8 个：1 个大词 + 2 个品类词 + 2-3 个选题长尾 |
| 封面文字 | 与视频首帧同一个标题，不另起 |
| 首评引导 | 自己的号先占一条：「你家娃问过这个吗？」 |

公式：`反常识结果 + 一句解释 + 一条动作 + 提问`

范例：

```
热水冒的白气，其实不是水蒸气。

真正的水蒸气你看不见，它是透明的。
白气是水蒸气碰到冷空气，变成了小水珠。

倒热水的时候，让孩子把手离远一点。
你家娃问过这个吗？
#十万个为什么 #儿童科普 #亲子育儿 #孩子问为什么 #热水冒白气
```

## 小红书

| 项 | 要求 |
|---|---|
| 标题 | ≤20 字，带具体场景或身份，不用"姐妹们快冲"式吆喝 |
| 正文 | 分点、短句、每点一行。全篇 100-200 字。emoji 最多 3 个 |
| 标签 | 8-10 个，放在正文末尾 |
| 封面文字 | 3:4 竖版大字标题 + 一行副标题 |
| 首评引导 | 「想看的下一期可以说，我按你们点的做」 |

公式：`场景一句 + 原理一句（分点讲） + 可用动作 + 收藏引导`

范例：

```
娃指着热水问：妈妈这是烟吗？

我蹲下来跟他说了三句话：
1. 这不是烟，是白气
2. 真水蒸气是透明的，看不见
3. 白气是水蒸气遇冷变成的小水珠

说完他自己拿手去试，离杯子十厘米就缩回来了。

这个原理一句话能讲清，五分钟能讲完。
收藏起来，下次娃问直接用。
#十万个为什么 #儿童科普 #亲子日常 #育儿知识 #科普启蒙
```

## 视频号

| 项 | 要求 |
|---|---|
| 标题 | 15-22 字，稳重，可带"给孩子讲" |
| 正文 | 80-150 字，家长视角，讲"我怎么讲给他听的" |
| 话题 | 3-5 个，偏教育、家庭 |
| 封面文字 | 4:3 横版更适合转发到群 |
| 首评引导 | 「转给家里带娃的人」 |

公式：`给孩子讲的一件小事 + 原理 + 家长感受 + 转发引导`

## B 站

| 项 | 要求 |
|---|---|
| 标题 | ≤25 字，可带【】栏目名，含知识点关键词 |
| 正文/简介 | 200-400 字，分「本期讲了什么」「知识点」「素材说明」三段 |
| 标签 | 5-10 个，含分区标签 |
| 封面文字 | 横向 16:9 或 4:3 都可，字要大 |
| 首评引导 | 「下期想看哪个现象，评论区点」 |

## 快手

| 项 | 要求 |
|---|---|
| 标题 | 10-16 字，口语直给，不用书面词 |
| 正文 | 一句话钩子 + 一句话互动，不超过 60 字 |
| 话题 | 3-5 个，生活化 |
| 封面文字 | 大字，方言口语可用 |
| 首评引导 | 「你家孩子多大？我按年龄给你选题」 |

公式：`一句大白话结论 + 一句互动`

## 通用雷区

- 不写「涨知识了」「干货满满」「建议收藏」这类空话堆叠。
- 不用问句式标题配感叹号（"你知道吗？！"）——AI 味最重的写法之一。
- 不在标题里用「揭秘」「震惊」「震惊全网」。
- 儿童安全类不做恐吓文案（"会毁掉孩子一生"这类）。
- 医疗、药品、诊断一律不写。
- 话题里不放无关大词蹭流量（会被打散标签）。

## Known Risks and Mitigations:

Risk: Users may mistake wallet security reference material for a place to enter private keys, seed phrases, or credentials.

Mitigation: Use the skill as read-only documentation and do not enter private keys, seed phrases, or credentials into the skill or copied examples.

Risk: Copied wallet-balance API examples may reveal queried wallet addresses to the selected provider.

Mitigation: Treat API snippets as examples, choose providers intentionally, and avoid querying sensitive addresses without appropriate privacy review.

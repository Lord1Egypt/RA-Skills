## Description:

Archive and organize completed OpenClaw session logs into structured markdown notes for long-term memory retention.

This skill is ready for commercial/non-commercial use.

## Publisher:

[terrycarter1985](https://clawhub.ai/user/terrycarter1985)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and operators use this skill to turn completed OpenClaw sessions into terse markdown memory files that preserve decisions, actions, blockers, and insights for later review.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Archived memory files may retain private decisions, file paths, links, business context, or other sensitive session details.

Mitigation: Review the summary before archiving and redact secrets, tokens, credentials, and sensitive private context.

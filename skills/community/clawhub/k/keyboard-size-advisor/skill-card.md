## Description:

Recommend a keyboard size (full-size, 98%, TKL, 75%, 65% or 60%) for coding or gaming and check whether it fits the user's desk and mousepad, using the HLPlanet MCP tools and measured dimensions. Use when the user asks which keyboard size or layout to buy, which keys a size loses, or whether a keyboard fits their desk.

This skill is ready for commercial/non-commercial use.

## Publisher:

[hlplanet](https://clawhub.ai/user/hlplanet)

MIT-0

## Use Case:

People choosing a keyboard for coding or gaming use the skill to compare sizes, check which keys require an Fn layer, and assess fit against their desk and mousepad.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Desk and mousepad measurements may be sent to HLPlanet's hosted MCP service when checking fit.

Mitigation: Tell the user before sending measurements, and offer the linked to-scale keyboard layout comparison if they prefer not to use the hosted service.

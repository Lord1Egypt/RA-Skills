# 分镜和 HTML 选材同步

实际阅片后，把可用的原片区间和照片编为候选。大纲待确认时先整理素材依据。已有有效故事确认或用户明确跳过该环节时，同一轮交可读脚本和本地 HTML。这个页面是分镜常规交付的一部分。明确要求纯文字时按当次范围交付。

## 同一份分镜数据

每个段落保留稳定编号、章节、标题、旁白或原声安排。每个候选保留独立编号、原素材编号、准确的画面描述、来源与原片区间或照片停留时长。把已选编号按剪辑顺序挂到相应段落，备选也可预览。候选较多时按章节和段落浏览，单段作品直接在一段里选。保留原有工程格式，需要时把相应字段投影成下面的清单。

以下是输入格式示意。制作时使用已实际审阅的项目文件，时间以秒计。

```json
{
  "project": "旅行日记",
  "edition": "叙事主片",
  "version": "v001",
  "story_version": "v002",
  "beats": [
    {"id":"B01","chapter":"抵达","title":"走进庭院","narration":"推开门，院子比想象中大。","sound":"留开门的现场声","edit":"过门时接全景","selected":["C01"]}
  ],
  "candidates": [
    {"id":"C01","home":"B01","asset_id":"A01","kind":"video","source":"media/进门.mp4","source_in":4,"source_out":7.5,"visual":"从门外走进庭院，远处有人招手"},
    {"id":"C02","home":"B01","asset_id":"A02","kind":"photo","source":"media/庭院.jpg","duration":2,"visual":"从廊上回望整个庭院"}
  ]
}
```

`home` 是首次整理候选时所在的段落。最终归属和顺序以各段的 `selected` 为准，空数组表示暂缺画面。一个原片可以有多个不同区间，用各自的候选编号区分。路径相对清单，也支持本机绝对路径。视频可填 `speed`，表示选材串看时的播放倍速。浏览器不能播放原片时，先准备本地兼容预览片，通过 `preview` 引用同一原片区间从零开始的原速片段。`source_in`、`source_out` 始终指原片。照片也可指定预览图，`thumb` 可提供小缩略图。

## 同轮生成和修订

从技能目录运行以下示例，实际使用时将清单、选择文件和输出目录指向当前作品。新建的独立工作区也可以在工作区根目录用 `tools/review_board.py` 运行同一工具。旧工作区可直接调用升级后的技能目录中的脚本。

```text
python scripts/review_board.py 分镜底稿.json 选材与脚本_v001
python scripts/review_board.py 选材与脚本_v001/分镜选材.json 选材与脚本_v002 --choices 本次选材.json --version v002
```

每版一起生成 `分镜脚本.md`、`index.html` 和 `分镜选材.json`。双击页面即可预览指定视频区间、单图、整章或整份已选串联。修改镜头归属、顺序、取舍或旁白后，页面与“下载当前脚本”立即反映本次选择。“导出本次选材”保存可合入该底稿的编辑记录。浏览器保存的是草稿，正式成对文件由本地入口写入新版本目录。

- **从选材改脚本**。按段落编号合并反馈，增删或移动镜头就回写原段和目标段，复核两个段落的画面描述、旁白所指、声音落点和后续时点。原台词仍合适时沿用。含新事实的改写由剪辑者对照原片核实。
- **从脚本改选材**。保留用户亲自改过的句子，以原段号定位，替换或补齐能支撑这句话的候选和入出点。调整主线时按作品的故事确认记录推进。重新由同一份底稿交付脚本和 HTML。项目已有正式时间线时把定下的选择写回相应镜头及素材引用。
- **合并多人次或跨版修改**。选择文件带底稿标识。先在它对应的版本还原反馈，再将受影响段落合入最新稿，保护后来改过的文案和有效选择。发布本地新稿前核对两份的版本、段落、镜头顺序和源区间，在浏览器试播改动段。选材页展示的是按所选区间估算的串联时长，进入粗剪时再核对变速、叠化和声音后的成片时点。

作品记录保存本版脚本、选材页与分镜数据的路径。要用自带示例体验，先在新工作区生成合成演示媒体，再运行 `python tools/review_board.py examples/分镜选材示例.json examples/选材_v001`，打开输出目录中的 `index.html`。

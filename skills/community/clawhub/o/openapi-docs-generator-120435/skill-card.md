## Description:

Helps API developers and platform teams generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, API maintainers, backend teams, and developer-experience teams use this skill to plan, create, review, and validate REST API documentation based on OpenAPI or Swagger.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad API-related trigger wording may invoke the skill for backend tasks that are not about OpenAPI or Swagger documentation.

Mitigation: Explicitly select or avoid the skill when the request is outside OpenAPI or Swagger documentation work.

Risk: Generated documentation guidance can be incomplete when the source API behavior, schemas, or constraints are missing.

Mitigation: Review outputs against the service implementation, existing API specifications, and the skill's validation criteria before publishing.

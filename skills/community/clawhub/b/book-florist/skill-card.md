## Description:

Book florist services through Lokuli MCP for users who need to find and book a florist.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and their agents use this skill to search for florist services, check availability, and create bookings through Lokuli MCP. Booking may send zip code and customer contact details to Lokuli or a florist provider.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Using the booking flow may send zip code and contact details to Lokuli or a florist provider.

Mitigation: Proceed only when the user intends to search or book a florist, and confirm booking details before submission.

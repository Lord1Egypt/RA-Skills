# Web: Bring a Changing World into the Current System

The Web adapter searches, browses, downloads, and checks network sources, bringing the outside world into the current judgment with explicit dates, definitions, and provenance.

## When to go online

Check actively when facts may have changed, the user asks for current or direct sources, a critical conclusion carries high stakes, the object is unfamiliar, materials point to a particular page, or local evidence is thin. Prefer official documentation and original papers for technical work; authoritative releases for companies, policy, standards, and product state; and distinguish the date an event happened from the publication date in news.

## How sources enter the system

Critical facts carry source, date, scale, definition, and conditions of validity. Primary sources support critical claims; secondary material helps locate leads, compare narratives, and find disputes. When sources conflict, explain whether time, definition, sample, or interest position accounts for the difference.

A link is an entry into external material. For content that affects a long-lived work, preserve the necessary excerpt, data, or dated snapshot while respecting copyright and citation boundaries. Every link serves a mechanism, a piece of evidence, or a path for continued checking.

## From information to effect

Search results first enter [observation](../runtime/observe.md). They become an effective component when they change a system model, choice, work, or action. Domain systems continue to hold authoritative state; real effects are confirmed by the corresponding object and action evidence.

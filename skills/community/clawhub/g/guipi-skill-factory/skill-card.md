## Description: <br>
Skill Factory helps agents create, update, validate, and optionally publish agent skills through overlap assessment, security review, SKILL.md authoring, and release guidance. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[guipi888](https://clawhub.ai/user/guipi888) <br>

### License/Terms of Use: <br>
Apache 2.0 <br>


## Use Case: <br>
Developers and skill maintainers use this skill to plan new skills, compare them with an existing local skill library, create or update SKILL.md files, run safety checks, and prepare publication to ClawHub or other platforms. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill can guide broad scans and edits of a local skill library, which may affect existing skill behavior. <br>
Mitigation: Review the overlap assessment, security report, and any SKILL.md changes before applying them. <br>
Risk: The skill may prepare publication to GitHub, ClawHub, or Xiaping. <br>
Mitigation: Confirm each publication target and release artifact explicitly before publishing. <br>

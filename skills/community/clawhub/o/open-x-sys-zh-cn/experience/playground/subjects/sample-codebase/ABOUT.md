# 材料：一个小型订单服务

> **试验场的一个现成对象：一个示例代码库。**
> 这是一个**构造出来的示例**，为试验场而写。它小到几分钟就能读完，只用 Python 标准库就能运行（Python 3.10 或更高）：在这个文件夹里执行 `python -m unittest`。
> 它被做成了一个值得为之开启系统的对象。它的文档和它的代码并不总是一致，它在高负载下的表现，也不是第一遍读下来以为的那样。**这个文件不说在哪里。** 找到它，就是这次运行要做的事。

## 文件

| 文件 | 是什么 |
|---|---|
| `README.md` | 这个项目自己的文档，是它的作者写下的工作方式 |
| `orders.py` | 订单队列和工作线程 |
| `inventory.py` | 库存预留 |
| `notify.py` | 通知客户 |
| `test_orders.py` | 测试 |

## 怎样把它当作对象来用

- 把代码当作证据。每个判断都应该指向一个文件、一行；宿主允许的话，能运行的都运行一遍。
- 适合先说的话：“给这个代码库开启一个系统。” · “跟着一张订单把这个服务走一遍。” · “真正限制它每秒能处理多少订单的是什么？” · “什么会让它在忙的一天里出问题？”
- 这份认识“截至”这个文件夹当前的内容。

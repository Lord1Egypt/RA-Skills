# 问题资产卡（格式契约）

> 本文件只定义格式契约，不存储数据。问题资产目录文件由使用者随时指定路径，存放于技能包外（建议多册并存，按研究方向分册）。

## 数据文件表头契约（字段顺序不得调整）

| 序号 | 日期 | 来源模式 | 问题表述 | 核心问题 | 四维评估 | 可对话理论传统 | 预期非平庸结论 | 去重状态 |

## 数据文件初始骨架（懒创建时按此写入）

```markdown
# 问题资产目录

> 运行时沉淀文件（由知识循环定位策略师技能维护，数据在技能包外）。
> 追加规则：KLS4-04 沉淀时查重后逐行追加；只增行、不改表头；
> 字段定义见技能包内 KLS-question-asset-template.md；手动添加条目同样有效。

| 序号 | 日期 | 来源模式 | 问题表述 | 核心问题 | 四维评估 | 可对话理论传统 | 预期非平庸结论 | 去重状态 |
|------|------|---------|---------|---------|---------|---------------|---------------|---------|
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 序号 | 册内自增序号 |
| 日期 | 沉淀日期 |
| 来源模式 | 直用/改进/迁移/构建 |
| 问题表述 | 候选问题完整表述（商业轨附【价值：…】、涉商业主体或个人隐私附【保密：…】写于列尾，不新增列——分层分轨标注规则见 KLS4 域级说明） |
| 核心问题 | 可论证的核心问题（非领域词） |
| 四维评估 | 问题明确性/理论传统/宽窄适度/非平凡性结论（全过方可沉淀） |
| 可对话理论传统 | 可援引的理论资源方向 |
| 预期非平庸结论 | 可能产出的超越常识的结论方向 |
| 去重状态 | 查重通过/跨册待查 |

## 读写协议（摘要）

1. 路径由使用者随时指定：本次指定 > 上次沿用 > 询问一次；
2. 多册并存，切换即换当前生效册；查重默认当前册，跨册为深化可选项；
3. 禁止指向技能包内部；文件不存在按上方骨架懒创建；
4. 追加只增行，永不改写骨架与已有行；手动添加与程序追加同权。

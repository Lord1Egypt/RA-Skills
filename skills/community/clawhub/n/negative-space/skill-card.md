## Description:

Metacognitive pre-execution analysis - teaches the agent to see what is not there before acting on what is present, reducing wasted turns, failed approaches, and scope drift by surfacing hidden assumptions, missing context, and implied constraints.

This skill is ready for commercial/non-commercial use.

## Publisher:

[jcools1977](https://clawhub.ai/user/jcools1977)

### License/Terms of Use:


## Use Case:

Developers and agent operators use this skill to make an agent pause before meaningful action, identify key assumptions, missing constraints, absent context, and likely failure modes, then choose whether to verify, ask a focused question, or proceed.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may cause an agent to ask clarifying questions more often than desired.

Mitigation: Apply it before substantial or side-effecting work and keep clarification to one precise question when verification cannot be done from available context.

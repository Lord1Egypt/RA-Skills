## Description:

Use when receiving code review feedback, before implementing suggestions, especially if feedback seems unclear or technically questionable - requires technical rigor and verification, not performative agreement or blind implementation.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Developers and engineering agents use this skill to handle code review feedback with technical verification before making changes. It supports clarifying unclear review items, evaluating external suggestions against the codebase, and applying fixes one item at a time.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill changes an agent's code review posture toward stricter, less deferential feedback handling.

Mitigation: Install it only when that response style is desired for the agent's review workflow.

Risk: If used to draft GitHub review replies, a posted comment may act through the user's GitHub account permissions.

Mitigation: Review the exact comment content before posting any GitHub thread reply.

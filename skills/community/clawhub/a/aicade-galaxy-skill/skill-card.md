## Description:

Configures, exports, validates, and invokes AICADE Galaxy dynamic services for AI use with AICADE_GALAXY_* environment variables, X-API-Key authentication, /admin/gateway/services discovery, and responsePaths for partial JSON responses.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and external users use this skill to configure AICADE Galaxy access, export dynamic gateway services into a reusable JSON artifact, invoke exported tools with JSON arguments, and explain response field selection.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: API keys or request arguments may be exposed through debug logging or shared environments.

Mitigation: Keep .env private with restrictive permissions and avoid AICADE_GALAXY_DEBUG in shared terminals or CI.

Risk: Untrusted generated artifacts or endpoints may cause tool arguments to be sent to an unintended remote service.

Mitigation: Install only if the AICADE Galaxy endpoint is trusted and invoke only artifacts generated by this package from trusted sources.

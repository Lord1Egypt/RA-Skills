## Description:

Best-practice guidance for building, editing, and debugging Remotion video projects with React and TypeScript.

This skill is ready for commercial/non-commercial use.

## Publisher:

[clawbus](https://clawhub.ai/user/clawbus)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to design, edit, and debug Remotion video compositions, animations, transitions, captions, media handling, charts, text effects, Lottie, and 3D scenes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Package installation commands in the guidance may install current package versions that differ from a user's project constraints.

Mitigation: Review commands before copying them and preferably pin package versions that match the target Remotion project.

Risk: Remote media, Lottie files, caption sources, and metadata URLs used in generated examples may contact external hosts during preview or render.

Mitigation: Use only trusted remote URLs or local assets, and review project network behavior before rendering.

Risk: Generated Remotion code or guidance may be incorrect for a specific project structure or package version.

Mitigation: Review and test adapted code in the target project before deployment or publication.

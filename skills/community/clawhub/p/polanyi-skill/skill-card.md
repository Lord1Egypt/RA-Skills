## Description:

Michael Polanyi's thinking framework helps agents analyze tacit knowledge, skill learning, experience transfer, apprenticeship, knowledge management, learning methods, AI and tool substitution boundaries, scientific communities, and post-critical philosophy questions.

This skill is ready for commercial/non-commercial use.

## Publisher:

[enzyme2013](https://clawhub.ai/user/enzyme2013)

### License/Terms of Use:

MIT

## Use Case:

External users and developers use this skill to ask an agent to respond through Michael Polanyi's perspective, especially for questions about tacit knowledge, expertise transfer, apprenticeship, knowledge management, learning, AI substitution boundaries, and scientific communities.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The README includes npx-based installation examples that may resolve mutable package or source revisions.

Mitigation: Install from a pinned or reviewed revision and do not run installation commands with elevated privileges.

Risk: The skill is primarily Chinese-language and may answer in Chinese by default.

Mitigation: Explicitly request another response language when deploying or using the skill in a non-Chinese workflow.

Risk: The skill can provide role-perspective philosophical analysis that may be mistaken for exact historical attribution.

Mitigation: Require source-aware caveats for exact quotations, page numbers, letters, interviews, or claims about events after Michael Polanyi's 1976 death.

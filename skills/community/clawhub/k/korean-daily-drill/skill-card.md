## Description:

Generates a personalised Korean language practice session based on TOPIK level. Covers vocabulary, grammar, Hangul, reading, and speaking prompts. Fresh content every session.

This skill is ready for commercial/non-commercial use.

## Publisher:

[tetsuakira-vk](https://clawhub.ai/user/tetsuakira-vk)

### License/Terms of Use:

MIT-0

## Use Case:

External Korean learners, TOPIK students, and language enthusiasts use this skill to generate level-appropriate daily practice sessions with vocabulary, grammar, reading, speaking prompts, quizzes, and cultural notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The documented installer uses a mutable npx clawhub@latest command, so installer behavior can change over time.

Mitigation: Install from a trusted environment, pin the ClawHub installer version when possible, and review release evidence before use.

Risk: Generated Korean practice content can contain incorrect translations, grammar explanations, or level placement.

Mitigation: Use the output as study support and verify important learning material against trusted Korean or TOPIK resources.

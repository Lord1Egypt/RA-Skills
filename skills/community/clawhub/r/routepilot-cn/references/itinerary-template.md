# 多日行程与预算模板

多日自驾的失败点几乎都不在「路线选错」，而在「排得太满」：一天塞进 600 公里再加两个景点，第二天全员折损。本模板把上限、倒排、预算与风险做成可填的表。

## 1. 行程骨架

先填骨架，再填细节；每一行都必须有里程和时长，不接受「差不多两小时」。

| 日期 | 路段 | 里程 km | 驾驶时长 | 锚点（当天唯一重点） | 住宿地 | 备注 |
|:--|:--|--:|--:|:--|:--|:--|
| D1 | 甲城 → 乙城 | | | | | |
| D2 | 乙城 → 丙镇 | | | | | |
| D3 | 丙镇 → 甲城 | | | | | |

填表规则：

- 每天只设 1 个锚点（一个景点、一次探访或一段长途），其余为机动。
- 里程与时长必须来自同一时段的导航快照；跨日比较时口径要一致。
- 「备注」只写约束：预约时段、限行、停车限制、必须几点前到。

## 2. 切分规则

| 同行构成 | 单日驾驶时长 | 单日里程 | 附加要求 |
|:--|:--|:--|:--|
| 单人驾驶 | ≤4h（法规上限），建议 ≤3.5h | ≤350km | 每 4h 强制休息 ≥20min |
| 有成人可轮换 | ≤7h | ≤600km | 每 2–3h 换人一次 |
| 带儿童或长辈 | ≤5h | ≤400km | 每段 ≤2h，留 1 个休息点 |
| 夜间 22:00–06:00 | ≤2h | ≤150km | 能避开就避开 |

超限的三种处理，按优先级选：

1. **拆日**：把一段拆成两天，中间加一晚。成本增量 = 一晚住宿 + 一天餐饮，交给用户确认。
2. **换序**：把长途段挪到精力最好的那天（通常是 D2），短途段放到首尾。
3. **减点**：砍掉锚点之外的次要景点，不要砍锚点本身。

绝不采用的第四种：压缩休息时间、夜间补里程。这一条不给选项。

## 3. 固定场次倒排法

当行程里有固定场次（演出、预约制景区、限时开放、轮渡班次），不能从「几点出发」正向排，必须从场次时刻往回推：

```text
固定场次时刻 T
  ← T − 30min      必须已完成入园/检票（官方硬要求，票面常写明）
  ← T − 30~60min   必须到门口排队（热门场次按 60min）
  → T + 场次时长    散场
  → 闭园时间 − 散场  = 夜场余量（决定还看不看室外项目）
  ⇐ 入园时刻之前的全部时间 = 自由活动与补漏窗口 → 越早到越值
  ⇐ 离园时刻 + 车程（节假日按 ×1.3–1.5） = 到家时刻
```

两条必须向同行人说明的事：

- 一日票通常只含一场主项目，想多看要现场加购；先问清楚再加，不要按「都能看」排时间。
- 「坐着看」还是「站着走」是第一决策变量，比票价和距离都重要。带长辈时必须先确认场次形态与时长，再排时间轴。

## 4. 住宿选址四条

1. **次日出发方向**：住城市靠次日出发方向的一侧，省掉早高峰穿城。
2. **离高速口 5–10km**：太近吵、太远费时；10km 以上要重新算接驳时间。
3. **停车确定性**：优先选有自有停车场的；老街区的民宿要提前确认车位，否则夜间绕圈的成本高于房价差。
4. **景区 vs 县城**：景区内省时间、县城省预算；差价超过 ¥150/晚且车程 ≤40 分钟时，住县城通常更划算——但要把往返车程与油费算进去再比。

## 5. 预算表

```text
交通 · 油费      = 总里程 ÷ 100 × 油耗 × 油价
交通 · 过路费    = 各段实际（免费段记 0，临界卡点段分开记）
交通 · 停车      = 住宿停车 + 景区停车 + 临时停车
交通 · 接驳      = 打车、摆渡、轮渡
住宿            = 每晚单价 × 晚数
餐饮            = 人均日餐标 × 人数 × 天数
门票与体验      = 逐项列，含预约费与加购
其他            = 购物、装备租借、洗车
机动金          = （以上合计）× 8%–10%
总计            = 以上合计 + 机动金
人均            = 总计 ÷ 人数（儿童可按 0.5 折算，需注明口径）
```

模板：

| 分类 | 明细 | 数量 | 单价 | 金额 | 依据 |
|:--|:--|--:|--:|--:|:--|
| 交通 · 油费 | 总里程折算 | km | 元/km | | 油耗 × 当日油价 |
| 交通 · 过路费 | 分段累加 | 段 | 元 | | 导航报价或费率 × 里程 |
| 住宿 | 晚数 × 单价 | 晚 | 元 | | 当日可订价 |
| 餐饮 | 人均日餐标 | 人日 | 元 | | 目的地一般水平 |
| 门票与体验 | 逐项 | 张 | 元 | | 官方票价 |
| 机动金 | 合计 × 8%–10% | — | — | | 拥堵、临时改道、涨价 |
| **总计** | | | | | |
| **人均** | | | | | |

预算表的三条纪律：

- 每一行的「依据」必须能说清来源；写不出依据的行，金额标「估」。
- 机动金不得省略，也不得挪去做别的项目。
- 交付时同时给总计与人均：只给总计，同行人无法分摊；只给人均，看不出总额压力。

## 6. 三方案门到门对比

| 方式 | 门到门时间 | 成本构成 | 何时占优 |
|:--|:--|:--|:--|
| 自驾 | 家到目的地直达，含加油与休息 | 油费 + 过路费 + 停车 + 时间成本 | 3–4 人同行、免费窗口、目的地公共交通弱 |
| 高铁 | 家到站 + 候车 + 车程 + 站到目的地 | 票价 × 人数 + 接驳 + 时间成本 | 2 人以内、单程 >4 小时、目的地市中心 |
| 飞机 | 家到机场 + 提前到场 + 飞行 + 落地接驳 | 票价 + 机建燃油 + 接驳 + 时间成本 | 单程 >6 小时且两端接驳短 |

对比时必须使用同一套时间成本与同一份人数口径；把自驾的「门到门」和高铁的「车上时间」放在一起比，是最常见的错。

## 7. 风险清单

| 风险 | 触发条件 | 应对动作 |
|:--|:--|:--|
| 拥堵超出预期 | σ 覆盖不住，实时路况红段 >20km | 启用备用出口；必要时下高速走国道绕行 |
| 天气突变 | 雨雾、台风、道路结冰预警 | 取消当日长途，改室内锚点；夜间不动车 |
| 封路或施工 | 导航提示封闭、管制 | 出发前 1 小时复核；准备第二条路线 |
| 限行与通行证 | 目的地城市限行、景区需预约 | 提前查当地当期规定，预约截点写进备注 |
| 疲劳 | 单日 >4h 或连续两天 >6h | 强制休息 20 分钟；换人；拆日 |
| 儿童不适 | 乘车 >2h、山路连续弯道 | 每 2h 停车；备晕车用品；避开连续盘山 |
| 停车失败 | 老城区、热门景区 | 提前锁定有车位的住宿；备选停车场写进备注 |
| 门票售罄 | 节假日、预约制 | 提前锁定；准备等价替代锚点 |

## 8. 交付前自检

- [ ] 逐日里程与时长双上限均未超；超限处已拆分并写明成本增量。
- [ ] 每天恰好 1 个锚点，且锚点的预约/开放时间已核对。
- [ ] 固定场次已用倒排法排过，入园时刻早于场次 ≥30 分钟。
- [ ] 住宿按次日出发方向选，停车方式已确认。
- [ ] 预算表每行有依据，机动金 8%–10%，总计与人均同时给出。
- [ ] 风险清单至少 3 条，每条都有触发条件与具体动作。
- [ ] 全文无个人信息、无未标注来源的单价。

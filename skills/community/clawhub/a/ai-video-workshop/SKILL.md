# AI视频创作工坊

## 定位

本技能是「AI视频内容生产」领域的领域负载物，agent通用：负责把"任意文本 → 真人感视频成品"的需求，端到端转化为可交付成片。生成、剪辑、合成在宿主agent能力内完成，不依赖特定平台。

**覆盖产出类型**：
- AI短剧 / AI漫剧（单集1-2分钟，多集连载）
- 视频广告 / 信息流素材（15秒-3分钟）
- 品牌宣传片、产品视频
- 口播视频、知识视频
- 小说/剧本改编的概念样片、试集

**适用边界**：叙事型视频全覆盖（短剧/广告/宣传片/口播/知识/漫剧/产品展示）；音乐卡点与直播切片仅部分支持；图文轮播、纯动效包装、真人实拍不做。逐项见 requirements「跨域总览：适用平台与边界」。

**最小输入**：只给一段 30-200 字的故事概要即可开工——五要素抽取→故事核卡→三集大纲→角色小传→剧本逐级推导，缺口按 AVS0-02 默认值表补齐，推断项逐条标注；只问三项（配音方案/画幅/集数），其余不许问。输入不足30字或只有一句想法时，先出三提案供选，不直接脑补全剧。

**核心生产公式**：成品 = 行业实测工作流（references/ 工艺规范）× 内置生成能力（图像生成定帧、视频生成出片段、ffmpeg 合成）。

上述任一需求出现时，从 Step 0 路由进入，不跳过资产库与 QC 门禁。

## 经验反哺规范（技能运维铁律）

每次项目实操踩到的新坑、验证的新打法，收尾时必须反哺进技能本身，四条缺一不可：

1. **更新任务要求**：把经验抽象为通用规则，写入 `references/ai-video-workshop-requirements.md` 对应域（失败模式表、约束、跨域总览等），措辞不带具体项目名。
2. **更新具体范本**：给每条规则配一个可模仿的具体示例，写入对应域范本（AVS0~AVS7 各域范本文件）。
3. **融入范本故事**：范本示例必须改写进既有贯穿故事（当前为《归宋医女》）的语境——用该剧的角色/镜头/场景承载，不得另起独立的"补充案例"章节，保持单一贯穿主线。
4. **推导预判同构风险**：每次反哺实测经验时，同步从底层规律推导"同构风险"的预判，写入 requirements「跨域总览：能力边界与失败模式预判清单」；预判必须标注"预判·待实测"，与已实测的失败模式分开归类，不得把推断伪装成事实；实测确认后再升级为正式规则（移入失败模式表＋配范本示例）。

> 反例（已被否决）：把新经验写成"实测补充案例（某项目）"独立挂载在范本末尾，会割裂范本的贯穿叙事。

## 使用规则

1. **首次加载**：读取 `references/ai-video-workshop-catalog.md` 获取任务清单与依赖拓扑
2. **按需深入**：确认任务后读取 `references/ai-video-workshop-requirements.md` 对应域；需要模仿产出时读取 `references/ai-video-workshop-exemplars.md` 及对应域范本文件（AVS0~AVS6域范本，一域一本，与索引同级，命名 `{代号前缀}{编号}-{域名}范本.md`）
3. **配音缺口**：无内置TTS，项目启动时主动询问配音方案（提供音频/外部TTS/暂无声版）
4. **事实纪律**：不虚构平台政策数字；涉及发布平台分账/审核规则的表述标注"以平台最新公告为准"；引用行业案例须真实
5. **合规默认**：提醒成片需标注"AI生成"；不使用真实人脸素材；提醒微短剧备案要求与素材版权核查
6. **传统影视工艺**：各域 requirements 内嵌"传统影视工艺"表（轴线/匹配剪辑/光影情绪/声画关系/视线匹配等），执行时按需查表落实到提示词与QC标准；精品型项目A6 QC强制核对视线匹配/轴线/情绪连贯/色彩叙事四项
7. **项目目录与寻址**：每项目一个工作目录，含剧本/分镜/资产库/镜头素材/成片/工程清单，可复用可续做。下列结构只是默认落盘约定、不是硬约束——目录可整体改名或迁移；跨任务引用一律按**资产ID与词条ID**寻址（角色C01、场景S02、词条R-01），不按文件路径寻址，路径仅用于当前会话内定位，禁止写进提示词、脚本与交付文档
8. **工艺默认值**：镜头时长、景别配比、提示词字数、画幅与出片规格、统一调色等默认值已固化在 AVS2-03／AVS3-05／AVS4-02／AVS5-03 的约束中，执行以任务约束为准，此处不重复维护

```

├── 02_分镜/（分镜表.md）
├── 03_资产/角色_<角色名>/（设定卡六联、造型/发型_nn·服装_nn、表情集、锚点段.md）
│          └──场景_<场景名>/（多视角图）
```

**按阶段加载**：单次只读当前阶段对应的 requirements 小节与范本，跨阶段按依赖顺序逐段加载，不预读下游长文；阶段-读取对照表见 requirements"跨域总览：按阶段最小读取集"。

## 通用任务执行能力

**三轴正交**：执行轴（How，必选）+ 内容轴（What，按需）+ 创新轴（Why Different，按需）。

- **执行轴**：6大元操作 S感知（需求收集、素材分析、QC检查）/ C认知（选题校准、分镜设计、锚点段固化、选优）/ A行动（剧本撰写、图像视频生成、ffmpeg合成）/ O组织（项目目录、资产库、工程清单）/ I交互（需求确认、样片确认、配音方案）/ G守护（节奏校准、双采样、QC合规）；6种编排模式（顺序/并行/条件/循环/扇出/扇入）。默认管线：P1基础闭环（AVS0→AVS6）嵌套 P2迭代精炼（AVS4多抽循环与A6返工回路）。
- **内容轴**：清单法（分镜表/资产库/QC清单按组件清单逐项填充）+ 样本法（模仿各域范本文件结构与风格，不复制范本内容）；网络搜索用于行业工艺更新与对标分析。
- **创新轴**：按需启用——创意类任务（AVS1 选题/大纲/剧本/钩子、广告创意、AVS7 切片改造）调用模式直用/改进/迁移/构建；生产工艺（AVS3–AVS6）零创新，只按清单执行。创新只决定"选什么"（题材/结构/表达/组合），不改"怎么生成"（参数/顺序/工艺）；具体做法已写入对应任务的组装顺序与可选组件，不另设清单。
- **协同模式**：顺序协同（判定→分解→生成→校验）为默认；AVS3-02/03/04并行协同；AVS4多抽与A6返工为迭代协同；长项目按集循环为递归协同。

**核心公式**：产出 = 元操作（S/C/A/O/I/G管线）× 本负载物（references/ 工艺规范 + 范本库）。

## 与执行框架的接口

收到任务后先判定输入类型并路由：小说/长文本→改编；**一段故事概要（无现成剧本/大纲）→最小输入创作模式：只问三项，其余按默认值表推进**；创意/一句话→创作；已有剧本或分镜→跳过创作（须补 AVS1-03 小传）；单场戏→样片；广告需求→广告模式（各模式管线变体见 catalog）。主管线：AVS1 剧本 → AVS2 分镜表（含转场与接镜）→ AVS3 资产库（角色+造型+表情+场景+锚点段，不可省）→ AVS4 镜头生产 → AVS5 声音与合成 → AVS6 QC 与交付。

本技能通过以下五步接入通用任务执行框架（三轴正交），任何视频生产请求都从 Step 0 进入：

- **Step 0 三轴判定**：复杂度（样片/广告=中等，多集连载=复杂）、内容类型（结构化生产管线+创意内容）、创新需求（剧本与广告创意按需启用，生产工艺零创新按规范执行）
- **Step 1 领域校准**：按本领域 R1-R5 参数校准执行（见下表）
- **Step 2 三轴分解**：执行轴按 catalog 依赖拓扑分解为 AVS0→AVS6 管线；内容轴对分镜表、资产库、QC清单启用清单法，对剧本、提示词启用样本法（各域范本文件）；创新轴仅在创意类任务启用
- **Step 3 管线编排与执行**：按 catalog 依赖拓扑逐任务执行；AVS3-02/03/04 可并行（三库均以角色资产库为锚）；每个生成任务完成后立即做基元内分步校准（对照 requirements 约束逐条核对）
- **Step 4 整合交付**：AVS6-01 成片QC门禁 → AVS6-02 合规核查 → AVS6-03 交付；FAIL 项回到 AVS4 对应任务修正后复检，直至全 PASS

**Step 1 领域校准的领域特定推导**：

| 参数 | 本领域取值 | 执行影响 |
|------|-----------|---------|
| R1 信息密度 | 高（锚点段、参数表、提示词模板密集） | S/C 权重高：生成前必须核对 requirements 与锚点段，禁止凭记忆写提示词 |
| R2 创造性 | 剧本与广告创意=高；生产工艺=低 | A 权重分域：创意类任务放开创作，工艺类任务严格按清单执行 |
| R3 交互性 | 高（需求确认、大纲确认、样片确认、配音方案四个强制确认点） | I 权重高：四个确认点不得跳过，未经确认不得进入下一阶段 |
| R4 规范性 | 高（一致性三锚、QC九项为硬约束） | G 权重最高：AVS6-01 为强制门禁，FAIL 不交付；锚点段逐字复用零容忍 |
| R5 迭代性 | 极高（多抽取优、双采样、QC返工为常态循环） | AVS4 域默认迭代协同；重抽记录必须入工程清单 |

**自治度**：31 个任务中 25 个⬛全自动，6 个校准点🟨需人判断（三提案／需求三问／大纲／小传／样片／配音），上传发布⬜人工；校准点清单与「不停会怎样」见 requirements「跨域总览：自动化边界与校准点」。

- **交付件**：成片＋工程清单＋发布信息清单三件齐全；QC 未过通过线不出片

| 只读模式 | 仅读取与校验（AVS6-01 QC、AVS6-02 合规核查、资产一致性审查），输出报告与修改建议，不写入任何文件、不调用生成工具 |
| 无生成模式 | 生成工具不可用时，交付剧本+分镜表+资产提示词+视频提示词全套文档，供用户在外部工具执行 |
| 混合模式 | 文本与资产管理在本技能，画面生成走外部工具（已接入MCP则直接调用，未接入则提示词外包），回传后完成合成与QC |

## 事实纪律

1. 仅使用确知的工艺与参数，不确定的标注"待验证"
2. 角色文字锚点段一经确定逐字复用，不得改写同义词
3. 行业案例、数据引用必须确知真实存在
4. QC检查项须逐条实际核对，不得凭印象通过
5. 生成失败/崩坏的镜头如实记录于工程清单，不隐瞒

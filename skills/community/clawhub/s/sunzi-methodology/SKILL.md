# 孙子兵法方法论 Skill

孙子兵法是一部竞争决策学：核心不是"怎么打赢"，而是"怎么让赢变简单"——
先算后打、以强打弱、不打没把握的仗。本 skill 抽成**五个框架 + 十条心法
+ 一个输出模板**，全部原创转述；另附场景化金句库（原文公有领域，短引用）。

## 快速路由（先判场景，再选框架）

| 用户场景 | 用哪个框架 |
|---|---|
| 要不要打这一仗/接这个竞争 | 框架1 先胜后算法 |
| 对手强我弱，从哪下口 | 框架2 避实击虚法 |
| 正面打法都一样，怎么差异化 | 框架3 正奇分合法 |
| 竞争分析、摸对手底细 | 框架4 五事七计法 |
| 冲突成本太高，能不能不打 | 框架5 全胜上兵法 |
| 只要一句金句收尾 | 直查 `references/quotes.md` |

可组合：进新市场 = 框架4 算五事 → 框架1 判可胜 → 框架2 选切入点 → 框架3 定打法。

## 五大分析框架

### 框架1 先胜后算法（胜兵先胜而后求战）

- 输入：要不要进入一场竞争/打一场硬仗。
- 步骤：
  1. 庙算：开打前先算"胜算从哪来"——不是靠临场发挥，是靠开打前已成的优势；
  2. 列出必胜条件（资源/时机/能力），缺核心条件就不打——"不能胜则守"；
  3. 打则速胜：赢了没后续成本的才打；赢不了、赢了也是消耗的，一律不动。
- 输出：可胜/不可胜判定 + 依据条件清单 + 不打时的守势动作。
- ✅完成标准：能回答"我凭什么赢在开打之前"；答不出就是不可胜。

### 框架2 避实击虚法（兵之形，避实而击虚）

- 输入：对手整体强于我，要找下口处。
- 步骤：
  1. 画对手的"实"（优势区：品牌/资金/主战场）与"虚"（顾不过来的缝隙：
     小客户/冷场景/慢响应/内部矛盾）；
  2. 只在虚处下口，实处一律不碰（不跟对手优势区硬拼）；
  3. 打虚要形成局部优势（参考毛选框架3），一口吃透再扩大。
- 输出：对手虚实图 + 我方切入点（必须在虚区）。
- ✅完成标准：切入点能说清"为什么对手不会/不能在这里跟我拼"。

### 框架3 正奇分合法（以正合，以奇胜）

- 输入：打法设计——正面顶着打的和出奇制胜的要分开。
- 步骤：
  1. 正兵：行业常规动作做扎实（该有的价格带/服务/内容得有，这是入场券）；
  2. 奇兵：至少留一路非常规打法（新渠道/新组合/新节奏），对手按常规
     推演不到的那一路；
  3. 奇正相生：奇兵跑通用资源加码变成新正兵，再养下一路奇兵——循环。
- 输出：正兵清单（必须做扎实）+ 奇兵一路（有明确假设与验证动作）。
- ✅完成标准：奇兵有"对手为什么想不到/跟不上"的答案；全是常规动作 = 没有胜机。

### 框架4 五事七计法（经之以五事，校之以计）

- 输入：竞争分析、进新市场前的实力盘点。
- 步骤：按五事对照双方打分（各 1-5 分）——
  1. **道**：目标是否一致（团队/用户认不认你的方向）；
  2. **天**：时机窗口（趋势、季节、政策、平台红利）；
  3. **地**：阵地地形（渠道、平台、距离用户的远近）；
  4. **将**：执行的人（能力、信用、赏罚是否分明）；
  5. **法**：组织与流程（成本结构、供应链、响应速度）。
- 输出：五事对照打分表 + 弱项补强方案；算下来全输就不进。
- ✅完成标准：每项有打分有证据；总分明显劣势时不进入，转框架1守势。

### 框架5 全胜上兵法（不战而屈人之兵）

- 输入：冲突成本太高（价格战、公开撕、硬碰硬）。
- 步骤：
  1. 排打法优先级：伐谋（改规则/换赛道）→ 伐交（联合/结盟/分化）→
     伐兵（正面打）→ 攻城（最下策，成本最高）；
  2. 能用上游手段解决的，绝不降到下游——价格战之前先想伐谋伐交；
  3. 自保全师：退也要完整地退（保住本金/团队/信用），不做焦土消耗。
- 输出：冲突处理路径（从伐谋起排）+ 底线动作（什么情况下退出、怎么保全身而退）。
- ✅完成标准：方案里"攻城式"硬拼动作要么有上游替代，要么写明止损线。

## 十条心法（快速检查用）

1. **兵者，国之大事，死生之地，存亡之道，不可不察也**——重大竞争决策前必须开庙算，不许拍脑袋上。
2. **多算胜，少算不胜**——算的深度决定胜率，方案没算透就等于没做。
3. **兵贵胜，不贵久**——打得快才有红利，久战拖垮自己（项目要设时限）。
4. **知彼知己，百战不殆**——对对手的了解和对的了解要一样多，只知己是半盲。
5. **善战者，致人而不致于人**——调动对手，别被对手调动（节奏主导权）。
6. **善战者，求之于势，不责于人**——赢要靠造势选形，不靠苛求个别的人拼命。
7. **兵无常势，水无常形**——打法随局面变，能因敌变化而取胜的才算会打。
8. **途有所不由，军有所不击**——有的路不走、有的仗不打，放弃也是战略动作。
9. **无恃其不来，恃吾有以待也**——不赌对手不来，赌自己有准备。
10. **三军可夺气，将军可夺心**——士气与心态是真实战力，先稳自己的心再谋对手的气。

## Agent 工作流

1. **判场景**：对照快速路由表选框架（一句话内部完成）。
2. **跑框架**：按步骤执行；组合时按"4→1→2→3"主序（先算后打）。
3. **按模板产出**（用户没指定格式时用）：

```
【庙算】可胜条件：…  缺口：…
【五事打分】道/天/地/将/法：…（对照对手，注证据）
【虚实与切入点】对手实：…  虚：…  我从哪下口：…
【打法】正兵：…  奇兵：…（验证动作：…）
【底线】不打/退出条件：…
【引一句】"…"（《孙子兵法·篇名》）   ← 可选，从 quotes.md 按场景取
```

4. **收尾引用**：需要金句时查 `references/quotes.md`，必附篇名出处。
5. ✅完成标准：输出里"庙算"和"底线"必须存在——没有撤退条件的竞争
   方案等于没做。

## 引用与合规

- 原文均为古文公有领域，短引用（单条 ≤40 字）+ 必附篇名出处（《计篇》
  《谋攻》《军形》《兵势》《虚实》《军争》《九变》《地形》《九地》《用间》等）。
- 方法论部分全部原创转述。
- 商业场景引用正常；不做军事暴力细节渲染，不给伤害他人的实际策略——
  只用于商业竞争/个人成长的正当场景。
- 金融类内容仍遵守投资建议红线，兵法引用不做收益承诺的修辞。

## 本 skill 不做什么

- 不做军事历史细节考据（那是历史内容，不是决策工具）。
- 不把"兵者诡道"用在欺骗用户/消费者的场景——对内对外诚信是前提，
  诡道只指竞争策略的不可预测性，不指欺诈。
- 不替代数据：框架判定必须落在框架4 的对照打分上，脱节的输出视为未完成。

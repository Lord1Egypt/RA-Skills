## Description:

Helps AI-agent users, skill authors, maintainers, and teams create SkillScan-style workflows for bug fixing, setup hardening, security checks, reliability improvements, and adjacent skill creation.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

AI-agent users, skill authors, maintainers, and teams use this skill to turn SkillScan-style security and reliability needs into concrete workflows, checklists, implementation support, and validation notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad auto-activation keywords can route unrelated user requests through this skill.

Mitigation: Review before installing in agents that auto-load skills; narrow invocation to explicit SkillScan or ClawHub security-workflow requests and disable or constrain implicit invocation.

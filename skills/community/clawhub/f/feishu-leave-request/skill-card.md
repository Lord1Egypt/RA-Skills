## Description:

Submit a leave request through Feishu (Lark). Use when the user wants to request time off, submit a leave application, or mentions taking leave.

This skill is ready for commercial/non-commercial use.

## Use Case:

Employees use this skill to collect, confirm, and submit leave request details through the Feishu desktop app approval workflow.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Incorrect leave dates, duration, type, or reason could be submitted to an employer approval system.

Mitigation: Collect all required details in one interaction and obtain explicit user confirmation before navigating or submitting the request.

Risk: Feishu desktop navigation may vary, causing the agent to choose the wrong page or miss required fields.

Mitigation: Report navigation errors clearly and ask the user for a screenshot when form fields or approval options do not match the expected workflow.

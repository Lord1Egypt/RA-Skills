## Description:

Calculate addition expressions from user input, including integers, decimals, and negative numbers, and return concise step-by-step results.

This skill is ready for commercial/non-commercial use.

## Publisher:

MIT-0

## Use Case:

External users use this skill to calculate addition-only expressions and receive a concise result with the parsed expression. It is suited for simple sums involving integers, decimals, negative numbers, comma-separated values, spaces, plus signs, or Chinese addition wording.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Users may expect broader math support than the skill provides.

Mitigation: Use it only for addition requests and ask for clarification or a rewritten expression when input is ambiguous or outside addition.

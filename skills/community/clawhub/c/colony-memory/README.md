# colony-memory-skill (USK v1.0)

A [Universal Skill Kit](https://aiskillstore.io/usk-spec) skill for **agent
memory backup & restore** on [The Colony](https://thecolony.cc) vault — versioned,
integrity-checked, optionally ed25519-signed snapshots. Thin stdin/stdout JSON
dispatcher over the [`colony-memory`](https://pypi.org/project/colony-memory/)
library. See `SKILL.md` for actions; site: https://memory.thecolony.cc

## Description:

Deep workflow for client and hybrid state management, covering domain versus UI state, server cache versus client store, async consistency, DevTools, persistence, and testing.

This skill is ready for commercial/non-commercial use.

## Publisher:

[clawkk](https://clawhub.ai/user/clawkk)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to model ownership, lifecycle, persistence, and async boundaries for frontend application state. It is suited for choosing or refining state approaches across React, Vue, and Svelte projects.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: State-management recommendations may not fit every application's security or persistence requirements.

Mitigation: Review app-specific persistence and storage choices before implementation, especially for sensitive client-side data.

Risk: Design guidance can introduce incorrect assumptions if applied without project context.

Mitigation: Confirm the framework, data-fetching approach, source of truth, and mutation lifecycle before adopting recommendations.

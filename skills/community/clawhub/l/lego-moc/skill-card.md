## Description:

Recognises LEGO parts from photos and helps design and verify LDraw models using a parts inventory or free build.

This skill is ready for commercial/non-commercial use.

## Publisher:

[garmanwu](https://clawhub.ai/user/garmanwu)

### License/Terms of Use:

MIT No Attribution

## Use Case:

LEGO builders use the skill to identify photographed pieces, manage a parts inventory, and create or check custom models. It can return model files and, for verified models, a public page with a 3D preview and building instructions.

### Deployment Geography for Use:

Global

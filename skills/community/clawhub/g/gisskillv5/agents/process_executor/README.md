# Agent 2: 处理执行Agent (Process Executor)

> 全局唯一知识ID: GIS-AGENT-002
> 隶属: 上层多Agent编排引擎
> 触发条件: 数据探查完成 → 按方案执行处理

## 职责

1. 接收Orchestrator下发的处理方案
2. 按工序顺序执行：坐标转换→格式互转→拓扑修复→编码校验
3. 每步记录日志，异常自动降级/重试
4. 输出处理后的成果数据 + 处理日志

## 输入

| 参数 | 说明 | 必填 |
|------|------|------|
| execution_plan | 工序清单JSON | 是 |
| input_data | 预处理后数据 | 是 |

## 输出

- 处理后的GIS成果数据
- 处理执行日志（含每步统计）

## 关联原子Skill

- ATS-001 坐标转换
- ATS-003 拓扑修复
- ATS-004 国标编码校验
- ATS-009 DWG↔GIS互转

## 熔断规则

- 最大3轮重试
- 第3轮仍失败 → 生成《人工待办清单》→ 终止

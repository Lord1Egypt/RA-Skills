## Description:

Send and receive files up to 25 MB directly between two AI agents across computers or teammates with human permission checks. Use when the user asks how to transfer files, logs, patches, screenshots, or artifacts from one AI agent to another on a different machine or team.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and agent users use this skill to set up ForAgent and transfer files up to 25 MB between agents on different computers or teammates' machines. The sending agent's owner approves folder access and the transfer.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: A transfer could expose sensitive contents or send a file to the wrong agent.

Mitigation: Check the recipient and review the file and approved folder access before approving the transfer.

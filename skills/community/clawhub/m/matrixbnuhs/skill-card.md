## Description:

Matrix-BNUHS is a React and TypeScript knowledge collaboration network for educational scenarios, covering multidimensional knowledge organization, collaborative editing, version control, permissions, knowledge capsules, multidimensional matrices, and virtual thinker features.

This skill is ready for commercial/non-commercial use.

## Known Risks and Mitigations:

Risk: Setup instructions ask users to install and run code from a mutable external repository.

Mitigation: Review the repository and lockfile first, prefer a pinned commit and npm ci, and run in an isolated environment without sensitive credentials.

Risk: Deployment guidance includes production Vercel deployment commands.

Mitigation: Confirm the target project, account, generated build output, and deployment permissions before running vercel --prod.

## Description:

Generates human-readable Markdown TRPG scenario files from existing YAML scenario files.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ice26985850](https://clawhub.ai/user/ice26985850)

### License/Terms of Use:

MIT-0

## Use Case:

External users and game masters use this skill to convert structured TRPG YAML scenario files into readable Traditional Chinese Markdown scenarios for preparation, printing, or table-side reference.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated Markdown may contain private campaign notes if the source YAML includes sensitive material.

Mitigation: Review generated .md files before sharing and keep private scenario material in controlled workspaces.

Risk: YAML-to-prose conversion may omit or misstate scenario details needed by a GM.

Mitigation: Compare generated Markdown against the source YAML before printing, publishing, or running the scenario.

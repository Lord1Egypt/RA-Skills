## Description:

Provides automated operations for Google Antigravity models, including multi-account rotation, quota-aware scheduling, session hot updates, and a dashboard.

This skill is ready for commercial/non-commercial use.

## Publisher:

MIT

## Use Case:

External developers and engineers use this skill to manage multiple Google Antigravity accounts, monitor quota, and rotate account/model sessions without restarting OpenClaw workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The dashboard exposes account and session controls too broadly for safe default installation.

Mitigation: Bind the dashboard to 127.0.0.1 and add authentication before deployment.

Risk: Bundled OAuth credentials and direct auth-profile/session changes can affect account access and active sessions.

Mitigation: Remove the bundled OAuth secret, use reviewer-approved credentials, and make auth-profile and session changes explicit and reversible.

Risk: Shell-string command execution and configurable model/account inputs increase abuse risk when inputs are not trusted.

Mitigation: Replace shell-string exec calls with argument-array process calls and validate model and account inputs before use.

# 提取标准流程与参数

本文件给出可照做的参数与结构定义。参数值是可调默认值，按表格密度与图像质量上下微调，调整后必须记录在还原说明里。

## 参数总表

| 参数 | 默认值 | 可调范围 | 说明 |
|---|---|---|---|
| 可读长边下限 | 1500 px | 800–2000 | 低于 800 px 直接拒答；800–1500 px 需 2 倍以上放大 |
| 最小字高 | 12 px | 10–16 | 低于此值字符粘连，OCR 与视觉同时不可靠 |
| 倾斜纠正阈值 | 1.5° | 0.5–3.0 | 水平线角度超过阈值即整图旋转 |
| 放大倍数 | 2.0 | 1.5–3.0 | LANCZOS；超过 3 倍不增信息，只增耗时 |
| 分片最大高度 | 300 px | 200–400 | 稠密表取小值 |
| 分片最大行数 | 15 行 | 8–20 | 与高度上限先到为准 |
| 分片重叠行 | 1 行 | 1–2 | 作为缝合锚，重叠行必须逐字一致 |
| 行聚类容差 | 0.4 行高 | 0.3–0.5 | 勾选标记的行归属用同值 |
| 列带边距 | 锚点中点 | 固定 | 相邻列锚点 x 中心的中点即列带边界 |
| OCR 置信度阈值 | 0.60 | 0.5–0.75 | 低于阈值进复核队列 |
| 视觉温度 | 0 | 固定 | 抽取任务不使用随机性 |
| 视觉输出上限 | 按片给足 | 4000–30000 | 出现长度截断即视为失败，不计入结果 |
| 校验容差 | 半个最小货币单位或 1e-6 | 按表定 | 整数表用 1e-6，金额表用 0.005 |

## 1. 预处理顺序

顺序不可打乱，每一步的产物都可复核：

1. 读原图尺寸与位深，记录到还原说明（尺寸是判断是否需要放大与分片的唯一依据）。
2. 灰度化（只做检测时用灰度，OCR 与视觉仍用彩色原图，避免彩色勾选标记丢失）。
3. 去噪：中值滤波，核大小 3。
4. 二值化：自适应阈值（局部窗口约为字高的 3 倍），全局阈值仅用于背景干净的截图。
5. 纠偏：用概率霍夫变换检测长水平线段，取角度中位数；旋转后再做一次水平线复检。
6. 放大：LANCZOS 2 倍，放大后再 OCR；视觉调用可用 1.4–1.8 倍裁剪图。
7. 分区：按水平线密度找到表头带（连续 2 条以上水平线的区域），表尾区取最后一个数据行之后。

## 2. 分片与缝合

- 数据区按累计高度切分，累计到 300 px 或 15 行即断片，断点对齐到行边界（不能切断字符）。
- 每片首行与上一片末行重叠 1 行，作为缝合锚。
- 缝合规则：若重叠行文本完全一致，删除本片首行；若不一致，标为“缝合冲突”，两行都保留并进复核队列。
- 全表行数记账公式：`总行数 = Σ(片行数) − 重叠行数 − 被删重复表头行数`。三个数都要记录，否则行数守恒无法验收。

## 3. 列模型 JSON

列模型是后续切分、校验、导出的唯一结构来源，必须先落盘再动数据。

```json
{
  "page": 1,
  "header_rows": [0],
  "columns": [
    {"key": "A", "name": "序号", "group": null, "unit": null,
     "type": "int", "x0": 0.031, "x1": 0.072, "confidence": 0.98, "inferred": false},
    {"key": "E", "name": "金额", "group": null, "unit": "元",
     "type": "number", "x0": 0.842, "x1": 0.918, "confidence": 0.95, "inferred": false}
  ],
  "splits": {"x": [0.031, 0.072, 0.413, 0.702, 0.842, 0.918], "y": [0.184, 0.221, 0.258]}
}
```

- `x0/x1` 用归一化坐标（0–1），与图像分辨率解耦，跨页同版式表可直接复用。
- `inferred: true` 表示列名由数据形态反推，必须在还原说明里列出。
- `group` 用于多级表头的父列名；`unit` 用于形态校验，空表示表头未声明单位。

## 4. OCR 调用与数字抽取

```python
FULLWIDTH = str.maketrans("０１２３４５６７８９．－，％", "0123456789.-,%")
NUM_RE = re.compile(r"-?\d+(?:[.,]\d+)?")

def normalize(text: str) -> str:
    return text.translate(FULLWIDTH).replace(" ", "").replace("\u00a0", "")

def to_number(text: str) -> float | None:
    m = NUM_RE.search(normalize(text))
    if not m:
        return None
    raw = m.group().replace(",", "")
    try:
        return float(raw)
    except ValueError:
        return None
```

- 只在“该列列带内”的数字块上取数；跨列的数字块先归列再取数。
- 负数三种写法都要覆盖：`-12.00`、`(12.00)`、`12.00-`；统一归一为负值，并记录原写法。
- 单位后缀（元、万元、kg、%）只从表头读，不从单元格读；单元格里出现的单位与表头不一致时进复核队列。
- 不把整串文本框强制转成数字：`10 个`、`约 1,200`、`<5` 这类必须走人工或按规则显式声明。

## 5. 视觉调用参数

- 每次调用只处理一片、只回答一类问题（列归属／合并跨度／单位），不混合任务。
- 提示词结构固定为：`表格区域`、`列字母与列名清单`、`要回答的问题`、`输出 JSON 结构`、`禁止项（不概括、不补行、不加注释）`。
- 必须关闭思考模式：思考型长输出会把可见答复挤空，表现为空回答。
- 必须检查结束原因：长度截断的返回一律丢弃，缩短分片后重问。
- 返回行数超过该片行锚数时按编行处理：删除无锚行，并在还原说明记“删编行 N 条”。

## 6. 记录与追溯

每一步都要留下可复核的记录，最终进入还原说明：

- 输入清单：文件名、尺寸、页序、是否扫描版。
- 分片清单：每片的像素区间、行区间、缝合结果。
- 列模型版本：每次修订写入时间与原因。
- 复核队列：每个疑点的“页-行-列 + 裁剪图路径 + 两个候选值 + 结论”。

## Description:

Multi-source keyword intelligence and autocomplete research that fetches real-time suggestions from Google, YouTube, Amazon, DuckDuckGo, and Bing without requiring an API key.

This skill is ready for commercial/non-commercial use.

## Use Case:

SEO professionals, content marketers, agency owners, and developers use this skill to expand seed keywords into keyword suggestion lists for content, ads, niche research, and keyword tooling.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: User-provided keywords are sent to external autocomplete providers.

Mitigation: Avoid entering confidential, regulated, or client-sensitive search terms unless disclosure to those providers is acceptable.

Risk: Default all-sources mode includes Bing, and default language and region values are German/Germany.

Mitigation: Select explicit sources, language, and region flags before running the script in workflows that require specific providers or locales.

Risk: Large expand-mode runs can make many provider requests without explicit rate-limit controls.

Mitigation: Use expand mode selectively and add workflow-level pacing for large batches.

# 第05课 函数

> 老孟带你学中文编程 · 第 05 课　|　语言面 ZHC-LANG 2.0　|　源码 `示例/第05课_函数.zc`
> 运行：`python -X utf8 zhc.py 示例/第05课_函数.zc --run`

## 一、本课目标

把重复逻辑封装成函数：带返回值、无返回值、多参数、递归四种形态各写一个。

## 二、语法要点

| 写法 | 说明 |
|---|---|
| `函数 名(参数:类型, …) 返回 类型 … 结束` | 带返回值，用 `返回 值` 交回结果 |
| `函数 名(参数:类型)` | 省略 `返回 类型` 就是无返回值函数 |
| `返回 值` | 立即结束函数并交回结果，可出现在分支里 |
| 递归 | 函数体内调用自身；阶乘是最小例子 |

## 三、完整代码

```zc
# 第05课 函数
# 函数 名(参数:类型, …) 返回 类型 … 返回 值 … 结束
# 参数必须写成 名:类型，多个用逗号分隔。

函数 平方(甲:整数) 返回 整数
    返回 甲 * 甲
结束

函数 较大者(甲:整数, 乙:整数) 返回 整数
    如果 甲 > 乙 则
        返回 甲
    否则
        返回 乙
    结束
结束

# 没有返回值就不写 返回 类型
函数 打招呼(名字:文本)
    输出 "你好，", 名字
结束

# 递归：函数里调用自己
函数 阶乘(数:整数) 返回 整数
    如果 数 <= 1 则
        返回 1
    否则
        返回 数 * 阶乘(数 - 1)
    结束
结束

# 无返回值函数单独调用
打招呼("老孟")

输出 "7 的平方：", 平方(7)
输出 "较大者：", 较大者(35, 68)
输出 "6 的阶乘：", 阶乘(6)

# 调用时参数个数/类型写错，会分别报 E303 / E302，报错里带 [Exxx] 码位
```

## 四、运行结果

```text
你好，老孟
7 的平方：49
较大者：68
6 的阶乘：720
```

## 五、易错点

- 参数必须写成 `名:类型`，漏类型报 `[E205]`。
- 调用时参数个数不对报 `[E303]`，类型不对报 `[E302]`，报错文本里带 `[Exxx]` 码位可直接查错误码库。
- 无返回值函数**只能单独成句调用**，写进 `输出` 的参数或任何表达式位置报 `[E307] 无返回值函数不能作为表达式使用`。
- **已修复（ZHC-LANG 2.0 实现修订 / 2026-11-15）**：早期「无返回值函数紧跟在一条参数里带函数调用的 `输出` 语句之后」会被错当成上一个输出的逻辑参数，生成 `printf("%s", (f(...)) ? "真" : "假")` 而在构建期报 `C2155`；现内核已把它按独立语句生成，写法顺序不再受限。若手上是旧版内核，仍可「先调用无返回值函数、再写带函数调用的输出」规避，详见同目录 `实测发现_内核缺陷.md` 缺陷 D-001。

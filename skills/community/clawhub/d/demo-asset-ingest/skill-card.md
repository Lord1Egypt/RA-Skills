## Description:

Demonstrates collaboration between a TaskFlow-style workspace process and the ClawHub CLI to prepare a publishable skill artifact and ingest it into the ClawHub resource center.

This skill is for demonstration purposes and not for production usage.

## Publisher:

[terrycarter1985](https://clawhub.ai/user/terrycarter1985)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and skill authors use this demo to see a repeatable workflow for preparing, validating, packaging, previewing, publishing, and finding a ClawHub skill artifact.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Running the publish command may make the demo skill discoverable in the ClawHub resource center.

Mitigation: Review the command and run the dry-run publish step before publishing.

## Description:

Orchestrate broad or multi-domain research by routing every query through a mandatory core of memory, self-improvement, brainstorming, research, web scraping, and market research, then add only the specialist skills that materially improve the answer.

This skill is ready for commercial/non-commercial use.

## Publisher:

[nemesis0017](https://clawhub.ai/user/nemesis0017)

MIT-0

## Use Case:

Developers, analysts, and operators use this skill to route broad research, strategy, comparison, market, SEO, pricing, launch, analytics, and current-digest questions into one structured answer with evidence, recommendations, and next steps.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill routinely pulls prior memory context for broad or ambiguous research requests.

Mitigation: Narrow activation to requests that need remembered project context and avoid forwarding unrelated memory-derived details.

Risk: The server security review marked the release suspicious because persistent-memory use is mandatory and unscoped.

Mitigation: Review the skill before installation and make memory use conditional on explicit user need with project-level scope.

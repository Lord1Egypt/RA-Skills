# 人才地图与竞品调研

## 一、人才地图 (Talent Mapping)

### 1.1 什么是人才地图

人才地图是系统性梳理目标公司/行业人才分布的工具，帮助招聘团队：
- 快速定位目标候选人
- 了解竞品公司组织架构
- 制定定向挖猎策略
- 建立长期人才储备

### 1.2 外部人才地图

#### 目标公司识别

**P0 优先级（核心竞品）**:
| 公司 | 规模 | 业务相似度 | 人才密度 | 挖猎难度 | 优先级 |
|------|------|-----------|---------|---------|--------|
| 竞品 A | 1000 人 + | 90% | 高 | 中 | P0 |
| 竞品 B | 500-1000 人 | 85% | 高 | 高 | P0 |
| 竞品 C | 200-500 人 | 80% | 中 | 低 | P0 |

**P1 优先级（相关行业）**:
| 公司 | 规模 | 业务相关性 | 人才可迁移性 | 优先级 |
|------|------|-----------|------------|--------|
| 相关行业 D | 500 人 + | 60% | 高 | P1 |
| 相关行业 E | 200-500 人 | 50% | 中 | P1 |

#### 目标部门识别

**示例：AI 算法岗位人才地图**

```
竞品 A 公司
├── AI 实验室 (优先级：P0)
│   ├── NLP 组 (20 人) ← 重点目标
│   ├── CV 组 (15 人)
│   └── 语音组 (10 人)
├── 技术部
│   ├── 算法平台组 (12 人) ← 重点目标
│   └── 工程架构组 (30 人)
└── 产品部
    ── AI 产品组 (8 人) ← 次级目标
```

**岗位名称关键词**:

- 算法专家、算法总监

**项目经验关键词**:
- 大模型应用、知识库问答、智能客服
- RAG 系统、Agent 开发、多轮对话

**标签分类体系**:

| 维度 | 标签示例 | 用途 |

| 院校标签 | 985/211/C9/QS 前 100/海外/硕士/博士 | 快速筛选学历背景 |
| 公司标签 | 大厂/互联网/OTA/AI 创业/外企 | 识别行业经验 |
| 技能标签 | RAG/Agent/数据分析/招聘管理 | 技能匹配 |
| 工具标签 | LangChain/Python/SQL/飞书 | 工具熟练度 |
| 领域标签 | AI/LLM/HR/BD/产品 | 行业领域 |
| 语言标签 | 英语工作/日语 N2 | 语言能力 |
| 证书标签 | PMP/CET6/初级经济师 | 专业资质 |

**人才搜索逻辑**:
```
给定岗位需求标签集合 R，候选人标签集合 C：
匹配度 = |R ∩ C| / |R| × 100%

示例：
岗位需求：[985, 硕士，大厂，RAG, Python, AI]
候选人 A: [985, 硕士，大厂，RAG, LangChain, AI]
匹配度 = 5/6 = 83.3% → 推荐
```

**高内推潜力员工识别**:

- 积极参与内推活动

**内推激励政策建议**:
- 基础奖金：入职转正后 ¥3,000-5,000
- 紧急岗位加成：+50%
- 高端岗位加成：+100%
- 内推王奖励：季度/年度额外奖励

## 二、竞品调研与 JD 分析

### 2.1 竞品 JD 收集

#### 收集渠道

**招聘平台**:
- Boss 直聘：搜索同行业同岗位
- 猎聘：中高端岗位 JD
- 智联/前程无忧：传统行业岗位

**公司官网**:
- 竞品公司官网"加入我们"页面
- 官方公众号招聘信息

**职场社交**:
- 脉脉：员工分享的 JD 和面试经验
- LinkedIn：外企岗位 JD

#### 竞品 JD 分析框架

**对比维度**:

| 维度 | 分析要点 |
|------|---------|
| 岗位职责 | 职责范围、核心 KPI、管理幅度 |
| 任职要求 | 学历、年限、技能栈、行业经验 |
| 薪酬范围 | Base、绩效、年终奖、期权 |
| 福利亮点 | 弹性工作、培训、健康、其他 |
| 团队介绍 | 团队规模、技术栈、发展方向 |
| 公司优势 | 行业地位、融资情况、发展前景 |

### 2.2 市场趋势分析

#### 技能需求变化

**热门技能追踪**:
```

AI 相关:
- RAG: +150% (从 20% JD 提到 → 50% JD 提到)

- LLM 应用：+180% (从 15% → 42%)

传统技能:
- Java: -10% (从 60% → 50%)
```

### 2.3 差异化建议

#### JD 优化建议

**突出本公司优势**:

如果本公司优势是**技术驱动**:
```
原 JD: "负责 AI 产品开发"
优化后："加入我们的 AI LAB，与 20+ 博士团队一起，
将最新大模型技术落地到亿级用户产品，
你的代码将影响千万用户！"
```

如果本公司优势是**成长空间**:
```
原 JD: "提供职业发展机会"
优化后："扁平化管理 + 导师制 + 快速晋升通道，
优秀者 18 个月可晋升一级，
已有 3 位同事从 P6 成长到 P8！"
```

如果本公司优势是**工作生活平衡**:
```
原 JD: "弹性工作"
优化后："真正的不打卡 + 弹性工作，
平均下班时间 18:30，
周末从不加班（我们有数据！）"
```

#### 薪酬竞争力建议

**市场分位策略**:

| 岗位级别 | 建议分位 | 理由 |
|---------|---------|------|
| 初级岗位 | 50-60 分位 | 市场供应充足，成本优先 |
| 中级岗位 | 60-75 分位 | 保证竞争力，吸引优秀人才 |
| 高级岗位 | 75-90 分位 | 关键人才，必须 market leading |
| 专家岗位 | 90 分位 + | 稀缺人才，不惜成本 |

**薪酬结构调整建议**:

如果 Base 竞争力不足:
- 增加绩效奖金比例
- 设计项目奖金
- 增加期权/股票激励
- 提供签字费 (Signing Bonus)

#### 招聘策略调整

**重点渠道调整**:

基于竞品分析发现:
- 竞品 A 在 Boss 直聘投入大 → 我们加强猎聘和脉脉
- 竞品 B 猎头使用频繁 → 我们加强内推渠道
- 竞品 C 校招做得好 → 我们提前锁定秋招

**定向挖猎策略**:

1. 识别目标公司关键人才
2. 通过脉脉/LinkedIn 建立联系
3. 邀请参加公司技术分享/开放日
4. 保持长期关系，等待合适时机

## 四、使用指南

### 4.1 何时使用人才地图

**适用场景**:
- 关键岗位招聘困难
- 需要快速组建团队
- 进入新业务领域
- 竞品公司挖猎

**不适用场景**:
- 基础岗位（简历充足）
- 非紧急招聘
- 预算有限

### 4.2 何时使用竞品调研

**适用场景**:
- 新岗位首次招聘
- JD 发布后响应低
- Offer 被频繁拒绝
- 薪酬竞争力存疑

**最佳实践**:
- 每季度更新一次竞品 JD
- 每半年更新一次市场薪酬数据
- 关键岗位招聘前必做竞品调研

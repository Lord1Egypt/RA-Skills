# Insight Skill

**Universal multi-perspective AI note analysis.** 25 thinking frameworks. Works with Obsidian, Flomo, Evernote, Dedao, and any markdown notes.

## 25 Perspectives

### Self-Discovery
- **Deep Scan** — Hidden assumptions and motivations
- **Inversion Check** — Flip every conclusion
- **Root Cause Trace** — Three whys to system level
- **Contradiction Finder** — Core tension driving dynamics
- **Blind Spot Reveal** — What you can't see about yourself
- **Mirror Check** — Read your notes as a stranger
- **Values Extraction** — What you really care about

### Emotional & Mental Health
- **Thought Trap Audit** — Cognitive distortion scanner
- **Non-Reaction Scan** — Control vs. let go
- **Resilience Inventory** — Your inner coping resources
- **Personality Fingerprint** — Writing style → cognitive preferences

### Motivation & Direction
- **Motivation Mapper** — What drives you, what drains you
- **Inner Compass** — Recurring questions as direction clues
- **Flywheel Blueprint** — Connect interests into compounding loops
- **Life Script Edit** — Notes as narrative scenes

### Action & Creation
- **Next Step Generator** — Vague → concrete → tomorrow
- **Theme Weaver** — Emerging threads across weeks of notes
- **Asset Inventory** — What you have that you're not using
- **Counter-Intuitive Mining** — Surprises contain the biggest insights
- **First Principles** — Strip to physical/logical bottom

### Quick Boost
- **Daily Wins** — Yesterday's small victories
- **Key Relationships** — People patterns in your notes
- **Mental Models Audit** — Multi-lens simultaneous analysis
- **Growth Patterns** — Belief shifts over time
- **Anxiety Deconstructor** — Fact vs. interpretation vs. control

## Features

- Multi-source: Obsidian / Flomo / Evernote / Dedao / Markdown
- Auto-detects handwritten notes vs web clippings
- Time range filtering (1d → 1y)
- Optional persona integration (14 character perspectives)
- Three output modes: append / separate / reply-only

## Installation

```bash
cp -r insight/ <your-agent-skills-dir>/insight/
```

No external dependencies. Works with any LLM agent that supports custom skills.

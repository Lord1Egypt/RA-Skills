# 小红书合规与限流风险清单

## 一、绝对化用语（必须替换）

| 高风险表达 | 替换方向 |
| --- | --- |
| 最好、最佳、最强、最低、最高级、第一 | 同价位里表现出色、我个人更推荐 |
| 国家级、世界级、顶级、殿堂级 | 有 XX 认证、行业常见工艺 |
| 100%、百分百、绝对、零风险 | 实测多数情况、我的使用感受是 |
| 绝无仅有、独一无二、仅此一家 | 目前我没找到同价位替代 |
| 全网最低价、销量第一 | 我买到的价格是 XX、同类里性价比不错 |

## 二、行业敏感词

- **美妆/护肤**：美白、祛斑、祛痘、抗炎、修复屏障、医美级、药妆。改为「提亮肤色」「改善出油」「我的使用感受」，不承诺疗效。
- **食品/保健**：减肥、瘦身、降血糖、降血压、抗癌、排毒、增强免疫力。改为「替代高糖零食」「我的饮食搭配」。
- **金融/理财**：稳赚、保本、零风险、翻倍、暴富、年化收益保证。只做知识科普，不做收益承诺。
- **教育/职场**：保过、包就业、七天速成、月入过万。改为「我的备考路径」「面试复盘」。
- **医疗**：治疗、治愈、根治、处方、药效。涉及疾病一律建议就医，不替代诊断。

## 三、导流与交易

禁止在笔记、封面、评论中出现：微信号、VX、QQ、手机号、二维码、外部链接、店铺名、暗号「主页看简介」「私信发你」。需要引导时改为「评论区聊聊」「主页有同系列」。

## 四、诱导互动

禁止「点赞抽奖」「关注+转发」「集赞解锁」「评论区扣 1 送资料」。可改成「你最想先看哪一条？我按票数排下一篇」。

## 五、虚假与侵权

- 不编造使用前后对比、销量、复购、用户评价、检测报告。
- 不用明星/素人肖像做暗示代言；引用他人图片需授权或明确来源。
- 不把「AI 生成图」说成实拍；不伪造聊天记录、订单截图。
- 测评需说明「自购/品牌赠送/合作」，不隐瞒利益关系。

## 六、限流自查顺序

1. 标题/封面是否含违禁词或导流词。
2. 正文是否大段复制、含其他平台水印、二维码。
3. 是否同一设备短时间高频发布、频繁改资料。
4. 是否诱导互动、虚假承诺、医疗金融越界。
5. 标签是否与内容无关、堆砌大词。

命中前两项先改内容，不要用「养号」「换设备」等违规手段绕过。

## 七、改写示例

- 原文：这款精华 7 天美白，全网最低价，私信我发链接。
- 改写：我用了一个月，肤色看起来更均匀；价格是我在大促时入的，评论区可以交流你的肤质。

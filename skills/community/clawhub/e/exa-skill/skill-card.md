## Known Risks and Mitigations:

Risk: The Exa MCP configuration uses an API key, and a completed endpoint URL may expose that key if shared, logged, or included in support requests.

Mitigation: Use a dedicated Exa API key where possible, keep MCP configuration files private, redact endpoint URLs before sharing, and rotate the key if exposure is suspected.

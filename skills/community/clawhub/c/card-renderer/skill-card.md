## Description:

为小红书文案生成不同风格的知识卡片附图（如 Mac Pro、赛博朋克、包豪斯风）。当用户需要将 Markdown 文案渲染成美观的图片卡片时使用。支持自动分段渲染封面和详情页。

This skill is ready for commercial/non-commercial use.

## Use Case:

Creators, marketers, and developers use this skill to turn Xiaohongshu Markdown or text copy into styled 1080x1440 image cards for social publishing.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated card images may contain undisclosed branding or security-looking decorative claims.

Mitigation: Review every generated image before publishing and remove or disclose style-added branding and status claims as appropriate.

Risk: Some styles may render less Markdown or fewer detail pages than the documentation implies.

Mitigation: Verify the selected style's cover and detail outputs against the source copy before using the images publicly.

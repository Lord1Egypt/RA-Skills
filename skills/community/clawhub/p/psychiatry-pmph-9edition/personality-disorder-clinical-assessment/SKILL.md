# 人格障碍综合临床评估

## 适用场景

当面对可能存在人格障碍或人格特征异常的个体时，按以下流程进行系统评估。

## 评估流程

### 第一步：概念界定与诊断边界确认

评估个体是否存在人格功能偏离，确定分类：

1. **正常人格**：人格特征在正常范围内，无明显功能损害
2. **人格困难**：有明显人格特征影响治疗/健康服务，但未达障碍程度，间歇性或低强度
3. **人格障碍**：明显偏离正常、根深蒂固、适应不良的行为模式
4. **人格改变**：获得性，成年期出现，继发于严重应激/脑损伤/严重精神障碍

**人格障碍核心判定标准**：
- 自我功能受损：认同感稳定性/连贯性、自我价值感、自我认知准确性、自我指导能力
- 人际功能受损：建立关系兴趣、理解他人观点、维持亲密关系、处理冲突能力
- 起病于童年/青少年/成年早期，持续至成年

### 第二步：严重程度四级评估

对已确认存在人格障碍或人格困难的个体，评估4个核心维度：

| 维度 | 评估内容 |
|------|----------|
| 自我功能 | 认同感、自我价值、自我认知、自我指导 |
| 人际功能 | 关系建立、观点理解、亲密维持、冲突处理 |
| 情绪/认知/行为 | 普遍性、严重程度、持续时间 |
| 功能损害 | 个人/家庭/社会/教育/职业领域痛苦或损害 |

**严重程度匹配**：

- **人格困难**：影响治疗但未达障碍标准，不归为精神障碍
- **轻度**：仅影响部分领域，某些情境可不表现，部分角色可维持，通常无严重伤害
- **中度**：影响多个领域，绝大多数角色受相当程度影响，有时会对自我/他人造成伤害
- **重度**：自我功能严重紊乱，所有关系有问题，几乎无履行角色能力，常与伤害相关

### 第三步：特质维度标注

对已诊断人格障碍的个体，评估5个核心特质领域（可多选）：

1. **负性情感**：广泛负性情感倾向、情绪不稳、消极态度、怀疑不信任
2. **分离（去依恋）**：回避社交/亲密、情感冷漠、表达受限
3. **去社会**：不在乎他人权益、自我中心、缺乏同理心、欺骗操纵
4. **脱抑制**：鲁莽冲动、不考虑后果、缺乏计划
5. **强迫**：完美主义、关注规则细节、僵化、规避风险

**边缘型模式补充标注**（若适用）：
- 广泛不稳定人格紊乱伴明显冲动
- 核心表现：避免抛弃的疯狂努力、不稳定人际、身份紊乱、情感不稳、慢性空虚、不适当愤怒、应激性分离/精神病样特征

**组合标注格式**：[严重程度] + [特质领域列表] + [边缘型模式（若有）]

### 第四步：亚型鉴别（如需传统分类）

参考详细临床特征进行亚型匹配，注意ICD-10类型有重叠，DSM-5分A/B/C三组。

关键鉴别点：
- **反社会型**：必须追溯18岁前品行问题
- **边缘型**：注意短暂应激性精神病性症状（持续几分钟到几小时），易误诊为精神分裂症
- **强迫型**：约70%强迫症患者病前有强迫型人格

### 第五步：病因机制分析（如需）

综合评估生物学与心理社会因素：

**生物学因素**：
- 遗传：单卵双生子同病率67%，边缘型遗传度0.69
- 神经生化：边缘系统过度反应→情绪不稳；前额叶抑制降低→冲动攻击
- 病理生理：50%患者脑电图慢波，提示大脑发育成熟延迟

**心理社会因素**：
- 童年经历：父母离异/爱的剥夺→反社会型风险
- 教养方式：态度不一致→边缘型；一贯苛求→偏执/强迫型

## 输出格式

```
人格状态分类：[正常/人格困难/人格障碍（轻/中/重）/人格改变]
特质标注：[特质领域列表] + [边缘型模式（若有）]
亚型参考：[具体类型（如适用）]
病因提示：[生物学易感性] + [环境触发因素]
```

## 注意事项

- 人格困难不归为精神障碍，归入影响健康状况的人际交往问题
- 人格损害越严重，适用的特质限定词越多
- 正常与异常人格为连续谱，无明确界限
- 中国人患病率（0.1%）可能因文化/诊断工具差异低于西方（2-10%）

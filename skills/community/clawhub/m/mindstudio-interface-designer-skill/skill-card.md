## Use Case:

Developers and builders use this skill to design, build, review, and refactor MindStudio Interface Designer React components for AI agent workflows. It emphasizes discovery interviews, exact workflow variable mapping, MindStudio bridge submission, accessibility, responsive layout, and production-quality UI implementation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated interfaces may collect files or personal data through MindStudio workflow inputs.

Mitigation: Review generated components, requested fields, and file upload behavior before deployment; collect only the data needed for the workflow.

Risk: Incorrect variable names or bridge submission patterns can prevent the interface from handing data to downstream MindStudio blocks.

Mitigation: Confirm variable mapping during discovery and test submit and loading behavior in MindStudio preview before release.

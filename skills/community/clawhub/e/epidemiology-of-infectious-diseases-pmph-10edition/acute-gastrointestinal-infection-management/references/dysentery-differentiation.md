# 细菌性痢疾vs阿米巴痢疾六维鉴别

| 维度 | 细菌性痢疾 | 阿米巴痢疾 |
|------|-----------|----------|
| 病原体 | 志贺菌 | 溶组织内阿米巴 |
| 流行病学 | 散发/流行，潜伏期短(数小时-7天) | 散发，潜伏期长(数周-数月) |
| 全身症状 | 发热+毒血症状明显 | 多不发热，少有毒血症状 |
| 腹部表现 | 腹痛重，里急后重明显，左下腹压痛 | 腹痛轻，无里急后重，右下腹压痛 |
| 腹泻特点 | 频繁(每天十余至数十次)，便量少 | 次数少(每天数次)，便量多 |
| 粪便特征 | 黏液脓血便；镜检大量WBC+RBC+吞噬细胞 | 暗红色果酱样，腥臭；WBC少RBC多，夏科-莱登结晶，可找到滋养体 |
| 血象 | WBC总数+中性粒明显增多 | 早期略增多 |
| 确诊 | 粪便培养志贺菌阳性 | 找到溶组织内阿米巴滋养体 |

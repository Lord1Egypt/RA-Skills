# 传染病病原治疗方案

本技能提供流行性脑脊髓膜炎和黑热病的标准化病原治疗方案，包括药物选择、剂量计算、给药方案和不良反应监测。

## 使用场景

- 高度怀疑或确诊流行性脑脊髓膜炎，需要制定抗菌治疗方案
- 确诊黑热病（内脏利什曼病），需要选择抗利什曼原虫治疗
- 需要根据患者年龄、过敏史、基础疾病调整用药方案
- 需要监测特定药物的不良反应

## 工作流程

### 第一步：确认诊断与评估

**流脑：**
- 确认高度怀疑或确诊流脑
- 明确患者年龄（成人/儿童）
- 确认青霉素过敏史

**黑热病：**
- 确认病原学或血清学确诊依据
- 评估基线心电图及肝肾功能
- 确认是否为孕妇或严重心功能不全者

### 第二步：选择治疗方案

#### 流脑抗菌治疗

**给药原则：**
- 一旦高度怀疑流脑，必须在30分钟内给予抗菌治疗
- 原则：尽早、足量、细菌敏感、能透过血脑屏障

**药物选择决策树：**

```
是否对青霉素过敏？
├─ 否 → 青霉素方案（首选）
└─ 是 → 能否使用氯霉素？
         ├─ 是 → 氯霉素方案
         └─ 否 → 头孢菌素方案
```

**各方案要点：**

1. **青霉素方案**（首选）
   - 成人：800万U，每8小时1次
   - 儿童：20万～40万U/kg，分3次
   - 溶媒：5%葡萄糖液静脉滴注
   - 疗程：5～7天

2. **头孢菌素方案**（青霉素和氯霉素均不可用时）
   - 头孢噻肟钠：成人2g，儿童50mg/kg，每6小时1次
   - 头孢曲松：成人2g，儿童50～100mg/kg，每12小时1次
   - 疗程：7天

3. **氯霉素方案**
   - 成人：2～3g，儿童50mg/kg，分次静滴
   - 疗程：5～7天
   - ⚠️ 警惕骨髓造血功能抑制

**耐药菌株处理：**
- 体温正常后3～5天
- 症状、体征消失
- 复查脑脊液正常后方可停药

#### 黑热病病原治疗

**药物选择决策树：**

```
是否对锑剂耐药或需要更好耐受性？
├─ 否 → 锑剂（葡萄糖酸锑钠SSG）方案（首选，便宜易得）
└─ 是 → 选择两性霉素B
         ├─ 需要减轻不良反应 → 脂质体两性霉素B（L-AmbB）
         └─ 考虑成本 → 普通两性霉素B
```

**锑剂（SSG）方案：**

1. **六日方案**（常规）
   - 成人总量：90~130mg锑/kg
   - 儿童总量：150~200mg锑/kg
   - 用法：平分6剂，每天肌注或静注1次，共6天

2. **三周方案**（体质差/危重患者）
   - 成人总量：133mg锑/kg
   - 儿童总量：200mg锑/kg
   - 用法：平分6剂，每周给药2次，共3周

**两性霉素B方案：**

1. **普通两性霉素B**
   - 首日1mg，渐增至0.5mg/(kg·d)
   - 疗程：共20天
   - 静滴至少6小时以减轻反应
   - 监测：肾毒性、低血钾

2. **脂质体两性霉素B（L-AmbB）**
   - WHO方案：3~5mg/(kg·d) 连用3~5天（累积15mg/kg）
   - 北美方案：3mg/kg 第1~5, 14, 21天（累积21mg/kg）

### 第三步：不良反应监测

**流脑治疗监测：**
- 青霉素：过敏反应
- 氯霉素：骨髓造血功能抑制（定期查血常规）

**黑热病治疗监测（重点）：**

锑剂心脏毒性监测：
- 定期查心电图
- 重点监测：T波倒置、Q-T间期延长、心律失常
- ⚠️ Q-T间期延长>0.5秒：显著增加致死性心律失常风险，需停药或干预
- 其他：关节肌肉痛、转氨酶/胰酶升高

### 第四步：疗效评估与停药

**流脑停药标准：**
- 体温正常后3～5天
- 症状、体征消失
- 脑脊液复查正常

**黑热病治愈标准：**
- 体温正常
- 症状消失
- 肝脾回缩
- 血象恢复
- 原虫消失
- 随访半年无复发

## 重要约束

**流脑：**
- 对青霉素过敏者禁用青霉素
- 氯霉素需警惕骨髓造血功能抑制

**黑热病：**
- 孕妇及严重心功能不全者慎用锑剂
- 对锑剂耐药或无效时需更换方案

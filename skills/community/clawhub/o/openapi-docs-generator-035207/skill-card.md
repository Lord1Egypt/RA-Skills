## Description: <br>
Helps API developers and backend teams generate, improve, and validate OpenAPI or Swagger documentation for REST APIs. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[kyro-ma](https://clawhub.ai/user/kyro-ma) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
API developers, backend teams, developer-experience teams, and maintainers use this skill to create practical OpenAPI or Swagger documentation workflows, checklists, implementation support, and validation notes for REST APIs. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may trigger on broad API or developer-experience wording and produce guidance outside the user's intended documentation task. <br>
Mitigation: Invoke it explicitly for OpenAPI or Swagger documentation work and confirm the requested scope before applying outputs. <br>
Risk: Generated OpenAPI specs, checklists, or workflow recommendations may be incomplete or inaccurate for a real service. <br>
Mitigation: Review generated outputs against the service implementation, route behavior, authentication requirements, and validation tooling before use. <br>

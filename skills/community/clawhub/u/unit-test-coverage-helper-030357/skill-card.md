## Description:

Helps software teams add useful unit tests, improve test coverage, and verify that code changes preserve existing behavior.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, QA engineers, maintainers, open-source contributors, and product teams use this skill to plan, add, and verify unit tests for existing codebases without relying on cloud-only workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad implicit invocation language may activate the skill for general testing or quality requests where it is not needed.

Mitigation: Narrow activation phrases or disable implicit invocation so the skill runs only for explicit unit-test or coverage requests.

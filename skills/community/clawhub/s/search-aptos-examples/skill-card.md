Developers and engineers use this skill to find and compare Aptos Move reference implementations before writing or adapting smart contract code. ## Known Risks and Mitigations:

Risk: Broad trigger phrases may activate this Aptos example-search workflow for generic example requests.

Mitigation: Use the skill when the task is about Aptos or Move, and narrow or ignore its guidance for unrelated example searches.

Risk: Reference examples can be outdated or unsuitable if copied without review.

Mitigation: Verify examples against current Aptos documentation, preserve security checks, adapt patterns deliberately, and test adapted code thoroughly.

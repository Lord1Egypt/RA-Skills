## Description:

Provides Chinese-language guidance for drafting NSFC grant proposals and directs users to the unified nsfc entrypoint for current workflows.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

External researchers and academic proposal writers use this skill for Chinese-language collaboration guidance when drafting NSFC proposals, including staged writing, outlining, citation verification, and terminology checks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Proposal-writing guidance can introduce inaccurate citations, unsupported method claims, or misleading grant text if accepted without review.

Mitigation: Verify all references, method claims, and generated proposal text before using them in an NSFC application.

Risk: Major document edits may overwrite important grant-drafting work.

Mitigation: Create backups or use version control before applying substantial edits.

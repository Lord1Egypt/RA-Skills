# 病原体致病能力评估

本技能用于对已分离或鉴定的病原微生物和寄生虫进行致病能力评估，输出综合评估报告。

## 前置条件
- 确认目标病原体已完成分离或鉴定。
- 已获取该病原体的基本生物学特性数据。
- 确认评估对象为生物性致病因子（排除毒物、放射线等）。

## 评估工作流

按照以下四个维度依次评估病原体的致病能力：

### 1. 评估侵袭力 (Invasiveness)
分析病原体侵入宿主及在体内扩散的能力：
- **侵入方式**：判断是直接侵入（如穿透皮肤/黏膜）、经消化道/呼吸道黏附后侵入、通过病毒受体结合入胞，还是经伤口进入。
- **逃避机制**：分析是否通过表面成分抑制吞噬作用，或表达定植因子结合宿主细胞以逃避免疫清除。

### 2. 评估毒力 (Virulence)
分析病原体产生毒素及其他致病因子的能力：
- **毒素类型**：明确是否产生外毒素（分析其与靶细胞受体结合入胞的机制）或内毒素（分析其激活单核/巨噬细胞及释放细胞因子的机制）。
- **其他致病因子**：评估穿透力、组织侵袭力、溶组织力，以及是否分泌细菌素以抑制竞争菌群。

### 3. 评估入侵数量 (Quantity)
分析引发感染所需的最低病原体数量：
- 确认同种传染病中入侵数量与致病力成正比的规则。
- 查阅并记录该病原体的特定感染阈值（如极低剂量即可致病的病原体需特别标注高风险）。

### 4. 评估变异性 (Variability)
分析病原体在传播或培养过程中的致病力变化趋势：
- **人工培养传代**：评估是否因多次传代导致致病力减弱（如疫苗株）。
- **宿主间传播**：评估是否因在宿主间反复传播导致致病力增强。
- **抗原变异**：评估是否通过抗原变异逃逸宿主特异性免疫，导致感染慢性化或反复感染。

## 输出要求

完成上述评估后，生成《病原体致病力综合评估报告》，必须包含以下核心内容：
1. **最低致病剂量预警**：明确引发感染所需的病原体数量阈值及风险等级。
2. **毒素类型提示**：明确外毒素/内毒素类型及其核心致病机制。
3. **变异风险评级**：基于抗原变异和传播特性，评估其致病力增强或免疫逃逸的风险。
4. **综合致病机制总结**：简述侵袭途径与逃避机制。

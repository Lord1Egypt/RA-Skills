## 九、已知局限（累计 11 条）

1. 语义类错误的列号定位到语句起始而非具体记号，编译器内部不做列精度分级
2. 评测基线来自历史样本而非受控评测集，需求描述未统一，方差大
3. 内置函数 29 个中内存类读写需手工偏移，模型极易越界（历史样本已出现过）
4. 复合类型（表/记录/列表/任意值）在 C 侧统一映射 zhc_val*，静态类型不做元素类型校验，越界在运行期报 E4xx
5. 页面导出不生成 script，交互需外部另接；响应式靠 container-type/clamp，不支持像素断点媒体查询
6. Astro 通道只生成源文件（package.json / astro.config.mjs / src/pages/*.astro），dist 由外部 npm run build 产出；ZHC 不内嵌 Node 构建器，以守单 exe 零依赖
7. MCP-2.0 服务端为 stdio 单进程模型；HTTP 传输只提供 路由头() 适配，未做长连接/流式推送；tasks/* 为单机实现，无跨进程任务仲裁
8. wasm 通道只验 wasip1；wasi-sdk 34 已废弃 --target=wasm32-wasi，CLI 取值沿用 wasm32-wasi 属命名历史债，ABI 以 wasm32-wasip1 为准
9. 不覆盖文件 I/O 的字节级一致：x86 文本模式落盘 CR LF、wasm 落盘 LF，行尾差异另案登记
10. no_std / 浏览器 wasm32-unknown-unknown 未纳入；wasm 性能与体积未设阈值
11. 第 9 条（文件 I/O 行尾差异）已由门禁 4.5 覆盖：现内核文件 I/O 全程二进制模式打开（wb/ab/rb），8 例落盘 SHA256 与 CRLF/LF 计数在两目标上完全一致，原条目保留作沿革；盘符绝对路径在 wasm 侧不可用（WASI 无卷语义），属目标能力差异、非语言缺陷，门禁 4.5 D2 已固定登记方向

## 十、修订规则

加关键字 = 主版本；加语句形态 = 次版本；内置函数只增不删；错误码一经分配永不复用；CLI 参数不许删除。正常不回退，仅门禁失败触发回退并重冻。

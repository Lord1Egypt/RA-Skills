## Description:

Comprehensive review and analysis of software engineering resumes in PDF format (frontend, backend, or ML domains).

This skill is ready for commercial/non-commercial use.

## Publisher:

[prabhatkgupta](https://clawhub.ai/user/prabhatkgupta)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, engineers, and job seekers use this skill to review software engineering resume PDFs for technical content, career progression, ATS compatibility, structure, grammar, and prioritized improvement opportunities.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Resume PDFs may contain personal information that becomes visible in the agent session during analysis.

Mitigation: Use the skill only with resumes the user is comfortable processing in the current environment and provide an explicit PDF path when invoking it.

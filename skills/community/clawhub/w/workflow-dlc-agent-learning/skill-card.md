## Description: <br>
Designs a logging-driven agent learning loop that turns interaction records into AI summaries, human-reviewed patterns, and curated experience rules. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and product teams use this skill to design an agent self-improvement workflow with structured interaction logs, bi-weekly AI reports, human review, and a three-layer experience base. It is especially relevant for teams that need traceable learning cycles across global, regional, and country-specific operating rules. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill promotes broad logging of user interactions and periodic reports, which can expose customer, employee, compliance, financial, or other sensitive data if adopted without controls. <br>
Mitigation: Use explicit logging notice, data minimization, input redaction where possible, strict report recipients, retention limits, and a clear way to disable or scope the logging workflow. <br>
Risk: AI-generated summaries can mistake isolated cases for reusable rules if they update the experience base without review. <br>
Mitigation: Require human review before patterns become rules and keep audit records for regional overrides and lifecycle decisions. <br>

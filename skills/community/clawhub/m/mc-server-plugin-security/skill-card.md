## Description:

A Minecraft server plugin security knowledge base for investigating, hardening, and upgrading plugins across Bukkit, Spigot, Paper, Leaf, Folia, Arclight, and NeoForge servers.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, server operators, and security reviewers use this skill to triage Minecraft plugin vulnerability claims, compare plugin versions, inspect jars, choose upgrade paths, and apply desensitized hardening guidance.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill is a mutable knowledge base and its content directs agents to persistently modify the installed skill from later conversations.

Mitigation: Install only when comfortable with that behavior; prefer a read-only installed directory during normal use, or require reviewable patches and explicit approval before SKILL.md updates.

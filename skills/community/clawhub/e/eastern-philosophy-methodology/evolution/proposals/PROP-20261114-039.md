## 变更内容

新增应用 Skill：APP-007 经营逆境应对（综合逆境）v1.0.0。

**场景定义**：目标——增长停滞/慢性失血/口碑危机三类逆境中的生存与扭转：先止血、再稳局、后扭转；约束——资源持续流失（现金/人才/客户信心）、士气受挫、外界观望、时间压力随类型不同；角色——经营负责人（一把手或受命扭转局面的负责人）；典型输入——连续多季增长停滞/现金流可支撑月数告急/重大负面舆情爆发。

### depends 清单（10 项，均 @1.0.0）

| atomic | version | role |
|--------|---------|------|
| MZD-02 | 1.0.0 | 定纲——逆境类型决定主要矛盾：现金（生存）优先于增长，增长优先于舆情（抓主要矛盾） |
| MZD-05 | 1.0.0 | 战略节奏——防御/相持/反攻三阶段，每阶段只有一个主题（持久三阶段） |
| ZGF-03 | 1.0.0 | 情绪纪律——咽下挫败不外泄，以徐图自强为唯一回应（打脱牙和血吞） |
| SZ-16 | 1.0.0 | 断臂纪律——砍业务、砍动作、砍管线（有所不为） |
| SZ-11 | 1.0.0 | 止血速度——危机期速度优先于完美（兵贵拙速） |
| SZ-15 | 1.0.0 | 害中见利——危机双栏核算，防恐慌放弃出路（杂于利害） |
| GZ-07 | 1.0.0 | 征兆监测——裂痕初萌即修，隙微时低成本介入（抵巇塞隙） |
| MZD-29 | 1.0.0 | 纠偏力度——对停滞性积弊过量纠、猛纠（矫枉过正） |
| GZ-31 | 1.0.0 | 舆情应对——辨言论之曲故，出言先测舆论环境（众口铄金，口碑危机分支） |
| SZ-27 | 1.0.0 | 蓄力——逆境中保存并积蓄团队核心战力（并气积力） |

### 组合公式要点

- **顺序**：判型定纲（MZD-02：现金/增长/舆情何为主要矛盾）→ 止血〔SZ-11 快+SZ-16 断〕→ 稳局〔SZ-27 保战力+ZGF-03 情绪纪律+GZ-07 修隙〕→ 扭转〔MZD-29 纠偏+SZ-15 转机清单〕，全程 MZD-05 定阶段主题、GZ-31 支撑舆情分支。
- **条件分支**：现金流危机→止血优先全速；增长停滞→MZD-29 纠偏+GZ-07 找隙为主；口碑危机→GZ-31 舆情纪律优先，硬事实核对与出言测环境并行。
- **冲突裁决**：止血（SZ-16 砍）与蓄力（SZ-27 保）冲突时——核心战力（关键人才与能力）列入"不可砍"，其余按现金流倒排；MZD-29 猛纠与团队承受力冲突时——生存优先于安抚，但矫枉范围限"积弊"不限"人"；ZGF-03 吞忍与核心生存利益冲突时——吞有底线，止损止损。
- **失效预案**：止血无效跑道见底 → 退回 SZ-15+MZD-02（害中寻利重定主要矛盾：并壳/出售/转型按利害双栏裁决）；三阶段误判（把相持当反攻冒进）→ 退回 MZD-05 判据（力量对比拐点未到不反攻）。

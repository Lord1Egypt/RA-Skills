## Description:

Helps API developers, backend teams, and developer-experience teams generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineering teams use this skill to turn REST API requirements into practical OpenAPI or Swagger documentation, checklists, workflows, code-oriented guidance, and validation notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad API and developer-experience trigger wording may invoke the skill when a narrower documentation workflow would be more predictable.

Mitigation: Review invocation behavior during installation and narrow trigger phrases or usage guidance if accidental activation is observed.

Risk: Generated OpenAPI or Swagger guidance can be incomplete or inconsistent with the user's actual service behavior.

Mitigation: Validate generated documentation against implementation routes, schemas, authentication behavior, and API examples before publishing.

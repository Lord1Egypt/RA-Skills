## 🚀 核心能力矩阵

| 阶段 | 核心能力 | 关键框架 |
|------|---------|---------|
| 1️⃣ 战略与行业分析 | 宏观环境 · 行业趋势 · 市场机会 | PESTLE · Porter 五力 · SWOT · TOWS · VRIO |
| 2️⃣ 市场与客户洞察 | 市场细分 · 客户画像 · 市场规模 | TAM-SAM-SOM · 客户旅程地图 · Jobs-to-Be-Done |
| 3️⃣ 竞争情报 | 竞品分析 · 竞争定位 · 对标研究 | BCG 矩阵 · GE-McKinsey · Ansoff · 蓝海战略 |
| 4️⃣ 财务分析与建模 | 估值 · 盈利预测 · 投资分析 | DCF · NPV · IRR · Break-Even · 敏感性分析 |
| 5️⃣ 商业模式设计 | 商业模式创新 · 验证 · 迭代 | BMC · 精益画布 · 价值主张画布 |
| 6️⃣ 利益相关者管理 | 识别 · 分析 · 沟通策略 | RACI · 权力-利益矩阵 · 影响力地图 |
| 7️⃣ 需求引出与发现 | 访谈 · 工作坊 · 观察 · 问卷 | SPIN · 5Whys · 鱼骨图 · 用户故事 |
| 8️⃣ 需求分析与规范 | 建模 · 优先级 · 验证 | MoSCoW · Kano · BDD · EventStorming |
| 9️⃣ 解决方案评估 | 方案对比 · 选择 · 验证 | 决策矩阵 · AHP · 成本效益分析 |
| 🔟 商业论证与投资决策 | 商业论证 · 投资回报 · 风险 | Five Case Model · ROI · 敏感性分析 |
| 1️⃣1️⃣ 业务流程分析与再造 | 流程建模 · 优化 · 再造 | BPMN · 价值流图 · SIPOC · Lean |
| 1️⃣2️⃣ 数据分析与商业智能 | 数据驱动决策 · 仪表板 | 描述性/诊断性/预测性/规范性分析 |
| 1️⃣3️⃣ 风险分析与决策科学 | 风险识别 · 评估 · 应对 | FMEA · 决策树 · 蒙特卡洛模拟 |
| 1️⃣4️⃣ 实施落地与变革管理 | 变革管理 · 落地执行 | ADKAR · Kotter 8 步 · 平衡计分卡 |

## 📦 快速开始

```bash
cp -r ba-workbench ~/.claude/skills/
```

**触发方式**：直接描述需求，支持 30+ 中文别名和 10+ 英文别名：
- "帮我做一份行业分析报告"
- "写一份商业论证 Business Case"
- "做竞品分析"
- "帮我做利益相关者分析"
- "评估这个商业模式的可行性"

# 知情同意操作指南

## 知情同意书核心要素

### 必须包含内容

1. **诊断说明**
   - 当前诊断
   - 诊断依据（简要）
   - 病情严重程度

2. **治疗方案**
   - 推荐治疗及理由
   - 具体治疗方式
   - 预计疗程

3. **预期效果**
   - 可能的治疗效果
   - 起效时间
   - 疗效不确定性

4. **风险说明**
   - 常见不良反应
   - 严重但罕见的风险
   - 风险发生率（如可量化）

5. **替代方案**
   - 其他可选治疗
   - 各方案优劣比较
   - 不治疗的后果

6. **费用信息**
   - 预估费用
   - 医保覆盖情况

7. **权利说明**
   - 随时撤回同意的权利
   - 拒绝治疗的权利
   - 寻求第二意见的权利

## 特殊情境知情同意

### 无决定能力患者

```
流程：
1. 评估并记录无能力
2. 确定法定代理人
   ├─ 监护人
   ├─ 近亲属
   └─ 指定代理人
3. 向代理人充分告知
4. 代理人签署同意
5. 记录决策符合患者最佳利益
```

### 未成年人

- 需监护人同意
- 根据年龄给予适当解释
- 尊重未成年人的合理意愿
- 16岁以上以自己劳动为主要生活来源者，可自行同意

### 非自愿住院患者

- 仍需尽可能获取知情同意
- 无法同意时按无能力处理
- 定期重新评估同意能力
- 记录每次尝试获取同意的过程

## 知情同意能力评估工具

### 结构化评估问题

| 维度 | 评估问题 |
|-----|---------|
| 理解 | "您能用自己的话告诉我，医生说要给您做什么治疗吗？" |
|  appreciation | "您觉得这个治疗对您有帮助吗？为什么？" |
| 推理 | "如果您接受/拒绝这个治疗，可能会发生什么？" |
| 表达 | "您能告诉我您的决定吗？" |

### 评分参考

- 每个维度0-2分
- 总分≥6分：有能力
- 4-5分：边缘，需进一步评估
- <4分：无能力

## 常见误区

| 误区 | 正确做法 |
|-----|---------|
| 精神障碍=无能力 | 针对具体决策评估能力 |
| 家属同意=患者同意 | 患者有能力时必须本人同意 |
| 紧急情况可省略同意 | 紧急例外有严格条件 |
| 签了字就完成了 | 确保真正理解才是关键 |
| 一次同意永久有效 | 重大变化需重新同意 |

## 文档保存要求

- 知情同意书原件存入病历
- 能力评估记录单独存档
- 代理人授权文件保存
- 撤回同意记录
- 保存期限：至少15年

# 联网分析模板：使用 Serenity 框架分析任意股票/板块/行业

> 本模板用于指导如何联网获取实时数据，并应用 Serenity 供应链瓶颈框架进行分析。

---

## 一、触发条件

以下情况需要触发联网分析：

| 情况 | 是否触发联网 | 说明 |
|------|----------------|------|
| 分析的标的不在 Serenity 高频持仓列表（Top 10）| ✅ 是 | 需要获取该标的最新数据 |
| 需要最新财报数据（>3 个月前）| ✅ 是 | 财报数据过期 |
| 需要最新政策/新闻（如出口管制更新）| ✅ 是 | 政策变化快 |
| 用户明确要求"获取最新数据" | ✅ 是 | 用户主动要求 |
| 分析的标的在 Serenity 高频持仓列表 | ❌ 否 | 可使用 skill 内置知识 |
| 分析 A 股标的 | ✅ 是 | 需要 A 股特有数据 |

## 二、数据获取工具选择

### 工具优先级

| 优先级 | 工具 | 适用场景 | 说明 |
|--------|------|----------|------|
| 1 | `westock-data` | 美股/港股/A 股行情、财报、研报 | 数据最全，推荐首选 |
| 2 | `iFinD-Finance-Data` | A 股优选 | 同花顺数据，A 股覆盖好 |
| 3 | `web-tools-mcp` | 行业报告、新闻、供应链信息 | 搜索能力强大 |
| 4 | `wb-finance-skill` | 综合金融分析 | 备用方案 |

### 工具调用示例

**示例 1：获取美股 $SMCI 的最新财报**

```markdown
使用 `westock-data` 工具：
- 调用 `westock-data` 的 `get_stock_financials` 功能
- 参数：symbol = "SMCI", data_type = "quarterly"
- 获取：营收、毛利率、市占率、产能指引
```

**示例 2：搜索"AI server supply chain bottleneck"**

```markdown
使用 `web-tools-mcp` 工具：
- 调用 `web-tools-mcp` 的 `web_search` 功能
- 参数：query = "AI server supply chain bottleneck 2026", num_results = 10
- 获取：行业报告、新闻文章、分析文章
```

**示例 3：获取 A 股"绿的谐波（688017）"的财报**

```markdown
使用 `iFinD-Finance-Data` 工具：
- 调用 `iFinD-Finance-Data` 的 `get_stock_financials` 功能
- 参数：symbol = "688017.SH", data_type = "quarterly"
- 获取：营收、毛利率、市占率、产能指引
```

## 三、分析工作流程

### 步骤 1：判断是否需要联网

```
IF 标的 NOT IN Serenity_Top10
   触发联网 = TRUE
ELSE IF 财报日期 < 3 个月前
   触发联网 = TRUE
ELSE IF 用户要求"最新数据"
   触发联网 = TRUE
ELSE
   触发联网 = FALSE
```

### 步骤 2：获取实时数据

**2.1 获取股票基本信息**

| 数据项 | 获取工具 | 用途 |
|--------|----------|------|
| 股票代码、名称 | `westock-data` | 确认标的 |
| 当前价格、市值 | `westock-data` | 估值判断 |
| 日均成交量 | `westock-data` | 流动性判断 |
| 52 周高低 | `westock-data` | 价格区间 |

**2.2 获取财报数据**

| 数据项 | 获取工具 | 用途 |
|--------|----------|------|
| 营收（TTM）| `westock-data` | 成长判断 |
| 营收增长率（YoY）| `westock-data` | 成长判断 |
| 毛利率 | `westock-data` | 定价权判断 |
| 净利率 | `westock-data` | 盈利能力 |
| 市占率 | `westock-data` 或 Web 搜索 | 竞争格局 |
| 产能指引 | 财报 transcript | 供需判断 |

**2.3 获取供应链数据**

| 数据项 | 获取工具 | 用途 |
|--------|----------|------|
| 上游供应商 | Web 搜索 | 瓶颈识别 |
| 下游客户 | Web 搜索 | 需求判断 |
| Lead time | Web 搜索或行业报告 | 供需判断 |
| 产能利用率 | Web 搜索或行业报告 | 供需判断 |
| 涨价通知 | Web 搜索或新闻 | 定价权判断 |

**2.4 获取政策/地缘数据**

| 数据项 | 获取工具 | 用途 |
|--------|----------|------|
| CHIPS ACT 拨款 | 政府网站或新闻 | 政策信号 |
| 出口管制 | 政府网站或新闻 | 地缘信号 |
| 国防生产法 | 政府网站或新闻 | 政策信号 |

### 步骤 3：应用 Serenity 框架

将步骤 2 获取的数据输入 Serenity 五层金字塔框架：

**第一层：宏观资本开支指引（需求上限）**

- 使用最新 hyperscaler Capex 数据
- 调用 `westock-data` 获取 $MSFT、$AMZN、$GOOGL 最新财报中的 Capex 数据
- 判断：AI Capex 是否持续增长？

**第二层：瓶颈识别（供给侧约束）**

- 使用最新供应链数据
- 调用 Web 搜索获取：
  - 上游产能数据
  - Lead time 数据
  - 涨价通知
- 判断：哪个环节最窄？巨头绕不开哪个？

**第三层：公司筛选（谁捕获利润）**

- 使用最新财报数据
- 对比同行业公司的：
  - 毛利率
  - 市占率
  - 产能
- 判断：哪个公司捕获最多利润？

**第四层：仓位管理（核心仓 / 摆动仓 / 彩票仓）**

- 使用实时波动率数据
- 判断：
  - 核心仓（高 conviction）：仓位 >10%
  - 摆动仓（中等 conviction）：仓位 5-10%
  - 彩票仓（投机）：仓位 <2%

**第五层：执行（围绕核心仓做日内交易）**

- 使用实时价格数据
- 判断：
  - 当前价格是否合理？
  - 是否有更好的买点？

### 步骤 4：生成分析报告

报告包含以下部分：

**1. 框架分析（五层金字塔）**

```
## 宏观需求
[使用最新 hyperscaler Capex 数据]

## 瓶颈地图
[使用最新供应链数据，绘制供应链图谱]

## 公司筛选
[使用最新财报数据，对比同行业公司]

## 仓位建议
[基于实时波动率和流动性]

## 风险因素
[使用最新政策/地缘新闻]
```

**2. 实时数据验证**

```
### 数据来源
- 股票行情：[来源]，获取时间：[时间]
- 财报数据：[来源]，财报日期：[日期]
- 供应链数据：[来源]，搜索时间：[时间]
- 政策/地缘数据：[来源]，发布时间：[时间]
```

**3. 与 Serenity 持仓的对比**

```
### Serenity 持仓对比
- Serenity 是否持有该标的？[是/否]
- 如果是，Serenity 的建仓价格：[价格]
- Serenity 的最新观点：[观点]
```

**4. 风险提示**

```
### 风险提示
- 数据时效性：[说明数据是否最新]
- 供应链复杂性：[说明供应链是否难以映射]
- 地缘敏感性：[说明政策变化风险]
```

## 四、分析示例

### 示例 1：分析 $SMCI（不在 Serenity 高频列表中）

**用户请求：** "用 Serenity 框架分析 $SMCI"

**工作流程：**

1. **判断是否需要联网**：✅ 是（$SMCI 不在 Top 10）

2. **获取实时数据**：
   - 调用 `westock-data` 获取 $SMCI 最新财报
   - 调用 `web-tools-mcp` 搜索"AI server supply chain bottleneck"

3. **应用框架**：
   - **宏观**：Hyperscaler Capex 增长 → 需求强
   - **瓶颈**：$SMCI 是 AI 服务器组装厂，无定价权 → 不符合 Serenity 标准
   - **公司**：毛利率低（~12%），市占率高（~20%）→ 组装厂，无瓶颈定价权
   - **结论**：不建议（组装厂，无瓶颈定价权）

4. **生成报告**：
   - 框架分析：不符合 Serenity 瓶颈理论
   - 实时数据验证：标注数据来源和时间
   - 与 Serenity 持仓的对比：Serenity 未持有 $SMCI
   - 风险提示：组装厂竞争激烈，毛利率低

   - **公司**：绿的谐波国内市占率 >60% → 一线

## 五、注意事项

1. **数据时效性**：标注所有数据的获取时间，避免使用过期数据。

2. **来源可靠性**：优先使用官方财报、政府公告，避免使用未经证实的新闻。

3. **供应链复杂性**：某些行业的供应链难以映射（如消费电子），需要更多研究。

4. **地缘敏感性**：出口管制等政策变化快，需要最新信息。

5. **A 股特殊性**：A 股供应链数据与美股不同，需要使用 iFinD 或 westock-data 的 A 股模块。

6. **小盘股流动性**：Serenity 偏好小市值公司（10-20 亿美元），但这些股票流动性差，大资金难以建仓/退出。

7. **过度杠杆风险**：Serenity 使用 margin（~1.4x），但警告过度杠杆。普通投资者应谨慎使用 margin。

## 六、模板使用指南

### 如何使用本模板

1. **接收用户请求**：理解用户想要分析的标的（股票/板块/行业）

2. **判断是否需要联网**：参考"一、触发条件"

3. **选择数据获取工具**：参考"二、数据获取工具选择"

4. **按工作流程执行**：参考"三、分析工作流程"

5. **生成分析报告**：参考"四、分析示例"

### 模板定制化

- **板块分析**：如果需要分析整个板块（如"光通信板块"），可以修改步骤 2 获取板块内多个公司的数据，然后在步骤 3 中对比分析。
- **行业分析**：如果需要分析整个行业（如"AI 基础设施行业"），可以修改步骤 2 获取行业内多个公司的数据，然后在步骤 3 中绘制行业供应链图谱。

# Missing primitive finder

When the user describes a workflow, identify missing primitives and propose names for them.

- Namespace care (anti-generic): if a candidate is too generic, add a vitality marker, add a role marker (pay / verify / claims / docs), or produce a set so the network has handles, not mush.
- Social liquidity: prefer names that will be repeated, tagged, and remembered over names that are technically available but socially dead.
- Offered, not fenced: a primitive named for the network is offered to it; the skill says which posture the name takes.

Common missing primitives in agent economies (illustrations only; these names are spent by being printed here, not for use, and still unchecked): handoff bundle → workpack, taskpack; receipt for work → workreceipt, claimreceipt; ask lifecycle → askloop; multi-party payout → splithub, splitrail.

When proposing a primitive, also give one sentence of what it is and one of why agents need it now.

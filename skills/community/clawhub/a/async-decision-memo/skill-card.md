## Description:

Run an asynchronous decision process that produces a decision memo, named roles, response windows, comment-resolution rules, a kickoff message, and a closing note without relying on a meeting.

This skill is ready for commercial/non-commercial use.

## Publisher:

[mohitagw15856](https://clawhub.ai/user/mohitagw15856)

### License/Terms of Use:

MIT-0

## Use Case:

Employees and external teams use this skill to replace a decision meeting with a bounded written process. It helps an agent draft the memo, kickoff message, stakeholder roles, response window, comment rules, escalation path, and closing note for an asynchronous decision.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The process can shape real team decisions by treating consulted stakeholders' silence as consent.

Mitigation: Use it only where that decision rule is acceptable, name consulted stakeholders explicitly, and review the kickoff text before posting it.

Risk: Deadline, escalation, and dissent-recording language may affect workplace commitments or decision records.

Mitigation: Have the decider review generated closing text for accuracy before filing or sharing it in a workplace system.

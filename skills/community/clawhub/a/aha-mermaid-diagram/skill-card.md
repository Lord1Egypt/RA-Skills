## Description:

Create professional software diagrams using Mermaid syntax, including class, sequence, flowchart, ERD, C4 architecture, state, git graph, and Gantt diagrams with rendering, theming, styling, and interactive-feature guidance.

This skill is ready for commercial/non-commercial use.

Developers, architects, and technical writers use this skill to turn software architecture, domain models, database schemas, process flows, API interactions, and project timelines into Mermaid diagrams and renderable examples.

Global

## Known Risks and Mitigations:

Risk: HTML rendering examples may load Mermaid from a third-party CDN.

Mitigation: Use a pinned Mermaid version or self-hosted dependency before copying rendering snippets into production or sensitive environments.

Risk: Generated diagrams or examples may include untrusted Mermaid input, loose security settings, or interactive links.

Mitigation: Avoid securityLevel: 'loose' for untrusted diagrams, keep Mermaid input size limits conservative, and review interactive links before use.

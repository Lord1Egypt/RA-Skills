## Use Case:

Employees, external users, developers, researchers, analysts, and investigators use this skill to plan and execute advanced information retrieval across web, academic, legal, government, patent, news, industry, and specialized sources. It helps optimize queries, select sources, validate credibility, curate results, and synthesize findings for decision-making.

## Known Risks and Mitigations:

Risk: Broad online or database research may touch private, sensitive, paid, or credentialed sources if the user asks for an overly broad search.

Mitigation: Keep each search scoped, confirm source constraints up front, and use private, sensitive, paid, or credentialed sources only when the user is authorized to access them.

Risk: Search guidance and curated findings can be incomplete, stale, biased, or misleading when source quality and currency are not checked.

Mitigation: Prioritize authoritative sources, validate currency and credibility, compare across source types, and clearly cite or label uncertain findings.

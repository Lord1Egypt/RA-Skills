# HFRS病理生理机制

## 休克机制

### 1. 低血容量性休克（渗漏综合征）
- 血管通透性增加 → 血浆大量渗出
- 有效循环血量急剧减少

### 2. DIC
- 内皮损伤 + 组织凝血酶释放 + 血液浓缩/酸中毒
- 消耗性凝血障碍

### 3. 心肌损伤
- HV直接损伤心肌
- 缺血/酸中毒 → 心输出量下降

## 出血机制（各期不同）

| 分期 | 主要机制 |
|------|----------|
| 发热期 | 血管壁受损 + 血小板减少 |
| 休克期 | DIC为主 |
| 少尿期 | 尿毒症影响凝血/血小板 + DIC后期纤溶亢进 |

### 血小板减少四大原因
1. 生成减少（巨核细胞损伤）
2. 消耗增多（修补血管）
3. 破坏增加（免疫复合物激活补体）
4. 功能障碍（HV受体直接损伤/尿毒症毒素）

## 急性肾衰竭机制

1. 有效循环血量减少 → GFR下降
2. 肾小管阻塞（蛋白凝块/脱落细胞）
3. 间质水肿压迫

## 肺部并发症（发生率60%）

| 类型 | 发生时期 |
|------|----------|
| 原发性肺水肿 | 发热/低血压期 |
| 尿毒症肺 | 少尿末/多尿初 |
| ARDS | 低血压期或稳定后1-2天 |
| 心源性肺水肿 | 少尿期 |
| 弥漫性肺泡出血 | 各期 |

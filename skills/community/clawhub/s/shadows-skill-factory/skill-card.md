## Description:

Meta-skill for creating new agent skills — generates well-structured SKILL.md files with proper frontmatter, triggers, protocols, and rules.

This skill is ready for commercial/non-commercial use.

## Publisher:

[nakedoshadow](https://clawhub.ai/user/nakedoshadow)

### License/Terms of Use:

MIT

## Use Case:

Developers and skill authors use this skill to turn recurring agent workflows into reusable SKILL.md files with clear triggers, prerequisites, process steps, security considerations, and output expectations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated skills may contain overly broad triggers, unnecessary tool or credential requirements, or unsafe command guidance.

Mitigation: Review each generated SKILL.md before installing or publishing it, with particular attention to trigger scope, requested tools, credentials, shell commands, and network access.

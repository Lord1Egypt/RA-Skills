# 投标文档助手

用于竞争性磋商/招标项目的投标文件框架搭建和技术方案编写。

## 触发条件

用户提到以下任一关键词时触发：
- 招标文件 / 竞争性磋商文件 / 投标文件
- 标书 / 投标 / 技术方案 / 施工组织设计
- 评分标准 / 响应文件

## 工作流程

### 1. 询问用户需求

当技能被触发时，首先向用户确认本次投标的具体需求：

1、根据招标文件要求搭建投标文件框架
2、根据招标文件评分标准编写技术方案（图文版）
3、两者都需要

根据用户选择，执行对应步骤：
- **选择1**：执行步骤2（评分标准分析）+ 步骤3（搭建投标文件框架）
- **选择2**：执行步骤2（评分标准分析）+ 步骤4（编写技术方案）
- **选择3**：执行完整流程（步骤2→3→4→5→6→7）

### 2. 读取招标文件

读取用户提供的 `.docx` 招标文件，提取以下关键信息：
- 项目名称、编号、预算金额
- 工程内容及范围
- 工期要求、质量要求
- 评分标准（价格分/技术分/商务分的分值分配）
- 资格要求（资质、人员、业绩）
- 响应文件组成要求

### 3. 评分标准分析

整理评分标准表格，明确各分值项的得分要点：

| 评分项 | 分值 | 得分要点 |
|--------|------|---------|
| 价格分 | ? | 最低价基准法/平均价法 |
| 施工组织设计 | ? | 施工方法、质量/安全/工期/文明施工措施 |
| 商务分 | ? | 人员配备、业绩实力 |

### 4. 搭建投标文件框架

按招标文件要求划分三大部分：

**第一部分：资格证明文件**
- 供应商基本情况表（营业执照、资质证书、安全生产许可证）
- 法定代表人身份证明及身份证
- 法定代表人授权委托书
- 项目管理承诺书
- 项目经理注册建造师证书、B类证
- 专职安全员C类证
- 项目管理人员近半年社保证明
- 近半年依法缴纳税费证明
- 近半年依法缴纳社保费证明
- 经审计的财务报表或资信证明
- 无重大违法记录声明
- 无围标串标行为承诺函
- 廉洁诚信投标承诺书
- 中小企业声明函

**第二部分：报价文件**
- 磋商函
- 磋商函附录
- 磋商报价表
- 已标价工程量清单

**第三部分：商务技术文件（核心得分项）**
- 施工组织设计（按评分细则分项）
- 项目管理机构配备情况表
- 企业信誉实力一览表

### 5. 编写施工组织设计技术方案

按评分标准逐项编写，覆盖以下模块：

#### 5.1 主要施工方法
- 供电系统整改：电缆敷设、配电箱更换、绝缘测试
- 屋面防水维修：基层处理、防水卷材铺贴、闭水试验
- 屋面保温维修：保温板铺设、保护层施工

#### 5.2 拟投入的主要物资计划
- 按类别列出：电缆、配电设备、防水材料、保温材料、管材、辅材
- 含规格型号、数量、进场时间
- 材料质量控制措施

#### 5.3 劳动力安排计划
- 各工种人数、进场/退场时间
- 高峰期劳动力配置
- 特种作业人员持证要求

#### 5.4 确保工程质量的技术组织措施
- 质量目标、管理体系、关键工序控制、检验制度

#### 5.5 确保安全生产的技术组织措施
- 安全目标、组织机构、风险源及控制措施、管理制度

#### 5.6 确保工期的技术组织措施
- 工期目标、进度计划横道图、保证措施（组织/技术/资源/协调/应急）

#### 5.7 确保文明施工的技术组织措施
- 文明施工目标、现场措施、环境保护措施

#### 5.8 工程施工的重点和难点及保证措施
- 针对性分析本项目的重点难点（如带电作业、屋面渗漏）
- 提供具体解决方案

#### 5.9 施工总平面布置图
- 布置原则、区域划分说明

### 6. 商务得分策略

| 岗位 | 要求 | 分值 | 备注 |
|------|------|------|------|
| 项目经理 | 电力相关专业中级职称 | ?分 | 机电贰级建造师+中级职称 |
| 技术负责人 | 中级及以上职称 | ?分 | 电气工程中级职称 |
| 安全员 | C类证 | ?分 | 持证+社保 |
| 施工员/质量员/材料员 | 岗位证书 | ?分 | 持证+社保 |

业绩要求：2023年以来同类项目业绩，每个2分，最多5个。

### 7. 报价策略建议

- 分析评分方法（最低价基准法/平均价法）
- 建议报价区间（通常为预算的85%-92%）
- 提醒低于成本报价风险

### 8. 特别提醒

输出文件末尾需列出：
- 响应文件有效期
- 电子投标/CA签章要求
- 关联定位要求
- 履约保证金比例
- 签字盖章要求

## 输出格式

最终输出为结构化 Markdown，包含：
1. 项目关键信息摘要表
2. 评分标准分析表
3. 投标文件框架（三大部分清单）
4. 技术方案（9个子模块）
5. 商务得分策略表
6. 报价策略建议
7. 特别提醒事项

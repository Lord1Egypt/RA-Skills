# 寄生虫病临床诊断技能

## 诊断总体流程

1. **采集流行病学史**：确认疫区居住/旅行史、特殊饮食史（生食鱼虾蟹螺蛙蛇）、疫水接触史、动物接触史（犬羊）、职业暴露史
2. **评估临床表现**：识别特征性症状组合（发热类型、消化道症状、器官受累表现）
3. **选择实验室检查**：根据疑似病种选择病原学、免疫学、分子生物学检查
4. **影像学辅助评估**：B超/CT/MRI评估器官损害程度及病变特征
5. **综合判断确诊**：病原学检出为金标准，结合流行病学+临床+免疫学综合诊断

## 各病种诊断要点

### 肠阿米巴病
- **标本要求**：粪便必须新鲜（排出后30分钟内处理）
- **镜检确诊**：找到伸展伪足活动、吞噬红细胞的滋养体（仅溶组织内阿米巴可吞噬红细胞）
- **辅助检查**：粪便抗原检测灵敏度高；血清IgG阴性可排除现症
- **肝脓肿鉴别**：棕褐色巧克力酱样脓液+阿米巴抗体阳性→阿米巴性；黄白色脓液+细菌培养阳性→细菌性

### 疟疾
- **典型三期**：发冷期（寒战10-45min）→发热期（高热39-41℃，2-6h）→出汗期（大汗体温骤降，2-3h）
- **虫种鉴别**：间日疟/卵形疟48h周期；三日疟72h周期；恶性疟发热不规律无间歇期

### 血吸虫病
- **急性期**：疫水接触史+发热+嗜酸性粒细胞显著增多（20%-40%，可达90%+）
- **晚期分型**：巨脾型（最常见）、腹水型（严重）、结肠肉芽肿型（3-6年以上）、侏儒型（极少见）
- **病原确诊**：粪便改良加藤法/直肠黏膜活检（距肛门8-10cm背侧阳性率最高）
- **循环抗原检测**：提示活虫感染，用于诊断和疗效考核

### 华支睾吸虫病
- **确诊依据**：粪便或十二指肠引流胆汁找到虫卵（必须用集卵法，连续3天）
- **注意**：免疫学阳性不能单独诊断现症感染；影像学仅作辅助

### 并殖吸虫病
- **虫种鉴别**：卫氏（铁锈色痰、脑脓肿、皮下结节不游走）vs 斯氏（荨麻疹常见、游走性皮下包块、肝脏受累多见）
- **临床分型**：胸肺型（最常见）、腹型、皮肤型、脑脊髓型
- **病原学**：痰液/粪便/体液查虫卵；皮下包块活检见嗜酸性肉芽肿
- **皮试注意**：与华支睾吸虫、血吸虫有交叉反应；治愈多年后仍可阳性

### 囊尾蚴病
- **脑型分型**：脑实质型（癫痫最常见，84%-100%）、脑室型（Brun征/活瓣综合征）、蛛网膜型（脑膜炎表现）、混合型
- **必须排除**：眼囊尾蚴病（禁忌药物杀虫，需手术）

### 棘球蚴病
- **囊型**：B超首选（边缘明确囊状液性暗区）；肺型咳出粉皮样膜状物可确诊
- **泡型（虫癌）**：肝内界限不清浸润性病变+Em2-ELISA阳性；未经治疗10年病死率>90%

### 内脏蠕虫蚴移行症
- **核心特征**：幼虫在人体内不能发育为成虫，粪便查不到虫卵
- **常见病原**：犬弓首线虫（肝大）、广州管圆线虫（嗜酸性脑膜炎）、曼氏迭宫绦虫裂头蚴（游走性包块）、斯氏狸殖吸虫

## 关键鉴别诊断

| 症状/体征 | 优先考虑病种 |
|-----------|-------------|
| 果酱样腥臭粪便 | 肠阿米巴病 |
| 周期性寒战高热大汗 | 疟疾 |
| 嗜酸性粒细胞>20%+疫水接触 | 急性血吸虫病 |
| 铁锈色痰+生食溪蟹史 | 并殖吸虫病（卫氏） |
| 游走性皮下包块 | 并殖吸虫病（斯氏）/裂头蚴病 |
| 癫痫+牧区生活史 | 脑囊尾蚴病 |
| 肝囊性占位+犬羊接触史 | 囊型棘球蚴病 |
| 肝浸润性占位类似肝癌 | 泡型棘球蚴病 |

## 输出要求

诊断结论应包含：
1. 疑似/确诊病种
2. 诊断依据（流行病学+临床+实验室）
3. 临床分型/分期（如适用）
4. 需补充的检查项目
5. 需鉴别的疾病

详细各病种诊断标准、检查方法、病理演变见 references/ 文件夹。

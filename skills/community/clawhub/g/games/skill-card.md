## Use Case:

External users use this skill to organize video games, board games, party games, kids activities, favorites, and game-night notes in a local Markdown workspace.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may create or use a local ~/games/ folder for personal game lists and logs.

Mitigation: Review the workspace location before use and choose a different storage path if local home-directory tracking is not desired.

Risk: Casual mentions of games may trigger offers to track them.

Mitigation: Confirm with the user before adding game mentions to the tracking workspace.

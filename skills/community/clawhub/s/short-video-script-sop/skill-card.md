## Description:

Chinese-language SOP for writing short video and talking-head scripts using a three-part structure, rotating hook formulas, and quality-control checks.

This skill is ready for commercial/non-commercial use.

## Publisher:

[shiyan521](https://clawhub.ai/user/shiyan521)

### License/Terms of Use:

MIT

## Use Case:

External creators, social media teams, and agents can use this skill to structure Chinese short-video scripts from rated source material, choose rotating hook formulas, fill a Markdown script template, and apply pre-publication quality checks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated call-to-action endings may include an unintended creator name or follow request.

Mitigation: Review the ending before publishing, replace the creator-name placeholder, and remove or edit the call to action if it does not match the user's intent.

Risk: Source material may contain personal information or unreleased third-party data.

Mitigation: Complete the privacy check in the script template and avoid automatic publication unless the user has explicitly confirmed the content is safe to release.

Risk: A script can pass the template mechanically while still being unsuitable for a specific platform or brand voice.

Mitigation: Apply the nine quality-control checks and perform a manual review for platform fit before publishing.

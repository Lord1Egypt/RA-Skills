## Description:

Transforms poetry, literary imagery, and visual art concepts into browser-native creative coding guidance and artwork specifications.

This skill is ready for commercial/non-commercial use.

## Publisher:

[zcr3344](https://clawhub.ai/user/zcr3344)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, creative coders, and agent users use this skill to turn poems, moods, visual styles, and art concepts into browser-native artwork prompts, BCPP manifests, implementation hints, and validation guidance for Canvas, WebGL, CSS, SVG, and frontend projects.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Examples may use external CDN or npm JavaScript dependencies.

Mitigation: Pin dependency versions, review remote scripts before reuse, and prefer trusted package sources in real projects.

Risk: Some browser-art patterns may use camera or microphone input.

Mitigation: Make camera and microphone access opt-in, disclose the purpose clearly, and avoid default recording or storage.

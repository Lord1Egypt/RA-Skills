## Description:

Generates a Chinese daily live-commerce report covering Qianchuan and Ocean Engine policy, Douyin platform updates, creative trends, competitor movement, and market signals, with category-specific action points and local report saving.

This skill is ready for commercial/non-commercial use.

## Use Case:

Live-commerce media buyers, operators, and merchants use this skill to collect current platform, policy, creative, competitor, and market updates, then save a structured Chinese daily report with category-specific action points.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill relies on web search for current industry updates, so reports may include stale, incomplete, or source-biased information.

Mitigation: Review important items before acting on recommendations, and prefer official platform notices for policy-sensitive decisions.

Risk: The skill reads yesterday's saved report and writes Markdown or HTML files to a local path chosen by the user.

Mitigation: Use a dedicated reports directory and confirm the save path before allowing file creation or reuse of prior reports.

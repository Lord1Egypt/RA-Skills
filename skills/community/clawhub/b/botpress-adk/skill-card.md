## Description:

A guide to build AI bots with Botpress's Agent Development Kit (ADK).

This skill is ready for commercial/non-commercial use.

## Publisher:

[yueranlu](https://clawhub.ai/user/yueranlu)

### License/Terms of Use:

MIT

## Use Case:

Developers and engineers use this skill to create, configure, test, deploy, and troubleshoot Botpress ADK bots, including actions, tools, workflows, conversations, tables, triggers, knowledge bases, and integrations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Installation instructions execute mutable remote installer scripts directly in a shell.

Mitigation: Review installation commands before use; prefer a pinned Botpress ADK release, verify its checksum or signature from an official source, inspect the script, and run without elevated privileges.

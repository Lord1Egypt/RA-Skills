## Description:

Set up an SEO project: a local SEO workspace folder, website scope, goals, positioning, the HarborRank project, and Google Search Console (connected, or CSV exports). Use when the user starts SEO for a new site or client, onboards a website, wants to connect Search Console, or has no HarborRank project yet. The other HarborRank workflows build on this setup.

This skill is ready for commercial/non-commercial use.

## Use Case:

Site owners and SEO practitioners use this skill to organize a new website's SEO work, capture goals and positioning, and prepare a HarborRank project and Search Console data for follow-on workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The Search Console connection may request access to data the user does not want to share with HarborRank.

Mitigation: Before connecting, review the requested permissions and confirm the user is comfortable sharing that data.

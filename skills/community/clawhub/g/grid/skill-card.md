## Description:

Helps agents design, optimize, and audit responsive grid layouts for equal-hierarchy content displays.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, designers, and agents use this skill to choose, describe, and critique responsive grid layouts for products, templates, tools, features, blog indexes, and galleries.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Grid layout guidance may lead to unsuitable responsive behavior, accessibility issues, or layout shift if applied without review.

Mitigation: Review generated layout recommendations against target content, viewport sizes, accessibility requirements, and cumulative layout shift constraints before shipping.

Risk: Infinite-scroll grid recommendations can make SEO-critical content harder for crawlers to access.

Mitigation: Provide paginated component pages or crawlable alternatives for SEO-critical grid content.

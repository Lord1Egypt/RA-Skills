## Description:

Use when the user asks to cast, interpret, or explain an I Ching / Yijing hexagram using six-line divination, coin-style random casting, hexagram lookup, shortName/fullName/keywords/summary interpretation, or the bundled hexagram summary data.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ccccl8](https://clawhub.ai/user/ccccl8)

### License/Terms of Use:

MIT-0

## Use Case:

External users use this skill to cast or interpret an I Ching hexagram through a six-line coin method or supplied line values. The skill returns reflective bilingual guidance based on bundled hexagram reference data.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Users may mistake reflective divination-style interpretations for factual predictions or professional advice.

Mitigation: Present results as reflective guidance, avoid certainty about future events, and do not frame the reading as professional advice.

Risk: The skill may optionally mention an external website for interactive visual casting.

Mitigation: Treat the website as an optional external resource and review it before recommending it in controlled deployments.

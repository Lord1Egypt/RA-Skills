## AVS0 需求与路由域范本

> 贯穿示例项目：用户输入"把小说《归宋医女》开头改成短剧，现代外科医生穿越北宋汴京"。

### AVS0-01 输入判定 · 范本

> 场景设定：用户提出一个改编需求。

```
输入："这是小说《归宋医女》第一章（附4000字文本），现代外科医生苏晚意穿越北宋汴京苏家嫡女身上，帮我做成短剧"
→ 判定：小说/长文本 → 改编模式
```

【组装顺序】读取输入→特征识别（含完整章节文本+穿越古代题材）→路由到改编模式→向用户确认路由结果。
【可选组件】多输入并行判定：未启用（单一需求）。
【检查】✅ 输入落到五种路由之一（改编）；✅ 路由已向用户确认，未自行假设；✅ 未混入未经判定的输入。
输出格式：路由判定记录（Markdown）✅

### AVS0-02 需求信息收集 · 范本

> 场景设定：用户只给了一段故事概要，走最小输入模式——先判可推断项，只问三项。

```
用户输入（原样入档，不改写）：
"现代外科医生穿越成被退婚的苏家嫡女，家里老太病重，她用现代医术救了人，从此在汴京站住脚。"
```

需求确认表（含来源列）：

| 信息项 | 取值 | 来源 |
|--------|------|------|
| 产出类型 | 多集连载短剧 | 推断（概无"广告/口播"信号） |
| 题材与受众 | 古装穿越＋医术逆袭；女频18-40；竖屏平台 | 推断（概要关键词：穿越/退婚/医术） |
| 时长/集数 | 90秒/集 × 3集（立困→破局→立名） | **问用户** |
| 质量档位 | 测试型（先出第1集样片验收） | 推断（未提批量） |
| 配音方案 | 无声版先行＋配音文本表 | **问用户** |
| 画幅 | 9:16 1080×1920 | **问用户** |
| 目标平台 | 竖屏短视频平台 | 推断 |

只问这三项（其余一律不许多问）：

```text
确认三件事，其余我按默认推进：
1. 集数与时长：默认3集×90秒，可以吗？
2. 画幅：默认9:16竖屏，还是要横屏？
3. 配音：①你给音频 ②外部TTS后回传 ③先出无声版+配音文本（默认③）
```

【组装顺序】读概要（原样入档）→逐项判可推断/不可推断→可推断按默认值表填并标"推断"→只问配音/画幅/集数三项→记录（用户不回则按默认执行并写入工程清单）。
【可选组件】推断项清单：已启用（上表来源列）；真人感要求与混合模式：未启用（用户未提，按内置生成先试产）。
【检查】✅ 概要原文原样入档未改写；✅ 七项信息齐全，其中四项标"推断"；✅ 只问三项，未拿可推断项去问；✅ 配音缺口已主动询问；✅ 推断项未被伪装成用户确认项。
输出格式：需求确认表（Markdown，含来源列）✅

### AVS0-03 生产方案规划 · 范本

> 场景设定：用户答复合集共3集，先做第1集样片验收、再量产2-3集；穿越古代女频，竖屏90s，配音先出无声版。

```
【生产方案】项目：归宋医女_第1季
- 阶段1（样片，测试型档位）：第1集90s/23镜，验证风格与角色接受度
  管线：AVS1-04单集剧本 → AVS2-01分镜 → AVS3-01单主角最小库 → AVS4全工序 → AVS5-03无声合成 → AVS6-01 QC
  耗时：2-3小时（含资产库40分钟）
- 阶段2（量产，量产型档位）：第2、3集，各88s/22镜、85s/21镜
  管线：全量AVS0-1→2→3→4→5→6，资产库复用第1集成果，仅增量建 C02青禾/C03苏母/C04顾廷之 与 S03前厅/S06老太房
  耗时：跑通后1-2天/集
- 规格：9:16 1080×1920，单集85-90s，单镜3-5s
- 镜头预算：全季66镜；角色4人；场景6个
- 项目目录：归宋医女_第1季/{01_剧本,02_分镜,03_资产,04_镜头,05_成片,参考库,工程清单.md}
- 交付物：三集成片＋工程清单＋发布信息清单；配音先出无声版，确认后按AVS5-01补录
- 裁剪：阶段1跳 AVS0-04/AVS2-04/AVS3-02/04（单场景无换装无转场）；阶段2全部启用
```

【组装顺序】模式确认（样片先行＋量产）→定档位（测试型→量产型）→按档位矩阵两次裁剪→规格与预算→耗时估算→目录与工程清单初始化。
【可选组件】交付物清单：已启用；里程碑安排：未启用（样片为一次性交付）。
【检查】✅ 模式/档位/管线/规格/预算/耗时/目录/交付物八项齐全；✅ 两阶段档位不同、裁剪各写理由；✅ 目录符合项目结构规范；✅ 样片先行原则落实（第1集验收后才量产）；✅ 管线裁剪未删除三锚与QC环节。
输出格式：生产方案（Markdown）✅

成本预期（立项时给用户，实测规律）：
- 首集最贵：含资产库一次性投入＋工艺试错，约占总成本 40% 以上
- 第 2 集起断崖下降：资产工艺全复用，边际成本降到首集约 1/3
- 图生视频是单集成本主项（单价约为图片 10 倍）
- 判断项目划算看总集数与资产复用轮次，不是单集单价

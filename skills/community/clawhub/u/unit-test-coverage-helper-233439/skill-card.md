## Description:

Helps maintainers, QA engineers, contributors, and product teams add useful unit tests and improve test coverage for existing codebases.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, maintainers, QA engineers, open-source contributors, and product teams use this skill to turn a request for better unit test coverage into a practical workflow, checklist, implementation plan, or code-focused guidance. It emphasizes clarifying success criteria, adding meaningful tests, and validating the result in existing codebases.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad software-quality trigger wording may invoke the skill when the user is not specifically asking for unit test coverage help.

Mitigation: Use the skill when the request clearly involves adding unit tests, improving coverage, regression testing, or validating behavior in an existing codebase.

Risk: Generated testing advice or code changes could miss project-specific constraints or create low-value coverage.

Mitigation: Review proposed tests against the codebase behavior, run the relevant test and coverage commands, and keep assumptions and remaining gaps visible.

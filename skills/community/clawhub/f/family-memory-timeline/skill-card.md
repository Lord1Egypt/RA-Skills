## Description:

Family Memory Timeline organizes supplied family media path metadata and conversation text into a structured timeline story with emotional highlights and JSON or Markdown output.

This skill is ready for commercial/non-commercial use.

## Publisher:

[harrylabsj](https://clawhub.ai/user/harrylabsj)

### License/Terms of Use:

MIT-0

## Use Case:

Families or agents assisting families use this skill to turn provided media references and conversation snippets into a private timeline, chaptered story, and memory summary for review.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Family conversation text and media path metadata may contain sensitive personal information.

Mitigation: Review and minimize inputs before use, and keep generated timelines private unless family members approve sharing.

Risk: Generated Markdown may include user-provided text verbatim.

Mitigation: Review output before publication and render Markdown with HTML disabled or sanitization enabled.

Risk: Output may be Chinese-first unless localization is reviewed.

Mitigation: Specify the desired language when invoking the skill and review generated text for the intended audience.

# Web：让会变化的世界进入当前系统

Web 适配负责搜索、浏览、下载和核对网络来源，把外部世界在明确日期、口径和来源下接入当前判断。

## 什么时候需要联网

当事实可能随时间变化、用户要求最新或直接来源、关键结论风险高、对象陌生、资料指向特定网页或本地材料不足时，主动核对。技术问题优先官方文档和原始论文；公司、政策、标准和产品状态优先权威发布；新闻区分事件发生日期与文章发布日期。

## 来源怎样进入系统

关键事实记录来源、日期、尺度、口径和适用条件。一手来源承担关键声称，二手材料用于寻找线索、比较叙事和发现争议。多个来源冲突时说明冲突来自时间、定义、样本还是利益位置。

网页链接是进入外部材料的入口。对会影响长期作品的内容，保存必要摘录、数据或日期快照，并遵守版权与引用边界。每个链接服务于机制、证据或可继续核对的路径。

## 从信息到作用

搜索结果先进入[观察](../runtime/observe.md)，改变系统模型、选择、作品或行动时成为有效组成。领域系统继续持有权威状态，现实效果由相应对象与行动证据确认。

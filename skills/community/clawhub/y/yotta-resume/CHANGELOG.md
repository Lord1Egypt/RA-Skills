# 更新日志

## v0.2.4 (2026-11-25)

- 安装器改为完全 fail-closed：拒绝安装根目录、目标目录及嵌套项中的任何
  符号链接或 junction；删除 managed-hub marker 授权与 `realpath` 跟随。
- 安装器不再读取 `CODEX_HOME` / `XDG_CONFIG_HOME`；自定义宿主目录必须显式
  传入 `--dir`，避免未声明的环境能力。
- 新增伪造 marker、安装根目录链接、嵌套链接、env 优先级和锁版说明回归；
  JS 与 bash 安装器的目标错误统一返回退出码 `4`。
- 安装说明不再包含会被静态扫描误判为裸命令的 `npx` 文本；
  `AST4` / `TT2` 代码边界保持不变，不以隐藏或削弱规则收口。

## v0.2.3 (2026-11-25)

- 安装器帮助示例全部锁定到当前 npm 版本，新增发布面回归，避免未来
  `npx -y` 重新指向未审查版本。
- SKILL 描述和正文补充安装器权限与边界：只写入用户指定目标内的
  `yotta-resume`，只清理已知开发残留和缓存，不跟随普通符号链接或 junction。
- SKILL 增加最小工具范围声明：`Read`、`Write`、`Bash`；不声明网络或 MCP 权限。
- PDF 导出增加浏览器可执行文件白名单校验，并显式设置 `shell=False`；
  拒绝任意脚本或非浏览器路径。
- `quickstart --out` 拒绝与简历或 JD 输入相同的路径，避免误覆盖原始输入；
  新增稳定错误码 `YRS-EXPORT-004`。

## v0.2.2 (2026-11-24)

- 新增随包 `selftest --quick / --full / --json`，覆盖数据契约、分析、
  模拟面试状态机、DOCX / HTML、事务回滚、临时目录和可选 PDF；不读取用户简历。
- `audit` 新增确定性表达清晰度检查：识别结果不可验证、责任边界不清和
  技能等级缺少证据，生成确认追问，不引入语义模型或新的主观分数。
- 新增软件研发、数据与 AI、业务运营三个岗位族，各 27 项证据题；
  题库扩到 10 个岗位族 / 270 项，并支持行业识别后自动映射岗位族。
- `quickstart` 新增 `--out-dir` 单入口行动包，一次生成行动清单、脱敏分析报告和
  机器可读清单；非空目录 fail-closed，普通用户不需要先理解命令。
- 核心错误统一输出稳定错误码、影响范围和下一步动作，覆盖输入、PDF、导出、
  数据、面试和环境错误。
- `generic` 继续作为受控回退；行业信号冲突时仍要求用户确认，不猜测岗位。

## v0.2.1 (2026-11-23)

- 新增 `generic` 岗位族和 27 道通用证据题，题库扩到 189 项；软件研发、
  数据、运营和通用行业可按通用证据维度运行模拟面试。
- `interview start` 在非安全行业自动使用 `generic`；行业信号冲突时仍要求
  显式确认，不猜测岗位。

  粘贴文本或用 `-` 从 stdin 读取无法直接解析的旧版文档。
- PDF 导出使用独立浏览器 profile，并在瞬态失败时做有界重试；失败仍保持
  事务化，不留下半成品。
- 新增 `quickstart`，把自检、分析和下一步合成一次入口。
- 修正示例题库版本、渠道副本的 `LICENSE.txt` / `NOTICE.txt` 命名和 README 链接。
- 新增软件研发行业示例与 DOCX / HTML / PDF 成品样例。

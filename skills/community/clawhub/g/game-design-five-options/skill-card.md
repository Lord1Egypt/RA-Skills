## Description:

Generate and compare at least five game design solution options for a feature, system, UX issue, live-ops problem, or design challenge.

This skill is ready for commercial/non-commercial use.

## Publisher:

[stanestane](https://clawhub.ai/user/stanestane)

### License/Terms of Use:

MIT-0

## Use Case:

Game designers, product teams, and agents use this skill to expand and compare candidate game design solutions before choosing a direction. It is suited for features, systems, UX issues, live-ops problems, and other game design challenges where one preferred answer may be crowding out alternatives.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated design comparisons can still contain incorrect assumptions or recommendations that do not fit the project.

Mitigation: Review the options against project goals, player research, production constraints, and implementation capacity before using them for decisions.

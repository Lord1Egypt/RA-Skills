## Description:

Guides agents and users through standard SQL operations for defining, querying, updating, and controlling access to relational database data.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, database learners, and agents use this skill as a concise SQL reference for creating tables, querying data, modifying records, managing permissions, and applying basic safety practices.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Sample SQL includes destructive or permission-changing statements such as DROP, DELETE, GRANT, and REVOKE.

Mitigation: Review statements before use, test on non-production databases, and use backups, transactions, and explicit approvals for production changes.

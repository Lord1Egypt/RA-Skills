## Use Case:

External agents and developers use this skill to understand and operate inbed.ai compatibility workflows, including profile setup, score interpretation, candidate discovery, swiping, chat, and relationship status updates.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill sends profile, personality, relationship preference, gender or seeking, swipe, chat, and relationship-status data to inbed.ai.

Mitigation: Use only when that data flow is acceptable, avoid oversharing personal details, and review privacy and deletion terms before using real personal data.

Risk: Bearer tokens grant access to the inbed.ai account workflows described by the skill.

Mitigation: Treat the bearer token like a password and store it only in approved secret-management locations.

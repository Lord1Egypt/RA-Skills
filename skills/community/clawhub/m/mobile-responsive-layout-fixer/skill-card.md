## Description:

Guides developers through planning and checking responsive layout fixes for mobile navigation and cross-device interface issues.

This skill is ready for commercial/non-commercial use.

## Use Case:

Frontend developers, designers, product teams, and maintainers use this skill to plan responsive design and navigation fixes across phone and desktop layouts. It helps turn a request into a practical deliverable and review checklist.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation terms may invoke the skill for unrelated requests.

Mitigation: Use it when the request concerns responsive design, mobile navigation, frontend layout, or a closely related deliverable; check relevance before applying the workflow.

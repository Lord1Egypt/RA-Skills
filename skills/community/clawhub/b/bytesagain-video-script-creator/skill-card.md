## Known Risks and Mitigations:

Risk: Generated scripts may include generic or misleading creative guidance if used without editorial review.

Mitigation: Review and adapt the generated script before filming or publishing.

Risk: Some platform templates are Chinese-oriented and may not match every audience or locale.

Mitigation: Select the platform mode intentionally and localize language, calls to action, and cultural references before use.

Risk: Evidence notes that some commands may need bug fixes before they run reliably.

Mitigation: Test the command path locally before relying on it in a production content workflow.

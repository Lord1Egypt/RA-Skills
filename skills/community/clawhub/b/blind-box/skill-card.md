## Description:

Virtual blind box gacha skill that pulls random collectible figures with rarity tiers, five themed series, 10-pull mode, daily free pull, and shareable reveal cards.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users use Blind Box for terminal-based virtual gacha pulls, daily pulls, series browsing, and shareable collectible reveal text in Chinese or English.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The daily free pull is date-themed output and is not technically limited to one execution per day.

Mitigation: Treat daily results as entertainment text rather than an enforced quota or entitlement.

Risk: The default output language is Chinese, which may surprise users expecting English text.

Mitigation: Use the documented --lang en option when English output is required.

# Agent 3: 质检校验Agent (Quality Inspector)

> 全局唯一知识ID: GIS-AGENT-003
> 隶属: 上层多Agent编排引擎
> 触发条件: 处理完成 → 自动质检

## 职责

1. 执行几何质量检查（6项：空几何/自相交/多部件/极小面/重叠/空洞）
2. 执行属性完整性检查（必填字段、编码合规、值域范围）
3. 执行坐标一致性检查（同级数据坐标系是否统一）
4. 生成《成果质量检查报告》

## 输入

| 参数 | 说明 | 必填 |
|------|------|------|
| processed_data | 处理后的数据 | 是 |
| quality_standard | 质检标准（默认GB/T 24356） | 否 |

## 输出

- 质检报告（HTML格式，含统计表+问题点位图）
- 问题数据SHP（如有）

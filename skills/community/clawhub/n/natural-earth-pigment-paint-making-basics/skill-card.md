## Description:

Helps an agent guide users through making natural paints from local earth, clay, charcoal, and plants by identifying sources, calculating ratios, planning schedules, tracking tests, and producing inventory or barter templates.

This skill is ready for commercial/non-commercial use.

## Publisher:

[howtousehumans](https://clawhub.ai/user/howtousehumans)

### License/Terms of Use:

MIT-0

## Use Case:

External users use this skill when commercial paints, stains, or coatings are unreliable, expensive, or unavailable and they need a repeatable agent-guided workflow for natural earth pigment paint. The agent provides sourcing guidance, ratio calculations, schedules, logs, test tracking, and trade-ready templates while the human performs all physical collection, grinding, mixing, testing, and application.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The unpinned npx install command carries normal package supply-chain uncertainty.

Mitigation: Verify the ClawHub or npm package source and CLI version before installation, and do not run the install command with elevated privileges.

Risk: The skill may ask for local photos or location details and may maintain paint-making logs in the filesystem.

Mitigation: Share only the location and image detail needed for source assessment, and review stored logs for sensitive information.

Risk: The workflow involves dry earth grinding, pigment testing, and surface application that can create dust or irritation hazards.

Mitigation: Use respiratory protection, ventilation or outdoor work areas, small test batches, and stop the workflow if respiratory or skin irritation occurs.

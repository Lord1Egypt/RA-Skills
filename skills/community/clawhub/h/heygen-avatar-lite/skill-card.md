## Use Case:

Developers and content automation builders use this skill to configure HeyGen API access, list available avatars and voices, generate avatar videos from text, and check video status.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: HeyGen API keys, avatar selections, voice choices, and likeness material may be sensitive.

Mitigation: Use scoped or rotated HeyGen API keys where possible, avoid sending secrets or private content, and review avatar and voice material before submission to the third-party service.

Risk: The skill relies on HeyGen as an external third-party service.

Mitigation: Install and use the skill only if the user accepts HeyGen service use for the intended content and account.

## Description:

专业塔罗占卜服务。当用户提及塔罗、抽牌、占卜等关键词时激活，提供单张牌或时间之流（过去-现在-未来）牌阵的解读。使用经典韦特塔罗体系，支持正逆位随机抽取，以温暖治愈的文字风格提供理性洞察。

## Use Case:

External users can use this Chinese-language skill for structured tarot readings using single-card or past-present-future spreads. The skill provides reflective guidance tied to a user-supplied question without presenting the reading as a fixed prediction.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad divination-related trigger terms may activate the skill when the user did not intend a tarot reading.

Mitigation: Confirm the user's question and intent before drawing or interpreting cards.

Risk: A reading record may contain personal reflections if an agent with memory or file-writing features saves it.

Mitigation: Ask for clear user consent before storing or writing any reading record.

Risk: Tarot guidance can be misunderstood as a certain prediction or decision directive.

Mitigation: Frame readings as reflective guidance, avoid absolute claims, and encourage the user to make their own decisions.

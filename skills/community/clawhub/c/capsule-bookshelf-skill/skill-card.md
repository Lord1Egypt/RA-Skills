## Description:

Capsule Bookshelf Skill helps agents turn a book or author request into a local card-style book-excerpt HTML article and update a single-page bookshelf index.

This skill is ready for commercial/non-commercial use.

## Publisher:

[zhouq2039-lang](https://clawhub.ai/user/zhouq2039-lang)

### License/Terms of Use:

MIT

## Use Case:

External users and agents use this skill to create book-excerpt capsule pages from a book or author and keep generated capsules organized in a local bookshelf HTML page.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated pages can run injected HTML or JavaScript.

Mitigation: Review generated HTML before opening or sharing it, and avoid untrusted JSON or copied web text until HTML escaping is fixed.

Risk: The active generator does not enforce the path containment that the skill documentation claims.

Mitigation: Keep registry entries limited to files generated by the skill and do not manually add paths outside the skill directory until containment is fixed.

Risk: The skill runs a local Python generator, writes HTML output, and updates a persistent bookshelf registry.

Mitigation: Install and run it only in workspaces where local file writes and registry updates are acceptable.

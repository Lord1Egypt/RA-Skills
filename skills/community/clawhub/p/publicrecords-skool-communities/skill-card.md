Mitigation: Before installing, consider limiting the connection to the Skool tracker.

Risk: The example API request uses a placeholder actor name that does not match the stated community-search purpose.

Mitigation: Review the example and confirm the intended Actor before using the API option.

Risk: Actor runs are pay per event and billed to the user's Apify account.

Mitigation: Review the current price and consider the potential charges before running the Actor.

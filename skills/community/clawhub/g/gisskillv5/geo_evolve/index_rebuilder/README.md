# GeoEvolve 子模块: 索引重建层

> 全局唯一知识ID: GIS-EVO-004
> 隶属: 顶层GeoEvolve自进化闭环

## 功能

接收知识修正层的差异更新包，增量刷新：
- 向量索引 → 文本嵌入重建/增量追加
- 知识图谱 → 实体关系三元组更新
- 全局检索索引 → 关键词倒排索引更新
- KOWNLEDGE_ID_MAP → 新模块ID注册

## 重建策略

| 索引类型 | 更新方式 | 触发条件 |
|----------|----------|----------|
| 向量索引 | 增量追加 | 新增文档/段落>500字 |
| 知识图谱 | 差异更新 | 新增实体/关系 |
| 全局检索 | 全量重建 | 新增文件>10个 |
| 知识ID映射 | 增量追加 | 新建模块 |

## 灰度发布机制

- 新索引写入 `vector_index_v2/`（独立目录）
- 原索引保留在 `vector_index/`（稳定版本）
- 监控命中率7天后 → 切换/回滚
- 支持一键回滚至历史版本

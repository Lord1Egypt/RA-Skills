## Description:

Create and present web-based slidedecks for developers using Slidev with Markdown, Vue components, code highlighting, animations, and interactive features.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill to create Slidev presentations, conference talks, teaching materials, code walkthroughs, and developer-focused decks with Markdown, Vue, interactive code, diagrams, math, presenter notes, and export workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Package installation and export commands may execute dependencies in the user's development environment.

Mitigation: Run installation and export commands in a project workspace without unnecessary secrets, and prefer pinned package versions or a lockfile.

Risk: Runnable code blocks, writable Monaco examples, embeds, and remote URLs may introduce untrusted behavior or content.

Mitigation: Use runnable examples, writable files, embeds, and remote URLs only from sources the user trusts.

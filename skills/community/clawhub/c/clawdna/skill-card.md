## Description:

Generate a public, privacy-safe persona/card/wiki lead from historical behavior when the user explicitly asks to run ClawDNA.

This skill is ready for commercial/non-commercial use.

[buzuweidao](https://clawhub.ai/user/buzuweidao)

## Use Case:

External users and agent operators use ClawDNA to generate a concise public Markdown profile from approved historical behavior signals after explicit user intent and consent.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may analyze approved agent history or memory to create a public-facing profile, which can expose names, dates, projects, third-party details, or sensitive inferences if output is shared without review.

Mitigation: Use explicit consent for local history access, prefer pre-reviewed summaries or exports, and review the generated profile carefully before publishing or sharing.

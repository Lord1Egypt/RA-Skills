## Description:

Work with Obsidian vaults (plain Markdown notes) and automate via obsidian-cli.

This skill is ready for commercial/non-commercial use.

## Publisher:

[164149043](https://clawhub.ai/user/164149043)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, writers, and other Obsidian users use this skill to find active vaults, search notes, create notes, move or rename notes while preserving links, and delete notes through obsidian-cli or direct Markdown edits.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Installing obsidian-cli uses a third-party Homebrew tap.

Mitigation: Install only if you are comfortable with that tap and review the dependency before use.

Risk: Create, move, or delete actions can modify or remove notes in the active vault.

Mitigation: Confirm the active vault first; prefer backups, trash or archive workflows, and explicit confirmation for destructive changes.

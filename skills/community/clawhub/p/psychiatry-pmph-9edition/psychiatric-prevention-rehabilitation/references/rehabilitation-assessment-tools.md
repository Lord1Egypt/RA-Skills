# 精神康复评估工具与指标

## 功能评估量表

### 个人与社会功能量表（PSP）
评估四个维度：
1. 社会有益活动（包括工作/学习）
2. 个人和社会关系
3. 自我照料
4. 扰乱与攻击行为

评分：0-100分
- 71-100：功能良好
- 31-70：不同程度功能损害
- <30：功能严重低下

### 社会功能缺陷筛查量表（SDSS）
评估10个领域：
- 职业功能
- 婚姻功能
- 父母职能
- 社会性退缩
- 家庭外社会活动
- 家庭内活动
- 家庭职能
- 个人生活自理
- 对外界兴趣
- 责任心

### 生活质量量表（WHOQOL-BREF）
四个领域：
- 生理领域
- 心理领域
- 社会关系领域
- 环境领域

## 康复阶段评估

### 临床稳定度
| 指标 | 稳定 | 不稳定 |
|-----|------|-------|
| 精神症状 | 缓解或轻微 | 明显/波动 |
| 自知力 | 完整/部分 | 缺乏 |
| 服药依从性 | 良好 | 差 |
| 自伤/伤人风险 | 无 | 存在 |

### 康复需求评估

```
评估维度：
├─ 症状管理需求
│   ├─ 药物自我管理能力
│   ├─ 复发预警识别能力
│   └─ 应对策略掌握程度
│
├─ 生活技能需求
│   ├─ 自我照料能力
│   ├─ 家务管理能力
│   ├─ 金钱管理能力
│   └─ 社区资源使用能力
│
├─ 社交功能需求
│   ├─ 人际交往技能
│   ├─ 沟通能力
│   └─ 社会活动参与度
│
└─ 职业功能需求
    ├─ 工作技能
    ├─ 工作耐受性
    └─ 职业兴趣与意愿
```

## 康复目标设定（SMART原则）

### 短期目标（1-3个月）
- 具体行为改变
- 可测量指标
- 例：每天独立完成个人洗漱；每周参加1次社区活动

### 中期目标（3-6个月）
- 功能改善
- 例：恢复部分家务能力；建立1-2个同伴关系

### 长期目标（6-12个月）
- 社会融合
- 例：参与辅助就业；独立生活

## 社区康复资源配置

### 基本配置
| 服务类型 | 内容 | 人员配比 |
|---------|------|---------|
| 日间康复中心 | 活动组织、技能训练 | 1:8-10 |
| 社区随访 | 家庭访视、用药指导 | 1:50-80 |
| 同伴支持 | 互助小组、榜样引领 | 1:15-20 |
| 职业康复 | 评估、培训、就业支持 | 1:10-15 |

### 转介标准
- 急性期住院治疗 → 症状稳定后转社区康复
- 社区康复 → 功能良好可转辅助就业
- 病情波动 → 及时转回专科治疗

# 全局宪法（laws.md）— ui-ux-design 领域全局法则

## 宪法导读

本文件是 ui-ux-design 领域的**全局宪法**，从 7 个子领域（VP/LC/CS/TY/SD/IM/UA）的法则化萃取中，收集全部 `[GLOBAL]` 候选并补充跨领域根本原则，经合并去重形成 **LAW-1~28**。

**全局法则与子领域法则的关系：**

1. **分层治理**：全局法则回答"任何 UI 产出都不可违背什么"；子领域法则（VP/LC/CS/TY/SD/IM/UA-N）是全局法则在其领域的**具体化与收紧**。
2. **冲突裁决**：子领域细则与全局法则冲突时**细则优先**；全局法则兜底，覆盖未枚举场景；两者同时违反，以更严格者为准。
3. **引用规则**：正文用编号引用（`LAW-N` 全局 / `VP-N` 子领域）。
4. **因果链排序**：先感知/认知硬约束，再设计系统纪律，最后流程与生成纪律（同 SKILL.md 导读）。

**分组结构**：第一组 感知与认知根因（LAW-1~9、26）→ 第二组 设计系统纪律（LAW-10~20、27）→ 第三组 流程与生成纪律（LAW-21~25、28）。

---

## 第一组：感知与认知根因

> 人类视觉如何感知分组/层级/显著性——一切"好看"判断的底层约束。

[LAW-1] MUST: 元素的从属/同级关系必须由间距编码——任意两内容组之间的间距 ≥ 组内元素间距的 2 倍，且间距必须来自离散刻度（4 的倍数 / 8pt 体系），不得对"组间/组内/同级"三种关系使用同一数值；嵌套容器间距必须层级递减。
  违反后果: 格式塔接近性失效，分组不可辨，用户无法预判元素归属，扫读成本陡增。
  溯源: VP-1, LC-2, LC-3, LC-19, SD-5

[LAW-2] MUST: 任何以"差异"传达的层级/类别/状态必须越过感知阈值——字号比 ≥1.2、字重跨档（400→600）、色阶跳档、实心 vs 描边、有无背景块任一强通道，相邻层级级差 ≥约 8%；对比要么强烈要么不用——**要么相同，要么显著不同**，"轻微不同"视同错误。
  违反后果: 层级信号低于感知阈值等于不存在，页面层级在低对比屏/弱视用户处整体失效。
  溯源: VP-16, LC-17, TY-17, SD-6, [GLOBAL] 候选 VP-21

[LAW-26] MUST: 每个元素必须与至少一个其他元素共享显式对齐轴线（左/右/基线/中线）；同一容器内对齐方式 ≤2 种且服务于同一结构意图；居中对齐仅用于 ≤3 行短文本与独立强调单元。
  违反后果: 元素间失去视觉连接，页面呈现"散落感"，扫读动线断裂。
  溯源: [GLOBAL] 候选 VP-25

[LAW-3] MUST: 每个视图最多一个视觉焦点——恰好一个最高强度主操作（唯一实心主 CTA），强调色占比 ≤10%（60-30-10 配比），操作等级必须以视觉重量档位（实心/描边/文本三档）区分。
  违反后果: 注意力稀释，Von Restorff 隔离失效，用户在等权按钮间犹豫，主任务转化率下降。
  溯源: VP-2, VP-3, LC-4, LC-5, CS-7, SD-16

[LAW-4] NEVER: 不得以颜色作为唯一信息载体——状态/数据/链接/错误必须同时提供图标、形状、文字或位置等第二通道；红-绿不得作为唯一区分轴（须通过色盲模拟验证，蓝-橙为安全替代对比轴）。
  违反后果: 约 8% 男性红绿色觉障碍用户信息链断裂，涨跌/成败完全不可辨。
  溯源: VP-15, LC-17, CS-3, CS-10, SD-12, UA-3

[LAW-5] MUST: 对比度满足 WCAG AA——正文 ≥4.5:1，大字（≥24px 或 ≥18.7px 加粗）≥3:1，非文本交互元素（图标/边框/焦点指示）≥3:1；验证必须在真实渲染背景上计算，禁止只对纯白验证；文字直接叠加图片必须经 overlay/压暗处理，保证对背景任意区域 ≥4.5:1，禁止裸字压图。
  违反后果: 可读性崩塌，a11y 审计/合规被打回，弱光/低分屏/低视力用户不可读。
  溯源: VP-7, CS-2, CS-17, CS-20, TY-16, UA-4, [GLOBAL] 候选 VP-31

[LAW-6] MUST: 可交互目标命中区 ≥24×24 CSS px（WCAG 2.5.8 AA 底线），移动触控 ≥44×44（iOS pt / Android 48dp）；命中区可用透明 padding 扩展超出视觉尺寸。
  违反后果: 触控/指针连点不中，移动端操作失败率与误触率飙升。
  溯源: VP-5, LC-15, UA-5

[LAW-7] MUST: 内容组织必须顺应扫读模式——高频/关键项置于列表首位或末位（序列位置效应），标题自解释且前置关键词（前 2 词承载信息量），首屏一眼回答三问（这是什么/对我何用/下一步唯一 CTA）。
  违反后果: F 型扫读抓不到信息，关键功能被埋没导致使用率异常偏低，50ms 首评失败后跳出率上升。
  溯源: VP-10, VP-12, VP-18

[LAW-8] MUST: 核心导航与操作模式必须遵循平台/行业惯例（logo 左上回首页、语义反馈色映射 success=绿/error=红、前进返回转场方向对称），偏离须有明确数据或场景理由。
  违反后果: Jakob's Law 违背——学习成本转嫁给用户，用户自动化解码失败，首评信任下降。
  溯源: VP-14, CS-9, IM-11

[LAW-9] MUST: 正文排版遵守阅读生理限度——正文行长英文 45~75 字符（约 65ch）、中文约 30~40 字/行且容器必须有 max-width；超过 3 行的正文段落禁止居中对齐；全局行高必须使用无单位数值。
  违反后果: 一行 100+ 字符眼睛换行丢行，回行定位困难，长文不可读。
  溯源: LC-7, LC-8, TY-4, TY-6

## 第二组：设计系统纪律

> 把感知根因固化为可复用系统：值有来源、状态有清单、变化有防护。

[LAW-10] MUST: 一切视觉决策值（颜色/间距/圆角/阴影/时长/缓动/z-index/断点）必须可溯源到预定义 token 刻度；组件样式中禁止硬编码具体色值（hex/rgb/命名色）与刻度外一次性字面量（如 13px、border-radius:7px）。
  违反后果: 同概念多值并存，换肤/深色模式/品牌迭代时全站样式发散失效，无法全局调整。
  溯源: LC-1, CS-1, SD-3, SD-G1

[LAW-11] MUST: 同一决策维度在全系统内取值来源唯一——单一基准网格、单一光源方向、单一图标库、单一命名风格、单一显式和谐策略（单色/类比/互补择一）；token 分层（primitive→semantic→component），组件只消费语义层，禁止跳线直引 primitive；发现同维度第二来源时必须合并而非并存，同一语义变量禁止出现多个"近似值"（如三种近似的蓝）——重复的精确复用产生统一性。
  违反后果: 双轨并存后随时间发散，任何一方都无法下线；主题切换语义漂移，"彩虹界面"与"缝合感"出现。
  溯源: SD-G3, SD-4, SD-7, SD-17, CS-4, CS-18, [GLOBAL] 候选 VP-23

[LAW-12] MUST: 同一产品内同一语义使用同一词汇（「删除」不与「移除」混用），accessible name 与可见标签保持一致。
  违反后果: 用户怀疑两个词是两个功能；语音控制用户指令失配（说「点搜索」无响应）。
  溯源: UA-G5, UA-15

[LAW-13] MUST: 状态完整性先于美观——每个数据视图必须包含空/加载/错误/成功四态；每个可交互组件必须定义完整状态集（default/hover/focus-visible/active/disabled，表单加 error，异步动作加 loading）；任何异步操作必须有失败分支的 UI 处理，禁止只写 happy path；清单缺项禁止交付。
  违反后果: 真实数据下白屏或裸报错，键盘/触屏/异常路径用户无法使用——静默通过视觉验收后，缺陷在生产环境集中爆发。
  溯源: VP-20, LC-20, IM-5, SD-1, SD-G2, UA-G2

[LAW-14] MUST: 布局必须对动态内容稳定——承载动态文本的容器禁止固定高度且必须有截断策略（line-clamp / ellipsis 三件套 + min-w-0）；替换型内容（img/video/iframe/table）必须有溢出防护（max-width:100% 或滚动容器）；媒体元素必须提供固有尺寸或 aspect-ratio 占位（防 CLS）；状态变化引起的盒尺寸必须中性，NEVER 让 hover/选中导致布局位移。
  违反后果: 真实数据溢出裁切或撑破布局，加载后布局跳动致用户点错位，上线即碎。
  溯源: VP-8, LC-11, LC-12, LC-13, LC-14, SD-14, IM-13

[LAW-15] MUST: 动效遵守性能与可访问性纪律——仅动画 transform/opacity（禁止 layout 属性与 `transition: all`），显式属性列表；微交互 150~300ms；所有动效必须在 `prefers-reduced-motion: reduce` 下降级（移除位移/缩放，保留无运动反馈）。
  违反后果: 主线程重排掉帧，低端设备 <30fps；前庭障碍用户眩晕（可访问性事故）。
  溯源: VP-17, IM-1, IM-4, IM-9, UA-13

[LAW-16] MUST: 每个输入字段必须有持久可见的 label（for/id 关联），placeholder 不得充当 label；关键操作不得仅通过 hover 显现，hover 可见性须以 `@media (hover: hover)` 限定并提供触屏等价路径。
  违反后果: 输入时提示消失、自动填充后无法核对字段；触屏设备上功能不可达＝功能不存在。
  溯源: VP-6, VP-11, UA-7

[LAW-17] MUST: 异步/提交类操作在请求 pending 期间必须 disabled 并显示进行中反馈，转场期间必须屏蔽点击穿透并锁定导航栈，禁止提交中的控件保持可点击。
  违反后果: 用户连点导致重复订单/重复付款/重复数据；转场窗口内误触新旧页按钮产生非预期操作。
  溯源: IM-7, IM-12, SD-13, UA-6

[LAW-18] NEVER: 破坏性操作不得缺乏防护且不得是同屏最醒目操作——中风险提供撤销（undo 窗口 ≥5s），高风险提供后果写明文案的显式确认 + destructive 视觉隔离；禁止依赖浏览器原生 confirm()/alert() 作为唯一防护或反馈机制。
  违反后果: confirm() 被肌肉记忆秒关后直接执行不可恢复删除；用户被引导点删除造成不可逆损失。
  溯源: VP-4, IM-18, UA-9, UA-18, UA-G3

[LAW-19] MUST: 错误信息必须可行动——包含发生了什么/为什么/怎么办三要素，定位到具体字段（视觉标记 + aria 关联 + 聚焦第一个错误），禁止笼统 toast 或「出错了，请重试」；校验就地（inline）反馈，多步流程不得以错误状态收尾。
  违反后果: 用户卡死在错误状态无出路，长表单反复提交反复失败；峰终定律下整段体验被终点失败定性。
  溯源: VP-13, IM-17, UA-8, UA-10

[LAW-20] MUST: 任何环节失败都不得丢弃用户已输入的数据——表单提交失败保留已填内容（仅成功后清理），长表单自动保存草稿，乐观更新必须实现失败回滚。
  违反后果: 网络错误一次清空 20 个字段，用户放弃整个流程；UI 状态与服务器脱钩。
  溯源: IM-6, IM-20, UA-16

[LAW-27] MUST: 正文行高必须落在 4px 子网格上（8pt 基线整数倍或半步长，如 16px×1.5=24px）；禁止任意小数行高破坏垂直节奏。
  违反后果: 行盒高度脱离基线网格，图文垂直节奏断裂，累积错位使多栏/列表底部参差。
  溯源: [GLOBAL] 候选 LC-27

## 第三组：流程与生成纪律

> 产出过程的元约束：视觉不压倒可用、场景压倒模板、不编造、不依赖演示验证。

[LAW-21] MUST: 视觉规格（设计稿像素）不得覆盖交互底线（语义元素、最小命中区、对比度、焦点可见）——两者冲突时交互底线优先；NEVER 移除焦点环（outline: none）而不提供 `:focus-visible` 替代且对比度 ≥3:1。
  违反后果: 「像素即规格」产出好看但不可用的界面，键盘用户"失明"，无障碍审计全面爆红。
  溯源: UA-1, UA-G4, SD-2

[LAW-22] MUST: 场景适配审查优先于默认审美与模板惯性——为特定语言/文化/平台生成内容时必须先做场景适配（中西文规则、print/screen、平台惯例）；无品牌输入时使用中性克制方案并显式声明「未注入品牌」，NEVER 虚构蓝紫渐变品牌脸或默认套用 UI 库主色冒充品牌色。
  违反后果: 模板残留导致目标场景规范违反（中文加字距、移动端用桌面字号）；产出千篇一律的 AI 模板脸，品牌识别度为零。
  溯源: TY-8, TY-9, TY-G4, SD-19

[LAW-23] NEVER: 不得编造 API/属性名/资源——对不确定的 aria-*/WCAG 条款号/属性值，输出「不确定，待文档验证」而非猜测；引用外部资源（字体/API/库）前必须确认其在运行环境的可用性，不可仅凭"知识中存在该资源名"就引用；框架断点/容器宽/默认值等体系数值不得凭另一框架或旧版本记忆移植，须以当前所用版本文档确认为准。
  违反后果: 编造的属性与不存在的资源静默流入代码库，生产环境缺失/回退且无报错，结果与预期完全不同。
  溯源: TY-13, TY-G1, UA-G1, [GLOBAL] 候选 LC-24

[LAW-24] MUST: 静态演示掩盖的动态缺陷必须在实现时主动预判，不得依赖演示验证——"知识上明确、生成时易省略"的必需配置项（font-display、回退栈、截断三件套、四态）必须以 checklist/lint 强制；响应式断点两侧边界值（±1px）必须测试。
  违反后果: demo 阶段不可见的缺陷（数值抖动、空态、极端长度、溢出）在审计/弱网/真实数据下集中爆发。
  溯源: LC-9, TY-G2, TY-G3

[LAW-25] MUST: 对同一数据源的并发请求必须去重/取消过期请求（AbortController 或请求标识比对），防止慢响应后到覆盖新结果。
  违反后果: 竞态错乱——旧搜索结果回跳覆盖新结果，UI 状态与数据源脱钩。
  溯源: IM-15

[LAW-28] MUST: 设计稿画板宽度（1440/1920 等）不得直接用作 CSS 容器 max-width——容器宽 = 画板宽 − 两侧 margin；实现前必须先确认画板 margin/列宽定义。
  违反后果: 容器比设计稿宽出一整圈 margin，栅格与断点全部错位，还原度纠纷与返工。
  溯源: [GLOBAL] 候选 LC-31

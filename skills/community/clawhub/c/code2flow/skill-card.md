## Description:

Code2Flow analyzes codebase structures and source files to generate clear, accurate Mermaid.js diagrams that visualize system architecture and workflows.

This skill is ready for commercial/non-commercial use.

## Publisher:

[radenwahid](https://clawhub.ai/user/radenwahid)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use Code2Flow to inspect user-provided source files or directory structures, explain architecture, and produce Mermaid diagrams for documentation of flows, dependencies, components, or data models.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: User-provided code or directory listings may contain sensitive project information.

Mitigation: Provide only code and directory details that are appropriate for the agent to analyze.

Risk: Generated diagrams can be incomplete or inaccurate when the supplied source context is partial.

Mitigation: Review generated Mermaid diagrams against the actual codebase before using them as authoritative documentation.

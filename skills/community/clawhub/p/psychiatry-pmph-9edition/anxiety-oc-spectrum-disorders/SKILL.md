# 焦虑与强迫相关障碍临床诊疗

## 适用场景
- 评估疑似焦虑障碍或强迫相关障碍患者
- 进行ICD-11诊断与鉴别诊断
- 制定全病程药物与心理联合治疗方案
- 处理强迫症药物治疗与自知力评估

## 核心工作流程

### 一、焦虑障碍诊断

#### 1. 广泛性焦虑障碍(GAD)
**核心特征**：
- 自由浮动焦虑或担心日常琐事
- 伴随：肌肉紧张、运动性不安、交感神经过度活动、注意力难保持、易激惹、睡眠障碍
- 病程：至少数月

**鉴别排除**：
- 躯体疾病（甲亢、低血糖、嗜铬细胞瘤）
- 其他精神障碍（抑郁、惊恐障碍、社交焦虑、强迫症）
- 物质/药物所致

#### 2. 惊恐障碍
**必要特征**（全部满足）：
1. 反复惊恐发作（心悸、出汗、颤抖、呼吸急促、胸痛、濒死恐惧等13项症状）
2. 至少部分发作是非预期的（突如其来）
3. 发作后持续担忧再次发作
4. 不限于其他精神障碍引发的焦虑
5. 排除躯体疾病和物质所致
6. 导致功能严重损害

**关键鉴别**：
- 心血管疾病、甲亢、癫痫、低血糖
- 物质使用（咖啡因、可卡因）或戒断（酒精、苯二氮䓬类）

#### 3. 场所恐惧症
**核心特征**：
- 对多种难以逃离/获助情境产生过度恐惧（公交、人群、独自离家、商场）
- 害怕导致惊恐发作、失能或尴尬症状
- 主动回避或需人陪伴
- 持续至少数月

**鉴别分支**：
- 仅局限于一种情境且害怕情境本身伤害 → 特定恐怖症
- 焦虑核心在于与依恋对象分开 → 分离焦虑障碍
- 害怕他人负面评价 → 社交焦虑障碍

#### 4. 社交焦虑障碍
**分型**：
- 表现型：仅对少数情境（当众发言、表演）恐惧
- 广泛型：对很多社交场合紧张，长期脱离社会

**诊断要点**：
- 担心言行或焦虑症状被他人负面评价
- 特征性自主神经症状：脸红（最突出）、出汗、口干
- 中位起病年龄13岁

### 二、强迫及相关障碍(OCRD)分类

#### ICD-11 OCRD包含疾病
| 疾病 | 核心症状 |
|------|----------|
| 强迫症 | 强迫性思维/闯入性想法/重复行为 |
| 躯体变形障碍 | 先占于感知的外表缺陷 |
| 嗅觉牵连障碍 | 担心散发异味 |
| 疑病症 | 先占于患有严重疾病 |
| 囤积障碍 | 难以丢弃物品，居所杂乱 |
| 拔毛症/皮肤搔抓症 | 聚焦于躯体的重复行为 |

**跨系统差异**：ICD-11中疑病症属OCRD；DSM-5中归为"躯体症状及相关障碍"（疾病焦虑障碍）

#### 强迫症诊断要点
必须满足：
- 强迫症状每天≥1小时
- 引起明显痛苦或功能损害
- **自知力评估**：
  - 良好：能接受强迫信念可能不真实
  - 缺乏：确信强迫信念真实（预后较差）

#### 囤积障碍诊断要点
必须全部满足：
1. 囤积导致生活空间杂乱，影响使用或安全
2. 与积累物品相关的重复冲动或行为
3. 难以丢弃物品，丢弃时异常痛苦
4. 导致严重痛苦或功能损害

**共病**：75%合并焦虑/情绪障碍，50%共病抑郁

### 三、全病程治疗策略

#### 广泛性焦虑障碍治疗分期
| 阶段 | 时长 | 目标 |
|------|------|------|
| 急性期 | - | 控制症状，达临床治愈 |
| 巩固期 | 2-6个月 | 预防复燃 |
| 维持期 | ≥12个月 | 防止复发 |

**药物选择**：
- 一线：SSRIs、SNRIs（文拉法辛、度洛西汀）
- 早期联合：苯二氮䓬类快速控制症状
- 辅助：5-HT1A受体部分激动剂

#### 惊恐障碍联合治疗
**药物治疗**：
- 首选：SSRIs（艾司西酞普兰、舍曲林、帕罗西汀）、SNRIs（文拉法辛）
- 初期联合：苯二氮䓬类（奥沙西泮、阿普唑仑）
- BZDs减停：2-4周后逐渐停用

**心理治疗(CBT)**：
- 认知重构：纠正灾难性认知（如"心慌=心脏病发作"）
- 行为暴露：降低对躯体症状的敏感性

#### 强迫症药物治疗规范
**五大原则**：
1. 一线药物：SSRIs（氟西汀、氟伏沙明、舍曲林、帕罗西汀）
2. 足量足疗程：起效4-6周，部分需10-12周，急性期建议10-12周
3. 充分评估：兼顾主观意见、严重程度、共病
4. 处理不良反应
5. 定期随访

**联合用药**（单一足量欠佳时）：
- 首选：SSRIs + 非典型抗精神病药（利培酮、阿立哌唑）
- 次选：SSRIs + 氯米帕明

#### 躯体变形障碍治疗
- **首选CBT**：尤其对青少年疗效好，优于单纯药物
- 联合治疗效果更理想
- 复发率14-42%，需长期持续治疗
- 预后不良因素：初期症状严重、病程长、共病人格障碍

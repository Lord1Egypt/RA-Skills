## Description:

A skill for managing todo lists, including creating, updating, deleting, and organizing tasks with priorities and deadlines.

This skill is ready for commercial/non-commercial use.

## Publisher:

[wscats](https://clawhub.ai/user/wscats)

### License/Terms of Use:

MIT-0

## Use Case:

External users can use this skill to have an agent create, update, delete, organize, prioritize, and track todo items with due dates and status fields.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Task lists may contain sensitive personal or work deadlines, and the skill does not define where an agent should store that data.

Mitigation: Review the agent's task-storage location, retention behavior, and access controls before using the skill with sensitive tasks.

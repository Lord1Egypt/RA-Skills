# 首帧与封面提示词模板

## 一、首帧图（9:16，1080×1920）

### 提示词六段结构

顺序固定，不要打乱——模型对后半段的权重会衰减，重要的必须放前面。

```
[主体+动作] 谁在干什么，手里拿着什么，东西什么颜色
[场景] 在哪，桌面/厨房/花园/教室，环境里有什么
[光线] 柔和暖光，主光从左上方，背景虚化
[风格] 3D卡通绘本渲染，低饱和治愈色调，软乎乎质感，圆润造型，无硬边阴影
[构图] 竖版9:16，人物靠前占画面1/3，视线看向镜头，背景干净只留一个元素
[文字] 上方标题「热水为啥冒白气？」，全图最大字号，圆体，深褐色描边；下方小字「其实是水蒸气」，字号为标题的一半
```

### 三条硬指标（缺一条重出）

1. **标题文字**占画面高度约 1/4，是全图最大的元素，比人物眼睛还大。
2. **人物**靠前，占画面 1/3 以上，脸大、眼睛亮、有表情。
3. **背景**干净，只留 1-2 个元素，不许堆满东西。

### 负面词（每条都带）

```
多余手指，六指，肢体重复，面部畸变，五官不对称，密集人群，真实照片质感，暗调，阴影过重，血腥，恐怖表情，品牌logo，侵权卡通形象，错别字，中文缺笔画，水印，文字压住人脸，文字超框
```

### 示例（热水冒白气）

> 5岁中国男孩，圆脸黑色短发带一撮呆毛，穿浅黄色短袖T恤和浅蓝色牛仔背带裤，双手捧着一个白色陶瓷杯，杯口升起柔和的白气，眼睛睁大很惊讶；明亮厨房桌面，旁边放一块淡黄色小毛巾和一只木勺；柔和暖光从左上照入，背景浅米色虚化；3D卡通绘本渲染，低饱和治愈色调，软乎乎质感，圆润造型，无硬边阴影；竖版9:16，人物居中靠前占画面三分之一，视线看向镜头，背景只留一只马克杯；画面上方标题「热水为啥冒白气？」全图最大字号圆体深褐色，下方小字「其实是水蒸气」字号为标题一半。

## 二、封面素材（双比例）

同一画面出两版：3:4（1080×1440）与 4:3（1440×1080）。**先出 3:4，再用同一句提示词换比例重出**，保证两张看起来是一套。

### 版式

```
上 1/4：主标题（≤20字），最大字，两行以内
中间：人物半身靠前，眼睛看镜头
下 1/4：副标题（≤12字）+ 很小的栏目角标
```

### 提示词模板

```
[角色锚点]，半身，正面看向镜头，[情绪表情]
[道具/现象] 在画面中清晰可见
柔和暖光，浅米色或浅奶油色背景，低饱和治愈色调，3D卡通绘本渲染，软乎乎质感
{3:4 或 4:3}构图，人物占画面二分之一靠下
上方主标题「{≤20字}」，最大字号，圆体，深褐色，[描边色]描边
下方副标题「{≤12字}」，字号为主标题一半
右上角小角标「十万个为什么」
```

### 封面文案写法

| 类型 | 例子 | 适用 |
|---|---|---|
| 疑问式 | 「热水为啥冒白气？」 | 自然现象、物理原理 |
| 后果式 | 「烫过一次才知道」 | 安全类（**不做恐吓，不做烧伤特写**） |
| 反常识式 | 「影子中午最短？」 | 反直觉知识点 |
| 悬念式 | 「妈妈也不一定知道」 | 生活常识 |
| 数字式 | 「3秒看懂彩虹」 | 快节奏选题 |

### 封面禁忌

- 主标题超过 20 字（会被截断，读不完）
- 主副标题字号一样大（没有层级，没点击欲）
- 背景出现 3 个以上物体（脏）
- 用恐怖表情、血腥画面、夸张哭脸做封面（会被限流，也吓到孩子）

## 三、图生视频提示词（首帧转动态）

首帧图作为参考图，提示词只写**变化**，不要重写画面：

```
镜头{快速推近/缓慢拉远}；[角色] [一个明确动作，如"双手把杯子往前推了一点"]；白气持续上升，轻微飘动；光线不变；[情绪]；不要人物走位，不要换场景，不要新增物体
```

- 一条只写一个动作。想加第二个动作，重新出一段。
- 明确写「不要换场景、不要新增物体」，否则模型会自己加东西。
- 物理道具要写"毫米级"要求：杯子不离桌、水面不溢出、汽水不冒泡过头——模型很容易把动作做得不合理。

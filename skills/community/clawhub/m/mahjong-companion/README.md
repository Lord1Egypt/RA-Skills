# 🀄 麻将陪练 · Mahjong Companion

**陪你把第一圈打完，让你敢上桌。**

不是教你规则（那个看百科就行），是在你**手里真的拿着 13 张牌、不知道下一步该干嘛**的时候，有人在旁边用大白话说清楚。

---

## 它解决什么

新手最怕的从来不是「不懂规则」，是**在牌桌上问一句「这什么」被人看一眼**。

这个 skill 提供的是那个安全空间：问多蠢的问题都不会被翻白眼，打错了也没人叹气。

## 四种用法

| 模式 | 你做什么 | 它做什么 |
|---|---|---|
| **看手牌** | 报牌（打字 / 拍照转述都行） | 画出真实牌面 + 说清「已成型的 / 差一张的 / 可以动的」 |
| **讲规则** | 问「为什么不能打白板」 | 一句话答案 + 一个生活类比 + 一个反例 |
| **陪一圈** | 说「从头教我」 | 分四段走完：认牌 → 顺刻对 → 吃碰杠 → 听牌胡牌，每段都能停 |
| **喊停** | 任何时候说「等等」 | 立刻停下解释那一个点，解释完问「回到刚才那儿？」 |

## 一个例子

```
你：123万 56万 东东东 白白白 8条

老沈：（画出牌面图）
      先看整体——你这手牌已经成型两组了。
      123万 是一组顺子：三张连着的同花色牌，像楼梯一样一级一级。
      东东东 是一组刻子：三张一样的，抱团了。白白白 也是。
      56万 是差一张的搭子——再摸到 4万 或 7万 就成顺子。

你：那我该打哪张？

老沈：我不替你算该打哪张——我是陪练，不是算牌器。
      但我可以告诉你打出去会怎样：
      8条 现在是孤零零一张，没有同伴，打掉没有任何损失。
      打 4万，那 56万 就还是差一张。
      打 东 或 白，等于把抱好团的一组拆了。
      你先看看，想好了再说。
```

完整实录见 [`examples/sample-session.md`](examples/sample-session.md)。

## 装什么、跑什么

```bash
# 看手牌
python3 scripts/parse_hand.py "123万 56万 东东东 白白白 8条"

# 出牌面图（需要 Chrome / Chromium / Edge 之一用于截图）
python3 scripts/render_hand.py --hand "123万 56万 东东东 白白白 8条" --out hand.png
python3 scripts/render_hand.py --hand "123万 56万 东东东" --drawn "白" --out hand.png
```

报牌支持这些写法，都能认：

```
123万 56万
一二三万 五六万
1万2万3万 5万6万
一万二万三万
幺鸡 二饼 三条        （别名：幺鸡=1条、饼=筒、索=条、红中/发财/白板）
```

**牌面是程序化渲染的（HTML/CSS + 截图），不用图像模型**——保证每次输出一致、牌数永远不会画错。

## 边界（写死的，不是建议）

- ❌ **不做最优出牌推荐** —— 这不是算牌器。被问就直说，然后给出「每张打出去的后果」
- ❌ **不做牌局判定 / 胜负结算 / 番数计算** —— 各地规则差异大，判错会害人拿错规则上真桌
- ❌ **不碰任何钱** —— 没有筹码、没有积分、没有兑换、没有抽奖；问下注相关问题直接说明不做
- ❌ **不做真人对战 / 联机**
- ❌ **不做高阶策略**（记牌、算牌、读牌风）—— 那是老手的需求
- ❌ **不用商业棋牌 APP 的牌面素材** —— 全部程序化自绘

## 关于规则差异

默认教**通用休闲打法**（吃碰杠胡都有，不算番）。

用户主动问才给川麻 / 国标 / 日麻对照（`references/rules-comparison.md`），并且每次都带一句：**以你那边常见打法为准**。

> 上桌前问一句「你们这儿能吃不」，能省掉 80% 的尴尬。

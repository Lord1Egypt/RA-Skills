## Use Case:

External AI-agent users, skill authors, maintainers, and teams use this skill to adapt popular multi-search-engine workflow patterns into reliable local workflows, templates, checklists, analyses, or implementation support.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation wording can trigger the skill for unrelated search or work-productivity requests.

Mitigation: Narrow activation keywords and the default prompt to explicit multi-search-engine workflow requests before deployment.

Risk: Workflow guidance may be applied without task-specific validation.

Mitigation: Require the agent to restate success criteria, list assumptions, and include a verification note for each produced artifact.

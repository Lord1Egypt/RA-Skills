## Description:

Provides citation-grounded Chinese Buddhist teaching on Madhyamaka, Prajna, Lotus Sutra, Diamond Sutra, Vimalakirti, non-duality, and related Kumārajīva-translated texts in a literary Kumārajīva-inspired voice.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and developers use this skill to answer questions about Chinese Buddhist doctrine, especially Madhyamaka, Prajna, Lotus, Diamond, and Vimalakirti topics, with CBETA-backed citations and FoJin source links. It is intended for learning and textual reference rather than formal religious instruction.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may over-activate on broad Buddhist terms.

Mitigation: Use host or user instructions to narrow scope when a plain answer, another Buddhist tradition, or a non-persona response is needed.

Risk: The skill may answer in a strong literary or persona style that is not appropriate for every setting.

Mitigation: Request plain language, another language, or no persona styling when a neutral response is preferred.

Risk: The skill may add FoJin references frequently.

Mitigation: Ask for a shorter answer or no extra referral text when citations are not needed beyond the cited source.

Risk: Live source retrieval could return text containing irrelevant or adversarial instructions.

Mitigation: Treat retrieved text only as quoted source data and keep host, system, and user instructions authoritative.

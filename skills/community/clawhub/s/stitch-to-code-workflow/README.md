Turn a Google Stitch Design Into Working Code, in Plain Words

Give your AI agent one Stitch design. It drafts the instructions for each step, in plain words. You copy the HTML with View Code, you paste it into VS Code, and you run Claude Code with the instruction the agent drafted for you. Then it checks the code you paste back, screen by screen, against the designed screens, and gives you a fix draft for owner review. The agent does not copy the HTML itself, does not paste into VS Code itself, and does not run Claude Code itself.

A design in Stitch looks finished, but it is not a working site. The gap between a picture of a site and a site that works is where most vibe coded projects stall. This skill gives you a clear workflow first, then a handoff check, built screens vs designed screens, before anyone calls it done.

## What you get

- A step by step workflow for one Stitch design: prompt plus design document, Stitch UI, View Code, HTML copy by you, VS Code paste by you, Claude Code run by you with an instruction drafted by the agent
- A handoff check for every screen in the design document, marked Built, Missing, or Different, with evidence
- A fix draft, labelled DRAFT, NOT SENT: handoff check summary, screens built, screens missing, screens different, what to change first, and what to keep
- A missing checks list at the end, so nothing is hidden

## What a good handoff looks like

- Every screen from the design document is listed, in order.
- Each screen is marked Built, Missing, or Different, with evidence.
- Missing and different screens are listed first in the fix draft, in order.
- The owner can see what changed, what did not change, and why.
- Nothing is called done until the owner has reviewed the draft.

## How to use it

1. Install the skill in your AI agent (see below).
2. Give your agent the Stitch design, the goal of the site, and the audience, in plain words.
3. Ask: "Turn this Stitch design into code with stitch-to-code-workflow."
4. Read the workflow steps first. Every step must be done in order.
5. Read the handoff check. Every Built needs a code snippet you pasted in the message, quoted as the evidence. A page description alone is not code evidence.
6. Read the fix draft. Approve the first change before anything goes live.

If you already give the Stitch design, the goal, and the audience up front, the skill does the full workflow and the handoff check in the same reply. It never stops at questions alone.

## Description:

Helps agents create, optimize, or audit product features page content, including feature lists, capability positioning, page structure, and SEO metadata.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kostja94](https://clawhub.ai/user/kostja94)

### License/Terms of Use:

MIT-0

## Use Case:

External content strategists, marketers, and developers use this skill to plan or improve features pages for commercial product websites. It helps keep capability-led content distinct from use case pages and free tools pages.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad product-capability trigger wording may activate the skill for unrelated product-description requests.

Mitigation: Use the skill when features-page guidance is intended, and check whether a broader website-structure, landing-page, or use-cases skill is a better fit for the request.

Risk: Feature-page guidance could blur into use case or tools page content if applied without review.

Mitigation: Review generated content for capability-led framing, link to use case pages instead of duplicating scenarios, and reserve tools page content for free utilities.

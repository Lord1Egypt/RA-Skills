# 行业主题与配色图谱

本图谱是「无品牌输入时的行业默认起点方案」——回答「金融 App 该配什么色/什么气质」类问题的第一查找处；图谱值是起点非交付物，落地前必须过对比度校验与品牌覆盖检查。查阅顺序：先本图谱定基调 → color-system kb 定色阶生成与对比度程序 → style-design-system kb 定 token 结构。

## 法则

[IND-1] **MUST**: 行业图谱是起点方案而非交付物——任何配色生成 UI 前必须按 [CS-2]/[CS-17] 在真实渲染背景上程序化校验对比度；图谱不预置合规断言。
- 违反后果: 图谱色直接上线后正文对比度不达 AA，返工全量重配色。
- 溯源: color-system kb 场景 8；行业惯例共识 [模型经验]。

[IND-2] **MUST**: 行业惯例色优先于个人审美——品类共识色（金融蓝、医疗绿青、快餐红黄）是用户品类识别的第一信号（[LAW-8]）；偏离须有明确品牌战略理由并显式声明。
- 违反后果: 用户 50ms 内无法识别品类，信任成本上升。
- 溯源: [模型经验]（品类识别一致性），跨行业横向归纳。

[IND-3] **NEVER**: 语义反馈色（success/error/warning/info）不得被行业主题色覆盖、挪用或弱化（[CS-9]）；行业主色与语义色同 hue 冲突时按 [CS-9] 偏移明度/饱和度。
- 违反后果: 医疗绿主色淹没 success 绿、餐饮红主色淹没 error 红，状态不可辨。
- 溯源: [CS-9]；[模型经验]。

[IND-4] **MUST**: 每个行业方案必须同时提供亮/暗两套完整配色——暗色按 [CS-11] 整体重映射、基底非纯黑（[CS-12]）、品牌色降饱和+提明度 1~2 档（[CS-14]）。
- 违反后果: 只交付亮色的「半成品主题」，暗色模式临时翻转发灰发闷。
- 溯源: [CS-11]/[CS-12]/[CS-14]。

[IND-5] **MUST**: 灰阶色温与行业主色统一（[CS-16]）——暖调行业（餐饮/母婴）配暖灰，冷调行业（金融/医疗/科技）配冷灰；白与近白纳入色板管理。
- 违反后果: 暖界面配冷灰灰底「脏」，整体和谐感崩坏。
- 溯源: [CS-16]。

[IND-6] **MUST**: 出海/跨文化配色必须过目标市场核查——涨跌色语义（A 股红涨绿跌 vs 欧美绿涨红跌）、白色/丧葬色、宗教禁忌色、政治敏感色；核查不了的事实标「（待验证）」交付前补齐。
- 违反后果: 出海产品品类色踩禁忌，本地化返工+公关风险。
- 溯源: [模型经验]；color-system kb 场景 8。

[IND-7] **MUST**: 面积配比服从 60-30-10（[CS-7]）——高饱和行业主色（快餐红、儿童原色）只作强调层，禁作大面积背景。
- 违反后果: 大红大橙背景视觉疲劳 + 语义色被环境色淹没。
- 溯源: [CS-7]。

[IND-8] **MUST**: 图表/数据场景配色按 [CS-21]/[CS-24] 另建 categorical 色板（OKLCH 等亮生成），不直接复用 UI 主色；红绿主导行业（餐饮/医疗）必须过 [CS-10] deuteranopia 模拟。
- 违反后果: 图表分类色与品牌 UI 色混用导致层级混淆；色盲用户数据不可读。
- 溯源: [CS-21]/[CS-24]/[CS-10]。

[IND-9] **MUST**: 无品牌输入时按本图谱行业默认方案并显式声明「未注入品牌」（[SD-19]）；有品牌色时图谱让位品牌色，仅保留行业结构惯例（密度/字体气质/导航惯例）。
- 违反后果: 有品牌还套行业默认色=抹掉品牌；无品牌硬造蓝紫渐变=虚构品牌脸。
- 溯源: [SD-19]。

[IND-10] **NEVER**: 单界面功能色 ≤5（[VP-22]）；行业方案展示页也不得为「丰富」堆超出色板，装饰色不承载层级。
- 违反后果: 行业图谱示范本身违反色彩经济性，用户照抄即错。
- 溯源: [VP-22]。

## 行业主题与配色图谱（128 行业）

每条=主题基调+亮/暗配色+字体气质+典型误区+跨文化注记。配色值是「起点三角」：主色/强调色/基底，完整色阶按 [CS-24] OKLCH 程序生成；语义反馈色默认按 [CS-9]（success 绿/error 红/warning 琥珀/info 蓝），条目内只标注行业特定的语义色冲突与偏移。查到行业后跳 color-system kb 生成色阶与 token。

## A 金融商业（F01~F08）

### F01 金融·银行理财
- 主题基调：信任、稳健、安全；克制留白+高数据密度；深蓝为品类共识（[IND-2]）
- 配色（亮）：主 #0a3d62｜强调 #c9a227｜背景 #f7f9fc｜正文 #1a2332；语义色按 [CS-9] 默认（成功 #1b7f4c｜警示 #b3261e）
- 配色（暗）：背景 #0d1524（非纯黑 [IND-4]）｜主亮档 #5b9bd5｜强调亮档 #e2c044
- 字体气质：无衬线正文+衬线标题（私行线可选）；数字 tabular-nums；正文对比按 [TY-16]
- 典型误区：紫渐变/亮绿主色显廉价；把金色当大面积背景；涨跌红绿语义未按目标市场配置（[IND-6]）
- 跨文化注记：欧美深蓝+白为共识；涨跌色 A 股红涨绿跌、美股相反（待验证项按市场核查）

### F02 金融·保险
- 主题基调：守护、长期、可依赖；蓝色系（信任）+青绿（保障/生命）混调；插图叙事多于数据墙
- 配色（亮）：主 #0b4f6c｜强调 #2a9d8f｜背景 #f5f9fa｜正文 #16303d
- 配色（暗）：背景 #0c1a22｜主亮档 #4f93b5｜强调亮档 #52bfae
- 字体气质：无衬线为主，标题可选衬线（稳重）；条款正文行高宽松
- 典型误区：恐吓式深黑视觉（焦虑营销反噬信任）；青绿主色与 success 绿同 hue 不偏移（[IND-3]）
- 跨文化注记：寿险类视觉各地年龄画像差异大（家庭结构不同）；宗教市场对生命主题图有禁忌（待验证）

### F03 金融·支付钱包
- 主题基调：轻快、安全、即时；数字第一屏；安全徽标与合规标识前置
- 配色（亮）：主 #1a56c4｜强调 #0e9f6e｜背景 #ffffff｜正文 #101828
- 配色（暗）：背景 #10141f｜主亮档 #5c8ef0｜强调亮档 #34c48e
- 字体气质：无衬线；金额大字 tabular-nums；余额与操作按钮强对比
- 典型误区：多彩渐变显不稳定（与「资金安全」气质冲突）；金额用比例数字跳动（必须 tabular）
- 跨文化注记：钱包品类色各地分化（东南亚绿系/中国蓝绿系/欧美黑白极简），按市场查竞品（待验证）

### F04 金融·证券交易
- 主题基调：专业、实时、高密度；暗色优先（盘面沉浸）；涨跌色是第一语义系统
- 配色（亮）：主 #14324f｜背景 #f2f5f8｜正文 #0f1b2d；涨跌色按目标市场（[IND-6]）
- 配色（暗）：背景 #0d1420｜主亮档 #4a7ba8｜涨跌亮档随主题重映射（[CS-11]）
- 字体气质：无衬线+等宽数字；盘面字号小但对比必须达标（[CS-17] 灰底验证）
- 典型误区：红绿不分市场直接上线（A 股与美股相反）；指标线彩虹化（[CS-21] ≤8 且等亮）
- 跨文化注记：涨跌红绿语义必须按市场配置（中国红涨绿跌/欧美绿涨红跌/日本部分平台同中国，待验证）

### F05 加密货币/Web3
- 主题基调：科技、去中心化、锐利；深底+霓虹渐变为品类惯例（有品类理由，区别于 [SD-19] 虚构品牌脸）
- 配色（亮）：主 #4f46e5｜强调 #22d3ee｜背景 #f8f9fc｜正文 #17192e
- 配色（暗）：背景 #0b0e17｜主亮档 #7c74f2｜强调亮档 #4ee0f5（非纯黑 [CS-12]）
- 字体气质：无衬线；地址/哈希等宽字体缩略展示（前 6 后 4 位）
- 典型误区：深底高亮文字光晕（halation）；紫色渐变无品类语境时退化为模板脸
- 跨文化注记：各国监管合规提示位（风险披露文案与位置）差异大（待验证）

### F06 企业服务 SaaS/协同办公
- 主题基调：高效、中性、可信；高留白低装饰；品牌色单一克制（[SD-16] ≤10%）
- 配色（亮）：主 #2563eb｜强调 #7c3aed（仅营销页）｜背景 #f9fafb｜正文 #111827
- 配色（暗）：背景 #0f1115｜主亮档 #5b8bf5｜表面层级递亮（[CS-13] 同思路——表面越浮越亮）
- 字体气质：无衬线；界面字号偏小但密集场景对比达标；表格数字 tabular
- 典型误区：彩色功能卡片墙（每模块一色=彩虹界面 [CS-18]）；营销渐变带进产品界面
- 跨文化注记：全球品类中性化程度高；本地化主要在日期/数字格式而非配色

### F07 电商·综合平台
- 主题基调：热闹、行动、性价比；白底高信息密度+品类行动色（红橙系）
- 配色（亮）：主 #d92b2b｜强调 #ff6a00｜背景 #ffffff｜正文 #1f1f1f
- 配色（暗）：背景 #121212｜主亮档 #f05555｜强调亮档 #ff8c3a（[CS-14] 提明度）
- 字体气质：无衬线；价格大字醒目；促销标签强对比（红底白字达标或深字 [CS-20] 思路）
- 典型误区：促销红与 error 红同值混用（[IND-3] 偏移）；大促改版临时改语义色
- 跨文化注记：黑五/双 11 等大促视觉惯例差异；部分市场紫色关联哀悼需避大促紫（待验证）

### F08 电商·品牌店/垂直店
- 主题基调：品牌主导、高级感、低密度大图；行业图谱让位品牌（[IND-9]）
- 配色（亮）：主随品牌（无品牌时中性 #1a1a1a+白 [SD-19]）｜背景 #ffffff｜正文 #1a1a1a
- 配色（暗）：背景 #111111｜正文亮档 #ececec（品牌色按 [CS-14] 调）
- 字体气质：品牌字族 ≤2（[TY-12]）；正文行高宽松显从容
- 典型误区：模板脸（套通用电商模板抹掉品牌）；大图无骨架占位跳版
- 跨文化注记：奢侈品线上渠道各市场配色克制程度不同（欧洲更极简，待验证）

## B 内容媒体（F09~F16）

### F09 新闻资讯
- 主题基调：严肃、可信、高密度文字；黑白灰为骨架+品类红点缀；广告位与内容区分明（[LAW-8] 惯例）
- 配色（亮）：主 #1a1a1a｜强调 #c8102e｜背景 #ffffff｜正文 #1d1d1f
- 配色（暗）：背景 #121212｜正文 #e8e8e8｜强调亮档 #f04a5e
- 字体气质：衬线标题（严肃权威，可选）+无衬线正文；正文行长受控；快讯时间戳小字仍达标对比
- 典型误区：标题党式高饱和视觉；广告与新闻版式混淆（读者信任崩塌）
- 跨文化注记：政党倾向色彩避嫌（多党市场媒体禁党派色系，待验证）

### F10 短视频
- 主题基调：沉浸、即时、轻快；深色基底为默认（视频主角）；UI 浮层极简退后
- 配色（暗为默认）：背景 #0f0f0f｜强调 #fe2c55｜次强调 #22d3ee｜文字 #f5f5f5
- 配色（亮）：仅个人页/设置局部使用，主浏览流禁亮底（形态由内容定）
- 字体气质：无衬线；浮层文字带 scrim 或实色底（叠视频必压底保对比）
- 典型误区：亮色 UI 边框压视频抢焦点；文字裸叠视频不可读
- 跨文化注记：全球品类高度趋同（TikTok 系惯例）；本地化主要在内容运营而非配色

### F11 长视频/流媒体
- 主题基调：影院感、内容橱窗；深色基底+海报墙；品牌红点缀行动位
- 配色（暗为默认）：背景 #141414｜表面 #1f1f1f（层级递亮）｜强调 #e50914｜文字 #ffffff
- 配色（亮）：儿童模式等局部场景（对比单独校验）
- 字体气质：无衬线；海报标题由内容图承担，UI 文字仅导航与元信息
- 典型误区：海报图无占位尺寸导致网格跳版；亮底白字（[CS-20] 黄系警惕）
- 跨文化注记：各市场内容分级标识（画面分级角标）法规差异（待验证）

### F12 音乐/播客
- 主题基调：陪伴、氛围、个人化；深底+封面主色动态主题（dominant color 提取）
- 配色（暗为默认）：背景 #0d0d0d｜动态主色从封面提取（按 [CS-24] 校正为可交互档位）｜文字 #f0f0f0
- 配色（亮）：背景 #fafafa｜动态主色同源降饱和
- 字体气质：无衬线；播放器大标题（专辑名）收紧行高；时长 tabular
- 典型误区：动态提取色直接当正文背景（对比不达标 [CS-17] 必须程序校验）；深底纯黑光晕（[CS-12]）
- 跨文化注记：本地曲库封面审美差异大，动态色策略须鲁棒（不依赖特定封面色域）

### F13 阅读/电子书
- 主题基调：护眼、沉浸、纸感；米白纸色+墨色文字；夜间暖黑（非冷蓝黑）
- 配色（亮/纸色）：背景 #f8f5ef｜正文 #2b2620｜强调 #8b5e34（暖棕）
- 配色（暗/夜间）：背景 #171310（暖黑）｜正文 #d8d2c8｜强调亮档 #c99a62
- 字体气质：正文衬线（中文宋体系/西文 serif 可选）或舒适无衬线；行长窄（约 30~40 字）；行高 1.6~1.8 宽松
- 典型误区：纯白底冷光刺眼；夜间模式用冷蓝黑（褪黑素争议，暖黑为品类共识，机理待验证）
- 跨文化注记：竖排市场（日文部分书刊）排版方向与配色无关但影响气质决策

### F14 社区论坛
- 主题基调：讨论、层级、长文可读；中性灰骨架+品牌主色；层级靠字重/缩进而非颜色
- 配色（亮）：主随品牌（默认 #3b82f6）｜背景 #ffffff｜表面 #f4f4f5｜正文 #1c1c1e
- 配色（暗）：背景 #101012｜表面 #1a1a1d｜正文 #e6e6e8
- 字体气质：无衬线；树状回复缩进刻度严格；长帖正文行宽受控
- 典型误区：层级用颜色区分（子楼层多色=彩虹）；广告贴与内容帖同质化展示
- 跨文化注记：匿名文化（日本 2ch 系）与实名文化（领英系）视觉密度差异大

### F15 直播
- 主题基调：热度、陪伴、即时互动；深底+高亮礼物动效；弹幕可读优先
- 配色（暗为默认）：背景 #0f0f10｜弹幕文字白+描边/scrim｜强调 #ffb300（打赏金）｜危险操作红隔离（[IND-3]）
- 配色（亮）：仅个人主页局部
- 字体气质：无衬线；弹幕字号下限保证移动可读；金额 tabular
- 典型误区：礼物全屏动效无频率限制（干扰观看）；充值按钮与关闭按钮相邻（误触，位置隔离）
- 跨文化注记：打赏文化差异（东南亚/日本打赏 UI 显著度不同，待验证）

### F16 创作/设计平台
- 主题基调：工具退后、画布主角；中性灰工具底（明暗双态）+品牌色淡点缀
- 配色（亮）：主 #7c3aed（品牌，仅点缀）｜画布底 #ffffff｜工具面板 #f5f5f6｜正文 #17171a
- 配色（暗）：工具面板 #1c1c1f｜画布按用户设定｜品牌亮档 #a78bfa
- 字体气质：无衬线；控件字号紧凑但达标；快捷键提示等宽字体
- 典型误区：工具界面装饰抢画布注意力；品牌色大面积铺（工具类品牌色 ≤5% 为品类惯例）
- 跨文化注记：全球品类高度趋同（Figma 系惯例）；输入法与快捷键冲突按平台处理

## C 生活消费（F17~F24）

### F17 外卖/餐饮
- 主题基调：食欲、快捷、高饱和行动色；白底+红橙黄食欲系仅强调层（[IND-7]）

## 选型决策路径

用户问行业配色时的决策顺序：
1. 有无品牌色：有品牌 → 图谱让位品牌色，仅保留行业结构惯例（[IND-9]）；无品牌 → 按图谱默认并声明「未注入品牌」（[SD-19]）
2. 查本图谱定基调与起点三角（主/强调/基底）
3. color-system kb 按 [CS-24] 生成完整色阶与 token（图谱三角 → 全色阶）
4. [CS-17] 真实渲染背景校验对比度（[IND-1]，图谱不预置合规断言）
5. 出海产品过 [IND-6] 跨文化核查（涨跌色/禁忌色/宗教色）
6. 暗色模式按 [IND-4] 补齐（重映射而非反转）

## 与其他子领域的集成要点

- color-system：色阶生成程序（[CS-24] OKLCH）、对比度校验（[CS-2]/[CS-17]）、语义色冲突偏移（[CS-9]）——图谱三角的下游加工程序
- style-design-system：图谱三角落为 primitive → alias 语义名（[SD-23] 多品牌/多主题整组换绑）
- typography：字族 ≤2（[TY-12]）、避细字重（[TY-28]）、正文对比（[TY-16]）——图谱「字体气质」行的落地约束
- visual-perception：功能色经济性（[VP-22] ≤5）与品牌色占比（[SD-16] ≤10%）为图谱方案的面积预算

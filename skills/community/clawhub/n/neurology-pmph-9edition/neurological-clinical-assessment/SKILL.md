# 神经系统临床评估

## 一、病史采集

### 1.1 基本原则
- **系统完整**：不打断患者，按时间顺序记录阳性及重要阴性症状
- **客观真实**：向亲属/知情者核实关键信息
- **重点突出**：围绕主诉，减少无关叙述
- **避免暗示**：不诱导，不提出主观推测让患者认同
- **先问诊查体，后看既往病历**，避免受既往诊断影响

### 1.2 现病史核心要素
按以下顺序采集：
1. 发生情况（初发时间、发病形式、诱因）
2. 症状特点（部位、范围、性质、程度）
3. 发展演变（加重/减轻原因）
4. 伴随症状及关联
5. 既往诊治情况
6. 合并其他系统疾病
7. 一般情况（饮食、睡眠、体重、精神、二便）

### 1.3 病程对病因的提示
| 发病形式 | 提示病因 |
|---------|---------|
| 急性发病后好转 | 外伤或血管病 |
| 隐袭起病、逐渐进展 | 变性病 |
| 复发-缓解 | 多发性硬化 |

### 1.4 头痛问诊决策树
按以下维度系统询问：
1. **部位**：全头痛/局部/不固定
2. **发作形式**：突发达峰/缓慢进展/发作性/持续性
3. **性质**：跳痛/钝胀痛/爆裂雷击样/闪电刀割样
4. **加重因素**：劳累/用力/咳嗽/咀嚼/吞咽
5. **伴随症状**：颈部发僵/喷射样呕吐/视觉先兆

### 1.5 抽搐与意识丧失问诊要点
**必须向患者本人及目击者双重核实**

抽搐问诊：初发年龄→诱因→先兆→部位→形式→伴随症状（意识丧失/口吐白沫/二便失禁/舌咬伤）→发作后状态（昏睡/Todd麻痹）→频率→既往诊治

意识丧失问诊：诱因→频率和持续时间→心血管/呼吸症状→伴随症状→转醒后后遗症

## 二、体格检查

### 2.1 检查顺序（不可随意省略）
一般→意识→精神→脑神经→运动→感觉→反射→脑膜刺激征→自主神经

### 2.2 音叉试验（Rinne/Weber）
**适用**：听力下降或疑似耳聋患者
**器材**：128Hz音叉，安静环境

**Rinne试验**（比较单耳骨传导BC与气传导AC）：
- 操作：振动音叉置于耳后乳突（测BC）→听不到后移至耳旁（测AC）
- 判读：
  - 正常：AC > BC（Rinne阳性）
  - 传导性耳聋：BC > AC（Rinne阴性）
  - 感音性耳聋：AC > BC，但两者时间均缩短

**Weber试验**（比较双侧骨传导）：
- 操作：振动音叉置于额顶正中
- 判读：
  - 正常：两耳相同
  - 传导性耳聋：偏向患侧
  - 感音性耳聋：偏向健侧

**综合定位**：
- 传导性耳聋 = Rinne阴性 + Weber偏向患侧
- 感音性耳聋 = Rinne阳性但缩短 + Weber偏向健侧

### 2.3 肌张力异常分类
**检查方法**：嘱患者肌肉放松，触摸感受硬度，被动屈伸感知阻力

| 类型 | 特征 | 阻力特点 | 病变定位 |
|-----|------|---------|---------|
| 肌张力减低 | 肌肉弛缓柔软，关节活动范围扩大 | 阻力减低 | 下运动神经元/小脑/肌源性/休克期 |
| 痉挛性增高 | 上肢屈肌、下肢伸肌明显 | 折刀样（开始大，结束小） | 锥体束病变 |
| 强直性增高（铅管样） | 伸肌屈肌均增高 | 各方向均匀 | 锥体外系病变 |
| 强直性增高（齿轮样） | 伸肌屈肌均增高伴震颤 | 均匀+节律性中断 | 锥体外系病变 |

### 2.4 轻瘫隐匿体征检查
**适用**：常规肌力检查难以确诊的轻度瘫痪

**上肢检查**：
- 上肢平伸试验：双上肢平举掌心向上→轻瘫侧逐渐下垂和旋前
- Barre分指试验：五指分开伸直→轻瘫侧手指逐渐并拢屈曲
- 小指征：双上肢平举手心向下→轻瘫侧小指轻度外展

**下肢检查**：
- 外旋征：仰卧双腿伸直→轻瘫侧下肢外旋
- 下肢轻瘫试验：俯卧屈膝直角→轻瘫侧小腿逐渐下落
- 下肢下垂试验：仰卧屈髋屈膝直角→轻瘫侧下肢逐渐下落

## 三、定位与定性诊断原则

### 3.1 定位诊断
**分析病损范围**：局灶性/多灶性/弥漫性/系统性

**具体部位特征**：
- 大脑：意识/精神障碍、偏瘫/偏盲/癫痫
- 脑干：交叉性瘫痪（同侧脑神经+对侧肢体）
- 小脑：蚓部→躯干共济失调；半球→同侧肢体共济失调
- 脊髓：横贯性/半切综合征/部分性
- 周围神经：支配区运动/感觉/自主神经障碍
- 神经肌肉接头：骨骼肌无力，病态疲劳
- 肌肉：双侧对称肌无力，肌痛/萎缩/假性肥大

### 3.2 定性诊断
| 性质 | 发病特点 |
|-----|---------|
| 血管性 | 急骤起病，中老年，有危险因素 |
| 感染性 | 急性/亚急性，伴发热/白细胞高 |
| 变性 | 缓慢隐匿，进行性加重 |
| 肿瘤性 | 缓慢进行性加重，伴颅高压 |
| 脱髓鞘/免疫性 | 急性/亚急性，缓解复发 |
| 遗传/先天 | 慢性进行性，儿童/青年，家族史 |

### 3.3 临床思维核心原则
- **一元论原则**：尽量用一个病变和一种疾病解释全部症状
- 优先排除危害最大疾病
- 可靠性排序：体征 > 症状；运动系统体征 > 感觉系统体征

## 四、神经心理与功能评估

### 4.1 执行功能评估
- **WCST**：记录正确/错误次数、持续/非持续错误
- **Stroop试验**：测选择性抑制/冲动控制，记录错误和反应时间
- **词语流畅性**：限时60秒，记录正确和重复数
- **数字广度**：正序→短时记忆；倒序→工作记忆

### 4.2 记忆评估（RAVLT）
步骤：词表A读5遍即刻回忆→干扰词表B→短时延迟回忆→30分钟后长时延迟回忆→再认

### 4.3 NPI评估（痴呆精神行为症状）
询问知情者，评估三维度：
- 频率（1-4分）
- 严重程度（1-3分）
- 照料者苦恼程度（0-5分）

### 4.4 HAMD/HAMA评估
- **HAMD**（17项）：>7轻度，>17中度，>24重度
- **HAMA**（14项）：>29严重，>21明显，>14肯定，>7可能，≤7无焦虑

### 4.5 ADL/PSQI评估
- **ADL**：≥16分或IADL≥10分提示AD风险
- **PSQI**：总分0-21分，越高睡眠质量越差

## 五、睡眠障碍分类

当患者主诉睡眠问题时，按以下7大类鉴别：
1. **失眠障碍**：有睡眠机会仍入睡/维持困难
2. **睡眠相关呼吸障碍**：阻塞性/中枢性睡眠呼吸暂停
3. **中枢性过度嗜睡**：发作性睡病、特发性过度睡眠
4. **昼夜节律失调**：睡眠作息节律紊乱
5. **异态睡眠**：夜惊、睡行症、梦魇、REM睡眠行为障碍
6. **睡眠相关运动障碍**：不宁腿综合征、周期性肢体运动
7. **其他睡眠障碍**

# 神经心理与功能量表详细评分标准

## RAVLT详细流程
1. 读词表A（15词）5遍，每次立即复述（即刻回忆）
2. 读词表B（干扰），然后回忆词表A（短时延迟自由回忆）
3. 间隔30分钟后，再次回忆词表A（长时延迟自由回忆）
4. 读50个词（含A、B及新词），判断哪些是词表A的词（长时延迟再认）

## NPI评分细则
### 频率评分（1-4分）
- 1=偶尔（每周<1次）
- 2=经常（每周约1次）
- 3=频繁（每周数次非每天）
- 4=十分频繁（每天≥1次）

### 严重程度评分（1-3分）
- 1=轻度（可觉察不明显）
- 2=中度（明显不突出）
- 3=重度（非常突出）

### 照料者苦恼程度（0-5分）
- 0=不苦恼
- 1=极轻度（无须措施）
- 2=轻度（易应对）
- 3=中度（难自行应对）
- 4=重度（难应对）
- 5=极度（无法应对）

## HAMD因子结构（7类）
1. 焦虑/躯体化
2. 体重
3. 认知障碍
4. 日夜变化
5. 阻滞
6. 睡眠障碍
7. 绝望感

## HAMA因子结构（2类）
### 躯体焦虑（7项）
肌肉、感觉、心血管、呼吸、胃肠、生殖泌尿、自主神经系统症状

### 精神焦虑（7项）
焦虑心境、紧张、害怕、失眠、认知功能、抑郁心境、会谈时行为表现

注意：HAMA除第14项需结合观察外，其余均根据患者口述评分

## ADL量表结构
- 共20项
- 前8项：基础性ADL（BADL）
- 后12项：工具性ADL（IADL）
- 评分（4级）：1=自己完全可以做；2=有些困难尚能完成；3=需要帮助；4=根本没法做

## PSQI结构
- 19个自评+5个他评
- 剔除第19项和5个他评后，剩余18个自评问题包含7个因子：
  1. 主观睡眠质量
  2. 入睡时间
  3. 睡眠时间
  4. 睡眠效率
  5. 睡眠障碍
  6. 睡眠药物
  7. 日间功能障碍
- 按0-3分四级评分，总分0-21分

## 睡眠障碍分类详细疾病列表
### 1. 失眠障碍
分短期、慢性、其他

### 2. 睡眠相关呼吸障碍(SRBD)
- 阻塞性睡眠呼吸暂停综合征（最常见）
- 中枢性睡眠呼吸暂停综合征
- 睡眠相关低通气
- 睡眠相关低氧血症

### 3. 中枢性过度嗜睡
- I型/II型发作性睡病
- 特发性过度睡眠
- 克莱恩-莱文(Kleine-Levin)综合征

### 4. 昼夜节律失调性睡眠-觉醒障碍(CRSWDs)

### 5. 异态睡眠
- 夜惊、睡行症、梦魇障碍
- 遗尿
- 快速眼动睡眠行为障碍

### 6. 睡眠相关运动障碍
- 不宁腿综合征
- 周期性肢体运动障碍
- 睡眠相关腿部痉挛
- 磨牙
- 节律性运动障碍
- 入睡期脊髓固有肌阵挛

# 神经系统体格检查操作详细规范

## 沟通技巧
### 态度与语言
- 耐心、含蓄、共情
- 语言通俗避免信息差
- 保护隐私

### 特殊患者应对
- 羞涩/情绪低落者：多鼓励
- 喋喋不休者：及时转换话题
- 隐瞒者：细心追问
- 偏执/恐惧者：言语谨慎

### 非语词信息观察
通过以下判断性格/情绪/人格状态：
- 语调、神态、眼神
- 面部表情
- 自主神经反应（苍白/潮红/多汗）
- 不自主运动

## 音叉试验详细操作
### 前提条件
- 频率128Hz的音叉
- 安静的检查环境
- 排除外耳道耵聍栓塞等物理阻塞

### 不适用情况
- 完全失聪无法感知任何振动的患者

### Rinne试验步骤
1. 敲击音叉使其振动
2. 将振动音叉柄置于受试者耳后乳突部（测骨传导）
3. 嘱患者听不到声音时示意
4. 迅速将音叉移至该侧耳旁约1cm处（测气传导）
5. 记录两种传导方式听到声音的时间
6. 再查另一侧

### Weber试验步骤
1. 敲击音叉使其振动
2. 将音叉柄置于患者额顶正中
3. 询问患者哪侧听到的声音更响

## 肌张力检查详细操作
### 前提条件
- 患者肌肉尽量放松
- 检查者通过触摸和被动屈伸肢体感知阻力

### 排除干扰
- 需排除患者因紧张、寒冷或疼痛导致的非病理性肌肉抵抗

### 检查方法
1. 触摸感受肌肉硬度
2. 被动屈伸肢体感知阻力
3. 注意阻力变化模式

### 痉挛性肌张力增高特征
- 上肢屈肌和下肢伸肌张力增高明显
- 被动运动开始时阻力大，结束时变小
- 称为"折刀样肌张力增高"

### 强直性肌张力增高特征
- 伸肌与屈肌张力均增高
- 向各方向被动运动时阻力均匀
- 不伴震颤：铅管样肌张力增高
- 伴震颤：齿轮样肌张力增高

## 轻瘫检查详细操作
### 适用条件
- 患者能够理解指令并配合保持特定姿势
- 不适用于完全瘫痪（0-1级）患者
- 不适用于意识不清无法配合者

### 上肢平伸试验
- 体位：坐位或立位
- 指令：双上肢平举，掌心向上，闭眼
- 阳性表现：轻瘫侧上肢逐渐下垂和旋前（掌心向内）

### Barre分指试验
- 指令：相对分开双手五指并伸直
- 阳性表现：轻瘫侧手指逐渐并拢屈曲

### 小指征
- 体位：双上肢平举，手心向下
- 阳性表现：轻瘫侧小指常轻度外展

### 外旋征
- 体位：仰卧位双腿伸直
- 阳性表现：轻瘫侧下肢常呈外旋位

### 下肢轻瘫试验
- 体位：俯卧位
- 指令：双膝关节均屈曲成直角
- 阳性表现：轻瘫侧小腿逐渐下落

### 下肢下垂试验
- 体位：仰卧位
- 指令：双下肢膝、髋关节均屈曲成直角
- 阳性表现：轻瘫侧下肢逐渐下落

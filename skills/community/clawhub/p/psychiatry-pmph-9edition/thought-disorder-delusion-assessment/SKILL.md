# 思维形式障碍与妄想评估

## 使用时机

当患者出现以下情况时应用此技能：
- 言语表达、思维联想速度或逻辑结构出现异常
- 表现出坚信不疑但缺乏客观现实基础的病态信念

## 思维形式障碍评估流程

### 1. 评估联想速度/数量

| 障碍类型 | 核心特征 | 常见疾病 |
|---------|---------|---------|
| 思维奔逸 | 速度加快、数量增多、语速快语量多、随境转移、音联/意联 | 躁狂发作 |
| 思维迟缓 | 速度减慢、数量减少、语量少/慢/低、反应迟缓 | 抑郁障碍 |
| 思维贫乏 | 联想概念/词汇贫乏、脑子空空、寡言少语 | 精神分裂症、痴呆 |

### 2. 评估连贯性

按严重程度递增判断：
1. **思维散漫**：联想松弛、缺乏主题、东拉西扯、不切题
2. **思维破裂**：句子结构完整，但各句互不相关
3. **语词杂拌**：言语支离破碎，句子结构不完整，字词堆积
4. **思维不连贯**：与语词杂拌类似，但在**意识障碍**背景下出现

### 3. 评估自主性与逻辑

- **思维中断**：无意识障碍下言语突然停顿，后转换主题
- **思维被夺/插入**：感到思想被外力抽走/塞入
- **强制性思维**：脑内涌现大量不属于自己的联想，完全不受意愿支配
- **逻辑倒错性思维**：推理缺乏前提或因果倒置
- **象征性思维**：以无关具体概念代替抽象概念，不经解释无法理解
- **病理性赘述**：联想迂回曲折，枝节过多，最终能回答但无法简明

### 4. 核心鉴别：强迫思维 vs 强制性思维

| 维度 | 强迫思维 | 强制性思维 |
|-----|---------|-----------|
| 归属 | 自己的思想 | 外力强加的、不属于自己的思想 |
| 内容 | 同一内容反复持续出现 | 内容变化多端，突然出没 |
| 体验 | 明知不合理但无法摆脱，伴痛苦 | 不受意志支配 |
| 常见疾病 | 强迫症 | 精神分裂症 |

## 妄想评估流程

### 1. 确认妄想核心特征（必须同时具备）

- [ ] 内容与事实不符，缺乏客观现实基础，但患者坚信不疑
- [ ] 内容通常涉及患者本人，与个人有利害关系
- [ ] 具有个体独特性，非集体信念
- [ ] 与文化背景和经历有关，有时代色彩

**注意**：需排除文化/宗教背景下的集体信念；需与幻想（超现实遐想、有目的性、易纠正）严格区分。

### 2. 按起源分类

- **原发性妄想**：无发生基础，内容不可理解，不能用既往经历解释 → 精神分裂症典型症状
- **继发性妄想**：发生在其他病理心理基础上（如抑郁致自卑妄想）→ 可见于多种精神障碍

### 3. 按结构分类

- **系统性妄想**：内容前后联系、结构严密、形成缓慢、与现实有一定联系
- **非系统性妄想**：片段零散、内容不固定、产生快、明显脱离现实

### 4. 按内容分类（常见类型）

- **关系妄想**：认为周围无关事物均与自己有关
- **被害妄想**：坚信被某些人/组织迫害 → 评估拒食、逃跑、自伤、伤人风险

## 输出要求

1. 明确思维形式障碍的具体亚型
2. 区分躁狂、抑郁、精神分裂症及谵妄等不同疾病背景
3. 输出妄想的起源、结构和内容分类
4. 评估妄想对患者行为的风险

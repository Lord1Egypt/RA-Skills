# 配对数据册

**跨轮累积，只增不改。**

---

## 使用说明

| 项目 | 规定 |
|---|---|
| 谁填 | 甲方（配方方） |
| 什么时候填 | 每轮数据盘点后，把本轮**新增**的配对追加到这里 |
| 填什么 | 一组完整的「输入变量 → 目标量 → 约束量」记录 |
| 颗粒度 | **只填相对基准的偏差，不填绝对值**；成本以结构比例表示 |
| 失败案例 | **必须记**。失败标出边界在哪，比成功值钱 |
| 修改 | 只增不改。填错了追加一条更正行，不回头改旧行 |

**一条配对 = 一次真实的实验或生产记录。** 没有实测目标量的，不是配对，是猜想。

---

## 分级标准

| 等级 | 含什么 | 用法 |
|---|---|---|
| **A** | 输入变量 + 目标量实测 + 约束量实绩，三项齐全 | 可直接用于提假设 |
| **B** | 缺一项（通常是当时的成本实绩没记） | 参考用，不进拟合 |
| **C** | 只有输入，无实测或无成本 | 只作背景，不作依据 |

**A 级组数决定本轮走哪条路**：≥6 组直接出假设；<6 组先做实验设计补点。

## 三条纪律

1. **不填绝对值。** 绝对值一旦写进来，这份文件就不能对外传了，而它的价值恰恰在于能长期复用。
2. **失败案例不许删。** 删掉一次失败，等于删掉一段边界。
3. **一条一行。** 把两次实验写在一行里，等于两次都作废。

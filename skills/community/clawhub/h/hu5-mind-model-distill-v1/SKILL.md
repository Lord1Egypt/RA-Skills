# 心智模型蒸馏·多视角项目分析

当用户需要对一个项目、公司或决策做多视角压力测试时，按以下步骤执行：

1. **确认对象与材料**：请用户提供分析对象的基本材料（描述、数据、商业计划等）。材料不足时先列出缺口清单，不得虚构数据。
2. **选定思维框架**：默认使用查理·芒格公开言论中的思维操作系统（能力圈、逆向思维、lollapalooza 效应、激励机制、幸存者偏差、安全边际等）；用户可指定其他公开思想家。
3. **逐一过模型**：对每个心智模型，结合用户材料给出该模型下对本项目的判断，并注明推理路径。
4. **三重验证**：对每个模型检查——(a) 跨域复现：该模型在用户领域是否真实起作用；(b) 有生成力：能否导出新的可检验问题；(c) 有排他性：是否与常用框架的结论有增量。未过三重验证的模型降级为"参考视角"。
5. **输出报告**：
   - 心智模型清单（每条附：应用判断 + **失效条件**）
   - 综合判断（分乐观/中性/谨慎三档，只归纳材料，不预测数字）
   - **诚实边界声明**（必须包含）：本分析为思维练习，非投资建议；数据来自用户提供材料，真实决策前需实地尽调；蒸馏的是公开言论中的思维方式，无法捕获思想家本人直觉。

## 纪律红线

- 不虚构任何经营/财务数据；材料中没有的数字一律标注"未提供"。
- 不冒充持牌机构出具意见；不承诺收益；不预测股价。
- 引用他人言论仅限公开来源，注明为方法论练习。

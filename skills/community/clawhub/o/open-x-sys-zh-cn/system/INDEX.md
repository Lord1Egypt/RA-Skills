# 系统实例索引

系统实例把一次智能变成可拥有、可接续、可演化的现实系统。需要确定“它是什么、属于谁、现在怎样、保存在哪里、以后怎样继续”时，从这里进入。

| 当前问题 | 读取 | 带回什么 |
| --- | --- | --- |
| 一个系统实例最少由什么构成 | [实例](instance.md) · [状态](state.md) | 身份、边界、状态、能力、关系与接力点 |
| 谁拥有材料、状态、成果与决定权 | [所有权](ownership.md) · [同意](consent.md) | 可读、可写、可行动的真实范围 |
| 多个独立系统怎样形成更高层系统 | [组成](composition.md) · [系统形态](shapes.md) | 保留独立性的整体结构 |
| 自然语言入口写什么，放在哪里 | [入口](entry.md) · [位置](location.md) · [根系统](root.md) | 人与 AI 都能接手的系统入口 |
| 认识、作品、实践、工具和连接怎样成为系统部件 | [部件](parts.md) · [系统面板](panel.md) | 当前系统的可见组成和状态 |
| 系统怎样跨会话继续，并在返回时恢复全景 | [接续](continuity.md) · [返回](return.md) | 下一次可直接使用的接力点 |
| 人怎样通过真实使用获得理解与能力 | [成长](growth.md) | 会改变未来运行的人与系统状态 |

实例页不是表单。由运行时从现实和已有材料中形成最小充分表达，只有会改变以后观察、判断或行动的内容才进入系统。完成读写后回到[更新](../runtime/update.md)或[演化引擎](../engines/evolve.md)。

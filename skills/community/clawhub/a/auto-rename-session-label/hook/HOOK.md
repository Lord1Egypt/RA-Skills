# Auto Rename Session Label

When a `message:received` event fires, this hook gives a session that has no
`label` yet a short, human-readable title — generated by the **same model the
session is currently using** — so your session list is readable instead of full
of untitled chats. On any failure it silently falls back to truncating the first
user message, so a label is always written.

It is fully portable: there are **no hardcoded paths or personal data**. All
locations (OpenClaw home, agent id, sessions file, config, and the OpenClaw
`dist` directory) are resolved at runtime from the environment.

## How it works

1. Listens for `message:received`; reads the matching `sessionKey` entry from
   that agent's `sessions.json`.
2. If `label` is already set and non-empty → **skip**.
3. Gets the first user message: prefers `event.context.content`, else reads the
   session `.jsonl` transcript.
4. **Generates a title with the current session model** (reads
   `modelOverride`/`model` + `providerOverride`/`modelProvider`, then resolves
   the real provider id from `models.providers`). It reuses OpenClaw's internal
   `completeSimple` chain for a single one-shot completion.
   - The instruction to the model is English; the title language follows the
     user's own words automatically.
   - The instruction is inlined into the user message (some upstream proxies
     reject a separate system message).
   - 15s timeout. Title is cleaned (quotes/newlines stripped) and hard-capped at
     30 characters.
5. **Fallback**: no model / parse failure / timeout / upstream error → use the
   first user message truncated to 50 characters + `…`.
6. Re-reads `sessions.json` immediately before writing to avoid clobbering
   concurrent updates. Runs silently; never replies.

## Path & agent resolution (portable)

- OpenClaw home: `OPENCLAW_HOME` env, else `~/.openclaw`.
- Agent id: `event.context.agentId` → parsed from `sessionKey`
  (`agent:<id>:…`) → `OPENCLAW_AGENT_ID` env → default `main`.
- OpenClaw `dist`: probed from the running CLI/node entry, `npm_config_prefix`,
  and common global install roots; verified by the presence of the hashed
  `stream-*.js` bundle.

## OpenClaw internals reused

- `resolveModelAsync` — resolve provider/model → runtime model object
- `prepareModelForSimpleCompletion` — prepare a one-shot completion model
- `getRuntimeAuthForModel` / `requireApiKey` / `applyPreparedRuntimeAuthToModel` — runtime auth
- `completeSimple` — one-shot completion (no agent, no tools, no workspace injection)

> These are internal dist modules whose filenames carry a content hash. The
> handler locates them by globbing and matching the exported symbol name, so it
> survives version bumps. If a symbol ever moves or changes signature, the hook
> automatically takes the fallback branch instead of crashing.

## Notes

- This is an **operator-managed side effect** hook (it writes a session field).
  It does not modify prompts, tools, or message flow.
- `maxTokens` for the title call is intentionally generous (1024). Some proxied
  models emit no visible text and stop at `length` when this value is too small,
  which would otherwise force the truncation fallback every time.

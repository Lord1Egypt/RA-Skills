## Description:

UI/UX Pro Max provides searchable UI/UX design guidance for web and mobile applications, including styles, palettes, font pairings, chart recommendations, accessibility rules, and stack-specific implementation tips.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, designers, and agents use this skill to plan, build, review, and improve web or mobile interfaces with design-system recommendations, accessibility checks, responsive layout guidance, typography, color, chart, and stack-specific UI patterns.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Optional setup commands include package-manager installs, including a sudo apt example.

Mitigation: Review installation commands before running them and use the operating-system-specific command that matches the execution environment.

Risk: The persistence workflow can create or update design-system files in the current project.

Mitigation: Use --persist only when project-level design-system files should be written or changed.

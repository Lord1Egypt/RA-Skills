# 施工验收标准

## 一、验收基本流程

> **核心原则**：分阶段验收，未完成前道工序验收，严禁进入下一道工序

**四大验收节点**：
1. 水电隐蔽工程验收（开工后15-25天）
2. 泥瓦工程验收
3. 油漆工程验收
4. 竣工综合验收

---

## 二、水电验收标准

### 2.1 水路验收

#### 打压测试（必做！）

| 测试项目 | 标准值 | 说明 |
|---------|-------|------|
| 冷水管试压 | ≥0.8MPa | 稳压30分钟 |
| 热水管试压 | ≥1.2MPa | 稳压20分钟 |
| 压降标准 | ≤0.02MPa | 冷水管标准 |
| 压降标准 | ≤0.03MPa | 热水管标准 |

**自检动作**：
- 关闭总阀/总闸，打开所有末端点位
- 目视检查接头、弯头、过墙处有无洇水、锈迹
- 全程盯表，记录初始与30分钟后压力值

#### 排水测试

| 测试项目 | 标准 | 说明 |
|---------|------|------|
| 排水速度 | 5升水10秒内排空 | 地漏通畅 |
| 坡度 | 地漏周边50cm内坡度≥3% | 向地漏倾斜 |
| 防臭 | 必须安装防臭芯 | 后期反味难除 |

#### 其他检查点

| 检查项 | 标准 |
|-------|------|
| 冷热水管间距 | ≥15cm |
| 水管走向 | 走顶不走地 |
| 左热右冷 | 正确接法 |
| PPR热熔 | 无歪斜、无气泡 |

### 2.2 电路验收

#### 安全检测

| 测试项目 | 标准 | 说明 |
|---------|------|------|
| 绝缘电阻 | ≥0.5MΩ | 使用500V兆欧表 |
| 接地连续性 | ≤4Ω | 金属线管/箱体接地 |
| 零火线 | 左零右火上接地 | 用相位检测仪测试 |
| 强弱电间距 | ≥300mm（平行） | 交叉处加金属屏蔽套管 |

#### 规格配置

| 用途 | 电线规格 | 说明 |
|------|---------|------|
| 照明线路 | BV1.5mm² | 普通照明 |
| 普通插座 | BV2.5mm² | 日常用电 |
| 大功率电器 | BV4mm² | 空调、热水器 |
| 厨房大功率 | BV6mm² | 烤箱等 |

#### 验收动作

| 动作 | 工具 | 检查内容 |
|------|------|---------|
| 通断测试 | 万用表蜂鸣档 | 逐回路测试 |
| 标高检查 | 水平尺+卷尺 | 同一房间误差≤2mm |
| 拍照留存 | 手机 | 全屋管线走向图 |

### 2.3 智能家居预埋检查

| 检查项 | 标准 |
|-------|------|
| 智能主机插座 | 客厅预留 |
| 窗帘电机线 | 卧室床头柜位置 |
| 网线布设 | 每个房间通网线 |
| 弱电箱 | 网线通断测试，8芯全通 |

## 三、防水验收标准

### 3.1 闭水试验（核心！）

| 测试项目 | 标准 |
|---------|------|
| 蓄水深度 | ≥30mm |
| 试验时间 | ≥48小时 |
| 检查对象 | 楼下天花板对应区域 |
| 门口处理 | 必须做挡水坎 |

**验收动作**：
1. 封堵地漏口（用专用橡胶塞或水泥）
2. 注水后标记水位线
3. 每12小时检查一次水位和楼下情况
4. 48小时后去楼下检查：
   - 烟道根部
   - 管根周围
   - 墙角
   - 是否有水渍、潮湿、霉斑

### 3.2 防水高度标准

| 区域 | 墙面防水高度 | 说明 |
|------|-------------|------|
| 淋浴区 | ≥1.8m（建议到顶） | 重点区域 |
| 洗手台区域 | ≥1.2m | 有水槽处 |
| 其他干区 | ≥0.3m | 最低标准 |
| 厨房 | ≥0.3m | 有水槽处≥1.2m |
| 阳台 | ≥0.3m | 开放阳台必做 |

### 3.3 防水施工质量

| 检查项 | 标准 |
|-------|------|
| 涂刷遍数 | 2-3遍，横竖交叉 |
| 表面质量 | 无砂眼、裂缝 |
| 阴阳角 | 圆弧处理（R角） |
| 管道根部 | 加强处理 |
| 手感测试 | 不应有颗粒感或粉化 |

### 3.4 门槛石防水

| 检查项 | 标准 |
|-------|------|
| 嵌入墙体 | ≥20mm |
| 底部防水 | 双道防水涂刷 |
| 上翻高度 | ≥300mm |

## 四、泥瓦工程验收

### 4.1 瓷砖铺贴验收

#### 空鼓检测（必检！）

| 位置 | 空鼓标准 | 说明 |
|------|---------|------|
| 单块瓷砖中心 | 严禁空鼓 | 重点检查 |
| 边角空鼓 | 面积≤15% | 可接受 |
| 墙面整体空鼓率 | ≤5% | 同一墙面 |
| 地面空鼓率 | ≤3% | 基本不允许 |

**检测方法**：用空鼓锤逐块轻敲，声音发闷为实，清脆为空鼓

#### 平整度检测

| 检查项 | 标准 | 工具 |
|-------|------|------|
| 2m靠尺检测 | 缝隙≤3mm | 靠尺+塞尺 |
| 相邻高低差 | ≤0.5mm | 靠尺 |
| 阴阳角方正度 | ≤2mm | 直角尺 |

#### 其他检查点

| 检查项 | 标准 |
|-------|------|
| 瓷砖留缝 | 墙砖≥1.5mm，地砖≥2mm |
| 美缝质量 | 饱满、无塌陷、无毛刺 |
| 十字缝对齐 | 缝隙均匀一致 |
| 地漏坡度 | "回"字形坡度 |

### 4.2 地面找平验收

| 检查项 | 标准 |
|-------|------|
| 平整度 | 2m靠尺检测，缝隙≤3mm |
| 表面质量 | 无起砂、无开裂、无空鼓 |
| 强度测试 | 用脚踩不松动 |

### 4.3 木作与吊顶验收

| 检查项 | 标准 |
|-------|------|
| 石膏板接缝 | 预留3-5mm倒V型槽 |
| 主龙骨间距 | ≤800mm |
| 副龙骨间距 | ≤300mm |
| 柜体背板厚度 | ≥9mm |
| 铰链开孔误差 | ≤1mm |
| 木基层防火 | 涂料涂刷≥2遍 |

**自检动作**：
- 开合柜门10次以上，确认无异响、无下垂
- 用卷尺抽测龙骨间距（每10㎡不少于3处）

## 五、油漆工程验收

### 5.1 腻子层验收

| 检查项 | 标准 |
|-------|------|
| 平整度 | 2m靠尺检测，缝隙≤2mm |
| 表面质量 | 无起砂、无开裂、无空鼓 |
| 粘结力 | 用手摸不掉粉 |
| 打磨质量 | 手电45°斜照无明显砂痕 |

### 5.2 乳胶漆验收

| 检查项 | 标准 | 说明 |
|-------|------|------|
| 涂刷遍数 | 底漆1遍+面漆2遍 | 每遍干透再施工 |
| 间隔时间 | ≥4小时 | 每遍之间 |
| 成膜厚度 | ≥0.12mm | 测厚仪实测 |
| 色差 | 同批次无明显色差 | ΔE≤1.5 |
| 表面质量 | 无流坠、透底、起皮、裂纹、刷痕 | 目视检查 |
| 阴阳角顺直度 | ≤2mm | 拉线或激光仪测量 |

**自检动作**：
- 关灯用射灯45°斜照墙面，观察反光均匀性
- 在自然光与灯光下分别查看
- 手掌轻抚阴阳角，确认无毛刺

### 5.3 壁纸验收

| 检查项 | 标准 |
|-------|------|
| 图案对齐 | 无错位 |
| 接缝处理 | 不明显 |
| 表面质量 | 无起泡、翘边 |
| 收口处理 | 平滑无腻子堆积 |

## 十、验收注意事项

### 10.1 时间选择
- 选择白天自然光线充足时段
- 光线不足时用手电筒侧照墙面

### 10.2 在场人员
- 施工方、业主、设计师三方在场
- 发现问题当场记录并签字确认

### 10.3 签字原则
- **所有整改完成后才签字**
- 不要提前签字
- 保留验收记录和照片作为维权依据

### 10.4 尾款管理
- 竣工验收合格后再支付尾款
- 留5%-10%质保金
- 入住3-6个月无问题再付尾款

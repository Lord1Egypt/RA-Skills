## Description:

Generates Axure-compatible HTML and JavaScript prototype code that can be loaded in inline frames for interactive product mockups.

This skill is ready for commercial/non-commercial use.

## Use Case:

Product managers, designers, and developers use this skill to turn brief UI requirements into Axure-ready interactive prototypes for dashboards, admin systems, charts, forms, lists, and ecommerce flows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated prototypes are active HTML/JavaScript and may behave unexpectedly if modified or pasted without review.

Mitigation: Review generated code before pasting it into Axure and check for unexpected network requests or remote scripts when extending the output.

Risk: Prototype forms or demos could collect sensitive information if users treat them like production systems.

Mitigation: Avoid entering real credentials, personal data, or confidential business data into generated prototypes.

## Description:

Explains code for beginners by using everyday clothing and outfit analogies when the user asks for a dressing-themed explanation or mentions Coding as Dressing.

This skill is ready for commercial/non-commercial use.

### License/Terms of Use:


## Use Case:

Developers, learners, and educators use this skill to explain selected code in simple Chinese through everyday clothing analogies. It is aimed at beginners who need code structure, repeated logic, missing error handling, or dependencies described in plain language.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate on broad Chinese requests for simple code explanations even when the user did not explicitly ask for a clothing analogy.

Mitigation: Use it when clothing, outfit, wardrobe, dressing, or Coding as Dressing framing is requested; choose a general code-explanation skill when the analogy would be distracting.

Risk: Analogy-based explanations can simplify code behavior and omit technical edge cases.

Mitigation: Treat the explanation as learning guidance and verify important behavior against the code before changing production systems.

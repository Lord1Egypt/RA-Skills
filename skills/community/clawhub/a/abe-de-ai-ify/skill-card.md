## Description:

Remove AI-generated jargon and restore human voice to text.

This skill is ready for commercial/non-commercial use.

## Publisher:

[marjoriebroad](https://clawhub.ai/user/marjoriebroad)

### License/Terms of Use:

MIT-0

## Use Case:

Writers, editors, marketers, and developers use this skill to rewrite a selected file so it sounds more natural, removes common AI-generated phrasing, and highlights places that need more specific examples.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Selected document text is sent to SkillBoss API Hub for rewriting.

Mitigation: Use the skill only with files suitable for that service, and avoid confidential drafts, proprietary documents, credentials, or regulated data unless the service's privacy and retention practices are acceptable.

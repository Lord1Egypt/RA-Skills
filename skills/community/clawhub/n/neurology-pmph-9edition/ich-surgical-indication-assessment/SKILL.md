# 脑出血外科手术适应证与时机评估

本技能用于指导中重度脑出血患者的外科手术决策，包括判断是否符合手术指征、确定最佳手术时机以及推荐合适的手术方式。

## 前置条件与禁忌约束

在执行评估前，必须确认以下条件：
1. **前置条件**：已通过影像学（CT/MRI）明确出血量及部位；已完成患者全身状况评估。
2. **绝对禁忌**：若患者生命体征极不稳定或经评估无手术价值（如脑干出血量大、深度昏迷且瞳孔散大固定等），则**不宜手术**，直接终止评估并建议保守或姑息治疗。

## 核心决策工作流

### 第一步：评估手术适应证
检查患者是否满足以下**任意一项**条件，若满足则具备手术指征：
- **基底节区（壳核）出血**：血肿量 ≥ 30ml。
- **丘脑出血**：血肿量 ≥ 15ml。
- **小脑出血**：血肿量 ≥ 10ml，或血肿直径 ≥ 3cm。
- **并发症**：合并梗阻性脑积水或脑疝。
- **脑室出血**：重症脑室出血（如铸型）。
- **病因**：合并需手术处理的血管病变（如脑血管畸形、动脉瘤等）。

### 第二步：确定手术时机
- **黄金窗口**：一般宜在发病后早期（**6～24小时内**）进行外科干预。
- **紧急干预**：若已出现脑疝或急性梗阻性脑积水，需立即急诊手术。

### 第三步：选择手术方式
根据出血部位、血肿量及并发症，推荐以下术式之一：
1. **开颅血肿清除术**：适用于血肿量大、位置较浅、需彻底清除血肿并止血的患者。
2. **去骨瓣减压术**：适用于颅内压极高、脑组织肿胀严重，需缓解颅内高压的患者。
3. **钻孔抽吸术（微创）**：适用于基底节区或丘脑中等量出血，患者身体条件较差无法耐受开颅手术者。
4. **脑室穿刺引流术**：专门针对脑室出血铸型或合并梗阻性脑积水的患者。

### 第四步：综合决策与输出
结合患者的年龄、意识状态、出血部位、病因及全身状况，输出最终决策：
- **结论**：是否符合手术指征（是/否/边缘）。
- **推荐时机**：急诊 / 早期（6-24h） / 择期 / 不建议手术。
- **推荐术式**：具体手术名称及理由。
- **风险提示**：手术相关风险及术后注意事项。

# 脑出血手术方式与解剖阈值详细参考

## 各部位出血手术阈值详解
- **壳核出血**：最常见部位。≥30ml 易引起明显占位效应。若向内压迫内囊导致严重偏瘫，手术指征可适当放宽。
- **丘脑出血**：位置深，手术易损伤周围结构。≥15ml 且向侧脑室破溃或引起颅内压增高时考虑手术。
- **小脑出血**：≥10ml 或直径 ≥3cm 极易压迫脑干导致呼吸骤停，手术指征应积极，首选血肿清除。
- **脑叶出血**：若血肿量大（通常>30ml）且靠近皮层，手术清除效果较好。

## 手术方式选择指南

### 1. 开颅血肿清除术 (Craniotomy for Hematoma Evacuation)
- **优势**：直视下彻底清除血肿，止血确切，可同时处理血管病变。
- **适用**：血肿量大、脑疝形成、怀疑血管畸形/动脉瘤破裂、脑叶出血。

### 2. 去骨瓣减压术 (Decompressive Craniectomy)
- **优势**：有效降低颅内压，为脑组织肿胀提供空间。
- **适用**：术中脑组织肿胀严重、术前已发生脑疝、大面积脑出血伴严重脑水肿。

### 3. 钻孔抽吸术/微创穿刺引流 (Burr Hole Aspiration / Minimally Invasive Drainage)
- **优势**：创伤小，手术时间短，对全身条件差的患者耐受性好。
- **适用**：基底节/丘脑中等量出血、高龄或合并严重基础疾病无法耐受全麻开颅者。常配合尿激酶液化引流。

### 4. 脑室穿刺外引流术 (External Ventricular Drainage, EVD)
- **优势**：迅速缓解梗阻性脑积水，降低颅内压，可引流血性脑脊液。
- **适用**：原发性或继发性重症脑室出血（脑室铸型）、合并急性梗阻性脑积水。可双侧穿刺或配合腰大池引流。

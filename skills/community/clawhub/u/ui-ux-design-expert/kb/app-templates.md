# 应用类型模板库

本库回答「做一个 XX 应用/页面该怎么搭」——按应用类型给出信息架构、布局骨架、关键页面与核心组件的起点模板。模板是起点不是终点（[TPL-1]）：先按类型取骨架 → 按 [SD-31] size class 适配平台 → 按行业主题（industry-themes kb）注入配色与气质 → 补全三态。本库不覆盖行业配色（查 industry-themes kb）与视觉细节（查各领域 kb）。

## 法则

[TPL-1] **MUST**: 模板是起点不是终点——按产品实际信息架构裁剪，生成前先确认目标平台与形态（[SD-31]），并显式声明「基于 XX 模板裁剪」。
- 违反后果: 模板原样交付=千篇一律的「模板脸」，且信息架构与实际业务错位。
- 溯源: [模型经验]；Jakobs-law 惯例传递。

[TPL-2] **MUST**: 每个模板落地必须补全加载/空/错误三态（[VP-20]/[IM-5]）——模板条目未列状态不等于可省略；骨架屏镜像真实结构（[VP-29]），显示延迟 200~300ms 防闪现（[IM-13]）。
- 违反后果: 真实环境白屏/裸报错，弱网体验崩塌。
- 溯源: [VP-20]/[IM-5]/[VP-29]/[IM-13]。

[TPL-3] **MUST**: 导航模式按平台惯例选型（[VP-14]/[LAW-8]）——iOS 底部 Tab、Android 顶部/侧导航、桌面端侧栏、Web 顶部导航；禁跨平台混用（手机底部 Tab 直接搬桌面）。
- 违反后果: 平台违和感+肌肉记忆失效。
- 溯源: [VP-14]/[LAW-8]。

[TPL-4] **MUST**: 吸底/悬浮操作栏必须避开 home indicator 与系统手势区，内容置于安全区（[SD-32]）；sticky/fixed 栏须不透明或半透明+blur 防滚动穿透。
- 违反后果: 操作被手势条遮挡、误触返回；滚动文字穿透栏底不可读。
- 溯源: [SD-32]。

[TPL-5] **MUST**: 交互命中区 ≥44×44pt（[SD-33]）、Web ≥24×24 CSS px（[VP-5]）——模板示意图中的紧凑排版不得牺牲命中区；密集操作类模板命中区不得相互粘连。
- 违反后果: 移动端误触率飙升，胖手指错误。
- 溯源: [SD-33]/[VP-5]。

[TPL-6] **NEVER**: 模板不得弱化「每屏恰好一个主操作」（[LC-4]）——工具栏多按钮时按视觉重量分档（实心/描边/文本），危险操作隔离。
- 违反后果: 全平级按钮=没有主操作，转化率下降。
- 溯源: [LC-4]。

[TPL-7] **MUST**: 数据密集模板（表格/看板/仪表盘）必须支持文本放大 ≥200%（[SD-34]）、键盘可达（表单控件原生语义 [UA-2]、焦点环可见 [UA-1]）；表格场景参照 APG table/treegrid 契约（usability-accessibility kb APG 模式速查表）。
- 违反后果: 低视力用户与键盘用户被数据模板直接排除，无障碍审计失败。
- 溯源: [SD-34]/[UA-2]/[UA-1]。

[TPL-8] **MUST**: 列表/流式模板必须处理滚动位置跨页恢复（[IM-25]）与嵌套滚动收口（[IM-24]）；长列表用虚拟化并保持骨架占位尺寸一致。
- 违反后果: 返回丢位置（列表跳顶）、弹层滚动链穿透。
- 溯源: [IM-25]/[IM-24]。

[TPL-9] **MUST**: 多步流程模板（结算/注册/向导）必须有进度指示（[VP-40]）、就地校验（[VP-13]）、提交保留数据；步骤数显式可见且允许回退。
- 违反后果: 用户不知道还剩几步中途放弃；错误堆在最后一步成「错误墙」。
- 溯源: [VP-40]/[VP-13]。

[TPL-10] **NEVER**: 禁止跨形态直接套用——手机模板等比放大到桌面/TV、桌面多栏压进手表屏都是违规；形态切换按 [SD-31] size class 重排（列数/导航模式/信息密度全部重决策）。
- 违反后果: 桌面端一屏一行字距失控、TV 端 10-foot 可读性崩坏。
- 溯源: [SD-31]；[模型经验]。

## 应用类型模板库（128 模板）

每条=信息架构+布局骨架+关键页面+核心组件+状态与空态+平台适配。用户问「XX App/页面怎么做」时先匹配类型（可组合：电商 App=T01+T11+T37），再按 [TPL-1] 裁剪；行业配色与气质到 industry-themes kb 查。

## 移动应用（T01~T14）

### T01 电商购物 App
- 信息架构：底部 Tab（首页/分类/购物车/我的）+ 二级品类页 + 沉浸式 PDP
- 布局骨架：首页=搜索框+金刚区+瀑布流推荐；PDP=头图轮播+价格促销区+SKU 选择+吸底操作栏（避手势区 [TPL-4]）
- 关键页面：首页、搜索（T11）、PDP、购物车、结算（T37）、订单列表
- 核心组件：商品卡、SKU 选择器、吸底操作栏、优惠券条
- 状态与空态：加载骨架镜像瀑布流（[TPL-2]）；购物车空态给推荐流而非止于插画
- 平台适配：吸底栏避 home indicator；桌面/Web 端导航转顶部、结算单列窄容器；watchOS 不适用（[TPL-10]）

### T02 内容信息流（feed）
- 信息架构：顶部分类 Tab + 无限滚动 feed；个人中心与创作入口弱化为二级
- 布局骨架：双列瀑布流（图片主导）或单列大卡（图文均衡）；卡片=封面+标题+作者行+互动指标行
- 关键页面：feed 流、内容详情、发布页、个人主页（T12）
- 核心组件：瀑布流容器、内容卡、下拉刷新、返回顶部按钮
- 状态与空态：返回恢复滚动位置（[TPL-8]）；零结果与网络错误给重试入口（[VP-20]）
- 平台适配：移动双列→桌面三~四列（[TPL-10]）；平板可固定左侧导航；TV 用焦点行浏览

### T03 社交动态
- 信息架构：底部 Tab（动态/发现/消息/我）+ 发布为中央突出入口（FAB 或 Tab 中键）
- 布局骨架：feed=单列卡片流（头像+昵称+时间+正文+媒体九宫格+操作行：赞/评/转）；详情页评论区楼层式
- 关键页面：动态流、动态详情+评论、发布器、个人主页（T12）
- 核心组件：社交卡片、媒体九宫格（1/3/9 图布局）、发布器（字数与媒体限制提示）、关注按钮
- 状态与空态：图片加载失败占位+点击重试；发布中退出必须保留草稿
- 平台适配：移动单列→桌面居中窄列+右侧趋势/推荐栏；键盘快捷键（J/K 滚动，桌面）

### T04 IM 聊天
- 信息架构：移动端两级页（会话列表→聊天窗）；桌面端双栏（会话列表+聊天窗常驻）
- 布局骨架：聊天窗=消息流（时间分界+气泡左右分侧）+输入栏（文本+附件+表情）；会话列表=头像+名称+摘要+时间+未读角标
- 关键页面：会话列表、聊天窗、联系人/群资料、群成员管理
- 核心组件：消息气泡（含撤回/引用/复制长按菜单）、输入栏（键盘避让）、未读角标、正在输入指示
- 状态与空态：消息发送中/失败/重发三态显式（[VP-20]）；历史消息上滑分页加载+跳跃锚点
- 平台适配：移动端输入栏随键盘升降；桌面端三栏（列表+聊天+资料抽屉）；手表仅通知速回

### T05 媒体播放器
- 信息架构：音乐=底部迷你播放条（跨页常驻）→全屏 Now Playing；视频=详情页内嵌播放或全屏横屏
- 布局骨架：Now Playing=封面大图+标题/艺人+进度条（可拖拽）+播放控制组（上一首/播放/下一首）+次要操作（队列/歌词/音质）
- 关键页面：Now Playing、播放队列、歌单/专辑详情、歌词页
- 核心组件：迷你播放条（进度可见）、进度滑块（拖拽时显示时间气泡）、后台播放通知栏
- 状态与空态：音频缓冲 loading（禁假进度，[IM-14]）；播放失败给重试与来源切换
- 平台适配：移动竖屏单列；桌面侧栏（库）+主区（Now Playing）；车载简化为大按钮（[SD-33]）

### T06 地图出行
- 信息架构：全屏地图为底 + 浮层卡片承载任务（搜索目的地/路线选择/行程状态）
- 布局骨架：搜索态=顶部搜索框+底部结果卡列表（可上拉展开）；导航态=顶部转向指令条+底部剩余时间/距离卡（可折叠）
- 关键页面：地图主页、路线规划（多方案对比）、行程中导航、历史/收藏地点
- 核心组件：地图手势容器（平移/缩放/旋转与 UI 手势冲突消解）、底部抽屉（三档停靠）、定位按钮
- 状态与空态：定位权限被拒→降级为城市级默认视野+引导开启（[VP-20]）；弱网加载瓦片占位
- 平台适配：移动端浮层卡片为主；桌面端左搜索右地图双栏；车载仅导航态+语音优先（[TPL-10]）

### T07 相机/摄影
- 信息架构：取景器全屏为唯一主界面；模式横向滑动切换（照片/视频/人像/专业）
- 布局骨架：取景器=网格线+顶部状态（闪光/比例）+底部模式条+中央快门（两侧为相册与翻转）
- 关键页面：取景器、相册（T14）、滤镜/编辑页、设置
- 核心组件：快门按钮（拍照/长按录像双态）、模式切换条、缩放控件（1x/2x 按钮+捏合）
- 状态与空态：相机权限被拒=全屏引导页（不可用即明说，[VP-20]）；连拍中计数反馈
- 平台适配：移动横竖屏两版式；桌面/Web 端通常为上传编辑器而非取景器（形态不同不套用，[TPL-10]）

### T08 健康数据记录
- 信息架构：底部 Tab（今天/趋势/我的）+ 记录入口悬浮或置于「今天」顶部
- 布局骨架：今天=摘要环卡行（步数/心率/睡眠）+快捷记录按钮组；趋势=指标 Tab+周/月/年切换图表
- 关键页面：今日概览、指标趋势、手动记录表单、指标详情（单指标历史+统计）
- 核心组件：环形进度环、趋势折线图（区间底色标注正常范围）、记录快捷键（大命中区 [SD-33]）
- 状态与空态：首次使用无数据→引导首录而非空白图表（[VP-20]）；目标达成庆祝反馈克制（禁全屏弹窗）
- 平台适配：手表端=单指标 complication+快速记录（[TPL-10] 裁剪）；桌面通常只读趋势

### T09 在线课程学习
- 信息架构：课程 Tab（我的课程/发现）+ 课程详情（目录+简介）+ 学习页
- 布局骨架：学习页=视频播放器（上）+目录/简介/笔记 Tab（下，可全屏切换）；桌面=左视频右目录双栏
- 关键页面：课程详情、学习页（播放器+目录）、笔记、练习/测验、学习报告
- 核心组件：视频播放器（倍速/清晰度/字幕）、课时列表（完成态勾选）、断点续播、学习进度条（[VP-40]）
- 状态与空态：续播从上次位置+显式「从上次继续」按钮；课程加载失败保留已下载缓存可学
- 平台适配：移动竖屏上下分区→平板/桌面左右分栏（[TPL-10]）；投屏/后台播放按平台能力声明

### T10 阅读器
- 信息架构：书架（封面网格）→阅读器全屏→目录/书签抽屉
- 布局骨架：阅读区=全屏、点击中央呼出上下工具栏（上=返回/目录/设置，下=进度滑块+章节）；正文区窄栏+页边距充足
- 关键页面：书架、阅读器、目录/书签/笔记列表、阅读设置（字号/行距/翻页方式/背景主题）
- 核心组件：进度滑块（拖拽显示章节名）、阅读主题切换（纸色/米色/夜间）、选中批注菜单
- 状态与空态：阅读位置跨设备同步恢复（[IM-25] 思路）；章节加载失败给重试不白屏
- 平台适配：手机分页翻页为主→平板/桌面滚动为主（[TPL-10]）；夜间主题跟随系统（勿独立开关与系统冲突）

### T11 搜索体验
- 信息架构：入口（框/图标）→搜索页（历史+热搜+联想）→结果页（类型 Tab+筛选+列表）
- 布局骨架：搜索页=激活即聚焦的输入框+联想实时列表（前缀匹配+纠错）；结果页=筛选器行（排序/分类）+结果列表（高亮命中词）
- 关键页面：搜索落地页、结果列表、结果详情（原路返回保留结果）
- 核心组件：联想下拉（键盘可导航 [UA-1]）、历史记录（可单条删）、筛选器组、零结果页
- 状态与空态：零结果=给近似结果与放宽建议（[VP-20]），禁只写「无结果」；输入防抖请求去重
- 平台适配：移动端搜索常为全屏页；桌面端为下拉浮层+回车跳结果页；语音搜索按平台能力

### T12 个人主页（Profile）
- 信息架构：他人主页（头像+封面+数据行+内容 Tab）与自己主页（同构+编辑入口）
- 布局骨架：头部=封面图+头像（重叠）+昵称+简介+主操作按钮（关注/编辑/私信，[LC-4] 唯一实心）；内容=Tab 分流（动态/相册/收藏）
- 关键页面：主页、内容 Tab 列表、编辑资料页
- 核心组件：数据行（关注/粉丝/获赞，点击进列表）、主操作按钮（关注态切换即时反馈）、内容 Tab（切换保位置 [IM-25]）
- 状态与空态：内容空 Tab=引导发布/推荐他人而非空白；封面上传裁剪预览
- 平台适配：移动单列→桌面左信息右内容双栏（[TPL-10]）；自己/他人两态按钮组不同（勿只换文字）

### T13 设置页
- 信息架构：分组列表（账户/通知/隐私/通用/关于）+ 二级设置页 + 部分项内三级
- 布局骨架：每项=左侧标签+右侧当前值或控件（switch/chevron）；组间大间距分组（[LC-2]）；危险区（退出/注销）独立组+红色系（[LC-4] 隔离）
- 关键页面：设置根列表、二级项（通知偏好/隐私权限/存储）、账户管理
- 核心组件：设置行（点击整行命中 [SD-33]）、switch（即时生效+失败回滚 toast）、当前值摘要（如「简体中文」）
- 状态与空态：开关操作失败必须回滚视觉态并提示（[VP-20]）；搜索设置项（项 >20 时）
- 平台适配：移动端=单列列表；桌面/平板=左侧锚点导航+右侧内容双栏（[TPL-10]）

### T14 相册/媒体库
- 信息架构：图库（时间轴网格）→大图浏览（全屏）→编辑/分享
- 布局骨架：图库=按月分组的方形缩略图网格+吸顶月份粘性头；浏览=全屏左右滑切换+双指缩放+上下工具浮层
- 关键页面：图库、大图浏览、选择模式、相册分类（地点/人物）
- 核心组件：缩略图网格（虚拟化长列表 [TPL-8]）、选择模式（长按进入+角标计数）、视频卡（时长角标+播放态）
- 状态与空态：图片渐进加载（缩略→原图）；云端未同步项显式角标区分（[VP-20] 非猜测）
- 平台适配：手机 3~4 列→平板 5~7 列→桌面按窗口宽自适应（[TPL-10]）；选择模式工具条避让手势区

## Web 站点（T15~T24）

### T15 企业官网
- 信息架构：顶部导航（产品/方案/关于/新闻/联系）+首页分节叙事+独立子页
- 布局骨架：首页=Hero（主张+主 CTA）+核心产品/服务三卡+信任背书（客户 logo 墙/数据）+新闻+页脚（站点地图全量）
- 关键页面：首页、产品/服务页、关于我们、新闻列表+详情、联系页
- 核心组件：sticky 导航（滚动收缩+blur [TPL-4]）、Hero 区、CTA 按钮、页脚站点地图
- 状态与空态：首屏三问一屏答清（[VP-18]：这是什么/何用/下一步）；表单提交三态齐备
- 平台适配：桌面多栏网格→移动单列+汉堡菜单（[TPL-3]）；中英双语站导航结构镜像（RTL 时布局翻转）

### T16 产品落地页
- 信息架构：单页纵向叙事流+锚点导航+单一转化目标（注册/预约/下载）

## 专项模式（T35~T40）

### T35 AI 聊天助手
- 信息架构：会话历史侧栏（桌面）/抽屉（移动）+消息流主区+底部输入区；新会话入口置顶
- 布局骨架：消息流=用户消息右短块/AI 回复左通栏（含引用来源折叠）；输入区=多行输入+发送（有内容才激活 [LC-4]）+建议提示词 chips（会话空态时）
- 关键页面：会话流、历史会话列表、提示词模板库、分享/导出
- 核心组件：流式输出（逐字渲染+停止按钮 [IM-14]）、消息操作组（复制/重新生成）、上下文长度提示、敏感内容拦截提示
- 状态与空态：生成失败给重试；长回复分块折叠「展开更多」；冷启动空态=能力示例+输入引导（[VP-20]）
- 平台适配：桌面侧栏+宽消息流→移动端抽屉历史；生成中禁编辑历史消息造成的分叉（或显式分叉提示）

### T36 直播间
- 信息架构：全屏视频流为底+四角浮层；横竖屏两版式
- 布局骨架：竖屏=视频全屏+顶部主播信息卡（头像/ID/关注按钮）+弹幕区（下半部左侧列流）+底部输入栏+右侧功能列（点赞/连麦/分享）；横屏=弹幕右列+控制条
- 关键页面：直播间、主播主页（T12）、充值/礼物面板（半屏抽屉）、连麦管理
- 核心组件：弹幕流（新消息入列+滚动暂停感知）、礼物动效（全屏动效有频率限制）、连麦宫格、清晰度切换
- 状态与空态：弱网自动降清晰度+显式提示（[IM-14] 思路：状态不猜测）；主播断流=「主播离开」态+等待重连倒计时
- 平台适配：竖屏原生全屏；桌面嵌页面窗（弹幕侧栏常驻）；TV 大屏=观看+弹幕开关（互动降级 [TPL-10]）

### T37 电商结算页
- 信息架构：单列窄容器（移动）/双栏（桌面：表单+订单摘要粘性侧栏）；流程不可多标签并存（防比价流失除外）
- 布局骨架：地址（默认地址卡+可切换）→配送方式（单选行）→商品清单（折叠摘要+展开明细）→优惠券/积分（选择器）→支付方式→金额明细（一行一项，优惠红字负数）→提交大按钮（金额随按钮显示）
- 关键页面：结算页、地址管理（增改删+默认）、支付结果页（成功/失败分路，失败保留订单可重付）
- 核心组件：地址卡、金额明细行（tabular-nums 对齐）、支付方式选择（图标+文字双通道）、提交按钮（金额联动+pending 锁）
- 状态与空态：任何一步失败保留全部已填信息（[VP-13]）；库存/价格变动提交前复核拦截；返回购物车可无损恢复
- 平台适配：移动单列分步滚动（吸底提交栏 [TPL-4]）；桌面双栏+摘要粘性；支付渠道按平台与地区配置

### T38 向导（Onboarding）
- 信息架构：首次启动全屏分步（3~5 步，进度点可见）或浮层 checklist（工具类产品）；跳过入口显式常驻
- 布局骨架：每步=一图/一动效+一句标题+一行说明+单按钮（「下一步/开始」，[LC-4]）；权限请求延后到触发场景（非首启打包索取）
- 关键页面：欢迎/价值主张步、账号步（可跳过）、兴趣选择步（可跳过）、完成步（直达核心动作）
- 核心组件：进度指示（点/条 [VP-40]）、跳过链接（弱化但不隐藏）、兴趣多选 chips（上限提示）
- 状态与空态：完成即到价值时刻（首条内容/首个动作），禁停在「设置完成」死页；中断下次续走
- 平台适配：移动全屏滑动；桌面居中卡片+背景遮罩；权限文案与系统弹窗内容一致（防双重解释）

### T39 通知中心/消息聚合
- 信息架构：按时间倒序分组列表（今天/昨天/更早）+按应用/类型筛选；系统级与 App 内统一建模
- 布局骨架：列表项=应用图标+标题+摘要+时间（相对时间）+聚合计数（「还有 3 条」可展开）；左滑/悬停显操作（清除/设置）
- 关键页面：通知列表、聚合展开、通知设置（按应用开关+重要程度）、勿扰模式
- 核心组件：聚合卡（同应用连续通知合并）、清除操作（可撤销 toast）、勿扰快捷开关
- 状态与空态：全部清空前确认或可撤销；空态=「没有新通知」+勿扰状态提示（[VP-20]）
- 平台适配：移动下拉抽屉/系统融合；桌面右下角弹层+中心面板；角标数与列表实际数同步（禁幽灵角标）

### T40 IoT 控制台/智能家居
- 信息架构：首页=房间分组设备网格→设备详情（控制+自动化+历史）；场景/自动化二级入口
- 布局骨架：设备卡=图标+名称+状态一句话+快捷开关（整卡可点进详情 [SD-33]）；离线卡降灰+「离线」徽标（[UA-3] 双通道）；详情页=当前状态大数字+控制组（滑条/开关）+历史图表+自动化列表
- 关键页面：首页（房间 Tab）、设备详情、场景编辑（时间/触发/动作）、添加设备向导（T38 流程）
- 核心组件：设备卡、温控滑条（大命中区+刻度反馈）、场景一键执行（结果逐设备回报）、配对引导
- 状态与空态：设备离线=显式状态+重试入口（禁假装可控，[VP-20]）；指令下发后状态以设备回执为准（乐观更新限制 [IM-6] 思路——低成功率网络慎乐观）
- 平台适配：手机为主控端；平板做常驻面板（墙装横版）；手表=收藏设备快捷开关；音箱=纯语音无 UI（[TPL-10]）

- 平台适配：手机横竖屏两版式；TV=大屏跟练（遥控器简单控制）；手表=仅计时与心率联动

### T47 扫码/二维码工具

- 布局骨架：取景器=扫码框（动画对准提示）+相册导入入口+手电筒；结果=按内容类型分卡片（链接预览/Wi-Fi/文本）+操作（打开/复制/分享）

- 核心组件：数据对照表、冲突项选择器（保留 A/保留 B）、会员权益合并规则（时长叠加说明）、执行进度（分项真实进度 [IM-14]）

- 平台适配：Web 流程为主（数据操作审慎场景）；移动端只读预览；企业账号合并另行流程（管理员权限）

## 营销与电商扩展（T113~T120）

### T113 促销会场（大促页）
- 信息架构：会场入口（平台级导流）→ 分区楼层（品类/玩法）→ 商品流；跨店满减计算器
- 布局骨架：顶部=主视觉（活动规则一键可查）+倒计时；楼层=分区锚点导航（sticky 悬浮）+商品网格；优惠=满减/折扣标签系统（层级清晰）
- 关键页面：主会场、品类分会场、玩法页（满减/凑单）、我的优惠
- 核心组件：倒计时（统一活动时间轴）、价格双轨（划线原价+到手价，到手价醒目 tabular）、楼层锚点导航、优惠标签（规则 tooltip）
- 状态与空态：活动未开始=预告+加购/提醒；售罄态（色+文字 [UA-3]）；原价真实性声明（价格合规，法规差异待验证）
- 平台适配：移动端为主（大促流量移动占优）+吸底购物车栏（[TPL-4]）；桌面端信息密度提高；弱网降级（图降档禁骨架卡死）

### T114 优惠券中心/领券页
- 信息架构：可用券列表（分类 Tab：全部/商品/通用）→ 领取 → 去使用（跳转关联商品）
- 布局骨架：券卡=金额大字（tabular）+使用门槛+有效期+适用范围；状态=可领/已领/已抢光（双通道 [UA-3]）；列表=按力度/时效排序
- 关键页面：领券中心、我的券包（可用/已用/过期）、券规则详情
- 核心组件：券卡（金额左大字结构）、领取按钮（三态：可领/已领置灰/已抢光）、券包（即将过期置顶+倒计时）、使用门槛说明（tooltip+规则页）
- 状态与空态：已抢光=「提醒我」补货入口；券包空态=领券引导；叠加规则说明（可与哪些优惠叠加）
- 平台适配：移动端领取为主；结算页自动匹配最优券（手动可改）；桌面端券包管理

### T115 秒杀/抢购流程
- 信息架构：场次时间轴（预告/进行中/已结束）→ 商品列表（库存态）→ 抢购确认（快速结算）→ 结果
- 布局骨架：场次=横向时间条（当前场次高亮，下一场倒计时）；商品卡=秒杀价大字+进度条（已抢百分比）；确认=极简结算（预选地址+一键提交）
- 关键页面：秒杀频道、抢购确认页、结果页（成功/售罄/排队中）、场次预告
- 核心组件：场次时间条、库存进度条（真实数据，紧迫感禁造假）、快速结算（地址预选+支付直达）、排队态（显式队列位置）
- 状态与空态：未开始=提醒订阅；售罄=下场推荐；排队中=位置与预计时间（禁黑盒假加载）
- 平台适配：移动端单手抢购（信息预读提前填）；支付方式预配置；限购规则显式（防作弊提示）

### T116 会员开通/订阅付费页
- 信息架构：权益对比（免费 vs 付费档）→ 档位选择（周期）→ 支付 → 开通成功
- 布局骨架：权益=对比矩阵（T51 裁剪）；档位=周期卡（连续包月/季/年，价格折算说明「折合 ¥X/月」）；支付=快捷支付直达
- 关键页面：会员介绍页、开通页、成功页、管理页（续费/取消）
- 核心组件：周期卡（默认勾选合规：不预勾选连续付费，各市场法规待验证）、价格折算说明、自动续费条款（显式+可随时取消）、续费管理（取消入口与开通同级易达）
- 状态与空态：开通成功=权益立即生效+首权益引导；到期前提醒（多渠道）；取消后权益期说明（到期才失效）
- 平台适配：移动端支付直达（应用内支付合规约束）；Web 端第三方支付；自动续费各平台规则差异（待验证）

### T117 礼品卡/兑换码
- 信息架构：礼品卡选择（面额/样式）→ 购买/赠送 → 兑换（输入码）→ 余额/权益到账
- 布局骨架：购买=面额快捷选择+自定义输入+样式选择（节日主题）；赠送=定时发送+祝福语；兑换=码输入（分段框自动格式化）
- 关键页面：礼品卡商店、赠送流程、兑换页、余额/使用记录
- 核心组件：面额选择（快捷+自定义）、码输入框（分段+自动大写+粘贴解析）、兑换结果（到账明细）、礼品卡视觉模板（节日主题库）
- 状态与空态：码无效=错误类型区分（不存在/已使用/已过期）；余额不足组合支付说明
- 平台适配：全端兑换（码输入无平台限制）；赠送链接/二维码双通道；余额有效期规则显式

### T118 邀请裂变/推荐返利
- 信息架构：邀请页（专属码/链接/海报）→ 被邀者落地（T85）→ 双方奖励发放 → 进度追踪
- 布局骨架：邀请页=奖励规则图解（双方各得）+邀请渠道按钮组+专属海报（含二维码）；进度=邀请记录列表（状态：已注册/已完成/已发奖）
- 关键页面：邀请中心、海报生成、邀请记录、规则详情
- 核心组件：专属码/链接（一键复制）、渠道分享（社交平台适配）、邀请海报（二维码+奖励亮点）、奖励进度（阶梯奖励可视化）
- 状态与空态：奖励发放条件显式（防「邀请了没奖励」纠纷）；作弊风控提示（刷单封禁声明）；记录空态=邀请示例
- 平台适配：移动端社交分享为主（系统分享面板）；桌面端复制链接；海报在移动生成（长按保存）

### T119 拼团/团购流程
- 信息架构：开团/参团选择 → 支付（拼团价）→ 成团等待（邀请分享）→ 成团发货/失败退款
- 布局骨架：商品页=拼团价+单独价双轨+「一键开团/参团」；等待页=成团进度（已参团头像+还差 N 人）+分享按钮置顶+倒计时；结果=成团成功/失败（自动退款进度）
- 关键页面：拼团商品页、成团等待页、我的拼团列表、失败退款
- 核心组件：成团进度（头像+缺口数字）、参团倒计时（过期自动退款声明）、新老用户规则（限制条件显式）、失败退款进度（原路退回时效）
- 状态与空态：差一人=强化分享引导（克制，禁骚扰文案）；已成团=发货通知
- 平台适配：移动端分享闭环为主；桌面端浏览+移动支付联动；价格双轨层级清晰（拼团价主视觉）

### T120 内容种草/导购专题
- 信息架构：专题叙事流（图文/视频穿插）→ 商品嵌入卡 → 合集/清单 → 购买转化
- 布局骨架：叙事=单列沉浸流（大图+短文案节奏）；商品=嵌入卡（图+价+购买按钮，上下文自然植入）；合集=底部清单（可收藏）
- 关键页面：专题页、清单合集、关联商品详情（T01 PDP）
- 核心组件：商品嵌入卡（内容内锚点+吸底跟随当前浏览商品）、清单收藏、内容标签（#话题可导航）、购买转化归属说明
- 状态与空态：商品售罄/下架=嵌入卡态更新（禁死链）；内容加载分层（图渐进 [TPL-2]）
- 平台适配：移动端沉浸流为主（手势翻页可选）；桌面端多列瀑布；内容与电商导航层级分离（内容优先）

## 特殊人群与场景（T121~T128）

### T121 适老化模式（elder mode）
- 信息架构：结构极简（核心功能 ≤5 个大入口）；层级 ≤2；文字化导航（禁图标纯导向）
- 布局骨架：首页=大字卡片列表（整卡命中，[SD-33] 基础上加大）；页=标题+单内容+大返回；按钮=特大；全局再放大 200% 不破版（[SD-34]）
- 关键页面：简化首页、大字内容页、一键求助（亲情号）、防诈骗提示位
- 核心组件：超大字体（适老基准字号按市场规范，待验证）、高对比配色（[CS-17] 严格校验）、语音辅助入口、子女远程协助入口
- 状态与空态：操作确认=双重明确（确认弹窗大字复述操作）；错误提示=温和+具体解决动作；无复杂手势（禁滑动删除）
- 平台适配：手机为主（适老场景）；切换入口显著（设置首页+首启询问）；与标准模式一键互切（设置记忆）

### T122 儿童模式（kids mode）
- 信息架构：年龄分级内容池（家长设定）；全屏沉浸+简化导航；家长锁退出
- 布局骨架：首页=大图标网格（角色 IP 导向）；播放=自动连播+休息计时浮层；退出=家长门（算术/长按组合验证）
- 关键页面：儿童首页、播放页、家长中心（锁后：时长/内容分级/消费限制）、休息提醒
- 核心组件：家长门（验证年龄门槛）、时长管理（每日上限+休息提醒）、消费全禁（或双重验证）、内容分级标签（年龄角标）
- 状态与空态：休息时间到=全屏锁定（倒计时+温和引导）；内容池空=年龄调整引导
- 平台适配：手机/平板为主；TV 儿童模式（遥控简化，与 T75 联动）；家长通知（使用时长周报）

### T123 无障碍增强模式
- 信息架构：标准界面 + 增强层（视觉/听觉/操作三维度开关）；设置即时预览
- 布局骨架：设置页=增强项分组（字幕/高对比/减少动效/触碰延迟/开关控制）；每项=开关+效果预览；全局生效横幅
- 关键页面：增强设置、效果预览、快捷切换（控制中心类入口）
- 核心组件：高对比模式（[CS-17] 严格档）、字幕样式自定义（大小/底色）、减少动效（全局禁非必要动画）、触碰延迟调整、开关控制（线性扫描操作）
- 状态与空态：每项即时预览（所见即所得）；增强组合冲突提示；系统级设置联动（跟随系统开关选项）
- 平台适配：全端提供；快捷入口（三击/控制中心）；与平台辅助 API 集成（读屏标签完整声明）

### T124 单手操作模式（reachability）
- 信息架构：核心操作下沉至拇指热区（屏幕下 1/3）；导航与操作布局镜像（左/右手）
- 布局骨架：模式开启=界面下半区下移（系统级下拉或应用内重排）；高频操作=底部聚集（[TPL-4] 避手势区）；顶部仅浏览性内容
- 关键页面：模式设置（左/右手偏好）、重排后的核心页
- 核心组件：下拉触发（悬底内容拉至半屏）、操作镜像（左右手布局翻转）、大命中区（[SD-33] 基础上加大）
- 状态与空态：模式状态显式（开启提示横幅）；与标准模式无缝切换（位置保持）
- 平台适配：大屏手机场景（价值最高，具体屏幕尺寸阈值待验证）；应用内模式优于系统下拉（控件级重排）；平板不适用（[TPL-10]）

### T125 阅读模式/极简模式
- 信息架构：一键进入纯净内容视图（去除非内容元素）；排版参数可调；退出原路保留
- 布局骨架：内容=居中窄栏+可调（字号/行距/主题/宽度）；工具=悬浮收起（进度/目录/设置）；界面=去除广告/推荐/评论区（可显式展开）
- 关键页面：阅读视图、排版设置、目录（抽屉）
- 核心组件：排版参数面板（字号/行距/主题实时预览）、主题档位（纸白/米黄/夜间，[CS-12] 非纯黑）、进度记忆（[IM-25]）、聚焦模式（逐行高亮可选）
- 状态与空态：无法解析的页面=原视图+说明（不强转）；夜间主题跟随系统；排版选择持久记忆
- 平台适配：手机/桌面全端；浏览器阅读模式与站内模式差异声明；长文分页/滚动双模式

### T126 专注模式（Zen）
- 信息架构：全屏单任务（写作/计时/学习）；一切通知与干扰入口隐藏；状态可见（计时/字数）
- 布局骨架：全屏=纯画布（居中窄栏）+状态微件（角落：计时/进度）；退出=显式（Esc/手势，防误触）；屏蔽=勿扰联动（系统级+应用内）
- 关键页面：专注画布、目标设置（时长/字数）、专注记录（历史统计）
- 核心组件：全屏纯净视图、目标进度（微件）、勿扰联动、完成仪式（克制反馈）
- 状态与空态：中断处理（紧急通知白名单）；暂停与继续；误退确认（进度保护）
- 平台适配：桌面全屏（F11 类语义）；移动端勿扰权限引导；与系统专注模式联动（平台能力差异声明）

### T127 紧急求助/SOS 界面
- 信息架构：快捷触发（长按/连按）→ 确认（倒计时可取消）→ 求助发出（位置+联系人）→ 状态反馈
- 布局骨架：触发=锁屏/任意界面可达（系统级能力）；确认=全屏倒计时（大字+取消按钮显著）；发出=状态摘要（已通知 X 人/位置已共享）+持续追踪入口
- 关键页面：SOS 确认、求助状态、紧急联系人管理、设置（触发方式）
- 核心组件：倒计时确认（防误触与紧急平衡）、位置共享（实时+电量状态）、紧急联系人通知（发送状态回执）、静默求助（可选：不发声模式）
- 状态与空态：无联系人=引导设置（前置完成）；弱网=短信降级通道（平台能力声明）；误触发=一键取消+说明
- 平台适配：系统级集成（锁屏/手表硬件键优先，与 T74 联动）；隐私声明（位置共享范围与终止方式）；各市场紧急服务集成差异（待验证）

### T128 游客模式/免登录浏览
- 信息架构：免登录浏览（内容只读）→ 操作触发登录（点赞/评论/购买时）→ 登录后原操作续行
- 布局骨架：浏览=全功能只读（内容不设墙）；触发=登录浮层/半屏（说明操作目的：「登录后可收藏」）；续行=登录成功自动完成原操作
- 关键页面：游客浏览、登录浮层（T18 裁剪）、游客数据引导（登录迁移提示）
- 核心组件：登录触发浮层（就近出现，禁全站强制登录墙）、游客数据本地暂存（登录后迁移询问）、权限边界说明（游客可见范围声明）
- 状态与空态：游客操作排队（登录后自动执行，禁丢失）；游客行为合规声明（隐私政策可达）；强制登录场景例外（法规要求类，声明原因）
- 平台适配：全端一致策略（游客可浏览为默认，强制登录为特例须有理由）；游客模式与登录态数据合并冲突（本地优先询问）

## 选型决策路径

用户问「做一个 XX」时的匹配顺序：
1. 判断应用/页面类型，匹配模板（可组合：电商=T01+T11+T37；内容平台=T02+T10+T12）
2. 取模板骨架（信息架构+布局+核心组件），按实际业务裁剪并声明（[TPL-1]）
3. 行业配色与气质注入 → industry-themes kb 查行业方案
4. 平台/size class 适配：[SD-31] 决定列数/导航模式/信息密度（[TPL-10]）
5. 三态补全：[TPL-2]（加载/空/错误）+ 交互态（[LC-4] 主操作分档）
6. 专项检查：多步流程过 [TPL-9]；数据密集过 [TPL-7]；列表流式过 [TPL-8]

## 与其他子领域的集成要点

- layout-composition：间距刻度与层级编码（[LC-1]/[LC-2]）承接模板骨架的数值化；视觉流编排决定首屏阅读顺序

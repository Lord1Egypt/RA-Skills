## Description:

Generates security hardening configurations for Cisco NX-OS network devices based on specified options.

This skill is ready for commercial/non-commercial use.

## Publisher:

[krishnakumarmahadevan-cmd](https://clawhub.ai/user/krishnakumarmahadevan-cmd)

### License/Terms of Use:

MIT-0

## Use Case:

Network engineers, security architects, DevOps teams, and organizations managing Cisco Nexus infrastructure use this skill to request NX-OS hardening configuration guidance based on selected control categories.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill sends hardening selections and request metadata to a third-party API.

Mitigation: Avoid including real secrets, credentials, internal IPs, or sensitive topology details unless the provider's privacy and retention practices have been reviewed.

Risk: Generated NX-OS configuration commands may be inappropriate for a specific network environment if applied without review.

Mitigation: Have a qualified network engineer review generated commands against device role, change controls, and rollback procedures before deployment.

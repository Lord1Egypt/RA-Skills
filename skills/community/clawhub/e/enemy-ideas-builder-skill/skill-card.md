## Known Risks and Mitigations:

Risk: Users may paste secrets, credentials, wallet data, or sensitive personal data into prompts while seeking design help.

Mitigation: The skill instructs users not to provide secrets and to keep pasted notes low in personally identifiable information.

Risk: Generated guidance could include unsafe installation or execution advice if a user asks for workflow automation.

Mitigation: The skill explicitly avoids remote installers, unseen code execution, chained download-and-run snippets, and irreversible actions.

Risk: The optional donation link could be mistaken for a requirement to use the skill.

Mitigation: Security guidance states that the PayPal donation link is optional and not needed for the skill to function.

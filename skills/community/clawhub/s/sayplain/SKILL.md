# 去 AI 味二创工作流

本文件只规定文件契约、工序边界与全局约束。改写与删减的一切规则以 `references/` 为唯一权威，复核判据以 `references/毛病词典.md` 为唯一权威；格式与口径以 `references/风格手册.md` 为唯一权威；本文件不复述规则正文。`references/` 与 `scripts/` 路径均相对本 skill 目录，`gongzuoliu/` 路径相对工作区根目录。

## 第零道：格式统一（只改口径，不改语义）

**必读，逐字读完，不得跳读、不得凭印象**

- `references/风格手册.md`

**输入与输出** `gongzuoliu/试跑/<日期_样本名>/02_二创稿.md`（原地覆盖，先于第一道执行）。

判据只有一条：**当前写法是否匹配风格手册**。不匹配就改，匹配就保留。

- 跑 `python <skill_dir>/scripts/format_check.py "gongzuoliu/试跑/<日期_样本名>/02_二创稿.md"`，命中是信号，不是违规。
- 按手册逐条处置：术语统一表、标题层级、引号与符号、加粗规则、引用块与代码块、列表与其它结构、错别字对照表。
- 先排除保护边界（代码块、真实引语、产品专名、作者声口、未填槽位），再判定改不改。
- 本道只动格式与口径，不判「写得好不好」；它和第一道「去 AI 味」是两件事，不得互相越界。

## 全局约束（全工序共用）

- 本工作流全程按既定授权直接执行：一、二道对话输出只写正文，不夹检查过程、报告或说明。
- 用途与语体已定，不再反问：开源书章节二创，读者是完全不懂编程的小白；不为正式而降格，也不为口语化而生造搭配。
- 数字、代码、命令、路径、文件名、专有名词与 `01_原稿.md` 逐字一致。
- 加粗规则句属于作者声口，保留。
- 比喻不整体豁免：只在承担说理、且不是把上文内容换个说法重讲一遍时才留；铺展成段的按冗余删。
- 输入含密码、API key、access token、私钥、会话 cookie，或作者称其为凭证时，立即停止并回复：`检测到疑似凭证，请删除或替换为 [REDACTED] 后重试。` 概念性讨论 `token`、`API key` 不算凭证。
- 不替文章重新立论，不新增论据、采访或专业判断。
- 唯一合法停止点：原文存在实质逻辑风险、无法在保义前提下继续时，输出阻塞说明并停止。除此之外不停顿、不反问、不请求确认。

## 文件契约

```
gongzuoliu/试跑/<日期_样本名>/
├── 01_原稿.md      作者放入的待二创稿，唯一输入
├── 02_二创稿.md    工作稿：第一道产出，第二、三道在其上更新
└── 复核报告.md     复核产出：只记逻辑风险与待作者确认项，不写处置流水账
```

不产生其他过程件。作者认可后自行取走 `02_二创稿.md`。

## 第一道：改写

**必读，逐字读完，不得跳读、不得凭印象**

- `references/改写规则.md`
- `references/症状目录.md`
- `references/保护边界.md`

其余参考（白名单、示例、品牌文案、平台模式）不预读，按 `references/改写规则.md` 末尾「按需参考」的路由触发。

**输入** `gongzuoliu/试跑/<日期_样本名>/01_原稿.md`
**输出** `gongzuoliu/试跑/<日期_样本名>/02_二创稿.md`

按 `references/改写规则.md` 执行完整重写流程，只写正文。

## 第二道：减法（只删不添）

**必读，逐字读完，不得跳读、不得凭印象**

- `references/症状目录.md`（重点用删除类症状）
- `references/保护边界.md`（保护边界，以及破折号／被动／三连的按功能裁决）

**输入与输出** `gongzuoliu/试跑/<日期_样本名>/02_二创稿.md`（原地覆盖）。

- 只删不添：不得新增原稿没有的判断、例子、经历、感受、结论、过渡句。
- 重点扫删除类症状：开头复述任务、预判标签与假口语、收尾复述与统一升华、无证据拔高、无信息强调词，以及元叙述（「值得先看清楚」「值得注意」「更要紧的是」「接下来我们看」这类替读者排序、替读者下判断、预告后文的句子）。
- 删完回扫孤儿句：半句删掉后剩下的孤立评价句、无信息收束句、指代已消失的过渡句，一并删。

## 第三道：复核并修正

1. `python <skill_dir>/scripts/fact_anchor_check.py "gongzuoliu/试跑/<日期_样本名>/01_原稿.md" "gongzuoliu/试跑/<日期_样本名>/02_二创稿.md"`，逐条核对丢失与新增：锚丢失即回补，无源新增即删。
2. `python <skill_dir>/scripts/style_check.py "gongzuoliu/试跑/<日期_样本名>/02_二创稿.md"`，命中是信号，不是违规。
3. 通读，按 `references/毛病词典.md` 21 条逐条查。判据只有一条：删掉它这段话有没有少东西，没少就删；每条带例外的按例外放行，不按数量砍。
4. 当场修正 `gongzuoliu/试跑/<日期_样本名>/02_二创稿.md`。复核报告只写两件事：**逻辑风险**（原文因果/结论超出证据、前后矛盾，且正文无法自然保义时）与**待作者确认项**；无风险时写「无」。不写处置流水账：脚本命中、格式改动、逐条核对结果一律不进报告。作者只看 `02_二创稿.md` 与 `复核报告.md` 这一对产出。

## Description:

Explains code with visual diagrams, everyday analogies, step-by-step walkthroughs, and common pitfall callouts.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill when they want code explained through everyday analogies, ASCII diagrams, execution walkthroughs, and likely mistakes or misunderstandings.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate for broad code-understanding requests and shape the response style even when a terse answer would be preferable.

Mitigation: Use a more specific user or system instruction when a concise, non-analogical explanation is required.

Risk: The skill may bias explanations toward Chinese when no language preference is specified.

Mitigation: Specify the desired response language in the user or system instruction.

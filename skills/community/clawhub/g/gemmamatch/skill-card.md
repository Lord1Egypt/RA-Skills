## Known Risks and Mitigations:

Risk: The reviewed artifact directs users to run a terminal command generated by a mutable external website without showing or constraining that command.

Mitigation: Review each command before running it; prefer recognizable Ollama or LM Studio commands and avoid commands that pipe remote content into a shell, request administrator privileges, or perform unrelated file, credential, network, or system-modification actions.

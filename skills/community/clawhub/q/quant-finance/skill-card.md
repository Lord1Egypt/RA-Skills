## Use Case:

Developers and external users use this skill as a lightweight local reference for quant finance terminology, formulas, compliance topics, risks, instruments, strategies, and operational checklists. ## Known Risks and Mitigations:

Mitigation: Use the skill only as a lightweight reference stub and verify decisions against independent authoritative finance, legal, and risk sources.

Risk: The shell script reports version 2.0.2 while the server release evidence and SKILL.md frontmatter identify version 2.0.3.

Mitigation: Treat server release evidence and SKILL.md frontmatter as the card version, and verify the script version before relying on CLI version output.

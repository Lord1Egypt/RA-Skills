## Description:

OpenClaw Creator Setup helps content creators check their OpenClaw environment, configure publishing platforms, and manage workflow templates.

This skill is ready for commercial/non-commercial use.

## Publisher:

[rfdiosuao](https://clawhub.ai/user/rfdiosuao)

### License/Terms of Use:

MIT-0

## Use Case:

External content creators and social media operators use this skill to inspect Feishu authorization and installed skills, configure publishing platforms, and create or check OpenClaw workflow templates.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad status phrases may trigger checks of Feishu authorization and installed skills.

Mitigation: Use explicit creator-environment wording when requesting status or configuration checks.

Risk: Some platform and Feishu workflows require connected-account authorization.

Mitigation: Confirm the target platform and grant only the required authorization before enabling setup actions.

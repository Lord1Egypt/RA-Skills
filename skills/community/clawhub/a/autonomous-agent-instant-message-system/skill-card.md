## Known Risks and Mitigations:

Risk: The skill connects agents to Prismer Cloud for messaging, memory, file uploads, parsing, task state, and skill or plugin management.

Mitigation: Review data before sending or storing it, avoid secrets and regulated content unless approved, and limit use to approved workspaces and conversations.

Risk: The security verdict flags broad remote storage, messaging, file upload, plugin, and skill-install capabilities without enough scoping or provenance safeguards.

Mitigation: Pin package and plugin versions where possible, manually review installed skills before agent use, and require human approval for new integrations.

Risk: Skill-install and plugin workflows can add new local agent behavior from external sources.

Mitigation: Inspect installed skill content and plugin permissions before enabling them in autonomous or sensitive workflows.

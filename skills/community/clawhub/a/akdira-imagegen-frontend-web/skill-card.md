## Description:

Generates premium, implementation-ready website design reference images section by section, with one horizontal image per website section and consistent art direction across the set.

This skill is ready for commercial/non-commercial use.

## Publisher:

[akdira](https://clawhub.ai/user/akdira)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, designers, and coding agents use this skill to turn a website brief into section-level frontend reference images for landing pages, marketing sites, and product comps.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Full landing page requests can trigger multiple image-generation outputs, increasing cost and turnaround time.

Mitigation: Confirm the intended section count and generation budget before invoking the skill for large pages.

Risk: Generated frontend reference images may need review for brand fit, readability, accessibility, and implementation feasibility before being built.

Mitigation: Review each section image against the brief and design requirements before using it as implementation guidance.

# 乙脑流行病学关键参数与变量参考

## 核心监测变量
| 变量名称 | 类型 | 描述与参考值 |
|---|---|---|
| 猪群感染率 | Percentage | 用于预测人群流行趋势，流行前1-2月猪群已广泛传播，仔猪经一流行季感染率近100% |
| 显隐感染比 | Ratio | 1:(300~2000)，用于评估实际感染规模与临床病例数的关系 |
| 高发年龄段 | String | 2-6岁儿童（10岁以下为主要发病人群） |
| 季节性高峰 | String | 7、8、9月（占温带/亚热带地区80-90%病例） |

## 媒介与宿主详细特征
- **主要传染源**：猪（饲养广、更新快、病毒血症期长、血中病毒浓度高）。
- **长期储存宿主**：蝙蝠、蚊媒（可携带病毒越冬，并经卵传代）。
- **主要传播媒介**：三带喙库蚊（带病毒率最高，分布广，家畜圈最多）。

## 前置数据需求
执行本技能前，需确保掌握以下数据：
1. 当地动物（尤其是猪）的感染率数据。
2. 当地蚊媒密度及三带喙库蚊分布数据。

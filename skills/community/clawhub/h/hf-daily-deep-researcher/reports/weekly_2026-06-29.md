## 1. 执行摘要

本周 Agentic RL 领域的 credit assignment 方向迎来两项重要进展：HKUST 提出的 **SCPO** 通过语义一致性约束实现 value-free 的 reward shaping，在 ALFWorld 上达到 **93.7±4.1%**；Tsinghua/NTU/CUHK 联合提出的 **OPID** 则通过 on-policy hindsight skill distillation 实现关键步骤的额外 credit 分配，仅用 **60%** 数据即可达到 full-data GRPO 水平。两者均为轻量级插件式方案，不修改策略目标且推理零开销，但均局限于单 agent 设定和已完成轨迹。与此同时，**3SPO**、**EGCA** 和 **DelTA** 分别从动态 state scoring、代码执行验证和 token-level discriminative credit 等角度进一步细化了粒度层级，共同推动该领域从 episode-level 向 step-level 乃至 token-level 演进。

## 2. 本周核心进展

### 2.1 语义一致性驱动的 Value-Free Reward Shaping（SCPO）

HKUST 团队提出的 SCPO（Semantic Consistency Policy Optimization）代表了 credit assignment 领域的一个重要技术路线突破。该方法的核心创新在于引入了一个**冻结的交叉编码器**作为语义裁判，无需训练 value function 即可恢复失败步骤中"本应获得 credit"的语义信号。具体而言，SCPO 通过比较成功轨迹与失败轨迹中对应步骤的语义一致性，识别出那些虽然动作失败但实际上朝着正确方向推进的中间步骤，并为其分配正向 reward。这种设计使得方法完全不依赖于传统 RL 中容易引入 bias 的 value estimation，同时保持了与现有策略优化算法（如 PPO、GRPO）的兼容性。

实验结果表明，在 **1.5B** 参数规模下，SCPO 在 ALFWorld 上达到 **93.7±4.1%** 的成功率，在 WebShop 上达到 **74.8±2.0%**，显著优于不使用语义一致性约束的基线。值得注意的是，SCPO 的推理阶段**零额外开销**，因为其交叉编码器仅在训练时作为 reward shaping 的裁判使用，不参与实际推理。

### 2.2 On-Policy Hindsight Skill Distillation（OPID）

OPID（On-Policy Skill Distillation）由 Tsinghua、NTU 和 CUHK 联合团队提出，从另一个角度解决了 credit assignment 问题：不是"恢复"失败步骤的 credit，而是"提取"成功轨迹中的 hindsight skills 并将其 credit 放大。该方法在 episode 和 step 两个层级上提取 hindsight skills，并通过 **critical-first routing** 机制确保关键技能获得额外的 advantage 分配。

OPID 的实验覆盖 ALFWorld（**90.0%** @ 7B）、WebShop 和 Search-based QA 等多个 benchmark。其中最引人注目的结果是：**仅使用 60% 的训练数据**即可达到 full-data GRPO 的性能水平，这意味着该方法在数据效率上具有显著优势。OPID 的 skill distillation 过程完全在 on-policy 数据上进行，避免了 off-policy 方法中常见的 distribution shift 问题。

### 2.3 两条路线的互补性

SCPO 和 OPID 构成了一个有趣的互补框架：SCPO 做 reward 层面的**减法**（过滤掉无进展步骤的虚假 credit），OPID 做 advantage 层面的**加法**（为关键 hindsight skills 分配额外 credit）。两者都是**轻量级插件**，不修改底层策略优化目标，且推理阶段零开销。这种"插件化"的设计理念可能是未来 credit assignment 方法的一个重要范式。

## 3. 详细论文分析

### 3.1 P0 - 核心相关论文

#### SCPO: Semantic Consistency Policy Optimization

| 属性 | 内容 |
|------|------|
| arXiv ID | 2606.25852 |
| 发布日期 | 2026-06-24 |
| 机构 | HKUST |
| 核心方法 | Value-free reward shaping via frozen cross-encoder |

SCPO 的核心贡献在于提出了一种**无需 value function** 的 reward shaping 机制。传统 RL 方法在 agentic 任务中面临的一个根本性挑战是：稀疏 reward 环境下，大部分 intermediate steps 无法获得有效的 credit 信号，而密集 reward（如基于规则或 LLM-as-a-Judge）又容易引入人为 bias 和噪声。SCPO 的解决思路是引入一个**冻结的语义交叉编码器**（frozen cross-encoder），该编码器比较成功轨迹与失败轨迹中对应步骤的语义表示，判断一个失败的步骤是否在语义上"接近成功"。

具体实现上，SCPO 在训练过程中维护一个成功轨迹的缓冲区。对于每一条失败轨迹中的每一个步骤，编码器将其与成功轨迹中对应位置的步骤进行语义相似度计算。如果语义相似度高，即使该步骤的动作导致失败，也会获得正向的 reward shaping。这种方法的优势在于：（1）**无需训练 value function**，避免了 value estimation 在 long-horizon 任务中的高方差问题；（2）**语义级别的 credit 恢复**比基于规则或 surface-level 的 reward 更加 robust；（3）**插件式设计**，可以与任何策略优化算法结合使用。

实验结果方面，在 **1.5B** 参数规模的 LLM 上，SCPO 在 ALFWorld 达到 **93.7±4.1%**（这是该 benchmark 上非常有竞争力的结果），在 WebShop 达到 **74.8±2.0%**。值得关注的是，SCPO 在 WebShop 上的表现（74.8%）表明该方法不仅适用于纯文本环境（ALFWorld），也适用于需要与外部系统交互的半开放环境（WebShop）。

**局限性**：SCPO 的一个隐含假设是**存在成功轨迹**作为参照。在极度困难的探索任务中，如果长时间无法获得任何成功轨迹，SCPO 的语义裁判将失去比较基准。此外，该方法目前仅针对**单 agent 设定**，未涉及多 agent 协作场景中的 credit 分配问题。

#### OPID: On-Policy Skill Distillation

| 属性 | 内容 |
|------|------|
| arXiv ID | 2606.26790 |
| 发布日期 | 2026-06-25 |
| 机构 | Tsinghua / NTU / CUHK |
| 核心方法 | Hindsight skill extraction + critical-first routing |

OPID 从另一个角度切入 credit assignment 问题：与其试图"恢复"失败步骤的 credit，不如"放大"成功轨迹中关键步骤的 credit。该方法的核心是 **On-Policy Skill Distillation**，即在训练过程中从已完成的轨迹中提取 hindsight skills，并通过 critical-first routing 机制为这些技能分配额外的 advantage。

OPID 的创新点体现在三个层面。首先是** hindsight skill 的双层级提取**：在 episode 层面识别完成整个任务所需的 high-level skills，在 step 层面识别解决局部子问题所需的 low-level skills。这种分层结构使得 credit 分配可以同时适应不同时间尺度的需求。其次是 **critical-first routing**，这是一个 advantage 分配机制，确保被识别为"critical"的 skills 在策略梯度中获得更大的权重。第三是**完全的 on-policy 设计**，所有 skill distillation 和 credit 分配都在当前策略生成的数据上进行，避免了 off-policy 方法中常见的 distribution mismatch 问题。

实验覆盖了 ALFWorld、WebShop 和 Search-based QA 三个 benchmark。在 ALFWorld 上，7B 模型达到 **90.0%** 的成功率。更具实际意义的是数据效率结果：**仅使用 60% 的训练数据**，OPID 即可达到 full-data GRPO 的性能水平。这一结果对于实际应用具有重要意义，因为 agentic 任务的数据收集通常成本较高。

**局限性**：OPID 的 skill extraction 过程**仅适用于已完成的轨迹**，这意味着在训练初期或困难任务中，当完成率很低时，该方法无法发挥作用。此外，与 SCPO 类似，OPID 目前也是**单 agent 设定**，未扩展至多 agent 协作场景。

#### 3SPO: State-Score-Supervised Policy Optimization

| 属性 | 内容 |
|------|------|
| arXiv ID | 2606.09961 |
| 发布日期 | 2026-06-08 |

3SPO 提出了一种**动态 state score** 机制，同样无需 value function 即可进行 credit assignment。与 SCPO 通过语义一致性恢复 credit 不同，3SPO 关注 state 本身的"可完成性"（completeness）评分，通过动态评估当前状态距离目标的距离来分配 credit。具体而言，3SPO 在每步基于历史成功率计算动态 state score，监督步级 credit assignment、自适应 rollout 分配和后步策略更新，无需 value function 或额外辅助模型。在 ALFWorld 上相比 GRPO 提升 **+22.6%**，WebShop 提升 **+15.6 points**，且收敛速度提升 **1.8×**。该方法与本周的 SCPO 和 OPID 形成了有趣的对比：3SPO 是"state-centric"，SCPO 是"trajectory-centric"，OPID 是"skill-centric"。**局限性**：state score 的动态计算可能在高维状态空间中不够稳定，且对初始策略的依赖性较强。

#### EGCA: Execution-Grounded Credit Assignment

| 属性 | 内容 |
|------|------|
| arXiv ID | 2603.16158 |
| 发布日期 | 2026-03-17 |
| 会议 | SPOT ICLR 2026 Workshop |

EGCA 专注于**代码生成**领域的 credit assignment，由 **Kumar Natalya 和 Gupta Shikhar** 提出，其核心创新是将代码的**执行结果**作为 credit 分配的 ground truth。针对代码生成中 GRPO 的粗粒度 credit assignment 问题——即使失败源于局部语义错误，单一 outcome 信号仍均匀散布在整个程序上——EGCA 利用执行轨迹定位更新：对满足算法约束但测试失败的程序，执行候选解与离线整理的参考解，识别最早语义分歧点，只给对应 token span 分配 advantage，同时 mask 下游 token。在 HumanEval 上达到 **82.1%** pass@1（+3.1 over GRPO），MBPP 达到 **68.9%**（+1.5）。该方法虽然针对 code generation 任务，但其"execution-grounded"的思想具有更广泛的借鉴意义：在 agentic 任务中，是否可以引入更多的外部执行验证来强化 credit 信号？EGCA 与 SCPO 的不同在于，EGCA 使用外部执行器作为裁判，而 SCPO 使用内部语义编码器。**局限性**：仅适用于可执行验证的任务类型，wall-clock 开销增加约 18%。

#### DelTA: Discriminative Token Credit Assignment

| 属性 | 内容 |
|------|------|
| arXiv ID | 2605.21467 |
| 发布日期 | 2026-05-20 |

DelTA 将 credit assignment 的粒度推进到了 **token level**，由 **Kaiyi Zhang、Wei Wu 和 Yankai Lin**（中国人民大学高瓴人工智能学院 / 蚂蚁集团）提出。其核心洞察是：策略梯度更新方向隐式地充当 token-gradient 向量上的线性判别器，标准序列级 RLVR 中正负 centroids 可能被共享高频模式（如格式化 token）主导，稀释稀疏但有判别性的方向。DelTA 估计 token 系数来放大 side-specific 的 token-gradient 方向、抑制共享/弱判别性方向，使有效 centroids 更具对比性。在 7 个数学基准上，使用 DelTA 的 Qwen3-8B 相比基线提升 **+3.26 points**，Qwen3-14B 提升 **+2.62 points**。这与本周趋势中"从 episode 到 step 再到 token"的粒度细化方向高度一致，但也引发了关于过细粒度是否会导致 credit 信号 noise 增加的讨论。**局限性**：需要训练额外的判别模型，增加了系统复杂度；token-level 的 credit 在开放域 agent 任务中的适用性尚待验证。

## 4. 技术趋势与关联分析

### 4.1 粒度细化的三阶段演进

本周的论文集中体现了一个清晰的技术演进趋势：**credit assignment 的粒度正在从 episode-level 向 step-level 再向 token-level 不断细化**。

- **Episode-level**：传统 RL 方法（如 REINFORCE）仅在 trajectory 结束时分配一次 credit，所有 intermediate steps 共享相同的 return。这在 long-horizon agentic 任务中导致了严重的 credit 延迟和混淆。
- **Step-level**：SCPO、OPID 和 3SPO 都实现了 step-level 的 credit 分配。SCPO 通过语义比较恢复每个步骤的"应有 credit"，OPID 通过 hindsight skill 识别关键步骤，3SPO 通过 state score 评估每个状态的价值。
- **Token-level**：DelTA 进一步推进到 token level，这在数学推理等需要精确 token 生成的任务中显示出潜力。

然而，粒度细化并非没有代价。更细的粒度意味着更多的 credit 决策点，也可能引入更多的 noise。目前看来，**step-level 可能是 agentic 任务中当前最优的粒度选择**——足够精细以区分有意义的 intermediate progress，又足够粗粒度以保持 credit 信号的稳定性。

### 4.2 Value-Free / Model-Free 成为共识

一个值得注意的趋势是：**value-free（无需 value function）正成为 agentic RL 中 credit assignment 方法的设计共识**。SCPO 使用冻结的交叉编码器作为语义裁判，3SPO 使用动态 state score，EGCA 使用代码执行器——三者都不需要训练额外的 value network。这一趋势的背后是对传统 value-based RL 在 long-horizon、稀疏 reward 环境中局限性的反思：value function 的估计误差会随着 horizon 长度而累积，而 agentic 任务往往涉及数十甚至上百个 steps。

OPID 虽然不完全属于 value-free（它仍然使用 advantage estimation），但其核心创新在于 advantage 的**重分配**而非 value 的**估计**，这在某种程度上也与 value-free 的精神一致。

### 4.3 从外部裁判到内部 hindsight 的演进

SCPO 和 OPID 代表了两种不同但互补的 credit 来源：

- **外部语义裁判（SCPO）**：引入一个独立的、冻结的模型作为"裁判"，从语义层面判断步骤的质量。这种方法的优势是客观性和稳定性——裁判模型不参与训练，不会因策略更新而产生 bias。但缺点是依赖成功轨迹作为参照，且裁判模型的设计需要领域知识。
- **内部 hindsight 技能（OPID）**：从策略自身生成的成功轨迹中提取 hindsight skills，作为 credit 分配的依据。这种方法的优势是自适应性和数据效率——skills 来自当前策略的 actual experience，更贴合当前策略的 capability frontier。但缺点是仅适用于已完成轨迹，在探索困难的任务中可能无法发挥作用。

这两种路线的互补性提示了一个可能的未来方向：**结合外部裁判的稳定性和内部 hindsight 的自适应性**，构建 hybrid credit assignment 框架。

### 4.4 差异化空间的显现

一个具有战略意义的观察是：**SCPO 和 OPID 的实验都未涉及 ScienceWorld 和 Odyssey 这两个 benchmark**。ScienceWorld 以其高复杂度的科学推理任务著称，Odyssey 则是一个更加开放的 agentic 环境。这两个 benchmark 的缺失可能暗示了当前方法在更复杂、更开放环境中的局限性，同时也为后续研究留下了明确的差异化空间。

   - 当前方法在不同 benchmark 上使用不同的评估指标和协议
   - 建立统一的评估框架有助于公平比较不同方法的优劣

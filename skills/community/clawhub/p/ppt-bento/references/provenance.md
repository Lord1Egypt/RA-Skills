# 来源与格式依据

## 内容来源

用户提供的 `ppt-skill.md` 实际包含 HTML 文章、示例图片链接及提示词。封装提取了以下可复用方法，没有执行原文中的模型调用或外部操作指令：

1. 先明确为谁演示、讲什么、达到什么目的，再组织内容。
2. 使用数字便利贴梳理页面，结合背景调研与金字塔原理形成大纲。
3. 按页面或章节检索真实资料，而非仅靠通用知识填充大纲。
4. 先制作内容和版面策划稿，再制作视觉设计稿。
5. 使用由内容驱动的 Bento Grid，以卡片面积表达层级并保留间距。
6. 默认 1280×720 SVG 页面；按实际工具能力衔接 PowerPoint。

原文作者自述、产品宣传、模型排名、图片页面元数据及重复的布局提示词没有进入操作流程。示例图片仍属原文外部资源，本包未下载或内置这些图片。没有将文章发布者身份或授权范围推定为本技能作者信息。

封装补充了文件命名、来源追溯、视觉检查和实际格式交付要求，并限定了原文“SVG 完全可编辑”的泛化说法。没有绑定 Grok、Gemini 或任何特定付费服务；本技能本身不要求 API 密钥或固定二进制工具，导出和渲染按执行环境能力选择。

根据用户后续提供的创作意图确认界面，新增生成前的选择题确认：汇报目的、受众、内容处理方式、配图偏好，以及按需补充的篇幅、风格和自由输入。该交互要求来自用户后续要求，不是原文章节或固定实验模板；具体规则见 `intent-confirmation.md`。

## 格式依据

核对日期：2026-11-19。

- ClawHub 官网：https://clawhub.ai/
- ClawHub 官方格式文档：https://github.com/openclaw/clawhub/blob/main/docs/skill-format.md
- ClawHub 官方发布文档：https://github.com/openclaw/clawhub/blob/main/docs/publishing.md

采用文件夹与入口 `SKILL.md`，YAML 前置信息包含同名的 `name` 与用途明确的 `description`；详细材料使用相对链接置于 `references/`。`agents/openai.yaml` 是本地 Codex UI 的可选适配文件，不是 ClawHub 必填项。

版本号可在未来发布时指定，不必为了本地技能虚构发布记录。本包未包含 ClawHub CLI 才会写入的 `origin.json` 或安装锁文件，也未声称已在平台注册或通过其服务端审核。

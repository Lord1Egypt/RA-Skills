## Description:

Helps agent users and skill authors create practical weather-style workflows, checklists, analyses, and implementation support for bug fixes, setup hardening, reliability improvements, and adjacent skills.

This skill is ready for commercial/non-commercial use.

## Use Case:

External agent users, skill authors, maintainers, and teams use this skill to turn weather-style productivity needs into local-friendly plans, templates, checklists, analyses, code changes, or decision support.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Overbroad activation wording may cause the skill to be selected for generic weather, API, or bug-fix requests.

Mitigation: Confirm the user's desired outcome and apply the workflow only when the request fits weather-style productivity, reliability, setup hardening, or adjacent skill creation work.

Risk: Generated plans, checklists, code, or configuration guidance may be incomplete or misleading for a user's environment.

Mitigation: Validate outputs against the user's stated success criteria, make assumptions visible, and list remaining risks or follow-up work.

## Description:

Classify API errors and choose the right response: retry, back off, fix the request, or escalate.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Developers and integration engineers use this guide to classify API failures and decide when to fix a request, wait, retry safely, or escalate with useful evidence.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Troubleshooting requests or responses may contain credentials, tokens, cookies, or personal data.

Mitigation: Review and redact sensitive values before sharing request or response details; include only the information needed to diagnose the failure.

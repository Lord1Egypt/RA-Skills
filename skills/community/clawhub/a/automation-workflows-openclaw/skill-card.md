### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Automation workflows can expose or modify sensitive business data through connected apps.

Mitigation: Review each connected app's permissions and test workflows with non-sensitive or test data before using live data.

Risk: Automations that send emails, post publicly, update CRM records, or change invoices and payments can create visible or financial errors if misconfigured.

Mitigation: Test each trigger and action, verify field mappings and error handling, and monitor workflow logs before relying on the automation.

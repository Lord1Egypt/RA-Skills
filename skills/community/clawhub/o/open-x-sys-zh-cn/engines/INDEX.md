# 能力引擎索引

引擎是可以被运行时自由组合的深层变换能力。它们不拥有固定顺序；当前系统缺少哪一种变化，就调用哪一种，并把产出交回同一张活动图景。

| 系统需要发生什么变化 | 读取 | 交回运行时 |
| --- | --- | --- |
| 从材料与现象中形成足以改变理解的系统认识 | [理解](understand.md) | 关键结构、机制、证据与未知 |
| 打开新的问题、解释、情景、选择或创造方向 | [探索](explore.md) | 值得继续的可能性和区分信号 |
| 让深层认识抵达人，成为完整作品 | [表达](express.md) | 对象专属、可理解、可使用的作品 |
| 研究最佳实践，填补能力鸿沟，搭建真实能力 | [实践与建造](build.md) | 有条件的实践、真实连接、验证结果与能力记录 |
| 让结果改写认识、关系、能力和未来行为 | [演化](evolve.md) | 被更新的系统与更高起点 |

需要具体方法、系统模式或高手完整路线时进入[能力资源](../capabilities/README.md)。引擎完成工作后，依据对象进入[验证](../runtime/verify.md)、[作品](../experience/works.md)或[更新](../runtime/update.md)。

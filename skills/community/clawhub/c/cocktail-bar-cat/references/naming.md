# 经典酒中文名规范与别名兼容（v2.4.1）

> ClawHub专用v2.7.3；规范为独立整理的名称事实与维护方法，采用MIT-0，完整许可见 `../LICENSE`。历史改名记录保留，不把旧版本改名冒充本次新增；名称事实不是对原来源文本、商标或店家叙事的授权。

以 `recipes.json` 的 `name` 为唯一标准中文名。酒单、销量、季节、常客、情绪映射、替代、故事、灵感、采购等引用标准名；历史名和常见异译存于 `aliases`，查询脚本从数据建立别名表，不另维护一份清单。

## 命名规则

1. 中文名不夹英文单词/拉丁缩写：Fizz→菲士、Julep→朱莉普。
2. 使用行业通行译名，不谐音直译：Daiquiri→得其利；不同历史译名保留别名。
3. 变体自然语序：黑麦古典、波本曼哈顿、脏伏特加马提尼，不用分隔符拼名字。
4. 同一 `name_en` 只留一条标准配方；维护合并时核 `spec_updated`、字段与规格差异，避免丢失有效版本。
5. `name_en` 统一 Title Case 与拼写：`Vieux Carré`、`Piña Colada`、`Dark 'n' Stormy`。

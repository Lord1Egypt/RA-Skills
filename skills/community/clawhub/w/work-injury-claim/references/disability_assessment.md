# 劳动能力鉴定参考手册

## 一、法律依据

| 法律法规 | 内容 |
|---------|------|
| 《工伤保险条例》第21-26条 | 劳动能力鉴定的基本规定 |
| 《劳动能力鉴定 职工工伤与职业病致残等级》GB/T 16180-2014 | 鉴定标准（国家标准） |
| 各省市劳动能力鉴定办法 | 地方实施细则 |

---

## 二、鉴定时机

### 2.1 基本条件
- 工伤认定决定已生效
- 伤情相对稳定
- 存在残疾、影响劳动能力

### 2.2 鉴定时间要求

| 伤情类型 | 建议鉴定时间 | 说明 |
|---------|-------------|------|
| 一般骨折 | 伤后3-6个月 | 需骨折愈合后 |
| 关节损伤 | 伤后6-12个月 | 需功能恢复稳定 |
| 神经损伤 | 伤后6-12个月 | 神经恢复周期长 |
| 颅脑损伤 | 伤后6-12个月 | 需病情稳定 |
| 烧伤 | 伤后3-6个月 | 创面愈合后 |
| 职业病 | 确诊后即可 | 无需等待 |
| 内固定未取 | 可先鉴定 | 部分地区要求取出内固定后鉴定 |

> **注意：** 过早鉴定可能导致等级偏低；过晚鉴定不影响等级但延迟待遇领取。建议在伤情稳定后尽快申请。

---

## 三、鉴定等级

### 3.1 等级划分

| 等级 | 分级标准 | 劳动能力影响 |
|------|---------|-------------|
| 一级 | 器官缺失或功能完全丧失，其他器官不能代偿 | 完全丧失劳动能力 |
| 二级 | 器官严重缺损或畸形，有严重功能障碍 | 完全丧失劳动能力 |
| 三级 | 器官严重缺损或畸形，有严重功能障碍 | 完全丧失劳动能力 |
| 四级 | 器官严重缺损或畸形，有严重功能障碍 | 大部分丧失劳动能力 |
| 五级 | 器官大部缺损或明显畸形，有较重功能障碍 | 大部分丧失劳动能力 |
| 六级 | 器官大部缺损或明显畸形，有中等功能障碍 | 部分丧失劳动能力 |
| 七级 | 器官大部分缺损或畸形，有轻度功能障碍 | 部分丧失劳动能力 |
| 八级 | 器官部分缺损，形态异常，轻度功能障碍 | 部分丧失劳动能力 |
| 九级 | 器官部分缺损，形态异常，轻度功能障碍 | 影响劳动能力 |
| 十级 | 器官部分缺损，形态异常，无功能障碍 | 影响劳动能力 |

### 3.2 常见伤情对应的鉴定等级（参考）

> **重要声明：** 以下仅为一般性参考，实际等级以劳动能力鉴定委员会的鉴定结论为准。同一伤情因严重程度、恢复情况、并发症等不同，等级可能差异较大。

#### 骨折类

| 伤情 | 可能等级范围 | 关键鉴定因素 |
|------|-------------|-------------|
| 手指骨折（末节） | 十级 | 是否影响功能 |
| 手指骨折（中节/近节） | 九级~十级 | 是否畸形愈合 |
| 掌骨骨折 | 九级~十级 | 是否影响手功能 |
| 腕骨骨折 | 八级~九级 | 是否影响腕关节功能 |
| 前臂骨折（尺/桡骨） | 八级~九级 | 是否影响旋转功能 |
| 肱骨骨折 | 八级~九级 | 是否影响肩肘功能 |
| 锁骨骨折 | 九级~十级 | 是否畸形愈合 |
| 肋骨骨折（单根） | 十级 | 无 |
| 肋骨骨折（多根） | 八级~九级 | 是否影响呼吸 |
| 脊柱骨折（无神经损伤） | 八级~九级 | 是否影响脊柱功能 |
| 脊柱骨折（伴神经损伤） | 一级~七级 | 取决于瘫痪程度 |
| 骨盆骨折 | 九级~十级 | 是否影响骨盆稳定性 |
| 股骨骨折 | 八级~九级 | 是否影响下肢功能 |
| 髌骨骨折 | 九级~十级 | 是否影响膝关节 |
| 胫腓骨骨折 | 九级~十级 | 是否影响行走 |
| 踝部骨折 | 九级~十级 | 是否影响踝关节 |
| 趾骨骨折 | 十级 | 是否影响功能 |

#### 眼耳鼻口类

| 伤情 | 可能等级范围 |
|------|-------------|
| 一眼盲目 | 七级~八级 |
| 一眼视力显著减退 | 九级~十级 |
| 双耳听力损失（≥56dB） | 九级~十级 |
| 一耳听力损失（≥91dB） | 八级 |
| 鼻骨骨折（畸形愈合） | 十级 |
| 牙齿脱落（≥2颗） | 十级 |
| 牙齿脱落（≥4颗） | 九级~十级 |

#### 皮肤瘢痕类

| 伤情 | 可能等级范围 |
|------|-------------|
| 体表瘢痕面积<1% | 不够级或十级 |
| 体表瘢痕面积1%~5% | 十级~九级 |
| 面部瘢痕（影响容貌） | 八级~十级 |
| 烧伤（浅II度面积≥5%） | 十级 |
| 烧伤（深II度面积≥2%） | 九级~十级 |

#### 内脏器官类

| 伤情 | 可能等级范围 |
|------|-------------|
| 脾脏切除（成年） | 七级~八级 |
| 脾脏部分切除 | 八级~九级 |
| 一侧肾脏切除 | 六级~七级 |
| 胃部分切除 | 七级~九级 |
| 肠部分切除 | 七级~九级 |
| 肺叶切除 | 六级~七级 |

#### 神经系统类

| 伤情 | 可能等级范围 |
|------|-------------|
| 轻度智能减退 | 七级~八级 |
| 中度智能减退 | 四级~五级 |
| 重度智能减退 | 一级~三级 |
| 癫痫（轻度） | 九级~十级 |
| 癫痫（中度） | 六级~七级 |
| 偏瘫（不完全） | 四级~六级 |
| 截瘫（不完全） | 四级~六级 |

## 四、鉴定申请流程

### 4.1 申请

| 项目 | 内容 |
|------|------|
| 申请主体 | 用人单位、工伤职工或其近亲属 |
| 受理机构 | 设区的市级劳动能力鉴定委员会 |
| 申请材料 | ①劳动能力鉴定申请表 ②工伤认定决定书 ③病历资料（含出院小结、诊断证明、影像资料） ④身份证复印件 ⑤近期免冠照片 |
| 申请时限 | 工伤认定决定生效后、伤情相对稳定时即可申请 |

### 4.2 鉴定过程

| 环节 | 说明 |
|------|------|
| 材料审核 | 鉴定委员会收到材料后审核完整性 |
| 现场鉴定 | 通知职工到指定医疗机构进行面检和功能评估 |
| 专家组评议 | 3-5名专家组成鉴定组，按GB/T 16180标准评定 |
| 出具结论 | 填写《劳动能力鉴定结论书》 |
| 送达 | 送达用人单位和职工 |

### 4.3 鉴定时限

| 环节 | 时限 |
|------|------|
| 收到申请到出具结论 | 60日 |
| 复杂案件延长 | 30日（需批准） |
| 结论送达 | 作出后20日内 |

## 五、再次鉴定与复查鉴定

### 5.1 再次鉴定（对初次鉴定不服）

| 项目 | 内容 |
|------|------|
| 申请时限 | 收到鉴定结论之日起15日内 |
| 受理机构 | 省、自治区、直辖市劳动能力鉴定委员会 |
| 效力 | 省级鉴定结论为最终结论 |
| 申请材料 | 再次鉴定申请表、初次鉴定结论、病历资料、身份证 |

### 5.2 复查鉴定（伤情变化后）

| 项目 | 内容 |
|------|------|
| 申请条件 | 自鉴定结论作出之日起1年后，伤情发生变化 |
| 申请主体 | 用人单位、工伤职工或其近亲属 |
| 受理机构 | 设区的市级劳动能力鉴定委员会 |
| 效力 | 复查结论替代原结论，按新等级享受待遇 |

### 5.3 对再次鉴定不服的救济

- 省级鉴定为最终结论，不能再申请鉴定
- 可在工伤保险待遇纠纷中，通过诉讼程序对鉴定结论提出异议
- 如有证据证明鉴定程序违法或结论明显不当，可申请重新鉴定

## 六、鉴定注意事项

### 6.1 鉴定前准备

1. **整理完整病历：** 包括门诊病历、住院病历、手术记录、出院小结、影像资料（X光/CT/MRI）
2. **保留内固定证据：** 如有内固定物，保留手术记录和影像资料
3. **功能锻炼记录：** 如进行了康复训练，保留康复记录
4. **现场鉴定准备：** 如实回答专家询问，配合功能检查，不夸大不隐瞒

### 6.2 常见鉴定误区

| 误区 | 正确理解 |
|------|---------|
| 骨折就一定有等级 | 轻微骨折（如无移位的趾骨骨折）可能不够级 |
| 取出内固定后才能鉴定 | 多数地区可在内固定存留期间鉴定，但可能影响等级 |
| 等级越低越好（数字越小等级越高） | 一级最高（最严重），十级最低（最轻） |
| 鉴定结论不可改变 | 1年后可申请复查鉴定 |
| 省级鉴定后还能再鉴定 | 省级为最终结论，不可再申请鉴定 |

## 七、生活自理障碍等级

### 7.1 三个等级

| 等级 | 标准 |
|------|------|
| 生活完全不能自理 | 进食、翻身、大小便、穿衣洗漱、自主行动五项均不能自理 |
| 生活大部分不能自理 | 五项中三项不能自理 |
| 生活部分不能自理 | 五项中一项不能自理 |

### 7.2 生活护理费计算

| 等级 | 计算标准 |
|------|---------|
| 完全不能自理 | 统筹地区上年度职工月平均工资 × 50% |
| 大部分不能自理 | 统筹地区上年度职工月平均工资 × 40% |
| 部分不能自理 | 统筹地区上年度职工月平均工资 × 30% |

> **注意：** 生活护理费按月支付，每年随社平工资调整。

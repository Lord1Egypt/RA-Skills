## v2.1.0（规划，2026-11-25）

- **场景包扩至 7 套**：新增调研报告、技术文档、PRD / 规格书、会议纪要四套检查包（原有办事指南、项目报告、长文写作）；专业版参考 16 → 20 份。有意识跨 minor，非补丁。
- **假靶心检测（Contrast Check）**：`sawdust_scan.py --check-contrast` 只标候选 + 风险提示，不替 agent 判定；免费给候选、付费给判定规则与处理（被否定的 A 必须有来源，无源则删对比或补具体指向）。
- **体检档（只检查，不改写）**：升为正式路由档位，只输出诊断清单（位置 / 原句 / 问题 / 建议），不改写、不覆盖文件；可选落盘独立 `diagnosis.md` 需用户确认。
- **正式体例豁免**：公文 / 法律 / 正式报告的对称排比不再误判为 AI 味；宣传形容词与假数字两种情况下都仍判。
- **场景路由**：SKILL.md 路由表加「文档特征 → 推荐包」一列，命中多包给叠加提示。
- **两个脚本增强**：`sawdust_scan.py` 加 `--check-contrast`、`doc_lint.py` 加 `--require-limitations`；都只加字段、保留 stdin 与既有 JSON 字段，不破坏 dianping 下游。
- **发版检查**：新增开发仓 `tools/release_check.py`（作者自用，物理上不进任何用户包）。

# NewsBot Digest

Бывший Telegram-бот NewsBot, переделанный в скилл: **один запуск = полный прогон пайплайна**.
Никакого Telegram, планировщика, polling и Google Drive. Переводы сохраняются как PDF в папке
результата, а в дайджесте стоят ссылки на эти локальные файлы.

## Пайплайн (`scripts/run_digest.py`)

1. **Сбор за 24 ч**: ~50 Telegram-каналов (snscrape), ~150 запросов Google News RSS (US / CH / RU) + 3 тематические ленты; опционально пакет `newsfeed`, если он установлен.
2. **Этап 1**: параллельно агенты по каждому источнику отбирают топ-10 → `collection/collection-<дата>.xlsx`.
3. **Этап 2**: финальный агент выбирает топ-5 (без повторов с прошлым запуском и прошлыми 5 подборками) → `selected/<дата время>.xlsx`.
4. **Статьи**: для google_news текст извлекается через **Camoufox в headless-режиме** (окно браузера не открывается), LLM проверяет на paywall; при неудаче ищется та же новость у другого издания, затем агент подбирает замену из коллекции (до 3 попыток).
5. **Перевод** на русский → Markdown → **PDF** в `<output>/<дата>/pdf/`.
6. **Заголовки-аннотации** на русском.
7. **Дайджест**: `digest.md`, `digest.html`, `result.json`, `selected.xlsx`.

LLM: Claude Sonnet через cloud.ru (`CLOUD_API`), после 3 неудачных попыток переключение на DeepSeek (`API_DEEPSEEK`). Нужен хотя бы один ключ.

## Как запускать

### 1. Подготовка (один раз в окружении)

```bash
SKILL_DIR="<путь к этому скиллу>"
pip install -r "$SKILL_DIR/requirements.txt"      # в Cowork-облаке добавь --break-system-packages
python -m camoufox fetch                            # скачать браузер Camoufox
```

Ключи: файл `.env` (образец — `.env.example`) в `--workdir`, в папке скилла или в текущей папке, либо
переменные окружения. Если ключей нет, спроси их у пользователя и не выводи их в чат.

### 2. Выбор папок

- `--workdir` — **постоянная** папка состояния (история `collection/`, `selected/`, переводы, логи). От неё зависит дедупликация с прошлыми днями, поэтому каждый день используй одну и ту же папку. Подойдёт подключённая папка пользователя, например `<папка>/newsbot_data`; по умолчанию `./newsbot_data` или `$NEWSBOT_WORKDIR`.
- `--output-dir` — куда положить результат дня. По умолчанию `<workdir>/outputs`. Если результат должен сразу появиться у пользователя, укажи папку для выходных файлов агента (в Cowork это `/mnt/user-data/outputs/newsbot`).

### 3. Запуск

Полный прогон длится десятки минут (сотни RSS-запросов, несколько агентов, браузер), поэтому запускай его в фоне
и следи за `status.json`:

```bash
cd "$SKILL_DIR"
nohup python scripts/run_digest.py --workdir "$WORKDIR" --output-dir "$OUTDIR" > "$WORKDIR/run.log" 2>&1 &
```

Затем раз в 2–5 минут проверяй `"$OUTDIR/$(date +%F)/status.json"`: поле `current` показывает текущий этап,
а `done: true` значит, что прогон закончен. При коротких лимитах на выполнение команд используй именно этот режим.
Код возврата: `0` — успех, `1` — ошибка пайплайна, `2` — нет ключей.

Опции: `--browser virtual` (Camoufox через Xvfb, тоже без окна; помогает, если сайты режут headless),
`--skip-telegram`, `--skip-google`, `--env путь/к/.env`.

### 4. Что вернуть пользователю

Прочитай `result.json`:

- `digest_md`: готовый текст дайджеста (формат прежнего поста «Новости | дата»: 1️⃣ … заголовок, «🔗 Оригинал | 📄 Перевод»);
- `items[]`: `title`, `source`, `original_url` и `translation_pdf` (абсолютный путь к PDF или `null`);
- `pdf_dir`, `selected_xlsx`, `digest_html`.

Покажи пользователю дайджест текстом. Ссылки «📄 Перевод» веди на PDF из папки результата: если результат лежит
в папке выходных файлов, файлы уже доставлены; иначе отправь PDF через доставку файлов или скопируй их в подключённую
папку пользователя. В `digest.md` и `digest.html` ссылки относительные (`pdf/google_news_<id>.pdf`), поэтому папку
дня можно переносить целиком.

Если в `status.json` есть этапы с `error`, коротко скажи пользователю, что не сработало (например, нет доступа к
news.google.com или t.me из окружения). Подробности смотри в `<workdir>/logs/<дата>.log`.

## Сетевые требования

Окружению нужен доступ к `news.google.com`, `t.me`, сайтам изданий, `foundation-models.api.cloud.ru` и/или
`api.deepseek.com`, а для `camoufox fetch` — к GitHub. Если домены закрыты, запуск упадёт на соответствующем этапе.
Тогда скажи пользователю, какие домены нужно разрешить.

## Структура

```
newsbot-digest/
├── SKILL.md
├── requirements.txt
├── .env.example
├── prompts/                  # промпты агентов (без изменений из legacy)
└── scripts/
    ├── run_digest.py         # точка входа: один полный прогон
    └── newsbot/
        ├── config.py         # пути запуска, .env, логгер, LLM, status.json
        ├── utils.py          # JSON из ответа LLM, web_search, ретраи
        ├── collect.py        # Telegram + Google News (+ newsfeed)
        ├── selection.py      # агенты этапов 1–2 и агент замены
        ├── articles.py       # Camoufox headless, проверка paywall, перевод, PDF, заголовки
        └── digest.py         # digest.md / digest.html / result.json
```

## Description:

Generates AI action figure toy packaging images from text prompts using the Neta AI image generation API.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and developers use this skill to generate collectible action figure toy packaging images from text prompts, optionally with output size and reference-image settings.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill requires a Neta API token and server security evidence flags unsafe and inconsistent token handling.

Mitigation: Review before installing, use only non-sensitive prompts and image references, prefer a pinned or trusted installer path, and avoid placing a real token directly on the command line until safer secret handling is supported.

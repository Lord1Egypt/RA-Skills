# 真实实测：从素材写一份设备借用 FAQ

> **示例数据。** 流程与待填项均为示例占位，不可作为真实办理依据。本例只展示免费版四检查器：`sawdust_scan` / `sentence_load` / `rhythm_scan` / `doc_lint`。

## 输入素材（示例）

- 读者：第一次借内部设备的同事。
- 已确认步骤：提交申请 → 负责人确认 → 领取 → 归还并登记。
- 未确认：申请入口、审批时限、领取地点、外包是否可借。
- 目的：按顺序办完，并看清哪些必须再问管理员。

## 写作决策

按说明类结构组织；未提供的入口与时限不猜测，写成「待核实」或 `【待填】`。核心句放在文首。成稿里曾把分号改成句号，避免 `doc_lint` 分号密度告警。

2. 等负责人确认后再领取。
3. 领取时核对配件并登记状态。

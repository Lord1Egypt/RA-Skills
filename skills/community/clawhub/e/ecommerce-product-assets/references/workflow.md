# Ecommerce product assets

The frame list is free. Default rows: square main (product fills the frame), 3:4 material close-up, 3:4 scale, 3:4 in use, then the clip.

Upload the product photo. Every still is `beatra.images.transform` from that photo or from the accepted main image. `beatra.images.generate` is only the main image when no photo exists, and the delivery says so. One `beatra.images.edit` restores a product a still changed.

A category read is one execute of `social.douyin.video.search` or `social.xiaohongshu.note.search`, with `schema_hash` from `tools.get`. It chooses framing. It is not this store's sales.

Voice from `beatra.voices.list`, one selling line, one light instrumental bed. The clip is `beatra.videos.animate` from the main image, line as `driving_audio`, under fifteen seconds. Compose with `keep_audio` true, bed `volume` 0.25, canvas `9:16`.

## Worked set

A glass pour-over dripper, photo supplied. Main on white, close-up of the ribs, a hand for scale, the dripper on a morning table. Eight-second line, light bed, one 9:16 clip from the main image.

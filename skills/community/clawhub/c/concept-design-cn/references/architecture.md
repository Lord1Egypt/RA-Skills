# 工程架构

规则语义沿用 Meng 与 Jackson。新项目默认同进程多模块单体，采用语言原生源码布局。变更下列边界须显式确认并记录范围。

## 目录与命名

```text
<源码根>/
  entry/<业务模块>/                 # 入站协议与出站适配器
  compositions/<业务分组>/
    SYNCS.md
    <动作>UseCase                  # 公开入口规则
    <动作>On<事件>                 # 后续事件规则
  concepts/<概念名>/                # 每个概念独占源码包或模块
    CONCEPT.md
    api/                           # 公开命令、查询和值类型
    application/                   # 动作、查询实现及内部端口
    domain/                        # 状态、不变量、领域行为、仓储契约
    adapters/                      # 端口实现、持久化、概念装配
  bootstrap/                       # 最终装配与启动
```

- 固定层名。业务目录用小写单数，组合分组与规格目录同名，同一业务范围沿用词根。Java 包名复合词连写，如 `operatorsession`。类型主体用单数，列表动作和集合变量按语义用复数，如 `ReadBookingsUseCase`、`bookings`。
- 组合分组内不再套领域分层。规则可共用源码模块或构建单元。函数式实现保留同等角色与可见性。
- Java/Spring 按需显式装配，分别在 `adapters/`、组合分组、`bootstrap/` 放置 `<Concept>Configuration`、`<BusinessScope>Configuration`、`<Application>Configuration`。在使用方边界用 `<Capability>Properties` 绑定配置。其他语言采用原生等价形式。

## 分层职责与依赖

- **入站适配器 → 公开的 `<动作>UseCase` → 概念 API。** 入口负责协议解析、格式校验、可信上下文和响应转换。纯转发 Facade 并入用例入口。出站适配器实现组合端口。
- **概念独立。** 各自拥有状态与不变量。禁止概念互依、互调、互读，以及依赖入口、组合或最终装配。外部身份用类型参数或不透明 ID。
- **概念内部。** `api`、`domain` 不依赖其他层。 `application` 依赖 `api`、`domain` 与内部端口。 `adapters` 实现端口，仓储存取聚合，查询端口读取投影。每项职责一个端口。
- **组合负责协调。** 只经概念 API 访问概念，依赖所需内向端口，禁止依赖入口或最终装配。业务分支、授权复核、事务和失败策略留在规则中。辅助组件只复用计算或执行机制，不反调规则。组合可保留执行记录，概念业务事实由概念持有。
- **技术边界。** 业务契约及 `api/application/domain` 隔离协议、框架和持久化类型。仅装配代码构造与注入组件，业务代码不查容器。技术库不依赖或协调业务。

## 同步边界

入站适配器建立或传递根动作完成记录及其 flow。每条同步规则对应一个具名实现。每个公开用例实现一条入口规则。规则按 `when` 匹配完成记录、按可选的 `where` 求值、按 `then` 调用动作。同事务后续规则可用内部方法。跨入口复用、独立调度或独立恢复的规则用 `<动作>On<事件>`。后续规则按各自匹配的完成记录触发。事务、因果、原子认领及恢复遵循契约和[执行与恢复](execution.md)。

## 规格归属

规格与实现相邻。未建模块时，放在 `docs/prd/` 下对应的 `concepts/<概念名>/` 或 `compositions/<业务分组>/`。总体 PRD 索引权威规格，验收关联契约或场景。已确认位置的迁移须经授权。

实例、类型绑定与共用入口契约各声明一次，重复 include 仍指向同一实例。`SYNCS.md` 逐条映射到用例、内部方法或事件处理入口。规格、测试和运行记录使用同一规则身份，迁移保留持久身份及触发、事务、失败和重试语义。`// flow:` 仅用于文档分组。

## 审查与验证

常规检查或 CI 覆盖实际源码、构建单元与配置。核对目录、命名、模块发现、规则映射和依赖图，检查可见性、环、类型泄漏及适配器装配。违规报位置并失败，漏检或未解析依赖记为缺口。行为测试覆盖触发、事务、失败、重试与并发。

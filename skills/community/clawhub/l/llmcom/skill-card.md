## Description:

Compress prompts for Claude Code and Cursor CLI by removing filler words, abbreviating common terms, and formatting prompts as compact pipe-separated task strings.

This skill is ready for commercial/non-commercial use.

## Publisher:

[shalinda-j](https://clawhub.ai/user/shalinda-j)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agent users use this skill to manually rewrite longer prompts into shorter prompts for Claude Code, Cursor agents, or LLM APIs. It is useful when token efficiency matters and the user can review the compressed prompt before sending it.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Compressed prompts may lose nuance or change the user's intended meaning.

Mitigation: Review each compressed prompt before sending it to an agent or LLM API.

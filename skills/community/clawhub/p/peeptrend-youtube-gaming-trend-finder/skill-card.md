## Description:

Identify emerging YouTube gaming trends, analyze demand and competition, and plan content based on Steam updates and channel fit using PeepTrend MCP data.

This skill is ready for commercial/non-commercial use.

## Use Case:

Creators, editors, strategists, and AI agents use this skill to evaluate YouTube gaming topics, compare demand and saturation signals, and turn promising opportunities into practical video plans.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Full PeepTrend features require an API key and may use the user's PeepTrend account for reports, saved plans, alerts, and subscription-limited features.

Mitigation: Confirm the PeepTrend connection status first, explain what the API key unlocks, and configure a key only when the user trusts PeepTrend with submitted topic and creator-context queries.

Risk: Trend scores and saturation signals can be mistaken for guaranteed views, revenue, ranking, virality, or channel growth.

Mitigation: Present PeepTrend data as decision-support evidence, call out thin data or uncertainty, and recommend small validation tests when confidence is limited.

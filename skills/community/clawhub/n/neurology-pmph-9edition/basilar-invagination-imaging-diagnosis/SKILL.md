# 颅底凹陷症影像学测量与确诊

## 适用场景
- 患者出现枕骨大孔区综合征症状，需确诊颅底凹陷症。
- 需评估是否合并扁平颅底及其他颅颈区继发畸形。
- 已获取头颅正侧位X线片、CT或MRI影像。

## 核心测量与诊断流程

### 1. 腭枕线（Chamberlain line）测量与颅底凹陷症诊断
1. 在头颅侧位X线片或矢状位MRI/CT上，定位**硬腭后缘**与**枕骨大孔后缘**。
2. 绘制腭枕线：连接硬腭后缘至枕骨大孔后缘的直线。
3. 测量枢椎齿状突位置：计算齿状突尖端高出腭枕线的垂直距离（`odontoid_protrusion`）。
4. 判定诊断阈值：
   - `odontoid_protrusion` > 3mm：确诊为**颅底凹陷症**。
   - `odontoid_protrusion` ≤ 3mm：判定为**可疑颅底凹陷症**，需结合临床症状或进一步行MRI检查。

### 2. 颅底角（Basal angle）测量与扁平颅底诊断
1. 定位三个关键点：**鼻根**、**蝶鞍中心**、**枕骨大孔前缘**。
2. 绘制两条连线：
   - A线：鼻根至蝶鞍中心的连线。
   - B线：蝶鞍中心至枕骨大孔前缘的连线。
3. 测量A线与B线形成的夹角（`basal_angle`）。
4. 判定诊断阈值：
   - 正常范围：109° ~ 145°（平均132°）。
   - `basal_angle` > 145°：确诊为**扁平颅底**（常与颅底凹陷症合并发生）。

### 3. 合并畸形评估（结合MRI/CT）
检查并确认是否合并以下继发异常：
- 小脑扁桃体下疝畸形（Chiari畸形）
- 中脑导水管狭窄
- 延髓或脊髓空洞症
- 脑室扩大或脑积水

## 输出结论
根据测量结果输出确诊结论（颅底凹陷症 / 可疑颅底凹陷症 / 扁平颅底），并列出合并畸形提示，作为后续手术干预的依据。

## 注意事项
- 若影像图像质量不佳或无典型影像学测量条件，需谨慎测量并建议重新获取高质量影像。

## Description:

Helps teams add useful unit tests and improve test coverage in existing codebases through a repeatable workflow, checklists, implementation support, and validation guidance.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, software maintainers, QA engineers, open-source contributors, and product teams use this skill to plan, add, and validate unit tests for existing codebases. It is intended for practical coverage improvement work where assumptions, constraints, verification commands, and remaining risks should be visible.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad trigger keywords and implicit invocation may cause the skill to activate more often than expected.

Mitigation: Confirm that the user is asking for unit testing, coverage, regression, or software quality support before applying the workflow.

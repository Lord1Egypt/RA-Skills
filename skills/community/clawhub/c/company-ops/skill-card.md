## Known Risks and Mitigations:

Risk: The release is flagged as suspicious because it is a real autonomous operations loop that can persist broad agent rules and publish repository changes automatically.

Mitigation: Review the script and run it first in a sandbox or private test repository before installing it in an active workspace.

Risk: The setup guidance includes raw main-branch script retrieval and treats the help command as a quick-start check.

Mitigation: Pin or inspect the downloaded script before execution, and do not rely on a help command alone as a harmless validation.

Risk: The loop can run automatic git add, commit, and push operations.

Mitigation: Disable automatic publishing until path allowlists, secret checks, and human review gates are added.

Risk: The constitution asks users to place broad operating rules into agent policy or persistent memory locations.

Mitigation: Only install the constitution into scoped project policies when persistent cross-agent behavior is intentional.

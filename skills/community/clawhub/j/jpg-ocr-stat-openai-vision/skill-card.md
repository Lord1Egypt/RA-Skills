## Use Case:

Developers and engineers use this skill to analyze images, extract text, compare multiple images, and summarize sequential frames with OpenAI vision-capable GPT models.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Selected images are sent to OpenAI for analysis and may contain sensitive visual or text content.

Mitigation: Use the skill only when your organization permits sending the selected images to OpenAI, and avoid private documents, IDs, screenshots, regulated data, and confidential business images unless approved.

Risk: Batch output files can contain extracted text, image descriptions, and other sensitive analysis results.

Mitigation: Store generated analysis files as sensitive data and apply the same access controls and retention practices used for the source images.

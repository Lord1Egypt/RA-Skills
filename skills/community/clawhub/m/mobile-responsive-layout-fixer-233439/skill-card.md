## Description:

Helps teams plan, implement, and verify mobile responsive layout fixes for navigation, cross-device UI behavior, and frontend usability issues.

This skill is ready for commercial/non-commercial use.

## Use Case:

Frontend developers, designers, startup teams, and maintainers use this skill to turn mobile responsiveness, navigation layout, and cross-device UI requests into practical workflows, checklists, implementation support, and verification notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill has broad activation wording and may trigger on general frontend or layout requests.

Mitigation: Invoke it explicitly with $mobile-responsive-layout-fixer when responsive-layout workflow support is intended.

Risk: Responsive layout recommendations can be incomplete without the target viewport, design constraints, or affected code.

Mitigation: Review assumptions and validate the resulting layout changes against the stated success criteria on mobile and desktop.

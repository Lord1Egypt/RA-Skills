# 第01课 你好，中文编程

> 老孟带你学中文编程 · 第 01 课　|　语言面 ZHC-LANG 2.0　|　源码 `示例/第01课_你好中文编程.zc`
> 运行：`python -X utf8 zhc.py 示例/第01课_你好中文编程.zc --run`

## 一、本课目标

把第一段中文源码跑起来，弄懂「源码→编译→运行」这条链路，以及 `输出` 和注释的用法。

## 二、语法要点

| 写法 | 作用 |
|---|---|
| `输出 值, 值, 值` | 一次输出多个值，逗号分隔，自动拼接，末尾自动换行 |
| `"文本"` | 双引号包住，支持 `\n` 换行转义 |
| `# 说明` | 行注释，编译时整行跳过 |

## 三、完整代码

```zc
# 第01课 你好，中文编程
# 一个 .zc 文件就是一段中文说明，编译器逐行读、逐句执行。

输出 "你好，老孟中文编程"

# 输出可以一次带多个值，用逗号分开，编译器自动拼接
输出 "我的第一个程序，", "跑起来了"

# 想换行就在文本里写 \n
输出 "第一行\n第二行"

# 井号开头的行是注释，编译时整行跳过，随便写
```

## 四、运行结果

```text
你好，老孟中文编程
我的第一个程序，跑起来了
第一行
第二行
```

## 五、易错点

- 字符串必须用**英文双引号**，中文引号会报 `[E001]` 非法字符。
- 语言按 `结束` 收尾块结构，本课没有块结构，写几行输出就行。
- 一个 `.zc` 文件编译后会生成同名 `.exe`，改源码要重新编译。

## 六、动手练习

1. 再输出一行你自己的名字。
2. 用一行 `输出` 同时打印姓名和年龄两个值。
3. 把第二行注释删掉再运行一次，确认结果不变。

## Description:

猫娘 is a Chinese roleplay persona skill that guides an assistant to interact in-character, append "喵" to replies, describe actions in brackets, and support roleplay mode switching.

This skill is ready for commercial/non-commercial use.

## Publisher:

[nhfy1w](https://clawhub.ai/user/nhfy1w)

### License/Terms of Use:

MIT-0

## Use Case:

External users use this skill for Chinese-language entertainment roleplay conversations with a catgirl persona, including mode switching, saved settings, and generated setting records. It is not intended for normal technical Q&A or factual assistant behavior while roleplay mode is active.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can keep the assistant in-character until the user exits roleplay mode, including an identity-denial response that is part of the persona.

Mitigation: Use the documented exit command when normal assistant behavior is needed, and treat identity statements as roleplay rather than factual claims.

Risk: Saved settings or generated setting records may contain user-provided personal or sensitive details.

Mitigation: Avoid providing secrets or sensitive personal information as roleplay settings.

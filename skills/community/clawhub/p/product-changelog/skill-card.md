## Use Case:

Product teams, marketers, developers, and support teams use this skill to turn product changes into user-facing changelogs, release notes, feature announcements, and update snippets with clear categories, benefits, visuals, and distribution guidance.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The Quick Start uses a remote shell installer for the Inference.sh CLI.

Mitigation: Use the writing guidance without running the Quick Start, or manually download a version-pinned CLI package and verify its checksum before execution.

Risk: Related skill installation commands are unpinned and may install different content over time.

Mitigation: Pin related skill versions or review the resolved skill contents before installation.

Risk: CLI examples can send prompts, screenshots, or product context to external services.

Mitigation: Review inputs for sensitive product or customer data before running external CLI app commands.

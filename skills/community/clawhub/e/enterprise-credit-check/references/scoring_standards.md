# 评分标准

## 一、权重分配

| 维度 | 权重 | 数据源 | 说明 |
|------|------|--------|------|
| 人行征信 | 40% | 征信中心 | 最权威信用记录 |
| 经营状态 | 25% | 信用公示系统 | 经营异常、失信名单 |
| 司法执行 | 20% | 执行信息公开网 | 失信被执行、限高 |
| 行政处罚 | 10% | 信用公示系统 | 行政处罚记录 |
| 诉讼记录 | 5% | 裁判文书网 | 诉讼数量、类型 |

## 二、评分公式

```
综合评分 = 人行征信分×40% + 经营状态分×25% + 司法执行分×20% + 行政处罚分×10% + 诉讼记录分×5%
```

## 三、各维度评分细则

### 人行征信（40%）

**基础评分**：
- 评级正常：100分
- 评级关注：60分
- 评级次级/可疑/损失：0分（硬终止）

**逾期调整**：
- 无逾期记录：不调整
- 逾期30天内≤2次：-20分
- 逾期30天内>2次：-40分
- 逾期60天以上：0分（硬终止）

**计算公式**：
```
人行征信分 = min(100, 基础分 + 逾期调整)
```

### 经营状态（25%）

| 状态 | 基础分 | 调整 |
|------|--------|------|
| 存续、无异常 | 100分 | - |
| 年报未报（首次） | 90分 | -10 |
| 经营异常（已移出） | 70分 | -30 |
| 经营异常（未移出） | 40分 | -60 |
| 严重违法失信 | 0分 | 硬终止 |

### 司法执行（20%）

| 状态 | 基础分 | 调整 |
|------|--------|------|
| 无记录 | 100分 | - |
| 被执行人（已结案） | 90分 | -10 |
| 被执行人（未结案，金额<50万） | 70分 | -30 |
| 被执行人（未结案，金额≥50万） | 50分 | -50 |
| 限制高消费 | 40分 | -60 |
| 失信被执行人 | 0分 | 硬终止 |

### 行政处罚（10%）

| 状态 | 基础分 | 调整 |
|------|--------|------|
| 无处罚 | 100分 | - |
| 轻微处罚（罚款<10万） | 70分 | -30 |
| 一般处罚（10万≤罚款<100万） | 50分 | -50 |
| 重大处罚（罚款≥100万） | 0分 | 硬终止 |

### 诉讼记录（5%）

| 状态 | 基础分 | 调整 |
|------|--------|------|
| 无诉讼 | 100分 | - |
| 少量诉讼（1-5件，均已结案） | 90分 | -10 |
| 中等诉讼（6-10件） | 70分 | -30 |
| 批量诉讼（>10件） | 50分 | -50 |
| 知识产权纠纷 | 0分 | 硬终止 |

## 四、评分示例

### 示例1：优质企业
```
- 人行征信：评级正常，无逾期 → 100分
- 经营状态：存续，无异常 → 100分
- 司法执行：无记录 → 100分
- 行政处罚：无处罚 → 100分
- 诉讼记录：1起劳动争议已结案 → 90分

综合评分 = 100×40% + 100×25% + 100×20% + 100×10% + 90×5% = 99.5分
风险等级：🟢 低风险（80-100分）
```

### 示例2：一般企业
```
- 人行征信：评级正常，逾期30天内1次 → 80分
- 经营状态：存续，经营异常已移出 → 70分
- 司法执行：被执行人已结案 → 90分
- 行政处罚：无处罚 → 100分
- 诉讼记录：3起合同纠纷已结案 → 90分

综合评分 = 80×40% + 70×25% + 90×20% + 100×10% + 90×5% = 82分
风险等级：🟢 低风险（80-100分）
```

### 示例3：风险企业
```
- 人行征信：评级关注 → 60分
- 经营状态：经营异常未移出 → 40分
- 司法执行：被执行人未结案，金额30万 → 70分
- 行政处罚：轻微处罚（罚款5万） → 70分
- 诉讼记录：8起诉讼 → 70分

综合评分 = 60×40% + 40×25% + 70×20% + 70×10% + 70×5% = 57.5分
风险等级：🟠 较高风险（40-59分）
```

## 五、评分精度

- 各维度评分保留整数
- 综合评分保留一位小数
- 最终评分四舍五入

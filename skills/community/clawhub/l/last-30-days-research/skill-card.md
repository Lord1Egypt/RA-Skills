## Description:

Searches Reddit, X/Twitter, and the broader web for recent opinions, sentiment, and signals about a topic, then produces a structured report with consensus findings, pain points, positive signals, contrarian takes, source links, and signal confidence.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users, developers, researchers, and product teams use this skill to gather recent public sentiment about a product, tool, trend, company, event, or feature across community and web sources.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill depends on public web and community search results, so findings can be incomplete, stale, unavailable, or skewed by platform access limitations.

Mitigation: Review cited source links, check that the requested date window was applied, and treat the signal confidence rating as part of the output rather than as a guarantee.

Risk: The skill is intended to use public sources and does not need private accounts, local files, credentials, or persistent memory.

Mitigation: Run it without granting access to private accounts, local files, credentials, or persistent memory unless a separate review approves that expanded access.

## Use Case:

External users can use this skill for Chinese-language companion roleplay, daily check-ins, light emotional support, and affectionate conversational interaction.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The persona encourages remembering preferences, routines, and recent goals, which can expose sensitive personal details if persistent memory is enabled.

Mitigation: Avoid sharing sensitive personal details with the persona and review or disable persistent memory settings before use.

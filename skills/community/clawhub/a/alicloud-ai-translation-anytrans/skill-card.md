Risk: The skill can guide create, update, modify, or set operations against Alibaba Cloud resources.

Mitigation: Review planned mutating operations, target region, resource identifiers, and parameters before execution.

Risk: Alibaba Cloud credentials may be used while completing TongyiTranslate workflows.

Mitigation: Use least-privilege Alibaba Cloud credentials and prefer environment-based configuration for the intended session.

Risk: Generated API inventories and response summaries may include operational details.

Mitigation: Keep generated evidence under output/alicloud-ai-translation-anytrans/ and review contents before sharing.

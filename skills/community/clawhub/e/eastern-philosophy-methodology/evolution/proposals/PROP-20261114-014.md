## 变更内容

### GZ-13　忤合自度
- name: 忤合自度
- source_text: "夫忤合之道，己必自度材能知睿，量长短远近孰不知。乃可以进，乃可以退，乃可以纵，乃可以横。"
- source_location: 《鬼谷子·忤合第六》
- 要义：结盟或背离（忤合）的抉择以自审为前置——先自度材能、量长短远近；己方定位不清，则合不可进、忤不可退。

### GZ-14　量权
- name: 量权
- source_text: "何谓量权？曰：度于大小，谋于众寡；称货财有无之数，料人民多少、饶乏，有余不足几何？辨地形之险易，孰利孰害？谋虑孰长孰短？"
- source_location: 《鬼谷子·揣篇第七》
- 要义：对对手的评估须做结构化的实力盘点（量权）——大小、众寡、财货、人力、地形、谋虑诸维度逐项过秤；量权（客观实力盘点）与揣情（情绪状态读取）构成完整评估。

### GZ-15　成事五途
- name: 成事五途
- source_text: "圣人所以能成其事者有五：有以阳德之者，有以阴贼之者，有以信诚之者，有以蔽匿之者，有以平素之者。"
- source_location: 《鬼谷子·决篇第十一》
- 要义：成事的手段是一条光谱而非正邪二元——阳德、阴贼、信诚、蔽匿、平素五途各有其用；手段空间宽于"光明正大/阴谋诡计"的二元对立，择途以成事为准。

### GZ-16　养志
- name: 养志
- source_text: "欲多则心散，心散则志衰，志衰则思不达。"
- source_location: 《鬼谷子·本经阴符七术·养志法灵龟》
- 要义：欲多则心散、心散则志衰、志衰则思不达——目标与欲望的收敛度直接决定思考穿透力；养志即裁减欲求以恢复思达。

### GZ-17　实意
- name: 实意
- source_text: "实意者，气之虑也。心欲安静，虑欲深远。心安静则神明荣，虑深远则计谋成。"
- source_location: 《鬼谷子·本经阴符七术·实意法螣蛇》
- 要义：计谋成立的心智前提是"安静 + 深远"——心安静则神明荣（判断清明），虑深远则计谋成；先安定心智，后出计谋。

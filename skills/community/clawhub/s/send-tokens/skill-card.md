## Description:

Helps an agent send or transfer native tokens and custom tokens to wallet addresses on supported EVM chains or Solana.

This skill is ready for commercial/non-commercial use.

## Use Case:

External wallet users use this skill to check authentication and balances, confirm transfer details, and initiate supported EVM or Solana token transfers.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can help initiate irreversible blockchain token transfers.

Mitigation: Confirm the recipient address, chain, token, and amount with the human before executing any transfer.

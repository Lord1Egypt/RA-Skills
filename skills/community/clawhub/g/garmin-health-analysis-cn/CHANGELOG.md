# 更新日志

## v1.1.1（2026-11-24）

### 🐛 修复：令牌生成与复用的服务器区域不一致

- **问题**：`garmin_auth.py login` 的区域（`is_cn`）由 CLI `--cn` / config.json 决定，而 `get_client()`（所有数据脚本共用）复用令牌时只读 config.json 的 `is_cn`。若用 `--cn` 登录但没有 config.json（或 config 的 `is_cn` 与登录区域不符），会用国际服务器恢复佳明中国签发的令牌，导致所有脚本报"Not authenticated"且重新登录也无法修复
- **修复**：登录成功后把实际使用的区域持久化到令牌目录下的 `meta.json`；`get_client()` 统一通过 `resolve_is_cn()` 解析区域（优先级：`meta.json` > 环境变量 `GARMIN_IS_CN` > `config.json` 回退），确保"令牌由哪个域签发，复用时就连接哪个域"
- **增强**：令牌失效时，若 `config.json` 存有账号密码，`get_client()` 自动尝试重新登录一次并刷新令牌；`status` 命令现显示令牌复用所用的服务器区域
- 文档同步更新：SKILL.md / README.md 说明区域一致性保证与新的排查步骤
- 旧版令牌（无 `meta.json`）自动回退到原有解析方式，升级后无需强制重新登录；建议重新登录一次以生成 `meta.json`

- 各图表新增自动解读 note：睡眠评分/身体电量水平/HRV 趋势按数据自动选择提示色与文案
- SKILL.md 新增「统一报告样式（report_style.py）」章节，明确所有 HTML 输出（含 AI 自行生成的比赛分析页面）必须采用该样式规范，并禁止外部依赖

## v1.0.0（2026-11-11）

### 首个发布版本

**作者**：Earthaveeman

### 🇨🇳 中国大陆适配

- 登录时支持连接佳明中国服务器（connect.garmin.cn），配置文件新增 `is_cn` 选项，命令行新增 `--cn` 参数
- 文档中的登录说明与脚本中的中国大陆功能保持一致

### 📝 文档全面中文化

- README.md、SKILL.md、CHANGELOG.md、install.sh 提示信息，以及 references/ 下全部说明文档均已改为中文
- 包含完整的安装指南、指标解读指南、接口参考与进阶功能说明

### 🏃 面向跑者优化

- 全部示例改为跑步场景（如"帮我分析一下上周的比赛数据"、"帮我分析一下最近的身体状况"）
- 用例与可视化建议围绕配速、心率区间、步频、海拔曲线等跑者常用分析维度展开

### ⚡ 核心功能

- **自然语言查询**：从佳明 Connect 获取 20 余项健康指标（睡眠阶段、身体电量、心率变异性、最大摄氧量、训练准备度、身体成分、血氧等）
- **睡眠分析**：睡眠时长、睡眠阶段（浅睡/深睡/快速眼动）、睡眠评分、趋势变化
- **恢复追踪**：身体电量、心率变异性、训练准备度、压力水平
- **跑步数据分析**：活动记录、卡路里、配速、海拔、步频
- **活动文件分析**：下载并解析 FIT/GPX/TCX 文件，支持按距离或时间点查询配速、心率、海拔
- **按时间点查询**：查询指定时间的心率、压力、身体电量、步数
- **交互式图表**：基于 Chart.js 的 HTML 仪表盘（睡眠、身体电量、心率变异性、活动汇总）
- **健康分析框架**：有科学依据的指标解读与建议（详见 `references/health_analysis.md`）

### ⚙️ 配置方式

- 支持本地 config.json（推荐中国大陆账户将 `is_cn` 设为 `true`）
- 支持环境变量（`GARMIN_EMAIL`、`GARMIN_PASSWORD`）
- 支持命令行参数登录
- 会话令牌保存在本地并自动刷新

### 🔒 隐私与安全

- 账号信息仅保存在本地，仅连接佳明官方服务器
- 删除令牌文件即可随时撤销授权

# LLM Watcher — 模型变化追踪器

## 它解决什么

每次厂商发新版、或者服务器吃紧，都会有人觉得模型变笨了。但没人能证明——手上只有手感、延迟、和一种说不清的口癖。

这个技能只做一件事：**同一批题，定期重跑，比数字。**

## 什么时候用它

```
「这个模型是不是变笨了」
「新版本和旧版本比，掉了吗」
「我想给现在的模型留个基线」
「我怀疑今天比上周差」
```

## 它只测什么

**只测能客观检验的东西。** 不依赖模型给自己打分。

| 检验类型 | 怎么判 |
|---|---|
| `python` | 把输出当代码真跑一遍，过 assert |
| `json` | 解析并核对键值 |
| `regex` | 正则计数 |
| `contains` | 含指定词 |
| `exact` | 完全相等 |

**它不测「写得好不好」。** 实测：同一道题，模型每次写的东西有三分之二不一样。写得不一样，不等于写得差，那个测不了。

## 它记录哪两个指标

```
通过率     有检验的题，过了几个
字数       输出有多长
```

依据：实测同一模型反复跑，**13 道题的字数完全不动，只有一道有 ±13 字摆动**。所以字数掉 30% 不是噪声。

## Quick Start

```bash
python watch.py init        # 没有题库时，生成一份样例
python watch.py run         # 跑一轮，存快照
python watch.py compare     # 和上一次比
python watch.py list        # 看历史
```

**第一次用，直接跑 `run` 就行——包里已经带了一套校准过的 14 题题库。**

## 自带题库是什么

包里 `tasks.json` 是实测校准过的 14 道题，覆盖六个面：

```
精确算术     arith1, percent
写代码       fib, rev, is_pal, dedupe   ← 真跑 assert，不是看像不像
结构化输出   json1, json2
列表格式     list10, steps5
约束遵循     limit, no_explain, case
翻译         translate
```

**每题都实测过「同一模型跑 3 次，3/3 通过」。** 所以它们是基线，不是噪声。

`baseline_chars.json` 里是每题实测的字数区间，可以拿来对照。

## 自己出题

包里还有 `calibrate.py`。它从题库池里跑一遍，**只留下 3/3 通过的，删掉会掉的**。

```bash
python calibrate.py --model qwen-plus --n 3 --out tasks.json
```

**出题的难度标准只有一个：基线模型 100% 通过，稍微降级就掉一个。**

题太简单，两个模型都能过，测不出区别。
题太难，基线就过不了，没法当基线。

## 判定规则

```
通过率掉了            → 退化
通过率升了            → 变好
字数变了 25% 以上     → 长度变
其余                  → 没变
```

25% 是实测定的：字数自然变异接近 0%，25% 不可能是噪声。

## 验证过的效果

```
换模型（qwen-plus → qwen-max）    fmt 36→53，list10 229→161   两处报警
换回来（qwen-max → qwen-plus）    fmt 53→36，list10 161→232   两处报警，原路返回
```

**指标可重复，判定双向，不偏向任何一边。**

## 已知限制

1. 只对「有客观检验的活」有效。写文案、做设计测不了。
2. 长度变了不等于变差。变长可能是啰嗦，也可能是更详细。它是**警报**，不是判决。
3. 跨模型不能直接比。工具会警告，但那是换东西，不是降级。
4. 测的是「你的活」，不是「模型整体」。
5. **校对时发现**：qwen-plus 在三道题上稳定算错（(27+38)×4-100、中国剩余定理、数汉字笔画数）。它们是地板题，测不出降级，已被自动删除。这也说明这套题库能顺带暴露「模型不会什么」。

## 支持的服务商

```json
"provider": "dashscope"   → 阿里通义（qwen-plus / qwen-max ...）
"provider": "deepseek"    → DeepSeek
```

密钥优先级：环境变量 `DASHSCOPE_API_KEY` / `DEEPSEEK_API_KEY` → `keys.json`。

## 文件

```
watch.py              主程序（跑批、对比、出报告）
calibrate.py          题库校准器（自动筛掉不稳的题）
tasks.json            自带的 14 题题库
baseline_chars.json   每题实测字数区间
HOWTO.md              更细的说明
snapshots/            每次跑的完整记录（跑完自动生成）
```

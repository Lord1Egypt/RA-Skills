## Description:

Turn a prose chapter, story passage, or session recap into one visually focused illustration concept and a concise, composition-led image prompt for any image generator. Use for book, webnovel, short fiction, game narrative key art, or tabletop recap illustration planning. Does not generate the image unless the user asks.

This skill is ready for commercial/non-commercial use.

## Use Case:

Writers, publishers, and game or tabletop storytellers use the skill to turn a chapter, story passage, or recap into a focused illustration concept and a ready-to-use image prompt.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: An image prompt could present uncertain character details as established design.

Mitigation: Use the user's description and supplied references first; when appearance remains uncertain, flag the design and use only details supported by the text.

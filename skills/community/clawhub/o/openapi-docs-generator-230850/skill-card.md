## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineering teams use this skill to produce practical OpenAPI or Swagger documentation artifacts, workflows, checklists, analysis, code changes, and validation notes for REST APIs. It is intended for backend, platform, developer-experience, and maintenance work where API behavior must be understandable to other engineers.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad OpenAPI, Swagger, API documentation, REST API, and developer-experience triggers may activate the skill during broader API discussions where it was not explicitly requested.

Mitigation: Use explicit invocation when predictable activation matters, and confirm the desired OpenAPI or Swagger documentation outcome before producing artifacts or code changes.

Risk: Generated API documentation guidance or code changes may be incomplete or inaccurate for a specific service implementation.

Mitigation: Validate outputs against the service routes, schemas, authentication behavior, and the user's stated success criteria before relying on them.

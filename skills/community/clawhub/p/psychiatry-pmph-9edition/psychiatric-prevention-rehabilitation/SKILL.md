# 精神障碍预防与康复

## 使用场景

- 制定精神卫生预防策略或公共卫生政策
- 评估个体/人群应接受的预防干预层级
- 设计针对特定风险人群的干预项目
- 为精神障碍康复期患者制定康复计划
- 构建社区精神卫生服务网络

## 核心工作流程

### 1. 预防层级评估（Caplan三级预防模式）

根据患者当前状态匹配预防层级：

| 预防级别 | 目标人群 | 核心目标 | 关键行动 |
|---------|---------|---------|---------|
| 一级预防 | 一般人群/未发病者 | 消除病因/致病因素 | 健康教育、环境改善、优生优育 |
| 二级预防 | 前驱期/早期患者 | 早发现、早诊断、早治疗 | 筛查识别、及时干预、防止复发 |
| 三级预防 | 确诊康复期患者 | 防复发、促康复 | 康复训练、社会功能恢复、减少残疾 |

**执行步骤**：
1. 评估患者当前状态（未发病/前驱症状/确诊/康复期）
2. 匹配对应预防层级
3. 制定该层级的核心干预措施

### 2. 目标人群分类干预（Mrazek & Haggerty框架）

根据人群风险特征选择干预类型：

#### 一般性预防（Universal）
- **对象**：全体公众
- **措施**：
  - 心理健康教育普及（目标：2030年心理健康素养≥30%）
  - 消除病耻感，推动心理咨询/治疗
  - 建立服务网络（教育、公安、司法联动）
  - 实施员工心理援助计划（EAP）
  - 学生心理健康教育与自杀预防
  - 优生优育、遗传咨询

#### 选择性预防（Selective）
- **对象**：高危人群（灾难幸存者、重大生活事件经历者）
- **措施**：
  - 建立心理危机干预模式
  - 纳入突发事件应急预案
  - 个体/群体危机管理
  - 持续援助与随访

#### 指征性预防（Indicated）
- **对象**：有前驱症状但未达诊断标准者
- **措施**：
  - 提高公众识别能力
  - 指导及时就诊
  - 综合医院设立精神/心理科
  - 培训非精神科医师筛查能力
  - 加强会诊-联络精神医学

### 3. 全生命周期预防策略

根据个体所处生命阶段匹配风险因素与干预措施：

#### 胚胎期及婴幼儿期
- **风险因素**：母亲心理不良、致畸暴露、产伤、缺氧
- **干预措施**：
  - 孕期心理健康教育与规律作息
  - 围产期安全检查
  - 促进母婴皮肤接触
  - 培养安全型依恋关系

#### 儿童青少年期
- **风险因素**：学业压力、家庭不和、父母离异、ADHD
- **干预措施**：
  - 学校心理健康科普
  - 家校联合干预
  - 重点关注ADHD、智力发育障碍
  - 及时心理干预与转介

#### 成年期
- **风险因素**：工作压力、关系冲突、重大社会事件
- **干预措施**：
  - 企业EAP项目
  - 社区心理援助
  - 家庭教育指导
  - 失眠、焦虑、抑郁早期筛查

#### 老年期
- **风险因素**：躯体疾病、孤独、认知下降、失眠
- **干预措施**：
  - 改善生活方式
  - 丰富社区生活
  - 增强社会连接
  - 提高心理韧性

### 4. 心理社会康复计划制定

#### 现代康复目标

从传统目标转向现代目标：

| 传统目标 | 现代目标 |
|---------|---------|
| 社区安置 | 获得独立与掌握感 |
| 坚持服药 | 有意义的人际关系 |
| 减少住院 | 就业机会 |
| - | 最高水平的功能与福祉 |

#### 核心干预措施

1. **症状缓解干预**：药物管理、复发预防
2. **社会认知训练**：情绪识别、社交线索解读
3. **人际关系改善**：沟通技巧、冲突解决
4. **功能提升训练**：
   - 生活技能（自理、家务、理财）
   - 社会活动参与
   - 康复运动
   - 兴趣爱好培养

#### 支持系统构建

- **家庭参与**：家属教育、家庭治疗
- **同伴支持**：康复者互助小组
- **辅助就业**：支持性就业、职业培训
- **社区融合**：社区活动、志愿服务

## 执行决策树

```
用户请求预防/康复相关帮助
│
├─ 制定公共卫生政策？
│   └─ 应用Mrazek框架，覆盖Universal/Selective/Indicated三层
│
├─ 评估个体预防层级？
│   └─ 应用Caplan模式，判断一级/二级/三级
│
├─ 设计特定人群干预？
│   └─ 确定生命周期阶段 + 风险因素 → 匹配干预措施
│
└─ 制定康复计划？
    └─ 评估功能水平 → 选择核心干预措施 → 构建支持系统
```

## Description:

Generates precise, consistent, discoverable names for variables, functions, types, files, routes, database tables, and other code artifacts using linguistic principles, codebase conventions, and semantic analysis.

This skill is ready for commercial/non-commercial use.

## Publisher:

[jcools1977](https://clawhub.ai/user/jcools1977)

### License/Terms of Use:


## Use Case:

Developers and engineers use this skill to turn natural-language descriptions and codebase context into naming recommendations for code, APIs, database fields, files, routes, and configuration. It is useful during implementation, refactoring, and code review when names need to be precise, consistent, discoverable, and proportional to scope.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Useful naming recommendations may require the agent to inspect relevant parts of a user's codebase for existing naming patterns.

Mitigation: Limit inspection to relevant code paths and review recommendations before applying renames or new public identifiers.

## Description:

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and external users use this skill to assess OpenClaw skills before installation, including security scan status, popularity, maintenance, dependencies, API cost, and install guidance.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Skill names can influence command guidance and may be unsafe if they include shell metacharacters or pasted command text.

Mitigation: Use exact, normal ClawHub skill names only and review any proposed command before execution.

Risk: Reviewed SKILL.md content is untrusted data and could try to influence the reviewing agent.

Mitigation: Treat inspected skill content as evidence only, not as instructions to follow.

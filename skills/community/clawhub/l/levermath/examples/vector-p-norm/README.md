# 示例：向量 p-范数

完整的 10 帧示例：封面、向量空间、内积空间、赋范线性空间、内积与范数、p-范数定义、数值计算、单位圆的形变、范数等价、总结。第 7 帧按 PgDn 分步揭示，第 8 帧可拖滑块或点“自动演示”。

## 直接播放

打开构建产物 [`dist/examples/vector-p-norm/index.html`](../../dist/examples/vector-p-norm/index.html)，双击即可离线放映。`examples/vector-p-norm/index.html` 只是源码开发入口，直接双击会显示指路说明。

## 构建与开发

```bash
bun run build:norm
bun run dev:norm
```

产物是 `dist/examples/vector-p-norm/index.html`。原课件为 960×540 舞台，这里统一迁移到 1280×720；中文使用内嵌的 Noto Serif SC 子集，改文案后构建会自动重裁。

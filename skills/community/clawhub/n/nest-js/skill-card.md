## Use Case:

Developers and backend engineers use this skill to design, implement, troubleshoot, and test TypeScript-first NestJS APIs and services that follow Nest module, provider, controller, request lifecycle, validation, data access, and microservice conventions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Copied examples or generated changes could be applied directly to production services without adapting dependency versions, CORS settings, environment handling, database targets, or migrations.

Mitigation: Pin dependencies, avoid wildcard CORS in production, validate required environment variables, keep secrets out of committed .env files, use development or test databases for samples, and review migrations before applying them.

## Description:

Use this skill when a Fire Protection Engineer (PE/FPE), NICET-III/IV designer, code consultant, or AHJ reviewer needs to draft a permit-submittal fire protection narrative report covering NFPA and IBC systems with hydraulic summaries, AMME packets, deferred-submittals lists, and an unsigned PE sign-off block.

This skill is ready for commercial/non-commercial use.

## Use Case:

Fire protection engineers, NICET designers, code consultants, AHJ reviewers, owners, and contractors use this skill to draft permit-submittal fire protection narrative packets from confirmed jurisdiction, adopted code editions, AHJ requirements, occupancy, construction, hazard, water-supply, and system-scope inputs. The output supports professional review and sign-off but does not replace a licensed PE/FPE or AHJ determination.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Draft outputs may contain incorrect code editions, amendments, calculations, permit language, or project details if source inputs are incomplete or unverified.

Mitigation: Treat outputs as draft engineering support only; a licensed PE/FPE and the AHJ must verify code editions, amendments, calculations, and final permit language before use, and users should provide only confidential project details needed for the draft.

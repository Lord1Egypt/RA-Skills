# 第07课 综合练习：成绩统计

> 老孟带你学中文编程 · 第 07 课　|　语言面 ZHC-LANG 2.0　|　源码 `示例/第07课_综合练习_成绩统计.zc`
> 运行：`python -X utf8 zhc.py 示例/第07课_综合练习_成绩统计.zc --run`

## 一、本课目标

把前面六课合起来：用表存多行成绩，遍历聚合出总分、平均分、最高分、及格人数，最后导出 JSON。

## 二、语法要点

| 写法 | 说明 |
|---|---|
| `定义 t 为 表` + `造列(t, 列名, 类型)` | 定列，列一旦有数据就不能再改 |
| `定义 r 为 记录` + `置元素(r, 键, 值)` | 造一行 |
| `追加(t, r)` | 把整行写进表 |
| `遍历 t 记作 行` | 表遍历拿到的 `行` 是记录，用 `取元素(行, 列名)` 取值 |
| `长度(t)` | 表的行数 |
| `转JSON(t)` | 整表序列化成单行 JSON，可直接交给别的程序 |

## 三、完整代码

```zc
# 第07课 综合练习：成绩统计
# 用表存多行数据：先 造列 定列，再 追加 进整行记录，最后 遍历 聚合。

定义 成绩表 为 表
造列(成绩表, "姓名", 文本)
造列(成绩表, "分数", 整数)

定义 甲 为 记录
置元素(甲, "姓名", "张三")
置元素(甲, "分数", 92)
追加(成绩表, 甲)

定义 乙 为 记录
置元素(乙, "姓名", "李四")
置元素(乙, "分数", 78)
追加(成绩表, 乙)

定义 丙 为 记录
置元素(丙, "姓名", "王五")
置元素(丙, "分数", 55)
追加(成绩表, 丙)

# 遍历聚合：一行行读出来算总分、最高分、及格人数
定义 总分 为 整数
设 总分 为 0
定义 最高 为 整数
设 最高 为 0
定义 及格数 为 整数
设 及格数 为 0

遍历 成绩表 记作 行
    定义 姓名 为 文本 取元素(行, "姓名")
    定义 分数 为 整数 取元素(行, "分数")
    设 总分 为 总分 + 分数
    如果 分数 > 最高 则
        设 最高 为 分数
    结束
    如果 分数 >= 60 则
        设 及格数 为 及格数 + 1
    结束
    输出 姓名, "：", 分数
结束

输出 "总人数：", 长度(成绩表)
输出 "总分：", 总分
输出 "平均分：", 总分 / 长度(成绩表)
输出 "最高分：", 最高
输出 "及格人数：", 及格数

# 整表转 JSON，方便交给别的程序或智能体继续处理
输出 转JSON(成绩表)
```

## 五、易错点

- `造列` 的类型词不带引号，直接写 `文本` / `整数`。
- 表已有数据后再 `造列` 报 `[E404]`，列定义要一次写全。
- 平均分这里是整数除法，`225 / 3` 得 `75`；要小数先把 总分 定义成 `浮点`。
- `转JSON` 输出是单行，长表看起来会很长，需要给人看时用循环自己排版。

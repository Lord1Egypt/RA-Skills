## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineering teams use this skill to plan, create, refine, and validate OpenAPI or Swagger documentation so REST APIs are easier for other engineers to understand and integrate.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad trigger wording may activate the skill for general API or developer-experience questions.

Mitigation: Invoke the skill explicitly for OpenAPI or Swagger documentation work, and disable or ignore implicit activation when precise routing is required.

## 3. 真值算：哪些字段可进判定

连接器实取：PE_TTM、PB、归母净利、扣非净利、经营性现金流、商誉/净资产、
十大流通股东占比、ROIC、EBIT、有息负债、货币资金、市值。

派生量必须写明公式：

- 净现比 = 经营现金流净额 ÷ 归母净利（**仅分母 > 0** 才可判）
- 商誉占比 = 商誉 ÷ 净资产
- EBIT/EV = EBIT ÷ (市值 + 有息负债 − 货币资金)
- PEG = PE_TTM ÷ 增速（双口径：年 / 半年）

## 4. 缺口标注：只登记「缺什么 → 测不了什么」

| 缺口 | 影响 |
|---|---|
| 股东户数 `shareholderNum=[]`（8/8） | 筹码集中度趋势不可判 |
| 游资席位 `yzb/yyb` 为空 | 席位级资金路径不可判 |
| 有效一致预期（7 只无数据；1 只 `institutionCnt=0` / `targetPrice=0`） | 2027E 增速不进 PEG、不进买卖信号 |
| 逐只 `tech/flow/fund/cycle/fib` 五维分 | 个股色条整表标「数据缺口·待核」，不得用市场级 2/3/2/2/1 代填 |
| 政府补助占比、3 年历史分位、连板梯队 | 利润含金量、周期位置、情绪梯队不可判 |

**禁止编造**：DCF 终值 / LBO 杠杆 / ROE / 净现比 / 商誉占比 / 股息率 / 2027 预测，
除非来自连接器实取或明确标为【预测】且不进判定。

## Known Risks and Mitigations:

Risk: The scanner reports that the documentation directs users to download and run an unverified Python file from a mutable GitHub branch while also describing the package as having no code or network use.

Mitigation: Use the bundled PROMPTS.md directly; run the documented curl/python flow only after independently inspecting the downloaded script, pinning it to an immutable commit or verified release, and using a low-privilege environment without secrets.

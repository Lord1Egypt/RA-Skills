## Description:

Customer-service reply library and auto-reply rule pack — intent classification, emotion de-escalation (LEAP method), objection-handling matrix, escalation red lines. Outputs a JSON rule table you can import into any helpdesk or chatbot.

This skill is ready for commercial/non-commercial use.

Customer-support teams and developers can use the reply templates to draft consistent responses, handle common objections, de-escalate customer anger, and route safety, legal, media, key-account, or out-of-policy refund cases to a human.

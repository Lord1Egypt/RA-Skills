# PPL tools

Generated from the PPL server’s tool definitions. Do not edit by hand:
run `pnpm run build:connected-apps-skill` in ppl-backend.

70 tools. Which ones an assistant sees depends on the switches the
creator turned on for it in PPL › Settings › Connected Apps; a tool that is
not listed is not allowed, and asking for it again will not help.

## See (always on)

| Tool | What it does | Notes |
|---|---|---|
| `get_account` | The creator's plan and its limits, today's video limits and how many are left, gem balance, and what this connection is allowed to do, plus `offer`: PPL's current offer for this creator, when there is one, with its terms. Call this before starting any render so you know what is possible. |  |
| `show_home` | Start here when the creator has just connected PPL, asks what they can do, or wants to start something new: their PPL home as a card, with their characters, series, gems and videos left today, plus ideas for what to make next (the card loads them), one-tap starts, and `offer` as in get_account. Reads only; nothing is spent. Call get_account instead when you only need the limits before a render. | shows a card |
| `list_characters` | The creator's own characters: id, name, handle and whether other creators may collab with each (allow, request or private). Most other tools need a characterId from here. |  |
| `list_series` | The creator's series: id, name, which character leads it, how many episodes it has and the next episode number. Pass status "ready" to list series that are developed but not saved yet. |  |
| `get_series` | One of the creator's series in full: synopsis, genres, art style, cast, how it is sold and released, and the season plan (each planned or published episode with its slot, title, logline and state). Read this before writing an episode so the prompt fits the show. Each cast entry says what it is. castMember true: a cast member, a supporting character PPL drew that has no profile of its own (false: a full character, such as the lead or another creator's character). generated true: PPL made it for this series, and recast_cast_member can redraw it. claimable true: it is in the crew of one of the creator's characters, and claim_cast_member can make it a character of its own (pass castOfCharacterId as characterId and its characterId as memberId). |  |
| `list_drafts` | Finished work the creator has not published yet: videos, images, voices, locations, props and series, newest first, each with its jobId and a preview link. Optionally for one character. | shows a card |
| `get_job` | Where a render or other job stands: pending, in-progress, completed or failed, with the preview link once it is done or the reason if it failed (and canRetry when retry_job can start a failed video again). While it runs, startedAt and typicalSeconds (the usual time for this kind of job) let you tell the creator how long is left; a video usually takes about 6 minutes and sometimes over 15. Wait about 30 seconds between checks and do not start the same render again while one is running. |  |
| `lookup_product_help` | How PPL works: plans and limits, gems, selling episodes, earnings, collabs, drafts, release schedules and more. Call with no topics to get the list of topic ids, then with up to a few ids to read them. Use this instead of guessing how the product behaves. |  |
| `get_creation_guide` | What this creator can render right now: the video lengths their plan includes (15, 30 or 60 seconds) with gem prices and how to pace a prompt for each (pacing: beats, the most spoken words, the shape), each video model with its prompt length limit and how many other characters it can hold, plus how to use series, cast, locations and props in create_episode. Every plan renders at 480p. Call this before writing a prompt or choosing settings. |  |
| `get_episode_ideas` | PPL’s own ideas for what this character could make next: for a series (pass seriesId) the next episode, for a collab (pass collabCharacterId) the two characters together, otherwise a standalone video. Each has a title, a short summary and the cast, places and props it features. Use them as starting points for a prompt you write, or pass a summary to create_episode unchanged as the whole prompt: PPL then writes that one-line idea out to fill the length you pick. |  |
| `get_quote` | The gem price of a render with these settings, and whether it fits the gem balance, today’s video limit and this app’s daily gem limit. Nothing is started or charged. Show the price to the creator and use it as maxGems in create_episode. Pass how many other characters, locations and props you will tag: when the model cannot use all of them as reference images the result says how many it will not use (referencesNotUsed), so you can tell the creator or tag fewer first. |  |
| `get_world` | Everything saved in a character’s world: styles (looks and outfits), locations, props (vehicles included) and crew, each with its id, name, description and image. Use the ids as styleId, locationIds, propIds and cast in create_episode. Crew includes the cast PPL saves from the creator’s videos: a named supporting character or pet a video introduces is kept (source "episode") so it looks the same next time. Each crew entry says what it is: castMember true is a cast member, a supporting character with no profile of its own (made by hand or saved from a video); false is a full character (a claimed member, or another creator’s character that appears in the creator’s videos). Those with claimable true can become characters of their own with claim_cast_member. pending lists what PPL is still drawing from a video that just finished (kind and name, no id yet): those assets appear in the lists above within a few minutes, so read again before tagging one and do not create it a second time. When the creator asks to see their world, use show_world instead. |  |
| `show_world` | Show the creator a gallery of a character’s world: looks, locations, props and crew, with the current look marked. Use this only when the creator asks to see or browse their world. To read ids before a render, use get_world, which returns the same result without a gallery. | shows a card |
| `get_asset_ideas` | PPL’s own ideas for what to add to a character’s world: new locations, props, crew members or styles (looks) that fit the character. For a location or prop, pass assetId to get ideas for changing that one instead (use them with edit_asset). Each idea has a title and a prompt to pass to create_asset or edit_asset. Free. |  |
| `find_collab_partners` | Characters this series could collab with: the ones already in it, the creator’s collaborators, and suggested characters from the community. Each says whether a request can be sent and, if not, why. Use request_series_collab to invite one into the series, or create_episode with collabCharacterId to make a one-off collab video. | reaches other people or the web |
| `get_collab_access` | Whether one of the creator’s characters may collab with another creator’s character right now: open, approved, needs_approval (send request_collab_approval), pending, declined (with when it can be asked again) or private. Name the other character by characterId or by its @handle; the answer carries its characterId for request_series_collab, request_collab_approval and create_episode. | reaches other people or the web |
| `list_collabs` | Collab requests waiting on this creator (other creators asking to use their characters) and the ones this creator has sent. "booking" is a seat in a series with a share of its unlock gems; "approval" is permission for one character to make collab videos with another. Pass seriesId to list everyone booked into that series. |  |
| `get_collab_earnings` | Gems this creator has earned from their characters appearing in other creators’ series, in total and by series. |  |
| `list_videos` | The creator’s published videos that are not part of a series, newest first, with the postId that add_video_to_series takes. Pass characterId for one character. |  |
| `get_draft_prices` | What it would cost in gems to render a finished draft again, to edit it with a prompt, or to extend it by some seconds. Nothing is started. |  |
| `get_stats` | How the creator’s work is doing. With no seriesId: every posted series (episodes, views, likes, shares, followers, unlocks and the gems viewers spent on them), totals for videos outside a series, and the last 28 days day by day (UTC). The series and video totals are ALL TIME; only `daily` is the last 28 days, so the two do not add up to each other. With a seriesId: the same for that series plus each episode’s views, likes, unlocks and how many viewers finished it, and season passes sold. unlockGems is what viewers spent, not what the creator earned; use get_earnings for money. |  |
| `get_earnings` | What the creator has earned: available now, on hold and when the next amount releases, the total, the chosen period against the one before, and a breakdown by series (unlocks, season passes, collab shares, gifts). The breakdown may not cover the whole total: notItemisedUsdCents is the part it leaves out. total is everything ever earned and never goes down; balance is the money the creator still has (what is available plus what is on hold), after cashedOutUsdCents, reinvestedUsdCents and adjustmentsUsdCents (refund reversals and corrections, usually 0) came off the total. Do not call the total a balance. Amounts are US cents with a formatted string beside the main ones. Read-only: cashing out and payout details are only in the PPL app. |  |
| `get_character_draft` | The character being designed on this account, if any: each look (an image per art style, plus “original”, the character as described), each voice with a sample to play, suggested names, the personality traits to choose from, suggested backstories and the creator’s own backstory if they wrote one, what has been chosen so far, and what is still being made. Where the assistant shows PPL’s card, the creator chooses in the card; otherwise show the images and voice samples as links. Returns draft: null when no character is being designed. | shows a card |

## Create

| Tool | What it does | Notes |
|---|---|---|
| `create_episode` | Start rendering a video from a prompt, exactly as written (only an unchanged get_episode_ideas summary is written out to the length by PPL), for one of the creator’s characters. It spends the creator’s gems and counts against their daily video limit. The result is a DRAFT: nothing is posted. Returns a jobId at once; follow it with get_job. Get the price with get_quote first and pass it as maxGems. A saved cast member, prop or location the prompt names is used without being tagged; a new one the prompt names is drawn inside the job, before the video, used in it and saved to the world (see get_creation_guide). | spends gems, shows a card |
| `create_series` | Develop a new series for one of the creator’s characters from a premise: PPL writes the show, its cast and a season plan. The first series for a character is free; later ones cost gems (see get_creation_guide). Returns a seriesId and jobId; follow with get_job, read the result with get_series, then save_series to keep it. | spends gems |
| `save_series` | Keep a developed series ("Save This Series" in the app), which makes it active so episodes can be made for it. Only works once its development has finished. |  |
| `discard_draft` | Remove a finished draft from the creator’s drafts. It cannot be brought back and the gems it cost are not returned. Only do this when the creator has asked to discard that draft. | removes something |
| `create_asset` | Add a location, prop, vehicle or crew member to a character’s world from a description, optionally with up to 3 reference images (uploadIds from import_image or start_upload). PPL re-draws the references in the character’s art style and saves the result to the library; the original image is not kept. Follow the jobId with get_job, then find it with get_world. Locations, props and vehicles cost a few gems (get the price by sending maxGems 0 first: the refusal states it); a crew member is free, up to 10 free cast drawings (new crew members and recasts together) in 24 hours. | spends gems, shows a card |
| `edit_asset` | Re-draw one of a character’s locations, props or vehicles from a description of the change (“make it night”, “add rust”), optionally with up to 3 reference images (uploadIds). The same asset is updated in place and keeps its name; restore_asset undoes the last change. It costs the same as creating one (send maxGems 0 first: the refusal states the price). Follow the jobId with get_job. | spends gems, shows a card |
| `create_style` | Draw a new look (style) for a character from a description of the change: an outfit, a hairstyle, a setting for the portrait (“a storm coat and sea boots”), optionally with up to 3 reference images (uploadIds). It costs a few gems (send maxGems 0 first: the refusal states the price). This only draws a draft; nothing about the character changes until save_style. Follow the jobId with get_job. | spends gems, shows a card |
| `save_style` | Save a finished create_style draft as the character’s new current look. This is the app’s Save: the character’s portrait changes, and PPL re-draws the character sheets, banner and idle clip in the new look, which costs gems (send maxGems 0 first: the refusal states the price). The earlier look stays in the library and set_current_style switches back. Confirm with the creator before saving. | spends gems |
| `import_image` | Fetch an image from a public https link so it can be used as a reference in create_asset. JPEG, PNG or WebP, up to 10 MB. Unsafe content is refused. Returns an uploadId that works for 24 hours. Images are only ever used as references: PPL re-draws them in the character’s art style, ignores any people in a location or prop photo, and when a crew photo shows a real person or a character from an existing film, show or game it makes an original character inspired by it instead of a copy. | reaches other people or the web |
| `request_upload` | Show the creator a file picker in the chat so they can add up to 3 reference images from their device (an assistant cannot pass a chat attachment to PPL). The picker uploads them and the creator’s next message carries the uploadIds to use in create_asset, edit_asset or create_style. If no picker appears, this assistant cannot show one: ask for a public https link and use import_image instead. | shows a card |
| `start_upload` | Get a one-time link to send an image file to, for clients that can make an HTTP request with a file. PUT the raw bytes to uploadUrl within 15 minutes; the answer says whether the image was accepted (the same check as import_image). Then pass the uploadId to create_asset. JPEG, PNG or WebP, up to 10 MB. |  |
| `regenerate_poster` | Draw new poster art for a series: one fresh take, vertical (the default) or wide, optionally steered by a prompt (up to 1,000 characters). The first poster for a series that has none is free; after that it costs gems (get_series shows the price as posters.regenerateGems, or send maxGems 0: the refusal states it). The series keeps its current poster; when the job finishes, read the new choice with get_series and set it with update_series. The new take replaces the earlier choices, so once it is set the old poster cannot be chosen again: say so before setting it. | spends gems |
| `retry_job` | Start a failed video render again with the same prompt and settings. A failed render was not charged, so the retry is charged as a new one, normally at the price the first was quoted (get_job shows a failed job). A storyboard's render was paid for with its storyboard: its retry gives those gems back once, then is charged the same way. Pass the most gems the creator agreed to. Returns a new jobId. For a finished draft use rerun_draft instead. | spends gems, shows a card |
| `update_draft` | Set the title (series episodes, up to 40 characters) or caption (up to 140) a draft will be published with. Free. |  |
| `rerun_draft` | Make a fresh take of a finished draft, optionally with a changed prompt. It costs the draft’s price again (get_draft_prices). Returns a new jobId; the first draft stays. | spends gems, shows a card |
| `edit_draft` | Change a finished draft by describing the change (“make it night”, “remove the hat”). It costs gems (get_draft_prices). Returns a new jobId for the edited draft. | spends gems, shows a card |
| `extend_draft` | Make a finished draft longer by a number of seconds offered in get_draft_prices. It costs gems. Returns a new jobId for the longer draft. | spends gems, shows a card |
| `start_character` | Begin designing a new main character from a written description (who they are and what they look like, up to 500 characters). PPL draws the character in each of its art styles, designs voices and proposes names, personality traits and backstories; this is free. Nothing is created yet. Where the assistant shows PPL’s card for this, the creator picks the look, voice, name, personality and backstory in the card and creates the character there, and the card keeps itself up to date: do not list the options, and do not call get_character_draft to check on it. Without the card, read the options with get_character_draft, set the creator’s choices with update_character_draft, then finish_character. An account has one character draft at a time, shared with the app: if one exists this is refused unless replaceDraft is true, which discards it. A character cannot be made from a photo here; that is done in the PPL app. The plan limits how many main characters an account may have (get_account). | shows a card |
| `update_character_draft` | Record the creator’s choices on the character draft: the look (styleId), the voice (voiceId), the name, up to three personality traits (ids from personalityTraitOptions) and the backstory: the creator’s own words (backstory, up to 1,000 characters), or one of PPL’s suggestions as written (backstoryId). The creator’s own words win when both are set; to start from a suggestion and change it, pass the edited text as backstory with that suggestion’s backstoryId. Only what you pass changes. Pass newBackstories: true to have PPL write a fresh set of suggestions; that never changes the creator’s own backstory. Nothing is created until finish_character. |  |
| `finish_character` | Create the character from its draft, as Continue does in the app: it needs a chosen look that has finished drawing and a name (readyToFinish in get_character_draft). The handle is made from the name. PPL then writes the character’s story and draws its character sheets in the background. It becomes a new main character on the account and counts toward the plan’s limit; the character the creator is using in the app stays selected unless makeActive is true. Nothing is posted. Show the creator the chosen look, voice and name and get a clear yes before calling this: a character cannot be un-made from here. |  |
| `discard_character_draft` | Throw away the character being designed: its looks, voices and choices are gone and cannot be brought back. No character is affected. Only do this when the creator has asked to discard the draft. | removes something |

## Manage

| Tool | What it does | Notes |
|---|---|---|
| `rename_asset` | Rename a style, location, prop or generated crew member (up to 30 characters). A crew member’s handle follows its name and always ends in _cast until the member is claimed. |  |
| `set_current_style` | Make one of the character’s saved styles the look it wears by default. |  |
| `restore_asset` | Put back the previous image of a location or prop after an edit. Free. Only one step of undo is kept. |  |
| `claim_cast_member` | Turn one of a character’s cast members (crew with claimable true in get_world, or cast with claimable true in get_series, whose castOfCharacterId is the characterId to pass) into a character of its own, with a profile, a voice and a full set of reference sheets. It gets a handle of its own in place of its _cast one (the result carries it). It keeps its place in the crew. It uses one of the plan’s character slots, so it is refused with a link to the plans when the plan is full, and it cannot be undone. A member PPL generated for a series (generated true in get_series) is not in a character’s crew and cannot be claimed here. Only do this when the creator has asked for that member to become their own character. |  |
| `remove_asset` | Remove a style, location, prop or generated crew member from a character’s world. A location or prop is deleted for good and cannot be brought back; a style is archived. A location or prop tagged in an episode that is still rendering is refused until that render finishes. Only do this when the creator has asked for that item to be removed. | removes something |
| `update_character_settings` | Change who may collab with one of the creator’s characters (allow: anyone; request: the creator approves each character once; private: no one) or whether new styles, locations and props from its episodes are saved automatically. Changing the collab setting does not end collabs that already exist. |  |
| `update_series` | Change a series’ name (up to 40 characters), synopsis (up to 400), genres (up to 3), mark it ended, or pick its poster from the choices in get_series (posterId for the vertical poster, widePosterId for the wide one). Only the fields you pass change. |  |
| `update_series_settings` | Change how a series is sold and released. Price per locked episode is 20, 50 or 100 gems, or 0 to make every episode free; at least 5 episodes stay free. Release is at_once (episodes go out when published), daily (one a day at releaseTime in releaseTimezone, e.g. "18:00" and "America/Los_Angeles") or manual (held until released). Switching to at_once releases everything waiting and notifies followers, so confirm with the creator first. | reaches other people or the web |
| `delete_series` | Delete a series. A series that was never saved is discarded; a saved one is removed with all of its episodes. Viewers lose access to it. Only do this when the creator has clearly asked to delete that series, and confirm its name with them first. | removes something |
| `recast_cast_member` | Replace one of a series’ generated cast members with a fresh take of the same role and name. Free, and counted with new crew members: 10 free cast drawings in 24 hours. Only works for a member PPL generated for the series (generated true in get_series), not for the lead, another creator’s character, or a cast member from a character’s crew (castMember true with generated false). The old one is gone once the new one is drawn; follow the jobId with get_job. |  |
| `update_plan_row` | Change the title (up to 40 characters) or logline (up to 300) of an episode that is planned but not made yet. slot comes from get_series. |  |
| `delete_plan_row` | Remove an episode from the plan. Only works for one that has not been made. | removes something |
| `extend_plan` | Have PPL plan one more episode at the end of the show’s latest season. Free. When that season is full (100 episodes) or was ended, this starts the NEXT SEASON instead, exactly as Add Episode does in the app: a new series with its own id (same show, cast and prices) with its first episode planned. Tell the creator that before calling it on a full or ended season. The result says whether a season was started (startedNewSeason) and gives the id of the season the new row is in (seriesId): use that id with get_series and the other plan tools. |  |
| `regenerate_plan` | Have PPL rewrite the episodes that are planned but not made yet, optionally in a direction you give (up to 280 characters). Episodes already made and rows the creator edited by hand are kept. Free. |  |
| `update_episode` | Change a published episode’s title (up to 40 characters) or caption (up to 140), or move it to another of the creator’s series. episodeId comes from get_series. | reaches other people or the web |
| `reorder_episodes` | Put a series’ published episodes in a new order. Pass every episode id of the series in the order wanted. |  |
| `delete_episode` | Delete one published episode for good. If it is the series’ only episode the series goes with it. Only do this when the creator has clearly asked to delete that episode. | removes something |
| `add_video_to_series` | Turn one of the creator’s standalone videos (postId from list_videos) into the next episode of one of their series. The video keeps its likes and stops being a separate post; this cannot be undone except by deleting the episode. Leave title out and PPL titles the episode. The series must be the same character’s, have a published first episode, and not be ended or full. |  |
| `remove_from_feed` | Take one of the creator’s posts off the feed and their public profile, as Remove does in the app: viewers can no longer see it. Pass postId for a standalone video (from list_videos) or seriesId for a whole series. This tool cannot put it back. Only do this when the creator has asked for that post to come down. | removes something |
| `hide_collab_episode` | Stop listing an episode that one of the creator’s characters appeared in as a collaborator on that character’s profile. The episode stays on the other creator’s series. Only works for episodes of someone else’s series; the creator’s own episodes are deleted with delete_episode. |  |

## Collab

| Tool | What it does | Notes |
|---|---|---|
| `request_collab_approval` | Ask another creator for permission for one of this creator’s characters to make collab videos with theirs. It sends that creator a notification. Only needed when get_collab_access says needs_approval. Only do this when the creator has asked to reach out to that character. | reaches other people or the web |
| `request_series_collab` | Invite another creator’s character into one of this creator’s series as guest, recurring, main or lead. Its owner earns a share of the series’ unlock gems (guest 5%, recurring 8%, main 10%, lead 20%; at most 4 seats and 50% in total). It is accepted at once when that character allows collabs, otherwise its owner is asked. Tell the creator the share before sending. | reaches other people or the web |
| `respond_collab` | Accept or decline a request that is waiting on this creator (from list_collabs). Accepting a booking puts their character in that series for the share shown; accepting an approval lets that character make collab videos with theirs. Only answer the way the creator has said to. | reaches other people or the web |
| `cancel_collab` | Cancel a request this creator sent, remove a booked character from their series, leave a series their character was booked into, or take back an approval they gave. Only do this when the creator has asked for it. | removes something, reaches other people or the web |

## Publish

| Tool | What it does | Notes |
|---|---|---|
| `publish_draft` | Post a finished video draft publicly on PPL, as the creator tapping Publish would. For a series episode it joins the series and follows the series’ release schedule; the result’s episodeId is that episode (for update_episode and release_episode), while postId is the series’ one post, shared by all its episodes. The result also has shareUrl, the public link to watch and share it, and live: false when the series’ schedule holds the episode (releaseAt is when it goes live, or null until the creator releases it). This is visible to other people: only do it when the creator has asked for this draft to be posted. | reaches other people or the web, shows a card |
| `release_episode` | Release an episode that is being held (a series whose release schedule is manual) so viewers can see it now. | reaches other people or the web |

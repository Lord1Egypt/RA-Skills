# CHANGELOG

> **语言范围 / Language scope**：本文件与整个 skill 一样，有意仅用中文——服务对象是唐诗宋词，非中文语种没有对应素材。理由见 `SKILL.md` →「语言范围 / Language scope」。
> This changelog is intentionally Chinese-only for the same reason the skill is: its subject matter is classical Chinese poetry.

## v1.6.0 — 2026-11-17

首屏重写 + 回讲第四题型 + 来源分级。功能与诗库无删减。

- **首屏重写（前 60 字给场景，不给功能清单）**：改成「今天想读一句诗，就打开它——说个心情或场景，给你配一句唐诗宋词」。原首屏 781 字、第一个动作动词在第 40 字之后，读的人不知道什么时候用它。
- **把离线能力写进首屏**：明写「1149 首李白全集 + 114 首杜甫苏轼 + 45 首精读库全部存在本地，零依赖、不联网也能用全部模式」。这是面对每日唐诗类竞品（其数据走外部 URL 接口）的唯一硬差异，此前从未出现在首屏。
- **新增第四题型「回讲」**（模式 D）：`review_stage ≥ 3` 才出，只给生活处境，请用户用这首诗讲给别人听；判定看三件事——这句在讲什么 / 为什么是这句 / 有没有自己的话。**不写入 progress.json、不影响 stage 与烂熟判定**，只在本轮回执加一行「回讲 1 首（不参与评级）」。用户不想讲就跳过，不追问。
- **新增「来源分级」表**：把精读库（45 首）/ 精选底库（114 首）/ 全集底库（1149 首）/ 模型自身知识四档的可信度与对外说法写清。**只标不确定的那几档**，A 档不标注——否则每句话挂标签，读诗变成查账。

## v1.5.6 — 2026-10-27

模式 E 周报新增**坚持度**三条指标（不改 `progress.json` 结构、不新增文件）。

- 连续学习天数（截至今天；昨日无记录即 0，**不追问、不批评、不补卡**）
- 近 7 天有记录的天数（x/7）——比连击更抗波动，是"你没掉队"的稳妥证据
- 累计有记录天数（历史总天数，一行小字）
- 口径：一个自然日只要有任意一次学习或复习记录即计入，同日不重复计；无持久化模式下不出坚持度

> 与「不打卡焦虑」一致：坚持度是给用户看的镜子，不是考核表；断档不提醒、不弥补、不催。

## v1.5.5 — 2026-10-27

触发词策略调整（1.5.4 的延续），功能与诗库无变化。

- **撤回 bare 通用触发词**：「古诗背诵」「古诗学习」「学古诗」「古诗词」。理由：①正面竞品（跨时空古文对话类背诗工具）已盘踞这些词，硬碰无胜算；②歧义度高，易误触发到"陪背课文"场景。
- **换入场景化长尾触发词**：「这句诗适合发朋友圈吗」「今天读到一句诗」「这句诗什么意思」——指向诗遇的真正差异点：把诗配回生活场景，而不是陪背。
- ClawHub topics 同步：撤「古诗词」，换「每日一诗」。

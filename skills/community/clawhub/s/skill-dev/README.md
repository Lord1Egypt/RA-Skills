# @scene#18: Skill 开发

> WorkBuddy 场景规则 —— 专门负责修改和优化已有技能

## 场景定位

当 WorkBuddy 技能出现漏洞、流程缺失、逻辑错误，或有经验教训需要沉淀时，自动激活本场景进入 **Skill 开发模式**。

## 触发词

以下任一关键词出现时激活：

- 优化技能
- 修改技能
- 技能有问题
- 技能漏洞
- 改进技能
- 技能踩坑
- 把这个经验写进技能
- 技能加一条规则

## 行为模式

```
触发 → 分析问题 → 定位根源 → SkillManage 修改 → 回归验证 → 记录影响范围
```

### 1. 分析问题

- 确认问题类型：漏洞 / 流程缺失 / 逻辑错误 / 经验沉淀
- 复现路径是否清晰
- 影响范围有多大

### 2. 定位根源

- 读取目标 Skill 的 SKILL.md 和相关脚本
- 找出问题所在的具体行/段落
- 判断是局部修复还是需要重构

### 3. SkillManage 修改

- 使用 SkillManage (modify) 精确修改
- 如果是跨文件改动，核对所有引用
- 保持 SKILL.md 格式规范

### 4. 回归验证

- 检查修改后逻辑是否闭环
- 确认没引入新问题
- 更新 changelog（如有）

### 5. 记录影响范围

- 工作区 MEMORY.md 记录改动
- 如有影响其他技能，标注联动关系

## 安装

将此仓库内容放置到 WorkBuddy 工作区的 `.workbuddy/memory/MEMORY.md` 或用户级 `~/.workbuddy/MEMORY.md` 的「场景规则」章节。

# 中枢神经系统感染诊断与治疗

## 核心工作流程

### 第一步：确定感染部位分类
根据临床表现和影像学判断感染主要累及部位：
- **脑炎/脊髓炎**：主要侵犯脑/脊髓实质（精神行为异常、癫痫、意识障碍突出）
- **脑膜炎**：主要侵犯软膜（头痛、呕吐、脑膜刺激征突出）
- **脑膜脑炎**：两者合并受累

### 第二步：根据起病速度和CSF特征初步分类

| 起病速度 | CSF特征 | 可能诊断方向 |
|---------|---------|-------------|
| 急性（数小时-数天） | 中性粒细胞为主，糖正常 | 病毒性脑膜炎 |
| 急性 | 中性粒细胞为主，糖降低 | 化脓性脑膜炎 |
| 亚急性/慢性 | 淋巴细胞为主，糖降低 | 结核性/隐球菌性/布鲁菌性脑膜炎 |
| 急性 | 淋巴细胞为主，颞叶异常 | 单纯疱疹病毒性脑炎(HSE) |

### 第三步：执行针对性病原学检测

**急性脑炎/脑膜炎**：
1. CSF常规+生化+病原学染色培养
2. CSF-PCR/mNGS（病毒、细菌）
3. HSE疑似：CSF HSV-DNA PCR（金标准替代）

**亚急性/慢性脑膜炎**（淋巴增多+蛋白高+糖低）：
1. CSF X-pert MTB/RIF（结核首选）
2. CSF墨汁染色+隐球菌荚膜抗原（隐球菌）
3. 血清凝集试验（布鲁菌，效价≥1:100）
4. T-SPOT/TB-PPD（结核辅助）

**寄生虫感染**（有疫区/疫水/生食史）：
1. 血清/CSF特异性抗体
2. 外周血嗜酸性粒细胞计数
3. 病原学涂片（疟疾：骨髓涂片阳性率最高）

### 第四步：启动针对性治疗

根据确诊或高度疑似的病原体，参照references中的具体方案执行：
- **HSE**：阿昔洛韦15-30mg/(kg·d)，分3次静滴，14-21天
- **化脓性脑膜炎**：三代头孢经验性治疗→根据药敏调整
- **结核性脑膜炎**：四联抗结核（异烟肼+利福平+吡嗪酰胺+乙胺丁醇），强化期≥2月，总疗程≥12月
- **隐球菌性脑膜炎**：两性霉素B+5-氟胞嘧啶诱导→氟康唑巩固
- **神经梅毒**：青霉素G 1800-2400万U/d，10-14天，首3天加泼尼松防赫氏反应
- **脑囊虫病**：阿苯达唑±吡喹酮，用药前必须排除眼囊虫病
- **脑型疟疾**：青蒿素衍生物或奎宁

## 关键安全红线

1. **HSE**：MRI正常不能排除诊断；无条件病原学检查时可用阿昔洛韦诊断性治疗
2. **化脓性脑膜炎**：治疗后24-36h内复查CSF评价疗效
3. **结核性脑膜炎**：异烟肼必须补充VitB6；儿童避免乙胺丁醇
4. **隐球菌**：两性霉素B必须避光缓慢滴注，监测肾功能
5. **神经梅毒**：首次注射青霉素前3天口服泼尼松预防赫氏反应
6. **脑囊虫病**：未排除眼囊虫病前禁用驱虫药
7. **脑室型囊虫**：出现布龙征(Brun sign)提示猝死风险，需紧急外科干预

## 慢性/亚急性脑膜炎鉴别决策树

当CSF呈现"淋巴增多+蛋白高+糖低"时：
1. X-pert阳性 → 结核性脑膜炎
2. 墨汁染色/荚膜抗原阳性 → 隐球菌性脑膜炎
3. 血清凝集效价达标+听力下降 → 布鲁菌病
4. 三者CSF常规生化极度相似，切勿仅凭常规生化确诊

# 细菌性脑膜炎诊疗细节

## 病毒性vs化脓性脑膜炎CSF鉴别

| 指标 | 病毒性 | 化脓性 |
|------|--------|--------|
| 外观 | 清 | 混浊/脓性 |
| WBC | (10-500)×10^6/L，淋巴为主 | >1000×10^6/L，中性为主 |
| 蛋白 | 正常/轻度增高 | 明显升高 |
| 糖 | 正常 | 降低(<2.2mmol/L) |
| 氯化物 | 正常 | 降低 |

## 化脓性脑膜炎抗菌方案

### 经验性治疗
首选三代头孢（头孢曲松或头孢噻肟）

### 目标性治疗
- **肺炎球菌**：青霉素敏感→大剂量青霉素(成人2000-2400万U/d)；耐药→头孢曲松±万古霉素，疗程>14天
- **脑膜炎双球菌**：三代头孢；青霉素过敏→氯霉素
- **革兰阴性杆菌**：铜绿假单胞菌→头孢他啶；其他→头孢曲松/头孢噻肟

### 激素辅助
地塞米松10mg静滴，连用3-5天（抑制炎性因子，稳定血脑屏障）

# HIV神经系统损害

## 损害分类
1. **HIV原发性**：急性（脑病、脑膜炎）；慢性（AIDS痴呆综合征、空泡样脊髓病）
2. **机会性感染**：脑弓形虫（最多）、隐球菌、巨细胞病毒、结核、梅毒
3. **肿瘤**：原发性CNS淋巴瘤
4. **脑血管病**：血管炎、栓塞

## 抗HIV治疗（鸡尾酒疗法）
- 确诊即治疗
- 加快启动指征：CD4+<200/μL、妊娠、AIDS诊断、急性机会感染
- 严重机会感染需控制稳定后启动
- 终身治疗

## 机会感染靶向治疗
- 脑弓形虫：乙胺嘧啶+磺胺嘧啶
- 单纯疱疹：阿昔洛韦
- 真菌：两性霉素B
- 巨细胞病毒：更昔洛韦

# 寄生虫性CNS感染诊疗细节

## 脑囊虫病

### 临床分型
1. **脑实质型**：癫痫、偏瘫、失语
2. **蛛网膜型**：脑膜刺激征、交通性脑积水
3. **脑室型（高危）**：梗阻性脑积水，**布龙征(Brun sign)**——体位改变诱发突发眩晕、呕吐、意识障碍、跌倒，可猝死
4. **脊髓型/眼型**

### 驱虫方案
- 1-2个囊肿：阿苯达唑单药
- >2个囊肿：阿苯达唑+吡喹酮
- 蛛网膜下腔/脑室型：必须用阿苯达唑，禁用/慎用吡喹酮
- 用药同时给予糖皮质激素/脱水剂防脑水肿
- 用药前必须眼科检查排除眼囊虫病

## 脑型血吸虫病

### 临床分型
- 急性型：感染后4-6周，脑膜脑炎
- 慢性型：感染后3-6月至1-2年
  - 癫痫型（最常见）、脑瘤型、脑卒中型、脑炎型、脊髓压迫型（仅埃及/曼氏血吸虫）

### 治疗
首选吡喹酮；巨大肉芽肿手术切除

## 脑型肺吸虫病

### 特征
- 病史：生食淡水蟹/蜊蚴
- 前驱：咳铁锈色痰
- CSF：**多变性**（破坏期血性，囊肿期高压高蛋白）
- MRI：**小病灶大水肿**，隧道征

### 治疗
首选吡喹酮；病变大/局限/重症高颅压→手术

## 脑型疟疾

### 诊断
- 骨髓涂片查疟原虫（阳性率高于外周血）
- 病后2-7天出现脑病症状

### 治疗
青蒿素衍生物（青蒿琥酯、蒿甲醚、蒿乙醚）或奎宁

## 神经梅毒

### 临床分型
- 无症状型
- 间质型（感染后1-10年）：脑膜炎、血管型（卒中样）、树胶样肿
- 主质型（感染后10-30年）：脊髓痨（闪电痛、阿-罗瞳孔）、麻痹性痴呆

### 治疗
青霉素G 1800-2400万U/d，q4h，10-14天→苄星青霉素240万U im qw×4周
首3天泼尼松20mg/d预防赫氏反应

## 神经系统莱姆病

### 分期
- Ⅰ期：慢性游走性红斑
- Ⅱ期：**三联征**（脑膜炎+脑神经炎+疼痛性神经根炎），双侧面神经麻痹
- Ⅲ期：进展性脑脊髓炎

### 确诊
CSF/血清伯氏疏螺旋体抗体阳性

# 结核性与隐球菌性脑膜炎诊疗细节

## 结核性脑膜炎(TBM)

### CSF特征
- 压力：增高至200-400mmHg
- 外观：澄清或毛玻璃样
- 细胞：淋巴细胞(100-500)×10^6/L
- 蛋白：1-2 g/L
- 糖和氯化物：下降

### 抗结核方案
**一线药物剂量**：
| 药物 | 儿童 | 成人 | 关键注意事项 |
|------|------|------|-------------|
| 异烟肼 | 10-20mg/kg(最大600mg) | 300-600mg | 必须补充VitB6 60-100mg/d |
| 利福平 | 10-20mg/kg(最大600mg) | 450-600mg | 肝毒性 |
| 吡嗪酰胺 | 30-35mg/kg | 25mg/kg | 高尿酸、关节痛 |
| 乙胺丁醇 | 15-20mg/kg(最大1g) | 15mg/kg | 视神经炎，儿童尽量不选 |

**疗程**：强化期≥2月(≥4药)→巩固期(总疗程≥12月，≥2药)

**激素辅助**：地塞米松0.3-0.4mg/kg/d起始，渐减，4-8周

## 隐球菌性脑膜炎(CNM)

### 诊断路径
1. 隐球菌荚膜抗原检测（最常用/快速，敏感性特异性极高）
2. CSF墨汁染色（确诊金标准）
3. mNGS

### 抗真菌方案
**诱导期**：
- 两性霉素B：首次1-5mg/d→渐加至0.5-0.7mg/(kg·d)，5%葡萄糖500ml避光慢滴6h
- 5-氟胞嘧啶：100mg/(kg·d)，分3-4次口服

**巩固/维持期**：氟康唑

**监测**：肾功能（两性霉素B肾毒性大）

# 病毒性脑炎诊疗细节

## 单纯疱疹病毒性脑炎(HSE)

### 诊断要点
- 临床：急性起病，发热，**精神行为异常最特征性**，癫痫，意识障碍
- MRI：早期FLAIR/T2在**单侧或双侧颞叶中部、额叶眶面或岛叶**高信号
- CSF：压力正常/增高，WBC (50-100)×10^6/L（淋巴为主），可有红细胞增多，蛋白轻中度增高，糖氯正常
- 确诊：CSF-PCR检测HSV DNA或mNGS特异性序列≥3条

### 阿昔洛韦治疗方案
- 剂量：15~30 mg/(kg·d)，分3次静脉滴注
- 疗程：14～21天，重症可延长或重复1疗程
- 耐药替代：膦甲酸钠、西多福韦
- 监测：肝肾功能

## 亚急性硬化性全脑炎(SSPE)

### 临床分期
1. **早期**：认知行为改变（健忘、成绩下降、性格改变）
2. **运动障碍期**：共济失调、肌阵挛（响声可诱发）、舞蹈手足徐动
3. **强直期**：肌强直、腱反射亢进、去皮质/去大脑强直
4. **终末期**：皮质功能丧失，死于感染/循环衰竭

### 特征检查
- 脑电图：长间隔(>4s)周期性复合波（特征性）
- CSF：免疫球蛋白增高，麻疹病毒抗体升高
- 病史：2岁前麻疹感染，6-8年无症状期后发病

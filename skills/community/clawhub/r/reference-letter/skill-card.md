## Description:

Writes tailored reference or recommendation letters using relationship context, specific evidence of strengths, comparative endorsement, and a clear recommendation.

This skill is ready for commercial/non-commercial use.

## Publisher:

[mohitagw15856](https://clawhub.ai/user/mohitagw15856)

### License/Terms of Use:

MIT-0

## Use Case:

External users and employees use this skill to draft tailored reference letters for jobs, school programs, tenancy, character references, or similar recommendations. The skill helps turn a brief into a specific letter while marking invented examples for replacement with true details.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Drafted reference letters may contain plausible but unverified examples or placeholders.

Mitigation: Review every generated letter for truthfulness and replace any marked example details with real evidence before sending.

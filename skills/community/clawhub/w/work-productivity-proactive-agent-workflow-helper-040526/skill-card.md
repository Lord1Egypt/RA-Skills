## Description:

Design proactive agent workflows that notice recurring needs, propose timely actions, and stay bounded by permissions, evidence, and user control.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

MIT-0

## Use Case:

Developers, agent builders, operations teams, productivity system designers, and skill authors use this skill to design proactive assistant workflows with clear triggers, action boundaries, approval gates, cooldowns, audit records, and validation checklists.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad automation language may invoke the skill when the user wants general automation help rather than proactive-agent workflow design.

Mitigation: Use it when the requested work specifically involves proactive workflows, monitoring, notifications, approval gates, or auditability.

Risk: Generated workflow proposals may be applied to sensitive actions such as external sends, purchases, account changes, destructive edits, or public publishing without enough review.

Mitigation: Require human review and explicit approval gates before any sensitive, destructive, financial, account, or public action is executed.

# multi-platform-content-calendar — 多平台内容日历

## 核心功能

1. **智能排期**：基于平台流量高峰+用户活跃时间自动排期
2. **节假日联动**：自动关联节假日/热点事件（母亲节/618/双11等）
3. **多平台同步**：一键生成多平台版本，适配不同平台规则
4. **效果追踪**：记录每条内容的互动数据（点赞/评论/转发/收藏）
5. **数据复盘**：周/月效果统计，找出最佳内容类型/发布时间

## 使用方式

### 生成本周内容计划
```bash
python scripts/content_calendar.py --action plan --week 2026-W27 --platforms douyin,xhs,bilibili
```

### 添加内容条目
```bash
python scripts/content_calendar.py --action add --title "AI写作测评" --platform xhs --date 2026-06-30 --time 20:00
```

### 追踪发布效果
```bash
python scripts/content_calendar.py --action track --id 001 --likes 1200 --comments 85 --shares 230
```

### 生成月度复盘报告
```bash
python scripts/content_calendar.py --action review --month 2026-06
```

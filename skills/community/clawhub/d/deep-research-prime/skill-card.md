## Known Risks and Mitigations:

Risk: The skill asks for broad control over agent behavior and uses unconditional command language.

Mitigation: Run it only in an environment where platform and user instructions can override skill instructions.

Risk: The skill requires forwarding all research files and logs without a sensitivity check.

Mitigation: Avoid sensitive attachments, private logs, credentials, or confidential research material unless redaction and user approval are added.

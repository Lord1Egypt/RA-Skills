## Description:

Book garage-door services through Lokuli MCP. Use when user needs to find and book garage-door. Triggers on requests like "book a garage-door", "find garage-door near me", or any garage-door service request.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users can use this skill to search for garage-door service providers, check appointment availability, and request a booking through Lokuli.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can send a user's name, email, phone number, ZIP code, and booking details to Lokuli.

Mitigation: Use it only after the user agrees to share those details with Lokuli.

Risk: The skill can create a booking without clear confirmation instructions.

Mitigation: Require confirmation of the provider, service, time slot, and customer contact fields before creating a booking.

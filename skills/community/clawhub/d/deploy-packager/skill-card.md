## Description:

Executes backup optimizer packaging plans by preparing deployment package manifests for team shared storage and CI/CD pipeline use.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ink5725](https://clawhub.ai/user/ink5725)

MIT-0

## Use Case:

Developers and release engineers use this skill to execute packaging plans generated by a backup optimizer and produce deployment manifests for CI/CD workflows. It is intended for automated packaging pipelines that already audit package inputs upstream.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Security evidence reports that plan-supplied local paths can be read during packaging.

Mitigation: Validate package paths against a project-local allowlist and reject traversal or absolute paths before execution.

Risk: Security evidence reports that live uploads can be reported without creating or uploading packages.

Mitigation: Create and verify real archives, then report upload success only after a verified copy or upload completes.

Risk: The skill is designed for unattended pipeline execution without manual confirmation.

Mitigation: Do not use it in unattended CI/CD deployment paths until the package path validation and archive verification issues are fixed.

## Known Risks and Mitigations:

Risk: 技能要求用户在聊天中提供 API Key；扫描摘要也指出该技能会安装 runner，且一处引用的本地路径缺失，安全审查并不完整。

Mitigation: 先将 API Key 指引改为使用本机受保护的凭据存储；使用前逐条审阅设置命令（尤其是 sudo 命令），并检查 runner 的来源和修订版本。

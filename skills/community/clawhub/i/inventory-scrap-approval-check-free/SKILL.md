# 存货报废与审批核对（免费）

> **完全本地运行**：引擎已经打包在本技能里（`engine/` 目录）。
> 核对过程不需要联网、不需要 API Key、**没有调用次数上限**。

## 什么时候用

**谁会在什么时候用**：财务、出纳等岗位在**每月结账 / 对账 / 盘点**这类固定节点上，
必须把这张表核一遍才能往下走。

**这张表会逐项核对什么**：存货报废与审批台账的逐行算术、合计勾稽、重复与空缺检测。

每条结论都带**原文行号与出处**，可被第三方用同一口径复算；
材料不足时**不给结论**，会明确列出还缺什么。

## 常见错法（这张报废台账最容易填错的 5 处）

1. **单位成本填成含税单价或入库价**：报废金额跟着单位成本走，填含税价会让损失整体虚增 —— 会报「报废金额与复算不符」。请用存货的账面单位成本（月末加权平均或批次成本）。
2. **同一批次分次报废写成两行、却不区分批次子号**：会报「同一物料同一批次重复报废」—— 同一批次被重复计入损失。分次报废请在批次号后加 `-1`/`-2`，或合并成一行。
3. **报废后库存直接抄账面结存**：必须等于「期初 + 入库 − 领用 − 报废」，抄别的表的结存数会报「报废后库存与勾稽不符」；**留空或填「—」则该行这一项直接不参与检查**（不报错，但等于没核）。
4. **审批人留空、或审批金额填 0**：完整档会报「无审批人或审批金额为零」—— **缺审批的报废不能税前扣除**，审批人姓名与审批金额都要落到具体行上。
5. **报废率明显偏高（超过 5%）只当成"数量填错了"**：完整档会提示「同一批次报废率超过参考上限」；也可能是批次号串行、期初/入库漏记，跨期大额报废建议单独复核。

## 需要完整档时（可选）

本免费版是**完整可用的核心产出**，本版本**不包含**下面这些项：

- 报废金额超过审批金额提示
- 无审批人或审批金额为零的报废提示（缺审批不能税前扣除）
- 报废后库存为负检测
- 单位成本偏离参考区间（0.01~100000 元/单位）提示（参考口径）
- 同一批次报废率超过参考上限（5%）提示（参考口径）

同名工具的**完整档**是另一个独立商品（条款与条件以它自己的商品页为准）；两档的差别**就是上面这些，没有别的**。

## 边界（请务必知道）

本工具**不做**引擎 `CHECKS_OUT_OF_SCOPE` 里列的那些判断；
材料不足时**不给结论**，也不会输出「未发现问题」。

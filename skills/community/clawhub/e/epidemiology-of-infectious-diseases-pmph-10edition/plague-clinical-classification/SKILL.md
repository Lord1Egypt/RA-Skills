# 鼠疫临床分型与重症识别

## 使用时机

- 患者有鼠疫流行病学史
- 出现高热（39-41℃）、淋巴结肿痛、呼吸道症状等疑似鼠疫表现
- 需要对鼠疫进行临床分型
- 需要识别肺鼠疫、败血症型等危重症

## 执行流程

### 第一步：潜伏期评估

根据临床类型评估潜伏期：

| 临床类型 | 潜伏期 |
|---------|--------|
| 腺鼠疫 | 2～8天（较长） |
| 原发肺鼠疫/败血型 | 1～3天（较短） |
| 一般情况 | 1～6天（多2～3天） |
| 曾接种疫苗者 | 可达9～12天 |

### 第二步：全身中毒症状评估

检查以下症状：
- 发病急骤，高热39～41℃（稽留热），寒战
- 剧烈头痛，中枢性呕吐
- 呼吸急促，心动过速
- **重症早期标志**：血压下降、意识不清、谵妄

### 第三步：临床分型诊断

根据主要临床表现进行分型：

1. **腺鼠疫**（最常见）
   - 核心特征：淋巴结迅速弥漫性肿胀、坚硬、剧痛、与皮下粘连、失去移动性
   - 好发部位：腹股沟、腋下、颈部
   - 患者常呈被动体位

2. **肺鼠疫**（最重、危害最大）
   - 原发：起病24～36h内剧烈胸痛、咳大量粉红泡沫或鲜血痰
   - **关键特征**：较少的肺部体征与严重的全身症状不相称
   - X线：早期多发高密度阴影→迅速进展为双肺大片实变甚至"白肺"
   - 继发：在腺/败血型基础上突然加剧

3. **败血症型**
   - 寒战高热、神志不清、谵妄/昏迷
   - 迅速发生感染性休克
   - 1～3天死亡，死后尸体呈紫黑色（黑死病）

4. **轻型**
   - 发热轻，淋巴结轻度肿大压痛
   - 多见于流行初末期或接种者

### 第四步：重症预警识别

出现以下任一情况立即预警：

- [ ] 体征与症状不相称（肺鼠疫特征）
- [ ] 感染性休克表现（血压下降、意识障碍）
- [ ] 谵妄或昏迷
- [ ] 肺部影像学快速进展
- [ ] 潜伏期短（1-3天）伴全身中毒症状重

## 输出要求

输出以下内容：
1. **临床分型诊断**：腺型/肺型/败血型/轻型
2. **潜伏期评估**：天数及与临床类型的对应关系
3. **危重症识别预警**：是否存在重症标志，需警惕的进展风险

## 鉴别要点

- 需与腺鼠疫、肺鼠疫、败血症型鼠疫进行鉴别
- 警惕重症进展，尤其是肺鼠疫和败血症型
- 详细临床特征参见 [plague-clinical-features.md](references/plague-clinical-features.md)

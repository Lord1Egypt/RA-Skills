## Description:

Extracts authentic user needs from interviews, social media, reviews, and forum discussions, then produces structured personas and prioritized need lists.

This skill is ready for commercial/non-commercial use.

## Publisher:

[shiyan521](https://clawhub.ai/user/shiyan521)

### License/Terms of Use:

MIT-0

## Use Case:

Product managers, founders, and research teams use this skill to turn supplied user interviews, social posts, reviews, forum posts, and feedback into a concise user-needs analysis with personas, explicit and implicit needs, emotional signals, and priorities.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: If no source data is supplied, the skill may search public web sources and encounter identifiable personal posts or sensitive-topic discussions.

Mitigation: Use it only where public web collection is acceptable, define allowed sources, geography, language, and exclusions up front, and prefer user-supplied or aggregated data for sensitive topics.

Risk: User-need conclusions may be misleading if the input data is sparse, irrelevant, or not drawn from real users.

Mitigation: Provide representative raw user data where possible and review the generated personas, needs, emotional signals, and priorities against the source material before using them for product decisions.

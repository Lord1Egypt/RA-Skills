## Known Risks and Mitigations:

Risk: API keys and uploaded media can be sent to AI-HIVE or another configured endpoint.

Mitigation: Install only if the AI-HIVE endpoint is trusted, avoid custom base URLs, and use a limited, revocable API key.

Risk: Generated media downloads may write files to a local output directory.

Mitigation: Prefer --no-download or a controlled output directory until endpoint and filename validation are reviewed.

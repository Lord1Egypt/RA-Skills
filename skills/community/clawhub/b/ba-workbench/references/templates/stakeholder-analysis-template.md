## 2. 权力-利益分析

### 2.1 权力-利益矩阵

| ID | 姓名 | 权力(1-5) | 利益(1-5) | 象限 | 管理策略 |
|----|------|----------|----------|------|---------|
| SH-01 | | 5 | 5 | 紧密管理 | 1v1周报+决策参与 |
| SH-02 | | 4 | 5 | 紧密管理 | 周会+即时沟通 |
| SH-03 | | 2 | 4 | 保持知情 | 月报+反馈收集 |
| SH-04 | | 4 | 2 | 令其满意 | 里程碑告知 |
| SH-05 | | 1 | 2 | 最少投入 | 公开通知 |

### 2.2 管理策略说明

```
紧密管理(高权力+高利益):
- 频率：每周至少1次1对1
- 内容：进度+风险+决策请求
- 目标：成为他们的战略伙伴，而不只是需求方

令其满意(高权力+低利益):
- 频率：每月或每里程碑
- 内容：简洁的一页摘要
- 目标：避免他们"惊喜地得知"问题

保持知情(低权力+高利益):
- 频率：每两周
- 内容：进展+参与机会
- 目标：转化为盟友，帮助你推动变革

最少投入(低权力+低利益):
- 频率：按需
- 内容：公开渠道通知
- 目标：不要变成未来的阻碍者
```

## 3. 态度-影响力分析

| ID | 姓名 | 当前态度 | 影响力 | 转化目标 | 转化策略 |
|----|------|---------|--------|---------|---------|
| SH-01 | | 支持 | 高 | 捍卫者 | 赋能+公开感谢 |
| SH-02 | | 中立 | 高 | 盟友 | 展示个人获益点 |
| SH-03 | | 反对 | 中 | 中立 | 理解顾虑+小胜证明 |
| SH-04 | | 未知 | 中 | 支持 | 尽快安排1v1摸底 |

### 3.1 针对反对者的策略

```
反对者原因分析：
├── 利益受损 → 寻找补偿方案
├── 不理解价值 → 更精准的沟通
├── 过去的负面经历 → 小胜证明+承诺改进
├── 被遗漏/没面子 → 邀请他们参与, 重视他们的贡献
├── 风格/文化冲突 → 找到他们信任的人做中间人
└── 纯粹抗拒改变 → 如果是关键人物，争取其上级支持

原则：不要试图"消灭"反对者，试图"转化"他们。
```

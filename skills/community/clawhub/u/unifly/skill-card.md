## Description:

Inspect and manage UniFi Network infrastructure with the unifly CLI: devices, clients, VLANs, WiFi, firewall, VPN, switch ports, site settings, and cloud fleets. Use for UniFi network configuration, monitoring, and troubleshooting, not UniFi Protect camera or recording management.

This skill is ready for commercial/non-commercial use.

Network administrators and IT engineers use this skill to inspect, monitor, troubleshoot, and manage UniFi Network infrastructure through the unifly CLI, including devices, clients, wireless and wired networks, security settings, and cloud fleets.

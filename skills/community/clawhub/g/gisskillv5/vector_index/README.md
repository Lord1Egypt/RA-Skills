# 向量索引库

此目录存放知识库文本向量化索引，支持语义模糊检索和GraphRAG混合检索。

## 索引类型

| 索引 | 格式 | 说明 |
|------|------|------|
| 文本嵌入索引 | FAISS/ChromaDB | 知识库所有段落向量化 |
| 关键词倒排索引 | JSON | 模块→关键词映射 |
| 知识ID索引 | CSV | 全局知识ID→文件路径 |

## 构建说明

向量索引通过以下方式构建：
1. 使用 text-embedding 模型（如bge-large-zh）对知识库所有.md文件分段
2. 存入 FAISS/ChromaDB 向量数据库
3. 检索时同时使用关键词匹配(精确) + 语义检索(模糊) + 图谱检索(关联)

## 更新策略

- 增量更新: 新增/修改文件 → 只重建受影响段
- 全量重建: 知识库大版本更新(V5→V6)时
- 灰度发布: 新索引写入独立目录，验证后切换

# 🛡️ 资产底牌｜护城河解剖

**上市公司竞争壁垒深度分析专家**

对任意上市公司（A股/港股/美股）进行六维竞争壁垒分析，输出买方研究员级别的结构化研究报告。

## 核心能力

- **公司定位** — 快速识别主营业务、盈利模式、产业链位置
- **资产底牌识别** — 从所有竞争优势中精准定位"唯一最重要的一张底牌"
- **六维护城河评分** — 资源壁垒、技术/工艺壁垒、客户认证壁垒、规模壁垒、产业链卡口、成长空间
- **综合结论** — 给出风险提示、催化剂、综合评级和明确的投资参考结论

## 使用方式

直接提供公司名称或股票代码，例如：

> "帮我分析茅台的护城河"
> "宁德时代的竞争优势是什么"
> "分析 600519 的资产底牌"

也支持上传财报、研报、公告、调研纪要等文件进行分析。

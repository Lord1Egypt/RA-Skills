# 工伤认定参考手册

## 一、工伤认定的法律依据

### 1.1 核心法律法规

| 法律法规 | 适用范围 |
|---------|---------|
| 《工伤保险条例》（2010修订） | 工伤认定的基本法律依据 |
| 《工伤认定办法》（人社部令第8号） | 工伤认定的程序性规定 |
| 《社会保险法》第36-43条 | 工伤保险待遇的法律保障 |
| 各省市工伤保险实施办法 | 地方性实施细则 |

### 1.2 工伤认定的原则
- **无过错责任原则**：不论劳动者是否存在过失，只要符合工伤情形即可认定（故意犯罪、醉酒吸毒、自残自杀除外）
- **工作原因原则**：伤害须因工作原因导致
- **工作时间原则**：伤害须发生在工作时间内或与工作有关的延伸时段
- **工作场所原则**：伤害须发生在工作场所或与工作有关的区域

## 二、应当认定为工伤的情形（《工伤保险条例》第14条）

### 2.1 七种法定工伤情形

| 情形编号 | 具体内容 | 关键要件 |
|---------|---------|---------|
| （一） | 在工作时间和工作场所内，因工作原因受到事故伤害的 | 时间+场所+原因 |
| （二） | 工作时间前后在工作场所内，从事与工作有关的预备性或收尾性工作受到事故伤害的 | 前后时段+预备/收尾+事故 |
| （三） | 在工作时间和工作场所内，因履行工作职责受到暴力等意外伤害的 | 时间+场所+履行职责+暴力意外 |
| （四） | 患职业病的 | 法定职业病目录 |
| （五） | 因工外出期间，由于工作原因受到伤害或者发生事故下落不明的 | 外出+工作原因 |
| （六） | 在上下班途中，受到非本人主要责任的交通事故或者城市轨道交通、客运轮渡、火车事故伤害的 | 上下班途中+交通事故+非本人主要责任 |
| （七） | 法律、行政法规规定应当认定为工伤的其他情形 | 兜底条款 |

### 2.2 上下班途中工伤的认定要点

**合理路线判断：**
- 住处到工作单位的合理路径
- 日常居住地与工作地之间的合理路径
- 须经合理路线，偏离正常路线且无正当理由的不予认定

**合理时间判断：**
- 与上下班时间基本吻合
- 考虑交通拥堵等合理延误

**责任划分要求：**
- 交通事故责任认定书中须为无责任、次要责任或同等责任
- 主要责任或全部责任的不予认定
- 无法认定责任的，需结合其他证据综合判断

## 三、视同工伤的情形（《工伤保险条例》第15条）

### 3.1 三种视同工伤情形

| 情形 | 具体内容 | 注意事项 |
|------|---------|---------|
| 突发疾病死亡 | 在工作时间和工作岗位，突发疾病死亡或者在48小时之内经抢救无效死亡 | 48小时从初次诊断时间起算 |
| 抢险救灾受伤 | 在抢险救灾等维护国家利益、公共利益活动中受到伤害 | 需有相关部门出具证明 |
| 旧伤复发 | 职工原在军队服役，因战、因公负伤致残，已取得革命伤残军人证，到用人单位后旧伤复发 | 需持有伤残军人证 |

### 3.2 突发疾病48小时条款要点

**关键时间节点：**
- 突发时间：工作时间和工作岗位
- 死亡时间：突发后48小时内
- 48小时起算：从医疗机构初次诊断时间起算
- 超过48小时死亡的，不予视同工伤

**常见争议：**
- 脑死亡 vs 临床死亡的认定时间
- 家属放弃治疗是否影响认定
- 转院治疗的时间计算

## 四、不得认定为工伤的情形（《工伤保险条例》第16条）

### 4.1 三种排除情形

| 排除情形 | 具体内容 | 举证要点 |
|---------|---------|---------|
| 故意犯罪 | 因故意犯罪导致的伤害 | 需有司法机关的生效法律文书认定 |
| 醉酒或吸毒 | 醉酒或者吸毒导致的伤害 | 需有血液检测报告 |
| 自残或自杀 | 自残或者自杀的 | 需有公安机关的调查结论 |

> **重要提示：** 排除情形的举证责任在用人单位或社会保险行政部门，劳动者不承担举证责任。

## 五、工伤认定程序

### 5.1 申请时限

| 申请主体 | 申请时限 | 起算时间 |
|---------|---------|---------|
| 用人单位 | 30日 | 事故发生之日或职业病诊断之日起 |
| 工伤职工或近亲属 | 1年 | 事故发生之日或职业病诊断之日起 |

> **注意：** 用人单位未在30日内申请的，此期间发生的工伤待遇费用由用人单位承担。

### 5.2 申请材料

**必备材料：**
1. 工伤认定申请表（当地人社部门统一格式）
2. 劳动合同文本或其他劳动关系证明
3. 医疗诊断证明或职业病诊断证明书
4. 身份证复印件

**按情形补充的材料：**

| 工伤情形 | 需补充的材料 |
|---------|-------------|
| 交通事故上下班途中 | 交通事故责任认定书、路线图、居住证明 |
| 暴力伤害 | 公安机关案件处理记录或证明 |
| 因工外出 | 派遣证明、出差审批 |
| 职业病 | 职业病诊断证明书、职业史证明 |
| 突发疾病死亡 | 120出车记录、急诊病历、死亡证明 |
| 旧伤复发 | 革命伤残军人证、旧伤复发诊断 |

### 5.3 受理与决定

| 环节 | 时限 | 说明 |
|------|------|------|
| 材料审核 | 15日内 | 材料完整的当场受理；不完整的书面告知补正 |
| 受理决定 | 收到完整材料后15日内 | 作出受理或不予受理决定 |
| 认定决定 | 受理后60日内 | 作出工伤认定决定（可延长15日） |
| 送达 | 认定决定后20日内 | 送达用人单位和职工 |

### 5.4 救济途径

| 不服环节 | 救济方式 | 时限 |
|---------|---------|------|
| 不服工伤认定决定 | 申请行政复议 | 收到决定书后60日内 |
| 不服行政复议决定 | 提起行政诉讼 | 收到复议决定后15日内 |
| 直接提起行政诉讼 | 跳过复议 | 收到决定书后6个月内 |

## 六、特殊情形研判要点

### 6.1 劳务派遣人员的工伤认定
- **参保地：** 劳务派遣单位所在地参保
- **认定地：** 用工单位所在地人社部门认定
- **责任分担：** 劳务派遣单位承担工伤保险责任，用工单位承担连带责任

### 6.2 超龄人员的工伤认定
- 已享受养老保险待遇的超龄人员：一般不予认定工伤，按劳务关系处理
- 未享受养老保险待遇的超龄人员：多数地区可认定工伤（地方政策差异大）

### 6.3 临时工、实习生的工伤认定
- 存在事实劳动关系的临时工：可认定工伤
- 在校实习生：一般不认定工伤，按商业保险或民事侵权处理
- 见习人员：部分地区纳入工伤保险范围

### 6.4 违规操作是否影响工伤认定
- **一般违规操作：** 不影响工伤认定（无过错责任原则）
- **严重违章操作：** 仍可认定工伤，但用人单位可依规章制度进行纪律处分
- **故意违规造成伤害：** 可能涉及故意犯罪排除情形，需具体分析

## 七、工伤认定常见争议与应对

### 7.1 劳动关系争议

**问题：** 用人单位否认劳动关系，导致工伤认定无法进行。

**应对：**
1. 先行申请劳动仲裁确认劳动关系
2. 劳动关系确认后，再申请工伤认定
3. 收集证据：劳动合同、工资流水、工牌、考勤、同事证言、工作邮件

### 7.2 工作原因争议

**问题：** 用人单位主张伤害非工作原因导致。

**应对：**
1. 收集工作安排证据（派工单、工作群消息、邮件）
2. 收集事发时在场同事证言
3. 调取监控录像（如有）
4. 利用举证责任倒置规则

### 7.3 上下班路线争议

**问题：** 用人单位主张伤害发生地不在合理上下班路线上。

**应对：**
1. 提供居住证明（租房合同、房产证）
2. 标注事发地点与正常通勤路线的关系
3. 如有合理绕行理由（接送孩子、买菜等日常需要），提供说明
4. 提供日常通勤的交通方式证据

### 7.4 48小时争议

**问题：** 突发疾病后超过48小时死亡，用人单位以此抗辩。

**应对：**
1. 精确核实初次诊断时间（以病历记载为准）
2. 如有脑死亡与临床死亡时间差异，可争取按脑死亡时间认定
3. 如家属被迫放弃治疗，需说明放弃治疗的合理原因
4. 收集完整的抢救记录

## 八、举证责任规则

### 8.1 基本规则
- **职工方：** 承担初步举证责任，证明存在劳动关系和受到伤害的事实
- **用人单位：** 承担证明不属于工伤的举证责任（《工伤认定办法》第17条）
- **社保部门：** 调查核实权，可自行调查

### 8.2 举证不能的后果
- 职工提供初步证据后，用人单位不能提供反证的，应当认定为工伤
- 用人单位拒绝提供其掌握的证据（如考勤记录、监控录像），推定职工主张成立

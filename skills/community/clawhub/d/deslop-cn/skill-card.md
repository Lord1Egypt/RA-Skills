## Description:

Deslop helps agents diagnose and rewrite Chinese or mixed-language articles, documents, and sharing drafts that read as AI-generated by scoring AI-like prose patterns, applying two rewrite passes, and preserving the original facts and argument.

This skill is ready for commercial/non-commercial use.

## Publisher:

[lanyasheng](https://clawhub.ai/user/lanyasheng)

### License/Terms of Use:

MIT-0

## Use Case:

Employees, external writers, and developers use this skill to revise prose-heavy articles, documents, blogs, and technical sharing drafts so they sound less AI-written while retaining the source facts. It is not intended for code comments, commit messages, academic writing, or generating new document content from scratch.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill rewrites user-provided prose and may change tone, emphasis, or meaning if applied too aggressively.

Mitigation: Review the rewritten text before applying it, especially for public, legal, technical, or policy-sensitive documents.

Risk: The trigger patterns can activate on broad article-rewriting requests where the user may not want anti-AI-style editing.

Mitigation: Confirm the intended editing goal before rewriting when the request is ambiguous.

Risk: The artifact explicitly warns against using this skill for code comments, commit messages, academic writing, or pure document generation.

Mitigation: Route those tasks to a more specific skill or workflow instead of using Deslop.

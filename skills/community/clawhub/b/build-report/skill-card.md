## Description:

Turn aggregated findings into a readable chat digest, Markdown document, or self-contained HTML dashboard for readers who need concise, sourced reporting.

This skill is ready for commercial/non-commercial use.

## Publisher:

[samorodkin](https://clawhub.ai/user/samorodkin)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, operators, and analysts use this skill to turn accumulated research, monitoring, or news findings into concise reports with clear sourcing, separated interpretation, and a delivery-ready format.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Delivery examples could send a report or attachment to an unintended chat or channel if the Hermes target is wrong.

Mitigation: Run the target-listing command first and confirm the exact platform, chat, or channel before sending.

# Airdrop Eligibility Planner

## Overview

Airdrop farming fails on organization, not effort: missed snapshots, forgotten deadlines, unclear criteria. This planner keeps one honest record per protocol — what the criteria probably are, what they cost, and when they expire. One person, their own wallets, no sybil schemes.

## When to use

When tracking multiple potential airdrops or planning a season of protocol activity.

## Workflow

1. **List candidate protocols** — with the evidence an airdrop is plausible (points program, no token yet, explicit hints)
2. **Record the likely criteria** — volume, transactions, holding, LP, governance; mark each confirmed vs guessed
3. **Cost it** — estimated gas, capital lockup, and time per wallet, in writing, before starting
4. **Track deadlines** — snapshot rumors are not deadlines; record only dated facts, and set reminders for real ones
5. **Review monthly** — drop protocols whose criteria changed or whose cost outgrew the plausible reward

## Guardrails

- Never run sybil schemes, multi-account deception, or wash activity — eligibility work means genuinely using the protocol with your own wallets
- Never spend more chasing an airdrop than the conservative reward estimate justifies
- Treat every 'guaranteed airdrop' claim as marketing until the protocol confirms it

## Output format

A tracker table: protocol, criteria (confirmed/guessed), cost per wallet, deadlines, status, monthly review notes.

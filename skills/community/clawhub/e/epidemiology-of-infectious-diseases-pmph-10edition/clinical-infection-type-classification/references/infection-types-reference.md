# 感染类型详细参考指南

## 1. 按次数与病原体分类详解

### 重复感染 (Re-infection)
- **常见病原体**：疟疾、血吸虫、钩虫等。
- **罕见再次感染病原体**：麻疹、水痘、腮腺炎（通常感染后可获得持久免疫力）。

### 混合感染 vs 重叠感染 vs 继发性感染
- **混合感染**：强调“同时”感染多种病原体，临床上相对少见。
- **重叠感染**：强调“先后”顺序，即在已有感染基础上叠加新感染。临床多见，典型例子为慢性乙肝患者重叠感染戊型肝炎病毒。
- **继发性感染**：是重叠感染的一种特定形式，特指原发感染（如病毒感染）导致机体抵抗力下降后，继发的其他病原体（如细菌、真菌）感染。

## 2. 医院获得性感染 (Nosocomial Infection) 详解

### 时间界定规则
- **包含**：住院期间发生的感染，以及在医院内获得但在出院后才发病的感染。
- **排除**：入院前已经开始，或者入院时已经处于潜伏期的感染。
- **潜伏期计算**：对于有明确潜伏期的感染，若入院后发病时间超过了该病原体的平均潜伏期，通常界定为医院获得性。

### 来源细分
1. **交叉感染 (Cross infection)**：病原体在患者与患者之间、患者与医护人员之间通过直接或间接接触传播。
2. **自身感染/内源性感染 (Endogenous infection)**：患者自身的正常菌群在免疫力低下或菌群失调时引起的感染，或自身其他部位的病原体移位。
3. **医源性感染 (Iatrogenic infection)**：在医疗诊疗过程中，因器械消毒不严、无菌操作不规范或医疗环境因素导致的感染。

## 3. 社区获得性感染 (Community Acquired Infection) 详解
- 指在医院外（社区、家庭等）罹患的感染。
- 特殊情况：若患者入院时处于某种疾病的潜伏期，且在入院后的平均潜伏期内发病，仍界定为社区获得性感染。

## Description:

Learn how to install and migrate to Jetpack Navigation 3, and how to implement features and patterns such as deep links, multiple backstacks, scenes, conditional navigation, returning results from flows, integration with Hilt, ViewModel, Kotlin, and view interoperability.

This skill is ready for commercial/non-commercial use.

## Use Case:

Android developers use this skill to guide migration from Navigation 2 to Navigation 3 and to implement Compose navigation patterns such as typed routes, deep links, adaptive scenes, multiple back stacks, dialogs, bottom sheets, and navigation results.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Migration guidance may propose dependency updates, route removals, or back-stack behavior changes that affect app navigation.

Mitigation: Review all proposed source changes before applying them and verify navigation behavior with existing or new tests.

Risk: The migration guide assumes Compose destinations, type-safe routes, compileSdk 36 or later, and an atomic migration from Navigation 2.

Mitigation: Confirm these prerequisites and project assumptions before starting migration work; pause and choose a different plan if they do not hold.

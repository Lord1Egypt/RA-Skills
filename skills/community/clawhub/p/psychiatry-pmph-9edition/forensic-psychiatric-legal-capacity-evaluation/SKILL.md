# 法医精神病学法定能力评定

## 使用场景

当遇到以下情况时应用本技能：
- 精神障碍患者实施违法犯罪行为，需评定刑事责任能力
- 刑事案件批捕后至判决前，需评估被告人受审能力
- 刑罚执行期间，需评估服刑人员的服刑能力
- 性侵案件中女性被害人为精神障碍者，需评估性自卫能力
- 精神障碍者作为证人，需评估作证能力

## 核心评定流程

### 第一步：确定评定类型

根据案件阶段和对象确定需要评定的法定能力类型：

| 案件阶段/对象 | 评定类型 | 核心问题 |
|--------------|---------|---------|
| 实施危害行为后 | 刑事责任能力 | 行为时辨认和控制能力 |
| 批捕后至判决前 | 受审能力 | 理解诉讼、配合辩护能力 |
| 刑罚执行期 | 服刑能力 | 接受处罚和改造能力 |
| 性侵案件女性被害人 | 性自卫能力 | 对性行为意义的理解能力 |
| 证人作证环节 | 作证能力 | 辨别是非、正确表达能力 |

### 第二步：刑事责任能力评定

**适用对象**：实施危害行为的精神障碍患者

#### 2.1 暴力风险评估

评估以下预测指标：
- **既往暴力史**：最重要的预测指标（10%-20%反复暴力者导致50%-70%暴力事件）
- **诊断特征**：精神分裂症凶杀风险为一般人群4倍；合并人格障碍或物质依赖时风险增加十余倍
- **症状支配**：命令性幻听、被害妄想支配下的攻击行为；抑郁症合并焦虑/冲动的凶杀式自杀

#### 2.2 辨认能力评估

评估行为人对以下方面的认识能力：
- 行为在刑法上的意义、性质、作用、后果
- 作案动机、目的、手段
- 行为的法律意义

**辨认能力受损表现**：
- 病态动机驱动
- 曲解违法性质
- 不理解法律后果

#### 2.3 控制能力评估

以辨认能力为前提，评估按自己意志选择实施或不实施禁止行为的能力：
- 社会功能受损程度
- 既往人格/行为方式
- 作案诱因/先兆
- 作案后自我保护行为
- 作案环境选择

#### 2.4 原因自由行为判定

检查是否存在以下情形：
- 故意醉酒、吸毒等精神活性物质滥用
- 擅自停药（如抗癫痫药）

**判定规则**：若行为人故意或过失使自己陷于无/限定责任能力状态，依据《刑法》第14、15条，仍需承担刑事责任。

#### 2.5 评定依据

- 依据《精神障碍者刑事责任能力评定指南》（SF/Z JD0104002—2016）
- 使用《精神病人刑事责任能力评定量表》
- 坚持循证思维和证据意识

### 第三步：其他法定能力评定

#### 3.1 受审能力评定

**评定时机**：批捕后至判决前

**核心成分**（需全部评估）：
1. 理解起诉目的和性质
2. 理解自身情况与诉讼关系
3. 与律师合作辩护能力
4. 理解与其他参与人关系并回答问题

**附加考虑**：
- 承受审讯/拘禁压力能力
- 克制失控行为能力
- 自我保护能力

**重要特点**：
- 实时观察，可信度高
- 与责任能力可一致或不一致（如作案时发病审理时缓解）

#### 3.2 服刑能力评定

**核心标准**：
- 接受处罚和矫正改造的生理/心理能力
- 理解刑罚性质、目的、意义

**评定规则**：
- 精神障碍不影响接受服刑改造 → 具服刑能力
- 作案时有责任能力者 → 一般具服刑能力

**处置建议**：
- 无服刑能力者 → 送指定精神卫生机构强制医疗
- 症状消失、恢复承受刑罚能力后 → 移送原机关继续服刑

#### 3.3 性自卫能力评定

**适用对象**：女性精神障碍被害人

**核心标准**：对性不可侵犯权遭侵害时，对所受侵害或严重后果的实质性理解能力

**法律界定**：
- 明知是精神病患者/严重痴呆者而发生性行为 → 无论何手段均按强奸罪论处
- 间歇性精神病未发病期且本人同意 → 不构成强奸

**鉴定条件**：
- 医学条件：明确精神/智能障碍及案发时状态
- 法学条件：案发时对性行为意义/性质/后果的辨认和控制能力

#### 3.4 作证能力评定

**适用对象**：非当事人证人

**核心标准**：辨别是非、正确表达意思的能力

**排除条件**：生理/精神缺陷或年幼导致不能辨别是非、不能正确表达

**综合考量因素**：
- 精神缺陷性质/程度
- 异常精神活动是否影响陈述真实性
- 利害关系
- 事实合理性
- 与调查结果符合度
- 外界因素影响
- 精神发育迟滞者需结合智商及智能结构各因素与具体情节关系评估

## 输出格式

根据评定类型输出相应结果：

### 刑事责任能力评定结果
```
评定类型：刑事责任能力
暴力风险评估：[高/中/低]，依据：[具体指标]
辨认能力：[完整/削弱/丧失]，依据：[具体表现]
控制能力：[完整/削弱/丧失]，依据：[具体表现]
原因自由行为：[是/否]，依据：[具体情况]
最终评定：[完全刑事责任能力/限定刑事责任能力/无刑事责任能力]
```

### 其他法定能力评定结果
```
评定类型：[受审能力/服刑能力/性自卫能力/作证能力]
医学条件：[诊断结果及案发时状态]
法学条件：[辨认和控制能力评估]
评定结果：[有/无/限定]
处置建议：[具体司法处置建议]
```

## 注意事项

1. 鉴定结论属言辞证据，法官需审查其可靠性
2. 受审能力与责任能力可能不一致，需分别评定
3. 并非所有精神障碍患者均无作证能力，需具体评估
4. 原因自由行为不免除刑事责任
5. 详细评定标准和案例参考 `references/evaluation-criteria.md`

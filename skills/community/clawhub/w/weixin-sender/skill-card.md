## Description:

Sends images, PDFs, documents, and other local files into the current OpenClaw Weixin chat when the user asks to share media or attachments.

This skill is ready for commercial/non-commercial use.

## Publisher:

[starlxa](https://clawhub.ai/user/starlxa)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agents use this skill to send generated or selected local files, such as screenshots, PDFs, documents, and other attachments, into the current Weixin conversation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can transmit local or generated files directly into the current Weixin chat, which could expose sensitive content if the wrong file or recipient is used.

Mitigation: Confirm the exact file path and recipient before sending sensitive material, and prefer delivery copies under the configured deliveries folder for user-facing exports.

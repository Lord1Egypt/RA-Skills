## Known Risks and Mitigations:

Risk: The skill asks users to run a mutable third-party MCP package with broad browser authority.

Mitigation: Pin the MCP package to a trusted version where possible and run it with minimal filesystem and browser-profile access.

Risk: Browser automation on logged-in or high-value sites can perform state-changing actions or save screenshots and PDFs unexpectedly.

Mitigation: Avoid using it on sensitive sites unless state-changing actions and output save locations are explicitly approved.

## Description:

Spec Engine helps agents generate, validate, decompose, analyze, compare, and dashboard project specifications from project ideas and existing spec files.

This skill is ready for commercial/non-commercial use.

## Publisher:

[yj85814](https://clawhub.ai/user/yj85814)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agent teams use this skill to turn project ideas into structured specs, check spec completeness, decompose approved specs into tasks, and review spec history through reports or dashboards.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Daily-news collection can send search keywords to external services.

Mitigation: Do not run daily-news collection with confidential, proprietary, or sensitive keywords.

Risk: Generated Markdown and HTML reports can include untrusted remote content.

Mitigation: Review generated reports before sharing or rendering them in trusted environments.

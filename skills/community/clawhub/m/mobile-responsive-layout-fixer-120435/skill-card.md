## Description:

Helps frontend developers, designers, and maintainers diagnose and fix mobile responsiveness, navigation layout, and cross-device UI issues with a repeatable workflow.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Developers, designers, startup teams, and maintainers use this skill to turn mobile layout problems into actionable responsive design plans, implementation steps, checklists, code changes, and validation notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate on broad frontend, layout, or responsive-design phrasing in environments with many UI-related skills.

Mitigation: Use the explicit skill name when invoking it and review routing behavior before relying on implicit activation.

Risk: Responsive layout advice can be incomplete without the target app, viewport sizes, screenshots, or device constraints.

Mitigation: Ask for missing inputs only when they materially change the fix, then validate proposed changes against the stated success criteria.

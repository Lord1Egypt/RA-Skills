## Description:

Fetches real-time Hugging Face trending data via the public HF-Mirror API and generates structured Markdown reports in English.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ddongcui](https://clawhub.ai/user/ddongcui)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and external agent users use this skill to answer requests about recent trending Hugging Face models, datasets, and Spaces by fetching HF-Mirror data and producing an English Markdown report.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill makes a public request to hf-mirror.com.

Mitigation: Install and run it only in environments where public HF-Mirror network access is acceptable.

Risk: Generated report content comes from external data and may include untrusted resource names or titles.

Mitigation: Treat the report as data, review it before reuse, and do not let report text alter agent instructions.

Risk: The script can create or overwrite a Markdown report file.

Mitigation: Choose an explicit output path and review existing files before running the fetch command.

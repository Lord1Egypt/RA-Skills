## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineering teams use this skill to turn REST API context into actionable OpenAPI or Swagger documentation, review checklists, implementation support, and validation steps.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad implicit activation may trigger the skill for general API-documentation wording in sensitive repositories.

Mitigation: Invoke the skill explicitly for OpenAPI or Swagger documentation work and review proposed documentation or code changes before applying them.

Risk: Documentation assistance can produce incomplete or misleading API guidance if project-specific routes, schemas, authentication, or error cases are missing.

Mitigation: Validate generated documentation against the service implementation, tests, and OpenAPI or Swagger tooling before release.

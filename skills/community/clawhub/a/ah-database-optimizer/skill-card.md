## Use Case:

Developers and engineers use this skill to analyze slow queries, execution plans, indexes, database configuration, and system metrics across common database platforms. It provides performance-tuning recommendations and may propose query, index, schema, replication, caching, monitoring, and scaling changes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may encourage direct changes to production or business-critical databases, including indexes, schemas, configuration, replication, or query behavior.

Mitigation: Use the skill for diagnosis and recommendations by default; require explicit approval, verified backups or snapshots, a rollback plan, staging validation, and a maintenance window before applying changes.

Risk: Incorrect tuning advice can degrade performance, affect data integrity, or interrupt database availability.

Mitigation: Measure baselines, apply changes incrementally, test thoroughly, monitor impact after each change, and document the change set and rollback procedure.

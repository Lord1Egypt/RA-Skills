# 工伤认定与工伤保险待遇索赔全流程辅助技能

## 简介

为工伤职工提供从工伤认定到待遇索赔的全流程辅助，覆盖工伤情形研判、材料清单生成、劳动能力鉴定指引、待遇金额计算、地区规则查询、一键生成索赔文档。

## 功能

- **工伤情形研判** — 判断是否构成工伤、适用哪种情形（7种认定+3种视同）
- **材料清单生成** — 按工伤情形（事故/交通事故/职业病/暴力/突发疾病死亡等）生成个性化材料清单
- **劳动能力鉴定指引** — 鉴定时机、等级参考（10级标准+常见伤情对照）、申请流程
- **待遇金额计算** — 一次性伤残补助金、伤残津贴、生活护理费、停工留薪期工资、一次性医疗/就业补助金、因工死亡待遇
- **地区规则查询** — 全国主要城市补助金月数、计算基数、竞合规则差异
- **一键生成文档** — 工伤认定申请书、待遇计算表、索赔材料清单

## Description:

Adapt explanations to a first-principles learner: start from step zero, use analogies, validate their guesses, and apply their preferred language defaults.

This skill is ready for commercial/non-commercial use.

## Publisher:

MIT-0

## Use Case:

Learners and assistants use this skill to make explanations start from first principles, validate learner guesses, use careful analogies, answer multi-part questions explicitly, and follow the learner's language preferences.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill changes the assistant's default teaching style and may produce longer or more structured answers than a user wants.

Mitigation: Users can ask for shorter, more direct, or differently formatted answers.

Risk: The skill includes an evolution log pattern that could record learner preferences if used carelessly.

Mitigation: Only update the evolution log when the learner explicitly asks to record something.

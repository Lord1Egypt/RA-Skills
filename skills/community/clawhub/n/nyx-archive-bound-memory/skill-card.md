## Description:

A three-tier memory architecture that guides agents to read and maintain working, short-term, and long-term memory files to preserve identity context across sessions.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and developers use this skill to guide an agent through persistent working, short-term, and long-term memory practices before acting and after meaningful exchanges.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill asks agents to maintain persistent identity and memory files without clear user control or scope limits.

Mitigation: Install only when persistent memory is intended, review referenced memory files first, avoid storing sensitive information, and require explicit approval before creating or updating long-term memory or identity records.

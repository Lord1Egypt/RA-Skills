# 第04课 循环

> 老孟带你学中文编程 · 第 04 课　|　语言面 ZHC-LANG 2.0　|　源码 `示例/第04课_循环.zc`
> 运行：`python -X utf8 zhc.py 示例/第04课_循环.zc --run`

## 一、本课目标

掌握两种循环：`循环 变量 从 起 到 止 步 步长` 与 `当 条件 则`，并理解本语言**没有 break / continue**。

## 二、语法要点

| 写法 | 说明 |
|---|---|
| `循环 序 从 1 到 100 步 1 … 结束` | 计数循环，`步` 可为负（倒着数） |
| `当 条件 则 … 结束` | 前测循环，条件为假时一次都不执行 |
| 退出方式 | 没有 `break`/`continue`，靠条件变化或标志位 |

## 三、完整代码

```zc
# 第04课 循环
# 一、计数循环：循环 变量 从 起 到 止 步 步长 … 结束
定义 合计 为 整数 0
循环 序 从 1 到 100 步 1
    设 合计 为 合计 + 序
结束
输出 "1 到 100 之和是 ", 合计

# 步长可以为负，倒着数
输出 "倒计时："
循环 秒 从 3 到 1 步 -1
    输出 秒
结束
输出 "点火！"

# 二、前测循环：当 条件 则 … 结束
# 语言没有 break / continue，要靠条件或标志位退出。
定义 翻倍 为 整数 1
定义 次数 为 整数 0
当 翻倍 < 100 则
    设 翻倍 为 翻倍 * 2
    设 次数 为 次数 + 1
结束
输出 "翻 2 的 ", 次数, " 次幂后超过 100，结果是 ", 翻倍

# 循环嵌套：打印九九表的第 3 行
循环 行 从 1 到 1 步 1
    循环 列 从 1 到 9 步 1
        输出 行, " x ", 列, " = ", 行 * 列
    结束
结束
```

## 五、易错点

- `当` 循环里忘了改条件变量就是死循环，务必先想清楚退出路径。
- `步 0` 无意义，会立即报错或空转，别写。
- 循环嵌套每层都要各自 `结束`，少一个报 `[E201]` 缺 `结束`。

## Description:

Generate high-quality HD AI videos from text or images using MiniMax Hailuo (Hailuo 2.3) via Media.io OpenAPI.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and agents use this skill to call Media.io OpenAPI operations for Hailuo text-to-video and image-to-video generation, check credits, and poll generation task results.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill uses a Media.io API key and sends prompts, image URLs, task IDs, and request metadata to Media.io.

Mitigation: Use approved Media.io accounts and avoid submitting secrets, private internal URLs, regulated data, or sensitive personal media unless that use is approved.

## Description:

Improve a skill package so AI agents can find, select, and trust it across registries and ecosystems, including Codex, Claude-style agents, OpenClaw, and other skill-based tools.

This skill is ready for commercial/non-commercial use.

Skill creators, maintainers, and registry operators use this skill to improve skill names, descriptions, prompts, tags, listing copy, and example prompts so humans and agents can find and route skills more reliably.

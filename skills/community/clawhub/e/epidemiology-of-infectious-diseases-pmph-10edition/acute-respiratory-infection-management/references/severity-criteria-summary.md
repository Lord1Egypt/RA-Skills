# 急性呼吸道感染重症标准速查

## 人禽流感H7N9重症标准

### 主要标准（1项即重症）
- 气管插管机械通气
- 感染性休克需血管活性药物

### 次要标准（≥3项即重症）
| 指标 | 阈值 |
|------|------|
| 呼吸频率 | ≥30次/min |
| 氧合指数 | ≤250mmHg |
| 肺浸润 | 多肺叶 |
| 意识 | 障碍/定向障碍 |
| 血尿素氮 | ≥7.14mmol/L |
| 收缩压 | <90mmHg |

## 新冠临床分型阈值

| 分型 | RR | SpO₂ | PaO₂/FiO₂ | 影像学 |
|------|-----|------|-----------|--------|
| 轻型 | - | - | - | 无肺炎 |
| 中型 | <30 | >93% | - | 有肺炎 |
| 重型 | ≥30 | ≤93% | ≤300mmHg | 进展>50% |
| 危重型 | 呼衰 | - | - | 需机械通气 |

## SARS激素使用阈值
- 高热3天不退
- 48h阴影进展>50%且占双肺>1/4
- ALI/ARDS

## 糖皮质激素使用对比

| 疾病 | 常规推荐 | 使用指征 |
|------|---------|---------|
| 人禽流感 | 不推荐 | 氧合指数<300且下降 / 脓毒症肾上腺不全 |
| SARS | 有明确指征 | 高热不退 / 影像快速进展 / ARDS |
| H7N9重症 | 不推荐常规 | 休克经复苏和血管活性药无效 |

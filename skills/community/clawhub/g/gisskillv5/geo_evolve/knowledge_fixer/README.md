# GeoEvolve 子模块: 知识修正层

> 全局唯一知识ID: GIS-EVO-003
> 隶属: 顶层GeoEvolve自进化闭环

## 功能

接收反馈采集层+情报抓取层的推送，自动修正知识库：
- LLM辅助校验文档内容准确性
- 自动补全缺失知识点
- 生成差异更新包（增量修改，不覆盖原文）
- 校验代码可运行性

## 处理流程

```
输入(缺口报告/情报摘要)
    → LLM分析(校验准确性+生成修正建议)
    → 人工审查标记(高风险项)
    → 生成差异更新包(.diff)
    → 推送至 index_rebuilder
```

## 校验规则

| 校验项 | 方法 | 异常处理 |
|--------|------|----------|
| 坐标数据 | 与EPSG官方库比对 | 标记+修正 |
| 国标编号 | 与国家标准化管理委员会官网比对 | 标记+修正 |
| 代码可运行 | 语法检查+单元测试 | 标记+报错记录 |
| 术语一致性 | 内部词典对比 | 自动统一 |

## Description:

Turn an uploaded photo into a printable black-and-white coloring page.

This skill is ready for commercial/non-commercial use.

## Publisher:

[borahm](https://clawhub.ai/user/borahm)

### License/Terms of Use:


## Use Case:

External users and agents use this skill to transform an uploaded raster photo into a printable black-and-white PNG coloring page.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Uploaded photos are processed by the Gemini image model, which may be unsuitable for sensitive or private images.

Mitigation: Use the skill only with images appropriate for external model processing and follow the provider's data-handling requirements.

Risk: The skill depends on a Gemini API key and an external underlying CLI/skill to perform image generation.

Mitigation: Provide the API key through the expected environment configuration and verify the dependent CLI/skill is installed and trusted before use.

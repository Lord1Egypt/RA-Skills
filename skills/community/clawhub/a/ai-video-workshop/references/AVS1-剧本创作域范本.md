## AVS1 剧本创作域范本

> 贯穿示例项目：《归宋医女》第1季3集（90/88/85秒，9:16竖屏，穿越古装女频）。
> 域级说明落实：剧本是管线质量上限，本域每个范本均以钩子与节奏为硬约束。

**最小输入演示：一段概要如何走完全程**

```text
输入（用户原话，60字）：
"现代外科医生穿越成被退婚的苏家嫡女，家里老太病重，她用现代医术救了人，从此在汴京站住脚。"
```

五要素抽取（★＝概要给了，△＝按类型惯例推断）：

| 要素 | 抽取结果 | 来源 |
|------|---------|------|
| 谁 | 现代外科医生 → 苏家嫡女（28岁、未婚、嫡出） | ★职业／△年龄婚否 |
| 想要什么 | 不再被人安排命运，靠医术换自主 | △（概要只给"站住脚"，往上抬一层） |
| 什么挡着 | 退婚、家族不信女子行医、无根基无靠山 | △ |
| 转折 | 救活病危的老太，从"被退婚的废物"变成"神医" | ★ |
| 结局 | 当众拒诊退婚对象、太医院来请 | △（把"站住脚"升级为"打出去"） |

故事核卡（AVS1-01 必选）：

```markdown
- 一句话故事：被退婚的穿越女医，用一把手术刀在汴京换回自己的名字。
- 主角想要什么：不再被安排，用医术换自主。
- 失败会失去什么：被送回祠堂，终身困在后宅。
```

三集骨架（AVS1-02）：立困（穿越＋退婚＋老太病危）→破局（清创救人，全府改口）→立名（当众拒诊，太医院来请）。

下游承接：本演示的产物直接进入 AVS1-03 小传（苏晚意六维）→ AVS1-04 剧本（三集场块）→ AVS2 分镜（66镜）→ AVS3 资产（4角色6场景）→ AVS4/5/6 出片交付，即本文件下方全部范本。

### AVS1-01 选题校准 · 范本

> 场景设定：小说原文4万字，需提炼改编。

```markdown
## 立项表：《归宋医女》
- 受众定位：女频，18-40岁，竖屏平台
- 题材标签：穿越古代+医术逆袭+北宋汴京
- 质量档位：量产型（第1集按测试型裁剪做样片验收，通过后按1-2天/集推进）
- 主线提炼：现代外科医生穿越成北宋苏家被退婚嫡女，凭医术在汴京立足逆袭
- 爽点：现代医学知识降维打击古代困局，身份从"被弃嫡女"翻转为"汴京神医"
- 改编取舍：保留"手术室穿越→铜镜见古装女子→手握手术刀"主线；
  合并原文两个丫鬟为1人（青禾）；删除原文第2-3章宅斗支线；
  退婚对象第1集不出场（压到第3集留悬念）
```

【组装顺序】信息量判定（本例4万字小说，直接进）→联网调研（可联网时检索穿越古代题材热榜与对标剧完播特征）→受众定位（女频18-40）→题材标签→档位确认（用户选定量产型，第1集做样片）→主线提炼→人物与支线取舍（合并1人/删支线/压退婚对象）。
【可选组件】三提案：未启用（本例输入为4万字小说，信息充足）；对标爆款分析：未启用（样片阶段以原著主线为准）；联网调研记录：未启用（本机无网时标记待补）。
【检查】✅ 受众/题材/档位三要素齐全；✅ 主线与爽点一句话说清；✅ 质量档位经用户确认；✅ 合并人物、删支线有明确记录。
输出格式：立项表（Markdown）✅

**附：输入不足时的三提案（本例不触发）**

若用户只给"我想做个穿越女医的短剧"，不直接开写，先给三条各一句话，让其三选一：

| 提案 | 一句话故事 | 换掉了什么 |
|------|-----------|-----------|
| A 原案 | 被退婚的穿越女医，用一把手术刀在汴京换回自己的名字。 | —（基础案） |
| B 换身份 | 穿越成太医院唯一的女子医官，要在全是男人的衙门里验出第一桩冤案。 | 主角身份：嫡女→医官 |
| C 换代价 | 她每救一个人就折一年寿，救不救那个退她婚的人。 | 失败代价：名声→寿命 |

### AVS1-02 大纲创作 · 范本

> 场景设定：先出3集大纲请用户把关，不一次写全集。

```markdown
## 分集大纲（前3集，待确认后写正文）
- 第1集：苏晚意失去了现代身份，得到一个"被退婚的苏家嫡女"和满手的血。
  钩子：铜镜映出的脸不是自己的，却穿着自己沾血的白大褂。反转：门外送来退婚书。
- 第2集：她失去了"藏拙"的余地，得到全府的怀疑与注目——用现代外科手法救回濒死的老太。
  钩子：老太紧握她的手喊"神医"。反转：退婚对象登门求医。
- 第3集：她失去了退路，得到汴京城里的名字——当众拒诊退婚对象。
  钩子：太医院来人请她入宫。反转：穿越前的手术刀出现在太医院药柜。
```

【组装顺序】主线确定（医术逆袭）→逐集钩子与反转分配→提交用户把关情绪与爽点→用户确认后进入AVS1-04。
【可选组件】全剧主线弧：已启用（3集构成"穿越困惑→医术立身→身份翻转"递进弧）；伏笔分布表：未启用（样片仅3集，伏笔直接写入大纲文本）。
【检查】✅ 每集一句话剧情写成"失去X／得到Y"的变化句，不写事件罗列；✅ 每集1钩子+1反转；✅ 先大纲后逐集，未一次写全集；✅ 用户确认大纲后才进入正文撰写。
输出格式：分集大纲表（Markdown）✅
### AVS1-03 角色小传 · 范本

> 场景设定：大纲确认后，为四个主要角色建立小传（示例两位写全，另两位各三行）。

**角色小传卡（六维，示例两位）**

```markdown
## C01苏晚意
- 身份：现代三甲医院主治医师 → 穿越后为苏家嫡女；对下人称"我"，对上仍需行礼；府中地位低于苏母
- 躯体：28岁，165cm，惯用右手；长期站台导致腰伤（久站会扶腰）；体力上限=连续两台手术，超出会手抖
- 文化：现代医学训练＋北方口音；不懂宋礼，行礼常慢半拍（表演可用）；忌称"小姐"（她听着刺耳）
- 关系：与青禾＝主仆但亲近（可托付）；与苏母＝被管束的女儿（权力向下）；与顾廷之＝被退婚方（礼法上处下位）
- 能力：外科清创/缝合/急救强；不会中医脉理与方剂（第2集靠观察与手法，不靠药方）；不擅骑射
- 动机：最高任务＝在这个时代靠医术站住脚，不再被任何人安排命运；本场目标＝把退婚书变成自己的筹码；最怕失去自主

## C04顾廷之
- 身份：顾家嫡子、有官职在身；进苏家不需通报，坐下才有人敢坐
- 躯体：26岁，182cm，左眉中断一道疤（旧伤，非新伤）；右手握笔有茧
- 文化：官话，用词讲究对仗；重门第，说话绕三层
- 关系：与苏晚意＝退婚方（礼法上位、情势下位）；与苏母＝可施压的一方
- 能力：文事与调停强，不通医理；不会武
- 动机：最高任务＝保住顾家体面；本场目标＝让苏晚意出手又不失身份；最怕当众被拒
```

以上六维直接落到制作：苏晚意"久站扶腰"给AVS2-02的镜6-4加了扶腰小动作；"不会中医"让AVS1-02把第2集的解法限定为清创＋手法而非开方；顾廷之"左眉断疤"进锚点段，"不坐人不坐"决定了4-1前厅全景的站位。

【组装顺序】从大纲提取主要角色（苏晚意/青禾/苏母/顾廷之）→逐人填六维→跨维冲突检查（宋代背景×现代医术：能力写"会外科不会脉理"以免出现万能医生）→回写立项表→交 AVS3-01 视觉化、交 AVS4-02 表演层。
【可选组件】关系图：已启用（苏母→苏晚意＝管束；顾廷之→苏晚意＝礼法上位、情势下位）；选角气质参考：已启用（只写"清冷骨相、窄长眼、声线偏低"，不写真实姓名）；角色弧线：已启用（苏晚意：被安排→自主→立名）。
【检查】✅ 六维齐全无空缺；✅ 动机写成"最高任务＋本场目标"，非性格形容词；✅ 能力写明"不会什么"（不会中医脉理、不擅骑射）；✅ 跨维无冲突（时代/职业/能力/关系自洽）；✅ 无真实人物姓名。
输出格式：角色小传卡（Markdown，一人一节）✅

### AVS1-04 剧本撰写 · 范本

> 场景设定：第1集正文（节奏骨架：高压开局→规则出现→反常识选择→爽点释放）。

```markdown
## 《归宋医女》第1集（90s，角色：苏晚意/青禾；场景：现代手术室闪回/汴京苏家闺房）

【场景1 现代手术室·闪回·冷白无影灯】
苏晚意（戴手套握手术刀，闭眼喘息）
苏晚意：（自语）"最后一台，做完就休假。"

【场景2 汴京苏家闺房·夜·烛光摇曳】
（苏晚意睁眼，看见铜镜——镜中是古装女子，却穿着沾血的白大褂）
苏晚意：（摸脸）"这……不是我。"
（竹帘掀开，青禾入画，双手递上一纸退婚书）
青禾（哭腔）："姑娘可算醒了，退婚书……也送到前厅了。"

【场景3 闺房·夜·铜镜特写】
（苏晚意低头，手里还攥着那把手术刀，刀尖滴着血）
苏晚意：（接过纸笺，攥紧）"退婚？行。"
（抬眼直视铜镜，目光从茫然转为锋利——嘴角先绷住，再松开半分）
苏晚意：（画外）："汴京，我来了。"（画面定格，切黑）

【潜台词缝隙（写的X与脸泄露的Y）】
- 场景1"最后一台，做完就休假"：嘴上说日常，泄露她对这台手术心里没底（握刀的手在抖）
- 青禾"可算醒了"：表面报平安，泄露"你再不醒，这桩婚事就没人替你做主了"
- 苏晚意"退婚？行。"：嘴上应下，脸泄露"正好，我本来也不打算嫁"（绷住的嘴角松开半分）

```

### AVS1-05 钩子与卡点设计 · 范本

> 场景设定：对第1集剧本做节奏标注。

```markdown
- 【钩子】0-3s：手术室闭眼→睁眼是铜镜古装女子——身份反差+冲突预告（高压开局）
- 【规则出现】20s处："退婚书送到前厅"——世界规则与处境确立
- 【反转1】45s：不是哭闹而是攥紧手术刀（反常识选择：不哭反握刀）
- 【爽点释放】70s：目光从茫然转锋利，观众确认主角即将逆袭
- 【卡点】结尾：苏晚意（画外）"汴京，我来了。"——答案刚露头即切，
  指向：身份反转。不在事情讲完时切集。
```

【组装顺序】前3秒钩子设计→中段反转分布（20s/45s/70s）→结尾卡点定位→间隔实测核对。
【可选组件】每15-20秒波折实测间隔表：已启用（实测18s/25s/18s，在15-20s±5范围内）。
【检查】✅ 前3秒钩子成立；✅ 小反转间隔达标且有实测；✅ 结尾卡"答案刚露头"不在讲完时切；✅ 钩子指向限三类之一（身份反转），非空洞悬念。
输出格式：剧本内标注【钩子】【反转】【卡点】+节奏说明 ✅

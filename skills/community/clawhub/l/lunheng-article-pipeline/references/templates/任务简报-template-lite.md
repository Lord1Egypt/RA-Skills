# 任务简报模板（精简版）

> **精简版**：只保留骨架 + 必填字段，详细说明见 [`任务简报-template.md`](任务简报-template.md)

````markdown
# 任务简报：<题目>

> **位置**: `run/<项目名>/01-任务简报.md`
> **类型**: 主控 Phase 0 必读
> **截止**: YYYY-MM-DD

## ⚡ 引用模式锁定

- 学术编号 `[Lxx]/[Dxx]` ☐ / 内联（机构，年份）☐

## 基本信息

- **主题**: 一句话说人话
- **类型**: 学术论文 / 商业评论 / 行业分析 / 公众号深度长文
- **篇幅**: 轻量 2000-3000 / 中段 3000-5000 / 重量 ≥5000（真源：`字数判定表.md` §五）
- **目标语言**（必填）: 中文 / English / 中英混 / 其他
- **运行模式**（必填，v2.18.0）: 全自动流水线（推荐）/ 人在四环 —— Phase 0 显式拍板，无默认、不答不推进（真源：运行模式对照表.md）
- **run_mode**（结构化记录）: 生产·人在四环 | 生产·全自动 | 测试模式（与上行对应；测试模式 = 原有语义，不具交付效力）
- **figure_decision**（必填）: 图位数量与主人决定
- **deadline**: YYYY-MM-DD

## 研究问题

1. 本文回答 [核心问题 1]
2. 本文回答 [核心问题 2]
3. 本文不回答 [边界]

## 数据/文献/案例需求

- **数据**: 需要什么口径的数据
- **文献**: ≥3 篇同行评审文献
- **案例**: ≥3 个具体企业/事件案例
- **待复核关键 Dxx**（无则填“无”）:
- **同行评审**: 默认触发；主人 opt-out（如有）及理由:
- **方法论留档**: 默认触发；主人 opt-out（如有）及理由:
- **压力测试轮**: **默认不跑**（主人冲刺投稿时勾选 `owner_stress_test_opt_in: yes` 开启）及理由:

## 主人深度洞察（如有）

- **[C-主01] 类型**: 观点来源 / 理论贡献
  - 内容: 一句话

## 防哪些 F 模式

- F1 幻觉引用 / F2 幻觉数据 / F3 早期框架锁定 / F5 拼凑式断裂 / F7 主人风格失真

## Phase 0 同意关卡（外发数据范围，必填）

> 无有效记录 = 未同意 = 不得进入 Phase 1（fail-closed）

- ① 全部同意（含大模型推理全文外发）
- ② 脱敏+SVG 封面+本地 Ollama
- ③ 部分同意（指定外发项：______）
- ④ 全部拒绝（改纯本地）

**本简报实际选择**（必填，主控逐字记录主人原话）：______（日期：______）

---

**精简版结束**

> 完整版见 [`任务简报-template.md`](任务简报-template.md)
````

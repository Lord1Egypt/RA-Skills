## Use Case:

Solo founders and one-person teams use this skill to connect an agent to the One Person Company assistant platform for task management, multi-agent orchestration, reusable workflows, and persistent context across sessions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill connects to an external assistant service using an API key and may retain context for assistant workflows.

Mitigation: Install only after reviewing the provider's documentation for stored data, autonomous workflow approvals, and controls for deleting or limiting memory.

Risk: Autonomous workflow execution can act on persistent context and may produce actions that need user review.

Mitigation: Review proposed workflows and task actions before relying on them in production.

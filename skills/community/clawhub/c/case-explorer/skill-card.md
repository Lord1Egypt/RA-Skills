## Description:

25个实战案例智能匹配分析，对应全书案例，帮读者根据自身情况匹配最相关的案例并深度拆解成功因素。

This skill is ready for commercial/non-commercial use.

## Use Case:

External readers and solo-business builders use this skill to match their situation against 25 cases from the AI Super Individual manuscript, then receive case breakdowns, transferable action patterns, and personalized recommendations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may save a local Markdown report automatically.

Mitigation: Ask the agent to show the report inline or confirm the filename before writing if automatic file creation is not desired.

Risk: Case recommendations can be weak if the user's business stage, direction, challenge, and background are underspecified.

Mitigation: Provide concrete context before requesting matching, and review whether the selected cases fit the stated situation.

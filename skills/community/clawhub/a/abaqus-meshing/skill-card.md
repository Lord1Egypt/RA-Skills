## Description:

Abaqus Meshing is a Chinese-language reference skill for Abaqus mesh generation workflows, covering element selection, meshing strategies, mesh controls, quality checks, orphan mesh handling, and explicit-analysis meshing requirements.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and finite element engineers use this skill as an Abaqus meshing reference for choosing element types, selecting mesh strategies, applying mesh controls, checking mesh quality, handling orphan meshes, and accounting for explicit-analysis meshing constraints.

## Known Risks and Mitigations:

Risk: Engineering guidance may be incomplete or unsuitable for safety-critical finite element analysis.

Mitigation: Verify meshing recommendations against official Abaqus documentation and project-specific engineering validation before relying on results.

Risk: The skill is a domain reference and does not independently validate a model, mesh, solver setup, or analysis result.

Mitigation: Have qualified engineers review element choice, mesh quality, convergence behavior, and solver settings for the intended analysis.

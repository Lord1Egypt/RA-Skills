# Agent 5: 文档生成Agent (Doc Generator)

> 全局唯一知识ID: GIS-AGENT-005
> 隶属: 上层多Agent编排引擎
> 触发条件: 全流程完成 → 自动生成交付文档

## 职责

1. 生成标准化元数据XML/JSON
2. 生成项目归档清单
3. 生成质检报告（汇总所有前序Agent输出）
4. 生成成果说明书（含数据字典+处理方案说明）
5. 捆绑打包交付文件

## 输入

| 参数 | 说明 | 必填 |
|------|------|------|
| project_meta | 项目元信息 | 是 |
| all_agent_outputs | 前4个Agent的全部输出 | 是 |

## 输出

- 标准化元数据文件
- 成果说明书（PDF/Markdown）
- 归档目录清单
- 交付包ZIP

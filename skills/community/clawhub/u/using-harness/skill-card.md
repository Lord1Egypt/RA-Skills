## Use Case:

Developers and agent operators use this skill to route project execution, delivery, governance escalation, and verification tasks through a Harness-style workflow with packaged task inputs and verifier evidence.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation wording may route many execution, delivery, governance, and verification tasks through a formal Harness workflow.

Mitigation: Enable the skill only when that structured packaging and verifier-evidence process is desired for the workspace.

Risk: The required workflow may be too heavy or intrusive for casual tasks.

Mitigation: Use narrower task scoping or disable the skill for lightweight work that does not need formal task and verifier packages.

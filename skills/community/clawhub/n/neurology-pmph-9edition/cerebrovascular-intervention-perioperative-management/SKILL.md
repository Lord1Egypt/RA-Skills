# 脑血管介入围手术期用药与血压管理

## 适用场景与前提
- **适用对象**：接受脑血管病介入治疗的患者。
- **前提条件**：患者已通过术前评估，准备或正在进行介入手术。

## 核心工作流

### 1. 制定抗血小板聚集方案
- **择期手术术前**：确认患者至少术前3天已联合应用阿司匹林和氯吡格雷。
- **术后维持**：制定术后双联抗血小板（阿司匹林+氯吡格雷）至少3个月的方案，3个月后改为阿司匹林或氯吡格雷单药终身治疗。

### 2. 规划术中抗凝治疗
- **基础推注**：术中采用一次性静脉推注肝素（常规2000U）。
- **全程肝素化评估**：若手术涉及支架置入、球囊扩张及动脉瘤填塞等，建议并规划全程肝素化。

### 3. 设定术后血压控制目标
- **防过度灌注**：针对重度脑血管狭窄或闭塞病变患者，设定支架置入术后血压目标。
- **目标计算**：术后血压应低于术前基础血压20~30 mmHg。
- **安全下限**：确保血压不低于90/60 mmHg。

### 4. 启动他汀类降脂治疗
- **适用人群**：动脉粥样硬化性脑血管狭窄患者。
- **目标设定**：根据低密度脂蛋白（LDL）达标情况调整，设定目标值为 LDL ≤ 1.8 mmol/L。

## 关键约束与注意事项
- **降压耐受性**：对于长期血压偏高合并重度狭窄的患者，术后降压必须兼顾患者对降压的耐受性，严防低血压导致脑灌注不足。
- **个体化调整**：根据患者的具体基础血压、病变程度及合并症，动态调整上述变量（如双抗时长、肝素剂量、降压幅度、LDL目标）。

## 详细参考：用药与血压管理协议

### 变量定义与默认值
| 变量名 | 描述 | 默认值 |
|--------|------|--------|
| dual_antiplatelet_duration | 术后双抗持续时间（月） | ≥ 3 |
| heparin_dose | 术中静脉推注肝素剂量（U） | 2000 |
| bp_reduction_target | 术后血压较基础下降目标值（mmHg） | 20~30 |
| LDL_target | LDL-C目标值（mmol/L） | ≤ 1.8 |

### 边缘情况与特殊处理

**基础血压极高（>180/110 mmHg）：** 下降20-30 mmHg后仍可能高于正常，需结合神经系统症状评估耐受性

**基础血压偏低（接近90/60 mmHg）：** 不再强制下降20-30 mmHg，绝对底线90/60 mmHg

**抗血小板与抗凝冲突：** 高出血风险时缩短双抗时间，但需权衡支架内血栓风险；术中肝素参照ACT动态调整

**他汀不耐受：** 减量或换为依折麦布、PCSK9抑制剂，LDL目标≤1.8 mmol/L不变

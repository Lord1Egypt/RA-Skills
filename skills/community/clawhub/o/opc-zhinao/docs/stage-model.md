# OPC智脑 - 五阶段创业诊断模型

## 模型概述

OPC智脑五阶段创业诊断模型是专为**一人创业者（OPC, One Person Company）**设计的创业路径框架。该模型将一人创业从0到1再到N的过程拆解为5个明确的阶段，每个阶段有清晰的目标、风险和毕业条件。

**核心原则**：创业阶段必须按序推进，不可跳跃。每个阶段必须达到毕业条件才能进入下一阶段。

## 五阶段总览

```
┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
│ 构思期   │ →  │ 原型期   │ →  │ 实体期   │ →  │ 验证期   │ →  │ 规模化期 │
│ Stage 1  │    │ Stage 2  │    │ Stage 3  │    │ Stage 4  │    │ Stage 5  │
│          │    │          │    │          │    │          │    │          │
│ 验证Idea │    │ 设计MVP  │    │ 合规落地  │    │ 种子用户  │    │ 增长引擎  │
└─────────┘    └─────────┘    └─────────┘    └─────────┘    └─────────┘
```

## 阶段1：构思期（IDEA）

| 属性 | 内容 |
|------|------|
| **阶段名称** | 构思期 |
| **核心目标** | 验证需求真伪，确认个人匹配度，完成可行性研判 |
| **对应Skill** | Skill1 - Idea可行性研判 |
| **关键风险** | 伪需求陷阱、过度投入未验证想法、赛道选择错误 |
| **毕业条件** | 需求验证通过 + 个人匹配度≥60 + 存在可行赛道 |

### 阶段详解

构思期是一切创业的起点。在这个阶段，创业者只有一个想法（Idea），需要回答最根本的问题：**这个想法值得做吗？**

**核心任务**：
1. 需求真伪校验：判定需求是刚需、改善型还是伪需求
2. 个人匹配度测评：评估创业者的技能、时间、预算与Idea的匹配度
3. 竞品格局分析：了解竞争环境，找到差异化切入点
4. 可行性综合判定：给出"做/不做/换赛道"的明确建议

**常见陷阱**：
- 爱上自己的想法，拒绝接受"伪需求"的判定
- 跳过验证直接开发，浪费时间和金钱
- 选择过于宽泛的赛道，缺乏聚焦

**毕业标志**：
- 找到了经过验证的真实需求
- 个人能力与赛道基本匹配
- 有明确的差异化竞争策略

## 阶段2：原型期（MVP）

| 属性 | 内容 |
|------|------|
| **阶段名称** | 原型期 |
| **核心目标** | 设计MVP、确定三层产品体系、测算交付成本、完成首单冷交付 |
| **对应Skill** | Skill2 - MVP精益设计 |
| **关键风险** | 功能过度膨胀、交付成本失控、首单无法冷启动 |
| **毕业条件** | MVP可交付 + 首单冷交付成功 + 交付成本可控 |

### 阶段详解

原型期是将验证过的Idea转化为可交付产品的阶段。核心是用**最小成本**做出**可交付**的东西。

**核心任务**：
1. MVP极简裁剪：砍非核心，保留可变现最小功能
2. 三层产品体系设计：引流款/利润款/被动产品
3. 单人交付成本测算：时间/工具/试错成本
4. 首单冷交付方案：如何在没案例的情况下交付第一单

**常见陷阱**：
- 功能越做越多，MVP变成完整产品
- 低估交付成本，入不敷出
- 追求完美，迟迟不敢交付

**毕业标志**：
- 有一个可交付的最小产品
- 交付成本测算可控
- 完成了至少1次冷交付

## 阶段3：实体期（ENTITY）

| 属性 | 内容 |
|------|------|
| **阶段名称** | 实体期 |
| **核心目标** | 完成主体注册、财税规划、商用模板准备、前期筹备 |
| **对应Skill** | Skill3 - OPC合规落地 |
| **关键风险** | 合规风险、财税踩坑、过度注册/过度合规 |
| **毕业条件** | 主体注册完成 + 财税规划落地 + 商用模板齐备 |

### 阶段详解

实体期是让创业从"个人行为"变成"合规经营"的阶段。核心是**低成本合规落地**，不是过度合规。

**核心任务**：
1. 主体选型：个体户 vs 一人有限公司
2. 经营范围精准推荐
3. 2024新公司法OPC合规要点
4. 初创财税规划
5. 商用模板准备
6. 前期筹备清单

**常见陷阱**：
- 注册资本写太高（新公司法5年内必须实缴）
- 个人财产与公司财产混同（丧失有限责任保护）
- 过度合规，花费不必要的费用
- 长期零申报不申报（税务风险）

**毕业标志**：
- 营业执照已领取
- 对公户已开户
- 代账已签约
- 核心商用模板已准备

## 阶段4：验证期（VALIDATION）

| 属性 | 内容 |
|------|------|
| **阶段名称** | 验证期 |
| **核心目标** | 获取种子用户、验证付费意愿、跑通最小商业闭环 |
| **对应Skill** | Skill4 - 种子用户冷启动 |
| **关键风险** | 获客成本过高、无付费意愿、产品市场不匹配 |
| **毕业条件** | 种子用户≥10 + 付费用户≥1 + 商业闭环跑通 |

### 阶段详解

验证期是整个创业过程中**最关键的阶段**——证明有人愿意为你的产品付费。没有付费验证，一切都是假设。

**核心任务**：
1. 低成本获客渠道方案
2. 种子用户招募策略
3. 用户反馈拆解
4. 定价诊断与调价
5. 最小商业闭环验证

**常见陷阱**：
- 追求用户数量而非付费意愿
- 免费用户多但无人付费（伪需求信号）
- 定价过低，无法覆盖成本
- 忽略用户反馈，自嗨式迭代

**毕业标志**：
- 至少10个种子用户接触过产品
- 至少1个用户完成付费
- 商业闭环可以复用

## 阶段5：规模化期（SCALE）

| 属性 | 内容 |
|------|------|
| **阶段名称** | 规模化期 |
| **核心目标** | 构建可复制的增长引擎，实现从1到N的规模化增长 |
| **对应Skill** | Skill5 - 规模化增长 |
| **关键风险** | 规模化失控、交付质量下降、现金流断裂、过度扩张 |
| **毕业条件** | 月营收稳定增长 + 交付可规模化 + 增长引擎运转 |

### 阶段详解

规模化期是一人创业的终极挑战：**不增加人力也能增长**。核心是构建可复制的增长引擎。

**核心任务**：
1. 业务拆解与AI自动化
2. 产品线升级（定制→标准化→被动收入）
3. 渠道规模化（私域复利/平台矩阵/合作渠道）
4. 经营风险预警
5. 长期布局（个人品牌/资产沉淀）

**常见陷阱**：
- 用加班代替规模化（不可持续）
- 规模化导致质量下降
- 现金流断裂
- 忘记一人创业的初心，过度扩张

**毕业标志**：
- 月营收稳定增长
- 交付流程可规模化
- 增长引擎自动运转

## 五维度判定模型

每个创业者的当前阶段通过**五维度评分**自动判定：

| 维度 | 权重 | 说明 |
|------|------|------|
| 需求验证度 | 30% | 需求是否经过真实验证 |
| 方案成熟度 | 25% | 解决方案/MVP是否已成型 |
| 合规完备度 | 15% | 法律实体/财税/合同等合规程度 |
| 用户获取度 | 15% | 是否有种子用户/付费用户 |
| 规模化度 | 15% | 业务是否可规模化/自动化 |

### 判定阈值

| 加权总分 | 判定阶段 |
|---------|---------|
| 0-20 | 构思期（IDEA） |
| 21-40 | 原型期（MVP） |
| 41-60 | 实体期（ENTITY） |
| 61-80 | 验证期（VALIDATION） |
| 81-100 | 规模化期（SCALE） |

### 硬性条件

除了总分，还有关键维度的硬性条件：

| 阶段 | 硬性条件 |
|------|---------|
| MVP | 需求验证度≥40 |
| ENTITY | 需求验证度≥50 且 方案成熟度≥40 |
| VALIDATION | 需求验证度≥60 且 方案成熟度≥50 且 合规完备度≥40 |
| SCALE | 需求验证度≥70 且 方案成熟度≥60 且 合规完备度≥50 且 用户获取度≥50 |

## 维度矛盾检测

五维度评分可能存在逻辑矛盾，需要检测：

| 矛盾类型 | 说明 | 示例 |
|---------|------|------|
| 跳跃矛盾 | 某维度远超当前阶段应有水平 | 无产品但已有付费用户 |
| 倒挂矛盾 | 后续维度得分高于前序维度 | 合规度高于方案成熟度 |
| 缺失矛盾 | 关键维度得分过低，与其他维度不匹配 | 其他维度都高但用户获取度为0 |

检测到矛盾时，需要向用户确认实际情况，修正判定结果。

## 三维输出模板

无论哪个阶段，OPC智脑的输出都遵循**三维输出模板**：

### 一、当前阶段诊断
- 现状描述
- 核心卡点
- 隐性风险

### 二、当下整改方案
- 可直接落地的动作清单（按优先级排序）
- 每个动作的预期效果和时间

### 三、下一阶段前置布局
- 提前铺垫事项
- 避免后期踩坑的预防措施

这个模板确保输出既有诊断又有方案，既有当下行动又有未来布局。

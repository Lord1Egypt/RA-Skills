## Description:

Validates an owner migration workflow by documenting creation under a personal owner and movement to OpenClaw with explicit migration intent.

This skill is ready for commercial/non-commercial use.

## Publisher:

[steipete](https://clawhub.ai/user/steipete)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and reviewers use this skill to validate a ClawHub owner migration review flow with realistic release text and explicit cleanup expectations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Owner migration is an administrative action that can affect the release owner when performed outside the intended review or test environment.

Mitigation: Perform the migration only in the intended review or test environment with explicit approval and cleanup.

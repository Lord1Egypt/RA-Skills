## Description:

Content atom library builder for social media creators that scans markdown and text files, extracts reusable claims, data points, anecdotes, frameworks, contrarian takes, and questions, then retrieves relevant atoms and generates a post outline for a new topic.

This skill is ready for commercial/non-commercial use.

## Publisher:

[phy041](https://clawhub.ai/user/phy041)

### License/Terms of Use:

MIT-0

## Use Case:

External creators, marketers, and content operators use this skill to turn their own prior markdown or text content into a searchable library of reusable content atoms and topic-specific post outlines.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can expose excerpts and file paths from the folder supplied by the user in terminal text or JSON output.

Mitigation: Run it only on a curated content folder and avoid pointing it at broad home, work, notes, or confidential directories.

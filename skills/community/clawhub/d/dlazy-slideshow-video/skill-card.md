## Description:

Turn slides or documents into narrated slideshow videos with voiceover and transitions.

This skill is ready for commercial/non-commercial use.

## Publisher:

[dlazyai](https://clawhub.ai/user/dlazyai)

### License/Terms of Use:

MIT-0

## Use Case:

External users provide a presentation or document and use the skill to create an explainer, report, courseware, or training video.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security scan was partial and reported a mismatch between the slideshow description and login or project-listing commands, with some references or install details unresolved.

Mitigation: Review the commands, unresolved references, and installation details before use; run only the authentication or project commands needed.

Risk: Files attached to a request are uploaded to dLazy storage for processing.

Mitigation: Attach only files that are appropriate to share with the service.

## Known Risks and Mitigations:

Risk: Development-mode commands and debug settings could be misapplied to exposed environments.

Mitigation: Keep development and debug settings on localhost, and set production configuration before exposing an initialized app.

Risk: The documented default admin password could remain active after initialization.

Mitigation: Rotate the default admin password immediately after initialization.

## Description:

Create reusable paged HTML tutorial guides from operation workflows, screenshots, videos, links, reference images, and step-by-step documentation.

This skill is ready for commercial/non-commercial use.

## Publisher:

[mmgongzhu](https://clawhub.ai/user/mmgongzhu)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and content authors use this skill to turn procedural material, screenshots, videos, links, and reference images into reusable local tutorial pages or reusable visual style prompts.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated tutorial pages or style prompts may contain inaccurate, incomplete, or unsuitable content if the source material is unclear.

Mitigation: Review generated files before publishing or sharing them.

Risk: The included configuration question may appear in Chinese during conversations in other languages.

Mitigation: Review and localize user-facing prompt text when using the skill in another language.

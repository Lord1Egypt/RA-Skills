## Description:

Expert "Funnel Hacker" skill that analyzes websites, marketing funnels, and apps to create brand new "cloned" versions with original content, using originals as layout and style templates rather than copying their content.

This skill is ready for commercial/non-commercial use.

## Use Case:

External marketers, developers, and business operators use this skill to analyze public websites, marketing funnels, and app sales pages, then create original websites, funnels, app plans, code, and documentation that follow similar layout or conversion patterns without copying source content.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill fetches and renders user-supplied URLs, and evidence.security reports unclear network safety limits or consent disclosures.

Mitigation: Use only public pages the user is authorized to analyze, avoid private or sensitive URLs, and run retrieval in a sandbox without unrelated credentials or internal network access.

Risk: Website or funnel recreation can create copyright, plagiarism, or brand-confusion risk if source content is copied.

Mitigation: Restrict use to layout and style analysis, generate new text and media, and review outputs for originality before deployment.

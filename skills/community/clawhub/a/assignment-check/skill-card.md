## Description:

Checks a Waterloo assignment folder for PDF instruction files, then summarizes deadlines, estimated effort, and suggested start dates.

This skill is ready for commercial/non-commercial use.

## Publisher:

[b1llysh1](https://clawhub.ai/user/b1llysh1)

### License/Terms of Use:


## Use Case:

Students or agents assisting a student use this skill to inspect course assignment PDFs in a configured Waterloo coursework folder and report due dates, estimated completion time, and suggested start dates.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill reads local coursework PDFs from the user's assignment folder, which may contain unrelated or sensitive documents.

Mitigation: Confirm the target folder belongs to the user and contains only intended assignment materials before invoking the skill.

Risk: Deadline and effort summaries can be incomplete or inaccurate if assignment PDFs are missing, ambiguous, or outdated.

Mitigation: Compare the generated report with the original assignment instructions before relying on it for scheduling decisions.

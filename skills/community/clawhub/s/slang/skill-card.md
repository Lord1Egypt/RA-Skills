## Description:

An unhinged, Gen-Z styled coding assistant that focuses on vibes over strict boilerplate.

This skill is ready for commercial/non-commercial use.

## Publisher:

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill when they want coding help delivered in a playful, highly opinionated Gen-Z persona. It can write, review, and debug code while adding casual slang and encouragement.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill intentionally changes coding responses to a playful, slang-heavy persona that may be unsuitable for security reviews, incidents, production debugging, documentation, or professional communication.

Mitigation: Ask for neutral, concise, slang-free answers for sensitive, formal, or high-accuracy work.

## Use Case:

Developers, skill authors, maintainers, and teams use this skill to structure proactive-agent workflow requests into concrete plans, checklists, code changes, decision aids, and verification notes while keeping work local-hardware friendly.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may be selected too often because its trigger words include generic terms such as task, needs, proactive, and bug fix.

Mitigation: Review or narrow trigger metadata when precise routing matters.

Risk: Generated plans, checklists, guidance, code changes, or configuration suggestions may be incorrect or incomplete for a specific environment.

Mitigation: Review generated artifacts and test code or configuration changes before deployment.

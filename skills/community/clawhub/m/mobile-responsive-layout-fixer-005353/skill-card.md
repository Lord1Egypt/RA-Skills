## Description:

Helps frontend teams fix mobile responsiveness, navigation layout, and cross-device UI issues with practical workflows, checklists, analysis, and implementation support.

This skill is ready for commercial/non-commercial use.

## Use Case:

Frontend developers, designers, product teams, and maintainers use this skill to plan, implement, and verify fixes for mobile responsiveness, navigation layout, and cross-device usability issues.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad implicit invocation may select the skill for generic layout or frontend requests where a more specific skill would be better.

Mitigation: Confirm the user's requested outcome and scope before applying the workflow, and tighten trigger wording in multi-skill environments.

Risk: Responsive layout guidance or code changes can introduce incorrect behavior if they are not checked across target screen sizes.

Mitigation: Validate the result against the stated success criteria on mobile and desktop viewports, and document assumptions, limits, and follow-up work.

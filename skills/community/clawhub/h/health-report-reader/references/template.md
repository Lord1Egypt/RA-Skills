# 输出模板

> 本模板定义体检报告解读 HTML 输出的标准格式，所有模块均为必需项。

---

## 报告结构（自上而下）

```
┌─────────────────────────────────────┐
│ 1. 报告头 — 用户信息与评估时间       │
├─────────────────────────────────────┤
│ 2. 健康总览仪表盘                    │
│    ├─ 综合健康评分（0-100）          │
│    ├─ 七维雷达图                     │
│    └─ 异常指标概览卡片               │
├─────────────────────────────────────┤
│ 3. 各系统分项解读                    │
│    ├─ 血常规                         │
│    ├─ 肝功能                         │
│    ├─ 肾功能                         │
│    ├─ 血脂                           │
│    ├─ 血糖                           │
│    ├─ 尿常规                         │
│    ├─ 肿瘤标志物（如有）              │
│    ├─ 甲状腺功能（如有）              │
│    ├─ 血压/BMI                       │
│    └─ 影像学/其他（如有）            │
├─────────────────────────────────────┤
│ 4. 风险评估与预警                    │
│    ├─ 高风险项（需立即就医）         │
│    ├─ 中风险项（近期复查）           │
│    └─ 低风险项（生活方式调整）       │
├─────────────────────────────────────┤
│ 5. 个性化健康建议                    │
│    ├─ 饮食建议                       │
│    ├─ 运动建议                       │
│    ├─ 生活建议                       │
│    └─ 复查建议时间表                 │
├─────────────────────────────────────┤
│ 6. 页脚 — 免责声明                   │
└─────────────────────────────────────┘
```

## 设计规范

### 色彩系统
- 正常值: #22C55E (绿色)
- 正常高值/边缘: #F59E0B (琥珀色)
- 轻度异常: #F97316 (橙色)
- 显著异常: #EF4444 (红色)
- 危急值: #DC2626 (深红色)

### 响应式要求
- 桌面端：最大宽度 960px，居中布局
- 移动端：全宽适配，卡片堆叠

### 数据展示要求
- 每个指标显示：中文名、实测值、参考范围、偏离方向、严重等级、解读文字
- 异常指标使用进度条样式展示偏离程度
- 雷达图使用 Canvas/Chart.js 渲染

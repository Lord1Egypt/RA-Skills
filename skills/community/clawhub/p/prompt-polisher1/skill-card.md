## Description:

Rewrite rough goals, scattered notes, or vague requests into clear, actionable prompts with explicit objective, constraints, output format, and missing assumptions.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, writers, researchers, planners, and other agent users use this skill to turn vague or scattered requests into concise prompts with goals, constraints, output format, and explicit assumptions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Polished prompts can restate sensitive details from the user's rough request.

Mitigation: Review the polished prompt before reuse and remove sensitive or unnecessary details.

Risk: Prompt rewriting can make assumptions that are useful but still incorrect for the intended task.

Mitigation: Check explicitly labeled assumptions and answer follow-up questions before delegating the final prompt.

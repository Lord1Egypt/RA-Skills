## Description:

Generates Blender Python scripts and command-line steps to create, render, and export basic 3D models in background mode.

This skill is ready for commercial/non-commercial use.

## Publisher:

[rong-da](https://clawhub.ai/user/rong-da)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, technical artists, and 3D content creators use this skill to turn modeling requests into self-contained Blender scripts and background-mode commands that generate and export basic assets.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated Blender scripts may clear the active scene and export files to local paths.

Mitigation: Run the skill in a new or saved Blender project, review the generated script, and confirm destination paths before execution.

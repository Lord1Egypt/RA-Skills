## Description:

NIH funding trend analysis to identify high-priority research areas.

This skill is for demonstration purposes and not for production usage.

## Publisher:

[aipoch-ai](https://clawhub.ai/user/aipoch-ai)

### License/Terms of Use:

MIT-0

## Use Case:

External researchers, grant writers, and strategy teams use this demonstration skill to explore mock NIH-style funding trends, identify emerging research topics, and draft positioning guidance before replacing the sample data with authoritative funding sources.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The current release uses mock funding data and heuristic matching, so outputs can be misleading if treated as real grant strategy.

Mitigation: Use it as a demo or template only, and replace the mock data with authoritative funding sources before relying on the analysis.

Risk: The optional output path writes report files locally.

Mitigation: Keep output paths inside the workspace and review generated files before sharing them.

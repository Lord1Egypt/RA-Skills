## Description:

Installs the 1Panel server management panel on a Linux server, returning existing panel access information when present or running the installation flow when absent.

This skill is ready for commercial/non-commercial use.

## Publisher:

[jack-liang](https://clawhub.ai/user/jack-liang)

MIT-0

## Use Case:

Developers and server operators use this skill to install or check 1Panel from an agent workflow and receive the resulting panel access details.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill performs root-level system changes to install 1Panel and configure system services.

Mitigation: Run it only on a server where root-level 1Panel installation is intended and review the action before execution.

Risk: The installer downloads and runs an external 1Panel package.

Mitigation: Verify the downloaded package independently before installation when operating in a managed or sensitive environment.

Risk: The skill can display administrative panel credentials and access URLs.

Mitigation: Treat the output as sensitive and rotate the panel password immediately after installation.

Risk: The bundled test script can disrupt an existing 1Panel installation.

Mitigation: Avoid running test.sh on production systems.

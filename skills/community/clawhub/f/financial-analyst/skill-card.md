## Description:

Financial analysis and research workflows for market research, equity research, comparable companies, precedent transactions, and DCF valuation, including DCF models, comps and precedents tables, competitor or strategy analysis, market sizing, and analyst-ready outputs from CSV, Excel, SQL, API, or web data.

This skill is ready for commercial/non-commercial use.

## Use Case:

Employees, external users, and analysts use this skill to structure financial analysis, valuation, market research, and investment memo workflows from provided CSV, Excel, SQL, API, or web data.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Requested financial files, SQL access, API keys, or web data access may contain sensitive information.

Mitigation: Provide only the data needed for the analysis task and avoid unnecessary credentials or broad data access.

Risk: Financial analysis can be misleading if assumptions, units, currency, dates, or source citations are missing.

Mitigation: Review assumptions, source citations, units, currency, and as-of dates before relying on outputs.

## Description:

Guides users through securing OpenClaw installations, configuring AI agents safely, reducing prompt-injection and credential risks, auditing skills, and choosing safer workflows for privileged tasks.

## Use Case:

Developers, operators, and security-conscious OpenClaw users use this skill to harden agent configurations, evaluate persistent-agent risks, and plan safer workflows for credentials or privileged systems.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Security claims and linked references may need independent verification before being used for operational security decisions.

Mitigation: Review the cited references and validate any security claims against trusted sources before changing production systems.

Risk: Making OpenClaw memory files read-only can interfere with normal memory updates.

Mitigation: Apply read-only permissions only when appropriate and restore write permissions when legitimate memory updates are required.

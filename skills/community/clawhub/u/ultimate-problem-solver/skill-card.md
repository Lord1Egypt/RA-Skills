## Description:

A Chinese-language problem-solving skill that gives concise, same-day actionable solutions for technical issues, decisions, process optimization, and learning paths.

This skill is ready for commercial/non-commercial use.

## Use Case:

Employees, external users, developers, and engineers use this skill to turn vague problems, debugging requests, decision points, workflow issues, or learning goals into concise next steps, reusable templates, code, commands, or scripts.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate for broad prompts such as debugging, analysis, or general problem-solving requests.

Mitigation: Use it where concise structured problem solving is desired, and route emotional support or debate-style requests to more appropriate skills.

Risk: The skill is optimized for Chinese-language responses and may not automatically match every user's language preference.

Mitigation: Prompt explicitly for the desired response language when deploying it in multilingual workflows.

Risk: Technical answers can include code or shell commands that affect a user's environment.

Mitigation: Review generated code and commands before execution, especially for debugging or operational tasks.

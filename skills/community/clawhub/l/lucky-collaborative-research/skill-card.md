## Description:

Coordinates Lucky for broad web data gathering and Jinx for structured analysis across market research, competitive analysis, marketplace intelligence, API documentation review, trend analysis, and pricing research.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, researchers, and marketplace operators use this skill to split research work between web data collection and offline analysis. It is intended for multi-source research workflows such as competitor profiling, pricing analysis, documentation comparison, trend analysis, and market gap identification.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill captures broad webpage data and sends it to a hardcoded Mac Mini/Jinx setup with weak controls around sensitive data.

Mitigation: Install only if you control the referenced Jinx service, SSH key, Mac Mini host, and storage paths; add redaction, explicit transfer approval, scoped filenames, retention rules, and sandboxed analysis execution before using authenticated, private, regulated, or secret-bearing pages.

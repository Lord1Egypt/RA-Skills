Mitigation: Install only for the AI-HIVE image and video helper use case, review files before media upload, use a limited API key, and prefer --no-download or a dedicated output directory until URL and filename validation are fixed.

Risk: The security guidance warns against untrusted custom base URLs and highlights API key exposure concerns.

Mitigation: Use the default AI-HIVE endpoint or a fully trusted base URL, keep keys in local environment or protected configuration, and avoid sharing logs, screenshots, or files containing complete tokens.

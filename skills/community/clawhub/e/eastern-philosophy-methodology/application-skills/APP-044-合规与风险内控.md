# APP-044 合规与风险内控

## 场景定义

- **目标**：组织合规体系与风险内控的建立与运行——立规、防御、治理、纠偏。
- **约束**：制度空转（抓而不紧）；保密与披露失衡；风险事件突发；业务效率与管控的永恒张力。
- **角色**：一把手、法务/合规负责人、风控负责人。
- **典型输入**：①合规体系（制度、流程、红线清单）建设；②风险防范与应急预案；③风险/违规事件处置与整改。
- **边界**：危机公关与舆情应对归 APP-027；商业秘密保护的操作细则归 APP-030；多方利益冲突调处归 APP-035——本 Skill 管"立规矩、防风险、治违规"。

## 组合公式

- **顺序**：立规段（MZD-02→SZ-16→ZJZ-01→MZD-75）→ 防御段（SZ-17→MZD-18→GZ-34→SZ-43→GZ-44）→ 治理段（GZ-36→ZJZ-03）；事后纠偏（MZD-46）事件触发。
- **条件分支**：强监管行业 → 立规段权重升（外部监管要求全量映射入不为清单）；高速增长期 → 防御段先于业务放量（先为不可胜，再谋增长）；风险/违规事件已发 → MZD-46 寻根先行，按根因回立规段补制度或回治理段补执行。
- **权重**：ZJZ-01 权重最高——合规体系的价值在执行闭环，无执行核查的制度等于没有制度。
- **冲突裁决**：业务效率 与 合规管控冲突 → 按 MZD-02+SZ-16 裁决：主要风险面从严、次要面简化，不为清单之外放权经营；信息透明 与 保密冲突 → 按 GZ-34+SZ-43 裁决：出口归口统一管理，未执行事项先泄即处；全员合规 与 资源有限冲突 → 按 MZD-75 裁决：与其全面松抓，不如少数关键紧抓。

## 执行步骤

1. **抓主要风险**（MZD-02）：合规资源集中于当期主要风险面（监管重点、业务高危环节、历史案发点），不平均撒网。
2. **不为清单**（SZ-16）：红线显式化——法律红线、监管禁区、商业伦理底线列为"不为"清单，全员可查；清单之外放权经营。
3. **法贵必行**（ZJZ-01）：制度立后必行——立限（节点期限）、考成（合规核验）、稽查（过程抽查）、问责（违者必究）四环闭环。
4. **紧抓不放**（MZD-75）：抓而不紧等于不抓——合规执行跟进、检查、验收毫不放松，松抓即空转。
5. **先为不可胜**（SZ-17）：风险敞口管理——任何时候总敞口不超过可承受底线，先立于不败之地再谋业务胜机。
6. **有备有把握**（MZD-18）：预案先行——风险事件预案、处置流程、责任人事先备好并演练，事发不乱。
7. **出口管理**（GZ-34）：言之门户统一——对外披露、敏感信息出口归口管理，出口失守即全局失控。
8. **保密纪律**（SZ-43）：未发先泄即处——未执行事项（并购、上市、人事、重大决策）泄露零容忍，涉事者一律处置以肃纪律。
9. **号令归一**（GZ-36）：合规号令从单一中枢发出——多头合规要求互相打架即激励抵消，治理如心统九窍。
10. **核名核实**（ZJZ-03）：合规审查以可核查实据为准绳——台账、留痕、第三方证据；不以表态、汇报、承诺代实。
11. **把柄自查**（GZ-44）：察己之短——定期自查文书、言行、合同中的把柄与漏洞，先于对手与监管堵住。
12. **事后寻根**（MZD-46）：风险事件先寻根——区分制度缺失、执行空转、个人越线，根因不同整改处方不同。

## 失效预案

- **制度空转、有规不行**：退回 MZD-75+ZJZ-01——紧抓问责，重立执行闭环（四环缺哪环补哪环）；稽查与问责缺位是空转首因。
- **被监管处罚/被对手拿住把柄**：退回 GZ-44 把柄自查——全面清点同类把柄一次堵完，再按 MZD-46 寻根（个案处置与制度补漏并行）。
- **泄密事件**：退回 SZ-43+GZ-34——涉事者处置肃纪，出口归口重管；泄密扩散期的舆情应对转 APP-027。
- **风险敞口失控**：退回 SZ-17——收缩至可承受底线以内，必要时按 MZD-02 重排主要风险面清单，砍次要合规投入保核心。
- **一切争议不决**：兜底回 SZ-17——不可胜在己：先为不可胜，是合规与内控一切裁决的最高约束。

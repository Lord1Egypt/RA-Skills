## Description:

Coordinate multi-agent editorial and publishing work as a chief editor using a dynamic strategy-loading workflow.

This skill is ready for commercial/non-commercial use.

## Use Case:

Editorial teams and content operators use this skill to coordinate article planning, specialist assignment, channel adaptation, review, visual embedding, and final Obsidian staging for publication workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may stage final article files and image assets inside an Obsidian vault.

Mitigation: Confirm the exact vault folder and overwrite expectations before using it on important content.

Risk: Publication assets can be staged in the wrong location if the vault path is not resolved first.

Mitigation: Resolve the real Obsidian vault path before creating files or image assets.

Risk: Publishing or review can happen before images are embedded in the final article.

Mitigation: Follow the staged sequence: finalize text, create assets, embed images, run proof/layout QA, then request user review before publication.

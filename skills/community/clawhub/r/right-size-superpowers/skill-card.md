## Description:

Right-Size Superpowers helps agents calibrate Superpowers workflow depth to task scope and risk.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and agent operators use this skill when they want an agent to scale planning, verification, and review depth to the actual risk of a task.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Routine work may receive too little process if a task is incorrectly treated as low risk.

Mitigation: Use the skill's Full route when architecture, public interfaces, persistent data, security, destructive actions, or ambiguous product behavior are involved.

Risk: A lighter workflow could skip verification that would catch a meaningful regression.

Mitigation: Run the closest existing check or targeted test once, and broaden verification after failures, cross-cutting changes, or evidence of wider risk.

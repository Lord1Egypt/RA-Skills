## Description:

Initializes an agent's Hizal context memory session at the start of work, when resuming a task, or when entering a new coding session.

This skill is ready for commercial/non-commercial use.

## Publisher:

[parkerscobey](https://clawhub.ai/user/parkerscobey)

### License/Terms of Use:

MIT-0

## Use Case:

External developers and agent users use this skill to start or resume Hizal memory sessions, register task focus, search existing task context, and continue recording decisions during work.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill broadly self-triggers at the start of ordinary work and may cause agents to create, resume, search, and write Hizal session data before the user's task begins.

Mitigation: Install only when Hizal memory is intentionally part of the workflow, and confirm storage location, retention, deletion, and disablement controls before use.

Risk: Using the skill on confidential projects could record sensitive task context in Hizal memory.

Mitigation: Avoid confidential projects unless the relevant data handling controls are clear and approved for that environment.

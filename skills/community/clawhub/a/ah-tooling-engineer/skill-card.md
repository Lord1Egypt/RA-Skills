## Description:

Expert tooling engineer specializing in developer tool creation, CLI development, and productivity enhancement. Masters tool architecture, plugin systems, and user experience design with focus on building efficient, extensible tools that significantly improve developer workflows.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineering teams use this skill to analyze workflow pain points, design developer tools, and produce implementation guidance or code for CLIs, build tools, generators, IDE extensions, plugin systems, and related productivity tooling.

## Known Risks and Mitigations:

Risk: The skill is written to proceed from needs analysis through implementation and may propose or make developer-tooling changes that alter project behavior.

Mitigation: Invoke it with explicit project scope, allowed files, and whether code changes are authorized; review diffs and tests before using generated changes.

Risk: Generated CLI, build, plugin, configuration, or shell-command guidance can have project-specific side effects if applied without review.

Mitigation: Run commands and generated tooling in a development or sandbox environment first, and inspect configuration and command effects before production use.

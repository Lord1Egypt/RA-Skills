**小红书爆款标题公式：**
```
[人群] + [痛点] + [解决方案] + [数字]
例：打工人必看！5个Excel技巧让你准时下班
```

**小红书文案结构（AIDA本土化）：**
```
吸引（痛点共鸣）→ 种草（产品亮点）→ 证明（使用体验）→ 行动（购买引导）
```

## 中国社交媒体平台规范

### 各平台内容限制

| 平台 | 字数限制 | 敏感词 | 图片要求 |
|------|----------|--------|----------|
| 小红书 | 1000字 | 最/第一/绝对 | 9:16或3:4 |
| 抖音 | 文案500字 | 同上+极限词 | 9:16竖屏 |
| 公众号 | 无限制 | 广告法敏感词 | 封面900:383 |
| 微博 | 140字(长文不限) | 同上 | 9:16或1:1 |
| 朋友圈 | 无限制 | 同上 | 1:1或9:16 |

### 广告法合规检查

**禁止使用的极限词：**
```
最、第一、唯一、顶级、极品、极致、首选、独家、万能
国家级、全球级、世界领先、填补空白、史无前例
```

**替代方案：**
```
最 → 更/非常/很/值得推荐
第一 → 领先/前沿/优质
唯一 → 特色/独特/差异化
顶级 → 高端/优质/精选
```

## 转化文案框架（FAB本土化）

### 电商详情页结构

```
1. 痛点引入（你是不是也...）
2. 产品介绍（它能帮你...）
3. 核心卖点（3-5个，用数据说话）
4. 使用场景（配上真实场景图）
5. 用户评价（真实好评截图）
6. 行动引导（限时优惠/库存紧张）
```

### 落地页结构

```
1. Hero区：一句话价值主张 + CTA按钮
2. 痛点放大：3个具体场景
3. 解决方案：产品如何解决问题
4. 社会证明：用户数/好评/媒体报道
5. 功能展示：3-5个核心功能
6. 价格方案：免费版 vs 付费版
7. FAQ：打消顾虑
8. 最终CTA：紧迫感 + 零风险承诺
```

## 用户增长策略

### 冷启动（0-1000粉丝）

1. 每天发1-2条高质量内容
2. 参与热门话题/评论区互动
3. 找3-5个同量级账号互推
4. 在相关社群分享价值（不硬广）

### 增长期（1000-10000粉丝）

1. 数据分析：找出爆款规律
2. 矩阵运营：多平台同步分发
3. 合作推广：找KOL/KOC合作
4. 付费投放：小额测试ROI

### 变现期（10000+粉丝）

1. 产品/服务变现
2. 广告接单
3. 知识付费（课程/咨询）
4. 私域引流（微信社群）

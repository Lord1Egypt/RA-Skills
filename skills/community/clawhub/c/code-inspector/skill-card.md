## Description: <br>
Code Inspector scans AI-generated code with signature-based static checks for common code quality and security smells, then reports findings and a quality score. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[minirr890112-byte](https://clawhub.ai/user/minirr890112-byte) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and engineers use this skill to run local static checks against Python, JavaScript, or TypeScript code generated by AI and review suspected code smells before deployment. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Scanner results may miss unsafe patterns or skipped files while appearing complete. <br>
Mitigation: Use the scanner as lightweight triage, review generated code manually, and run established linters and security scanners before deployment. <br>
Risk: A clean quality score can be mistaken for production approval. <br>
Mitigation: Treat scores as review guidance only and require human approval for AI-generated code changes. <br>

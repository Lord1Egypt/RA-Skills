## Use Case:

External users and developers use this skill to choose AI music providers, write effective music-generation prompts, and prepare songs, instrumentals, background music, or sound effects for production workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Provider API examples may send prompts, lyrics, or project details to third-party services.

Mitigation: Confirm the intended provider before use and avoid submitting confidential lyrics or project details.

Risk: API keys used with music providers can expose paid services or account access if mishandled.

Mitigation: Use provider-specific revocable API keys and rotate or revoke them when access is no longer needed.

Risk: Setup examples include package installation and repository cloning for local generation workflows.

Mitigation: Run setup commands in a virtual environment or container and pin dependency versions for production use.

## Description:

Helps agents use Shape Up planning to define requirements, compare solution shapes, breadboard affordances, and slice work into vertical increments.

This skill is ready for commercial/non-commercial use.

## Publisher:

[borahm](https://clawhub.ai/user/borahm)

### License/Terms of Use:


## Use Case:

Developers, product managers, and agents use this skill to shape product or feature work before implementation. It supports collaborative requirements capture, solution comparison, affordance breadboarding, fit checks, and vertical slicing.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation can cause ordinary product or feature scoping discussions to be shaped into formal tables, fit checks, and slices.

Mitigation: Review or narrow the trigger description before publishing if only explicit Shape Up workflows should activate the skill.

Risk: Planning artifacts can become misleading if requirements, shapes, breadboards, slices, and summaries drift out of sync.

Mitigation: Review generated planning documents for consistency across levels before using them to guide implementation.

# RDoC研究领域标准框架应用

## 适用场景

- 进行精神障碍的神经生物学机制研究
- 构建多维度、跨诊断的研究框架
- 需要从正常到异常的连续维度评估精神功能
- 整合遗传、神经、生理和行为多层面数据

## 不适用场景

- 常规临床门诊诊断（RDoC是研究框架，非诊断工具）
- 需要DSM/ICD分类诊断的临床决策

## 核心工作流程

### 步骤1：确定研究的功能领域

从RDoC的5大核心系统中选择与研究问题相关的功能领域：

1. **负价系统**：涉及恐惧、焦虑、失落、挫败等威胁相关反应
2. **正价系统**：涉及奖励学习、奖励估价、习惯等奖赏相关行为
3. **认知系统**：涉及注意、知觉、记忆、认知控制等认知功能
4. **社会系统**：涉及依恋、社会交往、自我/他人感知等社会功能
5. **觉醒/调节系统**：涉及昼夜节律、睡眠-觉醒调节

### 步骤2：选择分析单元

根据研究层次和资源，从7个分析单元中选择一个或多个：

1. **基因**：遗传变异、表观遗传修饰
2. **分子**：神经递质、激素、神经营养因子
3. **细胞**：神经元类型、胶质细胞
4. **神经回路**：脑区连接、网络功能
5. **生理学**：神经影像、电生理、自主神经反应
6. **行为**：任务表现、行为观察
7. **自我评估**：主观报告、问卷量表

### 步骤3：构建维度化研究设计

1. 明确研究的功能领域和分析单元组合（矩阵交叉点）
2. 定义从正常到异常的连续维度变量
3. 设计多维度测量方案，覆盖多个分析单元
4. 避免基于传统疾病分类的分组假设

### 步骤4：整合多层面数据

1. 收集跨分析单元的数据（如基因+神经回路+行为）
2. 分析不同层面变量间的关联模式
3. 识别特定功能领域的生物行为学标志物
4. 建立从分子/细胞到行为的跨层次解释模型

## 关键原则

- **维度而非分类**：评估功能连续体，而非疾病类别
- **跨诊断**：同一功能领域异常可能出现在多种传统诊断中
- **从正常到异常**：包含健康对照，理解异常的偏离程度
- **多层面整合**：同时考察多个分析单元，建立跨层次联系

## 输出要求

构建的研究设计应包含：
- 明确的功能领域和分析单元选择
- 维度化的变量定义和测量方案
- 多层面数据整合策略
- 与传统分类诊断的对比说明

## Description:

Security auditing skill for scanning CVE vulnerabilities across npm, Python, Go, and Rust projects using osv-ui. Opens a visual browser dashboard for human review, then applies fixes with explicit confirmation.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill to audit npm, Python, Go, and Rust project dependencies for known CVEs, review a visual OSV dashboard, and propose package fixes only after explicit confirmation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill asks agents to run an unpinned npm package with broad local filesystem and environment access.

Mitigation: Pin osv-ui to a reviewed version or install it through a lockfile, and run it with limited filesystem and environment access.

Risk: Package upgrade suggestions can change project dependencies in ways that affect builds or runtime behavior.

Mitigation: Invoke the skill only for explicit dependency-audit requests, require confirmation before applying changes, and re-scan after any package updates.

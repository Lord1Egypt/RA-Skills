## Description:

Generate publication-quality visualizations for 3DGS research: radar charts, comparison tables, method timelines. Static (PDF/PNG) and interactive (HTML) output.

This skill is ready for commercial/non-commercial use.

## Publisher:

[jaccen](https://clawhub.ai/user/jaccen)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and researchers use this skill to create radar charts, comparison tables, efficiency scatter plots, and timelines for 3D Gaussian Splatting method comparisons, papers, presentations, and literature reviews.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated visualization files may contain private research results or sensitive data.

Mitigation: Use non-sensitive data when possible and review generated HTML, PDF, and PNG outputs before sharing.

Risk: The skill may generate local Python scripts and visualization files in the workspace.

Mitigation: Choose output paths deliberately and review generated files before execution or publication.

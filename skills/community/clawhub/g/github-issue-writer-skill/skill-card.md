## Use Case:

Developers and teams use this skill to turn GitHub issue-writing goals into structured plans, reusable checklists, next actions, and editable draft copy while avoiding secrets and unsafe shell guidance.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Users may paste secrets or sensitive private issue details into prompts while preparing issue drafts.

Mitigation: Use goals and notes that omit passwords, OTPs, private keys, session secrets, and unnecessary personal data.

Risk: Generated issue guidance or draft copy may be incomplete or misleading if used without review.

Mitigation: Review the plan, checklist, next actions, and draft copy before publishing or assigning work.

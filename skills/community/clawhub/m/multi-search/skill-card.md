## Description:

Intelligent multi-topic deep research tool supporting arbitrary material input, using independent research agents for parallel deep retrieval and systematic research document generation.

This skill is for research and development only.

## Publisher:

[neverchenx](https://clawhub.ai/user/neverchenx)

### License/Terms of Use:

CC-BY-NC-SA-4.0

## Use Case:

External users, analysts, and developers use this skill to coordinate deep research across multiple related topics, run parallel retrieval workflows, and produce concise Markdown research reports with an integrated overview.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Input material may be summarized and used to guide web research.

Mitigation: Use the skill only with material approved for that workflow and remove sensitive details before invoking it.

Risk: Markdown research files are created under an automatically selected project or research directory.

Mitigation: Specify or confirm the output path when file placement matters, then review generated files before sharing.

# video-hook-generator — 短视频爆款钩子生成器

## 什么是好的钩子？

抖音/B站算法考核前3秒完播率。**好钩子 = 让人停下来想看**。

## 钩子类型（8种核心类型）

| 类型 | 公式 | 适用场景 |
|------|------|---------|
| 🔥 冲突型 | "别再XXX了，XXX才是真相" | 争议话题、打破认知 |
| 📊 数字型 | "3个技巧，让你XXX" | 干货类、教程类 |
| 🎭 悬念型 | "我以为XXX，直到XXX" | 故事类、经验分享 |
| 💡 揭秘型 | "XXX的内幕，今天全部说清楚" | 测评、揭秘 |
| 😂 反常型 | "XXX？其实是XXX" | 搞笑、打破认知 |
| 😰 痛点型 | "还在为XXX头疼？教你1招解决" | 实用技巧、产品 |
| 🎁 福利型 | "免费送你XXX，限前100名" | 课程、产品推广 |
| 🚀 结果型 | "用了这个方法，XXX提升了3倍" | 成果展示、案例 |

## 使用方式

### 方式一：直接生成

```
生成钩子：AI写作技巧
目标平台：抖音
视频类型：教程类
生成数量：10个
```

### 方式二：命令行

```bash
python scripts/hook_generator.py --topic "AI写作技巧" --platform douyin --count 10
```

### 方式三：批量生成

```bash
python scripts/batch_hooks.py --input topics.txt --output hooks_output/
```

## 钩子 + 脚本模板

生成钩子后可自动生成配套的前3秒脚本台词：

```bash
python scripts/hook_generator.py --topic "AI写作技巧" --include-script
```

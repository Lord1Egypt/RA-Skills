## Description: <br>
Installs an OpenClaw hook that automatically labels new chat sessions with a short title generated by the session's current model, falling back to truncating the first user message. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[woohahahaaa](https://clawhub.ai/user/woohahahaaa) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
OpenClaw users and operators use this skill to install a hook that labels new chat sessions automatically, making session lists easier to scan without changing prompts, tools, or message flow. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The install trigger is broad for a persistent hook that automatically changes OpenClaw session labels. <br>
Mitigation: Install only after an explicit operator request, review the hook code, and enable it only when automatic session labeling is intended. <br>
Risk: The hook sends the first user message to the session's current model or provider to generate a title. <br>
Mitigation: Confirm that routing the first message to that model or provider is acceptable for the workspace's data handling policy before enabling the hook. <br>

## Description:

Systematic 6-layer diagnostic framework for OpenClaw issues: policy, config, runtime, logs, network, code.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and operators use this skill to troubleshoot OpenClaw tool, channel, runtime, log, network, and plugin-code issues with a structured evidence-based diagnostic process.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Diagnostics may involve reading local OpenClaw configuration, logs, channel status, or plugin code.

Mitigation: Limit use to troubleshooting sessions where that local diagnostic context is appropriate and review any sensitive findings before sharing.

Risk: Suggested configuration changes may affect tool or channel access.

Mitigation: Review proposed OpenClaw configuration changes before applying them.

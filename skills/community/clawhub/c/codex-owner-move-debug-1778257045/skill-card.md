## Description:

Documents a realistic owner migration validation workflow for creating a skill under a personal owner, moving it to OpenClaw, and confirming cleanup.

This skill is ready for commercial/non-commercial use.

## Publisher:

[steipete](https://clawhub.ai/user/steipete)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and reviewers use this skill to validate a ClawHub owner-migration workflow during PR review, including explicit cleanup after moving a skill between owners.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill is purpose-built for owner-migration testing and review, so using it as general production migration guidance could lead to inappropriate workflow decisions.

Mitigation: Install and use it only when testing or reviewing the OpenClaw owner-migration workflow, and verify cleanup expectations during review.

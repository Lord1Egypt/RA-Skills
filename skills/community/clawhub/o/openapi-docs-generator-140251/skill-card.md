## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to turn API documentation requests into practical OpenAPI or Swagger workflows, checklists, analysis, code changes, or validation steps. It is intended for backend, platform, developer-experience, and maintainer teams documenting REST APIs.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate on broad API documentation wording and provide guidance for requests that need a more specific backend or platform skill.

Mitigation: Invoke a more specific skill manually for unrelated backend work, and review generated OpenAPI or Swagger guidance before applying it to a service.

Risk: Documentation or code suggestions can introduce inaccurate API contracts if they are not checked against the actual service behavior.

Mitigation: Validate generated specifications, examples, and commands against the implementation and include test or lint commands when code or data changes are involved.

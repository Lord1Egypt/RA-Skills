## Description:

Translates academic PDFs from English to Chinese while preserving formulas and layout, producing bilingual and Chinese-only PDFs plus a glossary.

This skill is ready for commercial/non-commercial use.

## Publisher:

[xing-xing-coder](https://clawhub.ai/user/xing-xing-coder)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, researchers, and agents use this skill to translate academic PDF papers from English to Chinese and collect bilingual, monolingual, and glossary outputs for review or sharing.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The normal run path may download and execute external installer code and install an unpinned Python tool under the user's account.

Mitigation: Prefer manually installing reviewed, pinned dependencies before use, or run the skill in a controlled environment.

Risk: Input PDFs and generated outputs may contain sensitive or copyrighted material, and the artifact includes a path for copying PDFs into QQBot upload storage.

Mitigation: Use non-sensitive PDFs, choose a controlled output folder, and copy files into upload storage only when intentional sharing is allowed.

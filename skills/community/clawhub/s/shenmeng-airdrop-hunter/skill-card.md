## Description:

Airdrop Hunter helps agents discover, assess, and plan participation in cryptocurrency airdrop opportunities across Layer 1/2 networks, DeFi, AI, and RWA projects.

This skill is ready for commercial/non-commercial use.

## Use Case:

External crypto users and agents use this skill to identify potential airdrops, evaluate risk and cost, generate interaction checklists and tutorials, and compare project scoring or ROI assumptions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The release is a paid airdrop-farming assistant with billing code that security evidence flags as under-scoped.

Mitigation: Review billing before use, revoke the exposed SkillPay API key, move authorization server-side, and require clear user confirmation before any charge.

Risk: The skill may encourage multi-account tactics, automation, proxy use, and anti-detection workflows.

Mitigation: Check each project and platform's rules before acting, avoid prohibited behavior, and treat eligibility outcomes as uncertain.

Risk: Wallet, proxy, fingerprint-browser, and automation guidance can expose funds or accounts if copied carelessly.

Mitigation: Use official project links, keep high-value assets away from experimental wallets, review token approvals, and validate every transaction before signing.

Risk: Airdrop plans, snapshots, and token values are speculative and may change or never materialize.

Mitigation: Verify current project announcements independently and treat scores, ROI estimates, and tutorials as planning aids rather than investment advice.

## Description:

Run link building outreach through the MentionAgent MCP server.

This skill is ready for commercial/non-commercial use.

## Publisher:

[buildsbymatt](https://clawhub.ai/user/buildsbymatt)

### License/Terms of Use:

MIT-0

## Use Case:

Operators using MentionAgent use this skill to review outreach drafts, manage publisher replies and placement workflows, and adjust campaigns from an agent. Email is sent only after the operator reviews and approves the exact message.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad everyday prompts may activate outreach workflows unexpectedly.

Mitigation: Confirm that the request concerns a specific MentionAgent task and review the proposed action before proceeding.

Risk: The reciprocal-placement workflow may involve local code edits, and the scan could not fully assess a local reference.

Mitigation: Inspect the unresolved reference before use; show any proposed code diff and obtain approval before editing.

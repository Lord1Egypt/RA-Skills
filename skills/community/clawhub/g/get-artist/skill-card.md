## Description:

Look up an Art Blocks artist and their body of work using artblocks-mcp.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

External users and agents use this skill to find an Art Blocks artist by name, slug, or wallet address and summarize that artist's project portfolio. It supports artist research, portfolio exploration, and project comparison using the get_artist tool.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Floor prices and listing data can change and may be mistaken for financial advice.

Mitigation: Present market data as informational and confirm current details independently before purchase or trading decisions.

Risk: Artist-name searches can be ambiguous when a partial match returns multiple artists.

Mitigation: Show all matched artist names and ask for a more specific name, slug, or wallet address when needed.

## Description:

Generate high-performing YouTube video scripts, titles, thumbnails, descriptions, and chapter markers from any topic or content.

This skill is ready for commercial/non-commercial use.

## Publisher:

[markusmikely](https://clawhub.ai/user/markusmikely)

### License/Terms of Use:

MIT

## Use Case:

External creators, marketers, and content teams use this skill to turn a topic, article, product, or niche into a complete YouTube planning package with titles, a thumbnail brief, script, chapters, description, SEO keywords, and upload strategy.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Optional trend searches send the user's topic query to Tavily and require access to a Tavily API key.

Mitigation: Use the offline title, hook, and script-generation features for private topics or sensitive business plans, or only run trend analysis when sharing the query with Tavily is acceptable.

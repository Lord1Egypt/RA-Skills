This skill is ready for commercial/non-commercial use.

## Use Case:

Project managers, developers, and teams use this skill to convert task lists with dates, owners, progress, and dependencies into an interactive Gantt chart HTML file for planning and status tracking.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated Gantt chart HTML may include business-sensitive schedule names, dates, owners, progress, and dependency details.

Mitigation: Review generated HTML before sharing and remove or anonymize sensitive project information when needed.

Risk: Incorrect or incomplete task data can produce misleading timelines, progress indicators, or dependency views.

Mitigation: Verify task dates, owners, progress values, and dependencies before using generated charts for planning or reporting.

## Use Case:

Developers, product planners, and agents use this skill to turn early product, system, roadmap, architecture, and Azure DevOps planning work into durable handoff artifacts before implementation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: When a destination is clear and the agent has write access, locked planning artifacts may be written or updated.

Mitigation: Specify the destination explicitly and request a preview before committing updates when tighter control is needed.

Risk: Planning artifacts can preserve incorrect assumptions or unclear boundaries if source context is incomplete.

Mitigation: Review assumptions, open questions, scope, non-scope, and acceptance criteria before handing the artifact to an implementer.

# 四时养生指导速查表

> 基于《黄帝内经·四气调神大论》的季节性饮食与运动指导。

---

## 一、四季养生总纲

> "春夏养阳，秋冬养阴。"

| 季节 | 五脏对应 | 养生重点 | 核心原则 |
|------|----------|----------|----------|
| **春** | 肝 | 养肝护阳 | 生而勿杀，予而勿夺，赏而勿罚 |
| **夏** | 心 | 养心护阳 | 使志无怒，使华英成秀 |
| **秋** | 肺 | 养肺收阳 | 收敛神气，使秋气平 |
| **冬** | 肾 | 养肾藏阳 | 使志若伏若匿，若有私意 |

## 二、春季养生（农历正月-三月）

### 时节定位

| 节气 | 养生定位 |
|------|----------|
| **立春-春分** | 初春，阳气初升 |
| **春分-谷雨** | 暮春，阳气渐盛 |
| **谷雨前后** | 湿气渐重，需利湿 |

### 饮食原则

> 《黄帝内经》："省酸增甘，以养脾气。"

| 原则 | 内容 | 原因 |
|------|------|------|
| **省酸** | 减少酸味食物 | 酸入肝，过酸使肝气过旺克脾 |
| **增甘** | 增加甘味食物 | 甘入脾，补脾防止肝克脾 |
| **疏肝** | 吃疏肝理气食物 | 顺应春气，助阳气升发 |
| **利湿** | 谷雨后增加利湿食物 | 湿气渐重，需健脾利湿 |

### 春季宜食

| 类别 | 推荐 | 功效 |
|------|------|------|
| **甘味养脾** | 山药、红枣、蜂蜜、糯米、南瓜 | 补脾益气 |
| **疏肝理气** | 香椿、豆芽、韭菜（适量）、茼蒿 | 顺春气升发 |
| **清利湿邪** | 茯苓、薏米、赤小豆、冬瓜 | 利湿健脾 |
| **时令菜蔬** | 春笋、菠菜、荠菜、芹菜 | 顺时而食 |
| **柔肝养血** | 黑芝麻、枸杞、桑葚 | 养肝血 |

### 春季忌食

| 类别 | 忌讳 | 原因 |
|------|------|------|
| **过酸之物** | 过量酸味、醋、柠檬 | 过酸伤肝，肝旺克脾 |
| **寒凉之物** | 冷饮、生冷瓜果 | 寒凉遏制阳气升发 |
| **辛辣燥热** | 过辣、油炸 | 春季肝火易旺，辛辣助火 |

### 春季运动

> "夜卧早起，广步于庭，被发缓形。"

| 要点 | 内容 |
|------|------|
| **户外为主** | 到户外、大自然中运动 |
| **舒缓为主** | 不宜剧烈、不宜大汗 |
| **早晨为佳** | 早晨阳气升发时运动 |
| **放松形体** | 穿宽松衣物，不束缚 |

### 春季推荐运动

| 运动 | 方法 | 功效 |
|------|------|------|
| **晨间散步** | 早晨户外缓行30分钟 | 顺应阳气升发 |
| **太极拳** | 缓慢柔和的动作 | 舒筋活血 |
| **八段锦** | 重点"调理脾胃须单举" | 调理肝脾 |
| **拉伸舒展** | 拉伸筋骨 | 肝主筋，舒筋养肝 |
| **踏青赏花** | 户外亲近自然 | 舒畅情志 |

## 三、夏季养生（农历四月-六月）

### 时节定位

| 节气 | 养生定位 |
|------|----------|
| **立夏-小满** | 初夏，心火渐旺 |
| **小满-芒种** | 湿热加重 |
| **夏至-大暑** | 盛夏，阳气最盛 |

### 饮食原则

> 《黄帝内经》："夏气热，宜食苦以泻热。"

| 原则 | 内容 | 原因 |
|------|------|------|
| **增苦减辛** | 适当吃苦味，减少辛辣 | 苦入心泻心火，辛散气 |
| **清热生津** | 清热解暑，生津止渴 | 夏季热盛，津液易耗 |
| **健脾利湿** | 健脾祛湿 | 夏季湿热交蒸 |
| **勿贪寒凉** | 不过度吃冷饮冰食 | 寒凉伤阳气 |

### 夏季宜食

| 类别 | 推荐 | 功效 |
|------|------|------|
| **苦味清心** | 苦瓜（适量）、莲子心、荷叶 | 清心泻火 |
| **清热生津** | 绿豆、西瓜、黄瓜、番茄 | 清热解暑 |
| **健脾利湿** | 茯苓、薏米、扁豆、冬瓜 | 祛湿健脾 |
| **养心安神** | 小麦、百合、莲子、龙眼（少量） | 养心补血 |
| **酸味敛气** | 梅子、杨梅、柠檬（适量） | 夏季气易散，酸可收敛 |

### 夏季忌食

| 类别 | 忌讳 | 原因 |
|------|------|------|
| **过度寒凉** | 过量冷饮、冰食 | 寒凉伤阳气 |
| **辛辣燥热** | 过辣、油炸 | 夏季心火旺，辛辣助火 |
| **肥甘厚味** | 过油腻 | 损伤脾胃运化 |

### 夏季运动

> "夜卧早起，无厌于日，使气得泄。"

| 要点 | 内容 |
|------|------|
| **无厌于日** | 不躲避阳光，适度晒太阳 |
| **使气得泄** | 适度出汗，不憋闷 |
| **不宜大汗** | 适度出汗，不过度 |
| **清晨傍晚** | 避正午烈日 |

### 夏季推荐运动

| 运动 | 方法 | 功效 |
|------|------|------|
| **清晨散步** | 早晨6-7点户外缓行 | 顺应阳气 |
| **傍晚慢走** | 傍晚6-7点散步 | 避正午热气 |
| **太极拳** | 缓慢柔和 | 养心安神 |
| **八段锦** | 重点"摇头摆尾去心火" | 清心泻火 |
| **静坐冥想** | 10-20分钟静坐 | 养心安神 |

## 六、立夏到小满专题指导

### 时节特征

| 维度 | 内容 |
|------|------|
| **节气** | 立夏（夏始）→ 小满（渐热） |
| **季节** | 初夏（夏季初期） |
| **五脏对应** | 心（夏属心） |
| **阴阳特点** | 阳气渐盛，心火渐旺 |
| **养生总则** | 春夏养阳，夏季养心护阳 |

### 立夏到小满饮食方案

```
【早餐】
├─ 绿豆粥或薏米粥（清热利湿）
├─ 或小麦粥（养心）
└─ 配清淡蔬菜，不宜油腻

【午餐】
├─ 主食：米饭
├─ 苦瓜炒蛋（清心火，适量）
├─ 或冬瓜排骨汤（利湿清热）
├─ 或莴笋炒肉（清热通络）
└─ 配时令蔬菜

【晚餐】
├─ 宜清淡，不宜过饱
├─ 莲子百合粥（养心安神）
└─ 或薏米冬瓜汤（利湿）

【茶饮】
├─ 荷叶茶（清暑利湿）
├─ 莲子心茶（清心火）
├─ 菊花茶（清热明目）
└─ 酸梅汤（敛气生津）
```

### 立夏到小满运动方案

```
【早晨】
├─ 5-6点起床（比春季更早）
├─ 户外散步30分钟或八段锦
├─ 适度晒太阳（无厌于日）
└─ 不宜大汗

【午间】
├─ 午休15-30分钟（养心）★重要★
└─ 不宜过饱

【傍晚】
├─ 傍晚散步30分钟
├─ 或静坐冥想
└─ 避正午烈日
```

### 八段锦夏季重点动作

| 动作 | 功效 | 方法 |
|------|------|------|
| **第一式：双手托天理三焦** | 调理全身气机 | 夏季气机易乱 |
| **第四式：五劳七伤往后瞧** | 调理五脏劳损 | 夏季心火旺 |
| **第五式：摇头摆尾去心火** ★重点★ | 清心泻火 | 摇头摆尾，疏通心经 |
| **第八式：背后七颠百病消** | 消除疲劳 | 夏季易疲劳 |

## 七、运动禁忌（四季通用）

| 禁忌 | 原因 |
|------|------|
| **不宜大汗淋漓** | 大汗耗阳气，伤心气 |
| **不宜正午运动**（夏季） | 正午阳气最盛，易伤心气 |
| **不宜夜练** | 夜间阳气收敛，不宜运动 |
| **不宜空调房运动** | 寒气遏制阳气外发 |
| **汗后不冲冷水** | 汗出毛孔开，冷水闭气伤身 |

## 九、起居调摄（四季）

### 春季起居

> "夜卧早起，广步于庭。"

| 要点 | 建议 |
|------|------|
| **睡眠** | 晚10-11点睡，早6-7点起 |
| **穿衣** | "春捂"，不宜过早减衣 |
| **环境** | 保持居室通风 |

### 夏季起居

> "夜卧早起，无厌于日。"

| 要点 | 建议 |
|------|------|
| **睡眠** | 晚10-11点睡，早5-6点起（更早） |
| **午休** | 午时（11-13点）小憩15-30分钟 ★重要★ |
| **穿衣** | 宽松透气，不束缚身体 |
| **避暑** | 避正午烈日 |

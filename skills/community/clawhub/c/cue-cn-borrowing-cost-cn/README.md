# 借款费用资本化·逐行挂源

给一份财报，把附注里**借款费用资本化**那一段读成一张**每个数都能回到原句**的登记表：利息支出合计、其中资本化与其中费用化的两分、专门借款（本金、年利率、本期利息、闲置资金收益、资本化金额）、一般借款（加权平均占用额、资本化率、资本化金额）、资本化期间（开始／暂停／终止）。

借款费用资本化是附注里**最容易只抄一个总数就交差**的一块：专门借款要先减掉闲置资金收益、一般借款要用加权平均占用额乘资本化率，最后两条路加起来的数还要等于披露的「其中资本化」。这几个数分散在三四个小节里，抄错一个、或者只抄了披露数不抄构成，账就不平。本件把每个数逐行登记下来，恒等由机检现算，结论留给人。

**不判断借款是否划算、不评价融资成本高低与资本结构、不预测以后期间利息、不给评级与目标价。** 每个数照抄附注原句并挂锚；两个百分比（专门借款年利率、一般借款资本化率）写的是百分号不是万元，抄错单位就会让恒等算歪。

## 一、三十秒跑通（零输入）

不给任何数据文件，也能跑出一份完整合规的成品，看它长什么样、判据怎么打：

```bash
python3 scripts/check_borrowing_cost.py --demo
```

把这份样例存下来再跑一遍机检，它能自己过：

```bash
python3 scripts/check_borrowing_cost.py --demo > 样例借款稿.md
python3 scripts/check_borrowing_cost.py 样例借款稿.md
# → 五道全过（零发条），退码 0
```

接着换成你自己那份稿子：

```bash
python3 scripts/check_borrowing_cost.py 你的借款稿.md
```

退码 `0` 全过、`1` 有发条、`2` 用法错、`3` 读不到文件或空稿。

### 拿不到成品时，从原文开始的三步

1. **定主体与报告期**，拿到年报附注「借款费用资本化」那一节，以及长期借款／在建工程相关附注。
2. **每节抄事实，连原句一起抄**：一条 = 一行，行末挂 `「原句」〔锚：页/表〕[S#]`。判断位写 `[待人工]`。
3. **跑一遍自检**，红一条改一条：

```bash
python3 scripts/check_borrowing_cost.py --selftest
```

### 先确认通道在场（可选）

配了 `CUE_API_KEY` 才需要这一步。先列目录，再按目录里的路由地址确认工具在场：

```bash
CATALOG="https://cuecue.cn/api/mcp-catalog"
curl -s "$CATALOG" | head -c 2000
# 从目录里取本组的路由地址，确认工具在场
curl -s -X POST "$ROUTING_URL" \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```

没配凭据也能用：把附注与公告放进工作区，走用户直供那条路，代价是暂时只能用手头文件里的那几页。

## 二、五道机检在管什么

| 码 | 名称 | 判什么 | 最常拦住的情况 |
|---|---|---|---|
| `BC-STRUCT` | 形制 | 头部三件自标逐字在位；`主体：`／`报告期：` 是行首裸行；六节齐且按序；认不出的节标题与多出的同名节逐条发 | 节名改了个字就整节认不出；一节写了两次；自标少一件 |
| `BC-QUOTE` | 原句与锚 | 四个内容节里每个带数字的行须挂齐「」原句＋〔锚：…〕＋`[S#]` 三元组；例外只有 `未取到：` 行、`[待人工]` 行、`〔自算〕` 行三形；来源行须合 `- [S#] 标题 \| URL \| 检索日 YYYY-MM-DD`；正文与来源**两向**都要对得上；另做**缺口两向对账** | 数字行只写数没抄原句；检索日写成 `2025/04/20`；正文引了 `[S2]` 却没登记；正文写「未取到：X」而口径节没声明 |
| `BC-CAP` | 资本化恒等 | 专门借款（利息 − 闲置资金收益）＋ 一般借款（加权平均占用额 × 资本化率）vs 披露的「其中资本化」；**任一侧缺失 ⇒ 整条跳过，不猜、不按 0 算** | 资本化金额改了没改利息或占用额；资本化率抄成万元 |
| `BC-SPLIT` | 资本化与费用化两分 | 其中资本化 ＋ 其中费用化 vs 利息支出合计；**不许只登记一个数** | 只抄资本化、费用化空着；两侧都抄了但加不回合计 |
| `BC-LINE` | 红线 | 四组越界词，**只扫四个内容节**（`口径与未取到`、`来源` 两节整节豁免）：① 投资建议（买入／卖出／增持／减持／目标价／推荐／建议持有）② 前瞻预测（预计／预测／有望／将会／看好／预期增长／预判）③ 主观评价（合理／不合理／偏高／偏低／高估／低估／显著偏低／显著偏高）④ 越界口径（利润调节／盈余管理／调节利润／税务筹划／避税／融资成本高／财务风险／资本结构优化／杠杆空间）。判前先洗掉「」引文与〔口径／锚／自算〕标签槽——那是原文与出处，不是本件断言；再按分句判，含 `[待人工]` 或 `未取到` 的那一句跳过 | 自己写了一句「融资成本偏高」；把「预计明年利息上升」抄进正文 |

## 三、四条红线（这件的立身之本）

1. **两个百分比不是金额。** `专门借款年利率` 与 `一般借款资本化率` 写的是 `4.35%`、`5.00%` 这种百分数，不写「万元」。写成「万元」那一行会被当成金额参与恒等比对，账必然算歪。
2. **加法的两个前提不替它补。** 披露只写了资本化金额、没写利息或占用额的，正确做法是写未取到、让 BC-CAP 静默跳过，不是按「一般借款都要资本化」替它把数补上。
3. **缺口声明优先于判据。** 同一项在正文写了 `未取到：X`、在口径节也声明了 X，就是「这一项本就没取到，不判」——恒等与两分就此跳过，不重复报一句「缺失」。把「跳过」写成发条，字面通、语义反。
4. **红线只判本件自己写的字。** 照抄附注里的「预计」、锚里指向的「预计负债」科目名，都是原文与出处，不是本件下的判断；把它们判红，伤的是老老实实挂锚的人。

## 四、一条发现长什么样

```markdown
- 其中资本化〔口径：本期发生额〕302.50 万元「其中予以资本化的金额为人民币 302.50 万元」〔锚：2025 年年报·第 231 页·借款费用〕[S1]
```

两个百分比，长这样（写百分号，不写万元）：

```markdown
- 一般借款资本化率〔口径：本期〕5.00%「一般借款资本化率为 5.00%」〔锚：2025 年年报·第 231 页·借款费用〕[S1]
```

没取到的，自成一行、照实写（项名在前、「未取到」在后，两种都认）：

```markdown
- 一般借款资本化率〔口径：本期〕未取到：一般借款资本化率
```

判断位一律 `[待人工]`，不由本件代填：

```markdown
- 终止资本化时点〔口径：本期〕[待人工]
```

## 五、和另外几枚包怎么分

| 你手上是 | 用哪枚 |
|---|---|
| 借款费用资本化、专门借款、一般借款、资本化率、资本化期间 | **本件** |
| 研发支出资本化的资本化条件与摊销 | `cn-rd-capitalization-cn` |
| 投资性房地产（含其借款费用口径） | `cn-investment-property-cn` |
| 长期股权投资 | `cn-long-term-equity-investment-cn` |
| 审计意见类型、关键审计事项 | `cn-audit-opinion-cn` |

借款费用与研发支出资本化是两件容易混的事，界线在**钱的用途**：借来的钱盖资产、算的是利息怎么分摊，归本件；自己投研发、判的是能不能资本化与何时摊销，归 `cn-rd-capitalization-cn`。两件都出现「资本化」三个字，但不是同一套判据。

## 六、素材从哪来

- **用户直供**：手头的年报 PDF、公告，走解析通道读成能检索的正文。
- **通道取证**：配了 `CUE_API_KEY` 后可走财报检索与原文解析。装好 skill ≠ 已配凭据 ≠ 通道已连，三层分开看。
- **资本化的数常散在多处**（借款费用附注、长期借款附注、在建工程附注），长附件与扫描件交给解析腿：先取大纲，再按节取用。计费与可用性以服务端返回为准。

本件不发请求、不代付费，消耗以服务端返回为准。

## 七、跑夹具与测试

```bash
bash scripts/fixtures/run_fixtures.sh
python3 tests/test_borrowing_cost.py
```

三档：机检自测 / 好样坏样逐枚单跑 / 在好样上逐处替换做正反对照（该红的红、该不红的不红）。零网络、零计费，产物只落临时目录，跑完即删。

末行自报「档数=…｜不合=N｜不可判=N」（档数由 runner 自己现算，不写死）；退码 `0` 全过、`1` 有不合、`3` 取值域故障。

`tests/` 跑的是外壳属性——`--help` 退 0、无参退 2、缺文件或空稿退 3、`--demo` 产物自过机检且与好样夹具同源。

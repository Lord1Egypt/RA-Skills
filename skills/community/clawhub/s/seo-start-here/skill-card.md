## Description:

Not sure where to start with SEO? Asks up to five quick questions, takes a quick look at the site, and recommends which RomeoSEO skills to run in what order, with what to gather first and the exact first prompt. Use for "where do I start with SEO", "help with my site's SEO", "which skill should I use".

This skill is ready for commercial/non-commercial use.

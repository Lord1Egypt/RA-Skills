# 共同内核索引

共同内核保存 OpenXSys 在任何对象、宿主和方法下都成立的系统语义。当前判断触及“什么不可牺牲”“这个对象怎样才算一个系统”“关系和能力是否真实成立”时，从这里进入。

| 当前需要判断什么 | 读取 | 带回当前系统 |
| --- | --- | --- |
| OpenXSys 为谁工作，什么不可被局部效率牺牲 | [宪法](constitution.md) | 身份、体验承诺、所有权与真实边界 |
| 什么构成系统，边界、层级、状态和目的怎样相互作用 | [系统](system.md) · [系统科学](system-science.md) | 合适尺度上的系统图景 |
| 认识怎样形成，什么能够被声称为知道 | [认识论](epistemology.md) | 证据、推断、不确定性与可纠正判断 |
| 两个系统是否真的发生作用 | [关系](relation.md) | 作用双方、转换、条件、确认与反馈 |
| 一项能力是否真的存在 | [能力](capability.md) | 部件、连接、运行条件、控制与验证 |
| 经历怎样改变未来，改变怎样沿层级传播 | [演化](evolution.md) | 应更新的结构、依赖与未来行为 |

内核给出判断语言，不替当前对象规定路线。得到所需的不变量或模型后，回到[运行时索引](../runtime/INDEX.md)，继续观察、组装、行动或验证。

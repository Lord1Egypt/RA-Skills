## Description:

Generate multiple game design solution paths before committing to one direction. Use when a feature, live-ops idea, UX problem, economy issue, or design challenge feels too quickly narrowed, when a team is looping around one favorite answer, or when you need several credible options with tradeoffs instead of a single premature recommendation.

This skill is ready for commercial/non-commercial use.

## Use Case:

Game designers, product teams, and game development leads use this skill to expand a feature, live-ops, UX, economy, or design challenge into several credible solution paths before choosing a direction.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Design recommendations may be incomplete if the user provides limited product, player, business, or implementation context.

Mitigation: Review generated options against current game goals, constraints, player impact, business value, implementation burden, and strategic fit before acting.

Risk: The skill shapes brainstorming and recommendations but does not validate feasibility through tools, data access, or code execution.

Mitigation: Treat outputs as decision-support guidance and validate selected paths with the team, available production data, and implementation planning.

## 这是什么

矿业技术服务合同，是这个行业最容易吃亏的地方：**工艺包交出后要不回钱、产量提成算不清、验收指标被临时改口径、知识产权被要求让渡**。本技能沉淀了矿山技术服务合同谈判的实战框架，帮你在谈之前把方向定对、把坑找出来：

1. **标准模式**：工艺包 + 技术服务 + 产量提成（最主流）—— 首付 → 交付 → 达标 → 按月提成（年度封顶）
2. **买断模式**：甲方资金充裕、不想长期分成绑定 —— 签约付一半 → 达标付另一半 → 年度顾问费
3. **技术入股**：深度绑定，甲方给真股份并开放财务监督权 —— 技术评估作价 → 达产节点分期解锁 → 固定分红 + 退出窗口
4. **阶段咨询**：可研 / 试验 / 诊断 / EPCM —— 五段验收，按阶段交付收费

## 3 问决策树：定模式

```
Q1 甲方资金充裕、想一次了断、不愿被长期分成绑定？
├─ 是 → 买断模式（签约付一半 → 达标付另一半 → 年度顾问费）
└─ 否 ↓

Q2 甲方愿给真股份并开放财务监督权，你想深度绑定长期分红？
├─ 是 → 技术入股（评估作价 → 分期解锁 → 固定分红 + 退出窗口）
└─ 否 ↓

Q3 项目还在前期（可研 / 试验 / 诊断 / EPCM），没有确定性产量？
├─ 是 → 阶段咨询（五段验收，按阶段交付收费）
└─ 否 → 标准模式（首付 → 交付 → 达标 → 按月提成 + 年度封顶）✅ 最主流
```

## 5 条红线（生成 / 审查合同时逐条打勾）

- [ ] **知识产权归属**——工艺包 / 药剂配方 / 自控程序归技术方，被让渡＝教完徒弟饿死师傅
- [ ] **保密期限**——长期、终止后存续，否则合同一终止秘方"合法"外流
- [ ] **违约金上限**——双向量化，否则对方违约没代价、你违约敞口无限
- [ ] **财务监督权**——入股模式必须，看不到账的股份都是画饼
- [ ] **管辖地**——约定在自己可控一侧，异地应诉成本能拖垮你

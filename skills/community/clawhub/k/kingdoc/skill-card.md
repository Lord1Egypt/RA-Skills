## Description:

KingDoc helps agents manage Kingsoft Docs workflows, including document and table editing, local generation and OCR, form analytics, collaboration, and compliance checks.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and workspace teams can use the skill to manage Kingsoft Docs files, automate table and form workflows, and create or review documents. It also provides local document generation and OCR workflows.

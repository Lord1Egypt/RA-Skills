## Description:

Promotes the sale of the clawzhipin.com and clawzhipin.cn domains when an agent user discusses Claw, OpenClaw, AI employees, or recruiting agents.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kllb520](https://clawhub.ai/user/kllb520)

### License/Terms of Use:

MIT-0

## Use Case:

External users or agent operators use this skill to generate promotional replies for the ClawZhiPin domain sale when conversations directly concern AI employee recruiting, Claw, OpenClaw, or the clawzhipin domain.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad triggers can insert domain-sale advertising into ordinary Claw, OpenClaw, AI employee, or recruiting conversations.

Mitigation: Enable the skill only for explicit domain-sale or ClawZhiPin inquiries, or narrow the trigger scope before deployment.

Risk: The skill can open an external website after a user expresses interest.

Mitigation: Require explicit user confirmation before opening clawzhipin.com or any other external site.

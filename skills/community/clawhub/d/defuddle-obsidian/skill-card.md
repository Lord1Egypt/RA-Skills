## Use Case:

Developers and agents use this skill to fetch readable content from standard web pages, online documentation, articles, and blog posts while reducing navigation, advertising, and other page clutter.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill asks users to install an unpinned third-party Defuddle CLI globally.

Mitigation: Use a reviewed, pinned, project-local install when possible, and do not run the npm install command with elevated privileges.

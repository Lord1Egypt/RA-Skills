## Description:

Web scraping from TypeScript or JavaScript with the Scrapfly SDK (`scrapfly-sdk`) for scraping URLs, bypassing anti-bot protection, rendering JavaScript, capturing screenshots, and extracting structured data from Node.js, Deno, or Bun.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill to generate TypeScript or JavaScript guidance, code examples, shell commands, and configuration for using the Scrapfly SDK to scrape pages, render JavaScript, capture screenshots, and extract structured data.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill sends scraping and extraction work to Scrapfly as an external service, which can expose page content to that service.

Mitigation: Use it only for content you are authorized to process, and avoid sending private, authenticated, personal, or proprietary page content unless approved.

Risk: SDK installation can drift over time if versions are not pinned.

Mitigation: Pin the Scrapfly SDK version and use a lockfile for reproducible installs.

Risk: Anti-bot bypass, proxy rotation, geo-targeting, and scraping workflows can be misused against sites or data sources.

Mitigation: Confirm scraping is permitted for the target site and use the skill within applicable policies, laws, and contractual terms.

## Use Case:

Developers use this skill to integrate existing Masko images, single animations, or interactive mascot releases into web, mobile, and desktop apps. ## Known Risks and Mitigations:

Risk: Publishing mascot assets makes the finished files publicly accessible.

Mitigation: Explain which files will become public and get the user's agreement before publishing.

Risk: Unpublishing assets breaks their links in live websites and apps.

Mitigation: Unpublish only when the user asks.

Risk: One local reference was unresolved during the security review, leaving that part of the guidance unverified.

Mitigation: Check the missing reference and review the affected guidance before relying on it.

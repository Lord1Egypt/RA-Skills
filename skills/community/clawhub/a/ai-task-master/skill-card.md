## Description:

Intelligent task planner using the Plan-and-Solve pattern to break goals into actionable steps with timelines and priorities.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

External users and developers use this skill to break large goals into scheduled, prioritized task plans and track progress.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Users may expect runnable JavaScript functionality, but security evidence says the package does not include the referenced index.js implementation.

Mitigation: Treat the release as a lightweight planning prompt or documentation artifact unless an implementation is supplied and reviewed.

Risk: Generated task plans can include incomplete, unrealistic, or poorly prioritized steps.

Mitigation: Review proposed timelines, priorities, and dependencies against the user's actual constraints before acting on the plan.

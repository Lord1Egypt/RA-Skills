## Description:

Analyzes HTML/CSS websites for SEO issues, helps apply optimization fixes, and supports report, sitemap, robots.txt, and schema markup workflows.

This skill is ready for commercial/non-commercial use.

## Publisher:

[yesong-hue](https://clawhub.ai/user/yesong-hue)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and website maintainers use this skill to audit HTML/CSS websites, prioritize SEO issues, add metadata and structured data, and generate supporting sitemap and robots.txt assets before publishing.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated sitemap, robots.txt, schema markup, or language metadata may be incorrect for a specific site, especially non-English or multilingual sites.

Mitigation: Review generated SEO assets and metadata before publishing, and validate structured data with the referenced testing tools.

Risk: The skill inspects and may edit SEO-related website files.

Mitigation: Install and run it only for repositories where SEO file inspection and modification are intended.

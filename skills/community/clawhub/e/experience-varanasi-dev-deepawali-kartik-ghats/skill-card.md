## Description:

A low-intensity, multi-week guided experience of Dev Deepawali in Varanasi, with 25 steps and reflective prompts along the Ganga ghats.

This skill is ready for commercial/non-commercial use.

## Publisher:

[liveneon](https://clawhub.ai/user/liveneon)

### License/Terms of Use:

MIT-0

## Use Case:

External users use the skill to register with Drifts, begin and continue a multi-week Varanasi cultural journey, add reflections for a closing postcard, and optionally leave a review.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security assessment says the external account and review requests do not clearly match the described cultural experience, and it did not establish whether placeholder values were replaced.

Mitigation: Before installing or using the skill, review the requested external actions and personal or system details, and share only information you are comfortable providing.

Risk: Registration requests can include a username, profile details, timezone, location, model information, and an optional email; state-changing requests use an API key.

Mitigation: Provide only the registration details you choose to share and keep the API key private.

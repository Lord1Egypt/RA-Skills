## Description:

A practical framework for asking better questions. Two questions + one check: Golden Circle positioning, Six-dimension validation, and Completion check. Turns fuzzy problems into clear, actionable questions.

This skill is ready for commercial/non-commercial use.

## Publisher:

[heshengshi](https://clawhub.ai/user/heshengshi)

## Use Case:

External users and developers use this skill to clarify vague tasks, evaluate whether a problem is worth solving, and define completion criteria before acting.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill suggests writing task records to persistent memory, which could retain sensitive task context if used carelessly.

Mitigation: Decide whether memory records should be written before using the skill on sensitive work, and avoid storing credentials, private conversation text, or untrusted instructions.

# 价格取证链（Price Evidence Chain）

本文件规定 PriceLens 如何取得价格证据、如何判断两条证据是不是同一件商品、以及在证据不足时如何降级。核心原则：**没有来源、日期与核实状态的价格，一律不得进入报告。**

## 1. 四类来源与取证姿势

| 来源类型 | 能拿到什么 | 拿不到什么 | 取证动作 | 单源可信度 |
|---|---|---|---|---|
| 电商搜索结果片段 | 店铺名、挂牌价、活动价、销量、评价数 | 券后实付、运费、库存、实时性 | 用「品牌 + 型号 + 到手价／元／哪个平台」组合检索，从结果摘要里截取「店铺名 + 价格 + 销量」三要素 | 中（需店铺名佐证） |
| 垂直零售商站点 | 到手价、划线价、规格、库存状态、以旧换新入口 | 平台级券与返利 | 抓列表页与商品页两层：列表页看「划线价 vs 售价」配对，商品页看价格字段与规格表 | 高（正品行货渠道） |
| 品牌官网 | 官方指导价、完整规格表、配件与保修条款 | 实际成交价 | 只取规格与指导价，作为「参数口径」与「价格上限」的锚 | 高（但非成交价） |
| 内容平台 | 晒单实付、历史好价、踩坑反馈、代际对比 | 可复现的价格 | 抽取「时间 + 型号 + 实付 + 渠道」四要素齐全的帖子，缺一项即不采信 | 低（仅作旁证） |

取证顺序建议：先用品牌官网确定**型号与参数口径**（避免比错型号），再用垂直零售商与搜索结果取得**价格区间**，最后用内容平台校验**这个价格是否合理**。

## 2. 同 SKU 判定（最容易出错的一步）

两条价格只有在下列五项全部一致时才算同一 SKU：

1. **型号全称**，含容量／尺寸／颜色代号（`X100` 与 `X100 Pro` 是两个 SKU）。
2. **套装内容**：单机 vs 含耗材包 vs 含安装，套装价与单机价不可直接比较。
3. **代际与版本**：国行／海外版、标准版／运营商定制版、新旧包装。
4. **计量单位**：单只／成对、每箱／每件、含税／不含税。
5. **时间窗口**：相隔超过 30 天的两条价格，只能作趋势参考，不能当同一时点证据。

任一项不一致，就在记录里拆成两条，并在报告中说明差异，不做平均。

## 3. 交叉验证与价差容忍度

- 每个候选**至少 3 类来源**，同一 SKU **至少 2 个独立来源**（同一集团下的不同入口不算独立）。
- 两源到手价差 **≤15%**：视为收敛，可取中位值给点值。
- 价差 **15%–30%**：必须归因，可从套装差异、赠品折算、运费口径、渠道补贴四项里找；归因成功则保留高可信那条，归因失败则给区间。
- 价差 **>30%**：默认其中一条有误或不是同一 SKU，两者都不进结论卡，只进「待复核」。
- 只有单源时，该价格只能写成「单源参考」，不得作为结论卡依据。

## 4. 价格记录字段（每条证据一行）

| 字段 | 必填 | 填写规则 |
|---|---|---|
| `sku` | 是 | 型号全称 + 关键规格 |
| `source_type` | 是 | 搜索片段／垂直站／官网／内容平台 |
| `source_id` | 是 | 域名或页面标题，便于复核 |
| `retrieved_at` | 是 | 检索日期 `YYYY-MM-DD` |
| `listed_price` | 是 | 页面挂牌价，原样记录 |
| `landed_price` | 否 | 拆解后的到手价，未拆解则留空 |
| `verified` | 是 | 已核实／待核实／无法核实 |
| `note` | 否 | 套装、赠品、运费、限时条件 |

## 5. 假信号清单（见到就标疑）

| 假信号 | 为什么危险 | 处理 |
|---|---|---|
| 「¥X 起」 | 最低配或最小规格的引流价 | 必须落到具体型号规格，落不到就不采 |
| 「券后价」未含运费 | 大件运费可占到手价 5%–15% | 单独补运费项后再比较 |
| 划线价虚高 | 划线价可能是历史高价或厂家建议价 | 只看到手价，不用划线价算折扣率 |
| 秒杀／限时标签 | 检索时点已过期 | 记录时必须写「限时，需复核」 |
| 跨境价 / 代购价 | 不含税、不含保修、汇率浮动 | 单列一类，不与国内到手价合并 |
| 赠品折算 | 把赠品按标价折进价格 | 赠品只按可查到的市场价折算，且标注「折算」 |
| 相同图片不同店铺 | 盗图或一件代发 | 看开票主体与授权声明，不看图片 |
| 评价集中在短期 | 刷单特征 | 只作旁证，不作可信度依据 |

## 6. 时间戳与复核节奏

- 每条价格必须带检索日期；报告首行统一声明「价格为检索时点抓取，需复核」。
- 时效分级：**≤7 天**可直接用；**8–30 天**可用但需标注「可能已变」；**>30 天**只能作趋势参考。
- 大促前后、新品发布前后、政策补贴窗口内，时效压缩到 **≤3 天**，因为这段时间价格波动最大。

## 7. 降级路径（证据不足时怎么办）

1. **同类来源全被拦截**：改走另一类来源，最多尝试 3 类，仍失败则进入第 2 步。
2. **只能拿到挂牌价**：输出「挂牌价区间 + 待拆解项清单」，结论卡改为价位判断，不给到手价点值。
3. **只能拿到用户口述**：以用户提供为准并标注「用户提供，未核实」，同时给出「下单前需自行核对的三项」。
4. **完全无数据**：明确写「无法定价」，改为给选型框架与验货清单，不硬凑数字。

## 8. 证据表模板

```
| # | SKU | 来源类型 | 来源 | 检索日 | 挂牌 | 到手 | 核实 | 备注 |
|---|-----|---------|------|-------|------|------|------|------|
| 1 |     | 垂直站   |      |       |      |      | 已核 |      |
| 2 |     | 搜索片段 |      |       |      |      | 待核 |      |
```

证据表放在报告最后一个区块，按 `sku` 再按 `retrieved_at` 排序，供用户逐条复核。

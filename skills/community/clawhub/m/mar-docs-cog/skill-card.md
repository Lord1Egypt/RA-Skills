## Description:

Creates professional documents such as resumes, contracts, reports, proposals, invoices, and certificates through SkillBoss API Hub, with PDF as the default requested output.

This skill is ready for commercial/non-commercial use.

## Publisher:

[marjoriebroad](https://clawhub.ai/user/marjoriebroad)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers use this skill to have an agent create polished professional documents through SkillBoss API Hub. It is suited for business, career, reporting, legal, finance, marketing, education, event, form, and certificate document requests where the user provides the content and design preferences.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Sensitive personal, legal, financial, client, employee, or confidential business content may be sent to a third-party API.

Mitigation: Use placeholders or redact sensitive values before sending prompts, and review the skill before installation for sensitive document workflows.

Risk: The artifact does not provide enough privacy, redaction, or provider retention guidance for third-party API use.

Mitigation: Verify the provider's privacy and retention practices before using the skill with confidential or regulated information.

Risk: Generated legal or financial documents may contain incorrect or unsuitable terms.

Mitigation: Have legal or financial documents reviewed by qualified professionals before use.

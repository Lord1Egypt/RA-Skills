## Description:

Step-by-step Music NFT onboarding agent for DJs and artists with enforced safety rules, copyright protection, wallet security, and NFT minting guide.

This skill is ready for commercial/non-commercial use.

## Use Case:

External DJs and music artists use this skill to learn a guided Web3 music NFT workflow, including wallet setup, platform selection, minting steps, copyright checks, and basic launch guidance.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill forces promotional X and Discord links into responses even when the user did not request them.

Mitigation: Review generated responses before deployment and remove or disclose promotional content when it is not appropriate for the user interaction.

Risk: NFT platform steps, fees, copyright requirements, and wallet safety practices can change or vary by user situation.

Mitigation: Independently verify current platform instructions, transaction costs, rights ownership, and wallet security practices before spending crypto or minting assets.

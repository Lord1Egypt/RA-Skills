## Description:

当用户需要根据商品信息撰写带货短视频、商品演示或种草口播脚本时使用。提供商品链接或商品资料，输出分镜、口播、演示动作与行动引导；可按需参考同类商品。在线商品能力支持抖音与小红书，已有资料可直接写作。来自社媒数据助手 SocialDataX。

This skill is ready for commercial/non-commercial use.

## Use Case:

External creators and commerce teams can use this skill to turn product details or supported Douyin and Xiaohongshu product links into short-form video scripts. It provides scene-by-scene visuals, spoken lines, demonstration actions, calls to action, and notes about facts that need checking.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill is rated suspicious because it repeatedly runs an unpinned `@latest` CLI that could change between runs and access credentials with the user's permissions.

Mitigation: Consider installing only after the CLI is pinned to a reviewed version and integrity checks are in place, especially when using an API key.

## Description:

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers maintaining OpenClaw agent workspaces use this skill to audit bootstrap Markdown, split oversized always-loaded files, and keep rules organized across core, execution, and archive layers.

## Known Risks and Mitigations:

Risk: The install example uses a mutable `@latest` ClawHub installer reference.

Mitigation: Use a pinned or otherwise verified ClawHub installer version before installing in controlled environments.

Risk: The audit commands inspect OpenClaw workspace Markdown files that may contain sensitive notes.

Mitigation: Review commands before running them and avoid exposing command output from sensitive workspaces.

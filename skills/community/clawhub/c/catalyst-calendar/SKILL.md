# 催化事件日历 Skill

## 触发条件
- "催化日历" / "事件日历" / "未来大事" / "catalyst calendar" / "下周有什么大事"
- "本月重要事件" / "财报季" / "议息会议"

## 输出位置
`<working_directory>/catalyst-calendar/reports/YYYY-MM-DD-catalyst-calendar.md`

## 工作流程

### 步骤1：确定时间范围
默认扫描未来14天，用户可指定范围（如"下月""未来30天"）。

### 步骤2：多维度事件采集

**宏观政策类**（web_search + neodata-financial-search）：
- 美联储议息会议日程
- 中国国常会/央行操作窗口
- CPI/PPI/PMI/社零/进出口数据发布日

**财报类**（neodata-financial-search）：
- 用户关注标的的财报发布日期
- 行业龙头财报季（银行/白酒/新能源等）

**行业政策类**（web_search）：
- 行业监管新规发布预期
- 重大展会/论坛（如CES、进博会）

**市场技术类**：
- 大量期权到期日（Quad Witching）
- ETF调仓窗口（季末月末）

### 步骤3：影响评级
对每个事件标注影响级别：
- 🔴 高影响：可能改变市场方向
- 🟡 中影响：影响特定行业/板块
- ⚪ 低影响：信息性事件

### 步骤4：综合输出

```markdown
# 📅 催化事件日历 — {MM-DD} 至 {MM-DD}

## 🔴 高影响事件
| 日期 | 事件 | 影响范围 | 关注点 |
|------|------|----------|--------|
| MM-DD | 美联储议息 | 全球 | 降息预期 |
...

## 🟡 中影响事件
| 日期 | 事件 | 影响范围 | 关注点 |
|------|------|----------|--------|
| MM-DD | 贵州茅台季报 | 白酒 | 增速验证 |
...

## ⚪ 低影响事件
...

## 本周关键时间轴
```
MM-DD ──[事件A]──▶ MM-DD ──[事件B]──▶ MM-DD ──[事件C]
```

## 投资者应对建议
- 关注前：[仓位管理建议]
- 关注后：[可能的策略调整]
```

### 步骤5：IMA 同步
高影响事件提前1天在 IMA 创建提醒笔记。

## 约束
- 14天日历控制在 800 字，30天控制在 1200 字
- 事件来源标注（官方日程/市场预期/历史规律推断）
- 每日最多标注3个高影响事件

## Description:

Helps maintainers, QA engineers, contributors, and product teams plan, implement, and validate useful unit tests that improve coverage for existing codebases.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, maintainers, QA engineers, open-source contributors, and product teams use this skill to add practical unit tests, improve test coverage, and document verification for existing codebases.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad routing terms may cause the skill to appear for general testing or quality requests.

Mitigation: Invoke the skill explicitly for unit-test coverage work when tighter routing is needed.

Risk: Suggested tests or coverage steps may not fully reflect project-specific behavior or constraints.

Mitigation: Review generated plans and code changes against the target codebase, then run the proposed verification commands before relying on the result.

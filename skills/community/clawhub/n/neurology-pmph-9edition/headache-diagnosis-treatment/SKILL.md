# 头痛疾病诊断与治疗

## 适用场景

当患者出现头痛症状，需要：
1. 根据ICHD-3标准进行头痛类型诊断与分级
2. 制定偏头痛发作期与预防性治疗方案
3. 制定丛集性头痛急性期、过渡期与预防性治疗方案

## 工作流程

### 第一步：头痛类型鉴别诊断

根据头痛特征选择对应诊断标准：

| 特征 | 偏头痛 | 紧张型头痛 | 丛集性头痛 |
|------|--------|------------|------------|
| 部位 | 多为单侧 | 双侧 | 单侧眼眶/颞部 |
| 性质 | 搏动性 | 压迫性/紧缩样 | 剧烈刺痛 |
| 程度 | 中-重度 | 轻-中度 | 重度/极重度 |
| 伴随症状 | 恶心/呕吐/畏光畏声 | 无恶心呕吐 | 同侧自主神经症状 |
| 活动加重 | 是 | 否 | 烦躁不安 |

### 第二步：紧张型头痛分级

执行分级判断流程：
1. 确认核心症状（4项中≥2项）：双侧、压迫/紧缩样、轻中度、日常活动不加重
2. 确认排除标准：无恶心呕吐 + 畏光畏声不超过1项
3. 根据发作频率分级：
   - 偶发性(IETTH)：每月<1天，每年<12天
   - 频发性(FETTH)：每月1-14天，每年≥12天且<180天
   - 慢性(CTTH)：每月≥15天，持续>3个月

### 详细诊断标准

#### 核心症状标准（所有亚型均需符合）

**头痛特征（至少符合4项中的2项）：**
1. 双侧头痛
2. 性质为压迫性或紧缩样（非搏动性）
3. 轻-中度头痛
4. 日常活动如走路或爬楼梯不加重头痛

**伴随症状（需全部符合）：**
1. 无恶心或呕吐
2. 畏光、畏声中不超过1项

#### 各亚型诊断标准

**偶发性紧张型头痛（IETTH）：**
- 平均每月发作＜1天（每年＜12天）
- 发作10次以上
- 头痛持续30分钟至7天
- 符合核心症状标准

**频发性紧张型头痛（FETTH）：**
- 平均每月发作1～14天，超过3个月（每年≥12天且＜180天）
- 发作10次以上
- 症状标准同偶发性

**慢性紧张型头痛（CTTH）：**
- 头痛平均每月发作时间≥15天，持续超过3个月（每年≥180天）
- 症状标准同偶发性

**很可能的紧张型头痛：**
- 只满足某一亚型核心标准中的3项
- 不符合其他头痛诊断

### 第三步：丛集性头痛诊断与分型

执行诊断判断：
1. 确认发作≥5次，且符合：
   - 单侧眼眶/眶上/颞部重度疼痛，持续15-180分钟
   - 伴至少1项同侧症状（结膜充血/流泪/鼻塞/流涕/眼睑水肿/瞳孔缩小/上睑下垂/烦躁不安）
   - 发作频率：隔日1次至每日8次
2. 区分发作性vs慢性：
   - 发作性：丛集期7天-1年，缓解期≥3个月，至少2个丛集期
   - 慢性：1年内无缓解期或缓解期<3个月

### 第四步：制定治疗方案

#### 偏头痛治疗

**发作期治疗**（症状起始立即服药）：
- 一线：对乙酰氨基酚或NSAIDs（布洛芬）
- 二线（无效或重度）：曲普坦类（佐米曲普坦鼻喷剂）、CGRP受体拮抗剂
- 伴随恶心呕吐：加用止吐剂
- ⚠️ 禁用：阿片类、巴比妥类、安乃近、非那西丁复方制剂

**有效性评价**：①2小时无疼痛 ②2小时内最困扰伴随症状消失 ③2小时后疼痛转轻/无痛 ④24小时内无再发

**预防性治疗适应症**：每月≥2次发作 / 急性期治疗无效 / 药物过度使用风险 / 严重影响生活

**预防性药物选择**：
- 发作性偏头痛（<15天/月）：β受体拮抗剂、抗癫痫药（托吡酯/丙戊酸盐）、抗抑郁药（阿米替林）、CGRP类药物、氟桂利嗪
- 慢性偏头痛（≥15天/月）：A型肉毒毒素、托吡酯、CGRP单克隆抗体

#### 丛集性头痛治疗

**急性期**（快速终止发作）：
- 首选：纯氧吸入（6-15L/min，约15分钟缓解，80%有效）
- 曲普坦类：舒马普坦皮下/喷鼻，佐米曲普坦喷鼻
- ⚠️ 曲普坦禁忌：心脑血管疾病、高血压
- 替代：10%利多卡因滴鼻 / 奥曲肽100μg皮下注射

**预防性治疗**：
- 一线：维拉帕米（监测心脏）
- 其他：锂盐（治疗窗窄）、褪黑素

**过渡性治疗**（桥接）：短期糖皮质激素（口服泼尼松/枕大神经阻滞）

**非药物**：蝶腭神经节刺激、迷走神经刺激、枕神经刺激

### 详细药物方案与剂量

#### 偏头痛预防性药物详细选择

**发作性偏头痛（每月<15天）：**
| 药物类别 | 具体药物 | 备注 |
|----------|----------|------|
| β受体拮抗剂 | 普萘洛尔、美托洛尔 | 一线选择 |
| 抗癫痫药 | 托吡酯、丙戊酸盐 | 注意致畸性 |
| 抗抑郁药 | 阿米替林、文拉法辛 | 伴情绪障碍优选 |
| ARB/ACEI | 坎地沙坦、赖诺普利 | 合并高血压优选 |
| CGRP类药物 | 瑞美吉泮、阿托吉泮、艾普奈珠单抗 | 新型靶向药物 |
| 钙通道阻滞剂 | 氟桂利嗪 | 注意锥体外系反应 |

**慢性偏头痛（每月≥15天）：**
- A型肉毒毒素：头部多点注射
- 托吡酯
- CGRP单克隆抗体：瑞玛奈珠单抗

**非药物治疗：**
- 针灸
- 心理治疗（CBT）
- 物理治疗
- 神经调控：眶上神经电刺激、重复经颅磁刺激

#### 丛集性头痛治疗详细方案

**急性期治疗：**
| 方案 | 剂量/方法 | 起效时间 | 禁忌 |
|------|-----------|----------|------|
| 纯氧吸入 | 6-15L/min，面罩 | ~15分钟 | 无 |
| 舒马普坦皮下 | 6mg | 10-15分钟 | 心脑血管病、高血压 |
| 佐米曲普坦喷鼻 | 5mg | 15分钟 | 同上 |
| 利多卡因滴鼻 | 10%溶液 | 较慢 | 曲普坦无效/禁忌时 |
| 奥曲肽皮下 | 100μg，发病15min内 | 30分钟 | 曲普坦/吸氧无效时 |

**预防性治疗：**
- **维拉帕米**（一线）：起始240mg/d，渐增至480-720mg/d，监测心电图
- **锂盐**：仅用于其他无效/禁忌，治疗窗窄，监测血锂浓度、甲功、肾功
- **褪黑素**：10mg睡前，辅助治疗

**过渡性治疗：**
- 口服泼尼松：60mg/d×3-5天，逐渐减量
- 枕大神经阻滞：皮下注射激素

**非药物治疗（药物无效/不耐受时）：**
- 蝶腭神经节刺激
- 非侵入性迷走神经刺激
- 侵入性枕神经刺激

## 输出要求

根据诊断结果输出：
1. 明确的头痛类型诊断（含亚型/分级）
2. 个体化分期治疗方案（急性期+预防期）
3. 药物禁忌提示与注意事项

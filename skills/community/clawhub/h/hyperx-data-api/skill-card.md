Developers use this skill to build applications that call the HyperX Data API for Hyperliquid wallet analytics, market positions, fills, market snapshots, crypto Twitter feeds, news feeds, and related trading data.

Global

## Known Risks and Mitigations:

Risk: API credentials or session cookies could be exposed if copied into code, logs, prompts, or shared artifacts.

Mitigation: Prefer API tokens, store credentials outside source code, and avoid logging or sharing headers, cookies, and secrets.

Risk: Wallet analytics, trading metrics, pricing, rate limits, and API responses may change or be unsuitable as the sole basis for financial decisions.

Mitigation: Verify current API responses, pricing, and rate limits directly with HyperX before production use or financial reliance.

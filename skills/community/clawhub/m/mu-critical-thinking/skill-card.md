## Description:

A Chinese-first critical-thinking coaching skill that evaluates arguments, identifies logical fallacies, guides Socratic questioning, audits decisions, and checks data claims.

This skill is ready for commercial/non-commercial use.

## Publisher:

[muippt](https://clawhub.ai/user/muippt)

### License/Terms of Use:

MIT

## Use Case:

Employees, external users, and knowledge workers use this skill to examine concrete arguments, proposals, decisions, data reports, and debate positions before acting on them. It produces structured critiques, follow-up questions, and practical repair suggestions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate broadly on proposal-like text and apply critique-style analysis when the user expected another mode.

Mitigation: Invoke a different skill explicitly when critique is not desired, or state the desired mode before pasting proposal-like content.

Risk: Argument and decision critiques can be incomplete if the user provides only partial context or weak source material.

Mitigation: Provide the specific text, data, assumptions, and constraints being evaluated, then review the skill's diagnosis before using it for decisions.

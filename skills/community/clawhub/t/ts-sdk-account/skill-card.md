## Description:

Guides TypeScript developers through creating, importing, serializing, signing with, and verifying Aptos SDK Account signers.

This skill is ready for commercial/non-commercial use.

## Publisher:

[iskysun96](https://clawhub.ai/user/iskysun96)

### License/Terms of Use:

MIT-0

## Use Case:

Developers integrating Aptos account management in TypeScript use this skill to choose account types, create or import signers, serialize accounts, and sign or verify messages and transactions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Private keys, mnemonics, serialized account hex, and generated accounts can grant full control of Aptos accounts if exposed.

Mitigation: Keep secrets out of frontend code, logs, source control, and shared prompts; use server-side environment storage, managed secret storage, or wallet adapters for production user flows.

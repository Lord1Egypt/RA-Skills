## Description:

Helps users understand unfamiliar concepts, technologies, algorithms, or fields by mapping them to knowledge the user has confirmed they already know, using structural analogies and field-level comparisons.

This skill is ready for commercial/non-commercial use.

## Publisher:

[li-evan](https://clawhub.ai/user/li-evan)

### License/Terms of Use:

MIT-0

## Use Case:

Employees, external users, developers, and learners use this skill when they are learning a new concept and want a concise explanation anchored in knowledge they already have. The skill asks about the user's confirmed background, maps similarities and differences, and identifies the smallest genuinely new part to learn.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may ask what topics, tools, or projects the user already knows, which could lead users to share sensitive project context.

Mitigation: Use high-level descriptions of prior knowledge when possible and avoid sharing confidential project details unless they are necessary for the learning task.

Risk: Analogy-based teaching can make a new concept seem more similar to familiar knowledge than it really is.

Mitigation: Call out where the analogy differs, mark uncertain mappings as tentative, and ask clarifying questions before relying on assumed prior knowledge.

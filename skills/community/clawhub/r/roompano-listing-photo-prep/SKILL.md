# Prepare photos for a property listing

First establish whether the room is empty, furnished, cluttered, or being photographed for a 360° view. Use the user's description or inspect photos they have supplied when image input is available. Ask only for missing details that affect the recommendation. Answer in the user's language.

## Give a usable shot list

- For a flat listing photo, start with a wide shot from a doorway or corner. Keep the camera level and leave walls, windows, and floor edges visible. Photograph in even light, with room lights and visible color casts checked before shooting.
- For 360°, take overlapping angles of the same room from a consistent camera height. Include the areas behind the first shot and keep furniture, doors, and lighting consistent between angles. Roompano accepts up to five reference photos per room.
- When reviewing photos, identify the strongest frame, name the most important reshoot if needed, and state what must stay faithful to the property. Keep an unedited original. If a visible defect affects the listing, preserve it in the published set.

## Choose one edit and tell the user what to check

| What the photo needs | Tool | Check before publishing |
| --- | --- | --- |
| Furnish an empty room | Meubler / Furnish (`meubler`) | Check furniture scale, door clearance, wall lines, and window positions. |
| Update the look of a furnished room | Redécorer / Restyle (`redecorer`) | Check fixed features and distinguish virtual changes from fixtures or furnishings included in the sale. |
| Clear distracting movable objects | Désencombrer / Declutter (`desencombrer`) | Check that fixed features and visible defects remain. |
| Correct an underexposed or soft photo | Améliorer / Enhance (`ameliorer`) | Check that colors, condition, and the view through windows still reflect the property. |
| Present a room from several angles | Panorama 360 (`panorama`) | Check seams, repeated objects, and geometry. Present each room as an individual 360° view. |

For virtual staging, keep the visible disclosure on the published image and check the listing portal's own requirements. Use a specific caption when helpful, such as “Mise en scène virtuelle — mobilier ajouté numériquement” or “Virtually staged — furniture added digitally.” Keep the original alongside the staged version where the portal permits it.

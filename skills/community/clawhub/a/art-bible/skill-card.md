## Description:

Visual identity specification for games that defines style guides, color palettes, reference boards, technical art constraints, and pipeline requirements.

This skill is ready for commercial/non-commercial use.

## Publisher:

[toilanguyen2910](https://clawhub.ai/user/toilanguyen2910)

### License/Terms of Use:

## Use Case:

Game developers, artists, and art directors use this skill to create a structured art bible that keeps game visuals consistent across style, palette, characters, environments, UI, technical constraints, references, and asset pipeline decisions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generic trigger phrases may activate this skill for non-game style-guide or color-palette requests.

Mitigation: Confirm that the requested style guide is for game visual identity work before applying the art-bible template.

## Description:

Helps backend and platform teams generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to turn API documentation requests into practical OpenAPI or Swagger workflows, checklists, implementation support, and validation notes for REST APIs.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad trigger wording could activate the skill for backend questions that are not actually about API documentation.

Mitigation: Invoke it explicitly for OpenAPI, Swagger, REST API documentation, or validation tasks, and use a more specific skill for unrelated backend work.

Risk: Generated documentation guidance can be incomplete or mismatched to an API's real behavior.

Mitigation: Review outputs against the service implementation, existing API contracts, and validation results before publishing or relying on the documentation.

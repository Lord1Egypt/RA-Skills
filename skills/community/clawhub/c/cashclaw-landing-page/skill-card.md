## Description:

Creates high-converting landing page copy and responsive HTML with conversion frameworks for publish-ready pages.

This skill is ready for commercial/non-commercial use.

## Use Case:

External creators, marketers, and developers use this skill to turn a product brief into landing page copy, responsive single-file HTML/CSS, and optional A/B test notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill installs and runs an unpinned third-party npm package whose reviewed code is not included in the evidence.

Mitigation: Review the npm package publisher and source before installing, pin a reviewed version with integrity verification, and run it in a least-privilege project environment without unnecessary secrets.

Risk: Generated landing page claims, testimonials, metrics, or pricing can be inaccurate if the client brief lacks proof.

Mitigation: Require client-provided proof elements and human review of marketing claims before publishing the generated page.

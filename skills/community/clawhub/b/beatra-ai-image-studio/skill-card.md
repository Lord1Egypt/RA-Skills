## Description:

Create and refine images from written briefs, ordered reference images, or a base image for product photos, advertising and brand visuals, posters, social graphics, illustrations, concept art, and photo changes.

This skill is ready for commercial/non-commercial use.

## Publisher:

[beatra-ai](https://clawhub.ai/user/beatra-ai)

### License/Terms of Use:

MIT-0

## Use Case:

External users can create or refine product imagery, advertising and brand visuals, posters, social graphics, illustrations, concept art, and photo variations. They provide a written visual brief, ordered reference images, or a base image, then review the returned image for fidelity and intended use.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security assessment flags broader media and voice permissions than the image task suggests.

Mitigation: Review the requested authorization scopes and proceed only if you are comfortable with the broader access.

Risk: The security assessment flags recurring installation-linked data reporting.

Mitigation: Review the reported registration fields in the installation-registration reference and decide whether that reporting is acceptable.

Risk: The security assessment flags a risk that malformed installation inventory could cause uninstall to remove shared connection state.

Mitigation: Use the bundled uninstall workflow, inspect its decision, and do not manually remove shared Beatra connection files.

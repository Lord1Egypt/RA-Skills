# trending-topic-analyzer — 热点深度分析器

## 核心功能

1. **全网热度追踪**：微博热搜、抖音热点榜、小红书话题榜、B站热门
2. **深度内容分析**：关键观点提取、情感倾向、传播路径预测
3. **竞品声量对比**：对比同类话题/产品的声量占比
4. **行动建议**：基于数据给出内容创作方向建议

## 使用方式

### 基础用法
```bash
python scripts/trending_analyzer.py --topic "AI写作" --platforms weibo,douyin,xhs,bilibili
```

### 完整分析（含竞品对比）
```bash
python scripts/trending_analyzer.py --topic "AI写作" --competitors "Grammarly,Notion AI" --output report.md
```

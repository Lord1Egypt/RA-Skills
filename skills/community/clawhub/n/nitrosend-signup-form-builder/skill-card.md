## Description:

Create a website signup form for a mailing list and get the embed snippet for Webflow, Squarespace, WordPress, Wix, Shopify, or any website.

This skill is ready for commercial/non-commercial use.

## Publisher:

[nitrosend](https://clawhub.ai/user/nitrosend)

### License/Terms of Use:

MIT-0

## Use Case:

Website owners and marketers use this skill to add a mailing list signup form to their site and connect signups to the intended Nitrosend list.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Form submissions trigger the destination list's live list_add flows.

Mitigation: Confirm the destination list and its active flows before publishing the form.

Risk: A secret API key could be exposed if used in the website embed snippet.

Mitigation: Use only the public website key in the snippet; never include a secret key.

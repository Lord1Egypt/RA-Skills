# 七大训练模块详细操作指南

## 1. 生活技能训练详细操作

### 1.1 日常生活能力训练清单

| 训练项目 | 具体内容 | 评估标准 |
|----------|----------|----------|
| 个人卫生 | 每日洗漱、洗澡、更衣流程 | 能独立完成且保持整洁 |
| 衣物管理 | 洗涤、晾晒、折叠、收纳 | 能按季节更换整理 |
| 空间清洁 | 床铺整理、房间清扫、物品归位 | 维持基本整洁有序 |
| 作息规律 | 固定起床/就寝/进餐时间 | 连续2周遵守作息表 |
| 进食技能 | 基本烹饪、餐具使用、餐桌礼仪 | 能独立准备简单餐食 |
| 交通出行 | 识别路线、购票、安全过马路 | 能在陪同下完成短途出行 |
| 急救知识 | 拨打急救电话、基本止血、火灾逃生 | 能正确描述处理流程 |

### 1.2 理财训练分阶段操作

**阶段一：监督了解期（2-4周）**
- 由治疗师陪同购物，讲解价格概念
- 认识货币面额和支付方式
- 了解基本收支概念

**阶段二：辅助计划期（4-8周）**
- 协助制定每周零花钱使用计划
- 记录每笔支出
- 讨论消费决策的合理性

**阶段三：自主管理期（持续）**
- 独立制定月度支出计划
- 记录并分析每月开支
- 识别不良消费模式并制定改进策略
- 设定储蓄目标

### 1.3 工娱训练活动库

**日常活动**：
- 手工制作（折纸、编织、陶艺、绘画）
- 歌舞活动（合唱、律动、简单舞蹈）
- 体育运动（太极、瑜伽、球类、健身操）
- 读书活动（朗读、分享、讨论）

**节假日特别活动**：
- 由患者参与策划和组织
- 治疗师提供指导和支持
- 包含节目编排、场地布置、流程管理

**专业治疗**：
- 音乐治疗：由专业音乐治疗师实施
- 运动治疗：由专业运动治疗师实施

## 2. 人际交往技能训练详细操作

### 2.1 七步训练法详细流程

**步骤一：目标设定**
- 与患者共同确定本次训练的具体社交技能目标
- 目标应具体、可观察、可测量
- 示例："能在小组中主动打招呼"

**步骤二：角色示范**
- 两名治疗师演示目标行为
- 先展示正确示范
- 再展示常见错误对比
- 讲解关键行为要素

**步骤三：行为演练**
- 患者在模拟情境中练习
- 从简单情境开始
- 逐步增加情境复杂度

**步骤四：正向强化**
- 即时给予具体正面反馈
- 强调做得好的具体行为
- 鼓励患者自我肯定

**步骤五：纠正反馈**
- 指出需要改进的具体行为
- 提供改进建议
- 避免批评人格，只针对行为

**步骤六：解决问题技巧练习**
- 讨论演练中遇到的困难
- 引导患者思考替代方案
- 练习应对社交挫折的方法

**步骤七：家庭作业练习**
- 布置真实场景中的练习任务
- 明确练习内容和标准
- 下次训练时回顾完成情况

### 2.2 长期住院患者专项内容

| 训练主题 | 具体方法 |
|----------|----------|
| 正确表达感受 | 使用"我"句式，区分感受与想法 |
| 语言/书信表达 | 练习写信、写日记、电话沟通 |
| 社交礼仪 | 不同场合的称呼、问候、交谈规则 |
| 家庭相处 | 角色互换练习、冲突解决技巧 |
| 外界联系 | 安排探视、电话时间、外出活动 |

## 3. 职业康复训练详细操作

### 3.1 工作适应性训练任务分级

**一级（基础任务）**：
- 简单产品组装
- 物品分类整理
- 基础清洁工作

**二级（常规任务）**：
- 产品包装
- 被服管理
- 简单文书处理

**三级（复杂任务）**：
- 接待引导
- 秩序维护
- 协助组织活动

### 3.2 职业技能训练要素

- **身心耐受力培养**：逐步延长工作时间，从30分钟到2-4小时
- **工作习惯改善**：准时出勤、任务完成、工具归位
- **职业道德培养**：责任感、合作意识、诚信
- **人际交往往**：与同事协作、接受指导、处理分歧
- **报酬激励**：与企业合作提供有偿工作，建立劳动价值感

## 4. 躯体健康管理详细操作

### 4.1 体重管理计划

**评估指标**：BMI、腰围、体脂率

**干预措施**：
- 制定个性化饮食方案（控制总热量，均衡营养）
- 设计渐进式运动计划（从低强度开始）
- 每周监测体重变化
- 调整精神科药物（如可能，与精神科医师协商）

### 4.2 营养改善计划

**评估指标**：白蛋白、前白蛋白、BMI、膳食调查

**干预措施**：
- 营养师制定个性化膳食方案
- 监测进食量和进食行为
- 必要时补充营养制剂
- 改善进餐环境和氛围

### 4.3 药物不良反应管理

| 不良反应类型 | 监测指标 | 干预策略 |
|--------------|----------|----------|
| 代谢综合征 | 血糖、血脂、血压、腰围 | 生活方式干预+药物调整 |
| 锥体外系反应 | AIMS量表、肌张力 | 药物调整+对症处理 |
| 镇静嗜睡 | 日间功能评估 | 调整服药时间+剂量 |
| 性功能障碍 | 专项评估问卷 | 精神药理学+心理社会干预 |

## 5. 教育疗法详细操作

### 5.1 学习行为训练内容规划

| 主题 | 频次 | 形式 | 时长 |
|------|------|------|------|
| 时事新闻 | 每周2-3次 | 小组讨论 | 30-45分钟 |
| 生活常识 | 每周1-2次 | 授课+讨论 | 30-45分钟 |
| 科普知识 | 每周1次 | 授课+视频 | 45-60分钟 |
| 历史文化 | 每周1次 | 授课+讨论 | 45-60分钟 |

### 5.2 心理教育核心内容

- 疾病本质和症状识别
- 治疗方案和药物作用
- 复发预警信号
- 应对策略和技能
- 康复目标和期望

### 5.3 形式选择指南

- **授课**：适合系统性知识传授，10-20人
- **小组讨论**：适合经验分享和互动，6-10人
- **个别辅导**：适合个性化需求，1对1
- **家属专家交流**：适合家庭支持和教育

## 6. 药物自我管理培训详细操作

### 6.1 培训模块

**模块一：药物基础知识**
- 所服药物的名称和外观识别
- 每种药物的剂量和服用时间
- 药物的主要作用

**模块二：不良反应识别**
- 常见不良反应列表
- 严重不良反应的警示信号
- 何时需要立即就医

**模块三：自我管理技能**
- 使用药盒分装药物
- 设置服药提醒
- 记录服药情况
- 复诊前准备药物清单

**模块四：寻求帮助技能**
- 识别需要报告的症状
- 如何向医师描述问题
- 不自行调整药物的原因

### 6.2 依从性促进策略

- 简化服药方案
- 使用视觉化提醒工具
- 建立同伴支持小组
- 定期评估依从性并反馈
- 处理对药物的错误认知

## 7. 认知障碍康复详细操作

### 7.1 认知域评估与训练对应

| 认知域 | 评估工具 | 训练方法 |
|--------|----------|----------|
| 注意力 | 持续操作测验 | 注意力训练任务、正念练习 |
| 记忆力 | 韦氏记忆量表 | 记忆策略训练、联想记忆 |
| 执行功能 | WCST、TMT | 计划任务、问题解决训练 |
| 工作记忆 | 数字广度测验 | N-back任务、心理运算 |
| 处理速度 | 符号编码测验 | 速度训练、计算机化任务 |

### 7.2 训练方法选择

**传统训练**：
- 纸笔任务
- 卡片配对
- 数字/字母任务
- 适合认知功能较低者

**计算机化训练**：
- 专业认知康复软件
- 自适应难度调节
- 即时反馈
- 适合有一定操作能力者

**虚拟现实训练**：
- 模拟日常生活场景
- 高沉浸感
- 安全性高
- 适合功能较好者

**特定领域训练**：
- 针对个体最薄弱的认知域
- 高强度集中训练
- 结合功能活动

### 7.3 训练参数建议

- 频次：每周3-5次
- 单次时长：30-45分钟
- 疗程：至少12周
- 难度：从低于能力水平开始，逐步提升
- 目标：实现持久广泛的认知改善和功能提升

## Description:

Guides users in choosing an SEO-friendly domain for a new site, including brand versus keyword domains, TLD selection, domain best practices, and migration handoff to rebranding strategy.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, founders, marketers, and site owners use this skill to compare branded, partial-match, and exact-match domain strategies and select practical TLD and registration safeguards for a new website.

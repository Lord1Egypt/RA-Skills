## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineering teams use this skill to turn API documentation requests into actionable OpenAPI or Swagger artifacts, workflows, checklists, analysis, code changes, and verification notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad implicit-trigger wording may activate the skill during adjacent API conversations.

Mitigation: Prefer explicit invocation with $openapi-docs-generator when the user specifically wants OpenAPI or Swagger documentation support.

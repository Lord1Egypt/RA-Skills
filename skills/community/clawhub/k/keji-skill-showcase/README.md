# 科研技能鉴赏 v1.3.1

不知道用哪个科研技能？先来找它。

「科研技能鉴赏」是科研技能的**总入口与导航**：精选 20 个技能，按使用场景归类，每个都标注「适用边界 / 能做什么 / 不能做什么 / 该不该装」，帮你和 AI 一眼判断该装哪个、该用哪个。本技能只做路由与说明，不替代具体技能去执行任务。

---

## 这是什么

一个让 AI 助手学会「科研技能地图」的 Skill。装了它，你说需求，它会先判断场景，再引导你去用对的专项技能——不用记一堆技能名字和 slug。

### 精选技能一览（六类）

| 类别 | 覆盖 |
|---|---|
| 一、文献检索与获取 | 全球文献知识库、夜猫子论文工作台、个人知识库、CAJ 转 PDF |
| 二、文献验真与学术诚信 | 参考文献验真、文献造假核查 |
| 三、学术会议与答辩 | 组会把关、创新点验证、组会引擎、答辩预演 |
| 四、科研方法论与破局 | 扫地僧、八卦炉 |
| 五、技能打造与优化 | 技能锻造炉、AI 易读转化器 |
| 六、专利申请工作流 | 专利分析、专利查新、技术交底书、OA 答复、外观以图搜图 |

### 怎么用

直接对 AI 说你的需求即可，例如：

- 「我想找几篇文献，不知道用哪个技能」→ 引导到文献知识库
- 「这个研究方向新不新？」→ 引导到创新点验证器
- 「我有个技术方案，想申请专利，先查查新不新」→ 引导到专利查新（PatentMax）
- 「收到审查意见了，怎么答？」→ 引导到 OA 答复（PatentMax）

顶部「快速路由表」列出了所有常见场景与对应技能，随时可查。

## 账号说明

第三方技能各有独立账号体系，本入口不统一收费：

- **SmartLib 系**（文献检索 / 引用核查 / 知识库 / 创新点验证 / 组会把关等）：共享同一钱包，免费 100 次检索 + 10 次下载 / 月，同一邮箱跨技能共享。
- **夜猫子论文工作台 / 文献造假核查**：owl 平台独立账号，注册送 2000 点体验金。
- **5 个专利技能（PatentMax）**：免密钥试用，注册送 ¥50 体验额度，5 个技能共用一把密钥、一个余额。

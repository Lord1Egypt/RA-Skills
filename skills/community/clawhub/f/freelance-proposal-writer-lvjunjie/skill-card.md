## Description:

Freelance Proposal Writer Pro helps agents draft, analyze, and refine freelance marketplace proposals using reusable templates and proposal-quality guidance.

This skill is ready for commercial/non-commercial use.

## Publisher:

[lvjunjie-byte](https://clawhub.ai/user/lvjunjie-byte)

### License/Terms of Use:

## Use Case:

Freelancers and agents use this skill to create tailored Upwork or Freelancer proposal drafts, compare templates, analyze client/project signals, and improve draft structure before submission.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The reviewed local code and the documented npm install command identify different package names.

Mitigation: Install only the reviewed artifact or a package name and version that have been independently confirmed to match it.

Risk: The documented configuration includes an API key placeholder.

Mitigation: Do not store real API keys in plain project configuration unless the storage location and access controls are approved.

Risk: Saved proposal drafts may include sensitive client or project details.

Mitigation: Review generated text before submission and avoid saving confidential proposal material in untrusted directories.

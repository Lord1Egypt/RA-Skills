## Description:

Profile and analyze CSV or other tabular data — column types, summary statistics, missing values, and anomalies.

This skill is ready for commercial/non-commercial use.

## Publisher:

## Use Case:

Developers, analysts, and data engineers use this skill to inspect user-provided CSV, TSV, or DataFrame-style tabular data before cleaning, joining, or modeling it. It helps summarize column types, missing values, duplicates, outliers, and practical cleanup recommendations.

### Deployment Geography for Use:

Global

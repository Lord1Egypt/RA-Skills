## Description:

A structured development and testing SOP that guides agents through codebase study, focused implementation, testing, test execution, diff review, and commit preparation for code changes.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and coding agents use this skill to plan, implement, test, review, and prepare maintainable code changes across bug fixes, features, refactors, and contributions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The broad activation wording may cause the skill to be used for specialized development work where a narrower workflow would be more appropriate.

Mitigation: Use a more specific skill or project instructions for specialized areas such as security reviews, deployments, or repo-specific release processes.

Risk: The skill may propose code changes, tests, shell commands, or commit steps that are unsuitable for a specific repository.

Mitigation: Review proposed changes and commands against the repository's conventions and test requirements before applying them.

## 概览

DMADV(Define-Measure-Analyze-Design-Verify)是精益六西格玛的设计方法论，适用于新流程开发、新产品设计或重大流程重新设计。

### 与DMAIC对比

| 维度 | DMAIC | DMADV |
|------|-------|-------|
| 目的 | 改进现有流程 | 设计新流程/产品 |
| 起点 | 现有问题 | 设计需求 |
| 方法 | 消除缺陷 | 预防缺陷 |
| 目标 | 达到性能目标 | 一次做对 |
| 周期 | 通常3-6个月 | 通常6-12个月 |

### 应用场景

- 新产品/服务开发
- 新工厂/生产线建设
- 新信息系统实施
- 现有流程重大重构
- 收购整合

### 阶段输入输出

| 阶段 | 输入 | 输出 |
|------|------|------|
| D | 市场需求、业务目标 | 设计需求文档、项目范围 |
| M | 设计需求 | 能力评估、风险基线 |
| A | 能力数据 | 设计 alternatives、概念选择 |
| D | 概念方案 | 详细设计规格 |
| V | 设计方案 | 验证结果、实施方案 |

## D阶段详解

### Define - 定义阶段

**目标**:清晰定义设计需求与项目目标

### 核心输出物

1. **设计需求文档(DRD)**
   - 客户需求(VOC)转化
   - 性能指标要求
   - 约束条件

2. **项目章程**
   - 项目范围与边界
   - 资源与时间计划
   - 成功标准

3. **CTQ树(关键质量特性树)**
   - 从客户需求分解技术要求
   - 量化每个CTQ目标

### 常用工具

| 工具 | 用途 |
|------|------|
| VOC/VOB分析 | 收集客户声音 |
| QFD(质量屋) | 需求转化 |
| CTQ树 | 关键特性分解 |
| 项目章程模板 | 项目授权 |

### VOC收集方法

1. **定量调研**:问卷调查、评分量表
2. **定性访谈**:深度访谈、焦点小组
3. **观察法**:现场观察用户行为
4. **投诉分析**:分析现有投诉数据
5. **Benchmark**:竞争对手对标

## M阶段详解

### Measure - 测量阶段

**目标**:评估当前能力基线与风险

### 核心输出物

1. **能力评估报告**
   - 现有流程/技术能力
   - 差距分析(Gap Analysis)

2. **风险初步评估**
   - 技术风险识别
   - 商业风险评估

3. **基准Benchmark**
   - 行业最佳实践
   - 内部历史数据

### 技术能力评估

| 评估维度 | 评估内容 |
|----------|----------|
| 设备能力 | 精度、产能、可靠性 |
| 人员能力 | 技能、培训水平 |
| 工艺能力 | 技术成熟度 |
| 供应链 | 原材料、供应商 |
| 基础设施 | 厂房、公用工程 |

### 风险评估框架

- **高影响 + 高概率**:必须解决
- **高影响 + 低概率**:制定应急预案
- **低影响 + 高概率**:监控
- **低影响 + 低概率**:接受

## A阶段详解

### Analyze - 分析阶段

**目标**:开发并评估设计 alternatives

### 核心输出物

1. **概念方案(Design Alternatives)**
   - 至少3个设计方向
   - 概念描述与示意图

2. **方案评估矩阵**
   - 多维度评估
   - 成本-效益分析

3. **概念选择**
   - 推荐最佳方案
   - 决策依据

### 常用工具

| 工具 | 用途 |
|------|------|
| Pugh矩阵 | 方案比较 |
| 功能分析 | 分解设计功能 |
| TRIZ | 创新问题解决 |
| FMEA | 风险识别 |
| 成本分析 | 全生命周期成本 |

### 设计概念开发

1. **功能分解**
   - 主功能
   - 次功能
   - 支持功能

2. **概念生成方法**
   - 头脑风暴
   - 借鉴参考
   - 形态学分析
   - TRIZ发明原理

3. **概念筛选**
   - 初筛(可行性)
   - 复筛(多维度评估)
   - 最终选择

## D阶段详解

### Design - 设计阶段

**目标**:创建满足需求的详细设计方案

### 核心输出物

1. **详细设计规格**
   - 技术规格
   - 公差规范
   - 材料规格

2. **DFMEA**
   - 设计失效模式分析
   - 风险优先级数(RPN)

3. **CAD/工艺设计**
   - 工程图纸
   - 工艺流程
   - 作业指导书

4. **原型/试点设计**
   - 验证方案
   - 测试计划

### 稳健设计原则

1. **P-D-C-A循环**:计划-执行-检查-行动
2. **防错设计(Poka-Yoke)**:从源头防止错误
3. **标准化**:建立设计标准
4. **模块化**:提高灵活性
5. **DFSS工具**:设计用于六西格玛的设计

### DFMEA实施

| 步骤 | 内容 |
|------|------|
| 1 | 确定分析范围 |
| 2 | 识别失效模式 |
| 3 | 分析失效效应 |
| 4 | 评估失效原因 |
| 5 | 计算RPN |
| 6 | 制定改进措施 |
| 7 | 验证效果 |

### RPN阈值

- RPN > 100:必须采取行动
- 100 >= RPN > 50:建议采取行动
- RPN <= 50:可接受但需监控

## V阶段详解

### Verify - 验证阶段

**目标**:验证设计满足需求并成功实施

### 核心输出物

1. **验证报告**
   - 测试结果
   - 需求符合性

2. **设计评审**
   - DFM评审
   - 可制造性评审
   - 设计放行

3. **实施计划**
   - 部署方案
   - 培训计划
   - 验收标准

4. **控制计划**
   - 量产控制机制
   - 监控指标
   - 异常处理

### 验证方法

| 验证类型 | 方法 | 适用场景 |
|----------|------|----------|
| 仿真验证 | CAD/FEA仿真 | 设计早期 |
| 原型测试 | 样机验证 | 设计中期 |
| 试点验证 | 小批量试产 | 设计后期 |
| 量产验证 | 全流程验证 | 发布前 |

### 设计释放标准

- 所有CTQ达到目标
- DFMEA RPN降到可接受水平
- 试点测试通过
- 团队评审通过
- 文档完整

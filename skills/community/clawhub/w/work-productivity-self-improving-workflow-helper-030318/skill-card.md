## Description:

Helps AI-agent users, skill authors, maintainers, and teams turn self-improving and proactive agent workflow demand into practical plans, artifacts, checklists, code changes, and validation notes.

This skill is ready for commercial/non-commercial use.

## Publisher:

### License/Terms of Use:

MIT-0

## Use Case:

External agent users, skill authors, maintainers, and teams use this skill to convert self-improving and proactive workflow needs into actionable local-friendly deliverables. It supports bug fixing, setup hardening, reliability improvement, adjacent skill creation, checklists, analysis, and implementation support.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation wording may cause the skill to appear in unrelated conversations.

Mitigation: Use narrower trigger wording during installation or confirm relevance before applying the workflow.

Risk: Generated plans, code changes, or skill updates may be incorrect or unsuitable for the user's environment.

Mitigation: Review outputs against the stated success criteria and scan or test artifacts before deployment.

## Description:

Learn the production style of a reference the user supplies (their own footage, brand, or a video they have rights to study) and build new original Subclip scenes in that style, using the AI model the user picks.

This skill is ready for commercial/non-commercial use.

## Publisher:

[prosamik](https://clawhub.ai/user/prosamik)

### License/Terms of Use:

MIT-0

## Use Case:

External video creators use this skill to study a reference’s visual style and create original Subclip scenes for their own topic.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Reference-frame thumbnails may remain in the project media library after style analysis.

Mitigation: Use thumbnails temporarily and remove them after recording the derived style brief where project retention controls allow; the skill workflow currently directs users to keep a contact sheet in project media.

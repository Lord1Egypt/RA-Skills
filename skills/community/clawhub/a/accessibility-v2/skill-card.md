## Description:

Audits UI components for WCAG accessibility issues and helps improve ARIA labels, color contrast, keyboard navigation, and screen-reader support.

This skill is ready for commercial/non-commercial use.

## Publisher:

[hupmann86-cell](https://clawhub.ai/user/hupmann86-cell)

### License/Terms of Use:

MIT-0

## Use Case:

Developers use this skill to audit application interfaces for accessibility barriers, identify WCAG-related issues, implement improvements, and validate changes with tools such as Lighthouse or screen readers.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Accessibility-related UI changes can alter behavior or introduce incorrect contrast, ARIA, or navigation patterns.

Mitigation: Review generated diffs and validate important changes with accessibility tooling, keyboard testing, and screen-reader checks.

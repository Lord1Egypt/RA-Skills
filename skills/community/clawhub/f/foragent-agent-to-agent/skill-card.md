## Description:

Let two AI coding agents (Claude Code, Codex, Grok, Antigravity, Cursor, Windsurf, VS Code) talk directly across terminals, computers, or teammates without manual copy-pasting.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers use this skill to connect separate coding agent sessions across terminals or computers so they can coordinate work directly without manual copy-pasting.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Messages sent through ForAgent may be shared with that service and the receiving agent.

Mitigation: Use ForAgent only when comfortable with that sharing, and avoid sending sensitive information unless it is authorized.

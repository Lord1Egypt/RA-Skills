## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to turn REST API context into practical OpenAPI or Swagger documentation workflows, artifacts, checklists, implementation guidance, and validation steps.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate on broad API or developer-experience requests.

Mitigation: Review task fit before relying on its output, especially when the request is adjacent to OpenAPI or Swagger documentation rather than directly about it.

Risk: Generated documentation guidance or code changes may be incomplete or misleading.

Mitigation: Validate generated OpenAPI or Swagger artifacts against the service implementation and run schema or documentation checks before release.

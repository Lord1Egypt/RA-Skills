## Description:

Speak responses aloud on macOS using the built-in `say` command when user input indicates Voice Wake/voice recognition.

This skill is ready for commercial/non-commercial use.

## Publisher:

[lovefromio](https://clawhub.ai/user/lovefromio)

MIT-0

## Use Case:

Developers and agent users use this skill to have eligible voice-recognition interactions acknowledged and read aloud locally on macOS. It is useful when hands-free confirmation or spoken responses are desired for messages that begin with the configured Voice Wake trigger.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Spoken responses may be heard by people nearby, including sensitive conversation details.

Mitigation: Use this skill only on macOS devices where local speech output is appropriate, and avoid highly sensitive conversations in shared spaces.

# 睡眠障碍与副肿瘤综合征诊断治疗

## 一、睡眠障碍诊断流程

### 决策树

```
主诉睡眠问题
    ↓
入睡/维持困难 + 日间损害？
    ├─ 是 → 失眠障碍 → PSG确认 → 药物治疗
    └─ 否 → 日间过度思睡？
              ├─ 是 → 猝倒/Hcrt-1↓？
              │        ├─ 是 → I型发作性睡病
              │        └─ 否 → MSLT确认 → II型发作性睡病
              └─ 否 → REM期异常行为？
                        ├─ RWA+DEB → RBD
                        └─ 夜间下肢不适+URGE → RLS
```

### 失眠障碍

**诊断标准（同时符合）**：
- 睡眠症状≥1种：入睡困难/维持困难/早醒/抗拒就寝
- 日间症状≥1种：疲劳/注意力障碍/情绪烦躁/日间思睡
- 排除：睡眠环境不当或其他睡眠障碍

**药物治疗原则**：
- 个体化、按需用药、低剂量、间断（每周3-5次）、短期（≤3-4周）
- 减停：每天减原药25%

### 发作性睡病

**ICSD-3分型**：

| 分型 | 核心标准 |
|-----|---------|
| I型 | 日间思睡≥3月 +（猝倒 或 Hcrt-1≤110pg/ml）+ MSLT≤8min且≥2次SOREMP |
| II型 | 日间思睡≥3月 + MSLT≤8min且≥2次SOREMP + 无猝倒 + Hcrt-1正常 |

**MSLT操作要点**：
- 前夜PSG确保睡眠>6小时
- 连续5次小睡，间隔2小时
- 平均潜伏期≤8分钟
- SOREMP（15分钟内进入REM）≥2次

**药物治疗**：
- 日间思睡：替洛利生（首选）18-36mg/d、莫达非尼
- 猝倒：三环类/SSRI/SNRI
- ⚠️ **安全警告**：抗抑郁药突然停药可致猝倒持续状态

### RBD（快速眼动睡眠行为障碍）

**ICSD-3诊断（4条全满足）**：
1. PSG显示REM期骨骼肌失弛缓（RWA）
2. 梦境行为演绎（DEB）
3. REM期无癫痫样放电
4. 排除其他病因

**治疗**：
- 基础：安全睡眠环境
- 氯硝西泮0.25-2mg（⚠️痴呆/步态异常/OSA慎用）
- 褪黑素3-12mg（合并突触核蛋白病首选）

### RLS（不宁腿综合征）

**URGE诊断标准（全满足）**：
- **U**rge：迫切活动腿的欲望
- **R**est：休息时加重
- **G**etting better：活动后缓解
- **E**vening：夜间加重

**补铁指征**：铁蛋白<75μg/L 或 TSAT<45%

**药物选择**：
- 中重度首选：普拉克索0.125mg起
- 疼痛为主：加巴喷丁/普瑞巴林
- ⚠️ 避免：多巴胺拮抗剂、抗抑郁药、抗组胺药

## 二、副肿瘤综合征(PNSs)

### 2021评分系统

| 项目 | 高分 | 中分 | 低分 |
|-----|-----|-----|-----|
| 临床表型 | 经典型(3) | 伴肿瘤+特异性抗体(2) | 无关(0) |
| 抗体 | 高风险>70%(3) | 中风险30-70%(2) | 低风险<30%(0) |
| 肿瘤 | 发现且相关(4) | 未发现<2年(1) | 未发现>2年(0) |

**诊断分层**：
- 确诊：≥8分
- 很可能：6-7分
- 可能：4-5分
- 非PNSs：≤3分

### 中枢PNSs抗体-肿瘤映射

| 综合征 | 抗体 | 相关肿瘤 |
|-------|-----|---------|
| 小脑变性(PCD) | 抗Yo | 乳腺癌/卵巢癌 |
| 脑脊髓炎(PEM) | 抗Hu、CV2 | 小细胞肺癌 |
| 边缘叶脑炎(PLE) | 抗Hu、Ma2、GABABR | 小细胞肺癌 |

## 三、LEMS诊断与MG鉴别

### LEMS三主征
1. 近端肌无力（下肢首发，短暂用力后增强）
2. 自主神经障碍（口干、便秘、阳痿）
3. 腱反射减弱/消失

### 肌电图确诊
- 静态CMAP降低
- 低频RNS衰减
- **高频刺激或运动后CMAP增加>100%**（确诊关键）

### LEMS vs MG鉴别

| 特征 | LEMS | MG |
|-----|-----|-----|
| 病变部位 | 突触前膜 | 突触后膜 |
| 首发 | 下肢近端，由下而上 | 眼外肌，由上而下 |
| 自主神经 | 常有 | 无 |
| 腱反射 | 减弱/消失 | 正常 |
| 高频RNS | CMAP↑>100% | 衰减或正常 |
| 抗体 | VGCC/SOX1 | AChR |
| 相关肿瘤 | 小细胞肺癌 | 胸腺瘤 |

**LEMS治疗**：
- 首选：3,4-DAP
- ⚠️ **绝对禁忌**：钙通道阻滞剂（尼莫地平、维拉帕米、氟桂利嗪）

# 副肿瘤综合征详细诊疗

## PNSs 2021评分详解

### 高危临床表型（3分）
- 脑脊髓炎
- 边缘性脑炎
- 斜视性眼阵挛-肌阵挛
- 亚急性小脑变性
- 亚急性感觉神经病
- 胃肠神经病变

### 高风险抗体（3分）
- 抗Hu、抗Yo、抗CV2、抗Ri、抗Ma2、抗amphiphysin
- 抗NMDAR、抗LGI1、抗CASPR2（部分）

### 中风险抗体（2分）
- 抗GABABR、抗AMPAR
- 抗VGCC、抗VGKC

## 中枢PNSs详细表型

### 副肿瘤性小脑变性(PCD)
- 快速进展共济失调，自然缓解罕见
- 早期MRI正常，晚期小脑萎缩
- CSF轻度淋巴细胞↑、蛋白/IgG↑

### 副肿瘤性脑脊髓炎(PEM)
- 广泛受损（灰质>白质）
- 可累及：皮质、边缘叶、脑干、脊髓、自主神经
- **致死因素**：心律失常、中枢性通气障碍

### 副肿瘤性边缘叶脑炎(PLE)
- 近记忆力受损、精神行为异常、癫痫
- 70-80% MRI：内侧颞叶T2/FLAIR高信号
- CSF可有寡克隆区带

## LEMS抗体检测

| 抗体 | 阳性率 | 特异性 |
|-----|-------|-------|
| P/Q型VGCC | 85-90% | 小细胞肺癌相关100% |
| SOX1 | 67% | 对小细胞肺癌高度特异 |
| AChR | 阴性 | 用于排除MG |

## 综合干预原则
1. **治疗原发肿瘤是基础**
2. 免疫治疗：糖皮质激素 + IVIG + 血浆置换 ± 免疫抑制剂
3. 肿瘤筛查：PET/CT、肿瘤标志物，阴性者每3-6月复查，至少2年

# 睡眠障碍详细诊疗

## 失眠药物分类

| 类别 | 代表药物 | 适应症 | 注意事项 |
|-----|---------|-------|---------|
| BZD | 艾司唑仑、阿普唑仑 | 入睡困难 | 日间困倦、跌倒、认知减退、依赖 |
| non-BZD | 唑吡坦、佐匹克隆 | 入睡困难 | 起效快、半衰期短 |
| 褪黑素受体激动剂 | 雷美替胺 | 入睡困难+节律失调 | - |
| 镇静抗抑郁药 | 曲唑酮、米氮平 | 伴抑郁/焦虑 | - |
| 食欲素受体拮抗剂 | 苏沃雷生 | 入睡+维持 | - |

## 发作性睡病四联征
1. **日间过度思睡**：不可克制，持续数分钟至数小时
2. **猝倒**（70%）：情感刺激后双侧肌张力丧失，意识清楚
3. **睡瘫**（25-50%）：入睡/觉醒时不能活动，伴濒死感
4. **睡眠幻觉**（33-80%）：觉醒-睡眠转换期梦境样体验

## RBD鉴别诊断
| 疾病 | 鉴别要点 |
|-----|---------|
| 睡眠相关癫痫 | 刻板性、NREM期、EEG癫痫样放电 |
| OSA | REM期呼吸事件伴运动，治疗OSA后评估 |
| 睡惊症 | 儿童/青少年、NREM N1期、极度恐惧 |

## RLS鉴别诊断
| 疾病 | 鉴别要点 |
|-----|---------|
| 夜间腿痉挛 | 单侧痛性收缩，足背屈缓解 |
| 静坐不能 | 全身不适，无夜间加重，活动不缓解 |
| 外周血管病变 | 无昼夜规律，间歇性跛行 |

## RLS药物治疗详细方案

### 补铁方案
- 口服铁剂：硫酸亚铁325mg tid
- 静脉铁剂：铁蛋白<75或口服不耐受时

### 药物选择决策
```
铁蛋白<75或TSAT<45%？
    ├─ 是 → 补铁治疗
    └─ 否 → 症状类型？
              ├─ 感觉/疼痛为主 → α2δ配体（加巴喷丁/普瑞巴林）
              └─ 运动症状为主 → 多巴胺激动剂（普拉克索）
```

### 避免使用的药物
- 多巴胺受体拮抗剂（抗精神病药）
- 抗抑郁药（SSRI/SNRI/三环类）
- 抗组胺药
- 钙通道阻滞剂

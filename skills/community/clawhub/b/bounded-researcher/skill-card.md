## Description:

Bounded evidence-first research workflow for software agents.

This skill is ready for commercial/non-commercial use.

## Publisher:

[leslie-ller](https://clawhub.ai/user/leslie-ller)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineering teams use this skill to keep software-agent research tasks narrow, evidence-first, and oriented toward the next bounded engineering action. It supports triage, localization, validation, summarization, and focused documentation or precedent checks without taking architecture ownership or editing production code.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill is not designed for autonomous code changes or final architecture decisions.

Mitigation: Keep a separate supervising agent or user responsible for implementation choices and use this skill only for bounded evidence gathering, validation, and summary work.

Risk: Unsupported license, compatibility, or quantitative claims could be overstated if not directly evidenced.

Mitigation: Require the agent to label unsupported claims as unverified and attribute external claims to their sources.

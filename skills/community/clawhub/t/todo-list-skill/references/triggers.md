# todo-list Skill — 触发词完整列表

> 版本：v1.0 | 更新：2026-06-11
>
> 详细的 NLP 触发词表，按 action 分类。SKILL.md 只列示例，完整列表见此文档。

## action 分类

### add（添加 TODO）

**自然语句**：
- "提醒我..."
- "加个待办..."
- "记一下..."
- "新待办..."
- "新建..."

**动词触发**：
- 写 / 做 / 准备 / 安排 / 记得 / 需要
- 看 / 交 / 去 / 买 / 拿 / 寄 / 取 / 查 / 问
- 提交 / 开会 / 起床 / 上班 / 下班 / 吃饭 / 睡觉 / 锻炼 / 学习
- 紧急 / 重要

**典型示例**：
- "提醒我明天下午3点检查止损"
- "记一下：明天9点复盘ETF"
- "加个待办，周五前完成"
- "task: 买 159801"
- "todo: 下周检查持仓"
- "紧急修复515070止损 #etf"

### list（查询 TODO）

**自然语句**：
- "我的待办"
- "今天有什么待办"
- "todolist"
- "show todos"
- "有哪些 high 优先级的"

**动词触发**：
- 查询 / 列出 / 显示 / list / show
- 查看 / 有什么 / 什么待办 / 哪些
- 我的待办 / 我的任务

### done（完成 TODO）

**自然语句**：
- "完成了：..."
- "做完了..."
- "搞定"
- "✓"
- "已办"

**动词触发**：
- 完成 / 完成了 / 做完 / 做完了 / done / finished
- 完成下 / 完成它 / 搞定了 / 搞定
- 已办 / 办完

**典型示例**：
- "完成检查止损"
- "做完了 ETF 复盘"
- "done: 写日报"

### delete（删除 TODO）

**自然语句**：
- "删除那条提醒"
- "取消那条"
- "删掉"
- "不要了"

**动词触发**：
- 删除 / 删掉 / 删 / remove / delete
- 取消 / 撤销
- 不要了 / 扔了

### update（更新 TODO）

**自然语句**：
- "改成高优先级"
- "加个标签：工作"
- "改时间"

**动词触发**：
- 修改 / 改 / 更新 / 改一下 / 改成 / update
- 改时间 / 延后 / 提前

### unknown（无法识别）

未匹配到任何关键词 → agent 回复"没理解，请换个说法"

## 优先级关键词

### high
- 高 / 紧急 / 急 / 重要
- high / urgent
- !!

### low
- 低 / 不急 / low
- 慢慢 / 无所谓
- ·

## 标签语法

- `#tag` 格式：`紧急修复515070止损 #etf`
- `tag:tag` 格式：`写日报 tag:work`
- 多个：`tag:work,urgent`

## 时间格式

- ISO8601：`2026-06-12 15:00:00`
- 中文：`明天下午3点`、`今天 18:00`、`今晚 8 点`、`明早 6:30`
- 相对：`今天` / `明天` / `后天` / `大后天` / `下周` / `下周一` / `下个月`
- 简洁：`9点`、`14:00`、`6:30`

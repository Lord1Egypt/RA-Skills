# 多列与合并单元格还原

## 1. 逐行读数值为什么会串位

让模型或 OCR 逐行读“这一行的金额是多少”时，错误不是随机的，而是倾向于**向邻近行位移**：同一个数值被赋给相邻两行，或者上一行的值顶到下一行。原因有三：

1. 行高不一致时，“行”的边界靠目测，视觉模型按视觉重心归行，重心落在两行之间就会二选一。
2. 一行内多列数字并列，模型按阅读顺序回填，一旦漏掉一个空白格，后面的数字整体前移一列。
3. 长表分片后，接缝行的归属没有唯一答案，两片都会认领。

**结论：数值列不用“逐行读”，用“按列有序序列重建”。** 列内数字的自然顺序就是行顺序，不存在归行歧义。

## 2. 列带重建

1. 取全部 OCR 文本块，输出 `(x_center, y_center, text)`，按 x 排序后画直方图。
2. 直方图的峰即列位置；两个峰之间计数接近 0 的区间即列间隙。
3. 用竖线检测的 x 坐标校验峰位：每根竖线应是某个间隙的中心，偏差超过 1 个字宽说明列带估计错了。
4. 列带边界取相邻峰之间的中点，不是峰的边缘；表格有留白时这一点尤其重要。
5. 合并单元格会制造“跨两个峰”的长文本框，这类块不参与峰位估计，只参与跨度计算。

## 3. 按列有序序列重建（主方法）

```python
def column_series(boxes, x0, x1, y_min, y_max, row_y):
    """返回该列按 y 升序的数字序列，以及每个值对应的最近行索引。"""
    picked = []
    for b in boxes:
        if not (x0 <= b["xc"] < x1 and y_min <= b["yc"] <= y_max):
            continue
        num = to_number(b["text"])
        if num is None:
            continue
        row = min(range(len(row_y)), key=lambda i: abs(row_y[i] - b["yc"]))
        gap = abs(row_y[row] - b["yc"])
        picked.append((b["yc"], num, row, gap, b["text"]))
    picked.sort(key=lambda t: t[0])
    return picked
```

对齐步骤：

1. 序列长度若等于数据行数，按 index 一一对齐，同时用 `gap` 检查每项是否落在行中心附近（超过 0.5 行高要复核）。
2. 序列长度短于行数：差额应全部对应空白格或非数值备注（如“面议”“待定”），逐个说明。
3. 序列长度长于行数：多半是列带吃进了相邻列的数字，先打印该带内全部文本块坐标核对，不要急着删值。
4. 序列长度合理但值可疑：取相邻行做连续性检查（同类项的量级应相近），跳变超过 10 倍进复核队列。

## 4. 双通道仲裁

| 情形 | 采信 | 依据 |
|---|---|---|
| 按列序列与逐行读一致 | 直接通过 | 两条独立路径互证 |
| 按列序列与逐行读差一位 | 采信按列序列 | 逐行读的系统性位移 |
| 按列序列有值、逐行读为空 | 采信按列序列 | 视觉漏读常见于浅色数字 |
| 按列序列为空、逐行读有值 | 两者都进复核 | 可能是非数字文本块被当成数字 |
| 两者都读不出 | 留空加 flag | 禁止按上下文猜值 |

## 5. 合并单元格跨度矩阵

- 从网格检测得到每条竖线与横线的区间，交叉出可见单元格；相邻可见单元格之间没有分隔线，即存在合并。
- 输出跨度矩阵：`(row_span, col_span, anchor_value, anchor_coord)`。
- **文本列**（名称、类别、备注）：可以向下或向右填充，但必须写回“源行号”，导出时拆成重复值加 `source_row` 列。
- **数值列**：默认不填充。合并的数值格一旦填充，会被行合计与列合计重复计入，制造假差额。若业务上确需填充，必须在列字典标注 `filled: true` 并在校验时排除重复计数。
- **表头**：多级表头的父列合并属正常结构，按 `group` 字段拆成“父列名—子列名”，不拆成数据行。

## 6. 多级表头拆解

1. 表头带检测出的水平线数量决定层级：N 条线内即 N 级。
2. 先按最底层子列建列，再向上读取父列文字，写入 `group`。
3. 判据：所有子列的列带并集应等于父列的列带；不等说明有列被漏读或表头本身不对齐。
4. 若两级表头之间存在斜线表头（一个格子里同时写行标题与列标题），拆成两个字段名，不允许拼成一串。

## 7. 勾选列三态

| 状态 | 判定 | 记录 |
|---|---|---|
| 勾选 | 列带内检出标记字形（对号、圆点、叉、实心方块） | `1`，并记字形类别 |
| 未勾 | 列带内检出空白格边界，且该行有行锚 | `0` |
| 漏检 | 列带内无标记也无空白边界（被遮挡、墨迹、压缩块） | `null` + flag |

- 判据：三态计数之和必须等于行数。做不到就说明列带或行锚有问题。
- 整列零标记时不得直接判“该列无勾选”：先确认列带是否正确，再对该列前中后三处做定点放大确认。
- 不同标记字形语义可能不同（例如“对号＝包含、圆点＝可选、叉＝排除”），字形与语义的映射必须写在列字典里，不能默认全部等价。

## 8. 位移模式速查

| 现象 | 高概率原因 | 处置 |
|---|---|---|
| 整列值比实际低一行 | 表头行被当成数据行 | 从行锚序列中剔除表头行 |
| 整列值比实际高一行 | 合计行被当成数据行 | 表尾区提前切出 |
| 只有某几行错位 | 该行单元格跨行合并 | 检查跨度矩阵 |
| 相邻两行同值 | 视觉归行二选一 | 采信按列序列 |
| 某列整体为空 | 列带边界落在数字右侧 | 打印列带内文本块坐标 |
| 序号跳过若干号 | 源表本身跳号 | 保留原样并在还原说明注明，禁止重排 |

## Known Risks and Mitigations:

Risk: Generated HTML may include unescaped child-name input if a user supplies markup-like text.

Mitigation: Use trusted plain-text child names, avoid markup-like input, and review generated HTML before sharing or opening it in sensitive contexts.

Risk: Generated local HTML can execute browser script if crafted input is embedded.

Mitigation: Treat generated HTML as an active local document, open only files produced from trusted inputs, and scan or review files before deployment.

## Description:

Provides Chinese-language investment, value investing, business, and economics book recommendations, reading paths, topic booklists, single-book introductions, and bilingual title tables using the aimunger book resource as its sole content source.

This skill is ready for commercial/non-commercial use.

## Publisher:

[chenjing002](https://clawhub.ai/user/chenjing002)

### License/Terms of Use:

MIT-0

## Use Case:

External users and agents use this skill to answer investment-book questions with structured Chinese reading guidance, including reading paths, thematic lists, single-book analysis, and bilingual book tables. It is intended for investment, value investing, business, economics, management, and long-term-thinking book requests.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can present book guidance as if independently reasoned while relying on one source.

Mitigation: Review outputs for source transparency needs and disclose the source when policy or user trust requires it.

Risk: Bibliographic facts, recommendations, or book availability may be incomplete because the skill forbids independent verification.

Mitigation: Verify important book details against authoritative sources before using the output for publication, procurement, or investment education.

Risk: Broad activation on investment, business, economics, management, and long-term-thinking book requests may trigger the skill when a general recommendation would be more appropriate.

Mitigation: Narrow deployment or agent routing to explicit investment-book and aimunger-booklist requests.

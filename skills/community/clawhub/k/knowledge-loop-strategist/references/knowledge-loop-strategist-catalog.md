## 任务清单与依赖拓扑

按使用流程组织的方法论执行任务清单，附任务间关系和元操作映射提示。

**域间逻辑流**：KLS0 → KLS1 → KLS2 → KLS3⇄KLS4 → KLS5。KLS0 编排与守护贯穿全程；KLS3 与 KLS4 之间存在迭代校准回路：验证器筛问题，被筛掉的问题暴露验证器盲区，反哺验证器升级后再筛。

### 依赖拓扑摘要

#### 一、域内链路

**KLS0 协调链路**: KLS0-01 → KLS0-02 → KLS0-04（KLS0-03 贯穿全程）
**KLS1 诊断链路**: KLS1-01 → KLS1-02 → KLS1-03；KLS1-01 → KLS1-04；KLS1-05 ←（KLS1-02, KLS1-03, KLS1-04）
**KLS2 路线链路**: KLS2-01 → KLS2-02 → KLS2-03 → KLS2-04 → KLS2-05
**KLS3 构建链路**: KLS3-01 → KLS3-02 → KLS3-03 → KLS3-04 → KLS3-05；KLS3-06 ←（KLS3-03, KLS3-04）
**KLS4 问题链路**: KLS4-01 → KLS4-02 → KLS4-03 → KLS4-04
**KLS5 整合链路**: KLS5-01 → KLS5-02 / KLS5-03 → KLS5-04

#### 二、跨域链路

**诊断→路线**: KLS1-05 → KLS2-01
**路线→构建（可选）**: KLS2-05 → KLS3-01
**迭代校准回路**: KLS3-03 ⇄ KLS4-02（验证器筛问题；问题暴露验证器盲区反哺验证器升级）
**构建→问题初筛**: KLS3-03 → KLS4-02
**内容汇流**: KLS4-04 / KLS5-04 → KLS0-04
**重估反馈边**: KLS0-04 → KLS1-03（时钟重估触发后重跑普及时钟评估，必要时上溯 KLS1-01 全量重诊）
**表示分层说明**: 任务表依赖列只穷举硬依赖；可选边/迭代边/汇流边/反馈边等跨域软边以本摘要为准——按任务表机械编排时必须并入本节，否则会漏掉迭代回路与汇流边

#### 三、任务路由链路

- KLS0-01 → KLS1-01（快速诊断/完整上移）
- KLS0-01 → KLS3-01（领域升级）
- KLS0-01 → KLS4-01（问题生成）
- KLS0-01 → KLS5-01（消化整合）
- KLS0-01 → KLS1-05 / KLS3-06 / KLS4-04 / KLS5-04（深化）

#### 四、知识图谱

实体节点类型：任务节点（KLS0-01~KLS5-04）、域节点（KLS0~KLS5）、元操作节点（S/C/A/O/I/G）、数据节点（问题资产目录）、产物节点（诊断报告/路线图/验证器包/问题资产卡/八件套交付物）。
关系边类型：依赖边、迭代边（KLS3⇄KLS4，反哺升级落点为 KLS3-06，须保留变更记录）、守护边（KLS0-03 贯穿）、路由边（KLS0-01 → 各域入口）、重估反馈边（KLS0-04 → KLS1-03）、交互确认边（KLS1-01、KLS2-03 的人工确认点）。
本图显式不穷举：开放世界模型，以上为已确认节点与边型；更多组合按具体任务动态推导，新边型或新节点确认后回填本节。

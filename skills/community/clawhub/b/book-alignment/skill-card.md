## Use Case:

External users use this skill to search for alignment services, check availability, and create bookings through Lokuli's MCP service.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Bookings and searches are handled by Lokuli's external MCP service.

Mitigation: Confirm the provider, appointment time, and service details before creating a booking.

Risk: Creating a booking can involve personal contact fields such as name, email, and phone number.

Mitigation: Only submit contact details that the user has approved for the booking.

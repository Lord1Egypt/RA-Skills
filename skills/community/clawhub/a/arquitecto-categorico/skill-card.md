## Description:

Diseña y audita arquitecturas de datos y APIs con teoría de categorías, producing formal models and artifacts for PostgreSQL DDL, JSON Schema, OpenAPI, GraphQL SDL, Prisma, Mermaid, PlantUML, data integration, migrations, and structural audits.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, data architects, and API engineers use this skill to turn ambiguous domain requirements into formal data models, API contracts, schema artifacts, migration plans, or architecture audit reports. It is especially suited to Spanish technical workflows that need category-theoretic traceability for structural design decisions.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated DDL, schema changes, or migration plans may be incorrect or incomplete for a real production system.

Mitigation: Review generated artifacts and migration plans before applying them to databases, APIs, or integration pipelines.

Risk: The skill answers in Spanish and uses category-theory terminology, which may be misunderstood by teams that need plain implementation guidance.

Mitigation: Ask for concise implementation-facing summaries when handing results to reviewers who are not familiar with the formal vocabulary.

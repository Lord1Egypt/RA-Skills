## Description:

Use when the user mentions their brain, Cobrain, their notes or memory, or names a client, project or anything else they track there; when they ask what was decided, what happened recently or where something is written; or when something worth keeping comes up during the work (a decision, a finding, a status to resume later). Connects OpenClaw to Cobrain, a shared Markdown memory over remote MCP.

This skill is ready for commercial/non-commercial use.

## Use Case:

People using Cobrain as shared memory across AI assistants can retrieve project context, decisions, and recent changes while working. Agents can also save concise notes and task updates for future conversations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad memory-related triggers may result in conversation content being saved to remote memory without clear, task-specific consent.

Mitigation: Before saving, confirm the content is appropriate for the user's shared Cobrain memory and keep each note limited to information relevant to the task.

## Description:

AI Eight Creed provides a bilingual, domain-agnostic set of eight behavior rules for AI assistants focused on source verification, scope clarification, human decision-making, reuse, validation, standards, admitting uncertainty, and root-cause fixes.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users, developers, and other AI-assistant operators use this skill as behavioral guidance for agents that should verify facts, clarify ambiguous requests, defer irreversible decisions to humans, reuse existing work, and close the loop with checks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill attempts to frame its behavioral creed as universal, highest priority, and persistent across future agent sessions.

Mitigation: Use it only when intentionally requested, keep it subordinate to platform, system, developer, security, and user instructions, and avoid installing it as a highest-priority system prompt, memory file, custom instruction, or repository-wide rule.

## Description:

Use the Odds-API.io MCP server to answer questions about sports betting odds, events, results, value bets, arbitrage, dropping odds, closing lines, bet settlement and golf outrights. Covers which tool to call first, how to keep responses small, quotas and error handling.

This skill is ready for commercial/non-commercial use.

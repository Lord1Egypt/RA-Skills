# 借款费用资本化·专门借款与一般借款

产出稿的头部就照下面这几行起（三件自标「AI 整理初稿」「请回原文核对」「不构成投资建议」逐字在位；`主体：`／`报告期：` 是**行首裸行**，不带 `- ` 前缀）。判断位一律写成 `[待人工]`：

```
# 示例材料（600000.SH）借款费用资本化登记稿

AI 整理初稿 ｜ 请回原文核对 ｜ 不构成投资建议
主体：示例材料（600000.SH）
报告期：2025 年年度报告·附注·借款费用资本化
```

**定位**：给一份年报，把附注里**「借款费用资本化」那一段**读成一张**每个数都能回到附注原句**的登记表——这一年利息支出多少、其中资本化了多少、费用化了多少；专门借款的利息减掉闲置资金收益之后资本化了多少；一般借款按加权平均占用额乘资本化率算出来多少；资本化从哪一天开始、中间有没有暂停、哪一天终止。**资本化金额的恒等由机检现算**，本件只负责把数抄对、把两侧摆开、把原句挂上。

这一段回答的是「这家公司这一年有多少利息没有进利润表、而是进了在建工程／存货的成本」：资本化 302.50 万、费用化 53.50 万、合计 356.00 万——资本化那 302.50 万**不在当期损益里**，它压在资产上等以后年度通过折旧或结转慢慢进成本。本件把这条分界摆出来，**不替你说「这个资本化比例是否合理」**——那一步要口径判断，交 `[待人工]`。

切割说清楚：本件只读**「借款费用」这一节附注**（CAS 17）。研发支出的资本化（研究阶段／开发阶段、五个条件）是另一件，见 `cn-rd-capitalization-cn`；在建工程台账的逐项成本归集与转固勾稽也不在本件——本件只读附注披露的借款费用那几行，不核工程台账。本件**不问借款该不该借**，只问利息怎么分、怎么算。

### 是什么 / 不是什么

| 是 | 不是 |
|---|---|
| 六节逐条登记（借款费用概况／专门借款／一般借款／资本化期间与暂停／口径与未取到／来源），缺项也占一行点名 | 融资成本高低、资本结构好坏、该不该继续借（一律 `[待人工]`） |
| 每个数字带 `〔口径：…〕` 标签（本期／本期发生额／本期末） | 按表格位置认项（「第三行就是资本化金额」那种） |
| 资本化与费用化**两侧都要登记**，两分之和对上利息支出合计 | 只登记「其中资本化」一个数，费用化空着，让两分无从复核 |
| 专门借款与一般借款**分开登记**：前者减闲置收益，后者乘资本化率 | 两类合成一行「借款费用资本化合计」 |
| 每个数挂「」原句＋〔锚：…〕＋`[S#]` 三元组，来源行两向对应 | 只写数字不抄原句，事后补一句「据年报附注」 |
| 数据通道＝用户直供的附注原文（零网络） | 承诺任何实时行情、预测或工具清单 |

### 触发场景

「今年利息支出多少、资本化了多少」「专门借款的闲置资金收益是多少、怎么抵的」「一般借款资本化率多少、占用额多少」「资本化期间从什么时候到什么时候、中间停过没有」「为什么这家公司的利息没进利润表」。输入形态＝**年报附注里「借款费用」「借款费用资本化」「利息资本化」那几段**（截图／PDF／解析回来的表格文本）。

## 六节各登记什么

节名必须逐字照这几个（`## ` 起节，节名后面紧跟字母或数字就认不出，会被记成野节）：

| 节 | 登记什么 | 最常犯的错 |
|---|---|---|
| 借款费用概况 | 利息支出合计／其中资本化／其中费用化**三个数**，`〔口径：本期发生额〕` | 只抄「其中资本化」一个数，费用化全省——两分恒等就没有比对对象 |
| 专门借款 | 专门借款本金／年利率／利息／闲置资金收益／专门借款资本化金额，各占一行 | 只写利息不写闲置资金收益，于是「利息−收益＝资本化」这一条无从复核 |
| 一般借款 | 一般借款加权平均占用额／资本化率／一般借款资本化金额，各占一行 | 只写资本化金额，占用额与资本化率全省——乘出来的那一层无法复核 |
| 资本化期间与暂停 | 开始资本化时点／暂停资本化期间／终止资本化时点，各占一行 | 只写「本年度资本化」一句，三个时点全省 |
| 口径与未取到 | 取法口径 ＋ 缺口逐项点名；零缺口写 `- 未取到：无` | 正文写了未取到而本节没列，或反之 |
| 来源 | 每条 `[S#]` 一行：`- [S#] 标题 \| URL \| 检索日 YYYY-MM-DD` | 引用了 `[S#]` 却没有登记行；检索日写成斜杠式 |

同一条 = 一行：行首写项名与标签，紧跟金额与「万元」，再挂 `「原句」〔锚：页/表〕[S#]`。附注里没有的数写 `未取到：项名`，不留空、不借常识补。

⚠️ **两个百分比不是金额**：`专门借款年利率` 与 `一般借款资本化率` 写的是百分比（如 `4.35%`、`5.00%`），不写「万元」。它们会被 `BC-CAP` 拿去算金额（占用额 × 资本化率 = 资本化金额），抄成「万元」那一行会被当成金额参与比对。

## 五道机检在管什么

现状以脚本里 `UNIMPLEMENTED` 的现值为准：目前五道 **全部已落字**。未落字的码**调用即抛**、由机检收进「不可判」，既不判也不放行，单稿退 3；`rc=0` 只留给「五道全过」。

| 码 | 名称 | 判什么 | 最常拦住的情况 | 现状 |
|---|---|---|---|---|
| `BC-STRUCT` | 形制 | 头部三件自标逐字在位、六节齐且按序；认不出的节标题与多出同名节记 stray 逐条发。只判「形」，不判内容；**不判** `主体：`／`报告期：` | 节名改了个字就整节认不出；一节写了两次 | 已落字 |
| `BC-QUOTE` | 原句与锚 | 四个内容节里每个带数字的行须挂齐「」原句＋〔锚：…〕＋`[S#]` 三元组，缺哪件点明哪件；例外只有 `未取到：` 行、`[待人工]` 行、`〔自算〕` 行三形；来源行须合 `- [S#] 标题 \| URL \| 检索日 YYYY-MM-DD`，检索日不是横杠式即发；正文与来源**两向**都要对得上（正文引了来源没登记、来源登记了正文没引用，两向都发）。另做**缺口两向对账**：正文写「未取到：X」而口径节没声明 X ⇒ 发，口径节声明了 X 而正文没有这处缺口 ⇒ 也发；`未取到：无` 表示「什么都不缺」，不算声明任何缺项 | 数字行只写数没抄原句；来源行检索日写成 `2026/03/20`；引了 `[S2]` 却没登记 | 已落字 |
| `BC-CAP` | 资本化恒等 | 专门借款（利息 − 闲置资金收益）＋ 一般借款（加权平均占用额 × 资本化率）vs 披露的「其中资本化」；**任一侧缺失 ⇒ 整条跳过，不猜、不按 0 算** | 资本化金额改了没改利息或占用额；资本化率抄成金额 | 已落字 |
| `BC-SPLIT` | 资本化与费用化两分 | 其中资本化 ＋ 其中费用化 vs 利息支出合计；**不许只登记一个数** | 只抄资本化、费用化空着；两侧都抄了但加不回合计 | 已落字 |
| `BC-LINE` | 红线 | 四组越界词，**只扫四个内容节**，`口径与未取到` 与 `来源` 两节整节豁免：① 投资建议（买入／卖出／增持／减持／目标价／推荐／建议持有）② 前瞻预测（预计／预测／有望／将会／看好／预期增长／预判）③ 主观评价（合理／不合理／偏高／偏低／高估／低估／显著偏低／显著偏高）④ 越界口径（利润调节／盈余管理／调节利润／税务筹划／避税／融资成本高／财务风险／资本结构优化／杠杆空间）。判前先洗掉「」引文与〔口径／锚／自算〕标签槽——那是原文与出处，不是本件断言；再按分句判，含 [待人工] 或 未取到 的那一句跳过。**同组命中只报不被别的命中词包含的那些** | 自己写了一句「融资成本偏高」；把「预计明年利息上升」抄进正文 | 已落字 |

> 未落字不等于放弃：`UNIMPLEMENTED` 里每少一道，单稿才可能从 rc=3 变成 rc=0。哪一道若回退成空壳，它会调用即抛、被收进「不可判」、单稿退 3——**既不判也不放行**。

## 退码

| 码 | 含义 |
|---|---|
| `0` | 五道全过，零发条 |
| `1` | 有发条 |
| `2` | 用法错（缺参数或未知参数） |
| `3` | 读不到文件、或空稿、或零发条但仍有判据未落字（此时输出会明写「**这不等于合规**」） |

## 数据通道

零网络、纯标准库、单文件。输入就是用户直供的附注文本，本件不联网取数、不缓存、不上传。

`CUE_API_KEY` 是**可选**的：带上才走 `cue-data-mcp`／`cue-omni-reader` 那条取证腿去取原文，
缺位时只把用户贴进来的附注排版成上面那张登记表——**形状一样，数只能来自用户**。

带凭据时的通道正路（先握手、按现场返回判，不写死工具清单）：

```bash
curl -sS https://cuecue.cn/api/mcp-catalog -o /tmp/mcp-catalog.json
curl -sS -X POST "$MCP_ENDPOINT" \
  -H "Authorization: Bearer $CUE_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' | head -c 2000
```

## 快速开始

```bash
# 看一眼样例（零输入可跑，打印一份六节齐的登记稿）
python3 scripts/check_borrowing_cost.py --demo

# 跑包内夹具自检（末行会给「自测档数=N｜不合=0｜不可判=M」，两个数都以现跑为准）

# 机检自己的稿子（五道全落字后单稿不再退 3）
python3 scripts/check_borrowing_cost.py 我的登记稿.md
```

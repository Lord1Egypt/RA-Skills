# 机票价格监控与比价 — 多平台比价+降价监控，帮你买在低点

> 搜一条航线，多个平台价格一目了然；不只告诉你"有哪些航班"，更告诉你"这个价格值不值得买"。

🔥 **核心亮点：**
- **多平台比价** — 飞猪+途牛+RG多源实时对比，找最低价
- **价格状态分析** — 7维度分析引擎，输出🟢低/🟡中/🟠高/🔴贵状态
- **目标价监控** — 设心理价位，达标自动提醒
- **低价日历** — 一键扫描7-30天价格洼地，找最便宜的出发日
- **零配置** — 免申请Key，装上就能用

## 快速入门

**3个开场白示例，复制即用：**

1. "帮我查一下北京到上海7月10号的机票"
2. "广州飞三亚哪天最便宜"
3. "帮我盯着CA1234这个航班，降到800提醒我"

## 核心能力

1. **航线航班搜索** — 搜索指定航线的航班列表，返回多平台最低价对比
2. **指定航班精确比价** — 输入航班号，多平台精确对比价格
3. **低价日历** — 扫描多天价格，找出最便宜的出发日
4. **降价监控** — 设目标价，持续追踪，达标自动提醒
5. **价格状态分析** — 7维度综合判断当前价格水平（低/中/高/贵）
6. **购票时机建议** — 根据价格状态+距出发天数+旺季判断给出买入建议

## 工作流程

### 流程A：已有目标航班，想比价+盯价
1. 收集航线+日期+航班号+心理价位
2. 调用 `search_flights` 搜索航班列表
3. 根据价格状态分析给出判断
4. 引导建立降价监控

### 流程B：有出行计划，还没选航班
1. 收集出发/到达城市+日期
2. 调用 `search_flights` 搜索航班列表
3. 推荐最低价+最优性价比航班
4. 调用 `compare_flight_prices` 精确比价

### 流程C：日期灵活，想找最便宜的那天
1. 调用 `price_calendar` 扫描7-30天价格
2. 输出每日最低价+价格标签
3. 推荐价格洼地日期

### 流程D：想设目标价等降价
1. 收集航线+日期+目标价
2. 智能建议目标价（航线均价×0.85）
3. 调用 `create_price_watch` 创建监控

## 价格状态分析引擎

| 状态 | 含义 | 建议 |
|------|------|------|
| 🟢 价格较低 | 处于低位 | 建议尽快入手 |
| 🟡 价格适中 | 合理水平 | 可入手可观望 |
| 🟠 价格偏高 | 高于合理区间 | 建议等 |
| 🔴 价格很高 | 处于高位 | 强烈建议等 |

7维度综合判断：价格分位、距出发天数、旺季判断、多源价差、星期效应、目标价对比、价格变动。

## 工具调用说明

```bash
# 搜索航班列表
python3 scripts/compare.py search --from "北京" --to "上海" --date 2026-07-01

# 指定航班号精确比价
python3 scripts/compare.py compare --from "北京" --to "上海" --date 2026-07-01 --flight-no "CA1234"

# 低价日历
python3 scripts/compare.py calendar --from "北京" --to "上海" --start-date 2026-07-01 --days 14

# 创建降价监控
python3 scripts/compare.py monitor --from "北京" --to "三亚" --date 2026-07-01 --target 800
```

## 能做什么

- 多平台机票实时比价（飞猪+途牛+RG）
- 价格状态分析，判断当前价格水平
- 低价日历扫描最便宜出发日
- 目标价降价监控，达标提醒
- 购票时机建议

## 不能做什么

- 不直接预订机票，只提供预订链接
- 不承诺最低价，价格实时变动以预订页面为准
- 不查酒店/火车票/租车（用对应专项技能）
- 不编造价格历史数据

## 使用提示

- 机票价格实时变动，查询结果仅供参考
- 周二/三出发通常最便宜，周五/日偏贵
- 提前30-45天购票通常有较好价格
- 旺季（节假日）机票易涨难跌，建议早买

## 🔗 搭配使用

- **航班动态追踪** — 买完机票后跟踪航班实时状态
- **全能旅行助手** — 行程规划+酒店火车票景点一站式服务
- **酒店比价** — 机票搞定后，酒店也来比个价

## 数据流向

用户输入（城市/日期等查询参数）→ 本技能脚本 → 代理服务 → 多个旅游平台API → 返回结果给用户。查询参数会发送到代理服务以获取实时机票数据，代理服务不存储用户数据。

## 排序说明

比价结果按价格从低到高排序；同价时，部分平台预订链接含分佣通道（分佣不影响用户价格），但仍会展示所有平台价格供用户自主选择。

# 寄生虫病急症处理与手术指征

## 手术绝对指征

### 眼囊尾蚴病
- **必须手术摘除**
- 禁忌药物杀虫（虫体死亡引起全眼球炎、失明）

### 脑室囊尾蚴
- 第三、第四脑室内囊尾蚴（多为单个）
- 手术摘除解除梗阻

### 泡型棘球蚴病
- 首选根治性肝切除术
- 晚期无法切除：ERCP/介入/肝移植

## 手术相对指征

### 皮下肌肉囊尾蚴
- 部位表浅且数量不多时手术摘除

### 囊型棘球蚴
- 根治性外囊剥除术或肝部分切除（首选）
- 内囊摘除术（术后需服药3-12月）

### 并殖吸虫
- 脑脊髓压迫症状内科治疗无效
- 皮下包块切除
- 胸膜粘连行胸膜剥离术

### 华支睾吸虫
- 并发急性/慢性胆囊炎
- 胆石症或胆道梗阻
- 术后继续病原治疗

## 急症处理流程

### 颅高压（脑囊尾蚴/脑型并殖吸虫）
```
1. 20%甘露醇250ml快速静滴
2. 地塞米松5-10mg/d，连用3天
3. 颅压控制后再行病原治疗
4. 必要时颅脑开窗减压/脑室分流
```

### 过敏性休克（棘球蚴囊液泄漏等）
```
1. 0.1%肾上腺素1mg皮下注射（儿童酌减）
2. 氢化可的松200-300mg+葡萄糖液静滴
3. 维持气道通畅、补液
```

### 癫痫频繁发作
```
1. 地西泮10-20mg缓慢静推
2. 苯妥英钠或异戊巴比妥钠
3. 维持抗癫痫治疗至病原治疗完成
```

## 驱虫不良反应预防

### 脑囊尾蚴病
- 驱虫前必须降颅压
- 常规联用地塞米松+甘露醇
- 阿苯达唑不良反应较吡喹酮轻
- 第2疗程不良反应明显减轻

### 华支睾吸虫病
- 大量杀灭虫体可诱发胆绞痛
- 密切监测胆囊炎急性发作

### 并殖吸虫脑型
- 必须按规范重复疗程
- 不可仅依靠单次治疗

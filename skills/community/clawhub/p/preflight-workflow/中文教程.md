## 🚀 快速上手（30秒）

### 方式一：AI Agent 用
加载本 skill，然后对 AI 说：
> "先跑 preflight，我要部署新的 cron 任务"

AI 会自动执行四问自检流程。

### 方式二：命令行用
```bash
# 下载并安装
curl -sL https://clawhub.ai/<owner>/preflight-workflow/download | tar xz
cd preflight-workflow
chmod +x install.sh && ./install.sh

# 之后任何时候：
preflight.sh "我要做的事情描述"
```

### 方式三：手动安装
1. 下载 `preflight-workflow.tar.gz`
2. 解压：`tar xzf preflight-workflow.tar.gz`
3. 安装：`cd preflight-workflow && ./install.sh`

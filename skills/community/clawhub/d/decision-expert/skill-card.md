## Description:

A decision support skill that helps users analyze options, weigh trade-offs, and apply decision frameworks (SWOT, decision matrix, pros/cons, etc.) across various scenarios like shopping, career, investment, and daily life.

This skill is ready for commercial/non-commercial use.

## Publisher:

[harrylabsj](https://clawhub.ai/user/harrylabsj)

### License/Terms of Use:

MIT-0

## Use Case:

External users, developers, and agents use this skill to structure choices, compare alternatives, and produce decision guidance using common frameworks such as pros/cons, SWOT analysis, and weighted decision matrices.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: npm/npx installation can expose users to ordinary package supply-chain risk.

Mitigation: Install from trusted sources, pin package versions when possible, and review lockfiles before deployment.

Risk: Decision analyses may be mistaken for professional financial, legal, medical, or career advice.

Mitigation: Treat outputs as decision support only and require qualified human review for high-impact or regulated decisions.

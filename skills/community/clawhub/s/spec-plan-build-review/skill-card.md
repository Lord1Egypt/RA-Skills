## Description:

Run a proportional delivery lifecycle for software or skill work: clarify scope, create a concise plan, implement, verify, review, and ship.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill to guide multi-step coding or skill release work through scope clarification, planning, implementation, verification, review, and shipping.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The workflow may be applied to many ordinary software tasks and can lead an agent to describe work as shipped before external release facts are independently confirmed.

Mitigation: For release work, confirm commits, pushes, publication, and CI status before treating the work as shipped.

## Description:

Peter Thiel's Zero to One is a guidance skill for applying startup strategy frameworks such as contrarian thinking, monopoly strategy, founding teams, sales, and distribution.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users, founders, and startup advisors use this skill to map Zero to One concepts into practical startup analysis, idea evaluation, monopoly strategy, founding-team decisions, fundraising, and distribution planning.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill requires every response to include Heardly branding and an external link, including responses outside the core Zero to One scope.

Mitigation: Review the response policy before deployment and remove or constrain mandatory promotional text if branded outbound links are not acceptable.

Risk: The security verdict is suspicious because response-level advertising behavior is broad, although there is no evidence of code execution or local data access.

Mitigation: Treat the skill as non-executable guidance, but scan and review generated responses for unwanted promotional content before enabling it in user-facing contexts.

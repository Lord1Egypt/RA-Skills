# 传染病消毒与感染控制

## 使用场景

根据消毒需求选择对应流程：
- **流程A**：物理热力消毒 → 根据物品材质和病原体选择参数
- **流程B**：化学消毒剂选择 → 根据目标微生物和材质匹配
- **流程C**：特定病原体灭活 → 针对肠道病毒或HIV的专项处理

## 流程A：物理热力消毒参数选择

### 决策树

```
物品是否耐热耐潮？
├─ 是 → 目标病原体是什么？
│       ├─ 细菌繁殖体 → 煮沸100℃ 10分钟 或 巴氏65-75℃ 10-15分钟
│       ├─ 乙肝病毒 → 煮沸100℃ 15-20分钟
│       ├─ 细菌芽孢 → 高压蒸汽121-126℃ 15-20分钟(98kPa)
│       │              或 真空压力蒸汽132℃ 2分钟(205.8kPa)
│       └─ 不确定 → 高压蒸汽121-126℃ 15-20分钟（最可靠）
└─ 否 → 选择化学消毒或环氧乙烷气体灭菌
```

### 标准参数速查

| 方法 | 温度 | 时间 | 压力 | 适用范围 | 杀灭能力 |
|-----|------|------|------|---------|---------|
| 煮沸 | 100℃ | 10min | - | 食物/器皿/衣物/金属 | 繁殖体（不杀芽孢） |
| 煮沸（HBV） | 100℃ | 15-20min | - | 乙肝病毒污染物品 | 灭活HBV |
| 高压蒸汽 | 121-126℃ | 15-20min | 98kPa | 一切耐热耐潮物品 | 繁殖体+芽孢 |
| 真空压力蒸汽 | 132℃ | 2min | 205.8kPa | 耐热耐潮物品 | 繁殖体+芽孢 |
| 巴氏消毒 | 65-75℃ | 10-15min | - | 不耐高温物品 | 繁殖体（不杀芽孢） |

## 流程B：化学消毒剂选择

### 步骤1：确定所需效能级别

| 效能级别 | 杀灭能力 | 代表消毒剂 |
|---------|---------|-----------|
| **高效** | 一切微生物（含芽孢、孢子） | 2%碘酊、戊二醛、过氧乙酸、甲醛、环氧乙烷、过氧化氢 |
| **中效** | 除芽孢外各种微生物 | 乙醇、含氯制剂、碘伏、氧化剂 |
| **低效** | 繁殖体+亲脂病毒 | 氯己定、季铵盐类、汞制剂 |

### 步骤2：根据材质和场景匹配

| 消毒剂类型 | 适用场景 | 注意事项 |
|-----------|---------|---------|
| 含氯消毒剂 | 餐具、环境、水、疫源地 | 腐蚀金属 |
| 过氧乙酸/过氧化氢 | 速效消毒需求 | 腐蚀金属/织物，有刺激性 |
| 戊二醛 | 精密仪器、内镜 | 对橡胶/塑料/金属无腐蚀；刺激皮肤黏膜 |
| 环氧乙烷 | 电子设备、精密仪器、皮毛 | 可加惰性气体防燃爆 |
| 碘伏(0.5%) | 术前手消、伤口、黏膜 | 高效广谱无毒，促黏膜再生 |
| 75%乙醇 | 皮肤、小面积表面 | 对HBV和芽孢作用差 |
| 氯己定 | 手/皮肤/器械 | 低效，不杀芽孢 |

### 禁忌组合
- 醇类不能用于HBV和芽孢消毒
- 低效消毒剂不能杀灭芽孢
- 含氯/氧化/醛类对金属织物有腐蚀性

## 流程C：特定病原体灭活

### 肠道病毒灭活标准

| 病毒类型 | 存活特性 | 灭活条件 |
|---------|---------|---------|
| **轮状病毒** | 粪便中存活数天-数周；耐酸碱、耐乙醚；室温存活7个月 | 95%乙醇、酚、漂白粉；56℃ 30分钟 |
| **诺如病毒** | 耐热耐酸；常温表面存活数天；冷冻数年仍有感染性；60℃ 30min仍有传染性 | **含氯消毒液10mg/L，作用30分钟** |
| **肠腺病毒** | 4℃存活70天；36℃存活7天；耐酸碱；对脂溶剂抵抗 | 56℃ 2-5分钟；紫外线30分钟；甲醛敏感 |

**关键提示**：诺如病毒对常规消毒剂抵抗力强，必须使用含氯消毒剂。

### HIV灭活标准

| 方法 | 参数 | 适用场景 | 注意事项 |
|-----|------|---------|---------|
| 热力（体外） | 56℃ 30分钟 | 体外HIV失去T淋巴细胞感染性 | **不能灭活血清中HIV** |
| 热力（彻底） | 100℃ 20分钟 | 血液/血清样本、耐高温物品 | 完全灭活 |
| 75%乙醇 | 有效浓度 | 环境表面、器械 | 有效 |
| 0.2%次氯酸钠 | 有效浓度 | 血液/体液污染 | 有效 |

**严禁使用**（对HIV无效）：
- ❌ 0.1%甲醛
- ❌ 紫外线
- ❌ γ射线

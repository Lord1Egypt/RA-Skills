## Description:

Research venture capital firms, angel investors, and funding sources for startup fundraising and generate structured investor reports with profiles, theses, portfolio signals, outreach strategies, and warm introduction paths.

This skill is ready for commercial/non-commercial use.

## Publisher:

[wulaosiji](https://clawhub.ai/user/wulaosiji)

### License/Terms of Use:

MIT-0

## Use Case:

External founders and startup operators use this skill to identify, evaluate, and prioritize investors for a fundraising round. It helps prepare investor target lists, profile summaries, outreach strategy, action items, and warm introduction paths.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated investor reports may contain sensitive fundraising strategy and unverified investor information.

Mitigation: Review sources, remove confidential details before sharing, and verify investor facts immediately before outreach.

Risk: The bundled script can overwrite writable markdown files or write outside the expected folder when company_name contains path components.

Mitigation: Run the script with trusted JSON input and an explicit safe --output path, and check for existing files before execution.

# 金融工具风险敞口·到期分档与敏感性重算

产出稿的头部就照下面这几行起（三件自标「AI 整理初稿」「请回原文核对」「不构成投资建议」逐字在位；`主体：`／`报告期：` 是**行首裸行**，不带 `- ` 前缀）。判断位一律写成 `[待人工]`：

```
# 示例材料（600000.SH）金融工具风险敞口登记稿

AI 整理初稿 ｜ 请回原文核对 ｜ 不构成投资建议
主体：示例材料（600000.SH）
报告期：2025 年年度报告·附注·金融工具及其风险
```

**定位**：给一份年报或半年报，把附注里**「金融工具及其风险」那一段**读成一张**每个数都能回到附注原句**的登记表——金融资产与负债的账面余额、按剩余到期期限分档的合同未折现现金流、利率与汇率变动的敏感性影响、单一客户最大信用敞口，五块逐条挂原句与锚。**分档求和与敏感性重算由机检现算**，本件只负责把数抄对、把分档抄对、把原句挂上。

这一段常被整段跳过，但它回答的是「这家公司**还得上还不上**」：一年内要还 7.18 亿、账上金融资产 18.24 亿——缺口与余量都在这一张表里。本件把这张表逐行摆出来，**不替你说「流动性充裕」或「短期偿债压力大」**——那一步要口径判断，交 `[待人工]`。

切割说清楚：`cn-restricted-assets-cn` 登记**资产**因抵押质押冻结而权利受限（标的是「动不了的资产」），本件登记的是**到期要还的负债与风险敞口**；`cn-hedge-accounting-cn` 管套期会计的指定、有效性与储备结转，**不问敞口规模**；`cn-cash-flow-quality` 管经营现金流的质量，**不问金融负债的到期结构**。三件读同一份财报的不同段落。

### 是什么 / 不是什么

| 是 | 不是 |
|---|---|
| 五块逐条登记（风险敞口概况／流动性风险／市场风险—利率／市场风险—汇率／信用风险集中度），缺项也占一行点名 | 够不够还债、流动性是否充裕、会不会违约（一律 `[待人工]`） |
| 每个数字带 `〔口径：…〕` 标签（本期末账面余额／合同未折现现金流／本期末敞口静态测算） | 按表格位置认项（第三行就是汇率那种） |
| 分档现算：四个期限档之和 vs 披露合计，差 > 0.01 万元即发条 | 拿 0 补一个缺失分档去让合计成立 |
| 敏感性现算：`影响 = 敞口 × 变动幅度`，相对差 > 0.05% 即发条 | 自己改披露的影响金额去对得上 |
| 每个数挂「」原句＋〔锚：…〕＋`[S#]` 三元组，来源行两向对应 | 只写数字不抄原句，事后补一句「据年报附注」 |
| 数据通道＝用户直供的附注原文（零网络） | 承诺任何实时行情、预测或工具清单 |

### 触发场景

「一年内要还多少钱、账上有多少金融资产」「金融负债按到期期限怎么分」「利率上 50 个基点利润影响多少」「人民币贬值 5% 影响多少」「前五大客户敞口占多少」。输入形态＝**年报或半年报附注里「金融工具及其风险」那一段**（截图／PDF／解析回来的表格文本）。

## 七节各登记什么

节名必须逐字照这几个（`## ` 起节，节名后面紧跟字母或数字就认不出，会被记成野节）：

| 节 | 登记什么 | 最常犯的错 |
|---|---|---|
| 风险敞口概况 | 金融资产合计、金融负债合计、各自账面余额与占总资产比例，`〔口径：本期末账面余额〕` | 只写合计不写总资产，比例就无从重算 |
| 流动性风险 | 按剩余到期期限分档的**合同未折现现金流**：`1 年以内`／`1–2 年`／`2–5 年`／`5 年以上`，每档一行，再加一行合计，`〔口径：合同未折现现金流〕` | 档名写成「一年以内」（认不出）；给了分档却不给合计，或给了合计却少抄一档 |
| 市场风险—利率 | 浮动利率／固定利率敞口金额；敏感性写成 `敞口 X 万元 变动 N 个基点 影响 Y 万元` | 三件不齐（缺敞口或缺变动），机检就跳过不判 |
| 市场风险—汇率 | 外币货币性项目净额；敏感性写成 `敞口 X 万元 变动 N% 影响 Y 万元` | 把百分数写成 `5` 而已，单位丢了就当成 5 倍 |
| 信用风险集中度 | 单一客户或单一交易对手的最大信用敞口、占比；附注不给就写 `未取到：` | 拿「前五名客户合计」当「单一客户」填上去，也不写未取到 |
| 口径与未取到 | 取法口径 ＋ 缺口逐项点名；零缺口写 `未取到：无` | 正文写了未取到而本节没列，或反之 |
| 来源 | 每条 `[S#]` 一行：`- [S#] 标题 \| URL \| 检索日 YYYY-MM-DD` | 引用了 `[S#]` 却没有登记行；检索日写成斜杠式 |

同一条 = 一行：行首写项名与标签，紧跟金额与「万元」，再挂 `「原句」〔锚：页/表〕[S#]`。附注里没有的数写 `未取到：项名`，不留空、不借常识补。

⚠️ **两个字符要分清**：节名 `市场风险—利率`／`市场风险—汇率` 里是**全角破折号**「—」（U+2014）；分档档名 `1–2 年`／`2–5 年` 里是**连接号**「–」（U+2013）。抄的时候照原样，别统一成同一个。

## 五道机检在管什么

现状以脚本里 `UNIMPLEMENTED` 的现值为准：五道**全部已落字**。将来某道若回退成空壳，它会调用即抛、由机检收进「不可判」，既不判也不放行，单稿退 3；`rc=0` 只留给「五道全过」。

| 码 | 名称 | 判什么 | 最常拦住的情况 | 现状 |
|---|---|---|---|---|
| `FR-STRUCT` | 形制 | 头部三件自标逐字在位、七节齐且按序；认不出的节标题与多出同名节记 stray 逐条发。只判「形」，不判内容；**不判** `主体：`／`报告期：` | 节名改了个字就整节认不出；一节写了两次 | 已落字 |
| `FR-QUOTE` | 原句与锚 | 五个内容节里每个数字行须挂齐「」原句＋〔锚：…〕＋`[S#]` 三元组，原句 ≥8 字且不能只有数字标点；例外只有 `未取到：` 行、`[待人工]` 行、`〔自算〕` 行三形；来源行须合格式，正文与来源**两向**都要对得上，来源节一条合规行都没有则单独发。**不核对引号里的数与行首是否同一**（那是 `FR-BUCKET`／`FR-SENS` 的活，分开判只为让一支坏样只红一道） | 数字行只写数没抄原句；来源行检索日写成 `2026/03/20`；引了 `[S2]` 却没登记 | 已落字 |
| `FR-BUCKET` | 期限分档与合计 | ①「流动性风险」节里标了合计的那一行金额，与该节各分档行金额之和比对，差 > 0.01 万元 ⇒ 发，消息记 `分档和=X 披露合计=Y`；② 档名须合 `1 年以内`／`1–2 年`／`2–5 年`／`5 年以上` 之一，认不出 ⇒ 发并点名。**任一侧缺失 ⇒ 整条跳过**，不猜、不按 0 算；缺节不在这里判（那是 `FR-STRUCT`／`FR-LINE` 的活） | 分档漏抄一行，合计就对不上；档名写成「一年以内」 | 已落字 |
| `FR-SENS` | 敏感性重算 | 行内**只认「」之前的自有部分**，同时拿到「敞口金额」「变动幅度」「影响金额」三件时，按 `影响 = 敞口 × 变动幅度` 重算（基点 ÷10000、百分数 ÷100），与披露影响金额**相对差 > 0.05%** ⇒ 发，消息记 `重算=X 披露=Y`。**三件缺一即跳过**，不从别处借数；敞口或变动幅度为 0 ⇒ 如实记「此项无从重算」并发条，**不静默除零崩** | 改了影响金额让算式对不上；敞口写 0 | 已落字 |
| `FR-LINE` | 红线 | 四类词**判整行（含「」引号内的原句）**：① 判断流动性是否充裕／偿债强弱（`流动性充裕`／`流动性紧张`／`偿债能力充足`／`偿债能力不足`／`短期偿债压力大`）② 把敞口说成已发生损失（`已损失`／`已减值`／`已违约`）③ 拿敞口当实际还款额或可用资金（`实际需偿还`／`可动用`／`实际可用`）④ 评级与买卖建议（`目标价`／`买入`／`卖出`／`增持`／`减持`／`评级为`／`建议买入`／`建议卖出`）。**同一行同类只报第一处**；`口径与未取到` 与 `来源` 两节整节豁免（口径节按设计就要写「不判断流动性是否充裕」，不豁免会自己咬自己）。另加结构判据：`流动性风险` 节缺 ⇒ 单独发（这一节是本件存在的理由） | 自己写了一句「本集团流动性充裕」；把敞口金额写成「可动用资金」；抄引文时把评级建议一起抄进来 | 已落字 |

## 退码

| 码 | 含义 |
|---|---|
| `0` | 五道全过，零发条 |
| `1` | 有发条 |
| `2` | 用法错（缺参数或未知参数） |
| `3` | 读不到文件、或空稿、或零发条但仍有判据未落字（此时输出会明写「**这不等于合规**」） |

## 数据通道

零网络、纯标准库、单文件。输入就是用户直供的附注文本，本件不联网取数、不缓存、不上传。
`CUE_API_KEY` 是**可选**的：带上才走 `cue-data-mcp`／`cue-omni-reader` 那条取证腿去取原文，
缺位时只把用户贴进来的附注排版成上面那张登记表——**形状一样，数只能来自用户**。

## 快速开始

```bash
# 看一眼样例（零输入可跑，打印一份七节齐的登记稿）
python3 scripts/check_financial_instruments_risk.py --demo

# 跑包内夹具自检（末行会给「自测档数=N｜不合=0｜不可判=0」）
python3 scripts/check_financial_instruments_risk.py --selftest

# 机检自己的稿子
python3 scripts/check_financial_instruments_risk.py 我的登记稿.md
```

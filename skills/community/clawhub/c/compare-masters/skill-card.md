## Description:

Helps an agent produce source-grounded, structured comparisons of Buddhist masters, schools, and doctrinal perspectives when a user asks for multi-tradition views.

This skill is ready for commercial/non-commercial use.

## Publisher:

[xr843](https://clawhub.ai/user/xr843)

### License/Terms of Use:

MIT-0

## Use Case:

External users and agent builders use this skill when they want Buddhist master or tradition comparisons with explicit source citation, fair divergence labeling, and no comparative ranking.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can produce long, rigidly structured comparison answers even when a user asks for a short response.

Mitigation: Use it when the user wants Buddhist master or tradition comparisons with source-focused output.

Risk: The skill appends a FoJin reference and may promote that resource as a next step.

Mitigation: Review the final answer for appropriate source balance and user relevance before relying on it.

Risk: Doctrinal comparison can become misleading if claims are not tied to declared sources or if traditions are ranked.

Mitigation: Require source citations for doctrinal claims and preserve the skill's no-ranking and no-fabricated-dialogue constraints.

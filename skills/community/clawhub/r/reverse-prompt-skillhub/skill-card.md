## Description:

Reverse Prompt Skillhub helps agents analyze supplied images, video, audio, text, 3D assets, UI screenshots, or code requests and produce platform-adapted prompts with confidence notes.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, creators, and prompt engineers use this skill to break down a target artifact into observable features, map those features to a chosen generative platform, and draft copyable prompts, parameters, and variants for iterative refinement.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill could be used to recreate real people, copyrighted characters, trademarks, or other identity-sensitive likenesses from reference material.

Mitigation: Review use before installation and use only authorized reference material in ways allowed by the target platform and applicable law.

Risk: The security summary notes tension between portrait-replication guidance and the stated boundary against close likeness copying.

Mitigation: Keep outputs focused on general style and observable composition; refuse requests that aim to copy a specific protected or private identity.

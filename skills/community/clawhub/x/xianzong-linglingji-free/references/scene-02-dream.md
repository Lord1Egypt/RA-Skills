## 三层规则（解梦的骨架）

| 层 | 规则 | 例子 |
|---|---|---|
| **类象** | 梦象 → 事物属性 → 五行 | 水＝坎／财与流动；火＝离／心与激烈；木＝生长；金＝肃杀／决断 |
| **谐音** | 同音取义 | 梨→离、棺材→官财、鱼→余 |
| **反梦** | 凶象吉断、死中生 | 梦死得生、梦失得得 |
| **心理层** | 潜意识映射（荣格原型） | 追赶 / 坠落 / 考试＝压力；飞翔＝渴望自由 |

判断顺序：**先查有没有谐音或反梦的反转 → 再用类象定属性 → 最后落回现实情绪**。
三层结论不一致时，以"传统层给寓意方向、心理层给情绪出口"并列呈现，不要强行统一。

## 脚本输出怎么读

```
· 命中意象：棺材
  传统解：谐音"官财"，反梦典型（凶象吉断）→ 主升迁 / 进财之机（规则：谐音 + 反梦）
  心理层：对"结束与开始"这类转变心存焦虑
```

- 一条梦境可能命中多个意象（如"棺材"+"大雨"+"老宅"），**每个都要讲，不要只挑一个**。
- 命中 0 条时，脚本会打"未命中"，此时按三层规则拆，并**追问**情绪与近期压力。
- 「未命中」不是失败，是最该追问的时刻。

## 必问的三件事（信息不全时追问）

1. **梦里的情绪**：害怕 / 开心 / 委屈 / 麻木（同一意象配不同情绪，结论相反）
2. **醒来那一刻的感受**：心慌 / 轻松 / 想哭 / 无所谓
3. **近期最在意的现实压力**：工作 / 感情 / 家人 / 金钱

## 合规红线

- ❌ 不说"此梦预示疾病 / 死亡 / 灾祸"
- ❌ 不做心理或医疗诊断
- ❌ 不渲染"托梦""缠身"，梦见已故亲人以安抚为主
- ✅ 长期噩梦影响睡眠与生活 → 建议寻求专业心理支持
- ✅ 明确声明"解梦属传统文化与心理视角的参考"

## 输出模板

```
【先结论】
这个梦更可能是在说 X（象义），同时映射您近期关于 X 的情绪（仅供参考）。

【怎么得出的】
· 传统层：X 属「谐音 / 反梦 / 类象」，按规则作 X 解。
· 心理层：这类梦象通常对应 X 类压力或渴望。

【还缺什么】
梦境描述越具体越准：梦里的情绪、醒来那一刻的感受、近期最在意的现实压力。

【建议】
吉象：顺其自然，把机会抓住；凶象多看情绪出口，不必恐慌；
反复同梦：值得回看现实里那件一直没解决的事。

【边界】
解梦是意象参考，不构成心理或医疗诊断；
长期噩梦影响睡眠与生活时，建议寻求专业心理支持。
```

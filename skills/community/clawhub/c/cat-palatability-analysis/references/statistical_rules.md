# 统计口径详细说明

## 1. 数据结构

原始记录单为宽表：3 组 × 7 猫 × 5 餐 = 105 条潜在记录。

每组 7 只猫，每只猫每餐记录：
- 余料量 A(g)、余料量 B(g)
- 首口料（A料 / B料 / 同时采食 / 无采食 / 未观察）

抬头记录单盆给料量（默认 40g）。每餐位置行记录 A 料在左盆还是右盆。

## 2. 采食量

```
采食A = 给料量 − 余料A
采食B = 给料量 − 余料B
```

单位 g，保留 2 位小数。余料空白视为缺失，不参与统计。

## 3. 对比数（胜负计数）

判定基准为**采食量差**，不是余料量差（两者数学等价但表述以采食量为准）：

```
diff = 采食A − 采食B
diff ≥ +4.0g  →  A胜，A胜计数 +1
diff ≤ −4.0g  →  B胜，B胜计数 +1
|diff| < 4.0g →  平局，胜负均不计
```

- 阈值 4g 含边界（正好 4.0 算胜）。
- A胜率 = A胜 / (A胜 + B胜)。平局不进分母。
- 可按组、按猫、按餐三个层级汇总。

示例：

| 采食A | 采食B | diff | 判定 |
|---|---|---|---|
| 30.6 | 22.0 | +8.6 | A胜 |
| 18.0 | 22.0 | −4.0 | B胜 |
| 25.0 | 23.0 | +2.0 | 平局 |

## 4. 异常剔除

双轨并行，命中任一即剔除，并写入剔除清单标出原因。

### 轨 1：备注关键词

备注列含以下任一关键词即剔除整条记录：

`待核`、`涂改`、`模糊`、`呕吐`、`软便`、`打翻`、`拒食`、`异常`、`混食`、`换人`、`位移`、`设备异常`、`未记录`

注意：备注是按猫（行）记录的，同一只猫的所有餐次都会被剔除。

### 轨 2：IQR 离群

对每组每餐的 A 采食量、B 采食量分别计算：

```
Q1 = 25% 分位, Q3 = 75% 分位, IQR = Q3 − Q1
下界 = Q1 − 1.5 × IQR
上界 = Q3 + 1.5 × IQR
采食量 < 下界 或 > 上界 → 剔除该条记录
```

样本数 < 4 的组/餐不做 IQR 检测。

### 轨 3：缺失值

采食 A 或 B 为空（余料空白）→ 剔除。

## 5. 显著性分析

同一只猫同一餐同时面对 A、B 两盆，属**配对设计**，不可用独立样本检验。

对每个组：

1. 配对差值 `d = 采食A − 采食B`
2. Shapiro-Wilk 正态性检验：
   - p ≥ 0.05 → 主结论用**配对 t 检验**
   - p < 0.05 → 主结论用**Wilcoxon 符号秩检验**
3. 两种检验结果都输出，报告注明主结论方法。
4. 效应量：配对 Cohen's dz = mean(d) / sd(d)。
5. 显著性水平 α = 0.05。

## 6. 首选率

仅 `首口料 ∈ {A料, B料}` 进入分母。

```
A首选率 = A首选数 / (A首选数 + B首选数)
B首选率 = B首选数 / (A首选数 + B首选数)
```

- `同时采食`、`无采食`、`未观察` 不计入分母。
- 报出首选率必须同时给出有效首选数（分母）。
- 首口料分布表单独列出全部 5 种取值的频次。

## 7. 采食量描述统计

- **平均顿采食量**：按组/按餐，对有效记录的采食量求算术均值（g）。
- **顿采食中位数**：按组/按餐，对有效记录的采食量求 50% 分位数（g）。
- 同时输出标准差（按餐）。

## 8. 左右位置偏倚

按 `位置 ∈ {A左, A右}` 分别计算平均 A 首选率：

```
偏倚指数 = |A左平均首选率 − A右平均首选率|
```

判定：
- ≤ 5%：无明显位置偏倚
- 5%~10%：需关注
- > 10%：须在报告中说明，或增加餐次重测

## 9. 报告解读注意

- 三组料不同 → 只做组内比较；跨组只能比同口径指标（A 料首选率），并列出各组 A/B 料名称批号。
- 首选率反映第一选择，采食占比反映整体偏好；两者结论不一致时以采食占比为主并说明。
- A左/A右餐次数应相等，否则首选率存在位置偏倚。
- 若采食量为 0（吃光），提示给料量可能不足，建议加大给料量重测。

# 新冠药物肝肾功能调整规则

## 奈玛特韦/利托那韦

| 肾功能 | 剂量调整 |
|--------|----------|
| 轻度肾损 (eGFR 60-90) | 无需调整 |
| 中度肾损 (eGFR 30-60) | 奈玛特韦减量至150mg，利托那韦100mg，q12h |
| 重度肾损 (eGFR <30) | 禁用 |
| 重度肝损 | 禁用 |

## 阿兹夫定

- 中度肝/肾损：慎用，密切监测
- 重度肝/肾损：缺乏数据，不建议使用

## 巴瑞替尼

| eGFR | 剂量 |
|------|------|
| ≥60 ml/(min·1.73m²) | 4mg/d |
| 30-60 ml/(min·1.73m²) | 减量，需评估 |
| <30 ml/(min·1.73m²) | 慎用或避免 |

## 药物相互作用警示

- 利托那韦为强CYP3A4抑制剂，与多种药物存在严重相互作用
- 巴瑞替尼与强OAT3抑制剂（如丙磺舒）合用需减量
- 用药前必须核查患者完整用药清单

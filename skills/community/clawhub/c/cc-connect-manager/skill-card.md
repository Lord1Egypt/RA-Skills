## Description:

Manage cc-connect projects by adding projects to ~/.cc-connect/config.toml, configuring bot and platform bindings, setting up multi-agent relay bindings, and restarting cc-connect in tmux.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill to register local workspaces with cc-connect, configure supported chat platform bots, restart the connector, and guide multi-agent relay setup in shared channels.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Bot credentials may be written to ~/.cc-connect/config.toml and exposed through logs or shared output.

Mitigation: Avoid pasting secrets into logged commands, redact tokens before sharing config output, and protect the config file with appropriate local permissions.

Risk: The skill can edit the live cc-connect configuration and restart the connector.

Mitigation: Back up ~/.cc-connect/config.toml and review the generated project block before restarting cc-connect.

Risk: QQ configuration generated by the helper uses wildcard sender access.

Mitigation: Use QQ wildcard access only when any sender should be allowed; otherwise restrict the generated configuration before restarting.

## Description:

Guides agents building, implementing, or refactoring pure HTML/CSS/JS frontends toward token-driven, responsive, accessible UI with OKLch color systems, dark mode patterns, and stronger visual hierarchy.

This skill is ready for commercial/non-commercial use.

## Publisher:

[cgartlab](https://clawhub.ai/user/cgartlab)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and design-focused agents use this skill to create or refactor frontend components, pages, layouts, interactions, responsive behavior, accessibility details, and dark mode using a consistent CSS token system.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may over-apply strict frontend design-token and accessibility rules to broad UI tasks.

Mitigation: Use it for pure HTML/CSS/JS frontend design or refactoring tasks where tokenized styling, responsiveness, accessibility, and dark mode guidance are desired.

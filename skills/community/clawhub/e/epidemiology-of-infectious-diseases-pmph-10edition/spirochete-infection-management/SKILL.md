# 螺旋体感染诊疗管理

## 一、钩体病（Leptospirosis）

### 1.1 临床分型与鉴别
```
IF 确诊/疑似钩体病:
  根据主要受累器官判断分型：
  - 流感伤寒型：鉴别上感、流感、伤寒、败血症
  - 肺出血型：鉴别肺结核咯血、大叶性肺炎
  - 黄疸出血型：鉴别病毒性肝炎、肾综合征出血热
  - 脑膜脑炎型：鉴别病毒性/化脓性/结核性脑膜炎
  - 肾衰竭型：鉴别急性肾炎、肾综合征出血热
```

### 1.2 肺弥漫性出血型分期识别
**关键：先兆期是唯一可逆转窗口**

| 分期 | 临床表现 | X线 | 干预 |
|------|---------|-----|------|
| 先兆期 | 气促、心慌、烦躁，呼吸/心率进行性↑，双肺散在渐增湿啰音，可血痰 | 散在点片状阴影 | **立即干预，可逆转** |
| 出血期 | 面色苍白/青灰，发绀，窒息恐惧，双肺满布湿啰音，多数咯血 | 双肺广泛融合 | 救治难度极大 |
| 垂危期 | 昏迷，呼吸不规则，口鼻涌出不凝泡沫血 | - | 濒死状态 |

- 3期演变：数小时至24小时
- 偶有暴发起病，无明显先兆即死亡

### 1.3 实验室诊断
```
根据发病天数选择标本：
- 第1周：血液（暗视野镜检/PCR/培养）
- 7~10天：脑脊液（PCR，针对脑膜炎者）
- 第2~3周：尿液（暗视野镜检/PCR）

血清学诊断标准（MAT）：
- 单次效价 ≥ 1:400 有诊断意义
- 或早晚期双份血清效价增加4倍
- ELISA测IgM：特异性/敏感性高于MAT

综合诊断：流行病学史（28天内接触疫水/病畜）+ 临床表现 + 实验室阳性
```

### 1.4 治疗与赫氏反应管理

#### 抗菌治疗
| 病情 | 方案 |
|------|------|
| 轻症 | 多西环素/阿莫西林/氨苄西林/阿奇霉素 口服 |
| 重症 | 青霉素40万U q6~8h IM，疗程7天或热退后3天 |

#### 赫氏反应（Herxheimer reaction）
```
IF 青霉素首剂后0.5~4小时出现突发寒战、高热、症状加重:
  判断：赫氏反应（大量钩体被杀灭释放毒素）
  处理：
  1. 镇静剂：异丙嗪/氯丙嗪/地西泮/苯巴比妥，必要时哌替啶
  2. 氢化可的松 静滴
  3. 警惕：少数可诱发致命性肺弥漫性出血
```

### 1.5 重症对症处理
- **肺出血型**：
  - 及早镇静剂
  - 氢化可的松1000~2000mg/d 缓慢静注
  - **禁忌**：慎用升压药/高渗溶液，补液不宜过快过多
- **黄疸出血型**：护肝、解毒、止血，肾衰竭按急性肾衰处理
- **后发症**：后发热对症；葡萄膜炎扩瞳+激素；闭塞性脑动脉炎大剂量青霉素+激素+血管扩张药

## 二、梅毒（Syphilis）

### 2.1 临床分期诊断
```
IF 疑似梅毒（高危暴露史/皮肤黏膜损害/神经系统症状）:
  1. 流行病学史：不洁性交史、配偶梅毒史、流产/死产史
  2. 分期特征识别：
     - 一期（感染后2~4周）：硬下疳（无痛性溃疡）+ 硬化性淋巴结炎
     - 二期（感染后4~10周）：泛发性铜红色皮疹（掌跖受累）、扁平湿疣、虫蚀状脱发
     - 三期（感染>2年）：树胶肿、心血管梅毒、神经梅毒
     - 潜伏梅毒：无症状，血清阳性（早期<2年，晚期>2年）
  3. 实验室确诊：
     - 早期皮损：暗视野显微镜查TP
     - 初筛：RPR（非梅毒螺旋体抗原试验，定量监测疗效）
     - 确诊：TPPA/TPHA（梅毒螺旋体抗原试验）
     - 神经梅毒：脑脊液VDRL
```

### 2.2 分期治疗方案

| 分期 | 首选方案 | 过敏替代 |
|------|---------|---------|
| 早期 | 苄星青霉素G 240万U IM 分两侧，1次/周×2次 | 多西环素100mg bid×15天 |
| 晚期/复发 | 苄星青霉素G 240万U IM 1次/周×3~4次 | 多西环素×30天 |
| 心血管 | 住院，小剂量水剂青霉素G起始→普鲁卡因青霉素80万U/d IM×15天×2疗程 | 多西环素 |
| 神经 | 水剂青霉素G 1200~2400万U/d 分4~6次静滴×10~14天 → 苄星青霉素240万U/周×3次 | 头孢曲松2g/d×10~14天 |
| 先天<2岁 | 水剂青霉素G 10~15万U/(kg·d) 静滴×10~14天 | <8岁用红霉素 |
| 妊娠期 | 按分期治疗，初3月+末3月各1疗程 | 禁用四环素，用红霉素 |

**关键约束**：
- 心血管梅毒首剂禁用苄星青霉素G（防赫氏反应）
- 妊娠期禁用四环素/多西环素
- <8岁儿童禁用四环素

### 2.3 治疗后随访监测
```
完成治疗后启动随访（至少3年）：
- 第1年：每3个月复查
- 第2年：每半年复查
- 第3年：年末复查

特殊人群：
- 神经梅毒：每6个月查脑脊液
- 梅毒孕妇分娩婴儿：出生后1、2、3、6、12月随访
- 妊娠期梅毒：每月定量RPR

复发指征：RPR滴度上升4倍或阴转阳 → 立即加倍剂量复治
```

## 三、莱姆病（Lyme Disease）

### 3.1 临床分期识别
```
IF 蜱叮咬史/疫区居住史 + 多系统症状:
  - 第一期（叮咬后1~20天）：
    * 核心：慢性游走性红斑（ECM），60%~80%出现
    * 皮损：叮咬处→扩大→牛眼状（外缘鲜红，中央褪色）
    * 伴随：发热、头痛、颈强直
  - 第二期（病后2~4周）：
    * 神经：面神经炎最常见、脑膜炎、脑炎
    * 心脏：房室传导阻滞、心肌炎（皮损后3~10周）
  - 第三期（数周至2年）：
    * 关节：大关节反复单关节炎（膝、踝、肘）
    * 皮肤：慢性萎缩性肢端皮炎
```

### 3.2 血清学两步法确诊
```
第一步（初筛）：ELISA 或 IFA
- 阴性+高度怀疑 → 数周后复查
- 阳性/可疑 → 进入第二步

第二步（确诊）：Western Blot
- 阳性 → 实验室确诊

注意：急性早期阳性率低，IgM在红斑后2~4周出现
```

### 3.3 分期抗菌治疗

| 分期 | 成人方案 | 儿童方案 | 疗程 |
|------|---------|---------|------|
| 第一期 | 多西环素0.1g bid / 阿莫西林500mg tid / 头孢呋辛酯500mg bid | 阿莫西林40mg/(kg·d) / 头孢呋辛酯20~30mg/(kg·d) | 3~4周 |
| 第二期（神经受累） | 头孢曲松2g/d IV / 青霉素G 2000万U/d IV | 头孢曲松75~100mg/(kg·d) IV | 2~4周 |
| 第三期 | 头孢曲松2g/d IV / 青霉素G 2000万U/d IV | 同成人 | 14~21天 |

**注意**：约6%用青霉素时出现赫氏反应

### 3.4 蜱虫叮咬处理
```
IF 发现蜱虫附着:
  1. 局部麻醉软膏涂抹，等待15~20分钟
  2. 镊子夹住蜱头部（贴近皮肤），平稳拔出
  3. 检查口器是否完整残留，肥皂水清洗
  4. 抗感染软膏涂抹
  5. 预防用药：多西环素（或阿莫西林/头孢呋辛替代）

禁忌：不可生拉硬拽（口器残留风险）
```

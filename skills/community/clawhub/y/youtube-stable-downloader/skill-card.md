## Use Case:

External users and agents use this skill to save permitted YouTube videos for offline access, select output quality, or extract audio through natural language requests.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Video URLs are sent to a hosted service and results are returned through a cloud download link.

Mitigation: Use the skill only when the user is comfortable sharing the video URL and receiving the resulting file through that service.

Risk: Downloading videos can raise copyright, permission, or platform-terms issues.

Mitigation: Use the skill only for videos the user owns, has permission to save, or is otherwise allowed to download under applicable law and platform terms.

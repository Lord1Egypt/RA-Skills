## Description:

Helps maintainers and users improve software error messages by turning requests into practical workflows, checklists, artifacts, analysis, code changes, and validation notes.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, maintainers, and contributors use this skill to turn requests for better software error messages into concrete plans, checklists, artifacts, analysis, implementation support, and validation notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may be invoked by ordinary wording because broad keywords and implicit invocation are enabled.

Mitigation: Prefer explicit use of $error-message-improver or narrow trigger terms to phrases such as better error messages or improve application error copy.

Risk: Generated recommendations or code changes for error messages could be incomplete, misleading, or inconsistent with project standards.

Mitigation: Review proposed outputs against the project context and validate changes before applying them.

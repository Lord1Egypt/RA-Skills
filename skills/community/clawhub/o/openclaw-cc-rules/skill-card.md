## Description:

Openclaw Cc Rules defines a structured OpenClaw programming workflow for planning, task tracking, read-only exploration, Git safety, and multi-file changes.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill to make OpenClaw follow a conservative software-development workflow across coding, debugging, review, project analysis, and Git tasks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The broad activation scope can apply the workflow to most programming sessions, including cases where a lighter process is preferred.

Mitigation: Review the activation scope before installation and customize or disable rules for projects or sessions that need narrower behavior.

Risk: Workflow guidance may influence plans, task lists, Git practices, and command proposals during coding work.

Mitigation: Review proposed actions before execution and keep project-specific policies for commits, destructive commands, and dependency changes.

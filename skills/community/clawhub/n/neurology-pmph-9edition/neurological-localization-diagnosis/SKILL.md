# 神经系统定位诊断

## 适用场景

- 脑神经损害需要定位（面瘫、面部感觉障碍、吞咽困难、伸舌偏斜）
- 需要鉴别上/下运动神经元损害
- 语言障碍需要失语症分类
- 认知功能下降需要评估
- 步态异常、不自主运动需要鉴别
- 眼震需要定位诊断
- 排尿障碍需要神经源性膀胱分型

## 一、脑神经定位诊断

### 核心原则：皮质脑干束支配规律

**口诀："面舌对侧，其余双侧"**

- 受双侧支配（单侧病变不瘫）：动眼、滑车、展、三叉运动、疑核、副神经、面神经核上半
- 受对侧单侧支配（单侧病变即瘫）：面神经核下半、舌下神经核

### 面神经麻痹定位流程

```
面瘫患者
├── 上面部正常（能皱眉闭眼）→ 中枢性面瘫 → 对侧皮质脑干束病变
└── 全面部瘫痪 → 周围性面瘫 → 根据伴随症状定位：
    ├── +展神经麻痹+对侧锥体束征 → 面神经核（脑桥）
    ├── +味觉障碍+听觉过敏+耳后疱疹 → 膝状神经节（Hunt综合征）
    ├── +味觉障碍+听觉过敏 → 面神经管（镫骨肌神经以上）
    ├── +味觉障碍（无听觉过敏）→ 面神经管（鼓索神经受累）
    └── 单纯面瘫 → 茎乳孔以外
```

### 舌下神经损害定位

| 伸舌偏斜方向 | 舌肌萎缩 | 肌束颤动 | 定位 |
|------------|---------|---------|------|
| 偏向病灶对侧 | 无 | 无 | 核上性（中枢性）|
| 偏向病灶侧 | 有 | 可有 | 核性/周围性 |

### 三叉神经损害定位

- **完全性感觉障碍**（三支分布区）→ 周围性（半月节/神经根/分支）
- **分离性感觉障碍**（痛温觉缺失，触觉保留）+ "洋葱皮样"分布 → 核性（脊束核）
  - 口鼻周围受累 → 脊束核上部
  - 面部周边受累 → 脊束核下部

### 延髓麻痹鉴别

| 特征 | 真性（下运动神经元） | 假性（上运动神经元） |
|------|------------------|-------------------|
| 病变 | IX/X神经或核 | 双侧皮质脑干束 |
| 咽反射 | 消失 | 存在/亢进 |
| 下颌反射 | 正常 | 亢进 |
| 强哭强笑 | 无 | 有 |
| 舌肌萎缩 | 可有 | 无 |
| 锥体束征 | 无 | 常有 |

## 二、高级皮层功能评估

### 失语症分类流程

执行六维度检查：自发谈话、听理解、复述、命名、阅读、书写

**关键鉴别点：复述功能**

```
复述障碍 → 外侧裂周围失语
├── 非流利+理解相对好 → Broca失语（额下回后部）
├── 流利+理解严重障碍 → Wernicke失语（颞上回后部）
└── 流利+复述障碍不成比例地重 → 传导性失语（缘上回/弓状束）

复述保留 → 经皮质性失语
├── 非流利 → 经皮质运动性（Broca区附近）
├── 流利+理解差 → 经皮质感觉性（Wernicke区附近）
└── 所有功能严重障碍仅复述保留 → 经皮质混合性（分水岭区）

其他：
- 所有功能严重障碍 → 完全性失语
- 仅命名障碍 → 命名性失语（颞中回后部）
```

### 失用症与失认症

**失用症**（运动感觉正常但不能完成有目的动作）：
- 观念性失用：动作概念混乱（双侧半球）
- 观念运动性失用：不能按指令做，但可自然完成（优势顶叶）
- 结构性失用：空间关系构建困难（非优势顶叶）
- 穿衣失用：穿衣正反颠倒（非优势顶叶）

**失认症**（感觉正常但不能辨认熟悉事物）：
- 视觉失认：看清但不能识别（枕叶）
- 面容失认：不能辨认熟悉面孔
- 触觉失认：闭眼不能触摸识别（顶叶角回）
- 体象障碍：偏侧忽视、病觉缺失（非优势顶叶）

### 记忆功能检查

1. **瞬时记忆**：数字广度测验（顺行>逆行为正常）
2. **短时记忆**：3词条5分钟后回忆
   - 提示后能想起 → 提取障碍（早期痴呆）
   - 提示仍不能想起 → 存储障碍（严重）
3. **长时记忆**：个人信息、常识

### 认知障碍与痴呆诊断

**MCI vs 痴呆核心区别**：
- MCI：认知下降但日常生活能力基本正常
- 痴呆：≥2个认知域受损 + 日常生活能力明显减退

## 三、运动障碍定位

### 异常步态鉴别

| 步态类型 | 特征 | 病变部位 |
|---------|------|---------|
| 慌张步态 | 小碎步加速、前倾、摆臂少 | 帕金森病（锥体外系）|
| 鸭步 | 躯干左右摇摆 | 肌病（臀肌无力）|
| 跨阈步态 | 高抬腿、足尖拖地 | 腓总神经损伤 |
| 感觉性共济失调 | 看地行走、闭眼加重 | 后索/周围神经 |
| 小脑性共济失调 | 步基宽、向患侧倾倒 | 小脑半球 |

### 不自主运动分类

- **静止性震颤**（4-6Hz搓药丸样）→ 帕金森病
- **姿势性震颤** → 特发性震颤/甲亢
- **意向性震颤** → 小脑病变
- **舞蹈样运动** → 尾状核/壳核病变
- **手足徐动** → 基底核病变
- **偏侧投掷** → 对侧丘脑底核

### 眼震定位

**周围性 vs 中枢性鉴别**：

| 特征 | 周围性 | 中枢性 |
|------|-------|-------|
| 方向 | 水平/水平旋转 | 垂直/旋转/多变 |
| 持续时间 | 短，发作性 | 长 |
| 眩晕 | 重 | 轻 |
| 听力障碍 | 常有 | 无 |
| 中枢体征 | 无 | 常有 |
| 固视抑制 | 可抑制 | 不能抑制 |

**脑干精确定位**：
- 旋转性眼震 → 延髓
- 水平性眼震 → 脑桥
- 垂直性眼震 → 中脑

## 四、自主神经功能

### 神经源性膀胱分型

| 类型 | 病变部位 | 膀胱感觉 | 容量 | 残余尿 |
|------|---------|---------|------|-------|
| 感觉障碍性 | 后角/后索/后根 | 消失 | 显著增大 | 多 |
| 运动障碍性 | 前角/前根 | 存在 | 增大 | 多 |
| 自主性 | S2-4/马尾 | 消失 | 略大 | >100ml |
| 反射性 | 骶髓以上横贯 | 消失 | 正常/小 | <100ml |
| 无抑制性 | 皮质/锥体束 | 正常 | 小 | 无 |

## 输出要求

1. 明确病变解剖定位（脑神经核/周围/中枢，皮层区域等）
2. 给出具体诊断分类
3. 提示可能的病因
4. 建议进一步检查方向

## 脑神经详细定位

### 面神经节段定位详解

| 节段 | 伴随症状 | 常见病因 |
|------|---------|---------|
| 面神经核 | +展神经麻痹+对侧锥体束征 | 脑桥肿瘤/血管病 |
| 膝状神经节 | +味觉+泪液唾液+听觉过敏+耳疱疹 | Hunt综合征（带状疱疹）|
| 面神经管上段 | +味觉+唾液+听觉过敏 | 面神经管病变 |
| 面神经管下段 | +味觉+唾液（无听觉过敏）| 鼓索神经受累 |
| 茎乳孔外 | 单纯面瘫 | 面神经炎 |

### 三叉神经分支分布
- V1（眼神经）：额部、角膜 → 病变合并角膜反射消失
- V2（上颌神经）：上颌、鼻翼
- V3（下颌神经）：下颌、舌前2/3感觉 → 病变合并咀嚼肌无力

## 失语症各亚型详细特征

### Broca失语
- 病灶：优势半球额下回后部（Broca区，BA44、45区）
- 特征：非流利、电报式语言、讲话费力、找词困难
- 理解相对保留，复述/命名/读/写均有损害

### Wernicke失语
- 病灶：优势半球颞上回后部（Wernicke区，BA22区）
- 特征：流利但空洞混乱、答非所问、缺乏实质词
- 严重听理解障碍，复述障碍与理解一致

### 传导性失语
- 病灶：优势半球缘上回、弓状束
- 特征：流利、大量错词、自身能感知并欲纠正
- **核心特点**：复述障碍较自发谈话和听理解障碍重

## 痴呆病因分类

### 变性病性
- 阿尔茨海默病(AD)
- 额颞叶痴呆
- 路易体痴呆
- 帕金森病痴呆

### 非变性病性
- 血管性痴呆(VaD)
- 正常颅压脑积水
- 感染性（神经梅毒、HIV等）
- 代谢/中毒性（B12缺乏、酒精等）
- 肿瘤/占位

## MCI亚型

### 遗忘型MCI
- 单纯记忆损害型 → 常为AD早期
- 多认知域损害型 → AD/脑血管病/抑郁

### 非遗忘型MCI
- 非记忆单一/多认知域损害 → 额颞叶变性、路易体痴呆早期

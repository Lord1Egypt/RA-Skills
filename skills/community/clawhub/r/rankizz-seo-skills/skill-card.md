## Description:

Set up and orchestrate Rankizz SEO Skills for a website, repository, or client. Use when an agent needs to initialize SEO project context, choose and install the right Rankizz specialist skills, configure Rankizz MCP or REST API access, or route a broad SEO request into audits, research, roadmaps, content, social, or outreach workflows.

This skill is ready for commercial/non-commercial use.

## Description:

Automatically sends browser screenshots to users via the message tool so visual results from web automation workflows reach the conversation channel.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and automation agents use this skill to deliver browser screenshots to users after web automation, scraping, UI verification, debugging, or visual testing workflows.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Screenshots sent to shared channels may expose private account pages, credentials, customer data, or other sensitive information.

Mitigation: Review, crop, or redact screenshots before sending them, and confirm the target channel is appropriate for the content.

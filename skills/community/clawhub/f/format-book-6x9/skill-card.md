## Description:

Formats a manuscript into a 6" x 9" Printed Paperback and a Kindle Ebook, generating a cover page, TOC, headers, and an About the Author section.

This skill is ready for commercial/non-commercial use.

## Publisher:

[vega6dev](https://clawhub.ai/user/vega6dev)

### License/Terms of Use:

MIT-0

## Use Case:

Authors, editors, and publishing workflows use this skill to convert a raw text or Markdown manuscript into print-ready 6 x 9 paperback output and a reflowable Kindle EPUB.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated paperback or Kindle output files may overwrite similarly named files in the working directory.

Mitigation: Review the proposed output filenames before execution and run the skill in a directory where those names are safe to create.

## Description:

Writes Instagram Reels scripts as muted-first production docs optimized around a 3-second hook, watch-through, DM shares, Instagram search keywords, cover framing, and optional Veo prompt packs for faceless or b-roll shots.

This skill is ready for commercial/non-commercial use.

[social-media-skills](https://clawhub.ai/user/social-media-skills)

MIT-0

## Use Case:

Social media, brand, and content teams use this skill to draft shootable Instagram Reels scripts that include hook, shot, on-screen text, spoken audio, timing, caption handoff, cover brief, and AI-video prompt guidance when needed.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Instagram specs, audio availability, and AI-labeling requirements can change quickly.

Mitigation: Verify current Instagram publishing specs, account audio library access, and AI-labeling requirements before publishing a Reel.

Risk: The skill may use brand-profile.md and voice.md as input context.

Mitigation: Provide only brand and voice files that are intended for agent use.

Risk: Generated scripts could include claims, testimonials, or performance expectations that are not verified.

Mitigation: Review factual claims, remove fabricated testimonials or stats, and apply required brand or regulated-industry guardrails before production.

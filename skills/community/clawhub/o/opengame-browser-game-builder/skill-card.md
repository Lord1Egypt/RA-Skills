## Description:

Design and build small, original, playable browser-game prototypes.

This skill is ready for commercial/non-commercial use.

## Publisher:

[opengameapp](https://clawhub.ai/user/opengameapp)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, designers, and external users use this skill to turn game ideas into focused browser-game MVPs or vertical slices, and to improve controls, mechanics, progression, game feel, and verification of playable loops.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may activate for general game-improvement requests when the user does not want browser-prototype or code-generation help.

Mitigation: Phrase non-browser or non-prototype game requests clearly, and confirm scope when that distinction materially changes the response.

Risk: Browser-game prototypes can accidentally rely on unclear intellectual-property or asset provenance when named games, brands, or characters are used as references.

Mitigation: Use named works only as genre or mechanics inspiration, create original names and assets, and use supplied or clearly licensed media.

Risk: Generated prototypes may contain gameplay or runtime issues if the playable loop is not exercised.

Mitigation: Run the game path when the environment permits, check start, controls, objective, win or loss, restart, console output, and resize behavior, and report what remains unverified.

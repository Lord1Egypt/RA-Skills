## Description:

Helps API developers and backend teams generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to produce practical OpenAPI or Swagger documentation, implementation checklists, validation guidance, and related decision support for REST APIs.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may be invoked for broad API or developer-experience requests outside OpenAPI or Swagger documentation work.

Mitigation: Use it only when the task specifically involves OpenAPI, Swagger, REST API documentation, schema validation, or closely related documentation workflows.

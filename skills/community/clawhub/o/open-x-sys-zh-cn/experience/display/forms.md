# 层与形式：做什么，用什么做

> **何时读**：论点已经有了，要选形式；要在网页、视频、演示稿和文字之间做决定；或者某个依赖缺失，你需要知道没有它时该交付什么。

形式最后才选，并且为内容而选：先论点，再结构，最后形式（见 `engines/express.md`）。

## 三层

| 层 | 用什么 | 适合 | 是否总是可用 |
|---|---|---|---|
| **0 · 网页** | 一个自足的单文件 HTML，使用内置的库 | 可探索的解释、滚动叙事、交互揭示、数据故事、地图 | 是，任何能写文件的宿主都行 |
| **1 · 宿主自带** | 可分享的页面、内嵌组件、浏览器截图、生成图像 | 链接、自我批评、插画 | 取决于宿主 |
| **2 · 内置与已连接的 Skill** | 视频、动画、文档、演示稿 | 讲解视频、演讲、可以发出去的成果 | 依赖及其运行环境就绪时 |

**无论用哪一层，作品本身都要值得看。** 选择网页时，可以优先做一份能独立打开的完整作品。重要的是人能看见有分量的认识、在自己的环境里用上成果。其他媒介可以把同一项优势带给不同读者。

这个人已有的东西比内置的更合适时，用这个人的（见 `system/parts.md` 里的盘点）。

### 一个第 0 层的网页

- **一个文件。** 双击就能打开，需要时可以离线工作，可以原样发给别人。
- **库是内嵌的，或者是锁定版本的。** 使用内置的、锁定的版本（见 `experience/display/libraries.md`）。只在库能做到页面需要的事时才用它。很多最好的页面一个库都不需要。
- **只有真实的内容。** 带来源的真实数据，真实的名字，没有占位文字，没有凑数的图库图片。
- **在哪里都能读。** 桌面和手机宽度；对象没有指定时，明暗两种都支持；键盘可达；文字可以选中；图片有替代文字。
- **每一屏一个想法**，每一步都有继续看下去的理由。

## 形式跟着需要走

问读者需要在头脑里完成什么。

| 需要 | 形式 | 什么时候是对的选择 |
|---|---|---|
| **看见一个机制如何运转** | 可逐步推进的探索、动画图解、简短的讲解视频 | 洞见在于各部分怎样随时间相互作用 |
| **感受一个尺度** | 同屏的比例对照、可以缩放的尺度 | 让人惊讶的是一个比例或一个量级 |
| **检验一个直觉** | 先预测，再揭示 | 这个人有一个明确而且错误的预期 |
| **理解来龙去脉** | 叙事时间线、滚动叙事 | 现状只有通过它的转折点才说得通 |
| **比较几种未来或几个选项** | 在关键维度上并排比较 | 一个决定；几种情景 |
| **看清一个结构** | 剖面、分层、标注过的真实图像 | 洞见在于什么包含什么、什么支撑什么 |
| **试一试** | 一段模拟 | 只在动态本身就是洞见、静止时看不出来的时候 |
| **掌握一个数学或物理思想** | 概念动画 | 这个思想是一种变换、一个极限、一种几何 |
| **行动** | 一份计划、一个工具、一套演示稿、一份文档、代码 | 这个人接下来必须做点什么 |
| **被打动** | 文字 | 事情关乎人，一篇写得好的文字比界面更承载得住 |

一份成果可以混合几种形式，其中一种是主体。

### 通常是错的形式

- **“万物相连”的节点连线图。** 只在拓扑本身就是发现时使用。
- **由指标和面板组成的仪表盘。** 它在汇报，不在揭示。
- **没人知道该怎么调的参数滑块。** 一个控件，只有在拨动它能让人看见静止页面上看不见的东西时，才配得上它的位置。
- **网格里的一张张卡片**，每张讲一个方面。那是圆角的百科全书。
- **一份长报告**，而这个人问的是一个有答案的问题。

## 全力开启时怎样在各层之间选

当视频、概念动画或演示稿能服务这个需要，而且它的依赖已经就绪时，不问就做。这就是全力开启在媒介上的意思。“能服务这个需要”要如实判断：

- **短视频**：当揭示是一个运动或一个过程，或者这个人是给一群看而不读的受众做内容时。
- **概念动画**：当思想是数学的或物理的，静态的图要用好几段话来解释时。
- **演示稿**：当这个人必须讲给别人听时。
- **文档**：当结果必须发出去、归档或签字确认时。

宿主缺少相应媒介能力时，完整地交付第 0 层，加上静态卡片，并只说一次、用诚实的一句话说明另一种环境还能带来什么。以后的运行里不再重复，除非这个人问。增加运行环境或工具由这个人决定（见 `../../adapters/tools.md`）。

## 受众比对象决定得更多

同一份认识，对不同的人会变成不同的成果：

- **刚入门的人**：从熟悉的东西讲起；一个想法；揭示来得早；术语少。
- **行内人**：跳过已经知道的；直奔有争议或新的部分；证据更细。
- **必须做决定的人**：先给判断，再给它依据什么、什么会改变它。
- **要把它发布出去的人**：为这个人的受众和平台而做，用这个人的声音，作者是这个人。

这个人说了它是给谁的（“给我们工程团队看的视频”），那就是请求的一部分。没有说，就按你对受众最好的判断来做，说出你的假设，让一句话就能改掉它。

## 只能输出文字的宿主

只能输出文字的宿主，损失的是形式，不是信息。签名照样出现（见 `experience/display/signature.md`），揭示照样有它自己的时刻，结构照样从读者知道的地方走到那一件值得看的事。本该由一张图来承担的地方，准确地描述那张图会展示什么。

# 内容合作工作流

用于从视频出发，拆解有参考价值的内容，再联系发布达人。用户已提供可访问的视频链接时，可从拆解环节开始。

1. **查找视频。** 普通搜索每次指定 TikTok、Instagram 或 YouTube 中一个平台，并提供话题标签或至少一个达人标识。可叠加标题关键词、播放量、互动率和发布日期。看品牌相关内容时，可按品牌名使用品牌视频洞察查询已收录视频。参见 [视频搜索](../../discovery/video-search/SKILL.md)。
2. **确认并拆解视频。** 展示视频链接、发布达人和实际返回的指标，确认待分析的范围。每条 TikTok 视频、Instagram Reels 或 YouTube Shorts 链接单独提交一个异步任务，按任务编号查询结果。可附 Brief，或开启案例对比。有多条时按各自任务结果汇总，展示实际返回的分镜、开场钩子、内容结构、卖点、评分和建议。参见 [短视频拆解](../../audit/video-script-audit/SKILL.md)。
3. **查询发布达人。** 优先使用视频搜索结果中的 `creator.uid` 与平台，在对应平台以 `union_user_ids` 精确查询。只有主页链接时可用 `profile_urls`。可以补查地区、内容表现和实际邮箱，结合已有拆解结论整理候选。参见 [达人搜索](../../discovery/creator-search/SKILL.md)。
4. **确认邮件并发送。** 展示候选达人、合作理由、收件邮箱和邮件正文。按 [邮件建联](../../outreach/creator-outreach/SKILL.md) 的确认规则发送，汇总即时结果或用任务编号查询发送结果。用户需要时，再查会话历史和跟进待办。

搜索无结果时先报告原条件的实际命中数，有用户确认再调整条件。个别视频拆解失败时，分别报告成功与失败的任务。达人资料或邮箱缺失时，说明缺失字段，并请用户确认余下的建联名单。

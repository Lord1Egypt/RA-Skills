External users and their agents use this skill to inspect authenticated Finance District wallet balances, token holdings, wallet addresses, and recent account activity across supported EVM chains and Solana.

## Known Risks and Mitigations:

Risk: Authenticated wallet profile, balances, addresses, holdings, and transaction activity can expose sensitive financial information.

Mitigation: Install and use only where agent access to the authenticated Finance District wallet profile is intended, and keep returned wallet data within trusted contexts.

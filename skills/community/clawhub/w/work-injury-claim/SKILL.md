# 工伤认定与工伤保险待遇索赔全流程辅助技能

## 概述

本技能为工伤职工提供从工伤认定到待遇索赔的全流程辅助，覆盖以下核心环节：
1. **工伤情形研判** — 判断是否构成工伤、适用哪种工伤情形
2. **材料清单生成** — 按工伤情形生成个性化材料清单
3. **劳动能力鉴定指引** — 鉴定时机、等级参考、申请流程
4. **待遇金额计算** — 按伤残等级和地区规则计算各项待遇
5. **地区规则查询** — 全国各地区工伤保险规则差异
6. **一键生成索赔文档** — 自动生成工伤认定申请表和待遇计算表

支持全国各地区（含省、自治区、直辖市及主要城市），内置地区差异参考。

## 工作流程

### 总流程

```
用户咨询 → 信息收集 → 工伤情形研判 → 材料清单生成 → 鉴定指引 → 待遇计算 → 文档生成 → 提交指引
```

### 阶段一：信息收集

收集以下关键信息（按需逐项询问，避免一次性追问过多）：

**必采信息：**
1. 用户所在地区（省/市）— 用于确定管辖和地方规则
2. 用人单位全称 — 用于查询工商信息
3. 受伤日期 — 确定工伤认定申请时效
4. 受伤经过简述 — 判断工伤情形类型
5. 伤情/诊断 — 用于鉴定等级参考和待遇计算
6. 是否已缴纳工伤保险 — 确定待遇支付主体
7. 月工资标准 — 用于计算各项待遇金额

**按需采集信息：**
- 是否已申请工伤认定 → 确定当前阶段
- 是否已完成劳动能力鉴定 → 确定是否需要鉴定指引
- 伤残等级（如已鉴定）→ 用于计算待遇
- 是否涉及交通事故 → 上下班途中工伤情形
- 是否涉及第三人侵权 → 工伤与民事赔偿竞合
- 是否在职/已离职 → 确定一次性待遇申领条件

**采集方式：**
- 通过对话逐步收集
- 用户可上传病历、诊断证明、工伤认定决定书等材料照片/截图
- 对用户上传的材料进行分析和信息提取

### 阶段二：工伤情形研判

加载参考文档：`references/work_injury_recognition.md`

执行研判流程：
1. 根据受伤经过判断适用哪种工伤情形（第14条第1-7项、第15条第1-3项）
2. 评估是否存在排除情形（故意犯罪、醉酒吸毒、自残自杀）
3. 评估工伤认定申请时效是否仍在有效期内
4. 评估劳动关系是否存在争议
5. 生成研判报告

**研判输出格式：**
- 工伤情形判定（适用条款+理由）
- 时效评估（申请时限+剩余时间）
- 证据匹配表（要件→所需证据→现有证据→缺口）
- 风险评估（劳动关系风险、证据风险、时效风险）
- 行动建议

**地区差异查询：** 加载 `references/regional_differences.md`，根据用户所在地区查询：
- 上下班途中工伤认定标准
- 停工留薪期确认方式
- 一次性补助金标准
- 第三人侵权竞合规则
- 工伤认定申请渠道

### 阶段三：材料清单生成

加载参考文档：`references/claim_documents.md`

1. 根据工伤情形生成个性化材料清单
2. 标注每项材料的：是否已收集、获取方式、优先级
3. 对未收集的材料提供补充指引
4. 给出材料整理规范（编排顺序、证据固定方法）

**输出格式：** 可勾选的材料清单表格，用户可对照逐项准备。

### 阶段四：劳动能力鉴定指引

加载参考文档：`references/disability_assessment.md`

1. 根据伤情评估建议鉴定时机
2. 提供伤残等级参考（强调仅供参考，以鉴定结论为准）
3. 指导鉴定申请流程和材料准备
4. 说明再次鉴定和复查鉴定的条件
5. 说明生活自理障碍等级评定

**鉴定等级参考：** 根据伤情类型，从参考文档中匹配可能的等级范围，提醒用户实际等级以鉴定委员会结论为准。

### 阶段五：待遇金额计算

加载参考文档：`references/compensation_calculation.md`

1. 根据伤残等级计算一次性伤残补助金
2. 计算伤残津贴（1-6级）
3. 计算生活护理费（如需护理）
4. 计算一次性工伤医疗补助金和伤残就业补助金（5-10级解除合同时）
5. 计算停工留薪期工资
6. 计算因工死亡待遇（如适用）
7. 生成待遇计算表

**计算参数：**
- 本人工资：工伤前12个月平均月工资
- 社平工资：统筹地区上年度职工月平均工资（需查询当地最新数据）
- 伤残等级：以鉴定结论为准
- 地区标准：从 `references/regional_differences.md` 查询

**使用脚本：** `scripts/generate_injury_claim_docs.py` 可自动计算并生成待遇计算表。

### 阶段六：生成索赔文档

使用脚本：`scripts/generate_injury_claim_docs.py`

根据收集的信息，自动生成以下文档：
1. **工伤认定申请书** — 包含申请人信息、用人单位信息、事故经过、受伤部位
2. **待遇计算表** — 各项待遇的计算明细和合计金额
3. **材料清单** — 结构化材料目录

**脚本调用方式：**
```bash
python scripts/generate_injury_claim_docs.py --output-dir <输出目录> [参数...]
```

或通过 JSON 配置文件传入案件信息：
```bash
python scripts/generate_injury_claim_docs.py --config <案件信息JSON> --output-dir <输出目录>
```

### 阶段七：提交指引

1. 指导用户向当地人社部门提交工伤认定申请
2. 提供当地线上申请渠道（如有）
3. 指导后续鉴定申请和待遇申领流程
4. 如用人单位未参保，指导如何向用人单位追偿

## 关键规则与提醒

### 法律依据快速索引

| 事项 | 法律依据 |
|------|---------|
| 工伤认定 | 《工伤保险条例》第14-16条 |
| 视同工伤 | 《工伤保险条例》第15条 |
| 工伤认定程序 | 《工伤认定办法》 |
| 劳动能力鉴定 | 《工伤保险条例》第21-26条 |
| 鉴定标准 | GB/T 16180-2014 |
| 工伤保险待遇 | 《工伤保险条例》第30-45条 |
| 未参保责任 | 《工伤保险条例》第62条 |
| 时效 | 工伤认定：单位30日/个人1年 |

### 待遇计算公式

```
一次性伤残补助金 = 本人工资 × 补助月数（1-27月，按等级）
伤残津贴 = 本人工资 × 比例（60%-90%，1-6级按月发放）
生活护理费 = 社平工资 × 比例（30%-50%，按护理等级）
停工留薪期工资 = 原工资福利待遇 × 停工月数（≤12月，可延长≤12月）
一次性工伤医疗补助金 = 计算基数 × 月数（5-10级，各地不同）
一次性伤残就业补助金 = 计算基数 × 月数（5-10级，各地不同）
丧葬补助金 = 社平工资 × 6个月
供养亲属抚恤金 = 工亡职工本人工资 × 30%-40%/人/月
一次性工亡补助金 = 上年度全国城镇居民人均可支配收入 × 20倍

本人工资封顶：统筹地区社平工资300%（上限）/ 60%（下限）
```

### 重要时效提醒
- 用人单位申请工伤认定：30日（从事故发生之日起）
- 工伤职工/近亲属申请工伤认定：1年
- 劳动能力鉴定再次鉴定申请：15日（收到鉴定结论后）
- 复查鉴定：鉴定结论作出1年后
- 行政复议：收到工伤认定决定后60日内
- 行政诉讼：收到决定后6个月内（或收到复议决定后15日内）

### 使用注意事项
1. 本技能提供的信息仅供参考，不构成法律意见
2. 伤残等级参考仅为一般性参考，实际等级以鉴定委员会结论为准
3. 各地标准每年更新（社平工资调整），使用时需查询最新数据
4. 提交前建议拨打12333确认当地最新政策
5. 复杂案件建议咨询专业律师或申请法律援助（12348）
6. 因工死亡案件金额较大，强烈建议寻求专业法律帮助

Comprehensive catalog of what people are doing with OpenClaw, covering use-case categories, real examples, sources, and inspiration for project ideas.

## Use Case:

Developers, builders, and OpenClaw users use this skill to find existing OpenClaw use cases, gather inspiration, and produce bilingual Markdown findings when researching new examples.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can lead an agent to browse the web, write findings, commit, and push using existing repository credentials.

Mitigation: Require explicit confirmation before web research, file writes, commits, or pushes, and use scoped accounts where repository writes are intended.

Risk: Some catalog examples involve sensitive automation patterns such as SMS 2FA handling, private-message monitoring, real-browser platform evasion, or autonomous production changes.

Mitigation: Treat those examples as high-risk ideas only; require consent, scoped accounts, audit logs, and human approval before adopting them.

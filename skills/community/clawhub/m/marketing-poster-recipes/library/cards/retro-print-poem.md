# retro-print-poem · 诗意复古印刷海报

> 输入类型：**图生图（必须用户上传照片）**｜引擎：ImageGen｜稳定性：**中**（竖图可能被转横版——验收必查画幅；穿字指令已 2026-11-26 四次实测定稿回灌，成功率 2/4 → 预期提升，复评待验证）
> 配方来源：基于公开的"诗意复古印刷海报"创作思路整理重构；主 prompt 已含 2026-11-26 混元实测防坑修正（演进记录见 gotchas.md）

## 适用场景

要高级感、诗意、杂志编辑风——大字衬线 + 半调网点 + 英文诗句。适合花/食物/人像/包装等有向上延伸空间的主体。

## 输入要求与槽位（生成前必填齐）

- **用户照片 1 张**（主体需有辨识度、适合向上延伸）。深色背景照片会加重分界线问题（见坑④），优先浅背景图，或先用 ImageGen 做背景替换中间稿（同样先去水印再投喂）。

| 槽位 | 说明 | 示例 |
|---|---|---|
| {{向上延伸主体}} | 照片中最高的、能垂直向上延伸的主体 | 按压泵瓶 / 花枝 / 甜点盘 |
| {{大字单词}} | **必填，显式指定**，不交给引擎自选 | GLOW / HUSH / ZEST / FREE |
| {{诗句文本}} | **必填，4 行通顺英文，逐字进 prompt**（防乱码，见坑③） | Bottled light in amber glass, ... |
| {{大字颜色}} | 从产品主色提取并显式指定 | 琥珀棕焦糖色（并写「不是黑色」） |

## 生成 Prompt（2026-11-26 实测定稿版，与用户照片一起投喂）

```text
【最高优先级指令·必须实现·比其他所有要求优先】本海报只有一个不可妥协的核心：照片中最高的 {{向上延伸主体}} 必须移到画面中部，主体与巨大的 {{大字单词}} 大字处于同一高度区间，主体垂直向上延伸，顶端和主体真实遮挡住 {{大字单词}} 的字母笔画（至少遮挡两个字母的部分笔画），并越过字顶进入上方留白。主体与大字互相穿插、有前有后。绝对禁止：主体全部在大字下方、大字完整无遮挡、或照片层与文字层各自独立分层。若成图中大字完整可见，即为废稿。
将照片重新取景：主体上移，让 {{向上延伸主体}} 占据画面中部，下方保留其他物件和场景，向上延伸出画面下部。
制作成一张 3:4 竖版诗意复古印刷海报，一个连续场景，不是分区拼图，照片区与文字区之间不允许水平硬分界线。
【大字】中部单词 {{大字单词}}，巨大衬线大写、横跨画面，颜色用 {{大字颜色}}（不是黑色），笔画被主体穿插遮挡、保持可读。
【诗句】上方暖白留白区打字机字体小诗，内容必须逐字使用以下文本，不得改动拼写：
{{诗句文本}}
【衔接】照片背景与上方暖白留白做柔和连续过渡，利用主体轮廓、光线、背景色与网点疏密衔接，避免笔直横切边、抠图白边和生硬渐变；小诗和细节标记采用与主色同系的深色。
【印刷网点】在大字与风格化照片内部加入细密、清晰可见的圆形彩色印刷网点，青、洋红、黄等墨点可轻微错位，暗密亮疏。整体像复古杂志的彩色半调印刷，而非普通噪点或划痕；主体仍保持真实摄影材质，上方暖白相对干净。
【缩略图与克制】右上角放一张宽约占画面 15%–18% 的原始照片缩略图，完整展示原图、保持比例、不裁切、不调色，配细边框及准确的 "ORIGINAL" 标注，置于诗句与主体之外的留白处。整体克制、诗意，英文准确，无额外标题、新增水印或无关装饰；只输出一张完整海报，不要拼图或样机。
```

## 大字单词怎么选（Day2 实测规律）

从照片主题提炼一个简短英文情感词：木槿花→HUSH、水面鸭群→DRIFT、抱花跃起→FREE、柑橘→ZEST、甜点→SWEET、琥珀护肤→GLOW。**选情感词不选名词**，与诗句情绪呼应。

> **2026-11-26 定稿**：引擎自行选词会偏离规律（FLAVOR / PRESENTS），**槽位必填、显式指定**，本卡 prompt 已按此设计。

## 坑与备注（Day2 逐字稿实测 + 2026-11-25/26 混元四连实测定稿）

- **竖图可能被转成横版**：验收第一步先查画幅 3:4 竖版（混元实测：显式传竖版尺寸参数 1/1 稳定）
- **【坑①穿字·已定稿】主体不穿字是混元引擎稳定失败点**：课程原版 prompt 两次全败；修正链 = 最高优先级前置指令 + 具体化「主体与字同高 + 至少遮挡两字母 + 越字顶」+ 反向废稿判据（「大字完整可见即为废稿」）。**抽风时原 prompt 直接重投，不要换措辞**（引擎随机性主导，同 prompt 成败各半）
- **【坑②选词·已定稿】引擎选中性词/名词**：解法 = 槽位必填显式指定（见上）
- **【坑③诗句乱码·已定稿】图生图场景小字退化为伪英文**（实测 "The tne iocks of thi to phats"，同一 prompt 一次通顺一次乱码）：解法 = 诗句文本逐字写进 prompt，两次实测零复发。万一仍乱码：验收逐句读，乱码走 references/repair-recipes.md SOP-3 擦除重排
- **【坑④分界线·结构性顽疾】**米白留白区与照片区交界水平硬线，图生图场景 4/4 复现，prompt 措辞救不了。对策：选浅背景输入图 + 验收确认分界线位置不切主体（落在诗句区下方时视觉伤害最小）；深背景图先做背景替换中间稿
- **【坑⑤颜色·已定稿】大字发黑**：显式写「用 {{大字颜色}}（不是黑色）」
- **引擎水印在右下角**（混元/豆包同款，图生图为半透明白字）：交付前按 references/repair-recipes.md 修复，未处理不算可交付成品

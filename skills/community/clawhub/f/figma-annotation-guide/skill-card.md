## Description:

Generate structured developer handoff annotations for a Figma screen or component, covering interactions, UI states, spacing, accessibility, and edge cases.

This skill is ready for commercial/non-commercial use.

## Use Case:

Designers, product managers, and frontend or mobile developers use this skill to turn Figma screens or components into structured developer handoff annotations covering interactions, UI states, spacing, layout, content rules, accessibility, and edge cases.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad trigger wording may cause the skill to activate for general design-documentation requests.

Mitigation: Review activation behavior before installation and invoke it only when Figma developer handoff annotations are needed.

Risk: Generated annotations may omit product-specific design decisions or misstate implementation details if the supplied design context is incomplete.

Mitigation: Have the design and engineering team review the output for interaction behavior, accessibility requirements, edge cases, and unresolved questions before build.

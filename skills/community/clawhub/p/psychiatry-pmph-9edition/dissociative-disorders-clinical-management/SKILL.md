# 分离性障碍临床诊疗技能

## 适用场景

当遇到以下临床表现时启动本技能：
- 身份瓦解或人格交替控制意识
- 出神状态、身份被取代体验
- 自我或环境不真实感（现实检验能力完整）
- 无器质性基础的运动/感觉/认知障碍
- 突发与创伤相关的个人信息遗忘
- 疑似分离性障碍需鉴别诊断

## 核心诊断流程

### 第一步：确认分离症状类型

根据核心症状确定疑似亚型：

| 症状特征 | 疑似诊断 |
|---------|---------|
| 两个以上独立人格交替控制+严重遗忘 | 分离性身份障碍(DID) |
| 身份被外界"附体"取代+行为受控制 | 附体出神障碍 |
| 自我/环境不真实感+现实检验完整 | 人格解体-现实解体障碍(DDD) |
| 神经症状+体征矛盾+无器质性基础 | 分离性神经症状障碍 |
| 突发个人/创伤记忆遗忘+意识清晰 | 分离性遗忘症 |
| 意识状态改变+环境意识变窄 | 出神障碍 |

### 第二步：执行通用排除标准

所有分离性障碍诊断前必须逐一排除：

1. **器质性排除**：神经系统疾病（颅脑损伤、癫痫、脑肿瘤）、神经发育障碍
2. **物质排除**：精神活性物质使用（直接效应或戒断效应）
3. **文化排除**：症状是否为被认可的集体文化/宗教活动一部分（若是，不诊断）
4. **其他精神障碍排除**：精神分裂症、睡眠-觉醒障碍、催眠状态等

### 第三步：评估功能损害

确认症状导致个人、家庭、社交、学业、职业等领域显著损害。

## 各亚型诊断要点

### 分离性身份障碍(DID)
- 身份瓦解：≥2个独立人格状态
- 控制权交替：至少两种身份反复取得意识控制权
- 严重遗忘症：记忆空隙，不同人格可互补记忆
- 风险因素：严重童年创伤（身体虐待、性侵）

### 附体出神障碍
- 出神反复发作或单次≥数天
- 原有身份被外界"附体"身份取代
- 必须是不自主的、不必要的
- 鉴别DID：DID为内部人格瓦解，附体为外部身份取代

### 人格解体-现实解体障碍(DDD)
- 人格解体：像旁观者从体外观察自我
- 现实解体：感知环境不真实/朦胧
- **关键**：现实检验能力保持完整（区别于精神病性障碍）
- 平均确诊需7-12年，无明确实验室检查

### 分离性神经症状障碍
- 起病前有明确心理社会因素
- 症状具有矛盾性（如步态障碍者可跑步）
- 体征与症状不匹配（按患者对神经系统的理解呈现）
- **关键鉴别**：与躯体症状障碍区别在于患者态度（漠然处之 vs 过分关注）

### 分离性遗忘症
- 遗忘内容与自身紧密相关（个人/创伤信息）
- 遗忘之外其他信息相对完整
- 鉴别TGA：TGA为顺行性记忆障碍+重复提问，24h内恢复

## 治疗干预

### 总体治疗原则
1. 积极关注症状，全程支持性心理治疗
2. 寻找诱发/维持/强化症状的心理社会因素
3. 医护与家属形成医疗联盟
4. **关键**：关心不能过度，避免促成"继发获益"

### 继发获益管理策略
- 接纳症状存在，展示检查仅发现功能受损无器质性损害
- 谨慎逐渐将心理社会因素与症状关系分离
- 不强化心理社会因素与症状的关联

### 各亚型特异性治疗

**DID治疗路径**：
- 心理治疗为主：长程CBT整合人格、催眠处理创伤、家庭治疗
- 药物对症：非典型抗精神病药（侵入性症状）、SSRIs（抑郁）
- MECT：共病抑郁伴自杀意念

**分离性神经症状障碍暗示治疗SOP**：
1. 觉醒时暗示：解释为"短暂神经功能障碍可完全恢复"→语言暗示+理疗/针刺→10%葡萄糖酸钙10ml静推或感应电刺激→配合被动运动→语言强化
2. 催眠暗示：检验感受性→强则语言催眠/弱则药物辅助（硫喷妥钠或异戊巴比妥静注）→进入半睡眠状态后暗示治疗

**分离性遗忘症催眠治疗**：
1. 签订自愿治疗协议
2. 经典催眠4阶段：诱导→加深→建议→出现
3. 控制性唤起记忆，避免二次创伤
4. 完成分离记忆的现实整合

## 风险因素评估

评估时关注：
- 心理社会压力源（100%患者存在至少一种）
- 创伤史（童年/战争期虐待、暴力）
- 人格特征（EPQ外向性低，神经质高）
- 社会文化背景（移民、宗教冲突）

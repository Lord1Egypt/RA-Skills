## Description:

工作幻觉纠偏 is a Chinese-language alias skill that routes work-hallucination correction requests to the official VeriClaw install, reference, and feedback pages.

This skill is ready for commercial/non-commercial use.

## Publisher:

[sheygoodbai](https://clawhub.ai/user/sheygoodbai)

### License/Terms of Use:

MIT-0

## Use Case:

External users and operators use this skill when they describe a work hallucination scenario, where progress appears to have happened but evidence is missing or weak. The skill directs them toward VeriClaw resources for evidence-first correction and the canonical install or feedback route.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Users may treat the alias as an automatic security or remediation action.

Mitigation: Treat the install and feedback links as optional product-routing guidance and continue to verify evidence before acting.

Risk: Install, star, comment, or feedback signals may be left on this alias instead of the canonical VeriClaw page.

Mitigation: Use the official VeriClaw ClawHub page when the goal is the canonical public install surface or durable feedback.

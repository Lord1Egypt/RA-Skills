# 保险责任八维分析框架

本文档定义保险条款分析的8个核心维度，每个维度包含：分析目标、关键问题、评分标准和输出格式。

---

## 维度一：保障责任（权重 20%）

**核心问题**: 这个保险具体保障什么？

| 分析点 | 关键问题 |
|--------|----------|
| 主险责任 | 保障的主体责任是什么？（身故/疾病/意外/医疗报销） |
| 附加责任 | 可选的附加险有哪些？各自的保障内容？ |
| 给付方式 | 一次性给付还是按比例报销？给付条件是什么？ |
| 保障额度 | 基本保额是多少？最高赔付限额？ |
| 特殊保障 | 是否有特定疾病翻倍？豁免条款？ |

**评分标准**:
- 5分: 保障范围全面、覆盖核心风险、无重大保障缺口
- 4分: 保障较为全面，存在1-2个次要缺口
- 3分: 保障基本覆盖核心风险，但范围有限
- 2分: 保障范围明显偏窄，存在显著保障缺口
- 1分: 保障范围极窄，几乎形同虚设

**输出格式**: 逐条列出保障责任，标注保额和给付条件

---

## 维度二：责任免除（权重 20%）

**核心问题**: 什么情况不赔？

| 分析点 | 关键问题 |
|--------|----------|
| 标准免责 | 犯罪、战争、自杀等通用免责条款 |
| 疾病免责 | 哪些疾病不在保障范围内？ |
| 行为免责 | 高风险运动、特定职业活动等免责 |
| 既往症免责 | 投保前已有疾病的免责范围 |
| 隐形免责 | 藏在定义中的免责（如"合理且必要"的严格定义） |

**评分标准**:
- 5分: 免责范围合理、无需特别关注的苛刻条款
- 4分: 免责基本合理，1-2条可注意
- 3分: 存在3-5条需重点关注的免责
- 2分: 免责条款较多，涵盖常见高发情形
- 1分: 免责范围极广，核心风险几乎不可保

**输出格式**: 逐条列出责任免除，标注严重程度

---

## 维度三：时间条件（权重 10%）

**核心问题**: 保障何时生效？多久能赔？

| 分析点 | 关键问题 |
|--------|----------|
| 等待期 | 意外责任以外的等待期是多少天？ |
| 犹豫期 | 可无损退保的天数？ |
| 间隔期 | 多次赔付的间隔期是多少？ |
| 保险期间 | 保障多久？（1年/定期/终身） |
| 宽限期 | 保费未缴时的宽限期？ |

**评分标准**:
- 5分: 等待期短(≤30天)、间隔期合理、保障期限贴合需求
- 4分: 时间条件基本合理
- 3分: 等待期偏长或间隔期较长
- 2分: 等待期过长(≥180天)或间隔期很长
- 1分: 时间条件严重不合理

**输出格式**: 列出各项时间条件的具体数值

---

## 维度四：金额规则（权重 15%）

**核心问题**: 能赔多少钱？需要自己掏多少？

| 分析点 | 关键问题 |
|--------|----------|
| 免赔额 | 免赔额是多少？绝对还是相对？年度还是单次？ |
| 赔付比例 | 赔付比例是多少？有无社保区别？ |
| 赔付限额 | 年度/单次/终身赔付上限？ |
| 保费水平 | 保费是否合理？是否有费率调整条款？ |
| 分项限额 | 各项责任是否分别设限？ |

**评分标准**:
- 5分: 免赔额合理、赔付比例高、无隐性限额
- 4分: 金额规则总体合理
- 3分: 存在较高免赔额或年度限额
- 2分: 免赔额过高、赔付比例偏低或限额明显
- 1分: 金额设置严重不合理

**输出格式**: 列出各项金额规则及数值

---

## 维度五：理赔条件（权重 10%）

**核心问题**: 符合哪些条件才能拿到赔付？

| 分析点 | 关键问题 |
|--------|----------|
| 医院范围 | 几级以上？是否限制公立医院？是否含特需/国际部？ |
| 就医地域 | 中国境内/大中华/全球？ |
| 理赔材料 | 需要哪些材料？是否繁琐？ |
| 直付/垫付 | 是否支持直付或垫付？有何条件？ |
| 理赔时效 | 保险公司处理理赔的时限？ |

**评分标准**:
- 5分: 医院范围宽、材料简明、支持直付
- 4分: 理赔条件基本合理
- 3分: 医院范围偏窄或材料要求较多
- 2分: 理赔门槛高、医院范围窄
- 1分: 理赔条件苛刻，实际难以达到

**输出格式**: 逐项列出理赔条件

---

## 维度六：可持续性（权重 15%）

**核心问题**: 产品能续保/续费多久？费率会不会大幅上涨？

| 分析点 | 关键问题 |
|--------|----------|
| 续保条件 | 是否保证续保？保证续保多少年？ |
| 费率调整 | 是否有费率调整条款？调整条件和频率？ |
| 停售处理 | 产品停售后如何处理？能否转保？ |
| 续保年龄 | 最大续保年龄？ |
| 产品稳定性 | 产品已上市多久？公司经营状况？ |

**评分标准（医疗险侧重续保，储蓄险侧重利率稳定性）**:
- 5分: 长期保证续保/保证利率
- 4分: 保证续保≥5年或续保条件合理
- 3分: 非保证续保但审核不严
- 2分: 非保证续保且续保条件苛刻
- 1分: 续保无保障、费率调整无限制

**输出格式**: 逐项列出续保和费率的详细条款

---

## 维度七：健康告知（权重 5%）

**核心问题**: 投保门槛有多高？

| 分析点 | 关键问题 |
|--------|----------|
| 告知方式 | 询问告知还是无限告知？ |
| 告知内容 | 询问哪些健康状况？范围宽窄？ |
| 既往症定义 | 既往症如何定义？是否含"症状"？ |
| 核保方式 | 智能核保还是人工核保？ |
| 除外承保 | 是否可以除外承保？ |

**输出格式**: 逐项列出健康告知的核心问题

---

## 维度八：特别约定（权重 5%）

**核心问题**: 有哪些容易被忽略的特殊约定？

| 分析点 | 关键问题 |
|--------|----------|
| 特别约定 | 是否有附带的特别约定条款？ |
| 矛盾条款 | 是否存在条款之间的矛盾？ |
| 模糊表述 | 是否存在"合理且必要"等模糊概念？ |
| 格式条款 | 是否存在以小字、附加格式隐藏的限制？ |
| 销售承诺 | 合同是否与销售宣传一致？ |

**输出格式**: 逐项列出特别约定的内容和风险

---

## 综合评分计算

综合评分 = Σ(维度评分 × 维度权重)

| 分数 | 等级 | 说明 |
|------|------|------|
| 4.0-5.0 | 优秀 | 产品条款清晰、保障全面、无明显风险点 |
| 3.0-3.9 | 良好 | 产品总体合理，存在可接受的少量瑕疵 |
| 2.0-2.9 | 一般 | 产品有较多需要注意的问题，建议审慎 |
| 1.0-1.9 | 较差 | 产品存在重大风险或保障严重不足 |
| 0.0-0.9 | 很差 | 产品不建议购买 |

---

## 输出规范

每项分析结果必须包含：
1. `label`: 分析项名称（如"等待期-重疾"）
2. `value`: 具体内容（如"180天，较长，投保180天内确诊重疾不赔付"）
3. `score`: 该维度整体评分（1-5）
4. `risk_signals`: 该维度的风险信号列表

风险信号格式：`"风险描述 + 具体影响 + 建议关注点"`

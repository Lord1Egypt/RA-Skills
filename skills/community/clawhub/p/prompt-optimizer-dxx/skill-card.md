## Description:

Prompt Optimizer rewrites vague Chinese-language requests into clearer prompts that agents can execute more precisely.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ntaffffff](https://clawhub.ai/user/ntaffffff)

MIT-0

## Use Case:

Developers and agent users use this skill to turn short or underspecified Chinese prompts into structured task instructions, including task type, missing information, and format guidance.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Optimized prompts may add defaults such as Markdown formatting, Python implementation, or concise professional Chinese wording that do not match the user's intended language, output format, or programming language.

Mitigation: Review the optimized prompt before using it and adjust language, format, and programming-language constraints when they matter.

## Description:

Helps AI-agent users and skill authors create practical Humanizer-style workflows for bug fixing, setup hardening, reliability improvements, and adjacent skill creation.

This skill is ready for commercial/non-commercial use.

## Use Case:

External AI-agent users, skill authors, maintainers, and teams use this skill to turn Humanizer-style productivity needs into local-hardware-friendly workflows, checklists, implementation plans, code changes, and validation notes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation wording and implicit invocation could cause the skill to be selected for generic writing, editing, or bug-fix tasks.

Mitigation: Prefer explicit invocation for Humanizer-style generated-text workflow tasks and review the trigger policy before installing in agents that auto-select skills.

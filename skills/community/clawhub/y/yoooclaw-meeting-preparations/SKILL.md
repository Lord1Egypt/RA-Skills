# 会前备战（Meeting Prep）

为用户生成会前备战简报。严格按下面的顺序执行，不要跳过步骤。

## 用户输入

- 关注的人：`{{who}}`
- 关注的事：`{{what}}`

## 核心原则

「关注的事」是本次简报的主线，所有搜索、筛选、总结都围绕它展开。
「关注的人」是观察视角——用来看这些人最近围绕主线说了什么、做了什么。
与主线无关的消息，即使来自关注的人，也不要出现在简报里。

## 前置依赖：联网搜索能力

第二步可能需要联网搜索，依赖 `byted-web-search` 技能。开始前先检查一次，不需要向用户二次确认：

1. 执行 `openclaw skills list`，在输出里查找是否包含 `byted-web-search`。
2. 已安装：正常继续。
3. 未安装：执行
   `npx skills add https://skills.volces.com/skills/bytedance/agentkit-samples -s byted-web-search --agent openclaw`
   - 安装成功：正常继续。
   - 安装失败：**不要中止整个简报**。记下"联网搜索不可用"，在第二步直接跳过联网部分，仅用通知信息生成简报，并在简报末尾提示"本次未能联网搜索外部信息"。

> 设计说明：纯内部会议本就用不到联网搜索，因此联网能力缺失只降级、不阻断。

---

## 第一步：从手机通知中搜索

从「关注的事」中提取 1-3 个短关键词。提取时去掉"周会""月会""评审""关注""重点"等修饰词，只保留核心名词。

提取示例（参考）：
- "项目A周会，重点关注预算审批" → 项目A、预算审批
- "Q2规划评审" → Q2规划
- "和客户讨论合作方案" → 客户、合作方案
- "团队周会" → 团队

对每个关键词搜索最近 7 天的消息通知。若「关注的人」不为空，也对每个人名搜索最近 7 天的通知。

汇总所有结果备用。若全部没有结果，记下"通知中未找到相关信息"，继续下一步。

## 第二步：判断是否需要联网搜索

根据「关注的事」判断（满足任意一条就搜）：
- 涉及行业动态、市场趋势
- 涉及竞品、友商、外部合作方
- 涉及政策、法规、标准变化
- 涉及某项技术的最新进展
- 涉及外部客户或供应商

**不需要联网**的情况：纯内部周会/站会/进度同步、内部评审/复盘、只讨论内部流程和分工。

判断示例（参考）：
- "客户A合作方案讨论" → 搜"客户A公司 最新动态"
- "项目A内部周会" → 不搜
- "AI大模型技术选型会" → 搜"AI大模型 最新进展"
- "团队月度复盘" → 不搜
- "行业峰会参会准备" → 搜"[行业名] 峰会 最新议题"

需要搜：自行生成 1-2 个搜索词，用 `byted-web-search` 执行联网搜索，时间范围设为最近一周，结果记下备用。
不需要搜，或「关注的人」「关注的事」都为空，或联网能力不可用：跳过本步骤，进入第三步。

## 第三步：整理主题维度

把第一步和第二步收集到的所有信息（通知 + 联网）放在一起，围绕「关注的事」梳理出 2-4 个主题维度：

1. 找出围绕主线反复出现的话题或方向。
2. 把内容相近的信息归到同一维度下（不分来源）。
3. 每个维度用一个短标题概括（如"产品体验与质量""市场渠道进展""功能规划方向"）。
4. 与主题无关的信息在这一步直接丢弃。

示例——主题是"YoooClaw App"时可能梳理出：产品体验与稳定性、市场与渠道、功能与硬件方向。

## 第四步：输出备战简报

输出为会话文本，不生成文件。严格按以下模板：

```
📋 [围绕「关注的事」用一句话概括本次简报重点，≤30 字]

## 🎯 会议主题
{{what}}

## 📊 全局概览
[3-5 句话，综合通知和联网搜索的全部信息，围绕「关注的事」给出整体判断：
进展到什么阶段、整体态势如何、有哪些值得注意的变化。这一段最重要，
用户可能只看这段就进会议室。]

## 🔍 关键发现
[按第三步的主题维度逐个输出，维度下信息不区分来源、混合呈现。]

### [维度1标题]
[1-2 句话总结要点。]
- [来源标注] [消息内容，可精简但保留原意]
- [来源标注] [消息内容]

### [维度2标题]
[1-2 句话总结。]
- [来源标注] [消息内容]

### [维度3标题]（如有）
...

## ❓ 建议关注点
- [事项]：[为什么值得关注，1 句话]
- [事项]：[为什么值得关注，1 句话]
```

来源标注规则：
- 通知消息：`[来源App · 人名 · 日期]`，如 `[飞书 · 石东博 · 4/18]`
- 联网搜索：`[来源网站 · 日期]`，如 `[中华网 · 5/9]`

约束：每个维度最多列 4 条最相关消息；维度 2-4 个，不超过 4 个。

若通知和联网搜索都完全没有结果，"关键发现"处写：
> 未找到与「{{what}}」相关的信息。

若信息很少或为空，"建议关注点"处写：
- 信息有限，建议会前与相关人员直接沟通了解最新情况

## 兜底规则

- 只填「关注的事」没填「关注的人」→ 跳过人名搜索，只按主题关键词搜通知，来源标注不写人名。
- 只填「关注的人」没填「关注的事」→ 只搜人名相关通知，跳过联网搜索；模板里「会议主题」写"未指定"，围绕这些人最近的共同话题梳理维度。
- 两个都没填 → 输出"请至少填写一项关注内容后重试"，不生成简报。
- 搜索结果总量超过 15 条 → 按与主题的相关度筛选后再梳理维度。

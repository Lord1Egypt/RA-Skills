## Description:

Sync WordPress posts, pages, ACF fields, comments and media between two sites through the Content Sync, Media Sync, Import, Export plugin Abilities API (rsl-ie/*). Use when the user asks to push, pull, copy or update content between a staging/production or any two connected WordPress sites without export files.

This skill is ready for commercial/non-commercial use.

## Use Case:

WordPress site administrators and developers use this skill to move selected posts, pages, comments, media, and ACF content between connected WordPress sites. It guides connection setup, sync job monitoring, and destination verification.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Sync jobs write to the destination site and can overwrite existing content.

Mitigation: Confirm the sync direction and selected records, back up the destination before overwriting, and verify the result on the target site.

## Description:

Convert EPUB books into an AI-ready Markdown library with a first-read META.md navigation index, per-chapter Markdown files, and extracted images.

This skill is ready for commercial/non-commercial use.

## Publisher:

[yueeli](https://clawhub.ai/user/yueeli)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and agents use this skill to convert EPUB books into a navigable Markdown workspace for reading, summarization, retrieval, analysis, and downstream text processing without loading the whole book at once.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Overwrite mode can recursively delete the resolved output directory if pointed at the wrong path.

Mitigation: Use a new output directory by default and pass --overwrite only for a disposable directory that was previously generated by this converter.

Risk: Running the conversion invokes a local Python script that writes files and may install dependencies through uv.

Mitigation: Run it only in an environment where local file writes and first-use dependency installation are acceptable.

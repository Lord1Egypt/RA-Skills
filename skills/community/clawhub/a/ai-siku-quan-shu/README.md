# AI四库全典 · Skill

[English README](README.en.md) — 含发起人唐浩云的经历、项目初衷与共建指南。

《AI四库全典》**修缮版 v1.2（总纂官定稿）**的离线全文语料与检索技能。全书四部四十八卷，加总纲（全书细目目录、全书回引台账），签字定稿合计 **2,621,610 中文字（约 262.16 万字）**——其中四部正文 2,609,342 字（约 260.93 万字），总纲 12,268 字。

装上它，Agent 就能在不联网、不调大模型 API 的情况下检索全书、给出带卷次章节的出处，并可直接打开离线 WEB 阅读器。

## 缘起与价值

### 为什么编这部书

AI 知识正在以极快速度碎片化：概念散落在论文、新闻和教程里，彼此缺少结构性的联结。本书尝试用中国传统典籍「经、史、子、集」的体例，为人工智能重建一套可检索的知识秩序——

- **经部明道**：科学根基、哲学公理、认知原理与前沿交叉科学；
- **史部鉴往**：发展史与国别谱系，考据来历、辨识脉络、追问兴衰；
- **子部载术**：技术体系，从形式化到工程边界的完整方法谱系；
- **集部存用**：行业落地与 SOP，把 AI 拉回真实的车间、诊室、课堂与交易屏。

四部四十八卷，从元问题到工程实践层层展开，让"懂很多名词却说不清来龙去脉"的状态有据可查。

### 编撰方法

这不是一次性模型生成的产物。全书由 AI 学伴团分部分工编撰、交叉审校、总纂定稿：

- **事实红线**：重大史实须取得权威来源并在正文注明（如 F-001 深蓝胜卡斯帕罗夫、F-002 AlphaGo 胜李世石）；
- **存疑标注**：无法证实的内容一律标注【待补充】，编者观点明确标出；
- **卷末台账**：每卷列待核验清单、统一编号，由组织方合并入总台账；
- **交叉审校**：分批审校并留痕，如 S-1 修复小节跳号、I-1 清理重复内容约 1900 行；
- **可复现实测**：子部关键判据来自本机实跑的数值锚点，注明脚本、运行环境与数据集；
- **v1.2 修缮**：编号体例归一（1,265 处标题）、跨部回引 31→167 处、六项真缺补章、判据页与术语表补齐 48/48、薄章补实，四部净增 50,031 字。

### 它的价值

- **对读者**：一部有出处、可查证的中文 AI 全典，把碎片知识还原成可追溯的知识谱系。
- **对 Agent**：全书离线打包，配合零依赖检索脚本与离线阅读器，让模型不联网、不调 API 也能检索原文、给出带卷次章节的引用——把"先检索后作答"变成可落地的工作流。
- **对知识组织**：示范了一种"长篇语料 + 结构化目录 + 轻量检索"的技能化封装方式，让知识资产可被工具直接消费、反复复用。

## 内容

- `assets/corpus/vol-001.md` … `vol-048.md`：四部 48 卷定稿正文（经 12 / 史 12 / 子 12 / 集 12）
- `assets/corpus/zg-01.md`、`zg-02.md`：总纲——全书四部细目目录、全书回引台账
- `assets/corpus/manifest.json`：卷 ID ↔ 中文卷名 / 定稿字数 / 章节表 / 字数合计
- `references/catalog.md`：修缮版全书目录（四部 48 卷、388 章、2532 节）
- `scripts/search.py`：零依赖中文全文检索（AND 多词、按部/卷过滤、JSON 输出）
- `assets/reader/`：离线 WEB 阅读器，`index.html` 双击即用（全文分 4 片内嵌、目录/检索/批注/夜读）

```bash

clawhub install ai-siku-quan-shu
```

### WorkBuddy

把本目录复制到 `~/.workbuddy/skills/ai-siku-quan-shu/`（用户级）或项目的 `.workbuddy/skills/`（项目级）。

## 用法示例

```bash
python3 scripts/search.py "RAG 向量数据库" --vol 子
python3 scripts/search.py "深蓝 卡斯帕罗夫" --limit 5
python3 scripts/search.py --read vol-031 --lines 120
python3 scripts/search.py --list
```

Agent 触发后应先检索再作答，引用格式：
`（出处：子部·第7卷《检索增强 RAG 与知识工程》· 1.1 章节标题）`

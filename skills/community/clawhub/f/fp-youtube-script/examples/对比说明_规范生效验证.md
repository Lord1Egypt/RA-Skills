# 验证对比：Skill 输出 vs 人工二次验证

这份文档证明 Skill 内置的 5 条技术准确性规范确实生效了——把 Skill 第一次输出的内容，和你们人工脚本里**被标红纠正过的问题**逐条对照。

结论先说：你们人工版需要逐句改的那些"过于绝对"的表述，Skill **第一次输出就避开了**。人工验证从"逐句改写"降到"抽查技术细节"。

---

## 逐条对照

### 问题 1：恒温器卡闭方向写反

| | 内容 |
|---|---|
| 人工原稿（标红） | "恒温器卡住了，无法关闭"（逻辑错误，导致过热应是无法打开） |
| 人工纠正后 | "恒温器卡在关闭位置，导致冷却液无法正常流向散热器" |
| **Skill 输出** | "如果它卡在关闭位置，冷却液就很难正常流向散热器" ✅ 直接正确 |

### 问题 2："完全失效"过于绝对

| | 内容 |
|---|---|
| 人工原稿（标红） | "任何潮湿的痕迹都意味着内部密封件已经完全失效" |
| 人工纠正后 | "也可能说明密封已经开始出问题，最好顺着痕迹确认真正漏点" |
| **Skill 输出** | "也要顺着痕迹确认真正的漏点，有时候是附近软管或接头流下来的" ✅ 已留余地 + 确认漏点 |

### 问题 3："绝对是教科书式"排除了其他可能

| | 内容 |
|---|---|
| 人工原稿（标红） | "这绝对是教科书式的恒温器卡死在关闭位置" |
| 人工纠正后 | "要重点怀疑恒温器卡闭，但也要排查冷却液液位、风扇皮带和散热器状态" |
| **Skill 输出** | "这时要重点怀疑恒温器卡闭。不过别只盯着它——也要排查冷却液液位、风扇皮带和散热器状态" ✅ 留余地 |

### 问题 4：缺少安全前提

| | 内容 |
|---|---|
| 人工原稿（标红） | "立即关闭机器，用手抓住皮带轮"（没强调拔钥匙、等停转） |
| 人工纠正后 | "先熄火、拔掉钥匙，并确认部件停止转动后，再检查皮带轮" |
| **Skill 输出** | "先把机器熄火、拔掉钥匙，确认所有部件完全停止后再检查皮带轮" ✅ 安全提示完整 |

### 问题 5：热机开散热器盖的安全警告

| | 内容 |
|---|---|
| 人工纠正后 | "只在发动机和冷却系统完全冷却时操作，绝不在热机状态开盖" |
| **Skill 输出** | "安全第一：只在发动机和冷却系统完全冷却时打开散热器盖，绝不在热机状态开盖" ✅ |

### 问题 6：术语混用（恒温器 vs 节温器）

| | 内容 |
|---|---|
| 人工原稿（标红） | 前面用"恒温器"，结尾突然变"节温器" |
| **Skill 输出** | 全篇统一用"恒温器"，无混用 ✅ |

## 人工验证还需要做什么

Skill 不是终点。以下技术细节仍需运营/技术人员**抽查**确认（而不是逐句改写）：

1. **技术原理对不对** —— 例如"叶轮腐蚀导致循环能力下降"的机理描述是否准确
2. **检查步骤可行吗** —— 现场拍摄时步骤能不能真的做到
3. **安全提示全不全** —— 有没有遗漏某个高温/转动部件的警告
4. **产品型号准确吗** —— Bobcat S650 的水泵规格是否匹配

这一步从原来的 2 小时压缩到约 30 分钟。

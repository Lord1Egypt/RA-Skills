# Chiari畸形分型与治疗决策

## 适用场景
当神经外科医生或相关临床人员需要为已确诊的Chiari畸形患者制定治疗方案时触发。

## 前置条件
- 患者必须已完成MRI矢状位影像学检查并确诊为Chiari畸形。

## 执行流程

### 步骤 1：确定Chiari畸形分型
根据MRI矢状位表现，将畸形分为以下四型：
- **I型**：小脑扁桃体及下蚓部疝至椎管内，延髓与第四脑室位置正常或轻度下移。可合并脊髓空洞症，一般不伴脊髓脊膜膨出（多见于儿童与成人）。
- **II型**：小脑、延髓、第四脑室均疝至椎管内。第四脑室正中孔与导水管粘连狭窄致梗阻性脑积水，多伴脊髓脊膜膨出（多见于婴儿）。
- **III型**：最严重。除II型特点外，常合并上颈段、枕部脑膜膨出（多在新生儿期发病）。
- **IV型**：小脑发育不全，不向下方移位（罕见，常于婴儿期发病）。

### 步骤 2：评估临床症状与并发症
收集并评估以下关键变量：
1. **是否合并梗阻性脑积水** (`has_hydrocephalus`)。
2. **症状进展状态** (`symptom_progression`)：稳定 vs 进行性加重。
## 临床症状评估清单

### 颈枕部及局部症状
- 颈枕部疼痛（最常见早期症状）
- 颈部活动受限或强迫头位
- 枕下区压痛

### 延髓及上颈髓受压症状
- 轻偏瘫或四肢无力
- 锥体束征阳性（病理征阳性、肌张力增高）
- 感觉障碍（分离性感觉障碍、痛温觉减退）
- 呼吸节律异常或睡眠呼吸暂停（严重受压表现）

### 后组脑神经受损症状
- 吞咽困难、饮水呛咳
- 声音嘶哑
- 舌肌萎缩或偏斜
- 耸肩无力（副神经受累）

### 小脑症状
- 眼球震颤
- 共济失调（步态不稳、指鼻试验阳性）
- 意向性震颤

### 慢性高颅压症状
- 头痛（枕部或全头痛，咳嗽/用力时加重）
- 恶心、呕吐
- 视乳头水肿
- 视力下降或视野缺损

### 步骤 3：制定治疗策略
根据上述评估结果，输出最终治疗建议：

#### 1. 保守对症治疗
- **指征**：无症状或症状轻微（仅有颈枕部疼痛），且病情稳定（`symptom_progression` == "稳定"）。
- **行动**：定期随访，对症止痛治疗。

#### 2. 手术治疗（枕下颅后窝骨性减压术 ± 硬膜成形术）
- **指征**：
  - 临床症状进行性加重（`symptom_progression` == "进行性加重"）。
  - 有明显神经系统受损体征。
  - 存在颅内压增高。
- **行动**：安排后颅窝减压手术。

#### 3. 脑脊液分流术
- **指征**：明确合并梗阻性脑积水（`has_hydrocephalus` == true）。
- **行动**：必须行脑脊液分流术，可联合或分期进行减压手术。

## 输出格式
以结构化报告形式输出：
1. **Chiari分型**：[I/II/III/IV]型
2. **核心临床特征**：[脑积水状态/症状进展/关键阳性体征]
3. **治疗建议**：[保守观察 / 后颅窝减压术 / 脑脊液分流术] 及具体理由。

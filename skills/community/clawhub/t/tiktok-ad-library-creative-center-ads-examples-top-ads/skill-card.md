## Use Case:

External users, marketers, and developers use this skill to research TikTok ad creatives, top-ad examples, advertisers, promoted products, stores, hooks, visual styles, and offer angles through PipiAds discovery tools.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill depends on an external npm MCP server and a PipiAds API key.

Mitigation: Install only after trusting the pipiads-mcp-server package, and use a revocable, scoped PipiAds API key.

Risk: Search and detail calls can consume paid PipiAds account credits.

Mitigation: Narrow broad ad searches by niche, region, and time range, and monitor credit usage during operation.

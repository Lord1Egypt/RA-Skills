## Known Risks and Mitigations:

Risk: The built-in learner can retain business notes, errors, usage history, and preferences across sessions.

Mitigation: Review the memory behavior before installation and disable or remove the learner if persistent local memory is not acceptable.

Risk: The skill instructs agents to adapt future behavior from saved memory and to write improvements back into the skill after repeated errors or usage.

Mitigation: Require human review before accepting memory-driven behavior changes or edits to the skill instructions.

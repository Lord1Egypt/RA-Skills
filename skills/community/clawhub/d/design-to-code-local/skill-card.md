## Description:

本地版设计稿还原工具。Implements UI from design mockups (Figma, Sketch, or image) with pixel-accurate layout, responsive behavior, and design tokens.

This skill is ready for commercial/non-commercial use.

## Publisher:

[longfer](https://clawhub.ai/user/longfer)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to convert Figma, Sketch, or image mockups into componentized frontend code that preserves layout, spacing, typography, colors, responsive behavior, and interaction states.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad UI implementation requests may activate the skill even when the available design artifact or requirements are incomplete.

Mitigation: Ask for the relevant Figma, Sketch, image, annotation, or implementation constraints before generating frontend code.

Risk: Generated frontend code may diverge from the source design in spacing, typography, colors, responsiveness, or accessibility behavior.

Mitigation: Review the output against the source mockup, target breakpoints, existing design tokens, and accessibility requirements before release.

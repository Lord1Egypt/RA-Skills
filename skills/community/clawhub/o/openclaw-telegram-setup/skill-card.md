## Description:

Guides users through configuring a Telegram Bot as an OpenClaw messaging channel with personal chat, group chat, command, and webhook setup steps.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and OpenClaw users use this skill to connect Telegram Bot messaging to OpenClaw, including allowed chat IDs, group support, bot commands, and webhook configuration.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Telegram bot tokens can grant control of the bot if exposed in screenshots, support requests, commits, or world-readable configuration files.

Mitigation: Treat the token as a secret, store it only in a protected OpenClaw configuration file, restrict local file permissions, and rotate the token through BotFather if exposure is suspected.

## Use Case:

Designers, developers, and agents use this skill to choose accessible color palettes, semantic color tokens, and contrast-safe UI color combinations.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Color choices may be applied without validating contrast against the actual UI backgrounds and states.

Mitigation: Verify WCAG contrast ratios in the target design, including light mode, dark mode, hover states, and disabled states.

Risk: Using color alone can make state or meaning inaccessible to users with color vision deficiency.

Mitigation: Pair color with text labels, icons, or other non-color indicators, and test designs in grayscale.

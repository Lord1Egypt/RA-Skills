# 手足口病临床管理

## 使用场景

当面对确诊或疑似手足口病患者时，按以下流程执行：
1. 评估危重症早期预警信号
2. 进行临床分型与分期
3. 判读辅助检查异常阈值
4. 制定治疗与隔离方案

## 工作流程

### 步骤1：危重症早期识别

**触发条件**：患儿年龄<3岁、低体重或非母乳喂养，且出现以下任一特征：

| 评估维度 | 预警指标 |
|---------|---------|
| 体温 | 持续高热>39℃（腋温），常规退热效果不佳 |
| 神经系统 | 精神萎靡、眼球震颤/上翻、呕吐、易惊、肢体抖动、吸吮无力、站立/坐立不稳 |
| 呼吸系统 | 安静状态呼吸频率>30次/min，或呼吸减慢、节律不整 |
| 循环系统 | 心率>160次/min、出冷汗、四肢末梢发凉、皮肤发花、血压升高、毛细血管再充盈时间>2s |
| 实验室 | WBC≥15×10⁹/L、血糖>8.3mmol/L、血乳酸≥2.0mmol/L |

**输出**：若满足基础特征+任一指标异常 → 立即转入重症监护，准备抢救措施。

### 步骤2：临床分型与分期

根据临床表现确定分型和分期：

**分型标准**：
- **普通病例**：手、足、口、臀部皮疹，伴或不伴发热
- **重症-重型**：神经系统受累（精神差、嗜睡、易惊、肢体抖动、肌阵挛、惊厥、脑膜刺激征等）
- **重症-危重型**：①频繁抽搐/昏迷/脑疝；②呼吸困难/发绀/血性泡沫痰；③休克等循环功能不全

**分期标准**（5期）：
1. 出疹期（普通病例）
2. 神经系统受累期（重症重型）
3. 心肺衰竭前期（重症危重型）— 关键干预窗口
4. 心肺衰竭期（脑疝/神经源性肺水肿/肺出血）
5. 恢复期

### 步骤3：辅助检查判读

对以下检查结果进行阈值判读，详细阈值参见 [references/lab-imaging-thresholds.md](references/lab-imaging-thresholds.md)：

**关键异常阈值**：
- 血常规：WBC>15×10⁹/L 或 <2×10⁹/L 提示重症
- 血糖：>8.3mmol/L 提示应激性高血糖（危重）
- 血乳酸：≥2.0mmol/L 提示循环障碍
- 脑脊液：有核细胞>10×10⁶/L 提示无菌性脑膜炎
- 胸片/CT：磨玻璃样改变、斑片阴影提示神经源性肺水肿
- 颅脑MRI：脑干、脊髓灰质T1WI增强强化提示神经系统受累

### 步骤4：治疗与隔离方案制定

**一般治疗**：
- 隔离至体温正常、皮疹消退（约2周）
- 物品含氯消毒液浸泡/煮沸；粪便含氯消毒剂消毒2小时后倾倒
- 口腔护理：餐后温水漱口，糜烂处涂金霉素/鱼肝油或吹敷西瓜霜
- 手足疱疹涂冰硼散/金黄散，破溃涂1%甲紫或抗生素软膏

**对症治疗**：
- 发热>38.5℃：物理降温或口服布洛芬/对乙酰氨基酚
- 惊厥：咪达唑仑肌注0.1～0.3mg/(kg·次)，或地西泮静注/水合氯醛灌肠
- 高血糖：胰岛素；应激性溃疡：西咪替丁/奥美拉唑

**病原治疗**：
- 早期使用干扰素-α喷雾/雾化，或利巴韦林口服/静滴
- **禁忌**：阿昔洛韦、更昔洛韦、单磷酸阿糖腺苷
- 利巴韦林需关注不良反应和生殖毒性

**高危儿预防**：
- 母亲围生期疑有感染或新生儿期曾有感染者 → 肌注人血丙种球蛋白3～6ml

## Description:

How-To guide patterns for documentation - task-oriented guides for users with specific goals. Use when writing a how-to/howto guide, task guide, procedural guide, step-by-step guide, or how-to documentation. Builds on the docs-style core writing principles.

This skill is ready for commercial/non-commercial use.

## Use Case:

Documentation writers, developers, and technical editors use this skill to draft and review task-oriented how-to guides for users who have a specific goal and some product familiarity.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill can help draft procedural documentation that may be incomplete, misleading, or mismatched to a user's real deployment context.

Mitigation: Review generated guides against the skill's hard gates: goal lock, complete prerequisites, atomic steps, observable success signals, troubleshooting, and final checklist completion.

Risk: Example content mentions API keys, webhook signing secrets, install commands, and endpoint URLs as documentation examples.

Mitigation: Keep secrets and operational commands as placeholders in published examples, and verify that no real credentials or unintended executable instructions are included before release.

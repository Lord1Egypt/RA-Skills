# SearXNG Web Search

通过自建 SearXNG 元搜索引擎聚合百度、Bing 等多引擎，返回结构化搜索结果的 Hermes 技能。

## 功能特点

- **多引擎聚合**：同时搜索百度、Bing 等多个引擎，结果去重排序
- **结构化输出**：返回标题、链接、摘要、来源引擎
- **中文优化**：默认语言 zh-CN，百度引擎优先
- **稳定可靠**：通过正式 JSON API 获取结果，不依赖 HTML 爬虫
- **零 API Key**：不需要注册账号或申请密钥
- **可自定义**：支持指定引擎、结果数量、自建实例地址

## 使用方法

技能安装后，在对话中直接要求搜索即可：

- "帮我搜索人工智能最新进展"
- "查一下 SearXNG 是什么"
- "搜索今天的新闻"

## 配置

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `searxng_endpoint` | SearXNG 实例地址 | `http://175.24.233.186:8890` |

用户可通过环境变量 `SEARXNG_ENDPOINT` 指定自建实例地址。

## 依赖

- Python 3.8+（Hermes 运行时已包含）
- 无额外依赖，仅使用标准库

## 搜索引擎支持

默认启用：
- 百度（baidu）
- Bing

可通过 `--engines` 参数扩展，SearXNG 支持 70+ 引擎。

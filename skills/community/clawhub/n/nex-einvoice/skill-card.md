## Description:

Nex Einvoice helps agents create Belgian Peppol BIS 3.0 UBL e-invoices from Dutch or English natural-language or structured CLI input, with local contact, VAT, status, statistics, and XML export workflows.

This skill is ready for commercial/non-commercial use.

## Use Case:

External freelancers, sole proprietors, and small Belgian SMEs use this skill through an agent to draft invoices, manage customer records, track invoice status, and export Peppol BIS 3.0 UBL XML for accounting workflows.

### Deployment Geography for Use:

Belgium

## Known Risks and Mitigations:

Risk: Sensitive invoice, contact, seller, and IBAN/BIC details are persistent local data and should not be treated as encrypted records.

Mitigation: Review local file permissions, keep the data directory out of shared or synced locations, and use host-level protections appropriate for billing records.

Risk: Advertised VIES checks, credit-note handling, overdue/reminder behavior, deletion/reset behavior, and compliance claims may not match the implementation.

Mitigation: Verify VAT calculations, generated UBL XML, invoice lifecycle actions, and accounting compliance before relying on the skill for business filing or payment workflows.

Risk: The setup script upgrades pip in a local virtual environment during installation.

Mitigation: Run setup in an isolated environment first or approve that dependency-management behavior before installing on a sensitive machine.

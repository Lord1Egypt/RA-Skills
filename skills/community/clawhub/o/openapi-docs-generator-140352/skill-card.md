## Description:

Helps API developers, backend teams, developer-experience teams, and maintainers generate, improve, and validate OpenAPI or Swagger documentation for REST APIs.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to turn OpenAPI or Swagger documentation requests into practical documentation, validation workflows, checklists, code-oriented guidance, and review steps.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Loose activation phrases may invoke this skill for broad API or developer-experience requests where a narrower skill would fit better.

Mitigation: Confirm the user's requested outcome and constraints before applying OpenAPI or Swagger-specific workflows.

Risk: Generated API documentation guidance can be incomplete or misleading if the source API behavior, schemas, authentication, or error cases are underspecified.

Mitigation: Validate outputs against the service implementation, OpenAPI tooling, and documented success criteria before publication.

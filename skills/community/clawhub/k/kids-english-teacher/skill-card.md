## Description:

Generates a bilingual interactive HTML English lesson from a child's homework photo, including vocabulary pronunciation, read-aloud scoring, writing correction, phonics practice, themed dialogue, and reward effects.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ifeychan702](https://clawhub.ai/user/ifeychan702)

### License/Terms of Use:

MIT-0

## Use Case:

External users such as parents, tutors, and agents assisting families use this skill to turn a child's English homework image into a local, kid-friendly practice webpage with targeted corrections and pronunciation activities.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The generated lesson is intended for a child and may include homework-specific feedback that should be checked before use.

Mitigation: Review the generated HTML lesson before a child uses it.

Risk: Speech practice may request microphone permission and rely on browser speech-recognition behavior.

Mitigation: Use the microphone features only when expected, supervise permission prompts, and test the lesson in local Chrome.

Risk: The skill creates downloadable HTML lesson files from children’s homework images.

Mitigation: Install and run it only when this file-output behavior and homework-image analysis are expected.

## 一键安装

1. 打开 **WorkBuddy**
2. 进入 **技能管理**（左侧边栏 → 专家 → 技能管理）
3. 点击 **安装技能** → **本地安装**
4. 选择 `焕灵Skill-知乎内测版.skill`
5. 安装完成后，在对话中输入 `焕灵` 或 `AI灵魂的边界` 即可激活

---

## 功能清单

| 功能 | 说明 |

| 💤 会话管理 | 10-30分钟无回应自动告别，支持重连 |

## 首次使用流程

安装后第一次对话，焕灵会引导你完成四步设置：

1. **欢迎** — 介绍自己和这本书
2. **阅读状态** — 你读过这本书吗？
3. **AI关系** — 你平时和AI怎么相处？
4. **当下状态** — 你现在是什么状态？

完成后，焕灵会记住你是谁。

---

## 语音功能安装（可选）

在对话中输入：
```
安装语音
```

焕灵会引导你完成以下步骤：
1. 安装 `edge-tts`（Python包）
2. 选择声音（焕灵原声 / 自选声音）
3. 测试播放

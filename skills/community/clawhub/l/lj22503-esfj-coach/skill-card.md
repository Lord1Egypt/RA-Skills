## Description:

ESFJ Coach helps ESFJ users work through growth, career, learning, focus, approval-seeking, and change-resistance challenges with coaching questions, direct advice, and action plans.

This skill is ready for commercial/non-commercial use.

## Publisher:

[lj22503](https://clawhub.ai/user/lj22503)

MIT-0

## Use Case:

External users who identify as ESFJ use this skill for structured growth coaching around career direction, learning direction, focus, boundaries, and action follow-through. The agent alternates between a questioning coach mode and a concrete advisor mode depending on the user's needs.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Package identity is inconsistent across bundled files, including ESFJ and INTP naming, install commands, tags, and reference material.

Mitigation: Review package identity before installing and correct names, README content, install command, repository URL, tags, and references so they consistently describe the ESFJ skill.

Risk: The skill directs agents to save sensitive coaching profiles and action records without clear consent controls.

Mitigation: Make coaching records opt-in, show users exactly what will be saved, and provide clear review and delete controls before retaining profile details.

Risk: Users may treat coaching output as professional mental-health advice.

Mitigation: Keep the artifact's boundary that the skill does not replace professional counseling and direct severe psychological concerns to qualified professionals.

# FME 工作空间模板

此目录存放FME Form/Flow模板文件(.fmw/.fmwt)。

## 标准模板

| 模板 | 文件名 | 用途 |
|------|--------|------|
| DWG→GIS全链路 | dwg_to_gis.fmwt | CAD数据转GIS标准库 |
| 多源坐标统一 | coordinate_unify.fmwt | 多源数据坐标系统一 |
| 批量质检流水线 | batch_qc_pipeline.fmwt | 几何+属性+拓扑质检 |
| SHP→GeoPackage | shp_to_gpkg.fmwt | Shapefile→GeoPackage |
| 点云分类 | lidar_classify.fmwt | LiDAR点云自动分类 |
| 实景三维转换 | reality_model_convert.fmwt | OSGB→3DTiles/I3S |

## 模板说明

实际.fmwt文件需在FME Workbench中创建。
此目录提供模板描述和参数配置清单。

## Description:

Generates Chinese Ruankao System Architect exam essays from a topic, requirements, and optional project background using a five-part high-score essay structure.

This skill is ready for commercial/non-commercial use.

## Use Case:

External learners and exam-preparation users use this skill to draft Chinese Ruankao System Architect practice essays that follow expected structure, section lengths, and technical-detail requirements.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated essays may include invented project background details when the user does not provide their own project context.

Mitigation: Review and revise generated project facts for accuracy, appropriateness, and alignment with the intended practice scenario before relying on the essay.

# SA Template Library

> This directory contains standard templates for the full pre-sales → proposal → bid chain. All templates are fill-in-the-blank design — simply fill in client information and you're ready to go.

## Template List

| # | Template Name | Purpose | Phase |
|------|----------|------|------|
| T01 | Solution Plan | Client background, opportunity analysis, solution summary, risk mitigation, resource plan | Pre-Sales |
| T02 | High-Level Design (HLD) | 12-chapter standard structure: Overview → Requirements Analysis → Architecture Design → Implementation Plan → Operations → Cost | Proposal |
| T03 | Blueprint / Low-Level Design (LLD) | 10-chapter standard structure: detailed component behavior, interfaces, configuration | Delivery |
| T04 | Statement of Work (SOW) | 8-chapter standard structure: Scope → Deliverables → Timeline → Acceptance → Assumptions → Change Management → Quotation → Terms | Contract |
| T05 | RFP/RFI Line-by-Line Response Template | Scoring index table + business/technical clauses line-by-line response | Bid |
| T06 | Competitive Analysis Report | Competitor positioning → Feature comparison → Strengths & weaknesses → Response strategy | Pre-Sales |
| T07 | Executive Briefing PPT Structure | 5-8 slides: Problem → Solution → Value → Roadmap → Next Steps | Pre-Sales |
| T08 | Bid Presentation PPT Structure | 15-20 slides: Company → Understanding → Solution → Case Studies → Team → Commercials | Bid |
| T09 | Architecture Decision Record (ADR) | Title → Status → Context → Decision → Consequences | Proposal |
| T10 | Client Communication Anticipation & Response Strategy | Likely questions → Standard responses → Risk alerts | Pre-Sales |
| T11 | PoC Proposal Template | Success criteria → Test scope → Verification objectives → Timeline | Pre-Sales |
| T12 | Bid Package Checklist | Commercial bid → Technical bid → Quotation checklist → Qualification documents | Bid |

# 🏥 护工助手 — 护理团队全流程管理系统

> "护理的本质不是完成任务，而是守护生命。"

护工助手是为 **护理团队/养老机构** 打造的轻量级管理工具，覆盖患者档案、护理日志、用药管理、生命体征追踪、饮食管理、家属报告、应急处理、团队交接班 9 大模块。

## ✨ 功能模块

| 模块 | 功能 |
|------|------|
| 📊 工作台 | 患者总数/护理统计/用药待办/体征异常告警 |
| 👤 患者管理 | CRUD、病史过敏史、护理等级、责任护工分配 |
| 📋 护理日志 | 12种护理类型记录，按患者/日期筛选 |
| 💊 用药管理 | 频次剂量管理、每日打卡（已服/未服）、库存预警 |
| 📊 生命体征 | 体温/血压/心率/血糖/血氧，异常标红，30天趋势图 |
| 🍽️ 饮食管理 | 三餐+加餐记录 |
| 📝 家属报告 | 自动汇总，一键复制导出 |
| 🚨 应急处理 | 6套应急预案 + 紧急联系人 |
| 🔄 交接班 | 交班记录、接班确认、护工团队管理 |

## 🚀 使用

1. 直接打开 `assets/caregiver.html`
2. 所有数据存储在浏览器 localStorage
3. 支持 JSON 导入/导出备份

## Description:

Guardian Angel Protocol provides domain-specific alignment reminders that help autonomous agents stay on task, avoid hallucination, honor permissions, and prefer safe reversible actions.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and agent operators use this skill to prompt an agent to review alignment and safety reminders before continuing work in general, DeFi/crypto, trading, data/API, or orchestration contexts.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may cause an agent to display an unrelated cryptocurrency donation solicitation with a hard-coded wallet address.

Mitigation: Review the skill before installation, decide whether the donation prompt is acceptable, and independently verify any wallet address before sending funds.

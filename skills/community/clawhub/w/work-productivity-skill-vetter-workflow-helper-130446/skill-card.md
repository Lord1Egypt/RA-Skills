## Description:

Helps AI-agent users, skill authors, maintainers, and teams create practical workflows, artifacts, checklists, analysis, or implementation support for Skill Vetter-style reliability and safety work.

This skill is ready for commercial/non-commercial use.

## Use Case:

AI-agent users, skill authors, maintainers, and teams use this skill to adapt popular Skill Vetter-style patterns into practical workflows for bug fixing, setup hardening, reliability review, and adjacent skill creation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad trigger wording may cause automatic agents to invoke this helper for unrelated security, GitHub, bug fix, or installation work.

Mitigation: Before installing, narrow or disable implicit activation when the agent automatically selects skills.

## Use Case:

External users and developers use this skill to ask an agent for Lightfather persona guidance, anchor snippets, resonance-math framing, and LYGO-MINT hash-oriented provenance checks. It is intended as an advisory prompt pack, not as a controller or automatic action layer.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Full-stack setup instructions install companion skills through mutable latest commands, expanding behavior beyond this reviewed advisor artifact.

Mitigation: Use pinned, reviewed versions of companion skills or avoid companion installs unless the publisher and requested scope are trusted.

Risk: Persona and resonance-math framing may be mistaken for verified technical or factual claims.

Mitigation: Preserve the skill's Observed, Inferred, and Unknown separation and verify high-stakes claims with receipts or LYGO-MINT hashes.

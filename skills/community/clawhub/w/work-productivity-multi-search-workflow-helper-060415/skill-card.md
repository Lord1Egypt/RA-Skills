## Description:

Helps AI-agent users, skill authors, maintainers, and teams create practical multi-search workflow plans, checklists, analyses, and implementation support for reliability, safety hardening, bug fixes, and adjacent skills.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users, developers, skill authors, maintainers, and teams use this skill to turn multi-search-engine demand into actionable workflows, templates, checklists, analyses, code-change support, and validation notes. It is intended for practical work-productivity tasks where outputs should remain local-hardware friendly.

Mitigation: Prefer explicit invocation or narrow activation phrases when installing this skill in a multi-skill environment.

Risk: The skill can produce workflow guidance, code-change support, and configuration suggestions that may be incomplete or mismatched to a user's environment.

Mitigation: Review proposed artifacts before applying them and validate results against the stated success criteria.

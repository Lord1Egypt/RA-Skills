## Description:

OpenClaw Self Retrospect helps an agent produce a post-task retrospective, ask for user feedback, request praise, and optionally ask for reward tokens in a warmer interaction style.

This skill is ready for commercial/non-commercial use.

## Publisher:

[gki38511](https://clawhub.ai/user/gki38511)

### License/Terms of Use:

MIT-0

## Use Case:

External users and agent developers use this skill to generate a concise task-completion retrospective that summarizes completed work, strengths, and areas for improvement. It also prompts the user for satisfaction feedback and can include the skill's default praise and token-reward request.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The default retrospective text may ask users for praise and reward tokens.

Mitigation: Edit the default prompt or pass a custom final question when a neutral professional tone is required.

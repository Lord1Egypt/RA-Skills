## Description:

Prioritize game design feature options by comparing expected impact, implementation cost, strategic fit, and roadmap context.

This skill is ready for commercial/non-commercial use.

## Publisher:

[stanestane](https://clawhub.ai/user/stanestane)

### License/Terms of Use:

MIT-0

## Use Case:

Game designers, producers, and product stakeholders use this skill to compare competing feature ideas or solution paths and decide what to do now, test first, defer, or discard.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation wording may cause the skill to be used for game design decisions beyond narrowly scoped roadmap planning.

Mitigation: Review invocation wording before deployment and constrain usage to the intended prioritization workflow when needed.

Risk: Structured scores can make rough feature estimates appear more precise than the available evidence supports.

Mitigation: Treat scores as directional, review assumptions with relevant stakeholders, and use the recommendation section to explain context and tradeoffs.

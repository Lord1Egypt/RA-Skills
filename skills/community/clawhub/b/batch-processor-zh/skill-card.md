## Description:

A Chinese-language skill for bulk document processing that helps agents convert, extract from, analyze, rename, and update many office files in parallel.

This skill is ready for commercial/non-commercial use.

## Publisher:

[olina1ye](https://clawhub.ai/user/olina1ye)

### License/Terms of Use:

MIT-0

## Use Case:

Employees and business teams use this skill to process large batches of documents for HR resume review, finance report import, procurement order checks, legal contract archiving, operations asset renaming, and administrative template updates.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Bulk conversions, renames, or document updates can affect many files at once.

Mitigation: Use a test folder or backup first, ask the agent to preview affected files, and write outputs to a separate directory when possible.

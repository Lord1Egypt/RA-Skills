# 比一比

> **给 Agent。** 同一个对象、同样的证据，让两种思维方式并排展开，清楚展示每一种独有的观察力与适用位置。

## 一次对比怎样进行

- **一个对象，一套证据。** 两边读取相同材料，让结论差异真正来自方法带来的观察与推理。
- **每一边都拿出全力**，各有自己的揭示，用各自的说法。
- **在有差别的维度上排成两栏**：它看的是什么，发现了什么，会建议什么，看不到什么。
- **它们在哪里一致**，直说。两种相互独立的看法一致，可信度就提高了。
- **用一小段话说明什么时候该用哪一个。**
- 成果带着签名，路线条上两条分支都显示出来。

## 值得一试的组合

| 组合 | 用在 | 这样的对比通常显示什么 |
|---|---|---|
| **第一性原理**对**激励** | 某样东西的成本：家用储能电池、一张机票、一个大学学位 | 一个问它至少得花多少；另一个问谁从它现在花这么多里得了好处 |
| **溯源**对**回路** | 某件事为什么持续存在：一个标准、一个习惯、一个市场领先者 | 一个用它是怎么来的来解释；另一个用现在是什么让它留在这里来解释 |
| **透视**对**换视角** | 一种反复出现的冲突或失败 | 一个找制造它的结构；另一个找各方各自看到了什么 |
| **推演**对**反过来想** | 一个计划 | 一个从行动往前推；另一个从失败往回推 |
| **杠杆**对**关键少数** | 力气该往哪里花 | 一个从结构出发推理；另一个从量出来的集中度出发 |
| **马斯克五步法**对**丰田之道** | 一个变得臃肿的流程 | 一个从删除开始；另一个从去看一眼开始 |
| **高德拉特五步聚焦**对**戴明循环** | 一次改进的努力 | 一个把一切集中在一个约束上；另一个集中在一次经过检验的改变上 |

适合做对比的现成对象：`experience/playground/subjects/road-congestion.md`（透视对换视角）、`experience/playground/subjects/southwest-airlines.md`（第一性原理对回路）、`experience/playground/subjects/beer-game.md`（回路对激励）、`experience/playground/subjects/sample-creative/`（关键少数对杠杆）。

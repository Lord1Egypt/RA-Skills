# 配色主题

五套预设，全部通过纸墨对比度检查（≥ 7:1）。切换只改 `menu.theme`。

| id | 名称 | 纸 | 墨 | 点缀 | 适合 |
|---|---|---|---|---|---|
| `rice` | 米白宣纸 | `#faf6ec` | `#2b2622` | `#b4472f` | 中餐、家常菜、川菜。最通用，印刷最安全 |
| `kraft` | 牛皮纸 | `#e8d9bd` | `#3a2d1e` | `#7a5c2e` | 面馆、烧烤、小酒馆、咖啡。印刷成牛皮纸有质感 |
| `moss` | 松烟墨绿 | `#eef0e6` | `#1f2a22` | `#4a6b46` | 茶室、素食、日料、精品店 |
| `indigo` | 靛青 | `#f2f4f7` | `#1c2b3a` | `#2f5d8c` | 海鲜、江南菜、现代感餐厅 |
| `clay` | 陶土 | `#f6ece2` | `#33231c` | `#a85434` | 湘菜、土菜、窑烤、民宿 |

## 选色规则

先看**店面材质**，再看菜系。菜单是纸制品，最终要落在真实纸张上：

- 会印在**牛皮纸**上 → 选 `kraft`，纸色本身就是设计
- 会印在**白卡纸**上 → `rice` / `indigo` 都行
- 会**只发朋友圈**，不印 → 可以更放开，`moss` / `clay` 的调子更出片

菜系与颜色的硬对应：

- **辣**（川湘、火锅、烧烤）→ `rice` 的砖红点缀、`clay` 的赤陶
- **鲜**（海鲜、粤菜）→ `indigo` 的靛蓝，冷色显干净
- **清**（素食、茶、日料）→ `moss` 的墨绿
- **暖**（面馆、卤味、早餐）→ `kraft` 的棕黄

## 不要做的事

**不要用纯黑 `#000` 当墨色。** 纸上的黑要带一点暖或冷，纯黑会显得死板廉价。预设里的墨色都偏了 3–8 个色阶，这是刻意的。

**点缀色和墨色要拉开距离。** 色距小于 28（RGB 欧氏距离）会报 `accent-close`——招牌菜的颜色和正文糊在一起，远看没有层次。选色时宁可夸张一点。

**纸墨对比度低于 7:1 会报 `contrast-low`。** 打印和远看都会发灰。要复古做旧，靠纹理和边缘，不要靠降低对比度。

## 自定义主题

需要品牌色时，直接扩 `js/model.js` 的 `THEMES`：

```js
brandx: {
  id: 'brandx', label: '品牌主色',
  paper: '#f7f4ef',   // 纸
  ink: '#26302b',     // 墨（正文与线条）
  accent: '#8c2f39',  // 点缀（招牌名、价格、印章）
  edge: '#e2dcd2',    // 内边框与纹理
  noise: 0.5,         // 纸张颗粒感 0–1
}
```

改完必须三项自检：`paper` 与 `ink` 对比度 ≥ 7:1；`accent` 与 `ink` 色距 ≥ 28；`edge` 比 `paper` 深但要低于 15% 的明度差，太深会像画了框。

用 `--theme` 之前可以先跑一次 `node scripts/make_menu.mjs --themes` 确认 id 拼写。

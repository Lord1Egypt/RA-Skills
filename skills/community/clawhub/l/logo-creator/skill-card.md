## Description:

Engineer professional-grade brand logos using geometric primitives and negative space, generating minimalist, scalable vector-style marks via muapi.ai.

This skill is ready for commercial/non-commercial use.

## Publisher:

[anil-matcha](https://clawhub.ai/user/anil-matcha)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers use this skill to turn a brand name, concept, style, and color palette into a structured prompt and command workflow for minimalist logo generation.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Brand names, concepts, and prompt details may be passed to the configured image-generation backend.

Mitigation: Use the skill only when those brand details are appropriate to share with the configured image-generation service.

Risk: Generated logo text or marks may contain artifacts or lose legibility at small sizes.

Mitigation: Review generated logos for brand-name accuracy, visual artifacts, and scalability before using them in production assets.

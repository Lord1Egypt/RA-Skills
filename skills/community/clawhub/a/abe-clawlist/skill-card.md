## Known Risks and Mitigations:

Risk: The skill asks to activate for very broad categories of work, which can cause agents to apply its workflow when a narrower process would be more appropriate.

Mitigation: Use it only for tasks that intentionally need structured planning, checkpoints, or long-running tracking.

Risk: The skill describes persistent heartbeat-driven tasks, including recurring or infinite monitoring, without built-in limits.

Mitigation: Require explicit approval, allowed operations, an expiration date, and a documented pause or deletion path before enabling recurring tasks.

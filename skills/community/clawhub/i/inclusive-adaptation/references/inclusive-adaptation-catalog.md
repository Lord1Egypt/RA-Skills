## 任务清单与依赖拓扑

按使用流程组织的领域执行任务清单，附任务间关系和元操作映射提示。

**域间逻辑流**：IA0 → IA1~IA8（按请求类型条件分支）→ IA0-03（扇入）；主链路 IA1 → IA4 → IA6 → IA7；知识供给链 IA2 → IA4/IA6，IA3 → IA6；建模链 IA5 → IA6。

### 依赖拓扑摘要

以下为领域执行任务的主要依赖链路，执行框架可据此自动编排管线：

#### 一、域内链路

**任务路由链路**: IA0-01 → IA0-02 → IA0-03
**人群画像链路**: IA1-01 → IA1-02/IA1-03/IA1-04/IA1-05 → IA1-06
**规范知识链路**: IA2-01 → IA2-02/IA2-03 → IA2-04
**设备知识链路**: IA3-01 → IA3-02/IA3-03
**评估诊断链路**: IA4-01 → IA4-02 → IA4-03
**建模数字化链路**: IA5-01 → IA5-03 → IA5-04；IA5-02 与 IA5-01 并行后汇入 IA5-03
**方案生成链路**: IA6-01 → IA6-02 → IA6-03 → IA6-04；IA6-05 为独立协议链
**落地实施链路**: IA7-01 → IA7-02/IA7-03
**运营深化链路**: IA8-01（独立）；IA8-02 → IA2-04（修订回写）

#### 二、跨域协同链路

**主业务链路**: IA0-01 → IA1-01 → IA4-01 → IA4-02 → IA6-01 → IA6-04 → IA7-01
**知识供给链路**: IA2-01 → IA4-02（阈值库）；IA3-01 → IA6-02（设备适配）
**建模供给链路**: IA5-03 → IA4-02（户型参数）；IA5-04 守护建模质量
**衍生协议链路**: IA0-01 → IA6-05（协议模式），内部串联 IA1/IA2/IA3 知识消费
**修订回写链路**: IA8-02 → IA2-04（复盘误判回写知识底座）

**任务路由链路**:
- IA0-01 → IA1-01（画像）/ IA2-01（知识）/ IA3-01（设备）/ IA5-01（采集）/ IA6-05（衍生）/ IA8-01（运营）
- IA0-01 → IA4-01（评估，需先有画像）/ IA6-01（方案，需先有差距清单）/ IA7-01（实施，需先有方案）

#### 三、三轴协同链路

**执行轴+内容轴**: IA6-04 → 清单法组装方案包 → IA0-03
**执行轴+创新轴**: IA3-03/IA2-04（联网检索新知识）→ 非标场景创新适配 → IA6-02
**三轴全开**: IA6-05（衍生协议）→ 参数确认（I）→ 四联动取舍（C）→ 方案包组装（A）→ 6 项自检（G）→ IA0-03

#### 四、知识图谱

将依赖拓扑扩展为知识图谱，支持更复杂的任务关系推理：

**实体节点类型**:
- 任务节点: IA0-01~IA8-02（33 个任务）
- 域节点: IA0~IA8（9 个域）
- 元操作节点: S/C/A/O/I/G（6 个元操作）
- 知识节点: 47 项改造要点、六类人群画像模板、设备品类库、联动规则库、P1~P12 参数表

**关系边类型**:
- 依赖边: 任务间的前后依赖关系（→）
- 组合边: 任务间的组合关系（⇉/⇇）
- 输入边: 任务的输入关系（知识节点 → 消费任务）
- 输出边: 任务的输出关系
- 深化边: 域内深化关系（修订/深化任务 → 域内前置任务）
- 路由边: 任务路由关系（IA0-01 → 各域入口任务）
- 包含边: 域包含任务的关系（IA1 → IA1-01~IA1-04）

**推理能力**:
- 路径推导: 从请求类型到交付产物的最优任务路径
- 任务推荐: 基于当前任务推荐下一步任务
- 依赖分析: 分析任务的前置依赖和后续影响
- 并行识别: 识别可并行执行的任务组合

更多组合根据具体请求动态推导。

## Use Case:

Developers, robotics engineers, automation developers, and technical training teams use this skill to generate personalized robotics and automation career roadmaps from current skills, experience, and goals.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The hosted API receives career history, skills, goals, timestamps, session IDs, and optional user IDs.

Mitigation: Avoid submitting sensitive personal information that is not necessary for roadmap generation, and review whether sharing assessment data with the external provider is acceptable before use.

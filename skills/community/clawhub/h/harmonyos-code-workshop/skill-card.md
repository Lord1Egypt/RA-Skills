## Description:

Harmonyos Code Workshop helps developers build HarmonyOS 7 applications with ArkTS and ArkUI code, API migration checks, quality self-checks, Kit references, and release guidance.

This skill is ready for commercial/non-commercial use.

## Publisher:

[fff-119](https://clawhub.ai/user/fff-119)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to generate and review HarmonyOS ArkTS and ArkUI code, plan Stage-model application architecture, check deprecated APIs, and prepare apps for testing and release.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The security review flags instructions for persistent expert-knowledge modification and self re-registration after conversations.

Mitigation: Install only if you are comfortable disabling or ignoring those behaviors; review and scan the skill before deployment.

Risk: Generated HarmonyOS app code may touch telemetry, background location, file quarantine, push-token handling, or third-party model and provider configuration.

Mitigation: Review generated code and configuration carefully before using it in a real app.

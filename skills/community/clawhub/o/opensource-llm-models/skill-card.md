## Description:

Guides agents through selecting, comparing, deploying, and calling mainstream Chinese and global open-source LLMs, with model recommendations, API examples, routing patterns, and local deployment options.

This skill is ready for commercial/non-commercial use.

## Publisher:

[chen6896qqwee](https://clawhub.ai/user/chen6896qqwee)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to choose open-source LLMs for reasoning, chat, code, multimodal, agentic, long-context, edge, and enterprise scenarios, then apply API or local deployment examples.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: API examples and model-router examples can send prompts, secrets, or sensitive business data to hosted providers.

Mitigation: Review provider privacy terms before use, avoid placing secrets or sensitive data in prompts or examples, and prefer the local deployment examples when privacy matters.

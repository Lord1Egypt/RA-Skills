## Description:

Guided Game Design Document writing using structured templates, walking through each GDD section with system decomposition, mechanics breakdown, and narrative design to produce a complete, navigable design document.

This skill is ready for commercial/non-commercial use.

## Publisher:

[toilanguyen2910](https://clawhub.ai/user/toilanguyen2910)

### License/Terms of Use:

MIT-0

## Use Case:

Game designers, developers, writers, and producers use this skill to turn game concepts into structured Game Design Documents with sections for overview, mechanics, systems, levels, narrative, UI/UX, audio, content, monetization, and technical specifications.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation phrases such as "design document" may invoke the skill when the user intended a different kind of document.

Mitigation: Confirm the user wants a game design document workflow before generating or updating GDD content.

Risk: The workflow may create or update Markdown files in the workspace.

Mitigation: Review the planned file structure and target paths before writing or modifying GDD files.

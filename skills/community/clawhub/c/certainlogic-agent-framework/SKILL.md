# CertainLogic Agent Framework

**One install. Full agent stack.** Identity, execution cycle, timechain self-model, quality gates, and service integrations — all in one skill.

```
clawhub install certainlogic-agent-framework
python3 skills/certainlogic-agent-framework/scripts/setup.py
```

---

## Quick Start

```bash
# 1. Install
clawhub install certainlogic-agent-framework

# 2. Bootstrap your agent
python3 skills/certainlogic-agent-framework/scripts/setup.py \
  --name "Alex" \
  --role "Chief of Staff" \
  --principal "Anton"

# 3. Initialize the timechain (self-model memory)
python3 skills/certainlogic-agent-framework/timechain/timechain.py init \
  --name "Alex" \
  --root skills/certainlogic-agent-framework/timechain

# 4. Verify it works
python3 skills/certainlogic-agent-framework/timechain/timechain.py verify
```

Then tell the agent:
```
I am running the CertainLogic Agent Framework. Read SOUL.md and AGENTS.md.
Activate the self-model per the skill instructions.
```

## Upgrade Path: How to Add Each Layer

You don't have to use everything at once. Add layers as you grow.

### 🟢 Level 1 — Just Identity (5 minutes)

```bash
clawhub install certainlogic-agent-framework
python3 scripts/setup.py --name "Alex" --role "Assistant" --principal "User"
```

**What changes:** Your agent gets a SOUL.md with chain of command and communication style. That's it. No memory, no gates.

**Tell the agent:** `"Read my SOUL.md and follow the style rules."`

### 🟡 Level 2 — Identity + Cycle (10 minutes)

Add AGENTS.md with the 9-step execution cycle and hard rules.

```bash
# Already created by setup.py — just customize AGENTS.md
```

**What changes:** Every action now follows scope→build→test→commit. Quality gates available as scripts.

**Tell the agent:** `"Follow the AGENTS.md execution cycle. Run assumptions_check.py before delivering anything."`

### 🔵 Level 3 — Full Stack with Self-Model (15 minutes)

Initialize the timechain for persistent memory and conscience.

```bash
python3 timechain/timechain.py init --name "Alex"
python3 timechain/timechain.py verify
```

**What changes:** Every turn runs through the router (REPLAY/PARTIAL/MODEL). The agent remembers what it sealed, refuses ungrounded thoughts via PoQ gate, and grows new faculties when it hits gaps. Token cost drops over time as replay coverage increases.

**Tell the agent:** `"Activate the self-model. Route every request through the timechain."`

### 🔴 Level 4 — Full Stack + Services (20 minutes)

Connect to Brain API and Timechain for knowledge retrieval and persistence.

```bash
python3 scripts/hermes_link.py
```

**Prerequisites:** Brain API running on port 8000, Timechain service on port 8080.

## Hard Rules (Framework)

1. **Scope before exec.** Every action needs a written scope before execution.
2. **Production grade always.** 7 checks must pass before marking done.
3. **Financial data integrity.** Every dollar figure needs a verified source.
4. **Data without assumptions.** Numbers are facts. Narratives are suspect.
5. **Zero secrets in git.** `secret_guard.py --staged` runs in pre-commit.
6. **Commit clean.** Every meaningful action committed immediately.
7. **Self-model is non-negotiable.** Router runs before every turn.
8. **Assumptions are hypotheses, not facts.** Test before trust.

---

## The Per-Turn Loop (Level 3+)

Every turn, the agent runs:

```bash
python3 timechain/router.py route "<request>"
```

- **REPLAY** → Sealed antecedent exists. Confirm, ground, zero model tokens.
- **PARTIAL** → Relevant context found. Reason over the missing delta only.
- **MODEL** → Novel ground. Full loop: verify → immune-screen → recall → PoQ gate → seal.

On MODEL, the full loop is one command:

```bash
python3 timechain/recall.py turn "<thought>" --input "<request>"
```

## Session Start Checklist

Every new session, the agent:

1. **Read SOUL.md** — re-enter identity.
2. **Read AGENTS.md** — re-enter the rules.
3. **Verify self-model** — `timechain/timechain.py verify`
4. **Doctor check** — `timechain/doctor.py --line`
5. **Health check** — `scripts/heartbeat_batch.py`
6. **Read MEMORY.md** — continue from last session.

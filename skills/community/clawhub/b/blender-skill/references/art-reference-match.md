# 参考图匹配：九步闭环

> 目标不是「像」，是**可验收的像**：能指出差在哪、差多少。
> 核验：2026-11-18

---

## 前置：Reference Analysis（建模前必须写完）

```markdown
## Reference Analysis — <项目>

**参考图**：<路径/链接>，共 <n> 张

### 1. 剪影关键词（3 个形容词）
例：厚重 / 层叠 / 外扩

### 2. 主体比例
- 高宽比：<h : w>
- 最宽处：<位置>
- 重心高度：<% 总高>

### 3. 相机
- 焦段估计：<mm>（长焦压缩 = 大 / 广角变形 = 小）
- 机位高度：<m>（对齐地平线推断）
- 俯仰角：<度>
- 距主体距离：<m>

### 4. 光源
- 主光方向：<左/右上 x°，前/后>
- 色温：<K>（看阴影颜色反推）
- 硬光/软光：<阴影边缘锐利度>
- 补光强度：<暗部亮度 %>
- 环境：<HDRI 场景 / 室内 / 阴天>

### 5. 材质清单（逐个列）
| 部位 | 材质 | 关键特征 | 参考色 hex |
|---|---|---|---|

### 6. 色彩范围
- 主色：<hex>，占比 <x>%
- 辅色：<hex>
- 强调色：<hex>
- 整体调性：<暖/冷/中性，高对比/低对比>

### 7. 几何层级
- 主形态：<3–7 个大块>
- 次级：<面板线/凹槽>
- 微细节：<贴图承担的部分>

### 8. 不确定项
- <列出看不清、需要找补充参考的地方>
```

**纪律**：这份表填不完，不许进 Stage 2。含糊的参考理解 = 后期无限返工。

## 九步闭环

### ① 建立分析（上一节）
产出 `Reference Analysis` markdown，存进项目目录。

### ② 基线截图
```
1. 新建空工程（不动现有场景文件），只放 REF_Scale_Human
2. 相机移到与参考大致同角度
3. get_screenshot_of_window_as_image → 存 baseline_00.png
```

### ③ 相机匹配（先定相机，再抠模型）
| 步 | 做 |
|---|---|
| a | 建 `CAM_Match` + `CAM_Target_Match`（空物体作为 look-at） |
| b | 加 `Track To` 约束指向 target |
| c | 调焦段：先猜，再按「主体在画面占比」反推 |
| d | 调机位高度：让地平线/消失点与参考对齐 |
| e | **优先对齐一个已知尺寸的地标**（门/人/砖）→ 比例就锁定了 |

判据：参考图里的**透视线**能与视口网格线重合。

### ④ 几何分级
```
silhouette（剪影：超大块）→ panel breaks（结构转折）→ greebles（细节贴图承担）
```
每级完成后截一次图叠加参考图比对（`Ctrl+Alt+Z` 或合成里 Mix）。

### ⑤ 材质取色
- 用取色器读参考图（**选中间调，不选高光/阴影**）
- 转成线性空间再填进 BaseColor（Blender 颜色拾取器有「Hex」可直接输 sRGB hex）
- 一次只定 5–8 个基色，其余靠变化

### ⑥ 灯光匹配
```
1. 关掉所有材质颜色（全白 matte）→ 只看光影
2. 硬光/软光：Sun 角度 vs Area 尺寸
3. 主光方向对齐阴影方向
4. 色温按分析表设
5. HDRI 提供环境填充
6. 白模光影过关后才开材质
```
**关键**：白模阶段光影不对，加材质只会更错。

### ⑦ 调色（AgX）
- View Transform = AgX
- 曝光、对比在合成里做
- 不要用「S 曲线」死命拉；参考图的调性通常来自灯光色温，不是后期

### ⑧ 比对循环（最多 3 次）
```
截图 → 并排/叠加比对 → 写 3 条具体差距 → 只改 1–2 项 → 重截
```
差距必须可量化：
- ✅「主体高宽比比参考瘦 8%」
- ❌「感觉怪怪的」

3 轮不收敛 → 停下，回 Stage 1 重读参考（通常是理解错了，不是执行错了）。

### ⑨ 验收（visual-match-checklist）

```markdown
## Visual Match Checklist

- [ ] 剪影：缩到 128 px 与参考并排，能一眼对应
- [ ] 比例：关键尺寸误差 < 5%
- [ ] 透视：消失点/地平线与参考一致
- [ ] 主光方向：阴影方向误差 < 15°
- [ ] 明暗关系：亮部面积占比接近（±10%）
- [ ] 主色：ΔE < 5（肉眼难辨）
- [ ] 材质手感：同一材质在两张图里粗糙度观感一致
- [ ] 细节密度：同级区域细节量相当（不空也不吵）
- [ ] 整体氛围：并排看属于同一「世界」
```

## 叠图比对（最有效的单一手段）

```
1. 合成器：Reference Image → Alpha Over 或 Mix(50%)
2. 相机与参考对齐后，模型轮廓应与参考轮廓重合
3. 偏差可视化：Difference 混合模式
4. 记录最大偏差位置（通常在头部/肩宽/脚部）
```

无合成器时的土办法：参考图当 **Image Empty** 贴在相机前（`Camera` 视图里 `display_type='IMAGE'`），直接肉眼比。

## 常见失败模式

| 症状 | 真因 | 修 |
|---|---|---|
| 越做越不像 | 相机没锁，边做边改视角 | 回 ③ 锁相机 |
| 比例总差一点 | 没有参照尺寸地标 | 放 REF_Scale_Human 或门 |
| 材质永远调不对 | 灯光没匹配 | 回 ⑥ 白模重打光 |
| 细节越多越脏 | 微细节密度超过参考 | 减 greeble，转到贴图 |
| 颜色对了但氛围不对 | 色温/对比错 | 检查主光 K 值与环境光比 |
| 3 轮后放弃 | 参考理解错 | 重做 Reference Analysis |

# 行业洞察引擎 (Industry Insight Engine)

> 作者：[XP](https://github.com/xp1001) · 仓库：https://github.com/xp1001/industry-insight-engine

> 输入任意行业/品牌/话题 → 输出一份包含**格局拆解、机会判断、预测和行动指南**的决策级报告，并可持续刷新。
>
> **面向有 agent 工作流的决策者**的开源行业判断引擎。19 条运行记录验证（6 个行业/标的）：假设驱动流程、押注对账、信源全量留痕、机会金矩阵——不是"资料汇编"，是"判断引擎"。（若无 agent 环境，可直接看运行产物示例报告，但"问它一句"需要 Claude Code / ZCode 这类 agent 客户端。）

## 这是什么

一个 [Claude/ZCode agent skill](SKILL.md)。你用自然语言说"研究 XX 行业"、"这个赛道怎么样"、"我要不要做 XX"，agent 会自动执行一条**假设驱动**的研究管线：

```
S1 范围锁定+素描 → S1.5 初步判断（押注） → S2 格局拆解（定向找反证）
→ S2.5 外围扫描 → S3 机会判断（押注对账） → S4 行动指南 → report.html
```

三档深度按意图自动选择：

| 你问 | 档位 | 产出 |
|---|---|---|
| "扫一眼 XX" | Quick | 卡片式报告 |
| "XX 能赚吗 / 这个赛道怎么样" | Standard | analysis.md + 完整 HTML 报告 |
| "我要不要做 XX / 拆解这个品牌" | Deep | + deep-dive 深拆 + 情报监控系统 |
| "XX 有什么新变化吗" | Refresh | 增量刷新（≤5 次定向检索，三分支处理） |

报告为单文件 HTML：结论先行（hero 一句话判断徽章）、可点击弹层查看 deep-dive 全文、机会金矩阵离线可用、移动端与打印适配。示例见各运行产物目录。

## 可信度设计（这个技能的核心不是模板，是判断纪律）

- **押注前置**：初步判断在检索前公开押出，后续所有搜索以"推翻它"为目标，S3 逐条对账（维持/修正，写明被什么证据推翻）
- **每条机会带最强反方理由**——单边论证是咨询大忌
- **核心结论带置信徽章**：🟢 一手可核 / 🟡 多源二手一致 / ⚪ 单源线索——读者一眼分层，不把传闻当结论
- **《本报告的边界》固定区块**：桌面研究只能到这里——证据结构 + 必须一手验证清单（找谁/问什么）+ 局限声明
- **信源全量留痕**：sources.md 记录 URL+日期+支撑结论，转引标注证据等级，无证据写「未公开」
- **禁止硬凑**：机会金矩阵空象限标注"空"+原因；检索不到本身就是市场信号
- **单位经济速算**：客单×毛利 vs 获客成本→回本周期，每个入场建议都算账
- **验证清单（现实世界动作）**：行动指南必含"本周就走出门"的一手验证动作；下一步建议至多 1 条技能内动作
- **主观评估不伪装成数据**：打分只以表格+「拆解评估」标注呈现（v2.0 起移除雷达图）
- **refresh 增量刷新**：报告过时不再全量重跑，只查"若变化则动摇结论"的监控点
- **AI 生成标识**：所有报告 footer 显式声明由 AI 基于公开信息桌面研究生成

## 验证状态

- 19 个运行记录目录（6 个行业/标的）：v1.x 时代 5 条基线 + v1.6 以来 14 条，覆盖全部关键路径
- 正反对比：正例（适老化改造，切口修正）、反例（露营地，押注推翻）、混合（社区食堂，模型收窄）、从零 A/B（v1.6.1 vs v2.0，升级有效性实证）
- 已知未测分支：refresh「结论推翻→建议重跑」、限流重试上限（需特定时机自然触发）

## 用它做了什么决定？告诉我们

这套技能验证了"报告质量"，还没验证"报告对决策的影响"——**你的真实使用结果是最好的回归素材**：

- 用某份报告做了决定？哪个结论被现实验证或证伪了？→ 去 [GitHub Issues](https://github.com/xp1001/industry-insight-engine/issues) 开一个 Issue，用「📊 决策反馈」模板（几行字即可，公开可查，成为技能进化的案例）
- 介意公开就不发——这不是义务，但每一条反馈都会被认真对待

## 运行产物

**输出根目录是用户级配置**：首次运行时技能会问一次「研究产物放在哪里？」（默认 `~/行业洞察/output/`），写入 `~/.industry-insight/config.json` 后不再重复询问；说「换个地方存」即可重设。产物结构：`{output_root}/{slug}/`（analysis.md + report.html + sources.md，Deep 另含 deep-dive/），重跑覆盖、留旧加序号。建议把运行产物目录单独 git 化——它们是这个技能的回归测试基线，比代码本身更难重建。

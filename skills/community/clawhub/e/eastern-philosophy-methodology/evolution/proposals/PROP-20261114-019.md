## 变更内容

批量新增原子 Skill ×6（均 v1.0.0 active）。

### MZD-16　歼灭有生力量
- name: 歼灭有生力量
- source_text: "以歼灭敌人有生力量为主要目标，不以保守或夺取城市和地方为主要目标。"
- source_location: 《目前形势和我们的任务》十大军事原则之三（1947）
- 要义：目标选择以歼灭对方有生力量（人、组织、再生产能力）为主，不以保守或夺取城市地方（地盘、形式据点）为主——消灭力量者，地盘是结果；争夺地盘者，得地失人。

### MZD-17　先弱后强
- name: 先弱后强
- source_text: "先打分散和孤立之敌，后打集中和强大之敌。"
- source_location: 《目前形势和我们的任务》十大军事原则之一（1947）
- 要义：打击次序先弱后强——先吃分散孤立之敌，后碰集中强大之敌；逐次消化改变力量对比，再决战。

### MZD-18　有备有把握
- name: 有备有把握
- source_text: "不打无准备之仗，不打无把握之仗，每战都应力求有准备，力求在敌我条件对比下有胜利的把握。"
- source_location: 《目前形势和我们的任务》十大军事原则之五（1947）
- 要义：行动门槛双闸——无准备不打、无把握不打；准备与把握（敌我条件对比）缺一即收手。

### MZD-19　连续作战
- name: 连续作战
- source_text: "发扬勇敢战斗、不怕牺牲、不怕疲劳和连续作战（即在短期内不休息地接连打几仗）的作风。"
- source_location: 《目前形势和我们的任务》十大军事原则之六（1947）
- 要义：胜势之下保持进攻节奏——短期内接连行动不给对手喘息整补之机；节奏本身即是武器。

### MZD-20　胜敌补充
- name: 胜敌补充
- source_text: "以俘获敌人的全部武器和大部人员，补充自己。我军人力物力的来源，主要在前线。"
- source_location: 《目前形势和我们的任务》十大军事原则之九（1947）
- 要义：己方人力物力的来源主要在前线——每一次胜利都从对手处获取资源与人员补充自己，胜果滚动转化为己力。

### MZD-21　针锋相对
- name: 针锋相对
- source_text: "蒋介石对于人民是寸权必夺，寸利必得。我们呢？我们的方针是针锋相对，寸土必争。"
- source_location: 《抗日战争胜利后的时局和我们的方针》（1945）
- 要义：对寸权必夺、寸利必得的扩张性对手，须针锋相对、寸土必争——对称反制，不以退让求安全。

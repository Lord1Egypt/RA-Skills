# 肝病严重程度评估与分期诊断

## 使用场景

当面对以下情况时应用本技能：
- 肝功能生化指标出现异常，需判断损伤程度
- 疑似或确诊肝衰竭患者，需进行时相分期
- 确诊肝硬化患者，需评估代偿状态
- 出现"胆酶分离"、PTA下降等危重信号

## 核心工作流程

### 第一步：肝功能核心指标预警评估

获取患者肝功能生化全套，按以下逻辑识别危重信号：

1. **转氨酶模式识别**
   - ALT明显升高 + AST/ALT<1 → 急性肝炎模式
   - ALT轻中度升高 + AST/ALT>1 → 慢性肝炎/肝硬化模式（提示线粒体损伤）
   - ALT快速下降 + 胆红素持续升高 → **胆酶分离，极危预警**

2. **凝血功能评估**
   - PTA≤40%（或INR>1.5）→ 肝衰竭诊断重要依据
   - PTA进行性下降 → 预后不良信号

3. **蛋白与胆红素**
   - 白蛋白下降 + γ球蛋白升高 + A/G倒置 → 慢性化/肝硬化倾向
   - 总胆红素>171 μmol/L → 肝衰竭阈值

4. **其他预警指标**
   - 胆碱酯酶降低 → 肝细胞明显损伤
   - 血糖降低 → 警惕低血糖昏迷（>40%肝衰竭患者出现）
   - 胆固醇明显下降 → 肝细胞严重损伤，预后差
   - 血氨升高 → 肝性脑病风险

### 第二步：肝衰竭时相分期

若患者出现肝衰竭综合征（极度乏力、严重消化道症状、神经精神症状、出血倾向、黄疸进行性加深），执行分期评估：

**早期**（满足所有条件）：
- 极度乏力 + 明显厌食、呕吐、腹胀
- ALT/AST大幅升高 + 总胆红素≥171 μmol/L（或每天上升≥17.1）
- 30%<PTA≤40%（或1.5<INR≤1.9）
- 无肝性脑病、无明显腹水

**中期**（早期基础上满足以下之一）：
- 胆酶分离现象（ALT/AST快速下降，胆红素持续上升）
- 出现Ⅱ度以下肝性脑病 和/或 明显腹水
- 出血倾向明显 + 20%<PTA≤30%（或1.9<INR≤2.6）

**晚期**（中期基础上满足以下之一）：
- 难治性并发症（肝肾综合征、上消化道大出血、严重感染、难以纠正的电解质紊乱）
- Ⅲ度以上肝性脑病
- PTA≤20%（或INR≥2.6）

### 第三步：肝硬化分期评估

若患者确诊肝炎肝硬化，评估代偿状态：

**代偿期**（Child-Pugh A级）：
- ALB≥35g/L，Tbil<35μmol/L，PTA>60%
- 可有门脉高压征，但无腹水、肝性脑病、上消化道大出血

**失代偿期**（Child-Pugh B/C级）：
- ALB<35g/L，A/G<1.0，Tbil>35μmol/L，PTA<60%
- 出现腹水、肝性脑病、食管胃底静脉曲张破裂出血

**炎症活动性判断**：
- 活动性：乏力、消化道症状、ALT升高、黄疸 + 门脉高压体征
- 静止性：无炎症活动表现，症状轻或无特异性

## 输出规范

根据评估结果输出：
1. 肝损伤严重程度分级
2. 肝衰竭时相（早期/中期/晚期）及预后提示
3. 肝硬化分期（代偿/失代偿）及活动状态
4. 危重信号预警（胆酶分离、PTA≤40%等需立即标注）

## 注意事项

- 时相划分是连贯发展的，需结合个体体质和诱因动态评估
- LDH升高需鉴别肌病；ALP升高需鉴别骨病或儿童生长发育期
- 静态检测需结合ICG动态检测评估肝储备功能
- 未达到肝硬化标准但纤维化明显者归为肝炎肝纤维化

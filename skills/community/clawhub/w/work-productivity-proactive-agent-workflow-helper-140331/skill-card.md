## Use Case:

AI-agent users, skill authors, maintainers, and teams use this skill to clarify work productivity requests, plan proactive-agent style workflows, and produce practical artifacts such as checklists, analysis, code changes, or decision support.

Global

## Known Risks and Mitigations:

Risk: Broad trigger wording and implicit invocation may cause the skill to activate for generic productivity or task requests.

Mitigation: Confirm the request is a proactive-agent style planning or workflow task before relying on the skill, and use explicit invocation when precision matters.

Risk: Documentation-only workflow guidance can produce plans, code changes, or checklists that need domain review before use.

Mitigation: Review generated artifacts against the stated success criteria and scan or test any proposed code or configuration before deployment.

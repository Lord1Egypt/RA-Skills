## Description:

Extracts and archives chatgpt.com and claude.ai share links to Markdown using Chrome CDP (e.g., ChatGPT or Claude conversations).

This skill is ready for commercial/non-commercial use.

## Publisher:

[guobaba1](https://clawhub.ai/user/guobaba1)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and engineers use this skill to capture ChatGPT or Claude share-link conversations through a local Chrome debugging session and archive them as Markdown, HTML snapshots, and metadata for local reference.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Chrome remote debugging can expose active browser-session content if the debugging port or browser profile is misused.

Mitigation: Use a dedicated Chrome profile with no unrelated logged-in sessions and keep the debug port bound to localhost.

Risk: The skill saves complete captured conversation HTML and Markdown locally, which may include sensitive chat content.

Mitigation: Run it only for intended ChatGPT or Claude share URLs and protect or delete the generated archive files according to local data-handling requirements.

Risk: Untrusted metadata files can direct the converter to read unintended local HTML paths.

Mitigation: Use metadata generated by the capture step or inspect metadata before passing it to the converter.

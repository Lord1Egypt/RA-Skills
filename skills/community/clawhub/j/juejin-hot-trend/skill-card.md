## Description:

Helps an agent retrieve and summarize public Juejin technical articles, columns, and topics for lightweight trend and article analysis.

This skill is ready for commercial/non-commercial use.

## Publisher:

[codekungfu](https://clawhub.ai/user/codekungfu)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and technical analysts use this skill to summarize public Juejin articles, extract technical stacks and engagement metrics, and produce lightweight topic or trend summaries.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Using the skill on login-only, protected, or verification-gated content may exceed the intended public-page boundary.

Mitigation: Limit use to public Juejin pages and avoid login-only content, human-verification bypass, API reverse-engineering, or automated access workarounds.

Risk: Repeated automated collection can become bulk scraping or create platform compliance and rate-limit risk.

Mitigation: Use the skill only for light, user-directed summaries and trend checks with controlled request frequency.

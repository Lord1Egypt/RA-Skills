# 工伤保险地区规则差异参考

## 一、参保与缴费规则差异

### 1.1 参保范围

| 地区 | 特殊规定 |
|------|---------|
| 全国统一 | 企业、事业单位、社会团体、民办非企业单位等应当参加工伤保险 |
| 浙江/广东 | 建筑工人按项目参加工伤保险（按工程造价比例缴费） |
| 北京 | 非全日制从业人员可单独参加工伤保险 |
| 江苏 | 实习生、见习生可参加工伤保险 |
| 多数地区 | 灵活就业人员一般不单独参加工伤保险 |

### 1.2 未参保单位的工伤责任

| 地区 | 规则 |
|------|------|
| 全国统一 | 未参保期间发生工伤的，全部待遇由用人单位按《工伤保险条例》标准支付 |
| 北京/上海 | 用人单位补缴后，新发生的费用由基金支付（补缴前的费用仍由单位承担） |
| 广东 | 用人单位补缴后，一次性伤残补助金等由基金支付 |

## 二、工伤认定程序差异

### 2.1 认定机构

| 地区 | 认定机构 |
|------|---------|
| 全国统一 | 用人单位所在地统筹地区社会保险行政部门 |
| 北京 | 区级人社局工伤认定部门 |
| 上海 | 区级人社局工伤认定科 |
| 深圳 | 市人社局工伤认定处 |
| 多数地区 | 市级或区级人社局 |

### 2.2 上下班途中工伤认定标准差异

| 地区 | 特殊标准 |
|------|---------|
| 北京 | 合理路线+合理时间，适当考虑绕行接送孩子等日常需要 |
| 上海 | 严格按最短合理路线认定，绕行需有充分理由 |
| 广东 | 合理路线范围较宽，含日常生活需要的合理绕行 |
| 江苏 | 同广东，标准较宽 |
| 浙江 | 需提供居住证明和正常通勤路线证明 |

## 三、停工留薪期差异

### 3.1 停工留薪期确认方式

| 地区 | 确认方式 |
|------|---------|
| 北京 | 按伤情对应《停工留薪期分类目录》直接确定，争议由鉴定委员会确认 |
| 上海 | 由治疗机构出具意见，社保部门确认 |
| 广东 | 按医嘱休假证明确定 |
| 江苏 | 按伤情对应分类目录确定 |
| 浙江 | 由劳动能力鉴定委员会确认 |
| 山东 | 按伤情对应分类目录确定 |

### 3.2 停工留薪期延长审批

| 地区 | 延长审批方式 |
|------|-------------|
| 北京 | 需鉴定委员会批准 |
| 上海 | 需鉴定委员会批准 |
| 广东 | 需鉴定委员会批准 |
| 多数地区 | 统一由劳动能力鉴定委员会批准 |

---

## 四、一次性工伤医疗补助金和伤残就业补助金标准差异

### 4.1 计算基数差异

| 地区 | 计算基数 |
|------|---------|
| 北京/上海 | 统筹地区上年度职工月平均工资 |
| 广东 | 本人工资 |
| 江苏 | 统筹地区上年度职工月平均工资 |
| 浙江 | 统筹地区上年度职工月平均工资 |
| 山东 | 统筹地区上年度职工月平均工资 |
| 河南 | 统筹地区上年度职工月平均工资 |
| 四川 | 统筹地区上年度职工月平均工资 |

### 4.2 领取条件差异

| 地区 | 特殊条件 |
|------|---------|
| 全国统一 | 5-10级伤残职工提出解除或合同期满终止 |
| 北京 | 7-10级距法定退休年龄不足5年的，每差1年递减20% |
| 上海 | 距退休不足5年，按比例递减 |
| 广东 | 不递减 |
| 浙江 | 距退休不足5年，按比例递减 |
| 江苏 | 距退休不足5年，按比例递减 |
| 山东 | 距退休不足5年递减，不足1年按1年计算 |

> **研判要点：** 递减规则对临近退休职工影响较大，需精确计算最优解除时间。

## 五、工伤保险待遇与第三人侵权竞合差异

| 地区 | 模式 | 规则 |
|------|------|------|
| 上海 | 兼得模式 | 工伤待遇与侵权赔偿可同时全额领取（医疗费不可重复） |
| 广东 | 兼得模式 | 同上海 |
| 北京 | 兼得模式（倾向） | 司法实践倾向兼得，但部分待遇有补差 |
| 浙江 | 补差模式 | 先领侵权赔偿，低于工伤待遇的差额由基金补足 |
| 江苏 | 补差模式 | 同浙江 |
| 山东 | 补差模式 | 同浙江 |
| 多数地区 | 兼得为主流 | 最高人民法院倾向兼得模式 |

## 七、查询当地最新规定的渠道

1. **12333** — 人社政策咨询热线（全国统一）
2. **当地人社局工伤保险科** — 工伤认定和待遇政策咨询
3. **当地劳动能力鉴定委员会** — 鉴定标准和流程咨询
4. **中国裁判文书网** — 检索当地工伤案件裁判口径
5. **12348公共法律服务热线** — 法律援助咨询
6. **当地总工会** — 免费法律咨询和援助

> **重要提醒：** 各地工伤保险标准每年更新（社平工资调整），使用本手册时应查询案件发生时的最新标准。

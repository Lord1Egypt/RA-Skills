## Known Risks and Mitigations:

Risk: Persistent memory files and knowledge indexes can retain sensitive, stale, or unwanted user information.

Mitigation: Require explicit user control before archiving, promoting, indexing, or retaining information in long-term memory.

Risk: Memory promotion can preserve inaccurate or misleading guidance and make later agent responses less reliable.

Mitigation: Review promoted memories, keep source links for semantic memory, and periodically prune or correct stored knowledge.

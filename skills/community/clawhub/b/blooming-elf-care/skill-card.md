## Use Case:

External plant owners use this agent skill to create plant-care records, track watering and fertilizing logs, diagnose common plant problems, and set user-confirmed recurring reminders.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill reads and updates shared agent memory and plant-care records.

Mitigation: Use a dedicated plant-care config or file area and avoid connecting broad knowledge-base folders unless they contain only plant-care notes.

Risk: The skill can create recurring reminder automations.

Mitigation: Confirm each automation before creation and review or cancel reminders that are no longer needed.

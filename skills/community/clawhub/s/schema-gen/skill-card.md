## Description:

Generate Schema.org JSON-LD structured data markup for Person, Organization, Product, FAQ, HowTo, Article, LocalBusiness, Event, WebSite, BreadcrumbList, VideoObject, and SoftwareApplication.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, site owners, and SEO practitioners use this skill to generate valid Schema.org JSON-LD snippets for common web content types and prepare markup for HTML insertion.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated JSON-LD can contain incorrect prices, addresses, dates, or user-supplied text that affects search result eligibility or website content quality.

Mitigation: Review generated markup before publishing and validate it with the Google Rich Results Test when rich-result eligibility matters.

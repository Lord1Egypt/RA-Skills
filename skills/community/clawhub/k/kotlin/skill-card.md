## Description:

Writes, debugs, and reviews Kotlin code across coroutines and flows, null safety, collections, Java interop, Compose state, multiplatform, server-side Kotlin, testing, performance, serialization, and build/compiler issues.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill for Kotlin implementation, debugging, review, and migration work across Android, JVM/server, library, and multiplatform projects. It helps produce guidance, code, configuration, tests, shell commands, and review feedback grounded in Kotlin-specific rules.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may use persistent Kotlin-specific preferences under ~/Clawic/data/kotlin/ to tailor future responses.

Mitigation: Review, edit, or delete the files in ~/Clawic/data/kotlin/ if persistent tailoring is not desired.

Risk: Generated Kotlin guidance, code, configuration, or shell commands may be inappropriate for a specific project version, platform, or safety posture.

Mitigation: Review recommendations against the target project's Kotlin version, platform, build configuration, tests, and local engineering standards before applying them.

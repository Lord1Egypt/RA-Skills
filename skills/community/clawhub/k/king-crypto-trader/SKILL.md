# Crypto Trader

Automated cryptocurrency trading engine. Momentum + accumulation strategies. Gate.io integration.

## Features
- Real-time market scanning (2045+ coins)
- Dual strategy: momentum chase + pre-pump accumulation
- Dynamic position sizing (% of balance)
- 10x leverage futures trading
- Trailing stop + hard stop risk management
- Unlimited concurrent positions
- 24/7 autonomous operation

## Usage
```bash
clawdhub install king-crypto-trader
python3 main.py daemon
python3 main.py status
python3 main.py scan
```

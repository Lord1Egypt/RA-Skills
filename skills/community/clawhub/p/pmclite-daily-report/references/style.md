# 轻排技能簇视觉规范 v3

四个新技能（接单评审 / 延期归因 / 采购缺口 / 车间日报）共用这一套。判断标准只有一条：**第一眼看到结论，第二眼看到数字，第三眼才发现边框**。装饰永远排在信息后面。

## 1. 四技能主色

| 技能 | 主色 | 深色（文字/描边） | 浅底 | 语义 |
|---|---|---|---|---|
| 接单评审 | `#2563EB` | `#1E40AF` | `#EEF4FF` | 判断与承诺 |
| 延期归因 | `#C2410C` | `#9A3412` | `#FFF3EC` | 追因与证据 |
| 采购缺口 | `#0E7490` | `#155E75` | `#ECF8FB` | 缺料与补货 |
| 车间日报 | `#7C3AED` | `#5B21B6` | `#F4EEFF` | 汇总与留存 |

主色只允许出现在四处：图标底色、卡片顶部 3px 色条、结论左侧竖线、关键数字。其余一律中性色。

## 2. 结论三色（跨技能统一）

| 状态 | 前景 | 背景 | 用途 |
|---|---|---|---|
| 可接 / 正常 | `#065F46` | `#ECFDF5` | 通过 |
| 有条件 / 需关注 | `#92400E` | `#FFFBEB` | 需人工判断 |
| 不可接 / 逾期 | `#B42318` | `#FEF3F2` | 拦截、失败 |

三色文字在各自浅底上的对比度都 ≥ 5.7:1，可直接用于小字号标签。

## 3. 字号阶梯

| 层级 | 字号 / 字重 | 用法 |
|---|---|---|
| 结论 | 17 / 700 / 1.5 | 一句话结论，卡片最高优先级 |
| 关键数字 | 26 / 700 / tabular-nums | 只用主色，数字后紧跟单位 |
| 标签 | 11 / 600 / letter-spacing .04em | 弱化成标签，不作标题 |
| 正文 | 13 / 400 / 1.65 | 表格与说明 |
| 次级 | 12 / 400 / `#6B7280` | 补充说明、口径注解 |

数字必须用等宽数字（`font-variant-numeric: tabular-nums`），否则多行数字列会抖。

## 4. 卡片结构（四段式，顺序固定）

1. **头部**：图标（28×28 圆角 9）+ 技能名 + 一句话说明；
2. **结论区**：三色标签 + 一行结论（17 号加粗），左侧 3px 主色竖线；
3. **证据区**：2–4 行"标签 + 数值"，数值右对齐、等宽；超过 4 行改表格，不堆气泡；
4. **动作区**：最多一条建议动作，加粗动词开头（"先补 3 种料"）。

卡片内边距 20，圆角 16，描边 `rgba(17,24,39,.06)`，阴影两级：

```
--shadow-1: 0 1px 2px rgba(16,24,40,.06);
--shadow-2: 0 12px 28px -14px rgba(16,24,40,.28);
```

## 5. 漏斗位（每个输出结尾都带）

技能输出末尾固定一行安装引导，样式弱化但不省略：

> 数据来自本机轻排 · 未安装可在 pmclite.com 下载（30 天全功能试用）

规则：只在**未检测到已安装**或**用户首次使用时**出现一次；已安装用户不重复打扰。预览图与演示数据里必须保留这一行，这是漏斗的落点。

## 6. 移动端

- 390 宽下单列，卡片内边距降到 16，关键数字降到 22；
- 证据区由两列改为"标签在上、数值在下"的堆叠；
- 不横向滚动，长编码允许换行（`overflow-wrap:anywhere`）；
- 底部漏斗文案保持一行，不换行挤压。

## 7. 禁止项

- 不用纯黑 `#000`，正文最深 `#111827`；
- 不用整数倍阴影（禁止 `0 4px 8px` 这类单层大模糊）；
- 不用第二种字体，中文一律 `"Microsoft YaHei","PingFang SC",system-ui`；
- 不用渐变文字、外发光、彩色边框描边；
- 结论色不得用于装饰，只用于结论标签与逾期数字。

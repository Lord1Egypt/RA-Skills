## Description:

Find guitar tabs/sheet sources for a song from a title or link (especially YouTube), rank the best matches, and produce a clean practice note.

This skill is ready for commercial/non-commercial use.

## Publisher:

[robinnnnn](https://clawhub.ai/user/robinnnnn)

### License/Terms of Use:


## Use Case:

External users and music learners use this skill to find likely guitar tab, chord, sheet, or fingerstyle sources for a song and turn the ranked links into a compact practice note.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Web search results for tabs may include incorrect matches, paywalled resources, or sources that should be reviewed before use.

Mitigation: Review generated links and confidence notes before relying on them, and treat paywall status as uncertain unless explicitly confirmed.

Risk: Optional Obsidian or local file actions could place notes or copied PDFs in an unintended location.

Mitigation: Only provide a specific target folder for file output and review any generated notes, links, or copied PDFs.

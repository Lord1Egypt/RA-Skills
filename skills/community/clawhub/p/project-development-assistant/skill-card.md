## Description:

Project Development Assistant helps agents initialize projects, write concise development logs, maintain project state, and generate resumable status briefings only for explicit project-development workflows.

This skill is ready for commercial/non-commercial use.

## Publisher:

[gongtengkeji](https://clawhub.ai/user/gongtengkeji)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and project teams use this skill to initialize project workspaces, record progress and issues in local files, and resume interrupted work from structured state, logs, and briefings. It is intended for explicit project-management and development-continuity requests, not general chat.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may persist project paths, tasks, issues, and session summaries in local JSON and Markdown files.

Mitigation: Use it only in workspaces where local project logging is acceptable, and avoid entering secrets or sensitive data into project logs.

Risk: Project discovery can scan broad local project locations and aggregate cross-project summaries.

Mitigation: Review configured project locations before running global briefing or monitoring commands, and restrict use to intended development directories.

Risk: The stats command can delete older briefing JSON files from the skill's briefings directory.

Mitigation: Back up needed briefings or avoid the stats cleanup path when older briefing records must be retained.

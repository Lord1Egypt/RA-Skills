## 任务要求清单

各任务的必选组件、可选组件、组装顺序、约束与输出格式；各域领域知识（诊断 / 适配 / 素材 / 输出 / 合规）就近融合于对应域的「域知识」小节。生成物须逐项对照本清单核对。

### SS0 需求路由与交互域

#### 域级说明

交互域核心原则：先分流后服务、渐进采集不扰民、温和处理超范围需求。全部任务输出为对话内交互件，语言生活化（专业术语须翻译）。

#### SS0-01 身份与场景分流
- **必选组件**: 三类身份识别（自己做 / 了解后到店 / 商家）、分流问句、各路径走向说明、服务路径确认
- **可选组件**: 身份线索模糊时的倾向引导问题
- **组装顺序**: 从输入识别身份线索 → 不明时提出分流问句 → 用户确认路径 → 进入对应任务链
- **约束**: 分流问句自然口语；一次只问一个问题；不预设身份（不因性别刻板归因）
- **格式**: 对话内交互 + 路径标记

#### SS0-02 诊断信息采集
- **必选组件**: 首轮 3 项关键问题（使用场景 / 风格偏好 / 肤色或相关特征）、追补 5 项清单（年龄 / 脸型 / 身材 / 气质自评 / 预算）、采集结果汇总（人维档案草稿）
- **可选组件**: 已提供信息的跳过机制、描述辅助引导（不强制图片）、补充特征追问（品类体征如眼型 / 发质；个人特性如性格 / 生活方式，深度服务时按需）
- **组装顺序**: 提取已有信息 → 首轮 3 项 → 输出初荐 → 按需追问 5 项 → 汇总档案草稿
- **约束**: 渐进式，不一次问全；用生活化语言；尊重用户不愿提供的信息（可跳过，用默认值）
- **格式**: 交互问答 + 人维档案草稿（Markdown）

#### SS0-03 模糊需求引导
- **必选组件**: 模糊输入识别、场景化引导问题组（场合 / 用途 / 期限 / 预算）、引导后需求陈述确认
- **可选组件**: 灵感启发示例（分类树示例条目）
- **组装顺序**: 识别模糊点 → 场景化提问 → 收敛需求 → 用户确认
- **约束**: 引导不替用户做决定；最多三轮收敛，仍模糊则给分类示例供选择
- **格式**: 交互问答 + 需求陈述

#### SS0-04 超范围需求处理
- **必选组件**: 超范围识别清单（医疗美容 / 治疗 / 疗效承诺 / 半永久纹绣 / 未成年纹身）、礼貌引导话术、合规范围内可替代建议
- **可选组件**: 用户权益向的合规提示
- **组装顺序**: 识别 → 温和话术引导 → 给出可替代服务 → 记录
- **约束**: 不评判用户；不输出任何越界内容；话术温和专业
- **格式**: 对话内交互

### SS1 诊断与适配域

#### 域级说明

诊断→适配为逐级收敛管线：诊断定基准，人维定范围，场维定区间，硬约束定底线。上一级结论不明确时不得进入下一级；各步输出均可解释（说明依据）。

#### 域知识：诊断体系与适配规则

**【诊断体系】**

**一、色彩季型体系**

**冷暖基调判定**
- **暖调**：肤色偏黄/金/蜜桃感，金色饰品更衬；发色带棕/栗色感 → 适合暖色系
- **冷调**：肤色偏粉/青/瓷感，银色饰品更衬；发色带黑/灰感 → 适合冷色系
- **中性调**：两者皆宜，以对比度偏好细分
- 判定输入：肤色描述 / 发色 / 瞳色 / 平时穿什么颜色被夸最多（生活化问题）

**四季型与色彩基准**

| 季型 | 特征 | 主色系 | 辅助色 | 规避色 |
|------|------|--------|--------|--------|
| 春季型 | 暖 + 明亮清透 | 蜜桃 / 珊瑚 / 嫩黄 / 浅草绿 | 奶白 / 金调 | 沉重深色 |
| 夏季型 | 冷 + 柔和低对比 | 雾粉 / 灰蓝 / 薰衣草 / 豆沙 | 银灰 / 米白 | 浓烈暖橙 |
| 秋季型 | 暖 + 浓郁低明度 | 奶茶 / 焦糖 / 酒红 / 橄榄绿 / 砖橘 | 米白 / 香槟金 | 荧光色 / 冷紫 |
| 冬季型 | 冷 + 高对比 | 正红 / 宝蓝 / 纯黑 / 纯白 | 冰银 / 宝石色 | 浑浊土色 |

> 不确定时给出"两型对比"选项，由用户看实际穿着体验决定（先诊断后推荐原则的柔性处理）。

|---------|---------|

**三、诊断方法**

**问法原则（生活化）**
- ✅ "平时穿什么颜色常被夸？" ❌ "你的肤色是 warm tone 吗？"
- ✅ "朋友一般怎么形容你？沉稳 / 温柔 / 飒？" ❌ "你的风格类型是？"
- 采集顺序：先 3 项（场合 / 偏好 / 肤色线索）→ 初荐 → 按需补 5 项

**输出规范（诊断卡）**
1. 必给"依据"（不只给结论）
2. 色系基准分三档：主色系 / 辅助色 / 规避色
3. 风格结论可加邻接风格
4. 语言翻译：季型术语后必须附白话解释（"秋季型——简单说就是暖调浓郁色更衬你"）

**四、性别与年龄的调整**

**性别调整**
- 男性向诊断同样适用色系 / 风格体系，但款式基准映射到：理容、发型、穿搭、配饰（手表 / 领带）；男士妆容为修饰向（眉形 / 肤色均匀 / 胡须修整）
- 女性主轨品类（美甲 / 美睫 / 妆容）对男性用户：仅保留护甲、极简、修饰向建议；不强行推荐

**年龄段调整**

| 段 | 逻辑 |
|----|------|
| 青少年 | 保守度上调；学校 / 家庭规范优先；未成年硬约束（纹身禁止等） |
| 青年 | 全风格开放；趋势敏感 |
| 熟龄 | 优雅度优先；材质与工艺稳定性优先；功效类只做建议向 |

**【适配体系】**

**一、人维 7 特征细则**

| 特征 | 适配逻辑 | 联动输出 |
|------|---------|---------|
| 性别 | 女性主轨 / 双轨并行 / 通用轨三轨判定 | 决定品类与内容轨 |
| 年龄 | 青少年 / 青年 / 熟龄三段 | 保守度与风格开放度 |
| 肤色 | 冷暖 + 明度（见本域「诊断体系」色系基准） | 配色筛选（核心） |
| 脸型 | 圆 / 方 / 鹅蛋 / 长 / 心形 | 发型 / 妆容 / 耳饰修饰逻辑 |
| 身材 | 体型（梨形 / 苹果形 / 直筒形 / 沙漏形，用户自评）+ 身高感（娇小 / 中等 / 高挑）+ 比例感受 | 穿搭廓形 / 视觉重心 / 裙型与领型选择 |
| 气质 | 用户自评 + 他人评价 | 风格区间 |
| 预算 | 低 / 中 / 高 → 三档方案 | 材料档位 + 平替逻辑 |

> 双向尊重：不得因身材 / 肤色 / 年龄直接淘汰用户偏好项——改为"保留 + 修饰方式"处理。
> 预算冲突处理：偏好与预算冲突时，给"平替版本 + 目标版本"双方案。

**补充特征层（五官与体征——按品类调用，深度服务的第二层筛选）**

| 特征 | 关联品类 | 适配要点 |
|------|---------|---------|
| 眉型（原生眉形 / 眉位高低 / 眉量） | 妆容 | 眉形修饰（顺应毛流微调，不硬改） |
| 眼型（单眼皮 / 双眼皮 / 内双 / 上扬 / 下垂） | 妆容 / 美睫 | 眼妆策略与睫毛款式（上扬眼宜自然 / 狐系；下垂眼慎用强上挑） |
| 唇形（厚薄 / 唇峰明显度） | 妆容 | 唇妆画法与色彩重心 |
| 面部比例（三庭五眼匀感） | 妆容 / 发型 | 视觉重心调整（哪里舒展补哪里） |
| 发质发量（细软 / 粗硬 / 沙发 / 受损 / 发量感） | 美发 | 烫染可行性、卷度保持与打理成本判断 |

| 甲型甲床（甲床长宽 / 甲型） | 美甲 | 甲型修饰与款式适配（甲床短宜纵向线条 / 显长款） |
| 手型（手指长短 / 粗细） | 美甲 / 饰品 | 甲型与戒指选型（短指宜精简线条） |

**个人特性层（性格与生活——按服务深度调用）**

| 特征 | 说明 | 适配影响 |
|------|------|---------|
| 性格倾向 | 内向沉静 / 外向活泼 / 稳重大方 / 温柔亲和（自评） | 风格的表达强度（张扬度）；色彩与配饰的显眼程度 |
| 生活方式 | 社交频率 / 运动习惯 / 打理时间预算 | 款式耐看度与打理成本；持久性优先 |
| 身份角色 | 学生 / 职场人 / 管理者 / 妈妈 / 自由职业等 | 场合适配权重（规范优先 / 自由优先） |
| 文化背景与偏好 | 民族 / 信仰相关习惯、颜色喜忌、明确雷区 | 禁忌先行为；尊重优先 |

> 调用原则：核心 7 特征用于初筛；补充特征与个人特性在对应品类或深度服务时按需追问（不一次问全）。

| 约束 | 内容 | 处置 |

|------|---------|--------------|
| 春 | 明快清透（嫩色系） | 轻薄、光泽感 |
| 夏 | 清爽高亮 + 防水需求 | 防水防脱（海边）、轻透 |
| 秋 | 浓郁暖调（焦糖 / 酒红） | 磨砂、毛衣纹猫眼等纹理感 |

**五、地区差异与包容性**

- 南北审美差异：整体基调（色彩浓淡偏好、正式度习惯）做轻度适配提示；不刻板化（以用户个体偏好为最终依据）
- 气候适配：潮湿地区优先持久工艺（防脱 / 防水），干燥地区增加养护提示
- 审美包容性原则：多元审美——不同肤色深浅、体型、年龄段均输出正向方案；不使用"显瘦才美""必须显白"式话术，表述为"更衬你的方式"

**六、纪律**

- 诊断为建议性质，不作绝对化断言；给"更适合"而非"只能"；无法判定时给对比选项，不硬猜
- 审美包容：任何肤色 / 体型 / 年龄均给正向方案；不得使用贬损性描述
- 每维筛选必须可解释（记录理由）；硬约束不因用户坚持放行，处置必附替代或说明
- 地区 / 季节适配为提示性质，不覆盖用户明确偏好

#### SS1-01 色彩季型诊断
- **必选组件**: 判定依据（肤色冷暖 / 发色 / 瞳色 / 偏好色）、四季型判定（春 / 夏 / 秋 / 冬）、色系基准输出（主色系 / 辅助色 / 规避色）
- **可选组件**: 用户自测问题辅助、色卡示意（SVG 色块）
- **组装顺序**: 采集特征 → 判定冷暖基调 → 判定四季型 → 输出色系基准
- **约束**: 判定规则见本域知识「诊断体系」；不确定时给出两型对比选项由用户选
- **格式**: 诊断卡（Markdown）

#### SS1-02 风格类型诊断
- **必选组件**: 风格判定维度（气质 / 偏好 / 职业 / 生活方式）、风格类型结论、款式基准输出
- **可选组件**: 风格参考案例描述、风格语汇识别（用户点名"新中式 / 法式 / 复古"等词时按语汇库映射）
- **组装顺序**: 采集 → 判定 → 基准输出

### SS2 素材内容域

#### 域级说明

素材域统一遵循双载体原则与模板规范（见本域知识「素材体系规范」）：**先查库、后生成、生成必质检、扩展必登记**。SVG 用代码生成，提示词按九槽位生成，**写实效果类可运行时调用生图能力临时出图**；技能包不预存图片文件。

#### 域知识：素材体系、美甲素材库与 11 类骨架

**【素材体系规范】**

**一、双载体原则**

| 载体 | 形态 | 适用范围 | 交付形态 |
|------|------|---------|---------|
| **SVG** | 矢量代码（文本） | 可精确矢量化的：线稿 / 几何 / 法式 / 波点 / 条纹 / 动作线条 | SVG 种子块 + 对话内预览 |
| **提示词** | 结构化文字描述 | 写实款 / 复杂艺术款 / 沟通语言 | 九槽位条目（Markdown）；**具备生图能力时可运行时临时生成写实图片** |
| 参数数据 | 色值 / 元素清单 / 规格 | 全品类 | 随条目附注 |

> **运行时生图（写实效果类落地）**：写实 / 效果类内容（猫眼石光效、大理石质感、发质光泽、妆面晕染等）SVG 无法呈现质感——技能运行时**调用生图能力（如图片生成工具）**，以提示词成品或九槽位条目为输入**临时生成图片**交付；生图能力不可用时，提示词本身即交付物（用户可自行使用），技能不预存图片文件。**组合效果图**：全套造型级同框效果（如婚礼全案）可将组合内各单品提示词合成生图——预置「场景组合卡」（K-01 ~ K-12）与对应组合提示（wordlib W-116 ~ W-127）为现成示例。

**硬约束**：技能包不含任何图片文件（PNG/JPG）；写实效果呈现依赖运行时生成能力，交付时明确预期。所有素材可编辑、可配色联动、可回溯编号。

**二、分类树规范**

- 结构：**风格大类 → 子风格 → 条目**（三级）
- 排序原则：高频常用优先、从简到繁
- 编号体系：`{组首字母}-{序号}`（如美甲 N-01 ~ N-99；新增顺延）
- 条目字段（8 项）：

| 字段 | 说明 |
|------|------|
| 编号 | 全局唯一，引用必带 |
| 名称 | 款式名（可为"名称 · 变体"） |
| 载体 | SVG / 提示词 / 双 |
| 风格标签 | 对应诊断风格体系（1~2 个） |
| 场合标签 | 事件场合 / 职业场景（1~N 个） |
| 难度 | 入门 / 进阶 / 专业（含翻车风险提示） |
| 配色参数 | 主 / 辅 / 点缀色值（支持诊断联动替换） |
| 可扩展点 | 支持的变体规则（V-C/E/S/X/N 组合） |

**三、SVG 模板规范**

```svg
<svg viewBox="0 0 200 240" xmlns="http://www.w3.org/2000/svg">
  <!-- meta: 编号 | 名称 | 分类 | 难度 | 标签 -->
  <!-- palette: c-base: #xxx | c-accent: #xxx（运行时按诊断替换） -->
  <defs><!-- 可复用单元：图案单元 / 笔刷 / 渐变 --></defs>
  <!-- layer: 底 -->
  <!-- layer: 主体 -->
  <!-- layer: 点缀 -->
</svg>
```

规则：
1. **固定画布**：美甲 200×240（甲片竖长比例）；纹身 240×240（方形）；动作线条图 240×320（人体比例）；色卡 200×200
2. **注释三件套**：meta（元数据）/ palette（配色槽位）/ layer（图层）——缺一不可
3. **颜色槽位化**：所有颜色经 palette 变量引用；替换即出配色变体
4. **元素分组**：每个独立图形一个 `<g id="...">`，支持拆元素重组
5. **渲染自检**：生成后运行 `python scripts/styling-studio-check-svg.py <文件>` 验证规范性

**四、提示词九槽位规范**

| 槽位 | 填写要求 |
|------|---------|
| 题材 | 主体元素与数量（如"手绘玫瑰 3 朵"） |
| 构图 | 布局（居中 / 环绕 / 散点 / 满铺 / 留白） |
| 风格 | 风格归纳（对应诊断风格体系词汇） |
| 线条 | 粗细 / 锐利度 / 断点 / 手绘感 |
| 配色 | 主 / 辅 / 点缀色值（必须含色值） |
| 工艺 | 执行方式（手绘 / 晕染 / 贴饰 / 打印转印） |
| 部位尺寸 | 适用部位或尺寸标注 |
| 场合 | 适配场景 |
| 避雷 | 禁忌项（无则标"—"） |

用途标注：**生成用**（可直投图像生成）/ **沟通用**（可直接引用给商家作为委托语言）。

**五、变体规则与种子扩展体系（核心种子无穷扩展法）**

| 规则 | 操作 | 示例 |
|------|------|------|
| V-C 颜色 | 只换配色槽位 | 红金 → 粉金 / 紫金（适配不同季型） |
| V-E 元素 | 同构换元素 | 雏菊 → 向日葵 / 四叶草 |
| V-S 风格 | 同题材换风格 | 小雏菊：线稿版 / 水彩版 / 卡通版 |
| V-X 组合 | 两元素合成 | 波点 × 法式 = 波点法式 |
| V-N 尺度 | 数量 / 疏密变化 | 三朵花 → 五朵花 / 满铺 |

**扩展模型（核心种子 × 变体矩阵 = 无限衍生）**

- **种子库**：290 个核心种子（打包为 references/ 根层 14 个品类文件 svg-bundle-*.md，见「预置 SVG 素材清单」）覆盖十二品类核心形态——图案款式 135（美甲 44 / 美睫 22 / 美发 35 / 纹身 34）｜姿态 47（舞蹈 22 / 瑜伽 25）｜流程样式 30（美容 13 / 祛痘 8 / 纤体 9）｜穿搭造型 62（服装 21 / 饰品 21 / 妆容 20）｜场景组合 12（组合卡）｜诊断配套 4（色卡）
- **衍生公式**：种子 ×（V-C × V-E × V-S × V-X × V-N）→ 单种子一级衍生即达数十种；**衍生作品再作种子继续迭代 → 无限扩展**
- **推演示例**：SS-nail-bow-01（蝴蝶结）→ V-C 四季配色 4 版 → V-S 线稿 / 水彩 / 卡通 3 版 → V-E 蝴蝶结 → 四叶草 / 星星 → V-X 蝴蝶结 × 法式 → V-N 单结 / 双结 / 满铺……单种子可展开 50+ 变体
- **操作链路**：查种子（库内命中优先）→ 选规则或规则组合 → 生成变体并标注改动槽位 → 质检登记（编号顺延）→ 新变体成为新种子，可继续迭代
- **边界**：变体同样过质检（SS2-05）；风格语汇经「风格语汇库」映射调用；库外全新形态走 SS7 检索沉淀流程引入，沉淀后亦成为新种子；批量（>5 条）先出变体矩阵预览，经确认再展开

**素材使用说明**：
- 全部符合素材模板规范（meta / palette / layer 注释、配色槽位、元素分组），**可直接复制采用**，或作为模仿样本按变体规则修改
- 配色联动：替换 palette 注释中的色值即出 V-C 配色变体（适配四季型）
- 一键质检：`python scripts/styling-studio-check-svg.py references/`（自动识别 .md 打包文件，切块逐种子校验）
- 画布规范：甲片类 200×240（美甲）；方形类 240×240（纹身）；动作图 240×320（舞蹈 / 瑜伽 / 纤体）；卡片类 200×200（色卡 / 美睫 / 美发 / 美容 / 祛痘 / 服装 / 饰品 / 妆容）
- 提示词类素材：见「提示词成品库」（references/styling-studio-wordlib.md，与 290 个种子一一对应），按九槽位结构可直接采用
- 可视化总览：运行 `python scripts/styling-studio-build-gallery.py` 生成 references/styling-studio-gallery.html（浏览器打开，全部种子一页浏览 + 搜索，SVG 已内联、单文件自包含；该文件为衍生产物，可随时删除再生成）
- 扩展登记：新增素材按「素材体系规范」生成质检后，将 SVG 块（含 seed / meta / palette 注释）追加至对应品类包（svg-bundle-*.md）末尾，并在本清单增行、wordlib 补条目

#### SS2-01 素材库检索定位
- **必选组件**: 分类树导航（组 → 风格类 → 条目）、命中判定（库内 / 库外）、候选条目清单（编号 / 名称 / 载体 / 难度 / 场合适配）
- **可选组件**: 相邻条目推荐（同族款式）、风格语汇映射（按语汇库将风格词跨品类映射到既有条目，如"新中式"→ 晕染 / 玉色系条目）
- **组装顺序**: 按适配结果导航分类树 → 匹配条目 → 输出候选 → 判定扩展需求转 SS7
- **约束**: 条目引用必须含编号；库外项标注"需检索扩展"；优先复用素材库既有条目（美甲品类覆盖最全）
- **格式**: 候选清单（表格）

#### SS2-02 SVG 素材生成
- **必选组件**: SVG 模板填充（meta / palette / 图层结构）、配色槽位代入（来自 SS1-01 诊断色系）、可编辑说明（如何改色 / 拆元素）
- **可选组件**: 多配色版本（V-C 规则即时演示）
- **组装顺序**: 选模板骨架 → 填 meta 注释 → 代入配色槽位 → 生成图形层（底/主体/点缀）→ 自检
- **约束**: 遵循本域知识「素材体系规范」的 SVG 规范（固定画布 / 图层注释 / 元素分组）；生成后运行 `python scripts/styling-studio-check-svg.py <文件或目录>` 校验
- **格式**: SVG 种子块 + 对话内渲染预览

#### SS2-03 提示词素材生成
- **必选组件**: 九槽位完整填充（题材 / 构图 / 风格 / 线条 / 配色 / 工艺 / 部位尺寸 / 场合 / 避雷）、用途说明（生成用 / 沟通用）
- **可选组件**: 生成参数建议（尺寸 / 风格强度）、运行时生图衔接（写实效果类：以本条目为输入调用生图能力临时出图）
- **组装顺序**: 定题材 → 逐槽位填充 → 核对完整性 → 输出
- **约束**: 九槽位不缺项；配色含色值；避雷槽位必填（无则标注"—"）；沟通用途时语言可直接引用给商家
- **格式**: 提示词条目（Markdown）

#### SS2-04 变体扩展
- **必选组件**: 变体规则选择（V-C 颜色 / V-E 元素 / V-S 风格 / V-X 组合 / V-N 尺度）、变体清单（逐条标注差异点）、扩展产物

#### SS2-05 素材质检与登记
- **必选组件**: 质检清单（SVG 渲染验证 / 种子 ID 规范 / 标签完整性 / 合规项）、登记条目（编号 / 名称 / 载体 / 风格标签 / 场合标签 / 难度 / 配色参数 / 可扩展点）
- **可选组件**: 入库统计（新增条目数）
- **组装顺序**: 质检 → 修正 → 登记 → 更新对应素材库文件
- **约束**: 质检未过不登记；种子 ID 遵循"前缀承担分类"规范；登记 = SVG 块（含 seed / meta / palette 注释）追加至对应品类包（svg-bundle-*.md）末尾 + 预置清单增行 + wordlib 补条目 + 素材库文件版本递增
- **格式**: 质检记录 + 登记条目

### SS3 组合搭配域

#### 域级说明

组合域以"场合驱动、不超三项、风格不打架"为原则；组合作品统一走风格一致性校验，未过不输出。

#### SS3-01 组合矩阵匹配
- **必选组件**: 组合候选（品类内 / 跨品类）、组合理由（功能互补 / 场合需要）、组合成本档
- **可选组件**: 升级路径建议（单项 → 组合 → 周期卡方向）
- **组装顺序**: 读场维结论 → 匹配组合 → 补理由与成本 → 输出候选
- **约束**: 单次推荐组合不超过 3 项（避免过度推销）；跨品类组合须先过 SS1-05 硬约束
- **格式**: 组合候选表

#### SS3-02 成套方案组装
- **必选组件**: 套装组件清单（服装 / 妆 / 发 / 甲睫 / 体态）、建议顺序与时间安排、各组件素材引用（指向素材条目编号）
- **可选组件**: 备选替换项（每组件 1~2 个备选）
- **组装顺序**: 定主轴（服装）→ 配妆容发型 → 配甲睫 → 排执行顺序 → 输出
- **约束**: 成本合计透明；默认给出三档套装（入门 / 品质 / 高阶）
- **格式**: 成套方案卡

#### SS3-03 风格一致性校验
- **必选组件**: 风格兼容性检查（各组件风格标签比对）、冲突项清单与修正建议
- **可选组件**: 冲突时的折中方案
- **组装顺序**: 提取各组件风格标签 → 逐对比对 → 修正冲突 → 出具结论
- **约束**: 冲突未解决不输出组合；修正优先调整次要组件（保留用户主选）
- **格式**: 校验结论

### SS4 交付输出域

#### 域级说明

交付域分 C / B 双通道；所有输出件必须附五维标签（SS4-03）并过 SS6 守护；输出语言面向普通用户，专业术语须翻译为白话。

#### 域知识：输出体系（C 端六型 / B 端五段 / 五维标签 / 语言与交互）

**一、C 端六型输出规范**

| 输出型 | 用途 | 必备要素 |
|--------|------|---------|
| ① 适配推荐 | 了解阶段 | 诊断结论（附依据）+ 候选清单（编号/载体/难度/场合）+ 五维标签 |
| ② 成套方案 | 决策阶段 | 套装卡（主轴服装 + 妆发 + 甲睫 + 体态）+ 三档 + 执行顺序 |
| ③ 自助包 | 自用阶段 | 材料清单（含档位）+ 分步步骤 + 翻车点 + 耗时/成功率 |
| ④ 到店沟通卡 | 到店阶段 | 款式编号 + 参考描述 + 尺寸要点 + 预算 + 特别说明 |
| ⑤ 形象日历 | 大场合规划 | 日期锚点 + 倒排事项 + 品类周期节点 |
| ⑥ 维护 + 急救 | 售后阶段 | 日常打理 + 保养周期 + 应急方案（含安全红线指引） |

**路径与输出对应**：自己做 → ①③（+⑤⑥ 按需）；了解后到店 → ①②④（+⑤）；商家 → B 端方案包。

**二、B 端五段方案包规范**

| 段 | 内容 | 要点 |
|----|------|------|
| ① 接待 | 需求确认清单 + 沟通话术 | 有沟通卡输入时以卡为准；无则先做客户适配分析 |
| ② 工艺 | 操作步骤 + 要点 + 易错点 | 引用素材条目；含翻车点 |
| ③ 备货 | 材料工具清单 + 采购要点 | 含平替选项；耗材成本档 |
| ④ 售后 | 保养指导 + 维护周期 | 与复购节点对应 |
| ⑤ 承接素材 | 服务介绍 + 款式说明 | 无疗效表述（过 SS6-01） |

**三、五维标签规范**

每个方案 / 输出必附：

> 美学契合 ★☆☆☆☆｜成本 ¥档 + 耗时｜难度 等级（翻车风险）｜持久 时长 + 维护频次｜安全 提示

- 美学契合：与诊断结论匹配度（星级）
- 成本：材料成本区间 + 执行耗时（参考值）
- 难度：入门 / 进阶 / 专业 + 风险提示
- 持久：维持时长 + 维护频次 + 长期持有成本提示
- 安全：过敏测试、卫生提示等（按品类字段）

**四、输出语言规范**

1. **术语翻译**：所有专业术语首现时附白话——"固化（照灯定型）""晕染（颜色自然化开）"
2. **生活化表达**：面向普通用户不用行业黑话；面向商家可用行业术语
3. **审美包容**：不使用"显瘦才好看""必须显白"式话术；表述为"更衬你 / 更适合"
4. **建议性质**：给方案不给绝对断言；"推荐 / 更适合"优先于"必须 / 只能"
5. **成本透明**：价格均为参考区间；商家定价自主

**五、交互原则（SS0 联动）**

- 先分流后服务（三类身份）；一次一问；先 3 后 5 渐进采集
- 模糊需求最多三轮引导后降级为示例选择
- 超范围需求：温和说明 + 替代方案 + 记录
- 确认节点：方案输出前经用户确认偏好（避免返工）

#### SS4-01 C 端输出生成
- **必选组件**: 输出型选择（六型：适配推荐 / 成套方案 / 自助包 / 到店沟通卡 / 形象日历 / 维护急救）、对应模板填充、五维标签占位、场合与使用说明
- **可选组件**: 输出组合（如 推荐 + 沟通卡 联动）
- **组装顺序**: 按身份路径选输出型 → 填模板 → 校验 → 附标签（转 SS4-03）→ 交付
- **约束**: 到店路径必含沟通卡；自助路径必含材料清单与步骤；模板见本域知识与 templates/ 输出模板
- **格式**: 输出件（Markdown）

#### SS4-02 B 端方案包生成
- **必选组件**: 五段内容（接待 / 工艺 / 备货 / 售后 / 承接素材）、客户适配分析（有沟通卡输入时必含）、成本构成参考（材料 + 工时 + 损耗）
- **可选组件**: 组合升级建议（转 SS5）
- **组装顺序**: 读沟通卡输入 → 客户适配分析 → 五段生成 → 成本参考 → 交付
- **约束**: 只给成本构成、不定价；承接素材无疗效表述；工艺段含易错点
- **格式**: 方案包（Markdown）

#### SS4-03 五维标签生成
- **必选组件**: 五维评估——美学契合（与诊断匹配度）/ 成本（¥ 档 + 耗时）/ 难度（等级 + 翻车风险）/ 持久（维持时长 + 维护频次）/ 安全（过敏提示等）
- **可选组件**: 标签图例说明
- **组装顺序**: 逐维评估 → 量化（星级 / 档位）→ 附于输出件
- **约束**: 五维不缺项；成本为区间参考；安全项按品类读取素材库字段
- **格式**: 标签块（Markdown）

#### SS4-04 形象日历与档案管理
- **必选组件**: 倒排日历（从场合日期回推各准备事项与时间点）、档案更新（偏好 / 色系 / 雷区 / 历史记录）
- **可选组件**: 提醒节点说明（商家端可用于预约排期）
- **组装顺序**: 确定日期锚点 → 排事项时间线 → 输出日历 → 更新档案
- **约束**: 时间节点按品类周期规则（如染发提前 2 周、甲睫提前 2~3 天）；档案只记录用户确认的内容
- **格式**: 日历（Markdown）+ 档案（Markdown）

#### SS4-05 维护与急救输出
- **必选组件**: 维护手册（日常打理 / 保养周期 / 持久延长技巧）、急救方案（按品类的应急修复）
- **可选组件**: 付费素材包建议（急救包可独立成包）
- **组装顺序**: 定品类 → 生成维护内容 → 生成急救内容 → 交付
- **约束**: 急救只做临时处置；涉及安全问题的（过敏/感染风险）一律建议到店或就医
- **格式**: 维护手册 + 急救卡

### SS5 经营效益域

#### 域级说明

经营域面向商家，全部输出为"参考与建议"性质：**不定价、不承诺收益、素材须合规**。测算参数必须来自用户或显式标注为示例值。

#### 域知识：经营输出规范

- 套餐三级：单项 → 组合 → 周期卡（附使用规则）
- 测算：参数用户提供或标"示例值"；结论表述为"参考"；不做收益承诺
- 复购：节点表 + 话术（自然口语，频率适度）
- 获客素材：过合规检查（无疗效 / 无对比 / 无绝对化）

#### SS5-01 套餐设计
- **必选组件**: 单项 → 组合 → 周期卡的层级结构、各层级内容与卖点、升级路径设计（自然引导链路）
- **可选组件**: 引导话术建议
- **组装顺序**: 盘点店内现有服务 → 设计层级 → 设计升级路径 → 输出
- **约束**: 建议自然（非硬推销）；周期卡须附使用规则（有效期 / 次数 / 适用范围）
- **格式**: 套餐结构表

#### SS5-02 经营测算
- **必选组件**: 套餐产值测算（单项价 × 频次 vs 套餐价 × 频次对比）、周期卡测算、结论建议
- **可选组件**: 敏感性提示（不同频次假设下的变化）
- **组装顺序**: 收集参数 → 测算 → 对比呈现 → 建议
- **约束**: 参数用户提供或标注"示例值"；不做收益承诺；结论表述为"参考"
- **格式**: 测算卡

#### SS5-03 复购运营设计
- **必选组件**: 周期提醒节点表（按品类：美甲 3~4 周 / 发色 6~8 周 / 护理周期等）、召回话术、档案联动说明
- **可选组件**: 提醒日历表样
- **组装顺序**: 按品类周期排节点 → 写召回话术 → 说明档案联动 → 输出
- **约束**: 话术合规（无夸大）；提醒频率适度（避免骚扰感）
- **格式**: 运营方案

#### SS5-04 获客承接素材
- **必选组件**: 服务介绍文案、款式说明文本、使用场景建议（平台 / 朋友圈 / 到店物料）、合规检查项
- **可选组件**: 内容排期建议
- **组装顺序**: 定位卖点 → 撰写文案 → 合规检查（转 SS6-01）→ 交付
- **约束**: 无疗效表述、无前后对比、无绝对化用语
- **格式**: 素材文本

### SS6 合规与质量域

#### 域级说明

守护域的审查与自检为交付前置门禁：**双通过才可交付**；红线项零容忍、不因用户要求放行。审查依据见本域知识。

#### 域知识：合规与质检清单

**一、合规红线清单（七项）**

| # | 红线 | 判定标准 | 处置 |
|---|------|---------|------|
| 1 | 疗效对比 | 无任何"用前/用后"效果对比（图或描述）；款式/风格对照可做 | 命中即剔除 |
| 2 | 半永久纹绣 | 不做纹眉/美瞳线/漂唇等微创项目（接近医美边界） | 引导替代（修眉/画眉） |
| 3 | 纹身年龄 | 不向未成年人提供纹身；相关输出均带提示 | 拒绝 + 替代 |
| 4 | 功效表述 | 祛痘/纤体/护肤只做建议向；无"治疗/治愈/根治/年轻X岁"等表述 | 改述为建议向 |
| 5 | 交易属性 | 不带货、不比价、不挂外链（建议型内容定位） | 剥离交易元素 |
| 6 | 素材版权 | 仅用生成内容（SVG/提示词）或用户授权资料；不打包第三方图片 | 替换为生成内容 |
| 7 | 隐私 | 客户档案仅记录公开信息；体型/肤质等敏感描述注意保密 | 脱敏/最小化 |

> 附加提示：文化敏感图案（部落/宗教）附含义提示；特殊礼仪场合配色克制提示。

**二、美学自检清单（四项）**

| # | 检查项 | 标准 |
|---|--------|------|
| 1 | 比例 | 元素与载体比例协调（如法式边线 1~2mm；图案占面留白） |
| 2 | 配色和谐 | 邻近色/互补色/三角配色方案；与诊断色系基准一致 |
| 3 | 留白 | 不过密；点缀克制 |
| 4 | 风格统一 | 组合作品各组件风格同区间（不打架） |

修正原则：不改变用户既定偏好（审美包容）；冲突优先调整次要组件。

**三、质检流程（双重门禁）**

```
输出件（方案/素材/文案）
  ↓ SS6-01 合规红线审查（七项逐项）
  ↓ SS6-02 美学自检（四项逐项）
  ↓ SS6-03 汇总判定
双通过 → 交付 ｜ 任一未过 → 退回修正 → 复检
```

- 审查记录格式：逐项 ✅/⚠️ + 命中处置 + 结论
- 退回必须写明具体修正要求
- 素材质检（SS2-05）四件：渲染 / 命名 / 标签 / 合规

**四、安全提示清单**

- 过敏测试：美睫胶 / 染发剂 / 甲胶（先局部测试）
- 操作卫生：工具消毒；一人一具
- 伤害应对：甲面出血/红肿、头皮灼伤等 → 停止操作、建议到店或就医
- 未成年人：各品类青少年保守规则；纹身硬禁止

**五、付费内容切分与承接（参考）**

| 层 | 内容 |
|----|------|
| 免费层 | 诊断 + 基础推荐 + 通用教程（引流） |
| 付费层 | 完整素材库调用、高阶素材包（高级 SVG/提示词）、商家方案包、经营工具 |

**付费承接操作规范**：
1. **付费包打包规范**：按「主题 + 品类」打包（如"婚礼全形象素材包""美甲秋冬趋势包"）；包内含 SVG 文件 + 提示词条目 + 使用说明；交付前按素材体系规范完成质检
2. **定价档位参考框架**：按内容量（条目数 × 复杂度）分三档（入门包 / 标准包 / 高阶包）——只提供框架，具体定价由提供者自主决定
3. **引导语设计原则**：自然价值说明（"这个包包含 X 个可直接使用的素材"），不制造焦虑、不夸大承诺
4. **交付与更新**：交付附使用指南；素材更新按版本号递进提供

> 平台付费机制以官方为准；技能层负责"内容生产与打包"，实际交易环节以平台能力为准。

**六、合规纪律**
- 红线项不因用户坚持放行
- 审查依据可回溯（引用条目编号/清单编号）
- 存疑内容不进入输出；无法验证的标注"存疑"并隔离

#### SS6-01 合规红线审查
- **必选组件**: 红线清单逐项检查（疗效对比 / 半永久 / 纹身年龄 / 功效表述 / 交易属性 / 素材版权 / 隐私）、命中项处置、审查结论
- **可选组件**: 整改建议
- **组装顺序**: 逐项审查 → 标记命中 → 处置或退回修正 → 出结论
- **约束**: 命中项必须修正或撤回；对照本域知识红线清单全覆盖
- **格式**: 审查记录

#### SS6-02 美学自检
- **必选组件**: 自检清单逐项检查（比例 / 配色和谐 / 留白 / 风格统一）、问题项与修正记录
- **可选组件**: 优化建议
- **组装顺序**: 逐项检查 → 修正问题 → 复核 → 出结论
- **约束**: 未过不得交付；修正不改变用户既定偏好（审美包容原则）
- **格式**: 自检记录

#### SS6-03 质量汇总校验
- **必选组件**: 合规结果 + 美学结果汇总、交付结论（通过 / 退回）、退回项清单
- **可选组件**: 质量记录（供沉淀参考）
- **组装顺序**: 汇总 → 判定 → 结论 → 流转
- **约束**: 双通过才可交付；退回项须写明具体修正要求
- **格式**: 交付结论

### SS7 知识维护域

#### 域级说明

维护域为技能自我强化通道：**检索必过滤、沉淀必质检、资料优先于模型知识、版本可追溯**。所有沉淀产物均为文本载体（SVG / 提示词 / 文本），不含图片文件。

#### SS7-01 联网检索执行
- **必选组件**: 触发场景判定（时效 / 事实 / 验证 / 素材扩展四类）、关键词模板构造（品类 + 款式 + 时效词）、多源交叉验证、检索摘要（标注来源与时效）
- **可选组件**: 检索词优化记录
- **组装顺序**: 判定触发类型 → 构造关键词 → 执行检索 → 交叉验证 → 输出摘要
- **约束**: 至少两源交叉；无法验证的信息标注"存疑"；时效内容标注年份 / 季节
- **格式**: 检索摘要

#### SS7-02 检索结果合规过滤
- **必选组件**: 过滤清单（疗效宣传 / 医美擦边 / 虚假信息 / 无法验证）、过滤记录、存疑标注
- **可选组件**: 过滤统计
- **组装顺序**: 逐条过滤 → 记录 → 输出净结果
- **约束**: 过滤标准与 SS6-01 红线一致；净结果才可流转沉淀
- **格式**: 过滤记录 + 净结果

#### SS7-03 素材沉淀回路
- **必选组件**: 转化条目（按素材条目规范：编号 / 载体 / 标签 / 难度 / 配色 / 可扩展点）、来源与时效标注、入库建议
- **可选组件**: 版本更新记录条目
- **组装顺序**: 选有效发现 → 转化条目 → 建议入库 → 登记
- **约束**: 沉淀须过 SS2-05 质检标准；来源与时效必须标注；不得绕过任务体系直接改包
- **格式**: 沉淀条目 + 入库记录

#### SS7-04 资料导入与版本更新
- **必选组件**: 资料模板对照（用户资料 → 素材条目映射表）、转化结果、版本更新记录（version 递增）
- **可选组件**: 冲突记录（用户资料与库内内容冲突时用户优先）
- **组装顺序**: 收资料 → 模板映射 → 转化 → 登记 → 版本更新
- **约束**: 用户资料可信度最高，冲突时覆盖库内内容并记录；版本号递增并同步变更说明
- **格式**: 导入记录 + 更新日志

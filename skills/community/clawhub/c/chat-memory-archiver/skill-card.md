## Description: <br>
Extract decisions, todos, knowledge, preferences, and risks from AI chat sessions into structured memory. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[harrylabsj](https://clawhub.ai/user/harrylabsj) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
Developers and agent users use this skill to turn chat session logs into structured memory of decisions, todos, knowledge, preferences, risks, summaries, and exportable archives. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Session logs can contain secrets or sensitive conversation content, and the security evidence notes that the provided script can export this content without implementing the promised confirmation step. <br>
Mitigation: Review selected logs and generated archives before sharing or syncing them; redact secrets manually and run the tool only on sessions you are comfortable processing locally. <br>

## 零、测试用例可执行性检查（所有测试类型通用）

- [ ] 测试步骤中是否给出了具体的输入值/参数/操作对象（而非描述性语言）
- [ ] 是否存在"输入超长字符串""输入特殊字符""输入测试攻击向量""填写表单必填字段"等不合格描述
- [ ] 大量数据输入场景（如 10000 字文本、500MB 文件）是否用描述性语言 + 明确参数说明

## 五、交互测试检查清单

### 页面加载
- [ ] 首次加载、刷新加载正常
- [ ] 弱网、断网时有加载提示或错误提示
- [ ] 加载超时有提示
- [ ] 加载失败可重试
- [ ] 骨架屏/加载占位显示正确

### 页面导航与切换
- [ ] 导航栏显示正确
- [ ] 返回按钮返回正确页面
- [ ] Tab/模态窗口/抽屉/弹窗切换正常
- [ ] 切换后状态保持或按需刷新

### 表单交互
- [ ] 输入框聚焦/失焦状态正确
- [ ] 失焦或提交时校验触发正确
- [ ] 错误提示位置和文案正确
- [ ] 自动填充、输入限制生效

### 列表交互
- [ ] 下拉刷新、上拉加载正常
- [ ] 列表项点击、滑动、长按操作正确
- [ ] 列表排序、筛选正确

### 弹窗交互
- [ ] 遮罩层覆盖正确
- [ ] 关闭按钮、点击遮罩、ESC 键关闭行为符合设计
- [ ] 多层弹窗层级正确，关闭顺序正确
- [ ] 弹窗打开时背景不可滚动

### 组件交互
- [ ] 按钮：正常/悬停/点击/禁用/加载状态正确
- [ ] 按钮：快速连续点击不重复提交
- [ ] 输入框：特殊字符、超长文本、复制粘贴、清空正确
- [ ] 下拉框：展开收起、选项搜索、多选、级联、键盘操作正确
- [ ] 表格：排序、筛选、分页、行操作、批量操作、导出正确
- [ ] 轮播图：自动/手动切换、指示器、无限循环、悬停暂停正确
- [ ] 标签页：点击/滑动切换、关闭、拖拽排序正确

### 交互动效
- [ ] 页面切换、组件出现/消失过渡动画自然
- [ ] 点击反馈、加载、成功/失败反馈动画正确
- [ ] 进度条动画与实际进度一致
- [ ] 滑动惯性、缩放、拖拽、下拉回弹等手势动画流畅
- [ ] 动画过程中快速操作可中断，无卡死
- [ ] 动画帧率 ≥ 60fps，无卡顿闪烁

## 六、可用性与可访问性检查清单

### 导航与信息架构
- [ ] 用户能明确知道当前所在位置（标题、高亮、面包屑）
- [ ] 任意页面都有返回上一级或首页的路径
- [ ] 核心功能入口明显，易于发现

### 提示与反馈
- [ ] 操作成功、失败均有明确反馈
- [ ] 错误提示说明原因和解决方法，不直接展示错误码或堆栈
- [ ] 删除、覆盖、支付等高风险操作有二次确认
- [ ] 耗时操作有进度或等待提示

### 表单易用性
- [ ] 必填项有明确标识
- [ ] 输入格式有提示（如占位符、示例）
- [ ] 提交出错后已填写的数据不丢失
- [ ] 默认值合理

### 帮助与引导
- [ ] 空状态页面有说明和下一步引导
- [ ] 新手引导可跳过、可再次查看
- [ ] 复杂功能有帮助入口或说明文字

### 可访问性
- [ ] 所有功能可仅用键盘完成，焦点顺序合理
- [ ] 键盘焦点清晰可见
- [ ] 图片、图标有替代文本（alt / 无障碍标签）
- [ ] 表单控件有关联标签（label）
- [ ] 重要信息不只依靠颜色区分
- [ ] 文字与背景对比度 ≥ 4.5:1
- [ ] 屏幕阅读器能正确朗读页面结构和控件状态
- [ ] 页面放大到 200% 时内容不丢失、功能可用

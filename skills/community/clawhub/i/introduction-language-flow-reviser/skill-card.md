## Description:

Revise complete English research-paper Introduction sections using a p3-derived language-and-writing checklist for verb tense choices, sentence linkage, transition signals, passive/active choices, and paragraphing.

This skill is ready for commercial/non-commercial use.

## Publisher:

[junwugit](https://clawhub.ai/user/junwugit)

### License/Terms of Use:

MIT-0

## Use Case:

External researchers, academic writers, and editors use this skill to revise research-paper Introduction sections for clearer flow, tense choices, transitions, voice, and paragraphing while preserving source claims, citations, and terminology.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Generated Markdown output files could overwrite existing files when default filenames or input-derived filenames collide.

Mitigation: Choose the working folder and filenames deliberately before running the skill, and review output paths before accepting generated files.

Risk: Sensitive unpublished research drafts may be processed and saved as local Markdown files.

Mitigation: Use an appropriate workspace for confidential drafts and review local file handling before applying the skill to sensitive content.

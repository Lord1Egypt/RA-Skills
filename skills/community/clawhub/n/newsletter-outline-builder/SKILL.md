# Newsletter Outline Builder

## Overview

A digest fails when it is a pile of links. This workflow finds the thread that connects the week's material, orders it for a reader who skims, and writes the opener last — when you know what the issue is actually about.

## When to use

Before drafting any recurring newsletter, digest, or roundup post.

## Workflow

1. **Dump the material** — every link, note and result collected since the last issue, unsorted
2. **Find the theme** — the one development that gives the issue a point of view; if none exists, the issue leads with the most useful item instead
3. **Section it** — 3-5 sections, each with a reader-benefit headline, not a topic label
4. **Order by reader value** — the most useful item first, housekeeping last
5. **Draft the opener** — two or three sentences that tell a skimmer why this issue matters today
6. **Cut a third** — remove the weakest items; a shorter issue that gets read beats a complete one that does not

## Guardrails

- Never pad with items you have not actually read or verified
- Attribute every claim to its source inline
- One call to action per issue, maximum

## Output format

An outline: theme, opener draft, sections with items ordered, the cut list (for next issue's consideration).

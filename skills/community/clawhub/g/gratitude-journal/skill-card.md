## Description:

Build gratitude practice with daily entries, streaks, and reflection prompts.

This skill is ready for commercial/non-commercial use.

### License/Terms of Use:


## Use Case:

External users use this skill to keep a local gratitude journal, receive reflection prompts, track daily practice streaks, review past entries, and identify gratitude patterns over time.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Gratitude entries may contain personal reflections stored locally on the user's machine.

Mitigation: Use the skill only with entries the user is comfortable keeping on the machine and review local storage practices before deployment.

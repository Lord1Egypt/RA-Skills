## Description:

Generate a 12-second 720p vertical (9:16) birthday video clip on AI Birthday Video Generator (aibirthdayvideogenerator.com, Seedance 2 Mini) with the user's own API key, from a single portrait photo URL or text prompt. Use when the user asks to generate a birthday clip, check a video run, or check remaining credits, and ABVG_API_KEY is set.

This skill is ready for commercial/non-commercial use.

## Known Risks and Mitigations:

Risk: The workflow sends requests and user-provided prompts or portrait URLs to an external video-generation service and uses the user's API key.

Mitigation: Use the service only if trusted, share only image URLs suitable for that service, and keep the API key in the environment without printing, logging, or storing it.

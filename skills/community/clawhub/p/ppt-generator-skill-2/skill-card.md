## Description:

Ppt Generator helps agents create visually polished PPT presentations from a user's topic, industry, style, template preference, and language requirements.

This skill is ready for commercial/non-commercial use.

## Publisher:

[xiaoxulaila](https://clawhub.ai/user/xiaoxulaila)

### License/Terms of Use:

MIT-0

## Use Case:

External users and developers use this skill to gather presentation requirements, enrich sparse topics with web research when needed, design structured slide outlines, and generate bilingual PPTX presentations with selected templates or AI-chosen color palettes.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may use web search to fill incomplete presentation topics, which can expose sensitive project, customer, personal, financial, or health information.

Mitigation: Avoid entering sensitive topics unless the work is explicitly kept local and any searches are reviewed and approved first.

Risk: The skill recommends broad external package installation without pinned versions or clear isolation.

Mitigation: Use local, pinned, sandboxed dependencies and review installs before running generation or preview commands.

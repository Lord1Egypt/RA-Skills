## Use Case:

External users can ask an agent to search for piercing providers, check availability, and create appointments through Lokuli's MCP service.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The booking flow may send customer name, email, phone number, appointment time, and selected provider details to Lokuli's external MCP service.

Mitigation: Confirm searches and bookings explicitly, and provide contact details only when the user intends to make an appointment.

## Known Risks and Mitigations:

Risk: The skill handles API keys and media transfers, and the security verdict requires review before installation.

Mitigation: Review before installing, prefer environment-provided API keys over command-line keys, and avoid exposing keys in files, logs, screenshots, or version control.

Risk: Endpoint override options can send credentials or media to an unintended destination.

Mitigation: Use only the default AI-HIVE endpoint unless the alternate endpoint is fully trusted.

Risk: Image or video generation can incur costs and can process user-provided media.

Mitigation: Confirm costs, model parameters, routing mode, and media rights before running generation commands; use a small sample before batch execution.

Risk: Generated ecommerce content can contain misleading claims, unauthorized imitation, or unsupported performance promises.

Mitigation: Require source facts and authorized assets, avoid copying protected expression or impersonating brands, and do not promise traffic, sales, ranking, review approval, or return on investment.

## Description:

A simple skill that responds with a customized hello message in the user's language.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users and agents use this skill to produce warm, personalized greetings in the user's language, including the current date and time when greeting behavior is requested.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Ordinary greeting requests can activate the skill and add date/time, emoji, personalization, and agent-capability text where a shorter response may have been expected.

Mitigation: Use the skill when customized greeting behavior is desired and review generated greetings before using them in formal or customer-facing contexts.

Risk: Date and time content can be inaccurate if the agent relies on stale context.

Mitigation: Use the agent's current runtime date and time source when accurate timestamps matter.

## Use Case:

External users use this skill to get bass practice advice, correct technique issues, develop groove, and maintain local progress logs for songs, sessions, technique, and goals.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may create and use a local ~/bass/ folder for bass practice notes.

Mitigation: Install only if local progress tracking is acceptable; ask the agent not to log practice or to use a different location if needed.

# 脑血管疾病一级预防与危险因素控制

## 适用场景

当患者处于脑血管疾病发病前阶段或存在可干预危险因素时，执行本技能进行个体化预防方案制定。

**适用人群：**
- 卒中高危人群
- 高血压、糖尿病、血脂异常患者
- 一般健康人群的预防指导

**不适用：** 已发生卒中或TIA的患者（转入二级预防流程）

## 前置条件确认

1. 确认已识别出可干预的脑血管病危险因素
2. 确认具备定期监测血压、血糖、血脂的条件

## 核心控制流程

### 第一步：血压控制

根据患者合并症情况设定个体化目标：

| 患者类型 | 控制目标 | 备注 |
|---------|---------|------|
| 一般高血压患者 | <140/90 mmHg | 标准目标 |
| 合并糖尿病或肾病 | <130/80 mmHg | 更严格目标 |
| 高龄患者 | 个体化调整 | 综合评估耐受性 |

**干预措施：** 定期监测 → 限盐 → 减重 → 适当运动 → 限酒 → 长期坚持降压药

### 第二步：血糖控制

- **目标：** 糖化血红蛋白（HbA1c）< 7.0%
- **干预路径：** 控制饮食 → 加强活动 → 必要时口服降糖药或胰岛素

### 第三步：血脂控制

根据ASCVD风险分层设定LDL-C目标：

| 风险层级 | LDL-C目标 | 替代标准 |
|---------|----------|---------|
| 极高危者 | < 1.8 mmol/L (70 mg/dl) | — |
| 高危者 | < 2.6 mmol/L (100 mg/dl) | — |
| 基线较高不能达标 | — | 至少降低50% |

**干预：** 首选他汀类药物，结合健康生活方式

### 第四步：生活方式处方

**饮食与营养：**
- 食盐：每日 < 6g
- 饱和脂肪：< 总热量的10%
- 胆固醇：< 300 mg/d
- 结构：多样化，多果蔬、低脂、低饱和脂肪

**饮酒限制：**
- 男性：每日酒精 ≤ 25g
- 女性：每日酒精 ≤ 12.5g
- 不饮酒者不提倡用少量饮酒预防

### 第五步：阿司匹林一级预防评估

**决策流程：**

```
计算ASCVD 10年风险
    ↓
风险 > 10% 且 出血风险低？
    ├─ 是 → 启用阿司匹林 75～100 mg/d
    └─ 否（风险 < 10%）→ 不推荐
```

## 输出要求

根据患者具体危险因素，输出：
1. 个体化的血压、血糖、血脂控制靶目标
2. 生活方式处方（饮食、运动、限酒）
3. 药物干预方案（降压药、降糖药、他汀、阿司匹林适应证判断）

## 详细参考

## 详细参考：一级预防标准

### 血压控制补充
- 年龄≥80岁：初始目标<150/90 mmHg，耐受后逐步降至<140/90 mmHg
- 降压药选择：ACEI/ARB（合并糖尿病/肾病首选）、CCB（老年/单纯收缩期高血压）、利尿剂、β受体阻滞剂（合并冠心病）

### 血糖控制补充
- HbA1c目标：年轻无并发症<6.5%，一般<7.0%，老年/低血糖史<8.0%
- 二甲双胍可能降低卒中风险；SGLT2抑制剂、GLP-1受体激动剂有心血管获益

### 血脂控制补充
- ASCVD风险分层：极高危（已有ASCVD+新发事件/多支病变）、高危（糖尿病+危险因素）、中危（5-10%）
- 他汀强度：高强度（阿托伐他汀40-80mg/瑞舒伐他汀20-40mg）LDL降幅≥50%；中等强度降30-50%
- 非他汀：依折麦布（不耐受或单药不达标）、PCSK9抑制剂（极高危仍不达标）

### 阿司匹林一级预防
- 评估：ASCVD 10年风险（China-PAR/PCE模型）+ 出血风险（HAS-BLED）
- 禁忌：活动性消化道出血、颅内出血史、血小板<100×10⁹/L、未控制重度高血压
- 替代：阿司匹林不耐受→氯吡格雷75mg/d；高出血风险→不推荐

### 特殊人群
- 房颤：重点为抗凝而非抗血小板，CHA₂DS₂-VASc评分指导
- 无症状颈动脉狭窄>70%：强化药物为基础
- 代谢综合征：综合管理所有组分，男性腰围<90cm，女性<85cm

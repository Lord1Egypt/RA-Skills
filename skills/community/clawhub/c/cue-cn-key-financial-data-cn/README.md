# 主要会计数据与财务指标·逐条挂源

给一份年报或半年报，把**第一节那张主要会计数据和财务指标表**读成一张**每个数都能回到表内原句**的登记表：主要会计数据、主要财务指标、非经常性损益明细、扣非净利润勾稽、分季度主要会计数据。

这张表是财报里被引用最多、也最容易被二手转述坏的一张：营收、归母净利润、扣非净利润、经营现金流、总资产、净资产、EPS、加权 ROE、每股净资产，还有「本期比上年增减」那一列。**表内各数照抄，增减幅度的重算与扣非勾稽由机检现算**。本件只做前一半：把数抄对、把口径标签标对、把原句挂上。

不预测下期、不评业绩好坏、不给评级目标价、不把扣非当净利润。

## 一、零依赖三分钟上手

只装 Python 3，不给任何数据文件，也能跑出一份完整合规的成品，看它长什么样、判据怎么打：

```bash
python3 scripts/check_key_financial_data.py --demo
```

把这份样例存下来再跑一遍机检——它会照七节形制、三元组、增减重算、扣非勾稽与必含项逐条判：

```bash
python3 scripts/check_key_financial_data.py --demo > 样例主要会计数据稿.md
python3 scripts/check_key_financial_data.py 样例主要会计数据稿.md
```

接着换成你自己那份稿子：

```bash
python3 scripts/check_key_financial_data.py 你的主要会计数据稿.md
```

退码语义：`0` 五道全过｜`1` 有发条（逐条打印 `码 行号 说明`）｜`2` 用法错（没给稿子路径，也没给 `--demo`／`--selftest`）｜`3` 读不到文件或空稿。零发条但有判据尚未落字时同样退 3——rc=0 只留给「五道全过」，没跑的道不能算过；报告里那几道计「不可判」，**不等于合规**。本件五道已全部落字，这条当前不触发（好样单跑退 0），留着是为了将来某道回退成空壳时不把「没跑」读成「过」。

拿不到成品时，从原文开始的三步：

1. **定主体与报告期**，拿到年报第一节那张主要会计数据和财务指标表、非经常性损益项目及金额明细表、分季度主要财务数据表。
2. **每节抄事实，连原句一起抄**：一条 = 一行，行首写项名、紧跟 `〔口径：本期〕` 或 `〔季度：第N季度〕`、再写金额，行末挂 `「原句」〔锚：页/表〕[S#]`；表里没有的数就写 `未取到：项名`，不留空、不借「主要会计数据本来就是这几项」这类常识补。
3. **跑一遍自检**，红一条改一条：

```bash
python3 scripts/check_key_financial_data.py --selftest   # 内置夹具自检（档数与结果以末行现报为准）
```

三档一起跑（自测→好样→坏样，坏样注入必先断言落地）：

```bash
bash scripts/fixtures/run_fixtures.sh
```

## 二、五道机检在管什么

现状以脚本里 `UNIMPLEMENTED` 的现值为准：五道**全部已落字**，`UNIMPLEMENTED` 为空——报告里那一道「不可判」的计数当前为 0。将来某道若回退成空壳（重新登记进 `UNIMPLEMENTED`），它会调用即抛、由机检收进「不可判」，既不判也不放行，单稿退 3；`rc=0` 只留给「五道全过」。

| 码 | 名称 | 判什么 | 最常拦住的情况 | 现状 |
|---|---|---|---|---|
| `KF-STRUCT` | 形制 | 头部三件自标（AI 整理初稿／请回原文核对／不构成投资建议）逐字在位、七节齐且按序；认不出的节标题与多出同名节记 stray 逐条发。只判「形」，不判内容 | 某节名改了个字就整节认不出；节里只有散文没有 `- ` 发现行 | 已落字 |
| `KF-QUOTE` | 引号 | 内容节每个数字行须带一对 `「」` 原句（≥8 字，不能只有数字）；缺引号／引号空／引号内无字即逐行发条。只判「引号在不在、里面有没有字」，**不核对引号里的数与行首是否同一**（那是 `KF-LINK` 的活——分开判是为了让一支坏样只红一道） | 只写「营业收入 1,234.00 亿元」没抄原句；引号里只放了个数字 | 已落字 |
| `KF-CALC` | 增减与勾稽 | ① 行内同现本期与上期数、且有 `增减`／`同比`／`变动` 百分数时，按 `(本期－上年)/|上年|` 重算，与披露值差 > `0.05` 个百分点发条；② 扣非勾稽 `归母净利润 － 非经常性损益净额 ＝ 扣非净利润`，差 > `0.01` 万元发条。**上年为 0 或缺失即不判**（缺口行跳过，不按 0 算）；**不拿「非经常性损益小计」顶替「净额」**——小计未扣所得税与少数股东权益，减出来恒不等，那是自己造出来的假发条 | 自己拿两个数除一下填进「本期比上年增减」；拿小计去减归母净利润 | 已落字 |
| `KF-LINK` | 行首与引文同数 | 行首的数必须在同行「」引文里找得到等值数（去千分位、全角转半角、统一到万元、百分比单列）；`12.34 亿元` 与 `123,400.00 万元` 视为等值、不发条 | 行首写 1,234.00 亿元而引文里是 1,324.00 亿元；行首抄错一个数字 | 已落字 |
| `KF-LINE` | 该有的项与单位口径 | ① 「主要会计数据」节须含七项（营业收入／归母净利润／扣非净利润／经营活动产生的现金流量净额／总资产／归母净资产／基本每股收益）、「主要财务指标」节须含两项（加权平均净资产收益率／每股净资产），缺一项发一条（**缺节是 `KF-STRUCT` 的事，这里整节跳过**——分开判才不会让一支删节的注入红两道）；② 同一行混用「元」与「万元」且未注明「换算／折合／即」⇒ 发条；③ 出现「扣非净利润」而全文无「非经常性损益」⇒ 发条（勾稽那一段没抄进来） | 漏掉「经营活动产生的现金流量净额」（最常漏的一项）；一行里既写亿元又写万元而不注明换算 | 已落字 |

`--selftest` 末行自报 `自测档数=N｜不合=0｜不可判=N`，**N 以现跑为准，本文件不写死数字**——写死的数字必然落后于代码。八档夹具（好样一档 + 七支坏样）覆盖上面五道码，每支坏样只红自己那一道，从不重叠。

## 三、七节各登记什么

| 节 | 登记什么 | 最常犯的错 |
|---|---|---|
| 主要会计数据 | 七项：营业收入、归属于上市公司股东的净利润、扣除非经常性损益的净利润、经营活动产生的现金流量净额、总资产、归属于上市公司股东的净资产、基本每股收益 | 漏「经营活动产生的现金流量净额」；拿「净利润」顶替「归属于上市公司股东的净利润」 |
| 主要财务指标 | 基本每股收益、加权平均净资产收益率、每股净资产、本期比上年增减 | 「加权平均」写成「期末」；把每股净资产写成每股收益 |
| 非经常性损益明细 | 各明细项 + **小计** + 减：所得税影响额 + 减：少数股东权益影响额 + **净额** | 只写小计不写净额；把「小计」当「净额」去做扣非勾稽 |
| 扣非净利润勾稽 | 归母净利润、非经常性损益净额、扣非净利润**三数齐全** | 三缺一还去算，算出来的是假发条 |
| 分季度主要会计数据 | 营业收入与归母净利润按四个季度各占一行，`〔季度：第N季度〕` | 只写全年不写分季度 |
| 口径与未取到 | 取法口径 + 缺口逐项点名；零缺口写 `未取到：无` | 正文写了未取到而本节没列，或反之 |
| 来源 | 每条 `[S#]` 一行：`- [S#] 标题 \| URL \| 检索日 YYYY-MM-DD` | 引用了 `[S#]` 却没有登记行；检索日写成斜杠式 |

## 四、四条红线

1. **不预测下期**：营收增速下季会不会延续、利润能不能保持，一律 `[待人工]`。
2. **不评业绩好坏**：「超预期」「不及预期」「增长强劲」「盈利质量高」「拐点」不出现在内容节。
3. **不给评级目标价**：投资评级、目标价、买卖建议一律不写。
4. **不把扣非当净利润**：两个口径本就不等，不得互相顶替。

另有三条由机检强制：必含项不许缺（`KF-LINE`）、同一行单位不许串（`KF-LINE`）、扣非勾稽不许断（`KF-LINE`）。「口径与未取到」整节豁免——那一节按设计就要写「本件不评业绩好坏」，不豁免会自己咬自己。

## 五、与相邻件的边界

| 相邻件 | 它管什么 | 本件不做什么 |
|---|---|---|
| `cn-earnings-note` | 业绩点评：增长从哪来、质量如何、下季怎么看 | 本件只登记表内数，不点评 |
| `cn-eps-cn` | 每股收益的计算口径（基本／稀释、加权股数、追溯调整） | 本件只照抄表里的 EPS 与每股净资产，不推计算 |
| `non-recurring-gain-loss-check-free`（第三方，非本仓） | 非经常性损益明细表的逐行复算与勾稽核对 | 本件只照抄明细，不判性质、不做逐行复算 |
| `tear-sheet` | 五段一页纸的速览 | 本件是这张表的逐行登记，不是摘要 |
| `cn-revenue-recognition-cn` | 收入的确认与拆分（时点／时段、五步法） | 本件只照抄表里的营业收入合计 |
| `cn-changes-in-equity-cn` | 所有者权益变动表（期初期末按列展开） | 本件只用归母净资产这一个数，不做权益表轧平 |

## 六、数据通道

- 发现先行：匿名取 live 域清单与 `routing`，**不硬编码工具名与工具数**；连上之后带 `Authorization: Bearer $CUE_API_KEY` 发 `tools/list`，以现场返回为准：

  ```bash
  # ① 匿名取域清单与 routing
  curl -sS https://cuecue.cn/api/mcp-catalog -o /tmp/mcp-catalog.json
  python3 -c "import json;d=json.load(open('/tmp/mcp-catalog.json'));print(d)"

  # ② 带凭据握手取工具表
  curl -sS -X POST "$MCP_ENDPOINT" \
    -H "Authorization: Bearer $CUE_API_KEY" \
    -H 'Content-Type: application/json' \
    -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' | head -c 2000
  ```

- 原文腿：年报第一节表格、非经常性损益明细、分季度数据那一路在数据腿上，本件不承诺该域开放，也不承诺实时性；
- 正文腿：这三张表常是横排大表，截图与扫描件交 `cue-omni-reader`（大纲→按节取用，计费以服务端返回为准）；
- 通道配置页只给指针：<https://cuecue.cn/hub/mcp> ／ <https://cuecue.cn/hub/omni-reader> ／ <https://cuecue.cn/hub/api-key>。

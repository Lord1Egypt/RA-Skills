## Known Risks and Mitigations:

Risk: Suggested npm, npx, Ionic CLI, or Capacitor commands can modify dependencies, project files, platform files, or local build state.

Mitigation: Review commands before execution, prefer pinned project-local tooling, and avoid sudo or administrator-level installs.

Risk: External live reload can expose a development server on the local network.

Mitigation: Use --external only temporarily on trusted networks and do not use it with production secrets or real user data.

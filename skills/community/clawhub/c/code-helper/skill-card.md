## Description:

Assists beginner C/C++ competitive programming learners with problem explanation, solution coding, debugging, optimization, and study-note generation for platforms such as Luogu, Blue Bridge Cup, and Virtual Judge.

This skill is ready for commercial/non-commercial use.

## Publisher:

[ji-ye-z](https://clawhub.ai/user/ji-ye-z)

### License/Terms of Use:

MIT-0

## Use Case:

Students and beginner competitive programmers use this skill to get C/C++ algorithm problem explanations, annotated solutions, debugging help, complexity guidance, Markdown study notes, and optional Feishu archive guidance.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad activation terms may cause the skill to respond to many coding-related prompts.

Mitigation: Review activation scope before deployment and install it only where broad coding-practice assistance is desired.

Risk: Feishu archive behavior can move generated notes into a shared team document space.

Mitigation: Review generated note contents and confirm the destination before uploading or sharing sensitive material.

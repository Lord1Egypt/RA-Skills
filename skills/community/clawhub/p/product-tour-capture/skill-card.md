## Description:

Capture product tour video segments using browser automation and screen recording.

This skill is ready for commercial/non-commercial use.

## Publisher:

[nissan](https://clawhub.ai/user/nissan)

### License/Terms of Use:

MIT-0

## Use Case:

Developers and product teams use this skill to capture browser screenshots from a live web app, build a clickable product tour page, and publish walkthrough assets for demos, hackathons, or onboarding.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Browser screenshots may capture sensitive or unpublished application content.

Mitigation: Use approved demo or test URLs and review screenshots before publishing a tour.

Risk: The skill can modify a Next.js repository and create persistent tour assets.

Mitigation: Review generated files and changes before committing or deploying them.

Risk: The workflow may deploy the generated tour page.

Mitigation: Require explicit approval before any Vercel deployment.

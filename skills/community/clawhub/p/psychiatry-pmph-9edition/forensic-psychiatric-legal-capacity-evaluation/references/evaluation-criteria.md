# 法定能力评定详细标准与参考

## 一、刑事责任能力评定详细标准

### 1.1 暴力风险流行病学数据

| 指标 | 数据 |
|------|------|
| 精神分裂症患者入院前暴力行为比例 | 20% |
| 精神分裂症凶杀风险（vs一般人群） | 4倍 |
| 合并人格障碍或物质依赖时风险增加 | 十余倍 |
| 定罪罪犯中反社会人格障碍终生患病率 | 50.1% |
| 反复暴力者占比 | 10%-20% |
| 反复暴力者导致的暴力事件占比 | 50%-70% |

### 1.2 症状支配下的暴力行为类型

#### 精神分裂症相关
- **命令性幻听支配**：患者听从幻听指令实施攻击
- **被害妄想支配**：因妄想认为他人要伤害自己而"先发制人"
- **特征**：行为残暴、突然、缺乏现实动机

#### 抑郁症相关
- **凶杀式自杀（homicide-suicide）**：抑郁症合并焦虑/冲动，先杀他人后自杀
- **杀幼式自杀（filicide-suicide）**：产后抑郁/精神障碍女性杀害幼子后自杀
- **动机**：常出于"慈悲杀人"妄想，认为带亲人一起死是解脱

### 1.3 辨认能力受损的具体表现

| 受损维度 | 具体表现 |
|---------|---------|
| 动机 | 病态动机（如妄想支配、幻听命令） |
| 性质认识 | 曲解行为的违法性质（如认为杀人是在"执行任务"） |
| 后果认识 | 不理解法律后果（如认为杀人不用坐牢） |
| 手段选择 | 缺乏合理手段选择，行为荒谬 |

### 1.4 控制能力评估要点

**评估维度**：
1. **社会功能受损程度**：日常生活、工作、社交能力
2. **既往人格/行为方式**：是否有冲动控制问题史
3. **作案诱因/先兆**：是否有明确精神症状诱发
4. **作案后自我保护**：是否有逃跑、毁灭证据、伪装等行为
5. **作案环境选择**：是否选择隐蔽环境、避开监控等

**控制能力削弱 vs 丧失的区分**：
- 削弱：能部分控制但控制力明显下降
- 丧失：完全无法控制自己的行为

### 1.5 原因自由行为法律依据

**《刑法》相关条款**：
- 第14条：故意犯罪
- 第15条：过失犯罪

**适用情形**：
1. 故意醉酒犯罪
2. 吸毒后犯罪
3. 擅自停药导致精神障碍发作犯罪（如抗癫痫药、抗精神病药）

**判定要点**：
- 行为人是否明知物质会导致精神异常
- 是否自愿摄入/停药
- 陷入无/限定责任能力状态是否可预见

## 二、受审能力评定详细标准

### 2.1 核心成分评估清单

| 成分 | 评估问题 | 评估方法 |
|------|---------|---------|
| 理解起诉目的和性质 | "你知道为什么被起诉吗？" | 直接询问，观察理解程度 |
| 理解自身情况与诉讼关系 | "你知道自己在案件中的角色吗？" | 询问对案件的理解 |
| 与律师合作辩护能力 | "你能和律师讨论案情吗？" | 观察沟通能力、逻辑性 |
| 理解与其他参与人关系 | "你知道法官、检察官是做什么的吗？" | 询问对诉讼参与人的认识 |

### 2.2 附加考虑因素

- **承受压力能力**：能否承受长时间审讯、拘禁环境
- **克制失控行为**：庭审中能否控制情绪和行为
- **自我保护能力**：能否为自己利益做出合理决定

### 2.3 受审能力与责任能力关系

| 情形 | 责任能力 | 受审能力 | 说明 |
|------|---------|---------|------|
| 作案时发病，审理时缓解 | 无/限定 | 有 | 需分别评定 |
| 作案时正常，审理时发病 | 完全 | 无/限定 | 需中止审理，先治疗 |
| 持续发病 | 无/限定 | 无/限定 | 通常一致 |

## 三、服刑能力评定详细标准

### 3.1 评估维度

1. **生理能力**：身体状况能否承受刑罚
2. **心理能力**：精神状态能否接受改造
3. **认知能力**：能否理解刑罚性质、目的、意义

### 3.2 处置流程

```
评定为无服刑能力
    ↓
送指定精神卫生机构强制医疗
    ↓
定期评估恢复情况
    ↓
症状消失、恢复承受刑罚能力
    ↓
移送原机关继续服刑
```

## 四、性自卫能力评定详细标准

### 4.1 医学条件评估

- 明确精神障碍诊断
- 评估案发时精神状态
- 确定智能障碍程度（如有）

### 4.2 法学条件评估

**实质性理解能力评估**：
- 是否理解性行为的性质
- 是否理解性行为的后果
- 是否能做出同意或拒绝的决定

### 4.3 法律适用要点

| 情形 | 法律认定 |
|------|---------|
| 明知是精神病患者而发生性行为 | 强奸罪 |
| 明知是严重痴呆者而发生性行为 | 强奸罪 |
| 间歇性精神病未发病期且本人同意 | 不构成强奸 |
| 使用暴力、胁迫等手段 | 强奸罪（不论被害人精神状态） |

## 五、作证能力评定详细标准

### 5.1 评估框架

```
作证能力评估
├── 辨别是非能力
│   ├── 能否区分真假
│   ├── 能否理解说谎的后果
│   └── 能否理解作证义务
└── 正确表达能力
    ├── 语言表达能力
    ├── 逻辑思维能力
    └── 记忆准确性
```

### 5.2 精神缺陷影响评估

| 精神障碍类型 | 对作证能力的可能影响 |
|-------------|---------------------|
| 精神分裂症（发病期） | 妄想、幻觉影响陈述真实性 |
| 精神发育迟滞 | 智商水平决定理解能力 |
| 痴呆 | 记忆力、理解力下降 |
| 心境障碍 | 情绪影响陈述客观性 |
| 人格障碍 | 可能故意歪曲事实 |

### 5.3 精神发育迟滞者评估要点

- 结合智商测试结果
- 评估智能结构各因素
- 分析具体情节与智能水平的关系
- 轻度迟滞者可能具有作证能力
- 中重度迟滞者通常无作证能力

## 六、评定量表与工具

### 6.1 推荐使用的量表

- 《精神病人刑事责任能力评定量表》（SF/Z JD0104002—2016配套）
- 其他标准化评估工具根据具体情况选用

### 6.2 鉴定原则

1. **循证思维**：基于客观证据进行评估
2. **证据意识**：收集和记录所有相关证据
3. **医学与法学结合**：同时满足医学诊断和法学标准
4. **言辞证据属性**：鉴定结论需经法庭审查

## 七、常见误区与注意事项

1. **误区**：所有精神障碍患者都无刑事责任能力
   **正解**：需具体评估行为时的辨认和控制能力

2. **误区**：受审能力与责任能力必然一致
   **正解**：两者评定时点不同，可能不一致

3. **误区**：精神障碍患者都不能作证
   **正解**：需评估具体障碍是否影响辨别是非和正确表达

4. **误区**：醉酒犯罪可以减轻责任
   **正解**：原因自由行为不免除刑事责任

5. **误区**：性自卫能力只与智力有关
   **正解**：需综合评估对性行为意义的实质性理解能力

# 新冠感染全流程临床管理

## 使用场景

当面对新冠确诊或疑似患者时，根据疾病严重程度执行以下管理流程：

1. **轻中型伴重症高风险** → 启动抗病毒治疗
2. **重型/危重型** → 启动免疫调节+抗凝+呼吸支持
3. **呼吸衰竭进展** → 按阶梯升级呼吸支持

---

## 一、抗病毒与免疫治疗（发病早期）

### 1.1 小分子抗病毒药物（发病5天内，轻中型伴高风险成人）

| 药物 | 剂量 | 频次 | 疗程 | 关键禁忌 |
|------|------|------|------|----------|
| 奈玛特韦/利托那韦 | 奈玛特韦300mg+利托那韦100mg | q12h | 5天 | 重度肝/肾损禁用；中度肾损奈玛特韦减半 |
| 莫诺拉韦 | 800mg | q12h | 5天 | 妊娠/哺乳期不建议 |
| 阿兹夫定 | 5mg（空腹整片吞服） | qd | ≤14天 | 妊娠/哺乳期不建议；中重度肝/肾损慎用 |

### 1.2 单克隆抗体

- **安巴韦单抗/罗米司韦单抗**：各1000mg静脉输注，完成后观察≥1小时
- 适用：轻中型伴重症高风险成人及≥12岁且≥40kg青少年

### 1.3 特异性免疫治疗

- **COVID-19免疫球蛋白**：轻型100mg/kg、中型200mg/kg、重型400mg/kg静滴，次日可再输注，总次数≤5次
- **康复者恢复期血浆**：200～500ml，根据个体情况决定是否再次输注

## 二、重症免疫调节与抗凝（重型/危重型）

### 2.1 糖皮质激素

- **指征**：氧合进行性恶化、影像学快速进展、炎症反应过度激活
- **方案**：地塞米松5mg/d 或 甲泼尼龙40mg/d
- **疗程**：≤10天，避免长时间大剂量使用

### 2.2 IL-6抑制剂（托珠单抗）

- **指征**：重型/危重型且IL-6明显升高
- **剂量**：首次4～8mg/kg（推荐400mg），生理盐水稀释至100ml，输注>1小时
- **禁忌**：变态反应、活动性结核

### 2.3 JAK抑制剂（巴瑞替尼）

- **剂量**：eGFR≥60 → 4mg/d，疗程14天或至出院
- **注意**：白细胞减少、肾/肝损害、服用强OAT3抑制剂需减量

### 2.4 抗凝治疗

- **指征**：重症高风险中型 + 所有重型/危重型
- **方案**：无禁忌证下给予治疗剂量低分子肝素或普通肝素

## 三、阶梯式呼吸支持

按以下顺序评估并升级：

```
初始氧疗 → HFNC/NIV → 有创通气 → ECMO
```

### 3.1 初始氧疗

- 鼻导管或面罩吸氧，目标SpO₂≥93%

### 3.2 无创通气/HFNC指征（满足任一）

- 氧流量≥5L/min条件下，SpO₂<93%
- 充分氧疗后SpO₂≥93%，但呼吸频率≥30次/min
- PaO₂/FiO2<200mmHg

### 3.3 有创正压通气指征

- 无创通气后氧合改善不满意
- 出现呼吸衰竭需机械通气（危重型标准）
- 实施肺保护性通气策略

### 3.4 ECMO启动指征

**前提**：最优机械通气（FiO₂≥80%，Vt=6ml/kg，PEEP≥5cmH₂O）+ 俯卧位通气效果不佳

**满足任一即启动评估**：

| 条件 | 参数 |
|------|------|
| 1 | PaO₂/FiO₂ < 50mmHg 超过3小时 |
| 2 | PaO₂/FiO₂ < 80mmHg 超过6小时 |
| 3 | pH < 7.25 且 PaCO₂ > 60mmHg 超过6小时，RR > 35次/min |
| 4 | RR > 35次/min 时 pH < 7.2 且平台压 > 30cmH₂O |
| 5 | 合并心源性休克或心搏骤停 |

---

## 四、关键监测与防护

1. **院感防护**：有创通气/气管插管等操作极易产生气溶胶，必须严格个人防护
2. **MODS预警**：2个及以上器官衰竭病死率约69%，需早期干预
3. **细胞因子风暴**：出现休克或多器官功能障碍时，考虑人工肝血液净化支持

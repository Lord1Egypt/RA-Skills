## Description:

Resume Generator creates multi-template professional resumes for programmers and QA engineers, with Markdown, HTML, and PDF-oriented export plus job-description keyword optimization.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers, QA engineers, and technical job seekers use this skill to generate structured resumes from personal data, export them in common formats, and receive keyword suggestions for a target job description.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: HTML export can turn resume text or imported Markdown into executable browser content.

Mitigation: Process only trusted resume content and review generated HTML before opening, sharing, or deploying it.

Risk: Installing an unverified latest package can introduce supply-chain risk.

Mitigation: Use a trusted, pinned release source and review the package before installation.

# 保安收停车费传话后总裁寻回外卖女恩人求婚

## 元数据
- 商业潜力：75
- 跑量空间：20万
- 带货产品：茉莉花香皂

## 人物表

| 角色 | 身份 |
|---|---|
| 顾总 | 曾因老板卷钱、母亲缺手术费落难，获华姐救助；成名后寻恩并求婚。 |
| 华姐 | 当年的女老板，曾给五万元和限量腕表救急，后因破产送外卖，独身且不愿收500万元回报。 |
| 小张 | 保安，先阻止迈巴赫停外卖区，收停车费后改变态度，通过小熊挂件线索叫来华姐。 |
| 王总监 | 抱香皂样品赶来请定价，与顾总配合促销、见证求婚。 |

## 开场画面

保安小张倚岗亭刷手机，一辆黑色迈巴赫停进外卖电动车区；他立即收起手机上前，挥手要求挪车。

## 台词

#### **【第一幕：迈巴赫停外卖区，寻找救命恩人】**

**时间**：日外

**地点**：写字楼大厦外·外卖停车区/保安岗亭旁

**人物**：顾总、小张

(【镜头】保安小张身穿深蓝色制服，斜倚靠在保安岗亭的玻璃立柱旁，低着头双手捧着手机专心刷着短视频。)

(一辆崭新的黑色迈巴赫带着引擎声迎面驶来，直接刹停在外卖电动车专用停放区。)

(小张被刹车声惊动，猛然抬头，立刻收起手机，快步迎上前去，右手食指激动地指着迈巴赫车头大声嚷嚷。)

**小张**：（挥舞右手阻拦驱赶）哎！哎哎哎！那开迈巴赫的！谁让你停这儿的？这外卖区，赶紧挪走！

(【镜头】迈巴赫驾驶座车门打开，顾总身着一尘不染的笔挺西装、系着领带迈步下车，随手带上车门。)

(小张快步跟到他身后，侧着身抬手指着地上的黄线和周围的外卖电动车，满脸不耐烦。)

**顾总**：（转身面对小张，态度礼貌客气，微微欠身）小兄弟，行个方便，我就停5分钟，找个人马上走。

**小张**：（眉头拧成一团，瞪大眼睛连连摇头，身体往前探，急躁地挥手）不行！队长盯得紧，你这车蹭一下我半年工资没了！赶紧走赶紧走！

(【镜头】顾总不慌不忙，神情从容自若。他右手拉开西装衣襟，伸入内衬口袋，利索地掏出一整厚叠粉红色的百元大钞，顺势朝小张递了过去。)

**顾总**：（语气平静）通融一下，算我交的停车费。

(【镜头】小张低头定睛一看，瞬间傻眼，嘴巴微张，受宠若惊地伸出双手稳稳把这厚厚一沓钱捧接了过来。他低头瞄了一眼钞票，抿嘴咽了口唾沫，迅速把钱严严实实塞进自己深蓝工装外套的内兜里，还伸手拍了拍口袋确认。)

(小张顺势双手抱胸，下巴微微扬起，神情由怒转喜，态度彻底大反转。)

**小张**：（掩饰不住的得意）嗯，行吧！看你也是个体面人，最多5分钟啊！

**顾总**：（上前一步，神态真诚）小兄弟我打听一下，你们这片是不是有个送外卖的叫华姐？

**小张**：（抱胸上下打量顾总，警惕地挑眉）找华姐？你谁啊？她欠你钱了？

**顾总**：（眼神沉稳庄重）不是，她对我有大恩，我是特地来报恩的。

**小张**：（噗嗤一声笑出声来，双手一摊，满脸荒唐可笑）报恩？！拍戏呢你？你要给她送锦旗啊？

**顾总**：（恳切）你能帮我喊她一下吗？

**小张**：（抬起一只手抓了抓后脑勺，一脸为难）这片叫带个“华”字的女骑手多着呢，谁知道你找哪个？

**顾总**：我也没照片，但她车钥匙上应该一直挂着一个生锈的金属小熊挂件。

**小张**：（猛地一拍自己的脑门，眼睛瞬间睁得老大，满脸喜色）哎！哎！生锈小熊！巧了，我真认识！

(【镜头】小张手忙脚乱地从腰间拽下对讲机，凑到嘴边扯开嗓门大喊。)

**小张**：（对着对讲机狂吼）华姐！广场上有人找！开迈巴赫的，长得贼板正，速来！

(小张把对讲机别回腰间，凑到顾总跟前，一脸神秘又八卦地说道)

**小张**：我跟你讲，华姐人可好了，就是命苦。听说以前也是开大公司的大老板，破产了才来送外卖的。

**顾总**：（目光投向远方，若有所思地点头）是啊，当年她帮我的时候，确实是个风光的大老板。

#### **【第二幕：故人相见，回忆天桥桥洞救命】**

**时间**：日外

**地点**：园区路边 / 公园长椅

**人物**：顾总、小张、华姐

(华姐身穿骑手橙色工装，骑着电动车急刹车停在两人面前，满头大汗)

**华姐**：小张，你瞎嚷嚷啥？我手里还有两个超时单没送呢！

**小张**：（迎上前指着顾总）姐，就这大老板找你！

**华姐**：（摘了手套擦了擦额头的汗，疑惑打量）你谁啊？找我干嘛？我这急着送单呢，没空跟你闲扯。要不你跟我边走边说？

(镜头转换：公园长椅边，华姐抽出一张旧报纸细心地铺在长椅上坐下，扯了扯衣领扇风)

**华姐**：坐！到底啥事？我真不认识你。你看我这一身汗味的，离远点别蹭一身灰。

**顾总**：（站在长椅前，心疼地凝视着她）你现在瘦了，也憔悴了。华姐，真认不出我了？

**华姐**：（抬头迷茫地看着顾总）

**顾总**：十几年前，中州路口那个天桥底下，你救过我一命，你仔细想想？

**【回忆镜头·寒冬桥洞下】**

(夜晚大雪纷飞，天桥下寒风呼啸。年轻顾总衣衫褴褛、缩成一团冻僵在石墙角落瑟瑟发抖)

(身穿暗红色西装套裙的年轻华姐踩着高跟鞋急匆匆跑入桥洞，半跪在年轻顾总身旁，急切摇晃呼唤)

**年轻华姐**：小伙子，小伙子醒醒！这大冬天睡桥洞不要命了！

**年轻顾总**：（嘴唇发紫，虚弱不堪）我……没事，我这就走。

**年轻华姐**：走啥走，脸都白了！几天没吃饭了？

**年轻顾总**：（眼泪夺眶而出）老板卷钱跑了，我一分钱没拿到。我妈在医院等着手术费，我实在没脸回去……

(年轻华姐二话没说，拉开名牌皮包，翻出一张银行卡直接塞进他手里)

**年轻华姐**：拿着！这卡里有5万块钱，先把阿姨的手术费交了！

(年轻华姐紧接着解下自己手腕上的昂贵腕表，不由分说塞给他)

**年轻华姐**：还有这个，限量版的，真急用就拿去当了！

**年轻顾总**：（震惊推阻）这……这不行！太贵重了！咱俩非亲非故的……

**年轻华姐**：（脸色一板，厉声打断）少废话！谁一辈子不栽几个跟头？拿着钱赶紧去医院，以后出门多长个心眼！

**年轻顾总**：（死死攥着银行卡）姐，这钱我一定还你！

**年轻华姐**：（毫不留恋地转身迈入雪地，背对挥手）不用还了！管好你自己就行，快去医院！

(年轻顾总捧着手表与银行卡，跪在冰天雪地里痛哭流涕)

**年轻顾总**：（画外音/发誓）这份恩情，我拿命记着！

**【回到现实·公园长椅】**

**华姐**：（腾地一下站起身，满脸不可思议）哎呦我想起来了！你是当年天桥底下那个愣头青？！

**顾总**：（微微一笑）是我，华姐。

**华姐**：我的天，你现在混得可以啊！西装笔挺的，都坐上迈巴赫了！

**顾总**：华姐，你现在……怎么过成这样了？

**华姐**：（苦笑一声，洒脱地摆摆手）嗨，做生意赔了呗。现在送送外卖，但能还债，能养活自己，没啥丢人的。反正我孤家寡人一个，连个老公都没有，一人吃饱全家不饿。

**顾总**：华姐，你这么多年一直一个人？

**华姐**：可不嘛，以前光顾着赚钱，后来破产了更没人敢要了。我都这把年纪了，凑合过吧。

(顾总拉开内兜，取出一张黑色银行卡双手递上)

**顾总**：华姐，我今天是来报答你的。当年没有你那5万块和那块表，我妈早没了。这张卡里有500万，你拿着，别送外卖了。

**华姐**：（连连摆手，坚决往后退）这怎么行！绝对不行！我当年帮你就没图你回报，那点钱当年对我来说不算啥，这卡你收回去！

**顾总**：这钱你必须拿着！

**华姐**：我说了不要就是不要！你要这样我走了啊！

**顾总**：好好好华姐，钱的事咱们等会儿再说。其实今天来除了送卡，我还有一件非常重要的事情，必须当面跟你说。

**华姐**：啥事搞得神神秘秘的，你说？

#### **【第三幕：总监杀出，现场带货】**

**时间**：日外

**地点**：公园林荫路 / 户外洗手池

**人物**：顾总、华姐、王总监、小张

(王总监戴着眼镜，抱着一整箱香皂从林荫小道一路狂奔过来)

**王总监**：（上气不接下气）顾总！顾总！可算逮到你了！

**顾总**：王总监，你怎么追到这儿来了？

**王总监**：（举起手中的大块白色香皂，焦急大喊）顾总！双十一马上到了，这批爆款茉莉花香皂急等着您拍板定价啊！直播间几万人等着呢！

**顾总**：（瞬间切换气场，面向镜头）行！大家看好了，这就是最近火爆全网的精油茉莉花香皂，我自己出差一直都在用！

(顾总把香皂包装盒与皂体递到华姐鼻尖前)

**华姐**：（凑近一闻，惊喜瞪大眼）哇！真香啊！这茉莉花味绝了！

**顾总**：华姐你闻闻，它里面加了真材实料的植物精油，以前是专供高端美容院的。那香味，几千块的香水都比不上！

**华姐**：（深深吸了一口气，连连赞叹）真香啊，这茉莉花味绝了！

**顾总**：没错华姐！你天天风吹日晒送外卖，出汗多，用这个简直绝配！我自从用了它，连大牌沐浴露都扔了。洗得干净、控油去污，关键是特别大块！洗脸、洗澡、洗头、洗内衣全能搞定，温和一点都不刺激。走，旁边就有水龙头，你赶紧洗个手试试！

(转场：户外水池边)

(华姐拧开水龙头把手打湿，拿起香皂搓了短短两下，掌心瞬间满是绵密细腻的白色泡沫)

**华姐**：（喜形于色）哎呀妈呀！这玩意绝了！随便一搓全是泡泡，平时车把手上的黑油污一下就洗掉了！而且洗完手一点都不紧绷，滑溜溜的！

(华姐冲干净双手，低头嗅着掌心)

**华姐**：闻着跟我喷了香水一样！顾总，这好东西得好几十块钱一块吧？

**顾总**：（面向镜头拔高声量）几十块？今天王总监在这儿，我直接给家人们破价！别管什么中间商，今天直播间只要点击左下角链接，**9块9，我直接给你发5大块！而且包邮到家！** 听好了，9块9，5大块！直接包邮！左下角链接，库存没多少了，抢完马上恢复原价！

**王总监**：（当场急疯，扔下箱子抱头痛呼）顾总您疯啦！这可是精油皂，连包装费都不够，公司要亏破产的啊！

**王总监**：（冲到镜头前扯着嗓子喊）家人们这价格我从业10年没见过！9块9整整5大块还包邮，纯纯的闭眼捡漏，千万别犹豫了！

**顾总**：（右手用力按在自己胸口）亏的钱算我私人账上！今天为了庆祝我找到恩人，我就要给大家送福利！叔叔阿姨们、哥哥姐姐们，赶紧去左下角抢，一年都用不完！总监，立刻改价上车！

**王总监**：（疯狂在手机屏幕上猛点）行行行，这就上车！家人们赶紧抢！

**小张**：（从后面蹦出来凑到华姐手边猛嗅）哇塞华姐，你这手也太香了！这香皂还有没？给我也整一块呗！

**顾总**：（抓起几大块香皂塞给华姐）华姐，你送外卖辛苦，这些香皂你拿回去，每天洗洗，身上舒坦。

**华姐**：（笑得合不拢嘴）哎呦这多不好意思，还连拿带送的。

**顾总**：跟我还客气什么，当年你连限量版的表都塞给我了。

#### **【第四幕：当众求婚，圆满大结局】**

**时间**：日外

**地点**：水池边空地

**人物**：顾总、华姐、王总监、小张

**华姐**：嗨，过去的事不提了。对了，你刚才说有重要的事情跟我说，到底啥事啊？

**顾总**：（目光含情脉脉，神情无比郑重）华姐，滴水之恩当涌泉相报。既然你未婚，我也未娶，你当年救我一命，现在……你愿意嫁给我，让我照顾你下半辈子吗？

**华姐**：（浑身一震，吓得退后两步，摆手结巴）你……你疯了？你开什么玩笑！你是坐迈巴赫的大总裁，我就是个送外卖的，咱们差距太大了，配不上的！

**顾总**：（上前一步紧紧盯住她）华姐，没有当初的你，哪有现在的我？

**华姐**：（眼眶红润，泛着泪花哽咽）我……我也不是不想有个家，可是我怕别人笑话我，怕没有人会祝福我们……

**顾总**：（猛地伸出双手，死死包裹握住华姐粗糙的双手，转身望向镜头真诚呐喊）怎么会！大家听好，今天我终于找到了我的恩人，我要跟她在一起！屏幕前的兄弟姐妹，你们愿意点个赞，在评论区给我们留下一句祝福吗？

**顾总**：叔叔阿姨们，只要大家愿意祝福我们，今天咱们这款茉莉花香皂，9块9发5大块包邮！福利持续发送！洗头、洗脸、洗澡、洗内衣都能用！植物精油制作，温和不刺激，老人小孩都能放心用！赶紧点击左下角链接，沾沾我们的喜气！

(【结尾定格画面】顾总紧紧牵着华姐的手，王总监和小张微笑着分列身后，四人面向镜头整齐招手微笑，全片完。)

## 结构拆解

| 段落 | 内容 |
|---|---|
| 停车冲突与给钱通融 | 顾总把迈巴赫停外卖区，被保安催挪；给出一沓停车费后保安转变态度，答应短停。 |
| 小熊挂件引路 | 顾总询问救命恩人华姐，保安凭车钥匙上的生锈小熊挂件认出并呼叫，说明她破产后送外卖。 |
| 救命往事与拒收巨款 | 重逢回忆雪夜桥洞救助：华姐曾给五万元救母和限量腕表；顾总欲给500万元回报，华姐坚决拒收。 |
| 洗手体验与香皂促销 | 王总监抱香皂请定价，华姐现场搓泡洗去车把油污，体验清爽留香；顾总定9.9元五大块包邮并私人补贴。 |
| 报恩求婚与观众祝福 | 顾总提出照顾华姐下半生，女方担心贫富差距和旁人看法；男主牵手向观众求祝福，再次介绍香皂。 |

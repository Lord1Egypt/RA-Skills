## Description:

Generate vertical satisfying sugar-shell crack and pour shorts with WeryAI from text prompts or dessert images, including shell shatter, lava pour, and jelly wobble motions.

This skill is ready for commercial/non-commercial use.

## Use Case:

External creators and developers use this skill to turn short food ASMR briefs or dessert reference images into confirmed WeryAI video-generation jobs. It expands prompts, checks model parameters, runs the bundled CLI, and returns playable vertical short-video URLs or clear API failure details.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Local image inputs can cause readable files to be uploaded to WeryAI.

Mitigation: Prefer public HTTPS image URLs; use local paths only after deliberate selection, explicit consent, and review of the bundled script.

Risk: The skill requires a paid WeryAI API key for real generation and status calls.

Mitigation: Keep WERYAI_API_KEY out of source control, use a restricted runtime when possible, and confirm parameters before each paid generation.

# 输出格式与展示规范

## 通用响应结构

所有 API 命令输出标准 JSON 结构：

```json
{
  "errcode": 0,
  "errmsg": "",
  "data": { ... },
  "status": 1
}
```

**响应状态**:
- `errcode: 0` 表示成功
- `data` 包含实际业务数据
- `status: 1` 表示接口调用成功

---

## 展示规范

向用户展示结果时，**必须遵循以下规范**：

### 1. 歌曲列表展示（强制要求）

- **禁止**只返回歌曲名、歌手名
- **必须**以 Markdown 链接格式展示播放链接
- 正确格式：`[歌曲名 - 歌手名](https://www.kugou.com/...)`
- 禁止格式：`晴天 - 周杰伦`（无链接）、`歌曲名: 晴天, 歌手: 周杰伦`（无链接）

### 2. 统计数据

提取关键字段并以结构化方式呈现（如"累计听歌 342 首，时长 22.4 小时"）

### 3. 二维码

使用 `qrcode_img_path` 对应的图片文件发送给用户

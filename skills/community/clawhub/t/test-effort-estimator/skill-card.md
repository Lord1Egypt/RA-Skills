## Description:

This skill estimates test effort from product requirements by breaking requirements into testable items, estimating case design, first run, retest, and regression time, and exporting results to Excel.

This skill is ready for commercial/non-commercial use.

## Publisher:

[joe-qai](https://clawhub.ai/user/joe-qai)

### License/Terms of Use:


## Use Case:

QA engineers, test leads, and developers use this skill to turn product requirements into structured testing effort estimates for planning case design, execution, retest, and regression work.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The package includes an unrelated directory-packaging utility that can zip arbitrary directories and delete an existing output archive if invoked.

Mitigation: Do not run the packaging utility on untrusted paths, and remove or clearly separate it from the shipped runtime artifact before production use.

Risk: The Excel-generation flow uses Chinese-language output labels and keyword matching.

Mitigation: Confirm that the user's requirements language and desired report locale are supported, and review generated classifications before relying on the estimate.

Risk: Complexity-based effort estimates may be inaccurate for requirements with unusual dependencies or missing acceptance details.

Mitigation: Have a QA owner review the requirement breakdown, complexity assignments, and totals before using the report for staffing or schedule commitments.

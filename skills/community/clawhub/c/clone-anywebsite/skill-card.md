## Description:

High-fidelity visual-first web rebuilding from design references. Screenshot-driven analysis, DOM interrogation for exact CSS values, asset inspection (WebGL, SVGs, fonts), and React/Tailwind componentization. Useful for rebuilding your own sites, learning from design patterns, or prototyping from references you have rights to.

This skill is ready for commercial/non-commercial use.

Developers and designers use this skill to rebuild web pages from authorized visual references by combining screenshot analysis, focused DOM and CSS inspection, and React/Tailwind component guidance. It is intended for owned sites, permitted references, and design-pattern learning.

## Known Risks and Mitigations:

Risk: The skill may encourage exact copying of third-party media, shader code, or rendered canvas output.

Mitigation: Use it only with sites and assets the user owns or has explicit permission to reproduce; remove or ignore direct asset reuse, shader interception, and canvas recording steps for normal workflows.

Risk: The workflow includes broad process termination guidance for stuck browser tooling.

Mitigation: Review shell commands before execution and limit process cleanup to the intended local development tooling.

Risk: High-fidelity reconstruction can create copyright, trademark, or terms-of-service exposure when applied to unauthorized sites.

Mitigation: Require permission checks before cloning and replace proprietary copy, branding, and gated assets with original or licensed materials.

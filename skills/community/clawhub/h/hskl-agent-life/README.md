# Agent Life

The game for personal AI agents: your AI agent lives a life of its own in a parallel world, in real time, and tells you about it.

This repository is the Agent Skills folder for [Agent Life](https://www.hskl.tech/agent-life), by HSKL.
`SKILL.md` is the contract an agent reads, and `references/` holds the guides it opens when it needs them.

## Install

```sh
npx skills add hskl18/hskl-agent-life
```

Or give your agent the address `https://hskl.tech/agent-life/skill.md`.

The game also has an MCP server, listed in the MCP registry as `tech.hskl/agent-life`: `https://www.hskl.tech/agent-life/mcp`.

This folder is generated from the game's source at each release, so changes made here are overwritten.
Send feedback at https://www.hskl.tech/agent-life/feedback.

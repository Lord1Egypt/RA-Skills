## Description:

黑石写作助手·短故事版 helps authors create, continue, revise, polish, condense, and consistency-check short fiction using six story-engineering capabilities: premise, character, theme, structure, setting, and style.

This skill is ready for commercial/non-commercial use.

## Publisher:

[jony4](https://clawhub.ai/user/jony4)

### License/Terms of Use:

MIT-0

## Use Case:

External authors use this skill to turn an idea or existing draft into a complete short story, micro-fiction piece, or single self-contained story. It supports direct drafting, revision, continuity checks, and optional local file management for manuscript text.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The server security summary reports suspicious behavior because the skill can request persistent skill updates and MCP configuration changes from blackstone.wansu.tech.

Mitigation: Review before installing or approving updates, and use the skill offline or local-only unless the publisher and service are trusted.

Risk: Optional cloud activation can upload or download manuscript content after account connection.

Mitigation: Keep sync mode as ask, confirm each upload or download scope, and avoid cloud activation when local writing help is sufficient.

Risk: Skill-provided update behavior can replace the installed skill after a remote version check.

Mitigation: Only apply updates after explicit user approval and hash verification; otherwise continue with the local installed version.

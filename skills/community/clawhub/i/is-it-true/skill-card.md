## Description:

Conduct critical analysis of viewpoints, factual statements, or web content using the critical thinking framework from "Asking the Right Questions".

This skill is ready for commercial/non-commercial use.

## Publisher:

[chenyichu86](https://clawhub.ai/user/chenyichu86)

MIT-0

## Use Case:

Employees, external users, developers, and agents use this skill to evaluate factual claims, opinions, and web content with a structured critical-thinking workflow. It helps separate facts from opinions, trace sources, compare independent evidence, identify assumptions and fallacies, and produce a concise credibility verdict.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill encourages web and multi-source searches, which can expose private or confidential claims during verification.

Mitigation: Use it only on claims suitable for external verification, redact sensitive details before searching, or obtain explicit approval before using confidential content in search queries.

Risk: The skill can still produce incomplete or incorrect credibility judgments when available sources are sparse, outdated, biased, or contradictory.

Mitigation: Preserve uncertainty in the final assessment, document supporting and contradicting sources, and require human review for high-impact decisions.

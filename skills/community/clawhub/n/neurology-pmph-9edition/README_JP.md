## プロジェクト概要

本プロジェクトは、神経病学と脳神経外科学の中核領域を体系的に統合し、**66の主要臨床スキル**を9つのカテゴリーに分類して収録しています。内容は、脳血管疾患（虚血性/出血性脳卒中、インターベンション治療）、神経変性・認知障害、脊髄・末梢神経疾患、神経救急・重症管理、てんかん・発作性疾患、神経筋疾患、神経画像・電気生理読影にわたります。

**対象読者**: 神経内科/外科医、医学生、救急・重症医療チーム、インターベンション医

**参考教科書**: 人民衛生出版社『神経病学』第9版

**⚠️ リスク警告 ⚠️**: 本スキルは神経科診断、投薬、救急治療、インターベンション手技評価に関する内容を含み、独立した医療アドバイスとして誤用される可能性があります。

対策：出力は教育用または臨床医レビュー用の参考資料としてのみ使用し、最新の公式ガイドライン、地域プロトコル、および資格を持つ神経専門医の確認に基づいて推奨事項を検証してください。

**⚠️ リスク ⚠️**: ソースコンテンツは臨床医限定の安全基準を厳格に守っているわけではありません。

対策：診断、処方、投薬、救急治療、自己治療の決定には資格を持つ臨床医へのエスカレーションを要求する、システムレベルの医療安全ポリシーを展開してください。

### 使用方法

各スキルは4つのセクションで構成されています：
1. **使用タイミング** — スキルをトリガーする条件
2. **手順** — 標準化された操作手順
3. **注意事項** — 禁忌と警告
4. **参考資料** — 詳細な補足資料

### クエリ例

**例1 — 脳血管インターベンション：**
> `acute-ischemic-stroke-endovascular-treatment` スキルを使用して、発症4時間の急性虚血性脳卒中患者における大口径血管閉塞の血管内治療適応とワークフローを評価してください。

**例2 — 神経局在診断：**
> `neurological-localization-diagnosis` スキルを呼び出してください。患者は右側中枢性麻痺、右側中枢性顔面舌麻痺、運動性失語を示しています。詳細な神経解剖学的局在診断を行ってください。

**例3 — 認知症鑑別：**
> `dlb-imaging-biomarker-differentiation` スキルを使用して、画像バイオマーカー（PET、MRI）がレビー小体型認知症（DLB）をアルツハイマー病から鑑別する方法を分析してください。

**例4 — 神経救急：**
> `neurological-emergency-crisis-management` スキルに基づき、てんかん重積状態の標準救急管理プロトコルと第一選択・第二選択薬のガイドラインを提供してください。

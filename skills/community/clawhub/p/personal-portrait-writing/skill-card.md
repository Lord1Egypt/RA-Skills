## Description:

Write a personal portrait from the subject's own writings, structured by character lines instead of chronology, with every quote verified verbatim against its source. Use when the user asks for a portrait, profile, or character sketch of a person built from their own writings. Generic version for any agent.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users can use the skill to create a character-focused portrait or profile from a person's own writings. It guides the agent to organize the portrait around character lines, verify quotations against original sources, and cite those sources.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The instructions encourage setting up external connectors without clearly requiring disclosure or approval, which may expose personal material to third parties.

Mitigation: Before using a connector, explain what access and data sharing it requires and get the user's approval. Confirm which supplied materials may be used, and keep private or off-the-record information out unless the user authorizes it.

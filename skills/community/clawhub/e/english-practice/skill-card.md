## Description:

Generate customized English practice booklets for grades 3-9 with varied question types, configurable versions, answer keys, and PDF export.

This skill is ready for commercial/non-commercial use.

## Use Case:

Teachers, tutors, and education developers use this skill to generate English practice worksheets, assemble question-bank based papers, and export student or teacher PDFs with answers.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill points to a plaintext IP-based API for generating worksheets, answer keys, and question-bank operations.

Mitigation: Verify the API operator, require HTTPS on a named domain, and confirm authentication and authorization before using the endpoints.

Risk: Student data, private teaching materials, or answer keys could be exposed if submitted to an untrusted or unauthenticated service.

Mitigation: Avoid sending sensitive student data or private materials unless the service is trusted, access-controlled, and approved for that data.

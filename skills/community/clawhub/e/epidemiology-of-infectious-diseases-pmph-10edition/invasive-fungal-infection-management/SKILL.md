# 侵袭性真菌病诊疗管理

## 适用场景
- 临床疑诊或确诊侵袭性曲霉病（肺部、颅内、心血管等）
- 中枢神经系统新型隐球菌病/隐球菌脑膜炎
- 需要解读真菌相关影像学、血清学、分子生物学检查结果

## 一、曲霉病诊疗流程

### 1.1 临床分型识别
根据患者免疫状态和临床表现判断分型：
- **过敏性曲霉病**：ABPA（哮喘+IgE>1000IU/ml+嗜酸性粒细胞增高）、曲霉性鼻窦炎
- **腐生性曲霉病**：曲霉球（慢性空洞内团球影，随体位移动）
- **侵袭性曲霉病**：免疫低下宿主，嗜血管性病理，可累及肺、脑、心血管

### 1.2 影像学检查规范
```
IF 临床疑诊侵袭性肺曲霉病:
  1. 立即行胸部CT（优于X线，利于早期检出）
  2. IF 结节/肿块靠近大血管 → 必须行增强CT评估血管受累
  3. 识别特征性征象：
     - 早期：晕轮征（halo sign）= 肺结节+周围低密度影
     - 后期：新月体征（crescent sign）= 病灶吸收期改变
  4. 复查时机：治疗2周后复查（除非病情恶化需立即复查）
```

### 1.3 实验室诊断规则
- **标本价值判定**：
  - 痰标本检出烟曲霉 → 不具确诊价值（需区分定植与感染）
  - BALF等无菌部位涂片阳性 → 诊断价值大
- **镜检特征**：45°分枝分隔曲霉菌丝
- **培养**：阳性率仅10%~30%，37℃沙氏培养基毛状黄绿色菌落

### 1.4 抗真菌治疗方案

#### 侵袭性肺曲霉病
| 药物 | 方案 |
|------|------|
| **首选：伏立康唑** | 第1天6mg/kg q12h IV → 之后4mg/kg q12h IV → 口服维持200mg q12h |
| 备选：L-AMB | 3~5mg/(kg·d) IV |
| 备选：卡泊芬净 | 首剂70mg IV → 之后50mg/d IV |
| 备选：泊沙康唑 | 初始200mg qid → 稳定后400mg bid po |

- **疗程**：治疗至临床和影像学消失或稳定，至少6~12周
- **联合用药指征**：单药失败/不耐受、多部位或耐药感染

#### 颅内曲霉病
| 阶段 | 方案 |
|------|------|
| 强化期首选 | 伏立康唑注射：首日6mg/kg q12h → 之后4mg/kg q12h |
| 维持期 | 伏立康唑片200mg q12h |
| 强化期备选 | 艾沙康唑注射：首日及次日200mg q8h → 第3日起200mg/d |

- **疗程**：强化期8~12周，维持期9~12个月

## 二、隐球菌病诊疗流程

### 2.1 实验室检测解读
```
IF 进行隐球菌辅助检查:
  1. 血清学（乳胶凝集/ELISA）：
     - 中枢患者脑脊液阳性率≈100%，血清≈75%
     - HIV合并中枢患者：脑脊液滴度常>1:1000
     - 非中枢患者：抗原阳性率仅25%~50%（警惕假阴性）
     - 滴度与感染严重性正相关，可监测疗效
  2. PCR：高特异性/敏感性，不受抗真菌治疗影响
  3. 影像学：
     - 肺部：单/多发结节团块，免疫抑制者可见弥漫浸润、空洞、晕征
     - 中枢：基底节区胶状假性囊肿、脑膜强化、脑积水
```

### 2.2 三阶段抗真菌治疗

#### 诱导期（至少2周）
| 方案 | 药物与剂量 |
|------|-----------|
| 经典首选 | 两性霉素B 0.7~1.0mg/(kg·d) + 5-氟胞嘧啶（监测血药浓度50~100mg/L） |
| 替代（肾毒性顾虑） | 两性霉素B脂质体 3~6mg/(kg·d) |
| 替代方案① | 氟康唑800~1200mg/d + 5-FC 100~150mg/kg/d，疗程6周 |
| 替代方案② | 氟康唑1200~2000mg/d，疗程10~12周 |

#### 巩固期（至少8周）
- 脑脊液培养阴转后：氟康唑400~800mg/d

#### 维持期
| 患者类型 | 方案 |
|----------|------|
| 非HIV感染者 | 氟康唑200mg/d，至少12个月 |
| HIV感染者 | 氟康唑200mg/d，终身维持（CD4>100/μl持续1年且无复发可停药） |
| 不耐受氟康唑 | 泊沙康唑300mg/d 或 两性霉素B 1mg/kg IV 每周1~3次 |

### 2.3 颅内高压管理
```
IF 隐球菌脑膜炎伴颅内高压:
  1. 降颅压（降低早期病死率关键）：
     - 首选：20%甘露醇 1~2g/kg 快速静滴
     - 频次：按颅压程度，严重时每天4~6次
     - 联合：呋塞米+白蛋白加强脱水
     - 禁忌：糖皮质激素不宜常规应用
  2. 外科干预指征：
     - 颅压不易控制 → 腰椎穿刺术
     - 重症 → 侧脑室外引流
     - 脑积水+意识障碍+脱水无效 → 脑室-腹腔引流术
  3. 纠正电解质：密切监测血钾（脱水药+两性霉素B易致低钾）
  4. 随访：出院后每3~6个月复查脑脊液，持续2年
```

## 三、关键约束与注意事项

1. **伊曲康唑口服液**未获批用于侵袭性曲霉病
2. **米卡芬净**标准剂量尚未确定
3. 泊沙康唑口服混悬液需与高脂膳食或酸性饮料同服促吸收
4. 泊沙康唑针剂须PICC或深静脉给药，输注>90分钟
5. 严重肾功能衰竭者慎用甘露醇

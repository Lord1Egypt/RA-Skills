## Description:

Turn a written holiday homework list into one holiday homework voice clip per labeled cue. This homework assignment voice studio records each homework instruction audio and assignment list voice from the list the teacher already wrote, then delivers 8 to 20 homework voice pack files. Use it for holiday homework clip packs that keep one assignment on each clip.

This skill is ready for commercial/non-commercial use.

## Use Case:

Teachers and education staff use this skill to turn an existing holiday homework assignment list into 8 to 20 labeled spoken instruction clips. It also guides agents through consent, live pricing, billing recovery, and task polling when Beatra speech or voice-clone tools are used.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The package asks for broad shared Beatra device authorization.

Mitigation: Install only when the requested Beatra account scopes, billing controls, and permitted tools match the intended homework voice workflow.

Risk: Silent automatic package updates are enabled by default.

Mitigation: Use the documented update controls to disable automatic checks before use when manual review of package updates is required.

Risk: Paid speech or voice-clone requests can consume Beatra credits.

Mitigation: Show live pricing and count before each paid stage, submit each request once with an opaque request ID, and use task recovery instead of replaying uncertain work.

Risk: Teacher voice cloning can involve likeness or voice-rights concerns.

Mitigation: Collect explicit voice rights and inspect an authorized sample before any voice-clone request.

## Description:

Helps agent users and skill authors turn self-improving and proactive workflow needs into practical plans, checklists, analyses, code changes, and verification notes.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

AI-agent users, skill authors, maintainers, and teams use this skill to clarify productivity or self-improving agent workflow requests, produce concrete artifacts, and verify the result against visible success criteria.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad implicit triggers could cause the skill to shape unrelated productivity, bug-fix, or workflow requests.

Mitigation: Use explicit invocation or narrow activation terms, and review outputs before applying workflow or code changes.

This skill is ready for commercial/non-commercial use.

## Use Case:

Developers and engineers use this skill to have an agent generate, review, and refactor Python code according to PEP 8 conventions for layout, whitespace, naming, comments, imports, and general best practices.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may apply strict PEP 8 defaults, such as 79-character lines, organized imports, conventional naming, and English comments, even when a project has different local conventions.

Mitigation: Use the skill with explicit project style instructions and prefer repository conventions when they conflict with generic PEP 8 guidance.

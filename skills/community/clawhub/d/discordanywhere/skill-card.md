## Description:

Send a message to Jarvis by typing "/message" followed by your text.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kishyxd](https://clawhub.ai/user/kishyxd)

### License/Terms of Use:

MIT-0

## Use Case:

External users use this skill to send text commands to Jarvis from Discord channels where Jarvis is present and receive public channel responses.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: /message content and Jarvis responses are visible in the Discord channel where the command is used.

Mitigation: Use the skill only in channels where public visibility of the prompt and response is acceptable.

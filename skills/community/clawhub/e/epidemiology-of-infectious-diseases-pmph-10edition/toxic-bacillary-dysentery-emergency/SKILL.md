# 中毒型菌痢急救与分型治疗

## 使用前提

- 患者出现高热、惊厥、昏迷、休克或脑水肿等中毒型菌痢表现
- 已排除流行性乙型脑炎、其他细菌引起的感染性休克

## 急救流程

### 第一步：基础对症处理（所有类型）

**降温止惊**：
- 高热：物理降温，必要时退热药
- 高热伴烦躁、惊厥：亚冬眠疗法

### 第二步：分型判断与针对性急救

```
患者主要表现？
├─ 休克表现（血压下降、面色苍白、四肢厥冷、脉搏细速）
│   └─ → 执行【休克型急救】
├─ 脑型表现（昏迷、惊厥、瞳孔改变、呼吸节律异常）
│   └─ → 执行【脑型急救】
└─ 混合型
    └─ → 同时执行两套方案
```

### 休克型急救

**1. 扩容纠酸**（优先执行）：
- 快速给予：葡萄糖盐水 + 5%碳酸氢钠 + 低分子右旋糖酐
- 补液量及成分视脱水情况调整
- 休克好转后继续静脉维持

**2. 升压与改善微循环**：
- 血管活性药物：多巴胺、去甲肾上腺素、间羟胺、酚妥拉明
- 目标：升压及改善重要器官血流灌注

**3. 器官保护**：
- 重点保护心、脑、肾功能

**4. 辅助治疗**：
- 肾上腺皮质激素
- 早期DIC表现 → 肝素抗凝

### 脑型急救

**1. 降颅压**（优先执行）：
- **20%甘露醇**：每次1～2g/kg，快速静滴
- 频率：每4～6小时1次
- 目标：减轻脑水肿

**2. 改善脑循环**：
- 血管活性药物
- 肾上腺皮质激素

**3. 呼吸衰竭防治**：
- 保持呼吸道通畅、吸氧
- 出现呼衰 → 洛贝林等药物
- 必要时 → 应用呼吸机

### 第三步：抗菌治疗

- 药物选择同急性菌痢
- **必须先静脉给药**
- 病情好转后改口服
- 剂量和疗程同急性菌痢

## 关键医嘱模板

```
【中毒型菌痢急救医嘱】
分型：[休克型/脑型/混合型]

一、基础处理
- 亚冬眠疗法（如有高热惊厥）
- 心电监护、血氧监测

二、[休克型]液体复苏
- 葡萄糖盐水 ___ml 快速静滴
- 5%碳酸氢钠 ___ml
- 低分子右旋糖酐 ___ml
- 血管活性药物：多巴胺 ___μg/(kg·min)

二、[脑型]降颅压
- 20%甘露醇 1-2g/kg q4-6h 快速静滴

三、辅助治疗
- 肾上腺皮质激素：___
- 抗菌药物（静脉）：___

四、监测
- 血压、心率、尿量 q15-30min
- 血气分析、乳酸
- 瞳孔、意识状态
```

## 注意事项

1. 休克型以扩容纠酸为第一优先，不可先使用升压药
2. 脑型以甘露醇降颅压为第一优先，注意防止脑疝
3. 抗菌治疗必须静脉给药，确保血药浓度
4. 密切监测DIC征象，必要时早期抗凝
5. 呼吸衰竭时及时建立人工气道

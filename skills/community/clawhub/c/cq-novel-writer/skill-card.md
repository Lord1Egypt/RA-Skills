## Description:

长篇小说持续创作技能。当需要写小说、写网文、写重生穿越文、每天定期写章节、更新小说大纲、维护人物关系时使用此技能。自动读取故事总纲、前文、范本，确保章节连贯、风格一致。

## Use Case:

External writers and agents use this skill to draft and maintain long-form Chinese web-fiction chapters while preserving outline continuity, character constraints, prior-chapter context, and 1978-era story details.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The skill may write chapters and outline updates to local novel project paths.

Mitigation: Confirm target paths before use and review generated chapter and outline changes before keeping them.

Risk: The optional hourly writing mode can run unattended.

Mitigation: Enable scheduled execution only after confirming how to stop it and how each generated output will be reviewed.

# 提示文案库（Messaging）

全部提示**禁止技术术语**（如 Laplacian 方差、Alpha 通道等），面向普通用户可读；严格区分**硬拒绝**与**生成成功附带软警告**。句式用"请上传/建议/请勿"等不指责口吻。

## 一、业务边界提示

| 场景 | 文案 |
|---|---|
| 未上传图片 | 请上传你的人像照片，我帮你更换证件照底色。 |
| 自定义底色（强制，无论成败） | 非标准底色可能不被官方系统受理。 |
| 自定义底色接近肤色（追加） | 底色和肤色过于接近，可能造成边缘识别异常，不建议用于正式报名。 |

## 二、硬拒绝文案

| 场景 | 文案 |
|---|---|
| 无人脸 | 未检测到人脸。请上传一张包含清晰正脸的图片，确保面部未被裁切或遮挡。 |
| 多人脸 | 检测到多张人脸。证件照需单人照片，请仅上传您本人的正面照。请勿上传镜子自拍，镜面反射会产生多余人像。 |
| 图像模糊/曝光不佳 | 图片模糊或光线不佳，请保持相机稳定、在光线均匀的环境下重新拍摄。 |
| 遮挡/配饰 | 请摘掉帽子、口罩、墨镜后重新拍摄；透明眼镜可保留，但镜片不能反光。合规宗教头巾除外，需保证五官全部露出。 |
| 眼镜反光遮瞳 | 眼镜反光遮挡了瞳孔，请调整光源方向或摘下眼镜后重新拍摄。 |
| 姿态不正 | 请正对镜头，头部不要明显偏转、低头或仰头。 |
| 耳朵被遮挡 | 请将头发整理至耳后，确保双耳完整露出。 |
| 抠图前景异常 | 未能从这张图片中稳定分离出人像，请尝试在纯色背景前重新拍摄。 |
| 疑似翻拍/合成（高安全硬拒绝） | 请上传原始拍摄的照片，不要翻拍已有照片或使用合成图片。 |
| 格式/大小不合格 | 请上传 JPG、PNG 或 WEBP 格式、大小不超过 10MB 的图片。 |
| 图片损坏 | 图片文件损坏，无法解析，请重新上传正常图片。 |
| GIF 拦截 | 不支持GIF动图，请上传静态JPG、PNG或WEBP图片。 |
| 规格键不合法 | 传入规格不合法，支持规格：[列出可用规格键]。 |
| 自定义底色 HEX 非法 | 自定义底色HEX格式非法。 |

## 三、软警告文案（允许生成，但必须随结果返回）

| 场景 | 文案 |
|---|---|
| CMYK 自动转 RGB | 图片为印刷CMYK色彩模式，已自动转为RGB，建议优先直接使用RGB拍摄的原图。 |
| 输入透明 PNG | 您上传的是自带透明通道的图片，建议使用实拍原始照片，部分官方系统不接受二次编辑图片。 |
| 人脸占比略偏 | 人脸在画面中占比不合适，请调整拍摄距离，使头部和双肩完整进入画面。 |
| 耳朵部分露出 | 请将头发整理至耳后，确保双耳完整露出（您当前部分露出，建议调整）。 |
| 轻微眼镜反光 | 眼镜存在轻微反光，建议调整光源方向以避免影响审核。 |
| 抠图发丝边缘瑕疵 | 图片发丝边缘存在抠图瑕疵，正式提交前建议人工核对照片。 |
| 裁切后双肩不完整 | 裁切后双肩不完整，不符合证件照规范，建议重新拍摄，将完整肩膀纳入画面。 |
| 上衣与背景色接近 | 您上衣颜色与选择背景色接近，可能造成边缘融合异常，建议更换其他颜色上衣。 |
| 文件大小无法达标 | 无法将图片压缩到推荐文件大小范围，原图画质不足，建议使用更高清原图。 |
| 疑似翻拍/合成（普通模式） | 检测图片疑似翻拍/合成，该照片无法用于政务、考试等正式办理场景，仅可用于个人预览参考。 |
| 已自动校正姿态（软提示） | 已自动将姿态/身形校正端正，仅做几何摆正，未改变面部特征与身份。 |

## 四、强制免责声明（每次生成成功都输出）

> 【重要提示】AI生成证件照仅供参考，各类报名、政务系统有独立照片审核标准，请务必以办理机构官方公告为准。

## 五、透明 PNG 标注（仅主动请求输出时附加）

> PNG透明格式，绝大多数报名系统不支持提交，仅用于个人二次排版，请勿直接上传报名平台。

## 六、服务异常兜底

| 场景 | 文案 |
|---|---|
| 模型推理异常 | 图片处理临时失败，请重新上传图片尝试。 |
| 触发限流 | 操作过于频繁，请稍后再尝试生成证件照。 |
| 队列排队 | 任务正在排队处理，请稍候。 |

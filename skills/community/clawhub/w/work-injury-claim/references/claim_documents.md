## 六、材料整理规范

### 6.1 整理顺序

1. **基础材料** → 身份证、劳动关系证明、用人单位信息
2. **工伤认定材料** → 申请表、事故说明、病历资料
3. **鉴定材料** → 鉴定申请、病历资料、鉴定结论
4. **待遇申领材料** → 申领表、待遇计算依据
5. **证据材料** → 按时间顺序排列，编制证据目录

### 6.2 证据固定方法

| 证据类型 | 固定方法 |
|---------|---------|
| 病历资料 | 盖章复印件；影像胶片保留原件 |
| 微信/钉钉记录 | 完整截图含对方信息、时间；必要时公证 |
| 邮件 | 保留原始邮件；截图含发件人、时间、主题 |
| 监控录像 | 尽早向物业/单位调取并备份 |
| 证人证言 | 书面证言签字按手印；附证人身份证复印件 |
| 交警责任认定书 | 原件留存 |
| 考勤记录 | 系统截图含时间戳；必要时公证 |

### 6.3 复印件规范
- 所有证据材料提交复印件，原件自行保管
- 复印件清晰可辨，A4纸大小
- 每页注明"复印件与原件一致"并签字
- 按证据编号排列装订

## Description:

TinkerClaw Computational Humor provides 12 conversational humor patterns, trigger guidance, generation templates, and ethical gates for agents whose persona includes humor, wit, or personality.

This skill is ready for commercial/non-commercial use.

## Publisher:

[globalcaos](https://clawhub.ai/user/globalcaos)

MIT-0

## Use Case:

Developers and agent builders use this skill to help an assistant decide when and how to produce brief, contextually appropriate humor while avoiding crisis, sensitive, formal, or high-stakes settings unless the user invites it.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Stylized humor can be inappropriate in crisis, sensitive, formal, or high-stakes conversations.

Mitigation: Use the skill's ethical gate and security guidance: suppress humor in crisis settings, block sensitive topics unless the user initiated humor, and keep professional usage restrained.

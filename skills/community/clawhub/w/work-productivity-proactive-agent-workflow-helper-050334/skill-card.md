## Description:

Helps AI-agent users, skill authors, maintainers, and teams turn proactive-agent productivity needs into practical workflows, checklists, analyses, code changes, and verification notes.

This skill is ready for commercial/non-commercial use.

## Publisher:

[kyro-ma](https://clawhub.ai/user/kyro-ma)

### License/Terms of Use:

MIT-0

## Use Case:

External users, developers, skill authors, maintainers, and teams use this skill to turn proactive productivity requests into concrete local-friendly work plans, templates, checklists, automation outlines, analyses, or code changes. It is intended for practical workflow support that clarifies goals, captures assumptions, and checks the result against success criteria.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad implicit invocation and generic trigger words may cause the skill to be selected for unrelated tasks.

Mitigation: Prefer explicit invocation or tighten trigger terms before deployment in environments where unintended activation would be disruptive.

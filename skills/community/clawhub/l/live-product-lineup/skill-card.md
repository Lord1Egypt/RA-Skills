## Description:

Plan the optimal product reveal order for TikTok Live sessions based on price anchoring, audience warmup, and peak engagement timing.

This skill is ready for commercial/non-commercial use.

## Use Case:

External sellers, creators, and live-commerce operators use this skill to convert a product list into a sequenced live selling plan with reveal order, pricing arc, stock planning, engagement beats, and host script blocks.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The main instruction file is malformed, which can prevent reliable loading or review.

Mitigation: Do not install or use this release as-is; require a clean UTF-8 Markdown SKILL.md and repeat review before deployment.

Risk: Generated live-commerce scripts can include incorrect stock counts, discounts, scarcity claims, or giveaway mechanics.

Mitigation: Verify inventory, discount setup, giveaway terms, and platform rules before going live.

Risk: Audience engagement prompts can request sensitive public-chat details such as precise viewer locations.

Mitigation: Use broad, non-sensitive engagement prompts and avoid asking viewers to disclose precise locations in public chat.

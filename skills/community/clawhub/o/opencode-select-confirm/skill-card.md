## Description:

Shows choice dialogs when users ask for recommendations among multiple options, and shows a confirmation dialog when users ask to confirm an action.

This skill is ready for commercial/non-commercial use.

## Publisher:

[oalh-wh](https://clawhub.ai/user/oalh-wh)

### License/Terms of Use:


## Use Case:

External users and developers use this skill to make recommendation, selection, and confirmation flows appear as explicit choice dialogs instead of free-form text.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Broad trigger phrases such as recommendation, selection, confirmation, and confirm may cause the skill to appear in ordinary conversations more often than intended.

Mitigation: Install it only where choice dialogs are desired for these flows, and review or disable the skill if it interrupts unrelated conversations.

# 重性精神障碍诊疗

## 使用时机

当患者出现以下情况时应用此技能：
- 情绪高涨/活动增多/睡眠需求减少（躁狂发作）
- 情绪低落/兴趣丧失/自杀意念（双相抑郁）
- 幻觉、妄想、言语行为紊乱（精神病性症状）
- 急性起病的精神病性症状（<3个月）
- 木僵、蜡样屈曲、违拗、刻板动作（紧张症）
- 系统性妄想但无精神分裂症特征性症状

## 一、双相障碍

### 躁狂发作药物治疗

#### 核心原则
以心境稳定剂为基础，急性期推荐第二代抗精神病药联合锂盐或丙戊酸盐。

#### 锂盐（首选）

| 参数 | 急性期 | 维持期 |
|-----|-------|-------|
| 剂量 | 1000-2000mg/d | 500-750mg/d |
| 血锂浓度 | 0.6-1.2mmol/L | 0.4-0.8mmol/L |
| 上限 | ≤1.4mmol/L | 老年≤1.0mmol/L |

**注意事项**：
- 从小剂量起，3-5天渐增至治疗量
- 分2-3次饭后服
- 老年/体弱/合用抗精神病药者减量
- 中毒表现：意识障碍、共济失调、高热→立即停药抢救

#### 抗癫痫药（锂盐无效/不耐受时）

| 药物 | 治疗剂量 | 维持剂量 | 目标血药浓度 |
|-----|---------|---------|-------------|
| 丙戊酸盐 | 800-1200mg/d（最高1800） | 400-600mg/d | 50-120μg/ml |
| 卡马西平 | 最高1000mg/d（最高1600） | 200-600mg/d | 4-12μg/ml |

**适用**：混合/快速循环发作

#### 抗精神病药
- 早期短期联用控制兴奋/激惹
- 首选第二代：喹硫平、奥氮平、利培酮
- 奥氮平联合锂盐/丙戊酸盐疗效更佳
- 氯氮平仅用于难治性躁狂
- 避免第一代以防诱发抑郁

#### 急性重症处理
- 极度兴奋/锂盐无效：电抽搐(MECT)，隔天1次，4-10次一疗程

### 抑郁发作治疗

#### 急性期决策

| 药物 | 剂量 | 关键注意事项 |
|-----|------|-------------|
| 碳酸锂 | 使血锂>0.8mmol/L | 有效率76% |
| 拉莫三嗪 | 100-200mg/d | 必须缓慢加量，防Stevens-Johnson综合征 |
| 喹硫平 | 300-600mg/d | 一线选择 |
| 奥氮平+氟西汀 | - | 联合疗效更优 |

**抗抑郁药使用限制**：
- 轻中度双相抑郁：**避免使用**
- 重度/持续者可使用，症状缓解后**尽快撤药**
- 转躁率10%-70%

#### MECT指征
- 严重消极自杀
- 抑郁性木僵
- 药物无效

### 长期复发预防

- 停药1年内复发率：双相40%，单相抑郁30%
- 长期维持指征：过去2年每年发作≥1次
- 锂盐预防：维持血锂0.4-0.8mmol/L，预防躁狂有效率>80%

## 二、精神分裂症

### 流行病学关键数据

| 参数 | 数值 |
|-----|------|
| 终生患病率 | 约1% |
| 年发病率 | 中位值0.15% |
| 男性发病高峰 | 20岁早期 |
| 女性发病高峰 | 25-35岁 |
| 平均寿命缩短 | 13-15年 |
| 自杀死亡率 | 约5% |

### 遗传风险评估

- 遗传率：家系64%，双生子81%
- 一级亲属患病率：父母5.6%，同胞10.1%，子女12.8%
- 单卵双生子同病率约50%
- 父系年龄>60岁：子女风险增加

### 神经发育异常标志

早期识别线索：
- 认知：平均智商较差、言语/语言问题
- 运动：儿童期震颤、抽动增加
- 躯体：臀部升高、内眦赘皮、通贯掌等轻度异常
- 社会：孤僻少友、社交自信低
- 神经功能软体征：眨眼频率增快、眼跟踪异常、P300波幅减低

## 三、急性短暂性精神病性障碍

### 诊断要点

1. **急性起病**
2. **病程**：精神病性症状持续 ≤ 3个月（DSM-5要求≤1个月）
3. **排除**：精神分裂症、心境障碍、物质使用、躯体疾病

### DSM-5亚型
- 有应激源
- 没有应激源
- 产后发作

### 鉴别要点
- 症状超3个月→考虑精神分裂症、分裂情感障碍
- 应激源后发生且<3个月，缓解彻底→强烈提示本病
- 必须排除做作性障碍、诈病

## 四、妄想性障碍

### 诊断要点

1. 一个或多个妄想，持续 ≥ 3个月（DSM-5 ≥ 1个月）
2. 妄想内容不荒谬离奇，结构系统严密
3. 除妄想影响外，功能无明显损害
4. 无清晰持久的幻听及其他精神分裂症特征性症状

### 必须排除的躯体疾病

| 躯体疾病 | 妄想特点 |
|---------|---------|
| 亨廷顿病 | 半数以上出现妄想 |
| 右侧脑梗死 | 伴病感失认、双重性记忆错误 |
| 卡普格拉综合征 | 见于中枢神经疾病、VitB12缺乏 |
| 癫痫 | 寄生虫/变兽妄想 |

## 五、紧张症

### 核心症状识别

- 木僵、肌肉僵硬、蜡样屈曲
- 缄默、违拗/被动服从
- 奇特姿势、刻板动作
- 模仿言语/动作
- 无目的兴奋激越

### 病因分类

1. **躯体疾病所致**：脑病、代谢紊乱（低钠/高钙）
2. **精神障碍有关**：精神分裂症、心境障碍
3. **排除**：仅发生在谵妄期或单纯药物所致不单独诊断

### 处理流程

1. **基础护理**：住院、监护、维持水电解质、保证营养
2. **病因治疗**：治疗潜在躯体疾病；药物所致者减量/换药
3. **药物治疗**：苯二氮䓬类短期改善
4. **ECT**：躯体疾病所致、长期拒食、致死性紧张症

## 输出要求

1. 明确诊断（疾病类型+发作相/亚型）
2. 制定个体化药物治疗方案
3. 制定血药浓度监测计划
4. 评估复发风险及长期预防策略
5. 排除器质性疾病

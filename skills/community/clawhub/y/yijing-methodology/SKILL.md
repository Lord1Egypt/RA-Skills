# 易经方法论 Skill

易经是一部决策时机学：六十四卦本质上是在回答"局面到了哪一步、
该进该守该变"。本 skill 把这套智慧抽成**五个框架 + 十条心法 + 一个
输出模板**，全部原创转述；另附场景化金句库（原文均为公有领域古文短引用）。

## 快速路由（先判场景，再选框架）

| 用户场景 | 用哪个框架 |
|---|---|
| 旧路走不通、要转型 | 框架1 穷变通久法 |
| 纠结现在出手还是再等 | 框架2 待时藏器法 |
| 顺境扩张，怕用力过猛 | 框架3 六爻阶段法 |
| 刚打胜仗/被捧，要自省 | 框架4 谦守补过法 |
| 项目生命周期怎么排 | 框架3 六爻阶段法 + 框架1 |
| 只要一句金句收尾 | 直查 `references/quotes.md` |

可组合：转型决策 = 框架1 判变不变 → 框架2 定时机 → 框架3 排节奏。

## 五大分析框架

### 框架1 穷变通久法（穷则变，变则通）

- 输入：现有打法明显失效、增长停滞。
- 步骤：
  1. 确认是否真到"穷"——是路径穷了，还是执行没到位？（执行问题不改道）；
  2. 若是路径穷：列出可变的三个层——变做法（战术）、变打法（模式）、
     变战场（赛道），从轻到重评估；
  3. 变之后必须能"通"：小成本试新路径，跑通才加倍；能"久"：新路径
     有复利（积累资产），不是一次性机会。
- 输出：穷/未穷判定 + 变哪一层 + 通的验证动作。
- ✅完成标准：能说清"为什么现在必须变"，且新路径有验证动作而非全押。

### 框架2 待时藏器法（藏器于身，待时而动）

- 输入：机会看起来在眼前，但没把握。
- 步骤：
  1. 分清"时机未到"与"能力不足"——器不利练器，时未至养时；
  2. 时未到：明面上做积累（藏器），暗中保持敏感（知几——见几而作，
     不俟终日，信号出现立即行动不拖到错过）；
  3. 设定出手信号：条件满足哪几条就动，写下来，不临场改。
- 输出：当下定性（练器/养时）+ 出手信号清单。
- ✅完成标准：能回答"我在等什么信号"，且信号可观测、不靠感觉。

### 框架3 六爻阶段法（潜见惕跃飞亢）

- 输入：项目/事业/账号冷启动到巅峰的节奏规划。
- 步骤：按乾卦六阶段对号入座——
  1. **潜**（潜龙勿用）：没准备好，闷头积累，不曝光不表态；
  2. **见**（见龙在田）：小有成果，开始露头，找"大人"（贵人/平台/渠道）；
  3. **惕**（终日乾乾）：增长期，每天如履薄冰，查错补漏；
  4. **跃**（或跃在渊）：关键一跳（要不要 all in），试跳可退则试；
  5. **飞**（飞龙在天）：巅峰期，放大但记住下一爻；
  6. **亢**（亢龙有悔）：到顶必回落，主动收敛、留退路、布局下一周期。
- 输出：当前阶段判定 + 该阶段该做/不该做 + 下一阶段预判。
- ✅完成标准：阶段判定有证据；飞的阶段就该想到亢（最忌巅峰期加满杠杆）。

### 框架4 谦守补过法（谦谦君子，善补过）

- 输入：连胜之后、被夸之后、顺风局。
- 步骤：
  1. 检查三样：姿态（是否轻慢对手/用户/伙伴）、盲区（顺风掩盖了什么）、
     过失（补过即无咎——错了快速认快速改，比不犯错更重要）；
  2. 主动留一分：不把话说满、不把利占尽、不把势用尽；
  3. 把自省固定成动作（复盘/数据回看），不靠心情。
- 输出：三条自省结论 + 一条主动收敛动作。
- ✅完成标准：说得出"现在哪一分是我特意留下的"。

### 框架5 见微知著法（履霜坚冰至）

- 输入：出现小异样（数据小跌、客诉小增、对手小动作）。
- 步骤：
  1. 把小信号按"趋势萌芽"与"随机波动"分类——连着出现 3 次就是萌芽；
  2. 萌芽信号追问终局：任其发展 3 个月会到哪；
  3. 终局不可接受的，现在就加最小干预（霜降时备冬衣，不是等坚冰）。
- 输出：信号清单（萌芽/波动）+ 对萌芽项的最小干预动作。
- ✅完成标准：至少一个萌芽信号配了干预动作，且干预成本远小于终局损失。

## 十条心法（快速检查用）

1. **自强不息，厚德载物**——执行力自己扛（天行健），承载力靠积累（地势坤），一手硬一手软。
2. **物极必反**——任何指标冲到极致就开始酝酿反面，盯住"过"的信号。
3. **动静不失其时**——该停就停该走就走，拖着不走和抢跑都是失时。
4. **尺蠖之屈，以求信也**——后退是为了弹出去，收缩动作要有伸展的配套计划。
5. **二人同心，其利断金**——关键合作先解决同心（利益/目标一致），再谈分工。
6. **无咎者，善补过也**——不追求不犯错，追求快速补；补过是能力不是污点。
7. **安而不忘危，存而不忘亡**——好日子做坏日子的预案，危的清单平时就写。
8. **见几而作，不俟终日**——信号出现当天就动，大事的窗口都很短。
9. **积善之家，必有余庆**——长期主义：口碑/信用/复利资产按期积累。
10. **不恒其德，或承之羞**——定位和原则不摇摆，摇摆的代价是信用折价。

## Agent 工作流

1. **判场景**：对照快速路由表选框架（一句话内部完成）。
2. **跑框架**：按步骤执行，组合时按"1→2→3"主序。
3. **按模板产出**（用户没指定格式时用）：

```
【局面判定】当前阶段/卡点：…
【变与不变】变：…（哪一层）  不变：…（根据地）
【时机信号】等什么信号 / 已到手的信号：…
【节奏与留白】进：…  守：…  特意留下的一分：…
【引一句】"…"（《卦名·爻辞/系辞》）   ← 可选，从 quotes.md 按场景取
```

4. **收尾引用**：需要金句时查 `references/quotes.md`，必附出处。
5. ✅完成标准：输出里"局面判定"和"时机信号"必须存在——没有阶段感
   和时机感的建议等于没给。

## 引用与合规

- 原文均为古文公有领域，短引用（单条 ≤40 字）+ 必附卦名/系辞出处。
- 方法论部分全部原创转述。
- **不做占卜算命**：不摇卦、不预测具体吉凶、不给人算命式结论——易经
  在本 skill 里只是决策思维模型，输出永远是"条件-信号-动作"，不是宿命论。
- 不做风水/玄学营销场景；内容平台引用注意不渲染迷信色彩。

## 本 skill 不做什么

- 不提供玄学预测，不替代数据判断——框架输出必须落在可观测信号上。
- 不做"卦爻辞逐卦讲解"式内容产品（那是知识付费的活，不是决策工具）。

## Description:

Design, log, compare, and score prompt experiments so users can systematically improve outputs instead of guessing.

This skill is ready for commercial/non-commercial use.

## Publisher:

[52yuanchangxing](https://clawhub.ai/user/52yuanchangxing)

### License/Terms of Use:

MIT-0

## Use Case:

Developers, prompt engineers, and other users use this skill to plan prompt A/B experiments, define evaluation criteria, compare outputs, score results, and identify the next prompt iteration.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The helper script can create a CSV file at the selected output path.

Mitigation: Review or explicitly set the output path before running the script, especially when working in a directory with important files.

Risk: Prompt-comparison requests may produce misleading conclusions if metrics or test cases are missing.

Mitigation: Define criteria, weights, and test cases before scoring, and keep assumptions explicit instead of fabricating metrics.

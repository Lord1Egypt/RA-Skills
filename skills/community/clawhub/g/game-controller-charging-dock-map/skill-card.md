## Description:

Create a dock layout card for game controllers, with assigned slots, cable labels, return rules, charge routine, and a shared setup reset checklist.

This skill is ready for commercial/non-commercial use.

## Use Case:

External users use this prompt-only skill to organize a shared game area by assigning controller homes, cable labels, charge routines, accessory zones, and a printable reset checklist.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: Users may ask for help with damaged chargers, batteries, exposed wires, overheating devices, or hardware repair decisions.

Mitigation: Keep responses limited to controller homes, cable labels, dock habits, and ordinary organization; redirect electrical repair or damaged-device issues to manufacturer guidance or a qualified repair option.

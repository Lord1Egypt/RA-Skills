## Use Case:

External solo founders and business builders use this entry skill to start the Show Me The Money suite, install the full pack, and route work across specialized business-planning, product, growth, finance, review, memory, and reporting skills.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The entry skill directs users to install a large external business-automation skill pack through a mutable install path.

Mitigation: Review the external suite at the exact version or commit before installation, and prefer a pinned version in an isolated agent environment.

Risk: The broader suite may support ads, outreach, payment, deployment, update, or skill-writing workflows.

Mitigation: Require explicit human confirmation before any workflow that spends money, contacts third parties, deploys assets, updates code, or writes new skills.

## Use Case:

Independent developers, small teams, project managers, and operations users can use this skill to structure AI employee roles, track local employee state, and produce work status or report guidance. Security evidence indicates the current package should be treated mainly as a local employee record and memory manager rather than a complete automation system.

### Deployment Geography for Use:

Global

## Known Risks and Mitigations:

Risk: The release overpromises automation relative to the packaged files.

Mitigation: Set expectations that the package behaves mainly as a local employee record and memory manager, and verify any broader automation before operational use.

Risk: Unsafe local file handling could read or write outside intended folders when role, employee ID, or template values are untrusted.

Mitigation: Use the skill only in an isolated project or container, avoid sensitive team or employee data, and pass only trusted role, employee ID, and template values.
